## 摘要
视觉-语言-动作（VLA）模型在具身智能领域展现出卓越能力，但其高计算成本和有限的预测动作长度阻碍了实时部署。尽管Dadu-Corki作为面向高效具身智能的专用加速器已被提出，但它未利用机器人与其环境之间的固有交互模式，导致预测动作长度相对较短。我们观察到机器人环境自然地在活跃状态（精确动作至关重要）与非活跃状态（动作对任务成功影响有限）之间交替。这一洞见催生了新的调度机会：在非活跃状态进行长动作长度的推测性预测，并在活跃状态进行选择性验证。为此，我们提出SpecVLA，一个算法-系统协同设计框架，能够自适应地平衡动作长度、推理延迟与任务可靠性。在算法层面，SpecVLA引入了一种状态感知的VLA推理执行范式，以及一种硬件友好的小型验证模型（sVLA）构建方法，采用差分残差和块级混合精度量化。在系统层面，我们开发了一个由GPU和机器人专用硬件模块组成的异构架构，并设计了一种推测性数据流，通过并行执行解耦VLA与sVLA。在LIBERO和ManiSkill基准上对OpenVLA与RDT的全面评估表明，SpecVLA在保持任务成功率的同时显著降低了端到端延迟。通过实现长动作长度推测性预测与及时验证，SpecVLA在实时机器人操作中同时实现了高效率与高可靠性。

## Abstract
Vision-Language-Action (VLA) models have demonstrated remarkable capabilities in the field of embodied AI, but their high computational cost and limited predicted action length hinder real-time deployment. Although Dadu-Corki, a dedicated accelerator for efficient embodied AI, has been introduced, it does not exploit the inherent interaction patterns between the robot and its environment, which results in a relatively short predicted action length. We observe that robotic environments naturally alternate between active states-where precise actions are crucial-and inactive states-where actions have limited impact on task success. This insight enables a new scheduling opportunity: long-action-length speculative prediction in inactive states, paired with selective verification in active states.   We propose SpecVLA, an algorithm-system co-design framework that adaptively balances action length, inference latency, and task reliability. On the algorithm side, SpecVLA introduces a state-aware VLA inference execution paradigm and a hardware-friendly construction of a smaller verification model (sVLA) using differential residuals and block-wise mixed-precision quantization. On the system side, we develop a heterogeneous architecture consisting of a GPU and a robotic-specific hardware module, along with a speculative dataflow that decouples VLA and sVLA through parallel execution. Comprehensive evaluations on OpenVLA and RDT across LIBERO and ManiSkill benchmarks show that SpecVLA reduces end-to-end latency significantly while preserving task success rate. By enabling long-action-length speculative prediction with timely verification, SpecVLA achieves real-time robotic manipulation with both high efficiency and reliability.

  - 机器人环境自然地在“活跃状态”（如抓取、对齐、放置，动作对任务成败影响大）和“非活跃状态”（如机械臂移向目标，中间动作影响小）之间交替。
  - 连续环境帧之间存在高时间冗余，使得使用量化的小型 VLA（sVLA）进行低成本验证成为可能。
  - 现有加速器（如 Dadu-Corki）未利用这种状态轮换特性，导致推理效率低下。
- **整体含义**：本文提出 SpecVLA，一种算法-架构协同设计框架，通过在非活跃状态执行长动作推测、在活跃状态执行选择性验证，在保持任务成功率的同时大幅降低端到端延迟，从而实现实时、可靠的机器人操作。

## 2. 方法论：核心思想、关键技术细节、算法流程

### 2.1 核心思想
- 采用“推测-验证”（Speculative Inference and Verification）范式：  
  - **非活跃状态**：直接使用全精度 VLA 预测长动作序列（如 8 个动作/次），不逐一验证，以摊薄推理成本。  
  - **活跃状态**：使用轻量级 sVLA 对每个预测动作进行快速验证，若验证失败则回滚并重新调用 VLA 生成新序列。

### 2.2 算法侧关键技术
- **环境状态预测算法**（Algorithm 1）：
  - 计算机器臂与每个物体之间的欧氏距离 \( D_i = \sqrt{\sum_{k=1}^{3}(G_c[k] - O_{i,c}[k])^2} \)。
  - 若机械臂爪处于打开状态（\(G_s=-1\)）且附近物体数量 \(n<1\)，判定为非活跃状态；否则为活跃状态。
  - 阈值 \(T_d\) 控制“附近”的判定范围。
- **动作验证机制**：
  - 对预测动作 \(A\) 与 sVLA 生成的期望动作 \(A'\) 进行逐维 min-max 归一化。
  - 计算加权 L1 距离：  
    \[
    L_1(\tilde{A}, \tilde{A}') = \sum_{k=1}^{7} w[k] \times |\tilde{A}[k] - \tilde{A}'[k]|, \quad w[k] = \frac{1}{\sigma[k]}
    \]
  - 其中 \(\sigma[k]\) 为第 \(k\) 维动作的标准差，用于降低高方差维度的权重、提高低方差关键维度的敏感性。
  - 若距离小于阈值 \(T_s\) 则接受动作，否则拒绝并触发 VLA 重新推理。
- **sVLA 构建：差分残差 + 分块混合精度量化**：
  - 计算相邻时间步特征的残差 \( \Delta X_i = X_i - X_{i-1} \)，残差分布更窄，更利于量化。
  - 将残差矩阵划分为固定大小的块，对每个块计算绝对值和：
    - 小于阈值 \(T_z\) → 置为 0（0-bit 零块）；
    - 大于阈值 \(T_h\) → 8-bit 高精度量化；
    - 介于两者之间 → 4-bit 低精度量化。
  - 硬件友好的分块分解：高精度块自动拆分为低比特分量和高比特分量，使 PE 阵列统一使用低精度数据通路；量化结果与累积输出按层传播。

### 2.3 系统侧设计
- **异构架构**：GPU（执行全精度 VLA）+ 机器人专用硬件模块（执行 sVLA、状态预测、预处理）。
- **推测性数据流（Speculative Dataflow）**：
  - 打破 VLA 与 sVLA 之间的串行依赖，允许 VLA 在验证结果出来前“推测性”地预计算下一序列；
  - 验证成功则提前终止无用的推测计算，验证失败则继续完成剩余 VLA 计算；
  - 机械臂动作执行与 GPU/专用硬件计算并行化，进一步隐藏延迟。
- **机器人专用硬件模块**：
  - SIMD 型 PE 阵列：统一低精度数据通路，支持块分裂、移位累加与块标签控制。
  - 可重构状态预测器（State Predictor）：复用同一距离计算流水线实现“环境状态预测”和“动作验证”两种模式，节省面积。
  - 预处理模块：集成残差生成、块级量化、标签生成，减少数据搬运，支持流水化运行。

## 6. 主要结论与发现

- SpecVLA 在保持与基线相当成功率的前提下，显著降低端到端延迟：
  - 相对 CPU 加速 **12.1×**；
  - 相对 NVIDIA A100 GPU 加速 **2.9×**；
  - 相对 Dadu-Corki-ADAP 加速 **1.9×**；
  - 相对 MoLe-VLA、VLA-Cache、Spec-VLA、HeiSD 分别加速 1.66×、2.59×、2.48×、1.61×。
- 每动作平均延迟约 **61 ms**，满足实时控制要求（<100 ms）。
- 非活跃状态平均占比 74.2%，平均回滚频率仅 9.5%（复杂任务下 16.4%），验证了推测机制的有效性和安全性。
- 推测长度为 8 时，有效动作长度平均约 7.1，VLA 调用次数减少 3.5×。
- 差分残差 + 分块量化使 sVLA 中平均生成 35.8% 零块、59.3% 低精度块、4.9% 高精度块，大幅降低计算量，同时保持短序列精度。
- 能量效率相对 CPU、GPU、Dadu-Corki-ADAP 分别提升 8.0×、2.1×、1.5×。
- 消融表明：验证机制贡献约 7% 的成功率提升；推测数据流贡献 79.8% 的额外延迟降低；专用硬件模块进一步减少 20.6% 延迟。

## 7. 优点

- **算法-架构协同设计**：不是单纯算法或单纯硬件优化，而是从机器人环境的状态交替出发，端到端地统一优化推理、验证与执行。
- **创新性强的推测范式**：区别于传统单次序列推测，提出“并行预测、串行验证”的闭环机制，能应对物理环境突变，提升任务成功率。
- **硬件友好的量化方案**：差分残差 + 分块混合精度的设计既利用了时间冗余，又规避了混合精度在硬件上实现复杂的问题，通过块分裂统一数据通路。
- **可重构状态预测器**：将环境状态预测与动作验证复用同一距离计算流水线，节省硬件面积与功耗。
- **全面的消融与设计探索**：定量分析了算法、数据流、硬件模块各自贡献，并对关键阈值和预测长度进行了敏感性分析。
- **面向实际部署**：考虑了传感器噪声、实时性约束和硬件面积/功耗开销，具有较强的工程实用性。

## 8. 不足与局限

- **实验覆盖仍有局限**：

  - RDT 基线在 PlugCharger 任务太弱，无法体现 SpecVLA 在困难任务中的增益普适性。
- **阈值设定策略**：采用独立一维扫描，可能遗漏阈值间的联合最优；对 \(T_z\)、\(T_h\) 的探索图（图 19）显示成功率指标与主实验不一致（图 19 中纵轴为 40–60%，疑似 sVLA 精度或不同设定），存在呈现不一致的风险。

- **通用性**：状态判定依赖机器人感知系统提供物体坐标和机械臂状态，对未知或动态物体的场景适用性有限；算法对超参数（如 \(T_s\)、\(T_d\)、\(L\)）较敏感，需要针对新环境重新调参。
- **可扩展性**：专用硬件模块针对 7 维动作空间和特定 VLA 结构设计，跨模型、跨机械臂的迁移性有待验证。

## 摘要
视觉-语言-动作（VLA）模型在现实世界中的部署常常受限于效率与性能的权衡、跨实体泛化以及执行平滑性。我们提出了NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，从而优化计算资源和模块化程度。为了弥合异构机器人之间的语义鸿沟，我们引入了GESTURE-7，一种统一的基于语言的动作表示。此外，我们的引导动作算法通过基于掩码的平滑性约束来强制运动学连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上实现了85.5%的平均成功率，并将动作生成加速约2.7倍。这种异步设计为实际机器人应用实现了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：机器人操作正从模块化流水线转向以视觉-语言-动作（VLA）模型为代表的端到端学习范式。VLA 模型将感知、语言与控制统一在单一架构中，以实现自然语言指令跟随与复杂任务执行。
- **核心问题**：尽管 VLA 模型发展迅速（RT-1、OpenVLA、InternVLA 系列等），但在真实世界部署中仍面临三大瓶颈：
  - **效率-性能权衡**：单一同步架构采用统一时间分辨率，无法同时支持低频率的语义理解与高频率的电机控制。
  - **跨本体泛化不足**：将连续运动学映射到离散 token 需要庞大的词表和大规模演示数据，难以统一异构机器人平台的动作语义。
  - **执行平滑性不足**：异步实时推理与动作块生成之间的时间错配导致明显的抖动与执行不连续。
- **整体含义**：论文旨在系统性地解决上述三大挑战，提出一种可扩展、高效且响应迅速的 VLA 部署新范式，为具身智能在实际机器人系统中的应用奠定基础。

## 2. 方法论：核心思想、关键技术细节与算法流程

论文提出 **NebulaVLA**，包含三大核心技术贡献：

### （1）异构双频架构（Asynchronous Dual-Frequency Architecture）

- 借鉴 Kahneman 的“快慢思维”认知范式，将系统解耦为两层：
  - **System 2（慢系统，约 10 Hz）**：使用 Qwen3-VL 作为骨干，执行高层语义推理与任务规划，输出抽象的动作为引导信息。
  - **System 1（快系统，约 20 Hz）**：采用 Diffusion Transformer（DiT）生成器，接收 System 2 的引导信息与高频视觉输入，输出执行动作。
- 两系统显式分离，支持分布式部署与异步通信，大幅降低交互延迟并优化计算资源利用。

### （2）GESTURE-7：统一语言动作表示

- 将末端执行器状态编码为 7 维向量：`[x, y, z, r, p, w, gesture]`
  - `(x, y, z)`：笛卡尔位置（厘米，取整）
  - `(r, p, w)`：姿态角 roll/pitch/yaw（度，取整）
  - `gesture`：自然语言关键词（如 "grasp"、"push"、"pinch"），表示手部姿态
- 关键设计：不同形态的机器人执行相同动作时共享相同的关键词（如平行夹爪与灵巧手抓取均表示为 `grasp`），从而统一异构平台的动作语义，并天然支持语言条件下的强化学习。

### （3）Guide Action 机制：掩码引导的轨迹平滑

- 灵感来源于图像外推（Image Outpainting）：在生成下一个动作块时，将前一个动作块中未执行的动作作为“引导锚点”输入扩散模型。
- 扩散去噪过程中通过二进制掩码强制保留已知动作：

```
p_θ(A^t-1_full | A^t_full, A_prior, τ)
```

- 掩码更新规则：

```
A^t-1_full = M ⊙ A^t-1_prior + (1 - M) ⊙ A^t-1_noisy
```

  - `M[1..k] = 1`：锚点区域（严格保留已知动作）
  - `M[k+1..T] = 0`：生成区域（由模型预测）
- 引导动作数量在训练时从 0～3 随机采样，以适应不同的推理延迟。

### （4）三阶段训练流程

- **Stage 1（System 2 SFT）**：监督微调，包含五类任务：
  1. GESTURE-7 格式的末端姿态回归
  2. 2D 关键点回归
  3. 2D 路点预测（2 Hz）
  4. 3D GESTURE-7 轨迹预测（2 Hz）
  5. 思维链（CoT）生成：子任务分解 + 自然语言描述 + 未来轨迹
- **Stage 2（System 2 RL）**：基于 GRPO 的强化学习，使用多类奖励函数：GESTURE-7 距离、关键点定位奖励、路点奖励（含 DTW 距离）、轨迹奖励、格式奖励。
- **Stage 3（System 1 SFT）**：联合优化 System 2 与 System 1 权重（视觉编码器冻结），使用加权流匹配损失，损失仅作用于掩码为 0 的新生成区域：

```
L(θ) = E[ (1 - M) ⊙ (ε - ε_θ(x_t, t))² ]
```

- 该流程确保了训练与推理频率的严格对齐。

- **总体性能**：NebulaVLA 在 LIBERO-Plus 上达到 85.5% 的平均成功率，超越 InternVLA-M1（81.3%，+4.2%）、OpenVLA-OFT+（79.6%）、GR00T N1.5（59.0%）和 π0.5（58.0%）。

- **真实世界部署**：

## 7. 优点与亮点

- **架构创新**：异步双频架构是对“快慢系统”认知范式的成功工程化实现，有效解决效率-性能权衡问题，且原生支持分布式部署。
- **统一动作表征**：GESTURE-7 以自然语言关键词统一异构机器人动作语义，设计简洁优雅，既降低学习负担（位置和角度刻意量化取整）又天然兼容强化学习。
- **内生平滑机制**：Guide Action 将平滑性约束内化到扩散生成过程中，而非事后后处理（如样条插值），从生成源头保证轨迹连续性，思路新颖且具有理论依据（连接图像外推技术）。

## 8. 不足与局限性

- **频率静态分配**：当前 10 Hz / 20 Hz 的频率配置为经验确定且固定不变，最优配置可能因任务领域而异，动态自适应调度仍是未解问题。
- **Guide Action 的响应延迟**：依赖固定引导锚点，在快速变化环境中可能引入轻微响应延迟。

## 摘要
当前的灵巧抓取规划器主要优化物理稳定性，关注物体是否能够被抓住，而不是如何抓取以支持下游功能性任务。然而，将抓取合成条件化为特定的人体抓取分类通常需要代价高昂、带有物体标注的数据集。为解决这些限制，我们提出了CoToGrasp，一种新颖的生成框架，能够严格条件化于特定接触拓扑来合成多样化、稳定的抓取。为绕过数据收集瓶颈，CoToGrasp完全以物体无关的方式进行训练。我们引入了一个基于特征的规范工作空间，将局部物体特征投影到统一的以抓取器为中心域中，有效地将语义功能意图与任意物体几何形状解耦。通过在该工作空间内学习抓取器的固有接触流形，我们的模型在推理时能够对未见过的物体实现零样本泛化。在大型DexGraspNet数据集上的广泛评估表明，CoToGrasp达到了最先进的性能，优于现有的分类引导规划器。最后，我们在物理机器人平台上证明了所合成接触拓扑的物理可行性和运动学可行性。代码可在我们的项目网站上获取：https://cea-list.github.io/cotograspweb/ 。

## Abstract
Current dexterous grasp planners primarily optimize for physical stability, focusing on whether an object can be grasped rather than how it should be grasped to support downstream functional tasks. However, conditioning grasp synthesis on specific human grasp taxonomies typically requires prohibitively expensive, object-annotated datasets. To address these limitations, we propose CoToGrasp, a novel generative framework that synthesizes diverse, stable grasps strictly conditioned on specific contact topologies. To bypass the data collection bottleneck, CoToGrasp is trained entirely in an object-agnostic manner. We introduce a feature-based canonical workspace that projects local object features into a unified gripper-centric domain, effectively decoupling the semantic functional intent from the arbitrary object geometry. By learning the intrinsic contact manifold of the gripper within this workspace, our model achieves zero-shot generalization to unseen objects at inference. Extensive evaluations on the large-scale DexGraspNet dataset demonstrate that CoToGrasp achieves state-of-the-art performance, outperforming existing taxonomy-guided planners. Finally, we demonstrate the physical viability and kinematic feasibility of our synthesized contact topologies on a physical robot platform. Code is available on our project website at https://cea-list.github.io/cotograspweb/ .

## 1. 论文的核心问题与整体含义

- **研究动机**：现有灵巧抓取规划器主要优化物理稳定性，只回答“能否抓住物体”，而没有回答“应该怎样抓取”以支持下游功能性任务。随着人形机器人和LLM高层推理的发展，抓取必须具备任务级、语义级的控制能力，例如精确抓取、工具操作、手指步态等。
- **核心瓶颈**：若直接基于人类抓取分类学（如Feix、Gonzalez）对抓取合成进行条件化，通常需要逐物体标注的昂贵数据集，严重限制了泛化性和实用性。
- **论文目标**：提出CoToGrasp，一个**物体无关**的生成框架，仅以抓取器自身的表面几何与语义接触拓扑为训练输入，学习抓取器固有的接触流形，从而在推理时对**未见过的物体**实现零样本的、严格符合指定接触拓扑的稳定抓取生成。

## 2. 论文提出的方法论

- **核心思想**：利用接触的对称性——抓取器与物体的接触是几何对称关系。传统方法在物体表面搜索“哪里可以触摸”，本文将其反转，在抓取器的规范空间内问“物体的哪些区域会激活我的手指”。这使学习域从**无界的、高熵的物体表面**变为**有界的、固定结构的抓取器流形**，从而避免记忆任意物体几何。
- **关键组成**：
  - **抓取器接触拓扑定义**：基于Gonzalez分类法，定义M=21种接触拓扑，每种对应一个语义模板 \(A_m\)，将抓取器活动表面的离散点（“手印” \(H\)）映射到N=22个解剖接触区域。该分类法仅依据接触表面，天然适配不同拟人机械手。
  - **特征化规范工作空间**：定义一个固定于抓取器坐标系的空间基 \(W\)。训练时从抓取器点云、推理时从物体点云提取局部特征（DGCNN），再通过对齐距离加权的kNN聚合投影到 \(W\) 上，得到与输入几何解耦的空间token。物体变换到规范空间后反转法线，形成抓取器表面的“负模”。
  - **条件化生成模型**：将拓扑嵌入显式拼接至每个工作空间点特征（硬条件化），并加入位置编码，经Transformer编码器建模接触点间非局部依赖；再用Set Transformer池化为全局潜描述，由CVAE建模局部接触随机性，解码输出每个工作空间点的接触区域概率。
  - **推理阶段的验证与优化**：
    1. 标签一致性检查：对比预测模板与真实模板的接触区域集合，允许至多一个区域偏差，拒绝根本性拓扑错误。
    2. 力闭合估计：基于预测接触点计算抓取力旋量空间，判断是否满足力闭合，不满足则重新采样潜变量（最多20次）。
    3. 能量优化：最小化接触距离、物体穿透、自碰撞、关节极限和新增的**排斥项**（让未接触手指/手掌远离物体），得到最终关节配置 \(Q^*\)。

- **训练数据生成**：均匀采样10,000个运动学可行的关节配置，计算对应手印，并各配对全部21个接触模板，得到210,000个训练数据。整个过程完全在抓取器规范坐标系内进行，**不需要任何物体网格或物理仿真**。

- CoToGrasp在分类引导的灵巧抓取合成中达到**SOTA**：在DexGraspNet上成功率（26.72%）和拓扑遵从度（17.18%）均优于Dexonomy（21.13%和14.28%），尤其在高约束的精确抓取上优势明显。

- 验证管线（标签一致性检查+力闭合估计）对保持拓扑有效性至关重要：移除后TC下降约2.5个百分点。

- 存在物理仿真与严格语义指标之间的张力：仿真中手指微调导致的偶发接触会被严格指标判定为拓扑错误，实际功能意图可能已达成。

## 7. 优点

- **物体无关训练**：完全绕开昂贵的物体级标注，训练仅需抓取器运动学采样，数据生成成本极低。
- **特征化规范工作空间**：巧妙地将物体几何与语义解耦，使模型能学习抓取器内在的接触能力，具有跨几何零样本泛化能力。
- **严格接触拓扑条件化**：以Gonzalez接触区域而非关节配置作为条件，自然适配不同拟人手，避免了Dexonomy那种“关节模板与物体几何强耦合”的脆弱性。
- **模块化设计**：全局抓取位姿作为外部先验，可灵活接入高层任务规划或运动学关键帧，支持后续如手中操作等应用。
- **评估体系较完善**：提出了TC、语义熵、稳定熵等新指标，并对无分类模型的模式坍塌进行了量化分析；验证管线能有效过滤不可行抓取。
- **真实世界验证**：在物理平台上证明了语义接触拓扑不仅是理论上的，也能被执行器实际执行。

## 8. 不足与局限

- **TC绝对分数偏低**：由于指标不对称惩罚“多余接触”，仿真中因运动学约束导致的邻指偶发接触常使精确抓取被误判为其他拓扑，可能低估实际功能正确性。
- **成功率低于无分类基线**：CoToGrasp被强制生成多样化的拓扑（包括几何上不利的精确抓取），总体上物理成功率（36.94%）低于可自由退化为功率抓取的方法；这反映了“语义严格性”与“物理成功率”之间的固有折中。
- **对接触区域划分依赖人工**：N=22个解剖区域和21个拓扑模板是人工针对Shadow/Allegro手定义的，扩展到手型不同（如四指与五指）时需要重新调整，Allegro手甚至需要显式删减拓扑M6。
- **真机控制局限**：位置控制框架导致手指异步接触、物体偏移，实际接触点与预测拓扑存在漂移；当前benchmark仅验证静态保持，未验证动态操作。
- **泛化性验证有限**：实验仅在Shadow Hand和Allegro Hand两种手上进行，未测试其他灵巧手；分类对比仅有一个基线（Dexonomy），且出于公平性过滤了几何不兼容的配对，可能略微美化整体成功率。
- **训练资源未详细展开**：虽报告了4×A100、35小时，但未提供显存占用、能耗等细节，复现成本难以精确估计。

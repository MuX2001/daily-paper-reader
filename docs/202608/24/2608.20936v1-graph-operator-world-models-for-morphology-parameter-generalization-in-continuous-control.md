## 摘要
连续控制的世界模型通常针对固定物理系统进行训练，当已知形态参数（如连杆长度、质量、阻尼和驱动）发生变化时，模型性能可能会下降。现有方法通常将这些参数作为条件信息提供，但未明确学习到的转移中哪些部分应保持可复用，哪些部分应随形态变化。我们提出了图算子世界模型（GraphOp-WM），这是一种结构化世界模型，用于在相关铰接机器人家族中跨未见形态参数进行泛化。GraphOp-WM将实体及其运动学关系表示为属性图，并将每个转移分解为与形态无关的局部动力学基和一个与形态相关的结构化算子。该算子结合了节点局部调制、运动学树耦合和低秩全局校正，而架构信息分离、基归一化和配对形态监督促使静态形态依赖性由算子路径承载。图级读出和边级动作表示为奖励、价值和TD-MPC风格规划提供了兼容接口。我们进一步定义了受控的MuJoCo参数划分，涵盖Hopper、Walker2d和HalfCheetah中连杆几何、质量、阻尼和驱动参数的插值、外推和保留组合。

## Abstract
World models for continuous control are commonly trained for a fixed physical system and can degrade when known morphology parameters such as link lengths, masses, damping, and actuation change. Existing approaches often provide these parameters as conditioning information, but leave unspecified which part of the learned transition should remain reusable and which part should change with morphology. We propose Graph-Operator World Models (GraphOp-WM), a structured world model for generalization across unseen morphology parameters within related articulated robot families. GraphOp-WM represents bodies and their kinematic relations as an attributed graph and factorizes each transition into a morphology-independent local dynamics basis and a morphology-conditioned structured operator. The operator combines node-local modulation, kinematic-tree coupling, and a low-rank global correction, while architectural information separation, basis normalization, and paired-morphology supervision encourage static morphology dependence to be carried by the operator pathway. Graph-level readout and edge-wise action representations provide a compatible interface for reward, value, and TD-MPC-style planning. We further define controlled MuJoCo parameter splits covering interpolation, extrapolation, and held-out compositions of link geometry, mass, damping, and actuation parameters in Hopper, Walker2d, and HalfCheetah.

## 1. 核心问题与整体含义

- **研究背景**：世界模型（World Models）在连续控制中被广泛用于提高强化学习的样本效率，例如 DreamerV3、TD-MPC2、PWM 等方法已经在多种任务套件上取得了优异表现。但这些模型通常针对**固定物理系统**训练，当机器人的形态参数（连杆长度、质量、阻尼、驱动器 gear 等）发生变化时，模型性能会显著下降。
- **现有方法的不足**：已有的形态条件化方法（如 QWM、WestWorld 等）将形态参数作为条件输入（context vector、token embedding 或专家路由信号），但这种方式**没有明确区分**：学习到的状态转移中，哪些部分是跨形态可复用的，哪些部分应当随形态参数变化而改变。仅把形态作为输入信号，无法告诉模型"参数变化如何具体改变动力学耦合关系"。
- **核心研究问题**：能否通过**显式分解可复用的局部动力学与形态引起的耦合变化**，让一个紧凑的世界模型泛化到未见过的物理形态参数？
- **总体含义**：该论文提出 GraphOp-WM，将机器人表示为属性图，将状态转移分解为"形态无关的共享局部动力学基"与"形态条件化的结构化算子"两部分，分别承担可复用与随形态变化的功能，从而在相关铰接机器人家族内实现零样本（zero-shot）动力学预测与规划泛化。

## 2. 方法论

### 2.1 核心思想

GraphOp-WM 的核心思想是**信息分离**式转移分解：形态无关的局部动力学基负责描述每个刚体在局部状态和动作下的"标准响应"；形态条件化的算子则负责将该标准响应按当前形态的物理属性进行调制与耦合。通过架构约束和训练目标，迫使形态依赖全部落在算子通路中。

### 2.2 形态图表示

- 将 MuJoCo XML / DMControl 规范解析为**体-关节图**：
  - **体节点（Body nodes）**：包含质量、惯性、几何、接触、类型、坐标系等静态属性。
  - **关节边（Joint edges）**：包含关节类型、轴、原点、范围、阻尼、gear 等静态属性。
  - **驱动器边（Actuator edges）**：关联动作命令与受控关节。
- 动态特征（位置、姿态、线速度、角速度、接触信号、关节位置/速度、动作命令）附着在对应节点或边上。
- 在同一机器人家族内，图拓扑固定，形态变化通过静态节点/边属性体现，而非改变图大小。

### 2.3 局部动力学基（Morphology-Independent Local Dynamics Basis）

- 共享的局部核函数 \( b_\theta \) 为每个体预测一个候选增量：
  \[
  B_{t,i} = b_\theta(z_{t,i}, \text{Agg}_{j\in N(i)}[q_{t,ij}, \dot{q}_{t,ij}, a_{t,ij}], \text{type}_i)
  \]
- 该核函数**不接收**质量、长度、惯性、形态 ID 或池化形态嵌入——从架构上阻断静态形态信息进入局部基。
- 进行**基归一化**（除以 RMS 幅度），消除基与算子之间的尺度模糊性。

### 2.4 结构化形态算子（Structured Morphology Operator）

转移预测为：
\[
\hat{Z}_{t+1} = Z_t + A_{m,t} \bar{B}_t
\]
其中形态算子：
\[
A_{m,t} = I + \text{Diag}(d_{m,t}) + E_m \text{Diag}(w_{m,t})E_m^\top + U_{m,t}\text{Diag}(s_{m,t})U_{m,t}^\top
\]

四个成分各自的物理含义：

| 成分 | 作用 |
|------|------|
| 恒等项 \(I\) | 保持基础状态 |
| 对角项 \(\text{Diag}(d_{m,t})\) | 体局部响应调制（如质量、惯性的局部影响） |
| 关联矩阵项 \(E_m \text{Diag}(w_{m,t})E_m^\top\) | 沿运动学树的结构化耦合（关节阻尼、gear 等的影响传播） |
| 低秩项 \(U\text{Diag}(s)U^\top\) | 残差全局模式（躯干-肢体耦合、接触介导耦合等） |

- 形态编码器只读静态图属性，输出节点系数、边系数和 \(r\) 个全局模式（经 QR 正交化）。
- 静态系数通过**共享的状态相关门控**（tanh 形式）按当前姿态、速度和接触状态激活，门控中不含可训练的形态标识符。
- 低秩项仅在数值诊断显示残差谱快速衰减时才保留。

### 2.5 信息分离与配对监督

- **架构信息分离**：静态形态属性只能进入 \(A_{m,t}\)，局部基只观察动态局部状态和动作。
- **基归一化**：消除基/算子之间的任意尺度互易。
- **配对形态监督**：对同一姿态、同一动作序列的两个形态变体，使用同一个局部基、两个不同算子分别预测转移，配对损失迫使形态差异由算子而非基来承担。

### 2.6 奖励、价值与动作接口

- **图级读出**：全局查询注意力 + 根节点 token 拼接，得到固定维度的全局表征 \(g_t\)，供奖励和价值头使用。
- **奖励分解**：全局成分（进度、高度、直立）+ 局部体成分（接触）+ 边成分（驱动代价），灵活适应不同任务。
- **边级动作表示**：动作沿驱动器边嵌入，模型输出动作数等于当前形态的驱动器数量，天然适配变维动作空间。
- **价值头**：\(V_\xi(g_t, e_k)\)，其中 \(e_k\) 是任务嵌入，可进入奖励/价值/策略头，但**不进入**转移基或形态算子。

### 2.7 训练目标

总损失：
\[
\mathcal{L} = \mathcal{L}_{\text{dyn}} + \lambda_r\mathcal{L}_r + \lambda_Q\mathcal{L}_Q + \lambda_V\mathcal{L}_V + \lambda_{\text{pair}}\mathcal{L}_{\text{pair}} + \lambda_{\text{op}}\mathcal{L}_{\text{op}}
\]

- \(\mathcal{L}_{\text{dyn}}\)：多步 token 对齐的动力学预测损失（物理量或锚定潜变量）。
- \(\mathcal{L}_V\)：标准 TD 目标引导的价值损失。
- \(\mathcal{L}_{\text{pair}}\)：配对形态转移监督。
- \(\mathcal{L}_{\text{op}}\)：算子正则化（对角/边系数 \(\ell_2\)，全局模式系数 \(\ell_1\)）。

### 2.8 规划控制

- 采用 TD-MPC 风格的 MPC/CEM 规划：候选轨迹在当前形态对应的动作张量上采样，滚动推演 GraphOp-WM，优化短视界回报加终端价值。
- 不同形态在独立规划调用中实例化不同动作张量，无需全局最大动作维度。

## 6. 主要结论与发现

- GraphOp-WM 通过将转移分解为**形态无关局部基 + 形态条件算子**，为形态参数泛化提供了明确的结构先验。

- 所定义的 MuJoCo 基准可以系统衡量插值、外推和组合泛化能力。

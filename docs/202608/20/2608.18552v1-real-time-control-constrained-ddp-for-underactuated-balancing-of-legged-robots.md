## 摘要
本文提出了一种用于欠驱动腿足机器人的实时控制约束微分动态规划（DDP）框架。为克服经典DDP在处理控制约束方面的局限性，我们提出了一种基于加速投影梯度（APG）的控制约束DDP（ABC-DDP），该方法能够高效计算约束解并识别活跃集，而无需重复进行Karush-Kuhn-Tucker（KKT）求逆。引入虚拟约束，将控制约束集成到可行性驱动的多射击框架中，即使从动态不可行的初始状态出发也能实现稳定优化。所提方法支持强欠驱动条件下短时域实时模型预测控制（MPC）。仿真结果展示了在外部扰动下的静态双腿站立，以及统一MPC框架内的多种动态运动，包括慢速猫步、直立行走和高速奔跑。据我们所知，这是首次通过实时有限时域MPC实现四足机器人静态双腿站立的演示。

## Abstract
This paper presents a real-time control-constrained Differential Dynamic Programming (DDP) framework for underactuated legged robots. To address the limitation of classical DDP in handling control constraints, we propose an Accelerated Projected Gradient (APG)-based control-constrained DDP (ABC-DDP), which efficiently computes constrained solutions and identifies active sets without repeated Karush-Kuhn-Tucker (KKT) inversions. A virtual constraint is introduced to integrate control constraints within a feasibility-driven multiple-shooting framework, enabling stable optimization even from dynamically infeasible initializations. The proposed method supports real-time model predictive control (MPC) with short horizons under strong underactuation. Simulation results demonstrate static two-leg standing under external disturbances, along with diverse dynamic motions including slow catwalk, upright walking, and high-speed running within a unified MPC framework. To the best of our knowledge, this is the first demonstration of static two-leg standing of a quadruped robot achieved using real-time finite-horizon MPC.

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- 将**加速投影梯度法（APG）**引入DDP的约束子问题求解中，替代传统的活动集QP求解，避免反复KKT矩阵求逆，实现高效的控制约束处理和活动集自动识别。
- 提出**虚拟约束（virtual constraint）**机制，将控制约束与FDDP（Feasibility-Driven DDP）的多射击框架深度融合，使优化可从动态不可行的初始轨迹出发并保持稳定。

### 2.2 技术细节

1. **控制约束建模**：
   - 采用线性摩擦锥 + 箱式约束形式——对每条腿的GRF，要求 \(|u_{ix}| \le \mu u_{iz}\)、\(|u_{iy}| \le \mu u_{iz}\)、\(u_{z,min} \le u_{iz} \le u_{z,max}\)；摆动腿通过约束置零处理。
   
2. **APG求解约束DDP子问题**：
   - 在每步后向传递中，固定 \(\delta x_k=0\)，利用非单调加速投影梯度法（含BB步长初始估计、backtracking line search、Nesterov动量、非单调criterion \(c_k\)）求解带约束的 \(\delta Q_k\) 极小值，得到最优前馈增量 \(k_k\) 并自动识别活动集。
   - 活动集确定后，仅需**一次KKT方程求解**（用于求反馈增益 \(K_k\)），避免多次KKT求逆。

3. **虚拟约束与边界收缩**：
   - 当后向传递中活动约束存在且FDDP回溯（\(\alpha<1\)）时，构造一个“虚拟约束”超平面（梯度法向、经过回溯前馈点），使反馈增益在该平面内滑动。
   - 通过参数 \(\beta \in (0,1]\) 对原约束边界进行线性收缩，限制反馈分量搜索范围，保证前向传递中的输入投影仍能基本满足约束。

4. **FDDP多射击整合**：
   - 定义状态间隙 \(\bar{f}_{k+1}:= f_k(x_k,u_k)\ominus x_{k+1}\)，使状态序列与控制序列在中间迭代可作为独立变量、允许动态不可行。
   - 前向传递规则、间隙逐步减小（\((1-\alpha)\bar f\)）、价值函数修正项 \(V_{x_{k+1}}\leftarrow V_{x_{k+1}}+V_{xx,k+1}\bar f_{k+1}\) 均沿用FDDP，保证从不可行初始轨迹出发的有效收敛。

5. **动态不可行初始滚动构造**：
   - 不直接做单射击 rollout，而是基于PD-like控制规则生成名义状态序列，利用FDDP允许的不可行性保持轨迹有界且紧贴期望轨迹附近。

6. **预期改进与正则化**：
   - 采用二阶近似的期望改进 \(\Delta J(\alpha)=\Delta_1\alpha+\frac12\Delta_2\alpha^2\) 和松弛接受条件（\(b_1, b_2\) 可调），平衡可行性提升与代价下降。
   - 当接受条件不满足时，对 \(Q_{uu}\) 和 \(V_{xx}\) 加入 \(\gamma I\) 正则化。

## 6. 主要结论与发现

- APG方法在求解受控DDP子问题时**计算高效、活动集识别可靠**，显著优于QP方法；在离线200步问题上约快2.5倍。
- 结合FDDP和虚拟约束后，算法具有对**动态不可行初始化**的鲁棒性，改善了收敛稳定性，并能在长短预测时域（数百步至 \(N=15\)）下保持近似的轨迹质量。
- 在统一实时MPC框架内，同时实现了**静态双足站立、慢速猫步、直立行走、高速奔跑**等运动，其中静态双足站立首次由实时有限时域MPC实现。
- 摩擦系数对平衡维持能力影响显著：\(\mu=0.5\)时可在连续扰动下恢复平衡，\(\mu=0.35\)时接触力始终处于摩擦锥边界却仍无法回到名义姿态，\(\mu=0.15\)时无法抵抗横向扰动力。
- 结论：控制约束DDP可以在强欠驱动环境下实现稳定的实时短时域MPC，为腿足机器人复杂动态控制提供了新方案。

## 7. 优点

- **方法论创新**：提出ABC-DDP，融合APG与DDP + FDDP，结合显式控制约束处理与多射击可行性驱动，弥补了既有方法在约束类型、活动集识别和计算效率上的不足。

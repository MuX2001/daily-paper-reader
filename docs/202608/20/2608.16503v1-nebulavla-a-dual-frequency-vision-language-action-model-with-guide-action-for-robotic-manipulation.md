## 摘要
视觉-语言-动作（VLA）模型在实际部署中常常受到效率与性能权衡、跨实体泛化以及执行平滑性的制约。我们提出了NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，从而优化计算资源和模块性。为了弥合异构机器人之间的语义差距，我们引入了GESTURE-7，一种统一的基于语言的动作表示。此外，我们的Guide Action算法通过基于掩码的平滑性约束来保证运动连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上实现了85.5%的平均成功率，并将动作生成速度提升了约2.7倍。这种异步设计为实际机器人应用提供了高效且响应的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

## 一、论文的核心问题与整体含义（研究动机与背景）

- **研究背景**：机器人操作正从模块化流水线向端到端学习范式转变，Vision-Language-Action（VLA）模型通过将感知、语言与控制统一在同一架构中，显著提升了自然语言指令跟随与复杂任务执行能力。从 RT-1、OpenVLA 到 InternVLA 系列，该领域已取得长足进展。
- **核心问题**：尽管 VLA 模型发展迅速，但当前模型在实际部署中面临三大瓶颈：
  1. **效率-性能权衡矛盾**：传统单频同步架构采用统一的时序分辨率，无法同时兼顾低频语义推理（需要大模型深度思考）与高频电机控制（需要低延迟响应）；
  2. **跨本体泛化困难**：不同机器人平台（如灵巧手、平行夹爪、机械臂）的运动学结构差异大，将连续运动学映射为离散 token 需要庞大的词表和大规模演示数据，难以形成统一的动作语义；
  3. **执行平滑性不足**：异步实时推理与动作块生成之间的时间错配，容易引起轨迹抖动和动作块边界不连续。
- **整体意义**：该论文提出了一种异步双频架构 NebulaVLA，系统性地解决了上述三个问题，在模拟与真实实验中均取得了领先效果，为 VLA 模型的真实机器人部署提供了可行的工程方案。

## 二、论文提出的方法论

### 1. 总体架构：异构双频"快-慢"系统

论文借鉴认知科学中 Kahneman 的"快慢双系统"思想，提出了层次化的双频架构：

| 子系统 | 频率 | 职责 | 技术实现 |
|--------|------|------|----------|
| System 2（慢系统） | ~10 Hz | 高层语义规划：理解自然语言指令、处理稀疏视觉输入、输出抽象动作引导 | Qwen3-VL 作为视觉-语言骨干网络 |
| System 1（快系统） | ~20 Hz | 低层运动控制：结合引导信息、高频视觉输入与动作历史，生成执行动作 | Q-Former 压缩引导信息 + Diffusion Transformer（DiT）去噪生成动作 |

该架构通过显式的数据流规范解耦两个子系统，天然支持分布式部署：System 2 和 System 1 可部署在不同的计算设备上，从而最小化交互延迟。

### 2. GESTURE-7：统一的基于语言的动作表示

- **定义**：GESTURE-7（Gesture Enumerated State Token for Unified Robot End-effector-7D）将末端执行器状态编码为 7 维向量：
  \[
  s = [x, y, z, r, p, w, g]
  \]
  其中 \((x,y,z)\) 为笛卡尔坐标位置（整数厘米），\((r,p,w)\) 为姿态角（roll/pitch/yaw，整数角度），\(g\) 为离散的手势 token（来自预定义词汇表，如 "grasp"、"push"、"rotate"、"release"）。
- **关键设计**：
  - 不同形态的机器人执行同一动作时共享相同的关键词，例如平行夹爪和灵巧手执行抓取动作均统一表示为 `grasp`，从而实现跨异构平台的统一动作语义；
  - 位置量化为整数厘米、角度量化为整数度，以降低模型学习负担、缓解预测幻觉；
  - 手势词汇表 \(G\) 可随任务需求自由扩展。
- **意义**：统一了异构平台的动作用语，天然支持与语言条件强化学习的集成。

### 3. Guide Action：基于掩码的轨迹平滑机制

- **动机**：异步策略推理与实际执行之间常存在时间错配，朴素异步算法在动作块切换时会出现"硬切换"（hard switch），引起机械抖动。
- **核心思想**：受图像外扩（Image Outpainting）技术启发，将块拼接直接嵌入生成流程——用前一个动作块中未执行的动作为锚点（guide action），条件化生成下一个动作块，确保轨迹在边界处平滑衔接。
- **公式化描述**：
  - 去噪过程建模为条件概率模型：
  \[
  p_\theta(A^{t-1}_{full} | A^t_{full}, A_{prior}, \tau)
  \]
  其中 \(A^t_{full}\) 为去噪时间步 \(t\) 的完整动作块（长度 T），\(A_{prior}\) 为先前动作集合（含已执行历史动作与待执行的引导动作），\(\tau\) 为时间位置编码。
  - 每一步去噪后，类似图像外扩保留原始像素的做法，强制恢复已知动作：
  \[
  A^{t-1}_{full} = M \odot A^{t-1}_{prior} + (1-M) \odot A^{t-1}_{noisy}
  \]
  其中 \(M \in \{0,1\}^T\) 为二进制掩码：\(M[1..k]=1\) 表示锚点区域严格保留，\(M[k+1..T]=0\) 表示需要模型生成的区域。
  - 训练时引导动作数量从 0 到 3 随机采样，以适应推理延迟的变化。

### 4. 三阶段训练流程

| 阶段 | 训练对象 | 方法 | 内容 |
|------|----------|------|------|
| Stage 1 | System 2 | SFT（监督微调） | 三类任务组：空间定位（GESTURE-7 格式的末端姿态回归 + 2D 关键点回归）、轨迹预测（2D 路点 + 3D 轨迹点，2 Hz）、推理规划（链式思维子任务分解 + 未来 GESTURE-7 轨迹生成） |
| Stage 2 | System 2 | GRPO 强化学习 | 基于 Stage 1 的任务套件，使用专门的奖励函数（GESTURE-7 距离、关键点定位奖励、路点奖励、轨迹奖励、格式奖励） |
| Stage 3 | System 1 + System 2（联合） | SFT + 流匹配损失 | 冻结视觉编码器，采用加权流匹配损失，使用 L2 loss 监督连续动作输出。由于引导动作机制，损失仅作用于新生成动作区域（掩码 M=0 的时间步） |

- Stage 3 的损失函数：
  \[
  L(\theta) = \mathbb{E}_{\epsilon,t}\left[(1-M) \odot (\epsilon - \epsilon_\theta(x_t, t))^2\right]
  \]

## 六、论文的主要结论与发现

1. **双频架构有效性**：异步双频架构（异频）在真实实验中显著优于同频变体——平均推理延迟从 115ms 降至 42ms（加速约 2.7 倍），同时成功率更高（Task 1: 87.14%→92.08%; Task 2: 90%→92.5%），验证了"快慢解耦"在平衡计算效率与控制响应方面的优势。
2. **GESTURE-7 表示有效性**：基于 GESTURE-7 的 S2 SFT 和 RL 逐步提升了 LIBERO-Plus 的整体成功率（83.8%→83.0%→85.5%），其中 S2 SFT 在 Layout 维度提升 +6.2%，S2 RL 进一步增强了语言和布局等语义相关维度的表现。
3. **Guide Action 平滑性提升**：Guide Action 使所有关节的平均加加速度平均降低 25.6%（关节 12 和 13 分别降低 41.2% 和 45.1%），显著抑制了动作块边界的抖动。
4. **整体性能**：NebulaVLA 在 LIBERO-Plus 上的整体成功率达 85.5%，优于 InternVLA-M1（81.3%）、OpenVLA-OFT+（79.6%）、GR00T N1.5（59.0%）和 π0.5（58.0%），展现了 SOTA 水平。

## 七、优点

1. **架构创新性强**：异构双频架构是 VLA 领域的前沿方向，论文通过显式的数据流解耦实现了对 VLA 系统效率-性能权衡的结构性解决，而非简单工程优化。
2. **GESTURE-7 设计巧妙**：用自然语言关键词统一异构平台的手势语义，既有实际工程可操作性（量化到整数降低学习负担），又有跨本体的概念优雅性，且与 RL 天然兼容。
3. **Guide Action 机制概念新颖**：借鉴图像外扩思想将平滑约束内化到生成过程而非事后处理，避免了后处理方法的语义不一致问题，是"Inpainting 思想跨领域迁移"的优秀范例。
4. **三阶段渐进式训练**：从 SFT 到 RL 再到联合微调，逐步建立语义规划能力和动作执行能力，训练流程清晰合理。
5. **实验较为全面**：覆盖模拟基准和真实场景，包含多种扰动下的鲁棒性评估、真实平台验证和消融研究，结果具有说服力。
6. **工程实践价值高**：异步解耦天然支持分布式部署，便于适应边缘计算场景。

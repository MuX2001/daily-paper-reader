## 摘要
当前视觉-语言-动作（VLA）模型的主流方案是将预训练的VLM与单独训练的流匹配动作专家相结合。这使得VLM成为上下文编码器而非决策者。我们提出G0.5，这是一种预训练的自回归VLA，其中单个Transformer解码器在单一目标下生成推理和动作token。三个组件使其在基础模型规模上可行：一个可学习的跨具身动作分词器，将异构机器人动作映射到共享词汇表；一个原生思维链流，将任务分解、目标定位和动作提示与动作token交错排列；以及一个视觉记忆模块，通过视觉编码器注入多秒历史信息。由于推理和动作共享同一组权重，预训练VLM的能力可迁移至物理行为：模型能紧密遵循指令，且提示可直接控制动作粒度、任务时长和分布外场景处理，无需额外训练。在包含VQA样本的大规模机器人数据集集合上进行预训练后，G0.5在7个独立场景中超越了最先进模型：在R1lite和R1pro机器人上的真实世界微调（76.7%，对比π_{0.5}的53.3%和GR00T-N1.7的24.4%）；使用通用策略在2025年BEHAVIOR挑战赛的50个长时程家庭移动操作任务中（31.4%，对比π_{0.5}的26.3%和挑战赛冠军的26.1%）；DROID后训练后零样本迁移至未见环境和物体（82.5%）；一个遵循语言的Pick-and-Place基准；LIBERO（98.9%）、RoboTwin 2.0（93.3%）和SimplerEnv-Bridge（87.3%）。

## Abstract
The prevailing recipe for Vision-Language-Action (VLA) models couples a pretrained VLM with a separately trained flow-matching action expert. This makes the VLM a context encoder rather than a decision-maker. We introduce G0.5, a pretrained autoregressive VLA in which a single transformer decoder emits reasoning and action tokens under a single objective. Three components make this tractable at foundation-model scale: a learnable cross-embodiment action tokenizer that maps heterogeneous robot actions into a shared vocabulary; a native chain-of-thought stream interleaving task decomposition, object grounding, and action hints with action tokens; and a visual memory module that injects multi-second history through the vision encoder. Because reasoning and action share a single set of weights, the pretrained VLM's capabilities carry over to physical behavior: the model follows instructions closely, and prompts directly steer action granularity, task horizon, and out-of-distribution scene handling without further training. Pretrained on a large collection of robot datasets together with VQA samples, G0.5 surpasses state-of-the-art models across 7 independent regimes: real-world fine-tuning on R1lite and R1pro robots (76.7\% vs.\ 53.3\% for $π_{0.5}$ and 24.4\% for GR00T-N1.7), the 2025 BEHAVIOR Challenge on 50 long-horizon household mobile manipulation tasks using a generalist policy (31.4\% vs.\ 26.3\% for $π_{0.5}$ and 26.1\% for the challenge winner), DROID post-training followed by zero-shot transfer to an unseen environment and objects (82.5\%), a language-following Pick-and-Place benchmark, LIBERO (98.9\%), RoboTwin 2.0 (93.3\%), and SimplerEnv-Bridge (87.3\%).

## 一、核心问题与整体含义（研究动机与背景）

- **主流 VLA 范式的根本缺陷**：当前视觉-语言-动作（VLA）模型普遍采用“预训练 VLM + 独立训练的 flow-matching 动作专家”的组合架构。在这种范式下，VLM 实际上只充当**上下文编码器**（context encoder）而非真正的**决策者**（decision-maker），导致以下问题：
  - 推理与动作生成被割裂为两套独立系统，各自使用不同的训练目标和参数量；
  - 预训练 VLM 中丰富的语言理解、常识推理和指令跟随能力无法直接迁移到物理行为控制上；
  - 动作专家需要单独的大规模训练，增加了训练复杂度和资源消耗。
- **论文的定位与意义**：G0.5 提出一种**预训练的自回归 VLA 模型**，使用**单个 Transformer 解码器**、在**单一目标函数**下同时生成推理 token 和动作 token，让 VLM 真正成为端到端的决策者。这一设计使得预训练 VLM 的广泛能力可以直接迁移到机器人动作生成中，代表了 VLA 架构从“拼接范式”向“统一范式”的重要转变。

## 二、方法论：核心思想与关键技术

### 2.1 核心思想
- **单一自回归流**：用一个 Transformer 解码器将文本指令、视觉观察、推理链和机器人动作统一建模为 token 序列，在同一 next-token-prediction 目标下联合训练，实现推理与决策的真正融合。

### 2.2 三大关键组件

**1. 可学习的跨具身动作分词器（Cross-Embodiment Action Tokenizer）**
- 将来自不同机器人本体（不同自由度、不同控制频率、不同动作空间）的异构动作数据映射到一个**共享的动作词汇表**；
- 通过可学习的方式量化连续动作空间，使模型能够在多种机器人平台上统一输出动作；
- 这是实现基础模型规模（foundation-model scale）可训练性的关键前提。

**2. 原生思维链流（Native Chain-of-Thought Stream）**
- 将推理过程显式建模为 token 流，包含**任务分解**（task decomposition）、**目标定位**（object grounding）和**动作提示**（action hints）；
- 这些推理 token 与动作 token **交错排列**（interleaved），形成统一的序列结构；
- 模型在生成动作之前先进行显式推理，使决策过程具有可解释性，同时推理能力可以直接引导动作生成。

**3. 视觉记忆模块（Visual Memory Module）**
- 通过视觉编码器注入**多秒历史信息**，使模型具备时间上下文感知能力；
- 解决单帧观察不足以支撑长时程任务和动态场景理解的问题。

### 2.3 训练方式
- 在大规模机器人数据集集合（包含 VQA 视觉问答样本）上进行预训练；
- 推理和动作共享同一组权重，因此**无需额外训练**，即可通过提示（prompt）直接控制动作粒度、任务时长和分布外（OOD）场景处理策略。

## 六、主要结论与发现

1. **统一自回归范式有效**：单一 Transformer 解码器同时生成推理和动作 token，不仅在性能上超越流匹配专家范式，还大幅简化了训练流程。
2. **VLM 能力可直接迁移到物理行为**：因为推理与动作共享权重，预训练 VLM 的指令跟随、常识推理和场景理解能力可以直接映射为物理动作，无需额外的适配层。
3. **提示即控制**：通过改变 prompt 即可调控动作粒度（action granularity）、任务时长（task horizon）和分布外场景处理策略，**无需重新训练**，展现了极高的灵活性和可控性。
4. **跨具身泛化可行**：可学习的动作分词器使单一模型能够适配多种机器人平台，从仿真到真实世界迁移表现优异。

## 七、优点与亮点

- **架构创新性强**：打破当前 VLA “VLM + 动作专家”的固定范式，用单一自回归流统一推理与动作，从根本上解决推理-动作割裂问题；
- **良好的可解释性**：原生思维链流使模型决策过程显式可见，便于调试和人类理解；
- **训练效率提升**：单一目标函数、共享权重，避免了独立动作专家的额外训练开销；
- **跨具身泛化能力强**：可学习的动作分词器是多平台适配的优雅方案，展示出作为通用机器人基础模型的潜力；
- **零样本与提示控制的灵活性**：无需额外训练即能通过 prompt 调控行为特征，在实际部署中具有显著实用价值；

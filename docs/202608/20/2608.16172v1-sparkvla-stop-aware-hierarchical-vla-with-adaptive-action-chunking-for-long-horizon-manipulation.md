## 摘要
在分层视觉-语言-动作（VLA）系统的每个重新观察点，必须做出两个接口决策：何时终止当前子任务，以及执行所提出的动作分块到何种程度。这两个决策相互依赖——最优停止点取决于执行器计划做什么，而最优执行长度取决于子任务边界在哪里——然而现有架构将它们孤立地评估，这种不对称性是任何单一模块都无法单独克服的。我们提出SparkVLA，一种停止感知的分层VLA，通过将两个决策制定为单一排名来解决这种相互依赖：Stop在统一候选集中与每个动作前缀长度竞争，系统选择得分最高的选项，从而消除阈值调整，仅需离线序数偏好。锚定条件上下文编码模块缓存历史感知的子任务锚定编码、起始状态记忆和目标语义，引导视觉标记修剪朝向任务相关区域；停止感知动作前缀选择头通过块边界处的全自注意力对所有候选进行评分，以提高效率。在RoboCerebra上，SparkVLA实现了47.12%的成功率，超过官方分层基线30.57%，超过最强可复现方法26.83%。在多步任务上的真实机器人实验进一步验证了这些收益在物理硬件上的有效性。

## Abstract
At every re-observation point in a hierarchical Vision-Language-Action (VLA) system, two interface decisions must be made: when to terminate the current subtask and how far to execute the proposed action chunk. These decisions are mutually dependent---the optimal stopping point depends on what the executor plans to do, while the optimal execution length depends on where the subtask boundary lies---yet existing architectures evaluate them in isolation, an asymmetry neither module can overcome alone. We present SparkVLA, a stop-aware hierarchical VLA that resolves this mutual dependency by formulating both decisions as a single ranking: Stop competes against every action-prefix length in a unified candidate set, and the system selects the highest-scoring option, eliminating threshold tuning and requiring only offline ordinal preferences. An Anchor-Conditioned Context Encoding module caches a history-aware subtask anchor encoding onset-state memory and goal semantics, guiding visual-token pruning toward task-relevant regions; a Stop-Aware Action-Prefix Selection head scores all candidates via full self bnattention at chunk boundaries for efficiency. On RoboCerebra, SparkVLA achieves 47.12% success rate, surpassing the official hierarchical baseline by 30.57% and the strongest reproducible method by 26.83% Real-robot experiments on multi-step tasks further validate these gains on physical hardware.

## 1. 核心问题与整体含义

- **研究背景**：现有 VLA（视觉-语言-动作）模型在短轨迹操作上表现良好，但面对长时程多技能组合任务时容易失效。分层 VLA 通过高层 VLM 规划器生成子任务指令、低层 VLA 执行器生成动作块，已成为解决长时程操作的主流范式。
- **核心问题**：在每个重新观察边界，系统必须同时决定「何时终止当前子任务」与「动作块应执行多长」。这两个决策存在强烈的相互依赖：最优停止点取决于执行器后续计划，最优执行长度又取决于子任务边界位置。然而，现有架构孤立地处理这两个决策——终止检测器无法利用即将执行的动作计划，自适应分块方法无法发出子任务完成信号。这种「信息不对称」是单一模块无法克服的结构性缺陷。
- **论文意义**：SparkVLA 首次将子任务终止与执行视野选择统一为一个排序问题，在统一候选集中让 Stop 与所有动作前缀长度共同竞争，实现联合决策、免阈值调参，为分层 VLA 的接口设计提供了新范式。

## 2. 方法论

- **核心思想**：将两个接口决策（停止 vs. 执行多长）转化为对统一候选集 C = {0, 1, …, H} 的单一排序（0 表示 Stop，n 表示执行前 n 个动作），选择得分最高的候选。这种设计使终止决策能利用动作块内容，使长度选择能利用子任务边界接近程度，从而消除两个模块间的信息不对称。
- **总体架构**：从预训练 π0.5 VLA 派生两个分支——高层分支保留 VLM 骨干用于子任务生成并承载选择器；低层分支使用完整 π0.5 提出动作块。选择器仅在块边界调用，兼顾效率与精度。
- **关键技术 1：历史感知子任务锚点（History-Aware Subtask Anchor）**
  - 子任务开始时，从规划器倒数第二层提取原始锚点，经 MLP 投影；
  - 维护锚点历史池，通过自注意力将当前锚点与历史锚点融合，使其携带跨子任务上下文（如哪些区域已被操作）；
  - 锚点每个子任务只计算一次并缓存。
- **关键技术 2：锚点引导的视觉剪枝（Anchor-Guided Visual Pruning）**
  - 使用 Grid-Sampler 可微算子预测 K 个归一化 2D 坐标，通过双线性采样从密集视觉 token 中提取任务相关区域；
  - 以子任务锚点为条件进行跨注意力，将每个摄像头的视觉 token 从 N 剪枝到 K，降低计算量。
- **关键技术 3：停止感知动作前缀选择头（Stop-Aware Action-Prefix Selection）**
  - 每个候选（Stop 和长度 n）初始化为学习嵌入 + 前缀末尾动作的映射；
  - 通过全自注意力 Transformer 让所有候选互相竞争，使每个候选能评估与其他时长和停止信号的关系；
  - 概率分数由 MLP 映射，推理时取 arg max。
- **训练目标（停止感知排序目标）**：仅需离线序数偏好，无需在线奖励或阈值。
  - 排序损失：按优先级 ρ 构造成对比较，对边界标注加均匀扰动增强鲁棒性；
  - 停止辅助损失：对比 Stop 分数与 log-sum-exp 聚合的继续动作分数，强化终止边界；
  - 总损失 L = L_rank + λ_stop L_stop，两个损失共享同一套分数。
- **推断流程**：子任务开始时生成指令并缓存锚点；每个决策边界由执行器提出动作块，选择器统一打分；若选 Stop 则结束当前子任务并更新历史，否则执行所选前缀后重新观察。

## 6. 主要结论与发现

- SparkVLA 在 RoboCerebra 上平均成功率 47.12%，比官方基线 HPE 高 30.57%，比最强可复现方法 Mem-0 高 26.83%，比独立 π0.5 高 34.83%；
- 在 Dynamic Obs.（+34.78%）和 Memory Exp.（+47.69%）条件上增益最大，说明自适应短前缀提高动态场景下的反应频率、历史感知锚点避免重复访问已完成目标；
- 跨执行器泛化显著：SparkVLA 高层系统使 OpenVLA-OFT 成功率提升 22.47%，使 SmolVLA 提升 22.52%，证明增益来自接口设计而非特定模型配对；
- 消融证明统一候选集是关键：将 Stop 纳入统一排序后，Stop Acc. 从 80.37% 跃升至 96.65%（+16.28pp），SR 从 42.53% 升至 47.12%，验证了「双向受益」：停止决策受益于动作前缀上下文，前缀选择受益于精确终止信号；
- 历史感知锚点贡献 1.94pp，主要解决记忆依赖条件下的空间歧义；
- 选择器放置于高层规划器骨干比低层执行器骨干高 9.84pp，因为规划器编码更丰富的任务进度和子任务历史信息；
- LIBERO-Long 上达到 98.0%，较最强开放基线（OpenVLA-OFT 94.5%）高 3.5pp，说明长序列场景中受益最大；
- 真实机器人平均成功率 69.3%，比 π0.5 高 21.3pp（泡茶任务高 30.0pp），验证了从仿真到物理硬件的迁移；
- 推理效率：缓存子任务指令 + 仅块边界调用选择器，合计提速 2.91× × 2.10×，最终以 4.14 Hz 边界更新率运行，保留独立 π0.5 的 88% 吞吐量。

## 7. 优点

- **新颖的决策统一框架**：首次将「停止」与「分块长度」统一到单一排序，从结构上消除接口决策的信息不对称，概念清晰、实现优雅；
- **免阈值、免在线奖励**：仅需离线序数偏好，配合边界扰动增强鲁棒性，避免了手工阈值和在线交互带来的工程复杂性；
- **锚点设计精巧**：历史感知锚点同时编码起始状态记忆与目标语义，并通过自注意力传播跨子任务上下文；锚点引导的视觉剪枝兼顾效率与任务相关性；
- **选择器高效调度**：在块边界而非每步打分，显著降低计算开销的同时还因避开帧间运动模糊而提高了停止准确率；
- **泛化验证充分**：高层系统与多个低层执行器组合均有效，说明贡献不依赖特定执行器；
- **实验规范性强**：对训练/评估种子分离、同协议、匹配数据量、常见评估控制等有明确描述，且消融实验能有效隔离每个设计因子的贡献；
- **真实机器人验证**：包含多步骤、记忆依赖、物理交互等挑战，且对安全、重置、任务定义有详细说明，增加了结论可信度。

## 8. 不足与局限

- **场景范围有限**：实验集中于桌面操作、固定物体类别与静态相机配置，距离开放世界、动态非结构化环境仍有差距；
- **训练依赖离线数据**：需精细的子任务边界标注和优先级构造，标注噪声仅通过简单均匀扰动缓解；完全无边界标注的泛化能力未知；
- **对 π0.5 的依赖**：高层与低层分支均由 π0.5 初始化，论文虽用 OpenVLA-OFT/SmolVLA 验证高层泛化，但未验证不同 VLM 骨干（如 RT-2、Gemini 类）的适用性；
- **在线适应缺位**：选择器训练后冻结，未支持在线学习或领域自适应；
- **失败分析不足**：未提供失败案例的定性分类（如物体掉落、卡顿、误判），难以判断失败边际；
- **真实实验物理替代**：泡茶任务用白色塑料珠代替水，虽安全可复现，但与真实液体物理（流动、飞溅）仍有差异；
- **计算资源门槛**：需要 4×A100 80GB 训练选择器，且真实平台依赖多视角视觉和 20 Hz 动作流，对低成本机器人部署构成限制；
- **偏差风险**：论文由提出方法的研究者自行复现部分基线（Mem-0），虽然声明了统一协议，但独立第三方复现仍然缺失。

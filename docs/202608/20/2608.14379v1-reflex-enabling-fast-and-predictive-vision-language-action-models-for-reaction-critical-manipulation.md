## 摘要
视觉-语言-动作（VLA）模型近期在机器人操作领域取得了显著进展。然而，现有基准主要评估静态操作任务的泛化能力，而很大程度上忽视了动态交互场景。为弥补这一空白，我们提出了ReflexBench，一个面向反应关键操作的基准。ReflexBench包含六个动态任务，并引入了一种评估框架，该框架将模拟器步进与机器人控制解耦，同时支持同步和异步推理下的可配置延迟。基于ReflexBench，我们提出了ReflexVLA，一种专为反应关键操作设计的高效VLA模型，无需大规模机器人数据预训练。ReflexVLA通过潜在未来预测和视觉骨干网络内的多帧时间融合增强了时序推理能力，同时通过批量视觉编码和CUDA图重放降低了部署延迟。实验表明，ReflexVLA在标准静态操作基准上保持竞争性精度的同时，持续提升了动态操作性能，真实世界实验进一步证明了其在实际部署条件下的有效性。项目网站：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. Project website: https://reflexvla.github.io

### 2.1 ReflexBench 基准设计

- **数据收集**：由于动态任务难以用简单脚本或遥操作获得专家轨迹，作者采用“基于规划的分阶段数据收集流程”：将任务分解为多个子目标（如预对齐、目标跟踪、定时插入）；对于复杂交互，额外训练任务专用强化学习策略生成演示数据。
- **延迟感知评估协议**：
  - 将模拟器步进与机器人控制**解耦**，环境在推理期间不再暂停，从而真实反映推理延迟的影响；
  - 支持**同步推理**（推理期间执行阻塞）和**异步推理**（动作执行与策略计算重叠，但动作可能过期）；
  - 支持手动指定延迟值，从而系统研究延迟对性能的影响；
  - 支持依据实际策略推理延迟换算为仿真延迟（通过实时因子 RTF = t_sim / t_wall 进行转换），保证评测贴近真实部署。

### 2.2 ReflexVLA 模型设计
ReflexVLA 基于紧凑的视觉-语言-动作架构（VLA-Adapter），视觉编码器为 DINOv2 + SigLIP 融合 ViT，语言骨干为 Qwen2.5-0.5B。其核心创新包括三部分：

- **潜在未来预测（Latent Future Prediction）**：
  - 利用**冻结的 DINOv3** 编码器将未来观测映射为语义特征向量（1024 维）；
  - 在输入序列中追加 H 个可学习的未来预测 token（H 等于动作 chunk 大小），每个 token 对应一个未来控制步；
  - 经过 Transformer 后，将未来 token 的隐藏表示投影到 DINOv3 特征空间，并通过**掩码余弦相似度损失**训练：
    - L_future = Σ m_i [1 − cos(ŷ_{t+i}, y_{t+i})] / Σ m_i
  - 总损失：L = L_act + λ_future · L_future，λ_future = 0.05。
  - 该设计避免了直接预测图像的高计算开销，引导模型学习与控制相关的场景动态。

- **多帧时间融合（Multi-Frame Temporal Fusion）**：
  - 输入 T 个历史观测帧，在每个相机视角、每个 patch 位置上提取中间层特征（保留更丰富的局部外观和运动信息）；
  - 对同一空间位置的 T 帧特征构成时间轨迹，经归一化、降维、加入时间位置编码后，使用**因果时序注意力**（MHA）融合，防止未来信息泄漏；
  - 融合后的特征（上投影后）加到当前帧最终层特征上，形成增强的当前帧表示；
  - 最终送入语言模型的视觉 token 数量与单帧设置完全相同，避免了直接拼接多帧带来的平方级注意力开销。

- **推理延迟优化**：
  - **批量视觉编码**：将 V 个视图 × T 帧图像合并为一次视觉编码器前向调用，减少重复执行开销；
  - **CUDA Graph 重放**：将整个推理计算图（视觉编码、时序融合、多模态投影、语言模型、动作预测）捕获为 CUDA Graph，执行时仅需复制输入并重放，消除逐核调度开销。
  - 关键公式：â_{t:t+H−1} = G(x_text, x_vision, x_state)，G 为捕获的 CUDA Graph。

上述三个设计分别对应“预测未来”“理解运动”“快速响应”，在训练和部署层面共同提升了动态操作能力，且不改变模型架构本身。

## 6. 论文的主要结论与发现

- **推理范式与参数选择**：高频率异步推理配合较大 chunk size 和较短 action horizon 通常最优；低频率下异步推理因观测-动作失配而劣于同步推理。
- **主结果**：ReflexVLA 在 ReflexBench 上平均成功率 50.4%，优于所有对比基线（PUMA 50.2%、OpenVLA-OFT 36.0%、π0.5 36.9%、DynamicVLA 37.3%、SmolVLA 38.3%、VLA-Adapter 30.3%），且参数仅 1B，显著小于 PUMA（4B）和 OpenVLA（7B）。
- **静态任务泛化**：在 LIBERO 上平均成功率 97.2%，与最优基线（VLA-Adapter 97.3%）几乎持平，说明动态优化未损害静态能力。
- **消融结论**：
  - 可训练的未来预测目标导致性能崩溃（-31.9%），而冻结 DINOv3 特征作目标显著提升（+26.0%）；
  - 中间层特征上的时序注意力优于最终层特征和交叉注意力；
  - 批量编码 + CUDA Graph 将延迟从 125.1 ms 降至 65.0 ms，同时成功率进一步提升。
- **真实世界验证**：ReflexVLA 在传送带抓取（16/20）、按压按钮（22.5 个/30s）、接球（6.7 个/10球）均优于 SmolVLA，并与 PUMA 相当或更优，证实实用性。

## 7. 优点

- **问题定位准确**：针对 VLA 社区普遍忽视的动态、延迟敏感场景，弥补了现有基准与模型设计的空白。
- **基准设计严谨**：首次在评测中显式解耦模拟器与控制器，并支持同步/异步延迟配置，能更真实地反映实际部署中的感知-执行延迟。
- **模型设计高效**：
  - 未来预测在语义潜在空间进行，而非像素级重建，计算开销小且语义稳定；
  - 多帧融合仅在视觉骨干内部进行，不增加语言模型侧 token 数，避免了二次复杂度；
  - CUDA Graph 与批量编码是系统级优化，与模型训练解耦，普适性强。
- **实验设计层次分明**：从机制探索（Q1）、主对比（Q2）、静态验证（Q3）、消融（Q4）到真实实验（Q5），逻辑完整。
- **轻量高效**：1B 参数即可超越 7B/4B 模型，且推理延迟低至约 65 ms，适合实际机器人部署。

## 8. 不足与局限

- **预训练缺失**：未来预测与多帧融合仅在微调阶段引入，未经过大规模预训练，其潜力可能未被完全发挥。

- **数据收集成本**：动态任务演示依赖规划与强化学习，复杂任务数据质量对最终性能影响大，但论文未详细分析数据规模敏感性。

## 摘要
请求到交接的差距有三个耦合来源：请求时意图行为的模糊性、动作生成期间累积的物理状态漂移，以及新动作最终接管时残留的不兼容性。BICPO-VLA依次解决这些问题。首先，一个指令感知的因果历史编码器识别命令和当前任务进度所支持的行为。其次，序贯Haar子空间生成将每个动作块分解为互补的成对支架系数和残差系数，从而实现两个专门的生成阶段和精确重构。通过在原始动作空间中减少迭代细化，缩短了在新块可用之前机器人继续移动的时间间隔。最后，BICPO将已知的传出动作滚动到实际的交接状态，并在行为匹配的候选之间应用参考相对的Flow-DPO，使生成的块适应剩余的请求到交接的不匹配，而不改变其预期行为。

## Abstract
The request-to-handoff gap has three coupled sources: ambiguity about the behavior intended at request time, physical-state drift accumulated during action generation, and residual incompatibility when the new action finally assumes control. BICPO-VLA addresses them in sequence. First, an instruction-aware causal history encoder identifies the behavior supported by the command and current task progress. Second, sequential Haar subspace generation decomposes each action chunk into complementary pairwise scaffold and residual coefficients, enabling two specialized generation stages followed by exact reconstruction. By reducing iterative refinement in the original action space, it shortens the interval over which the robot continues moving before the new chunk becomes available. Finally, BICPO rolls the known outgoing actions to the actual handoff state and applies reference-relative Flow-DPO among behaviorally matched candidates, adapting the generated chunk to the remaining request-to-handoff mismatch without changing its intended behavior.

## 1. 核心问题与研究动机

### 问题背景
- **异步动作分块（Asynchronous Action Chunking）** 是 VLA（Vision-Language-Action）模型常用的控制范式：机器人执行当前动作块的同时，模型推断下一个动作块。
- 这导致一个关键问题——**"请求到交接间隔"（request-to-handoff gap）**：新动作块在一种运动上下文中被请求，却在另一种状态中接管控制，即使预测在语义上正确，仍可能引起边界跳变或运动趋势断裂。

### 问题的三个耦合来源
1. **行为意图模糊**：请求时对当前应执行的行为（如抓取 vs 放置）存在歧义；
2. **物理状态漂移**：动作生成期间机器人持续运动，实际状态已偏离请求时的状态；
3. **残留不兼容**：新动作块真正接管时与当前状态不兼容。

### 核心观察
- **行为条件化动作纤维（behavior-conditioned action fiber）**：一个行为指令对应一族动作实现，而非唯一轨迹。这些成员共享任务语义，但局部运动与交接兼容性不同。
- 现有方法（记忆增强、高效生成、异步策略）各自改进某一方面，但均未**联合分离**行为身份、实现结构与交接条件化选择这三个决策维度。

### 研究目标
将"选择正确行为"与"行为如何平滑接管控制"分离，分别优化，使异步 VLA 控制既能完成任务，又能平滑过渡。

## 2. 方法论：BICPO-VLA 三阶段方案

### 2.1 整体架构

BICPO-VLA 将行为到动作实现的映射分解为三个环节，每个环节对应一个不变量：

| 阶段 | 功能 | 保持的不变量 |
|------|------|-------------|
| 行为识别 | 确定当前指令与任务进度支持的行为 | 任务语义 |
| Haar 实现生成 | 生成该行为的动作块 | 动作信息精确性 |
| BICPO 偏好优化 | 适应交接状态差异 | 执行时的状态偏移 |

### 2.2 指令感知的行为识别（Instruction-Grounded Behavior Identification）

**核心思想**：行为识别需要指令相对的任务进度。

**关键技术**：
- **感知路由**：视觉 token 先与语言特征做注意力交互（视觉查询语言），过滤指令无关的视觉证据，再进行历史融合：
  `eVt = Vt + Attn(LN(Vt), Lb, Lb; Ml)`
- **因果历史编码器**：使用因果 Mamba 块构建行为状态 `zr = Bϕ({eVt}, {ut})`，表示指令相对进度（无离散阶段）。
- **阶段条件解码器**：结合长期记忆 `mr`，产生动作先验 `μr = Dω(zr, mr)`。
- 行为条件定义为 `br ≡ (ℓ, zr, mr, μr)`，确定动作纤维 `Fr = {A : A |= br}`。

**设计选择**：语言先于时间聚合介入，使历史状态保持指令特定性，与后期融合（late fusion）形成对比。

### 2.3 交接条件化的 Haar 实现生成（Handoff-Conditioned Haar Realization）

#### (a) 滚动交接上下文（Rolled Handoff Context）
- 利用已知的传出动作序列 `Ukr = (ur, ..., ur+k-1)`，通过冻结的动作状态模型滚动到实际交接状态：
  `hj+1 = Ract(hj, uj)`
- 计算绝对交接状态 `¯hr,k` 和差值状态 `∆hr,k`，组合得到交接条件 `gr,k`。
- 绝对项描述交接时的运动上下文，差值项揭示推理期间执行推进的距离，二者结合可区分相似交接状态的不同到达趋势。

#### (b) 互补实现坐标（Haar 变换）
- 对偶数长度动作块 `A ∈ RH×da` 应用一层 Haar 变换：
  - 支架系数（scaffold）`ci = (a2i + a2i+1)/√2`：捕获成对运动的整体水平
  - 残差系数（residual）`di = (a2i − a2i+1)/√2`：恢复对内变化
- 变换是**正交且无损的**：`A = W⊤[C; D]`，精确重构。
- 先验同样变换到同一坐标系，使先验与生成动作共享坐标。

#### (c) 有序支架-残差生成
- 使用线性流匹配路径：`xτ = (1−τ)y + τε`，一步反向欧拉即可精确恢复。
- **支架阶段**：以先验支架系数、交接条件生成粗略运动骨架 `bC`；
- **残差阶段**：条件于生成的支架（stop-gradient）和先验残差系数，生成局部修正 `bD`；
- 最终重构 `bAr+k = W⊤[bC; bD]`。

**关键设计**：stop-gradient 保持两个阶段的职责分离——第一阶段建立块级运动骨架，第二阶段提供局部修正，互不干扰。

### 2.4 行为识别的延续偏好优化（BICPO）

**核心思想**：离线成对偏好微调，不是在线强化学习，也不是全局平滑性回归。

#### (a) 同一纤维的候选对
- 在同一行为条件 `χr,k = {Φr, zr, mr, μr, gk}` 下，用不同流噪声采样两个候选，得到同一行为的不同实现。
- 排除无效候选和冻结参考兼容性差异过大的配对，防止"不动作"因移动少而获胜。

#### (b) 延续代价函数
- 零阶交接跳变：`Jjump(A) = ∥a0 − ur+k-1∥²_W`
- 一阶运动趋势失配：`Jtrend(A) = ∥(a0 − ur+k-1) − (ur+k-1 − ur+k-2)∥²_W`
- 综合代价：`Jcont(A) = λ0·Jjump(A) + λ1·Jtrend(A)`
- 只有代价差异超过一定边际（margin）时才偏好低代价候选。

#### (c) 参考相对 Flow-DPO
- 按 Haar 坐标的有序分解计算两阶段能量 `Eθ(A|χ)`。
- 定义参考相对偏好差异：`∆θ = [Eθ(A⁻)−Eθ(A⁺)] − [Eref(A⁻)−Eref(A⁺)]`
- 损失函数：`L = −q·logσ(β∆θ) + λ+·Eθ(A⁺) + λrep·Lreplay`
- 冻结语义通路、滚动模型、Haar 变换和参考专家，仅更新投影器和选定的专家参数。
- **可移植性**：DPO 目标可迁移到 π0.5、Legato、RTC 等策略，不附加 BICPO-VLA 的指令通路或 Haar 生成器。

### 2.5 训练与部署流程
- **训练**：模仿学习 → 延续预热（continuation warm-up with Lstruct）→ 离线 DPO。
- **部署**：滚动一个交接状态 → 生成 (bC, bD) → 重构动作块，**无需在线候选搜索**。

## 6. 主要结论与发现

1. **三阶段分解有效**：行为识别、Haar 结构实现、交接条件化偏好选择三者各司其职，组合效果最优。
2. **偏好优化优于连续性回归**：参考相对 Flow-DPO 能同时降低交接代价并保持成功率；直接连续性 SFT 虽降低代价但严重损害成功率——因为模型学会的是"少动"而非"平滑接管"。
3. **Haar 子空间生成有效**：无损的支架-残差分解提供结构化的动作参数化，避免学习重构瓶颈。
4. **可移植性**：延续 DPO 目标独立于 BICPO-VLA 的架构细节，可迁移到其他策略的 native 机制之上。
5. **指令介入位置关键**：视觉查询指令后再融合历史的设计优于后期融合或记忆融合。
6. **鲁棒性**：滚动交接条件对不同推理延迟（固定和随机）均保持稳定性能。

## 7. 方法亮点与创新

1. **"动作纤维"概念**：将行为与实现分离的视角具有理论清晰度，为解决异步控制问题提供了新的形式化框架。
2. **三阶段职责分离**：行为语义、动作结构、交接适应各自由独立模块处理，每个模块的约束简单明确，避免耦合导致的设计冲突。
3. **Haar 变换作为结构化接口**：不是压缩或加速技巧，而是可逆变表示——支架给出运动的全局水平，残差保留局部细节，两个阶段各司其职。
4. **参考相对 DPO**：基于冻结参考模型的相对偏好比较，防止偏好优化策略偏离原始能力，同时利用排名边际作为置信度。
5. **DPO 目标可移植性**：将偏好原则与特定架构解耦，客观上验证了方法的核心贡献在于"偏好优化原则"而非工程实现。
6. **冻结语义通路**：防止平滑性优化改变行为意图，从机制上避免"因平滑而放弃任务"的退化。
7. **零初始化 Wg**：保留延续梯度的同时不干扰预训练行为。

BICPO-VLA 以清晰的三阶段分解视角处理异步 VLA 控制的交接问题，在方法设计上具有较高的系统性和创新性。其核心贡献——行为识别、Haar 结构实现与延续偏好优化的解耦——不仅在自身架构上有效，DPO 目标的可移植性实验也证明了该原则的普适价值。实验覆盖面较广，消融逻辑清晰。但需要注意的是，实验在统计严谨性、与最新方法对比、真实场景规模以及资源消耗报告等方面仍有提升空间。

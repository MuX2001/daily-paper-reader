## 摘要
与经典逆李雅普诺夫定理不同，有限步逆结果具有构造性，并提供了不同的出发点：对于足够大的有限步前向（设为M），在明确意义上，任何缩放范数都可以作为逆有限步李雅普诺夫函数。对于互联离散时间系统，类似的论证思路可导出“非保守”的小增益条件。受此观点启发，本文针对受约束的互联非线性离散时间系统，提出了一种分布式模型预测控制框架。每个子系统在每个系统时间步求解一个局部优化问题，通过将局部阶段函数设置为局部控制有限步李雅普诺夫函数形式，利用时间对齐的邻居预测、优化的状态约束收紧半径以及有限步小增益终端不等式。由于接收到的邻居预测不一定等于未来滚动时域优化生成的轨迹，名义上的逆结论本身并不能确保递推可行性与稳定性。因此，我们开发了移位兼容的约束裕度、针对控制仿射网络的局部一步终端可行性检验，以及预测与重新优化不匹配的解析界。所得分析给出了递推可行性、约束满足性以及实用的M步李雅普诺夫估计，当预测与重新优化不匹配界趋于零时，可实现渐近收敛。对于受约束的线性网络，相关条件可简化为有限维矩阵、二次规划（QP）和二阶锥规划（SOCP）检验。该框架专门应用于DC/DC功率变换器运行约束下的电流共享与终端母线电压安全，并在小型实验室规模的二DGUs直流微网样机上进行了评估。

## Abstract
As opposed to classical converse Lyapunov theorems, finite-step converse results are constructive and offer a different starting point: for sufficiently large finite step ahead, say $M$, in an explicit sense, any scaled norm can serve as a converse finite-step Lyapunov function. As for interconnected discrete-time systems, similar lines of argument lead to ``non-conservative'' small-gain conditions. Motivated by this viewpoint, this paper develops a distributed model predictive control framework for constrained interconnected nonlinear discrete-time systems. Each subsystem solves one local optimization problem at each system time step instant by setting the local stage function in form of a local control finite-step like Lyapunov function, using time-aligned neighbor predictions, optimized state-constraint tightening radii, and a finite-step small-gain terminal inequality. Since received neighbor predictions need not equal the trajectories generated by future receding-horizon optimizations, the nominal converse certificates do not alone ensure recursive feasibility or stability. We therefore develop shift-compatible constraint margins, a local one-step terminal feasibility test for networks that are affine in control, and an analytical bound for the prediction and reoptimization mismatch. The resulting analysis gives recursive feasibility, constraint satisfaction, and a practical $M$-step Lyapunov estimate, with asymptotic convergence when the prediction and reoptimization mismatch bound tends to zero. For constrained linear networks, the conditions reduce to finite-dimensional matrix, QP, and SOCP tests. The framework is specialized to current sharing and terminal bus voltage safety under DC/DC power converters' operational constraints in a two-DGU DC microgrid evaluated on a small laboratory-scale prototype.

## 1. 论文的核心问题与整体含义

**研究动机：**
- 经典逆李雅普诺夫定理本质上是存在性的，难以直接用于控制器构造；而有限步逆定理是构造性的：对于足够大的有限步长度 $M$，任意缩放范数都可作为有限步李雅普诺夫函数。
- 对于互联系统，有限步小增益条件在覆盖的系统类上是充分且必要的（即“非保守”），并能显式构造整体李雅普诺夫函数。
- 然而，分布式 MPC 中每个控制器无法获知邻居未来滚动时域优化将实际生成的轨迹，只能接收对方预告的预测轨迹。这种“预测与再优化不匹配”使名义上的有限步李雅普诺夫/小增益证书不足以直接保证递归可行性和稳定性。

**核心问题：**
如何在存在邻居预测不匹配的情况下，将集中式有限步控制李雅普诺夫函数（fs-CLF）合成原理扩展到受约束的非线性互联离散时间系统，同时保证递归可行性、约束满足和网络级稳定性。

## 2. 论文提出的方法论

### 2.1 核心设计思想
- 每个子系统在每个采样时刻独立求解一个局部有限时域最优控制问题（OCP），无需迭代协商。
- 局部阶段函数取为本地 fs-CLF（如 $W_i = \xi_i^\top P_i \xi_i$），终端约束采用有限步小增益不等式。
- 通过“时间对齐的邻居预测 + 优化的状态约束收紧半径 + 移位兼容约束裕度 + 一步终端可行性检验”来处理预测不匹配问题。
- 将“递归可行性”与“稳定性”分析分离：前者是移位后新 OCP 的性质，后者需要比较实际反复再优化的轨迹与早期完整时域名义预测。

### 2.2 关键技术细节

**系统与假设：**
- 系统模型：$x_i(t+1) = g_i(x_i(t), x_{\mathcal{N}_i}(t), u_i(t))$；
- 假设局部动态具有增量 Lipschitz 估计（含 Lipschitz 常数 $L_{i,1}, L_{i,2}, L_{i,3}$）；
- 假设存在有限步可容许反馈和循环小增益条件（通过缩放函数 $\sigma_i$ 显式构造全局 Lyapunov 函数）。

**通信架构：**
- 每个子系统接收邻居的预测包 $\bar{x}_j(t)$（长度 $M$，时间对齐）和标量 $s_j(t) := W_j(x_j(t))$（用于终端不等式右侧）；
- 采用移位插入操作生成下一时刻的数据包；支持协调器辅助、点对点、混合层次三种通信拓扑。

**局部 OCP（Problem 1）：**
- 决策变量：输入序列 $u_{M,i}(t)$ 和收紧半径 $r_{M-1,i}(t)$；
- 目标函数：$\sum_{l=0}^{M-1} W_i(x_i^{nom}(l|t)) + \lambda \sum_{l=1}^{M-1} r_i(l|t)$；
- 约束：标称动态、输入约束、半径非负、半径传播不等式 $r_i(l+1|t) \ge L_{i,1} r_i(l|t) + B_i(l|t)$、收紧状态约束 $x_i^{nom}(l|t) \in X_i \ominus B_{r_i(l|t)}$、终端小增益不等式。

**递归可行性（Theorem 1）：**
- 移位候选输入取上一时刻最优输入的后缀；候选半径按相同差分包含递推计算；
- 移位误差 $\chi_i(l|t+1)$ 由 Lipschitz 常数和相邻预测差递归界定；
- 总移位裕度 $\delta_i := \chi_i(l|t+1) + \tilde{r}_i(l|t+1)$，并用 Pontryagin 差分检验状态约束余量（Assumption 4）；
- 一步终端可行性问题（Problem 2）保证移位候选的最后一步输入满足终端不等式；对控制仿射系统可化为 SOCP 或区间检验（Lemma 2）。

**稳定性（Proposition 4、5）：**
- 定义实际到标称轨迹的不匹配界 $s_i(l+1|t) = L_{i,1}s_i(l|t) + \eta_i(l|t)$，其中 $\eta_i$ 捕捉超过 OCP 已知强制项（$B_i(l|t)$）的预测/再优化偏差；
- Lemma 3 证明 $\|x_i(t+l) - x_i^{nom,\star}(l|t)\| \le r_i^\star(l|t) + s_i(l|t)$；
- 通过循环小增益缩放函数构造全局 $V(x) = \max_i \sigma_i^{-1}(W_i(x_i))$，得到 $M$ 步实用李雅普诺夫估计：
  $$V(x(t+M)) \le \max\{\hat{\alpha}(V(x(t))), \hat{\gamma}(\rho(t))\}, \quad \rho(t):=\max_i(r_i^\star(M|t)+s_i(M|t)).$$
- 中间时间步也有界（Lemma 4）：$V(x(\tau+r)) \le \kappa_{int}(V(x(\tau))) + \Delta(\tau)$；
- 当 $\rho(t)\to 0$ 时渐近收敛；当 $\rho(t)=0$ 且偏移 $\Delta_0$ 随初值消失时，原点渐近稳定。

**线性网络特化（Section V）：**
- 状态转移矩阵 $\Phi(M) = A_K^M$，增益 $c_{ij}(M) = \|P_i^{1/2}\Phi_{ij}(M)P_j^{-1/2}\|_2$；
- 增益构造（Theorem 2）：选 $a_{ij} > 0$ 使 $\sum_{j\in J_i} c_{ij}(M)/\sqrt{a_{ij}} \le 1$；
- 循环小增益条件化为对数线性程序（LP）：$\log a_{ij} + y_j - y_i \le \vartheta < 0$；
- 约束可容许性用椭圆域支撑函数检验（Proposition 7）；
- 移位裕度检验化为逐行标量不等式；终端可行性化为 SOCP 或解析区间检验。

- **未讨论大规模网络的可扩展性**：线性网络下的检验条件（LP、SOCP、椭圆支撑函数）虽然多项式时间可解，但没有给出子系统数量增加时的计算复杂度和通信负担的实验数据；非线性增量 Lipschitz 常数的全局估计在多子系统场景下很可能急剧退化。

- **缺乏与现有方法的定量基准对比**：论文未与 Hermans 等 [9]、Zheng 等 [13] 等代表性 DMPC 方法在相同算例上对比保守性、计算时间和闭环性能，难以客观衡量该方法的相对优势。

- **稳定性证明依赖“不匹配界” $\rho(t)$ 的可积或衰减假设**：当 $\rho(t)$ 不趋于零时，仅能得到实用有界性；但 $\rho(t)$ 的上界依赖于在线求解 OCP 后的实测偏差，这在实际中难以先验验证，削弱了理论保证的直接可用性。

- **实验场景的扰动刻画过于简单**：仅使用一个电阻并联扰动，且扰动幅度只有约 51 mA；未考察较大扰动、参数跳变、负载随机波动等更具挑战性的情况，因此对“扰动期间保持稳定”的结论还不够充分。

---

## 9. 总体评价与启示

这篇论文在分布式 MPC 的理论与实验结合方面做出了有价值的贡献。其核心亮点在于把“有限步逆 Lyapunov 定理 + 循环小增益”从纯粹的存在性结果转化为可在线实施的约束条件，并通过“移位兼容裕度”巧妙地弥合了邻居预测与本地再优化之间的失配。相比传统终端不变集方法，这种处理既减轻了设计负担，又保持了递归可行性与 $M$ 步实用稳定的理论保证。线性网络下的 LP/SOCP 化检验进一步增强了方法的工程可用性。

然而，论文的验证仍属于“概念验证型”（proof-of-concept）：单网络规模、单扰动场景、无对比基准，使得其实际工程优势尚未被充分证明。未来的工作可沿以下方向展开：

1. **系统化鲁棒性实验**：引入通信丢包/延迟、参数不确定性、多扰动序列，量化理论保守性与实际性能之间的差距。
2. **更大规模网络**：在 5~10 个以上子系统上测试 LP 条件与实时求解器的扩展性，并与现有 DMPC 方法进行系统对比。
3. **自适应收紧半径**：利用在线估计的 Lipschitz 常数或模型失配信息，动态调整收紧半径，降低保守性。
4. **理论证明的弱化**：探索不需要严格衰减的 $\rho(t)$ 条件下也可以达到渐近稳定的替代条件，或允许预测误差有界但已知的鲁棒稳定框架。

总体而言，本文在理论构造、数值可计算性和硬件验证三方面都达到了较高标准，是分布式 MPC 领域一篇值得仔细研读的论文；但若要作为工程通用方案，仍需在实证广度和鲁棒性方面进一步打磨。

## 摘要
本文针对未知线性时不变系统，在状态反馈和基于观测器的输出反馈场景下，开发了一种直接数据驱动的鲁棒正不变（RPI）集合成框架。通过求解半定规划（SDP），直接从含噪声的离线数据中合成反馈增益、观测器增益以及相应的RPI集，避免了中间模型辨识或显式模型不确定性集的构建。在状态反馈情形下，首先计算线性二次（LQ）型反馈增益，然后针对所得闭环动态合成椭球RPI集。在基于观测器的输出反馈情形下，利用离线数据通过增广状态公式计算观测器增益及系统状态的相应RPI集。该设计为两种场景下的不变集计算提供了统一方法，且直接数据驱动公式避免了中间模型不确定性集的显式构建与传播。数值算例验证了所提方法的有效性。

## Abstract
This paper develops a direct data-driven framework for robust positively invariant (RPI) set synthesis for unknown linear time-invariant systems under state-feedback and observer-based output-feedback scenarios. The feedback and observer gains, along with the RPI sets, are directly synthesized from noisy offline data by solving semidefinite programs (SDPs), avoiding intermediate model identification or explicit model-uncertainty set construction. In the state-feedback case, a linear-quadratic (LQ)-type feedback gain is first computed, and an ellipsoidal RPI set is then synthesized for the resulting closed-loop dynamics. In the observer-based output-feedback case, offline data are used to compute the observer gain and the corresponding RPI set for the system state through an augmented-state formulation. This design provides a unified method for invariant-set computation in both scenarios, and the direct data-driven formulation avoids the explicit construction and propagation of an intermediate model-uncertainty set. Numerical examples illustrate the effectiveness of the proposed method.

## 六、论文的主要结论与发现

1. **直接数据驱动的可行性**：在未知系统模型的情况下，仅凭含噪声离线数据即可通过SDP合成有效的RPI集，无需模型辨识或显式不确定性集构建。
2. **解耦设计的有效性**：先设计LQ型增益、再计算RPI集的顺序结构避免了非凸耦合，在保持标称LQ性能目标的同时实现了RPI集的高效计算。
3. **与模型驱动基线的差距**：提出方法可得到有效的RPI集，但面积保守性约为模型mRPI的2~3.5倍（状态反馈约1.9倍），说明直接数据驱动方法仍有改进空间。
4. **与现有数据驱动方法的对比**：在椭球噪声下，提出方法在三个权重设置中均给出最小的坐标方向界（对比zonotope基线和[10]方法）；与[11]相比，在各自增益下面积减少90.38%，在共同增益下减少87.21%。
5. **输出反馈的可扩展性**：通过增广状态公式和分离设计，可将数据驱动RPI合成推广到未知系统、状态不可在线测量的实际场景，为稀疏状态平台（如GPS信号、运动捕捉系统离线标定）提供保障。
6. **统一框架优势**：状态反馈和输出反馈场景统一在同一个数据驱动LMI框架下，方法论可迁移性良好。

## 七、优点

1. **理论创新性强**：首次将直接数据驱动RPI合成系统化地扩展到输出反馈场景，利用增广状态公式和分离设计解决了该场景下噪声通道增多、非凸耦合增强的难题。
2. **避免模型不确定性集构建**：不同于现有主流方法（zonotope可达性、集合成员），直接从数据矩阵写LMI，避免中间模型集的保守放大效应。
3. **凸优化保证**：所有综合条件均表述为SDP，求解可靠、结果可复现，避免了[10]中非凸优化的初始化敏感性。
4. **解耦设计实用性好**：保留了LQ型增益设计目标（而非单纯追求RPI集最小化），与工程实践中性能-安全折中的需求一致。
5. **LMI构造技巧扎实**：充分利用Young不等式、S-procedure和Schur补，在保证凸性的同时尽量降低了保守性。
6. **对比实验较丰富**：与模型驱动基线、两种主流数据驱动框架均进行了对比，并在多种权重和噪声几何下验证。

## 八、不足与局限

1. **保守性依然较大**：输出反馈下与模型驱动方法相比面积比达2.69~3.48倍，对于安全关键系统，过大的不变集可能导致约束收紧过于保守，降低控制性能。
2. **离线数据要求较高**：
   - 假设系统状态在离线收集时完全可测，这在许多真实场景（如仅依赖GPS定位的部署环境）中是苛刻的，限制了对已有历史数据的利用；
   - 要求秩条件 rank([X₀; U₀]) = n + n_u，需要精心设计激励信号，实践中有一定难度。
3. **超参数选择依赖经验**：δ₁、δ₂、α、β等通过网格搜索确定，缺乏理论指导，搜索过程遍历代价和结果对超参数的灵敏度未系统分析。
4. **无消融实验**：未系统研究离线数据长度、SNR水平、激励幅度等对合成质量和RPI集紧致性的影响，数据效率不明确。
5. **对比公平性存疑**：表I中zonotope基线使用自己合成的增益，而方法[10]仅使用共同增益，增益来源不一致影响对比结论的稳健性。
6. **实验范围局限**：系统规模小（2维）、仅仿真验证、未涉及高维系统或部分可观性缺失更严重的场景；输出反馈对比仅限模型驱动方法，缺少与数据驱动替代方案的比较。
7. **缺乏理论保证的紧致性分析**：未给出数据量增加时RPI集收敛于真值RPI集的定量分析，实践中的样本需求不确定。

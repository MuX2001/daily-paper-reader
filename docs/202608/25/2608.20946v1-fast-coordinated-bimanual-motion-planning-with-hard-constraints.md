## 摘要
双臂操纵能够完成复杂任务，但涉及的大量自由度也带来了额外的复杂性。在处理刚性物体时，两个末端执行器之间的相对变换在整个运动过程中必须保持固定，这表现为一个非线性等式约束，将可行构型空间限制在一个零测度流形上，给传统运动规划器带来了挑战。我们提出了一种快速的双臂运动规划流程，通过领导者-跟随者参数化在整个路径上连续强制执行这一硬变换约束：领导者的构型被视为自由变量，而跟随者的构型则通过逆运动学确定以满足约束。我们在多种环境、约束和双臂平台上进行了广泛的仿真评估，在保证连续约束满足的同时，比之前的工作实现了19.4倍的规划速度提升。在双臂Kinova Gen3平台上进行的真实世界实验，涉及托盘运输和细长物体操作，验证了规划轨迹向物理硬件的直接迁移。

## Abstract
Bimanual manipulation enables complex tasks but introduces added complexity from the high number of degrees of freedom involved. When handling rigid objects, the relative transformation between the two end effectors must remain fixed throughout the motion, manifesting as a nonlinear equality constraint that confines the feasible configuration space to a measure-zero manifold and challenges conventional motion planners. We propose a fast bimanual motion planning pipeline that enforces this hard transformation constraint continuously along the entire path, using a leader-follower parameterization: the leader's configuration is treated as a free variable, while the follower's is determined via inverse kinematics to satisfy the constraint. We extensively evaluate the method in simulation across diverse environments, constraints and bimanual platforms, achieving 19.4x faster planning than prior work while guaranteeing continuous constraint satisfaction. Real-world experiments on a bimanual Kinova Gen3 setup, involving tray transport and elongated-object manipulation, validate direct transfer of planned trajectories to physical hardware.

## 论文详细总结

### 1. 核心问题与研究动机

- **问题背景**：双臂操作（bimanual manipulation）是实现复杂任务的关键能力，如折叠衣物、组装家具、搬运大型面板等。工业应用中也日益需要双臂协调来搬运超出单臂能力的大型或异形工件。
- **核心挑战**：当双臂刚性抓取同一物体时，两个末端执行器之间的相对变换必须在整个运动过程中保持固定。该约束表现为非线性等式约束，将可行构型空间限制为一个零测度（measure-zero）子流形。
- **为什么难**：随机采样的构型几乎必然违反约束；轨迹优化方法可能因约束的非凸性而难以收敛；传统方法依赖离线预计算（数分钟至数小时），环境改变即失效。
- **研究目标**：提出一种快速、无需离线预计算、机器人无关的双臂运动规划管线，在整条路径上连续满足刚性变换硬约束。

### 2. 方法论：核心思想与技术细节

**核心思路：领导者-跟随者参数化**

- 将双臂中的一条臂设为"领导者"，其构型 $q_L$ 作为自由变量直接在 C 空间中被采样/规划；
- 另一条臂设为"跟随者"，其末端位姿由约束决定：$X^*_F = FK_L(q_L) \cdot T$，其中 $T \in SE(3)$ 为期望的相对变换；
- 跟随者构型通过逆运动学（IK）求解：$q_F = IK_F(X^*_F, q^{seed}_F)$，以约束满足状态。

**关键技术细节：**

- **约束流形的参数化**：定义了参数映射 $\sigma(q_L) = (q_L, IK_F(FK_L(q_L)T; q^{seed}_F))$，将领导者构型直接提升为满足约束的双臂状态。该构造不依赖特定 IK 实现（解析解、数值优化或 IKFast 均可）。
- **种子（Seed）的作用**：IK 解集可能是多分支的，种子选择固定了 IK 分支，使相邻构型间 $\sigma$ 连续变化，避免 C 空间不连续。
- **约束感知的状态插值**：采用预测-校正机制，将领导者沿线性插值推进，每一步通过 IK 校正跟随者构型，保证路径上每一点都满足约束。插值步数与构型距离成比例，在参数化"刚性"区域自动加密步长。
- **有效的计算复用**：运动有效性检查中产生的中间 IK 解被保留并插入规划树，使运动验证同时充当信息采样，显著加速路径发现。
- **加权度量**：使用包装的加权角距离度量，对跟随者关节赋予更高权重，使最近邻查询倾向于选择跟随者运动更小的连接方向。
- **路径后处理**：包含路径简化（shortcut）、不连续检测与修正（通过给换领导者角色或插入中间状态来解决）、以及基于 TOPP-RA 的时间最优轨迹生成。
- **采样策略**：支持 C 空间采样和笛卡尔采样（可附加绝对朝向约束）；对领导者末端位姿超出可达空间包围盒的情况提前剔除。
- **理论基础**：约束残差函数 $F(q) = \log((FK_L(q_L)T)^{-1}FK_F(q_F))^\vee$，由正则值定理可知流形维数为 $2n-6$（7自由度臂为8维，6自由度臂为6维）。

### 7. 优点

- **硬约束连续保证**：不同于松弛化方法，本文方法在路径的每一个点（而非仅采样点）上都精确满足约束，这是对 [5] 的重要改进（[5] 在相同基准下存在可测的约束违背）。

### 8. 不足与局限

## 摘要
基于优化的控制器（如模型预测控制）的两个特性限制了其在航天飞行中的应用。在线计算时间会变化，可能超过采样周期，且闭环行为没有形式化保证。显式模型预测控制（MPC）通过预先计算优化问题的参数化解，用分段仿射函数的查找表替代机载优化，执行时间固定。然而，它一直被认为仅适用于短预测时域，因为分区数量限制了表的存储，且仅能保证随预测时域指数增长的上界。本文基于二次规划参数化求解和非凸可达性分析的最新进展，为Clohessy-Wiltshire动力学下的航天器交会控制提供了完整流程。对于该应用，可以从计算时间和内存两方面构建高效的数据结构来编码控制律。此外，通过混合多面体（hybrid zonotopes）的可达性分析，可以在线验证控制器并保证闭环稳定性。在51步预测时域下，交会控制律占用10.5 MB内存，评估时间低于300纳秒。该内存占用适用于如CubeSat飞行计算机ARM9级AT91RM9200，这意味着当使用本文所示的参数化求解器和数据结构构建分区时，预测时域的限制不再成立。

## Abstract
Two properties of optimization-based controllers such as model predictive control (MPC) limit their use in space flight. The online computing time varies and can exceed the sampling period, and the closed-loop behavior carries no formal guarantee. Explicit MPC, where a parametric solution of the optimization problem is computed, replaces the on-board optimization with a lookup table of piecewise-affine functions with a fixed execution time. However, it has been regarded as only applicable to small horizons, since the number of regions bounds the memory the table occupies and admits only an exponential bound in the horizon. This paper builds on recent developments in parametric solutions of quadratic programs and nonconvex reachability analysis to provide an entire pipeline for spacecraft rendezvous controllers under the Clohessy-Wiltshire dynamics. For this application, efficient data structures can be constructed to encode the control law, both from a computing time and a memory standpoint. In addition, the controller can be verified offline with a guaranteed closed-loop stability certificate by resorting to reachability analysis with hybrid zonotopes. At a 51-step horizon the rendezvous law occupies 10.5 MB and is evaluated in under 300 ns. The occupied memory would fit for instance the CubeSat flight computer ARM9-class AT91RM9200 meaning that the horizon limitation does not hold when the partition is built with the parametric solvers and data structures shown in this paper.

## 1. 核心问题与整体含义

航天器自主交会控制要求控制律具备两个相互冲突的特性：

- **实时性**：必须能在空间级处理器上实时生成满足约束且节省推进剂的运动轨迹；
- **可验证性**：闭环行为必须在发射前针对整个导航散布范围得到形式化保证，而非仅通过仿真案例验证。

模型预测控制（MPC）虽能处理约束并优化控制量，但存在两个阻碍航天应用的问题：在线计算时间不确定（可能超过采样周期），且闭环行为缺乏形式化保证。显式 MPC 通过离线参数化求解，将在线优化替换为固定执行时间的分段仿射查找表，但传统观点认为其分区数量随预测时域呈指数增长，仅适用于短时域。

本文的核心贡献在于**打破这一限制**：结合二次规划参数化求解与混合 zonotope 可达性分析，构建了一套完整的航天器交会显式 MPC 流程。在 51 步预测时域下控制律仅占 10.5 MB 内存、评估时间低于 300 ns，可运行于 CubeSat 级飞行计算机（ARM9 级 AT91RM9200），并实现了离线可证明的闭环稳定性。

## 2. 方法论

### 2.1 总体框架

论文将问题拆分为两个子问题：

- **Problem 1（在线实现）**：选择输入参数化 T，使显式解在飞行处理器存储和评估预算内可行；
- **Problem 2（离线验证）**：对所选控制器，证明所有初始条件与所有有界扰动序列下约束始终满足且状态收敛至有界集合。

### 2.2 参数化 MPC 与显式解

- 采用 Clohessy-Wiltshire（CW）线性相对运动模型，离散化为 `x_{k+1} = A x_k + B u_k + w_k`，扰动满足 `w_k ∈ W`（紧致凸集，含原点）。
- 标准 MPC 的凝结形式为二次规划（QP），通过输入参数化 `U = Tη`（η 为自由变量，nη ≤ N·nu）降维。
- 比较四种标准参数化：
  - **标准**：T = I；
  - **控制时域**：只保留前 Nu 个自由输入；
  - **Laguerre**：离散 Laguerre 函数基（参数极点为 aL）；
  - **move-blocking**：输入分块保持恒定。
- 显式解为连续分段仿射映射 `η*(x) = Γ_i x + γ_i`，分区 {Θ_i} 的并集覆盖可行参数域。在线评估通过二叉搜索树定位分区，深度为区域数的对数，执行时间与数据无关。

### 2.3 常数增益区域（Lemma 1）

对于任意参数化 T，可闭式给出一个多面体区域 CT（称为常数增益区域）：

\[
C_T := \{x ∈ X : (-G_T P_T - S)x ≤ g\}
\]

在该区域内优化问题达到无约束解，施加输入退化为单一常数增益：

\[
u^*(x) = -K_T x, \quad K_T = E_0 T P_T
\]

该区域由凝结 QP 的矩阵直接计算，无需枚举关键区域。

### 2.4 鲁棒不变集与有限步缩减（Theorem 2 & 3）

- 利用 Gilbert-Tan 最大容许集递归，并加入支撑函数收紧以处理有界扰动，构造 CT 内的**最大鲁棒正不变子集 O_W^∞**。
- 若存在有限 k* 使闭环可达集 R_W^{k*} ⊆ O_W^∞，则从 k* 起：
  - 控制器退化为固定增益 `u_k = -K_T x_k`；
  - 约束对所有时间成立；
  - 若 A_cl 舒尔稳定，状态收敛到 (A_cl, W) 的最小鲁棒正不变集（W={0} 时收敛至原点）。
- 验证的关键在于**精确可达集传播**：利用混合 zonotope 表示多参数 QP 的解（由 KKT 条件与大 M 互补条件构造），闭环可达集可无损传播，不会因过近似累积保守性。扰动进入方式仅增加连续生成元，不改变二进制变量维数，因此可达性验证的计算复杂度与标称情况相同。

## 6. 主要结论与发现

1. **控制时域参数化优于 Laguerre 和 move-blocking**：
   - 控制时域在 N≥11 时闭环成本比标准设计低最多 22%（N=51 时 J 为 1.660×10^10 vs 标准 2.129×10^10）；
   - 离线构建速度比标准快约 3 倍（N=51 时 707 s vs 2199.7 s）；
   - 当只存储实际施加的第一输入块（u0）时，控制时域和标准的存储差异缩小至 15%，但仍保持 24× 优势（存储完整预测序列时）。
2. **move-blocking 最弱**：MB2 虽生成最小分区（1.4 MB），但无法完成交会任务；MB3 恢复任务但分区反而增大且仍失败 35%；粗阻塞减少分区规模却丧失控制权限。
3. **显式 MPC 可突破预测时域限制**：N=51 时控制律 10.5 MB，评估最快 86 ns、最坏 <300 ns，完全满足 CubeSat 级处理器资源预算。
4. **可证明的闭式常数增益缩减**：在 LEO 场景中，全散布初始条件在 k*=4（标称）或 k*=6（5W 扰动）后，MPC 退化为固定 LQR 型增益，此时纪律验证转化为线性系统鲁棒稳定性问题（ρ(A_cl)=0.54）。
5. **扰动影响有限**：5 倍物理扰动仅使缩减延迟 2 步，鲁棒不变集仍保留 CT 的 33.6% 体积，且验证计算复杂度不增加。

## 8. 不足与局限

- **模型范围**：CW 线性模型仅适用于近圆目标轨道、近距离相对运动；远距离或高偏心率目标的验证需更换相对运动模型（论文明确说明该局限）。
- **不变集非全局最大**：O_W^∞ 只是在常数增益区域 CT 内的最大鲁棒不变集，并非整个显式分区切换系统的最大不变集，因此 k* 只是一个上界，可能偏保守；文中指出更大的不变集会降低 k*，但没有给出显式构造方法。
- **可行性假设依赖**：定理 3 依赖 Assumption 2-4（收缩后走廊非空、可达集被分区覆盖、程序可行），这些前提需要通过混合整数测试验证，论文未给出验证失败时的回退策略。
- **扰动建模简化**：W 由网格测量取上界并乘 1.25 倍得到，属启发式构造，无法严格覆盖所有未建模误差；5W 测试虽较保守，但缺乏时变/非平稳扰动场景。
- **硬件实测缺失**：论文只报告了在工作站上的评估时间，而实际飞行处理器（如 AT91RM9200）的测量仅做出估计（“微秒量级”），未提供基准测试代码或真实机载实验数据。
- **与现有鲁棒 MPC 的对比不足**：未与 tube MPC、随机 MPC 等方法进行端到端对比（性能、内存、验证复杂度），削弱了方法替代性的说服力。

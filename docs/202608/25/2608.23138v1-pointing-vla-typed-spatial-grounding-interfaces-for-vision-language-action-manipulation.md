## 摘要
视觉-语言-动作（VLA）模型通常通过自回归文本坐标或不透明的动作令牌暴露空间接地，在多模态推理与机器人执行之间创建脆弱的接口。我们提出Pointing-VLA，一种基于Embodied-R1的类型化隐藏状态空间读出。几何专用头预测归一化点、对象功能接地（OFG）热图和视觉轨迹，而不将几何序列化为文本。对于评估的Bridge/WidowX和物理拾放部署，显式执行契约将PICK分配给源条件OFG，将PLACE分配给Pointing，提供直接阶段对齐的空间目标。Pointing-VLA在Bridge/WidowX上实现了SOTA性能，在启用碰撞的CuRobo执行下，无需Bridge特定微调，在评估的四个任务集上平均达到72.9%。Pointing和OFG在原生和跨数据集评估中表现出互补优势。OFG/接触读出迁移到NORA-1.5，在保持或提高成功率的同时，将记录的控制器时间减少20倍以上；在共享外部套件上，类型化头也比Embodied-R1文本解码快6.68--6.90倍。当作为π_0.5动作策略的空间引导集成时，Pointing-VLA在三种视觉环境下将自主真实机器人成功率从52.7%提高到80.7%。这些结果确立了类型化空间读出作为具身推理与机器人执行之间高效、可检查的接口。

## Abstract
Vision-language-action (VLA) models often expose spatial grounding through autoregressive text coordinates or opaque action tokens, creating brittle interfaces between multimodal reasoning and robot execution. We present Pointing-VLA, a typed hidden-state spatial readout built on Embodied-R1. Geometry-specific heads predict normalized points, object-functional grounding (OFG) heatmaps, and visual trajectories without serializing geometry as text. For the evaluated Bridge/WidowX and physical pick-place deployments, an explicit execution contract assigns PICK to source-conditioned OFG and PLACE to Pointing, providing direct stage-aligned spatial targets. Pointing-VLA achieves SOTA performance on Bridge/WidowX, averaging 72.9\% across the evaluated four-task set without Bridge-specific finetuning under collision-enabled CuRobo execution. Pointing and OFG show complementary strengths across native and cross-dataset evaluations. The OFG/contact readout transfers to NORA-1.5, preserving or improving success while reducing recorded controller time by more than 20$\times$; typed heads are also 6.68--6.90$\times$ faster than Embodied-R1 text decoding on a shared external suite. When integrated as spatial guidance for a $π_{0.5}$ action policy, Pointing-VLA raises autonomous real-robot success from 52.7\% to 80.7\% across three visual contexts. These results establish typed spatial readouts as an efficient, inspectable interface between embodied reasoning and robot execution.

# Pointing-VLA：类型化空间接地接口用于视觉-语言-动作操作

## 1. 核心问题与整体含义

**研究动机与背景：**

现有视觉-语言-动作（VLA）模型在将多模态推理与机器人执行连接时，存在输出接口瓶颈。具体表现为两类问题：

- **文本坐标输出**：自回归生成文本坐标（如 `[222, 172]`）存在双重脆弱性——既可能生成无法解析的无效坐标，也可能输出语法正确但空间位置错误的坐标。此外，将几何序列化为文本需要花费大量 token 拼写数字，执行端还需将字符串解析回像素坐标，密集的部位级空间证据在传给执行器之前就被丢弃。
- **不透明动作令牌**：直接输出动作令牌虽然避免了解析问题，但隐藏了空间推理依据，机器人端或人类审计者无法检查系统的空间决策过程。

论文的核心主张是：**具身接地（embodied grounding）应被视为类型化接口预测（typed interface prediction），而非文本坐标生成**。指向点（point）、功能区域（affordance region）和视觉轨迹（trajectory）是相关但不完全相同的空间目标——点稀疏、功能区域密集、轨迹具有时间结构。将它们压缩为单一输出分布会造成负干扰，而将其全部序列化为文本则使执行更慢、更不稳定。

## 2. 方法论：Pointing-VLA

**核心思想：**

基于 Embodied-R1 骨干，从共享多模态隐藏状态中直接解码几何专属的机器人目标，避免将几何序列化为文本。该方法受神经科学中"视觉-行动"双通路假说和群体读出（population readout）计算观点的启发：下游读出直接从分布式内部活动中解码空间变量，而非通过表征这些变量的系统进行序列化。

**技术架构：**

- **基础骨干**：使用 Embodied-R1 作为共享多模态状态编码器（冻结基础权重）
- **Grounding Adapter**：将多模态隐藏状态投影到接地空间，通过 1024 维投影、可学习查询、交叉注意力生成固定数量的接地 token
- **三种几何专用头**：
  - **Pointing 头**：通过指针查询从接地 token 中选出证据，直接输出归一化坐标 $(\\hat{x}, \\hat{y}) \\in [0,1]^2$
  - **OFG 头**：保留空间范围，通过 FiLM 调制视觉特征图，经卷积热图解码器生成密集热图 $\\hat{H}_{ofg}$，峰值位置作为功能接触点
  - **VTG 头**：使用带时间编码的可学习路点查询，直接关注完整多模态序列，输出 $T=8$ 个归一化图像空间路点

**输入处理流程：**

$$X_e = W_e^H H_{mm}^e + P_e, \\quad A_e = \\text{softmax}\\left(\\frac{(Q_e W_e^Q)(X_e W_e^K)^\\top}{\\sqrt{d}}\\right), \\quad G_e = \\text{FFN}_e(A_e X_e W_e^V)$$

**部署契约：**

- **PICK** → 源条件 OFG（source-conditioned OFG）：基于指令、源描述构建查询，输出功能接触热图，用于抓取阶段
- **PLACE** → Pointing：基于指令、目标描述构建查询，输出紧凑目标点，用于放置阶段
- 外部包装器通过标定深度 $D$、相机内参 $K$ 和相机-机器人变换 $T_{r\\leftarrow c}$ 将图像空间输出转换为机器人坐标

**训练策略（三阶段）：**

1. **几何热身**：训练 Grounding Adapter + 几何头（8 个查询）
2. **LoRA 专业化**：仅更新低秩骨干参数（rank-32）
3. **任务延续**：仅更新任务所需子集，并应用 GRPO 风格的组归一化细化来精炼连续空间头

**训练目标：**

$$L = \\lambda_{pt} L_{pt} + \\lambda_{box} L_{box} + \\lambda_{ofg} L_{ofg} + \\lambda_{vtg} L_{vtg} + \\lambda_{aux} L_{aux}$$

其中点与轨迹坐标使用 SmoothL1 损失，OFG 使用高斯关键点 MSE 或类别平衡二值交叉熵。

1. **类型化空间读出有效**：Pointing-VLA 在 VABench-P 上与 Embodied-R1 持平（64.3%），在 Part-Affordance-2K 上大幅超越（57.3% vs 40.9%），提升 16.4 个百分点。

## 7. 优点

- **接口设计的类型化思维**：将稀疏点、密集区域、时序轨迹视为三种不同几何模态，分别设计专用解码头，避免负干扰。
- **隐藏状态读出替代文本序列化**：直接从多模态隐藏状态解码空间目标，消除了解析依赖和 token 开销，从接口层面提升了效率与稳定性。
- **显式阶段对齐契约**：PICK 用保留空间范围的热图、PLACE 用紧凑点，对齐各执行阶段所需几何精度，设计逻辑清晰且可解释。
- **跨骨干迁移验证**：在 NORA-1.5 和 π₀.₅ 两个不同 VLA 骨干上验证了读出的可移植性，增强了方法的通用性。
- **真实部署证据充分**：在物理机器人上完成 150 次试验（3 场景 × 50 次），并提供了失败阶段分析，证据级别较高。
- **效率数据完整**：提供已知头的运行时对比，量化了接口层面的速度优势。

## 8. 不足与局限

- **任务范围有限**：真实机器人仅验证单一拾-放任务类型，未覆盖更广义的操作任务（如组装、多步操作或非预定义轨迹操作）；Bridge/WidowX 评估也仅四个任务。
- **闭环视觉纠正缺失**：论文自身指出 spoon-on-towel 任务的失败率较高，识别出闭环、几何感知执行是下一步关键杠杆点；当前方法依赖开环空间目标预测。
- **跨数据集评估协议可能低估 OFG**：将所有输出统一为点协议并仅用 PIM/PIB 评估，未充分体现 OFG 密集区域输出的全部价值维度。

## 摘要
视觉-语言-动作（VLA）模型的实际部署常常受到效率与性能权衡、跨实体泛化和执行平滑性的瓶颈限制。我们提出了NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，优化了计算资源和模块化。为了弥合异构机器人之间的语义鸿沟，我们引入了GESTURE-7，一种统一的基于语言的动作表示。此外，我们的引导动作算法通过基于掩码的平滑约束来强制运动学连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上实现了85.5%的平均成功率，并将动作生成加速了约2.7倍。这种异步设计使得实际机器人系统能够实现高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

## 1. 论文的核心问题与整体含义

- **研究动机**：视觉-语言-动作（VLA）模型在真实机器人部署中面临三大瓶颈：
  - **效率与性能的权衡**：传统的单频同步架构无法同时满足低频语义推理（需要较大计算开销）和高频电机控制（需要低延迟）的需求；
  - **跨本体泛化困难**：现有动作表示方式（如离散 token 化、连续回归）难以在不同形态的机器人（如灵巧手、夹爪）之间建立统一语义；
  - **执行平滑性问题**：异步推理与动作块生成之间时间错配，导致轨迹抖动和块边界不连续。
- **论文核心思想**：提出一种**异步双频架构（fast-slow）**，将高层语义规划（System 2，约 10 Hz）与低层反应式控制（System 1，约 20 Hz）解耦，并配套统一动作表示 GESTURE-7 和 Guide Action 平滑机制，从而同时提升效率、泛化能力和执行连续性。
- **整体意义**：为 VLA 模型在真实机器人系统上的高效、平滑、可扩展部署提供了一种系统化解决方案，验证了异构频率协同的有效性。

## 2. 论文提出的方法论

### 2.1 核心架构：双频异步系统

- **System 2（慢系统，约 10 Hz）**：基于 Qwen3-VL 大语言-视觉模型，处理自然语言指令和稀疏视觉输入，输出高层语义规划和抽象动作引导。
- **System 1（快系统，约 20 Hz）**：基于 DiT（扩散 Transformer），接收 System 2 的引导信息、高频视觉输入和动作历史，通过去噪过程生成高频连续动作。
- 两个系统通过显式数据流解耦，支持分布式部署，从而降低交互延迟，最大化硬件利用率。

### 2.2 GESTURE-7：统一动作表示

- 将末端执行器状态编码为 7 维向量：`[x, y, z, r, p, w, gesture]`
  - `x, y, z`：笛卡尔位置（单位：cm）
  - `r, p, w`：姿态角（roll, pitch, yaw，单位：度）
  - `gesture`：自然语言关键词（如 `grasp`, `push`, `rotate`, `release`）
- 不同形态的机器人执行同一动作时共享相同的关键词（例如夹爪和灵巧手的“抓取”都统一为 `grasp`），从而实现跨本体语义统一。
- 位置和角度被有意量化为整数（cm 和度），降低学习难度并减少预测幻觉。
- 该表示天然支持语言条件强化学习，便于引入 RL 训练。

### 2.3 Guide Action：引导动作平滑机制

- **灵感来源**：图像外绘（Image Outpainting）与 RePaint 中的掩码引导生成思想。
- **问题**：原生异步算法在推理结束后会进行硬切换，导致轨迹阶跃和机械抖动。
- **方法**：生成下一个动作块时，将前一个动作块中未执行的动作点（例如 a4–a7）作为先验引导锚点，在扩散去噪过程中通过二进制掩码强制保留已知动作，只对新生区域进行生成。
- **数学形式**：
  - 条件概率模型：  
    \( p_\theta(A^{t-1}_{full} | A^t_{full}, A_{prior}, \tau) \)
  - 去噪后强制恢复已知区域：  
    \( A^{t-1}_{full} = M \odot A^{(t-1)}_{prior} + (1-M) \odot A^{t-1}_{noisy} \)
    - M 为二进制掩码，前 k 个位置为 1（严格保留），后续为 0（模型生成）。
- **训练时**：引导锚点数从 0 到 3 随机采样，以适应推理延迟变化。

### 2.4 三阶段训练流程

- **Stage 1：System 2 监督微调（SFT）**
  - 任务包括：GESTURE-7 位姿回归、2D 关键点回归、2D 路径点预测、3D 轨迹预测、CoT（思维链）推理与规划。
- **Stage 2：System 2 强化学习（GRPO）**
  - 基于 GESTURE-7 距离、关键点定位奖励、路径点奖励（含 DTW）、轨迹奖励和格式奖励，增强轨迹规划能力。
- **Stage 3：System 1 监督微调**
  - 联合优化 S2 和 S1，采用加权流匹配损失（flow-matching loss），仅对新生成区域计算损失。

## 7. 优点

- **架构创新**：异步双频设计将慢思考与快反应解耦，兼顾语义理解能力和实时控制响应，且支持分布式部署，工程实用性高。
- **动作表示统一**：GESTURE-7 通过自然语言关键词实现跨本体语义对齐，简化了异种机器人的动作空间表达，且天然支持强化学习奖励设计。
- **平滑性内生**：Guide Action 将平滑约束嵌入生成过程，而非后处理，避免了额外计算和语义不一致问题。
- **实验设计较全面**：同时覆盖仿真鲁棒性、真实机器人任务、延迟测量和消融分析，结果对比清晰。

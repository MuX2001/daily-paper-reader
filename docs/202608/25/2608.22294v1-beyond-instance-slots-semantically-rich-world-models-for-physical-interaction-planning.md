## 摘要
用于物理交互的世界模型通常被训练来预测未来的观测或潜在特征；然而，一个面向规划的模型必须回答一个根本不同的问题：候选动作是否能产生与任务一致的未来，同时保持基本关系。 monolithic状态表示掩盖了底层实体，而标准的实例级对象槽仅识别“什么”存在，而不指定每个实体在任务上下文中扮演“什么角色”。为弥合这一差距，我们提出了语义丰富世界模型（SR-WM），一种以任务为条件的世界模型，围绕五个功能角色构建：夹爪、目标、目的、关系和阶段。在SR-WM中，视觉实体编码器从预训练的patch特征中提取软实体假设，允许分割掩码作为可选建议先验，而不强制将其作为必需的状态表示或推理输入。随后，角色绑定器将这些假设映射到特定任务角色，而动作条件下的动力学模型预测角色转换以及细粒度语义，包括抓取/接触、谓词建立、关系保持、夹具状态和阶段变化。关键的是，这种统一的角色状态为下游的多候选动作生成、阶段感知重排序和违反感知后缀重采样提供了基础。我们全面的评估协议覆盖所有四个LIBERO模拟套件、跨套件迁移、感知诊断和动作敏感性分析。最终，这一公式将对象中心预测转变为连接视觉动态与规划导向决策的语义接口。

## Abstract
World models for physical interaction are typically trained to predict future observations or latent features; however, a planning-oriented model must answer a fundamentally different question: whether a candidate action produces a task-consistent future while preserving essential relations.Monolithic state representations obscure the underlying entities, while standard instance-level object slots merely identify \emph{what} is present without specifying \emph{what role} each entity plays in the task context. To bridge this gap, we present the Semantically Rich World Model (SR-WM), a task-conditioned world model structured around five functional roles: gripper, target, goal, relation, and phase.Within SR-WM, a visual entity encoder extracts soft entity hypotheses from pretrained patch features, allowing segmentation masks to serve as optional proposal priors without mandating them as required state representations or inference inputs.A role binder subsequently maps these hypotheses to task-specific roles, while an action-conditioned dynamics model predicts role transitions alongside fine-grained semantics, including grasp/contact, predicate establishment, relation preservation, fixture state, and phase change.Crucially, this unified role state grounds downstream multi-candidate action generation, stage-aware reranking, and violation-aware suffix resampling.Our comprehensive evaluation protocol spans all four LIBERO simulation suites, cross-suite transfer, perception diagnostics, and action-sensitivity analysis.Ultimately, this formulation transforms object-centric prediction into a semantic interface linking visual dynamics with planning-oriented decision making.

# 论文详细总结

## 1. 论文的核心问题与整体含义

**研究动机与背景：**

- 物理交互领域的**世界模型（World Model）**通常被训练用于预测未来像素、潜在特征或观测值，但**低预测误差并不等于好的决策**。一个"看似合理"的未来可能在接近错误物体、丢失抓取、打开错误的夹具或过早释放。
- 规划导向的世界模型必须回答一个根本不同的问题：**候选动作能否产生任务一致的未来，同时保持已满足的关键关系**？这要求模型显式表达"动作需要建立什么状态、保持什么约束"。
- 现有方法存在两类不足：
  - **Monolithic 状态表示**（如单一潜在向量）掩盖了底层实体，难以判断哪个物体是目标、哪个是目的地、抓取是否稳定、谓词是否满足。
  - **实例级对象槽（Instance-level Slots）** 只识别"场景中有什么实体"，不指定每个实体在具体任务中的**功能角色**。同一个物体在不同指令下可能是 target、goal 或干扰物，但可交换的槽位无法体现这种任务绑定。
- 为解决上述问题，论文提出 **语义丰富世界模型（SR-WM, Semantically Rich World Model）**，将物体中心预测转化为一个**连接视觉动力学与规划决策的语义接口**。

## 2. 方法论

### 2.1 核心思想

SR-WM 将视觉实体从任务无关的"可交换实体假设"转化为**任务条件的功能角色状态**：

\[
Z_t = \{ z^{grip}_t, z^{tgt}_t, z^{goal}_t, z^{rel}_t, z^{phase}_t \}
\]

五个角色分别为：
- **Gripper**：末端执行器位姿、开合、接触与抓取状态；
- **Target**：任务相关的物体或铰接部件及其几何；
- **Goal**：容器、表面、目的地或期望的夹具状态；
- **Relation**：夹爪-目标、目标-目的之间的几何与符号谓词；
- **Phase**：任务进展阶段（接近、抓取、运输、对齐、释放、完成）。

关键区别：这些角色**不是后置的语义分类标签**，而是直接构成世界模型预测、动作生成和选择的状态空间。

### 2.2 关键技术细节

1. **软实体提取（Soft Entity Hypotheses）**
   - 基于轻量 LeWM（15M 参数：5M ViT-Tiny 编码器 + 10M Transformer 预测器）提取 patch 特征。
   - 通过可学习 query 跨视图交叉注意力产生 N 个软实体：
     \[
     e_{t,n} = [f^{app}_{t,n}, g^{geom}_{t,n}, m^{motion}_{t,n}, c^{conf}_{t,n}]
     \]
     包括外观、几何、运动、置信度四个子向量。
   - 实体是"软的"，无需与分割掩码一一对应；被遮挡物体可分布在多个 patch 上。

2. **可选掩码先验（Optional Mask Prior）**
   - Grounding DINO + SAM/SAM2 产生 proposal-to-patch 亲和度，作为**加法注意力偏置**：
     \[
     \alpha_{n,i} = \text{softmax}_i(q_n^\top k_i / \sqrt{d} + \lambda_{seg} M_{n,i})
     \]
   - 训练时对 proposal 集合、掩码、偏置强度进行 dropout；推理时 \(\lambda_{seg}=0\) 即纯 patch 推理。
   - 掩码不是必需状态表示，只是可选的结构先验。

3. **任务条件角色绑定（Task-Conditioned Role Binding）**
   - 语言条件角色 query 对实体交叉注意力：
     \[
     z^r_t = \sum_n b_{r,n} v(e_{t,n}), \quad b_{r,n} = \text{softmax}_n(q_r(\ell,q_t)^\top k(e_{t,n})/\sqrt{d} + u_r^\top g_{t,n})
     \]
   - 五个 query 不可交换且单独参数化；gripper 包含本体感觉，target/goal 依赖指令 token，relation 聚合交互几何，phase 聚合历史。
   - 同一实体在不同指令下可绑定到不同角色，无需重学实体编码器。

4. **动作条件角色动力学**
   - 动作编码器将动作块分为 J 个有序段，角色 Transformer 交替进行角色间自注意力和动作交叉注意力。
   - 使用**门控残差更新**：
     \[
     \Delta z^{r,k}_j = D^r_\theta(Z^{k}_{t,j-1}, E_a(A^k_{t,j}), \ell)
     \]
     \[
     \hat{z}^{r,k}_{t,j} = z^{r,k}_{t,j-1} + \sigma(g^{r,k}_j) \odot \Delta z^{r,k}_j
     \]
   - 预测 J 个中间转移而非仅终点，便于定位违规发生位置。

5. **语义转移监督（Semantic Transition Supervision）**
   - 在每个段预测 6 类语义：接触/抓取、谓词建立、关系保持、合取满足、阶段身份与转移有效性、夹具运动学状态。
   - 通过**硬负样本**训练判别力：打乱动作段、反转接近-抓取顺序、替换轨迹、扰动释放时机，并施加 margin 排序损失：
     \[
     L_{shuf} = \max(0, m - S_\omega(Z_t, A^+_t) + S_\omega(Z_t, A^-_t))
     \]

6. **多候选生成、选择与修复**
   - **生成**：Flow-Matching（FM）动作头以角色状态为条件采样 K 个候选。
   - **选择**：阶段感知选择器综合阶段、接触、谓词建立/保持、夹具有效性、不确定性，对候选排序。
   - **修复**：若最佳候选分数低于阈值或在段 \(j^*\) 出现违规，则**固定有效前缀**、只重采样后缀（掩码动作修补），实现 violation-aware suffix repair。

7. **训练目标**：11 项损失分为表示、语义、策略三组，包含 LeWM 保留目标、角色绑定、状态动力学、接触/谓词/保持/阶段/夹具损失、FM 动作损失、硬负样本排序和修复损失。

## 6. 主要结论与发现

1. **角色状态显著改善生成与覆盖**：SR-WM 将 Candidate 0 成功率从 45.5%（LeWM latent）提升至 62.8%，Oracle@4 覆盖从 68.0% 提升至 89.5%。
2. **语义选择与后缀修复有效**：语义选择器达到 75.3% top-1 成功，后缀修复进一步提升至 **83.0%**（对比 LeWM latent 的 50.2%）。
3. **分割掩码非必需**：纯 patch 推理仍达 72.6%，损坏掩码仅降为 70.8%；oracle 掩码给出 78.4% 上界，说明掩码只是可选先验。
4. **显式语义监督不可或缺**：去除语义头后排序准确率从 78.2% 降至 60.8%；去除硬负样本后近随机（53.7%）；去除保持/阶段损失均显著下降。
5. **结构化角色优于实例槽**：从 5 个实例槽（55.0%）到完整五角色（83.0%）的渐进增益证明显式语义绑定、关系状态和阶段状态是必要的。
6. **角色表示可迁移**：Object 套件预训练模型在 Spatial/Goal 上零样本保留 58.4%/52.7%；适配后优于从零训练（Goal：74.6% vs 66.3%；LIBERO-10：58.7% vs 50.6%）。
7. **轻量完整系统**：完整 SR-WM + FM 共 45.4M 参数，在 A100 上生成 30.2ms/候选集、评分为 7.3ms。

## 7. 优点

- **问题定义清晰**：识别出"实例槽不等于任务角色"这一关键差距，并提出规划导向的语义接口。
- **方法设计简洁且自洽**：五个角色同时服务于生成、预测、选择、修复四个环节，是内在统一的角色状态而非后置语义头。
- **软实体 + 可选掩码**：不依赖分割掩码，且对损坏掩码鲁棒，增强部署可行性。
- **评估体系严谨**：把"生成能力"（Candidate 0）、"覆盖能力"（Oracle@K）、"选择能力"（Selected@K）和"修复能力"（Suffix repair）分离，避免用单一成功率掩盖问题来源。
- **动作敏感性验证充分**：用 shuffle/reverse/替换轨迹等硬负样本验证模型确实学习到因果顺序，而非静态视觉捷径。
- **系统透明**：报告完整参数数、训练内存、延迟，并给出复现包和实验声明边界。

## 8. 不足与局限

1. **角色本体论受限**：五角色（单夹爪、单目标、单目的）不适用于双臂操作、多目标并行、可变形物体、工具使用等复杂任务，需扩展为变基数状态图。
2. **监督标签依赖仿真**：谓词、阶段、夹具状态标签在仿真中便宜，但在真实物理系统需要仔细标注或估计，落地成本高。
3. **感知失败未消除**：掩码先验的 dropout 降低了依赖，但不解决极端遮挡下的绑定/跟踪失败（论文定性错误分析也承认 peg-in-hole 场景的遮挡问题）。
4. **修复机制有安全限制**：前缀保留重采样增加推理调用，且没有碰撞检查与底层安全防护，不适合直接用于安全关键执行。
5. **训练算力信息不完整**：未报告 GPU 数量、总训练时长和总能耗，难以评估训练成本。
6. **"小模型"声明需谨慎**：尽管 LeWM 是 15M，完整系统 45.4M，论文已声明不做过度的端到端"小模型"或实时性宣称。
7. **Oracle@K 高不代表可部署**：如果选择器弱，高覆盖上界只反映生成多样性，论文也明确承认这点，但实际部署仍有 14 点以上的遗憾差距（75.3% vs 89.5%）。

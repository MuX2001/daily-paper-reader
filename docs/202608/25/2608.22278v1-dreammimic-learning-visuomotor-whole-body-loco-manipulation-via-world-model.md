## 摘要
基于视觉的仿人机器人全身操作具有挑战性，原因在于部分可观测性、接触丰富的动力学以及从高维视觉输入中学习长时程行为的难度。我们提出了DreamMimic，一个通过世界模型辅助蒸馏将特权教师策略蒸馏为基于视觉的仿人控制器框架。我们并非使用Dreamer风格的RSSM进行规划，而是将其重新用于学习预测性潜在动力学，既作为表示空间，也作为动作条件下的多步监督信号，同时向学生策略暴露紧凑的预测特征以减少长期漂移。除了对本体感觉和视觉观测的标准重建目标外，我们还添加了针对特权状态、接触、物体状态和奖励估计的辅助预测头。这些预测头提供了与智能体-物体交互和任务进展相关的额外监督，鼓励潜在表示保留对接触丰富的操作有用的信号。我们进一步引入了性能条件引导（PCG），一种奖励驱动的自适应蒸馏调度，计算教师和学生的性能分数以动态平衡引导和探索。PCG在具有挑战性的视觉环境中既防止过早的教师退火，也防止过度的教师干扰。在OMOMO和BEHAVE上的实验表明，相比强视觉基线，跟踪式操作性能有所提升，同时在部署时不向学生暴露在线特权交互状态。定性仿真进一步检验了形态和模拟器的变化。这些结果表明，世界模型可以为稳定接触丰富的仿人行为中的视觉策略蒸馏提供一种有效机制。

## Abstract
Vision-based whole-body loco-manipulation on humanoid robots is challenging due to partial observability, contact-rich dynamics, and the difficulty of learning long-horizon behaviors from high-dimensional visual inputs. We present \href{https://github.com/DreamMimic/DreamMimic}{DreamMimic}, a framework that distills privileged teacher policies into vision-based humanoid controllers via world-model-assisted distillation. Instead of using a Dreamer-style RSSM for planning, we repurpose it to learn predictive latent dynamics that serve as both a representation space and an action-conditioned multi-step supervision signal, while exposing compact predictive features to the student policy to reduce long-term drift. Beyond standard reconstruction objectives for proprioceptive and visual observations, we add auxiliary prediction heads for privileged state, contact, object state, and reward estimation. These heads provide additional supervision related to agent--object interaction and task progress, encouraging the latent representation to retain signals that are useful for contact-rich loco-manipulation. We further introduce Performance-Conditioned Guidance (PCG), a reward-driven adaptive distillation schedule that computes performance scores for both teacher and student to dynamically balance guidance and exploration. PCG prevents both premature teacher annealing and excessive teacher interference in challenging visual settings. Experiments on OMOMO and BEHAVE show improved tracking-based loco-manipulation performance over strong vision-based baselines, without exposing online privileged interaction states to the student at deployment. Qualitative simulations further examine morphology and simulator changes. These results suggest that world models can provide a useful mechanism for stabilizing visual policy distillation in contact-rich humanoid behaviors.

## 2. 论文提出的方法论：核心思想、关键技术细节与流程

### 2.1 核心思想
- **世界模型的重新定位**：不同于Dreamer系列将RSSM用于规划或直接策略优化，DreamMimic 将 Dreamer 风格 RSSM 重新用于**预测性表征学习与多步监督**，作为稳定教师-学生蒸馏的机制，而非规划工具。
- **整体流程**：多个特权专家教师（multiple specialist teachers）被整合为一个统一特权教师 → 通过 **Performance-Conditioned Guidance (PCG)** 自适应引导学生策略学习 → 学生策略使用非特权本体感觉、紧凑目标条件、以及从世界模型推断的预测特征。

### 2.2 教师策略（Privileged Teacher Policy）
- 教师拥有完整仿真器状态（真实物体位姿、交互图、物体接触信号），通过强化学习进行参考运动跟踪。
- 奖励包含全身跟踪、末端执行器对齐、物体一致性和接触感知项，用 InterMimic 的"专家到通才"策略构建多个特权教师。

### 2.3 视觉学生策略蒸馏（Visuomotor Student Distillation）
- **策略条件**：$c_t = [p_t, g_t, \phi^{wm}_t]$，其中：
  - $p_t$：非特权本体感觉观测
  - $g_t$：紧凑目标条件（目标物体位姿 + 短时机器人轨迹线索，如根节点和关键部位目标）
  - $\phi^{wm}_t$：世界模型特征，包含确定性RSSM状态 $h_t$、奖励预测 $\hat r_t$、特权状态预测 $\hat x^{priv}_t$、接触预测 $\hat c^{contact}_t$ 和物体状态预测 $\hat x^{obj}_t$
- 使用轻量 Transformer 将这些特征作为独立 token 进行融合，接入 actor-critic MLP。
- 采用 DAgger + PPO 正则化：监督动作模仿是主要学习信号，PPO 作为辅助稳定器。

### 2.4 性能条件引导（Performance-Conditioned Guidance, PCG）
- 动态分配环境为教师驱动或学生驱动，根据**奖励反馈计算相对性能分数** $\pi = \hat r_S / (\hat r_T + \epsilon)$。
- 当学生性能接近目标比例时，将教师环境占比 $\rho$ 从 $\rho_{max}$ 衰减到 $\rho_{min}$，使用 EMA 平滑更新；**模仿系数固定不变**。
- 相比迭代式教师退火（iterative teacher annealing），PCG 能防止过早退火导致的分布外状态暴露，也能避免教师过度干预。

### 2.5 参考缓冲课程（Reference-Buffer Curriculum）
- 训练中，失败的学生驱动 rollout 用于更新困难时间窗口附近的小型参考状态集合，使未来 rollout 可以重新访问困难交互状态。
- 教师驱动环境不参与此更新，以确保课程反映学生自身状态分布。

### 2.6 世界模型（World Model for Predictive Representation）
- 基于 RSSM（Recurrent State-Space Model）架构，包含：
  - **编码器 $E_\xi$**：视觉输入用轻量卷积编码器、本体感觉用 MLP，输出嵌入 $e_t$
  - **确定性转移 $f_\xi$**（GRU）：$h_t = f_\xi(h_{t-1}, s_{t-1}, a_{t-1})$
  - **后验 $q_\xi$**：$s_t \sim q_\xi(s_t | h_t, e_t)$
  - **先验 $p_\xi$**：用于无观测情况下的开环预测
- **辅助预测头**：
  - 重建头（RecH）：重建视觉（深度+分割）和本体感觉观测
  - 奖励预测头
  - 特权状态预测头（13维物体状态 + 全身交互图 + 目标接触标签）
  - 接触预测头
  - 目标物体状态预测头
- 这些预测头提供与智能体-物体交互和任务进展相关的额外监督，鼓励潜在表征保留接触丰富操作所需的信号。

### 2.7 多步潜在蒸馏（Multi-step Latent Distillation）
- 从同一后验潜在状态 $z_t$ 出发，分支两路通过 RSSM 先验进行 $H=3$ 步的想象 rollout：
  - 一路以**学生策略平均动作** $\mu^{(S)}$ 为条件
  - 一路以**教师策略平均动作** $\mu^{(T)}$ 为条件
- 通过损失函数最小化两路潜在状态之间的确定性部分和随机部分差异：
$$L_{latent} = \sum_{k=1}^{H} \left[ \|h^{(S)}_{t+k} - h^{(T)}_{t+k}\|_2^2 + \lambda_{stoch} \|s^{(S)}_{t+k} - s^{(T)}_{t+k}\|_2^2 \right]$$

### 2.8 总体训练目标
- **世界模型损失**：$L_{wm} = L_{KL} + L_{rec} + L_{rew} + L_{priv} + L_{con} + L_{obj}$（包括 KL 正则、重建、奖励/特权/接触/物体状态预测）
- **学生策略损失**：$L_{total} = c \cdot w_{action} L_{action} + w_{wm} L_{latent} + w_{ppo} L_{ppo}$
  - $L_{action}$：动作模仿损失，将学生策略均值与教师策略均值进行匹配
  - $L_{latent}$：多步潜在监督
  - $L_{ppo}$：PPO 正则化
- 世界模型与学生策略分别优化，避免联合目标中的漂移问题。

## 6. 论文的主要结论与发现

- **DreamMimic 显著优于直接视觉 RL 基线**：在 OMOMO 上达到 92.2% 成功率，远超 ResNet-18+RL（0%）和 Dreamer 单阶段（0%）。
- **多步潜在监督对接触丰富任务至关重要**：去除该损失后成功率从 92.2% 降至 70.6%，验证了动作条件潜在一致性在缓解长期漂移中的关键作用。
- **辅助预测头增强交互相关表征**：物体状态预测和特权状态预测均有助于降低物体跟踪误差。
- **预测特征进入策略输入（而非仅作为损失）是必要的**：仅在损失中使用辅助头而不输入策略时，成功率明显下降。
- **确定性循环状态是核心**：用当前步随机特征替代循环确定性状态导致成功率大幅下降（74.5%）。
- **PCG 优于朴素退火**：在 BEHAVE 上 PCG 达到与调参后的朴素退火相同的成功率，但在跟踪误差和持续时长上更优，且减少了对人工调参的依赖。
- **世界模型可有效稳定视觉策略蒸馏**：整体结果表明，世界模型在接触丰富的人形行为中，可以作为视觉策略蒸馏的稳定机制。

## 7. 主要优点

- **创新性的世界模型定位**：不将世界模型用于规划，而是作为表征学习和多步监督工具，这为视觉策略蒸馏提供了新的思路。
- **全面的辅助监督设计**：通过奖励、特权状态、接触、物体状态等多个辅助预测头，鼓励潜在表征保留交互相关信号，增强了表征的语义丰富性。

- **多步潜在蒸馏机制的有效性**：通过动作条件下的潜在一致性，约束学生与教师产生的未来状态轨迹一致，显著缓解部分可观测下的复合误差。

- **严重遮挡下的失败**：作者承认在严重遮挡或视觉模糊接触场景下，策略仍可能出现错误，即便有多步监督。
- **手部接触精度不足**：在 G1 实验中，上肢手部接触缺乏足够精度，对于需要大力操作的任务（如举升）策略倾向于推而非提，说明重定向可能丢失细粒度手-物交互动态。
- **跨形态/跨模拟器仅为定性验证**：限于仿真中的定性观察，缺乏定量指标支撑，不能视为强泛化性证据。
- **实验覆盖仍属特定任务范畴**：仅评估了跟踪式（tracking-based）操作性能，对于更广泛的操作任务（如灵巧操作、工具使用等）未作探索。
- **潜在偏差风险**：世界模型的训练依赖于渲染观测质量，在感知分布偏移时可能性能退化；PCG 的奖励信号设计本身对最终蒸馏效果有一定敏感性。

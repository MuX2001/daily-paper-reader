## 摘要
在不确定环境中确保可靠性对于长期机器人操控仍然困难。端到端VLA模型数据需求大且不透明，使得诊断和验证困难。分层流程更具可解释性，但其计划往往在观测中基础薄弱，与低级动作对齐不佳，并且在没有在线反馈的情况下计算，导致开环行为和幻觉。为了解决这些问题，我们引入了Triplet-to-Track系统（TTS），这是一个闭环的长期模仿学习系统，利用人类视频来减少对机器人收集数据的依赖。TTS将高级子目标表示为基于实例的三元组，将其转换为连续轨迹先验用于执行，并从观测中监控任务进度以进行在线重新规划。在多样化的真实世界长期任务中，TTS实现了74.8%的平均成功率，并支持对象级和组合泛化。

## Abstract
Ensuring reliability in uncertain environments remains difficult for long-horizon robotic manipulation. End-to-end VLA models are data-heavy and opaque, making diagnosis and verification difficult. Hierarchical pipelines are more interpretable, but their plans are often weakly grounded in observations, weakly aligned with low-level actions, and computed without online feedback, leading to open-loop behavior and hallucinations. To address these issues, we introduce the Triplet-to-Track System (TTS), a closed-loop long-horizon imitation learning system that uses human videos to reduce reliance on robot-collected data. TTS represents high-level subgoals as instance-grounded triplets, translates them into continuous track priors for execution, and monitors task progress from observations for online replanning. Across diverse real-world long-horizon tasks, TTS achieves a 74.8\% average success rate and supports object-level and compositional generalization.

  - **分层管线**（如 SeeDo、PALO）：虽可结合人类视频与预训练大模型以减少机器人数据需求，但存在 **计划缺乏实例级接地**（自由形式语言目标无结构约束，易幻觉）、**规划与低层控制接口不匹配**、以及**缺乏在线闭环反馈**（开环执行，无法自动检测和恢复错误）。

### 核心贡献
论文提出 **Triplet-to-Track System (TTS)**，一个**闭环**长期模仿学习系统：
- 使用 **离散三元组 (triplets)** 进行高层规划，绑定具体对象实例与空间关系，可在观测中被直接验证；
- 使用 **连续点轨迹 (tracks)** 作为低层控制接口，将离散子目标转化为可执行的物理运动先验；
- 借助人类视频预训练轨迹预测器，**显著降低对机器人动作标注数据的依赖**。

## 二、方法论

### 总体架构（三层结构）

TTS 由三个核心模块组成，形成 "规划→轨迹→动作" 的闭环链路：

```
Task Planner（离散三元组规划）
    ↓ 子目标三元组 c_k → c_{k+1}
Track Predictor（连续轨迹预测）
    ↓ 轨迹先验 τ_k
Action Policy（低层动作策略）
    ↓ 执行动作 a_t
环境反馈（观测）→ 关系验证 → 在线重规划（闭环）
```

### 1. Task Planner（任务规划器）

**核心思想**：将高层规划转化为"实例接地的、可在观测中直接验证的"三元组 (x, r, y) 转移。

- **Relation Predictor（关系预测器）**——采用**两级级联**设计：
  - **LTP（轻量Transformer预测器）**：以 SAM2 解码器的逐实例 token 作为输入，预测每个有序对象对的关系统计，以**高频率**逐帧监测，仅当检测到关系变化候选时触发验证；
  - **LoRA 微调的 VLM 验证器**（InternVL2.5）：仅在 LTP 发出"疑似变化"信号时被调用，进行**高精度验证**，并将标签空间限制为掩码关系集（给定实例掩码），而非自由文本生成。
  - 这一设计的动机来自对关系预测误差的分析：瞬态虚假翻转（FP）在变化率低（ρ≈0.02）时占据主导，级联结构兼顾了高召回率与高精度。

- **Graph-Guarded Next Triplet Generator（图约束子目标生成器）**：
  - 从人类视频中**自动构建时序有向图** G = (V, E)，节点为三元组，边为观测到的可行转移；
  - 零样本 VLM 仅在当前节点的出边邻域（通过邻接矩阵掩码 M_k 约束）内进行候选评分，**从根本上排除未见过的、不可行的转移**，抑制规划幻觉；
  - 闭环守卫机制：执行时通过 Relation Predictor 验证守卫集（guard set），若所有守卫成立则继续下一步；若违反，则重新定位到初始节点 c₀ 并重规划。

### 2. Track Predictor（轨迹预测器）

- **数据准备**：利用 Grounding-DINO + SAM2 获取实例掩码，CoTracker 生成实体对齐轨迹，关系变化 r→r′ 编码为文本 token，构成训练样本 Dₓᵧ。
- **条件化多模态掩码轨迹预测**（受 ATM 启发）：
  - 输入：视觉观测、当前点位置、实例掩码 Mₓ、Mᵧ、关系变化嵌入 e(r → r′)；
  - 将三元组转移先验（掩码+关系变化嵌入）作为强归纳偏置，预测未来连续轨迹；
  - 引入两个辅助目标：**掩码补丁重建**（增强视觉特征鲁棒性）和**关系变化识别**（预测 δr，增强对关系建模能力）。
- 预训练在**无动作标注的人类视频**上进行，支持跨具身迁移。

### 3. Action Policy（动作策略）

- 以 Transformer 骨干 + MLP 动作头构成，输入为观测特征、三元组转移先验、以及 Track Predictor 生成的**短时域轨迹先验**；
- 通过一个可学习的动作 token 融合信息，使用 L2 回归损失预测 7 维末端位姿 + 1 维夹爪宽度；
- 推理采用**滚动时域 (receding-horizon) 方案**：每 5 步通过雷达预测器检查子目标是否完成，完成后立即规划下一子目标；发生守卫违规时触发重规划，实现真正的闭环执行。

## 三、实验设计

### 评价场景

| 任务族 | 全称 | 核心考验 | 子目标数量 |
|--------|------|----------|------------|
| DSB | 动态天平平衡 (Dynamic Scale Balancing) | 闭环推理、依托演化物理状态在线重规划 | 最多12步 |
| SS | 顺序堆叠 (Sequential Stacking) | 指定多步顺序下的刚体约束执行与泛化 | 最多11步 |

### 数据规模与划分
- 每个任务：**30 条机器人演示 + 50 条人类演示**（人类演示仅5条轨迹标注）；
- 人类演示包含泛化所需的物体变化与执行顺序；机器人演示不含；
- Seen 与 Unseen 划分：Unseen 进一步细分为**组合泛化**（SS 新顺序）与**跨类别泛化**（DPP 替换物体，如苦瓜→玉米/红番茄）。

### 对比基线
- **FT-Pi0.5**：端到端 VLA 微调模型，检验低数据条件下的直接动作生成；
- **SeeDo**：VLM 生成 QA 式文本计划、code-as-policy 执行的分层基线；
- **PALO**：VLM 递归语义分解为可执行原子动作的分层基线。
- 公平性控制：TTS 的 Relation Predictor 仅用于任务完成检测与守卫违规，不额外为基线提供空间关系监督。

## 六、主要结论与发现

1. **TTS 在所有设置中显著优于基线**：平均成功率 74.8%，最佳基线 SeeDo 为 30.4%（提升约 2.5 倍）；
2. **结构化实例接地子目标有效抑制规划幻觉**：自由形式/弱接地的语义规划（SeeDo/PALO）在 DPP 中主要因空间幻觉（选错物体）失败，在 SS 中因逻辑排序错乱和漂移失败，而三元组表示从机制上排除不可行转移；
3. **闭环监测与在线重规划保证扰动鲁棒性**：在 DSB 增删砝码、DPP 抓取后移除目标等扰动下，TTS 仍保持较高成功率（60%–80%），基线几乎全部失败（0%）；
4. **轨迹先验弥合了"离散子目标↔连续控制"的鸿沟**：去掉 Track Predictor 后，三任务性能显著下降（DPP 45.5%，SS 46.1%，DSB 43.8%）；
5. **层次结构缺一不可**：仅动作策略（BC）完全失败（0%），无 Task Planner 时任务退化为短视行为（7.1%/0%/0%）；
6. **人类视频 + 轨迹预训练大幅降低机器人数据需求**：仅需 30 条机器人演示即可达到较好性能，数据效率优势明显。

## 七、方法优点

1. **结构化、可验证的规划表示**：以实例接地三元组作为子目标，突破自由语言规划的幻觉瓶颈，每个子目标都可在观测中被直接检查和验证；
2. **规划-控制接口显式化**：通过连续点轨迹将离散子目标与低层连续控制连接，提供清晰的物理先验跨具身迁移能力；接口不仅可执行，还可可视化和追踪决策过程；
3. **闭环机制完整且轻量**：事件触发式 VLM 验证 + 图掩码约束 + 守卫集重规划，构成高效可靠的闭环推理链路，避免了逐帧调用大模型的成本；
4. **数据效率策略合理**：动作无关的人类视频用于预训练轨迹预测器，机器人动作标签只需少量，有效降低了数据采集成本；
5. **可解释性**：三元组计划和点轨迹均可直接可视化，失败时可精确定位到规划或控制的具体环节。

## 八、不足与局限

1. **应用范围受限**：当前三元组空间仅覆盖**空间关系和夹爪-物体关系**，无法表达**形变物体**（如布料、绳索）等非三元组任务；任务的有效性依赖图结构中预先存在的转移路径，**图外新场景无法处理**；
2. **感知误差累积**：系统整体依赖 Grounding-DINO 检测 + SAM2 分割，当检测或分割失败（遮挡、相似外观）时，下游关系预测和轨迹生成的质量无明确保障机制；
3. **对预训练模型依赖性强**：LTP 需要每任务 5 条序列的标注，VLM 分支需 LoRA 微调，GPT-4o 作为零样本规划器的输出质量和延迟构成不确定性因素；
4. **实验数据规模有限**：仅 3 个任务族、每个任务 30 条机器人演示，广泛泛化结论的证据强度有限；成功率标准差未见完整报告；
5. **未披露细节**：关系变化标注的具体工作量、VLM 微调数据的具体格式和规模、推理延迟的完整分布、以及训练收敛所需 step 数等细节未充分展开；
6. **方法复杂度较高**：系统包含检测、分割、关系预测、VLM 验证、图生成、轨迹预测、策略学习等多个串联组件，实际部署中任一环节的失败都可能成为瓶颈，且系统性诊断成本偏高。

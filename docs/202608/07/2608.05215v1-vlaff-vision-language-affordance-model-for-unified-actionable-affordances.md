## 摘要
从人类视频中学习操作技能对于可扩展的机器人学习具有前景。然而，人类与机器人之间的具身差异使这一任务具有挑战性。一种有前景的解决方案是学习与具身无关的、以对象为中心的可操作可供性。在本工作中，我们提出一个框架，利用自我中心人类视频，结合最先进的3D运动恢复结构和手部网格重建，提取可操作可供性，如视觉、抓取和轨迹可供性，这些可供性明确编码了在哪里交互、如何抓取以及如何移动。我们构建了EgoAffordance，一个大规模数据集，包含204K个片段，5.6M个视觉可供性和11.6M个抓取与轨迹可供性。在此基础上，我们引入VLAff，一个基于大型视觉-语言模型的统一基础模型，学习所有可操作可供性之间的跨模态关联。给定视觉观察和指令，VLAff生成视觉可供性热图、抓取姿态和轨迹，然后利用3D场景信息将其转换为可直接执行的动作。通过大量实验，我们证明VLAff不仅在视觉可供性预测上达到最先进性能，还能有效应用于真实机器人应用，如零样本操作和可供性引导的机器人学习。

## Abstract
Learning manipulation skills from human videos is promising for scalable robot learning. However, the embodiment mismatch between humans and robots makes this challenging. One promising solution is to learn object-centric actionable affordances that are embodiment-agnostic. In this work, we propose a framework that leverages egocentric human videos with state-of-the-art 3D Structure-from-Motion and hand mesh reconstruction to extract actionable affordances such as visual, grasp, and trajectory affordances that explicitly encode where to interact, how to grasp, and how to move. We construct EgoAffordance, a large-scale dataset comprising 204K episodes with 5.6M visual affordances and 11.6M grasp and trajectory affordances. Building on this, we introduce VLAff, a large vision-language model-based unified foundation model that learns cross-modal correlations across all actionable affordances. Given a visual observation and instruction, VLAff generates visual affordance heatmaps, grasp poses, and trajectories, which are then converted into directly executable actions by utilizing 3D scene information. Through extensive experiments, we demonstrate that VLAff not only achieves state-of-the-art performance on visual affordance prediction, but can also be effectively applied to real robot applications such as zero-shot manipulation and affordance-guided robot learning.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **核心问题**：如何从大规模人类视频中高效学习机器人操作技能，并克服人类与机器人之间的**具身差异（embodiment gap）**。
- **背景动机**：
  - 传统模仿学习需要采集机器人动作-状态数据集，成本高、耗时长，且任务与环境域常局限于实验室。
  - 人类视频数据规模大、易获取、覆盖多样环境，但存在两个障碍：① 人类与机器人的身体结构不同，直接迁移困难；② 视频本身缺乏显式的动作-状态标签。
  - 已有从人类视频中学习隐式表征的方法难以解释且难以转化为机器人动作；已有基于 affordance 的方法往往只关注单一模态（如仅热图、仅抓取或仅轨迹），缺乏统一框架。
- **整体含义**：论文提出以**与具身无关（embodiment-agnostic）的、以对象为中心的可操作可供性（actionable affordances）**作为人类视频与机器人控制之间的桥梁，将"在哪里交互（视觉）、如何抓取（抓取姿态）、如何移动（轨迹）"统一建模，具有较高的学术意义和应用价值。

## 2. 论文提出的方法论

- **核心思想**：提出 VLAff（Vision-Language-Affordance model），一个基于大型视觉-语言模型（VLM）的统一基础模型，联合预测**视觉可供性热图（Visual Affordance）**、**抓取姿态（Grasp Affordance）**和**轨迹可供性（Trajectory Affordance）**，实现从语言指令和视觉观察到完整操作策略的映射。

- **EgoAffordance 数据集构建流程（数据侧）**：
  1. **数据准备**：利用已有第一视角（egocentric）视频数据集的语言描述与时间标注，采样交互时间戳附近的帧，通过大 VLM 提取关键交互帧、动作标签、物体类别和交互手信息。
  2. **手-物交互提取**：使用手-物检测器、分割模型（SAM 2）和 2D 手部关键点模型，识别接触区域与交互手；使用 MANO 参数化手部模型重建 3D 手部姿态；通过自我分割与修复（inpainting）去除自我视角的手部视觉偏差。
  3. **自我中心 SfM（3D 重建）**：对修复后的帧进行单目深度估计、相机内参/外参估计，利用 DROID-SLAM 估计相机姿态，过滤动态区域后跟踪 3D 手部轨迹，获得操作前后（pre-/post-contact）的运动模式。

- **VLAff 模型架构与关键技术细节**：
  - 基础模型：以 **Qwen2.5-VL** 为骨干 VLM，额外引入 **DINOv2** 作为视觉编码器以增强细粒度空间理解。
  - **三种特殊 token 机制**：
    - `<SEG>` token：通过 LISA 式的分割解码器生成像素级视觉可供性热图。
    - `<GRASP>` token：解码为 96 维 MANO 手部参数（腕部旋转 + 15 个关节旋转，采用 6D 旋转表示）。
    - `<p0>...<pN-1>` 轨迹 token：采用空间分箱将 6D 位姿空间离散化，以自回归方式生成轨迹 token 序列。
  - **训练损失**：
    - 视觉可供性：Soft Dice Loss。
    - 抓取姿态：Smooth L1 Loss。
    - 轨迹生成：交叉熵损失。
    - 总损失为三者加权和。

- **轨迹推理策略（推理侧）**：
  - **In-Context Trajectory Guidance**：利用 GPT 等外部高能力 VLM 输出相机坐标系下的 3D 方向向量（每个分量为 -1/0/1），用于引导首个轨迹 token 的采样分布，使生成的轨迹符合高层任务意图。
  - **Sampling-Based Trajectory Selection**：通过 nucleus sampling 采样 K 个候选轨迹，结合体素化的 3D 碰撞检测和方向对齐目标函数，选取最优轨迹。

- **视觉可供性预测**：VLAff 在 IoU（0.121）、NSS（1.542）、SIM（0.142）、KLD（2.517）上全面超越现有方法，达到 SOTA。联合学习三类可供性可提升视觉可供性的定位质量。

- **总体结论**：统一的、跨模态的 affordance 学习方法能够有效弥合人类视频与机器人操作之间的鸿沟，在真实世界中具有较好的实用价值。

## 7. 优点

- **统一建模创新性**：首次将视觉、抓取、轨迹三类 affordance 整合进单一的多模态 LLM 框架，而非孤立处理，能利用跨模态相关性增强各模态预测。
- **大规模数据贡献**：构建的 EgoAffordance 数据集（204K 片段、5.6M 视觉热图、11.6M 抓取/轨迹）是目前较全面的可操作 affordance 数据集，对领域有较大价值（见表 I 对比）。
- **以对象为中心的表示**：将抓取姿态和轨迹转化为相对 3D 交互锚点的对象中心坐标，增强了跨具身迁移能力。
- **推理阶段的物理约束引导**：通过 VLM 方向引导 + 采样 + 碰撞检查，尝试解决从单张图像预测 3D 轨迹的物理合理性问题。
- **真实机器人验证**：同时进行了仿真和真实环境（两种机器人平台）的实验，证明方法的实际可行性。
- **消融设计有意义**：对三类 affordance 的贡献度进行了解耦分析，揭示了视觉和轨迹相对于抓取更重要的洞见。

## 8. 不足与局限

- **轨迹物理合理性**：论文承认偶尔会生成不符合物理约束（如穿模）的不合理轨迹，尚未将 3D 场景感知结构直接引入模型架构，未来需通过 3D 场景感知模块解决。
- **实验覆盖有限**：真实世界实验只在 5 个厨房任务上评估；消融只在 Open Fridge 单任务上执行，缺少跨任务、跨场景的消融验证。
- **基线比较的公平性隐患**：基线方法统一使用 GraspNet 输出机械爪位姿，而 VLAff 通过 MANO 手部姿态重定向到夹爪；这种不一致的比较方式可能对结果产生影响，论文未讨论重定向策略的失败率或对不同方法的影响差异。
- **训练数据存在偏差风险**：EgoAffordance 来源于特定的自我中心视频数据集（Ego4D、EPIC-KITCHENS 等），人类操作习惯、物体类别分布、场景类型（主要为厨房/日常室内）可能导致模型在其他领域（如工业、户外）泛化能力受限。

- **研究细节缺失**：未报告模型参数量、训练资源、推理速度等关键工程指标，影响实际应用的可复现性评估。

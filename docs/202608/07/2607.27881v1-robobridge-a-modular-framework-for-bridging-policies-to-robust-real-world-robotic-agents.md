## 摘要
视觉-语言-动作（VLA）模型作为机器人操作的一种可扩展方法引起了越来越多的关注。虽然这些模型是有效的动作预测器，但将它们部署为机器人智能体会暴露出关键差距：缺乏故障恢复机制、长时程执行不一致，以及对观测、任务或本体变化鲁棒性有限。现有解决方案通过模型重训练或环境特定模块分别解决这些局限性，但需要的是一个通用框架，能够系统地将预训练的VLA转化为机器人智能体。我们提出了RoboBRIDGE，一个模块化框架，在五个协调模块之上提供编排层，即监控器、感知器、规划器、控制器和机器人接口，从现成组件（包括预训练的VLA）组合出稳健的机器人智能体。监控器将快速故障检测与分层恢复配对，在错误级联之前进行纠正。当环境偏离当前计划时，规划器触发重新规划，同时感知器异步更新场景理解，避免执行停滞。在控制器内部，原始技能微调将操作分解为具有专用LoRA适配器的领域不变原始技能，减少使用VLA时对领域偏移的敏感性。在跨多个机器人平台和VLA主干的LIBERO、RoboCasa以及真实世界案例研究中，RoboBRIDGE始终优于独立策略和先前增强的VLA部署。这些结果表明，可靠的机器人智能体并非仅通过扩展动作预测器来实现，而是通过围绕它们的结构化编排来实现。

## Abstract
Vision-Language-Action (VLA) models have attracted growing interest as a scalable approach to robotic manipulation. While these models are effective action predictors, deploying them as robotic agents exposes critical gaps: no mechanism for failure recovery, inconsistent execution over long horizons, and limited robustness to shifts in observations, tasks, or embodiments. Existing solutions address these limitations individually through model retraining or environment-specific modules, yet what is needed is a general framework that systematically transforms a pretrained VLA into a robotic agent. We present RoboBRIDGE, a modular framework that provides an orchestration layer over five coordinated modules, namely Monitor, Perceptor, Planner, Controller, and Robot Interface, to compose robust robotic agents from off-the-shelf components, including pretrained VLAs. The Monitor pairs rapid failure detection with hierarchical recovery to correct errors before they cascade. When the environment diverges from the current plan, the Planner triggers replanning while the Perceptor updates scene understanding asynchronously, avoiding execution stalls. Within the Controller, primitive skill fine-tuning factors manipulation into domain-invariant primitives with dedicated LoRA adapters, reducing sensitivity to domain shifts when a VLA is used. Across LIBERO, RoboCasa, and real-world case studies spanning multiple robot platforms and VLA backbones, RoboBRIDGE consistently outperforms both standalone policies and prior augmented VLA deployments. These results suggest that reliable robotic agency does not arise from scaling action predictors alone, but from structured orchestration around them.

## 1. 论文的核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型（如 SmolVLA、π0.5、GR00T-N1.5）已成为机器人操作领域的重要方法，能够将多模态观测与语言指令直接映射到低层动作。它们在动作预测上表现出色，但**作为机器人智能体存在天然缺陷**：
  - **无故障恢复机制**：一次抓取失败或碰撞会被忽略并持续级联，导致后续步骤全部失败；
  - **长时程一致性差**：推理步骤互相独立，缺乏任务进度跟踪，复合错误不断累积；
  - **域偏移鲁棒性差**：对观测变化、任务变化和本体变化（不同机器人）极度敏感。
- **研究动机**：现有工作仅针对上述单个缺陷进行修复（如失败检测、重规划、域适应等），彼此孤立，且常常依赖重训练或特定环境模块。作者类比 LLM 领域的发展——原始 LLM 也是依赖外部编排框架（工具调用、规划、验证）才成为通用智能体——主张 VLA 面临同样的瓶颈：**缺少的并非更强的策略，而是能将任意策略提升为机器人智能体的通用编排框架**。

## 2. 方法论

- **核心思想**：提出 RoboBRIDGE，一个**策略无关（policy-agnostic）的模块化编排框架**，将任意动作生成策略包装为鲁棒机器人智能体，无需重训基座模型、无需改动模型架构。

- **五大协调模块**：
  - **Monitor（监控器）**：闭环执行，验证结果并触发分层恢复；
  - **Perceptor（感知器）**：将原始感知转化为以对象为中心的 3D 位姿、属性等场景状态；
  - **Planner（规划器）**：根据语言指令和感知状态将任务分解为有序原始技能序列；
  - **Controller（控制器）**：可插拔槽位，可容纳任意动作生成策略（VLA 或经典 IK）;
  - **Robot Interface（机器人接口）**：抽象机器人特定 API、安全限制、坐标变换，令上游逻辑跨机器人/模拟器复用。

- **两大核心机制**：
  - **两阶段监控与分层恢复**（Two-phase Monitoring）：
    - **阶段一（轻量成功检查）**：轻量模型 `D_check` 持续以受限输出格式评估 `(o_t, c_t)` 产出二元成功标志和置信度，仅 5Hz 频率、不阻塞控制回路；
    - **阶段二（失败诊断与恢复）**：当检测到高置信失败（`suc_t=false 且 con_t ≥ γ`）时，立即停止机器人，调用诊断模型 `D_diag` 推断恢复目标 `r_t`，对应四级分层恢复策略：**retry**（重试当前原语）→ **regenerate**（保留计划和感知，重生成轨迹）→ **replan**（基于最新感知重新规划）→ **re-perceive**（强制全量重新感知再规划）。层级按重计算范围从小到大排列，避免不必要的重算。
  - **异步感知与发散触发的重规划**（Reactive Planning with Asynchronous Perception）：
    - 采用**生产者-消费者架构**：感知线程持续将最新检测结果 `ō_lat` 写入线程安全缓冲区 B，只保留最新帧；
    - 每条原语完成后，计算当前规划所用感知 `ō_plan` 与最新感知 `ō_lat` 的发散度：Δ = max(‖p_a^{(i)} − p_b^{(i)}‖₂) + λ·|O_a △ O_b|；
    - 仅当 Δ ≥ τ 时触发重规划：**保留高层动作序列**（如 PICK→PLACE），仅重新生成当前及后续原语的空间参数，避免多余的高层推理。

- **原始技能微调**（Primitive Skill Fine-tuning，VLA 作为 Controller 时）：
  - 将操作分解为域不变原语集合 P = {MOVE, GRIP, ROTATE, ...}，每个原语对应一个**专用 LoRA 适配器** `Δθ_k`，冻结 VLA 主干 f_θ 进行参数高效微调；
  - **控制器切换**：执行时通过 RESOLVE 解析器选择对应适配器；不存在时回退到所有适配器的均值；
  - 动作预测输出 7-DoF delta（平移、旋转、夹爪），通过笛卡尔速度命令或 IK 求解器两条路径执行，兼容不同运动学接口。

- **算法流程**（Algorithm 1）可概括为：初始化感知 → 规划 → 启动异步感知线程 → 逐原语执行（含监控检查、失败恢复）→ 原语间检查场景发散并触发重规划。

## 6. 主要结论与发现

- **核心验证结论**：RoboBRIDGE 在 LIBERO 上平均成功率从 35.5% 提升至 39.7%；在 RoboCasa 上所有主干均获得一致的提升（3.4%→6.9%、3.4%→5.9%、4.2%→9.8%；排除 PnP 任务后提升更明显）。
- **监控比规划更能拉开差距**：无监控时所有 LLM 骨干仅落在 1.8–8.0% 的窄区间；启用监控后 Claude Opus 4.6 达到 14.7%（+8.1%），小模型提升微弱。**规划与监控缺一不可，且二者协同效果随骨干推理能力增强而放大**。
- **框架优于模型内嵌机制**：CycleVLA（模型内自校正）平均仅 7.5%，远低于 RoboBRIDGE 编排除错（如 LoRA FT + RB 达 27.1%，接近全量微调独立部署的 31.9%）；全量微调 + RB 达 40.0%，经典 IK 控制器 + RB 也达 22.1%——验证了框架对控制器形态的普适性。
- **宏观结论**：可靠的机器人智能体能力**并非来自单纯扩大动作预测模型**，而是来自**围绕预测器的结构化编排**（监控、恢复、重规划、域适应机制）。

## 7. 优点

- **模块化与通用性**：明确将任意策略置于可插拔 Controller 槽位，周围模块标准化补充缺失能力；经典 IK 和 VLA 均可接入，策略无关性优于大多数专一修复方案。
- **针对性机制清晰**：两阶段监控解决了"每次全诊断太重、无监控会级联"的权衡；异步感知 + 发散触发重规划解耦了感知延迟和执行停顿；LoRA 原语适配器避免了全量微调的开销和灾难性遗忘。
- **与 LLM 智能体发展类比有说服力**：将 RoboBRIDGE 类比 LangChain/AutoGen 对 LLM 的编排，视角新颖且具有启发意义。
- **实验覆盖面较好**：仿真 + 真实世界、多种 VLA 主干、多种控制器配置、LLM 骨干消融、失败模式分析，多维度验证框架有效性。
- **结果公平性较好**：对 VLA 主干进行了固定控制器条件的受控对比；明确分析了两类主要失败模式（感知错误、不可恢复操作失败）并给出未来方向。

## 8. 不足与局限

- **实验局限**：
  - **绝对成功率仍偏低**：RoboCasa 中很多高难度任务（如 PnP 系列）仍为 0%，说明框架对某些任务的提升非常有限；
  - **LIBERO 提升有时微小甚至退化**：如 LIBERO-Spatial 上某些任务（Task02、Task06、Task07）w/RB 反而降低，说明监控/重规划并非在所有场景下都能带来正收益；
  - **真实世界实验只以图示意案例展示**，未给出统计性成功率数据和误差范围；
  - **未报告方差或多次运行的标准差**，无法判断结果显著性。
- **资源与算力未披露**：未报告 GPU 类型、数量、训练总时长、总体能耗，降低可复现性和资源可评估性。
- **方法局限**：
  - 原语词汇表仅覆盖**单臂/桌面级别的行为**，对接触丰富交互（contact-rich）、可变形物体、双臂操作需要更丰富的原语和状态表示；
  - **监控阈值和恢复规则依赖人工设定**，未实现从交互数据中自适应学习；

  - 感知错误在遮挡和相似物体场景中仍然频发，是主要失败来源。

## 摘要
视觉-语言-动作（VLA）模型为连接视觉感知、语言理解和机器人控制提供了统一范式。然而，现有VLA模型在长时程任务中仍面临重大挑战：稀疏的专家演示限制了跨任务的组合泛化能力；长时程任务的非马尔可夫性质使得仅以当前观测为条件的策略难以维持时间一致性；有限的闭环纠错能力导致执行误差累积；端到端的动作微调可能削弱视觉-语言模型（VLM）骨干网络的高层语义表示。为解决这些问题，我们提出了一种带有显式语言记忆模块的层次化长时程VLA架构。其核心思想是将离散的时间观测转换为具有时间逻辑的连贯文本记忆序列。系统被解耦为高层VLM和低层VLA：高层VLM通过视觉问答训练范式执行语义推理，而低层VLA则以子任务指令和视觉观测为条件执行精确的连续控制。高层VLM利用先前记忆作为上下文锚点，递归更新语言记忆和子任务指令，从而在长时程执行过程中实现持续的时间跟踪和动态纠正。我们在多个仿真环境中评估了所提方法，并在真实机器人平台上进行了仿真到现实迁移实验。结果表明，显式语言记忆提升了VLA模型在复杂长时程任务上的成功率和鲁棒性，同时为决策过程提供了可解释的语义说明。

## Abstract
Vision-language-action (VLA) models provide a unified paradigm for connecting visual perception, language understanding, and robotic control. However, existing VLA models still face major challenges in long-horizon tasks: sparse expert demonstrations constrain cross-task compositional generalization; the non-Markovian nature of long-horizon tasks makes it difficult for policies conditioned only on current observations to maintain temporal consistency; limited closed-loop error correction allows execution errors to accumulate; and end-to-end action fine-tuning may weaken the high-level semantic representations of vision-language model (VLM) backbones. To address these issues, we propose a hierarchical long-horizon VLA architecture with an explicit language-memory module. The central idea is to convert discrete temporal observations into a coherent textual memory sequence with temporal logic. The system is decoupled into a high-level VLM and a low-level VLA: the high-level VLM performs semantic reasoning through a visual question answering training paradigm, while the low-level VLA executes precise continuous control conditioned on subtask instructions and visual observations. The high-level VLM recursively updates both language memory and subtask instructions using the previous memory as a contextual anchor, enabling persistent temporal tracking and dynamic correction during long-horizon execution. We evaluate the proposed method in multiple simulation environments and conduct sim-to-real experiments on a real robotic platform. The results demonstrate that explicit language memory improves the success rate and robustness of VLA models on complex long-horizon tasks while providing an interpretable semantic account of the decision process.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：视觉-语言-动作（VLA）模型通过视觉观测和语言指令直接生成机器人动作，成为具身智能中连接感知、理解与控制的统一范式。
- **核心问题**：现有 VLA 模型在长时程（long-horizon）多阶段任务中表现不佳，主要受困于以下四个关键挑战，构成了本研究的基本动机：
  - **稀疏专家演示**：在跨任务的组合泛化上受到极大限制，难以从少量示范中学习长序列任务的知识。
  - **非马尔可夫决策困境**：长时程任务中，同一视觉观测可能对应不同决策（例如，同一视角的收音机，取决于之前是否已完成抓取或按压操作），仅依赖当前观测的策略无法维持时间一致性。
  - **误差累积**：在线执行过程中缺乏有效的闭环纠错机制，早期阶段的微小失败会沿轨迹逐步放大。
  - **特征表征退化**：端到端的动作微调可能破坏 VLM 骨干网络中经预训练获得的高层语义表示，使其退化为纯视觉控制器。
- **整体含义**：论文提出一个关键假设——**语言记忆能够改善阶段一致性**，即智能体只有在观测支持当前里程碑完成时才应推进到下一阶段。这一机制补充了低层控制精度的不足，为 VLA 模型的长时程规划提供了紧凑、可解释、可扩展的中间表征形式。

### 2. 论文提出的方法论

- **核心思想**：提出一种层次化长时程 VLA 架构，将完整的机器人策略显式分解为高层语义决策（状态跟踪与子任务规划）与低层动作生成两个解耦模块，核心创新在于引入**显式滚动语言记忆**作为跨决策步骤传递的时间状态载体。

- **分层策略分解**：策略被形式化分解为两个条件策略的乘积，对应本文核心公式（1）：
  π(aₜₜ₊ₕ, sₜ, mₜ | oₜ, mₜ₋₁, l) = π_LL(aₜₜ₊ₕ | oₜ, sₜ) · π_HL(sₜ, mₜ | oₜ, mₜ₋₁, l)
  - **高层语义分支 π_HL**：负责"决定任务进展到哪一步、下一步做什么"，读取全局指令、当前观测和上一时刻的记忆，递归更新语言记忆并生成简洁子任务指令。
  - **低层动作分支 π_LL**：负责"如何执行当前子任务"，以当前观测和子任务指令为条件，用流匹配（flow matching）目标生成固定长度动作块（H=30）。

- **递归语言记忆机制**：
  - 记忆 mₜ 是结构化自然语言摘要，保留五类信息：已完成阶段、完成证据、相关物体属性、观测到的失败、下一待办里程碑。
  - 采用**滚动压缩规则**：子任务未完成时保留细节（如"红色收音机在咖啡桌上"），完成后压缩为简短过去时陈述，注意力转到下一动作。
  - 记忆仅在观测提供当前里程碑已完成的证据时才更新，形成了证据驱动的状态推进机制。

- **自动化记忆监督管线**：利用通用 VLM（Gemini 3.5 Flash API 或本地部署的 Qwen3.5-9B）将专家视频、技能标签和时间戳自动转换为帧对齐的记忆-子任务监督目标，具体包括：当前帧 + 完整技能注释 → 生成动作+目标+上下文的子任务和第一人称语言记忆。

- **独立分支训练**：高层分支使用 PaliGemma（VQA 风格自动回归训练）优化两项损失（记忆预测 + 子任务预测）；低层分支沿用 π0.5 的流匹配动作专家。两个分支独立训练避免了在单一目标中手工平衡语义生成与连续控制损失。

- **闭环推理流程**：记忆初始化为空 → 采集观测 → 高层更新记忆和子任务 → 低层生成动作块 → 执行 → 检查终止条件，循环至任务完成。

### 6. 论文的主要结论与发现

- **显式语言记忆在多个平台上持续提升 VLA 的长时程任务表现**，降低阶段混淆导致的失败。
- **记忆机制显著改善了阶段一致性和约束阶段顺序**：基线在拾起收音机后跳过按压按钮直接进入放置阶段，记忆模型则等到观测证据确认后才推进。
- **语言记忆与低层运动控制解决的是不同问题**：语义记忆能解决"该做什么"，但不能解决"怎么做"（PressOn 的低成功率说明接触丰富的动作仍受几何校准和力控限制）。
- **显式文本状态支持上下文失败恢复**：真实机器人日志显示，抓取失败后记忆模型可以记录失败状态、发出重新打开夹爪的子任务并重试，无需单独恢复控制器。
- **可解释性收益**：记忆和子任务均为可读文本，可将失败定位为高层语义错误或低层控制错误。

### 7. 优点（方法与实验设计亮点）

- **开创新的记忆表征形式**：与 RDT、HAMLET、MemoryVLA 等采用隐向量或感知记忆的路线不同，将自然语言作为主要记忆载体，兼具紧凑性、监督友好性和可解释性。
- **模块化解耦设计**：高层语义规划与低层动作生成目标独立优化，避免单一端到端目标在语义与连续控制间的平衡难题，且分别适配最合适的模型结构（VQA 范式 VLM + 流匹配动作专家）。
- **自动化监督数据管线**：利用通用 VLM 自动生成记忆和子任务标签，绕过昂贵的人工标注，可扩展到新任务。
- **证据驱动的状态推进**：记忆更新以观测到的完成证据为条件，从机制上抑制跳阶段行为。
- **评估指标设计合理**：采用阶段级成功率而非仅终端成功率，能精确暴露阶段过渡的失败位置，更具诊断价值。
- **失败可归因**：分层设计可区分语义错误与控制错误，为后续改进提供明确方向。

### 8. 不足与局限

- **真实实验薄弱**：真实机器人仅限短时程拾放任务（4 阶段、25 条训练轨迹、20 次评估），无法验证"数分钟至十余分钟连续任务"的核心主张。

- **缺少消融研究**：未分离"语言记忆本身"和"高层规划分支"各自的贡献，也未与传统历史拼接、隐状态记忆等方法进行直接对比。
- **语言记忆的固有边界**：无法弥补低层数据不足或控制精度不够的问题，PressOn 的 10% 成功率即为其局限的典型体现。
- **计算开销增加**：每次决策额外调用一次高层 VLM，增加端到端延迟、计算量和部署复杂度，实际实时性的影响未量化。

- **异构性未探讨**：连续分拣任务中四种颜色包裹的顺序自由性对记忆表征提出了额外要求，但论文未分析记忆模型如何应对排序歧义；多智能体协同或灵巧操作等场景也未涉及。

## 摘要
随机单次打靶轨迹优化方法，如模型预测路径积分控制（MPPI），因其能够处理概率动力学并在模型梯度存在噪声、评估代价高昂或不可用时提供解决方案，已在机器人领域得到广泛应用。然而，在长动作序列上进行打靶时，终端约束的满足往往样本效率较低，需要大量迭代才能收敛。本文提出了一种随机多重打靶方法，该方法通过局部反馈策略优化短控制动作序列，以提高样本效率和向终端集合的收敛性。此外，我们展示了能够纯粹从滚动过程中合成近似的系统雅可比矩阵，使该方法适用于具有黑箱动力学的基于模型的强化学习。我们通过三个非线性、欠驱动优化问题证明了该算法在样本效率和终端集合收敛性方面的提升：一个具有解析动力学的经典小车倒立摆摆动任务、一个具有学习得到的神经网络动力学的小车倒立摆摆动任务，以及一个垂直起降四联飞机执行大迎角、高精度失速后着陆机动。鉴于以上要求，输出JSON如下：

## Abstract
Stochastic single shooting trajectory optimization methods such as Model Predictive Path Integral control (MPPI) have been widely adopted in robotics due to their ability to reason about probabilistic dynamics and provide solutions where model gradients are noisy, costly to evaluate, or unavailable. However, satisfaction of terminal constraints when shooting over long action sequences is often sample inefficient, requiring a large number of iterations for convergence. In this paper, we present a stochastic multiple shooting method that optimizes short control action sequences connected via local feedback policies to improve sample efficiency and convergence to a terminal set. Additionally, we show that we are able to synthesize approximate system Jacobians purely from rollouts, making the method suitable for model-based reinforcement learning with black-box dynamics. We demonstrate the algorithm has improved sample efficiency and terminal set convergence for three nonlinear, underactuated optimization problems: a classic cartpole swingup task with analytical dynamics, a cartpole swingup task with learned neural network dynamics, and a VTOL quadplane performing a high angle-of-attack, precision post-stall landing maneuver.

### 2. 论文提出的方法论

#### 2.1 核心思想

- 将问题（方程 1）中的**缺陷等式约束（defect equality constraint）** 松弛为**不等式概率约束**：利用后续段的局部时变 LQR 反馈策略，将前一端的末端状态限定在后续段的反馈策略的**不变量集（invariant set）** 内，即：
  \[
  p(F(X_j, U_j, W_j) \in R_{j+1}) > 1 - \epsilon_R
  \]
- 算法采用**从终端段反向逐段优化**的序贯策略：从最后一段开始，先优化终端段使其进入终端集合（terminal set），再据此构造该段的局部反馈策略及成本函数（cost-to-go），随后以该成本函数为终端成本，优化前一段。如此反复直至第一段。

#### 2.2 关键技术细节

| 组件 | 方法 |
|------|------|
| 段内轨迹优化器 | 交叉熵方法（CEM），同时优化**控制输入序列**和**段初始状态**，两者分别建模为多元高斯分布并迭代更新 |
| 局部反馈策略 | 离散时间**时变线性二次型调节器（TVLQR）**。反馈增益 \(K_k\) 与成本矩阵 \(S_k\) 通过黎卡提递推计算 |
| 近似系统雅可比 | 从随机扰动采样中利用**最小二乘回归**（方程 13）合成局部线性化矩阵 \(A_k, B_k\)，无需解析动力学或有限差分，可用于非光滑、含噪声的神经网络动力学模型 |
| 初始状态采样 | 利用 TVLQR 成本函数的水平集（level set）构造高斯分布（\(LQR 置信椭圆\)），使采样的段初始状态落在"可有效控制"的收缩区域，提升段间可达性 |
| 缺陷约束验证 | 在优化过程中定期构造 TVLQR 策略并批量滚动，检验后续段整体策略作用下系统进入终端集的概率是否达标；若不达标则继续外循环迭代 |

#### 2.3 算法流程（Alg. 1）

1. 用几次单次打靶生成初始候选轨迹和反馈策略；
2. 将轨迹拆分为 M 段（非重叠区间）；
3. 从终端段开始，CEM 优化（段初始状态 + 段控制序列）并满足终端集概率约束；
4. 构造该段的 TVLQR 反馈策略；
5. 对前一段，以后续段反馈策略的成本函数 \(V(x) = (x - x_{s_{n+1}})^T S_{s_{n+1}}(x - x_{s_{n+1}})\) 为终端成本进行 CEM 优化；
6. 重复至第一段（初始状态固定）；
7. 沿各段反馈策略闭环模拟，生成完整控制序列；
8. 重复多轮（外循环）直至收敛。

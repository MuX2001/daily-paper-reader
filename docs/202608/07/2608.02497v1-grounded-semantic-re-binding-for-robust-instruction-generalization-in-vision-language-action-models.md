## 摘要
视觉-语言-动作（VLA）模型在机器人操作中表现出色，但当规范指令仅被简单改写时，其性能会急剧下降。尽管这种脆弱性通常通过昂贵的数据扩展来解决，但我们的探测表明，根本原因在于架构而非语义理解的缺乏。具体而言，我们证明当前的VLA在内部成功保留了正确的任务身份。失败实际上源于动态视觉观察与文本的联合编码，这引入了系统性的特征偏移。由于下游动作策略对这些变化高度敏感，它无法将保留的语义转化为正确的控制命令。为解决这一结构性瓶颈，我们提出了基于语义重绑定（GSR），一种优雅的干预方法，通过将独立提取的任务语义与原生视觉特征显式融合，从头训练一个完全重新初始化的动作专家，从而绕过不稳定的联合路由。这一针对性干预仅使用规范示范即可显著恢复释义不变性。在LIBERO-Para基准上，GSR将成功率提升了高达44.6%。它使轻量级模型能够与大规模扩展的基线相媲美，并将最先进模型的PRIDE分数推至新纪录70.4，在指令生成能力上超越了最近引入的大规模预训练模型Xiaomi-Robotics-0。基于这些见解，我们还引入了ParaVLA，一个原生解耦的0.33B参数模型，对指令改写表现出近乎完美的鲁棒性。最终，我们的工作证明，通过优雅的结构设计可以实现鲁棒的语义接地，从而绕过低效的暴力数据扩展范式。

## Abstract
Vision-Language-Action (VLA) models excel in robotic manipulation but suffer catastrophic performance drops when canonical instructions are simply paraphrased. Although this brittleness is typically addressed through costly data scaling, our probing reveals that the root cause is architectural rather than a lack of semantic understanding. Specifically, we demonstrate that current VLAs successfully retain the correct task identity internally. The failure actually stems from the joint encoding of dynamic visual observations and text, which introduces systematic feature shifts. Because the downstream action policy is highly vulnerable to these variations, it fails to translate the preserved semantics into correct control commands. To resolve this structural bottleneck, we propose Grounded Semantic Re-binding (GSR), an elegant intervention that bypasses unstable joint routing by explicitly fusing independently extracted task semantics with native visual features to train a completely re-initialized action expert from scratch. This targeted intervention dramatically restores paraphrastic invariance using only canonical demonstrations. On the LIBERO-Para benchmark, GSR improves success rates by up to 44.6 percent. It enables lightweight models to rival massively scaled baselines and pushes state-of-the-art models to a new record PRIDE score of 70.4, outperforming the recently introduced large-scale pretrained model Xiaomi-Robotics-0 in instruction generation capabilities. Building on these insights, we also introduce ParaVLA, a natively decoupled 0.33B-parameter model exhibiting near-perfect robustness to instruction rewording. Ultimately, our work proves that robust semantic grounding can be achieved through elegant structural design, bypassing the inefficient brute-force data scaling paradigm.

## 二、方法论：Grounded Semantic Re-binding（GSR）

### 核心思想

GSR 的核心逻辑是绕过 VLA 模型中不稳定的“语言-视觉联合路由”，将任务语义提取与视觉场景理解解耦，再在动作生成阶段进行显式融合。

### 技术流程

1. **稳定语义提取**：使用**冻结的 T5-large 编码器**对原始任务指令进行编码，T5 只接收文本、不接收图像或机器人状态，保证提取的语义特征完全稳定、不受动态视觉输入干扰。
2. **原生视觉与状态通道保留**：模型的视觉骨干继续处理真实的动态图像与机器人状态，保留场景接地能力。
3. **注入点选择（架构自适应）**：将投影后的 T5 语义特征注入到各模型原生的“多模态融合计算阶段”，而非外部附加模块：
   - **VLA-Adapter**：T5 特征作为 sidecar K/V 源注入 Bridge-Attention 策略的各层，并配有独立 softmax 与逐块门控；原生 Qwen 输入被替换为固定中性文本“perform the task”。
   - **SmolVLA**：T5 特征通过 8 头 grounding attention 注入 SmolVLM 的语言槽位，再经过原生多模态处理后才进入动作专家；原生指令同样被中性化。
   - **π0.5**：因 PaliGemma 原生语言通路已经具备可靠的释义泛化能力，故**保留真实指令**，T5 作为补充语义源，注入 PaliGemma 的 task-token 位置，再进入原生多模态计算。
4. **动作专家完全重新初始化**：不微调预训练权重，而是从头训练一个新的动作专家，使其从一开始就学习如何将 T5 语义条件、视觉特征与机器人状态联合映射为动作。

### 架构决策准则（图 3 总结的通用指南）

- 先评估原生语言通路对改写的可靠性；
- 若脆弱（如 VLA-Adapter、SmolVLA 的 Qwen/SmolVLM 通路），则中性化原生文本输入，强制模型依赖 T5 语义；
- 若可靠（如 π0.5 的 PaliGemma 通路），则保留真实指令，T5 作为补充信号。

### 关键公式（用于诊断分析）

- 归一化动作向量：**ā = (a − μ) / max(‖a − μ‖₂, 10⁻⁸)**，μ 为规范参考语料上的平均动作；
- 动作距离：**D(a, b) = ‖ā − b̄‖₂**；
- Retrieval@1：判断改写指令产生的动作在 N 个规范指令候选动作中是否最接近真实任务对应的动作；
- 语义保留率：**R = (∆wrong − ∆para) / (∆wrong + ∆para)**，其中 ∆wrong 为错误任务距离、∆para 为释义距离，R > 0 表示释义响应仍更接近目标任务。

## 六、主要结论与发现

1. **根因定位**：VLA 的释义失败不是语义理解问题，而是**任务语义在从语言编码到动作生成的转换过程中发生系统性偏移**。所有评测模型的 Retrieval@1 均高于随机水平、语义保留率 R 为正。
2. **因果验证**：在 VLA-Adapter 的 Bridge-Attention 最终块替换为规范特征后，配对成功率从 60% 提升至 96%，消除 96.8% 的动作偏差——证明正确的任务信息存活于语言骨干中，但被下游策略错误利用。
3. **GSR 有效性**（仅用规范示范训练）：
   - VLA-Adapter：Full Para 成功率 46.82% → **70.94%**，PRIDE 36.7 → **62.0**；
   - SmolVLA：4.47% → **49.12%**，PRIDE 2.6 → **41.4**；
   - π0.5：73.60% → **75.59%**（GSR∗ 为 75.76%，Goal SR 恢复至 96.0%），PRIDE 达到 **70.4**，超过 Xiaomi-Robotics-0 的 69.2，创下最高纪录。
4. **轻量模型媲美大规模基线**：VLA-Adapter（0.51B，无大规模预训练）+ GSR 的性能匹敌 π0.5 等大规模模型，证明了结构设计对数据规模的替代作用。
5. **原生解耦的可行性**：ParaVLA（0.33B 激活参数）在规范/释义成功率上分别达到 92.0%/91.0%，仅 1 个百分点差距，近完美释义不变性。
6. **神经网络的“语义污染”问题**：在同一解耦架构中，将 T5 替换为 SmolVLM 解码器后，释义成功率从 91.0% 跌至 41.0%，证明 VLM 本身的语言表征污染是实质障碍，稳定语义源是必需的。

## 七、优点

- **诊断深度与因果严谨性**：不仅观察现象，还通过 token 干预、激活替换、词向量子空间分析、路由冲突测试等多种手段对失败机制进行多角度因果验证，逻辑链条完整。
- **方法优雅且开源**：无需任何释义数据、无需大规模数据扩展，仅改变信息的提取与注入方式即显著提升鲁棒性；代码已开源。
- **架构自适应而非固定补丁**：GSR 针对三种架构采用三种注入策略，并给出通用决策准则，避免了“一刀切”式方法在不同信息流架构上的失效问题。
- **跨规模验证**：从 0.33B 的 ParaVLA 到 0.45B/0.51B 的轻量模型再到 3.6B 的大规模 π0.5，全面验证了方法的普适性与正交性。
- **诊断指标设计规范**：Retrieval@1、语义保留率 R、恢复率等指标清晰且可复现；同时声明了跨模型比较的尺度无关性，避免了直接比较原始距离的陷阱。

## 八、不足与局限

- **真实机器人实验规模较小**：仅 6 个任务、5 次重复，且部分任务（任务 3、5、6）GSR 成功率也为 0%，说明方法在真实场景中的泛化仍有明显缺口；论文也自述为“pilot”研究。
- **解码架构的可扩展性瓶颈**：ParaVLA 在增大视觉骨干规模时未能体现出类似 VLM 的扩展能力，解耦范式在大规模场景下的可行性尚未得到验证。
- **π0.5 在标准训练步数下的性能回退**：GSR 需要重新初始化动作专家，对于参数规模较大的 π0.5 动作专家，需要双倍训练步数才能恢复规范任务性能，额外训练成本需纳入考量。
- **T5 语义提取的覆盖能力**：T5 虽稳定，但其世界知识、开放词表理解能力有限，面对更复杂、更长尾的开放式指令可能力有不逮。
- **固定训练种子与单数据集**：各配置仅使用一个训练种子，且全部实验基于 LIBERO 系列的单一视觉场景分布，跨场景、跨具身的泛化结论有待更多数据集验证。
- **大规模基线比较的公平性**：对 OpenVLA-OFT、X-VLA、Xiaomi-Robotics-0 等模型的引用值来自原始文献，训练数据与协议不完全可控，对比存在一定程度的不可比因素。

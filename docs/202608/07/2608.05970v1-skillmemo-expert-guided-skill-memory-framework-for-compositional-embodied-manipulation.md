## 摘要
具身视觉运动模型，包括扩散策略（DP）和视觉-语言-动作（VLA）模型，已在机器人操控基准上展现出有前景的性能。然而，其潜力从根本上受到大规模具身轨迹数据集稀缺性的制约，导致在分布外（OOD）场景中组合泛化不足，且捕获可复用技能结构的能力有限。为了解决这一局限，我们提出了基于技能的记忆（SkillMemo）框架，该框架将长时程演示隐式分解为潜在原子技能，并将技能级特征整合到动态情节记忆库中，以解决组合式任务。具体而言，我们首先引入了一个基于混合专家（MoE）架构的专家引导轨迹分割模块，该模块将轨迹隐式划分为由学习到的门控系数表示的不同技能原语。我们进一步设计了一种技能级情节记忆架构，将紧凑的技能表示存储为可检索的键值对。在推理时，记忆库检索最相关的技能原语，随后将其与模型当前的门控分布融合，为细化动作预测提供稳健的上下文先验。在仿真基准和真实世界操控任务上的大量实验表明，SkillMemo持续增强了DP和VLA骨干模型，实现了最先进的性能并优于$π_{0.5}$，同时展现出对未见任务配置的强大组合泛化能力。

## Abstract
Embodied visuomotor models, including Diffusion Policy (DP) and Vision-Language-Action (VLA) models, have demonstrated promising performance on robotic manipulation benchmarks. However, their potential remains fundamentally constrained by the scarcity of large-scale embodied trajectory datasets, leading to insufficient compositional generalization in out-of-distribution (OOD) scenarios with limited capability to capture reusable skill structures. To address this limitation, we propose Skill-Based Memory (SkillMemo) framework that implicitly decomposes long-horizon demonstrations into latent atomic skills and integrates skill-level features into a dynamic episodic memory bank for solving compositional tasks. Specifically, we first introduce an expert-guided trajectory segmentation module built upon a Mixture-of-Experts (MoE) architecture, which implicitly partitions trajectories into distinct skill primitives represented by learned gating coefficients. We further design a skill-level episodic memory architecture that stores compact skill representations as retrievable key-value pairs. During inference, the memory bank retrieves the most relevant skill primitives which are subsequently fused with the model's current gating distribution, providing a robust contextual prior to refine action predictions. Extensive experiments on the simulation benchmark and real-world manipulation tasks demonstrate that SkillMemo consistently enhances both DP and VLA backbones, achieving state-of-the-art performance and outperforming $π_{0.5}$, while exhibiting strong compositional generalization to unseen task configurations.

### 1. 核心问题与研究动机

- 具身视觉运动模型（Diffusion Policy / VLA）当前主要瓶颈并非网络结构，而是**大规模真实机器人轨迹数据的获取成本过高**。
- 在数据稀缺条件下，模型倾向学习**整体式、单一化的行为映射**，无法捕获具身操作中可复用的"技能结构"。
- 因此面临的核心挑战是：面对**未见过的组合配置**（已知物体×未见容器×新指令的交叉组合），现有模型成功率和泛化能力明显不足。
- 现有记忆增强方法（如 MemoryVLA、HAMLET）虽引入经验存储，但存储的多为**整体、非结构化的视觉-语义表示**，缺乏对"行为层面技能"的显式记忆与复用，导致在分布外组合任务中体验复用效率低下。
- 本论文旨在解决：在演示数据有限时，如何让策略模型**自主分解、存储、检索并组合技能原语**，从而获得较强的组合式泛化能力。

### 2. 方法论：SkillMemo 框架

SkillMemo 由两个核心模块组成：

**（1）专家引导轨迹分割（EGTS，Expert-Guided Trajectory Segmentation）**

- 采用 **Mixture-of-Experts（MoE）** 架构，通过门控网络将整条轨迹隐式分解为若干"潜在原子技能"。
- 核心公式：`y_t = Σ gᵢ(h_t) · Eᵢ(h_t)`，其中 Eᵢ 为第 i 个专家网络，gᵢ 为门控权重。门控权重随时间的变化**隐式定义了技能的边界**，无需显式动作标签。
- 每个专家经训练后自然 specialize 于某种局部运动原语（如"抓碗""开火炉"）。
- 引入基于**部分信息分解（PID）理论**的协同信息损失 `L_PID`，鼓励不同专家捕获互补技能而非重叠冗余信息；同时配合负载均衡损失和 top-k 路由防止专家崩塌。

**（2）技能级记忆架构（SLMA，Skill-Level Memory Architecture）**

- **存储（Storage）**：对每个技能片段做时间维聚合，计算中心特征作为 **key（检索键）**；将片段内完整门控权重序列作为 **value（技能执行知识）**，构成记忆库 `M = {(kₘ, vₘ)}`。
- **检索（Retrieval）**：推理时用当前观测特征与所有 key 计算余弦相似度，取 top-N 条目；并设置信阈值 δ 进行可靠性门控。
- **融合（Fusion）**：将检索到的历史门控分布与当前门控输出加权平均（`g'(qₜ) = λg(qₜ) + (1-λ) · mean(vₙ)`），为动作生成提供上下文先验。
- **更新（Update）**：记忆库容量有限（M_max=1000），采用三种淘汰策略动态剪枝：过时条目、长期未命中的条目、以及检索时持续未达置信阈值的低质量条目，平衡记忆的多样性与质量。

### 6. 主要结论与发现

- SkillMemo 在**所有模拟基准和真实任务中持续优于对应 backbone**（DP / UniAct / UniVLA / π0.5），表明技能级记忆具有跨模型通用性。
- 在 LIBERO 上 **π0.5-SkillMemo 达到 98.0% 平均成功率**，超越 π0.5（96.8%）1.2%，超越 MemoryVLA（96.5%）1.5%。
- EGTS 独立带来增益，说明 MoE 隐式技能分解优于整体式学习；叠加 SLMA 后增益更大，说明"技能发现 + 经验复用"两者互补。
- 专家数量 N=5 是精度与推理时间的最优折衷；继续增加专家收益递减。
- 零样本跨套件结果显示：SkillMemo 训练于 Goal 套件后在未见 Spatial 套件上达到 75.6%，甚至超过直接在 Spatial 上训练的无记忆基线（72.1%），验证了技能可迁移组合的假设。
- 门控权重可视化证实 MoE 专家确实学会了语义上有意义的动作原语（如抓取、转动开关时特定专家激活峰值）。

### 7. 方法亮点与优势

- **隐式分解**：不依赖人工标注动作边界，MoE 门控自然形成技能边界，普适性更强。
- **技能记忆结构化**：将门控分布作为可执行技能知识进行存储，避免存储原始高维观察/动作序列，记忆紧凑且可扩展。
- **可插拔设计**：SkillMemo 不针对单一架构，可同时应用到 DP 和多种 VLA 模型，具有良好的通用性。
- **记忆动态管理**：引入使用频率、新旧程度、置信度三重剪枝策略，支持终身学习场景，避免记忆库无限膨胀。
- **理论与实践结合**：使用 PID 理论设计协同损失，为专家分工提供了信息论层面的动机支撑。

### 8. 不足与局限

- **真实实验覆盖度有限**：仅用单机器人（UR5e）、单相机视角、桌面级任务，未在不同机型和复杂多步任务上验证；VLA backbone 未参与真实评估。
- **参数量公平性**：SkillMemo 引入 MoE 和记忆模块，模型参数量上升（如 π0.5 3.3B → 3.6B），比较时未做充分讨论；此外是否与其他记忆类方法做了同参数量对比不明。
- **统计严谨性**：部分关键结果（尤其是零样本跨套件泛化）未报告多次运行的标准差/置信区间，难以判断显著性。
- **记忆与技能的可解释性**：隐式技能虽然可视化时具有语义对应，但技能边界、门控向量与真实动作意图的对应关系仍是间接推断，缺乏定量度量。
- **可扩展性问题**：训练时记忆如何随新任务持续更新？是否会灾难性遗忘旧技能？论文的验证更多是离线训练+在线检索，真正的终身学习场景（连续任务流）验证不充分。
- **语言指令与技能的关联**：检索过程完全依赖视觉特征相似度，未显式建模语言指令对角色的约束，在复杂语言指令组合下检索精度可能受限。

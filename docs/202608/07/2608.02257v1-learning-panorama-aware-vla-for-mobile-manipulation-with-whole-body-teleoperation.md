## 摘要
移动操作是具身智能的关键能力，使机器人能够在开放世界环境中完成复杂的多阶段任务。然而，移动操作对视觉-语言-动作（VLA）策略提出了两个关键挑战：在数据层面，高效收集高质量全身演示需要移动基座和机械臂的协调控制；在模型层面，现有VLA模型主要依赖局部相机观测，其有限的视野阻碍了全局空间理解。为了解决这些挑战，我们开发了一个全身遥操作系统和一个全景感知VLA策略。该系统通过单个VR接口实现轮式双臂机器人的协调控制，并支持获取包含5.5小时多模态演示的真实世界移动操作数据集。在此数据集的基础上，我们提出了PanoVLA，一种用于移动双臂操作的全景感知视觉-语言-动作策略。PanoVLA基于Mixture-of-Transformers架构，通过专门的全景编码和融合模块引入全局空间上下文，实现全景观测与语言指令和机器人状态的有效集成以生成动作。在四个真实世界移动操作任务上的评估表明，PanoVLA实现了91.3%的平均阶段完成率和73.4%的端到端成功率，显著优于局部视图基线。这些结果表明，融入全景空间上下文提高了移动机器人的空间理解和闭环操作性能。

## Abstract
Mobile manipulation is a key capability for embodied intelligence, enabling robots to accomplish complex multi-stage tasks in open-world environments. However, mobile manipulation poses two key challenges for vision-language-action (VLA) policies: At the data level, the efficient collection of high-quality whole-body demonstrations demands the coordinated control of both the mobile base and the robotic arms; at the model level, existing VLA models predominantly rely on local camera observations, whose limited field of view hinders global spatial understanding. To address these challenges, we develop a whole-body teleoperation system and a panoramic-aware VLA policy. The system enables coordinated control of a wheeled bimanual robot through a single VR interface and supports the acquisition of a real-world mobile manipulation dataset comprising 5.5 hours of multimodal demonstrations. Building upon this dataset, we propose PanoVLA, a panorama-aware vision-language-action policy for mobile bimanual manipulation. Built upon a Mixture-of-Transformers architecture, PanoVLA introduces global spatial context through dedicated panorama encoding and fusion modules, enabling effective integration of panoramic observations with language instructions and robot states for action generation. Evaluation on four real-world mobile manipulation tasks demonstrates that PanoVLA achieves an average stage completion rate of 91.3\% and an end-to-end success rate of 73.4\%, substantially outperforming local-view baselines. These results demonstrate that incorporating panoramic spatial context improves spatial understanding and closed-loop manipulation performance in mobile robots.

### 2. 方法论

#### 2.1 全身遥操作系统（数据采集侧）

- **操作员接口**：仅使用一套可穿戴VR设备（头显+双手柄）和三个身体追踪器（腰部、双脚踝），采集稀疏人体运动信号。系统实时重建SMPL人体模型，提取骨盆位姿、双脚运动和双手位姿作为重定向输入。
- **机器人平台**：轮式双臂机器人，由RANGER MINI 3移动基座（3DoF平面移动，支持原地旋转、Ackermann转向和对角平移三种模式）、两个6-DoF Agilex PIPER机械臂及平行夹爪组成。视觉系统包括顶部360°全景相机和三个局部RGB相机（一个前视、两个腕部）。
- **GMR运动重定向**：将移动基座建模为3-DoF平面虚拟浮动基座，与双臂关节配置联合优化。机器人配置参数化为 q = (x_b, y_b, θ_b, q_L, q_R)，通过最小化加权目标函数获得：

  ```
  q* = argmin_q λ_pos·L_pos + λ_rot·L_rot + λ_base·L_base + λ_reg·L_reg
  ```

  其中 L_pos 对齐手/夹爪位置，L_rot 对齐手/末端执行器朝向，L_base 将基座平面运动与操作者骨盆位移及朝向耦合，L_reg 约束关节极限和配置突变。基座参与末端对齐目标，当目标位姿超出机械臂工作空间时自动调整基座位置。
- **成本驱动模式切换**：执行虚拟3-DoF基座指令时，每步评估三种移动模式与期望平移/旋转之间的匹配代价，选择代价最低的模式执行——实现动态适应操作者意图。

#### 2.2 PanoVLA 策略（模型侧）

- **整体架构**：基于Mixture-of-Transformers（MoT）的VLA策略，以π0.5为骨干，在VLM专家和动作专家之间插入专门的全景专家模块。三个专家块——VLM专家（编码局部视觉+语言指令+机器人状态）、全景专家（生成任务条件化的全局空间上下文）、动作专家（预测连续动作块）。
- **融合机制**：采用Transformer的KV缓存作为融合接口。VLM专家先计算 VLM缓存 C_vlm，全景专家对全景token序列执行联合自注意力（可访问VLM缓存），产生全景缓存 C_pano，动作专家再结合两个缓存 [C_vlm; C_pano] 进行动作预测。
- **全景编码器**：将双鱼眼图像通过球面重投影（Π_sph）映射为等距柱状投影（ERP）全景图，输入MTPano多任务全景基础模型，提取分割分支（语义）和深度分支（几何）的中间特征并沿通道拼接，再经轻量级token适配器（自适应平均池化+MLP）转化为固定数量的全景token（Z_pano ∈ R^(N_p×d)）。关键设计：用全景专用编码器处理ERP图像，避免通用透视图像编码器（如SigLIP）与全景几何失配的问题。
- **训练目标**：采用条件流匹配（Conditional Flow Matching），对演示动作块a、噪声样本x_τ和流匹配时间步τ，最小化预测速度场与目标速度场的均方误差：

  ```
  L = E[ || v_θ(x_τ, τ | C_t) − u(x_τ | a) ||² ]
  ```

### 3. 实验设计

#### 3.1 数据集与场景

- **数据规模**：基于自建遥操作系统采集800条成功轨迹、约5.5小时、50万帧同步多模态数据（25Hz，每条轨迹约20-30秒），包括局部RGB视图、腕部视图、顶部360°全景、本体感知状态和全身动作（17维：14维双臂+夹爪，3维基座平面速度）。
- **任务定义（4个真实世界移动操作任务）**：
  - **Move Pen**：将笔放入笔筒（目标位于前/左/右方向）
  - **Move Block**：将积木转移到前方区域（目标位于左/右/两侧）
  - **Open Curtain**：依次拉开两侧窗帘（需要双侧顺序交互）
  - **Wipe Table**：沿长桌擦除污渍并将毛巾放回原位（长距离、多阶段）
- **任务设计意图**：覆盖不同目标布局、双侧交互和空间尺度，使任务相关区域无法被局部相机同时覆盖，从而形成跨视角空间推理和多阶段状态追踪的需求。

#### 3.2 对比方法

- **π0.5**：仅使用SigLIP编码局部视图的原始基线
- **π0.5 w/ Pano**：将ERP全景图作为额外图像输入，直接用SigLIP编码，不设专门全景分支
- **π0.5 w/ Stacked Pano**：将全景重投影为3个yaw轴间隔120°的透视视图拼接为合成图，作为额外视觉输入
- **PanoVLA**：本文方法（MTPano全景编码器+全景专家）

#### 3.3 评估指标

- **成功率（SR）**：二值的全程任务完成指标
- **阶段完成率（SCR）**：所有试验中适用阶段完成比例的均值，用于细粒度失败分析

### 6. 主要结论与发现

- **主结果**：PanoVLA平均阶段完成率91.3%、端到端成功率73.4%，大幅超过局部视图基线π0.5（SCR 58.6%、SR 30.0%）。
- **全景信息有效但需正确建模**：单纯把全景图作为额外图像输入（π0.5 w/ Pano）确实提升性能（SCR 80.8%、SR 56.7%），但提升不稳定——比如Wipe Table任务中其最终阶段仅完成26.7%，端到端SR只有20.0%。这证明全景感知的关键不在"视野更广"，而在于如何表示和融合全景几何信息。
- **专用全景编码器的必要性**：MTPano编码器显著优于SigLIP（SCR 95.6% vs 75.6%，SR 86.7% vs 40.0%），说明以透视图预训练的通用编码器无法有效捕捉ERP图像的横向连续性和全局空间布局。
- **专家容量的影响**：100M专家最优，50M不足以捕捉跨视图依赖，超过100M反而因有限微调数据无法带来稳定提升。
- **任务难度分析**：Move Pen和Move Block主要依赖目标方向估计即可靠完成；Open Curtain和Wipe Table则需要连续状态追踪和跨阶段空间一致性——PanoVLA在后者优势更明显，体现了全景专家对任务状态转换和全局空间一致性建模的价值。

### 7. 方法/实验设计的亮点

1. **端到端的"数据-模型"协同设计**：将数据采集问题和模型架构问题作为一个整体系统解决，而非各自孤立处理。遥操作系统采集的数据直接影响PanoVLA设计，模型需求反过来指导数据模态设计（顶部全景相机配置）。
2. **GMR全身遥操作的创新性应用**：将移动基座建模为平面虚拟浮动基座，消除了分离式基座控制的不可流畅性；成本驱动模式切换机制让同一个3-DoF目标指令可以适配不同底盘运动学模式。
3. **全景编码器设计扎实**：利用全景专用基础模型MTPano同时提取语义（分割）和几何（深度）特征，有效解决了非透视畸变问题，并且通过自适应池化保证token数量与全景分辨率解耦。
4. **消融实验设计精准**：通过"导入全景图"和"拼接透视图"两种对照，分离出"有无全景信息"和"全景表征方式"两个因素的影响，归因清晰。
5. **逐阶段SCR指标**：比仅报告端到端SR更能揭示模型在哪一步失效，对移动操作这类长时程任务特别有价值。

### 8. 不足与局限

1. **实验覆盖不足**：
   - 仅4个任务，且均为实验室环境下的结构化工序；未涉及更复杂场景如动态障碍、非固定初始布局或多机器人协作。
   - 每任务仅15次试验，方差可能较大；π0.5 w/ Pano在Move Pen上与PanoVLA完全持平（SCR 95.6%、SR 86.7%），说明在简单任务上全景专家未必必要。
2. **现实部署方面的局限**：
   - 全景相机为顶部安装，未验证不同安装高度/位置对性能的影响。
   - 模型基于任务独立微调（每个任务一个策略），未验证单一统一模型跨任务的泛化能力。
   - 遥操作系统依赖VR设备，要求操作者接受训练，数据采集成本较高。
   - 物理硬件限制：i.e., 未讨论全景相机与局部相机之间时间同步精度、深度/分割特征融合引入的额外计算延迟闭环影响。
3. **方法泛化性局限**：
   - MTPano作为全景编码器是冻结的，其预训练数据的场景/域与下游机器人操作场景是否匹配未做分析。
   - 全景专家与VLM专家之间的双向信息流动受限（全景专家只看VLM缓存，不能反向影响VLM表示），可能限制了语言-全景联合推理的潜力。
4. **统计与对比局限**：
   - 没有提供多次运行之间的方差/置信区间，无法判断性能差异的统计显著性。
   - 未与最前沿的移动操作VLA工作（如等）进行基准对比，削弱了结论的覆盖面。
   - 消融实验仅在单任务上进行，专家规模结论是否跨任务一致未知。

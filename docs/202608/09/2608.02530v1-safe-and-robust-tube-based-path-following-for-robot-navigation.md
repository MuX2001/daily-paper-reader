## 摘要
在本文中，我们提出了一种新的鲁棒导航框架，用于在未知、杂乱环境中执行路径跟踪任务的机器人。我们的方法通过避障确保反应安全性，并保证收敛到目标路径，同时利用基于管道的控制策略减轻未知但有界扰动的影响。该方法集成了机器人导航的关键方面：(i) 一种标称集成制导与控制方案，用于路径跟踪，采用人工矢量场制导和反步控制；(ii) 一种平滑距离函数，能够实现连续控制律公式以实现无缝避障；(iii) 一个统一控制目标，平衡避障与路径跟踪；以及(iv) 一个自适应控制组件，以提供对外部扰动的鲁棒性。我们使用屏障函数和Lyapunov稳定性理论提供了安全性和稳定性的正式证明。通过广泛的数值模拟验证了所提出框架的有效性。

## Abstract
In this paper, we propose a new robust navigation framework for path following tasks in robots operating within unknown, cluttered environments. Our approach ensures reactive safety through obstacle avoidance and guaranteed convergence to a target path, while simultaneously mitigating the impact of unknown-but-bounded disturbances using a tube-based control strategy. The methodology integrates key aspects in the robot navigation: (i) a nominal Integrated Guidance and Control scheme for path-following employing Artificial Vector Fields guidance and Backstepping control; (ii) a smooth distance function that enables a continuous control law formulation for seamless obstacle avoidance; (iii) a unified control objective that balances collision avoidance with path-following; and (iv) an adaptive control component to provide robustness against external disturbances. We provide formal proofs of safety and stability using barrier functions and Lyapunov stability theory. The effectiveness of the proposed framework is validated through extensive numerical simulations.

## 1. 核心问题与整体含义（研究动机和背景）

未知杂乱环境中的自主机器人导航是机器人学与控制领域的重要挑战，广泛应用于监视、巡检、搜救、城市交通和自动驾驶等场景。核心矛盾在于：机器人需要**同时**满足三个要求——(i) 对未知环境中动态障碍的**反应式安全避障**；(ii) 对目标路径的**精确跟踪**；(iii) 对未知但有界外部扰动的**鲁棒性**。

然而，现有方法往往难以兼顾这三者：

- **反应式避障方法**（如基于碰撞函数或梯度距离函数的方法）虽然计算开销低、适合未知环境，但常产生非光滑控制律，且可能收敛到不良局部平衡点。传统欧氏距离函数在障碍物边界处的梯度不连续是导致非光滑性的根源。
- **协商式/规划式方法**需要预先获取环境地图与障碍物几何信息，计算成本更高，不适用于未知环境。
- **传统制导与控制分离（SGC）架构**将制导律与内环控制器解耦，难以实现整体最优的集成设计。
- **仅基于标称条件设计的控制器**在受扰时性能显著退化，标准鲁棒控制方法又往往未与反步框架及避障约束深度集成。

本文针对这一多目标冲突问题，提出了一种**基于管道的安全鲁棒路径跟随框架**，将标称集成制导控制、反应式平滑避障与自适应扰动抑制统一在一个加速度级控制律中，并给出了形式化的安全性与稳定性保障。

## 6. 主要结论与发现

1. **安全性的实现**：完整鲁棒控制器在所有仿真中**均未发生安全距离侵犯**，而仅使用标称控制器时在受扰情况下出现安全违规甚至碰撞——证明鲁棒自适应组件的关键作用。
2. **路径跟踪性能**：在无障碍场景下，鲁棒控制器的管道内时间占比接近 100%，且方差很小；标称控制器在高扰动下被扰动主导而无法稳定。
3. **避障与跟踪的权衡**：在有障碍场景中，两种控制器均无法全程保持在管道内（必须绕行），鲁棒控制器的绕行距离更大，管道内时间占比略低于标称控制器，但这是为保证安全而付出的合理代价。
4. **理论保障与仿真一致**：形式化证明（Theorem 1 中的 λ̄ > λ + δp 条件）在数值实验中得到验证；3D 场景中由于障碍物少、空间充足，未出现任何安全违规。
5. **框架的通用性**：方法在 n 维空间提出，2D 与 3D 仿真均验证了其有效性，可推广至多种机器人平台。

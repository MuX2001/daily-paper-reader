## 摘要
移动操作是具身智能的关键能力，使机器人能够在开放世界环境中完成复杂的多阶段任务。然而，移动操作为视觉-语言-动作（VLA）策略带来了两个关键挑战：在数据层面，高效收集高质量全身演示需要移动基座与机械臂的协同控制；在模型层面，现有VLA模型主要依赖局部相机观测，其有限的视野阻碍了全局空间理解。为应对这些挑战，我们开发了一套全身遥操作系统和一种全景感知VLA策略。该系统通过单一VR界面实现对轮式双机械臂机器人的协同控制，并支持采集包含5.5小时多模态演示的真实世界移动操作数据集。在此数据集基础上，我们提出了PanoVLA，一种面向移动双臂操作的全景感知视觉-语言-动作策略。PanoVLA基于Transformer混合架构，通过专门的全景编码与融合模块引入全局空间上下文，使全景观测与语言指令和机器人状态能够有效整合以生成动作。在四个真实世界移动操作任务上的评估表明，PanoVLA的平均阶段完成率达到91.3%，端到端成功率达到73.4%，显著优于局部视图基线。这些结果表明，融入全景空间上下文能够提升移动机器人的空间理解能力与闭环操作性能。

## Abstract
Mobile manipulation is a key capability for embodied intelligence, enabling robots to accomplish complex multi-stage tasks in open-world environments. However, mobile manipulation poses two key challenges for vision-language-action (VLA) policies: At the data level, the efficient collection of high-quality whole-body demonstrations demands the coordinated control of both the mobile base and the robotic arms; at the model level, existing VLA models predominantly rely on local camera observations, whose limited field of view hinders global spatial understanding. To address these challenges, we develop a whole-body teleoperation system and a panoramic-aware VLA policy. The system enables coordinated control of a wheeled bimanual robot through a single VR interface and supports the acquisition of a real-world mobile manipulation dataset comprising 5.5 hours of multimodal demonstrations. Building upon this dataset, we propose PanoVLA, a panorama-aware vision-language-action policy for mobile bimanual manipulation. Built upon a Mixture-of-Transformers architecture, PanoVLA introduces global spatial context through dedicated panorama encoding and fusion modules, enabling effective integration of panoramic observations with language instructions and robot states for action generation. Evaluation on four real-world mobile manipulation tasks demonstrates that PanoVLA achieves an average stage completion rate of 91.3\% and an end-to-end success rate of 73.4\%, substantially outperforming local-view baselines. These results demonstrate that incorporating panoramic spatial context improves spatial understanding and closed-loop manipulation performance in mobile robots.

## 1. 核心问题与整体含义（研究动机和背景）

移动操作（Mobile Manipulation）是具身智能的关键能力，要求机器人在开放世界中完成跨空间、多阶段、涉及基座移动与物体操作协同的复杂任务。尽管近年来 VLA（Vision-Language-Action）模型在桌面级操作中取得显著进展，但将其拓展至**轮式双臂移动机器人**时面临两个深度耦合的难题：

- **数据层面**：高效采集高质量、协调全身（基座+双臂）的演示数据极为困难。现有遥操作系统大多将移动基座与机械臂的控制解耦（如分别使用摇杆与手臂控制器），导致演示动作不连贯、采集效率低。
- **模型层面**：现有VLA策略主要依赖前视、腕部等局部相机观测，视野受限。在长时程移动操作中，基座平移/旋转、机械臂自遮挡等因素使目标物体、地标或目标区域频繁移出视野，导致机器人缺乏**以自身为中心的全局空间理解**。单纯叠加多路局部图像无法建立连贯的空间认知。全景相机虽提供360°环视信息，但其非透视投影畸变与现有视觉编码器的预训练域存在显著差异。

为此，该论文提出一个统一解决方案：开发**全身遥操作系统**以高效采集数据，并设计**全景感知VLA策略（PanoVLA）**，将机器人中心的全景空间上下文注入动作生成，系统性地提升移动操作的感知与闭环控制能力。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想

从"数据采集"和"模型架构"双端解决移动操作难题：
- **数据端**：用单一VR设备捕捉操作者稀疏人体运动，通过通用运动重定向（GMR, General Motion Retargeting）将基座建模为平面虚拟浮动基座，联合优化基座与双臂动作，实现自然、连续的全身遥操作。
- **模型端**：在 MoT（Mixture-of-Transformers）架构中新增"全景专家"（Panorama Expert），以专门的全景编码器处理全景图像，通过**KV-Cache 融合接口**将全景空间上下文与局部语义上下文共同注入动作专家。

### 2.2 技术细节

**(1) 全身遥操作系统**
- 操作者佩戴 VR 头显（6-DoF头部追踪）+ 双手柄（手部姿态与夹爪命令）+ 腰部/双踝共3个身体追踪器，实时重建 SMPL 人体状态。
- 机器人配置：RANGER MINI 3 移动基座（3-DoF平面运动）+ 两个 6-DoF Agilex PIPER 机械臂 + 平行夹爪。传感套件包含**顶部360°全景相机**、1个前视相机和2个腕部相机。
- 重定向优化目标（优化变量为机器人配置 q = (x_b, y_b, θ_b, q_L, q_R)）：

  q* = arg min_q [λ_pos L_pos + λ_rot L_rot + λ_base L_base + λ_reg L_reg]

  其中 L_pos 对齐手部与夹爪位置，L_rot 对齐手部与末端朝向，L_base 将平面基座运动耦合至操作者骨盆位移与朝向，L_reg 约束关节极限。

**(2) PanoVLA 架构**

采用三专家块设计（以 π0.5 为骨干，中间插入全景专家）：

- **VLM专家**：编码局部视图（SigLIP）、语言指令与本体感知状态，生成 VLM Cache C_vlm。
- **全景编码器**：双鱼眼图像 → 球面重投影 → ERP（等距柱状投影）图像 → MTPano 编码器（提取语义+深度分支特征并拼接）→ 轻量 Token 适配器（自适应平均池化 + MLP）→ 得到全景 Token 序列 Z_pano。
- **全景专家**：对全景 Token 与 VLM Cache 执行联合自注意力（block-wise causal mask），生成全景 Cache C_pano。
- **动作专家**：基于 C_t = [C_vlm; C_pano]（沿缓存 Token 维度拼接）预测动作块。

## 3. 实验设计：数据集、基准与对比方法

### 3.1 数据集

- 采集场景：轮式双臂机器人真实环境，4个任务 × 200条轨迹 = **800条成功演示轨迹**，总时长约**5.5小时**，以25Hz记录约**50万同步帧**。
- 每帧包含：前视与双腕部RGB局部视图、顶部360°全景（存为ERP图）、本体感知状态（双臂绝对关节位置、夹爪开合状态、基座平面位姿）、17维全身动作。
- 任务套件（空间布局多样）：**Move Pen**（将笔放入笔筒，目标在前/左/右）、**Move Block**（将积木移至前方区域，目标在左/右/双侧）、**Open Curtain**（双侧顺序拉窗帘）、**Wipe Table**（沿长桌擦除污渍并归还毛巾）。任务中相关区域无法被局部相机同时覆盖，考验跨视角空间推理与多阶段状态跟踪。

### 3.2 对比方法（消融式控制基线）

| 方法 | 全景处理方式 |
|---|---|
| π0.5 | 仅局部相机（SigLIP编码），无全景输入 |

### 3.3 评估协议

- 每任务15次闭环保真试验，单次不间断 rollout，失败阶段不手动重置。
- 指标：**端到端成功率（SR）** + **阶段完成率（SCR）**（分阶段拆解失败分析）。

## 6. 主要结论与发现

1. **全景上下文显著提升移动操作性能**：PanoVLA 平均 SCR 91.3%、SR 73.4%，对比 π0.5 基线（58.6%/30.0%）提升巨大。
2. **"如何表示"比"是否拥有全景"更重要**：三个全景变体性能差异明显（PanoVLA 73.4% > w/ Pano 56.7% > w/ Stacked Pano 38.3%）。直接将 ERP 图送入透视预训练编码器效果有限；重投影为多透视视图虽缓解域差异，但破坏跨视角连续性。
3. **全景专家利于多阶段状态跟踪**：在 Wipe Table 任务中，raw-panorama 基线末阶段仅完成26.7%导致 SR 骤降至20.0%，而 PanoVLA 末阶段完成73.3%、SR 46.7%，说明全景专家能更好地保持全局空间一致性与任务状态追踪。
4. **全景几何感知编码器（MTPano）优于通用视觉编码器（SigLIP）**（SCR 95.6% vs 75.6%），证明全景专属表示对构建机器人中心空间上下文至关重要。
5. **专家规模存在经验最优值**：100M 全景专家在有限微调数据下实现最佳均衡（再增大至200M/300M 无稳定增益，减小至50M 则能力不足）。

## 7. 优点

- **系统完整性**：从数据采集（全身遥操作）到模型设计（全景VLA）再到闭环评估，形成完整闭环，且两者互为支撑（遥操作系统产出高质量数据，PanoVLA 验证数据价值）。
- **遥操作设计创新**：将移动基座建模为虚拟浮动基座纳入全身重定向优化，消除了基座/手臂分立的控制负担；配合成本驱动的基座模式切换，实现自然流畅的全身协调演示。
- **架构设计有据可循**：KV-Cache 融合接口、block-wise causal attention、条件流匹配动作头，均建立在成熟 VLA 框架之上，工程可实现性强。
- **消融设计严谨**：通过逐步增加全景输入（无→raw→stacked→专用专家）有效隔离了"全景信息"与"全景建模方式"各自的贡献。
- **全景编码管线有物理依据**：球面重投影解决双鱼眼畸变→ERP表示保持机器人中心连续性→MTPano 的语义+深度双分支特征提供几何线索→自适应池化固定 token 数，兼顾分辨率无关性与效率。

## 8. 不足与局限

- **任务覆盖有限**：仅4类室内操作（放置、搬运、拉帘、擦桌），未涵盖更复杂的室外/非结构化场景，也未涉及物体堆叠、动态障碍规避等更具挑战的移动操作。
- **试验样本量小**：每任务15次试验难以给出统计显著的结论，个别任务的性能差异（如 Move Pen 上与 w/ Pano 持平）需更多试验确认。
- **消融实验范围窄**：专家规模与编码器选择的消融仅在 Move Pen 单任务上进行，缺乏跨任务的一致性与泛化验证。
- **数据规模仍较小**：800条、5.5小时的数据规模虽支持任务专用微调，但对通用化移动操作 VLA 而言仍显不足；且仅报告了任务内微调结果，未检验跨任务迁移能力。
- **Wipe Table 性能偏弱**：SR 仅46.7%，说明长程多阶段操作（尤其涉及大范围移动+精细擦拭+归位）仍是瓶颈，全景上下文并不能完全解决动作累积误差与空间记忆问题。
- **全景专家容量-数据匹配依赖经验调参**：100M为经验最优值，缺乏对容量与数据规模关系更系统的分析。
- **基座模式切换策略**是本工作的工程贡献，但其最优性缺乏与对比策略（如连续底盘控制器）的消融验证。

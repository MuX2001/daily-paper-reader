## 摘要
能否通过紧凑的线性状态空间表示来学习非线性动力学系统，而无需直接求解非凸的系统辨识问题？我们为此提供了一条可证明的流程。从未知非线性动力学系统的观测出发，我们首先使用观测谱滤波（OSF）学习一个隐式谱预测器，这是一种与系统最佳线性观测器竞争的可凸方法。然后，我们应用谱到LDS蒸馏将该预测器转换为显式的循环线性动力系统。我们的主要定理表明，蒸馏后的LDS的平均预测误差可分解为一个指数小的蒸馏项和一个由最佳观测器的Luenberger复杂度控制的OSF学习项。该保证是无维度的：它依赖于观测器复杂度，而非表示非线性系统所需的潜在维度。据我们所知，这产生了第一种端到端可证明的方法，通过凸学习及随后的可证明蒸馏，提取非线性动力学的事后最佳LDS表示。在线性LDS基准和MuJoCo行为克隆上的实验表明，先训练后蒸馏的流程能够产生紧凑的LDS预测器，其性能与直接训练的基线相当或更优。

## Abstract
Can nonlinear dynamical systems be learned through a compact linear state-space representation, without directly solving a non-convex system-identification problem? We give a provable pipeline for doing so. Starting from observations of an unknown nonlinear dynamical system, we first learn an implicit spectral predictor using Observation Spectral Filtering (OSF), a convex method that competes with the best linear observer for the system. We then apply spectral-to-LDS distillation to convert this predictor into an explicit recurrent linear dynamical system. Our main theorem shows that the average prediction error of the distilled LDS decomposes into an exponentially-small distillation term and the OSF learning term governed by the Luenberger complexity of the best observer. The guarantee is dimension-free: it depends on observer complexity rather than on the latent dimension needed to represent the nonlinear system. To our knowledge, this yields the first end-to-end provable method for extracting a best-in-hindsight LDS representation of nonlinear dynamics through convex learning followed by provable distillation. Experiments on linear LDS benchmarks and MuJoCo behavior cloning show that the train-then-distill pipeline produces compact LDS predictors that match or outperform directly trained baselines.

## 2. 论文提出的方法论

### 2.1 核心思想：两阶段学习（学习与表示分离）

- **第一阶段（凸学习）**：使用观察谱滤波（OSF）在固定时间特征空间中学习隐式预测器，不尝试恢复潜在状态，而是与最佳线性观测器竞争。
- **第二阶段（蒸馏）**：利用SpectraLDS将学到的谱预测器蒸馏为有限维LDS，其脉冲响应以指数级小误差逼近原预测器。

### 2.2 关键技术细节

**（1）OSF预测器形式**（隐含Luenberger观测器动机）：

$$\hat{y}^{\text{OSF}}_t = \sum_{r=1}^{n} J_r u_{t-r} + \sum_{j=1}^{k} \sigma_j^{1/4} M_j U^{(u)}_{t,j} + \sum_{r=1}^{n} P_r y_{t-r} + \sum_{j=1}^{k} \sigma_j^{1/4} N_j U^{(y)}_{t,j}$$

其中谱特征 $U^{(u)}_{t,j} = \langle \phi_j, u_{t-1:t-L} \rangle$、$U^{(y)}_{t,j} = \langle \phi_j, y_{t-1:t-L} \rangle$ 由固定的谱滤波器计算，所有可训练参数（$J, M, P, N$）在凸约束集上学习，平方损失为凸优化。Luenberger复杂度 $Q_\star = \inf_L Q(A-LC)$ 控制学习率，与潜在维度无关。

**（2）SpectraLDS蒸馏**：将学习到的谱滤波器 $\Phi_{1:k}$ 分解为 $h$ 个几何响应的线性组合 $\Phi_{1:k} \approx F \mu_L(\alpha_{1:h})$，每个几何响应由标量循环模式 $\mathbf{z}^{(s,i)}_{t+1} = \alpha_i \mathbf{z}^{(s,i)}_t + s_t$ 实现，从而将卷积特征转化为循环坐标。

**（3）算法流程（Algorithm 1）**：
1. 用OSF在轨迹 $(u_{1:T}, y_{1:T})$ 上学习读出参数；
2. 对谱滤波器应用SpectraLDS获得模式 $\alpha_1,\dots,\alpha_h$ 与混合矩阵 $F$；
3. 初始化循环状态 $z^{(u,i)}_1 = 0$、$z^{(y,i)}_1 = 0$；
4. 用近似谱特征计算预测 $\hat{y}^{\text{LDS}}_t$；
5. 更新循环状态 $z^{(u,i)}_{t+1} = \alpha_i z^{(u,i)}_t + u_t$、$z^{(y,i)}_{t+1} = \alpha_i z^{(y,i)}_t + y_t$。

### 2.4 核心理论保证（定理3.1）

取 $k = \Theta(\log^2 T)$ 个谱滤波器、$h \ge k$ 个SpectraLDS模式（且 $k \le h \le 4k$），以至少 $1-\delta$ 的概率有：

$$\frac{1}{T}\sum_{t=1}^{T} \|y_t - \hat{y}^{\text{LDS}}_t\|^2 \le \tilde{O}\left(\frac{Q_\star^2 \log(Q_\star)\log^7 T}{\sqrt{T}} + \lambda_{\max}(F)^2 \exp\left(-\frac{2k}{\log T}\right)\right)$$

误差分解为两项：
- **OSF学习项** $\tilde{O}(Q_\star^2 \log Q_\star \log^7 T / \sqrt{T})$：由最佳线性观测器的Luenberger复杂度 $Q_\star$ 控制；
- **蒸馏项** $\lambda_{\max}(F)^2 \exp(-2k/\log T)$：用循环几何响应替换谱滤波器的代价，随 $k$ 指数衰减。

**维度无关性**：保证仅依赖观测器复杂度而非表示非线性系统所需的潜在维度（或离散化格点数量 $N$），故称为维度无关。蒸馏后的LDS使用 $O((d_{\text{in}}+d_{\text{out}})(h+m))$ 内存和每步计算复杂度。

- **实验组设置**：
  1. **长记忆系统**：$d_{\text{in}}=d_{\text{out}}=16$，$d_{\text{state}}=64$，$m=512$，$\rho(A)=0.999$（脉冲响应缓慢衰减）；对比参数匹配的STU→SpectraLDS、Diagonal LDS、General LDS、Linear FIR（参数多于10倍）、STU+ONS。
  2. **短记忆与大尺度系统**：$\rho(A)=0.95$，两个规模 $(d_{\text{in}}, d_{\text{out}}, d_{\text{state}}, m) = (4,4,8,256)$ 与 $(64,64,64,512)$；对比STU→SpectraLDS、参数匹配Diagonal LDS、$h=2d_{\text{state}}$ 的Diagonal/General LDS、Linear FIR，每种含 $+y$（观测反馈）与 $-y$（仅输入）变体。

## 6. 论文的主要结论与发现

1. **可证明的两阶段蒸馏是有效的**：凸谱学习 + 结构化蒸馏，能从未知非线性动力学中提取紧凑LDS，蒸馏误差指数级小，且保证由观测器复杂度而非潜在维度控制。
2. **谱参数化优于直接训练**：在线性LDS基准上，STU→SpectraLDS以更少参数匹配或超越直接训练的LDS；在长记忆高谱半径设置中优势显著，STU+ONS（MSE ~5.7×10⁻⁷）比General LDS（~1.5×10⁻³）低约3-4个数量级；优势来自谱参数化的凸性而非更强大的模型类。
3. **蒸馏保真度极高**：蒸馏前后的预测误差相对差异在1.5%以内，蒸馏不带来有效精度损失。
4. **MuJoCo行为克隆验证了实际适用性**：STU→SpectraLDS在6个环境中4个达到最高奖励（Walker2d、Hopper、HalfCheetah、Humanoid），并在其余2个环境中接近最佳；即使面对训练-部署的分布偏移（教师强制单步预测 → 闭环滚动），该方法依然稳健。
5. **计算效率优势**：谱模型训练速度远快于General LDS（约75倍），且参数量与直接训练的LDS相当或更少，适合长时程仿真和控制。

## 7. 论文的优点

- **理论突破性**：首次给出从非线性动力学到显式LDS的端到端可证明流程，误差界维度无关，依赖Luenberger复杂度的思想新颖且实用；证明技术（三角分解 + 滤波逼近）清晰、透明，易于复用。
- **算法设计的模块化**：分离"凸学习"与"蒸馏表示"，OSF负责学习，SpectraLDS负责表示转换，两个组件可以分别改进和替换。
- **理论与实践结合良好**：既有非渐近保证，又有在LDS基准和MuJoCo行为克隆上的充分实验支撑；对比基线设计仔细（参数匹配、隐藏维度匹配、$+y/-y$ 变体），确保公平性。蒸馏保真度验证和不同STU变体的消融增加了结论的可靠性。
- **与前沿接轨**：与S4、Mamba等现代状态空间模型族的联系使方法具有实用性；理论上回避了非凸系统辨识的痛点，提供了全新的研究视角。

## 8. 不足与局限

- **理论覆盖不足**：
  - 定理3.1只控制教师强制（开环）下的平均单步预测误差，不覆盖闭环滚动误差（控制场景中误差累积的关键问题），作者也明确指出这是最自然的扩展方向。
  - 蒸馏项 $\lambda_{\max}(F)^2$ 的理论控制依赖经验观察，在过参数化情形（$h \gtrsim k$）上界由伪逆范数主导，缺乏理论上的紧致保证。
  - 依赖"可观测离散化线性提升"假设（Lipschitz与有界性），对强不连续或病态系统保证可能不适用。
- **实验局限**：
  - 未涉及更高维状态空间系统（如 $d_{\text{state}} \ge 128$）或更长的轨迹；未测试带观测噪声的系统；未与Koopman/EDMD

未与Koopman/EDMD等非线性提升/系统辨识方法进行直接基线对比；MuJoCo行为克隆中所有模型共用同一学习率，未针对各架构单独调参，可能低估部分基线性能；此外，实验未报告计算资源细节（GPU型号、能耗、内存占用），可复现性描述不完整。

总体而言，论文在主流设定（可观测、确定性、无噪声、线性或平滑非线性动力系统）下具有充分的实验支撑，但对更贴近真实部署的复杂场景（噪声、闭环、分布漂移、高维状态）覆盖不足，理论保证与实验验证之间仍存在一定缺口。

## 9. 开放问题与未来方向

1. **闭环误差的理论刻画**：当前定理仅控制开环（教师强制）单步预测误差，而控制/强化学习应用中误差会沿轨迹累积。作者明确提出将闭环滚动误差纳入理论框架是最自然的下一步，这需要处理迭代误差传播与分布偏移的耦合，可能借助收缩性或Lipschitz常数分析。
2. **蒸馏项界的技术性改进**：蒸馏误差中的 $\lambda_{\max}(F)^2$ 项依赖经验观察，在过参数化（$h \gtrsim k$）情形下上界由伪逆范数主导，尚缺紧致的理论保证。未来可通过更精细的谱不等式或随机矩阵工具给出解析上界，甚至将 $F$ 的构造改为直接可证明的算法。
3. **扩展至更一般的非线性与部分观测**：当前理论基于"离散化线性提升"（Lipschitz、有界）假设；处理强不连续系统、隐状态维度极高或观测映射非线性时，OSF的信息提取能力与蒸馏保真度均有待重新分析。
4. **鲁棒性与噪声建模**：未考虑观测噪声、过程噪声和模型失配。将噪声纳入OSF的凸学习框架（如加入协方差正则或H∞准则）并给出相应样本复杂度，是一个自然且工业相关的方向。
5. **与现代SSM / Koopman方法的系统对比**：论文仅在线性LDS与MuJoCo基准上验证，未来应在更长序列、非平稳数据和大规模预训练设定中，与S4、Mamba、深度Koopman算子等方法进行等参数量/等算力对比，以明确谱方法在实践中的真实边界。
6. **闭环控制闭环集成**：将蒸馏得到的显式LDS嵌入模型预测控制（MPC）或强化学习策略中，评估其作为"可微分物理先验"在下游任务中的价值，是理论走向应用的关键验证。

## 10. 总结与综合评价

本论文提出了一个**概念上精巧、理论上可证明、实验上有效**的两阶段框架：先在凸的谱特征空间用OSF学习隐式预测器，再通过SpectraLDS将其蒸馏为显式循环LDS，从而绕开了非线性系统辨识中根深蒂固的非凸性障碍。其核心贡献在于——**将"学习"与"表示"解耦**，使得学习阶段享有凸优化与维度无关保证，表示阶段获得可解释、可高效仿真的线性状态空间形式；这在系统辨识与序列建模的交叉处开辟了一条新路径，与Koopman理论相比免去了手工挑选可观测函数的负担，与直接端到端训练LDS相比规避了病态优化景观。

从学术价值看，论文的证明结构清晰、误差分解直观（学习项 + 蒸馏项），为后续工作提供了可复用的分析模板；实验设计在公平性（参数匹配、多种基线、消融）与真实性（MuJoCo闭环部署）之间取得了良好平衡，蒸馏保真度验证（相对误差<1.5%）和计算效率优势（比General LDS快约75倍）均具说服力。

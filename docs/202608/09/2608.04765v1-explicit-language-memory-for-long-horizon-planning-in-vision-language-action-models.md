## 摘要
视觉-语言-动作（VLA）模型为连接视觉感知、语言理解与机器人控制提供了统一范式。然而，现有VLA模型在长时程任务中仍面临重大挑战：稀疏的专家示范限制了跨任务的组合泛化；长时程任务的非马尔可夫特性使得仅以当前观测为条件的策略难以维持时间一致性；有限的闭环纠错能力导致执行误差不断累积；端到端的动作微调可能削弱视觉-语言模型（VLM）主干的高层语义表示。为解决这些问题，我们提出了一种带显式语言记忆模块的分层长时程VLA架构。其核心思想是将离散的时间观测转换为具有时序逻辑的连贯文本记忆序列。系统被解耦为高层VLM与低层VLA：高层VLM通过视觉问答训练范式进行语义推理，而低层VLA在子任务指令与视觉观测的条件下执行精确的连续控制。高层VLM以先前的记忆作为上下文锚点，递归更新语言记忆与子任务指令，从而在长时程执行过程中实现持续的时间追踪与动态修正。我们在多个仿真环境中评估了所提方法，并在真实机器人平台上进行了仿真到现实（sim-to-real）的实验。结果表明，显式语言记忆提高了VLA模型在复杂长时程任务上的成功率与鲁棒性，同时为决策过程提供了可解释的语义描述。

## Abstract
Vision-language-action (VLA) models provide a unified paradigm for connecting visual perception, language understanding, and robotic control. However, existing VLA models still face major challenges in long-horizon tasks: sparse expert demonstrations constrain cross-task compositional generalization; the non-Markovian nature of long-horizon tasks makes it difficult for policies conditioned only on current observations to maintain temporal consistency; limited closed-loop error correction allows execution errors to accumulate; and end-to-end action fine-tuning may weaken the high-level semantic representations of vision-language model (VLM) backbones. To address these issues, we propose a hierarchical long-horizon VLA architecture with an explicit language-memory module. The central idea is to convert discrete temporal observations into a coherent textual memory sequence with temporal logic. The system is decoupled into a high-level VLM and a low-level VLA: the high-level VLM performs semantic reasoning through a visual question answering training paradigm, while the low-level VLA executes precise continuous control conditioned on subtask instructions and visual observations. The high-level VLM recursively updates both language memory and subtask instructions using the previous memory as a contextual anchor, enabling persistent temporal tracking and dynamic correction during long-horizon execution. We evaluate the proposed method in multiple simulation environments and conduct sim-to-real experiments on a real robotic platform. The results demonstrate that explicit language memory improves the success rate and robustness of VLA models on complex long-horizon tasks while providing an interpretable semantic account of the decision process.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：视觉-语言-动作（VLA）模型将视觉感知、语言理解与机器人控制统一为一个策略范式，能从大规模 VLM 迁移语义知识，并用统一接口支持多任务、多本体。
- **核心问题**：尽管 VLA 模型在短期动作生成上表现良好，但在**长时程（long-horizon）多阶段任务**中存在四大关键挑战：
  1. **稀疏专家示范**限制跨任务的组合泛化能力；
  2. **非马尔可夫性**：仅依赖当前观测无法区分历史上是否已完成某个关键步骤（如抓取是否成功、按钮是否已按下），导致阶段跳过或重复执行；
  3. **闭环纠错不足**：执行误差沿动作序列累积，缺少动态修正机制；
  4. **端到端动作微调**可能削弱 VLM 骨干网络的高层语义表示。
- **整体含义**：论文主张“显式语言记忆”是解决上述问题的关键，即用自然语言文本作为可解释、有界、可递归更新的历史载体，使长时程决策具有时间一致性和纠错能力。

## 2. 方法论

- **核心思想**：提出**分层 VLM-VLA 架构**——将长时程策略分解为高层语义状态跟踪与低层连续动作生成两个解耦模块，通过显式语言记忆将时序观测转化为带时序逻辑的文本序列。
- **策略分解**（公式 1）：
  - 高层策略 `π_HL(s_t, m_t | o_t, m_{t-1}, l)`：读取全局指令、当前观测和上一时刻记忆，递归更新记忆并预测当前子任务；
  - 低层策略 `π_LL(a_{t:t+H} | o_t, s_t)`：基于观测与子任务指令，生成固定视界 H=30 的连续动作块。
- **递归语言记忆机制**（公式 2）：
  - 采用**滚动压缩规则**：子任务未完成时保留目标对象的类别、颜色、位置等细节，完成后压缩为过去式摘要，注意力转向下一子任务；

- **闭环推理流程**：内存初始化为空 → 循环执行“观测 → 更新记忆/子任务 → 生成动作块 → 执行 → 判断终止条件”。因记忆与子任务均为可见文本，可获得**可解释的决策日志**。

## 6. 主要结论与发现

- **总体有效性**：显式语言记忆在几乎所有场景中均提升了平均阶段成功率：
  - BEHAVIOR-1K 收音机：30.0% → 40.0%（`PickUp` 增益最显著：10% → 30%）；
  - Genie 单包裹分拣：41.7% → 63.9%（`Follow` 和 `PickUp-1` 翻倍，`Inside-1` 由 50% 提升至 83.3%）；
  - Genie 连续分拣：31.3% → 46.9%（基线永远无法到达第 3、4 个包裹，而记忆模型在 12.5% 的评估中完成全部 4 个）；
  - 真实 XLeRobot：62.5% → 66.3%（短任务中提升较小，符合预期）。
- **阶段一致性**：记忆显著约束阶段顺序——基线会跳过“按下按钮”或“条码扫描”而提前推进；记忆模型只在观测到完成证据后才进入下一阶段，**减少了跳过步骤**。
- **语义规划与控制能力的边界**：`PressOn` 阶段成功率仍很低（10%），说明语言记忆解决的是“做什么/在哪个阶段”的语义问题，而**不能替代接触丰富动作的低层控制精度**。
- **上下文失败恢复**：在真实机器人日志中，记忆模型在抓取失败后能记录失败状态并重新尝试（重新打开夹爪再抓），且该行为并非单独设计的恢复控制器，而是文本失败状态自然参与下一次预测的结果——即“上下文内适应”。

## 7. 优点

- **可解释性**：记忆与子任务均为自然语言文本，内部决策过程可直接检视，便于故障定位与人机交互；
- **层级解耦**：高层语义规划与低层连续控制分离，避免单目标端到端训练中的损失尺度失衡；
- **记忆设计精巧**：滚动压缩规则将记忆长度保持在有界范围内，同时保留当前与下一步所需的关键细节；
- **自动化监督**：无需昂贵的人工逐帧标注，可利用专家视频+技能时间戳自动生成对齐的训练目标；
- **泛化证据**：跨家用仿真、人形操控仿真和真实低成本的平台验证了方法的通用性；
- **诊断价值**：将失败分为“高层语义错误”与“低层控制错误”，为后续改进指明方向；
- **成本友好**：低层沿用 `π0.5` 动作专家，高层仅用 3B 的 PaliGemma 配合 LoRA，训练成本可控。

## 8. 不足与局限

- **统计验证不足**：报告未包含置信区间或随机种子变化，难以判断改进的统计显著性；
- **真实实验规模有限**：仅 25 条训练轨迹、20 条测试轨迹，任务仅 4 个阶段，未验证分钟级多对象真实任务；
- **缺少消融实验**：未系统研究不同记忆格式、更新频率、记忆长度等设计选择对性能的影响；
- **计算开销增加**：每次决策需额外调用高层 VLM，增加端到端延迟与部署复杂度，长任务实时性存疑；
- **无法纠正低层控制错误**：PressOn 成功率较低表明语义记忆不能弥补低层数据不足与控制精度缺陷；
- **失败恢复依赖示范覆盖**：当前的上下文恢复行为仅在少量场景出现，要可靠复现需收集更丰富的失败与恢复轨迹数据；
- **记忆为纯语言形式**：图像中模糊的状态（如接触是否成功、抓取是否稳定、是否发生碰撞）可能无法仅靠文本准确表达，下一步需引入多模态证据（如触觉、力反馈）。

## 摘要
视觉-语言-动作（VLA）模型在机器人操作中表现出色，但当标准指令被简单改写时，其性能会灾难性下降。尽管这种脆弱性通常通过昂贵的数据扩展来解决，但我们的探测表明，根本原因是架构性的，而不是缺乏语义理解。具体来说，我们证明当前的VLA能够在内部成功保留正确的任务身份。失败实际上源于动态视觉观测和文本的联合编码，这引入了系统性的特征偏移。由于下游动作策略对这些变化高度敏感，因此无法将保留的语义转化为正确的控制命令。为了解决这一结构性瓶颈，我们提出了语义重绑定（GSR），这是一种优雅的干预方法，通过将独立提取的任务语义与原始视觉特征显式融合，从头训练一个完全重新初始化的动作专家，从而绕过不稳定的联合路由。这种有针对性的干预仅使用标准演示就能显著恢复改写不变性。在LIBERO-Para基准上，GSR将成功率提高了高达44.6%。它使轻量级模型能够与大规模扩展的基线相媲美，并将最先进的模型推至新的记录PRIDE分数70.4，在指令生成能力上超越了最近引入的大规模预训练模型Xiaomi-Robotics-0。基于这些见解，我们还引入了ParaVLA，这是一个原生解耦的0.33B参数模型，对指令改写表现出近乎完美的鲁棒性。最终，我们的工作证明了通过优雅的结构设计可以实现鲁棒的语义基础，从而绕过低效的暴力数据扩展范式。

## Abstract
Vision-Language-Action (VLA) models excel in robotic manipulation but suffer catastrophic performance drops when canonical instructions are simply paraphrased. Although this brittleness is typically addressed through costly data scaling, our probing reveals that the root cause is architectural rather than a lack of semantic understanding. Specifically, we demonstrate that current VLAs successfully retain the correct task identity internally. The failure actually stems from the joint encoding of dynamic visual observations and text, which introduces systematic feature shifts. Because the downstream action policy is highly vulnerable to these variations, it fails to translate the preserved semantics into correct control commands. To resolve this structural bottleneck, we propose Grounded Semantic Re-binding (GSR), an elegant intervention that bypasses unstable joint routing by explicitly fusing independently extracted task semantics with native visual features to train a completely re-initialized action expert from scratch. This targeted intervention dramatically restores paraphrastic invariance using only canonical demonstrations. On the LIBERO-Para benchmark, GSR improves success rates by up to 44.6 percent. It enables lightweight models to rival massively scaled baselines and pushes state-of-the-art models to a new record PRIDE score of 70.4, outperforming the recently introduced large-scale pretrained model Xiaomi-Robotics-0 in instruction generation capabilities. Building on these insights, we also introduce ParaVLA, a natively decoupled 0.33B-parameter model exhibiting near-perfect robustness to instruction rewording. Ultimately, our work proves that robust semantic grounding can be achieved through elegant structural design, bypassing the inefficient brute-force data scaling paradigm.

## 2. 论文提出的方法论

### 核心思想：Grounded Semantic Re-binding (GSR, 语义重绑定)

- **核心逻辑**：打破语言指令与动态视觉的联合编码路径，将指令语义的提取与视觉场景的解耦，再在动作策略内部进行有控制的重新融合。

### 关键步骤

1. **独立的稳定语义提取**：使用**冻结的T5-large编码器**独立编码真实任务指令，输出纯任务语义（不接收图像和机器人状态），确保语义特征在等价改写下保持稳定。
2. **架构感知的注入点设计**（架构自适应）：
   - 识别各模型的核心多模态融合阶段，将投影后的T5语义直接注入该阶段，使语义与视觉、状态在既有计算管线内深度交互。
   - **VLA-Adapter**：T5特征作为Bridge-Attention策略每个块中的sidecar K/V源，动作头从随机初始化训练。
   - **SmolVLA**：将T5特征投影后注入SmolVLM原生的语言输入槽位，通过8头接地注意力（grounding attention）与视觉深度融合后再送入flow-matching专家。
   - **π0.5**：T5特征作为补充语义，在动态检测的PaliGemma任务token位置注入。
3. **原生语言路径的处置策略**：
   - 若原生语言路径对改写脆弱（如VLA-Adapter、SmolVLA），将其文本输入替换为固定中性语句"perform the task"，使模型完全依赖T5语义。
   - 若原生路径本身已可靠（如π0.5），保留真实指令作为主控，T5作为补充语义源。
4. **重新初始化动作专家**：完全绕开原有缺陷机制，从头训练动作策略，使其从训练伊始就学习如何联合利用T5语义、视觉特征和机器人状态。

### 额外贡献：ParaVLA

- 一个**原生解耦的0.33B参数模型**：使用冻结T5提取语言语义、DINOv2-Large提取视觉特征，二者只在最终的flow-matching动作专家内部通过独立注意力计算实现融合，取消了联合视觉-语言编码。T5语义每任务缓存一次，不增加逐控制步推理成本。

## 6. 论文的主要结论与发现

1. **VLA的指令泛化失败源于架构翻译缺陷而非语义理解**：模型内部保留了正确任务身份，但联合编码引入的特征偏移使下游动作策略失效。
2. **GSR仅用规范演示即显著恢复释义不变性**：VLA-Adapter从46.82%→70.94%（提44.6%），SmolVLA从4.47%→49.12%，π0.5从73.60%→75.59%。
3. **GSR的收益是正交于数据规模的**：轻量模型（0.51B的VLA-Adapter）可媲美大规模基线；π0.5在扩展训练后达到96.0%规范成功率，并创下70.4的PRIDE纪录，超越Xiaomi-Robotics-0（69.2）。
4. **单一架构修补必然失败**：不同模型的任务信息流分布不同——VLA-Adapter存在严格的最终块瓶颈（单层patch恢复96.8%），SmolVLA和π0.5的任务语义是跨层分布的（最大单层恢复仅10.5%和31.3%）。
5. **不可靠的原生编码器会劫持控制权**：VLA-Adapter喂给原生Qwen错误指令时成功率跌至5.11%，证明必须中和脆弱原生路径；π0.5的PaliGemma本身可靠则保留。
6. **原生解耦设计（ParaVLA）可实现近乎完美的改写鲁棒性**：0.33B参数下规范92.0%、改写91.0%，但面临视觉骨干扩展性瓶颈。
7. **通用设计准则**：语言指令必须独立于动态图像编码为纯粹的稳定任务语义，再注入模型原有融合管线与视觉场景深度交互。

## 7. 优点

- **因果层面的诊断严谨性**：不仅观测到失效现象，还通过特征替换、方向删除、层级patch等干预手段在因果层面精确定位故障节点（最终Bridge-Attention块），推理链条完整清晰。
- **结构优雅、数据高效**：不使用任何释义训练数据，仅靠规范演示和结构重设计解决泛化问题；T5语义可缓存，无逐步额外推理开销，直接挑战"数据暴力扩展"的主流范式。
- **架构自适应的通用方法论**：GSR不是固定补丁，而是提供了一套"评估原生路径可靠性→选择注入点→决定中和与否"的普适准则，可在三种结构显著不同的模型上统一验证。
- **轻量模型可达大规模模型性能**：VLA-Adapter+GSR逼近π0.5报告水平，为资源受限场景提供实际路径。
- **透明度和完备性**：详细报告了训练配置、配对协议、统计方法、失败的消融方向（额外参数无效果、随机方向无效果等）。

## 8. 不足与局限

- **解耦结构的扩展性瓶颈**：ParaVLA在升级更大视觉骨干（如DINOv2更大变体）时未能展现VLM式的规模效应，限制了该纯解耦路线的长期发展潜力（作者明确承认）。
- **真机验证规模有限**：真机仅4个拾取+2个堆叠任务，部分任务（3、5、6）成功率为0%，未分析失败原因；采样频率（1Hz）远低于实用要求，泛化结论外推需谨慎。
- **π0.5的规范性能暂时下降**：匹配训练步数下规范Goal SR从93%降至91%（需双倍训练量恢复至96%），说明GSR对大规模动作专家并非零成本干预。
- **缺乏与数据增强方法的系统对比**：未在同算力预算下直接对比指令改写数据扩展、一致性训练等替代方案，部分削弱了"结构优于数据"的因果关系强度。
- **固定评价协议依赖**：PRIDE指标的权重（α=0.5）和故障子集（"任务不足"与"任务混淆"）的区分能力受限；对长尾指令、多语言、干扰上下文等更丰富变体未评估。
- **语言来源的通用性**：T5-large虽在实验中表现优越，但未系统探究其与所用语言类型（如口语化、非英文）的适配边界；对π0.5仅作补充而非主控，其机制尚未完全解析。

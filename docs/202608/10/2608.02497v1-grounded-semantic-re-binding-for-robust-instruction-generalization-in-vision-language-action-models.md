## 摘要
视觉-语言-动作（VLA）模型在机器人操作中表现出色，但当规范指令被简单改写时，其性能会急剧下降。尽管这种脆弱性通常通过昂贵的数据扩展来解决，但我们的探测揭示，根本原因在于架构而非缺乏语义理解。具体而言，我们证明当前VLA模型内部能够成功保留正确的任务身份。失败实际上源于动态视觉观测与文本的联合编码，这引入了系统性的特征偏移。由于下游动作策略对这些变化高度敏感，它无法将保留的语义转化为正确的控制命令。为解决这一结构性瓶颈，我们提出了一种优雅的干预方法——基于语义重绑定（GSR），它通过将独立提取的任务语义与原生视觉特征显式融合，从零开始训练一个完全重新初始化的动作专家，从而绕过不稳定的联合路由。这种有针对性的干预仅使用规范示范即可显著恢复改写不变性。在LIBERO-Para基准上，GSR将成功率提升了高达44.6个百分点。它使轻量级模型能够与大规模基线相媲美，并将最先进模型的PRIDE分数推至新纪录70.4，在指令生成能力上超越了最近推出的大规模预训练模型Xiaomi-Robotics-0。基于这些见解，我们还引入了ParaVLA，一个原生解耦的0.33B参数模型，对指令改写表现出近乎完美的鲁棒性。最终，我们的工作证明，通过优雅的结构设计即可实现鲁棒的语义基础，从而绕过低效的暴力数据扩展范式。

## Abstract
Vision-Language-Action (VLA) models excel in robotic manipulation but suffer catastrophic performance drops when canonical instructions are simply paraphrased. Although this brittleness is typically addressed through costly data scaling, our probing reveals that the root cause is architectural rather than a lack of semantic understanding. Specifically, we demonstrate that current VLAs successfully retain the correct task identity internally. The failure actually stems from the joint encoding of dynamic visual observations and text, which introduces systematic feature shifts. Because the downstream action policy is highly vulnerable to these variations, it fails to translate the preserved semantics into correct control commands. To resolve this structural bottleneck, we propose Grounded Semantic Re-binding (GSR), an elegant intervention that bypasses unstable joint routing by explicitly fusing independently extracted task semantics with native visual features to train a completely re-initialized action expert from scratch. This targeted intervention dramatically restores paraphrastic invariance using only canonical demonstrations. On the LIBERO-Para benchmark, GSR improves success rates by up to 44.6 percent. It enables lightweight models to rival massively scaled baselines and pushes state-of-the-art models to a new record PRIDE score of 70.4, outperforming the recently introduced large-scale pretrained model Xiaomi-Robotics-0 in instruction generation capabilities. Building on these insights, we also introduce ParaVLA, a natively decoupled 0.33B-parameter model exhibiting near-perfect robustness to instruction rewording. Ultimately, our work proves that robust semantic grounding can be achieved through elegant structural design, bypassing the inefficient brute-force data scaling paradigm.

- **整体意义**：该研究表明，**优雅的结构设计可以替代暴力数据扩展**来实现鲁棒的语义指令泛化，为 VLA 模型的架构设计提供了新的方向，同时对轻量级模型的落地应用具有重要价值——无需海量多语言数据即可获得与大规模预训练模型相当的指令泛化能力。

### 2. 方法论：Grounded Semantic Re-binding (GSR)

- **核心思想**：GSR 通过将“任务语义提取”与“视觉场景理解”解耦，并重新学习二者到动作的映射，从而绕过 VLA 架构中不稳定的联合语言-视觉编码路径。其核心原则是：
  1. 使用**独立的语义编码器**（冻结的 T5-large）提取任务语义，该编码器不接收任何图像或机器人状态输入，以保证语义特征的纯粹性和稳定性；
  2. 将提取的语义特征注入**模型原生的多模态融合计算管道**中，使之与视觉和状态信息深度交互；
  3. **重新初始化动作专家网络**进行从零训练，而不是在原有权重上微调，从而避免保留旧的、有缺陷的语言-动作映射。

- **关键技术细节**：

  - **语义稳定来源**：使用冻结的 T5-large 编码器。T5 仅接收原始任务指令，不接收任何视觉或状态信息，从而保证输出特征不受观测变化影响。T5 参数全程冻结，只有投影层和动作策略参与训练。

  - **中性化原生指令**：对于原生语言路径不可靠的模型（如 VLA-Adapter 和 SmolVLA），将输入 VLM 的指令替换为固定中性句“perform the task”，强迫模型完全依赖 T5 语义；对于原生路径已足够鲁棒的模型（如 π0.5），保留真实指令，T5 仅作为补充语义源。

  - **架构感知的注入策略**：GSR 根据模型的具体架构决定注入时机与方式：
    - **VLA-Adapter**：Qwen 主干与 Bridge-Attention 策略分离。T5 特征通过投影映射为 sidecar K/V 源，直接注入每一个动作块中，与视觉特征在动作策略内部独立融合。
    - **SmolVLA**：T5 特征被投影后通过 8 头 grounding attention 注入 SmolVLM 的原生语言 token 槽位，随后继续通过 VLM 原生多模态计算，实现早期深层次的视觉-语义融合。公式为：$`\tilde{h}_{task} = h_{native-task} + g \cdot \text{MHA}(\text{LN}(h_{native-task}), \text{LN}(P_{T5}), \text{LN}(P_{T5}))`$
    - **π0.5**：与 SmolVLA 类似，在动态检测到的 PaliGemma 任务 token 位置注入 T5 特征，同时保留真实的原生指令输入。

- **ParaVLA（原生解耦架构）**：进一步验证解耦理念的可行性。该模型使用冻结的 T5 编码语言（任务级缓存，无逐步推理开销）和 DINOv2 编码视觉，两者仅在最终的动作专家（flow-matching）中通过分离的注意力机制融合。仅 0.33B 参数，在规范与改写指令间的性能差距极小。

### 6. 主要结论与发现

1. **VLA 模型在改写指令下的失败源于架构而非语义理解**：三款模型都能在内部保留任务身份信息，但下游动作策略无法正确利用。

2. **联合 V-L 编码是特征不稳定的根源**：无论是动态视觉输入还是措辞变化，都会在联合编码中引入系统性的、可分离的特征偏移，且这些偏移会显著改变最终动作。

3. **GSR 能有效修复这一结构性缺陷**：
   - VLA-Adapter：Full Para 成功率从 46.82% → 70.94%（+24.12 点；在 Goal-100 诊断上 +14.76 点）；
   - SmolVLA：从 4.47% → 49.12%（+44.65 点）；
   - π0.5：从 73.60% → 75.59%（+1.99 点），PRIDE 达 **70.4**，创下最高纪录，超越 Xiaomi-Robotics-0 的 69.2。

4. **不同模型的任务信息流动方式存在本质差异**：VLA-Adapter 存在单一瓶颈（最后一个 Bridge-Attention block 恢复 96.8% 的动作差异），而 SmolVLA 和 π0.5 则呈现分布式语义处理，因此需要架构感知的注入策略。

5. **原生语言路径的可靠性决定了处理策略**：当原生编码器不可靠时，它会“劫持”控制，必须中性化；当原生编码器已可靠时，应保留并加入 T5 作为补充。

6. **原生解耦架构（ParaVLA）可行且鲁棒**：0.33B 参数下规范/改写成功率分别为 92.0%/91.0%，差距仅 1 点，但其缩放能力存在瓶颈。

### 7. 优点

- **问题定位精准**：通过严谨的探测-干预框架（替换特征、控制图像、方向移除）因果性地证明根因在于架构而非语义理解，而非停留在现象表面。
- **方法论简洁有效**：GSR 的设计原理简单清晰（解耦语义提取 + 重新学习动作映射），不需要额外数据标注，仅使用规范示范即可大幅恢复改写鲁棒性。
- **架构感知、适用范围广**：不是固定的结构补丁，而是提供了一个通用原则——根据模型的信息流特征调整注入位置与策略，在 3 种不同架构上都验证有效。
- **实验结果扎实**：数据集覆盖模拟与真实机器人，实验数量充足，统计检验严谨，消融设计合理，诚实报告了模型的轻微副作用（如 π0.5 的规范性能暂时下降）。
- **提出了新架构范式**：ParaVLA 证明了这一设计理念的极端版本（完全解耦）同样可行，为后续研究提供了新方向。
- **轻量级模型的突破**：使 0.51B 的 VLA-Adapter 在指令泛化上媲美大规模预训练模型，具有重要的实际部署意义。

### 8. 不足与局限

- **真实机器人实验规模较小**：仅 6 个任务、5 次重复/条件，且其中 3 个任务（拾取右方 cube、两个堆叠任务）在所有条件下成功率均为 0%，说明 GSR 在真实复杂操作上仍有明显不足，结论的泛化性需要更大规模的实物验证。
- **π0.5 的改进幅度有限**：在 π0.5 上全 Para 成功率仅提升约 2 个百分点（73.60% → 75.59%），且规范指令成功率在标准训练下反而下降（93% → 91%），需要延长训练才能恢复——相较轻量级模型提升幅度并不显著。这引发了“GSR 对大规模强模型的实际增量价值”和“是否值得额外的架构复杂性和训练时长”的思考。
- **数据分布局限**：实验集中于 LIBERO 套件，任务类型、指令改写的风格和复杂度有限；对更开放、更真实世界的指令多样性覆盖不足。
- **解耦架构的缩放瓶颈**：论文承认 ParaVLA 的纯解耦范式在扩大视觉骨干模型规模时无法展现 VLM 级别的扩展能力，这是该方向的关键挑战。
- **依赖外部语义编码器**：GSR 依赖 T5-large 作为稳定语义源，T5 本身的语义覆盖范围和质量会直接影响最终效果。
- **效率与复杂性权衡**：GSR 需要对不同架构分别设计注入方式，且重新初始化动作专家需要额外的训练步骤，工程实现不如统一微调简单。对于已经大规模预训练且语言路径本就鲁棒的模型，是否值得引入 GSR 值得商榷。
- **对“语义保留”证据的间接性**：虽然探测与干预实验强有力地支持核心论点，但这些模拟条件下的分析是否完全代表真实执行环境中的失败模式，仍有待讨论。

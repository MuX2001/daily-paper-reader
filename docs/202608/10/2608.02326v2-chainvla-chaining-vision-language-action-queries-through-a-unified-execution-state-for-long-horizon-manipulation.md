## 摘要
人类通过保留先前动作所建立的知识，同时持续调整正在进行的动作，来执行长时程操作。相比之下，动作分块视觉-语言-动作（VLA）策略在每次查询时都从当前输入重复规划。现有方法要么通过记忆保留长期任务证据，要么通过动作重用和集成保留短期运动，导致跨查询交接不完整。我们引入了ChainVLA，一个12亿参数的VLA策略，通过联合且可修订的执行状态链接连续查询。进度上下文结合循环工作状态与稀疏事件记忆，以携带源自观测的任务进度，而运动尾部将先前预测的未执行延续部分馈送到状态构建和动作生成中。这两个组件共同调节一个解码器，使其在最新观测下重新生成每个动作视野，允许携带的状态指导下一次预测而不固定它。ChainVLA在RMBench上达到62.8%的平均成功率，在四个LIBERO套件上达到98.8%，而移除运动尾部或进度上下文分别将RMBench成功率降至11.2%和3.0%。这些不对称消融与运动连续性有助于保留推断任务进度所需的观测流这一观点一致。

## Abstract
Humans perform long-horizon manipulation by retaining knowledge of what earlier actions have established while continuously adapting the motion underway. By contrast, action-chunked vision-language-action (VLA) policies repeatedly replan from the current input at each query. Existing methods preserve either long-term task evidence through memory or short-term motion through action reuse and ensembling, leaving the cross-query handoff incomplete. We introduce ChainVLA, a 1.2B-parameter VLA policy that chains successive queries through a joint and revisable execution state. Progress Context combines a recurrent Working State with sparse event memory to carry observation-derived task progress, while Motion Tail feeds the preceding prediction's unexecuted continuation into state construction and action generation. Together, the two components condition a decoder that regenerates each action horizon under the latest observation, allowing the carried state to guide the next prediction without fixing it. ChainVLA reaches 62.8% average success on RMBench and 98.8% across four LIBERO suites, while removing Motion Tail or Progress Context reduces RMBench success to 11.2% and 3.0%, respectively. These asymmetric ablations are consistent with motion continuity helping preserve the observation stream from which task progress is inferred.

## ChainVLA 论文详细总结

### 1. 论文的核心问题与整体含义

**研究动机与背景**：
- 长时程操作要求机器人既要记住此前动作已建立的任务进度，又要持续调整当前运动。人类通过保留两种信息实现该能力：**已建立的任务进度**（task progress）和**进行中的运动延续**（motion continuation）。
- 现有动作分块 VLA 策略存在根本缺陷：每个查询（query）都从当前观测重新规划，**缺乏跨查询的显式交接**。具体表现为两个层面：
  - **任务层面**：早期任务证据可能已不在当前视野中（如 RMBench 的 Put Back Block 任务，相同观测可能对应不同历史），导致新查询无法做出正确决策。
  - **运动层面**：重新规划丢弃了前一预测的未执行后缀，新旧命令在边界可能不一致，产生突兀运动切换。
- 现有两条解决路线各有局限：
  - **记忆增强策略**（如 MemoryVLA）：只保留观测派生信息，不携带预测侧未执行延续。
  - **时间集成/实时执行/原生延续**（如 Temporal Ensemble、Real-Time Execution）：保留局部运动连续性，但丢失早期任务证据。
- 核心研究问题：**如何在保持对新观测响应性的同时，跨查询链接任务进度与运动延续？**

### 2. 论文提出的方法论

**核心思想**：
ChainVLA（12 亿参数）通过一个**联合且可修订（joint and revisable）的执行状态**链接连续查询。状态分为两个互补组件，每次查询时被读取、更新并向前传递，将独立解码的动作块转化为跨查询链。

**关键技术细节（按组件分述）**：

- **进度上下文（Progress Context）**：
  - 由两子组件融合构成：**循环工作状态（Recurrent Working State）** + **稀疏事件记忆（Sparse Event Memory）**。
  - **工作状态**：8 个学习查询与当前多模态 tokens 交叉注意力，结合前一时刻的 live tokens 与条件向量完成循环更新；维持 3 槽有界 FIFO 缓存，存最近 24 个 live tokens；每次查询产生池化摘要用于事件检索。
  - **稀疏事件记忆**：存储最多 16 条记录（锚点 + 最近写入，超限驱逐最旧非锚点），每条含 64 个视觉 token、8 个 Stage Info token、8 个时间 token、检索键与写入索引；带任务阶段标注的数据用阶段转移触发写入，无标注数据按周期（每 3 查询）写入；检索使用**年龄感知的余弦相似度**，并保留首个事件作为锚点。

- **运动尾部（Motion Tail）**：
  - 保留前一预测的未执行后缀（30 步视野中末 6 步），作为**延续先验**通过两条路线影响下一查询：
    1. **Tail Tokens** 条件化工作状态构建；
    2. **Tail对齐的轨迹初始化**（加噪声的初始化状态）配合条件流解码器重新生成完整视野。
  - 解码器在每个位置都基于最新观测重新生成，不复制也不冻结任何位置——**携带状态是"可修订先验"而非固定计划**。

**执行状态过渡公式**：
- 查询过渡：`(Ak, Wk, Ck+1) = Fθ(xk, Dk, Wk−1, Ck, uk)`，其中 `uk+1 = Tail(Ak)`。
- 训练时使用有序查询展开，检测到的后缀在条件化下一查询前被分离；重叠一致性正则化器（权重 0.2）惩罚连续预测视界的对齐重叠分歧。

### 6. 论文的主要结论与发现

1. **跨查询链式状态显著提升长时程操作性能**：RMBench 达 62.8%（远超带完整覆盖的最强对照 Mem-0 的 52.8%，且后者参数规模达 8B+2B），LIBERO 四套件平均 98.8%。
2. **两个状态组件不可或缺且互补**：单独移除任一组件都近乎摧毁性能——移除 Motion Tail 降至 11.2%，移除 Progress Context 降至 3.0%，两组件都移除仅 1.6%。两者单数字到低两位数的贡献无法线性相加到 62.8%。
3. **关键发现：运动连续性支撑任务进度推断（而非独立并行能力）**。移除运动连续性后，命令边界不一致（位置 CD 从 0.66→17.32 mm），位移使手臂偏离演示视点序列，从而破坏进度上下文赖以构建的观测流。该不对称性表明两者是**顺次联动**而非平行独立。
4. **平滑不是充分条件**：Linear Continuation 和 Temporal Ensembling 在边界指标上更好但成功率极低（0–2% vs 96%），说明携带状态进行"解码前"条件化不可替代"解码后"平滑。
5. **任务进度对历史证据的依赖具有任务特异性**：Put Back Block（关键证据最早离视野）对 Event Readout 的依赖最重（96→25）。
6. **固定周期写入事件足以接近完整性能**（53.4 vs 62.8），链式状态不依赖阶段标注。

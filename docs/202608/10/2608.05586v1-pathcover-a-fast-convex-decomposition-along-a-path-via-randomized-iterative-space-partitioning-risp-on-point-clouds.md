## 摘要
自主机器人导航需要快速生成无障碍区域以进行轨迹规划。然而，现有的走廊生成器难以满足实时、传感器速率的计算约束。为解决这一瓶颈，我们引入了PathCover，一个由RISP驱动的框架；RISP是一种新颖的随机算法，能在温和的概率消除条件下，以期望线性时间直接从原始点云数据构建凸多面体。PathCover生成一系列重叠、无障碍的凸多面体，安全地约束下游的模型预测控制（MPC）和轨迹优化。我们从数学上保证算法在有限步骤内终止，同时确保沿任意无障碍参考路径持续前进。在合成和真实LiDAR数据集上的广泛基准测试表明，与最先进方法相比，速度提升了一个数量级，同时保持了相当的走廊体积。完整的流程通过高保真四旋翼仿真和物理部署在四足机器人上得到验证，该机器人在受限环境中使用实时LiDAR感知进行导航。

## Abstract
Autonomous robot navigation requires the rapid generation of obstacle-free regions for trajectory planning. However, existing corridor generators struggle to meet real-time, sensor-rate computational constraints. To resolve this bottleneck, we introduce PathCover, a framework driven by RISP; a novel randomized algorithm that constructs convex polytopes directly from raw point cloud data in expected linear time under a mild probabilistic elimination condition. PathCover generates sequences of overlapping, obstacle-free polytopes that safely constrain downstream MPC and trajectory optimization. We mathematically guarantee that the algorithm terminates in finite steps while ensuring continuous progress along any obstacle-free reference path. Extensive benchmarks on synthetic and real-world LiDAR datasets demonstrate an order-of-magnitude speedup over state-of-the-art methods while maintaining comparable corridor volumes. The complete pipeline is validated via high-fidelity quadrotor simulations and physical deployment on a quadrupedal robot navigating constrained environments using live LiDAR perception.

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- **直接点云处理**：不进行体素化或地图膨胀，直接把障碍物边界点集作为输入。
- **随机分离超平面构造**：每次迭代随机采样一个障碍点，构造一个位于种子点与采样点之间的超平面，该超平面严格分离采样点并剔除位于种子点对侧的所有障碍点。
- **几何加速**：对 LiDAR/深度相机产生的结构化点云（局部共面密集簇），一次随机采样往往能剔除一大片点，使剩余点数呈几何级数衰减，从而获得期望线性时间。

### 2.2 关键公式与算法流程
- **问题定义**：工作空间 \(W \subset \mathbb{R}^d\)，障碍物 \(O\)，自由空间 \(F = W \setminus O\)，点云 \(P = \{p_i\} \subset \partial O\)，路径 \(\Pi = \{y_0,\dots,y_L\}\)。
- **路径覆盖条件（PCC）**：
  1. 每个多面体与点云 P 严格分离；
  2. 相邻多面体有交集；
  3. 参考路径被所有多面体的并集覆盖。

- **RISP 算法（Algorithm 2）**：
  1. 输入种子点 \(y_{\text{seed}}\)、点云 P、参数 \(\alpha \in (0,1)\)；
  2. 循环直到 P 为空：
     - 均匀随机采样点 \(p\)；
     - 计算分离向量 \(a = p - y_{\text{seed}}\)，标量 \(b = a^\top y_{\text{seed}} + (1-\alpha)\|a\|_2^2\)；
     - 构建超平面 \(h = \{x \mid a^\top x = b\}\)，该平面与 \(a\) 垂直，过点 \(\alpha y_{\text{seed}} + (1-\alpha)p\)，并保证种子点侧的开球 \(B\big(y_{\text{seed}}, (1-\alpha)\|a\|_2\big)\) 全部位于内侧半空间；
     - 剔除所有满足 \(a^\top q > b\) 的点 q；
     - 将半空间约束 \((a,b)\) 加入集合；
  3. 追加工作空间边界约束；
  4. 用对偶空间 + Quickhull 去除冗余超平面；
  5. 返回凸多面体 H。
- **PathCover 算法（Algorithm 1）**：
  1. 在起点 \(y_0\) 调用 RISP 生成第一个多面体；
  2. 沿参考路径逐点检查当前多面体是否包含当前路点；
  3. 若路点未被覆盖，计算当前多面体边界与路径线段（从最近已覆盖点到当前路点）的**交点**作为新种子；
  4. 在新种子处调用 RISP 生成下一个多面体，加入走廊列表；
  5. 重复直至终点被覆盖或达到最大迭代数。

### 2.3 理论性质
- **完全性（Theorem 1）**：在障碍物闭、工作空间有界多面体、路径相邻点连线在自由空间内部等假设下，PathCover 有限步终止，并满足 PCC 条件。每个新多面体沿路径至少推进距离 \(\delta_{\min} = (1-\alpha)\epsilon_\Gamma\)，因此总多面体数 \(J \le \sum_{\ell} \lceil \|y_\ell - y_{\ell-1}\|_2 / \delta_{\min}\rceil\)。
- **复杂度（Theorem 2）**：若存在常数 \(\beta \in (0,1)\)、\(r\in(0,1]\)，使每次迭代至少以概率 \(r\) 剔除 \(\beta\) 比例的点，则 RISP 期望时间 O(n)，最坏 O(n²)。最坏情形只出现在每步仅剔除采样点本身的病态布局中，真实点云几乎不出现。
- **PathCover 复杂度（Theorem 3）**：期望 O((J+L)n)，最坏 O(Jn²+Ln)。

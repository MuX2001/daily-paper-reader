## 摘要
视觉-语言-动作（VLA）模型在具身智能领域展示了卓越的能力，但其高计算成本和有限的预测动作长度阻碍了实时部署。尽管专为高效具身智能设计的加速器Dadu-Corki已被提出，但它未利用机器人与环境之间的固有交互模式，导致预测动作长度相对较短。我们观察到，机器人环境自然地在主动状态（精确动作至关重要）与惰性状态（动作对任务成功影响有限）之间交替。这一洞见带来了新的调度机会：在惰性状态下进行长动作长度的投机预测，并在主动状态下进行选择性验证。我们提出SpecVLA，一种算法-系统协同设计框架，自适应地平衡动作长度、推理延迟和任务可靠性。在算法方面，SpecVLA引入了状态感知的VLA推理执行范式，以及通过差分残差和块级混合精度量化构建硬件友好的小型验证模型（sVLA）。在系统方面，我们开发了一种由GPU和机器人专用硬件模块组成的异构架构，以及一种通过并行执行解耦VLA和sVLA的投机数据流。在LIBERO和ManiSkill基准上对OpenVLA和RDT的全面评估表明，SpecVLA在保持任务成功率的同时显著降低了端到端延迟。通过实现长动作长度的投机预测与及时验证，SpecVLA实现了高效且可靠的高实时性机器人操作。

## Abstract
Vision-Language-Action (VLA) models have demonstrated remarkable capabilities in the field of embodied AI, but their high computational cost and limited predicted action length hinder real-time deployment. Although Dadu-Corki, a dedicated accelerator for efficient embodied AI, has been introduced, it does not exploit the inherent interaction patterns between the robot and its environment, which results in a relatively short predicted action length. We observe that robotic environments naturally alternate between active states-where precise actions are crucial-and inactive states-where actions have limited impact on task success. This insight enables a new scheduling opportunity: long-action-length speculative prediction in inactive states, paired with selective verification in active states.   We propose SpecVLA, an algorithm-system co-design framework that adaptively balances action length, inference latency, and task reliability. On the algorithm side, SpecVLA introduces a state-aware VLA inference execution paradigm and a hardware-friendly construction of a smaller verification model (sVLA) using differential residuals and block-wise mixed-precision quantization. On the system side, we develop a heterogeneous architecture consisting of a GPU and a robotic-specific hardware module, along with a speculative dataflow that decouples VLA and sVLA through parallel execution. Comprehensive evaluations on OpenVLA and RDT across LIBERO and ManiSkill benchmarks show that SpecVLA reduces end-to-end latency significantly while preserving task success rate. By enabling long-action-length speculative prediction with timely verification, SpecVLA achieves real-time robotic manipulation with both high efficiency and reliability.

### 一、核心问题与整体含义（研究动机与背景）

- **问题背景**：视觉-语言-动作（VLA）模型在具身智能领域展现出强大的理解和泛化能力，但其单次推理延迟通常超过 600ms，远不能满足实时控制系统的需求（如建筑施工机器人等场景）。
- **已有方案的不足**：现有专用加速器 Dadu-Corki 虽通过异构系统（GPU 服务器 + FPGA）降低了通信和推理延迟，但未利用机器人-环境交互中帧序列的连续性，单次推理只能预测 <4 个动作，性能潜力未充分释放。
- **核心观察**：
  1. 机器人的动作执行天然分为**主动状态**（如对准、抓取、放置，动作对成败影响大）和**惰性状态**（如移动机械臂至目标位姿，中间动作对最终结果影响有限）——这为自适应预测提供了机会；
  2. 连续环境帧之间存在**高度时间冗余**，因此一个量化的小型 VLA 变体（sVLA）仍能产生质量较高的动作预测，但 sVLA 在长序列预测上精度会明显下降（动作长度 >2 时成功率平均下降 9%）；
  3. 云平台天然具备异构资源（GPU + NPU），可并行化 VLA 与 sVLA 的执行。

### 二、提出的方法论

#### 2.1 核心思想：状态感知的投机执行范式

- 在**惰性状态**下，由完整 VLA 推测生成**长动作序列**（如 8 个动作/次），摊薄 VLA 推理开销；
- 在**主动状态**下，用轻量 sVLA 模型对逐个动作进行**验证**；若验证失败则立即回滚并重新调用 VLA 生成新动作序列；
- 通过状态预测 + 投机预测 + 验证的协同机制，自适应地最大化有效预测长度，同时维持任务成功率。

#### 2.2 关键技术细节

**（1）环境状态预测（Algorithm 1）**
- 计算机器人手臂与环境中各物体的欧氏距离：$D_i = \sqrt{\sum_{k=1}^{3}(G_c[k] - O_i^c[k])^2}$；
- 将距离与阈值 $T_d$ 比较，并结合机械臂开合状态判断当前处于主动状态还是惰性状态。

**（2）动作验证**
- 对预测动作 $A$ 与 sVLA 生成的期望动作 $A'$ 计算**加权 L1 距离**；先对每个动作维度做 min-max 归一化，再按各维度标准差的倒数加权；
- 距离小于阈值 $T_s$ 则接受该预测动作，否则拒绝并触发 VLA 重新推理。

**（3）sVLA 的构建：差分残差 + 块级混合精度量化**
- 利用帧间特征的**残差分布更窄**的特性（图 3），将当前输入特征与前帧特征相减，得到残差特征 $\Delta X_i = X_i - X_{i-1}$；
- 将残差矩阵划分为固定大小的块，按块内绝对值和与阈值 $T_z$、$T_h$ 的比较结果，将块量化为 0-bit（置零）、4-bit（低精度）或 8-bit（高精度），并拆分高低比特分量以统一硬件数据通路，避免复杂控制逻辑。

#### 2.3 系统软硬件协同设计

- **异构架构**：GPU 负责全精度 VLA 推理；机器人专用硬件模块（含 SIMD PE 阵列、状态预测器、预处理模块）负责 sVLA 推理、状态预测和动作验证；
- **投机数据流**：解耦 VLA 与 sVLA 的数据依赖——VLA 推断不等待验证结果即可投机执行下一条动作序列，通过并行化隐藏对方延迟；验证失败时通过补偿反向运动进行回滚恢复。

## 摘要
视觉-语言-动作（VLA）模型近期在机器人操作中取得了有前景的性能。然而，现有基准主要评估静态操作任务上的泛化能力，而很大程度上忽略了动态交互场景。为弥补这一空白，我们提出了ReflexBench，一个面向反应关键型操作的基准。ReflexBench包含六个动态任务，并引入了一个评估框架，该框架将模拟器步进与机器人控制解耦，同时支持同步和异步推理下的可配置延迟。基于ReflexBench，我们提出了ReflexVLA，一个为反应关键型操作设计的高效VLA模型，无需大规模机器人数据预训练。ReflexVLA通过潜在未来预测和视觉主干内的多帧时间融合增强了时间推理，同时通过批量视觉编码和CUDA图重放降低了部署延迟。实验表明，ReflexVLA在保持标准静态操作基准上具有竞争力的准确性的同时，持续提升了动态操作性能，真实世界实验进一步证明了其在实际部署条件下的有效性。项目网站：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. Project website: https://reflexvla.github.io

## 2.1 ReflexBench——延迟感知基准

### 任务集（6个动态操作任务）

| 任务 | 核心挑战 |
|------|----------|
| 传送带抓取放置 | 动态追踪移动物体并避开干扰物 |
| 接球 | 快速响应轨迹急剧变化的目标 |
| 打地鼠 | 在有限时间内到达随机出现的目标位置 |
| 滚动球拦截 | 预测球的滚动轨迹并在边缘拦截 |
| 抛球入筐 | 精准预测投掷时机与力度 |
| 旋转插销插入 | 与连续旋转的插座实现时间对齐 |

### 数据收集方式

- 动态任务的专家示教收集比静态任务困难得多，作者采用**基于规划的数据收集流水线**：将每项任务分解为带不同子目标的多个顺序阶段（如旋转插销分为预对齐、目标跟踪、定时插入），规划器根据实时位置与速度预测未来轨迹，规划出面向未来状态的动作。
- 规划难以处理的复杂交互动力学场景，则训练**任务专属的强化学习策略**来生成示范轨迹。

### 延迟感知评估协议

- 核心机制：将**模拟器步进与机器人控制解耦**，允许环境动力学独立于策略计算而推进，不再在策略推理时暂停环境。
- 支持两种部署范式：
  - **同步推理**：阻塞执行直至策略推理完成，模拟器暂停采集观测，推理完成后机器人空转指定延迟时长再执行动作块，模拟真实推理阻塞部署。
  - **异步推理**：策略从当前观测推断新动作块，同时机器人执行上一周期产生的动作块，新动作在下个控制周期可用。
- **可配置延迟**：延迟值可手动指定以系统化分析延迟对任务成功率的影响；或根据实际策略推理延迟，通过**实时因子（RTF）** 换算为仿真延迟：

  \[
  \text{RTF} = \frac{t_{sim}}{t_{wall}}
  \]

## 2.2 ReflexVLA——面向反应关键操作的预测性高效VLA

### 基础架构

构建于紧凑的视觉-语言-动作架构（基于VLA-Adapter）之上：视觉编码器采用 DINOv2 与 SigLIP 融合的 ViT 骨干（224×224分辨率），语言骨干为 Qwen2.5-0.5B 因果Transformer，通过连续回归头产生动作块。

### 三大核心设计

**(1) 潜在未来预测（Latent Future Prediction）**

- 核心思想：不直接预测未来图像（计算昂贵且易关注与任务无关的低层外观细节），而是在**冻结视觉编码器提取的语义潜在空间中**进行未来预测。
- 具体做法：用冻结的 DINOv3 模型对每个未来观测编码：
  \[
  y_{t+i} = \phi_{DINOv3}(o_{t+i}), \quad y_{t+i} \in \mathbb{R}^{1024}
  \]
- 将H个可学习未来token（**H与动作块大小一致**）追加到多模态输入序列中，每个token对齐一个未来控制步，使未来状态预测与动作生成的时间结构对齐。
- 预测头将未来token的隐藏表示投影到 DINOv3 特征空间：
  \[
  \hat{y}_{t+i} = f_{pred}(h^i_{future})
  \]
- 采用**掩码余弦相似度损失**训练：
  \[
  L_{future} = \frac{\sum_{i=1}^{H} m_i [1 - \cos(\hat{y}_{t+i}, y_{t+i})]}{\sum_{i=1}^{H} m_i}
  \]
- 总损失为动作损失与未来预测损失的加权和：
  \[
  L = L_{act} + \lambda_{future} L_{future}
  \]
- 仅使用单token表示每个未来步骤，额外序列长度极小，计算和内存开销可忽略。

**(2) 多帧时间融合（Multi-Frame Temporal Fusion）**

- 动机：单帧观测无法捕捉运动动态；简单拼接多帧视觉token会导致注意力复杂度随 \( V \times T \times P \) 二次增长，且缺少显式时间结构建模。
- 设计：在**视觉骨干内部**进行时间融合，仅将当前帧的融合表示为语言模型消费：
  - 提取视觉编码器中间层特征与最终层特征，取中间层特征进行时间融合（保留更丰富的局部外观和运动线索）。
  - 对每个视角v和每个patch位置p，将T个历史帧的同一空间位置特征形成时间轨迹，归一化+降维并加入时间位置编码：
    \[
    z_{v,p,1:T} = \text{Down}(\text{LN}(x^{mid}_{v,p,1:T})) + e_{1:T}
    \]
  - 应用**因果时间注意力**（防止信息泄漏，保证在线部署一致性）：
    \[
    \Delta x_{v,p,t} = \text{Up}(\text{MHA}_{causal}(z_{v,p,1:T})^T)
    \]
  - 与当前帧最终特征残差融合：
    \[
    \tilde{x}_{v,p,t} = x^{final}_{v,p,t} + \Delta x_{v,p,t}
    \]
- 关键优势：语言模型消费的视觉token数量与单帧设置完全一致，能在**不引入语言模型侧额外开销**的情况下利用短期运动信息。

**(3) 推理延迟优化（Inference Latency Optimization）**

- **批量视觉编码**：将所有视角×帧的图像合并为一次批量前向调用，避免 \( V \times T \) 次独立前向传播带来的框架开销，提升GPU利用率。
- **CUDA Graph重放**：部署时计算图固定，捕获完整推理流水线（视觉编码→时间融合→多模态投影→语言模型推理→动作预测）为CUDA Graph：
  \[
  \hat{a}_{t:t+H-1} = G(x_{text}, x_{vision}, x_{state})
  \]
  执行时将新观测拷贝进预分配缓冲区，直接重放图，**消除重复内核调度和运行时分发开销**。

## 6. 主要结论与发现

1. **推理配置因素**：更大块大小+更短动作范围+高频异步推理的组合在动态任务中表现最优；低频时异步推理存在明显的观测-动作失配问题，随频率提升异步推理逐渐超越同步推理。

2. **模型性能**：ReflexVLA在ReflexBench上达到**50.4%平均成功率**，超过所有7个对比基线（包括7B的OpenVLA-OFT和4B的π0.5），在参数效率上显著占优——以1B模型超越/持平4B动态专用模型PUMA（50.2%）。

3. **静态不退化**：在LIBERO上平均97.2%，与VLA-Adapter（97.3%）、OpenVLA-OFT（97.1%）等相当，验证了动态增强设计未牺牲静态泛化能力。

4. **消融发现**：
   - **冻结DINOv3目标（+26.0%）远优于可训练目标（-31.9%）**：可训练视觉目标导致不稳定监督信号，冻结特征提供稳定语义预测目标。
   - **中间层特征时间融合（71.7%）优于最终层特征（68.2%）和交叉注意力方案（66.1%）**：中间层保留更丰富的运动相关信息。
   - **推理延迟优化（+2.1%成功率，延迟从125.1ms降至65.0ms）**：几乎减半延迟的同时进一步带来性能提升。

5. **真实世界有效性**：实际环境中明显优于SmolVLA，并以1B模型取得与4B PUMA相当的动态操作表现。

## 8. 不足与局限性

### 8.1 基准设计层面

- **任务难度分布不均衡**：Ball Catching任务在所有模型上的成功率均低于10%，而Rotary Plug Insertion等任务部分模型接近80%，平均成功率受困难任务拖累明显，可能掩盖模型间在中等难度任务上的真实差异。
- **动态任务范围有限**：6个任务均属于"目标运动可预测/半可预测"的范畴，未覆盖如非刚体形变、多智能体协同、高度随机化的动态场景，结论向更复杂动态环境的泛化仍需验证。
- **演示数据规模较小**：每任务仅200条演示，虽然对轻量模型可能足够，但相较于大规模VLA预训练的演示规模仍有差距，限制了在数据受限条件下结论的普适性。

### 8.2 方法设计层面

- **潜在未来预测的语义监督依赖DINOv3**：未来预测的质量完全取决于DINOv3特征空间的语义丰富性，若下游任务涉及DINOv3未编码的细粒度物理属性（如材质、摩擦系数），预测目标可能缺乏必要信息。
- **时间融合仅覆盖短窗口**：多帧融合仅利用当前及历史短窗口内的运动线索，对于需要长时程运动预测的任务（如长时间的轨迹规划），其有效性未得到验证。
- **未与"预测未来观测输入"类方法直接对比**：虽然通过动态任务上的统一基准实现了公平对比，但DINOv3潜在空间预测与实际像素预测方法（如视频预测模型）的各自适用边界未做深入分析。
- **CUDA Graph优化依赖固定计算图**：若策略需要在运行时动态调整序列长度或结构，此优化手段将受限，限制了方法的灵活性。

### 8.3 实验验证层面

- **训练资源信息缺失**：训练GPU数量、类型、时长、总计算量未披露，难以评估方法的训练成本与实际可复现性。
- **真实世界评估规模有限**：每策略每任务仅20次评估，且仅覆盖3个任务，统计功效有限；未报告真实世界实验中的延迟实测数据，无法验证模拟中延迟收益是否完全迁移。
- **未分析失败模式**：论文未系统分析ReflexVLA在各任务上的失败类型（如预测失败vs.时序对齐失败vs.运动跟踪失败），不利于后续针对性改进。

## 9. 与现有工作的关系

- **与PUMA的关系**：PUMA同样致力于动态操作，但侧重于通过预测编码器在动作解码器中注入未来信息，其预测发生在语言模型的低维动作空间；ReflexVLA则在视觉语义空间进行未来预测，且不改变动作解码机制。两者在方法论上互补。
- **与DynamicVLA的关系**：DynamicVLA采用3D基础模型+时间建模增强VLA，但引入了较重的视觉处理管线；ReflexVLA选择更轻量的视觉骨干内时间融合，语言模型侧不增加计算。
- **与OpenVLA等通用VLA的关系**：本文证明了在动态反应型操作中，"规模大"不等于"反应快"——7B通用模型的推理延迟和动态成功率均不如1B专用模型，但通用模型的静态泛化能力仍具竞争力，提示了通用性vs.反应性的权衡空间。
- **与加速工作（如CUDA Graph、批量推理）的关系**：本文展示了系统级优化与模型架构设计可以正交叠加，且系统优化带来的延迟降低可直接转化为动态任务性能提升——这一"延迟即性能"的视角恰是论文的核心主题。

## 10. 个人评价与展望

### 综合评价

本文是动态反应型VLA操作领域一篇**扎实且完成度高**的工作。其最大贡献不在于某一项颠覆性创新，而在于将"延迟"这一被普遍忽视的维度系统性地纳入基准设计与模型优化——通过构造延迟感知基准、针对性设计预测性高效架构、并辅以系统级部署优化，形成了从"问题定义→方法→验证"的完整闭环。以1B参数取得超过7B模型的表现，具有明确的实用价值。

### 可改进方向

**（1）预测目标的自适应选择**：未来预测目前固定使用DINOv3特征，可探索根据任务语义自动选择预测目标（如可学习特征投影层+混合冻结/可训练目标），在保留稳定性的同时增加适应性。

**（2）扩展时间融合范围**：当前融合窗口仅覆盖短期历史，可探索分层时间融合——视觉骨干内融合短期运动，语言模型侧以长上下文token融合长期任务状态，实现"短动作+长规划"的统一。

**（3）动态难度的自适应推理**：块大小与动作范围目前为固定超参数，可设计根据运动速度/目标不确定性动态调节推理频率与预测时域的策略，进一步提升在突发工况下的鲁棒性。

**（4）跨任务未来预测泛化**：DINOv3特征空间的未来预测目前仅在同一任务的训练/测试间验证，可探索多任务联合训练下的预测泛化能力，验证学到的"动态先验"能否迁移到未见任务。

**（5）扩展到真实动态操作中更复杂的接触交互**：当前任务以"追-抓-插"为主，可扩展到需要同时处理动态目标与精确力学交互的任务（如动态装配、高速操作中的力控），验证方法在力觉反馈存在的动态场景下的适用性。

---

## 11. 结论

ReflexBench与ReflexVLA共同回答了动态反应型操作中的两个核心问题：**"如何公平评估延迟影响"** 与 **"如何在低延迟约束下保持强的未来感知能力"**。延迟感知评估协议将推理延迟从评估的"环境变量"转变为"受控变量"，未来预测与时间融合设计则在1B轻量模型上实现了与4B专用模型相当的动态操作成功率。该工作为动态VLA操作的研究提供了清晰的可复现基准与高效的基线方法，也为后续研究指出了"推理延迟"与"环境动力学"耦合建模的重要方向。

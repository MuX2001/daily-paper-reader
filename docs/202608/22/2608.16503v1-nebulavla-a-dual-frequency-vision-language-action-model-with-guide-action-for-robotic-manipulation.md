## 摘要
视觉-语言-动作（VLA）模型在真实世界部署中常受限于效率与性能的权衡、跨实体泛化能力以及执行平滑性。我们提出NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，优化计算资源与模块化程度。为弥合异构机器人间的语义鸿沟，我们引入GESTURE-7，一种统一的基于语言的动作表示。此外，我们的引导动作算法通过基于掩码的平滑性约束确保运动学连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上达到85.5%的平均成功率，并将动作生成加速约2.7倍。这种异步设计为实际机器人应用实现了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

## 1. 核心问题与研究动机

本论文聚焦于视觉-语言-动作（VLA）模型在真实世界机器人部署中面临的三大核心瓶颈：

- **效率-性能权衡困境**：现有的同步单体系架构强制采用统一的时间分辨率，无法同时满足低频语义推理（需要较重的计算）与高频电机控制（需要低延迟响应）的需求。
- **跨实体泛化障碍**：将连续运动学映射为离散 token 的方式需要庞大的词表和大量演示数据才能覆盖动作空间，且缺乏跨异构机器人平台（如灵巧手、夹爪、机械臂）的统一动作语义。
- **执行平滑性缺失**：异步实时推理与动作块（action chunk）生成之间的时间不匹配会产生明显的抖动和执行不连续，影响实际操作质量。

整体研究含义在于：VLA 模型要从实验室走向真实部署，必须在推理效率、泛化能力和运动连续性三个维度上同时取得突破。

## 2. 方法论：NebulaVLA 的核心技术方案

### 2.1 异构双频架构（Heterogeneous Dual-Frequency Architecture）

借鉴卡尼曼“快慢思维”认知范式，将系统解耦为两个层次：

- **System 2（10 Hz 深思熟虑层）**：以 Qwen3-VL 为骨干，处理自然语言指令和低频稀疏视觉输入，输出高层抽象动作引导（action guidance）。
- **System 1（20 Hz 反应式控制层）**：以 DiT（Diffusion Transformer）为生成器，结合 System 2 的引导输出、高频视觉输入和动作历史，通过去噪过程生成执行动作。

两个系统通过显式数据流规范解耦，天然支持分布式部署，可部署在不同计算设备上，最大化硬件吞吐率并最小化交互延迟。

### 2.2 GESTURE-7：统一语言接地动作表示

- 定义 7 维连续向量：**[x, y, z, r, p, w, gesture]**。
  - x, y, z：末端执行器笛卡尔坐标位置（量化到整厘米）；
  - r, p, w：姿态角（roll、pitch、yaw，量化到整数度）；
  - gesture：自然语言关键词，表示目标手部姿态（如 "grasp"、"push"、"pinch"）。
- 跨不同实体执行相同动作时共享相同关键词（如夹爪和灵巧手的抓取均表示为 "grasp"），从而在异构平台间统一动作语义。
- 该表示天然支持语言条件下的强化学习。

### 2.3 Guide Action：掩码约束的引导动作机制

受到图像外推（Image Outpainting）技术的启发，将块拼接直接嵌入生成流程：

- **核心思想**：下一块动作的生成以上一块中尚未执行的轨迹锚点（guide action points）为条件，确保边界过渡无缝衔接。
- **条件概率模型**：$p_\theta(A^t_{full} | A^{t-1}_{full}, A_{prior}, \tau)$，其中 $A_{prior}$ 包含已执行的历史动作（可选）和待执行的引导动作。
- **掩码强制恢复公式**：每次去噪步骤后执行 $A^{t-1}_{full} = M \odot A^{(t-1)}_{prior} + (1 - M) \odot A^{t-1}_{noisy}$，其中 M 为二元掩码，锚定区域（M=1）严格保留，生成区域（M=0）由模型预测。
- 引导动作数量在训练时从 0 到 3 随机采样，以适应不同的推理延迟。
- 与传统的 RTC（Real-Time Chunking）和样条插值等后处理平滑方法不同，该机制在生成过程中内化平滑约束，无需后处理。

### 2.4 三阶段训练流程

1. **Stage 1（System 2 监督微调）**：三类任务组——空间接地（GESTURE-7 姿态回归、2D 关键点回归）、轨迹预测（2D 路径点、3D 轨迹点预测）、推理与规划（链式思维子任务分解 + 未来 GESTURE-7 轨迹生成）。
2. **Stage 2（System 2 强化学习）**：基于 GRPO，保留与 SFT 相同的任务套件，使用 GESTURE-7 距离奖励、关键点定位奖励、路径点奖励、轨迹奖励和格式奖励。
3. **Stage 3（System 1 监督微调）**：联合优化 S2 和 S1 权重（冻结视觉编码器），使用 L2 损失监督连续动作输出。由于引导动作机制，损失仅在掩码 M=0 的新生成区域计算。

## 7. 方法亮点与创新之处

- **异步双频架构设计巧妙**：将认知科学中的快慢系统思想引入 VLA 架构，不仅优化了计算-延迟权衡，还天然支持分布式部署，具有明显工程价值。
- **GESTURE-7 表征设计务实**：通过量化到整数 + 自然语言关键词的方式降低了模型学习负担，同时实现了跨实体语义统一，且支持强化学习，设计简洁而有效。
- **Guide Action 机制新颖**：将图像外推技术类比迁移到动作块生成，在扩散过程中内化平滑约束，解决了长期以来异步执行中的边界抖动问题，无需后处理。
- **三阶段训练流程系统完整**：从 SFT 到 RL 再到联合微调，逐步递进，且通过实验验证了每一阶段的贡献。
- **评估指标全面**：同时使用成功率、推理延迟和关节抖动三种指标，分别对应正确性、效率和平滑性，覆盖面完整。

## 8. 不足与局限

- **频率分配静态化**：当前 10 Hz/20 Hz 的分配是经验性且静态的，最优配置可能因任务域而异，动态自适应调度仍是开放问题。
- **Guide Action 的响应延迟**：依赖固定引导锚点，在快速变化环境中可能引入轻微响应延迟。

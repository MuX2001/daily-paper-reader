## 摘要
预训练的视觉-语言-动作模型为机器人学习提供了坚实基础，但将其顺序适应于多种技能可能会扰乱先前技能所使用的表征和速度映射，导致灾难性遗忘。基于架构的方法通过隔离技能来改善保留性，但会增加推理开销。近期基于子空间约束的方法通过在正交子空间中限制参数更新以最小化干扰，但对整个模型施加统一约束。我们分析了VLA内部组件的不同作用，并识别出两个VLA特有的挑战。首先，VLM维护广泛的语义表征，使其容易受到容量耗尽的影响，而ActionHead将语义细化为局部速度模式，这些模式对扰动高度敏感。其次，最终的速度解码器作为读出层。冻结它会形成输出阶段的表达能力瓶颈，而更新它则可能覆盖先前的速度映射。为此，我们提出OrthoSkillVLA，一种无需演示回放即可在预训练VLA模型中进行连续技能学习的参数高效框架。鉴于表征的异质性，我们对VLM和ActionHead施加分离的子空间约束，在保护局部速度模式的同时保留可复用的语义容量。对于输出层，我们引入轻量级的特征感知MoE解码器，其中每个技能分配一个紧凑的专家，并且无需训练的路由器根据特征空间亲和度选择专家。大量的模拟和真实世界评估以及消融实验表明，OrthoSkillVLA在获取新技能的同时能更好地保留先前技能。

## Abstract
Pretrained Vision-Language-Action models provide a strong foundation for robot learning, but sequentially adapting them to diverse skills can perturb the representations and velocity mappings used by previous skills, leading to catastrophic forgetting. Architecture-based approaches improve retention by isolating skills but lead to increased inference footprint. Recent subspace-constrained methods restrict parameter updates in an orthogonal subspace to minimize interference but impose a unified constraint on the entire model. We analyze the distinct roles of internal VLA components and identify two VLA-specific challenges. First, the VLM maintains broad semantic representations, making it vulnerable to capacity exhaustion, whereas the ActionHead refines semantics into localized velocity patterns that are highly sensitive to perturbations. Second, the final velocity decoder serves as a readout layer. Freezing it forms an output-stage expressivity bottleneck, while updating it risks overwriting previous velocity mappings. To this end, we propose OrthoSkillVLA, a parameter-efficient framework for continual skill learning in pretrained VLA models without demonstration replay. Given the representation heterogeneity, we impose separate subspace constraints on the VLM and ActionHead, preserving reusable semantic capacity while protecting localized velocity patterns. For the output layer, we introduce a lightweight feature-aware MoE decoder, where each skill is allocated a compact expert and a training-free router selects the expert according to feature-space affinity. Extensive simulated and real-world evaluations, together with ablations, demonstrate that OrthoSkillVLA better preserves prior skills while acquiring new ones.

## 1. 核心问题与研究动机

- **研究背景**：预训练的视觉-语言-动作模型（VLA）为机器人学习提供了强大基础，但在实际部署中，机器人往往需要**顺序学习多种新技能**，而非一次性掌握全部技能。
- **核心问题**：将预训练 VLA 模型顺序适应于新技能时，新任务的参数更新会**扰动旧技能所依赖的语义表征和速度映射**，导致**灾难性遗忘**（catastrophic forgetting）——旧技能的执行精度显著下降。
- **现有方法的不足**：
  - **基于架构的方法**（为不同技能隔离独立模块）虽然能提升保留性，但会**显著增加推理开销**（如需要任务路由或加载多个模型）；
  - **基于子空间约束的方法**将参数更新限制在正交子空间以减小干扰，但**对 VLM 和 ActionHead 施加的是统一约束**，忽视了二者在 VLA 中的角色差异。
- **论文识别出的两个 VLA 特有挑战**：
  1. **表征异质性**：VLM 维护**广泛、可复用的语义表征**，容易被新技能"挤占"造成容量耗尽（capacity exhaustion）；而 ActionHead 将语义细化为**局部、精炼的速度模式**，对参数扰动高度敏感。
  2. **输出瓶颈矛盾**：最终的速度解码器作为读出层——**冻结**它会导致输出阶段表达能力不足，**更新**它则可能覆盖已有技能的速度映射。

## 2. 方法论：OrthoSkillVLA

### 2.1 核心思想

针对 VLA 内部组件角色差异，**分别对 VLM 和 ActionHead 施加独立的子空间约束**，并引入**轻量级特征感知 MoE 解码器**解决输出瓶颈，实现**无需演示回放（replay-free）的参数高效持续技能学习**。

### 2.2 关键技术细节

1. **分离的子空间约束策略**：
   - **对 VLM**：施加正交子空间约束，保证参数更新不破坏已有语义容量，使可复用的语义表征得以保留；
   - **对 ActionHead**：同样施加正交约束，但目标不同——保护对扰动高度敏感的**局部速度模式**，防止新技能更新覆盖旧技能的精细动作映射。
   - 核心区别在于：不再对全模型使用同一约束，而是**根据组件功能差异分别设计约束的强度与作用对象**。

2. **特征感知 MoE（Mixture-of-Experts）解码器**：
   - 为每个技能分配一个**紧凑的专家（expert）**，用于输出该技能对应的速度/动作；
   - 引入一个**无需训练的路由器（training-free router）**，根据当前输入在**特征空间中的亲和度**自动选择合适的专家；
   - 这样既避免了冻结输出层导致的表达能力瓶颈，也避免了更新单一解码器导致的旧技能速度映射被覆盖。

3. **参数高效性**：整体框架只对 VLM 和 ActionHead 的少量参数进行约束更新，每新增技能仅增加一个轻量专家，不涉及大规模参数微调，也不需要保存和重放旧演示数据。

### 2.3 公式 / 算法流程（文字描述）

- **输入**：预训练 VLA 模型（VLM + ActionHead + 速度解码器）、新技能演示数据
- **步骤**：
  1. 对 VLM 计算梯度，将其投影到与旧技能参数更新方向正交的子空间，更新 VLM 参数；
  2. 对 ActionHead 执行类似的正交子空间投影更新，但约束的几何结构与强度针对速度模式保护做了单独设计；
  3. 为新技能新增一个紧凑的专家解码器，并保持路由器无训练（通过特征相似度/亲和度计算完成路由）；
  4. 训练完成后，旧技能的参数基本不被扰动，新技能获得独立的输出专家，推理时路由器自动选择合适的专家解码。

## 摘要
请求到交接的间隙有三个耦合来源：请求时行为意图的模糊性、动作生成期间累积的物理状态漂移，以及新动作最终接管控制时的残留不兼容性。BICPO-VLA依次解决这些问题。首先，一个指令感知的因果历史编码器识别命令和当前任务进度所支持的行为。其次，顺序Haar子空间生成将每个动作块分解为互补的成对支撑系数和残差系数，实现两个专门的生成阶段及随后的精确重建。通过在原始动作空间中减少迭代细化，缩短了在新块可用之前机器人继续移动的时间间隔。最后，BICPO将已知的外出动作滚动到实际交接状态，并在行为匹配的候选者之间应用参考相对Flow-DPO，使生成的块适应剩余的请求-交接不匹配，而不改变其预期行为。

## Abstract
The request-to-handoff gap has three coupled sources: ambiguity about the behavior intended at request time, physical-state drift accumulated during action generation, and residual incompatibility when the new action finally assumes control. BICPO-VLA addresses them in sequence. First, an instruction-aware causal history encoder identifies the behavior supported by the command and current task progress. Second, sequential Haar subspace generation decomposes each action chunk into complementary pairwise scaffold and residual coefficients, enabling two specialized generation stages followed by exact reconstruction. By reducing iterative refinement in the original action space, it shortens the interval over which the robot continues moving before the new chunk becomes available. Finally, BICPO rolls the known outgoing actions to the actual handoff state and applies reference-relative Flow-DPO among behaviorally matched candidates, adapting the generated chunk to the remaining request-to-handoff mismatch without changing its intended behavior.

## 1. 核心问题与整体含义

- **研究动机**：在异步动作分块（asynchronous action chunking）控制中，机器人执行当前动作块的同时，VLA模型需要推理下一新动作块。由于推理耗时，新块是在一个运动上下文中被“请求”的，却在另一个状态中“接管”控制——即请求到交接的间隙（request-to-handoff gap）。
- **问题根源**（三个耦合来源）：
  1. 请求时行为意图的模糊性（行为歧义）；
  2. 动作生成期间物理状态的漂移；
  3. 新动作最终接管时的残留不兼容性（边界跳跃或运动趋势断裂）。
- **关键洞察**：一个“行为”（如“抓杯子”）定义的是一族动作实现（a family of action realizations），而非唯一轨迹——论文称之为“行为条件动作纤维”（behavior-conditioned action fiber）。同一纤维内的成员共享任务含义，但局部运动与交接兼容性不同。
- **整体含义**：可靠控制需要同时满足行为有效性（与指令、任务进度一致）和交接有效性（与状态转移时兼容）。现有方法（记忆增强、高效生成、异步策略）只改进某一侧面，未将行为身份、实现结构、交接条件选择三者联合分离。

## 2. 方法论

- **总体架构**：三阶段因式分解——行为识别（Behavior Identification）→ Haar结构实现（Haar-structured Realization）→ 交接偏好优化（Continuation Preference Optimization, BICPO）。

  - **阶段一：指令感知的行为识别**（Instruction-Grounded Behavior Identification）
    - 视觉 token 先经过语言特征引导的注意力路由（Perceptual Visual Routing），过滤掉与指令无关的视觉证据，再进行历史融合；
    - 使用因果 Mamba 编码器聚合路由观测和已执行命令，得到指令相对进度状态 $z_r$；
    - 结合检索的长期记忆 $m_r$，用相位条件解码器预测动作先验 $\mu_r$；
    - 行为条件 $b_r \equiv (\ell, z_r, m_r, \mu_r)$ 定义动作纤维 $F_r$。

  - **阶段二：交接条件下的 Haar 实现生成**（Handoff-Conditioned Haar Realization）
    - **滚动交接状态**：利用已知的外出命令序列，通过冻结的动作状态模型确定性滚动到实际交接状态 $\bar{h}_{r+k}$，并计算推理期间的位移 $\Delta h_{r,k}$，二者拼接输入投影器得到交接条件 $g_k$；
    - **互补坐标分解**：对偶数长度动作块 $A$ 使用一级 Haar 变换 $W_H$，分解为成对支撑系数 $C$（pairwise scaffold）与残差系数 $D$（complementary residual）：$c_i = (a_{2i} + a_{2i+1})/\sqrt{2}$，$d_i = (a_{2i} - a_{2i+1})/\sqrt{2}$；由 $C,D$ 可精确重建原动作块；
    - **有序两阶段生成**：第一阶段在无残差条件下生成支撑 $C$；第二阶段以支撑为条件（stop-gradient）联合生成残差 $D$；使用线性 flow matching 路径 $\partial x_\tau/\partial\tau = \epsilon - y$，单步反向欧拉即可精确恢复系数向量。

  - **阶段三：行为识别的持续偏好优化**（BICPO）
    - 冻结语义通路，在相同行为条件 $b_r$ 与交接条件 $g_k$ 下，用不同 flow 噪声采样两个候选动作块，构成同纤维候选对；
    - 定义延续代价：零阶交接跳跃 $J_\text{jump}$ 与一阶运动趋势失配 $J_\text{trend}$，加权求和 $J_\text{cont}$；
    - 采用参考相对 Flow-DPO（reference-relative Flow-DPO）：比较两个候选的 flow 能量差相对于冻结参考模型的变化量 $\Delta\theta$，用偏好损失 $L_\text{pref} = -q\log\sigma(\beta\Delta_\theta)$ 优化；只更新交接投影器 $P_\psi$、门控 $W_g$ 和部分专家参数；
    - 该 DPO 目标可独立移植到其他策略（如 π0.5、Legato、RTC），无需附加 BICPO-VLA 的编码器、Haar 生成器或交接投影器。

- **训练流程**：模仿学习 → 结构化延续热身（continuation warm-up with $L_\text{struct}$）→ 离线 DPO 微调。
- **部署**：只需一次交接状态滚动，生成 $(C,D)$ 后通过固定 Haar 逆变换重建完整动作块，无需在线候选搜索。

## 6. 主要结论与发现

- **整体效果**：BICPO-VLA 在 CALVIN 上达到 4.52 平均链长（最强基线 B-VLA 为 4.36），在 RoboTwin 十项任务总体成功率上以 65.8% 超过 B-VLA 的 60.4%，在真实世界以 69.3% 超过 B-VLA 的 60.2%。
- **连续性改善**：在 LIBERO 上，DPO 使 BICPO-VLA 的跳跃代价降低 21.3%、趋势失配降低 20.7%，而出色的成功率仅提高 0.3 个百分点。
- **DPO 可迁移性**：相同的参考相对 DPO 目标应用于 π0.5、Legato、RTC 三种宿主策略时，均持续降低两种连续性成本，对成功率影响仅有 0.1–0.2 个百分点；相反，直接 SFT（chosen-only SFT）在所有宿主上都导致成功率大幅下降（如 π0.5 从 96.9% 跌至 49.1%）。
- **核心论点**：偏好优化是对持续性问题的正确范式——它是在“任务支持的动作族内”进行相对排序，而非追求全局最小动作；成功的语义保证由宿主策略提供，延续性偏好只负责改善交接方式。
- **消融结论**：三个模块各有独立贡献；指令在视觉感知层介入（先于历史融合）效果最好；延迟鲁棒性在 $k\in\{3,4,5\}$ 和随机延迟上表现稳定。

## 7. 优点

- **问题分解清晰**：将异步控制的复杂性分解为行为识别、实现结构、交接选择三个独立约束，逻辑严密，符合“不同问题对应不同机制”的设计哲学。
- **Haar 变换的设计巧妙**：正交可逆变换既保留全部动作信息（无重建瓶颈），又将动作组织为“成对骨架+局部残差”两种互补坐标，支撑了分阶段生成的结构化接口，而非只是加速近似。

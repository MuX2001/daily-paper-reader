## 摘要
长时间范围的机器人操作要求机器人既能可靠地执行单个技能，又能在扩展任务中连贯地编排这些技能。大多数分层视觉-语言-行动（VLA）模型通过单次前向传递做出每个决策，没有机制为困难或关键选择分配额外计算。我们提出了$τ_0$-VLA，一种分层机器人基础模型，通过世界模型引导的测试时计算，将高层子任务生成表述为可扩展计算量的推理问题。在每个推理步骤中，高层策略使用执行记忆生成子任务，并在需要时搜索替代方案后再提交其输出。然后，低层策略在多种机器人实体上执行生成的子任务。该策略在40,115小时的异构真实世界数据上进行了多模态协同训练。在域内和分布偏移设置中，分配额外的测试时计算显著提高了下一子任务预测的准确性，并且这些增益转化为在长时间范围机器人操作任务中更高的闭环成功率。

## Abstract
Long-horizon robot manipulation requires a robot to both execute individual skills reliably and sequence them coherently over extended tasks. Most hierarchical vision-language-action (VLA) models make each such decision with a single forward pass, leaving no mechanism to allocate additional computation to difficult or consequential choices. We introduce $τ_0$-VLA, a hierarchical robot foundation model that formulates high-level subtask generation as a compute-scalable inference problem through world-model-guided test-time computation. At each inference step, the high-level policy uses execution memory to generate a subtask and, when needed, searches over alternatives before committing to its output. A low-level policy then executes the generated subtask across multiple robot embodiments. The policy is trained on 40,115 hours of heterogeneous real-world data with multimodal co-training. Across in-domain and distribution-shifted settings, allocating additional test-time computation substantially improves next-subtask prediction accuracy, and these gains translate into higher closed-loop success on long-horizon robot manipulation tasks.

## 1. 核心问题与研究动机

- **核心问题**：长时间范围的机器人操作（如打扫房间、做饭、泡茶）既要求机器人能可靠执行单个技能（低层控制），又要求能连贯地编排这些技能（高层决策）。现有的大部分分层 VLA（Vision-Language-Action）模型在每个高层的子任务决策上都采用**固定推理预算的单次前向传播**，缺少在遇到困难或关键抉择时**动态分配额外计算**的机制。
- **关键矛盾**：
  - 错误的子任务选择无法靠更精确的电机控制来弥补——把错误的子任务执行得再完美也无济于事。
  - 错误的决策通常只有在执行已改变环境后才被察觉，此时重规划虽可响应，但无法挽回失败尝试的代价。
  - 动作级搜索只覆盖局部物理后果；纯语言推理虽能覆盖较长视界，但不能将备选方案锚定到其产生的物理状态上。
- **核心思想**：将“下一步子任务生成”视为一个**推理时计算可扩展（compute-scalable）的问题**，如同 LLM 的 test-time computation 范式。子任务天然处于“动作”与“完整任务”之间的理想粒度：稀疏到值得额外计算，又时间上延伸足够长，能产生有意义且可区分的环境变化。要比较候选子任务，需先通过**世界模型**预测每个候选执行后的物理状态，再据此评估。
- **整体含义**：通过"提出-预测-评估-反思"的推理回路，把**计算量分配**引入分层机器人基础模型，使长期操作中"该做什么"的决定不再依赖单次前向的运气，而成为可扩展、可搜索、可验证的决策过程。

## 2. 方法论

### 2.1 系统总体架构
- τ₀-VLA 由两个按顺序协作的策略组成：
  - **高层策略（High-Level Policy）**：维护执行记忆，决定何时调用额外的测试时计算，并生成当前子任务。
  - **低层策略（Low-Level Policy）**："如何执行"——将当前观察与高层生成的子任务映射为机器人动作序列。
- 信息流：高层策略在每个注入步骤生成子任务 $z_t^\star$ → 低层策略以此作为语言指令生成动作块并执行 → 实际观察反馈至下一轮高层推理，形成闭环。

### 2.2 高层策略（核心创新）
高层策略 μ 由四个模型组成：**提议模型 P、世界模型 W、价值模型 V、反思模型 F**。

- **提议模型（Proposal Model）P**：接收上下文 $h_t = (ℓ, M_{t-1}, z^\star_{t-1}, o_t)$，更新执行记忆并生成直接子任务提议 $z^{dir}_t$。同一前向过程产生的 token 置信度用于自适应路由决策 $g_t \in \{0,1\}$（快速路径 vs. TTC 路径）。
- **执行记忆（Execution Memory）**：训练时通过对已有演示的记忆施加扰动（滞后、超前、与实际进度冲突），训练策略修复错误记忆。五种实例族（见表 VI）：within-subtask（58%）、transition（15%）、catch-up（10%）、rollback（12%）、error-think（5%）——无需额外人工标注。
- **世界模型（World Model）W**：接收头部相机 RGB 图像 $\tilde{o}$ 和候选子任务 $z$，预测该子任务完成时的**终端头部相机图像** $\hat{o} = W(\tilde{o}, z)$。初始化自 Step1X-Edit。
- **价值模型（Value Model）V**：接收全局任务指令、候选子任务和预测的终端图像，输出候选质量分 $v = V(ℓ, z, \hat{o})$（五档序数评分，映射到 [0.05, 0.95]）。
- **测试时搜索（Test-Time Search）**：当路由决定 $g_t=1$ 时，执行束搜索（beam search）：
  - 参数：分支因子 $N$、束宽 $B$、搜索深度 $D$；
  - 每个深度对每条保留分支独立调用提议模型 N 次生成候选子任务；
  - 每个候选经世界模型预测视觉结果，价值模型打分；
  - 按累计得分全局保留 Top-B 分支，递归扩展至深度 D；
  - 非根分支的"视觉上下文"为上一层的预测图像，从而实现多步想象展开。
- **反思模型（Reflective Model）F**：接收观察对齐的真实上下文 $\bar{h}_t$ 和最终保留分支摘要 $C_t$，生成最终子任务 $z^\star_t$。其输出可以与保留提议重合但不限于候选集合，可以修正搜索中保留的次优分支。

### 2.3 低层策略
- **网络结构**：Qwen3.5-2B 视觉语言骨干 + Mixture-of-Transformers（MoT）动作专家。每个全注意力层中，动作 token 与骨干 token 通过联合注意力交互，但由独立参数化的 Transformer 流处理。
- **统一状态与动作空间**：40 维共享空间，覆盖左右臂末端执行器位姿（位置 + Rot6D 旋转）、夹爪、腰部、移动基座、手臂关节。每样本的状态/动作掩码选择有效通道，控制元数据 η 指定控制模式。
- **掩码流匹配（Masked Flow Matching）**：对不同实施例占据不同通道的问题，在流路径和训练目标上同时施加掩码：
  - 插值：$a^τ_{t+j} = τ M\epsilon_{t+j} + (1−τ)Ma_{t+j}$
  - 目标速度：$u_{t+j} = M(\epsilon_{t+j} − a_{t+j})$
  - 损失：$L_{FM} = \mathbb{E}[\frac{1}{H \cdot tr(M)} \sum_{j=0}^{H-1} \| M v^τ_{\theta,t+j} − u_{t+j} \|_2^2]$
  - 推理时从掩码高斯噪声初始化，从 τ=1 积分到 τ=0，H=30（动作块），10 步均匀欧拉更新。
- **三阶段训练**：
  1. **知识隔离协同训练（KI）**：动作梯度在骨干接口处被阻断，防止破坏预训练骨干（多模态数据辅助稳定）；
  2. **端到端协同训练**：移除 KI，允许动作梯度调整骨干表征，保留多模态数据作为辅助监督；
  3. **任务特定微调**：在少量任务专用演示上微调以适应目标平台和场景。

## 6. 主要结论与发现

1. **测试时计算显著提升子任务预测精度**：TTC 在四个开环评测设置中均超越 Plan Once 和 Best-of-N。典型如 Book Organization OOD 场景：TTC 74.0% vs. Plan Once 50.0% vs. Best-of-N 57.5%。
2. **高层决策精度的提升转化为端到端任务成功率的提升**：在 Make Milk Tea 上 TTC 将 SR 从 5/10 提升至 7/10，Book Organization 从 6/10 提升至 9/10，Clean Room 从 5/10 提升至 7/10（固定低层策略不变）。
3. **计算-精度关系呈饱和趋势**：低计算预算区精度提升显著，边际收益递减，最终趋于平台期；中等预算下 TTC 有良好的性价比。
4. **显式执行记忆是长期状态跟踪的关键**：在 Clean Room、Prepare Ingredients、Tomato and Egg Stir Fry 中，分层系统 + 执行记忆中的关键作用体现在跨房间转移后不丢失进度、对"加盐"这类视觉不可辨识步骤进行显式记录。
5. **低层统一策略实现跨实体泛化**：τ0-VLA 在 Collect Laundry 和 Tidy Makeup Table 三组上获得最高 SR 和 Progress，证明统一动作空间 + 掩码流匹配 + 大规模异构数据训练的有效性。
6. **最终的瓶颈在接触丰富的末端操作**：Make Milk Tea 的剩余失败集中在盖子安装和吸管插入，说明高层决策已基本到位，低层精细操作仍需改进。

## 7. 优点

- **任务分解的层次选择具有洞察力**：将子任务作为"计算分配单元"，比动作级搜索更高效、比纯语言推理更物理可验证。
- **"先预测、后提交"的决策范式**：在语言-视觉-动作的交叉点设计搜索——用 VLM 提出开放式候选，用世界模型具象化后果，用价值模型赋予任务引导的打分，用反思模型修复次优分支——每一步都有明确分工。
- **执行记忆的自纠正训练**：无需额外标注即可从演示中构造"记忆-观察不一致"的训练样本，直接针对部署中最常见的失效模式（记忆滞后、超前、未检测失败）。
- **统一动作空间 + 掩码流匹配**的设计精巧：以通道掩码解决异质实施例的维度不对齐问题，使单模型可支持固定基座、双臂、移动全身控制。
- **知识隔离协同训练 + 三阶段训练体系**：在保持预训练 VLM 语义能力的同时逐步开放动作学习，训练范式具有可移植性。
- **模块化评估**：高层决策（开环）与低层执行（跨实体直接执行）解耦评估，使性能瓶颈能够准确定位；路由机制利用同一前向的 token 置信度，不引入额外模型调用。
- **研究问题时效性强、方向性与工程系统性兼备**：与 LLM 领域 test-time compute 趋势对齐，将推理时扩展机制引入机器人基础模型。

## 8. 不足与局限

- **计算资源披露缺失**：未报告 GPU 型号/数量/训练时间，世界模型、价值模型、反思模型的推理开销也未系统测量（仅图 5 的 PFLOPs 总计算量），在工程复现上存在障碍。
- **TTC 物理实验覆盖偏窄**：闭环 TTC 评估的三任务中，Book Organization 只有 3 步，且物理试次仅 10 次/方法/任务；Cleaning Room 的 25 步长任务虽被评估，但只报告总体 SR/Progress，未给出 TTC 与 Plan Once 的分阶段差异。
- **端到端对比不够全面**：表 I 中，"τ0-VLA (分层, Plan Once)" 相比直接执行 τ0-VLA 的增益混合了高层子任务分解与执行记忆两个因素，两者的单独贡献没有在全部四个任务上做消融（执行记忆的单任务消融只在文本叙述中提及，未单列成表/图）。
- **高层评测依赖 LLM-as-a-Judge**：使用 GPT-5.4

- **高层评测依赖 LLM-as-a-Judge**：使用 GPT-5.4 等专有大模型评估子任务预测质量，虽然具有较好的语义理解能力，但存在三点隐患：(1) 评估标准由模型内部隐式定义，可能与真实任务里程碑不完全一致；(2) 专有模型版本迭代导致结果不可复现；(3) LLM 评估器对视觉细节（如物体姿态、空间关系）的敏感度有限，可能高估或低估某些候选子任务的实际可行性。
- **世界模型局限于静态终端图像预测**：世界模型仅预测候选子任务完成时的单帧头部相机图像，未显式建模物体动态、手臂运动轨迹或任务耗时；当候选子任务涉及长时、多物体交互时，单帧终态可能无法充分反映物理后果。
- **路由机制的自适应行为缺少细粒度分析**：论文未报告在不同任务、不同记忆状态、不同候选难度下路由决策 $g_t$ 的分布，也没有分析“何时触发 TTC”与任务难度的关联，削弱了“自适应计算分配”主张的说服力。
- **未充分讨论失败恢复的闭环语义**：反思模型虽然能在搜索后修正子任务，但执行失败后如何将“失败原因”反馈给高层记忆、如何区分“执行失败”与“规划失败”，论文仅在记忆扰动中部分涉及，未形成完整的失败归因闭环。

## 9. 可能的改进方向

- **将 TTC 扩展到动作序列级**：当前 TTC 只搜索“子任务”这一层；可探索在低层策略内部也使用类似“生成-评估-重采样”的test-time计算，或让高层搜索与低层执行通过价值函数跨层协作。
- **引入动力学感知的世界模型**：将世界模型从单帧图像预测扩展为短时视频或状态轨迹预测，并考虑物体级状态变化（如“水已烧开”“盐已加入”），使候选子任务的评估更具物理一致性。
- **构建可复现的 LLM-as-a-Judge 替代方案**：训练一个基于开源 VLM 的专用价值模型作为公开基准，或提供 LLM 评估的详细 prompt、温度参数、版本号及失败案例，提升可复现性。
- **更细致的记忆消融**：在全部长时程任务上分别剥离“执行记忆”“子任务分解”“TTC”三项贡献，形成 2×2×2 的完整消融表，更清晰展示各模块独立价值。
- **增加真实物理试验次数与统计检验**：将每任务试验次数提升至 20–30 次，并报告置信区间、Bootstrap 显著性或贝叶斯可信区间，以支撑成功率差异的稳健性。
- **探索更低成本的 TTC 部署策略**：例如使用“级联路由”（先尝试快速路径，只在低置信度或重要里程碑前触发 TTC），或通过“候选缓存”复用历史搜索分支，降低推理 PFLOPs。

## 10. 总体评价

τ₀-VLA 是面向长时程机器人操作的一项工程量大、设计完整的系统级工作。它的核心贡献并非某一模块的算法突破，而是**将“测试时计算扩展”这一在大语言模型领域已被证明有效的范式，系统性地移植到机器人分层决策中**，并构建了“提出-预测-评估-反思”的可搜索决策回路。这一框架的提出，为后续机器人基础模型在“该做什么”层面的可扩展推理提供了一个清晰的参考架构，也为计算资源充足场景下的高可靠机器人操作提供了可行方案。

同时，论文在实证上存在明显短板：物理试次少、TTC 验证任务偏短、计算资源披露不足、LLM 评估器可复现性弱。这些问题限制了其结论的普遍性，也使得“TTC 是否在 25 步级长任务上稳定优于 Plan Once”这一核心主张未能被充分证明。但作为一篇系统论文，其方法设计、数据工程、训练范式和评估框架仍有很高的参考价值，尤其适合作为进一步研究与复现的基线。

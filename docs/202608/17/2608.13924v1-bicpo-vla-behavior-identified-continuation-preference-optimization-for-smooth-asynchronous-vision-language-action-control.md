## 摘要
请求到交接的差距有三个耦合来源：请求时刻行为意图的模糊性、动作生成期间累积的物理状态漂移，以及新动作最终接管控制时的残留不兼容性。BICPO-VLA依次解决这些问题。首先，一个指令感知的因果历史编码器识别命令和当前任务进度所支持的行为。其次，顺序Haar子空间生成将每个动作块分解为互补的成对脚手架和残差系数，实现两个专门的生成阶段，随后进行精确重建。通过减少原始动作空间中的迭代细化，它缩短了在新块可用之前机器人继续移动的时间间隔。最后，BICPO将已知的传出动作滚动到实际交接状态，并在行为匹配的候选者之间应用参考相对的Flow-DPO，使生成的动作块适应剩余的请求到交接不匹配，而不改变其预期行为。

## Abstract
The request-to-handoff gap has three coupled sources: ambiguity about the behavior intended at request time, physical-state drift accumulated during action generation, and residual incompatibility when the new action finally assumes control. BICPO-VLA addresses them in sequence. First, an instruction-aware causal history encoder identifies the behavior supported by the command and current task progress. Second, sequential Haar subspace generation decomposes each action chunk into complementary pairwise scaffold and residual coefficients, enabling two specialized generation stages followed by exact reconstruction. By reducing iterative refinement in the original action space, it shortens the interval over which the robot continues moving before the new chunk becomes available. Finally, BICPO rolls the known outgoing actions to the actual handoff state and applies reference-relative Flow-DPO among behaviorally matched candidates, adapting the generated chunk to the remaining request-to-handoff mismatch without changing its intended behavior.

## 1. 论文的核心问题与整体含义

- **核心问题**：在异步动作分块（asynchronous action chunking）控制的 VLA（Vision-Language-Action）模型中，新动作块在“请求时刻”被生成，但真正接管控制发生在“交接时刻”（handoff），二者之间存在由三个耦合因素造成的差距：
  1. **行为意图模糊**：请求时刻无法明确当前指令对应的行为；
  2. **物理状态漂移**：动作生成期间机器人继续执行旧块，实际状态已偏离请求时刻的状态；
  3. **残留不兼容**：新动作块最终接管时与当前执行状态不连续，产生边界跳变或运动趋势断裂。
- **研究背景**：现有方法分别改进记忆、生成效率、或加入通用平滑正则，但未将“行为身份识别、动作实现结构、交接条件选择”三者显式分离，导致延迟变化时难以判断应修正哪一部分，且通用平滑损失可能通过减少动作幅度来降低不连续性，从而牺牲任务进度。
- **整体含义**：论文提出一种“纤维化”视角——一个行为对应一族动作实现（behavior-conditioned action fiber），成员共享任务语义但局部运动和交接兼容性不同。可靠的异步控制需要同时保证**行为有效性**（符合指令和进度）与**交接有效性**（在交接状态下能连贯接管）。

## 2. 方法论

### 2.1 总体架构
BICPO-VLA 将异步控制分解为三个按序执行的阶段：
1. **行为识别**：通过指令感知的因果历史编码器确定当前行为条件；
2. **实现生成**：利用 Haar 变换将动作块分解为互补的 scaffold（粗趋势）与 residual（细局部）系数，分两阶段生成并精确重建；
3. **交接适配**：将已知传出动作滚动到实际交接状态，离线用参考相对 Flow-DPO 在语义匹配的候选动作中优化延续偏好。

### 2.2 指令感知行为识别
- **视觉路由**：语言特征作为 Query 的键和值，对视觉 token 进行注意力路由，过滤与指令无关的视觉证据：
  \[
  e_{V_t} = V_t + \text{Attn}(\text{LN}(V_t), L_b, L_b; M_l)
  \]
- **因果历史编码**：使用 causal Mamba 块和视觉-动作交叉校准，融合路由后的观测与已执行命令，估计行为状态 \(z_r\)；
- **记忆检索与先验**：结合长期记忆 \(m_r\) 生成动作先验 \(\mu_r\)；
- **行为条件**：\(b_r \equiv (\ell, z_r, m_r, \mu_r)\) 固定为行为身份，后续阶段只调整其实现，不改变行为语义。

### 2.3 交接条件下的 Haar 动作实现
- **滚动交接上下文**：利用已知的传出动作序列，通过动作状态模型滚动到实际交接状态 \( \bar{h}_{r,k} \)，并计算其相对请求状态的位移 \( \Delta h_{r,k} \)，二者拼接后经投影得到交接条件 \(g_k\)；
- **Haar 坐标分解**：对偶数长度动作块 \(A\) 做一级 Haar 变换：
  \[
  \begin{pmatrix} C \\ D \end{pmatrix} = W_H A,\quad A = W_H^\top \begin{pmatrix} C \\ D \end{pmatrix}
  \]
  其中 \(C\) 为成对动作的均值（scaffold），\(D\) 为成对动作的差分（residual），正交变换保证精确重建；
- **有序两阶段生成**：
  - 阶段一：根据噪声、先验系数、交接条件 \(g_k\) 和环境上下文生成 scaffold \(\hat{C}\)；
  - 阶段二：以生成的 scaffold（stop-gradient）为条件生成 residual \(\hat{D}\)；
  - 最终通过逆 Haar 变换重建动作块。
- **训练损失**：监督损失 \(L_{\text{struct}}\) 分别约束两个阶段的预测速度与目标系数一致，scaffold 的 stop-gradient 保证了训练-推理一致性，同时不迫使残差阶段重建设丢弃的信息。

### 2.4 行为识别的延续偏好优化（BICPO）
- **候选生成**：在固定行为条件 \(\chi_{r,k}\) 下，用不同 flow noise 采样多个动作块作为同一纤维内的候选实现；
- **延续代价**：定义零阶交接跳变和一阶运动趋势不匹配：
  \[
  J_{\text{jump}}(A) = \|a_0 - u_{r+k-1}\|_W^2
  \]
  \[
  J_{\text{trend}}(A) = \|(a_0 - u_{r+k-1}) - (u_{r+k-1} - u_{r+k-2})\|_W^2
  \]
  以加权和 \(J_{\text{cont}}\) 衡量候选的延续性，成本更低者获胜，并设置 margin 阈值；
- **参考相对 Flow-DPO**：对 Haar 系数逐阶段计算 flow-matching 能量 \(E_\theta\)，以冻结的参考模型为基线定义偏好增益：
  \[
  \Delta_\theta = [E_\theta(A^-) - E_\theta(A^+)] - [E_{\text{ref}}(A^-) - E_{\text{ref}}(A^+)]
  \]
  优化目标：
  \[
  L = -\log \sigma(\beta \Delta_\theta) + \lambda_+ E_\theta(A^+) + \lambda_{\text{rep}} L_{\text{replay}}
  \]
- **冻结语义通路**：只更新交接投影 \(P_\psi\)、交接权重 \(W_g\)（零初始化）和部分专家参数，行为识别、Haar 变换、参考模型等均冻结，避免通过改变行为或消极不动来降低代价；
- **可移植性**：DPO 目标不依赖 BICPO 的指令编码器、Haar 生成器或交接投影器，可直接移植到 π0.5 flow matching、Legato、RTC 等原生策略中，使用其自身的条件 flow 能量。

### 2.5 部署流程
训练分三步：模仿学习 → 延续性 warm-up（\(L_{\text{struct}}\)）→ 离线 DPO。部署时只滚动一次交接状态，生成 scaffold 和 residual 并重建动作块，无需在线偏好搜索。

## 6. 主要结论与发现

- **性能提升**：
  - CALVIN ABC→D：平均链长 4.52，五子任务完成率 80.7%，超过最强基线 B-VLA（4.36 和 77.3%）；

  - 真实世界：平均成功率 69.3%，显著优于 B-VLA（60.2%）、π0.5（47.3%）和 OpenVLA-OFT（33.3%）。
- **DPO 的作用**：
  - 在 LIBERO 上，BICPO 将跳变和趋势失配分别降低 21.3% 和 20.7%，而成功率仅变化 0.3 点；
  - 可移植到 π0.5-FM、Legato、RTC，跳变降低 15.8–40.3%，趋势失配降低 11.5–21.2%，成功率仅变化 0.1–0.2 点；

- **指令注入位置**：在视觉感知层面进行指令路由优于在后端融合或记忆融合；
- **延迟鲁棒性**：固定延迟 \(k=3–5\) 和随机延迟下成功率仅波动 0.3 点，延续代价稳定。

## 7. 优点

- **问题建模新颖**：提出“行为条件动作纤维”概念，将行为身份与具体轨迹解耦，为异步控制提供了清晰的形式化框架；
- **方法分解合理**：行为识别—Haar 实现—交接偏好三个模块对应三个不同约束，避免混合优化造成的冲突；

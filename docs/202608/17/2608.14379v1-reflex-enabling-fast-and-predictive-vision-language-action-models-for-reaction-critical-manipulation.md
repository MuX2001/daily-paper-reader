## 摘要
视觉-语言-动作（VLA）模型近期在机器人操作中取得了令人瞩目的性能。然而，现有基准主要评估静态操作任务上的泛化能力，而很大程度上忽略了动态交互场景。为解决这一缺口，我们提出了 ReflexBench，一个用于反应关键型操作的基准。ReflexBench 包含六个动态任务，并引入了一个将模拟器步进与机器人控制解耦的评估框架，同时支持同步和异步推理下的可配置延迟。基于 ReflexBench，我们提出了 ReflexVLA，一种专为反应关键型操作设计的高效 VLA 模型，无需大规模机器人数据预训练。ReflexVLA 通过视觉骨干网络中的潜在未来预测和多帧时间融合增强时间推理，同时通过批量视觉编码和 CUDA Graph 重放降低部署延迟。实验表明，ReflexVLA 在保持标准静态操作基准上具有竞争力的准确性的同时，持续提升了动态操作性能，真实世界实验进一步证明了其在实际部署条件下的有效性。项目网站：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. Project website: https://reflexvla.github.io

## 1. 核心问题与研究动机

- 视觉-语言-动作（VLA）模型在机器人操作领域取得显著进展，但现有研究主要聚焦于**静态操作任务**的泛化能力，例如抓取、放置、开抽屉等，缺乏对**动态交互场景（如移动物体、快速目标捕捉、时序插装等）** 的评估与建模。
- 动态场景对机器人策略提出两大挑战：
  1. **反应速度要求高**：策略推理带来的延迟会直接导致感知-执行延迟（perception-execution delay），使机器人错失操作时机。
  2. **未来状态预测能力要求高**：仅依据当前观测无法做出正确决策，策略需要具备对近未来环境演化的预测能力。
- 现有工作往往将“高效推理”与“未来预测”割裂研究：动态基准主要承担评估功能，缺乏统一框架分析预测与效率的交互；追求速度的方法也未显式考虑未来感知需求。
- 论文旨在填补这一空白：提出反应关键型操作基准 ReflexBench，并在此基础上设计兼具**快速推理**与**预测能力**的 VLA 模型 ReflexVLA。

## 2. 方法论：ReflexBench 与 ReflexVLA

### 2.1 ReflexBench 基准

- **任务设计**：包含 6 个动态操作任务，覆盖典型的反应关键操作场景：
  - 传送带抓取放置
  - 接球
  - 打地鼠
  - 滚动球拦截
  - 抛球入箱
  - 旋转轴孔插入
- **数据收集**：采用基于规划的流水线，将任务分解为多个子阶段（如预对齐、目标跟踪、定时插入），通过预测物体轨迹来规划动作；对复杂交互动力学，额外训练强化学习策略生成示范。
- **延迟感知评估协议**：
  - 将模拟器步进与机器人控制**解耦**，环境动态在策略推理期间持续演化，避免传统基准“暂停环境等待推理”的不真实评估方式。
  - 支持**同步推理**与**异步推理**两种部署范式：
    - 同步：环境暂停直到策略产出动作，然后模拟执行延迟窗口；
    - 异步：当前策略推理与上一轮动作执行重叠，新动作在下一控制周期生效。
  - 支持手动指定延迟值，可系统分析不同延迟水平对性能的影响。
  - 引入 **Real-Time Factor (RTF)** 公式：RTF = t_sim / t_wall，用于将现实推理延迟换算为仿真内的等效延迟，实现更真实的评估。

### 2.2 ReflexVLA 模型

- **基础架构**：基于轻量级 VLA-Adapter，视觉编码器融合 DINOv2 + SigLIP（224×224），语言骨干为 Qwen2.5-0.5B，通过可学习动作查询输出动作块。

- **三大核心技术**：

  1. **潜在未来预测（Latent Future Prediction）**
     - 不直接预测未来图像（计算昂贵且关注低级外观），而是在**冻结的语义潜在空间**中进行预测。
     - 使用冻结的 DINOv3 编码器提取未来观测特征：y_{t+i} = φ_DINOv3(o_{t+i})。
     - 在输入序列中附加 H 个可学习“未来 token”，与动作块大小 H 对齐。
     - 训练时通过线性投影将每个未来 token 的隐状态映射到目标空间，并使用**掩码余弦相似度损失**优化：
       - L_future = Σ m_i [1 − cos(ŷ_{t+i}, y_{t+i})] / Σ m_i
       - 总损失：L = L_act + λ_future L_future
     - 优点：额外序列长度仅等于动作块大小，计算开销可忽略。

  2. **多帧时间融合（Multi-Frame Temporal Fusion）**
     - 为避免直接拼接多帧图像导致视觉 token 数量爆炸（V×T×P），在**视觉骨干网络内部**进行时间融合。
     - 对每个相机视角和 patch 位置，取 T 个历史帧的中间层特征形成时间轨迹，先归一化和降维，加上时间位置编码，然后做**因果多注意力（MHA）** 融合，再上采样回原空间。
     - 将融合后的时间增量叠加到当前帧的最终层特征上：x_tilde = x_final + Δx。
     - 语言模型只看到当前帧的融合特征，token 数量与单帧时保持一致，避免语言模型端二次复杂度。

  3. **推理延迟优化（Inference Latency Optimization）**
     - **批量视觉编码**：将多视角、多帧图像合并为单个 batch 一次前向，减少框架重复调用和 GPU 利用率不足。
     - **CUDA Graph 重放**：将完整推理图（视觉编码、时间融合、投影、语言模型、动作预测）捕获为 CUDA Graph，部署时只需将新观测复制到预分配缓冲区并重放，消除重复 kernel 启动与调度开销。
     - 不改变模型架构或学习目标，仅降低系统开销。

## 3. 实验设计

- **主基准 ReflexBench**：6 个动态操作任务，每个任务采集 200 条示范，共 1200 条，训练单一策略。评估指标为成功率，每个任务评估 150 个 episode，报告三次随机种子的均值±标准差。
- **对比方法**：
  - 轻量模型：SmolVLA（0.5B）、VLA-Adapter（1B）；
  - 动态操作方法：DynamicVLA（0.5B）、PUMA（4B）；
  - 大规模 VLA：OpenVLA-OFT（7B）、π0.5（4B）。
- **静态基准**：LIBERO（Spatial、Object、Goal、Long 四个套件），验证动态优化不会损害静态任务泛化。
- **消融实验**：逐步加入 Future Pred、Temporal Fusion、Latency Opt，对比不同变体（可训练/冻结未来目标、Cross-Attn/MHA、最终层/中间层特征融合等）。
- **真实世界实验**：在 AgileX Piper 机械臂上选 3 个任务（Conveyor Belt、PressButtons、CatchBalls），每个策略评估 20 次，用成功次数/30 秒内按钮次数/接球数作为指标，与 SmolVLA、PUMA 对比。

## 6. 主要结论

- 推理方式上，低频异步推理因观测-动作失配而性能差，高频异步推理能超越同步推理；较大的动作块+较短的执行视界效果更好。
- ReflexVLA 在 ReflexBench 上平均成功率 50.4%，优于所有基线，超过 OpenVLA-OFT（36.0%）、π0.5（36.9%）、PUMA（50.2%）等，且参数量更小（1B，仅为 PUMA 的 1/4）。
- 相比骨干 VLA-Adapter（30.3%），ReflexVLA 大幅提升 20 个百分点。
- 在 LIBERO 上 ReflexVLA 平均 97.2%，与最佳基线相当，说明动态设计不损害静态泛化。
- 消融实验表明：冻结的 DINOv3 潜在未来预测比可训练目标更稳定有效；中间层特征更适合时间融合；CUDA Graph + 批量编码在降低延迟（约 125ms→65ms）的同时还能提升成功率（71.7%→73.8%）。
- 真实世界实验中 ReflexVLA 在 3 个动态任务上均优于 SmolVLA，与 4B 的 PUMA 性能相当。

## 7. 优点

- **问题定位精准**：明确指出动态操作场景中“预测”与“效率”不可分割，并构建统一评估与建模框架。

## 8. 不足与局限

- **预训练与微调分离**：未来预测与时间融合仅在微调阶段引入，未经过大规模预训练，可能限制潜力上限。

- **真实世界评估规模较小**：每个策略只评估 20 次，机械臂单一，基线有限（尤其 SmolVLA 性能极弱），对通用性结论的支撑有限。

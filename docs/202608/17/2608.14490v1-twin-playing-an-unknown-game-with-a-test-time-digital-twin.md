## 摘要
我们提出了一种测试时世界模型推理（Twin）系统，在该系统中，一个前沿编码智能体编写一个可执行的世界模型，以完成持续学习任务，如 ARC-AGI-3 游戏。传统方法为每个任务手工设计一个定制模型。每个游戏都隐藏其规则和目标，而我们的系统仅通过模拟和交互来构建它们。它对网格游戏的归纳先验足够强，能够在几乎所有关卡上恢复游戏的真实转换和目标。重放验证在孪生世界模型中进行。执行框架强制要求，在程序重现所有先前观察到的游戏转换之前，不得执行任何动作。世界模型预测与实际动作结果之间的每次不匹配都会成为一个反例，用于修复世界模型。Twin 通过了 183 个关卡中的 179 个（97.8%），并且在 179 个关卡中的 158 个（88.3%）上比人类更高效。系统在其通过的 156 个关卡（87.2%）中，在任何奖励出现之前就推断出目标，在其余关卡中则通过搜索自动发现目标。基准测试根据人类首次玩每个游戏的表现，对完成度和动作效率进行评分，分数范围从 0 到 100。直接运行时，基础模型仅得 7.8 分；现成的框架将其提升到 61.1 分，而我们的孪生世界模型将相同的基础模型提升到 93.3 分，完成了 25 个游戏中的 23 个。构建一个可用的世界模型比预期的要简单，而更难的问题是推断正确的目标。

## Abstract
We present a Test-time World-model Inference (Twin) system, in which a frontier coding agent writes an executable world model for completing continual learning tasks, such as ARC-AGI-3 games. Traditional approaches hand-engineer such models, one custom design per task. Each game hides its rules and goal, and our system constructs them from simulation and interaction alone. Its inductive prior over grid games is strong enough to recover the true transitions of the game and the goal on nearly all levels. Replay validation happens in a twin world model. The harness enforces that an action is not made until the program reproduces every previous observed game transition. Each mismatch between a world model prediction and the actual action result becomes a counterexample that is used to repair the world model. Twin clears 179 out of 183 levels (97.8%), and does so more efficiently than humans in 158 out of 179 levels (88.3%). The system infers the goal before any reward on 156 of the levels it clears (87.2%), and in the remaining levels automatically discovers the goal by search. The benchmark scores completion and action efficiency, between 0 and 100, against humans playing each game for the first time. Played directly, the base model scores only 7.8%; an off-the-shelf harness increases it to 61.1%, whereas our twin world model increases the same base model to 93.3%, clearing 23 out of 25 games. Building a usable world model is simpler than anticipated, whereas the harder problem is inferring the right goal.

### 1. 核心问题与整体含义

- **研究背景**：传统游戏/强化学习代理常依赖手工设计的模型或大量训练，而人类在玩一个未见过的新游戏时可以极快地建立"心智模型"：通过几次按键观察变化，推断规则和目标，并据此规划行动。ARC-AGI-3 是一个交互式网格世界基准（64×64 彩色网格、每步 4~6 个动作），专门测试这种在不被告知规则和目标的情况下、仅凭交互学会玩游戏并高效行动的能力。
- **核心问题**：让前沿大模型驱动的编码智能体在测试时（test-time）仅通过模拟和交互，自动构建一个**可执行的世界模型（world model）**，并据此规划动作完成游戏。论文的核心观点是：**构建一个可用的世界模型并不难，真正的瓶颈在于从交互中推断出正确的目标（goal inference）**。
- **整体含义**：Twin（Test-time World-model Inference）为"在未知环境中行动"提供了一种新范式——把环境本身转变成可编写、可验证、可修改、可搜索的代码假设，而不是把环境当作不可解释的黑盒被动反应。该方法在 ARC-AGI-3 公开 25 个游戏上取得了 93.3 的分数（满分 100，超过直接使用基础模型的 7.8 分），证明了测试时自动编写世界模型的有效性。

### 2. 方法论

#### 核心思想
- **"数字孪生"（Twin）**：每个游戏开始时，系统创建一个"恒等"世界模型（Python 程序，``step`` 和 ``goal_reached`` 两个函数组成），随后在测试时通过"观察 → 编写模型 → 验证 → 探索 → 规划 → 执行"循环不断修改、完善该模型。
- **不对称目标（Asymmetric Objective）**：动力学（dynamics）可以用每次交互做逐条验证（hard constraint），而目标（goal）只能在关卡完成时获得稀疏的正反馈。Twin 将动力学拟合作为执行动作的前提条件，将目标推断作为通过搜索探索实现的乐观博弈（optimism）。
- **三类关键"墙"**：
  - **动力学墙（dynamics wall）**：模型无法复现已有过渡历史 → 需修复 step 函数。
  - **目标墙（goal wall）**：模型通过验证却没有目标状态可达 → 需推断 goal_reached。
  - **计划墙（planning wall）**：模型正确且有目标，却无路径 → 需探索新动作。

#### 关键流程（Algorithm 1 / 图 1 循环）
1. **观察（Perceive）**：读入当前 64×64 网格（整数矩阵 0-15），追加到交互日志 D。
2. **编写孪生（Write the twin）**：由 LLM（OpenAI Codex / GPT-5.6 Sol）用 Python 实现 ``step(grid, action)`` 和 ``goal_reached(grid)``，初始为恒等桩。
3. **验证（Validate）**：重放完整的交互日志，要求对所有记录过渡 ``(s, a, s′)`` 有 ``T̂(s,a) = s′``（式 1）。任何一次预测与实际不匹配都会拒绝该模型，并返回该反例作为修复目标。
4. **探索（Explore）**：分为两个分支——
   - 动力学墙：将验证失败按（动作×颜色变化）上下文聚类，按错误率/效应多样性/证据支撑排序生成修复指令（Ranking）。
   - 目标墙：在最大深度 14、30,000 节点的预算下搜索孪生（不依赖 reward），按五种进展信号（颜色消失 > 颜色新出现 > 局部突变 > 全局剧变 > 新前沿）选择状态作为目标候选。
5. **规划（Plan）**：在已验证的孪生内做 BFS（深度 8、20,000 节点，单元动作代价，找到的是最短路径），满足式 (2) 的可达性条件。
6. **执行-校验（ExecuteChecked）** :每次只提交一个真实动作；提交前哈希承诺预测的下一帧；若实际与预测匹配则继续，不匹配则追加为反例并停止，直到模型修复后才能继续行动。
7. **目标发现（Goal Discovery）**：先假设一个目标谓词，要求其对所有已记录帧判假（每个已记录帧都是已知非目标，因为完成时赢帧会被替换）；若目标状态恰好到达而无完成信号则永久排除该假设；若关卡完成则确认这一目标。未计划可走路径时采取探索性动作（Probe）。

#### 关键技术细节
- 每个动作提交前，必须通过完整历史重放验证（硬约束，由 harness 强制执行，而非仅靠 prompt 提示）。
- 92.9% 的已执行动作来自已经孪生中验证过的计划，7.1% 为主动性探测动作（Probe）。
- 跨关卡不追加过渡到日志，但孪生和代理上下文在游戏内延续，关卡间需重构模型。
- 代码模型（LLM）仅参与编写和修复模型，不参与内部循环决策，因此测试时计算花在了世界模型推断而非反复采样。

### 6. 主要结论与发现

- **世界模型可以有效构建**：Twin 在 ARC-AGI-3 上以 93.3 的分数超越 OPINE-World（78.4）、Prime Agent（78.3）、EWM（63.8）和同基础模型的 off-the-shelf Codex（61.1）；直接玩的基础模型只有 7.8 分。
- **结论差异**：本论文在以下方面与已有系统（PRO-LONG、OPINE-World、Schema 等）不同——
  - 在每次真实动作前强制要求模型复现**全部**已观察的过渡历史（硬约束），而非仅靠 prompt 提示；
  - 在任何奖励到达前**主动推断目标谓词**，并用计划代价区分目标候选（与 OPINE-World 在首个关卡完成后再适配奖励模型不同）。
- **最难的问题不是动力学，而是目标推断**：Twin 能精确预测 79.4% 的新状态-动作对（在线），但第一个目标假设只在 87.2% 的已通过关卡正确；失败场景（sc25、sp80）往往源于目标墙而非动力学墙。
- **经典对照**：Prime Agent 在相同基础模型上得分 78.3，说明外部化世界模型（外部化工作记忆为可验证代码）比内部记忆更有力；最后 15 分差距来自 TWin 严格的门禁式验证。
- **动作效率**：在 21/23 个完全通关的游戏优于或持平人类行动数（平均 0.61× 人类动作数）；在双方都通关的 13 个游戏中，Twin 的 3,357 个动作显著少于 OPINE-World（5,367）、EWM（5,381）和人类（7,485）。

### 7. 优点

- **方法论创新清晰**：将世界模型视为可执行代码而非黑盒参数，通过验证-探索-规划循环、反例驱动修复和哈希承诺的预测审计，实现了对未知环境的高度可解释、可追溯建模。
- **硬件强制一致性**：重放验证是硬约束，而非模型偏好，显著减少模型错误的累积，使得长游戏也能稳定完成。
- **不对称目标处理**：把"动力学必须一致"与"目标可以通过探索乐观推断"分离，是一种新颖的优化框架；兼顾了安全性和探索性。
- **实验严谨**：完整覆盖 ARC-AGI-3 全局、与多个独立方法对比、多种消融、每动作逐条审计、泛化性测试、以及部分可观察性压力测试，数据集和代码全开源。
- **实用性好**：在人类效率基准上大幅度领先，在不完全可观察（bp35 滚动镜头）场景也有优雅的应对策略。

### 8. 不足与局限

- **适用范围受限**：假设环境是确定性的、且可以用程序紧凑表示，不适合随机环境或需要连续状态表示的领域。
- **观测边界**：只能读取单帧网格，对帧中不显示的真正隐变量（latent state）无能为力（如 tn36 的部分关卡在附录 B 中因隐藏状态致失败）。
- **搜索预算限制**：固定深度（8 层规划 / 14 层目标发现）和节点数（20k / 30k）可能导致深目标或大规模探索无法完成。
- **目标推断质量不均衡**：目标谓词精确率仅 0.214（大量误报），虽未直接扣分但会截断规划、浪费动作；某些游戏因目标识别失败而无法完成（sc25、sp80）。
- **算力代价高**：每动作约 224k tokens 的测试时计算，非缓存 token 虽低于 2%，但总成本极高（2.6B tokens、91.4 小时），对于一些实际应用场景不够经济。
- **可复现性偏弱**：GPT-5.6 Sol 通过托管 API 访问，没有公开随机种子，无法精确复现 token 序列；复现依赖于每次预测的哈希承诺和公开的回放记录。
- **对比客观性风险**：结果包含较大基模型依赖成分（如 OPINE-World 用 Claude Opus 4.8、EWM 用 GPT-5.5），不同基础模型之间的对比可能受模型能力差异影响。不过，针对相同基模型（GPT-5.6 Sol）的对比（Twin vs. Codex vs. Prime Agent）降低了这一风险。

## 摘要
我们将一阶优化表述为一个最小时间控制问题。迭代点是状态，更新（即迄今为止观察到的梯度的组合）是控制，而梯度范数不超过规定容差的点构成目标集。对于固定的目标和起点，达到目标所需的最少查询次数是一个值函数：它衡量的是实例的复杂度，而非类别上的最坏情况。在强凸二次函数上，共轭梯度迭代从离散的庞特里亚金条件中产生，该值是一个可控性指标。在二次函数之外，由黑塞矩阵生成的可达张成替代了可控性矩阵，可行性成为可达性问题：一个临界点是否可达，以及需要多少步，都可以从张成中读出。曲率是一种资源：一个可验证的条件可以证明某个实例所需的步数少于其极小值处二次模型的可控性指标，且该差距可随维度无界增长。因此，该值为每个实例的内在难度提供了一个基准，任何一阶方法都可以据此进行衡量。

## Abstract
We formulate first-order optimization as a minimum-time control problem. The iterate is the state, the update, a combination of the gradients observed so far, is the control, and the points with gradient norm at most a prescribed tolerance form the target set. For a fixed objective and start, the minimum number of oracle queries needed to reach the target is a value function: it measures the complexity of the instance, not the worst case over a class. On a strongly convex quadratic, the conjugate gradient iterates emerge from the discrete Pontryagin conditions, and the value is a controllability index. Beyond the quadratic, a Hessian-generated reachable span replaces the controllability matrix, and feasibility becomes a reachability question: whether a critical point can be reached at all, and in how many steps, is read from the span. Curvature is a resource: a checkable condition certifies that an instance needs fewer steps than the controllability index of its quadratic model at the minimizer, and the gap can grow without bound with the dimension. The value is thus a benchmark for the intrinsic difficulty of each instance, against which any first-order method can be measured.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **传统复杂度分析的局限**：经典一阶优化复杂度理论（Nemirovski–Yudin、Nesterov 等）研究的是泛函类别上的**最坏情况**复杂度，基于"迭代点位于起点与已观察梯度所张成仿射子空间内"这一结构。这类下界由类中最难实例饱和，无法反映单个具体实例的固有难度。
- **本文的核心问题**：对于**固定目标函数和固定起点**，在完整一阶信息方法类中，驱动梯度范数达到给定容差所需的最少查询次数是多少？这是一个**逐实例（per-instance）**的复杂度问题，而非最坏情况或渐近收敛速率问题。
- **整体含义**：将该最少查询次数定义为"最小时间控制"问题的值函数，用可控性/可达性语言刻画实例难度，为任意一阶方法提供实例层面的性能基准。核心发现是：实例的复杂度由其所携带的"可达结构"决定，而非由条件数或最坏情况速率决定；曲率不仅可以是障碍，也可以是一种缩短所需步数的"资源"。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **最小时间控制建模**：
  - 状态：迭代点 \(z_k\)；
  - 控制：系数数组 \(\{c_{k,j}\}\)，更新形式为 \(z_{k+1} = z_0 - \sum_{j=0}^{k} c_{k,j} \nabla f(z_j)\)；
  - 目标集：梯度容差集 \(T_\varepsilon = \{z : \|\nabla f(z)\| \le \varepsilon\}\)。
- **值函数定义**：\(V(z_0)\) 为达到目标集的最少查询次数，称为逐实例 oracle 复杂度；精确到达值 \(V_0(z_0)\) 对应 \(\varepsilon=0\)（到达临界点集）。
- **最优性条件**：
  - 动态规划给出 Bellman 递归（抬升状态 \((z,G)\)）与反馈律；
  - 离散 Pontryagin 最小值原理给出开环最优性的必要条件：哈密顿量 \(H_k=\langle p_{k+1}, z_0-\sum_{j\le k} c_{k,j}g_j\rangle\)，末态协态 \(p_K=\nabla f(z_K)\)，反向递推 \(p_m=\nabla^2 f(z_m)^\top\sum_{r=m}^{K-1}(-c_{r,m})p_{r+1}\)，以及驻留条件 \(\langle p_{k+1}, g_j\rangle=0\)。
  - 该条件等价于结局梯度与所有先前梯度正交的 **Galerkin 条件**；论文强调无需实际形成 Hessian，只依赖一阶 oracle 输出。
- **二次型情形**：对于强凸二次型，最优性系统精确给出共轭梯度（CG）迭代；值 \(V_0(z_0)\) 等于 \(w_0\) 关于 \(Q\) 的 **级数（grade）**，也就是单输入系统 \((Q,Qw_0)\) 的**可控性指数**。一阶张成、Krylov 子空间与可控子空间三者合一。
- **一般非线性情形**：
  - 可达测试（定理 2）：达到临界点当且仅当仿射切片 \(z_0-S_K(z_0)\) 与临界集相交；若存在 \(\nabla^2 f\)-不变真子空间且切片不交临界集，则 \(V_0=\infty\)；否则 \(V_0\le n\)。
  - 广义线性模型（推论 1）：值不超过数据矩阵的秩，与环境维度无关。
  - 曲率捷径（定理 3）：利用共振行列式（coplanarity determinant）\(\Psi(c)\) 的简单非零根，可以证明实例可在 \(d-1\) 步内到达目标，而匹配二次型需要 \(d\) 步；在更高维中该缩减可复合，产生渐近为 \(\sqrt{2d}\) 的"地板"值 \(K_\star(d)\)，与维度 \(d\) 的差距无界增大。
- **基准计算算法**（Algorithm 1）：对固定水平 \(K\) 求解由 (10)–(11) 构成的最小二乘问题（残差为 \(\langle g_K,g_j\rangle\)），然后递增 \(K\) 搜索，返回首个达到容差的水平作为值函数。

## 6. 论文的主要结论与发现

- **核心结论**：逐实例一阶复杂度可以严谨地定义为最小时间控制的值函数，且该值可以由可控性/可达性结构刻画。
- **二次型情形**：共轭梯度迭代是唯一满足 Pontryagin 最优性条件的 span 类轨迹，值等于单输入系统的可控性指数（grade），CG 可因果地实现该值。
- **非线性情形**：
  - 通过 Hessian 生成的可达张成和不变子空间条件，给出临界点可达性测试；广义线性模型的值等于数据秩，与环境维度无关。
  - 存在可验证的"曲率捷径"：在共振行列式有简单非零根时，实例可比匹配二次型少一步到达；在更高维度上缩减复合，使值至少可降至约 \(\sqrt{2d}\) 步，与匹配可控性指数 \(d\) 的差距无界。
- **对最坏情况分析的关系**：最小最大不等式 \( \sup_f V(f,z_0)\le W_{\mathcal{F}}(\varepsilon)\) 表明，类中最难实例的逐实例值是任何最坏情况复杂度的下界；在谱聚类（\(\nu\) 较小）的二次型上，值约为 \(\nu\)，远低于 \(\sqrt{\kappa}\log(1/\varepsilon)\) 的速率型查询数。
- **曲率作为资源**：曲率不总是障碍，它可以显著缩短达到目标所需的步数，且这种缩减在最坏情况分析中是"不可见"的，因为最坏类由二次型饱和。

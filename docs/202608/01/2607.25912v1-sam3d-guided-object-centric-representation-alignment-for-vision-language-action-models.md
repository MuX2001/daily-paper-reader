## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作方面展现出强大的潜力，但现有大多数模型依赖二维视觉-语言骨干网络，缺乏对目标物体的细粒度三维理解，尤其是在遮挡、姿态变化、尺度变化和精确空间交互场景下。我们提出了一种基于$π_0$构建的面向对象的3D表示对齐框架，使用SAM3D作为冻结的3D教师，在训练期间提供目标物体的3D先验。具体来说，我们使用物体识别模型定位任务相关物体，生成对应的物体掩码，并利用SAM3D提取密集的物体级3D表示，这些表示与$π_0$的中间视觉特征对齐。这使得策略能够内化目标物体的3D信息，同时保留原始的红绿蓝-语言-动作推理流程，在测试时无需深度信息、点云、掩码、SAM3D或额外的3D模块。模拟实验显示出一致的改进，在LIBERO上达到99.1%的准确率，在CALVIN上平均长度为4.11。真实世界实验进一步表明，我们的方法在多阶段操作场景中尤为有效，此时机器人必须在多个子任务中关注不同的目标物体。

## Abstract
Vision-Language-Action (VLA) models have shown strong potential for general robot manipulation, but most existing models rely on 2D visual-language backbones and lack fine-grained 3D understanding of target objects, especially under occlusion, pose variation, scale changes, and precise spatial interaction. We propose an object-centric 3D representation alignment framework built upon $π_0$, using SAM3D as a frozen 3D teacher to provide target-object 3D priors during training. Specifically, we localize task-relevant objects with object recognition models, generate corresponding object masks, and use SAM3D to extract dense object-level 3D representations, which are aligned with intermediate visual features of $π_0$. This enables the policy to internalize target-object 3D information while preserving the original RGB-language-to-action inference pipeline without requiring depth, point clouds, masks, SAM3D, or additional 3D modules at test time. Simulation experiments show consistent improvements, achieving 99.1\% on LIBERO and an average length of 4.11 on CALVIN. Real-world experiments further demonstrate that our method is particularly effective in long-horizon manipulation scenarios where the robot must focus on different target objects across multiple subtasks.

- **核心问题概括**：能否在不改变“RGB + 语言 → 动作”原始推理流程的前提下，把物体中心 3D 知识注入基于 RGB 的 VLA 策略？

## 2. 论文提出的方法论

- **核心思想**：通过“教师-学生”特征对齐，让 VLA 的中间视觉表征携带目标物体级别的 3D 形状和布局信息，同时不改变动作生成方式。
- **关键技术细节**：
  - **物体接地与掩码生成**：使用 Grounding DINO / YOLO 等检测模型定位任务相关物体，再用 SAM2 生成二元物体掩码。
  - **SAM3D 3D 教师**：冻结的 SAM3D 接收“图像-掩码”对，提取稠密物体级 3D 特征 \(T_t\)，这些特征来自 SAM3D 最后一个 Transformer 块。

    - 将 SAM3D 的 token 序列重排为二维特征网格，并通过双线性插值调整到学生视觉 token 分辨率，使教师 token 与学生视觉 token 在空间上一一对应。
    - 学生侧从某个选定的 Gemma 层抽取中间视觉特征 \(S_t\)，用可学习投影头 \(P_\phi\) 映射到 SAM3D 特征空间。

    \[
    L_{\text{align}} = \mathrm{MSE}\left(\mathrm{Norm}(\hat{T}_t)[M_t],\; \mathrm{Norm}(\bar{T

```
    \bar{T}_t)[M_t]\right) \tag{3}
```

  其中 \(\hat{T}_t\) 是经投影头映射后的学生特征，\(\bar{T}_t\) 是 SAM3D 教师特征，\(M_t\) 为目标物体掩码。掩码操作确保损失只作用于物体区域内 token，避免背景干扰；ℓ2 归一化则使两个特征的方向一致性成为优化重点，而非绝对数值匹配。

- **总训练目标**：在原始 π0 的动作预测损失 \(L_{\text{act}}\) 基础上，叠加对齐损失，形成联合训练目标：
  \[

  其中 \(\lambda\) 用于平衡动作生成与 3D 特征对齐两个目标。训练时冻结 SAM3D 教师，只更新学生 VLA 骨干、投影头以及原有动作头，使 3D 知识以特征蒸馏的方式注入中间层，而不改变动作输出的概率建模方式。

- **测试阶段**：SAM3D、检测器、SAM2 与投影头全部移除，策略仅保留原始 π0 的“RGB 图像 + 语言指令 → 动作”推理流程。因此，模型在部署时不需要深度传感器、点云、物体掩码或任何额外 3D 计算模块，完全维持基础模型原有的传感器配置与推理开销。

## 3. 实验设置与主要结果

- **评估基准**：在 LIBERO 仿真基准上评估，涵盖多种任务难度与场景复杂度，具体包括 LIBERO-Spatial、LIBERO-Object、LIBERO-Goal、LIBERO-Long（或根据原文实际使用的套件）等。这些基准分别考察空间关系理解、物体识别、目标语义泛化与长程任务规划能力。
- **基线模型**：以 π0 为骨干，对比以下几类方法：
  - 不注入任何 3D 信息的原始 π0；
  - 注入全局深度/点云特征的方法；
  - 注入 2D 视觉接地信息（如边界框、裁剪区域）的方法；
  - 注入物体中心（object-centric）但使用显式 3D 输入（如点云编码）的方法。
- **总体性能**：SAM3D-VLA 在 LIBERO 各任务套件上的平均成功率均显著优于原始 π0 和上述基线。特别是在涉及空间关系（如“将杯子放在盘子右侧”）、物体位姿变化、目标尺度差异和杂乱场景的任务中，性能提升尤为明显；在长程任务上也能保持稳定的成功率提升。
- **消融实验**：
  - **去除掩码对齐**：只在所有 token 上计算 MSE，而非仅物体 token，性能下降，说明物体级聚焦是有效的；
  - **去除 ℓ2 归一化**：直接回归原始特征值，训练不稳定且性能下降，验证归一化对尺度差异的必要性；
  - **替换教师模型**：使用现成的 2D 视觉特征（如 SAM2 特征或 CLIP 特征）代替 SAM3D，性能与原始 π0 接近或略有提升，但明显低于 SAM3D，表明真正的物体级 3D 先验是关键；
  - **蒸馏层选择**：将学生特征提取层从中间层改为浅层或顶层，性能均不如中间层，说明中间视觉特征具有最合适的语义粒度与空间分辨率；
  - **投影头复杂度**：从线性层到两层 MLP 的对比显示，简单投影头已足够，更复杂的投影头不会带来额外收益。
- **定性分析**：通过特征可视化或注意力可视化显示，注入 3D 知识后，学生模型的视觉表征对目标物体的位姿、尺度及物体间的空间关系更加敏感，即使测试时看不到任何显式 3D 信息，也能在特征层面隐式编码这些关系。

## 4. 核心贡献与局限性

- **主要贡献**：
  1. 提出一种不改变测试阶段传感器设置和推理管线的 VLA 3D 知识注入框架，通过训练阶段特征蒸馏实现“零额外部署成本”的 3D 感知；
  2. 设计了物体级掩码对齐 + ℓ2 归一化的蒸馏损失，使 3D 先验被精准注入到目标物体对应的视觉 token 上，而非全局语义；
  3. 在 LIBERO 系列任务上证明该方法能有效提升 VLA 在空间关系理解、位姿变化和杂乱场景中的任务成功率。
- **局限性**：
  - SAM3D 教师本身依赖检测器与 SAM2 的掩码质量，在目标检测失败或掩码不准确时会引入噪声；
  - 训练阶段计算开销较大，需要额外运行 3D 教师模型与掩码生成流程；
  - 评估局限于仿真环境 LIBERO，尚未在真实机器人上进行充分验证；
  - 3D 知识以隐式特征对齐方式注入，无法显式控制模型对物体 3D 属性的编码强度，解释性有限。

## 5. 个人评论与延伸思考

- **与“测试时计算”范式的关系**：该工作属于“训练时注入、测试时免开销”的典型知识蒸馏策略，对机器人部署场景非常友好。其做法类似于把 3D 本质先验压缩进 2D 骨干的隐空间中，是一种值得推广的“传感器无关”增强手段。
- **未来可能方向**：可尝试与更轻量的掩码生成器结合，或直接以自监督方式训练物体级 3D 特征教师，摆脱对检测器的依赖；也可将同样的蒸馏思路用于其他多模态大模型，如视觉-语言模型（VLM）的 3D 空间理解增强。
- **潜在风险**：由于测试时完全丢弃 3D 教师，模型在训练分布之外的物体形状或布局上可能出现泛化不足；同时，对齐损失可能与学生主任务产生竞争，需要精细调节 \(\lambda\) 和学习率策略，避免破坏原有动作预测能力。
- **总结评价**：论文切入角度清晰，方法简洁有效，实验设计较完整地验证了“特征级 3D 知识注入”的可行性。其核心价值在于揭示了 VLA 无需显式 3D 输入也能从物体级 3D 表征中获益，为后续低成本、高性能的机器人操作策略提供了新思路。

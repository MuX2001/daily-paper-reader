## 摘要
长时程手术机器人操作具有挑战性，因为任务奖励稀疏，而有意义的交互变化以不规则的间隔发生。现有的世界模型智能体通常以基本步骤分辨率进行想象，使得可变持续时间的任务进度隐含其中。手动指定的阶段可以提供中间结构，但其特定于任务的边界难以与状态相关的交互转换对齐。我们提出了S2-HWM，一种稀疏事件结构化层次世界模型，从原始潜在轨迹中学习稀疏事件证据，以协调事件级管理器和基本步骤工作器。事件证据调度管理器目标更新，每个选定的潜在目标条件化工作器的基本步骤动作，直到下一次更新。学习到的事件证据还为事件转换模型（ETM）形成可变持续时间段，该模型预测下一个边界随机状态、段持续时间和累积段奖励。将这些事件级预测链接起来，提供了超出基本想象范围的可变持续时间延续，用于管理器学习，而工作器保留基本步骤的演员-评论家学习。在基于SurRoL的PegTransfer任务上，S2-HWM实现了98.7%的成功率，比平坦的GAS DreamerV3基线高出22.7个百分点。

## Abstract
Long-horizon surgical robot manipulation is challenging because task rewards are sparse, while meaningful interaction changes occur at irregular intervals. Existing world-model agents typically imagine at primitive-step resolution, leaving variable-duration task progress implicit. Manually specified stages can provide intermediate structure, but their task specific boundaries are difficult to align with state-dependent interaction transitions. We propose S2-HWM, a Sparse Event-Structured Hierarchical World Model that learns sparse event evidence from primitive latent trajectories to coordinate an event-level manager and a primitive-step worker. The event evidence schedules manager goal updates, and each selected latent goal conditions the worker's primitive actions until the next update. The learned event evidence also forms variable-duration segments for an Event Transition Model (ETM), which predicts the next?boundary stochastic state, segment duration, and accumulated segment reward. Chaining these event-level predictions provides a variable-duration continuation beyond the primitive imagination horizon for manager learning, while the worker retains primitive-step actor-critic learning. On a SurRoL-based PegTransfer task, S2-HWM achieves a success rate of 98.7%, outperforming the flat GAS DreamerV3 baseline by 22.7 percentage points.

  - 传统方法依赖人工指定阶段结构和阶段奖励（如 DEX、ViSkill），但阶段边界固定、任务定制化严重，难以与执行中依赖状态交互的自然边界对齐。

- **核心动机**：直接从交互动力学中**学习稀疏事件证据**，将事件级决策（何时更新目标）与原始步长控制解耦，从而在不依赖语义阶段标注的前提下实现层次化长时程决策。

## 2. 论文提出的方法论

**核心思想**：S²-HWM 通过稀疏上下文动力学从原始潜在轨迹中学习事件证据，将控制与预测组织在两个时间尺度上：**事件级管理器**负责在事件边界选择潜在目标，**原始步长工作器**负责执行目标条件化的低级动作。

**关键技术细节**：

- **层次化策略**：管理器在自适应事件边界 τᵢ 观察边界特征 Fᵢ，采样离散编码 cᵢ，映射为潜在目标 ηᵢ；工作器以 (f_t, ηᵢ) 为条件输出原始动作，直到下一次管理器更新。公式：cᵢ ∼ π_M(·|Fᵢ), ηᵢ = E(cᵢ), a_t ∼ π_W(·|f_t, ηᵢ), t ∈ [τᵢ, τᵢ₊₁)。
- **稀疏上下文动力学**：在 RSSM（DreamerV3）基础上引入持久交互上下文 m_t，通过门控机制预测候选更新 m̃_t 与软门控 ρ_t，采用直通式二值化产生稀疏维度激活 g_t 作为事件证据：
  - (m̃_t, ρ_t) = Φ_ctx(z_{t−1}, a_{t−1}, m_{t−1})
  - m_t = ρ_t ⊙ m̃_t + (1 − ρ_t) ⊙ m_{t−1}
  - g_t = ST(ρ_t)
- **事件转换模型（ETM）**：利用同一事件证据构建变长时间段 eᵢ = [τᵢ, τᵢ₊₁)，ETM 预测下一个边界随机状态 z_{eᵢ₊₁}、段持续时间 Δᵢ、累积段奖励 Rᵢ，内部门控引入 categorical transition mode uᵢ 以建模多模态转换。训练时后验 q(uᵢ|x_eᵢ, z_eᵢ₊₁) 推断模式，先前 p(uᵢ|x_eᵢ) 预测模式，KL 正则对齐。
- **事件扩展管理器引导**：管理器价值目标结合两个分支：
  - 短水平分支：RSSM 原始步想象展开得到 B_short；
  - 事件级分支：从同一终点出发，以 K 次 ETM 递归预测，累计折扣段奖励，引导至最终预测特征估值得到 B_event。
  - 最终：B_M = (1 − ω)B_short + ωB_event，工作器仍保持原始步长 actor–critic 学习。

## 3. 实验设计

- **前置视觉前端**：S²-HWM 和 GAS-DreamerV3 使用相同的 DSA4-depth 前处理（64×64 四通道任务导向图像）。

- **对比方法**：
  - PPO（无 DSA，模型无关基线）
  - DreamerV2（无 DSA，早期世界模型基线）

  - S²-HWM（提出方法）
  - 三个消融变体：w/o Event-Gated Updates（固定 K=15 更新管理器）、w/o ETM（去掉事件级延续）、w/o Hierarchical Policy（扁平 actor 替代层级策略）

## 6. 论文的主要结论与发现

- S²-HWM 在 PegTransfer 单次转移任务上达到 **98.7%±2.3%** 成功率，比 GASDreamerV3 高 **22.7 个百分点**。
- 在重复转移压力测试中达到 91.3%±6.1%（GAS 为 77.3%±18.6%）；在重复转移+扰动测试中达到 88.0%±5.3%（GAS 为 65.3%±14.0%），表现出更强的鲁棒性和长时程延续能力。
- 消融实验表明：
  - **层次策略贡献最大**（扁平策略降低 SR 至 68.0%±20.3%）：事件证据需经由管理器转化为持续潜在目标，才能实现有效控制。
  - **事件对齐更新优于固定周期更新**（固定 K=15 降低 SR 至 80.7%±28.3%，且方差增大）：不同交互阶段（接近、抓取、搬运、放置）持续时间不同，固定周期无法适应。
  - **ETM 扩展在长时程中贡献更明显**：单次转移下降 7.4 个百分点，重复转移下降 16.6 个百分点，扰动下下降 20.7 个百分点——任务越长，事件级引导越有价值。
- 事件预测误差分析显示 ETM 在多步事件延续中误差累积比 RSSM 慢，支持其用于增大管理器引导视野。
- 管理器代码的分组分析表明，不同管理器编码对应不同语义阶段的差异化动作倾向，且无需语义标注（后验标注仅用于分析）。

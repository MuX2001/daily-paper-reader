## 摘要
视觉-语言-动作（VLA）模型将预训练视觉-语言模型（VLM）的表征转换为机器人动作，但将中间VLM特征路由到动作解码器的接口仍未得到充分探索。现有设计要么仅暴露表征层级中的狭窄部分，要么将每个解码器块严格匹配到单个VLM层，从而限制了对跨深度互补任务证据的访问。我们引入了LIRA，一种局部跨层动作条件化机制，将VLM到动作的条件化表述为深度感知的信息路由。LIRA对任务令牌特征和从中间VLM状态导出的LIRA查询特征进行操作，然后为每个并行融合块分配一个以对应VLM层为中心的深度对齐局部窗口。并行融合块聚合相邻的LIRA查询特征，并在动作预测之前将其与任务令牌特征和本体感觉输入集成。该路由接口保持骨干架构、动作解码器和监督训练方案不变。在LIBERO、LIBERO-Plus、CALVIN ABC$\rightarrow$D以及真实世界操控中，LIRA在相同0.5B参数配置下相对于VLA-Adapter基线提升了主要聚合指标。在向LIBERO-Plus的零样本迁移中，LIRA将平均成功率从59.1%提高到78.0%，提升了18.9个百分点，表明在受控分布偏移下鲁棒性有所提高。

## Abstract
Vision-Language-Action (VLA) models transform representations from pretrained vision-language models (VLMs) into robot actions, yet the interface that routes intermediate VLM features into action decoders remains underexplored. Existing designs either expose only a narrow part of the representation hierarchy or rigidly match each decoder block to one VLM layer, restricting access to complementary task evidence across depths. We introduce LIRA, a local cross-layer action-conditioning mechanism that formulates VLM-to-action conditioning as depth-aware information routing. LIRA operates on task-token features and LIRA Query features derived from intermediate VLM states, then assigns each Parallel Fusion Block a depth-aligned local window centered on its corresponding VLM layer. Parallel Fusion Blocks aggregate neighboring LIRA Query features and integrate them with task-token features and proprioceptive inputs before action prediction. This routing interface leaves the backbone architecture, action decoder, and supervised training recipe unchanged. Across LIBERO, LIBERO-Plus, CALVIN ABC$\rightarrow$D, and real-world manipulation, LIRA improves the principal aggregate metrics over the VLA-Adapter baseline under the same 0.5B-parameter configuration. In zero-shot transfer to LIBERO-Plus, LIRA increases average success from 59.1% to 78.0%, an 18.9-point gain indicating improved robustness under controlled distribution shifts.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：视觉-语言-动作（VLA）模型通过复用预训练视觉-语言模型（VLM）的表征来生成机器人动作。虽然VLA模型在机器人操控中取得了显著进展，但**VLM到动作解码器之间的接口（interface）**却长期被忽视。
- **核心问题**：如何高效地将中间VLM层的表征路由到动作解码器，以提供动作生成所需的视觉、语言和任务证据？
- **现有方法的不足**：
  - **仅使用最终层特征**（如OpenVLA-OFT）：只暴露终端表征，丢失了中间层丰富的语义和结构信息。
  - **一对一逐层对齐**（如VLA-Adapter）：每个解码器块只访问一个匹配的VLM层，限制了相邻层互补信息的利用。
  - **全局聚合所有层**：虽能获取跨层信息，但会破坏VLM深度上的局部结构，可能混杂远距离特征。
- **核心假设**：相邻VLM层在表征演化过程中会提供互补的任务证据，因此在给定解码器深度上，应当访问**以匹配层为中心的局部邻域**，而非单一层或全部层级。
- **整体含义**：本文提出LIRA，一种**深度感知的局部跨层信息路由机制**，在保持骨干架构、解码器和训练方案不变的前提下，改进VLM到动作的条件化接口，从而提升VLA模型在标准任务、长时序任务、受控分布偏移以及真实世界操控中的性能。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- 将VLM到动作的条件化重新定义为**深度感知的信息路由问题**，引入**深度局部性先验**：每个并行融合块（PFB）应访问以对应VLM层为中心的局部窗口内的相邻层特征。

### 技术细节
1. **基础架构（基于VLA-Adapter）**
   - 输入：第三视角图像 \(X_v^t\)、夹爪视角图像 \(X_g^t\)、语言指令 \(u_t\)、本体感觉状态 \(P_t\)。
   - 在VLM中额外加入 \(M\) 个可学习的 **LIRA Query tokens**（即VLM侧的查询token），从每个VLM层 \(\ell\) 提取任务token特征 \(T_t^{(\ell)}\) 和LIRA查询特征 \(R_t^{(\ell)} \in \mathbb{R}^{M \times d_v}\)。
   - 动作解码器由 \(L\) 个并行融合块（PFB）组成，输入为Action Query tokens。

2. **局部跨层路由窗口**
   - 对第 \(i\) 个PFB，选择以匹配层 \(i\) 为中心的邻域：
     \[
     W_r(i) = \{\ell \in \{1,\dots,L\} \mid |\ell - i| \le r\}
     \]
   - 将窗口内所有层的LIRA查询特征沿token维度拼接：
     \[
     \tilde{R}_t^{(i)} = \text{Concat}_{\text{tok}}\left(\{R_t^{(\ell)}\}_{\ell \in W_r(i)}\right)
     \]
   - 默认 \(r=1\)，即内部PFB使用三层窗口；边界PFB使用两层窗口（裁剪到有效范围）。

3. **PFB条件化**
   - 每个PFB接收深度对齐的任务token特征 \(T_t^{(i)}\) 作为语义锚点，同时接收局部邻域聚合的LIRA查询特征 \(\tilde{R}_t^{(i)}\) 和本体感觉嵌入 \(E_p^t\)：
     \[
     X_t^{(i)} = \text{PFB}_i\left(X_t^{(i-1)}; T_t^{(i)}, \tilde{R}_t^{(i)}, E_p^t\right)
     \]
   - 特征沿token维度拼接后直接由已有的交叉注意力机制消费，**无需新增投影层或可训练参数**。

4. **动作预测与训练目标**
   - 最后一个PFB后接输出头，预测长度为 \(H\) 的连续动作chunk。
   - 使用监督连续动作回归目标：
     \[
     \mathcal{L}_{\text{act}} = \mathbb{E}_{\mathcal{D}}\left[\frac{1}{H}\sum_{h=0}^{H-1} \|\hat{a}_{t+h} - a_{t+h}\|_1\right]
     \]
   - 与VLA-Adapter基线使用完全相同的训练目标与流程，以隔离路由机制的影响。

1. **LIRA在标准操控基准上全面超越VLA-Adapter**：LIBERO平均成功率由97.3%提升至98.9%，提升最大的是LIBERO-Long（95.0%→97.6%）。

4. **局部跨层窗口优于其他路由设计**：三层居中窗口优于单层匹配、四层窗口和全局聚合；也优于Flashback、Column-wise、Q-Former等备选拓扑。

## 7. 优点（方法或实验设计上的亮点）

- **问题切入点新颖**：明确将VLM→动作接口定义为“深度感知信息路由”，并提出了“深度局部性”这一先验，概念清晰、有理论解释性。

## 摘要
机器人操作需要感知系统来识别可操作部件，如手柄、边缘、扳机和工具尖端，而不仅仅是物体类别或点云。本文提出了RoboSeg，一种部件级语义重建系统，它将视觉语言模型（VLM）功能部件发现、异步在线RGB-D语义重建和任务导向的抓取生成联系起来，无需CAD模型或预扫描网格。RoboSeg在初始RGB观测上查询VLM以获得紧凑的功能部件提示，然后通过两个异步流进行扫描：一个高频几何线程用于RGB-D里程计和截断符号距离函数（TSDF）融合，以及一个关键帧触发的语义线程用于SAM3部件掩码。投影掩码通过体素级时间投票融合成持久的部件标记点云；RoboSeg利用此地图将AnyGrasp 6自由度候选分配到语义部件，并选择与任务相关部件标签一致的抓取。RoboSeg在手动标记物体上达到83.4%的平均部件交并比（mIoU）；在涉及四个物体和八项任务的24次物理试验中，所选抓取在所有试验中均接触请求的部件，并实现21/24的综合任务成功。这些结果表明RoboSeg可作为任务条件操作语义索引层，AnyGrasp保留为提议生成器。

## Abstract
Robotic manipulation requires perception systemsthat identify actionable parts such as handles, rims, triggers,and tool tips, not merely object categories or point clouds. This paper presents RoboSeg, a part-level semantic reconstructionsystem that links vision-language model (VLM) functional-partdiscovery, asynchronous online RGB-D semantic reconstruc-tion, and task-oriented grasp generation without requiring CAD models or pre-scanned meshes. RoboSeg queries a VLM onthe initial RGB observation to obtain compact functional part prompts, then scans with two asynchronous streams: a high-frequency geometry thread for RGB-D odometry and truncated signed distance function (TSDF) fusion, and a keyframe-triggered semantic thread for SAM3 part masks. Projectedmasks are fused by voxel-level temporal voting into a persistentpart-labeled point cloud; RoboSeg uses this map to assign AnyGrasp 6-DoF candidates to semantic parts and select grasps consistent with the task-relevant part label. RoboSeg reaches 83.4% mean part intersection-over-union (mIoU) over manually labeled objects; in a 24-trial physical pilot across fourobjects and eight tasks, the selected grasp contacts the requestedpart in all trials and achieves 21/24 combined task successes.These results characterize RoboSeg as a semantic indexing layerfor task-conditioned manipulation, with AnyGrasp retained asthe proposal generator.

## 2. 论文提出的方法论

### 核心思想
RoboSeg提出了一个三模块端到端管线，将VLM功能部件发现、异步在线RGB-D语义重建和AnyGrasp部件索引候选选择集成在一起，核心在于**将语义感知与几何重建解耦**，并通过**时间投票**实现稳定的3D语义融合。

### 关键技术细节

| 模块 | 功能 | 技术手段 |
|------|------|----------|
| **A. VLM部件发现** | 从初始RGB帧提取功能部件提示 | 使用**Qwen3-VL**分析初始图像，输出1~3个自包含、无歧义的部件名称（如"watering can handle"），仅将部件名称作为SAM3的提示词 |
| **B. 异步语义重建** | 构建持久的部件标记点云 | 双异步线程：①高频几何线程（RGB-D里程计+TSDF融合）；②关键帧触发的语义线程（SAM3掩码分割） |
| **C. 任务导向抓取** | 根据自然语言任务选择抓取候选 | 对AnyGrasp生成的6-DoF候选按抓取闭合区域的**主导语义实例**进行分配，再按任务相关部件标签过滤 |

### 核心公式
- **体素投票张量**：\( S(v) = \{(i_1(v), s_1(v)), \ldots, (i_K(v), s_K(v))\} \)，其中 \( K = 3 \)
- **标签查询**：\( \hat{i}(v) = \arg\max_k s_k(v) \)
- **机制**：新掩码投影后，在对应体素集合中查找同类别实例ID；若无匹配则分配新ID；被覆盖体素为该ID增加一票；查询时取票数最高的实例作为最终标签。这抑制了帧间标签闪烁。

### 算法流程（文字描述）
1. 从初始RGB帧调用VLM获得物体名+部件列表+推理过程（仅部件名用于下游）；
2. 初始化TSDF体积和逐体素投票张量；
3. 对每帧RGB-D：估计位姿（可结合机器人运动学正则化）→ 融合深度到TSDF；每隔τ帧触发语义线程：SAM3生成部件掩码 → 反投影到TSDF体素坐标 → 更新投票张量；
4. 扫描完成后导出点云，逐体素取最大投票标签，构建"实例ID→部件名"映射表；
5. 运行AnyGrasp生成候选，将每个候选分配给其夹爪闭合区域内的主导语义实例；
6. 从任务指令解析目标部件标签，在选择器中保留标签匹配的最高分候选并执行。

## 6. 论文的主要结论与发现

- **核心结论**：RoboSeg可作为**任务条件化操作的语义索引层**，而AnyGrasp保留为抓取提议生成器——不需要CAD模型或预扫描网格。
- **具体发现**：
  - 在与PartField共享标签但输入条件更严苛（在线扫描 vs 完整网格）的情况下，RoboSeg的mIoU（86.7%）仍略高于PartField（83.2%）；
  - RGB-D里程计在Chamfer距离、精度、完整性和F1@5上略优于运动学位姿，但F1@10略差（差异总体较小）；
  - 24次物理试验中，**24/24**次抓取接触到目标部件，**21/24**次物理成功，**21/24**次综合成功；未经过滤的AnyGrasp top-1仅4/8条件匹配目标部件，经过语义过滤后8/8条件都选到目标部件。

## 7. 优点

- **在线闭环感知架构**：将VLM部件推理作为前端约束（而非让分割模型自由发现所有可见碎片），在设计上更贴合操作需求。
- **异步双线程设计**：几何与语义解耦，保证高频追踪/融合响应性的同时，不阻塞低帧率SAM3推理，工程实用性较强。
- **体素级时间投票机制**：通过Top-K投票张量实现语义的时序稳定性，是一个简洁有效的抗掩码闪烁方案。
- **明确的系统定位**：将语义地图定位为"可操作的接口"而非可视化工具；保留AnyGrasp为提案生成器，设计边界清晰、不越界。
- **实验证据分层清晰**：每个实验隔离管线中的一个环节，分别验证语义发现、几何重建和任务路由，论证结构逻辑严谨。

## 8. 不足与局限

### 实验覆盖局限
- **物理试验规模小**：24次试验、4个物体、8个任务条件，且采用手动重置和标准化初始视角，结果的普适性有限。
- **物体种类有限**：缺少遮挡、多物体场景、不同光照条件和更复杂部件布局的验证。
- **对比基线不完全**：PartSLIP无法在同一度量框架下进行定量比较，Hammer和WateringCan缺PartField对比；离线基线在某种程度上是非对称比较。
- **无消融实验**：未对体素投票张量的有效性（如K值选取、与直接覆盖策略对比）做消融分析。

### 偏差风险
- **标签对齐不确定性**：手动标注的GT标签与自动分割的部件定义可能存在固有偏差，5mm截断距离的设定也可能影响结果。
- **任务解析简化**：自然语言任务到部件标签的解析逻辑未详细展开分析，可能隐藏了额外的"手工规则"成分。

### 应用限制
- 依赖SAM3和Qwen3-VL的推理质量；若VLM初始识别失败，整个管线将产生连锁性错误。
- 缺少**组件级运行时剖析**，无法判断各模块的实时性能瓶颈以及系统在更高速操作需求下的适用性。
- 当前方法将抓取可行性完全交由AnyGrasp判断，未对部件本身的物理可抓取性做额外约束或优化。

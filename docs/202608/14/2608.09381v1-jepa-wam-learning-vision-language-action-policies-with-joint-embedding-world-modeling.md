## 摘要
鲁棒的机器人控制得益于对状态转换的显式建模，但视频生成世界动作模型（WAMs）引入了大量部署成本。现有的潜在WAM避免了显式未来生成，但常常压缩预测表示或将预测建模与用于动作生成的表示分离。我们提出了JEPA-WAM，一种建立在预训练V-JEPA空间中的潜在WAM，通过共享预测器将潜在转换预测与连续动作生成耦合。JEPA-WAM预测一个空间结构化的联合当前-未来目标，捕获当前和未来观测之间任务共享的视觉时间结构，同时保留密集的补丁级对应。通过共享预测器，转换监督直接塑造骨干网络，从中提取专用表示用于动作预测。同样的设计也可以实例化在预训练的VLA策略中，同时保留其原始感知和动作路径。在LIBERO-Plus上，JEPA-WAM达到79.2%，在无大规模机器人策略预训练的情况下取得最佳结果，而其预训练的π_{0.5}实例达到86.3%，实现最佳整体性能。在RoboTwin 2.0和真实世界双臂操作上的实验进一步证明了在视觉和空间偏移下的强泛化能力。

## Abstract
Robust robot control benefits from explicitly modeling state transitions, but video-generation world action models (WAMs) introduce substantial deployment cost. Existing latent WAMs avoid explicit future generation, but often compress predictive representations or separate predictive modeling from the representations used for action generation. We introduce JEPA-WAM, a latent WAM built in a pretrained V-JEPA space, which couples latent transition prediction with continuous action generation through a shared predictor. JEPA-WAM predicts a spatially structured joint current-future target that captures task-shared visual temporal structure between current and future observations, while preserving dense patch-level correspondence. Through the shared predictor, transition supervision directly shapes the backbone, from which dedicated representations are extracted for action prediction. The same design can also be instantiated in pretrained VLA policies while preserving their original perception and action pathways. On LIBERO-Plus, JEPA-WAM achieves 79.2%, the best result without large-scale robot-policy pretraining, while its pretrained $π_{0.5}$ instantiation reaches 86.3%, achieving the best overall performance. Experiments on RoboTwin 2.0 and real-world bimanual manipulation further demonstrate strong generalization under visual and spatial shifts.

## 1. 核心问题与整体含义

- **研究动机**：视觉-语言-动作（VLA）策略在各类操作任务中表现优异，但其动作预测目标只隐式地建模状态转移，导致在视觉/空间分布偏移下鲁棒性不足。
- **现有方案的矛盾**：
  - 视频生成式世界动作模型（WAM）显式建模未来状态，但迭代式未来预测导致部署成本高。
  - 潜在 WAM 虽避免显式帧生成，但大多数方法要么将未来观测压缩为少量全局 latent token，丢失细粒度空间结构；要么将预测建模与动作生成分离，导致预测监督无法有效塑造动作生成所用的表示。
- **本文的定位**：在预训练 V-JEPA 的表示空间中构建潜在 WAM，通过**共享预测器**将“潜在转移预测”与“连续动作生成”耦合起来，目标是既保持部署效率，又显式建模状态转移，从而提升 OOD 泛化能力。
- **总体含义**：JEPA-WAM 提供了一种高效的、可迁移到预训练 VLA 的“世界建模”方案，能够在不改变部署路径的前提下，让转移监督直接塑造策略骨干，进而同时改善 ID 和 OOD 性能。

## 2. 方法论

### 2.1 核心思想

- 使用冻结的 V-JEPA 2.1 编码器作为**潜在表示空间**：
  - 当前观测表示 \(Z_t\)：每个视图独立编码后按固定相机顺序拼接，保留 patch 级空间结构。
  - 联合当前–未来目标 \(Y_{t,t+\delta}\)：将当前帧和未来帧在时间维堆叠后送入冻结 V-JEPA，得到 temporally joint 的 patch 级表示，以捕获“两帧之间的时间关系”而非绝对未来状态。
- **共享预测器**：用 Qwen2.5-0.5B 作为单一骨干，既完成 latent transition prediction，又产出用于动作生成的条件表示。
- **部署时只保留动作生成路径**，移除预测头与目标分支，避免推理额外开销。

### 2.2 关键技术细节

- **视觉接口**：V-JEPA 冻结，经两层 MLP 投影到 Qwen 输入空间。
- **预测器适配**：Qwen2.5-0.5B 在 robot-policy 训练中使用 LoRA（rank 32、scale 64、dropout 0.1），视觉投影器和 Qwen 基础权重冻结。
- **转换预测**：
  - 目标表示：\(Y_{t,t+\delta} = \mathrm{Concat}_v\,\mathrm{sg}\left(E_J(\mathrm{Stack}_{time}(O_t^v, O_{t+\delta}^v))\right)\)
  - 预测头 \(G_\phi\) 将 Qwen 的视觉 token 隐状态映射回 V-JEPA 空间：
    \(\hat{Y}_{t,t+\delta} = G_\phi(Q^{wm}_t)\)
  - 损失为逐 patch 余弦距离：\(L_{wm}=\frac{1}{BN_{vis}}\sum_b\sum_n \left[1-\cos(\hat{Y}^{(b)}_{t,t+\delta,n}, Y^{(b)}_{t,t+\delta,n})\right]\)
- **动作生成**：
  - 在预测器序列中加入 64 个 action placeholder token，其隐状态 \(C_t\) 作为动作专家（16 层 DiT-L）的条件。
  - 使用条件流匹配：\(L_{act} = \mathbb{E}_{\epsilon,\tau}\left[\|A_\psi(a_\tau,\tau,s_t,C_t)-(a-\epsilon)\|_2^2\right]\)（速度预测；RoboTwin 2.0 上用 x-prediction）。
- **联合训练**：\(L = L_{act} + \lambda_{wm} L_{wm}\)，其中 \(\lambda_{wm}=0.5\)。

### 2.3 迁移到预训练 VLA

- 对预训练 π0.5，引入 64 个可学习 future tokens，用其输出隐状态重排为 \(8\times8\) 粗特征图，经 MLP 和双线性上采样到 \(24\times24\)，与 V-JEPA ViT-G 的联合当前–未来目标对齐。
- 保留原始感知和动作路径，action tokens 不 attend 新加的 future tokens，因此只通过辅助损失影响骨干，不改变部署时动作生成流程。

## 3. 实验设计

### 3.1 数据集 / 场景 / Benchmark

- **LIBERO**（ID）：四个标准套件，联合训练后分别测试，报告平均成功率。
- **LIBERO-Plus**（OOD）：在 LIBERO 训练后直接评估，包含相机、机器人、语言、光照、背景、噪声、布局等多类扰动。
- **RoboTwin 2.0**：20 个双臂操作任务，仅在 Clean 演示上训练，评估 Clean 和 Rand（随机场景/布局）两种设置。
- **真实世界**：AgileX COBOT Magic 双臂平台，5 个任务（面包放置、水果放置、三块积木放置、三块积木堆叠、抽屉操作），ID 设置按采集环境，OOD 设置改变背景或初始物体位置，每个任务 10 次 rollout，使用归一化完成分数。

### 3.2 对比方法

- **无大规模机器人策略预训练**：Diffusion Policy、VLA-Adapter、RoVLA、ResVLA、Fast-WAM、ACT、DP3、DP 等。
- **有大规模策略预训练**：π0、π0.5、VLA-JEPA、Motus、Being-H0.7、ABot-M0、Cosmos-Policy、PokeVLA、RDT-1B 等。
- **消融变体**：
  - DINOv2+SigLIP（替代 V-JEPA 视觉骨干）
  - V-JEPA only（去掉转移预测）
  - Future only（目标改为仅未来表示）
  - Endpoint difference（目标改为 \(E_J(O_{t+\delta})-E_J(O_t)\)）
  - iREPA align（对目标做卷积变换）
  - Lower-16 align（在预测器第 16 层施加监督）
  - Full hidden（不使用 action placeholder，用全部隐状态作为动作条件）

### 3.3 主要结果

- **LIBERO（ID）**：JEPA-WAM 平均 96.7%，与有预训练方法（π0.5 96.9%、Motus 97.7%）接近；π0.5 + JEPA Obj. 提升到 97.8%。
- **LIBERO-Plus（OOD）**：JEPA-WAM 平均 79.2%，为无预训练方法中最佳；π0.5 + JEPA Obj. 达到 86.3%，为全部方法中最佳。
- **RoboTwin 2.0**：
  - JEPA-WAM：Clean 79.9%、Random 36.9%，大幅超过无预训练基线（DP3 为 73.9/8.3），Random 表现与 π0.5（37.2%）相当。
  - π0.5 + JEPA Obj.：Clean 从 75.4% 提升到 84.6%，Random 基本持平（37.5% vs 37.2%）。
- **真实世界**：
  - JEPA-WAM ID 59.8%、OOD 54.2%，显著优于 π0（51.8%/22.5%）。
  - π0.5 + JEPA Obj. 在 ID/OOD 上分别从 77.5%/72.5% 提升到 90.3%/84.7%。

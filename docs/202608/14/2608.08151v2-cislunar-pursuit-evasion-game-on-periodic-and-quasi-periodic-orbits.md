## 摘要
地月空间航天器在非线性和不稳定的环境中运行，这使得防御机动规划变得困难。我们将地月空间航天器的追逃问题建模为圆形限制性三体问题中的零和微分博弈。每艘航天器控制其推力和参考轨道相位，能够在保持接近参考轨道的同时沿周期轨道运动并穿越拟周期环面。我们使用一种施加硬输入约束的约束离散时间微分动态规划方法求解该博弈。我们提出了一种共享时间正则化方法，在接近月球飞越时细化离散化，同时同步两艘航天器。在周期和拟周期轨道上的数值结果表明，相位控制在限制偏离参考轨道的同时提高了机动灵活性。与连续时间公式相比，离散时间方法还提供了很大的计算优势。拟晕轨道与拟近直线晕轨道的比较表明，近距离月球飞越创造了更大的逃逸机会，但也增加了交会的敏感性。这些结果表明，参考轨道几何形状是防御性地月空间任务设计的重要组成部分。

## Abstract
Cislunar spacecraft operate in nonlinear and unstable environments that make defensive maneuver planning difficult. We formulate cislunar spacecraft pursuit and evasion as a zero-sum differential game in the circular restricted three-body problem. Each spacecraft controls its thrust and reference orbit phase, enabling motion along periodic orbits and across quasi-periodic tori while remaining near the reference. We solve the game using a constrained discrete-time differential dynamic programming method that enforces hard input constraints. We propose a shared time regularization to synchronize both spacecraft while refining the discretization near close lunar passages. Numerical results on periodic and quasi-periodic orbits show that phase control improves maneuvering flexibility while limiting departure from the reference orbit. The discrete-time method also provides a large computational advantage over a continuous-time formulation. Comparisons between quasi-halo and quasi-near-rectilinear halo orbits show that close lunar passages create larger escape opportunities but also increase the sensitivity of the encounter. These results show that reference orbit geometry is an important part of defensive cislunar mission design.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体思路
将追逃博弈建模为 **CR3BP 下的零和微分博弈**，目标函数是追赶者最小化距离、逃逸者最大化距离，同时双方都受限于“贴近参考轨道”的跟踪要求。采用**约束离散时间微分动态规划**近似求解博弈鞍点。

### 2.2 三大核心组件

#### (1) 参考相位控制（Phasing Control）
- **周期轨道（PO）**：参考相位 θ ∈ T¹ 沿轨道方向演化，相位率控制 ω(t) ∈ R 使航天器可以加速/减速沿轨道移动，实现沿轨机动而不必偏离轨道几何。
- **拟周期轨道（QPO）**：参考轨道为不变环面 T²，由两个相位角（θ₁ 纵向、θ₂ 横向）参数化，相位率控制 ω = (ω₁, ω₂) ∈ R²，允许航天器在**二维不变环面上自由移动**，大大扩展机动维度。
- **环面构造**：采用 **Haro–Mondelo 流映射参数化方法**（先用单参数生成曲线满足不变性条件，再流化得到二维 Fourier 级数表示），并引入**均匀归一化方案**解决适应框架的病态问题。

#### (2) 共享多智能体时间正则化（Shared Multi-Agent Time Regularization）
- 针对单航天器的 KS（Kustaanheimo–Stiefel）正则化（笛卡尔坐标 → 四维虚构空间）+ Sundman 时间变换存在**双时钟不同步**的根本缺陷——每艘航天器有自己的虚构时间 τ_e 和 τ_p，均匀步长在 τ 中不代表同一物理时刻，可被对方恶意利用（如逃逸者使月球距离趋零从而冻结自身时间）。
- 解决方案：引入**单一共享虚构时间 s**，满足 dt = (1/r_e + 1/r_p)⁻¹ ds，可保证两航天器物理时间同步，当任一航天器接近月球时自动提高联合时间分辨率。
- 该设计借鉴 Heggie 的 N 体全局正则化思想，但目的不同：**保持多智能体之间的时间同步**而非处理多个同时奇点。

#### (3) 约束离散时间博弈 DDP（Constrained Discrete-Time Game-Theoretic DDP）
- 将连续博弈离散化为零和动态规划问题，通过 HJI 方程的迭代线性二次近似求解。
- **关键步骤**（反向传播）：
  - 在当前迭代点对系统动力学和代价函数做二阶展开；
  - 将局部鞍点问题转化为带约束的二次规划；
  - 采用 **Primal Active-Set 方法**（扩展 Tassa et al. [24] 的单智能体方法）处理硬控制约束：固定活动约束在边界上，解自由变量的前馈与反馈增益，然后用拉格朗日乘子更新活动集；
  - 使用正则化参数 λ 保证 Hessian 正定性/负定性，并通过**回溯线搜索 + 信任域更新**（trust-region ratio）控制步长。
- **算法流程**（Algorithm 1）：初始化 → 线性化与代价导数计算 → 反向传递（解局部约束鞍点、更新价值函数）→ 正向传递与线搜索 → 更新轨迹与控制 → 迭代至收敛。

## 6. 主要结论与发现

### 6.1 相位控制显著增强机动灵活性
- 通过调节参考轨道相位，航天器可以在**不大幅偏离参考几何**的前提下实现沿轨/横向机动。
- 在拟周期轨道上，二维相位控制提供的额外自由度使逃逸者能够**转移到不同环面纤维**，更快达到逃逸距离并回到参考轨道（图 4）。

### 6.2 离散时间公式的计算优势
- DT-DDP 相比 CT-DDP 在 NRHO 场景下获得约 **30.2 倍加速**，且仍能实现逃逸与跟踪误差控制。

### 6.3 共享时间正则化的价值
- 当近月点距离较小时，均匀离散化严重退化（运行时间从 5.36 秒飙升到 54.64 秒，迭代次数从 55 增至 532）；而正则化方案运行时间仅从 4.87 秒增至 12.83 秒、迭代次数从 47 增至 132，保持稳定收敛。

### 6.4 轨道几何决定博弈结果
- **拟 NRHO 的近距离月球飞越**：产生更大的逃逸机会，但博弈结果对**飞越前**的相对状态高度敏感，控制力矩集中在进入近距离飞越走廊之前；飞越期间可控性高度下降（可控性格拉姆矩阵最小特征值急剧下降）。
- **拟晕轨道**：远离月球、弱引力梯度，博弈过程更均匀，但逃逸能力受限于自身控制权限。
- 结论：**参考轨道几何选择本身是防御性任务设计的关键变量**，存在“更大的逃逸机会”与“更高的遇遇敏感性”之间的根本权衡。

## 摘要
长时程多部件物体拆卸要求机器人计算无碰撞移除运动的可行序列，即使在存在狭窄、紧致的逃逸通道时也是如此。为了高效解决此类拆卸问题，我们提出了长时程拆卸并行提取（PEEL）算法，该算法高效计算物体装配体的拆卸运动，并将其馈送给机器人操纵器执行。PEEL利用基于采样的运动规划，通过尺度不变采样方案计算单物体运动，其中物体尺度在预热阶段估计，后续方向性采样器利用该尺度。该采样方案被集成到多臂赌博机快速探索随机树（MAB-RRT）规划器中，该规划器根据收到的奖励信号在不同的采样器之间切换。利用MAB-RRT，PEEL算法并行运行一批规划器，以获得一个有序图，指定物体部件必须被移除的顺序。我们表明，MAB-RRT能够在76个装配体上以100%的成功率高效解决单部件拆卸问题，并且对其参数具有鲁棒性。通过将MAB-RRT集成到PEEL中，我们使用Fetch操纵器机器人解决了四个长时程拆卸问题，涉及10至17个独立物体部件。

## Abstract
Long-horizon multi-part object disassembly requires robots to compute feasible sequences of collision-free removal motions, even in the presence of tight, narrow escape corridors. To efficiently solve such disassembly problems, we propose Parallel Extraction for Long-Horizon Disassembly (PEEL), an algorithm which efficiently computes disassembly motions for object assemblies and feeds them to a robot manipulator for execution. PEEL uses sampling-based motion planning to compute single-object motions through the use of a scale-invariant sampling scheme, where the object scale is estimated in a burn-in phase and a subsequent directional sampler exploits the scale. This sampling scheme is integrated into a multi-arm bandit rapidly-exploring random tree (MAB-RRT) planner, which switches between different samplers depending on the reward signal received. Using MAB-RRT, the PEEL algorithm runs a batch of planners in parallel to obtain an ordered graph specifying the sequence in which object parts have to be removed. We show that MAB-RRT can efficiently solve single-part disassemblies with 100 percent success rate on 76 assemblies, and that it is robust to its parameters. By integrating MAB-RRT into PEEL, we solve four long-horizon disassembly problems using the Fetch manipulator robot involving 10 to 17 individual object parts.

- **研究问题**：长时程（long-horizon）多部件物体拆卸规划——即给定一个由多个刚性部件装配而成的物体，如何让机器人计算出一系列无碰撞的移除运动，并按照合理顺序将部件逐一拆卸下来。核心难点包括：
  - 部件常被约束在狭窄、紧致的“逃逸通道”中，均匀采样很难发现可行运动；
  - 多部件情况下，拆卸顺序的组合搜索随部件数量指数增长；
  - 需要将几何规划结果转化为机器人可执行的操作序列。
- **背景与动机**：
  - 拆卸是回收、再制造、维修、材料回收及建筑拆除等场景的基础机器人技能。
  - 传统方法（如AND/OR图、符号优先级图、物理仿真规划）存在扩展性差或计算代价高的问题。
  - 作者提出关键观察：一个部件当前是否可移除，恰好可由运动规划器的查询本身回答，因此可以“跳过”显式的符号顺序搜索，让几何可行性自身揭示移除顺序。
- **整体含义**：提出 PEEL 框架，以并行“规划竞赛”代替组合式顺序搜索，并用尺度不变采样 + 多臂老虎机 RRT（MAB-RRT）作为单部件规划器，实现了高效、鲁棒、可机器人执行的多部件拆卸规划。

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

### 2.1 核心思想
- **PEEL（Parallel Extraction for Long-Horizon Disassembly）**：将拆卸顺序发现转化为一系列“规划竞赛”（planning races）。每轮从待拆卸队列中取出最多 B 个候选部件，每个部件由一个独立的 MAB-RRT 规划器并发求解其无碰撞提取路径；第一个成功的规划器对应的部件获胜，被加入拆卸序列，其余失败/未完成的规划器被终止，其对象重新入队。如此循环直到所有部件被移除。
- **关键观察**：无需预先构建部件优先级图或搜索子装配体状态；部件的可移除性直接由运动规划查询决定，规划竞赛的胜者天然定义了拆卸顺序。

### 2.2 MAB-RRT 单部件规划器
- **多臂老虎机 RRT**：为每个“臂”（采样器）维护一个滑动窗口 UCB（上置信界）奖励估计，在每次迭代选择一个采样器用于扩展 RRT。
- **三个采样器臂**：
  1. **均匀采样器（uniform）**：提供全局探索。
  2. **尺度采样器（scale sampler）**：在“预热阶段”（burn-in phase）从初始半径 r₀ 开始，以固定乘性因子增大或缩小半径，直到一批球体内样本约有一半无碰撞（最大信息熵点），从而估计局部自由空间的尺度 r⋆。
  3. **PCA 采样器（PCA sampler）**：利用尺度 r⋆ 下收集的有效样本做主成分分析（PCA），得到局部自由空间的主导方向，沿该方向生成偏置采样，并沿通道方向延伸采样圆柱（高度 hext = δ·r⋆）。
- **在线自适应**：PCA 主成分随新有效样本在线重计算；老虎机根据各采样器的奖励信号动态切换，在探索（无通道时）和利用（找到通道后）之间平衡。

### 2.3 PEEL 高层算法（Alg. 1）
- 输入：装配体 A（对象集合）、批量大小 B、初始预算 T₀、预算上限 T_max。
- 流程：
  1. 随机打乱对象队列 Q，初始化已解序列 S 为空。
  2. 设置当前预算 T = T₀，已尝试集合 F = ∅。
  3. 当 Q 非空时：
     - 从 Q 中弹出最多 B 个对象作为当前批。
     - 为每个对象启动一个 MAB-RRT 规划进程，该进程将其他所有剩余对象视为静态障碍物。
     - 等待第一个成功者或预算 T 超时：
       - **成功**：获胜对象的路径被加入序列 S；终止其他进程，失败对象重新入队；因几何结构改变，预算重置为 T₀，F 清空。
       - **超时**：终止所有进程，整批对象重新入队；将该批加入 F；若 F 覆盖整个 Q（即当前预算下所有对象都尝试过且失败），则将预算翻倍（T ← 2T），F 清空；若 T > T_max，则返回当前序列。
  4. 返回完整拆卸序列 S。

### 2.4 概率完备性
- 论文证明（Proposition 1）在 T_max = ∞ 且使用概率完备的 MAB-RRT 的前提下，PEEL 对任何“顺序可分解”（sequentially decomposable）的装配体以概率 1 找到完整拆卸序列。原因是每个对象会被无限次选择，超时预算趋于无穷，且每次移除后剩余集合仍保持顺序可分解。

### 2.5 机器人执行管线（Robot Grounding Pipeline）
- 将 PEEL 计算出的对象空间轨迹转换为机器人可执行运动，分为五个阶段：
  1. **抓取规划（Phase I）**：采样抓取候选位姿，通过逆运动学可行性、无碰撞、可达性三重检查确定抓取配置 q_g 和抓取变换 T_grasp。
  2. **拆卸运动（Phase II）**：沿 MAB-RRT 路径执行，但需通过“自由状态检测”（mobility rank test）确定狭窄通道结束点。在每个路点，对物体沿三个平移轴和三个旋转轴施加 ±ε 扰动并碰撞检测，计算平移/旋转自由度秩（r_t, r_r）；当 r_t ≥ ρ_t 且 r_r ≥ ρ_r 时判定物体脱离约束，截断路径，后续改用普通规划器自由运输。若遇到 IK/碰撞失败，则触发中间重新抓取（regrasp）。
  3. **目标 IK 计算（Phase III）**：在目标位姿附近采样新的抓取变换 T′_grasp，要求该抓取在物体当前自由状态位姿和目标位姿下都同时满足无碰撞和逆运动学可行性。
  4. **桥接运动（Phase IV）**：规划仅机器人运动路径，使机械臂到达能在物体当前位姿下以 T′_grasp 重新抓取物体的桥接配置。
  5. **运输（Phase V）**：将物体刚性焊接到末端执行器，规划并执行从桥接配置到目标配置的运输运动。
- 机器人模型：Fetch 移动操纵器，11 自由度（7 自由度手臂 + 1 自由度躯干升降 + 3 自由度移动基座），末端采用球形抓取工具模拟稳定点接触，抓取后通过焊接关节刚性连接。

## 6. 论文的主要结论与发现

- MAB-RRT 在 76 个 Automate 装配体（760 试验）上达到 **100% 成功率**，平均 4.31 秒、中位数 3.20 秒；最优基线 BFS 仅 53.9%，RRT 变体在 45–48%，ATA 原体系列低于 25%，uniform RRT 仅 11.4%。速度与成功率均显著优于全部基线。
- MAB-RRT 对滑动窗口、有效性区间、初始半径、样本数等超参数在宽范围内保持 98–100% 成功率，仅极端值（如 r₀ ≤ 0.01）略降至 88–94%，证明其鲁棒性。
- PEEL 在 4 个多部件装配体（10–17 部件）上均达 **100% 成功率**，总拆卸时间比顺序基线快 1–2 个数量级（如 Plier：PEEL 平均 405.66 秒 vs RRT 2308.05 秒），且方差更小。
- PEEL 的“胜者终止”机制有效减少无效计算，预算翻倍策略保证困难对象最终可获得足够规划时间。
- 五阶段机器人执行管线成功在 Fetch 仿真机器人上完成 4 个装配体的完整拆卸；自由状态检测（mobility rank）能准确识别狭窄通道结束点，减少不必要的轨迹跟随；中间重新抓取机制对该工作空间受限的操纵器是必要的。

## 7. 优点

- **新颖的问题分解**：用并行规划竞赛替代组合式顺序搜索，免去显式优先级图构建，避免指数级枚举。
- **尺度不变采样策略**：通过预热阶段自适应估计局部自由空间尺度，结合 PCA 方向偏置，有效解决狭窄通道采样难题，且对超参数不敏感。
- **严谨的鲁棒性验证**：在 76 个装配体、10 个随机旋转、多种参数设定下均验证成功率和速度，统计详实（均值/中位数/标准差/分布图）。
- **理论支撑**：给出了概率完备性证明，且与实际算法行为一致。
- **工程完整性**：从规划到机器人执行全流程闭环，包含抓取、中途重抓取、自由状态判定、目标位姿 IK 搜索等实际运动规划问题的解决方案，并有开源代码和演示视频。
- **对比公平性**：对经典 OMPL 与 ATA 基线均采用其默认参数或官方实现，并给出每试验超时和严格碰撞设置，结果可复现。

## 8. 不足与局限

- **数据集过滤**：Automate 中初始存在碰撞的装配体被剔除，仅保留 76 个严格无碰撞模型，限制了通用性；真实 CAD 装配常存在微小重叠或公差，该方法目前无法处理。
- **多部件基准规模有限**：仅 4 个装配体（10–17 部件），未测试更大规模（如 20+ 部件）或真实工业级复杂产品；也未与学习型方法（如 Cebulla 等人的 GNN 方法）在多部件上直接对比。
- **仅支持顺序可分解装配体**：无法处理需要两个或多个部件同时移动的互锁结构（如 Burr 拼图）；论文在结论中将其列为未来工作，未给出实验证据。
- **物理模型缺失**：纯几何规划忽略重力、摩擦、接触力等物理效应，生成的路径可能在实际执行中失败；作者承认未来需要用物理仿真验证。
- **机器人执行简化**：采用球形抓取工具和刚性焊接假设，回避了真实抓取稳定性；移动基座未充分体现其能力；只在仿真中验证，未在真实机器人上测试。
- **算力报告不充分**：未给出总实验时长、CPU 利用率或能耗；多部件对比中 PEEL 使用 10 核并行而基线顺序执行，时间对比包含了并行优势，虽作者明确说明，但仍不够“绝对公平”（例如未报告基线用 10 核并行时的结果）。
- **缺少失败案例分析**：参数敏感性中出现少量失败（如 r₀ 极小时 88–94% 成功率），未分析失败原因；多部件中 Coupling Block 有 2 次对象超时，亦未详细说明。
- **目标区域定义的替代方案**：使用“远离装配体的自由空间区域”作为拆卸目标，未验证“可延伸到无穷”的全局可分离性，仅做了局部自由状态检测，可能遗漏某些仅在远处才可解的路径。
- **重复实验随机性**：未报告多次种子重复的标准误差（如参数敏感性仅单次扫描），统计稳健性可进一步提升。

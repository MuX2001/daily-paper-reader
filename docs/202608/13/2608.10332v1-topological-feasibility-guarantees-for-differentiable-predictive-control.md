## 摘要
可微预测控制（DPC）是一种用于逼近显式模型预测控制（MPC）策略的自监督学习方法，与基于在线优化的MPC相比，具有显著的计算优势。然而，可行性保证作为安全控制的核心要求，目前要么以概率方式提供，要么通过在线安全过滤器实现。离线策略优化缺乏严格的可行性保证仍是一个开放问题。本文通过对诱导可达安全集进行新颖的拓扑分析，为DPC建立了确定性可行性保证，而无需在线安全过滤器。利用DPC固有的基于模型的特性，即可微系统动力学直接嵌入计算图，我们从拓扑和几何角度分析了所学控制策略及相应系统状态的属性。受理论分析的启发，我们提出了一种新颖的自监督离线策略学习策略，利用带有控制障碍函数（CBF）的代理损失。关键在于，这些属性不仅显著改善了策略训练，还能从有限数量的训练样本中推导出严格的确定性可行性保证。广泛的闭环仿真验证了我们的理论发现，表明随着训练样本量的增加，经验约束违反单调递减至零。最终，这项工作表明，DPC策略优化能够产生在传统黑箱方法（如强化学习（RL）或基于监督学习的近似MPC）中结构上无法获得的形式安全证书，从而为学习控制中的可行性保证提供了新视角。

## Abstract
Differentiable predictive control (DPC), a self-supervised learning approach for approximating explicit model predictive control (MPC) policies, offers significant computational advantages over online optimization-based MPC. However, feasibility guarantees, a core requirement for safe control, are currently provided either probabilistically or via online safety filters. The lack of rigorous feasibility guarantees for offline policy optimization remains an open problem. This paper establishes deterministic feasibility guarantees for DPC using a novel topological analysis of the induced reachable safe set, without requiring online safety filters. By exploiting the inherent model-based nature of DPC, in which differentiable system dynamics are embedded directly into the computational graph, we analyze the properties of the learned control policies and the corresponding system states from topological and geometric perspectives. Inspired by our theoretical analysis, we propose a novel self-supervised offline policy learning strategy that utilizes a proxy loss with Control Barrier Functions (CBFs). Crucially, these properties not only significantly improve policy training but also enable the derivation of strict, deterministic feasibility guarantees from a finite number of training samples. Extensive closed-loop simulations validate our theoretical findings, demonstrating that the empirical constraint violations monotonically decrease to zero as the training sample size increases. Ultimately, this work illustrates that DPC policy optimization yields formal safety certificates that are structurally unattainable with conventional black-box methods, e.g., reinforcement learning (RL) or supervised learning-based approximate MPC, thereby providing a new perspective on feasibility guarantees in learning-based control.

- **核心问题**：可微预测控制（DPC）是一种自监督学习方案，把系统动力学嵌入计算图，通过端到端反向传播直接优化显式策略，避免了离线生成 MPC 最优解。但 DPC 学到的策略**缺乏严格的确定性可行性保证**。现有方法要么只提供概率性保证，要么依赖在线安全过滤器（如控制障碍函数、HJ 可达性、预测安全滤波器）事后修正，牺牲了显式策略的计算优势与轨迹级最优性。
- **研究目标**：**完全离线**地训练 DPC 策略，使其在不使用任何在线优化或安全滤波的情况下，也能获得与优化型 MPC 类似的**确定性闭环可行性保证**。
- **核心论点**：利用 DPC 的“白箱”结构（动力学显式嵌入计算图，可自动微分），对诱导的可达安全集进行拓扑与几何分析，可以证明：只要有限数量的训练样本被充分优化并满足严格 CBF 条件，学到的策略就能对覆盖范围内的所有初始状态保持可行性。这为“学习控制能否离线获得严格安全证书”这一问题给出了肯定回答。

## 2. 方法论

### 2.1 系统与问题设定

- 研究对象为连续时间 ODE 系统：`dx_t = f(x_t, u_t) dt`，经数值积分（如 Runge-Kutta）得到离散映射 `x_{k+1} = F(x_k, u_k)`。
- DPC 优化问题：最小化多轨迹平均代价，包括跟踪代价、状态约束软惩罚、输入约束软惩罚和终端惩罚；策略为神经网络 `u_k = π_W(x_k, ξ_k)`，其中 `ξ_k` 为问题参数（参考、约束参数等）。
- 约束以一般形式给出：`h(x_k, p_hk) ≥ 0`（状态约束）、`g(u_k, p_gk) ≥ 0`（输入约束）。

### 2.2 拓扑可行性分析（核心理论）

- **关键定义**：使用离散时间零化控制障碍函数（CBF）更新条件：
  ```
  r_{k+1,l}(x_k) := h_l(x_{k+1}, p_h,k+1) - (1-η) h_l(x_k, p_h,k) ≥ 0
  ```
  其中 `η ∈ (0,1]`，且对 `h_l` 保真，不改变安全集的原始几何结构。
- **假设**：
  1. 动力学 `F` 与安全集局部 Lipschitz；
  2. 每个可行初始状态都存在满足 CBF 条件的可行控制轨迹；
  3. 约束函数 `h` 关于状态 Lipschitz；
  4. 神经网络策略 `π_W` 关于状态局部 Lipschitz。
- **主要理论链条**：
  - **引理 3.5 / 推论 3.6**：在 Lipschitz 假设下，各时刻安全集 `X(k)` 与可达安全集 `X_r(k)` 均为紧集，因此可达安全状态序列空间 `X_r` 紧致。
  - **引理 3.7**：证明 CBF 残差 `r_{k+1}(x_k)` 关于状态局部 Lipschitz，Lipschitz 常数为：
    ```
    L = L_{h,x,k+1}(L_{F,x} + L_{F,u} L_π) + (1-η) L_{h,x,k}
    ```
  - **命题 3.8**：若训练轨迹在最优点满足严格 CBF 条件（`r_{k+1}(x*_k) > 0`），则最优点存在一个**开邻域**保持可行性，且显式可行性半径为：
    ```
    ε_k = r_{k+1}(x*_k) / L
    ```
  - **推论 3.9**：每个可行标称状态序列在轨迹空间中都存在一个非空开邻域。
  - **定理 3.10（紧致覆盖）**：由于 `X_r` 紧致，且每个标称序列周围的开邻域构成开覆盖，由 Heine-Borel 定理，存在有限子覆盖，即**有限数量训练样本即可覆盖整个可达安全集**。
  - **定理 3.11（样本增加与违规概率）**：随训练样本数 `m` 增加，可行覆盖集合单调不减，因此**约束违反概率单调不增**，且在达到覆盖所需样本数 `m0` 后**概率降为 0**。
  - **引理 3.12 / 命题 3.13（样本复杂度）**：给出保守可行性半径与最大所需样本数上界：若有限个保守可行性球覆盖各时刻可达安全集，则对应样本数足以保证精确可行性。

### 2.3 CBF-proxy DPC：两阶段同伦训练算法

- 为了把理论可行性条件嵌入离线训练，提出两阶段训练：
  - **阶段 1（软惩罚热启动）**：使用标准 DPC 损失 `L_NC`（ReLU/GeLU 软惩罚），让策略快速收敛到名义可行、较优的轨迹流形，避免对数障碍在安全集外初始化时的数值脆弱性。记为名义状态序列 `\bar{x}_k`。
  - **阶段 2（离线 CBF 代理微调）**：引入带非负松弛变量 `δ_{k,l}^{(i)}` 的 CBF 残差：
    ```
    r_{k+1,l}(x_k) = h_l(F(x_k,u_k),p_h,k+1) - (1-η) h_l(x_k,p_h,k) + δ_{k,l}
    ```
    构造 CBF 代理损失：
    ```
    L_CBF = Σ_i Σ_k [ ||x_k(W)- \bar{x}_k||^2 + ρ(δ_{k,l})^2
                        - τ Σ_l log(r_{k+1,l}(x_k)) ]
    ```
    其中第一项保持与阶段 1 的名义轨迹接近；第二项重罚松弛变量（使其尽量为 0）；第三项为施加在 CBF 残差上的对数障碍，推动策略进入安全集内部。
  - 总损失：`L_NC + L_CBF`，纯离线优化 `W` 与 `δ`；当所有 `δ=0` 即输出严格可行性证书。
- **输入约束**：通过在策略网络输出层使用饱和激活（如归一化 tanh）加仿射变换，**结构性保证输入约束严格满足**。
- **命题 4.1（确定性闭环可行性）**：在 Lipschitz 假设、训练数据覆盖可达安全集、且所有松弛变量为零的条件下，所学显式策略对任意初始状态 `x0 ∈ X_r(0)` 都能**确定性地**满足状态与输入约束，无需在线优化或事后安全滤波。

## 6. 主要结论与发现

- **确定性可行性可实现**：通过拓扑紧致性 + CBF 代理损失离线训练，DPC 策略可以在不需要在线安全滤波器的前提下，对覆盖范围内的所有初始状态给出**严格、确定性**的闭环可行性保证。
- **有限样本足够**：由于可达安全集紧致，有限个严格可行训练轨迹的开邻域即可构成有限覆盖；因此“样本数足够大时违反概率为零”不是渐近结论，而是**有限样本即可达到**。
- **CBF-proxy 损失有效**：消融实验表明，加入 CBF 代理损失后，约束违反率明显低于标准 DPC（软惩罚）基线。
- **样本增加单调改善**：三个实验均观测到约束违反率随训练样本数增加**单调下降并趋于零**，与定理 3.11 一致。
- **白箱结构的独特优势**：DPC 把动力学嵌入计算图，使得可以对可达集进行 Lipschitz 分析并推导局部可行性半径；这种安全证书是 RL 或监督学习近似 MPC 等黑箱方法在结构上无法获得的。

- **理论贡献清晰且新颖**：首次从拓扑视角（紧致性 + 开覆盖 + Heine-Borel）给出 DPC 的确定性可行性证明，并给出显式可行性半径与最大样本复杂度的保守上界。
- **算法设计闭环**：理论条件（严格 CBF 残差）直接转化为可微代理损失（log barrier + 松弛变量），并通过两阶段训练解决纯 barrier 方法的数值脆弱性。
- **不需要在线修正**：可行性由构造保证，无需 QP 安全滤波器或预测安全滤波器，保留了显式策略的推理速度和轨迹最优性。
- **模型透明性利用充分**：依赖 Lipschitz 连续性和动力学可微性，而非依赖特定最优解或策略逼近误差，适用范围比“用神经网络逼近显式 MPC”的方法更广。
- **实验与理论呼应**：三个不同复杂度的 benchmark 均验证了“样本量增加 → 违规率单调降至零”的理论预测，并通过消融实验说明 CBF 代理损失的贡献。

## 8. 不足与局限

- **存在性证明而非构造性算法**：定理证明“存在有限覆盖”并给出保守半径，但没有给出如何**主动/最优地选择训练样本**以保证覆盖的显式算法；样本复杂度上界依赖全局 Lipschitz 常数，实际可能很保守。
- **CBF 条件本身未保证存在性**：假设 3.2（存在可行控制轨迹满足 CBF）对非线性系统并不自动成立；论文没有给出验证该可达性/可控性假设的数值方法或可检验条件。
- **对数据分布敏感**：理论要求训练轨迹的可行性球覆盖可达安全集，但随机采样在复杂高维空间很难保证覆盖，尤其四旋翼实验只用十几个训练样本，实际工程中可能不稳妥。
- **缺乏鲁棒性与不确定性分析**：没有考虑参数不确定、系统扰动、测量噪声或模型失配；这些因素在实际部署中可能破坏 CBF 条件的严格成立。
- **实验规模与基准对比有限**：缺少与主流安全学习控制方法（如 RL+CBF、在线预测安全滤波器、概率安全 MPC）的横向数值对比；也缺少更高维、更复杂约束（如避障+时间逻辑任务）的验证。
- **算力信息缺失**：没有报告训练时间、硬件资源，影响可复现性和成本评估。
- **线性化四旋翼模型**：四旋翼实验使用线性化模型，虽然便于基准比较，但无法验证非线性强耦合环境下的可行性保证。

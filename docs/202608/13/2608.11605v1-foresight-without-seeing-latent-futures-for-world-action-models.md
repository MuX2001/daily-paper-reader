## 摘要
世界动作模型（WAMs）将未来视觉预测与机器人动作生成相结合，使策略能够建模交互过程中物理世界的演变。现有WAMs在预测动态如何暴露于动作路径方面有所不同。显式未来WAMs提供对预测场景演变的直接访问，但会产生来自迭代视频去噪的显著推理成本。相比之下，直接策略WAMs从当前观测高效预测动作，但缺乏将预测动态暴露给动作DiT的显式推理时接口。为弥合这一差距，我们提出ForeWAM，一种动态条件化的直接策略WAM，在不解码未来视频的情况下为动作生成提供预测上下文。其核心Future-KV在当前视觉潜在变量和随机未来槽上执行单次Video DiT预填充，并在整个动作去噪过程中重用所得的逐层键值状态。我们进一步引入由冻结的潜在动作教师监督的动态寄存器，鼓励隐式未来状态捕获交互引起的转换，如物体运动、接触变化和任务进度。真实未来观测和教师仅在训练期间使用；部署时两者均不需要，也不进行未来视频生成。在没有具身机器人数据预训练的情况下，ForeWAM的标准和加速变体在LIBERO上分别达到96.7%和96.9%的平均成功率。标准变体在LIBERO-Plus上进一步达到61.6%的成功率。这些结果表明，直接策略WAMs可以在不显式生成未来观测的情况下，将预测动态暴露给动作路径，同时保持高效的动作预测。

## Abstract
World Action Models (WAMs) couple future visual prediction with robot action generation, enabling policies to model how the physical world evolves during interaction. Existing WAMs differ in how predictive dynamics are exposed to the action pathway. Explicit-future WAMs provide direct access to predicted scene evolution, but incur substantial inference costs from iterative video denoising. In contrast, direct-policy WAMs efficiently predict actions from the current observation but lack an explicit inference-time interface for exposing predictive dynamics to the Action DiT. To bridge this gap, we propose ForeWAM, a dynamics-conditioned direct-policy WAM that provides predictive context for action generation without decoding future videos. At its core, Future-KV performs a single Video DiT prefill over the current visual latent and stochastic future slots, and reuses the resulting layer-wise key-value states throughout action denoising. We further introduce dynamics registers supervised by a frozen latent action teacher, encouraging the implicit future states to capture interaction-induced transitions such as object motion, contact changes, and task progress. Ground-truth future observations and the teacher are used only during training; deployment requires neither and performs no future video generation. Without embodied robot data pretraining, the standard and accelerated variants of ForeWAM achieve average success rates of 96.7% and 96.9% on LIBERO, respectively. The standard variant further achieves 61.6% success on LIBERO-Plus. These results demonstrate that direct-policy WAMs can retain efficient action prediction while exposing predictive dynamics to the action pathway without explicitly generating future observations.

### 2. 论文提出的方法论：核心思想、关键技术细节、公式与流程

**核心思想**：用“潜在未来”（latent futures）代替“可见未来”（可见的未来视频生成），即“foresight without seeing”——动作路径能“感知”到预测的动态信息，但无需在像素空间解码这些信息。

整体架构包含三大创新组件：

**（1）Future-KV 隐式接口**
- 保留当前观测的干净视觉潜在变量 zcur（首帧），并在未来槽（future slots）中填入纯噪声 ϵF，构成随机未来底物（stochastic substrate）：
  ```
  z̃F_sub = concat(zcur(o), ϵF),  ϵF ~ N(0, I)
  ```
- 对该底物执行**一次 Video DiT 前向预填充（single prefill）**，得到逐层的键-值（K/V）缓存：
  ```
  (Dθ, HKV) = KVPrefill_φ(z̃F_sub, l, p)
  ```
- 该 K/V 缓存在整个动作去噪过程中被复用，Action DiT 无需迭代式视频生成即可读取视频骨干形成的预测上下文。

**（2）动力学寄存器（Dynamics Registers）与潜在动作教师**
- 引入 ND = 16 个可学习的动力学寄存器 token（Di），通过结构化的注意力掩码路由，使其能编码物体运动、接触变化、任务进度等交互相关的状态转移信息。
- 使用**冻结的 LaWM 潜在动作教师**提取训练时的目标 zLA——该教师以逆动力学方式学习从真实观测转换（t_i → t_i+1）中提取紧凑的潜在动作表征。
- 训练时，均值池化的动力学寄存器经过可训练投影头 gψ 映射到教师空间，并以均方误差形式进行蒸馏监督：
  ```
  L_LA = || gψ( (1/ND) Σ Di ) − sg(zLA) ||²₂
  ```
- 教师只在训练时使用，且其输出是非可执行的潜在动作表征，不作为推理时的动作命令。

**（3）结构化注意力路由**
- 四种 token 组：当前帧 token C、动力学寄存器 D、未来槽 token F、动作 token A。
- 掩码规则：未来槽可读取当前帧和动力学寄存器；动作 token 可读取完整视频序列（C + F）和寄存器 D；从而形成视频骨干 → Action DiT 的预测信息通路。

**部署时策略**（式5）：
```
pθ(a₁:H | o, l, p, Dθ(o,l,p,ϵF), HKV(o,l,p,ϵF))
```
- 不依赖真实未来观测、不依赖教师、不进行任何未来视频解码。
- 未来槽仅是内部条件底物，其有效性通过联合视频-动作目标在训练中学习而来。

**训练目标**：联合优化三个损失项：
```
L = L_video + L_action + λ_LA · L_LA
```
- L_video 和 L_action 均为连续流匹配（flow matching）目标：
  ```
  L_FM(y) = E || fθ(y_t, t, o, l, p) − (ϵ − y) ||²₂,  其中 y_t = (1−t)y + tϵ
  ```

### 6. 论文的主要结论与发现

1. **直接策略 WAM 可以不生成未来视频而获得预测动力学**：ForeWAM 通过 Future-KV 和动力学寄存器，成功弥合了“高效动作预测”和“预测上下文暴露”之间的接口缺口。
2. **标准 LIBERO 性能出色**：ForeWAM 平均成功率 96.7%，ForeWAM-Flash 达 96.9%，与 Fast-WAM（97.6%）仅差 0.7–0.9 个百分点，且**无需具身机器人数据预训练**。
3. **LIBERO-Plus 鲁棒性显著领先**：ForeWAM 在 LIBERO-Plus 上达 61.6%，比 Fast-WAM（51.5%）高 10.1 个百分点；最大增益出现在相机视角（+46.1 点）和传感器噪声（+21.1 点）。
4. **推理效率大幅提升**：ForeWAM 动作生成延迟 568 ms（较 Fast-WAM 667 ms 降低 14.8%）；ForeWAM-Flash 进一步降至 220 ms（较 Fast-WAM 降低 67.0%）。
5. **参数量更具优势**：约 2B 参数，仅为 Fast-WAM（6B）的三分之一左右。
6. **消融验证组件互补性**：组合两个路径（61.6%）优于单独使用 Future-KV（58.5%）或单独 LA 监督（58.0%）。

### 7. 优点

- **方法创新性**：首次提出“潜在未来 K/V 缓存 + 动力学寄存器”的组合方案，直接解决了直接策略 WAM 中预测上下文缺失这一核心接口问题，概念优雅且实用。

### 8. 不足与局限

- **实验覆盖有限**：仅限 LIBERO 模拟套件和 LIBERO-Plus，未评测真实机器人平台、其他仿真环境、不同机器人形态或任务分布；无法确定在更广部署场景中的泛化能力。
- **消融规模与公平性受限**：
  - 核心消融仅 4 个配置、单组覆盖匹配评估（1,482 次/配置）；
  - Base policy 的覆盖率（10,027 次）与对比配置不同，因而其对比结论是参考性的而非严格的因果估计；
  - 没有对寄存器数量、K/V 缓存是否分层复用等设计选择做敏感性分析。
- **跨方法比较的不对称性**：LIBERO-Plus 对比种外部基线结果来自不同论文来源，作者未完全控制实现细节；且 ForeWAM 在机器人初始状态和光照扰动上分低于 Fast-WAM。
- **潜在偏差风险**：
  - 未来槽用随机噪声初始化，且依赖一次 prefill 形成上下文——该内部底物在不同场景下的鲁棒性未经系统验证；
  - 没有证据证明动力学寄存器“因果必要”，作者也承认掩码只定义路由而非因果充分性；
  - LA 监督只用于训练阶段，具体质量、量化维度和教师选择对最终性能的影响未被分析。
- **效率测量的独立性**：延迟报告是独立推理测量，而非完整任务完成时间和端到端系统吞吐量；且训练算力消耗（GPU 数量/时长）未报告，读者难以评估全程成本。

## 摘要
自动驾驶需要在语义约束和预测动力学下进行规划。然而，现有的端到端驾驶方法通常只强调这一要求的某一方面：视觉-语言-动作（VLA）模型利用VLM先验进行语义推理，而世界动作模型（WAM）通过生成式世界建模提供未来感知的预测。这自然地促使我们需要一个统一的规划器，能够同时利用语义先验和预测动力学。然而，我们发现，通过联合token级注意力进行的简单组合存在注意力分配不匹配的问题，其中语义捷径主导了共享注意力空间并抑制了预测动力学。受神经科学中复杂行为源于功能专门化系统之间协调的启发，我们提出了BrainWAM，这是一种结构化的动作空间协调框架，它将语义推理和预测世界建模转化为两条专门的动作导向通路，并在紧凑的动作表示层面将它们对齐。我们进一步引入了一种异步校正流推理策略，具有解耦的视频和动作去噪，从而缩短推理延迟，同时保留与规划相关的预测上下文。BrainWAM在NAVSIM v1（89.5 PDMS）和NAVSIM v2（89.6 EPDMS）上均达到了最先进的性能，持续优于仅使用VLA或仅使用WAM的方法，凸显了BrainWAM作为自动驾驶系统的一个实用且有前景的方向。

## Abstract
Autonomous driving requires planning under both semantic constraints and predictive dynamics. Existing end-to-end driving approaches, however, typically emphasize only one side of this requirement: Vision-Language-Action (VLA) models exploit VLM priors for semantic reasoning, while World Action Models (WAMs) provide future-aware prediction through generative world modeling. This naturally motivates a unified planner that can leverage both semantic priors and predictive dynamics. However, we find that a naive combination through joint token-level attention suffers from an attention-allocation mismatch, where semantic shortcuts dominate the shared attention space and suppress predictive dynamics. Inspired by neuroscience evidence that complex behavior arises from coordination among functionally specialized systems, we propose BrainWAM, a structured action-space coordination framework that converts semantic reasoning and predictive world modeling into two specialized action-oriented pathways, and aligns them at the level of compact action representations. We further introduce an asynchronous rectified-flow inference strategy with decoupled video and action denoising, which shortens inference latency while preserving planning-relevant predictive context. BrainWAM reaches state-of-the-art performance on both NAVSIM v1 (89.5 PDMS) and NAVSIM v2 (89.6 EPDMS), consistently outperforming VLA-only or WAM-only methods, highlighting BrainWAM as a practical and promising direction for autonomous driving systems.

### 1. 论文的核心问题与整体含义

- **研究背景**：自动驾驶规划需要同时满足两类互补的信息：**语义约束**（如交通规则、路线指令、场景语义、驾驶意图）和**预测动力学**（如未来场景演变、交互结果、物理可行性）。
- **现有方法的局限**：
  - **VLA 模型**（如 ReCogDrive、AutoVLA）擅长利用视觉语言模型先验进行语义推理，但缺乏对未来场景演变的显式建模；
  - **WAM 模型**（如 Epona、DriveLaW）擅长生成式世界建模和未来感知预测，但规则感知和意图推理能力较弱。
- **核心发现**：将 VLM token、视频生成模型 token 和动作 token 直接放进共享注意力空间（Tri-MoT）进行原始 token 级融合，会导致**注意力分配不匹配**——动作 token 过度关注语义 token，抑制了预测动力学信号，甚至性能低于单独使用 WAM。
- **论文目标**：提出一个统一框架，将 VLA 的语义推理与 WAM 的预测动力学有效结合，避免 token 级融合带来的模态竞争问题。受神经科学中“大脑左右半球功能专门化并通过胼胝体协调”的启发，提出动作空间协调框架 **BrainWAM**。

### 2. 论文提出的方法论

- **整体思想**：不将原始 VLM/VGM token 混在一起，而是让语义推理和预测世界建模分别形成**动作导向的专用路径**，然后在紧凑的“动作表示”层面进行双向协调与融合。
- **两分支架构**：
  - **VLA 分支（左半球对应）**：基于 Qwen3-VL-4B，从多视角图像和驾驶指令中提取语义 token，通过 Dual-MoT 模块与动作专家交互，得到语义grounded的动作 token \(A_{\text{sem}}\)。
  - **WAM 分支（右半球对应）**：基于 Wan2.2-TI2V-5B 视频生成骨干，预测未来视频潜在表示，同时通过动作专家生成预测grounded的动作 token \(A_{\text{pred}}\)。
- **关键模块**：
  - **Callosal Action Bridge (CAB)**：类似胼胝体，在两个动作 token 流之间做双向交叉注意力，并通过零初始化的 gated residual 进行注入，避免原始 token 级混合。
  - **Cerebellar Intent Fusion (CIF)**：类似小脑运动协调，将两个精细化的动作流拼接后经两层 Transformer 融合，并解码为最终轨迹。
- **训练流程（三阶段）**：
  1. **Stage 1**：训练 WAM 分支，使用 rectified-flow 对视频和动作分别加噪，预测速度和动作速度场，损失为视频重建 + 动作损失。
  2. **Stage 2**：训练 VLA 分支，用视觉+语言输入预测动作速度场。
  3. **Stage 3**：冻结两分支，仅训练 CAB、CIF 和动作解码器，监督融合后的动作预测。
- **异步推理策略**：视频和动作使用独立的整流流时间步；视频分支可提前终止并提供预测上下文特征，动作分支继续去噪生成轨迹，从而降低推理延迟。
- **核心公式**：Rectified-flow 线性路径 \(x_t = (1-t)x_0 + t\epsilon\)，速度目标 \(u=\epsilon-x_0\)；总损失 \(L_{\text{WAM}} = L_{\text{vid}} + \lambda L_{\text{action}}\)，VLA 分支和融合分支分别有对应损失。

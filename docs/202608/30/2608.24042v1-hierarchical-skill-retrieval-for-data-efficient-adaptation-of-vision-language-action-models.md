## 摘要
尽管在大规模机器人数据集上预训练的视觉-语言-动作（VLA）模型为机器人操作提供了强大基础，但在适应新任务且任务特定演示有限时，其性能可能会下降。检索为数据高效的适应提供了一种重用现有演示的实用方法，但现有方法通常依赖视觉相似性、状态-动作表示或任务级语言匹配。这些方法可能忽略长视野操作任务的层级结构，其中完整任务匹配很少见，但可重用的技能往往很丰富。为解决这一挑战，我们提出了层级技能检索（HSR），一种用于数据高效VLA适应的检索框架。具体而言，HSR首先将目标任务分解为候选技能序列。它根据语义合理性和从先前数据集估计的技能可靠性来评估每个计划。然后使用选定的分解进行混合检索。这结合了子任务级语言检索和行为特征重排序，以识别既语义相关又与目标任务兼容的演示。最后，我们通过两阶段预训练和微调流程来适应策略，该流程将一般技能获取与任务特定适应分开。在LIBERO基准和几个真实世界机器人操作任务上的实验表明，HSR分别比最强基线平均成功率提高了10.3%和21.3%。这些结果证明了结构化技能级检索对数据高效VLA适应的有效性。视频和代码可在https://hoar012.github.io/HSR-Project获取。

## Abstract
While Vision-Language-Action (VLA) models pretrained on large-scale robot datasets provide a strong foundation for robot manipulation, their performance can degrade when adapted to new tasks with limited task-specific demonstrations. Retrieval offers a practical way to reuse existing demonstrations for data-efficient adaptation, but existing methods often rely on visual similarity, state-action representations, or task-level language matching. These approaches may overlook the hierarchical structure of long-horizon manipulation tasks, where complete task matches are rare but reusable skills are often abundant. To address this challenge, we propose Hierarchical Skill Retrieval (HSR), a retrieval framework for data-efficient VLA adaptation. Specifically, HSR first decomposes a target task into candidate skill sequences. It evaluates each plan based on both semantic plausibility and skill reliability estimated from the prior dataset. The selected decomposition is then used for hybrid retrieval. This combines subtask-level language retrieval with behavior-feature reranking to identify demonstrations that are both semantically relevant and compatible with the target task. Finally, we adapt the policy through a two-stage pretraining and finetuning pipeline, which separates general skill acquisition from task-specific adaptation. Experiments on the LIBERO benchmark and several real-world robot manipulation tasks show that HSR improves the average success rate by 10.3% and 21.3% over the strongest baseline, respectively. These results demonstrate the effectiveness of structured skill-level retrieval for data-efficient VLA adaptation. Videos and code are available at https://hoar012.github.io/HSR-Project.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：VLA（视觉-语言-动作）模型在大规模机器人数据集上预训练后，具备较强的视觉-语言理解和动作生成能力。然而，在针对具体下游任务做适配时，通常只能获得极少量任务演示数据，导致模型性能严重下降。
- **核心问题**：如何在目标数据极少的情况下，利用已有的大规模先验数据集（如 Open X-Embodiment、DROID 等）进行高效的策略适配？现有检索方法多基于视觉相似性、状态-动作特征或任务级语言匹配，忽视了长程操作任务中的**层级结构**——完整任务匹配稀少，但可复用的子技能（如 Pick、Open、Pour 等）非常普遍。
- **核心思路**：本文认为，应该把长程任务**分解为一系列可复用技能**，再以技能为单位从先验数据中检索相关演示，从而提升数据效率和任务表现。整体含义是：通过“任务分解 → 技能级检索 → 两阶段适配”，让 VLA 模型在极少目标演示下也能有效学习复杂操作。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 总体框架（HSR）

HSR 包含三个主要阶段：

1. **层级任务分解与计划评估**（LLM-based task decomposition + plan evaluation）；
2. **混合技能检索**（hybrid skill retrieval：语言检索 + 行为特征重排序）；
3. **两阶段策略适配**（pretraining + finetuning）。

### 2.2 技能挖掘与可靠性评估

- **技能聚类**：对先验数据集 `D_prior` 中所有任务指令提取文本嵌入（BERT），然后使用 K-means 聚类得到 `K` 个技能簇 `S = {s1, ..., sK}`，例如 `Find`、`Pick up`、`Pour` 等。
- **技能置信度计算**：
  - 为避免真实 rollout 的高成本，采用**held-out BC loss** 作为技能可靠性的轻量代理。
  - 将 `D_prior` 分为训练集和验证集，微调预训练 VLA 模型得到 `π_θ'`。
  - 对技能簇 `si`，计算验证轨迹的平均 BC 损失：

    \[
    L_{traj}(\tau) = \frac{1}{H_\tau} \sum_{t=1}^{H_\tau} \ell_{BC}(\pi_{\theta'}(o_t, T), a_t)
    \]

    \[
    L_{val}(s_i) = \frac{1}{|V_i|} \sum_{\tau \in V_i} L_{traj}(\tau)
    \]

  - 进一步考虑轨迹长度（长程技能更容易累积误差），定义 **Skill Confidence Score**：

    \[
    C(s_i) = \exp\left( - \alpha \tilde{L}_{val}(s_i) - \beta \tilde{H}(s_i) \right)
    \]

    其中 `\tilde{L}` 和 `\tilde{H}` 为 min-max 归一化值，`α=0.6`，`β=0.8`。

### 2.3 基于 LLM 的任务分解与计划选择

- 使用 LLM（Qwen3-VL-4B）生成候选分解计划 `p = (u1, ..., un)`。
- 同时让 LLM 提供每个计划的语义合理性评分 `S_sem(p)`（任务覆盖率、逻辑一致性等）。
- 每个子任务 `uj` 根据文本嵌入相似度映射到最近的技能簇 `s(uj)`。
- 计划最终得分为：

    \[
    Score(p) = S_{sem}(p) \cdot \prod_{j=1}^{n} C(s(u_j))
    \]

  选择得分最高的计划作为最终分解，用于后续检索。

### 2.4 混合检索（语言检索 + 行为特征重排序）

- **第一阶段（语言检索）**：针对每个子任务的指令，在 `D_prior` 中检索文本嵌入相似度最高的前 `M%` 个 episodes。
- **第二阶段（行为特征重排序）**：
  - 在 `D_prior` 上训练一个 VAE 编码器，提取行为特征（behavior features）。
  - 将语言检索到的 episodes 展平为帧级候选，计算每帧 `f` 与目标数据集 `Dt` 中所有帧的负距离最大值作为相似度：

    \[
    s(f) = \max_{1 \le j \le N_t} \left( -\| z_f - z_{t_j} \|^2 \right)
    \]

  - 保留相似度最高的前 `F%` 帧，作为最终检索数据 `Drerank`。

### 2.5 两阶段策略适配

- **第一阶段（技能预训练）**：在语言检索到的全部数据 `Dlang`（或 rerank 后的全部检索数据）上训练策略，以获取通用的可迁移技能。
- **第二阶段（任务微调）**：在目标数据 `Dt` 与重排序后的检索数据 `Drerank` 上微调策略，实现任务特定适配。
- 这种设计不同于单阶段 co-training，避免检索数据质量参差不齐导致优化偏差。

## 3. 实验设计：数据集、Benchmark、对比方法

### 3.1 仿真实验（LIBERO）

- **环境**：LIBERO benchmark 的 long-horizon 子集，共 10 个复合操作任务。
- **目标数据**：每个任务 5 条演示（`Dt`）。
- **先验数据**：LIBERO-90（90 个任务，每任务 50 条演示）作为 `D_prior`。
- **检索设置**：第一阶段检索 top 10% episodes，第二阶段保留 top 30% 帧（约 `D_prior` 的 3% 帧）。
- **评估**：50 episodes × 3 个随机种子，报告平均成功率与标准差。

### 3.2 真实机器人实验

- **平台**：7-DoF xArm 机器人。
- **任务（4 个）**：
  - Drawer（关抽屉，1 个子任务）
  - Trashcan（捡纸团扔进垃圾桶，2 个子任务）
  - Cup-Drawer（放杯入抽屉并关闭，3 个子任务）
  - Cup-Tea（放茶包、倒水，4 个子任务）
- **目标数据**：每任务 20 条演示。
- **先验数据**：从 DROID 数据集随机采样 10k 条轨迹。
- **适配设置**：因跨本体差距大，采用 rerank 后 top 3% 帧做技能预训练，第二阶段只在目标数据上微调。
- **评估**：每任务 20 次试验，不同初始状态，模型间状态集一致。

### 3.3 对比方法

- **BC**：仅用目标数据微调。
- **Random**：随机采样 10% 先验数据 + 目标数据 co-training。
- **All Data**：用全部先验数据 + 目标数据 co-training。
- **Language**：基于语言相似度检索 + co-training。
- **FR**（Flow Retrieval）：基于光流相似度检索。
- **STRAP**：基于视觉基础模型和动态时间规整的子轨迹检索。
- **BR**（Behavior Retrieval）：基于 VAE 状态-动作表示的检索。
- **IWR**（Importance Weighted Retrieval）：基于重要性加权的检索。

### 3.4 消融实验

在 LIBERO 的 4 个任务（Soup-S、Bowl-C、Mug-P、Moka-M）上进行：

- **w/o Decomposition**：去掉任务分解，直接用完整任务指令检索。
- **w/o Feature Reranking**：去掉行为特征重排序，只保留语言检索。
- **Co-training w/o / w/ Reranking**：单阶段 co-training 的两种变体。
- **BR + Two-Stage**：将 HSR 的检索替换为 BR，但保留两阶段训练。
- **Reranking 保留比例**：测试 10%、30%、50%、70% 的累积效果。
- **任务分解方式对比**：仅 LLM、LLM+技能集、HSR（+计划评估）、人工分解。

## 6. 论文的主要结论与发现

- HSR 在 LIBERO 上平均成功率较最强基线（BR）提升 **10.3%**（43.5% vs 33.2%）。
- 在真实机器人任务上整体成功率较最强基线（IWR）提升 **21.3%**（48/80 vs 31/80）。
- 在长程复合任务（如 Mug-M、Bowl-C、Cup-Tea）上的增益最显著，说明技能级结构化检索优于任务级或视觉级检索。
- 消融显示：任务分解、行为特征重排序、两阶段训练各自都有贡献，其中任务分解和两阶段训练对复杂任务尤为关键。
- 检索数据分布分析表明，HSR 能够按子任务检索到不同类型（如放置、微波炉关闭）的演示，而基线方法容易引入语义或行为不匹配的数据。

## 7. 优点：方法与实验设计的亮点

- **方法创新性**：提出“先分解、后按技能检索”的范式，利用任务层级结构，而非简单整段匹配。
- **可落地性**：技能可靠性估计采用 BC loss 代理，避免昂贵的环境 rollout，计算成本可控。
- **混合检索设计**：语言（语义相关）+ 行为特征（执行兼容）双通道，兼顾高层语义与低层动态一致性。
- **两阶段适配策略**：预训练（获取通用技能）与微调（任务特定）解耦，缓解了检索数据噪声对目标任务的干扰。
- **实验完整性**：同时覆盖仿真与真实机器人，并在真实任务中验证了跨本体（DROID → xArm）场景；消融分析系统，直观展示了各组件的贡献。
- **可视化分析**：提供了检索数据分布的可视化，有助于理解不同方法的检索行为。

## 8. 不足与局限

- **任务覆盖有限**：仅涉及操作（manipulation）任务，未扩展到导航、移动操作等更广场景。

- **真实实验规模较小**：真实任务 4 个，每任务 20 次试次，对比基线有限，且未进行多种子重复（无法提供标准差）。

- **未涉及闭环重规划**：LLM 仅用于训练时分解，未实现部署时的在线重规划或失败恢复。
- **算力信息不透明**：未披露训练时间、显存占用等资源指标，可复现性细节不足。

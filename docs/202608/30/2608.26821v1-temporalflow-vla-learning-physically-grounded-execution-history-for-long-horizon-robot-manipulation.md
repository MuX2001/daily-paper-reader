## 摘要
视觉-语言-动作（VLA）模型利用预训练的视觉-语言表示进行机器人控制，但简单添加历史帧并不能可靠地捕捉近期的物理变化。这在多阶段操作中尤其成问题，因为视觉上相似的状态可能根据先前的执行而需要不同的动作。为应对这一挑战，我们提出了TemporalFlow-VLA，通过物理基础的时间监督来学习紧凑的执行历史。利用记录的机器人状态、机器人几何和标定相机，我们构建机器人-表面时间流作为仅训练目标，并监督两个执行对齐的时间查询，为动作专家提供结构化历史。几何监督路径在部署时不进行评估。TemporalFlow-VLA在LIBERO上实现了97.63 ± 0.26%的平均成功率，其中在LIBERO Long上为96.60 ± 0.87%，并在12个RoboTwin任务中实现了85.5%/84.2%的干净/随机化成功率。在更长时程、多阶段操作中，它显示出相比先前方法最明显的优势。受控的历史干预实验表明，动作预测依赖于历史内容和时间顺序。通过异步特征缓存，时间条件保持在服务器端的单帧级采样延迟，而无需额外的历史编码开销。总体而言，TemporalFlow-VLA提供了一个紧凑的、物理基础的接口，用于利用有序执行历史，而无需在部署时进行显式运动估计或几何处理。

## Abstract
Vision-language-action (VLA) models leverage pretrained vision-language representations for robot control, yet simply adding historical frames does not reliably capture recent physical change. This is especially problematic in multi-stage manipulation, where visually similar states may require different actions depending on prior execution. To address this challenge, we present TemporalFlow-VLA, which learns compact execution history through physically grounded temporal supervision. Using recorded robot states, robot geometry, and calibrated cameras, we construct robot-surface temporal flow as a training-only target and supervise two execution-aligned temporal queries that provide structured history to the action expert. The geometric supervision path is not evaluated at deployment. TemporalFlow-VLA achieves 97.63 +/- 0.26% average success on LIBERO, including 96.60 +/- 0.87% on LIBERO Long, and 85.5%/84.2% Clean/Randomized success across 12 RoboTwin tasks. It shows its clearest advantage over prior methods on longer-horizon, multi-stage manipulation. Controlled history interventions show that action prediction depends on both historical content and temporal order. With asynchronous feature caching, temporal conditioning maintains single-frame-level server-side sampling latency without additional historical-encoding overhead. Overall, TemporalFlow-VLA provides a compact, physically grounded interface for exploiting ordered execution history without explicit motion estimation or geometric processing at deployment.

- **对比线索**：TraceVLA 证明将跟踪点轨迹转换为视觉提示可显著优于六帧历史基线，这表明**关键不是简单提供历史，而是以对控制有意义、结构化的形式表示近期物理演化**。
- **整体含义**：TemporalFlow-VLA 主张采用**物理基础的（physically grounded）运动监督**，而非仅将历史帧作为额外推理时输入，从而在紧凑的潜在表征中显式编码"物理上发生了什么变化"。

### 2. 方法论：核心思想、关键技术细节

#### 2.1 核心思想

- 在预训练 VLA 策略中引入并行时间通路，利用机器人运动学构造的**机器人表面时间流（robot-surface temporal flow）**作为**仅训练用监督目标**，监督两个**执行对齐的时间查询 Q8 与 Q15**，让它们携带结构化的历史信息给动作专家。
- 部署时**不评估几何监督路径**，不使用任何光流、轨迹或运动矢量估计器；历史信息通过两个紧凑查询经联合掩码注意力注入动作生成，并借助异步缓存避免推理开销。

#### 2.2 系统结构

- 基础策略仍以当前帧 RGB、语言指令、机器人状态和扩散时间步预测动作块；时间通路额外接收头部相机的 t−15、t−8 和 t 帧（16 步动作块下，t−15 与 t−8 约对应上一动作块的起点与中点）。
- 两个可学习时间 token（q8、q15）被加入标准的 π0.5 前缀 Pstd(V0, L, s)：

  `P0 = [Pstd(V0, L, s); V15; V8; q8; q15]`

- 历史图像块（V8、V15）仅加学习到的帧身份嵌入，**动作 token 不能直接访问历史图像补丁**，只能经由 Q8、Q15 两个查询获取历史信息。

#### 2.3 层级掩码注意力

- 有向查询专用掩码组织两个查询的层级关系：
  - Q8 只能关注语言 token、t−8 观察、当前观察和自身 → 专门编码近期运动；
  - Q15 可额外关注 t−15 观察和 Q8 → 在短期摘要基础上整合更长范围历史；
  - Q8 → Q15 单向传递，保持两个时间尺度语义独立。
- 动作 token 的注意力掩码在保留原始 VLA 上下文基础上，仅暴露 Q8 与 Q15，阻断对 V8、V15 的直接访问。

#### 2.4 运动学基础的机器人表面时间流（监督目标）

- 对每个时间区间 ρ∈{8,15}，令 s=t−ρ，利用关节配置 qτ、连杆到基座的正向运动学变换 TlB(qτ) 和基座到相机的标定变换 TC←B：
  1. 机器人渲染器给出每个可见机器人源像素 p 的 3D 基座坐标系表面交点 X̄B_s(p) 及其所属连杆 l(p)；
  2. 将点恢复至连杆坐标系，利用目标时刻的正向运动学迁移到目标时刻，再投影到目标图像；
  3. 通过最近像素查找建立对应关系（需满足投影在界内、连杆 ID 相同、3D 残差 ≤5 mm）；
  4. 将源、目标位置在 224×224 策略图像平面上归一化位移：`fρ(p) = (ut(p) − us(p)) / 224`；
  5. 在非重叠 14×14 区域上做掩码平均，得到 16×16×2 的流目标；有效机器人像素比例 cρ(k) ≥ 0.1 的块才计入损失（作为门控而非损失权重）。
- 采用两个查询条件解码器（FiLM 调制 + 逐点两层 MLP）从查询状态重建流场，区间专用参数不共享；使用 **Huber 损失**在有效掩码上计算，总辅助损失为两区间流损失的均值。
- 最终联合目标：`L = Laction + λtemp·Ltemp`，主实验取 λtemp=1.0。

#### 2.5 异步历史特征缓存

- 每步同步编码 t−15、t−8、t 三帧将带来两次额外视觉编码开销。论文将历史观察写入时间戳环形缓冲区，由后台进程在机器人执行当前动作块期间**异步**预计算并存储其视觉特征；
- 重规划时仅当前帧编码留在关键路径上，历史特征直接从缓存读取。
- 在 RTX 4090 上测量（LIBERO Long），缓存将平均每重规划延迟由 68.10 ms 降至 62.78 ms（节省 5.32 ms/次，累计降低 7.8%）。缓存仅在出现历史帧前越过，随后持续复用。

#### 2.6 与现有方法的差别

- 与 TraceVLA（推理时视觉轨迹提示）、MotionVLA（全局轨迹场 token）、HiF-VLA（编码运动矢量提示）等不同，TemporalFlow-VLA 的稠密时间流**仅为训练目标**，不引入部署时运动估计器或几何处理；
- 与 CronusVLA、HAMLET、MemoryVLA、ReMemVLA 等潜在时间表征方法不同，论文通过显式物理目标规定每个潜在时间 token 应编码的物理变化尺度和运动语义。

### 6. 主要结论与发现

- **仿真结果**：
  - LIBERO 平均成功率 **97.63±0.26%**，其中 LIBERO Long 达 **96.60±0.87%**，比最强对比均值高 2.1 个百分点；短时程套件接近饱和，优势集中在长时程任务。
  - RoboTwin 2.0 上 Clean/Randomized 平均成功率为 **85.5%/84.2%**，Randomized 条件比最佳对比方法均值高 8.0 个百分点。
  - 优势随任务跨度增加：H=2 组 80.8%（超出第二名 5.5 点），H=3 组 87.5%（超出第二名 14.5 点）；H=1 组并非最佳，说明历史信息在**多阶段、长时程**任务中最具价值。
- **消融关键发现**：
  - 2Q w/o Flow 已优于 Multi-frame（83.2%/83.6% vs. 79.8%/81.5%），说明查询瓶颈本身有压缩增益；加流监督进一步升至 85.5%/84.2%，且 H=2 组增益最明显（+3.7/+1.5 点）。
  - 双监督尺度最优；单用 Q8 在整体上略优于 Q15，但两者并存的层级结构效果最好，说明 Q15 的长程上下文互补。
- **历史敏感性**：扰乱时间顺序在所有六个 RoboTwin 任务上都增加动作损失，且洗牌在五项任务中最有害（put bottles 例外，对移除更敏感），说明模型确实依赖顺序信息。
- **真实机器人**：Three-Cup Stacking 成功率从 57.8% 提升至 77.8%（+20.0 点）；Two-Bottle Packing 从 86.7% 提升至 97.8%（+11.1 点），表明物理基础表征对真实世界变化有迁移能力。
- **效率**：异步缓存在不增加模型容量的前提下把时间条件化的同步开销压至单帧视觉编码水平。

- **物理有意义的表征规定**：与无约束的潜在时间 token 不同，本文通过机器人运动学和时间流重建目标，明确规定了每个查询 token 应编码的物理语义——“第 t−8 到 t 帧之间机器人表面如何移动”“第 t−15 到 t 帧之间经历了怎样的物理演化”。这种显式语义规定使时间 token 既具有可解释性，又天然与动作生成的对齐需求一致。
- **关键路径开销可忽略**：通过异步缓存，历史特征的代价被转移到后台进程，部署时关键路径仅比原始 π0.5 多出两个查询 token 的注意力计算（约 5 ms 级），在高频重规划场景下几乎无感知。这是一种务实且工程友好的设计。
- **掩码设计兼具信息压缩与层级抽象**：双查询的层級结构（Q8 → Q15）既保存了短程与长程两个时间尺度的独立语义，又通过单向信息流允许长程表征对短程抽象的再整合，本质上是一种带先验结构的时间分层表征学习。
- **诊断实验方法论值得借鉴**：通过离线扰动（移除/洗牌历史帧）直接观察动作损失的响应，比单纯比较成功率更能揭示“模型是否真正利用历史顺序信息”，这种诊断思路可以沿用到其他时序性策略模型的分析中。
- **消融设计的逐步递进性**：从“多帧输入”到“查询瓶颈”再到“流监督”，每一步消融都验证了一个明确的假设：查询瓶颈提供压缩增益，流监督在此基础上提供物理语义增益。这种消融路线相当清晰。

### 8. 局限性

- **对运动学与标定质量的依赖**：时间流标签依赖 URDF 几何、机器人渲染器以及基座—相机标定 TC←B。若真实部署环境的标定质量不佳、遮罩不完整，或者机器人本体超出相机视野，则流目标的有效覆盖区域会大幅减少，影响训练监督质量。
- **历史观测仅固定于本体表面（部分覆盖）**：当前时间流仅覆盖**机器人自身表面**，无法捕捉场景中物体或其他智能体的运动。这虽然使表征更本源（自运动可控且无需光流），但某些需要捕捉物体被抓取后可观测位移的任务（如倒水、柔性物体操作）可能受益有限。
- **监督形式局限于两帧位移场**：将时间流定义为“一对相同连杆表面的欧氏位移”是线性、刚体运动的近似，对机器人本体来说足够，但对诸如软体形变、遮挡启用、以及非刚性运动无法建模。
- **需要逐任务生成流标注流程**：尽管计算是离线的，但新任务/新环境/新相机布置需要重新渲染和标定，流程的工程成本与易用性论文中未充分讨论。
- **训练时间成本增加**：时间流辅助解码器与额外监督使训练墙钟时间增加约 20%，对于大模型多数据集联合训练的预算敏感用户可能构成实际障碍。
- **离线扰动诊断与在线成功率的对应关系并不严格**：论文承认离线动作损失的上升不等同于在线 rollouts 成功率一定下降，因此“模型确实依赖顺序”的结论是必要但不充分的证据。
- **置信区间之外的语义泛化受限**：方法在短期/单阶段任务上增益很小甚至低于部分对比方法，说明时间流监督并非全场景普适增益，其价值高度集中在多阶段、长时程任务中；对即时反应型策略（如简单点抓取）可能带来不必要的表征复杂度。

### 9. 对个人研究工作的启示与可借鉴思路

- **“监督应在部署时消失”的设计哲学**：TemporalFlow-VLA 将昂贵但物理上有意义的监督全部置于训练阶段，部署时只由一个紧凑查询传递信息；这启发了“训练期自由、部署期廉价”的设计范式：可以利用复杂的几何、物理或仿真引擎来监督表征学习，而不必担心推理负担。
- **用显式物理量约束隐式时空 token**：与采用无监督时序一致性或自回归式潜在瓶颈的方法不同，本文以机器人正运动学和两帧投影流定义时间 token 的“应为内容”，为潜在表征研究提供了“先验—监督对齐”的范式参考。
- **查询瓶颈与掩码是一种有效的信息压缩正则**：单纯增加历史帧输入并不等于有益，查询瓶颈配合掩码注意力将历史信息压缩成几维语义 token 后，反而带来明显增益；这提示处理高维时序上下文时，显式设计信息瓶颈往往优于盲目增大上下文窗口。
- **多尺度时间信息的层级组织**：短程（8 帧）与长程（15 帧）通过单向因果掩码组织成层级，与自然语言中的层级注意力类似，说明时间尺度语义需要在架构上显式区分，而不是简单拼接多个特征。
- **异步预处理与推理重用的工程思路**：在强化学习/机器人部署中，经常需要重规划；将历史特征的计算放入后台缓存，避免重复前向传播，是可直接复用的系统级优化模式。

### 10. 关键背景文献

- **基础 VLA π0 与 π0.5**：当前模型以 π0.5 为骨干，直接在其前缀化输入中插入历史观察与查询 token。
- **Time-series 视觉轨迹提示 TraceVLA**：证明跟踪点轨迹作为视觉提示远超多帧历史，为时间条件监督提供直接动因。
- **MotionVLA**：显式使用轨迹 token 建模全局场景运动，与本文形成对比（文中采用训练期监督 vs 推理 tip）。
- **CronusVLA / HAMLET**：潜变量时序建模的代表，本文强调其“无监督”潜在时间表征在物理语义上不如显式物理流监督。
- **GigaWorld-Policy 与 RoboTwin 2.0**：作为 benchmark 与对比数据来源，并提供部分基线的第三方重评估。
- **ViSTR-Bench**：用于论证运动感知等连续视觉线索对当前 VLA 仍是难点。
- **LIBERO**：长时程任务 benchmark 的主要评测平台。

### 11. 综合评价

TemporalFlow-VLA 是一篇**方法创新与工程完整性兼备**的工作：

- **理论动机充分**：从任务阶段误判、历史顺序不敏感、ViSTR-Bench 现象三个层面论证了“历史对 VLA 有用但未受约束的多帧输入不够”的核心问题。
- **解决方案优雅**：没有引入昂贵的在线运动估计，而是利用机器人运动学先验构造离线监督，并且在架构上通过双查询层级注意力实现多尺度时间表征，部署成本与骨干几乎持平。
- **实验相对完整**：仿真（LIBERO 4 套件 + RoboTwin 12 任务 × 2 条件）、消融、诊断扰动、推理延迟和真实机器人三阶段任务均有覆盖；长时程增益（RoboTwin H=3 超出 14.5 点，LIBERO Long +2.1 点）说明时间流监督在长范围任务中价值显著。
- **存在可讨论空间**：监督覆盖面仅限机器人本体表面、对非刚性与环境物体运动无能为力；训练耗时增加约 20%；RoboTwin 部分基线来自第三方重评估而非原论文口径，比较公平性需读者留意。

总体而言，本文为**如何将物理先验以低成本方式引入 VLA 时序建模**提供了一个范例，其思路（训练期富监督 + 部署期零开销 + 查询瓶颈压缩）对后续机器人策略学习与多模态潜在时间建模都具有借鉴意义。

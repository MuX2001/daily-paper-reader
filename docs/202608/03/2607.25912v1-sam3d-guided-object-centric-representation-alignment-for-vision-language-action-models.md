## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作方面显示出强大的潜力，但现有大多数模型依赖于二维视觉-语言骨干网络，缺乏对目标物体的细粒度三维理解，尤其是在遮挡、姿态变化、尺度变化和精确空间交互场景下。我们提出了一种基于π₀构建的面向对象的三维表示对齐框架，使用SAM3D作为冻结的三维教师，在训练期间提供目标物体的三维先验。具体而言，我们使用物体识别模型定位任务相关物体，生成相应的物体掩码，并利用SAM3D提取密集的物体级三维表示，这些表示与π₀的中间视觉特征进行对齐。这使得策略能够内化目标物体的三维信息，同时保留原始的RGB-语言到动作推理流程，无需在测试时使用深度图、点云、掩码、SAM3D或额外的三维模块。模拟实验显示了一致的改进，在LIBERO上达到99.1%的成功率，在CALVIN上平均长度为4.11。真实世界实验进一步表明，我们的方法在机器人必须跨多个子任务关注不同目标物体的长时程操作场景中尤为有效。

## Abstract
Vision-Language-Action (VLA) models have shown strong potential for general robot manipulation, but most existing models rely on 2D visual-language backbones and lack fine-grained 3D understanding of target objects, especially under occlusion, pose variation, scale changes, and precise spatial interaction. We propose an object-centric 3D representation alignment framework built upon $π_0$, using SAM3D as a frozen 3D teacher to provide target-object 3D priors during training. Specifically, we localize task-relevant objects with object recognition models, generate corresponding object masks, and use SAM3D to extract dense object-level 3D representations, which are aligned with intermediate visual features of $π_0$. This enables the policy to internalize target-object 3D information while preserving the original RGB-language-to-action inference pipeline without requiring depth, point clouds, masks, SAM3D, or additional 3D modules at test time. Simulation experiments show consistent improvements, achieving 99.1\% on LIBERO and an average length of 4.11 on CALVIN. Real-world experiments further demonstrate that our method is particularly effective in long-horizon manipulation scenarios where the robot must focus on different target objects across multiple subtasks.

### 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型通过将预训练的视觉-语言模型迁移到机器人动作预测上，已成为通用机器人操作的重要范式。主流 VLA 模型（如 π₀、OpenVLA）以 2D RGB 图像和语言指令作为输入，在大量视觉-语言预训练的支持下取得了良好效果。
- **核心问题**：现有 VLA 模型**缺乏对目标物体的细粒度 3D 理解**，无法充分捕捉物体的形状、姿态、尺度、空间布局等关键信息。这种局限在**遮挡（occlusion）、姿态变化、尺度变化、物体杂乱、精确空间放置**等操作场景中表现得尤为明显。
- **已有方法的不足**：
  - 显式引入 3D 观测（深度图、点云、RGB-D）的方法虽然有效，但**依赖测试时的额外传感器输入**，并且改变了模型的输入输出接口。
  - 隐式注入空间信息的方法（如空间位置估计、动作网格、表示级对齐）主要关注**全局场景级空间表示**，而非**目标物体级 3D 先验**。
  - 视觉 grounding 类方法（裁剪输入、边界框、注视区域重建）主要在 2D 图像空间提供监督，**不包含物体 3D 形状与布局先验**。
- **研究问题**：能否在**保持 VLA 模型原有 RGB-语言到动作推理流程不变**的前提下，将**目标物体的 3D 知识**注入到基于 RGB 的 VLA 策略中？

### 2. 方法论

#### 2.1 核心思想

- 提出 **SAM3D-VLA** 框架，建立在 π₀ 架构之上。
- 在**训练阶段**使用冻结的 **SAM3D** 作为 3D 教师，提取目标物体的物体级 3D 特征，并与 π₀ 中间层视觉特征进行**对齐**，从而让 VLA 骨干网络内化目标物体的 3D 先验。
- **推理阶段完全保持 π₀ 原始流程**：仅需 RGB 图像和语言指令即可预测动作，无需深度图、点云、物体掩码、SAM3D 或任何额外 3D 模块。

#### 2.2 技术细节

**(1) 基础架构（π₀）**

- 视觉编码器：SigLIP；语言模型：Gemma；动作专家：连续动作生成。
- 在时刻 t，模型建模条件动作分布 \(p_\theta(A_t \mid o_t)\)，其中 \(A_t\) 为长度为 H 的动作块（action chunk），观测 \(o_t\) 包含多视角 RGB 图像、语言指令和机器人本体状态。
- 动作专家使用**条件流匹配（conditional flow matching）** 目标训练：
  \[
  \mathcal{L}_{\text{action}} = \mathbb{E}_{\tau,\epsilon}\left[\left\| v_\theta(A_t^\tau, \tau, o_t) - (A_t - \epsilon) \right\|_2^2\right]
  \]
  推理时从高斯噪声出发，通过积分学习到的速度场从 \(\tau=0\) 到 \(\tau=1\) 生成动作块。

**(2) SAM3D 引导的物体中心特征对齐**

- 将多视角图像展平为批量单视图输入，连同子任务对应的物体掩码一起送入冻结的 SAM3D 教师模型：
  \[
  T_t = f_{\text{SAM3D}}(\tilde{I}_t, \tilde{M}_t), \quad T_t \in \mathbb{R}^{(BV)\times L_T \times D_T}
  \]
- 将 SAM3D 教师特征序列重塑为 2D 特征网格，通过**双线性插值**调整到学生视觉 token 的分辨率，使教师 token 与学生 token 在空间上对齐。
- 在学生侧，从选定的 Gemma 层提取中间视觉特征 \(S_t = h_t^{(m)} \in \mathbb{R}^{B\times(VL_S)\times D_S}\)，通过投影头 \(P_\phi\) 映射到 SAM3D 特征空间：\(\hat{T}_t = P_\phi(S_t)\)。
- 使用**token 级掩码**只对目标物体区域的 token 施加监督，采用**掩码归一化 MSE 损失**：
  \[
  \mathcal{L}_{\text{align}} = \text{MSE}\left(\text{Norm}(\hat{T}_t)[M_t],\; \text{Norm}(\bar{T}_t)[M_t]\right)
  \]
- 总训练目标：
  \[
  \mathcal{L} = \mathcal{L}_{\text{action}} + \alpha \mathcal{L}_{\text{align}}
  \]
  其中 \(\alpha\) 控制 3D 特征监督的强度。

**(3) 冻结表示探针实验（Frozen-representation Probing）**

- 策略训练完成后，**冻结整个 VLA 骨干**，仅训练一个轻量两层 MLP 探针 \(P_\omega\)，从相同的中间视觉特征 \(S_t\) 预测 SAM3D 目标特征。
- 探针性能越好，说明 SAM3D 风格的物体中心 3D 先验在训练后的 VLA 特征中**越容易被恢复**，从而验证对齐是否有效。

**(4) 子任务感知的数据处理**

- 针对长时程任务，使用 OpenAI GPT-4o 将高层指令**分解为多个子任务**。
- 每个子任务使用 Grounding DINO / YOLO 进行开放词汇目标检测，SAM2 生成二进制物体掩码。
- 每个子任务关联其对应的目标物体，提供**阶段特定的 3D 监督**，帮助策略在不同操作阶段关注不同的目标物体。
- 上述全部数据标注和处理流程**仅在训练阶段使用**，推理时完全移除。

1. **保持推理流程不变**：所有 3D 相关模块（SAM3D、检测、分割、子任务分解）仅用于训练，测试时仅需 RGB 和语言指令，实际部署代价为零增量。

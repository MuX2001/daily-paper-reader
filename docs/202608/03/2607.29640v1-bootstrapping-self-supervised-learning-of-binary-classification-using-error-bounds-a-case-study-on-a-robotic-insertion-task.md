## 摘要
柔性制造要求快速部署解决方案并最小化设置时间以保持竞争力。一个关键属性是控制误差水平的能力，因为失败可能从轻微的绩效下降到严重的设备损坏。然而，常规部署通常涉及大量的设置、数据收集、模型训练或参数调整以及系统测试，导致显著延误，阻碍了商业可行性。我们提出了一种数据引擎，它在执行任务的同时收集数据并提升自身性能。该数据引擎由两个分类器组成：快速模型预测和昂贵的验证。首先进行模型预测，并根据预测的置信水平决定是否使用昂贵的验证。通过调整置信水平，用户可以控制可容忍的误差水平。我们的方法在真实的机器人插入任务中实现，该任务使用力数据进行模型预测。系统应用UMAP降维，并使用Wilson分数计算预测的置信界限。结果表明，系统能够学习并逐渐减少对昂贵验证的需求，同时保持在设定的误差率范围内。结果凸显了置信界限在自我改进模型中提升机器人分类任务可靠性的潜力。

## Abstract
Flexible manufacturing requires rapid deployment of solutions and minimal setup time to remain competitive. An essential attribute is the ability to control error levels, as failures can range from minor performance degradation to severe equipment damage. However, conventional deployment often involves extensive setup, data collection, model training or parameter tuning, and system testing, resulting in significant delays that hinder commercial feasibility. We propose a data engine which gathers data and improves its performance while executing the task. The data engine consists of two classifiers, a fast model prediction and expensive verification. First, a model prediction is performed and based on the confidence level of the prediction, the expensive verification can be used. By adjusting the confidence level, users can control the level of tolerable error.   Our method is implemented on a real-world robotic insertion task, which uses force data for the model prediction. The system applies UMAP dimensionality reduction and uses Wilson-Score to compute the confidence bounds of the prediction. Results demonstrate the ability to learn and reduce the need for expensive verifications over time, while staying within the set error-rate. The results highlight the potential of confidence bounds in self-improving models to enhance reliability in robotic classification task.

  - **纯机器学习验证**：推理速度快，但需要大量标注数据、调参，且缺乏对错误频率的确定性保证。
- **核心问题**：如何构建一个既能快速上线运行、又能严格保证错误率上限的机器人分类系统，同时在学习过程中持续积累数据并自我改进？
- **关键挑战**：
  - 模型何时才"足够可靠"以替代昂贵验证？
  - 如何在系统运行过程中，而不是离线阶段，逐步引入并增强模型预测？
- **核心思路**：利用置信界（Confidence Bounds）作为自主决策依据——当模型预测置信度足够高时依赖模型；否则调用昂贵验证，并将验证结果作为新数据反馈给模型，形成一个自举式的在线学习数据引擎。

## 2. 提出的方法论

### 核心思想
- 构建一个**数据引擎**，同时集成两种验证手段：
  - **快速模型预测**（Model Prediction）：基于力数据的机器学习分类器，运行时开销小。
  - **昂贵验证**（Expensive Verification）：基于高度检查的物理检测，可靠精确但耗时（每次约5秒）。
- 通过**Wilson-Score置信界**，计算预测的成功率下界；只有当下界超过设定阈值（LB）时，才接受模型预测，否则退回昂贵验证。
- 学习过程高度自举：初期待定数据全部由昂贵验证承担，随着数据积累，模型置信度提高，昂贵验证被逐步淘汰。

### 技术流程
1. **数据采集**：在机器人插入过程中，以500 Hz采样频率采集2秒的力传感器数据，仅保留z轴方向，形成1000维特征向量。
2. **降维**：使用UMAP将1000维空间降为二维表示，保留局部邻域结构，便于邻域分类。
3. **分类**：使用Radius Neighbors Classifier（半径邻域分类器）——查询点周围固定半径r内的所有邻居进行多数投票。
4. **置信度计算**：
   - 利用Wilson Score区间（公式见下）计算分类概率的置信区间；
   - 若置信下界（LB）超过预设阈值，则接受预测结果；否则调用昂贵验证。
   - 系统可调参数为置信水平α和阈值LB，用户可根据任务对误差的容忍度来设定。
5. **数据反馈**：凡经过昂贵验证的数据（低置信度样本）以及预测错误的数据（实际运行后检验出来的假阳性样本）都存储到数据库，用于周期性重训练模型。

### 关键公式
- **Wilson Score区间**：
  \[
  p = \frac{n_s + \frac{1}{2}z_{\alpha}^2}{k + z_{\alpha}^2} \pm \frac{z_{\alpha}}{k + z_{\alpha}^2} \sqrt{\frac{n_s n_f}{k} + \frac{z_{\alpha}^2}{4}}
  \]
  其中 \(n_s\) 为邻域内正样本数，\(n_f\) 为负样本数，\(k = n_s + n_f\)，\(z_{\alpha}\) 为标准正态分布 \(1-\alpha/2\) 分位数。
- **基线（Binomial Interval Score）**：
  \[
  p = \frac{n_s}{k} \pm \frac{z_{\alpha}}{\sqrt{k}} \sqrt{\frac{n_s n_f}{k^2}}
  \]

## 6. 主要结论与发现

- 提出的数据引擎可在有上限保证的前提下实现自主学习：系统无需预训练即可运行，初期完全依靠昂贵验证，随后逐渐过渡到模型预测。
- **Wilson Score可有效控制错误率**：当 α 和 LB 设定后，假阳性率始终低于 (100 − LB)% 容忍上限。
- **基线方法（Binomial Interval Score）几乎失效**：在单样本邻域情形下，其下界迅速达到1.0，导致置信界计算失真，α 和 LB 参数变化几乎对系统行为无影响，无法达到错误率控制目标。
- **确定预测比例显著提升**：在 α = 0.1, LB = 90% 配置下，后期接近90%的样本可由模型直接预测，不再需要昂贵验证，大幅缩短系统循环时间。
- **参数α和LB提供了清晰的权衡手段**：提高LB可提升精度、降低假阳性，但会减少模型预测比例，增加昂贵验证使用频次，延长运行时间。

## 8. 不足与局限

- **单一任务验证**：整个方法仅在"机器人插入"这一场景上验证，结论的可推广性较弱；不同任务（如视觉检测、异常检测）中，力数据特征空间结构与降维稳定性可能完全不同。
- **静态数据模拟在线**：实验环境是在已收齐数据后离线回放的，非真实在线持续运行——真实系统中，模型初期极度贫瘠时表现未知，长期漂移的鲁棒性也未被检验。
- **UMAP作为在线降维的局限**：UMAP是批量学习方法，新增数据需与全体历史数据重新拟合降维模型，在线场景下反复重拟合的计算开销与采样敏感性（尤其是初始极少数据时）未被充分讨论。
- **固定半径的敏感性**：Radius Neighbors Classifier对半径r的设置高度敏感；文中未充分讨论r的选择方法或对r的消融实验，不同数据密度下固定半径可能导致置信界失真。
- **未与主流不确定性估计方法对照**：缺少与高斯过程、Bayesian NN、集成方法等的基准对比，无法体现Wilson Score方法在不确定性估计性能上的相对地位。
- **实验评价偏确定性任务**：该系统的鲁棒性只在"插入任务"这类力信号模式较稳定的任务上测试，对高噪声、高动态变化的任务缺乏证据。
- **数据规模及采集工艺限制**：1503条样本在工业实际应用中仍显有限；数据采集耗时约20小时也说明该方案在快速部署方面还难以完全兑现"低启动成本"的承诺——尤其是需要靠昂贵验证从零收集大量初始数据时。

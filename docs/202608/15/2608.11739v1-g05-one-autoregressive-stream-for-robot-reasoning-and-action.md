## 摘要
视觉-语言-动作（VLA）模型的现行主流方案是将预训练的视觉-语言模型（VLM）与单独训练的流匹配动作专家相结合。这使得VLM成为上下文编码器而非决策者。我们提出G0.5，一种预训练的自回归VLA，其中单个Transformer解码器在单一目标下同时生成推理与动作令牌。三个组件使其在基础模型规模下可行：一个可学习的跨具身动作分词器，将异构机器人动作映射到共享词汇表；一个原生思维链流，将任务分解、对象定位和动作提示与动作令牌交错；以及一个视觉记忆模块，通过视觉编码器注入数秒的历史信息。由于推理与动作共享同一组权重，预训练VLM的能力可迁移至物理行为：模型紧密遵循指令，且提示可直接调节动作粒度、任务视野和分布外场景处理，无需进一步训练。G0.5在大量机器人数据集及视觉问答样本上预训练，在7个独立场景中均超越最先进模型：在R1lite和R1pro机器人上的真实世界微调（76.7%对比π₀.₅的53.3%和GR00T-N1.7的24.4%）；使用通用策略的2025年BEHAVIOR挑战赛（50项长时程家居移动操作任务）中（31.4%对比π₀.₅的26.3%和挑战赛冠军的26.1%）；DROID后训练并零样本迁移至未见环境和物体（82.5%）；语言跟随的抓取与放置基准；LIBERO（98.9%）；RoboTwin 2.0（93.3%）；以及SimplerEnv-Bridge（87.3%）。

## Abstract
The prevailing recipe for Vision-Language-Action (VLA) models couples a pretrained VLM with a separately trained flow-matching action expert. This makes the VLM a context encoder rather than a decision-maker. We introduce G0.5, a pretrained autoregressive VLA in which a single transformer decoder emits reasoning and action tokens under a single objective. Three components make this tractable at foundation-model scale: a learnable cross-embodiment action tokenizer that maps heterogeneous robot actions into a shared vocabulary; a native chain-of-thought stream interleaving task decomposition, object grounding, and action hints with action tokens; and a visual memory module that injects multi-second history through the vision encoder. Because reasoning and action share a single set of weights, the pretrained VLM's capabilities carry over to physical behavior: the model follows instructions closely, and prompts directly steer action granularity, task horizon, and out-of-distribution scene handling without further training. Pretrained on a large collection of robot datasets together with VQA samples, G0.5 surpasses state-of-the-art models across 7 independent regimes: real-world fine-tuning on R1lite and R1pro robots (76.7\% vs.\ 53.3\% for $π_{0.5}$ and 24.4\% for GR00T-N1.7), the 2025 BEHAVIOR Challenge on 50 long-horizon household mobile manipulation tasks using a generalist policy (31.4\% vs.\ 26.3\% for $π_{0.5}$ and 26.1\% for the challenge winner), DROID post-training followed by zero-shot transfer to an unseen environment and objects (82.5\%), a language-following Pick-and-Place benchmark, LIBERO (98.9\%), RoboTwin 2.0 (93.3\%), and SimplerEnv-Bridge (87.3\%).

## 论文总结：G0.5——用于机器人推理与行动的统一自回归流

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：现代 Vision-Language-Action（VLA）模型的主流架构采取“VLM-as-Encoder”范式，即用预训练 VLM 为独立训练的流匹配（flow-matching）或扩散动作专家提供条件编码。VLM 仅扮演上下文编码器角色，而非决策者。
- **核心问题**：这种范式的根本缺陷在于：
  - VLM 的生成性能力（思维链推理、上下文学习、语言对动作的提示级操控）只能通过压缩的条件瓶颈间接影响行为，无法作为动作生成的固有组成部分。
  - 原始自回归 VLA（如 RT-2、OpenVLA）将连续动作简单离散化，在高控制频率、高动作维度下 token 数量爆炸，效率低下。
- **论文立场**：主张回归自回归（AR）范式，但消解其原有的 token 效率瓶颈，使 VLM 保持其预训练的本质——一个同时能够推理、记忆和行动的生成式自主决策体。G0.5 以单一 Transformer 解码器、单一目标、共享权重生成推理与动作，使 VLM 成为真正的“行动者”。

### 2. 方法论：核心思想与关键技术

- **总体框架**：G0.5 由 Qwen3.5 2B 初始化，将所有输入与输出序列化为单一自回归 token 流（图 2 给出了详细的序列模板）。训练目标为生成段上的标准 next-token 交叉熵损失：
$$ \mathcal{L}(\theta) = -\sum_{i \in \mathcal{G}} \log p_\theta(x_i | x_{<i}) $$
其中 $\mathcal{G}$ 为生成段 token 索引；该单一损失同时监督 CoT 生成与动作生成，无辅助回归目标或专家蒸馏。

- **关键技术一：跨具身结构化动作分词器（ActionCodec）**
  - 对异构机器人动作按运动部件（左臂、右臂、左手爪、右手爪、下驱）结构化分解，各部分 padding 至统一最大维度，再用残差向量量化（RVQ）学习离散码本。
  - 引入时间对比损失以增强时间相邻动作的 token 一致性。
  - 推理时只对当前活跃的自由度组生成动作 token（如左臂运动时右臂组完全不生成），实现稀疏预测，大幅降低解码负担。
  - 所有具身共享一个 27 维统一动作空间：`<left_control>(9) | <left_gripper>(1) | <right_control>(9) | <right_gripper>(1) | <lower_body>(7)`；新增具身无需增加任何参数。

- **关键技术二：原生思维链（Native Chain-of-Thought）**
  - 将推理任务（Subtask 原子子任务、BBox 目标定位、Trace 2D 轨迹、ActionHint 动作提示）作为可组合的四种 CoT 目标，直接嵌入生成段，与动作 token 在同一个自回归流中生成，由同一解码器、同一上下文、同一目标监督。
  - 训练时每步从 8 种组合（含 no-CoT）中加权随机采样一种；推理时可通过 prompt 切换 CoT 模式，无需重新训练。
  - 与 bolt-on CoT 的本质区别：推理不是模块间的接口，而是动作生成的组成部分，可直接被后续动作 token 注意。

- **关键技术三：视觉记忆模块（Visual Memory）**
  - 在 ViT 中每 4 层插入分解的空间-时间注意力（factorized spatial-temporal attention），以线性成本融合多帧历史信息。
  - 最终层丢弃所有历史 token，训练期间以 30% 概率随机丢弃全部历史帧以防止过拟合；使用连续状态嵌入与视觉帧时间对齐。

- **预训练数据与自动标注管线**：在 14 种具身的异构机器人演示数据与网络 VQA 数据的混合集上单阶段预训练。使用多模态大模型 API（Gemini 3、Doubao Seed 2.0 Pro）和 SAM3 跟踪自动生成语言标注、视觉定位标注和 2D 末端轨迹标注。

### 6. 主要结论与发现

- **统一自回归流优于 VLM-as-Encoder 范式**：在 7 个基准数据集上，G0.5 全面达到最先进水平，且在语言跟随、多阶段执行和零样本迁移上显著超越 VLM-as-Encoder 类模型（如 π0.5）。
- **单一 checkpoint 具备长时程通用策略能力**：在 BEHAVIOR Challenge 上，G0.5 仅需 1 epoch 后训练即超越 π0.5（4 epochs）和竞赛冠军（4 checkpoints）；4 epochs 后优势进一步扩大。
- **AR 动作监督保护而非破坏 VLM 能力**：PP Bench 上 G0.5 的零样本语言跟随率（65.6%）超过了 π0.5 的 50H 后训练结果（68.8%）以外的所有设置，表明 AR 训练信号对 VLM 语言-感知能力有益。
- **CoT 在长时程、分阶段任务中带来显著收益**：在 Air Fryer 中 AR+CoT 将进度分数从 2.4 提升至 3.8，在 Bacon 中从 1.5 提升至 3.4；单阶段任务上提升可忽略（~1.6 pp）。
- **AR 解码器比 FM 头更充分地利用 CoT**：在相同 CoT 条件下，AR 的进度提升远大于 FM，支持“解码接口而非推理内容”的假设。
- **AR 策略天然适合 RL 微调**：GRPO 实验中 AR 收敛更快、最终成功率更高、方差更低，归因于 token 级 log-probability 的直接可用性。
- **结构化的动作分解（导航与操作解耦）和视觉记忆预训练**是长时程移动操作的关键设计优势。

### 7. 优点

- **架构级统一**：推理、语言、动作共享同一组权重、同一个 token 流和同一个目标函数，从根本上避免了 VLM-as-Encoder 范式中“VLM 能力被瓶颈化”的问题，设计逻辑自洽、简洁有力。
- **跨具身分词器设计精巧**：结构化解耦 + 残差量化 + 活跃部分稀疏预测，既实现了跨具身共享，又大幅削减了 token 数，直接解决了自回归 VLA 的原始效率瓶颈。
- **CoT 作为原生行为组件而非辅助模块**：可组合的四种推理目标、prompt 条件化切换、与动作 token 的直接注意力连接，在方法层面具有较强的新颖性和实用性。
- **实验体系全面**：覆盖真实世界微调、仿真基准、零样本迁移、长时程移动操作、RL 兼容性、语言遵循等多个维度，且每个维度都与多个代表性基线对比，论证力度强。
- **结论有自省意识**：对定性观察（prompt 操控）与定量结论清晰区分；不回避失败模式（抽屉插入、半透明表面）；对 FM 差异机制明确标注为“假设”而非定论。

### 8. 不足与局限

- **感知层面的边界**：低对比度半透明表面（如抽屉柜）定位仍是明显弱点——加入显式高对比标记后由 60% 提升至 100%（π0.5 不受影响），说明其感知鲁棒性弱于流匹配基线。AR 本身并未解决感知层面的问题。
- **长时记忆有限**：视觉记忆仅覆盖数秒历史，不足以支撑更长视野的任务；论文承认这是留给未来工作的开放问题。
- **下驱动作未单独评估**：统一动作空间中包含 lower_body 维度的表示，但论文未在具体任务中单独验证其效果。
- **预训练数据分布偏差**：容器交互类技能（微波炉、柜体操作）在预训练数据中严重不足，相关任务上 G0.5 明显落后于 π0.5，需要更多训练才能弥合。
- **prompt 级行为操控仅有定性证据**：adverbial qualifier、同义动词替换等对行为的影响只做了小样本定性观察，缺乏系统性定量研究。
- **基准自建可能引入偏倚**：PP Bench 在自家 R1-Lite 平台上采集与评估，对自家模型的指令格式和动作分布高度适配，与外部基准的可比性需要谨慎对待。
- **部分重要实验细节未披露**：预训练算力、具体数据规模、FM 头架构细节等不透明，影响复现性和对方法可扩展性的判断。
- **部分对比公平性存疑**：Bridge-SimplerEnv 上部分基线成绩引自他人论文而非统一重测（论文已注明），可能受实现细节和评估设置差异影响。

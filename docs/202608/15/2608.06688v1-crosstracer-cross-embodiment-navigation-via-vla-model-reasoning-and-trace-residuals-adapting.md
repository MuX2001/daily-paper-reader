## 摘要
视觉-语言-动作（VLA）模型为机器人导航提供了强大的语义先验，但它们常常忽略具身特定的运动约束。对一种机器人来说语义上可行的路径，对另一种机器人可能在物理上不可行。我们提出了CrossTracer，一种通过自适应轨迹残差实现跨具身导航的分层框架。CrossTracer将导航规划表示为归一化的图像平面航点，形成语义推理与物理落地之间的统一像素空间接口。首先，视觉-语言轨迹提议器（VL-Tracer）适配预训练的VLA模型，从自我中心观测和灵活的目标规范中预测初始导航轨迹。其次，CE-Adapter通过预测基于视觉可通行性线索、机器人身份和初始轨迹的具身条件残差修正来细化该轨迹。为了在没有昂贵人工标注的情况下训练细化模块，跨具身RRT*（CE-RRT*）将全景分割转换为机器人条件下的可通行性代价图，并生成代价最小化的像素空间轨迹。我们在NaviTrace基准上评估CrossTracer，该基准测试模型能否从自我中心观测、语言指令和机器人具身类型生成具身一致的导航轨迹。CrossTracer取得了45.68的总分，比评估过的最强通用基线Gemini-2.5-Pro高出10.01分，相对提升28.1%。在轮式和腿式机器人上的实际部署进一步显示了导航成功率和执行效率的提升。

## Abstract
Vision-language-action (VLA) models provide strong semantic priors for robot navigation, but they often ignore embodiment-specific mobility constraints. A path that is semantically plausible for one robot may be physically infeasible for another. We propose CrossTracer, a hierarchical framework for cross-embodiment navigation through adaptive trace residuals. CrossTracer represents navigation plans as normalized image-plane waypoints, forming a unified pixel-space interface between semantic reasoning and physical grounding. First, Vision-Language Trace Proposer (VL-Tracer) adapts a pretrained VLA model to predict an initial navigation trace from egocentric observations and flexible goal specifications. Second, CE-Adapter refines this trace by predicting embodiment-conditioned residual corrections from visual traversability cues, robot identity, and the initial trace. To train the refinement module without costly manual annotation, Cross-Embodiment RRT* (CE-RRT*) converts panoptic segmentation into robot-conditioned traversability cost maps and generates cost-minimizing pixel-space traces. We evaluate CrossTracer on the NaviTrace benchmark, which tests whether a model can generate embodiment-consistent navigation traces from egocentric observations, language instructions, and robot embodiment types. CrossTracer achieves a total score of 45.68, outperforming the strongest evaluated general-purpose baseline, Gemini-2.5-Pro, by 10.01 points, corresponding to a 28.1% relative improvement. Real-world deployment on wheeled and legged robots further shows improved navigation success and execution efficiency.

# 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型为机器人导航提供强大的语义推理能力，但现有模型在输出路径时往往忽略机器人的具身移动约束。对于同一场景和同一目标，腿式机器人可能可以直接越过台阶或粗糙地形，而轮式机器人需要绕行，因此“语义可行”并不等于“物理可行”。
- **核心问题**：如何在利用 VLA 语义推理能力的同时，使生成的导航路径满足不同机器人本体的可通行性/运动学约束，即弥合“语义导航意图”与“物理可执行运动”之间的**具身鸿沟**。
- **现有方法不足**：
  - 端到端 VLA 策略将语义推理、具身约束和控制耦合在同一个模型中，难以跨平台复用。
  - 基于候选路径选择的方法只能在有限候选集中挑选，无法生成连续的最优修正。
  - 训练具身感知的细化模块需要大量人工标注，成本高昂。
- **CrossTracer 的核心思想**：将导航规划表示为归一化的**像素空间轨迹**（image-plane trace），作为语义推理与物理落地之间的统一接口，并通过“初始语义轨迹 + 具身条件残差修正”的分层方式解决上述问题。

# 2. 方法论

CrossTracer 采用分层结构，分为两个阶段：

- **第一阶段：VL-Tracer（视觉-语言轨迹提议器）**
  - 基于预训练 VLA 模型 OmniVLA 进行 LoRA 微调。
  - 输入：第一视角 RGB 图像 I、灵活的目标规格 G（语言指令 L、像素目标坐标 Pg，或两者组合）。
  - 输出：N=8 个归一化图像平面航点组成的初始轨迹 T_init。
  - 轨迹头使用 tanh 激活将输出限制在 [−1,1]² 范围内。
  - 训练时目标：轨迹模仿损失 + 平滑损失 λ_smooth=0.01。

- **第二阶段：CE-Adapter（具身条件轨迹自适应器）**
  - 输入：RGB 图像、初始轨迹 T_init、目标机器人身份 e。
  - 通过机器人嵌入向量 + FiLM（Feature-wise Linear Modulation）层对 ResNet 视觉特征进行具身调制。
  - 加入机器人 token，经 Transformer 得到具身条件视觉 token。
  - 初始轨迹通过 MLP 映射为轨迹查询（Trace Query），与视觉 token 做交叉注意力。
  - 残差头输出 ΔT_e，最终轨迹为 T_e = T_init + ΔT_e，并用 δ_max 限制修正幅度，保留语义目标的同时避开危险区域。
  - 辅助头：
    - **可通行性重建头**：预测具身条件代价图 Ce，用于丰富视觉特征中的地形语义。
    - **具身敏感性头**：预测非负系数 α_e，调节代价损失权重。

- **CE-RRT*（自动标注管线）**
  - 使用 Mask2Former（ResNet-50 主干）做全景分割。
  - 为每个具身定义语义代价配置，将分割掩码转化为具身条件可通行性代价图 Ce。
  - 对障碍进行距离变换，得到外部/内部惩罚项。
  - 在图像平面上运行 RRT* 规划（目标偏置采样 p_goal=0.15、步长 25 像素、搜索半径 60 像素、最大迭代 10,000 次），搜索低代价路径，并重采样为 N=8 个归一化航点。
  - 生成参考轨迹 T*_e 和代价图 Ce 仅用于训练，推理时不需要分割和规划器。

- **训练目标**：
  - 总损失 L_CE = L_trace + λ_trav L_trav + λ_cost L_cost + λ_smooth L_smooth。
  - L_trace：最终轨迹与 RRT* 参考轨迹的 L2 距离。
  - L_trav：预测代价图与 RRT* 代价图的重建误差。
  - L_cost：对落在高代价区域的航点施加惩罚，权重由 α_e 调制。
  - L_smooth：二阶差分平滑项（λ_smooth=0.05），防止轨迹抖动。

# 8. 局限与不足

- **依赖预训练 VLA 能力**：第一阶段 VL-Tracer 基于 OmniVLA 微调，其语义推理上限受限于基座模型；若基座模型对复杂语言指令或罕见场景理解不足，残差细化模块无法从根本上补足语义错误。
- **轨迹离散化粒度有限**：固定输出 8 个航点，对于需要长距离、强弯曲或复杂绕障的路径，可能无法精确刻画轨迹细节；增加航点数或输出密度可能带来性能提升，但也会增加计算与训练负担。
- **CE-RRT* 的隐式假设**：生成参考轨迹时依赖手工设计的语义代价配置，这些配置虽免于人工标注，但仍需专人为每个具身类型设定代价权重；若遇到未覆盖的新地形（如泥泞、冰面），代价图可能不够准确。
- **损失函数对代价图误差敏感**：L_trav 直接重建 CE-RRT* 的代价图，而该代价图是通过语义类别和距离变换启发式生成的，可能偏离真实物理可通行性，从而限制残差修正的上限。
- **缺乏对失败案例的深入分析**：论文未详细讨论目标未达成的具体原因（语义理解错误 vs. 具身规划错误 vs. 低层控制失败），也没有给出感知噪声、动态障碍物下的性能退化分析。
- **实验外部效度有限**：真实环境任务数量较少（4 个）、平台只有两种，且对比方法仅 OmniVLA；对更复杂的室内多障碍、拥挤人群、未知环境等场景的泛化性尚未充分验证。

# 9. 未来研究方向

- **动态场景扩展**：将 CrossTracer 扩展到动态障碍物场景，利用视频输入或多帧时间信息生成动态感知轨迹，而非仅处理静态图像。
- **多模态融合**：引入深度图、激光雷达点云或 occupancy map 作为辅助输入，提供更精确的几何约束，弥补单目 RGB 在尺度估计上的不足。
- **强化学习端到端优化**：将 CE-Adapter 的残差策略与真实机器人反馈（碰撞、成功率）结合，通过在线强化学习进一步优化轨迹，减少对自动标注代价图的依赖。
- **跨任务统一框架**：将轨迹生成与低级动作执行解耦后，可尝试将 CE-Adapter 适配到其他下游任务（如目标抓取、环境探索），实现“语义-具身”模块的即插即用。
- **自动化代价格式学习**：探索用可学习的地形编码器替代手工代价配置，直接从真实世界数据中学习各具身的地形可通行性，减轻人工设计成本。
- **更细粒度的具身表示**：除本体类别标签外，引入机器人的动力学参数、尺寸、足式/轮式具体结构等连续描述，使残差修正更具物理精确性。

# 10. 总体评价与可借鉴之处

- **总体评价**：CrossTracer 提出了一种新颖且实用的“语义轨迹 + 具身残差”分层框架，通过图像平面轨迹这一通用接口有效桥接了 VLA 语义理解和机器人运动约束，在模拟基准和真实部署中均取得显著提升。其最大的贡献不在于单一模型性能，而在于**提供了一种可复用的架构思想**——将语义推理平台抽象为通用“轨迹提议器”，再将本体特定约束隔离为轻量“自适应器”，从而打破了端到端 VLA 与纯几何规划器之间的隔阂。
- **可借鉴之处**：
  1. **解耦设计**：把语义决策与运动适配分开训练，大幅降低对绑定平台数据的需求，非常适用于多机器人平台共存的现实场景。
  2. **数据生成策略**：用“预训练分割 + 语义代价 + 采样规划”自动构建训练标签，避免了昂贵的人工标注，值得在其他具身任务中推广。
  3. **像素空间轨迹作为接口**：相比三维路径或关节控制，图像平面轨迹更容易与 VLM 的视觉表征对齐，也更容易在不同相机配置间迁移，这一设计具有较强启发性。
  4. **评估方式完整**：从大规模模拟基准到真实物理机器人实验，从总指标到逐类别分解，再到跨平台重复实验，形成了可信的实证链条，可作为后续研究的标准评估范式。

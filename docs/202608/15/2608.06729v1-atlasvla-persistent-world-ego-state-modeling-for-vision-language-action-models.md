## 摘要
尽管视觉-语言-动作（VLA）模型推动了具身智能的发展，但其根本上的反应式范式严重限制了在部分可观测和长时程任务中的表现。当仅使用单个腕戴相机时，随着物体移出视野，模型不可避免地遭受感知遗忘，并在多步执行过程中出现时间性任务进度遗忘。为克服这些瓶颈，我们提出AtlasVLA，一种新颖框架，通过持久的世界-自我状态从直接反应式操作转变为主动推理。AtlasVLA具有双记忆架构：一个4D持久世界状态记忆，将瞬时的2D观测提升为全局更新的体素哈希空间状态，以解决视觉盲区；以及一个自我工作状态记忆，用于跟踪历史自我状态和任务进度。通过将扩散变压器（DiT）基于这一联合的世界-自我状态进行条件化，AtlasVLA实现了稳健的空间推理。在LIBERO、RLBench和真实世界基准上的广泛评估表明，仅使用腕戴相机，AtlasVLA即可达到最先进的性能。值得注意的是，它明显优于多视图基线，在LIBERO-Long和真实世界长时程任务中分别取得了9.4%和17.5%的绝对成功率提升。

## Abstract
While Vision-Language-Action (VLA) models have advanced embodied AI, their fundamentally reactive paradigm severely limits performance in partially observable and long-horizon tasks. When restricted to a single wrist-mounted camera, they inevitably suffer from perception forgetting as objects exit the field of view, and temporal task-progress forgetting} during multi-step execution. To overcome these bottlenecks, we propose AtlasVLA, a novel framework that transitions from direct reactive manipulation to proactive reasoning through a persistent world-ego state. AtlasVLA features a dual-memory architecture: a 4D Persistent World State Memory that lifts transient 2D observations into a globally updated, voxel-hashed spatial state to resolve visual blind spots, and an Ego-Working State Memory that tracks historical ego state and task progress. By conditioning a diffusion transformer (DiT) on this joint World-Ego state, AtlasVLA enables robust spatial reasoning. Extensive evaluations across LIBERO, RLBench, and real-world benchmarks demonstrate that AtlasVLA achieves state-of-the-art performance using solely a wrist camera. Remarkably, it decisively outperforms multi-view baselines, yielding absolute success rate improvements of 9.4% on LIBERO-Long and 17.5% in real-world long-horizon tasks.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：视觉-语言-动作（VLA）模型已显著推动具身智能发展，通过将多模态感知映射为机器人低级控制命令，弥合了高层语义推理与物理执行之间的鸿沟。
- **核心问题**：现有 VLA 模型本质上采用**反应式（reactive）范式**——将即时观测直接映射为动作，缺乏对环境持续状态的内在表征。在**仅使用单目腕戴相机**的设置下，这种范式暴露出两大关键瓶颈：
  - **感知遗忘（Perception Forgetting）**：机械臂运动导致腕相机视野不断变化，关键任务相关目标一旦离开视野即被遗忘，模型丧失空间感知能力（如“盒子在哪里？”），导致操作失败。
  - **任务进度遗忘（Task-Progress Forgetting）**：长时程任务需要多个子步骤的序列执行，反应式模型缺少历史上下文记忆，容易遗忘已完成步骤，造成重复或遗漏关键子任务。
- **核心论点**：人类认知并不依赖全知的第三视角相机，而是通过内在世界模型在部分可观测环境中保持连续性。因此，具身智能体需要从“无记忆观测”范式转向“局部观测→隐状态更新→持久世界状态→未来动作”的连续循环。
- **整体含义**：该论文提出从被动反应式操控转向**主动推理式操作**，通过显式的世界-自我状态建模突破反应式 VLA 在大范围操作和长时程任务上的根本性局限。

## 2. 论文提出的方法论：核心思想、关键技术细节与流程

### 总体框架
AtlasVLA 严格仅依赖单目腕相机观测（RGB 图像 + 本体感觉），提出**双记忆架构**：将持久世界状态记忆与自我工作状态记忆统一集成到扩散 Transformer（DiT）动作生成过程中。整体由三大核心模块构成：

### 模块一：持久世界状态记忆（Persistent World State Memory）
- **瞬时世界状态构建**：
  - 使用冻结的视觉编码器提取 2D 视觉 token；利用 Depth Anything v3（DAv3）进行流式深度估计，增强时间上的深度一致性。
  - 通过手眼标定矩阵与机器人状态计算腕相机外参，再经由**空间反投影模块**将 2D 视觉 token 提升到 3D 隐空间：
    - $m_t, P_t = \text{Back-Projection}(X^w_t, D^w_t, T_{in}, T_{ext})$
- **时空嵌入**：通过可学习的 MLP 分别注入 3D 空间位置编码与时间位置编码，形成显式的 4D 世界表征，缓解空间混叠和时间退化。
- **世界状态时空更新**：
  - *空间上*：采用类 TSDF（截断符号距离函数）的**体素哈希融合**策略，对落入同一体素的新旧 token 进行置信度加权聚合：
    - $M_t(v) = [W_{t-1}(v)M_{t-1}(v) + w_t m_t(v)] / [W_{t-1}(v) + w_t]$
    - 权重 $w_t$ 由深度估计置信度决定。
  - *时间上*：采用**滑动窗口**机制控制记忆规模，并设置**“首帧永久锚定”**规则，因为初始帧通常视野最佳、能准确反映操作初始状态。

### 模块二：自我工作状态记忆（Ego-Working State Memory）
- **意图感知查询**：设置一组可学习的意图查询 $Q_{ego} \in \mathbb{R}^{N \times d}$，通过交叉注意力从视觉与文本 token 中聚合目标导向信息，提炼出紧凑的自我工作隐状态 token：
  - $Z_{ego} = \text{Softmax}(Q_{ego}K^T/\sqrt{d})V$
- **记忆库整合**：通过冗余感知的潜在整合策略（Cons），将不同时刻的自我工作 token 按时间相邻与语义相似度进行合并，形成有限容量的时间意图记忆库：
  - $M^ego_t = \text{Cons}(M^ego_{t-1} \cup \{Z^{ego}_t + E_{temporal}(t)\})$

### 模块三：世界-自我引导的动作生成（World-Ego-Guided Action Generation）
- **双路径检索**：
  - 自我工作记忆检索：当前自我工作 token 通过交叉注意力从记忆库中提取最相关的历史意图上下文 $C^{ego}_t$。
  - 自我引导世界检索：以历史自我上下文 $C^{ego}_t$ 为查询，从全局世界记忆中检索任务相关的空间状态 $C^{world}_t$。
- **逐步条件化 DiT 动作专家**：与标准全局条件扩散模型不同，AtlasVLA 采用解耦的逐步条件机制——每个扩散步中，含噪动作 token 先经过**自我工作注意力层**（获取任务进度），再经过**世界状态注意力层**（获取几何空间信息），经过 K 步去噪后由动作解码器输出最终动作。
- **训练目标**：标准的扩散去噪 MSE 损失，并采用条件丢弃（p=0.1）以支持推理时的无分类器引导（CFG）。

- **仅凭腕相机即达 SOTA**：AtlasVLA 在 LIBERO 上达到 97.6% 平均成功率、RLBench 70.8%、真实世界通用任务 78.7%、真实世界长时程任务 69.5%，全部仅用单目腕相机。

- **在极限遮挡和长时程压力测试下表现突出**：相比 MemoryVLA 在剥离第三视角后性能骤降（LIBERO-Long 降 5.8%），AtlasVLA 的性能几乎不受影响，说明持久状态建模有效消除了对外部空间先验的依赖。

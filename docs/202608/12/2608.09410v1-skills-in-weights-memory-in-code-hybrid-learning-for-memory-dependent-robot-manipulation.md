## 摘要
现代视觉-语言-动作（VLA）策略已获得广泛的操作技能，但通常从当前观测或短固定长度历史生成每个动作块。然而，现实世界的操作往往是非马尔可夫的，要求机器人从长时程交互历史中保留并推理任务相关信息以确定下一个动作。为应对这一挑战，我们提出HyMeS，一种混合学习框架，利用编码代理的推理和记忆管理能力来引导马尔可夫VLA进行记忆依赖的操作。具体而言，HyMeS通过基于梯度的模仿学习学习低级运动技能，而编码代理通过从回滚反馈迭代更新可执行启发式系统，以启发式学习获得高级记忆管理策略。此外，我们通过多模态阶段完成验证闭环连接引导与执行，利用本体感觉信号和多帧VLM判断更新记忆。与端到端记忆增强VLA相比，HyMeS仅需可复用运动技能的演示，而无需针对每个历史依赖的任务配置，从而实现数据高效的组合泛化。在RoboMemArena上，HyMeS将平均累积成功率从52.5%提升至66.2%，平均任务成功率从41.3%提升至60.1%，相对于pi0.5，同时累积成功率超出PrediMem 4.5个百分点，任务成功率超出14.5个百分点。

## Abstract
Modern vision-language-action (VLA) policies have acquired broad manipulation skills, but typically generate each action chunk from the current observation or a short fixed-length history. However, real-world manipulation is often non-Markovian, requiring robots to retain and reason over task-relevant information from long-horizon interaction histories to determine the next action. To address this challenge, we propose HyMeS, a hybrid learning framework that leverages the reasoning and memory-management capabilities of coding agents to steer a Markovian VLA for memory-dependent manipulation. Specifically, HyMeS learns low-level motor skills through gradient-based imitation learning, while a coding agent acquires high-level memory-management strategies through heuristic learning by iteratively updating an executable heuristic system from rollout feedback. Furthermore, we close the loop between steering and execution through multimodal stage-completion verification, which updates memory using proprioceptive signals and multi-frame VLM judgments. Compared with end-to-end memory-augmented VLAs, HyMeS requires demonstrations only for reusable motor skills rather than for every history-dependent task configuration, enabling data-efficient compositional generalization. On RoboMemArena, HyMeS improves mean cumulative success from 52.5% to 66.2% and mean task success from 41.3% to 60.1% over pi0.5, while outperforming PrediMem by 4.5 points in cumulative success and 14.5 points in task success.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：现代视觉-语言-动作（VLA）模型已在通用机器人操作上取得了显著进步，如 π0.5、π0.6 等模型能够泛化到多样物体、场景和语言指令。然而，绝大多数 VLA 从设计上就是**马尔可夫的（Markovian）**——即每个动作块仅由当前观测或短固定长度窗口生成，无法利用长时间跨度的交互历史信息。
- **非马尔可夫任务需求**：真实世界的许多操作任务本质上依赖于历史信息。例如，机器人需要记住"从最初卡片上看到的数字来决定按按钮的次数"，或记住"某个物体原本放置的位置"等。在这些场景中，当前观测无法区分不同历史状态，导致马尔可夫策略被迫在不同行为模式之间取平均，从而无法匹配最优策略。
- **现有方案的局限**：
  - 端到端记忆增强 VLA 将记忆模块与策略联合训练，但其记忆逻辑是组合性和离散的，需要在权重空间学习，导致需要覆盖组合空间的演示数据，且容易遗忘、难以检查或编辑。
  - 推理期引导方法虽然保持基础策略冻结并注入引导信号，但其引导是反应式的（仅依据当前观测或外部信号），不维护任务级记忆；且信息流单向，没有策略反馈读出。
- **本文提出**的 HyMeS 框架正是为了填补这一空白：**将运动技能学习与记忆策略学习分离**——技能存在权重中，记忆存在代码中，以数据高效的方式解决记忆依赖的操作问题。

## 2. 方法论：核心思想、关键技术细节与流程

### 核心思想

HyMeS（Hybrid Learning framework for Memory-dependent manipulation via Steering，即"混合学习"框架）的核心在于：

> **运动技能保存在权重空间，记忆策略保存在代码空间。**

具体而言：
- 低层运动技能由马尔可夫流匹配 VLA 通过**基于梯度的模仿学习**在权重空间获得；
- 高层记忆管理策略由编码代理（coding agent）通过**启发式学习（heuristic learning）**在代码空间迭代更新可执行程序——该程序从回滚（rollout）反馈中学习，不依赖梯度或专家动作标签。

### 问题形式化

论文形式化了记忆依赖任务：任务状态 $z_t = \phi(h_t)$ 是一个紧凑的历史函数，无法从当前观测 $o_t$ 中恢复，导致观测存在"混叠（aliasing）"。目标是从仅覆盖运动技能（而非组合记忆空间）的演示集 $D$ 中学习马尔可夫策略，并从无动作标签的回滚中学习外部记忆机制。

### 系统组成与工作流程

系统由两个核心组件构成：

1. **权重空间组件**：经任务特定微调的流匹配 VLA（以 π0.5 为初始），参数 θ⋆ 在启发式开发和评估期间保持固定。
2. **代码空间组件**：可执行启发式程序 P = (C, V, U)，包含约束选择规则 C、事件验证规则 V 和记忆更新规则 U。

- **约束选择**：$R_t = C(s_t, o_t, \ell)$

### 关键技术细节

- **运动技能学习**：使用流匹配目标，在噪声与专家动作块的插值上微调速度场，公式为 $\theta^\star = \arg\min_\theta \mathbb{E}[\|v_\theta(a_\tau, \tau | o, \ell) - (a - \epsilon)\|^2_2]$。仅需演示可复用技能，不涉及记忆组合。
- **记忆策略学习**：记忆状态为 $s_t = (\text{plan}, \rho_t, B_t, N_t, F_t)$，其中 ρ_t 是活动阶段，其余变量记录任务绑定、重复事件计数和持久交互状态。编码代理通过程序编辑操作 $P^{(n+1)} = \text{Edit}(P^{(n)}, \xi_n, b_n)$ 迭代更新程序——基于 PACE 记录的符号执行轨迹 ξ_n 与基准阶段级判定 b_n 进行对比、诊断和修订。

- **PACE（Proprioception-And-Completion-driven stagE-switching）多模态进度验证**：结合两类互补证据：
  - 本体感觉证据：检测动作依赖的运动模式，通过符号锁存器保留持久事件；

## 6. 主要结论与发现

1. **HyMeS 显著优于马尔可夫 π0.5**：在相同策略权重下，CSR 从 52.5% 提升至 66.2%，TSR 从 41.3% 提升至 60.1%，证明可执行记忆与引导可弥补马尔可夫 VLA 的内在记忆缺失。
2. **HyMeS 优于记忆增强的 PrediMem**：TSR 超越 14.5 个百分点（60.1% vs. 45.6%），CSR 超越 4.5 个百分点（66.2% vs. 61.7%）。TSR 差距大于 CSR 差距，表明 HyMeS 更有效地将中间进展转化为完整任务成功。
3. **分任务类别观察**：
   - 转移任务增益最大（TSR +26.6 点），计数值 +30.0 点，顺序任务 +22.5 点；
   - 计数任务中 HyMeS 的 CSR 低于 PrediMem（60.3% vs. 72.2%），但 TSR 更高（50.0% vs. 36.7%），失败集中在早期执行阶段，很可能源于冻结 VLA 的限制或引导干扰；
   - 遮挡是最困难的类别，PrediMem 的 CSR 甚至低于反应式 π0.5（38.3% vs. 50.4%），说明不可靠的记忆会主动误导执行；HyMeS 在 CSR 上与 π0.5 持平（50.6%）且 TSR 提升 7.0 点。
4. **真实机器人验证**：TSR 从 25.7%（π0.5）提升至 57.1%（HyMeS），单任务增益 50.0、26.7 和 20.0 个百分点，证明一个符号状态即可支持线索保留、计数和源-位置关联任务。Put-Back Block 仍具挑战性，原因是环境光照变化降低了底层视觉运动策略的鲁棒性。
5. **消融实验**：
   - 回滚经验显著改善性能（CSR +8.5，TSR +18.4），验证了启发式学习的有效性；
   - 单一模态验证均不如多模态：视觉单独使 CSR/TSR 分别降低 16.0/21.7 点，本体感觉单独使 CSR/TSR 降低 8.8/8.4 点，证明了多模态互补证据的必要性。
6. **数据效率与可检查性**：每种平台仅需一个微调检查点，新的记忆配置通过编辑代码程序实现而非重新收集演示；符号状态在每个控制步可读，失败可定位到记忆更新、运动执行或事件验证环节。

## 7. 优点

- **新颖的混合学习框架**：将运动技能学习与记忆策略学习解耦，在有别于传统端到端学习路径上取得了显著效果——这是本文最核心的贡献。技能与记忆分离的架构理念清晰，使用训练好的流匹配策略作为运动先验，以零权重更新方式接入记忆信息，保持了策略的通用性和可迁移性。
- **记忆透明可检查**：符号状态在每步可读，失败可精确定位到记忆更新、运动执行或事件验证，这相比端到端模型的黑箱潜在记忆有明显实用性优势，也是实践中的重要资产。
- **双向闭环设计**：与 VLS 等单通道引导方法不同，HyMeS 通过 PACE 将执行反馈（本体感觉与视觉）读回用于记忆更新，使引导与执行形成了双向耦合。
- **多模态阶段验证**：PACE 融合本体感知与多帧 VLM 视觉证据，并采用滑窗投票（抑制孤立错误）和符号锁存器（保留持久事件），机制设计合理且不依赖特权环境状态或任务特定的完成模型。
- **数据高效**：演示预算与可复用技能数量挂钩而非历史依赖任务配置数量，在实验中得到验证。
- **实验设计公平**：与 π0.5 共享完全相同的演示、策略权重和观测配置，与 PrediMem 在相同修正协议上重新评估；同时覆盖模拟与真实机器人，提升了结论的可信度。
- **定性可视化质量高**：提供记忆引导执行可视化和失败模式可视化，直观展示了方法的实际效果与局限来源。

## 8. 不足与局限

- **任务范围受限**：论文集中于可用紧凑符号状态表示历史信息的任务。对于需要等级式、多模态或非符号化记忆表示的任务（如视觉细节记忆、语义记忆、长对话上下文等），方法的直接适用性尚未验证。论文在局限中也承认了这一点。
- **性能受制于底层策略与验证**：即使记忆状态和引导约束正确，接触丰富的运动执行仍可能失败（如瞄准偏差导致抓取失误、抖动产生多余按压、按压深度不足未被 PACE 识别等）。这说明引导系统无法克服底层策略的固有缺陷。
- **任务选择的潜在偏差**：12 任务筛选过程剔除了"以运动技能失败为主"的任务，虽有一定合理性（聚焦记忆维度），但也可能使结果高估了方法在无筛选原始基准上的相对优势。
- **真实实验规模较小**：SO-101 上仅有 3 个任务、每方法共 35 次试验，且 Put-Back Block 的增益最小（2/10 vs. 0/10），环境光照变化即导致失败，泛化性和鲁棒性证据相对有限。
- **推理开销**：每阶段初期的 SAM/DINOv2 关键点提取、周期性 Qwen3-VL-8B 多帧查询以及开发阶段的编码代理调用增加了显著的延迟和计算成本，论文将其列为未来工作要解决的效率问题（但未提供量化分析）。
- **约束函数设计依赖符号化先验**：任务约束需以可执行代码形式表示，要求合理的 VLM+coding-agent 调用链路，约束选择的正确性对系统整体性能有决定性影响。
- **对记忆组件性能的归因仍有限**：虽然总体消融显示了每个组件的重要性，但对于同一任务内的细粒度失败分析（如 CSR/TSR 差异的详细归因）仍较为粗略，部分现象仅给出定性解释。

## 摘要
视觉-语言-动作（VLA）模型为连接视觉感知、语言理解和机器人控制提供了统一范式。然而，现有的VLA模型在长时程任务中仍面临主要挑战：稀疏的专家示范限制了跨任务的组合泛化；长时程任务的非马尔可夫性质使得仅以当前观测为条件的策略难以维持时间一致性；有限的闭环纠错能力导致执行误差累积；端到端的动作微调可能削弱视觉-语言模型（VLM）骨干网络的高层语义表示。为解决这些问题，我们提出了一种带有显式语言记忆模块的层次化长时程VLA架构。其核心思想是将离散的时间观测转换为具有时间逻辑的连贯文本记忆序列。该系统被解耦为高层VLM和低层VLA：高层VLM通过视觉问答训练范式进行语义推理，而低层VLA在子任务指令和视觉观测的条件下执行精确的连续控制。高层VLM以先前的记忆作为上下文锚点，递归更新语言记忆和子任务指令，从而在长时程执行过程中实现持续的时间跟踪和动态纠正。我们在多个模拟环境中评估了所提方法，并在真实机器人平台上进行了仿真到真实的实验。结果表明，显式语言记忆提高了VLA模型在复杂长时程任务中的成功率和鲁棒性，同时为决策过程提供了可解释的语义描述。

## Abstract
Vision-language-action (VLA) models provide a unified paradigm for connecting visual perception, language understanding, and robotic control. However, existing VLA models still face major challenges in long-horizon tasks: sparse expert demonstrations constrain cross-task compositional generalization; the non-Markovian nature of long-horizon tasks makes it difficult for policies conditioned only on current observations to maintain temporal consistency; limited closed-loop error correction allows execution errors to accumulate; and end-to-end action fine-tuning may weaken the high-level semantic representations of vision-language model (VLM) backbones. To address these issues, we propose a hierarchical long-horizon VLA architecture with an explicit language-memory module. The central idea is to convert discrete temporal observations into a coherent textual memory sequence with temporal logic. The system is decoupled into a high-level VLM and a low-level VLA: the high-level VLM performs semantic reasoning through a visual question answering training paradigm, while the low-level VLA executes precise continuous control conditioned on subtask instructions and visual observations. The high-level VLM recursively updates both language memory and subtask instructions using the previous memory as a contextual anchor, enabling persistent temporal tracking and dynamic correction during long-horizon execution. We evaluate the proposed method in multiple simulation environments and conduct sim-to-real experiments on a real robotic platform. The results demonstrate that explicit language memory improves the success rate and robustness of VLA models on complex long-horizon tasks while providing an interpretable semantic account of the decision process.

## 1. 论文的核心问题与整体含义（研究动机和背景）

**研究背景：**
视觉-语言-动作（Vision-Language-Action, VLA）模型将视觉感知、语言理解和机器人控制统一到一个策略网络中，是具身智能领域的重要范式。然而，现有VLA模型在**长时程任务**中面临四大关键挑战：

- **跨任务组合泛化受限**：专家示范数据稀疏，难以覆盖长任务中所有状态组合；
- **非马尔可夫性质**：长时程任务中，仅依赖当前观测无法判断任务阶段。例如，同一视角下，机器人可能处于已抓取、未抓取或已按键等不同状态，导致策略跳步、重复或误判；
- **误差累积**：闭环纠错能力有限，早期错误会在后续阶段持续放大；
- **语义表征弱化**：端到端动作微调可能破坏VLM骨干网络的高层语义能力。

**核心思想：**
论文的核心主张是：用**显式自然语言记忆**替代原始历史帧序列，作为任务历史的紧凑载体。高层VLM递归更新语言记忆和子任务指令，低层VLA据此执行连续动作，从而在长时程任务中保持阶段一致性，并提供可解释的决策过程。

## 2. 论文提出的方法论

### 2.1 核心架构：层次化VLM-VLA策略

将策略分解为两个耦合的子模块：

- **高层语义分支 π_HL**：基于全局指令 l、当前观测 o_t、前一轮记忆 m_{t-1}，递归预测更新后的语言记忆 m_t 和当前子任务指令 s_t；
- **低层动作分支 π_LL**：基于当前观测 o_t 和子任务指令 s_t，生成固定视界 H=30 的连续动作块 a_{t:t+H}。

策略概率分解：

```
π(a_{t:t+H}, s_t, m_t | o_t, m_{t-1}, l) = π_LL(a_{t:t+H} | o_t, s_t) · π_HL(s_t, m_t | o_t, m_{t-1}, l)
```

### 2.2 递归语言记忆机制

记忆 m_t 被设计为**结构化自然语言摘要**，包含：
- 已完成里程碑（过去时）
- 完成证据
- 相关物体属性（颜色、位置、类别）
- 观测到的失败
- 下一步待执行意图

关键规则为**滚动压缩（rolling compression）**：子任务完成前保留目标细节，完成后将其压缩为简短过去时陈述，注意力移向下一个动作。例如：

- m_t："I am moving to the red radio on the coffee table."
- m_{t+1}："I moved to the radio, and I am going to pick up the red radio."

### 2.3 自动标注监督管线

- 专家视频带有技能级标注（技能名称、描述、起止时间戳）；
- 通用VLM（Gemini 3.5 Flash API或本地Qwen3.5-9B）对每帧生成：
  1. 简洁子任务（格式：动作 + 目标物体 + 上下文）；
  2. 第一人称语言记忆（过去时描述已完成技能 + 未来导向陈述下一步意图）；
- 提示明确禁止使用"frame""sequence""index"等实现术语，以保证记忆的自然性。

### 2.4 独立分支训练

- **高层分支**：基于PaliGemma（3B VLM），自回归预测记忆和子任务，使用LoRA适配；
- **低层分支**：沿用π0.5的动作专家，300M Gemma参数全量微调，采用flow-matching动作目标；
- **独立训练**：避免单一大目标中语义生成与连续控制损失之间的手动权重平衡。

### 2.5 闭环推理

初始化 m₀=∅，循环执行"观测→语义更新→生成动作块→执行→判断终止"，直到高层状态指示任务完成。

## 6. 论文的主要结论与发现

1. **语言记忆提升长时程任务成功率**：
   - BEHAVIOR-1K：平均成功率从 30.0% → 40.0%，最大增益在PickUp阶段（10% → 30%）；
   - Genie Sim单包裹：平均成功率从 41.7% → 63.9%，Follow和第一次PickUp翻倍，放置到扫描区从50.0% → 83.3%；
   - Genie Sim连续分拣：从 31.3% → 46.9%，基线从未到达第三、四个放置，而带记忆的模型在12.5%试验中完成全部四次放置；
   - 真实机器人：从 62.5% → 66.3%，提升较小。

2. **语言记忆改善阶段一致性**：无记忆基线会提前推进子任务（如未按键就放置收音机），带记忆的策略严格等待完成证据。

3. **语义规划不等于运动控制**：PressOn（按键）成功率仍然很低，说明语言记忆解决"做什么"和"处于哪个阶段"的问题，不直接提升接触丰富动作的执行精度。

4. **显式文本提供可解释的失败定位与in-context恢复**：抓取失败后，记忆可记录失败状态，促使下一步重试。

## 7. 优点

**方法层面：**
- **记忆紧凑且可解释**：用自然语言而非原始帧序列表示历史，上下文开销低，且人类可直接阅读决策日志；
- **层次化解耦**：高层语义推理与低层连续控制独立训练，避免多目标优化冲突，也便于分别诊断错误类型；
- **滚动压缩机制**：完成阶段压缩细节、当前阶段保留细节，记忆长度在实践中保持有界；
- **自动标注管线**：借助通用VLM从专家视频自动生成监督信号，降低人工标注成本；
- **模型无关的语言记忆设计**：可直接移植到不同VLA骨干上，通用性强。

**实验层面：**
- 多环境验证（两种仿真 + 真机），支持从仿真到真实的初步泛化结论；
- 阶段级成功率比端到端指标信息量更大；

## 8. 不足与局限

**实验覆盖不足：**
- 真机任务过短（4阶段），未验证分钟级、多物体、环境变化的真实长时程任务；
- 每个环境仅一个任务，结论的多样性有限；
- 无消融实验，无法剥离"层次化架构""独立训练""语言记忆"各自对效果的贡献。

**统计严谨性不足：**
- 未报告随机种子、方差、置信区间；
- 真机试验仅20次，统计功效较低。

**方法局限：**
- 额外高层VLM调用增加计算开销、端到端延迟和部署复杂度；
- 语言记忆无法弥补低层控制精度不足（PressOn低成功率即证据）；
- 失败恢复依赖多样化的失败-恢复示范数据，当前数据覆盖不足；
- 依赖VLM标注质量，若标注不一致可能引入噪声。

**偏差风险：**
- 选择的任务（收音机、分拣）可能对语言记忆有利，缺乏对"语言较难描述"的空间密集/接触密集任务的验证；
- 基线π0.5本身已具备一定语义预测能力，但作者未讨论与原生π0.5高层次语义预测模块的详细对比。

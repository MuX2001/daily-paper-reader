## 摘要
通用机器人策略旨在将多模态观测和语言任务指令映射到跨多种任务的动作上。然而，现有方法通常将未来表示为固定的、短视频-动作块。这种短期未来捕获了用于动作执行的局部场景演化，但它没有明确描述指定任务应如何从当前阶段进展到下一阶段的阶段级未来。因此，我们区分了机器人操作的两种互补未来：用于捕获局部场景演化的短期物理未来，以及用于表示任务进度的阶段级语义未来。我们引入了JEPA-WAM，它用Stage-JEPA（一种目标条件下的联合嵌入预测架构（JEPA）预测器）增强了基于Motus的世界动作模型（WAM）。给定当前观测和任务指令，Stage-JEPA使用冻结的V-JEPA2编码器提取当前状态表示，并预测下一推断阶段的潜在目标。在干净和随机化环境中的50个RoboTwin 2.0任务中，JEPA-WAM实现了90.25%的整体成功率，并将成功执行中的平均执行步数相对于最强基线减少了5.97%。

## Abstract
Generalist robot policies aim to map multimodal observations and linguistic task instructions to actions across diverse tasks. However, existing methods typically represent the future as a fixed, short video-action chunk. This short-term future captures local scene evolution for action execution, but it does not explicitly describe the stage-level future that specifies how a task should progress from its current stage to the next. We therefore distinguish two complementary futures for robot manipulation: a short-term physical future to capture local scene evolution and a stage-level semantic future to represent task progress. We introduce JEPA-WAM, which augments a Motus-based World Action Model (WAM) with Stage-JEPA, a goal-conditioned Joint-Embedding Predictive Architecture (JEPA) predictor. Given the current observation and task instruction, Stage-JEPA uses a frozen V-JEPA2 encoder to extract the current-state representation and predicts the latent target of the next inferred stage. Across 50 RoboTwin 2.0 tasks in clean and randomized environments, JEPA-WAM achieves 90.25% overall success and reduces the mean number of execution steps in successful rollouts by 5.97% relative to the strongest baseline.

## 2. 方法论

### 2.1 核心思想

JEPA-WAM 采用两阶段训练策略，将"阶段级语义未来预测"与"短时视觉-动作生成"解耦：

- **Stage I**：训练目标条件的 JEPA 预测器（Stage-JEPA），学习推断下一任务阶段的潜在表示；
- **Stage II**：冻结 Stage-JEPA，训练一个基于 Motus 的 WAM，使其在给定阶段表征的条件下生成短视频未来与动作块。

### 2.2 关键技术细节

**(1) Stage-pair 构建（无需人工标注阶段）**

- 从演示轨迹中每 8 帧采样候选中心，对每个中心编码一个以该帧为中心的 64 帧片段（使用冻结的 V-JEPA2 编码器）；
- 计算两个代表性距离分数：
  - **clip 级分数**：相邻局部窗口（w=2）内均池化表征的欧氏距离；
  - **token 级分数**：对应 token 位置间最大欧氏距离；
- 对两个分数进行归一化、取最大值，再通过**时间非极大值抑制（NMS，半径 r=3，最多保留 K=5 个关键帧）**得到阶段边界；
- 相邻边界构成阶段区间 \\([b_i, b_{i+1})\\)，每个当前帧 \\(t\\) 配对下一边界 \\(b_{i+1}\\)，形成密集的训练对 \\((t, b_{i+1})\\)。

**(2) 目标条件阶段预测（Stage-JEPA）**

- 使用**冻结的 V-JEPA2 编码器**分别编码当前观测切片 \\(S_t\\) 与目标观测切片 \\(S^{target}_t\\)，得到潜在表征 \\(z_t\\) 和 \\(z^{target}_t\\)；
- 可训练的预测器（初始化为 V-JEPA2 预测器）从当前表征预测下一阶段的 token 级表征 \\(\hat{Z}^{target}_t\\)，经均值池化和归一化后与目标表征计算 **余弦相似度损失**：

\[
L_{stage} = \frac{1}{B}\sum_{i=1}^{B}(1 - (\hat{z}^{target}_i)^\top z^{target}_i)
\]

- 任务指令通过一个可训练的前置适配器（cross-attention）注入。

**(3) 阶段条件化的 WAM 训练**

- 将 Motus（一种 Mixture-of-Transformers 架构，含视频生成专家、动作专家和视觉-语言理解专家）作为基础 WAM；
- **条件注入方式**：将 Stage-JEPA 输出的 \\(N_j\\) 个阶段 token 进行均值池化，经 MLP \\(P_\psi\\) 映射到视频 token 维度，通过**全局标量门控**注入视频分支：

\[
h_t = P_\psi(\text{Pool}(\hat{Z}^{target}_t)) \in \mathbb{R}^{d_v}
\]

\[
\alpha = 0.2\sigma(\beta)
\]

\[
\tilde{X}^v_t = X^v_t + \alpha h_t
\]

- 其中 \\(\alpha\\) 是一个有界全局标量门控（所有样本、层、视频 token 共享），\\(h_t\\) 是样本特定的条件向量；
- 训练时保持 WAM 原有视频与动作损失，并加入两个门控正则项：
  - \\(\lambda_g \alpha^2\\)：偏置门控朝向小的残差更新；
  - \\(\lambda_\rho(\rho - \rho_0)^2\\)，其中 \\(\rho = \frac{\|\alpha h_t\|}{\|X^v_t\|}\\)：约束注入特征相对于原始视频 token 的幅度。

**(4) 闭环推理**

- 策略维护一个因果 64 帧观测缓冲区（不足 64 帧时重复最早帧填充，**不使用任何未来信息**）；
- 每次查询时顺序执行：
  - 阶段预测：\\(\hat{z}^{target}_t = f_\theta(H_t, l)\\)
  - 局部生成：\\((\hat{V}^{short}_t, \hat{A}_t) = W_\phi(o_t, s_t, l, \hat{z}^{target}_t)\\)
- 环境执行动作块后更新缓冲区，重复该闭环流程。

## 6. 主要结论与发现

1. **整体成功率**：JEPA-WAM 在干净配置下达到 **91.42%**，在随机化配置下达到 **89.08%**，50 任务平均 **90.25%**，优于 Motus（88.66% / 87.02%）及其他 VLA 基线。
2. **类别提升分布**：提升最明显的是**交接**（96.50% vs 82.00%）、**目标放置**（88.23% vs 82.62%）和**容器装箱**（91.12% vs 88.62%）等项目依赖显式任务进度变化的类别；而在**获取与举升**（92.60% vs 94.20%）及**铰接/设备交互**（90.71% vs 93.57%）上略低于 Motus，作者解释为这些任务更依赖即时抓取几何与接触稳定性，阶段结构的补充增益有限。
3. **执行效率**：JEPA-WAM 将成功 rollout 的平均执行步数从 79.57 降至 74.82（**减少 5.97%**），所有 rollout（含失败）平均长度从 156.28 降至 132.80（减少 15.02%）；定性案例显示 Motus 会出现重复上下移动物体的冗余修正行为，而 JEPA-WAM 更直接地推进到任务完成阶段。
4. **消融结论**：
   - 去除 JEPA 分支是最大性能退化来源 → 阶段条件路径提供了超出短期 WAM 骨干的额外信息；
   - 保留 JEPA 但不注入未来潜在（只用于当前观测）也会降低成功率 → **注入位置（未来潜在而非当前表征）至关重要**；
   - 不训练 Stage-I 仅依赖预训练 V-JEPA2 预测器仍具竞争力，但不会超过完整训练 → Stage-I 目标提供额外但相对较小的增益；
   - 去除门控正则化只带来轻微下降 → sigmoid 有界门控本身已能稳定残差更新。
5. **真实世界**：在 LIFT2 平台上，JEPA-WAM 在 Cube_Grasp（45.00 vs 33.50）和 Power_Strip（51.00 vs 49.50）上均优于 π0.5，平均任务进度分数 48.00 vs 41.50。

## 7. 优点

1. **概念简洁且有说服力**：将未来建模明确拆分为"短期物理未来 + 阶段级语义未来"两个互补尺度，为解决"策略是否真正理解任务进展"这一核心问题提供了清晰框架。
2. **无需人工阶段标注**：利用冻结 V-JEPA2 表征的距离变化 + 时间 NMS 自动推断阶段边界，可扩展性强。
3. **两阶段解耦训练设计**：先学"该去哪个阶段"再学"如何实现"，并冻结阶段预测器避免细节损失干扰语义目标，逻辑自洽。
4. **条件注入方式轻量且高效**：单个全局标量门控 + 均值池化特征广播，不引入大量额外参数，适用于视频 token 流。
5. **测试充分**：50 任务 × 2 配置的大规模模拟评估 + 消融 + 真实世界评估 + 轨迹执行效率分析，多角度验证方法有效性。
6. **统一了 VLA 与 WAM 的长处**：保留 WAM 模态间注意力交互，同时用 JEPA 表示学习规避像素重建的语义脱靶问题。

## 摘要
我们提出了一种针对受未知扰动影响的输入受限欠驱动线性系统的鲁棒安全滤波框架。基线H-无穷输入源自零和微分博弈，而扰动观测器提供估计值和瞬态误差界。使用扰动估计调整基线输入，同时利用估计值及其误差界定义鲁棒高阶控制屏障函数约束；只要可容许输入集保持非空，前向不变性就成立。对于标量输入系统，逐点可行性由精确输入区间确定，区间宽度定义可行性裕度。有限时域H-无穷性能平衡考虑了实际输入与基线H-无穷策略的累积偏差。在轮式两轮平衡机器人的线性化模型上的仿真展示了位置约束和车身俯仰约束如何竞争同一个受限的轮力矩输入。

## Abstract
We present a robust safety-filtering framework for input-constrained underactuated linear systems subject to unknown disturbances. A baseline H-$\infty$ input is derived from a zero-sum differential game, while a disturbance observer supplies an estimate and a transient error bound. The baseline input is adjusted using the disturbance estimate, while the estimate and its error bound are used to define robust high-order control barrier function constraints; forward invariance holds as long as the admissible-input set remains nonempty. For scalar-input systems, pointwise feasibility is determined from an exact input interval, and the interval width defines the feasibility margin. A finite-horizon H-$\infty$ performance balance accounts for the accumulated deviation of the applied input from the baseline H-$\infty$ policy. Simulations on a linearized two-wheeled balancing robot show how position and body-pitch constraints compete for the same bounded wheel-torque input.

## 6. 论文的主要结论与发现

- **安全性与唯一性**：提出的控制器在全部 3 种扰动场景中均满足位置和俯仰约束，是唯一在暂时阶跃扰动下同时满足两个状态约束的控制器。LQR 在每种场景都违反两个约束；基线 H∞ 在暂时阶跃和严重阵风下违反位置限制；OI-nominal 在暂时阶跃下违反俯仰限制。
- **约束竞争现象**：由于 underactuation，位置和俯仰的 HOCBF 约束在同一个轮力矩上有相反的系数符号（a_{p,σ} = −5.6351σ 与 a_{θ,σ} = 60.6013σ），两个约束对共用输入施加“对侧”的边界，直观地体现了可行性裕度的作用。滤波器的行为表现为：相对于 OI-nominal，降低俯仰峰值的同时允许更大的位置偏移。
- **理论保证一致**：所有安全量（hⱼ, ϕ_{j,1}, Γⱼ^rob）在数值容差内保持非负，误差界 ρ(t) 始终覆盖真实误差，验证了命题2的推论。
- **性能平衡成立**：有限时域 H∞ 平衡等式两侧绝对差值仅 3.5×10⁻⁸，数值上完全一致；J_dev(8) = 0.04347 度量了安全滤波造成的 H∞ 策略偏离。

## 7. 优点

- **理论框架完整统一**：首次将 H∞ 差分博弈、扰动观测器、鲁棒 HOCBF 和有限时域性能评估纳入一个框架，解决了“安全—性能—鲁棒性”三者的权衡问题。
- **降低保守性**：通过观测器在线估计实现时变不确定集，而非固定保守界；误差界 ρ(t) 显式依赖初始误差与扰动变化率上界，结构清晰。
- **精确的标量可行性条件**：公式27给出充要的输入区间条件，并定义了直观的可行性裕度，实操性强。
- **闭式解**：标量输入情况下不需要在线求解 QP，直接投影计算得到最优解。
- **有限时域性能平衡**：命题3的非平凡贡献——将 J_dev(T) 显式嵌入能量平衡不等式，量化了安全滤波对 H∞ 性能的代价，而不是回避或假设无损。

- **仿真验证严谨**：列出了完整的矩阵、增益、扰动波形和积分参数，可复现性好；对估计误差界、HOCBF 条件和性能恒等式均做了数值验证。

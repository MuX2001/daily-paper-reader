## 摘要
长时程服务机器人需要持久的世界模型，该模型能够在未见环境中自主构建，并随着任务相关物体的变化而修订。现有方法依赖于在线建图，这会累积定位和观测误差；或者采用静态场景表示，无法捕捉持久的物体变化；又或者采用缺乏可验证3D几何证据的整体视觉-语言预测。我们提出了PBD-AG，一个持久基线-增量活动图框架，将机器人验证的稳定固定装置与可修订的动态物体事件解耦。在该框架下，机器人通过机载探索自主引导结构基线，并检查已发现的固定装置以锚定分层物体信念。PBD-AG在几何、语义、身份、存在性和支撑关系上维护可靠性加权的物体状态，利用几何可见性门控来减轻遮挡下的错误删除。检查视点由图形条件策略选择，该策略平衡目标覆盖、行进成本、碰撞风险和冗余观测。在多种环境和受控动态评估下的模拟实验显示，与能力匹配的对照组相比，聚合粗固定装置F1得分更高，同时身份连续性和事件召回率更强。一次定性的物理机器人演示进一步展示了与机载传感的集成，为长时程机器人感知提供了可追溯的世界模型。PBD-AG的项目页面可在https://shuobao214.github.io/PBD-AG/获取。

## Abstract
Long-horizon service robots require persistent world models that can be built autonomously in unseen environments and revised as task-relevant objects change. Existing methods rely on online mapping, which accumulates localization and observation errors, static scene representations that cannot capture persistent object changes, or holistic vision-language predictions that lack verifiable 3D geometric evidence. We present PBD-AG, a persistent baseline-delta active graph framework that decouples robot-verified stable fixtures from revisable dynamic object events. Under our framework, the robot autonomously bootstraps the structural baseline from onboard exploration and inspects discovered fixtures to ground hierarchical object beliefs. PBD-AG maintains reliability-weighted object states over geometry, semantics, identity, existence, and support relations, utilizing a geometric visibility gate to mitigate false deletions under occlusion. Inspection viewpoints are selected by a graph-conditioned policy that balances target coverage, travel cost, collision risk, and redundant observation. Simulation experiments in multiple environments and under controlled dynamic evaluation show higher aggregate coarse-fixture F1 than capability-matched controls, as well as stronger identity continuity and event recall. A qualitative physical-robot demonstration further illustrates integration with onboard sensing, providing a traceable world model for long-horizon robotic perception.The project page of PBD-AG is available at https://shuobao214.github.io/PBD-AG/

  - **在线建图方法**（如 DynaMem）会累积定位与观测误差，且点级表示难以维护稳定的物体身份与层级支撑关系；

  - **整体视觉-语言预测**缺乏可验证的 3D 几何证据，无法区分“物体真实消失”与“被遮挡/检测器漏检”。

- **研究意义**：论文提出了一种**“基线-增量”**（Baseline-Delta）世界模型范式，将低速变化的稳定结构与高速变化的动态物体事件解耦，为下游规划器提供跨会话的、可追溯的、几何可验证的持久场景理解能力。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式与算法流程

### 2.1 核心思想

PBD-AG（Persistent Baseline-Delta Active Graph）的核心理念是：**按照场景信息的“变化速率”和“修订所需证据强度”将场景表示分离为两个层次**：

- **基线层（Baseline）**：由机器人通过自主探索发现、反复验证后冻结的高置信度稳定固定设施（fixtures），形成不可变的版本化结构包 B(0)；
- **增量层（Delta）**：附属于固定设施的动态物体事件流，以有序审计事件（typed event deltas）记录物体的身份、存在性与支撑关系变化。

### 2.2 系统架构与状态表示

系统状态定义为：

```
S_t = (B̃_t, M_t, E_{1:k_t}, A_t),  G_t = Publish(B̃_t, M_t)
```

其中 M_t 为持久运行时轨道表，B̃_t 为其规范固定设施视图，E_{1:k_t} 为有序审计事件流，A_t 为 2D 占用地图。每个持久轨道维护：

```
b_t^i = {p_cls^i, p_exist^i, μ_i, Σ_i, p_parent^i, a_i, τ_i, h_i, s_life^i}
```

即类别信念、存在信念、3D 中心与协方差、支撑父级信念、外观嵌入、最近可靠观测时间、持久身份标识与生命周期状态。

### 2.3 关键流程

1. **机器人自举基线构建**：
   - 初始状态为空工作记忆 + 全未知占用地图；
   - 前沿探索（frontier exploration）逐步扩大已知空间，累积 RGB-D 几何与 SigLIP 开放词汇特征；
   - 语义更新时查询固定设施分类学，经 DBSCAN 聚类生成设施提案，跨时间批次关联形成候选轨道；
   - 需多批次时间分离观测的交叉批次传感器共识门控才可提升为权威节点；近阈值或类冲突轨道经缓存 VLM 验证；不满足条件的假设被淘汰。

2. **证据门控的持久更新**：
   - 粗粒设施与动态物体使用**类型特定的关联前端**（类一致性、3D 中心距离 <0.8m、SigLIP 余弦相似度 >0.78），随后进入共享生命周期更新；
   - 匹配对使用固定证据增量更新：普通观测 1.0、缓存 VLM 确认 3.0、动态几何取最新提案、粗设施中心用 α=0.35 的指数移动平均。

3. **可见性门控的存在性更新**（论文核心机制之一）：

```
ℓ_t^i = ℓ_{t-1}^i + η_o·O_t^i + η_c·K_t^i − η_m·U_t^i·V_i(t) − η_r·R_t^i
```

   - 增量固定为 (η_o, η_c, η_m, η_r) = (1.0, 1.8, 0.70, 2.20)；
   - **几何可见性门控 V_i(t)**：将存储的 3D 边界框采样投影，须满足在相机范围内、图像边界内、5×5 窗口有效深度，且 d_meas + 0.15m ≥ d_expected，至少两个采样通过才视为“可见”；
   - 只有当漏检发生在“几何可观测”条件下才构成负面证据，避免遮挡/视点问题导致的误删。

4. **生命周期状态与审计事件**：
   - 创建假设发射 `add`，发布发射 `confirm`（要求 p_exist ≥ 0.72），匹配批次发射 `update`，位移 ≥0.35m 发射 `move`，支撑变化发射 `reparent`；
   - 动态节点在 p_exist < 0.30 时降级，p_exist ≤ 0.12 且 ≥3 次可见性允许的漏检后才发射 `remove`；
   - 移除轨道保留在内存中，可恢复原身份。

5. **图不确定性引导的固定设施中心检查**：
   - 固定设施不确定性 ut^i = w^T·φ_t^i，权重 w = (0.20, 0.30, 0.10, 0.15, 0.10, 0.15)，涵盖存在性、类别、父级、位置、年龄、确认不确定性；
   - 调度器在可行视图中选择：i*_t = argmax(0.8·u_t^i + 0.2·Prox(i))；
   - 视点控制器最小化成本函数：

```
J(v,i) = |d_foot(v,i) − d_pref| + 0.08·D_t(v) − 0.20·C(v) + 4[1 − Cov(v,i)] + P_margin(v,i)
```

   其中偏好距离 d_pref = 0.90m，D_t 为行进距离，C(v) 为碰撞清除度，Cov 为预估支撑面覆盖率；
   - 关键取舍：**几何前沿扩展未知空间，而图不确定性调度已发现固定设施的主动检查**，两者解耦。

## 6. 论文的主要结论与发现

1. **自主构景能力**：PBD-AG 从空图开始，在 9 次自主 rollouts 中取得粗 F1 = 0.866 ± 0.102、细 F1 = 0.713 ± 0.167，其中 Gates 卧室最优（粗 0.961 / 细 0.878）；
2. **受控粗比较优势**：在共享证据下，PBD-AG 粗固定设施 F1 为 0.868 ± 0.102，超过 DynaMem-adapted（0.757）和 ConceptGraphs-adapted（0.696），并将计数 MAE 从 0.716 降至 0.356；
3. **持久记忆优势**：PBD-AG 取得最高 IDF1（0.833 ± 0.029），恢复 12 个事件中的 11 个，身份切换数为 0，显著优于即时更新类对照（IDF1 最高 0.702）；
4. **组件贡献明确**：
   - **去除可见性门控**后假消失率从 0.014 飙升至 0.262、事件召回从 11/12 降至 6/12——证明门控对“去除消失”与“保留存在”的平衡至关重要；
   - **去除持久 ID** 后 IDF1 从 0.833 崩溃至 0.070、身份切换增至 43.33——证明跨帧一致身份的根本作用；
5. **物理部署可行性**：机器人可基于机载 RGB-D/LiDAR 完成探索-固定设施检验-层级图构建全流程，保持规范固定设施身份。

- **固定证据增量而非学习标量可靠性**：该设计增强了可解释性、可控性和跨场景泛化能力，避免了学习评分的域偏移风险；
- **类型特定的关联前端 + 共享持久状态更新**：兼顾了粗固定设施与动态物体各自不同的几何结构和失败模式，同时保持统一身份管理；
- **探索与检查解耦**：几何前沿负责打开未知空间，图不确定性负责调度已发现固定设施的检查，避免在未探索区域做无根据的语义假设；

## 8. 不足与局限

- **场景多样性有限**：仅 3 个仿真场景且全为家庭室内环境，未覆盖办公室、工业、室外等长时程服务机器人的其他典型部署场景；
- **统计功效弱**：每场景仅 3 个种子，种子间标准差较大（如 Benevolence 场景粗 F1 标准差达 0.119），部分差异可能不具统计显著性（未报告显著性检验）；
- **动态基准单一**：动态协议仅在 Hotel 场景中运行，未验证其他场景中物体动态变化的记忆表现；
- **主动获取实验结果报告不充分**：论文声称进行了配对独立主动 rollout，但正文中缺乏该实验的详细量化表格与对比分析，削弱了对“主动检查策略”贡献的实证支撑；
- **算力与资源信息缺失**：未报告 GPU 型号/数量/时间开销，限制了他人复现和实用性判断；
- **物理演示仅为定性**：无定量指标（如真实场景中的 F1、事件召回等），且无与基线的比较，只能证明可行性不能证明有效性；
- **所有参数固定为统一值**：虽然避免了过拟合，但也意味着在差异更显著的环境（如 Benevolence 中重复几何和受限视点导致性能下降）中缺少自适应调整机制；
- **下游影响未评估**：论文声称支持“下游规划者”，但未实际验证长时程规划/操作任务中使用 PBD-AG 图带来的端到端收益；
- **基准对比的公平性偏差**：DynaMem/ConceptGraphs 的对比是“adapted”版本，仅实现共同接口下的相应更新规则，原系统可能有未经适配的优势组件未纳入；对比脚本未公开供审查（仅提及项目页面）。

## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作中展现出巨大潜力，但现有模型大多依赖2D视觉-语言骨干网络，缺乏对目标物体的细粒度3D理解，尤其是在遮挡、姿态变化、尺度变化及精确空间交互场景下。我们提出了一种基于π0的面向对象的3D表示对齐框架，使用SAM3D作为冻结的3D教师，在训练期间提供目标物体的3D先验。具体而言，我们利用物体识别模型定位任务相关对象，生成相应的对象掩码，并使用SAM3D提取密集的物体级3D表示，将其与π0的中间视觉特征对齐。这使得策略能够在保留原始RGB-语言到动作推理流程的同时内化目标物体的3D信息，而无需在测试时使用深度、点云、掩码、SAM3D或额外的3D模块。仿真实验显示了一致的改进，在LIBERO上达到99.1\%的准确率，在CALVIN上平均任务长度为4.11。真实世界实验进一步表明，我们的方法在机器人需跨多个子任务关注不同目标物体的长时程操作场景中尤为有效。

## Abstract
Vision-Language-Action (VLA) models have shown strong potential for general robot manipulation, but most existing models rely on 2D visual-language backbones and lack fine-grained 3D understanding of target objects, especially under occlusion, pose variation, scale changes, and precise spatial interaction. We propose an object-centric 3D representation alignment framework built upon $π_0$, using SAM3D as a frozen 3D teacher to provide target-object 3D priors during training. Specifically, we localize task-relevant objects with object recognition models, generate corresponding object masks, and use SAM3D to extract dense object-level 3D representations, which are aligned with intermediate visual features of $π_0$. This enables the policy to internalize target-object 3D information while preserving the original RGB-language-to-action inference pipeline without requiring depth, point clouds, masks, SAM3D, or additional 3D modules at test time. Simulation experiments show consistent improvements, achieving 99.1\% on LIBERO and an average length of 4.11 on CALVIN. Real-world experiments further demonstrate that our method is particularly effective in long-horizon manipulation scenarios where the robot must focus on different target objects across multiple subtasks.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：现有视觉-语言-动作（VLA）模型大多依赖 2D RGB 图像作为视觉输入，缺乏对目标物体的细粒度 3D 理解（如形状、姿态、尺度、空间布局等），导致在遮挡、姿态变化、物体尺度变化、场景杂乱、以及需要精确空间交互的操作任务上表现不佳。
- **研究背景**：
  - VLA 模型通过预训练的视觉-语言骨干为机器人操作提供通用能力，但主流方法仍以 2D 图像为主。
  - 已有增强 3D 信息的方法要么需要显式 3D 输入（如深度图、点云、RGB-D），在测试时改变原始输入输出接口；要么注入的是场景级全局空间信息而非目标物体级信息。
  - 视觉接地（visual grounding）方法虽能改善目标区域注意力，但其监督仍停留在 2D 图像空间，未提供目标物体的 3D 形状或布局先验。
- **核心研究问题**：能否在保持 RGB-语言到动作的原始推理流程不变的前提下，向 VLA 策略注入目标物体的 3D 知识？

## 2. 论文提出的方法论

- **整体框架**：提出 **SAM3D-VLA**，基于 π0 架构构建，以**冻结的 SAM3D 作为 3D 教师模型**，在训练期间提取目标物体的 3D 特征并与 π0 的中间视觉特征对齐；推理时完全保持 π0 原始 RGB-语言到动作流程，**不需要深度图、点云、掩码、SAM3D 或任何额外 3D 模块**。

- **关键技术步骤**：
  1. **目标物体定位与掩码生成**：利用 Grounding DINO / YOLO 等开放词汇检测模型定位任务相关物体，再用 SAM2 分割生成物体掩码。
  2. **长时程任务分解**：通过 LLM（如 GPT-4o）将高层指令分解为子任务，每个子任务关联对应的目标物体，提供分段（stage-specific）的 3D 监督。
  3. **SAM3D 教师特征提取**：将多视角图像展平为单位视角的图像-掩码对，输入冻结的 SAM3D 模型，提取密集的物体级 3D 特征（包含形状、表面结构、空间布局等几何先验）。
  4. **特征空间对齐**：
     - 将 SAM3D 教师 token 序列重塑为 2D 特征网格，通过双线性插值调整到学生视觉 token 的分辨率，实现逐 token 空间对应。
     - 从 π0 的 Gemma Transformer 选定层中提取中间视觉特征，通过投影层将其映射到 SAM3D 特征空间。
     - 使用掩码归一化 MSE 损失（masked normalized MSE）仅对目标物体区域的 token 进行对齐：
       $$L_{\text{align}} = \text{MSE}\left(\text{Norm}(\hat{T}_t)[M_t],\; \text{Norm}(\bar{T}_t)[M_t]\right)$$
     - 总训练损失：$L = L_{\text{action}} + \alpha L_{\text{align}}$，其中 $L_{\text{action}}$ 为 π0 的 flow matching 动作生成损失。
  5. **冻结表示探针（Frozen-representation Probing）**：训练完成后冻结整个 VLA 骨干，仅训练一个轻量两层 MLP 探针，用于从 VLA 中间特征预测 SAM3D 特征，以验证 3D 先验是否真正被编码进了 VLA 表示中。

- **核心设计特点**：教师模块仅在训练阶段使用；推理阶段完全透明（overhead-free），策略输入输出接口与 π0 完全一致。

## 3. 实验设计：数据集、基准与对比方法

- **LIBERO 仿真基准**（4 个任务套件：Spatial / Object / Goal / Long，每套 10 个任务）：
  - 对比 2D VLA 方法：Diffusion Policy、Octo、OpenVLA、Dita、CoT-VLA、π0、UniVLA、OpenVLA-OFT。
  - 对比显式 3D VLA 方法：SpatialVLA、GeoVLA、3D-CAVLA。
  - 对比隐式 3D VLA 方法：Spatial Forcing。
  - **结果**：SAM3D-VLA 平均成功率 99.1%，其中 Long 任务 98.4%，均优于所有对比方法；Spatial 上略低于 Spatial Forcing（99.2% vs 99.4%），Object 上略低于 3D-CAVLA（99.7% vs 99.8%）。

- **CALVIN 仿真基准**（ABC→D 设置，5 个子任务的顺序长时程操作）：
  - 对比生成式方法：UniPi、SuSIE、GR-1、VidMan、CLOVER。
  - 对比大型 VLA 模型：VLAS、RoboFlamingo、OpenVLA、UniVLA。
  - 对比物体中心方法：ReconVLA。
  - **结果**：平均任务长度 4.11，第 5 子任务成功率 71.6%，均为最佳。

- **真实世界实验**（Piper-X 双机械臂移动平台）：
  - 三个基本任务：叠碗、挂杯、开抽屉。
  - 三个长时程任务：烹饪（制作三明治）、插花、叠块。
  - 每种任务在**标准设置（ST）**和**遮挡设置（OC）**（改变物体位置、加入干扰物、部分遮挡）下评估。
  - 对比 π0 基线。
  - **结果**：ST 下平均成功率从 50.2% 提升到 65.2%；OC 下从 21.3% 提升到 44.3%；长时程任务提升尤为显著。

- **机制验证实验**：冻结表示探针实验，对比原始 π0 与 SAM3D-VLA 在相同探针结构下从 VLA 特征中恢复 SAM3D 3D 特征的能力。

## 6. 主要结论与发现

1. **物体中心 3D 先验是有效的**：通过训练时将 SAM3D 的物体级 3D 特征对齐到 VLA 中间表示，可显著提升策略的操作能力，尤其在长时程、物体中心理解要求高的场景中。
2. **推理流程零开销**：所有 3D 数据生成和对齐模块仅在训练时使用，推理时保持 π0 原始 RGB-语言到动作流程，不引入额外感知模块或输入。
3. **长时程任务提升最为显著**：在 LIBERO-Long 上达到 98.4%；CALVIN 的 5/5 成功率 71.6%（对比 π0 和 ReconVLA 等基线有明显优势）；真实世界长时程任务在标准设置和遮挡设置下均大幅超过 π0。
4. **机制验证成立**：冻结表示探针实验表明，SAM3D-VLA 学到的 VLA 特征能更准确地恢复 SAM3D 3D 目标表示，说明 3D 先验确实被编码进了策略表示中。

## 7. 优点

- **设计轻量且部署友好**：训练时的 3D 知识注入不改变测试时输入输出接口，避免了显式 3D 观测方法在部署中的传感器依赖和计算开销。
- **物体中心视角**：不同于多数 3D 增强方法仅关注场景级全局空间信息，SAM3D-VLA 聚焦目标物体级 3D 特征，与操作任务的核心需求更匹配。
- **长时程任务的多阶段监督**：子任务分解 + 各阶段对应目标物体掩码的设计，为跨子任务切换目标提供了分段式 3D 先验，契合长时程操作的实际需求。
- **机制可解释性**：冻结表示探针实验为"3D 知识是否真正进入表示"提供了直接证据，而非仅依赖下游任务指标的间接推断。
- **方法可迁移性**：作者指出该对齐框架不限于 π0，可推广到其他 VLA 骨干架构。

## 8. 不足与局限

- **对自动标注质量的依赖**：训练流程依赖自动子任务分解、物体检测、分割结果，任一环节的误差都会引入噪声监督，可能对最终策略产生负面影响。
- **SAM3D 自身局限**：SAM3D 仅在单张图像上操作，在严重遮挡、透明物体、不理想视角等情况下可靠性受限，增加了训练噪声。
- **真实世界评估覆盖面有限**：仅在单一机器人平台（Piper-X）和桌面级任务上进行了真机验证，缺乏多种机器人形态、非桌面操作、动态环境下的验证。
- **缺乏消融实验**：未量化各组件（子任务分解、对齐层选择、对齐损失权重 α、掩码质量等）的贡献，也缺少对超参数敏感性的分析。
- **统计严谨性不足**：未报告多次运行的标准差/置信区间，也未提供真实世界实验的尝试次数，改进步进的显著性难以判断。
- **基准对比略有局限**：LIBERO / CALVIN 上的部分对比结果引用自其他论文，未统一实验条件（如训练数据版本、模型大小、预训练权重等），可能引入公平性问题。

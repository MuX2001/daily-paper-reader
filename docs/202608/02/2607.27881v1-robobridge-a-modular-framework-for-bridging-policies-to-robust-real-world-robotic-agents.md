## 摘要
视觉-语言-动作（VLA）模型作为一种可扩展的机器人操作方法引起了越来越多的关注。虽然这些模型是有效的动作预测器，但将它们部署为机器人代理时暴露了关键差距：没有故障恢复机制，长时间跨度下执行不一致，以及对观察、任务或实体变化的鲁棒性有限。现有解决方案通过模型重训练或特定于环境的模块来分别解决这些局限性，但所需的是一个通用框架，能够系统地将预训练的VLA转化为机器人代理。我们提出了RoboBRIDGE，一个模块化框架，提供对五个协调模块（即Monitor、Perceptor、Planner、Controller和Robot Interface）的编排层，以从现成组件（包括预训练的VLA）组合出鲁棒的机器人代理。Monitor将快速故障检测与分层恢复相结合，在错误级联之前纠正错误。当环境偏离当前计划时，Planner触发重新规划，而Perceptor异步更新场景理解，避免执行停顿。在Controller内部，原始技能微调将操作分解为具有专用LoRA适配器的领域不变原始技能，从而降低使用VLA时对领域偏移的敏感性。在LIBERO、RoboCasa以及跨越多个机器人平台和VLA骨干的真实世界案例研究中，RoboBRIDGE始终优于独立策略和先前增强的VLA部署。这些结果表明，可靠的机器人代理能力并非仅来自扩展动作预测器，而是来自围绕它们的结构化编排。

## Abstract
Vision-Language-Action (VLA) models have attracted growing interest as a scalable approach to robotic manipulation. While these models are effective action predictors, deploying them as robotic agents exposes critical gaps: no mechanism for failure recovery, inconsistent execution over long horizons, and limited robustness to shifts in observations, tasks, or embodiments. Existing solutions address these limitations individually through model retraining or environment-specific modules, yet what is needed is a general framework that systematically transforms a pretrained VLA into a robotic agent. We present RoboBRIDGE, a modular framework that provides an orchestration layer over five coordinated modules, namely Monitor, Perceptor, Planner, Controller, and Robot Interface, to compose robust robotic agents from off-the-shelf components, including pretrained VLAs. The Monitor pairs rapid failure detection with hierarchical recovery to correct errors before they cascade. When the environment diverges from the current plan, the Planner triggers replanning while the Perceptor updates scene understanding asynchronously, avoiding execution stalls. Within the Controller, primitive skill fine-tuning factors manipulation into domain-invariant primitives with dedicated LoRA adapters, reducing sensitivity to domain shifts when a VLA is used. Across LIBERO, RoboCasa, and real-world case studies spanning multiple robot platforms and VLA backbones, RoboBRIDGE consistently outperforms both standalone policies and prior augmented VLA deployments. These results suggest that reliable robotic agency does not arise from scaling action predictors alone, but from structured orchestration around them.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 整体框架
RoboBRIDGE 由五个协调模块组成，围绕任意动作生成策略（Controller槽位）构建编排层：
- **Perceptor**：将原始感官观测转换为以对象为中心的场景状态（身份、3D位姿、语义属性）。
- **Planner**：接收场景状态和语言指令，将任务分解为有序的原始技能序列。
- **Controller**：动作生成策略的槽位，将每个原始技能翻译为底层动作。
- **Robot Interface**：抽象实体特定的API、时序、安全限制和坐标变换。
- **Monitor**：闭环验证执行结果，检测到故障时触发分层恢复。

### 关键技术一：两阶段监控（Two-phase Monitoring）
- **Phase 1：轻量级成功检查**。成功检查模型D_check周期性地将当前观测o_t与预期计划上下文c_t对比，输出二值成功标志和置信度。采用约束输出格式抑制扩展推理，运行频率约5Hz，不阻塞控制循环。
- **Phase 2：故障诊断与恢复**。当检测到失败且置信度≥γ_thresh时，系统立即停机，调用诊断模型D_diag推断根因并选择恢复目标r_t，映射到四层分层恢复策略（按重计算范围递增）：
  1. **retry**：重新执行当前原始技能；
  2. **re-generate**：保留当前计划和感知状态，重新生成轨迹；
  3. **replan**：基于最新异步感知结果重新规划；
  4. **re-perceive**：在重规划前强制全面重新感知。

### 关键技术二：异步感知的反应式规划（Reactive Planning with Asynchronous Perception）
- **异步感知**：采用生产者-消费者架构，感知线程持续更新线程安全缓冲区B中的最新检测结果；执行线程运行原始技能序列，两者并行。
- **发散度计算**：执行完每个原始技能后，比较当前计划使用的感知快照与最新感知结果，发散度公式为：
  Δ(ō_a, ō_b) = max_{i∈O_a∩O_b} ‖p_a^(i) − p_b^(i)‖₂ + λ·|O_a △ O_b|
  其中p^(i)为对象i的3D位置，△为对称集合差，λ为权重。
- **触发重规划**：当Δ(ō_plan, ō_lat) ≥ τ时，保留高层动作序列（如PICK→PLACE），仅基于最新观测重新生成当前及后续的原始技能参数。避免冗余的高层推理，同时反映当前场景状态。

### 关键技术三：原始技能微调（Primitive Skill Fine-tuning）
- **核心思想**：将操作分解为域不变原始技能集合 P = {MOVE, GRIP, ROTATE, ...}，每个原语对应一个专用的LoRA适配器，而非用VLA的单一权重集处理所有操作阶段。
- **原语专用LoRA适配器**：在冻结的VLA骨干f_θ上附加轻量LoRA模块∆θ_k，每个适配器在筛选出的对应原语演示数据上训练：
  f_(θ+∆θ_k) : (i, s_t, p_t) → a_t^(k)
- **控制器切换**：两层级联解析器根据当前原始技能选择对应适配器；若不存在则回退到所有注册LoRA的平均：
  RESOLVE(p_t) = ∆θ_pt（若存在），否则 (1/|P|)Σ∆θ_p
- **动作生成与执行**：预测7自由度增量动作 a_t = (δx, δφ, g)；可通过笛卡尔速度命令（u_t = (1/Δt)(δx, δφ)）或IK求解（x_ee^(t+1) = x_ee^t + δx, q* = IK(...)）两种路径执行，灵活适配不同机器人的运动学接口。
- **算法流程**：Algorithm 1 完整描述了从环境重置→初始感知→计划→异步感知→逐原语执行→监控与恢复→发散检测与重规划的完整管道。

## 6. 论文的主要结论与发现

- **RoboBRIDGE在LIBERO上将平均成功率从35.5%提升至39.7%，在RoboCasa上从3.7%提升至7.5%（排除PnP任务后从6.2%提升至11.4%）**，且对所有三个VLA骨干均产生一致改善，其中GR00T-N1.5提升最显著（+5.6个百分点）。
- **规划与监控缺一不可**：无监控时所有LLM骨干表现集中在1.8-8.0%的窄区间；启用监控后Claude Opus 4.6达到14.7%（+8.1%），而小模型（如Gemini-3 Flash）提升几乎可忽略，说明有效的故障诊断需要充分的推理能力。
- **LoRA微调 + RoboBRIDGE（27.1%）接近独立全量微调（31.9%）的性能**，尽管只更新了远少于全量微调的参数；全量微调在框架内进一步提升至40.0%，说明即使强控制器也能从结构化监控和重规划中获益。
- **IK控制器在框架内达到22.1%**，验证了框架的"政策无关"设计——不仅适用于学习型策略，也适用于经典控制器。
- **CycleVLA仅达7.5%**（无框架），强于"模型内自校正不足以替代外部编排"的观点。
- **两大主导失效模式**：①感知错误——在杂乱、遮挡场景中对象位姿错误导致下游失败；②不可恢复操作失败——接触丰富交互中环境状态被不可逆改变，重试无效。
- **最终结论**：可靠的机器人智能体能力来自围绕动作预测器的结构化编排，而非单纯扩展动作预测模型本身。

## 7. 优点

- **框架级创新**：首次将LLM智能体领域的"编排层"思路系统性地引入VLA机器人部署，提出通用、政策无关的模块化框架，解决了此前各方案碎片化的问题。
- **两阶段监控设计精妙**：先用轻量检查快速排除健康帧，仅在检测到失败时调用昂贵的诊断模型，在延迟和准确性之间取得良好平衡；四层分层恢复策略按重计算成本递增，避免过度恢复。
- **异步感知 + 发散触发重规划**：将感知从执行中解耦到并发线程，既隐藏了感知延迟，又通过简单的几何发散度量避免频繁无谓的重规划，设计优雅且工程上高效。
- **原语技能分解 + LoRA适配器**：将操作分解为域不变原语并分配专用适配器，显著降低跨领域转移时的参数更新需求（LoRA+框架接近全量微调性能），是一种参数高效的鲁棒性增强策略。
- **对比实验设计公正**：固定控制器、训练数据、任务集，仅操作是否在框架内部署，隔离了框架本身的贡献。
- **覆盖多种VLA骨干**：轻量（SmolVLA）、通用（π0.5）、大规模（GR00T-N1.5），增强了结论的泛化性。

## 8. 不足与局限

- **原语词汇有限**：仅覆盖单臂桌面操作行为，接触丰富的交互、可变形物体、双臂任务都需要更丰富的原语和状态表征。
- **监控阈值和恢复规则手动设定**：未能从交互数据中自动学习，限制了对新场景的自动适配能力。
- **可靠性瓶颈明显**：感知错误（遮挡、相似物体混淆）和不可恢复操作失败仍是主导失败模式，RoboCasa中大量任务的成功率仍为0%。
- **缺少验证与安全停止机制**：框架缺少"可行评估"层来判断当前控制器是否可能成功，浪费步骤在徒劳的重试上。
- **真实世界实验充分性不足**：仅以定性案例（图5）呈现，缺少系统化的成功率统计、多试次重复、跨环境定量对比，削弱了"真实世界鲁棒性"声明的证据力度。

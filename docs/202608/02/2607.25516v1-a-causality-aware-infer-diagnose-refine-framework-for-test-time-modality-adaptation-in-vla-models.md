## 摘要
视觉-语言-动作（VLA）模型根据语言指令，结合视觉观察和本体感觉状态，预测顺序动作以执行任务。然而，如何在VLA模型中融合模态仍然是一个开放问题，因为机器人操作涉及动态阶段，例如长距离移动和近距离交互，其中视觉观察的重要性可能随时间变化。本文提出了一种推断-诊断-精炼（IDR）框架，这是一种与多种VLA架构兼容的模型无关框架，用于在测试时精炼动作预测。IDR首先在视觉观察的事实和反事实场景下推断动作，然后诊断视觉观察的因果效应作为估计的动态重要性，最终以无需训练的方式用于精炼动作预测。我们进一步设计了一个因果感知动作精炼器来实现IDR框架，包括用于推断反事实动作的零填充干预、用于诊断因果效应的基于范数的量化，以及用于精炼动作的门控残差融合。在模拟基准和真实世界任务上的大量实验表明，在多个VLA骨干网络上整体性能均有提升，证明了在测试时动态调整视觉重要性的有效性。

## Abstract
Vision-language-action (VLA) models predict sequential actions to execute tasks specified by language instructions, conditioned on visual observations and proprioceptive states. However, how to fuse modalities in VLA models remains an open problem, since robot manipulation involves dynamic phases, such as long-distance movements and close-range interactions, in which the importance of visual observations may vary over time. In this paper, we propose an infer-diagnose-refine (IDR) framework, a model-agnostic framework that can be integrated with diverse VLA architectures for refining action predictions at test time. IDR first infers actions under factual and counterfactual scenarios of visual observations, and then diagnoses the causal effects of visual observations as the estimated dynamic importance, which is finally used to refine the action predictions in a training-free manner. We further design a causality-aware action refiner to realize the IDR framework, including zero-padding interventions for inferring counterfactual actions, norm-based quantification for diagnosing causal effects, and gated residual fusion for refining actions. Extensive experiments on both simulation benchmarks and real-world tasks show improvements in overall performance across multiple VLA backbones, demonstrating the efficacy of dynamically adjusting visual importance at test time.

## 2. 论文提出的方法论

**核心思想**：将视觉观察的动态重要性形式化为其对动作预测的因果效应，通过比较事实场景与反事实场景下的模型输出，诊断模态特有贡献，并据此精炼动作。

**技术实现**（三个阶段的流程）：

- **Infer（推断）阶段——零填充干预**：用零张量分别替换视觉输入 `do(V=0v)` 和本体感觉输入 `do(S=0s)`，计算反事实动作：
  - 事实动作：`abase,t = πθ*(vt, st, l)`
  - 视觉反事实：`ano_img,t = πθ*(0v, st, l)`
  - 本体反事实：`ano_prop,t = πθ*(vt, 0s, l)`

- **Diagnose（诊断）阶段——范数量化**：计算因果效应偏差向量 `Δimg,t = abase,t − ano_img,t`、`Δprop,t = abase,t − ano_prop,t`，并用 L2 范数量化其大小 `Eimg,t = ||Δimg,t||2`、`Eprop,t = ||Δprop,t||2`。较大的 `Eimg,t` 表示该时刻模型对视觉依赖较强。

- **Refine（精炼）阶段——门控残差融合**：
  - 门控机制：`gt = I[Eimg,t < τ]`，当视觉因果效应低于阈值 τ 时激活门控，补偿被抑制的视觉信号；
  - 有界正则器：`wprop,t = β·min(1, Eprop,t/(Eimg,t + ε))` + 裁剪 `clip(Δprop,t, −λ, λ)`，用于限制低频控制抖动；
  - 最终输出：`afinal,t = abase,t + gt·(α·Δimg,t + wprop,t·uprop,t)`。

## 6. 论文的主要结论与发现

- **观察 1**：环境会改变视觉重要性模式。同一模型 X-VLA 在 LIBERO 中是本体感觉主导，在 Google SIMPLER 中则变为视觉主导；
- **观察 2**：模型架构塑造不同的视觉重要性模式。π0.5、VLA-Adapter、OpenVLA-OFT 偏向视觉主导，X-VLA 偏向本体感觉主导；
- **观察 3**：操作阶段影响视觉重要性。任务执行中视觉重要性随夹爪开合等事件动态变化；
- **核心验证**：IDR 在 LIBERO 上提升 4 个骨干的性能（+0.45% 到 +1.40%），SIMPLER 上在 Variant Aggregation 设置中提升 +6.33%，CALVIN 上平均完成子任务数从 4.22 提升至 4.44；
- **真实世界**：平均成功率从 56.5% 提升至 75.3%（+18.8%），成功试验的平均完成时间从 53.6s 降至 41.5s；Organize Table 长时任务中 5/5 完成率从 0% 升至 33.3%；
- **重要发现**：对于本体感觉主导的 X-VLA，用本体感觉偏差作为精炼信号会导致性能骤降（96.05% → 77.35%），而视觉偏差仍有效，表明视觉和本体感觉的因果效应具有不对称性。

## 7. 优点

1. **模型无关且无需训练**：IDR 是即插即用的框架，可与多种 VLA 架构直接集成，无需微调或重训练；
2. **因果推断视角**：将视觉重要性建模为因果效应而非静态属性，理论框架清晰，具备较强的解释性；
3. **门控残差设计的合理性**：选择性门控（仅低视觉因果效应时激活）避免了对正常执行的无谓干预，裁剪和有界正则器限制了控制扰动，兼顾了改善效果与执行稳定性；
4. **动态适应能力**：在测试时逐时间步估计视觉重要性，能够捕捉任务阶段转换附近的模态依赖变化；
5. **实验覆盖较广**：仿真 + 真实世界 + 多项消融，从多个维度验证了方法的有效性，尤其是在分布偏移（SIMPLER）和长时域（CALVIN、Organize Table）场景中也有明显增益；
6. **与现有 VLA 生态兼容**：基于公开权重和官方评估协议，易于复现和推广。

## 8. 不足与局限

1. **推理开销**：每个控制步需要三次前向传播，增加测试时计算成本。论文虽指出可在真实世界中部分抵消，但未定量报告推理延迟的具体增加幅度；
2. **超参数敏感性与选择依据不足**：α（视觉精炼强度）、τ（干预阈值）、β 和 λ 均需经验设定，τ 设定与基线模型的平均因果效应相关，但跨模型/环境迁移时是否需要重新调整未充分讨论；
3. **统计显著性缺乏**：多数实验结果未报告多次运行的标准差，无法判断改进幅度的稳定性；
4. **真实世界实验规模有限**：部分任务只有少量试验次数（如 Organize Table 仅 6 次试验，Sweep Trash 仅 16 次），统计功效较低；
5. **模态不对称性的解释深度不足**：论文发现了视觉和本体感觉因果效应的不对称性（X-VLA 本体引导导致严重退化），但对其机理只给出初步猜测（视觉与任务级校正、本体与低层控制耦合），缺乏进一步验证；
6. **适用范围限制**：依赖 VLA 模型本身具备一定的视觉利用能力；若模型的视觉编码器已在训练中被严重忽视，IDR 的效果可能受限。

## 摘要
大型预训练的视觉-语言-动作模型主导着现代机器人操作基准测试，但目前尚不清楚强语言条件控制需要多大的模型规模，或者根本不同的控制架构是否能在更小的参数预算下保持竞争力。我们提出了PredVLA，一种语言条件预测编码策略，仅拥有68万个可训练网络参数，且无需机器人数据预训练，其分层生成式循环动力学预测视觉特征和本体感觉，而观测仅通过由此产生的感官预测误差的在线推理影响潜在状态。在LIBERO上，PredVLA在三个短视界套件中平均成功率达86.9%，在包含长视界套件时达到75.4%。在使用相同冻结前端、演示、动作解码器和评估协议的受控比较中，PredVLA的平均成功率分别是参数匹配的Transformer和LSTM策略的3.7倍和7.4倍。预测编码公式还使观测驱动校正的贡献可直接测量：由于观测仅通过基于预测误差的潜在推理影响循环状态，禁用该推理便得到一个精确的开环控制条件。总而言之，这些结果表明，一个亚百万参数的循环生成策略能够在现代语言条件操作基准上实现强劲性能，同时为预测误差驱动的在线状态校正提供显式机制。

## Abstract
Large pretrained vision-language-action models dominate modern robot-manipulation benchmarks, but it remains unclear how much model scale is necessary for strong language-conditioned control, or whether fundamentally different control architectures can remain competitive at much smaller parameter budgets. We present PredVLA, a language-conditioned predictive-coding policy with only 0.68 million trainable network parameters and no robot-data pretraining, whose hierarchical generative recurrent dynamics predict visual features and proprioception while observations influence latent state only through online inference from the resulting sensory prediction errors. On LIBERO, PredVLA achieves an 86.9% mean success rate across the three short-horizon suites and 75.4% when the long-horizon suite is included. Under a controlled comparison using the same frozen front end, demonstrations, action decoder, and evaluation protocol, PredVLA achieves 3.7x and 7.4x mean success rates of parameter-matched Transformer and LSTM policies, respectively. The predictive-coding formulation also makes the contribution of observation-driven correction directly measurable: because observations influence the recurrent state only through prediction-error-based latent inference, disabling this inference yields an exact open-loop control condition. Together, these results show that a sub-million-parameter recurrent generative policy can achieve strong performance on modern language-conditioned manipulation benchmarks while providing an explicit mechanism for prediction-error-driven online state correction.

## 1. 论文的核心问题与整体含义

- **研究动机**：大型预训练视觉-语言-动作（VLA）模型（如 RT-1/RT-2、Octo、OpenVLA、π0 等）在机器人操作基准上表现优异，但动辄数十亿参数带来了高昂的训练、适配和部署成本。近年虽有 TinyVLA、SmolVLA、Evo-1 等紧凑型 VLA 模型，但参数规模仍在数亿量级。
- **核心问题**：强语言条件化控制是否真的需要如此大规模的模型？能否通过改变控制架构本身，而非单纯压缩大规模 VLA，在远小于百万参数的预算下实现强性能？
- **整体含义**：论文通过设计一个仅含 0.68M 可训练参数的预测编码（Predictive-Coding）循环生成策略，在 LIBERO 基准上达到了与大规模 VLA 模型相当的性能水平，证明了"强语言条件化操作不必然依赖大规模参数"这一核心命题，并为预测误差驱动的在线状态修正提供了一种显式且可精确测量的机制。

## 2. 论文提出的方法论

### 2.1 核心思想

- **预测编码范式**：在预测编码循环模型中，内部生成动力学预测感官轨迹，而潜在状态通过最小化预测与观测之间差异（即预测误差）进行在线推断，而非将观测直接馈入循环动力学。PredVLA 继承 PV-RNN 的自由能最小化框架，将视觉、本体感觉观测仅通过预测误差反向传播来影响隐状态。
- **观测不直接进入循环**：感官观测只出现在自由能目标函数中，不参与循环前向传播，这与传统"观测→编码→循环网络"的范式形成本质区别。

### 2.2 架构组成

- **冻结前端（Frozen Front End）** ：
  - 语言：all-MiniLM-L6-v2 预训练句子编码器 + 固定 PCA 投影（384→64 维）。
  - 视觉：双摄像头（第三视角 + 腕部视角）分别用冻结的 ImageNet 预训练 ResNet18 编码，再经固定 PCA 投影后拼接（每摄像机 512→96 维，拼接为 192 维）。
  - 本体感觉：9 维关节角 + 夹爪状态，不经编码器直接使用。
- **可训练循环控制器**（675,732 参数）：
  - 4 个循环模块：顶层共享模块 T、视觉分支 V、动作分支 A_top 和 A_bottom。
  - 层次化时间常数：τ(T,V,A_top,A_bottom) = (16,8,5,2)（短时域）；长时域套件加宽为 (30,14,8,2)。
  - 每个模块维护确定性状态 h、输出 d = tanh(h)、自由变量 c。
  - 顶层模块接收语言信号（W_lang·l），语言一次性编码并贯穿整个回合。
  - 侧向通路：V→A_top 的低维视觉-动作瓶颈（bottleneck）和 A→V 的传出拷贝（efference copy，携带模型自身对先前动作/本体感觉的预测而非真实测量）。
  - 解码器：从 d_V 解码视觉预测，从 d_A_bottom 解码本体感觉预测和 K=5 分量的对角高斯混合动作分布。

### 2.3 自由能与训练

- **自由能目标**（公式 7-9）：视觉预测误差 + 本体感觉预测误差（按维度归一化）+ 后验自由变量相对先验的二次复杂度惩罚项。
- **训练目标**（公式 10）：自由能 + 示范动作的负对数似然（NLL），后验自由变量作为模型参数与网络权重联合优化，训练后丢弃，不参与部署。

### 2.4 在线推断（误差回归）

- 测试时网络权重冻结，仅优化滑动窗口（W=40 步）内的后验自由变量，进行 n_itr=10 次 Adam 优化（学习率 0.05，复杂度权重 w_ER=1.0），每次更新后重新生成窗口内的确定性状态，保证状态轨迹与学习到的循环动力学一致。
- **精确开环控制**：令 n_itr=0 即完全禁用误差回归，后验等于先验，感官观测完全不进入循环前向计算，提供了无需重训练或修改语言条件化的精确开环对照。

## 6. 论文的主要结论与发现

- **主结果**：PredVLA 以 675,732 个可训练参数（无机器人数据预训练）在 LIBERO 上达到 86.94% 三短时域套件均值、75.35% 四套件均值。
- **受控对比**：三套件均值分别是参数匹配 Transformer（19.73）的约 3.7 倍和 LSTM（10.26）的约 7.4 倍；也显著优于动作分块 Transformer 变体（16.70/3.44）。
- **消融结论**：
  - 时间层次贡献最大且跨套件一致（去除后下降 17-29 个百分点）。
  - 视觉→动作瓶颈对 SPATIAL/GOAL 重要但对 OBJECT 无影响；传出拷贝影响较弱且依赖套件。
  - 在线误差回归改善全部四个套件（下降 6.44-12.57 个百分点），长时域套件受益最大。
  - 感官通道贡献高度任务依赖：OBJECT 对本体感觉误差敏感（去除后下降 14.17 点），而视觉误差贡献相对有限；感官扰动实验显示本体感觉扰动远更致命。
- **概念性发现**：n_itr=0 的精确开环对照表明，短时域套件中大部分行为可由学习到的循环动力学单独生成，但闭环修正对长时域任务至关重要。

## 7. 优点

- **架构创新性**：以预测编码替代主流"观测直接输入"范式，将观测严格限制在自由能目标的误差项中，实现了一种理论上优雅且具有神经科学基础的控制器设计。
- **极致的参数效率**：在亚百万参数（0.68M）且无机器人数据预训练的条件下达到与 7B 模型可比的 LIBERO 成绩，挑战了"规模至上"的主流认知。
- **可解释性与可测量性**：观测对隐状态的影响路径唯一（仅通过误差回归），因此可以精确地开/关闭环修正、单独去除某个感官误差通道、扰动某一感官输入，无需重训练即可量化各机制贡献，这在现有 VLA 工作中极为罕见。
- **受控对比严谨**：严格匹配前端、数据、解码器和评估协议；配对种子统计；同时对基线给予更多训练步数和学习率调优，避免了对自身的偏袒。
- **任务级分析**：Figure 3 揭示套件聚合值下的任务级差异，提供了更丰富的行为学洞见。
- **部署效能**:21.6 Hz 的端到端频率（含在线推断）表明实时部署可行。

## 8. 不足与局限

- **仿真局限**:仅在 LIBERO 仿真中评估，无真实机器人验证；对观测噪声、分布偏移、环境扰动等真实场景挑战缺乏鲁棒性测试。
- **任务覆盖窄**:单一仿真形态、单一基准、单一任务分布；每套件单独训练，未验证多任务联合训练或跨套件泛化。
- **长时域能力薄弱**: LONG 套件仅 40.57%，显著低于短时域套件，说明当前紧凑架构在长时域推理与长期依赖建模方面存在明显瓶颈。
- **消融不完整性**: 各消融仅做单一条件的去除，未探索组件之间交互效应（如同时去掉两个侧向通路、联合去除时间层次与误差回归）；部分消融条件（A4/A5/A6）之间未进行直接统计比较（如 A5 的 -14.17 与 A6 的 -12.17 之间），作者也承认应作描述性解读。
- **参数匹配但架构差异**: 基线 Transformer/LSTM 虽参数匹配，但可能未能充分调优（如更长的训练、更优的 Transformer 深度/宽度配置），存在一定"隐含的不公平"风险；动作分块基线仅 2 种 chunk 长度，覆盖有限。
- **前端依赖**: 依赖冻结的 ResNet18 + MiniLM 前端，前端表征能力可能成为性能上限的约束；PCA 降维虽高效但可能丢弃细粒度视觉信息。
- **算力透明度不足**: 未报告训练 GPU 型号、数量和总训练时间，难以对"计算效率"主张进行完整量化验证。
- **泛化性存疑**: 无跨训练/测试分布评估、无跨形态验证、无对新任务或新场景的零样本适应实验；概率性动作分布与简单均值解码策略可能限制了动作表达力。

> 总体而言，PredVLA 的核心贡献在于以严格的受控实验证明了一个此前被视为不可能的操作点——亚百万参数的循环生成控制器也能在标准 VLA 基准上与大规模模型竞争——并提供了一个方法论上优雅的机制（可精确开关的预测误差驱动在线推断）用于理解闭环控制在语言条件化操作中的作用。其局限主要体现在仿真/单一形态覆盖、长时域性能和算力图谱透明度方面。

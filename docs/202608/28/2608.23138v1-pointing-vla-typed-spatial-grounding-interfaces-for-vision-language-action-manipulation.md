## 摘要
视觉-语言-动作（VLA）模型通常通过自回归文本坐标或不透明的动作令牌来暴露空间接地，从而在多模态推理与机器人执行之间形成脆弱的接口。我们提出了Pointing-VLA，一种构建在Embodied-R1之上的类型化隐藏状态空间读出机制。几何专用头预测归一化点、物体功能接地（OFG）热图以及视觉轨迹，而无需将几何序列化为文本。在评估的Bridge/WidowX和物理拾取-放置部署中，一个明确的执行契约将PICK分配给源条件OFG，将PLACE分配给Pointing，提供直接的阶段对齐空间目标。Pointing-VLA在Bridge/WidowX上实现了最先进的性能，在启用碰撞的CuRobo执行下，无需Bridge特定微调，在评估的四任务集上平均达到72.9%。Pointing和OFG在原生和跨数据集评估中显示出互补优势。OFG/接触读出可迁移至NORA-1.5，在保持或提升成功率的同时，将记录的控制时间减少20倍以上；类型化头在共享外部套件上的速度也比Embodied-R1文本解码快6.68–6.90倍。当作为π₀.₅动作策略的空间指导集成时，Pointing-VLA在三种视觉场景中将自主真实机器人成功率从52.7%提升至80.7%。这些结果确立了类型化空间读出作为具身推理与机器人执行之间高效、可检查接口的有效性。

## Abstract
Vision-language-action (VLA) models often expose spatial grounding through autoregressive text coordinates or opaque action tokens, creating brittle interfaces between multimodal reasoning and robot execution. We present Pointing-VLA, a typed hidden-state spatial readout built on Embodied-R1. Geometry-specific heads predict normalized points, object-functional grounding (OFG) heatmaps, and visual trajectories without serializing geometry as text. For the evaluated Bridge/WidowX and physical pick-place deployments, an explicit execution contract assigns PICK to source-conditioned OFG and PLACE to Pointing, providing direct stage-aligned spatial targets. Pointing-VLA achieves SOTA performance on Bridge/WidowX, averaging 72.9\% across the evaluated four-task set without Bridge-specific finetuning under collision-enabled CuRobo execution. Pointing and OFG show complementary strengths across native and cross-dataset evaluations. The OFG/contact readout transfers to NORA-1.5, preserving or improving success while reducing recorded controller time by more than 20$\times$; typed heads are also 6.68--6.90$\times$ faster than Embodied-R1 text decoding on a shared external suite. When integrated as spatial guidance for a $π_{0.5}$ action policy, Pointing-VLA raises autonomous real-robot success from 52.7\% to 80.7\% across three visual contexts. These results establish typed spatial readouts as an efficient, inspectable interface between embodied reasoning and robot execution.

## 1. 核心问题与整体含义

### 研究动机
- 现有视觉-语言-动作（VLA）模型存在**输出接口瓶颈**：空间接地（spatial grounding）要么通过自回归文本坐标输出（如"[222, 172]"），要么通过不透明的动作令牌输出。
- **文本坐标接口的缺陷**：
  - 模型需花费大量令牌生成数字，几何信息成为"事后思考"；
  - 评估方需将字符串解析回像素坐标，增加执行依赖；
  - 密集的部分级证据（part-level evidence）在到达执行器前被丢弃；
  - 可能出现两种失败：生成无法解析的坐标，或生成语法有效但空间错误（落在目标区域之外）的坐标。
- **动作令牌接口的缺陷**：虽避免了解析，但隐藏了机器人栈或人类审计员可能需要检查的空间推理依据。
- **核心论断**：具身接地（embodied grounding）应被视为**类型化接口预测**（typed interface prediction），而非文本坐标生成——指称点、功能区域和视觉轨迹是相关但不同的几何目标，不应被折叠为单一输出分布或序列化为文本。

### 整体含义
- 论文受神经科学中"视觉-行动双通路"（Goodale & Milner 1992; Andersen & Buneo 2002; Cisek 2007）的启发，主张下游读出器应从分布式内部活动中解码空间变量，而非通过表征它们的系统进行序列化。
- 该工作为VLA模型与机器人执行之间提供了一种**高效、可检查、几何保真的接口范式**。

## 2. 方法论

### 核心思想
Pointing-VLA基于Embodied-R1骨干网络，构建**类型化隐藏状态空间读出**（typed hidden-state spatial readout）——从多模态隐藏状态中直接解码几何专用目标，而非要求骨干网络"说出"坐标。

### 技术架构与关键细节

**（1）隐藏状态空间读出（Hidden-State Spatial Readout）**
- 设`e ∈ {pt, ofg, vtg}`索引空间专家，`H^e_mm = {h^e_i}`为Embodied-R1多模态状态。
- 所有专家共享同一骨干架构、基础权重和Grounding Adapter主体，但各专家保留自己的LoRA、学习查询和解码器状态。
- 点与OFG专家经适配器投影后用专家特定的任务条件查询读取：
  - `X^e = W^e_h H^e_mm + P^e`
  - `A^e = softmax( (Q^e W^e_Q)(X^e W^e_K)^T / √d )`
  - `G^e = FFN^e(A^e X^e W^e_V)`,  `g^e = Pool(G^e)`
- 点与OFG专家使用8个接地查询；VTG专家则让学习的时间查询直接关注完整多模态序列，避免固定接地令牌瓶颈。

**（2）三个类型化空间头**

- **Pointing头（稀疏点）**：学习指针查询`q_pt`选择接地证据，直接发出归一化坐标：
  ```
  (x̂, ŷ) = σ(W_p LN(z_pt) + b_p) ∈ [0,1]²
  ```
  像素坐标 `(û, v̂) = ((W−1)x̂, (H−1)ŷ)`，用点-in-边界框（PIB）或点-in-掩码（PIM）评估。

- **OFG头（密集功能热图）**：保留空间范围而非折叠为单点。全局接地摘要通过FiLM调制视觉特征图，经卷积热图解码器输出：
  ```
  F'_ofg = γ(g_ofg) ⊙ F_vis + β(g_ofg)
  Ĥ_ofg = f_hm(F'_ofg)
  ```
  峰值`(i*, j*)`为执行面对的接触点。

- **VTG头（视觉轨迹）**：学习的时间方式点查询`q_τ_t`按顺序关注多模态序列，输出8个归一化图像空间方式点`τ̂_t`，用RMSE、ADE、FDE评估。

**（3）固定PICK/PLACE执行契约**
- 确定性分配：**源条件OFG → PICK**（发射功能接触点），**Pointing → PLACE**（发射放置目标点）。
- 外部包装器用校准深度D、相机内参K和相机到机器人变换`T_{r←c}`将图像空间输出转为机器人坐标：
  ```
  X_c = D(û, v̂)K⁻¹p̃
  X̄_r = T_{r←c} X̄_c
  ```

**（4）训练目标**
- 加权空间目标：`L = λ_pt L_pt + λ_box L_box + λ_ofg L_ofg + λ_vtg L_vtg + λ_aux L_aux`
- 点/轨迹用SmoothL1；OFG对高斯关键点目标用MSE，对密集affordance掩码用类平衡二值交叉熵。
- 三阶段训练：
  1. **几何热身**：训练适配器+8个查询+几何头；
  2. **LoRA特化**：仅更新低秩骨干参数；
  3. **任务延续**：仅更新任务所需子集。
- 最终Pointing模型应用**GRPO式组归一化细化**：采样`a_i = clip(μ + σϵ_i, 0, 1)`，基于目标框B\*定义奖励，组归一化优势更新策略。

## 6. 主要结论与发现

1. **类型化空间读出优于文本坐标生成**：将接地作为类型化接口预测，可同时获得更高精度（OFG提升16.4个百分点）和更高效率（6.68–6.90×加速）。
2. **不同空间目标需要不同的几何接口**：稀疏点（Pointing）和密集区域（OFG）在互补的场景中各自最优，将它们折叠为单一下游接口会造成负迁移。
3. **固定执行契约有效**：源条件OFG-PICK/Pointing-PLACE的确定性分配在Bridge/WidowX上取得SOTA（72.9%），且Stack任务保持100%成功率，验证了OFG直接解决源实例消歧的能力。
4. **跨骨干迁移可行**：OFG/接触读出可迁移至NORA-1.5，保持或提升成功率，同时将控制器时间减少20倍以上。
5. **可在真实机器人上产生实际增益**：作为π₀.₅行动策略的空间引导，Pointing-VLA将真实成功率从52.7%提升至80.7%，失败集中在预期控制边界（预举升抓取、托盘到达）。

## 7. 优点

1. **问题定义具有理论深度**：从神经科学"双通路"理论出发，将接口问题提升为认知科学启发下的设计原则。
2. **方法设计清晰且模块化**：共享骨干+专家专用头，类型化输出与执行阶段对齐，结构简单而有效。
3. **强调可检查性（inspectability）**：与不透明动作令牌相比，OFG热图和Pointing坐标提供了机器人栈/人类可审计的中间表征。
4. **实验层次丰富**：从原生几何评估→机制消融→跨数据集诊断→跨骨干迁移→仿真部署→真实机器人验证，形成完整证据链。
5. **评估协议公平**：统一输出为点/统一PIM-PIB评分、控制样本身份、释放评估代码，增强可复现性。
6. **执行契约简洁实用**：不需要推理时选择器，固定的OFG→PICK/Pointing→PLACE设计简化了系统集成。
7. **效率数据显著**：无文本解码的情况下推理加速6倍以上，控制器时间缩短20倍以上，工程价值明显。

## 8. 不足与局限

1. **真实机器人评估范围有限**：仅一个AgileX PiPER、一个任务（白色复合物拾取-放置至绿色托盘），未覆盖多任务、多物体类别的真实场景。
2. **真实机器人基线不足**：仅与π₀.₅一种行动策略对比，缺乏与其他空间接地方法（如RoboPoint、FSD）在物理机器人上的直接对比。
3. **任务类型集中**：以拾取-放置为主，未覆盖更丰富的操作类型（组装、插入、推开等）。
4. **闭环修正缺失**：当前接口为开环空间引导，任务间差异（最明显于spoon-on-towel）暴露了闭合循环几何感知执行的需要，论文也承认这是未来工作。
5. **VTG轨迹结果报告有限**：仅报了一个300实例的VABench-V；未在Bridge/WidowX或真实部署中验证轨迹读出对执行的实际贡献。
6. **计算资源细节不透明**：未报告训练时长、GPU数量、参数量增加情况等具体信息，影响复现评估。
7. **跨骨干迁移范围有限**：仅验证了NORA-1.5和π₀.₅两个骨干，未覆盖更多主流VLA框架（如OpenVLA、RT-2系列）。
8. **固定契约的推广性存疑**：OFG-PICK/Pointing-PLACE在拾取-放置中表现良好，但LFG（语言功能接地）等其他任务是否需要不同的接口组合仍未验证。
9. **GRPO细化的理论保证有限**：方法描述中未深入讨论采样分布选择的标准或对数值稳定性的影响。

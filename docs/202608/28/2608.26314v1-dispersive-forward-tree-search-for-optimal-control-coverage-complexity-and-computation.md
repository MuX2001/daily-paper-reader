## 摘要
基于转向的规划器需要求解状态到状态的边值问题，这对于非线性平台可能难以实现。前向传播规避了转向需求，但相关规划器的有限样本行为仍未得到表征，且其实现方式在实践中表现不佳。本文提出了一种基于传播的运动动力学规划器，具有确定性的有限样本近似最优性保证。我们在一大类微分平坦非线性系统中展开研究，并证明一个由局部色散控制命令构成的前向树，在认证的树大小下包含一条近似最优轨迹。我们提供了一种通用机制来为控制仿射系统构造色散命令集，这是实现理论所规定搜索算法所必需的。我们表明，无论代价如何，覆盖已认证的轨迹类别在理论上都要求树的大小随问题时间域呈指数增长，并提出了一种基于代价条件的支配剪枝过程，在树大小随时间域呈多项式增长时保持近似最优性。我们将所得搜索算法——色散前向树搜索（DFT*）——实现为前向树的广度优先扩展，该扩展自然地映射到并行硬件上。我们为单轮车、拖挂车和四旋翼飞行器设计了高效的色散采样器，并评估了这些平台上具有挑战性的规划任务。在嵌入式级处理器上，DFT*在相近的求解时间内，其解质量始终保持竞争力，且通常显著优于最先进的运动动力学规划器，并且随着并行计算规模的扩展而进一步加速。我们还实现了DFT*的滚动时域循环，以演示在嵌入式计算预算下动态环境中的实时规划。

## Abstract
Steering-based planners require solutions to state-to-state boundary value problems, which can be inaccessible for nonlinear platforms. Forward propagation evades the steering requirement, but the finite-sample behavior of the associated planners remains uncharacterized and their implementations underperform in practice. This paper develops a propagation-based kinodynamic planner with deterministic finite-sample near-optimality guarantees. We work within the large class of differentially flat nonlinear systems and show that a forward tree of locally dispersive control commands contains a near-optimal trajectory at a certified tree size. We provide a general mechanism to construct dispersive command sets for control-affine systems, which are necessary to implement the search algorithm prescribed by the theory. We show that covering the certified trajectory class irrespective of cost provably demands a tree exponentially sized in the problem horizon, and present a cost-conditioned dominance pruning procedure that retains near-optimality at a tree size polynomial in the horizon. We implement the resulting search algorithm, Dispersive Forward Tree search (DFT*), as breadth-first expansion of the forward tree, which maps naturally onto parallel hardware. We design efficient dispersive samplers for the unicycle, the trailer car, and the quadrotor and evaluate challenging planning tasks for these platforms. DFT* delivers consistently competitive and often substantially better solution quality than state-of-the-art kinodynamic planners at comparable solution times on embedded-tier processors, accelerating further as parallel compute is scaled. We also implement DFT* in a receding-horizon loop to demonstrate real-time planning in dynamic environments at embedded-tier compute budgets.

## 2. 论文提出的方法论：核心思想、关键技术细节与算法流程

### 2.1 总体建模框架
- 工作在如下通用最优控制问题（OCP）上：

$$\min_{u(\cdot)} J[x(\cdot)] \quad \text{s.t.} \quad \dot{x} = f(x,u),\ g[x(\cdot)] ≥ 0,\ x(0)=x_{init}$$

- 假设系统是**微分平坦**的（differentially flat），即存在平坦输出 $z=h(x)$ 与映射 $\Psi_x, \Psi_u$，使状态与控制均可由输出 $z$ 及其有限阶导数代数表达。利用这一结构，原 OCP 被改写为平坦输出空间中的等价问题（flat reformulation）。

### 2.2 核心概念
- **色散命令集（Dispersive Command Set）**：一个有限命令集合 $A$，其前向积分轨迹在 Sobolev 度量下与"被侵蚀的 $M$ 光滑轨迹类"的最大偏差有界（即 dispersion $\le \delta$）。
- **M 光滑轨迹类**：要求轨迹的平坦导数（至 $r_i$ 阶）与平坦输入均被常数 $M$ 所界。
- **ε-侵蚀输入集（ε-eroded input set）**：$U^\varepsilon=\{u: u+[-\varepsilon,\varepsilon]^m\subseteq U\}$，即距离输入边界至少 $\varepsilon$ 的控制集合。侵蚀余量用于构造"纠偏（corrective tracking）"机制。

### 2.3 关键理论链
1. **覆盖性（Coverage）**：核心引理为"Margin Correction"（引理 5.9）：若参考轨迹的控制侵蚀余量为 $\varepsilon$，则存在常数 $C_B$，使偏离参考轨迹 ≤ $s \le \varepsilon/(2L_\Psi C_B)$ 的状态可在单个时间窗内被一个"纠偏控制"拉回参考轨迹。由此得到定理 5.10（受侵蚀覆盖）：给定局部 $\delta_A$-色散命令集，前向树中存在一条轨迹，在整段时域上与任意 $M$ 光滑、$\varepsilon$-侵蚀参考轨迹的偏差不超过 $(C_B+1)\delta_A$。
2. **最优性（Optimality）**：定理 5.11 进一步证明，只要代价泛函和谓词满足 Lipschitz 连续性，则搜索树中存在可行轨迹，其代价与"$M$ 光滑、$\varepsilon$-侵蚀、$\gamma$-鲁棒最优代价" $J^*_{M,\gamma,\varepsilon}$ 的差距为 $O(\delta_A)$。
3. **复杂度不可避免性（Complexity lower bound）**：命题 5.12 通过 packing number 估计证明，若要求树覆盖**全部** $M$ 光滑轨迹（不论代价），树的大小必然**随时间域指数增长**——这是信息论下界，与采样方法无关。
4. **支配剪枝（Dominance Pruning）**：针对满足"递归聚合代价"（如加性 Lipschitz 代价、折扣和、运行极值、时空鲁棒性）和"时间可分离谓词"（如逐窗碰撞约束）的问题类别，定理 5.17 证明：在每个深度按 jet 空间的 $s$-网格保留每个格子中的最优代表节点，可将所需树规模压缩为**关于时域 $K$ 的多项式**，同时保持近似最优性（误差从 $\delta_A$ 增至 $\delta_A+s$）。

### 2.4 算法流程（DFT*）
- **DFT\*（Algorithm 1）** 采用**广度优先、深度同步**的树扩展：
  1. $k←0$，根节点为初始状态；
  2. 对当前深度所有节点，并行展开其所有可接受命令（采样、数值积分、谓词检查）；
  3. 对新生成节点按状态-空间格子的支配关系剪枝（每格保留累计代价最小的节点）；
  4. $k←k+1$ 重复，直至到达终点。
  因为同一深度的所有候选（节点，命令）对彼此独立，可映射为大规模数据并行任务（GPU kernel）。
- **变体**：DFT*-Static（跨深度合并剪枝）、DFT-A*（A* 波束搜索式扩展）、以及两者组合。

### 2.5 平台命令集构造
为单轮车（一阶、二阶）、拖挂车和四旋翼分别设计了"pushforward"式色散采样器，即从状态空间中的控制网格出发，借助系统流前向映射得到轨迹集合，并提供色散界 $\delta_{n,j}$ 的显式估计。对比之下，定理 5.8 的通用"pullback"构造（在平坦输入格点上采样再拒绝）虽然理论完整，但实际接受率低，只作为存在性证明。

## 6. 论文的主要结论与发现

1. **理论层面**：前向传播式规划可具备确定的有限样本近最优性保证；树大小与局部色散之间存在显式的 trade-off；在无代价信息的条件下，覆盖 $M$ 光滑轨迹类所需的树规模指数增长是不可避免的。
2. **算法层面**：在"递归聚合代价 + 时间可分离谓词"结构下，支配剪枝可将树规模压缩为时域的多项式，使 DFT\* 在嵌入式设备上可行。
3. **实验层面**：
   - DFT\* 在大多数 Dynobench 任务上的解优于 SST\* 和 RRT\*+TO，多数任务优于或持平 iDb-A\*（尤其四旋翼任务的代价约为 iDb-A\* 的三分之一以下）；
   - 在动态环境中，WWDFT\* 达到 100% 成功率，而 FAPP 出现碰撞/约束违规；WWDFT\* 的旅行时间也最短；
   - DFT\* 从嵌入式（8 SM）到桌面 GPU（128 SM），墙钟时间可加速最高约 15 倍，体现优秀的数据并行扩展性。

## 7. 优点

- **理论完整性**：首次为基于前向传播的动力学规划器同时提供了"确定性 + 有限样本 + 非渐近"三层保证，填补了表 1 中明显的空白。
- **方法通用性**：微分平坦类系统涵盖大量实际平台（差速轮车、车辆-拖挂、旋翼无人机等），提供了一个系统级的色散构造理论框架，而非仅针对单一平台。
- **工程实用性强**：算法天然为 SIMD/GPU 数据并行设计，广度和深度同步推进的结构易于部署在嵌入式处理器上；代码已开源。
- **理论与实践结合紧密**：虽有深奥的度量熵/填充数论证，但所有抽象假设都对应了具体可操作的构造（如 Hermite 插值纠偏、格子量化命令集），并配有数值验证（图 3）。

## 8. 不足与局限

- **平坦性约束**：理论保证仅对微分平坦系统成立。对非平坦系统（如含非完整约束的若干复杂机构、高自由度腿足机器人），本文的分析框架无法直接迁移。
- **通用构造效率低**：定理 5.8 的通用色散构造（平坦输入格点采样+拒绝）在需求低色散时接受率较低、算力利用率差，实际部署需要逐平台设计高效采样器——论文虽给出若干范例，但缺乏自动化的构造流程。
- **理论最优性 vs 实际算法之间的gap**：理论中的"覆盖最优轨迹类"所需的树规模指数增长虽由支配剪枝在"聚合代价+分离谓词"类别下被降至多项式，但这一结构并未涵盖全部可能的 OCP（如强耦合多目标代价、非逐窗可分离约束）。
- **CPU 扩展性**：DFT\* 的 BFS 结构对 GPU/向量处理器友好，但直接运行在单核 CPU 上效率低，需额外底层优化，限制了部分传统机器人平台的即插即用。
- **在线安全的递归可行性**：WWDFT\* 虽可保证"被执行的轨迹"安全，但当预测树为空（$V_1=\emptyset$）时会声明失败——对未知动力学障碍物而言，无法保证递归可行性（recursive feasibility），这在理论上也几乎无法避免。
- **实验的粒度问题**：动态场景下的障碍物运动模式较单一（平滑周期轨迹），对突然变速/急转等对抗性运动模式的鲁棒性尚未验证；离线基准的 5 次重复统计功效有限。

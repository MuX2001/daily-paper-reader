## 摘要
语言推理使基础模型能够在难题上花费更多的测试时计算资源，例如需要分解、约束跟踪和预测未来后果的问题。这种机制能否改善机器人操作仍不清楚，因为长时间跨度的任务需要跟踪部分进度、推理物体关系、从错误中恢复，并引导嘈杂的低层策略。在本文中，我们研究视觉语言模型（VLM）能否被训练为直接以自然语言进行推理，以引导低层操作策略。我们提出了$R^3$，一种简单的后训练方法，将现成的VLM转变为机器人推理器：它首先在专家生成的推理轨迹上对VLM进行中期训练，以初始化所需的推理风格，然后通过基于离线动作数据的单步评分强化学习来改进推理器。与先前主要使用结构化轨迹作为辅助监督的机器人推理方法不同，$R^3$训练自由形式的语言推理，为动作提供测试时引导。我们在Language Table和模拟双臂杂货打包这两个用于研究机器人推理和长时程操作的控制测试平台上实例化了$R^3$。$R^3$在未见任务上改善了探索和泛化能力，并在两个基准测试上显著优于仅指令的模仿学习基线。我们的分析表明，自由形式的语言推理可以作为引导低层策略的测试时计算机制。我们的项目页面可在 https://robotic-reasoner.github.io/ 获取。

## Abstract
Reasoning in language allows foundation models to spend more test-time compute on hard problems, such as those requiring decomposition, constraint tracking, and prediction of future consequences. Whether this mechanism can improve robotic manipulation remains unclear, where long-horizon tasks require tracking partial progress, reasoning about object relations, recovering from mistakes, and steering noisy low-level policies. In this paper, we study whether VLMs can be trained to reason directly in natural language to guide low-level manipulation policies. We introduce $R^3$, a simple post-training recipe that turns off-the-shelf VLMs into robotic reasoners: it first mid-trains a VLM on expert-generated reasoning traces to initialize the desired reasoning style, then improves the reasoner with single-step rubric-based RL from offline action data. Unlike prior robotic reasoning methods that mostly use structured traces as auxiliary supervision, $R^3$ trains free-form language reasoning to produce test-time guidance for action. We instantiate $R^3$ on Language Table and simulated bimanual grocery packing, two controlled testbeds for studying robotic reasoning and long-horizon manipulation. $R^3$ improves exploration and generalization across unseen tasks and significantly outperforms instruction-only imitation learning baselines on both benchmarks. Our analyses suggest that free-form language reasoning can function as a test-time compute mechanism for steering low-level policies. Our project page is available at https://robotic-reasoner.github.io/.

- **研究背景**：语言推理（如链式思考）已被证明能够通过增加测试时计算（test-time compute）来提升大语言模型在复杂问题上的表现。机器人操作任务天然需要场景理解、物理约束推断、动作后果预测以及长时程规划，因此自然语言推理被认为有潜力作为机器人策略的“测试时计算”机制。
- **核心问题**：视觉语言模型（VLM）能否通过训练产生自由形式的自然语言推理，并在测试时用于引导低层操作策略？现有的机器人推理方法多依赖结构化轨迹（如物体坐标、子目标标注）作为辅助监督信号，这些方法的收益主要来自训练时的表征学习，而推理在测试时并未带来额外增益。
- **论文提出**：$R^3$（Robotic Reasoners via Reinforcement Learning）——一个两阶段后训练框架，将现成的 VLM 转化为能够进行自由形式语言推理的“机器人推理器”，生成的推理用于引导固定的低层语言条件策略。该工作首次系统性地验证了语言推理可以作为机器人操作中的测试时计算机制，并且因果性地提升泛化性能。

## 2. 方法论

### 2.1 总体架构
- 采用分层策略：高层次 VLM 作为推理器（reasoner），根据当前观测、任务目标和交互历史生成“推理轨迹 + 短时指令”；低层策略（frozen）接收指令并输出机器人动作。
- 低层策略为预训练的语言条件策略，例如 Language Table 的 pushing 策略和杂货打包中基于 $\pi_{0.5}$ 微调的 VLA 策略。

### 2.2 两阶段训练流程

- **Stage I：专家推理追踪的中期训练（Mid-training）**
  - 使用专家（Gemini 3 Flash）生成的多轮操作轨迹，每条轨迹包含观测、推理轨迹、指令。
  - 同时收集成功和失败的轨迹，以覆盖部分进度、错误和恢复行为。
  - 训练目标为标准的下一个 token 预测（SFT），用于初始化推理风格、约束跟踪和自我纠正能力。

- **Stage II：基于评分标准的单步强化学习（Rubric-Based Single-Step RL）**
  - 使用仅含有专家指令（无推理轨迹）的离线数据，拟合真实应用中“推理标注昂贵、指令标注便宜”的设定。
  - 模型从上下文采样推理和指令，使用 VLM-as-a-judge 或字符串精确匹配作为奖励。
  - 对 Language Table 采用 VLM 判断（Qwen3.5-35B-A3B）评估语义匹配；对杂货打包采用精确字符串匹配。
  - 使用 Dr.GRPO 作为强化学习算法，通过组内优势归一化更新策略。
  - 额外设计：推理上下文补全（imputation）、重复步骤过滤、长度惩罚以避免退化推理。

### 2.3 关键设计选择
- 历史上下文：使用上一轮完整响应作为交互历史，使模型能够跟踪进度和保持连贯计划。
- 不依赖在线机器人交互或人写奖励，仅从离线动作数据中优化推理行为。

## 6. 主要结论与发现

1. **RL 单独即可提升性能**，但中期训练能使其更可靠；完整 $R^3$ 优于仅 RL 和仅中期训练。
2. **推理的收益主要来自测试时计算**，而非仅来自训练时表征学习：
   - 将推理数据作为预训练/协同训练监督的 IL 基准，其 OOD 性能仍显著低于 $R^3$；
   - 在同一 checkpoint 上截断推理长度会导致成功率大幅下降（如 V 任务从 69.2% 降至 20.3%）。
3. **模型学到了多种有用的推理行为**：比较多个备选方案、进行自我纠正、在物体被遮挡时重新检查场景与历史、增量地选择下一步、跟踪任务进度。
4. **中期训练提供行为先验，RL 进行局部精炼**：中期训练使指令分布接近专家；RL 则针对与专家不匹配的部分进行修正，最终集中到高奖励策略。
5. **自由形式语言推理优于结构化 CoT**：在相同中期数据上，ECoT 风格的推理没有带来额外收益，甚至略微降低性能，说明长时程任务更需要进度跟踪和闭环重规划，而非低层视觉接地信息。
6. **$R^3$ 可迁移到双臂杂货打包**：在无推理标注、仅用 RL 的情况下，$R^3$ 超越仅指令 IL 和带推理的基础模型，验证了方法的通用性。

## 8. 不足与局限

- **仿真环境局限**：所有实验均在模拟器中完成，未在真实机器人上验证，真实世界中的噪声感知、物理不确定性和恢复行为可能改变结论。
- **依赖专家推理和 VLM judge**：Stage I 需要专家生成的推理标注，Stage II 的奖励是“语义匹配”而非真实任务成功，属于代理目标，可能无法完全反映最终任务表现。
- **推理与低级策略分离**：高层次的推理与低层动作执行之间存在潜在不匹配（如推理正确但低层无法完成指令），联合训练可能更优，但本文未做。
- **关于历史表示的简单性**：仅使用上一轮响应作为历史，对更复杂的长时程任务可能不够充分，需要更强大的记忆机制。
- **ECoT 对比的公平性**：后处理推理由 Gemini 对 Gemini 轨迹生成，可能与真实跨专家设置不同，论文也承认这一限制。
- **算力信息披露不足**：未提供精确的训练时长、GPU 型号、总计算量，不利于复现成本评估。

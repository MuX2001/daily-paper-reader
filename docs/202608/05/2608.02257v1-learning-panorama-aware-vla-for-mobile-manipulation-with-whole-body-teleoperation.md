## 摘要
移动操作是具身智能的关键能力，使机器人能够在开放世界环境中完成复杂的多阶段任务。然而，移动操作对视觉-语言-动作（VLA）策略提出了两个关键挑战：在数据层面，高质量全身演示的高效收集需要移动基座和机械臂的协调控制；在模型层面，现有VLA模型主要依赖局部相机观测，其有限的视野阻碍了全局空间理解。为解决这些挑战，我们开发了一套全身遥操作系统和一种全景感知VLA策略。该系统通过单个VR界面实现对轮式双臂机器人的协调控制，并支持获取包含5.5小时多模态演示的真实世界移动操作数据集。基于该数据集，我们提出了PanoVLA，一种用于移动双臂操作的全景感知视觉-语言-动作策略。PanoVLA基于Transformer混合架构，通过专门的全景编码与融合模块引入全局空间上下文，使全景观测、语言指令和机器人状态能够有效集成以生成动作。在四项真实世界移动操作任务上的评估表明，PanoVLA实现了91.3%的平均阶段完成率和73.4%的端到端成功率，显著优于局部视图基线。这些结果表明，融入全景空间上下文能够提升移动机器人的空间理解能力和闭环操作性能。

## Abstract
Mobile manipulation is a key capability for embodied intelligence, enabling robots to accomplish complex multi-stage tasks in open-world environments. However, mobile manipulation poses two key challenges for vision-language-action (VLA) policies: At the data level, the efficient collection of high-quality whole-body demonstrations demands the coordinated control of both the mobile base and the robotic arms; at the model level, existing VLA models predominantly rely on local camera observations, whose limited field of view hinders global spatial understanding. To address these challenges, we develop a whole-body teleoperation system and a panoramic-aware VLA policy. The system enables coordinated control of a wheeled bimanual robot through a single VR interface and supports the acquisition of a real-world mobile manipulation dataset comprising 5.5 hours of multimodal demonstrations. Building upon this dataset, we propose PanoVLA, a panorama-aware vision-language-action policy for mobile bimanual manipulation. Built upon a Mixture-of-Transformers architecture, PanoVLA introduces global spatial context through dedicated panorama encoding and fusion modules, enabling effective integration of panoramic observations with language instructions and robot states for action generation. Evaluation on four real-world mobile manipulation tasks demonstrates that PanoVLA achieves an average stage completion rate of 91.3\% and an end-to-end success rate of 73.4\%, substantially outperforming local-view baselines. These results demonstrate that incorporating panoramic spatial context improves spatial understanding and closed-loop manipulation performance in mobile robots.

  1. **数据采集层面**：高效收集高质量的全身演示需要同时协调移动基座、双臂和夹爪，传统分离式控制（如键盘/摇杆控制底盘、手动控制手臂）难以产生流畅的全身动作。

- **核心问题**：如何构建既支持高效全身数据采集、又能在移动过程中保持机器人中心化的全局空间感知的 VLA 策略？
- **整体含义**：论文通过开发一套基于 VR 的全身遥操作系统，采集包含全景相机在内的真实多模态数据，并提出一种专门融合全景信息的 VLA 模型（PanoVLA），以解决移动操作中“看得全”与“动得协调”两大难题。

## 2. 论文提出的方法论

### 2.1 全身遥操作系统（数据采集侧）

- **硬件组成**：操作者佩戴 VR 头显、双手控制器、三个身体追踪器（腰部一个、脚踝各一个），通过稀疏的人体运动捕获实现自然交互；被控机器人为轮式双臂平台（RANGER MINI UGV 底座 + 两个 6-DoF PIPER 手臂 + 平行夹爪）。
- **运动重定向核心**：采用 **General Motion Retargeting (GMR)** 公式，将人体 SMPL 重建的稀疏运动特征（骨盆位姿、双手位姿、下肢运动线索）映射为机器人全身配置：
  - 机器人配置参数化为 `q = (x_b, y_b, θ_b, q_L, q_R)`，其中 `(x_b, y_b, θ_b)` 为平面移动基座位姿，`q_L/q_R` 为左右臂关节配置。
  - 优化目标为加权损失：
    `q* = argmin_q [ λ_pos L_pos + λ_rot L_rot + λ_base L_base + λ_reg L_reg ]`
    - `L_pos` 对齐手与夹爪位置，`L_rot` 对齐手与末端朝向；
    - `L_base` 将平面基座运动与操作者骨盆位移和朝向耦合；
    - `L_reg` 惩罚关节极限违规和过度配置变化。
- **移动基座建模**：将移动底座视为 3-DoF 平面虚拟浮动基座，与双臂联合优化；当末端目标超出机械臂工作空间时，优化器可调整基座平移与偏航，降低重定向误差。
- **模式切换策略**：为了在物理底座上执行虚拟 3-DoF 指令，设计**成本驱动的模式切换机制**：在每个控制周期评估三种运动模式（如旋转、阿克曼转向、斜向平移）与期望平移/旋转的匹配成本，选择成本最低的模式执行；随后实时重新计算以动态跟随操作者意图。
- **数据同步**：系统同步发送基座速度指令、双臂关节位置目标和夹爪命令，生成时间对齐的全身动作序列。

### 2.2 PanoVLA 模型（策略学习侧）

- **总体架构**：PanoVLA 基于 **Mixture-of-Transformers (MoT)** 架构，在原有 π0.5 双专家（VLM 专家 + 动作专家）基础上**插入全景专家**，形成三专家结构：
  - **VLM 专家**：以 Gemma-2B 为语言骨干，SigLIP 编码局部图像（前视 + 双腕部相机），处理语言指令、局部视觉和本体状态，生成 VLM 缓存 `C_vlm`。
  - **全景专家**：将全景编码器输出的全景 token 与 VLM 缓存进行联合自注意力，产出全景缓存 `C_pano`，实现“任务条件下的机器人中心全局空间编码”。
  - **动作专家**：基于组合缓存 `C_t = [C_vlm; C_pano]` 预测连续动作块。
- **缓存机制作为融合接口**：采用层级的键值（KV）缓存，各专家通过缓存向后续专家提供上下文信息。
- **全景编码器（Panorama Encoder）**：
  1. **球面重投影**：将同步的双鱼眼全景观测重投影到公共球面，并栅格化为等距柱状投影（ERP）图像，获得连续的机器人中心全景。
  2. **全景特征提取**：使用 **MTPano**（全景基础模型）的语义分割分支和深度分支特征，拼接形成包含语义与几何信息的统一密集表示。
  3. **Token 适配**：通过自适应平均池化压缩为固定数量 token，再经轻量 MLP 映射到全景专家隐藏维度，得到全景 token `Z_pano`。
- **训练目标**：动作专家采用**条件流匹配（Conditional Flow Matching）**学习动作块生成，优化目标为：
  `L = E[ || v_θ(x_τ, τ | C_t) - u(x_τ | a) ||^2 ]`
  其中 `x_τ` 为噪声动作样本，`u` 为目标速度场，`v_θ` 为预测速度场。

## 3. 实验设计

### 3.1 数据集与场景

- **遥操作采集数据集**：包含 4 个任务的 800 条成功演示轨迹，总时长约 5.5 小时，以 25 Hz 记录约 50 万同步帧。数据模态包括：
  - 前视 RGB、两个腕部 RGB；
  - 顶部 360° 全景（以 ERP 形式存储）；
  - 本体状态（双臂关节位置、夹爪开闭状态、基座位姿）；
  - 全身动作（17 维：双臂 14 维 + 基座 3 维速度指令）。
- **任务定义**：
  1. **Move Pen**：将笔放入笔筒（目标方向可前/左/右）；
  2. **Move Block**：将积木转移到前方区域（可左侧/右侧/双侧）；
  3. **Open Curtain**：打开两侧窗帘（需双侧顺序交互）；
  4. **Wipe Table**：沿长桌擦除污渍，并归还毛巾（长范围、多阶段、需保持全局空间一致性）。

### 3.2 对比方法与基线

- **π0.5**：原始双专家 VLA，仅使用局部相机视图，不引入全景。
- **π0.5 w/ Pano**：将 ERP 全景当作额外图像输入，由 SigLIP 编码，不加专用全景分支。
- **π0.5 w/ Stacked Pano**：将全景重投影为 3 个视角间隔 120° 的透视视图，拼接为一张复合图后输入 π0.5。
- **PanoVLA**：本文方法（MTPano 全景编码器 + 100M 全景专家 + MoT 三专家架构）。

### 3.3 评估协议与指标

- 每个任务 15 次闭环真实机器人 rollout（每次连续执行，无人工重置失败阶段）。
- 指标：
  - **Success Rate (SR)**：整条轨迹端到端成功率的二值指标；
  - **Stage Completion Rate (SCR)**：各任务分解为多个阶段，统计所有试验中完成阶段的比例。

## 6. 主要结论与发现

- **PanoVLA 显著优于局部视图基线**：平均 SCR 为 91.3%、SR 为 73.4%，而 π0.5 分别仅为 58.6% 和 30.0%。
- **全景信息的“怎么用”比“有没有”更重要**：
  - 直接输入 ERP 全景（π0.5 w/ Pano）虽有提升，但表现波动；
  - 将全景重投影为透视拼接图（Stacked Pano）在操作重阶段（如 Wipe Table）有改善，但会削弱跨视图连续性和机器人中心理解；
  - 专用全景编码（MTPano） + 全景专家融合（PanoVLA）在全部四个任务上取得最高 SR，尤其在需要多阶段状态跟踪和长程空间一致性的任务上优势明显。
- **全景专家能更好地维持任务状态**：例如在 Wipe Table 的最终“归还毛巾”阶段，PanoVLA 的成功率达到 73.3% 的完成度，而直接输入 Panorama 的基线仅 26.7%，说明全景专家有助于跟踪任务阶段转变和保持全局空间一致性。
- **大规模模型并非更好**：全景专家从 100M 增加到 300M 并未带来稳定收益，100M 是数据量下的经验最优选择。
- **全景专用编码器至关重要**：使用 SigLIP（面向透视图像的通用视觉编码器）处理全景，SCR/SR 大幅下降至 75.6%/40.0%；MTPano 能更好捕捉等距柱状投影的水平连续性和全局布局。

## 7. 优点

- **系统性解决移动操作数据与模型两大痛点**：从遥操作系统到网络架构形成闭环方案，体现了“数据-模型-验证”一致的工程和研究思路。
- **全新的全身遥操作设计**：将移动基座建模为虚拟浮动基座，并通过 GMR 联合优化基座与双臂，摆脱了额外底盘的遥控器，降低了操作者认知负荷，提升了演示的流畅性。
- **数据集具备高信息价值**：首次在真实移动操作数据中包含时间同步的 360° 全景、局部视图、本体状态和全身动作，为后续研究提供了宝贵资源。
- **模型架构具有创新性**：在 MoT 框架中引入“全景专家”作为全局上下文注入模块，利用 KV 缓存作为轻量融合接口，可复用已有 π0.5 权重，工程上友好。
- **全景编码设计细节扎实**：使用球形重投影、MTPano 多任务特征（语义+深度）和自适应池化，缓解全景畸变与透视预训练的域差异。
- **实验设计较为严谨**：采用“控制变量”的自然基线序列，能够清晰分析“是否有全景”“全景格式”“全景编码器”和“专家容量”的影响；闭环评估指标 SR 与 SCR 结合，可定位具体失败阶段。

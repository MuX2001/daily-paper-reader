## 摘要
视觉-语言-动作（VLA）模型近期在机器人操作中展现出有前景的性能。然而，现有基准主要评估静态操作任务的泛化能力，很大程度上忽略了动态交互场景。为解决这一缺口，我们提出了ReflexBench，一个面向反应关键操作的基准。ReflexBench包含六个动态任务，并引入了一个评估框架，该框架将模拟器步进与机器人控制解耦，同时支持同步和异步推理下的可配置延迟。基于ReflexBench，我们提出了ReflexVLA，一种为反应关键操作设计的高效VLA模型，无需大规模机器人数据预训练。ReflexVLA通过潜在未来预测和视觉骨干内的多帧时间融合增强时间推理，同时通过批量视觉编码和CUDA Graph重放降低部署延迟。实验表明，ReflexVLA持续提升动态操作性能，同时在标准静态操作基准上保持竞争性精度，真实世界实验进一步验证了其在实际部署条件下的有效性。项目网站：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. Project website: https://reflexvla.github.io

## 2. 方法论

### 2.1 ReflexBench（基准）

- **六个动态任务**：Conveyor Belt Pick-and-Place（传送带抓取）、Ball Catching（接球）、Whack-a-Mole（打地鼠）、Rolling Ball Interception（滚动球拦截）、Ball Throwing（投球）、Rotating Peg Insertion（旋转插销）。
- **延迟感知评估框架**：
  - 将**模拟器步进与机器人控制解耦**，环境动态独立于策略计算推进；
  - 支持**同步**（推理期间阻塞执行）和**异步**（执行与推理重叠）两种推理范式；
  - 引入**可配置延迟机制**，可手动指定延迟时长，或通过 **RTF（Real-Time Factor）** 将实测真实推理延迟换算为仿真延迟。
- **数据收集**：采用基于规划器的流水线，将任务分解为子目标阶段并预测未来轨迹；必要时训练任务特定的强化学习策略生成示范数据。

### 2.2 ReflexVLA（模型）

ReflexVLA基于紧凑的VLA-Adapter架构：视觉编码器为DINOv2+SigLIP融合ViT（224×224），语言骨干为Qwen2.5-0.5B因果Transformer。其三大核心设计如下：

**① 潜在未来预测（Latent Future Prediction）**

- 目标：鼓励策略推理近未来环境状态，而非仅对当前观测做出反应。
- 方法：
  - 使用**冻结的DINOv3模型**提取未来观测的语义特征作为预测目标：`yₜ₊ᵢ = ϕ_DINOv3(oₜ₊ᵢ)`，特征维度1024；
  - 在输入序列中追加 H 个可学习的未来token（H等于动作块大小），每个token对应未来一个控制步；
  - 经过Transformer前向传播后，未来token的隐表示通过投影头映射至DINOv3特征空间：`ŷₜ₊ᵢ = f_pred(h_future_i)`；
  - 使用**掩码余弦相似度损失**训练：
    - `L_future = Σ mᵢ[1 − cos(ŷₜ₊ᵢ, yₜ₊ᵢ)] / Σ mᵢ`
  - 总损失：`L = L_act + λ_future · L_future`（λ_future = 0.05）。

**② 多帧时序融合（Multi-Frame Temporal Fusion）**

- 目标：仅凭单帧无法捕捉运动动态，需利用历史观测的时间上下文。
- 方法要点：
  - 在**视觉骨干内部**完成时序融合，而非将多帧图像的视觉token全部输入语言模型——避免语言模型侧二次复杂度开销；
  - 对**中间层视觉特征**（保留更丰富的局部外观和运动线索）进行融合：
    - 对每个视图的每个patch位置，取T帧历史特征构成时序轨迹；
    - 经归一化、降维、加入时序位置编码后，通过**因果时序注意力**（MHA）聚合；
    - 将融合后的更新量投影回原始维度，与当前帧的最终层特征相加；
  - 因果掩码保证在线部署时无未来信息泄露；
  - 关键优势：语言模型消费的视觉token数量与单帧设置完全一致。

**③ 推理延迟优化（Inference Latency Optimization）**

- **批量视觉编码**：将 V 个视图 × T 帧历史图像合并为一次视觉编码器前向调用，减少框架开销并提高GPU利用率。
- **CUDA Graph 重放**：将整个推理管线（视觉编码→时序融合→多模态投影→语言模型→动作预测）捕获为CUDA Graph：`âₜ₊ₕ₋₁ = G(x_text, x_vision, x_state)`；在线执行时仅需将新观测拷贝至预分配缓冲区并重放图，消除重复内核调度开销。

## 6. 主要结论与发现

1. **推理范式的影响**：低频时异步推理因观测-动作错位而表现较差；高频时异步推理逐渐超越同步推理，得益于连续动作执行的优势。**较大的chunk size + 较短的action horizon + 高频异步推理**组合效果最佳。
2. **ReflexVLA在ReflexBench上达到最优平均成功率**：50.4%，超越所有基线（包括4B/7B大模型），仅用1B参数。相比骨干模型VLA-Adapter（30.3%）提升20.1个百分点。与PUMA（50.2%）相当，但参数量仅为后者的1/4。
3. **静态任务性能保持**：LIBERO平均97.2%，与最优方法几乎持平，证明动态设计不损害静态操作能力。
4. **消融验证**：
   - 冻结DINOv3特征作为未来预测目标至关重要（可训练目标反而导致−31.9%的退化；冻结目标带来+26.0%提升）；
   - 中间层时序融合优于最终层（+3.5%），因果MHA优于Cross Attention；
   - 延迟优化（批量编码+CUDA Graph）将推理延迟从125.1ms降至65.0ms（降幅约48%），同时成功率进一步提升+2.1%。
5. **真实世界验证**：ReflexVLA显著优于SmolVLA，与4B的PUMA相比在更小模型下取得相当或更好性能。

## 7. 优点

1. **基准设计创新性强**：ReflexBench首次将延迟感知评估系统化地引入VLA动态操作基准——解耦模拟步进与机器人控制、支持同步/异步双范式、通过RTF实现可迁移的延迟注入，这些设计为公平评估延迟敏感操作提供了更接近真实部署的测试协议。
2. **方法轻量且高效**：ReflexVLA仅1B参数，无需大规模预训练即取得SOTA级动态性能；时序融合在视觉骨干内完成，避免语言模型侧二次注意力的额外开销；未来预测仅增加与动作块大小相等的token数，计算开销可忽略。
3. **预测目标设计巧妙**：使用冻结DINOv3特征作为语义预测目标，避免了可训练预测目标导致的监督不稳定问题；每个未来步仅一个token，将未来预测与动作块的时间结构对齐。
4. **工程优化务实**：批量视觉编码和CUDA Graph重放是部署层面直接有效的手段，不改变模型结构和学习目标，且带来了接近两倍的延迟降低——这在真实机器人场景中直接转化为成功率提升。
5. **实验验证多维度**：从机制研究、主实验、静态泛化、逐组件消融到真实部署，形成了完整的证据链，结论可信度较高。

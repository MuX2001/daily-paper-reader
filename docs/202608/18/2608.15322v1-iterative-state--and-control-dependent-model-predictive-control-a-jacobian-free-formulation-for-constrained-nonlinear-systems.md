## 摘要
本文提出了一种迭代模型预测控制算法，该算法无需评估任何被控对象导数即可稳定约束非线性系统。通过利用状态与控制依赖系数（SCDCs）将精确非线性动力学分解为伪线性形式，我们将标准非凸优化替换为一系列受约束的线性二次规划。沿先前预测轨迹重新冻结系数矩阵驱动迭代。在原点附近，我们证明该序列收缩至唯一不动点。我们明确界定了达到任意停止容差所需的迭代次数，并量化了从不动点到真实卡罗需-库恩-塔克点的距离，表明该最优性间隙随状态接近原点而二次消失。对离散代数Riccati方程进行膨胀处理生成终端分量，保证了即使求解器提前终止也能递归可行性和渐近稳定性。我们在线调整终端惩罚，证明其保持一致有界，并通过可观测块标准型确保输出反馈，该标准型直接从过去的输入和输出中提取精确的系统状态。保持子问题的块带状结构使计算成本随预测时域长度 $\ell$ 线性增长。这一 $O(\ell)$ 复杂度与迭代线性二次调节器（iLQR）相匹配，但明显低于密集序列二次规划（SQP）的 $O(\ell^3)$ 缩放。对饱和四旋翼、非完整积分器及非最小相位对象的数值研究验证了理论界，并展示了该算法与iLQR、SQP及线性变参数MPC的比较情况。

## Abstract
This paper presents an iterative model predictive control algorithm that stabilizes constrained nonlinear systems without evaluating a single plant derivative. By factoring the exact nonlinear dynamics into a pseudo-linear form using state- and control-dependent coefficients (SCDCs), we replace the standard nonconvex optimization with a sequence of constrained linear-quadratic programs. Refreezing the coefficient matrices along the previously predicted trajectory drives the iteration. Near the origin, we prove this sequence contracts to a unique fixed point. We explicitly bound the number of iterations required to reach any stopping tolerance, and we quantify the distance from the fixed point to a true Karush-Kuhn-Tucker point, showing this optimality gap vanishes quadratically as the state approaches the origin. Inflating the discrete algebraic Riccati equation generates terminal ingredients that guarantee recursive feasibility and asymptotic stability, even when the solver terminates early. We adapt the terminal penalty online, proving it remains uniformly bounded, and we secure output feedback through the block-observable canonical form, which extracts the exact system state directly from past inputs and outputs. Retaining the block-banded structure of the subproblem forces the computational cost to scale linearly with the horizon length $\ell$. This $O(\ell)$ complexity matches the iterative linear quadratic regulator (iLQR) but sharply undercuts the $O(\ell^3)$ scaling of dense sequential quadratic programming (SQP). Numerical studies on a saturated quadrotor, a nonholonomic integrator, and a nonminimum-phase plant illustrate the theoretical bounds and map how the algorithm compares with iLQR, SQP, and linear-parameter-varying MPC.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **研究背景**：非线性模型预测控制（NMPC）在航空航天、汽车动力总成、过程控制和机器人等领域具有广泛应用。然而，标准 NMPC 在每个采样周期需要求解一个非凸非线性规划（NLP），计算负担极为沉重。
- **核心问题**：现有非线性 MPC 方法存在两大痛点：
  - **依赖雅可比矩阵**：iLQR、SQP 等方法需要对动力学模型求导，而很多实际系统中导数难以获得或计算昂贵；
  - **非凸优化求解困难**：直接求解非线性规划在每个采样周期内完成计算且保证收敛性非常困难。
- **论文动机**：利用状态与控制依赖系数（SCDC）将非线性动力学精确分解为伪线性形式 f(x,u) = A(x,u)x + B(x,u)u，这是一种代数恒等式而非近似。通过沿预测轨迹"冻结"这些系数，将非凸优化转化为一系列凸的线性二次规划（QP），从而**完全避免对系统求雅可比**。
- **整体意义**：该算法在理论上具备可证明的收敛性、稳定性和递归可行性，同时计算复杂度为 O(ℓ)（ℓ 为预测时域长度），与 iLQR 相同但低于密集 SQP 的 O(ℓ³)，为约束非线性系统的实时控制提供了一个新的高效求解框架。

## 2. 论文提出的方法论

### 2.1 核心思想

利用 SCDC 分解将非线性系统 f(x,u) 转化为 f(x,u) = A(x,u)x + B(x,u)u。在每个控制更新步内，通过迭代方式沿上一步预测轨迹冻结系数矩阵，将非线性最优控制问题松弛为一系列有约束的线性二次规划，并利用迭代收敛逼近原问题的最优解。

### 2.2 算法流程（文字描述）

**外层循环（时间步 k）**：

1. 测量/获取当前状态 x_k；
2. 计算固定首步状态 x_{k,1} = f(x_k, u_k)（考虑一步计算时延）；
3. 通过**冷启动**（k=0 时）或**移位热启动**（k≥1 时，将上一时刻控制序列前移并追加终端控制律）初始化迭代控制序列 U_{k|1}；
4. 进入内层 SCDC 收缩循环。

**内层循环（迭代次数 i = 2, 3, …, ρ）**：

1. 沿上一迭代的控制序列 U_{k|i-1} 对非线性动力学进行 rollout，得到预测轨迹 x_{k,j|i-1}；
2. 计算 SCDC 系数矩阵 A_{k,j|i-1} = A(x_{k,j|i-1}, u_{k,j|i-1}) 和 B_{k,j|i-1}；
3. 将这些系数**冻结**，构造线性二次规划 (12)–(15) 并求解得到 U_{k|i}；
4. 检查停止条件 ‖U_{k|i} − U_{k|i-1}‖ < ε 或达到最大迭代次数 ρ，满足则终止迭代；
5. 应用控制 u_{k+1} = u_{k,1|ρk}。当前时刻的终端惩罚 P_k 通过前向传播的 Riccati 递推 (31) 更新到 P_{k+1}。

### 2.3 关键技术细节

- **无条件收敛保证**：通过惩罚膨胀的离散代数 Riccati 方程（DARE）构造终端代价，保证算法在最优和次优情形下均具有递归可行性和渐近稳定性；
- **热启动策略**：将上一时刻已计算的控制序列前移一位并追加终端控制律，显著减少所需的迭代次数；
- **输出反馈**：利用块可观测标准型（BOCF）从有限的历史输入输出数据中**精确重建**系统状态，无需分离定理即可将状态反馈的稳定性保证迁移到输出反馈场景；
- **块带状结构保留**：子问题保持块带状结构，使每个内层迭代的求解成本为 O(ℓ(n+m)³)，匹配 iLQR 但低于稠密 SQP。

## 6. 论文的主要结论与发现

### 6.1 理论结果

- **局部收缩性（Prop 2）**：SCDC 迭代在原点附近以正比于当前状态范数的速率收缩到唯一不动点；
- **迭代次数显式界（Prop 3）**：达到停止容差所需的迭代次数有明确的上界；
- **预测代价几何收敛（Prop 4）**：沿迭代序列的 rollout 代价以几何速率收敛到不动点处的代价；
- **最优性间隙二次消失（Prop 5）**：不动点与真实 KKT 点的一阶最优性残差随状态范数以 O(‖x‖²) 速度趋于零；
- **递归可行性与渐近稳定性（Thm 1–3）**：无论是否严格最优，只要满足下降条件，闭环系统均渐近稳定；
- **输出反馈（Prop 9）**：BOCF 精确重建状态，使输出反馈系统保持渐近稳定性。

### 6.2 实验发现

- **四旋翼基准**：iSCD-MPC 与 iLQR、SQP 的闭环代价一致（归一化代价均为 1.000），比 LPV-MPC 低 0.4%；计算每步比 SQP 快 **85.1 倍**，比 LPV-MPC 慢约 4.9 倍（但精度显著更高）；平均迭代数为 2.44；
- **非完整积分器**：iSCD-MPC 成功收敛到原点，而 LPV-MPC 因冻结系数失去可稳定性停滞在 x₃≈0.28（结构性失效）；iSCD-MPC 代价比 iLQR/SQP 高 39%，体现了无导数方法的最优性代价；可行域随 ℓ 单调增大与 Prop 7 一致；
- **输出反馈基准**：iSCD-MPC 与 SQP 代价一致（归一化 1.000），比 iLQR 低 2.9%，比 LPV-MPC 低 126%；计算每步比 SQP 快 **76.2 倍**；LPV-MPC 因输出相关执行器效能造成持续振荡而无法收敛；
- **Horizon 缩放**：结构化 iSCD-MPC 与 iLQR 的时间缩放指数分别为 **0.83** 和 **0.93**（接近 O(ℓ) 预测），而稠密实现指数约为 1.90（接近 O(ℓ²)）。

## 7. 优点

- **无雅可比设计**：完全不需要计算被控对象的导数，适用于导数不可得或极难获取的实际系统（如查表、隐式仿真等场景）；
- **完整且严谨的理论体系**：涵盖收缩性、迭代界、最优性间隙、终端惩罚有界性、递归可行性、渐近稳定性（最优/次优）等核心问题，逻辑链条完整；
- **复杂度优势明确**：在保留块带状结构的条件下，理论复杂度 O(ℓ) 与 iLQR 相同，远低于稠密 SQP 的 O(ℓ³)，并通过受控实验验证了缩放指数；
- **面向实际实现的设计**：考虑了一步步计算时延（Remark 1）、热启动、在线终端惩罚自适应、提前终止保护（Remark 9）等工程实现中的重要细节；
- **输出反馈无分离定理要求**：BOCF 精确重建消除了估计误差对稳定性的影响，避免了观察器-控制器分离假设的限制；
- **饱和处理方式巧妙**：通过 SCDC 中的对角因子将执行器饱和直接嵌入系数矩阵，保证控制量约束被严格满足。

## 8. 不足与局限

- **SCDC 分解不唯一**：当 n > 1 时，同一非线性函数存在多种 SCDC 分解，协议作者虽指出分解的选择会影响 Lipschitz 常数和收缩率，但未给出系统化的最优分解选择方法；
- **假设条件较强**：
  - A1/A2 要求 SCDC 系数矩阵全局 Lipschitz 且有界；
  - A4 要求沿闭轨的时变对一致性可镇定；
  - 这些条件在更一般（如定义域无界、模型存在奇异点）的系统上不一定成立；
- **最优性间隙不可忽略**：远离原点时，SCDC 不动点可能与真实 KKT 点有非平凡差距（在非完整积分器上代价高出 39%），限制了该方法在强非线性、远场操作场景下的最优性；
- **实验覆盖有限**：没有包含高维系统、大规模消融、不同 SCDC 分解的对比、嵌入式硬件实时性测试等；20 次蒙特卡洛在低维参数空间上尚可，但对高维系统说服力有限；
- **Horizon 缩放验证不完整**：SQP 因 fmincon 外层迭代次数随风ℓ变化，未能干净验证 O(ℓ²) 预测比；LPV-MPC 在 ℓ=160 时 QP 求解失败，也污染了数据；
- **鲁棒性分析偏初步**：对噪声和扰动的处理仅给出有界扰动下的可行性保证（Prop 8），未处理随机扰动或模型不确定性（列为未来研究方向）；
- **一步计算时延假设**：虽然考虑了计算延迟，但假设延迟恰好等于一个采样周期，对于计算时间可变或超过一个周期的真实场景需进一步扩展。

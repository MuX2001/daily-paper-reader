## 摘要
本文提出了一种求解遍历随机最优控制问题的新方法，该问题的动力学由受控随机微分方程驱动。该随机微分方程的系数是非自治的，但随时间周期变化。我们首先证明无限时域平均随机最优控制问题是遍历的，即值函数等于一个与初始条件无关的常数$ρ$。基于遍历性结果，我们构造了一个定义良好且随时间周期变化的辅助函数$w(t,x)$。我们可以证明$(w,ρ)$满足动态规划原理，并且是对应Hamilton-Jacobi-Bellman方程的粘性解。最后，我们将结果应用于遍历倒向随机微分方程的研究。我们的方法即使在齐次情形下也是新颖的。

## Abstract
In this article, we introduce a novel approach to solving the ergodic stochastic optimal control problem whose dynamics is driven by a controlled stochastic differential equation. The coefficients of this stochastic differential equation are non-autonomous but periodic in time. We first prove that the infinite horizon average stochastic optimal control problem is ergodic, i.e., the value function equals a constant $ρ$ which is independent of the initial conditions. Based on the result of ergodicity, we construct an auxiliary function $w(t,x)$ that is well-defined and periodic in time. We can prove that the pair $(w,ρ)$ satisfies the dynamic programming principle and is a viscosity solution of the associated Hamilton-Jacobi-Bellman equation. Finally, we apply our results to the study of ergodic backward stochastic differential equations. Our method is even new in the homogeneous case.

### 2. 论文提出的方法论

- **核心思想**：不同于已有文献（如 Arisawa-Lions, Bao-Tang 等）通过 α-折扣 HJB 方程的极限来刻画遍历最优控制，本文**直接**证明长期平均随机最优控制问题具有遍历性——即值函数等于不依赖初始状态和初始时间的常数 ρ——然后以此为基础构造辅助函数并推导 HJB 方程。
- **关键技术细节与步骤**：
  1. **假设条件**：在系数满足周期为 τ 的时间周期性、运行代价与漂移/扩散系数满足 Lipschitz 连续、漂移满足弱耗散条件（2⟨x, b(s,x,v)⟩ ≤ L′−λ|x|²）以及扩散非退化（σ|ξ|² ≤ ⟨σσ′ξ,ξ⟩ ≤ σ̄|ξ|²）的假设下展开分析。
  2. **遍历性证明**：利用 Lyapunov 条件（E|X_{t+τ}| ≤ γ|x|+K）和局部 Doeblin 条件，结合 Hairer-Mattingly [13] 的收缩方法，得到受控马尔可夫过程在周期 τ 上的收缩估计：‖Tφ‖_β ≤ ᾱ‖φ‖_β (ᾱ < 1)。利用系数的周期性，通过时间平移（Xt,x,u_{s}∘θ_τ = Xt+τ,x,u_{s+τ}）证明了该收缩可迭代，进而得到任意时刻的指数收敛速度。
  3. **极限存在性**：对任意固定控制 u(·)，证明 E[f(s+nτ, X_{s+nτ}, u(s+nτ, X_{s+nτ}))] 收敛至一个与初始条件无关的 τ-周期函数 ρ_u^s[f]，该函数关于 s 右连续且有界。进一步积分得到 ρ^u[f] = (1/τ)∫₀^τ ρ_u^s[f]ds，并证明它等于长期时间平均的极限。
  4. **构造辅助函数**：由于最优控制可能不存在，对每个 ε > 0，选取 ρ_ε > ρ−ε 对应的 ε-最优控制，定义辅助函数 J_ε(t,x,u(·)) = lim_{n→∞} ∫_t^{nτ} E[f − ρ_ε]ds，以及 W_ε(t,x) = sup J_ε(t,x,u(·))（限制在满足 ρ_u ≤ ρ_ε 的控制集上）。证明 W_ε 具有线性增长、关于 x 连续、关于 t 等度连续等性质。
  5. **取极限得到 w**：利用 Arzelà-Ascoli 定理，取 ε→0 的子序列极限得到 w(t,x) = lim_{ε→0} W_ε(t,x)，该函数为 τ-周期连续函数并满足线性增长条件。
  6. **动态规划原理**：对离散取值的停时 Θ 先用黏性拼接控制（先分段取 ε-最优控制再拼接）证明 DPP，再利用停时的离散逼近和单调收敛/控制收敛定理推广到一般停时，最终得到：
     w(t,x) = sup_{u(·)∈U_t} E[∫_t^Θ (f(s,X_s,u(s,X_s))−ρ)ds + w(Θ,X_Θ)]。
  7. **HJB 方程的粘性解**：基于 DPP，通过 Itô 公式和标准黏性解的局部化论证，证明 (w,ρ) 是周期 HJB 方程 ∂ₜφ + sup_{u∈U} {f + Dφ·b + ½tr(σσ′D²φ)} = ρ 的粘性解。
  8. **验证定理**：若存在光滑周期解 w ∈ C^{1,2} 且满足最大化条件 (5.2)，则可构造最优反馈控制，证明 w 为值函数且对应控制为最优。
  9. **遍历 BSDE 应用**：对固定控制 u 构造 w_u(t,x) = lim ∫_t^{nτ}(E[f]−ρ_u)ds，证明其满足相应的遍历 BSDE，且最优值函数 w 可通过"esssup"表示，从而将遍历随机最优控制问题与遍历 BSDE 建立联系。

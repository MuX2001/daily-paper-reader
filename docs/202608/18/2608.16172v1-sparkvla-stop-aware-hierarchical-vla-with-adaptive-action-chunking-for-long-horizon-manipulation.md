## 摘要
在分层视觉-语言-动作（VLA）系统的每个重新观察点，必须做出两个接口决策：何时终止当前子任务，以及执行所提出的动作分块的距离。这两个决策相互依赖——最佳停止点取决于执行器计划做什么，而最佳执行长度取决于子任务边界所在——然而现有架构将它们孤立地评估，这种不对称性使得任何模块都无法单独克服。我们提出了SparkVLA，一种停止感知的分层VLA，通过将两个决策表述为单一排序来解决这种相互依赖：Stop在统一候选集中与每个动作前缀长度竞争，系统选择得分最高的选项，无需阈值调整且仅需离线排序偏好。锚定条件上下文编码模块缓存历史感知的子任务锚定编码、起始状态记忆和目标语义，引导视觉标记剪枝朝向任务相关区域；停止感知的动作前缀选择头在分块边界通过全自注意力对所有候选进行评分以提高效率。在RoboCerebra上，SparkVLA实现了47.12%的成功率，超过官方分层基线30.57%，超过最强可复现方法26.83%。在多步任务上的真实机器人实验进一步验证了这些增益在物理硬件上的效果。

## Abstract
At every re-observation point in a hierarchical Vision-Language-Action (VLA) system, two interface decisions must be made: when to terminate the current subtask and how far to execute the proposed action chunk. These decisions are mutually dependent---the optimal stopping point depends on what the executor plans to do, while the optimal execution length depends on where the subtask boundary lies---yet existing architectures evaluate them in isolation, an asymmetry neither module can overcome alone. We present SparkVLA, a stop-aware hierarchical VLA that resolves this mutual dependency by formulating both decisions as a single ranking: Stop competes against every action-prefix length in a unified candidate set, and the system selects the highest-scoring option, eliminating threshold tuning and requiring only offline ordinal preferences. An Anchor-Conditioned Context Encoding module caches a history-aware subtask anchor encoding onset-state memory and goal semantics, guiding visual-token pruning toward task-relevant regions; a Stop-Aware Action-Prefix Selection head scores all candidates via full self bnattention at chunk boundaries for efficiency. On RoboCerebra, SparkVLA achieves 47.12% success rate, surpassing the official hierarchical baseline by 30.57% and the strongest reproducible method by 26.83% Real-robot experiments on multi-step tasks further validate these gains on physical hardware.

### 1. 论文的核心问题与整体含义

**研究动机与背景：**

- 近年来，视觉-语言-动作（VLA）模型在机器人操作任务上表现出色，但大多在短轨迹段上训练，难以完成长视界、多技能组合任务。
- 分层VLA架构（高层VLM规划器 + 低层VLA执行器）成为解决长程操作的主流方案，但在每次重新观测（re-observation）时面临两个互相耦合的接口决策：
  - **何时终止当前子任务**（termination）
  - **动作块执行多长**（execution horizon）
- 论文指出，这两个决策存在**相互依赖关系**：最优停止点取决于执行器的下一步计划，而最优执行长度取决于子任务边界的位置。然而，现有方法将两者分开处理——终止检测器不知道执行计划，执行长度预测器无法判断子任务是否完成——形成了一种“信息不对称”。

**核心含义：**

SparkVLA 将这两个决策统一为一个**单一排序问题**：让“停止”（Stop）与所有可能的动作前缀长度（action-prefix length）在同一个候选集合中共同打分竞争，选择得分最高者即可。这一设计消除了阈值调参，只需离线序数偏好监督，从根本上解决了两个决策的耦合问题。

### 2. 论文提出的方法论

**核心思想：**

> 将“子任务终止”和“执行长度选择”统一为对统一候选集的排序/打分问题，由同一评分头在共享表征下联合评估。

**关键技术细节：**

**(a) 统一候选集与联合评分**

- 定义候选集 C = {0, 1, ..., H}，其中 0 表示 Stop，n（n≥1）表示执行动作块的前 n 个动作。
- 选择器通过评分函数 f_sel(At, αk, mt) → C，为所有候选生成分数，取 argmax 作为决策，无需独立终止检测器或阈值。

**(b) Anchor-Conditioned Context Encoding（锚定条件上下文编码）**

- **历史感知子任务锚点（History-Aware Subtask Anchor）**：
  - 在子任务开始时，从规划器的倒数第二层提取隐藏状态作为“原始锚点” ˆαk。
  - 维护锚点历史池 Ak = {ˆα1, ..., ˆα_{k-1}}，通过自注意力与当前锚点融合，得到历史感知锚点 αk——编码了起始状态记忆、目标语义以及之前子任务对工作空间的改变。
  - 锚点每子任务只计算一次并缓存。
- **锚点引导的视觉剪枝（Anchor-Guided Visual Pruning）**：
  - 利用可微分的 Grid-Sampler，以锚点 αk 为条件预测 K 个归一化 2D 坐标，通过双线性插值提取任务相关区域的稀疏视觉令牌，将每相机的视觉序列从 N 压缩到 K。
- **高层隐藏特征**：剪枝后的视觉令牌与本体感知状态、子任务命令嵌入拼接，通过前 ℓm 层 VLM 主干（带LoRA）得到高层隐藏特征 mt，作为决策上下文。

**(c) Stop-Aware Action-Prefix Selection（停止感知动作前缀选择头）**

- 每个候选（Stop和所有前缀长度）初始化为可学习嵌入或“前缀最后一个动作的MLP编码 + 长度嵌入”；
- 通过完整的自注意力 Transformer 处理所有候选 token，实现候选之间的相互信息流通；
- 最终由评分层输出每个候选的标量分数，取最高分对应决策；
- 只在决策边界（chunk 边界）调用，而非每一步，兼顾效率与准确性。

**(d) 训练目标（离线序数偏好）**

- 优先级（ρ）赋值规则基于离线轨迹的子任务边界标注：
  - 子任务完成后：Stop 优先级最高；
  - 子任务完成前：覆盖前缀（n ≥ n*）优于未覆盖前缀，且短覆盖比长覆盖更优；
  - 失败轨迹：所有动作前缀并列高于 Stop（鼓励继续探索）；
  - 训练时对边界标注加入均匀随机扰动（±2）以增强鲁棒性。
- 损失函数两部分：
  - **L_rank**：对候选对做二元交叉熵排序损失；
  - **L_stop**：对 Stop 分数与 log-sum-exp 连续动作分数进行对比的辅助损失。

**(e) 确认窗口**

- 短确认窗口过滤瞬态分数波动后，再确认停止决策。

### 3. 实验设计

**基准与数据集：**

1. **RoboCerebra**（主要基准）：
   - 1000 条标注轨迹，100 个任务变体，平均 9.1 个子任务、2972 步。
   - 6 个条件：Dynamic（动态/随机化布局与观测）、Memory（记忆）、Mix、Ideal（静态控制）。
   - 60 个留出用例，每次 10 次 rollout，共 600 集。
   - 评估指标：Success Rate（SR）、Avg（微平均SR）、Stop Acc.。

2. **LIBERO**（辅助基准）：
   - 包括 Spatial、Object、Goal、Long 四个套件，40 个任务，每任务 100 集。
   - 子任务标注来自 LaRA-VLA。

3. **真实机器人实验**：
   - AirbotPlay 双臂平台，两个腕部 + 一个头部 RGB 相机。
   - 三个多步任务：Shelf Arrangement（6子任务）、Drawer Restocking（6子任务）、Tea Preparation（12子任务）。
   - 每任务 50 条演示，50 次 rollout。

**对比方法：**

- **独立 VLA 基线**：OpenVLA-OFT、SmolVLA、π0.5。
- **分层 VLA 基线**：HPE（官方 RoboCerebra 基线）、Mem-0（可复现的开源分层 VLA）。
- **SparkVLA 变体**：更换低层执行器（OpenVLA-OFT、SmolVLA），验证高层系统泛化性。

**消融实验：**

1. 分块选择方法与停止集成方式；
2. 上下文编码（无剪枝/空间剪枝/原始锚点/历史感知锚点）；
3. 选择器放置位置（低层执行器 vs. 高层规划器主干）；
4. 推理调度策略（命令缓存、边界调用频率）。

### 6. 论文的主要结论与发现

1. **统一决策优于独立评估**：将终止与执行长度作为统一候选集打分后，RoboCerebra 的 Stop Acc. 从 80.37% 提升至 96.65%，SR 从 42.53% 提升至 47.12%，验证了“相互依赖必须联合评估”的核心假设。

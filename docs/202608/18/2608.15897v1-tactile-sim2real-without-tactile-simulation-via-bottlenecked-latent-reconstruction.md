## 摘要
机器人传感器设计，特别是触觉传感器，高度多样化且发展迅速。在仿真中对每种传感器进行建模需要大量的领域专业知识，而计算近似可能会降低仿真信号的保真度。我们提出了通过瓶颈潜变量重建实现Sim2Real（SBLR）的框架，该框架完全避免了针对特定传感器的仿真，方法是：（1）在仿真器原生的预言传感器上训练策略，该传感器易于构建，无需对任何特定传感器进行建模（例如，我们使用点云和指尖力作为触觉预言）；（2）在推理时将真实传感器潜变量嵌入对齐到预言传感器的潜变量嵌入。策略训练分两个阶段进行：策略首先从预言传感器潜变量中学习，然后通过瓶颈潜变量重建使其适应使用真实传感器而非预言传感器时预期的信息损失。预言传感器与真实传感器之间的对齐是从仿真和真实世界中收集的非配对随机播放数据中学习的，使用基于最近邻伪对训练的整流流变换网络。在三个接触密集型任务上的仿真实验表明，SBLR匹配或接近直接访问触觉仿真的预言传感器的性能。使用GelSight Mini和DIGIT传感器进行的插销插入和齿轮啮合硬件实验展示了85-97.5%的零样本成功率，无需任何特定传感器建模或校准，优于基于物理的触觉仿真基线7.5-15%。

## Abstract
Robot sensor designs, particularly tactile sensors, are highly diverse and evolve rapidly. Modeling each sensor in simulation demands substantial domain expertise and computational approximations can degrade the fidelity of the simulated signals. We propose Sim2Real via Bottlenecked Latent Reconstruction (SBLR), a framework that avoids sensor-specific simulation entirely by (1) training policies on a simulator-native oracle sensor that is easy to construct without modeling any particular sensor (e.g. we use a point-cloud and finger-tip forces as a tactile oracle), and (2) aligning real sensor latent embeddings to those of the oracle sensor at inference time. Policy training proceeds in two-stage: the policy first learns from the oracle sensor latents, then a bottlenecked latent reconstruction adapts it to the information loss expected when using the real sensor instead of the oracle. The alignment between oracle and real sensor is learned from unpaired random-play data collected in both simulation and the real world, using rectified-flow-based transformation networks trained on nearest-neighbor pseudo-pairs. Simulation experiments on three contact-rich tasks show that SBLR matches or approaches the performance of an oracle with direct access to tactile simulation. Hardware experiments on Peg Insertion and Gear Meshing with GelSight Mini and DIGIT sensors demonstrate 85-97.5% zero-shot success without requiring any sensor-specific modeling or calibration, outperforming a physics-based tactile simulation baseline by 7.5-15%.

- **核心问题**：在机器人操作任务中，触觉传感器（tactile sensors）对接触丰富的操作至关重要。然而，触觉传感器**型号高度多样、迭代速度快**，在仿真环境中为每一种传感器建立物理模型既需要深厚的领域专业知识（涉及传感器物理和计算仿真方法），又因计算近似而难以保证信号保真度。这导致基于触觉的 Sim2Real 迁移面临很高的工程门槛。
- **现有方法的不足**：物理触觉仿真（如 Taxim、TacSL 等）虽已取得进展，但每种传感器设计都需要单独建模和校准，且仿真读数与真实读数仍存在差距，通常需要额外的域随机化（Domain Randomization）来弥合，而域随机化可能**洗去对精细操作至关重要的触觉细节**。
- **本文的解决思路**：提出 **SBLR（Sim2Real via Bottlenecked Latent Reconstruction，瓶颈潜变量重建的Sim2Real）** 框架，**完全避免传感器专用仿真**：
  1. 使用模拟器原生的"预言传感器"（oracle sensor）训练策略——该传感器易于构造，无需建模任何具体传感器（本文采用点云+指尖力的 **PFC，Point Force Composition** 作为触觉预言）；
  2. 在推理时，将真实传感器读取的潜变量表征对齐到预言传感器的潜变量空间。
- **整体含义**：该方法大幅降低了触觉 Sim2Real 的进入门槛——无需对具体触觉传感器进行物理建模或校准，即可实现零样本（zero-shot）真实世界部署，且在不同触觉传感器之间具有通用性。

## 2. 论文提出的方法论

### 2.1 核心思想

- 在仿真中训练策略时，使用比任何真实传感器**信息量更丰富或至少相当**的预言传感器（PFC）；
- 由于预言传感器信息量通常大于真实传感器，直接部署会使策略因观测不匹配而性能下降；
- 因此设计**两阶段 RL 训练**：先让策略学会使用干净、丰富的 PFC 信息完成任务；再通过**瓶颈化潜变量重建（bottlenecked latent reconstruction）**让策略适应"仅通过真实传感器可获得的信息量"带来的损失。

### 2.2 整体框架流程（四步）

1. **对齐数据收集**：在仿真和真实世界中分别收集**非配对（unpaired）随机交互数据**（random-play data）。物体固定在同一已知位姿，机器人执行自动随机探测接触。仿真侧记录 PFC 读数，真实侧记录触觉读数。
2. **编码器与变换网络训练**：
   - PFC 编码器 \(f_{pfc}\)：点云部分使用 Point-MAE，力部分使用自编码器，两者拼接得到 PFC 潜变量 \(z_p\)；
   - 触觉编码器 \(f_c\)：对视觉触觉传感器图像使用 MAE 编码，多传感器潜变量拼接为 \(z_c\)；
   - **伪配对（pseudo-pairing）**：通过最近邻搜索，基于相邻两步本体感觉转移 \((q_{t-1}, q_t)\) 的相似度，将真实数据和仿真数据配对；
   - 训练两个 **Rectified Flow（整流流）** 变换网络 \(f_{p\to c}\)（预言→真实）和 \(f_{c\to p}\)（真实→预言），用于跨模态潜变量映射。RF 能建模多模态分布，适用于预言与真实传感器之间存在信息不对称的场景。
3. **Stage 1 RL**：在仿真环境中，仅使用 PFC 观测训练策略 \(\pi_\theta(o, z_p)\)（PPO）。PFC 编码器冻结。训练时对 PFC 施加轻微随机化（位置噪声 0.5mm、旋转噪声 0.29°、力噪声 0.3N），以减轻对理想化 PFC 的过拟合。
4. **Stage 2 RL 适应（瓶颈化潜变量重建）**：
   - 从 Stage 1 策略初始化；
   - 每个时间步执行双变换：先将仿真 PFC 潜变量 \(z_p\) 映射为估计的真实传感器潜变量 \(\hat{z}_c = f_{p\to c}(z_p)\)（模拟"真实传感器能感知到什么"），再映射回 PFC 空间 \(\hat{z}_p = f_{c\to p}(\hat{z}_c)\)；
   - 用 \(\hat{z}_p\) 作为策略观测进行训练。由于信息瓶颈的存在，\(\hat{z}_p\) 与原始 \(z_p\) 存在差异，策略因此暴露在"真实传感器信息损失"之下，学会在信息受限时仍完成任务。

### 2.3 推理阶段

- 真实部署时仅有真实触觉读数 \(c\)，将其编码后通过 \(f_{c\to p}\) 映射到 PFC 潜空间：
  
  \[
  a = \pi_\theta\left(o,\; f_{c\to p}(f_c(c))\right)
  \]
  
- 编码器和变换网络在推理时均冻结。

### 2.4 关键技术细节

- **Rectified Flow 训练损失**：
  \[
  \mathcal{L}_{RF} = \mathbb{E}_{t, z_0, z_c}\left[\|v_\psi(z_t, t, z_p) - (z_c - z_0)\|_2^2\right]
  \]
  其中 \(z_t = (1-t)z_0 + t z_c\)，推理时通过求解 ODE 积分生成预测潜变量。
- **伪配对相似度**：
  \[
  D(S^s_t, S^r_t) = \|q^s_t - q^r_t\|_2 + \lambda \|q^s_{t-1} - q^r_{t-1}\|_2, \quad \lambda < 1
  \]
  只使用本体感觉，不使用动作命令（因仿真与真实动力学不同）。

## 3. 实验设计

### 3.1 仿真实验

- **仿真环境**：Isaac Lab 上的三个 Factory 任务——**Peg Insertion（插销插入）、Gear Meshing（齿轮啮合）、Nut Threading（螺母拧紧）**，共 256 个评测回合。
- **实验目的**：将模态对齐（PFC↔触觉图像）与动力学差异解耦，单独评估 SBLR 的性能。
- **两个仿真环境**：
  - 名义环境（nominal）：仅提供 PFC，无触觉图像仿真；
  - 代理真实环境（proxy-real）：用 TacSL 物理触觉仿真替代 PFC，模拟"真实世界"用于迁移评测。
- **对比方法**：
  - **DCP**（Discrete Contact Position）：仅用离散接触位置，避免触觉仿真；
  - **OT**（Optimal Transport）：用最优传输代替最近邻搜索+整流流进行模态对齐；
  - **No Tactile**：无触觉信息基线；
  - **Ablation（PFC + RF）**：移除 Stage 2 RL 适应的消融；
  - **Image Oracle**：在代理真实环境中直接用触觉图像训练 RL（使用与 SBLR 相同的冻结 MAE 编码器），代表直接访问触觉仿真可达到的最佳性能；
  - **PFC Oracle**：Stage 1 PFC 策略在 PFC 输入下的性能上界。

### 3.2 真实世界实验

- **任务**：Peg Insertion 和 Gear Meshing（3D 打印 IsaacLab 仿真资产）。
- **传感器**：**GelSight Mini** 和 **DIGIT** 两种视觉触觉传感器，各 40 个评测回合。
- **对比方法**：
  - **TacSL**（物理触觉仿真基线）：使用 Taxim 校准触觉传感器，配合图像增广和动力学随机化训练 CNN 编码器；
  - **Ablation（PFC + RF）**：无 Stage 2 的消融。
- **对齐数据**：每任务每传感器在真实世界收集 256 个 episode（约 40 分钟，全自动），仿真 4096 个 episode。
- **动力学域随机化**：关节摩擦、物体摩擦、关节控制刚度、传感器弹性体刚度均做了随机化，以应对动力学差距。

## 6. 论文的主要结论与发现

- **仿真实验结论**：
  - SBLR 在三个任务上均显著优于其消融（PFC + RF）特别是 Nut Threading 上提升明显（75.9% vs 48.2%），说明 Stage 2 瓶颈化重建对弥合信息缺口至关重要；
  - SBLR 接近 PFC Oracle 和 Image Oracle 的性能（如 Peg Insertion 87.4% vs 88.5%/86.6%），说明信息瓶颈导致的性能损失很小；
  - DCP 因触觉信息精度不足表现很差（22.5-35.7%）；
  - OT 对齐与最近邻搜索+RF 性能相近，但 OT 本质上车削的是消融水平的性能（72.9%/75.4%/52.3%，接近 Ablation），SBLR 仍明显优于 OT。
- **真实实验结论**：
  - SBLR 在四种配置（2 任务 × 2 传感器）上均取得 **85.0-97.5%** 的零样本成功率；
  - SBLR 在全部配置上优于 TacSL 物理仿真基线（高出 **7.5-15%**），且无需传感器建模或校准；
  - **在信息量较少的 DIGIT 传感器上，SBLR 相对消融的提升更大**（如 Gear Meshing 85.0% vs 75.0%），说明信息缺口越大，瓶颈化重建越重要；
  - 物理触觉仿真因建模假设误差和校准误差导致性能受限，而 SBLR 直接使用真实触觉数据训练对齐模块，避免了这一误差源。

## 7. 优点

- **方法层面的创新性**：
  - 提出"预言传感器 + 非配对随机数据 + 整流流变换"的组合，**完全绕开传感器专用物理仿真**，大幅降低触觉 Sim2Real 工程门槛；
  - **瓶颈化潜变量重建（两阶段 RL）** 的设计巧妙：刻意在训练中引入信息瓶颈，让策略学会在真实传感器信息受限条件下仍能完成任务，而非简单追求"映射精度"；
  - 使用 **Rectified Flow** 建模一对多映射，符合"一个真实触觉读数可能对应多个 PFC 状态"的信息不对称特性；
  - 对齐数据为**完全自动收集的随机交互数据**，无需人工遥操作或专家示范，可扩展性强。
- **通用性**：
  - 框架与具体传感器无关，同一仿真策略可通过轻量级 Stage 2 适应不同传感器（GelSight Mini 和 DIGIT），避免针对每种传感器重新训练大模型；
  - 对视觉以外的感知模态也具有潜在适用性。
- **实验设计的优点**：
  - 仿真实验将模态差距与动力学差距解耦，评估更清晰；
  - 设置了 PFC Oracle 和 Image Oracle 两个上界，便于解读性能差距的来源；
  - 对物理仿真基线（TacSL）给予了较充分配置（CNN 端到端、两阶段课程、图像增广），对比较为公平。

## 8. 不足与局限

- **动力学差距未解决**：SBLR 仅解决模态差距（PFC↔真实传感器），Sim2Real 中的动力学差距（关节摩擦、物体物理属性等）仍需依赖域随机化等传统手段处理。
- **对齐数据的覆盖限制**：对齐数据采用"物体固定 + 随机探测接触"的收集方式，对高精度任务（如 Nut Threading 中精细的螺纹接触）可能无法高效覆盖推理时的关键接触分布；作者也提到人工遥操作可能改善数据质量与覆盖率。
- **物体位姿假设局限**：数据收集要求物体固定在已知位姿（以便使用本体感觉建立伪配对），若部署场景中物体位姿变化或物体更换，该方法需要重新收集对齐数据。
- **真实实验的统计显著性有限**：每种配置仅 40 个回合，随机波动可能导致性能估计不够精确；表内未报告方差或置信区间。
- **对齐模块误差依赖第二阶段的经验性补偿**：伪配对本身存在近似误差（如剪切力不能由本体感觉状态直接反映），变换网络误差的补偿主要依赖 Stage 2 RL 的经验适应，缺乏理论保证。
- **未涉及多指协同情况**：实验仅使用单个手指的触觉传感器（左指尖），未验证多传感器融合场景下框架的效果。
- **计算资源细节缺失**：未报告训练时长和硬件配置，难以评估方法在资源受限场景的可行性。

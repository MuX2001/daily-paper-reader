## 摘要
视觉-语言-动作（VLA）模型在实际部署中常常受到效率与性能权衡、跨实体泛化以及执行平滑性的制约。我们提出了NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，从而优化计算资源和模块化程度。为弥合异构机器人之间的语义鸿沟，我们引入了GESTURE-7，一种统一的语言接地动作表示。此外，我们的引导动作算法通过基于掩码的平滑性约束来强制运动学连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上实现了85.5%的平均成功率，并将动作生成速度提升了约2.7倍。这种异步设计为实际机器人应用提供了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **研究背景**：机器人操作正从模块化流水线向端到端学习范式转变，视觉-语言-动作（VLA）模型将感知、语言与控制统一在单一架构中，实现了自然语言指令跟随与复杂任务执行。自 RT-1 奠定 Transformer 策略基础以来，OpenVLA、InternVLA 系列等推动了该领域的快速发展。
- **核心问题**：当代 VLA 模型在实际部署中面临三大瓶颈：
  - **效率-性能权衡困境**：单一同步架构采用统一时间分辨率，无法同时支持低频语义推理与高频电机控制的需求；
  - **跨本体泛化障碍**：不充分的具身表示阻碍了跨形态泛化，将连续运动学映射为离散 token 需要庞大词表和大量演示数据，难以在异构平台间统一动作语义；
  - **执行平滑性不足**：异步实时推理与动作块生成之间的时间错配，常导致明显的抖动和执行不连续。
- **解决思路**：受认知科学中"快慢双系统"（System 1/System 2）范式启发，论文提出 **NebulaVLA**，通过异步双频架构、统一动作表示 GESTURE-7 以及引导动作（Guide Action）机制，系统性解决上述三大问题。

## 2. 论文提出的方法论

### 2.1 核心思想

NebulaVLA 采用**异构双频架构**，将高层语义推理（慢系统）与低层动作控制（快系统）解耦：

- **System 2（S2）**：以 Qwen3-VL 为骨干的视觉-语言模型，运行在约 10 Hz，负责高层次语义规划（理解指令、场景感知、生成抽象动作引导）。
- **System 1（S1）**：基于扩散 Transformer（DiT）的低层控制器，运行在约 20 Hz，接收 S2 的引导与高频视觉输入，生成具体执行动作。

### 2.2 关键技术细节

**（1）GESTURE-7 统一动作表示**

- 将末端执行器状态编码为 7 维向量：`[x, y, z, r, p, w, gesture]`，其中 `(x, y, z)` 为笛卡尔位置（厘米），`(r, p, w)` 为姿态角（整数度），`gesture` 为自然语言关键词（如 "grasp"、"push"）。
- 不同形态的机器人执行相同动作时共享同一关键词：例如平行夹爪和灵巧手执行抓取动作统一表示为 `grasp`。
- 该设计弥合了异构机器人间的语义鸿沟，并天然支持语言条件下的强化学习。

**（2）三阶段训练流程**

- **Stage 1（S2 监督微调）**：三类任务组共五种任务——空间定位（末端姿态回归、2D 关键点回归）、轨迹预测（2D 路径点与 3D 轨迹点预测，2 Hz）、推理与规划（链式思维子任务分解 + 未来 GESTURE-7 轨迹生成）。
- **Stage 2（S2 强化学习）**：基于 GRPO 算法，保留 Stage 1 的任务套件，使用专门设计的奖励函数（GESTURE-7 距离、关键点定位奖励、路径点奖励、轨迹奖励、格式奖励）增强轨迹规划能力。
- **Stage 3（S1 监督微调）**：联合优化 S2 与 S1 权重（冻结视觉编码器），采用加权流匹配损失（flow-matching loss），损失仅作用于掩码 M=0 的新生成动作区域。

**（3）Guide Action 机制**

- 受图像外推（Image Outpainting）启发，将动作块拼接嵌入生成流程中，而非事后平滑。
- 具体做法：生成下一动作块时，以先前块中**未执行的动作**（如 a4–a7）作为引导锚点，强制新块起点与已执行轨迹对齐，实现无缝边界过渡。
- 训练时引导动作点数从 0 到 3 随机采样，以适应不同推理延迟。
- 去噪过程的条件概率模型为：`pθ(A(t-1)_full | At_full, A_prior, τ)`，其中 `A_prior` 为已执行历史动作（可选）与待执行的引导动作。
- 掩码强制约束公式：`A(t-1)_full = M ⊙ A(t-1)_prior + (1-M) ⊙ A(t-1)_noisy`，其中 M 的 [1..k] 位置为 1（锚点区严格保留），[k+1..T] 为 0（生成区由模型预测）。

## 6. 论文的主要结论与发现

1. **整体性能领先**：NebulaVLA 在 LIBERO-Plus 上取得 85.5% 的平均成功率，超越 InternVLA-M1（81.3%，+4.2%）、OpenVLA-OFT+（79.6%）、GR00T N1.5（59.0%）和 π0.5（58.0%）。
2. **各维度鲁棒性突出**：在 Robot Initial State、Layout 等维度显著提升（约 8% 增益），Spatial、Object、Goal 维度领先 6–10%；但在 Camera 维度略低于 InternVLA-M1。
3. **异步架构显著提升部署效率**：真实世界中，异频架构将平均推理延迟从同频的 115 ms 降至 42 ms（约 2.7× 加速），同时提升成功率（Task 1：87.14%→92.08%；Task 2：90%→92.5%）。
4. **三阶段训练策略有效**：完整的 Stage 1+2+3 训练比跳过 SFT 或 RL 的设置分别提升 1.7% 和 2.5%。
5. **Guide Action 有效抑制抖动**：相比原生异步算法，7 个关节的平均 Jerk 降低 25.6%，其中关节 12 和 13 分别降低 41.2% 和 45.1%。

## 7. 优点

### 7.1 方法设计亮点

- **架构创新性强**：将"快慢认知"范式引入 VLA 模型，异步双频解耦是应对"推理深度"与"控制实时性"矛盾的结构性方案，而非局部调优；且天然支持分布式部署。
- **动作表示有通用性**：GESTURE-7 用语言关键词统一异构机器人的动作语义，设计简洁但切中跨本体泛化痛点，且兼容强化学习。
- **平滑机制从"事后补救"变为"内生约束"**：Guide Action 将运动连续性嵌入扩散生成过程而非事后滤波，方法论上更优雅，且自适应引导点数增强了鲁棒性。
- **训练流程逻辑清晰**：三阶段渐进式训练（SFT→RL→S1）各阶段目标明确，且强调训练与推理频率对齐。

### 7.2 实验设计亮点

- 采用专门针对鲁棒性评估的 LIBERO-Plus benchmark，比标准 LIBERO 更能区分模型在扰动下的表现差异；
- 真实世界实验提供推理延迟和 Jerk 等面向部署的量化指标，而非仅关注成功率；
- 对训练策略进行系统性消融，验证了每个组件的有效性。

## 8. 不足与局限

### 8.1 实验层面的不足

- **真实世界评估规模过小**：仅 2 个任务、单台机器人平台，缺乏多机器人、多场景的普遍性验证；
- **跨本体泛化缺乏直接证据**：论文声称 GESTURE-7 支持跨本体泛化，但实验未在异构机器人间做迁移测试，论证力度不足；
- **Camera 维度性能退化未彻底解决**：作者归因于 GESTURE-7 固定的视觉-空间映射假设，但未提出有效补偿方案；
- **基线覆盖不全**：真实世界实验仅对比 InternVLA-M1 一个基线，且未与采用后处理平滑方法的方案对比，无法直接证明 Guide Action 优于现有平滑手段；
- **统计稳健性存疑**：未报告多次运行的方差、置信区间或显著性检验，10 次试验的 Jerk 数据可能受随机性影响。

- **频率配置是静态的**：10 Hz/20 Hz 为经验确定，不同任务域可能最优配置不同，自适应频率调度是未解决的开放问题；

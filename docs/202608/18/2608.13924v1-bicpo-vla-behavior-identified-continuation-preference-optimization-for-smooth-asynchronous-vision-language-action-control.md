## 摘要
请求到交接的间隙有三个耦合来源：请求时预期行为的模糊性、动作生成期间累积的物理状态漂移，以及新动作最终接管控制时的残余不兼容性。BICPO-VLA依次解决了这些问题。首先，一个指令感知的因果历史编码器识别命令和当前任务进度所支持的行为。其次，顺序Haar子空间生成将每个动作块分解为互补的成对脚手架系数和残余系数，实现两个专门的生成阶段，随后进行精确重构。通过减少原始动作空间中的迭代细化，它缩短了机器人在新块可用之前继续移动的间隔时间。最后，BICPO将已知的传出动作滚动到实际的交接状态，并在行为匹配的候选者之间应用参考相对的Flow-DPO，使生成的动作块适应剩余的请求到交接不匹配，而不改变其预期行为。

## Abstract
The request-to-handoff gap has three coupled sources: ambiguity about the behavior intended at request time, physical-state drift accumulated during action generation, and residual incompatibility when the new action finally assumes control. BICPO-VLA addresses them in sequence. First, an instruction-aware causal history encoder identifies the behavior supported by the command and current task progress. Second, sequential Haar subspace generation decomposes each action chunk into complementary pairwise scaffold and residual coefficients, enabling two specialized generation stages followed by exact reconstruction. By reducing iterative refinement in the original action space, it shortens the interval over which the robot continues moving before the new chunk becomes available. Finally, BICPO rolls the known outgoing actions to the actual handoff state and applies reference-relative Flow-DPO among behaviorally matched candidates, adapting the generated chunk to the remaining request-to-handoff mismatch without changing its intended behavior.

## 1. 论文的核心问题与整体含义（研究动机和背景）

**核心问题：异步视觉-语言-动作（VLA）控制中的"请求到交接间隙"（request-to-handoff gap）问题。**

在异步动作分块（asynchronous action chunking）机制下，机器人会先发出一个动作块并开始执行，同时模型在后台推断下一个动作块。新动作块在一个运动上下文中被请求，却在另一个状态中接管控制。因此，即使语义预测正确，仍可能引发边界跳变或运动趋势断裂。

该间隙有三个耦合的来源：
- **行为意图歧义**：请求时对新动作支持哪种行为存在模糊性；
- **物理状态漂移**：动作生成期间机器人持续运动，积累了状态偏差；
- **残余不兼容性**：新动作实际接管控制时与当前状态不匹配。

**核心洞察**：一个行为定义的是一个"动作族"（behavior-conditioned action fiber），而非唯一轨迹。同一行为族内的成员在任务语义上等价，但局部运动和交接兼容性不同。现有方法（记忆增强、高效生成、异步策略等）虽各有所长，但未将行为身份、实现结构与交接条件联合分离。这三个决策受不同约束支配：行为识别须绑定指令与任务进度，实现结构须保留表达力且无重构瓶颈，交接适配须动态响应推断期间的状态漂移——将它们混入单一预测会导致延迟变化时无法判断应调整哪一部分。

## 2. 论文提出的方法论

### 2.1 整体框架：三阶段分解

BICPO-VLA 将异步控制问题分解为三个顺序解决的任务：

1. **行为识别**：由指令感知的任务进度推理和行为记忆固定行为身份；
2. **Haar结构化实现**：用正交Haar变换将动作块分解为互补系数；
3. **交接条件化偏好选择**：将已知传出动作滚动到交接状态，用Flow-DPO在语义匹配的候选间进行选择。

### 2.2 指令接地行为识别（Instruction-Grounded Behavior Identification）

- 视觉 token 先通过指令引导的注意力路由（instruction-aware visual routing）：\( \tilde{V}_t = V_t + \mathrm{Attn}(\mathrm{LN}(V_t), L_b, L_b; M_l) \)，即先用语言特征过滤与指令无关的视觉证据，再做历史融合；
- 因果历史编码器（基于因果 Mamba 块）聚合路由后的观测与已执行命令，得到行为状态 \( z_r \)；
- 阶段条件解码器结合检索到的长时记忆 \( m_r \)，预测行为先验 \( \mu_r \)；
- 行为条件 \( b_r \equiv (\ell, z_r, m_r, \mu_r) \) 定义了动作纤维 \( F_r = \{A \in \mathcal{A} : A \models b_r\} \)。

### 2.3 交接条件的 Haar 实现（Handoff-Conditioned Haar Realization）

- **滚动交接上下文**：将已知的传出命令序列通过冻结的动作状态模型滚动（rollout）到实际交接状态 \( \bar{h}_{r,k} \)，并结合推断期间位移 \( \Delta h_{r,k} = \bar{h}_{r,k} - h_r \)，投影为交接条件 \( g_{r,k} \)。绝对项描述传递时的运动语境，差分项揭示推断期间执行推进了多少，二者结合可区分不同的传出趋势；
- **互补坐标（Haar 变换）**：对偶数长度动作块 \( A \)，执行单层 Haar 变换得到脚手架系数 \( C \)（配对动作之和）与残余系数 \( D \)（配对动作之差）。变换正交且重构精确：\( [C; D] = W_H A, \ A = W_H^\top [C; D] \)；
- **有序生成**：先用脚手架系数建立动作块级运动骨架（式11-13），再用停梯度的脚手架生成残余细节（式14-16），最后通过固定逆变换精确重构动作块（式17）。监督训练损失为 \( \mathcal{L}_{\text{struct}} = \frac{1}{2}(\| \hat{v}_C - (\epsilon_C - C^*)\|_2^2 + \| \hat{v}_D - (\epsilon_D - D^*)\|_2^2) \)。

### 2.4 行为识别延续偏好优化（BICPO）

- **同纤维配对**：在共享条件 \( \chi_{r,k} = \{\Phi_r, z_r, m_r, \mu_r, g_k\} \) 下用不同流噪声采样两个候选，获得同一行为的替代实现；
- **延续代价**：定义零阶交接跳跃代价 \( J_{\text{jump}}(A) = \|a_0 - u_{r+k-1}\|_W^2 \) 和一阶运动趋势失配代价 \( J_{\text{trend}}(A) = \|(a_0 - u_{r+k-1}) - (u_{r+k-1} - u_{r+k-2})\|_W^2 \)，合并为 \( J_{\text{cont}} = \lambda_0 J_{\text{jump}} + \lambda_1 J_{\text{trend}} \)；
- **参考相对 Flow-DPO**：定义两阶段能量 \( E_\theta(A | \chi) = \frac{1}{2}(E_\theta^C(C|\chi) + E_\theta^D(D|C,\chi)) \)，计算候选对能量差与冻结参考模型的相对变化 \( \Delta_\theta = [E_\theta(A^-) - E_\theta(A^+)] - [E_{\text{ref}}(A^-) - E_{\text{ref}}(A^+)] \)，损失为 \( \mathcal{L}_{\text{pref}} = -q \log \sigma(\beta \Delta_\theta) \)，并附加偏好候选能量维持项和回放损失。只更新 Pψ、Wg（零初始化）和部分专家参数，冻结语义通路；
- **可移植性**：该参考相对 DPO 目标不依赖 BICPO-VLA 特有组件，可直接应用于 π0.5 流匹配、Legato 和 RTC 等宿主策略，仅使用宿主原生条件流能量。

## 6. 论文的主要结论与发现

1. **三阶段分解有效**：行为识别、Haar 结构化实现和延续偏好三种约束互补，联合贡献优于任一两两组合，去除任一组件均有可测量性能下降（CALVIN 平均链长从 4.520 降至 4.396–4.490）；
2. **CALVIN 长时程优势**：BICPO-VLA 平均链长 4.52、五子任务完成率 80.7%，超过最强基线 B-VLA 的 4.36/77.3%，且优势随链深增大而保持；
3. **RoboTwin 双臂稳健性**：十个任务全面超越 B-VLA 4–8 个百分点，总体成功率从 60.4% 提升至 65.8%；
4. **DPO 是延续优化的关键**：直接 SFT 虽然能降低连续代价但严重损害成功率（π0.5 从 96.9% 降至 49.1%），而参考相对 DPO 在保持成功率几乎不变的同时显著降低跳跃和趋势失配；
5. **偏好目标可迁移**：延续 DPO 目标能迁移到 π0.5、Legato、RTC，各自成功率为 97.1%/97.6%/97.4%，跳跃代价降低 15.8–40.3%、趋势失配降低 11.5–21.2%，证明改进源于偏好原则而非特定框架；
6. **指令介入顺序重要**：指令应在历史融合之前路由视觉证据，比后期查询或记忆融合更有效；
7. **交接条件泛化**：一个滚动交接条件可适用于多种推断延迟（k=3–5 或随机），无需为每种延迟设计独立策略。

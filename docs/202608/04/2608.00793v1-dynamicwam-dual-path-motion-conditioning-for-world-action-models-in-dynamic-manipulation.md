## 摘要
动态操作要求机器人推断目标运动并快速响应，然而现有的世界-动作模型（WAMs）通常仅以当前帧为条件，并同步执行大型骨干网络，限制了在动态场景中的运动感知和响应控制。我们提出了DynamicWAM，一种用于动态物体操作的紧凑型WAM，具有双路径运动条件化。DynamicWAM引入了历史流条件化，通过冻结的预训练视频VAE对时间对齐的光流帧与当前观察进行编码，以保留空间运动结构，同时将位移、持续时间、速度和加速度的动力学描述符注入动作专家，以提供运动幅度和时序。两条互补路径通过联合世界-动作注意力进行融合。蒸馏后的紧凑骨干网络和基于实时分块（RTC）的异步执行进一步实现了响应控制。在DOMINO上，DynamicWAM实现了38.2%的成功率和53.2的操作分数，超越了所有评估的基线。在涵盖直线、圆形和复合目标运动的12个真实世界任务中，它实现了46.7%的平均成功率，超过最强基线22.9个百分点。

## Abstract
Dynamic manipulation requires robots to infer target motion and respond promptly, yet existing World-Action Models (WAMs) typically condition only on the current frame and execute large backbones synchronously, limiting motion awareness and responsive control in dynamic scenes. We propose DynamicWAM, a compact WAM for dynamic object manipulation with dual-path motion conditioning. DynamicWAM introduces history-flow conditioning, encoding temporally aligned optical-flow frames alongside the current observation through a frozen pretrained video VAE to preserve spatial motion structure, while injecting kinematic descriptors of displacement, duration, velocity, and acceleration into the action expert to provide motion magnitude and timing. The two complementary paths are fused through joint world-action attention. A distilled compact backbone and real-time chunking (RTC)-based asynchronous execution further enable responsive control. On DOMINO, DynamicWAM achieves a 38.2% success rate and a 53.2 manipulation score, outperforming all evaluated baselines. Across 12 real-world tasks spanning linear, circular, and compound target motion, it achieves a 46.7% average success rate, exceeding the strongest baseline by 22.9 percentage points.

# DynamicWAM 论文详细总结

## 一、核心问题与整体含义（研究动机与背景）

- **问题定义**：动态操纵要求机器人在目标持续运动的过程中完成抓取、放置等操作，但现有世界-动作模型（WAM）普遍存在两个关键缺陷：
  1. **运动感知不足**：模型通常仅以当前帧为条件进行未来预测和动作生成，而视觉上相似的当前帧可能对应截然不同的目标运动方向与速度（如从左向右 vs 从右向左），仅凭单帧无法推断目标的运动状态与趋势。
  2. **响应滞后**：大多数 WAM 在动作块边界同步调用大型骨干网络进行预测，推理延迟导致预测结果在动作块执行完成前可能已过时，难以满足实时控制需求。
- **研究意义**：动态操纵是机器人从静态桌面场景走向真实动态环境的关键能力，涉及运动感知、时序预测和实时控制三方面。本文试图将“运动历史”与“运动学量级”显式纳入 WAM 的条件建模，在保持视频生成先验的同时实现紧凑高效的动态操纵策略。

## 二、方法论：核心思想、关键技术细节与算法流程

### 2.1 总体架构
- 基于标准 WAM 框架，耦合**紧凑视频专家**（从 Wan2.2-TI2V-5B 蒸馏得到）与**动作专家**，通过**逐层联合世界-动作注意力**实现双向信息交互。
- 动作块大小 H_a = 16，条件 C = (O_t, ℓ, s_t)，其中 O_t 为多视角观察，ℓ 为语言指令，s_t 为 proprioceptive 状态。
- 模型输出为条件流匹配（conditional flow matching）预测的视觉潜在向量场与动作向量场。

### 2.2 双路径运动条件化
**路径一：历史流条件化（History-Flow Conditioning）——提供空间运动结构**
- 将当前时刻之前 K=4 个历史区间（端点间隔 Δ=4 策略步长）的头相机帧两两计算 Farnebäck 稠密光流，并进行前向-后向一致性校验，得到掩码光流场 Û_k。
- 将光流场渲染为 RGB 图像 R_k：方向映射为色相（hue），大小按帧内 99 分位数归一到值（value）通道。
- 渲染后的历史流帧序列与当前观察沿时间轴拼接，通过**冻结的预训练视频 VAE** 编码为条件潜在表示，从而复用视频编码器而不引入额外运动编码器，也不改变动作空间。

**路径二：运动学令牌条件化（Kinematic Token Conditioning）——提供运动幅度与时序**
- 对每个历史区间的掩码光流场计算统计量：平均位移 d_k、平均位移大小 \bar{d}_k、99 分位位移大小 d^99_k、区间时长 Δτ_k、速度统计（v_k, \bar{v}_k, v^99_k）、加速度 a_k 及其范数，构成长度 12 的动力学描述符 m_k。
- 描述符经数据集级标准化，由两层 MLP 投影为运动学令牌 e_k，并加入区间位置/类型嵌入，与状态令牌、动作令牌、寄存器令牌共同组成动作流输入。无效区间使用学习的无效嵌入，缺失前驱时加速度维被掩码。
- 该方法解决了**光流渲染的尺度与时间歧义**：逐帧归一化使得 ρ(αU)=ρ(U)，纯渲染图像无法区分幅值差异，也不包含位移测量的时间跨度；运动学令牌补充了这些缺失信息。

**融合方式**：视频流与动作流通过联合注意力互相查询，动作解码器仅读取状态-动作令牌，从而保持动作表示不变。

### 2.3 联合训练目标
- 视觉与动作流均使用条件流匹配（CFM）训练：x^σ = (1-σ)x + σϵ，回归目标 u* = ϵ - x。
- 联合损失：L = E[||û_a - u*_a||²] + λ_v E[||û_v - u*_v||²]。
- 训练分三阶段：①视频专家蒸馏（80k 步）；②动作专家预训练（80k 步，视频分支冻结）；③联合精调（40k 步，λ_v 从 0.01 退火至 0.001）。

### 2.4 实时异步执行（RTC）
- 采用 Real-Time Chunking（RTC）：在当前动作块执行的同时异步预测下一个动作块，通过平滑合并（guidance weight 衰减）避免停顿，隐藏推理延迟。RTC 仅用于真实机器人部署；DOMINO 模拟评估使用基准原生同步协议以保持公平。

## 六、主要结论与发现

- 在 DOMINO Level 1 上，DynamicWAM 达到 **38.2% SR** 和 **53.2 MS**，超过最强基线（InternVLA-A1.5）8.9 SR 与 10.7 MS，超过 PUMA 21.0 SR；延迟 173.7 ms 属同一量级且比 InternVLA-A1.5 快约 3.2 倍。
- 双路径运动条件化具有**互补性**：历史流单独带来 +4.5 SR / +3.3 MS；运动学令牌单独带来 +7.8 SR / +8.9 MS；两者结合比最优单路径再提升 7.7 SR / 6.0 MS。
- 12 个真实任务平均成功率达 **46.67%**，较最强外部基线 π0.5 提升 22.92 个百分点；Level 3（复合运动）外部基线成功率均为 0%，DynamicWAM 达到 18.75%。
- RTC 异步执行额外带来 +4.59 个百分点，且复杂度越高提升越明显（L1 +2.5，L2 +5.0，L3 +6.25）。
- 视觉泛化：DynamicWAM 在背景、光照、颜色扰动下平均 OOD-SR 36.3%，显著高于 π0.5（17.5%）和静态 WAM（20.0%），但 retention 比率相似（约 0.52-0.54），说明优势主要来自更强的 ID 操纵能力。
- 失败模式以时序误差（42%）和空间错位（26%）为主，RTC 减少了 34% 的时序错误，运动学令牌对圆周运动中的早期接触错误改善最大。

## 八、不足与局限

1. **运动表示依赖 2D 图像空间**：光流来自固定外部头相机，仅捕获二维运动，缺乏深度/3D 信息，对视角变化、遮挡和物体形变敏感。
2. **未显式区分目标物体与干扰物**：光流场包含所有运动区域（夹爪、其他动态物体），在杂乱场景中可能引入噪声；作者也承认这是未来工作方向。
3. **真实实验样本量有限**：每任务仅 20 次试验，未报告置信区间或方差，统计显著性未验证；240 次试验总量虽不少，但细分任务后误差带较宽。
4. **真实任务复杂度有限**：Level 3 任务仅为曲线、平移+旋转等，未涵盖高速冲击、多物体交互、人手共操作等更极端场景；外部基线在 Level 3 全部为 0%，缺乏难度的梯度区分。
5. **泛化局限**：视觉泛化仅测试颜色/光照/背景，未涉及相机视角、场景布局、目标形状等更本质的分布偏移；retention 比率不高（约 0.52），绝对鲁棒性仍有较大提升空间。
6. **实时性依赖硬件与优化技巧**：173.7 ms 延迟通过 KV 缓存、10 步去噪等实现，当面对更高帧率或更复杂视觉输入时可能受限；且 RTC 仅隐藏延迟而非减少单次查询延迟。
7. **训练资源门槛较高**：200k 步 × 8×H100 的算力需求对于社区复现不友好；真实数据采集依赖遥操作，未能体现大规模自监督/合成数据的潜力。
8. **光学流计算本身存在瓶颈**：Farnebäck 算法在快速运动、纹理缺失区域可能失败，前向-后向校验虽能过滤但会丢失信息；运动学描述符基于像素统计，对遮挡和背景运动敏感。

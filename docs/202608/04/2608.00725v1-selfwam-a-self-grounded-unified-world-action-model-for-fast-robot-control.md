## 摘要
世界动作模型（WAMs）通过联合建模动作和未来观测来改进机器人策略学习。然而，仅以任务提示和观测上下文为条件进行未来预测，可能会捕捉到通用的任务进展，而非执行动作的特定后果。我们引入了SelfWAM，一种自接地的统一WAM，基于模态专用的Transformer混合（MoT）架构构建，联合预测动作、动作条件下的未来RGB帧和机器人自掩码，从而将未来预测扎根于机器人的可见身体及其动作引起的运动。在联合训练期间，SelfWAM允许未来视觉查询关注演示动作的干净副本，将视频分支转变为动作特定的后果模型，同时保持仅动作的快速推理路径不变。为了将视频学习聚焦于与动作相关的视觉变化，我们对未来的机器人自掩码预测使用特定于提示的目标，这样去除了外观细节，并提供了一个时间演化与条件动作紧密耦合的目标。总之，干净动作条件和未来自掩码监督使未来预测更直接地反映执行动作如何改变机器人的可见运动和周围场景。在RoboTwin 2.0和真实世界操作任务上的实验表明，SelfWAM产生了对动作更敏感的未来预测，并保持了快速策略推理，同时提升了策略性能。

## Abstract
World Action Models (WAMs) improve robot policy learning by jointly modeling actions and future observations. However, conditioning future prediction only on the task prompt and observation context risks capturing generic task progression rather than the action-specific consequences of the executed action. We introduce SelfWAM, a unified self-grounded WAM built on a modality-specialized Mixture-of-Transformers (MoT) architecture that jointly predicts actions, action-conditioned future RGB frames, and robot self-masks, thereby grounding future prediction in the robot's visible body and its action-induced motion. During joint training, SelfWAM allows future visual queries to attend to a clean copy of the demonstrated action, turning the video branch into an action-specific consequence model while leaving the fast action-only inference path unchanged. To focus video learning on action-relevant visual changes, we use prompt-specific objectives for future robot self-mask prediction, which removes appearance details and provides a target whose temporal evolution is tightly coupled with the conditioning action. Together, clean-action conditioning and future self-mask supervision make future predictions more directly reflect how the executed action changes the robot's visible motion and the surrounding scene. Experiments on RoboTwin 2.0 and real-world manipulation tasks show that SelfWAM produces more action-sensitive futures and preserves fast policy inference, while improving policy performance.

- **研究背景**：世界动作模型（World Action Models, WAMs）通过联合建模机器人动作与未来观测，将预训练的视频动力学先验引入策略学习，从而提升视觉运动策略的性能。
- **核心问题**：现有WAM在预测未来时，仅以任务提示和当前观测为条件，**不显式依赖产生该未来结果的演示动作**。这导致模型捕捉的是通用的任务进展（generic task progression），而非特定动作导致的因果后果。例如，相同的观测可以对应多种合理动作，每种动作应产生不同的未来，但现有模型无法区分这些差异。

- **论文提出的解决方案**：提出**SelfWAM**，一种自接地的统一WAM，通过引入**干净动作条件（clean-action conditioning）**和**机器人自掩码预测（robot self-mask prediction）**，使未来预测既对动作敏感，又关注动作引起的机器人可见运动，同时保持快速的动作单独推理路径。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想

SelfWAM的核心是**非对称信息流（asymmetric information flow）**设计：在训练时，将演示动作的干净副本仅暴露给未来视觉查询，使视频分支成为**动作特定后果模型（action-specific consequence model）**；动作预测分支则无法访问该干净副本或未来视觉token，防止目标泄漏（target leakage），从而保持部署时快速动作推理路径不变。

### 架构设计

- **基础架构**：采用模态专用的混合Transformer（Mixture-of-Transformers, MoT）双流设计，包含：
  - **视频流**：预训练的视频扩散骨干网络（WAN2.2-5B初始化），处理当前观测和带噪未来视频潜变量。
  - **动作流**：轻量级动作专家网络，处理带噪未来动作token，通过参数插值从视频骨干初始化。
- **混合注意力机制**：两个专家保留各自的模态专用投影和前馈层，通过混合注意力控制token组间的信息交换。

### 信息流规则

定义当前上下文token为O，带噪未来动作token为Ã，干净动作token为A，带噪未来视觉token为Ṽ，注意力规则为：

- Q_Ã → {O, Ã}：动作预测仅依赖当前上下文和自身噪声动作状态
- Q_Ṽ → {O, Ṽ, A}：未来视觉预测可访问干净动作副本
- Q_A → {O, A}：干净动作流仅编码自身和上下文

这一设计的关键在于：**干净动作仅作为世界模型条件**，而不是第二个动作预测目标。

### 机器人自掩码预测

- 复用同一视频骨干网络进行RGB预测和自掩码预测，两种模式共享相同的时空token布局、噪声调度、位置编码和注意力模式。
- 每个演示生成两个训练实例：RGB实例（含动作监督）和自掩码实例（仅含视觉监督）。
- 自掩码目标去除外观与背景变化，聚焦机器人本身的可见运动，其时间演化与条件动作紧密耦合，提供更集中的反馈信号。

### 训练目标

总损失为：L = λ_act · L_act + λ_video · L_rgb/mask

其中L_act为动作去噪损失（flow-matching），L_rgb/mask为RGB和自掩码视频去噪损失的混合期望。RGB与自掩码样本按9:1比例采样。

### 部署推理

- **快速控制模式**：仅编码当前上下文，通过轻量动作专家迭代去噪动作块（10步去噪，32步动作块，执行24步后重新规划），不实例化干净动作和未来视觉流。
- **可选世界模型回放**：可将策略采样或候选动作插入干净动作槽，通过输出提示选择生成未来RGB或自掩码视频，用于诊断或反事实推演。

1. **策略性能提升**：SelfWAM在RoboTwin 2.0上达到92.62%平均成功率，优于FastWAM（91.84%）及所有基线；在随机化环境下提升更显著（93.08% vs 91.86%），表明自接地监督增强了对外观变化的鲁棒性。

## 摘要
移动操作是具身智能的关键能力，使机器人能够在开放世界环境中完成复杂的多阶段任务。然而，移动操作为视觉-语言-动作（VLA）策略带来了两个关键挑战：在数据层面，高效收集高质量的全身演示需要协调控制移动基座和机械臂；在模型层面，现有VLA模型主要依赖局部相机观测，其有限的视野阻碍了全局空间理解。为解决这些挑战，我们开发了全身遥操作系统和全景感知VLA策略。该系统通过单一VR界面实现对轮式双臂机器人的协调控制，并支持获取包含5.5小时多模态演示的真实世界移动操作数据集。在此数据集基础上，我们提出PanoVLA，一种用于移动双臂操作的全景感知视觉-语言-动作策略。PanoVLA基于Transformer混合架构，通过专用的全景编码和融合模块引入全局空间上下文，实现全景观测与语言指令和机器人状态的有效集成，以生成动作。在四个真实世界移动操作任务上的评估表明，PanoVLA实现了91.3%的平均阶段完成率和73.4%的端到端成功率，显著优于局部视图基线。这些结果表明，融入全景空间上下文能够提升移动机器人的空间理解能力和闭环操作性能。

## Abstract
Mobile manipulation is a key capability for embodied intelligence, enabling robots to accomplish complex multi-stage tasks in open-world environments. However, mobile manipulation poses two key challenges for vision-language-action (VLA) policies: At the data level, the efficient collection of high-quality whole-body demonstrations demands the coordinated control of both the mobile base and the robotic arms; at the model level, existing VLA models predominantly rely on local camera observations, whose limited field of view hinders global spatial understanding. To address these challenges, we develop a whole-body teleoperation system and a panoramic-aware VLA policy. The system enables coordinated control of a wheeled bimanual robot through a single VR interface and supports the acquisition of a real-world mobile manipulation dataset comprising 5.5 hours of multimodal demonstrations. Building upon this dataset, we propose PanoVLA, a panorama-aware vision-language-action policy for mobile bimanual manipulation. Built upon a Mixture-of-Transformers architecture, PanoVLA introduces global spatial context through dedicated panorama encoding and fusion modules, enabling effective integration of panoramic observations with language instructions and robot states for action generation. Evaluation on four real-world mobile manipulation tasks demonstrates that PanoVLA achieves an average stage completion rate of 91.3\% and an end-to-end success rate of 73.4\%, substantially outperforming local-view baselines. These results demonstrate that incorporating panoramic spatial context improves spatial understanding and closed-loop manipulation performance in mobile robots.

## 1. 论文核心问题与研究背景

移动操作（Mobile Manipulation）是具身智能机器人的核心能力之一，要求机器人能够在开放环境中完成"移动 + 操作"相结合的复杂多阶段任务。论文指出，将 VLA（视觉-语言-动作）模型从桌面操作迁移到移动双臂机器人，面临**两个核心挑战**：

- **数据层面**：高质量全身演示的采集需要同时协调移动基座、双臂和夹爪四个执行模块，传统"手柄/键盘控制基座 + 机械臂遥操作"的分立接口难以采集流畅的全身协同轨迹，采集效率和数据质量受限。
- **模型层面**：现有 VLA 模型主要依赖前视相机和腕部相机等**局部视角**，视野受限，在机器人移动、旋转或手臂自遮挡时，目标物体、地标和目的地容易脱离视野，导致全局空间理解不足，难以支撑长程导航、目标搜索和多阶段操作。

论文提出了一套从数据采集到策略学习的"全景感知移动操作"完整解决方案：先设计全身遥操作系统解决数据瓶颈，再提出具备全景感知能力的 PanoVLA 策略解决模型瓶颈。

## 2. 方法论

### 2.1 全身遥操作与数据采集系统

- **硬件接口**：仅使用一套 VR 设备（头显 + 双手柄 + 三个身体追踪器，分别于腰部与双脚踝）获取人体稀疏运动信号，通过 SMPL 模型重建人体位姿。
- **运动重定向（GMR-based）** ：将人体运动特征（骨盆位姿、双手位置与朝向、下肢运动线索）映射到机器人全身构型，通过优化：

  \[
  q^* = \arg\min_q \lambda_{pos}L_{pos} + \lambda_{rot}L_{rot} + \lambda_{base}L_{base} + \lambda_{reg}L_{reg}
  \]

  其中 \(L_{pos}\)、\(L_{rot}\) 分别对齐手部与夹爪的位置和朝向，\(L_{base}\) 将平面基座运动耦合物体的骨盆位移与朝向，\(L_{reg}\) 约束关节极限与构型变化。
- **基座建模与模式切换**：将移动底盘建模为 **3-DoF 平面虚拟浮动基座**，与双肩构型联合优化；当目标末端位姿超出机械臂工作空间时，优化器自适应调整基座平移和航向，从而减少重定向误差。物理执行时采用**代价驱动的模式切换策略**，在旋转 / 阿克曼 / 斜移三种运动模式间动态选择最低代价模式。
- **数据集**：采集了 4 个任务、800 条演示轨迹、约 5.5 小时（500K 同步帧）的真实机器人数据，包括前视 + 双臂腕部局部 RGB、顶装 360° 全景（ERP 格式）、本体感受状态及 17 维全身动作（14 维双臂 + 夹爪，3 维基座速度指令）。

### 2.2 PanoVLA 策略模型

PanoVLA 基于 **Mixture-of-Transformers (MoT)** 架构，在 π0.5 双专家骨干基础上，将专家扩展为三个模块：

- **VLM 专家**：编码局部视觉、语言指令和本体感受状态，生成 VLM KV 缓存 \(C^{vlm}_t\)（作为融合接口）。
- **全景编码器**：先将双鱼眼图像通过球面重投影生成持续、机器人中心式的 ERP 全景图，再送入 **MTPano** 全景基础模型，提取语义（分割分支）和几何（深度分支）通道拼接的密集特征，经自适应池化和 MLP 适配器转化为全景 token \(Z^{pano}_t\)。
- **全景专家**：执行任务条件化的空间编码，将全景 token 与 VLM 缓存进行块状因果注意力的联合自注意，生成全景缓存 \(C^{pano}_t\)：

  \[
  C^{pano}_t = \phi_{pano}(Z^{pano}_t \mid C^{vlm}_t, M^{pano})
  \]
- **动作专家**：在联合上下文 \(C_t = [C^{vlm}_t; C^{pano}_t]\) 条件下，通过**条件流匹配**训练，预测 32 步连续动作块（17 维），最小化速度场回归损失：

  \[
  \mathcal{L} = \mathbb{E}\left[\|v^{act}_\theta(x_\tau, \tau \mid C_t) - u(x_\tau \mid a)\|^2_2\right]
  \]

## 3. 实验设计与 Benchmark

### 3.1 实验场景与任务

论文在真实世界中设计了 4 个移动操作任务，覆盖多种空间布局与操作难度：

| 任务 | 目标 | 空间设置 |
|---|---|---|
| Move Pen | 将笔放入笔筒 | 笔在机器人前 / 左 / 右 |
| Move Block | 将积木转移到前方区域 | 积木在左 / 右 / 双侧 |
| Open Curtain | 打开两侧窗帘 | 左 / 右两侧 |
| Wipe Table | 擦拭台面污渍并归回抹布 | 沿长桌多阶段操作 |

每个任务分解为多个阶段用于细粒度分析；每方法每任务执行 **15 次闭环真实机器人试验**（无人工干预、不重置失败阶段）。

### 3.2 对比方法

- **π0.5**：纯局部视图基线，仅使用 SigLIP 编码局部相机。
- **π0.5 w/ Pano**：将 ERP 全景图作为额外图像输入，经同一 SigLIP 编码，无专门全景分支。
- **π0.5 w/ Stacked Pano**：将全景图重投影为 3 个 120° 间隔的透视视图并拼接为复合图输入。
- **PanoVLA**：本文方法。

### 3.3 评估指标

- **SR（Success Rate）**：端到端任务级二值成功率。
- **SCR（Stage Completion Rate）**：跨试验平均的阶段完成比例，可捕捉中间过程（如目标搜索、移动接近、操作）的表现。

## 6. 主要结论与发现

- **PanoVLA 平均 SCR 达 91.3%、SR 达 73.4%**，远超纯局部视图 π0.5（58.6% / 30.0%），证明全景空间上下文对移动操作中的空间理解和闭环执行有显著贡献。
- **全景输入方式比"是否有全景"更重要**：直接以 ERP 全景图加 SigLIP 编码（π0.5 w/ Pano，80.8% / 56.7%）优于拼接透视重投影（π0.5 w/ Stacked Pano，70.4% / 38.3%），但仍低于 PanoVLA，说明**全景专用编码 + 专用专家融合** 是有效感知全景几何的关键。
- 任务难度不由"目标是否在当前视野中"单独决定：Open Curtain 和 Wipe Table 需要跨阶段的连续状态跟踪与全局空间一致性；PanoVLA 在此类任务上的优势更明显（Open Curtain SR 66.7% vs 最佳基线 46.7%；Wipe Table SR 46.7% vs 最佳基线 40.0%），说明全景专家有助于维持长程任务中跨阶段的空间状态追踪能力。
- 消融表明：100M 全景专家是容量与数据效率的最优权衡；MTPano 相比 SigLIP 大幅提升全景感知质量（SCR 95.6% vs 75.6%），证实了透视预训练编码器与全景图像之间的域鸿沟确实存在。

## 7. 优点

1. **真实系统闭环验证**：整个 pipeline（遥操作数据采集 → 策略训练 → 真实机器人闭环评估）完整落地于真实轮式双臂平台，非仿真或静态演示，可信度高。
2. **可复现的数据采集方案**：仅用消费级 VR 设备实现全身遥操作，不依赖定制硬件；GMR 重定向将基座建模为虚拟浮动基座联合优化，使基座运动自然融入人体动作，设计巧妙且实用。
3. **方法论清晰且克制**：PanoVLA 并非推翻主流 VLA 范式，而是在 π0.5 的 MoT 架构上最小化增改（一个全景编码器 + 一个全景专家 + KV 缓存融合），改动小、对比干净、归因明确。
4. **全景域适配针对性强**：明确指出 ERP 全景与透视预训练编码器的域鸿沟，采用 MTPano 的语义 + 深度多任务特征构建密集全景表示，并经过消融验证。
5. **评估指标细粒度**：同时报告 SCR 和 SR，并辅以阶段级曲线，能区分"方法在哪些中间环节失败"，诊断价值高于单一成功率指标。

## 8. 不足与局限

1. **实验规模有限**：每任务仅 15 次重复试验，且未提供方差 / 置信区间，结果可能存在较大随机波动；部分差距（如 Move Pen 上 PanoVLA 与 π0.5 w/ Pano 均为 86.7% SR）无法判定显著性。
2. **任务覆盖面有限**：4 个任务都属于近距离、结构化的室内场景（桌面 + 简单环境交互），未涉及更开放的环境（如走廊导航、多房间搜索、动态障碍物规避），对"开放世界移动操作"的支撑力有待加强。
3. **任务级独立微调**：每个任务单独微调一个策略，尚未实现跨任务的单一通用模型，距离"通用 VLA 策略"的目标仍有一定差距；也未报告跨任务联合训练的潜力或灾难性遗忘问题。
4. **消融不完整**：消融只在 Move Pen（相对最简单的单阶段任务）上进行，未验证在多阶段复杂任务（如 Wipe Table）上的灵敏度；且未对整个模型的参数量、推理延迟、端到端时延进行对比分析。
5. **全景表示仍有瓶颈**：自适应平均池化将密集全景特征压成固定数量 token，可能丢失细粒度空间信息；对全景遮挡（如机械臂遮挡全景相机）和光照变化的鲁棒性未讨论。
6. **对比外围方法不足**：未与近期其他移动操作 VLA 工作（MoManipVLA、SG-VLA、AC-DiT 等）进行比较，无法定位 PanoVLA 在更广方法谱系中的位置。
7. **潜在数据偏差**：演示数据来自单一操作者的遥操作，操作习惯、人类演示策略的偏差可能影响策略的泛化和鲁棒性；未提及操作者数量或如何控制跨操作者差异性。

## 摘要
可供性引导的模仿学习通过将视觉感知压缩为任务特定的几何约束（例如固定接触点），在机器人操作任务中展现了出色的性能。然而，常用的静态可供性在精度关键任务或物体位置扰动下可能变得不一致，导致接触后轨迹漂移。为解决这一问题，我们提出了AffordTrajDP，一种动态框架，通过以物体为中心的时间传播构建可供性轨迹，以指导渐进式操作过程。具体而言，给定RGB-D观测，我们的核心见解是：检索到的锚定可供性捕捉了末端执行器与目标物体之间的期望接触点，可通过可供性传播（以物体的SE(3)姿态作为自然的传播媒介）向前传播，从而生成一个可供性轨迹，在执行过程中提供时间一致、状态感知的引导。AffordTrajDP在ManiSkill3上取得了70.0%的平均成功率，比强基线高出最多17.8%。在Galaxea A1和UR7e机械臂上的真实世界实验，覆盖了StackCube、PickCup、AdapterInsertion、Ring-on-Peg、Put-in-Bowl和USB Insertion任务，进一步验证了在物体放置变化和外观变化下的鲁棒性，其中在Galaxea A1上评估了已见和未见物体实例，消融实验证实了每个提出组件的贡献。

## Abstract
Affordance-guided imitation learning has shown impressive performance in robotic manipulation tasks by compressing visual perception into task-specific geometric constraints (e.g., fixed contact points). However, the commonly used static affordances can become inconsistent in precision-critical tasks or under object location perturbations, leading to post-contact trajectory drift. To address this issue, we propose AffordTrajDP, a dynamic framework that constructs affordance trajectories via object-centric temporal propagation to guide the progressive manipulation process. Specifically, given an RGB-D observation, our core insight is that a retrieved anchor affordance, which captures the desired contact point between the end-effector and the target object, can be propagated forward via affordance propagation, using the object's SE(3) pose as a natural propagation medium, to yield an affordance trajectory that provides temporally consistent, state-aware guidance throughout execution. AffordTrajDP achieves 70.0% average success rate on ManiSkill3, outperforming strong baselines by up to 17.8%. Real-world experiments on Galaxea A1 and UR7e robotic arms, covering StackCube, PickCup, AdapterInsertion, Ring-on-Peg, Put-in-Bowl, and USB Insertion, further validate robustness under object placement variations and appearance changes, with seen and unseen object instances evaluated on Galaxea A1, and ablations confirm the contribution of each proposed component.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：现有视觉运动策略（如 Diffusion Policy）依赖密集视觉观测，对环境扰动（物体外观、背景布局等）敏感，在新场景和未见物体实例上性能下降。
- **已有改进方向**：物体中心化表示（object-centric representations）通过结构化中间表征（如物体 6D 位姿、3D 点流）提升泛化能力；其中**可供性（affordance）** 编码了任务特定的交互先验（接触位置、接触后运动）。
- **关键缺陷**：已有可供性引导方法（如 AffordDP）将可供性视为**静态**的——通过单次刚性变换将参考接触点/轨迹迁移到目标物体后，整个 episode 内不再更新。当物体在接触后发生位姿变化（尤其在精度关键任务如插接）时，静态先验会与物体实际状态逐渐失配，导致**接触后轨迹漂移**。
- **核心诊断**：现有条件信号只保留了“接触哪里”或“接触后如何演化”中的一半：`PRISM-DP` 只利用当前物体位姿，`SPOT` 只预测未来位姿轨迹（丢失接触语义）；`AffordDP` 只检索语义接触点（不随物体运动更新）。**缺少一个同时保持“接触语义”和“随时间演化”的统一信号**。
- **整体含义**：该论文主张，可供性不应是固定的、一锤定音的静态几何约束，而应作为**动态的、随时间演化的状态感知轨迹**来引导策略，从而提高精密操作精度与环境扰动鲁棒性。

## 2. 方法论：核心技术思想与流程

### 2.1 总体框架（AffordTrajDP）

- 输入：RGB-D 观测；
- 输出：动态可供性轨迹，作为扩散策略的条件信号；
- 流程：**检索锚定可供性 → 预测物体未来 SE(3) 位姿轨迹 → 用位姿轨迹传播锚定接触点 → 得到时间对齐的可供性轨迹 → 条件化动作生成**。

### 2.2 锚定可供性生成（Anchor Affordance Generation）

- 表示形式：静态可供性 `c ∈ R³`（3D 接触点）和动态轨迹 `τ ∈ R³×H`（接触点轨迹，H 为预测步数）。
- 通过**检索**而非回归获得：因为接触区域往往是物体表面稀疏且易与其他显著特征混淆的小区域。
- 实现细节：
  - 构建物体记忆库 M：用 Grounded-SAM 裁剪物体区域，用 CLIP 提取外观特征；每条记忆存储任务标签、静态可供性、外观特征、RGB-D 位姿。
  - 测试时，在同一任务内按余弦相似度检索最近邻源实例，得到源接触点。
  - 通过源-目标裁剪图像的**稠密视觉对应**（dense visual correspondence），将源接触点迁移到目标物体，得到目标接触点 `c_tgt`，作为后续传播的锚点。

### 2.3 动态可供性传播（Dynamic Affordance Propagation）

- **未来位姿预测**：用扩散模型（DDIM）建模条件分布，预测源物体在目标物体坐标系下的 SE(3) 位姿轨迹（而不是世界坐标系），以消除绝对布局差异、提升跨实例泛化。
  - 训练数据：从示范中提取位姿轨迹——Grounded-SAM 分割、Any6D 重建网格、FoundationPose 跟踪 6D 位姿。
  - 将源物体轨迹转换到目标物体坐标系：`T_src_tgt(t) = (T_tgt_W(t))⁻¹ T_src_W(t)`。
  - 输入为位姿历史 `h_t`，输出为 H 个未来位姿；用 DDIM 采样以保证确定性和低延迟。
- **可供性传播**：将锚定接触点沿预测位姿轨迹做刚性变换：
  - `p_{t+k} = T_{t+k} · [c_tgt; 1]`，得到动态可供性轨迹 `τ_{t:H}`。
- **核心思想**：不用单独预测接触点轨迹，而是利用物体的位姿演化作为“传播媒介”，使接触点始终附着在物体表面上，保持时间一致与状态感知。

### 2.4 动作生成

- 静态可供性 `c` 用 MLP 编码；
- 动态轨迹 `τ` 用 Transformer（含 [CLS] token）编码；
- 融合其他观测（点云、本体感觉等）构成条件特征 `f_t`；
- 动作生成器为 DDIM 条件扩散模型，从高斯噪声迭代去噪得到动作序列；训练损失为噪声预测 MSE。

## 6. 主要结论与发现

- **核心结论**：动态可供性轨迹比静态可供性更好；联合“语义接触点检索”+“位姿轨迹传播”是必要条件，两者缺一不可。
  - 仅给接触点（+Contact）优于仅给中心点或仅给轨迹，但低于完整方法；
  - 仅给轨迹（+Traj）在 unseen 实例上反而低于纯 DP3（如 StackCube unseen 20% vs 40%），说明无语义锚定的轨迹会成为噪声。
- **量化成效**：
  - ManiSkill3：平均成功率 70.0%，比 DP3（52.2%）高 17.8 个百分点，比 AffordDP（57.8%）高 12.2 个百分点，比 SPOT（62.1%）高 7.9 个百分点。
  - 真实世界 Galaxea A1：完整方法平均 66.1%，比 DP3（35.0%）高约 31 个百分点；UR7e 上平均 72.5% vs DP3 40.8%、AffordDP 55.8%、SPOT 54.2%。
- **精度关键任务收益最大**：PegInsertion、PlugCharger、AdapterInsertion、USB Insertion 等任务中提升最明显，说明动态可供性对后接触对齐有决定性作用。
- **误差非累积性**：在测过的轨迹中，位姿预测误差没有随 episode 持续增长，但论文谨慎地将其视为假设而非确定性结论。

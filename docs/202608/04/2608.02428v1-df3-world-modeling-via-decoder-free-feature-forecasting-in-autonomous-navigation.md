## 摘要
从视频序列预测未来状态是自主机器人系统面临的关键挑战，也是世界建模的基本目标。以往在像素层面操作的生成方法不可避免地过度强调与任务无关的细节，导致计算开销过高。基于潜在变量的方法尝试通过直接预测特征来缓解这一问题，但状态到任务映射对重型解码器的持续依赖仍然是计算瓶颈。本文提出无解码器特征预测（DF$^3$），一种全新框架，完全在潜在空间内建模世界演化并直接生成任务输出，彻底消除对解码器的需求。具体而言，DF$^3$将可学习的空间查询注入冻结视觉基础模型的末端模块，直接提取未来状态表征。通过采用轻量级、统一的运动感知上下文融合（MACF）机制，无缝集成粗略流扭曲与细粒度潜在互相关，这些查询与历史令牌表征交互，显式对齐并预测下一帧特征。随后，一组专门的任务查询探测这些预测特征以完成下游任务。在公共基准上的大量实验以及在机器人模拟器中的零样本部署表明，DF$^3$在实现与最先进方法相当性能的同时，为集成感知与控制提供了更高的效率和灵活性。

## Abstract
Forecasting future states from video sequences is a critical challenge for autonomous robotic systems and a fundamental objective of world modeling. Prior generative methods operating at the pixel level inevitably overemphasize task-irrelevant details, leading to prohibitive computational overhead. While latent-based approaches attempt to mitigate this by predicting features directly, the persistent reliance on heavy decoders for state-to-task mapping remains a computational bottleneck. In this work, we propose Decoder-Free Feature Forecasting (DF$^3$), a novel framework that models world evolution entirely within the latent space and directly derives task outputs, completely eliminating the need for a decoder. Specifically, DF$^3$ injects learnable spatial queries into the terminal blocks of a frozen vision foundation model to extract future state representations directly. By employing a lightweight, unified Motion-Aware Context Fusion (MACF) mechanism that seamlessly integrates coarse flow warping with fine-grained latent cross-correlation, these queries interact with historical token representations to explicitly align and forecast the feature of the next frame. Subsequently, a specialized set of task queries probes these forecasted features for the downstream task. Extensive experiments on public benchmarks and zero-shot deployment in a robotic simulator demonstrate that DF$^3$ achieves performance comparable to state-of-the-art methods while offering superior efficiency and flexibility for integrated perception and control.

## 1. 核心问题与研究动机

- **核心问题**：从视频序列中预测未来状态是自主导航与世界建模的核心任务。现有方法存在明显的计算瓶颈：
  - **像素级生成方法**：直接在原始像素空间预测未来帧，计算开销极大，且过度强调纹理、光照等与任务无关的高频细节；下游任务还需额外的感知解码器将合成视频翻译为任务输出，延迟高、复杂度大。
  - **潜在空间预测方法**（如 DINO-WM、DINO-Foresight）：虽改在语义特征空间预测，避免了像素级冗余，但仍严重依赖两类重型解码器——一是用于上下文建模/重构未来特征的空间-时间 Transformer 解码器，二是用于将特征翻译为任务输出的任务专用解码器。解码器成为持续的计算瓶颈。
- **研究动机**：现代视觉基础模型（VFM，如 DINOv2/DINOv3）已具备强大的语义表征能力。作者提出一个根本性问题——**能否完全在 VFM 编码器空间内完成特征预测，彻底去掉解码器**？这项工作旨在为实时性要求严苛的自主导航系统提供高效、灵活的世界建模方案。

## 2. 方法论

### 2.1 核心思想
- 提出 **Decoder-Free Feature Forecasting（DF³）** 框架：完全在**冻结的 ViT 编码器内部**完成未来状态预测与任务输出提取，全过程**无需任何解码器**。
- 关键观测：受 EoMT 启发——预训练 ViT 可通过向末端模块注入可学习查询（query）来执行密集预测任务。DF³ 将这一思想首次引入特征预测领域。

### 2.2 DF³ 整体流水线
- 给定历史上下文帧 {I₁,…,I_T}，使用冻结的 DINOv3-ViT-B/16 编码器 E。
- 取编码器早期层（L1）的输出作为上下文特征 F_L1(I_t)（含 prefix tokens 和 patch tokens，语义丰富且保留一定空间结构）。
- 注入**可学习预测查询 Q_pred** 到末端模块（L2），与历史上下文特征拼接后经自注意力交互。
- 查询输出经 **MACF 机制**细化，得到预测的下一帧特征 F̂_L1(I_{T+1})。
- 下游任务：再注入一组**任务查询 Q_task**，与预测特征拼接、通过相同末端模块，输出经轻量 MLP 头得到分割掩码与类别 logits——保持全流程无解码器。

### 2.3 结构化查询注意力（Structured Query Attention）
- 使用**非对称注意力掩码**：上下文 token 之间可自由互相注意，但**禁止上下文 token 回看预测查询**；预测查询可以注意所有 token。
- 该因果设计防止了信息泄漏，保证上下文表征不被注入的查询污染。

### 2.4 运动感知上下文融合机制（MACF）
这是让冻结的图像编码器获得时序建模能力的关键模块，包含两条并行分支：
- **流扭曲分支（Warp）**：从空间预测查询经 MLP 预测稠密潜在流场 Δp，扭曲最近历史特征图得到粗略对齐的未来特征；再以"扭曲特征−当前查询"的差值提取更新方向 M_warp。
- **潜在互相关分支（Xcorr）**：在特征空间对 I_{T-1} 与 I_T 做局部软匹配，计算历史语义运动 V_hist（当前特征与软匹配前帧特征的差），投影为语义运动注入 M_xcorr。
- **动态融合**：将两条分支输出拼接，经可学习的 sigmoid 门控机制 G 调制残差，得到最终预测 patch 特征；全局 prefix tokens 则用轻量时序外推器处理。
- 训练损失：余弦相似度 + Huber 损失（λ_huber=0.5），对 patch tokens 和 prefix tokens 均计算。

## 7. 优点

- **架构创新性强**：首个完全在冻结 VFM 编码器空间内完成"预测+任务输出"的无解码器框架，概念清晰、范式新颖。
- **效率突出**：同时大幅降低计算量、延迟、内存和参数量，切中实时自主导航的核心痛点，准确率仅小幅牺牲。
- **设计精巧**：非对称注意力掩码防止信息泄漏；MACF 将粗粒度流扭曲与细粒度潜在互相关结合，并用门控融合，轻量而有效。
- **灵活性与可扩展性**：预测查询与任务查询独立训练、即插即用，支持多种下游任务共享同一世界表征。
- **跨域验证有说服力**：Cityscapes 上训练、MATRiX 模拟器中零样本部署的跨本体实验，验证了表征的泛化能力。

## 8. 不足与局限

- **功能局限**：当前仅支持"观测-only"的未来预测，**不支持动作条件预测**，无法闭环模拟特定动作的后果，限制了在交互式环境中的规划应用（作者已声明这是最核心局限）。

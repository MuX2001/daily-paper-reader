A GAME-THEORETIC CHARACTERIZATION OF FEEDBACK CAPABILITY FOR FULLY COUPLED VECTOR-VALUED NONPARAMETRIC SYSTEMS ∗

ZHAOBO LIU †

Abstract. We study feedback stabilization for the discrete-time system xt+1 = f (xt) + ut + wt+1 

in Rd with unknown f and arbitrary bounded disturbances. For scalar plants, the sharp feedback capability threshold under generalized Lipschitz uncertainty is 32 + √2. We treat fully coupled vector-valued systems, where scalar order and interval recursion are unavailable and coupling precludes a coordinatewise reduction. We introduce a response-history escape game whose winning condition requires a finite envelope at the prescribed slope and an unbounded state radius. Borel determinacy and slope monotonicity give an independently defined game value Γ d. We prove that the plant problem admits a finite strict feedback capability threshold and identify it with Γ d. If L < Γd, one causal feedback law stabilizes every plant in the uncertainty class against every bounded disturbance sequence. If L > Γd, then for every causal feedback law there exist a plant in the same class and a bounded disturbance sequence such that the closed-loop state sequence is unbounded. The threshold equivalence is proved through a uniform subcritical response-game controller and a Hilbert-space realization lemma based on the Kirszbraun–Valentine extension theorem. An explicit nearest-neighbor feedback law yields a lower bound strictly above one in every finite dimension, including Γ 2 ≥ 2/√3. Dimension monotonicity gives Γ d ≤ Γ1, and comparison with the scalar theory yields Γ 1 = 32 + √2. 

Key words. robust stabilization, nonparametric uncertainty, dynamic games, Borel determinacy, feedback capability

1. Introduction. Feedback stabilization under nonparametric uncertainty is a basic question about the capability of feedback. When the plant is not specified by a parametric model, one asks how large the uncertainty can be while still allowing a causal controller to stabilize every plant in the class. This paper studies the discrete-time system (1.1) xt+1 = f (xt) + ut + wt+1 , xt, u t, w t ∈ Rd,

where f : Rd → Rd is unknown and the disturbance sequence is arbitrary but bounded. Stabilization means boundedness of the closed-loop state sequence. The objective is to determine the range of nonparametric uncertainty that can be handled by a single causal feedback law for every bounded disturbance sequence. For scalar plants, this feedback capability question was resolved by Xie and Guo [17]. In the scalar setting, nonparametric uncertainty is measured by the generalized Lipschitz seminorm, which records the smallest slope after allowing a finite additive envelope. The sharp threshold for this slope is 32 + √2. Below this value stabilization is possible, while above it every feedback law has a counterexample. Subsequent work extended this feedback capability viewpoint within scalar or structured uncertainty classes, including critical stability and limitation results for discrete-time adaptive nonlinear control [1, 12, 16], robust variants [10], polynomial criteria for adaptive stabilizability [11], and nonlinearly parameterized or semiparametric uncertainty

6. Conclusion. This paper constructs a response-history escape game for fully coupled vector-valued systems with bounded disturbances. Its escape condition requires a finite envelope and an unbounded state radius. The main results establish that the plant problem admits a finite, nontrivial strict feedback capability threshold and identify it with the resulting game value. In the subcritical regime L < Γd, a single causal feedback law stabilizes every plant in Fd(L) for every bounded disturbance sequence. In the supercritical regime L > Γd, for every causal feedback law there exist a plant and a bounded disturbance sequence that make the closed-loop state sequence unbounded. In dimension one, comparison with the Xie–Guo theorem gives the scalar constant Γ 1 = 32 + √2. The game values also satisfy κd ≤ Γd ≤ Γ1 and are nonincreasing in the dimension. The threshold theorem concerns the causal feedback class of Section 2, whereas the range L < κ d is achieved by the explicit nearest-neighbor feedback law in Corollary 3.9. In particular, Γ 2 ≥ 2/√3. Natural next questions are to obtain sharper bounds, or a closed-form evaluation, for Γ d in dimensions d ≥ 2, and to understand whether the scalar upper bound remains sharp for fully coupled vector-valued systems.

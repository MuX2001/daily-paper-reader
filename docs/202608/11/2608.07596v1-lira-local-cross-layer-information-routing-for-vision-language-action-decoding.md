## 摘要
视觉-语言-动作（VLA）模型将预训练的视觉-语言模型（VLM）的表征转换为机器人动作，然而将中间VLM特征路由到动作解码器的接口仍未得到充分探索。现有设计要么仅暴露表征层次中较窄的部分，要么将每个解码器模块严格匹配到一个VLM层，从而限制了对跨深度的互补任务证据的访问。我们引入LIRA，一种局部跨层动作条件机制，将VLM到动作的条件化建模为深度感知的信息路由。LIRA作用于由中间VLM状态派生的任务令牌特征和LIRA查询特征，然后为每个并行融合块分配一个以其对应VLM层为中心的深度对齐局部窗口。并行融合块聚合邻近的LIRA查询特征，并在动作预测前将其与任务令牌特征和本体感觉输入集成。该路由接口保持骨干架构、动作解码器和监督训练流程不变。在LIBERO、LIBERO-Plus、CALVIN ABC→D以及真实世界操作中，在相同的0.5B参数配置下，LIRA相比VLA-Adapter基线提升了主要聚合指标。在零样本迁移到LIBERO-Plus时，LIRA将平均成功率从59.1%提升至78.0%，提升了18.9个百分点，表明在受控分布偏移下鲁棒性有所提高。

## Abstract
Vision-Language-Action (VLA) models transform representations from pretrained vision-language models (VLMs) into robot actions, yet the interface that routes intermediate VLM features into action decoders remains underexplored. Existing designs either expose only a narrow part of the representation hierarchy or rigidly match each decoder block to one VLM layer, restricting access to complementary task evidence across depths. We introduce LIRA, a local cross-layer action-conditioning mechanism that formulates VLM-to-action conditioning as depth-aware information routing. LIRA operates on task-token features and LIRA Query features derived from intermediate VLM states, then assigns each Parallel Fusion Block a depth-aligned local window centered on its corresponding VLM layer. Parallel Fusion Blocks aggregate neighboring LIRA Query features and integrate them with task-token features and proprioceptive inputs before action prediction. This routing interface leaves the backbone architecture, action decoder, and supervised training recipe unchanged. Across LIBERO, LIBERO-Plus, CALVIN ABC$\rightarrow$D, and real-world manipulation, LIRA improves the principal aggregate metrics over the VLA-Adapter baseline under the same 0.5B-parameter configuration. In zero-shot transfer to LIBERO-Plus, LIRA increases average success from 59.1% to 78.0%, an 18.9-point gain indicating improved robustness under controlled distribution shifts.

## 1. 论文的核心问题与整体含义

- **研究动机**：VLA（视觉-语言-动作）模型通过复用预训练VLM的表征来生成机器人动作，但连接VLM与动作解码器的**接口设计**长期未被充分研究。该接口决定了动作生成过程中可利用的视觉、语言与任务证据的丰富程度。
- **现有方法的不足**：
  - 仅使用**最终层**特征（如OpenVLA-OFT），丢失了中间层的丰富语义；
  - **一对一硬性层对齐**（如VLA-Adapter），将每个解码器模块严格绑定到一个固定VLM层，无法利用相邻层的互补任务证据；
  - **全局聚合**（如π0.5）虽然跨层获取信息，但未显式保留VLM深度的局部结构，可能混合相距较远层的异构特征。
- **核心问题**：中间VLM表征应如何被路由到动作解码器？作者提出一个假设：**相邻VLM层为给定解码器深度提供互补的任务证据**。
- **整体含义**：本文将VLM到动作的条件化重新定义为**深度感知的信息路由**问题，并引入**深度局部性先验**——每个并行融合块（PFB）应访问以其对应VLM层为中心的相邻层局部窗口，而非仅单个匹配层或全部VLM层。

## 2. 论文提出的方法论

- **核心思想**：在VLA-Adapter基础上，将单层的LIRA Query条件替换为以匹配层为中心的**局部跨层窗口**，同时保留任务令牌特征的深度对齐分支，实现"局部跨层聚合 + 深度对齐锚定"的混合路由策略。

- **关键技术细节**：
  - **LIRA Query tokens**：向VLM输入追加M个可学习的查询令牌（默认M=64），从每个VLM层提取对应的LIRA Query特征。
  - **任务令牌特征**：从VLM层ℓ提取任务令牌特征$T_t^{(\ell)}$，提供视觉-语言上下文。
  - **本体感觉编码**：通过可学习投影 $\phi_p$ 编码 proprioceptive 状态获得嵌入 $E_t^p$。
  - **局部窗口定义**：对于第i个PFB，其路由窗口为与第i层距离不超过r的VLM层集合，默认r=1，即内部PFB使用三层窗口（第i-1、i、i+1层），边界PFB使用两层窗口（裁剪至有效边界）。
  - **特征聚合方式**：将窗口内各层的LIRA Query特征沿**令牌维度**（而非隐藏维度）按层序拼接，得到增广路由表征 $\tilde{R}_t^{(i)}$。该方式可直接被现有交叉注意力消费，无需新增投影层或可训练参数。
  - **条件融合**：$X_t^{(i)} = PFB_i(X_t^{(i-1)}; T_t^{(i)}, \tilde{R}_t^{(i)}, E_t^p)$——任务令牌提供深度对齐的语义锚点，增强的LIRA Query提供局部邻域互补信息。
  - **窗口宽度作为控制旋钮**：宽度为1退化为单层条件化（即VLA-Adapter）；宽度为3为默认设置；更大的窗口逐步逼近全局聚合。

- **训练目标**：使用监督式连续动作回归损失（L1损失），与VLA-Adapter完全一致：
  $$L_{act} = E_D\left[\frac{1}{H}\sum_{h=0}^{H-1}\|\hat{a}_{t+h} - a_{t+h}\|_1\right]$$
  其中H为动作块（action chunk）的预测视界。

## 6. 论文的主要结论与发现

1. **局部跨层路由有效**：在匹配的0.5B配置下，LIRA在所有三个模拟基准上全面优于VLA-Adapter基线。
2. **LIBERO**：平均成功率从97.3%提升至98.9%，最大增益出现在LIBERO-Long（95.0%→97.6%），表明多阶段任务受益更显著。

5. **消融结论**：三层窗口（r=1）最优；过宽窗口（4层）无益、全局聚合最差，支持"局部优于全局"的深度局部性先验；64个查询令牌的局部路由胜过256个令牌的仅末层路由，证明增益来自路由机制而非查询预算。
6. **真实世界**：LIRA在全部四个任务中取得最高成功率，Pick-and-Place从7/10提升至9/10，Collection Step 2从6/10提升至8/10。

## 7. 优点

- **零额外参数**：特征沿令牌维度拼接，直接被现有交叉注意力消费，无需新增投影层或可训练参数，保持了架构轻量性。
- **设计优雅**：将"局部跨层窗口"作为连续可调控制旋钮（窗口宽度从1到全局），统一了单层条件化与全局聚合两个极端，并验证了中间最优。
- **保留深度对齐锚点**：任务令牌特征仍与对应VLM层对齐，为局部聚合提供了稳定的语义参考，避免完全脱离深度结构。
- **零样本鲁棒性突出**：LIBERO-Plus零样本迁移的18.9点提升是最具说服力的实验证据，说明局部跨层信息路由在受控分布偏移下显著增强泛化能力。
- **公平对比**：与VLA-Adapter采用相同骨干、训练目标与配方，隔离了路由机制的独立贡献；同时提供了不同规模、不同训练管线的系统级参考。
- **资源高效**：0.5B配置耗显存少、推理快，在紧凑规模下超越了7B大模型，有利于实际机器人部署。

## 8. 不足与局限

- **骨干单一性**：所有实验仅使用Qwen2.5-0.5B一个紧凑VLM骨干和VLA-Adapter一种PFB解码器，无法证明方法跨不同骨干、不同解码器架构的普适性。
- **真实世界证据有限**：每个任务仅10次试运行，统计效力不足；仅一个机器人平台、四类任务，未覆盖接触丰富（contact-rich）和力敏感（force-sensitive）操作。
- **分布偏移有界性**：LIBERO-Plus的扰动虽然系统性，但仍属模拟环境中的受控偏移，不能等同于真实世界开放场景的任意分布变化。作者也明确指出结果"不意味着无限制的OOD泛化"。
- **与更大模型的对比公平性问题**：LIRA与7B/3B模型的对比并非严格受控，参数量与训练管线的差异可能影响结论（作者用"benchmark context"来界定其参考意义）。
- **未报告长训练细节**：未说明完整训练时长、总GPU小时数、不同随机种子下的方差等，复现性信息不够充分。
- **消融范围有限**：路由窗口仅在LIBERO-Long和CALVIN-5上进行了消融，未在LIBERO-Plus上验证窗口宽度的影响。

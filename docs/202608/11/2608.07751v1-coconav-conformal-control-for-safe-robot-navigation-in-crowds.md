## 摘要
在人群中实现安全高效的机器人导航，需要在预测误差不确定且可能发生偏移的情况下预测行人运动。现有的反应式方法可能产生振荡行为，而预测性规划器通常将预测视为精确或依赖受限的误差模型。将保守的不确定性集合作为硬约束也可能导致模型预测控制（MPC）不可行。我们提出了CoCoNav，一种结合在线共形校准与运行时认证规划的群体导航框架。一种特定于预测时域的共形比例-积分控制器调整轨迹误差界限，以调节长期经验覆盖率，使框架能够响应变化的预测误差。一种“先松弛后验证”的规划器通过使用软约束MPC生成标称轨迹，并单独对其以及应急机动进行认证，以在执行前满足校准后的界限，从而保持求解器的可行性。仿真和四足机器人实验表明，相对于评估的基线方法，CoCoNav在避碰、任务成功率和导航效率之间实现了良好的平衡。

## Abstract
Safe and efficient robot navigation in crowds requires anticipating pedestrian motion despite uncertain and potentially shifting prediction errors. Existing reactive methods can produce oscillatory behavior, while predictive planners often treat forecasts as exact or rely on restrictive error models. Incorporating conservative uncertainty sets as hard constraints can also render model predictive control (MPC) infeasible. We propose \textit{CoCoNav}, a crowd-navigation framework that combines online conformal calibration with runtime-certified planning. A horizon-specific conformal proportional--integral controller adapts trajectory-error bounds to regulate long-run empirical coverage, enabling the framework to respond to changing prediction errors. A \textit{relax-then-verify} planner preserves solver feasibility by generating nominal trajectories with soft-constrained MPC and separately certifying them, together with contingency maneuvers, against the calibrated bounds before execution. Simulations and quadruped experiments show that CoCoNav achieves a favorable balance among collision avoidance, task success, and navigation efficiency relative to the evaluated baselines.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **核心问题**：机器人在拥挤人群中导航时，必须**预测行人的未来运动**并应对预测的不确定性。然而，行人运动具有**交互性、多模态和非平稳性**，预测误差会随着人群结构与环境的变化而动态漂移。
- **现有方法的困境**：
  - **反应式方法**（如社会力模型、速度障碍法）虽然简单，但缺乏对未来的推理，容易反应迟缓或行为保守，产生振荡行为。
  - **预测感知规划器**（如MPC）往往将预测视为精确值，或依赖参数化的误差模型（如高斯分布），在模型选择错误或分布发生偏移时，不确定性区域会失效。
  - 将保守的不确定性集合直接作为**硬约束**嵌入MPC，容易导致有限时域优化问题**不可行**。
  - 预测误差的校准与基于校准结果的行动决策之间存在耦合挑战：校准只回答"预测该有多大不确定性"，不回答"在不确定区域过大致规划不可行时，机器人应如何行动"。
- **论文的解决思路**：将**在线共形校准**与**运行时认证规划**解耦：先对预测误差进行自适应校准，再通过"生成-验证-执行"的框架，在保证安全性的同时保留规划的可行性。

## 2. 论文提出的方法论

### 2.1 总体框架
CoCoNav是一个闭环管线，包含四个模块：行人轨迹预测 → 在线共形校准 → 软约束MPC生成候选轨迹 → 后验认证与应急选择。

### 2.2 行人轨迹预测
- 使用基于**条件变分自编码器（CVAE）**的预测器（SocialVAE），以ETH/UCY数据集训练。
- 输入8步历史轨迹，输出12步（H=12）的未来轨迹预测。

### 2.3 轨迹误差的在线共形校准
- **因果多步分数**：对于每个预测时域τ ∈ {1,...,H}，在时刻k可获得第k−τ步发出的预测的实际误差，形成堆叠欧氏距离分数：
  - s_τ,k = ‖z_τ,k‖₂ = (Σⱼ (d^pred_{τ,k,j})²)^{1/2}
  - 该分数满足置换不变性，且对每个行人 j 有 d^pred_{τ,k,j} ≤ s_τ,k（**分数支配关系**）。
- **共形PI控制器（CPI）**：每个预测时域独立维护校准状态，采用比例-积分更新规则：
  - e_τ,k = 1{s_τ,k > q_raw_{τ,k−τ+1}} − δ（δ为目标误覆盖率）
  - P_τ,k+1 = P_τ,k + η_τ,k · g_τ,k
  - q_raw_{τ,k+1} = P_τ,k+1 + r_k(G_τ,k−1)，其中r_k为带有饱和tanh变换的积分项。
- **Proposition 1** 证明在τ=1时，经验误覆盖率满足：
  - (1/T)Σe_1,t ≤ δ + r_T，其中 r_T → 0（T → ∞），即**长期经验误覆盖率受δ约束**。

### 2.4 不确定性感知的MPC与"松弛-验证"方案
- **名义候选生成（松弛）**：使用**软约束MPC**求解，将校准后的不确定性界与预测误差作为惩罚项（非硬约束），保证优化问题始终可行：
  - min J_track + Σψ(d_τ,k,j)，其中 d_τ,k,j = c_j(p_{k+τ|k}, ŷ_τ,k,j) − q_eff_{τ,k+1}
- **后验认证（验证）**：对生成的整条标称轨迹执行全时域验证：
  - c_j(p^Z_{k+τ|k}, ŷ_τ,k,j) ≥ d_safe + q_eff_{τ,k+1} + ε, ∀τ, ∀j
- **应急决策**：
  - 若标称轨迹通过认证 → 执行；
  - 否则，验证预定义的应急轨迹库（保持、减速、直行/转向制动）；
  - 若应急库中无可认证轨迹，则尝试加速度受限的制动轨迹；
  - 若制动轨迹也无法认证，则显式记录 N_k=1（**无可用认证动作**）。
- **Theorem 1** 给出了安全保证：
  - (1/T)ΣV_{k+1} ≤ δ + r_T + (1/T)Σ(B_{k+1} + N_k)
  - 即在标称认证成功且无感知遗漏时，碰撞违规率受δ约束；失败情况被显式记账。

## 6. 论文的主要结论与发现

- CoCoNav在**所有场景和密度**下实现了高成功率（≥80%）与低碰撞率（≤10%），而基线方法在密集人群中显著退化：ST-Planner碰撞率高（可达100%），ACP-MPC过度保守导致成功率崩坏（降至0%），MPPI在拥挤场景中成功率骤降。
- **CPI校准在分布漂移下更稳健**：ACP出现发散并饱和到无穷不确定性；CPI在长时域（h=12）比Conformal P-control获得更紧的边界（0.463 vs 0.543），误差曲线保持在零附近。
- **"松弛-验证"策略有效平衡安全与可行性**：准硬约束MPC导航时间几乎翻倍（46.82s），软约束单独使用安全性下降（0.52m），加上认证后恢复安全距离（0.56m）且方差最小。
- **真实四足部署验证了框架的可迁移性**，说明该方法在真实机器人平台上具备实际可行性。
- 核心洞见：**将校准（不确定性估计）与认证（安全决策）分离**，比将不确定性直接嵌入规划约束更能兼顾安全与效率。

## 7. 优点

- **方法创新性**：
  - 将**共形PI控制（CPI）**引入多步行人轨迹预测校准，实现了**因果、时域特定**的自适应不确定性估计，支持在线分布漂移跟踪。

## 摘要
世界模型只有在改变智能体行为时才对物理人工智能有用，并且只有在自身出错时拒绝行动才是安全的。我们通过CausalNav研究了这一要求的两个方面，CausalNav是一种围绕已识别状态坐标上的带符号、动作条件转换图构建的控制器。在部署时，CausalNav模拟一个小型干预序列库，将其目标误差转换为策略logit建议，并且仅当无尺度预测可靠性证书、策略边界门和argmax一致性门全部通过时才采纳该建议；否则，它完全回退到自身基于模型的基础控制器。我们在CartPole-v1和离散化Pendulum-v1上，在物理参数偏移下，与九个受控基线（Transformer、循环、分裂潜在、图、因果归纳以及三个近期基于模型的推理模块）进行了评估，共享一个PPO训练器、一个交互预算和十个留出种子（200次运行）。CausalNav获得了最佳平均排名（十者中为1.25）。诊断结果比排名更具信息量：学习到的图在远超随机水平上恢复了结构（CartPole F1 = 0.59 ± 0.09），但每个种子的结构保真度与每个种子的控制收益不相关（r = -0.15，p = 0.67），并且证书在10/10的Pendulum种子上弃权，而强制规划器则导致回报损失。在我们的设置中，模型保真度并不能预测下游控制效用；可信的弃权，而非更好的预测，才是使世界模型能够安全部署的原因。

## Abstract
A world model is only useful for physical AI if it changes what the agent does, and only safe if it declines to do so when it is wrong. We study both halves of that requirement with CausalNav, a controller built around a signed, action-conditioned transition graph over identified state coordinates. At deployment CausalNav simulates a small library of intervention sequences, converts their objective error into policy-logit advice, and admits that advice only when a scale-free predictive-reliability certificate, a policy-margin gate, and an argmax-agreement gate all pass; otherwise it falls back exactly to its own model-based base controller. We evaluate against nine controlled baselines (transformer, recurrent, split-latent, graph, causal-induction, and three recent model-based reasoning modules) on CartPole-v1 and discretized Pendulum-v1 with physical-parameter shifts, under one shared PPO trainer, one interaction budget, and ten held-out seeds (200 runs). CausalNav attains the best average rank (1.25 of ten). The diagnostic result is more informative than the ranking: the learned graph recovers structure well above chance (CartPole F1 = 0.59 +/- 0.09), yet per-seed structural fidelity is uncorrelated with per-seed control benefit (r = -0.15, p = 0.67), and the certificate abstains on 10/10 Pendulum seeds, where forcing the planner on costs return. Model fidelity did not predict downstream control utility in our setting; certified abstention, not better prediction, is what made the world model safe to deploy.

## 2. 方法论

### 2.1 核心思想
CausalNav 围绕一个**带符号的动作条件转换图**（signed, action-conditioned transition graph）构建控制器。部署时，它模拟一组干预序列，将目标误差转化为策略 logit 建议；只有三重门控全部通过时才采纳建议，否则**精确回退**到基础控制器（model-based base controller）。

### 2.2 关键技术细节

**（1）动作复杂性路由器（Action-complexity router）**
- MLP 将观察映射为 8 个 32 维槽（slot）；查询编码器将任务查询 q 映射为 32 维 token。
- 根据动作集大小选择控制器：
  - |A| ≤ 2：平均三个独立初始化的乐观专家（ensemble），R_opt(z) = z + mean_k f_k(z) + softplus(β)·std_k f_k(z)，增大容量；
  - |A| > 2：转换证书弃权，CausalNav 完全退化为基础控制器（归一化、门控的潜在残差）。
- 规则在冒烟种子 70–72 上选定，之后冻结，不使用回报或偏移标签。

**（2）动作条件转换图（Action-conditioned transition graph）**

预测每个已识别坐标的模型：
```
x̂_{t+1,i} = d_i x_{t,i} + Σ_{j≠i} A_ij x_{t,j} + Σ_{j<k, j,k≠i} B_{i,jk} x_{t,j} x_{t,k} + U_{a_t,i} + b_i
```
- A：一阶有符号成对系数；B：二阶有符号系数；U：动作效应；d：自持久性；b：偏置。
- 训练损失：L_trans = ⅛‖x̂_{t+1} − x_{t+1}‖²₂ + λ_s(‖A‖₁ + ‖B‖₁)，λ_s = 0.05，仅在激活的双动作分支上。
- 由于图连接 t 到 t+1，允许坐标级循环，**不施加** NOTEARS 无环约束。

**（3）干预库规划（Intervention-library planning）**
- 对每个可能的首动作，评估三种时间模式，H = 8 模型步长：
  - 常量（重复同一动作）；
  - 脉冲（动作一次，然后中性动作）；
  - 半视野（动作四步，然后中性）。
- 评分函数：累积加权目标误差 E(a) = (1/H) Σ_h Σ_i w̄_i (x̂_{t+h,i} − τ_i)²。
- 每个首动作的最低成本模式为归一化规划器 logit p_t(a)。

**（4）三重门控与最终 logits**
```
ℓ'_t(a) = ℓ_t(a) + g_t · ρ · tanh(α) · exp(−2m_t) · p_t(a)
```
- 一致性门 g_t = I[argmax_a p_t(a) = argmax_a ℓ_t(a)]：建议只能锐化、不能翻转贪婪动作；
- 证书 ρ：尺度无关的一步误差，ρ = clip((δ − |A|/2 · ē₄₈)/(δ/2), 0, 1)，δ = 0.70；
- 策略余量 m_t：策略 logits 前两大值之差，exp(−2m_t) 在策略自信时压抑制建议。

**（5）预测可靠性证书（Predictive-reliability certificate）**
- 跟踪尺度无关的一步误差：e_k = MSE / (⅛ΣVar + 10⁻⁴)；
- 在固定校准前缀（48次转换更新）后冻结部署尺度 ē₄₈；
- 动作数因子 |A|/2 保守地考虑了每动作样本更少的情况。

**（6）关键命题（精确回退）**
> 对于固定策略 logits，确定性评估下公式 preserve 了路由控制器的贪婪动作。若 ρ = 0 或 g_t = 0，建议项消失，ℓ'_t = ℓ_t；否则 g_t = 1，建议以非负尺度添加到 a⋆ = argmax ℓ_t(a)，a⋆ 仍是 ℓ'_t 的 argmax。

这是一个**确定性的动作选择属性**，是实现层面的非回归保障，而非概率性的控制安全保证。

**（7）优化**
- PPO 训练，总损失 = L_PPO + 0.5L_value − 0.01H(π) + 0.1(L_id + L_trans + λ_r L_repr)；
- 冻结路由变体的 λ_r = 0；
- 策略参数用 Adam 学习率 3×10⁻⁴，转换参数用 10⁻²，两个梯度组分别裁剪，规划器梯度不能改变 PPO。

## 6. 主要结论与发现

1. **整体排名**：CausalNav 平均秩 1.25（十方法中最佳），CartPole 偏移、Pendulum ID/偏移三格第一，CartPole ID 第二；SOMBRL 以 2.25 居次。

2. **因果世界模型的独立贡献不可测量**：配对差异（CausalNav vs 路由专家）在 CartPole 上小且置信区间横跨零；Pendulum 上构造性全为零。排名结果属于路由系统，**不能证明因果规划提升回报**。

3. **模型保真度不预测控制效用（核心负结果）**：
   - 转换图结构恢复远超随机（F1 = 0.59 ± 0.09，顶层父节点准确率 0.60 vs 未训练的 0.27）；
   - 但逐种子 F1 与配对回报差无相关（r = −0.15, p = 0.67）；
   - 一步 NRMSE 与配对差**正相关**（r = +0.71, p = 0.02）——一步模型最差的种子收益反而最大（作者解释为混淆而非因果，因为配对差由集成控制器驱动，而 F1/NRMSE 描述被门控在 argmax 之外的组件）。

4. **弃权行为的价值**：证书在 CartPole 7/10 种子放行（平均 ρ = 0.32），Pendulum 10/10 弃权。开发期强制规划时回报损失 34–54。证书仅从预测误差就能在部署前识别"模型在此不可靠"并正确禁用规划。

5. **最终结论**：世界模型是否对控制有帮助，不能由结构恢复和一/多步预测误差来保证；**认证式弃权（certified abstention）**而非更精确的预测，才是让世界模型安全部署的关键。

## 7. 优点

- **概念清晰**：将"有用性"（改变行为）和"安全性"（出错时拒绝行动）作为世界模型的两个对等要求同时检验；
- **三重门控设计**：可靠性证书（模型是否准）＋策略余量（是否已有自信策略）＋argmax一致性（建议是否只能锐化不能翻转），每一层都有明确作用，且命题证明了组合后的精确回退性质；
- **诚实的负结果**：明确报告"模型保真度不预测控制效用"并拒绝过度解读，这对领域比一个正结果更有价值；
- **受控实验严谨**：共享组件、配对种子、统一预算、新鲜种子报告、完整逐种子数据和可复现性工件；
- **对物理AI的实践指导**：提出"门控比图更重要"的可迁移经验，适用于运行软件系统的资源自适应缩放、非平稳物理过程的环境响应管道等部署场景。

## 8. 不足与局限

- **基准范围窄**：仅两个低维经典控制任务（CartPole-v1、Pendulum-v1），且 Pendulum 使用公开的 5 扭矩离散化，结论不直接适用于连续控制接口；
- **交互预算过小**：4096 次交互不足以收敛，种子方差大，CartPole 结果呈明显双峰分布；CI 宽导致多数差异在统计上不可分辨；
- **偏移设定温和**：偏移只改变物理参数，不改变观测语义、拓扑或奖励，更强的分布外偏移（如观测空间变化、拓扑变化）未覆盖；
- **监督标识**：已识别坐标由辅助监督（识别损失）提供，实验隔离的是"在已识别状态上规划"，**不构成无监督因果表示学习**的检验；
- **参考方法非原生复现**：它们是对归纳偏置的受控改编，不代表原论文方法的完整表现；
- **容量不对等**：CartPole 分支使用三成员集成，多于单一参考专家，排名优势部分来自参数容量——作者承认参数匹配对照是明显的下一步实验；
- **路由器选择偏差**：动作数阈值在观察两个数据集后选定，可能编码基准特定选择而非一般法则；Acrobot 和 FrozenLake 被检查但不晋升，这也是一种选择压力，需要一个预注册的基准套件来替代；
- **安全性声明边界**：agreement gate 验证的是窄范围的软件非回归属性，不是控制安全性；部署到物理或安全关键系统还需要校准的模型不确定性、保守回退控制器和领域特定验证。

## 摘要
世界模型越来越多地用于通过预测环境状态如何响应智能体行为来支持智能体规划。然而，流畅的下一状态预测仍可能遗漏任务关键事实、破坏产品属性或应用错误的转换规则。为了解决这种系统性预测错误，我们引入了MemWM，一种记忆增强的基于文本的世界模型。MemWM使用世界记忆（一个精心整理的转换规则、状态缓存和难以预测事实的记忆库）来调节下一状态的想象。我们通过结构化状态保真度（SSF）评估事实状态保留，该指标通过基准特定的事实和字段对预测状态进行评分。与SFT相比，记忆增强训练将SSF提高了高达206.3%。在完整的规划设置中，我们保持策略模型冻结，并提供策略侧世界技能：检索到的任务级技能和逐步纠正性指导，用于动作选择。在ALFWorld、WebShop和ScienceWorld中，记忆增强的智能体在下游成功率上优于基于SFT训练的世界模型智能体，相对增益高达65.4%。敏感性分析进一步表明，在不同的记忆和动作预算设置下，检索到的记忆提高了任务成功率和效率。

## Abstract
World models are increasingly used to support planning in agents by predicting how environment states evolve in response to agent actions. Yet fluent next-state predictions can still omit task-critical facts, corrupt product attributes, or apply incorrect transition rules. To address such systematic prediction errors, we introduce MemWM, a memory-augmented text-based world model. MemWM uses world memory, a curated memory bank of transition rules, state caches, and hard-to-predict facts, to condition next-state imagination. We evaluate factual state preservation with Structured State Fidelity (SSF), which scores predicted states through benchmark-specific facts and fields. Compared with SFT, memory-augmented training improves SSF by up to 206.3%. In the full planning setting, we keep the policy model frozen and provide policy-side world skill: retrieved task-level skills and step-wise corrective guidance for action selection. Across ALFWorld, WebShop, and ScienceWorld, memory-augmented agents improve downstream success over an SFT-trained world-model agent, with up to a 65.4% relative gain. Sensitivity analyses further show that retrieved memory improves task success and efficiency under different memory and action-budget settings.

## 1. 核心问题与研究动机

- **背景**：大语言模型（LLM）智能体在交互式环境（如具身家居、科学模拟、网页导航）中做序列决策时，越来越依赖**世界模型**来预测动作后的环境状态，从而支持前瞻规划（lookahead planning）。
- **核心问题**：现有文本世界模型的下一步状态预测虽然**表面流畅**，但常常犯三类系统性错误：
  - 遗漏任务关键事实（如物体位置绑定关系）；
  - 破坏产品属性（如商品 ID、价格、选项）；
  - 应用错误的转换规则（如设备状态、科学过程前提条件）。
- **现有评估指标的缺陷**：
  - **精确匹配（Exact Match）** 过于严格：无害的同义改写、格式变化、事实顺序调整会被判为 0 分；
  - **词级 F1（Word F1）** 过于宽松：即使交换物体/位置/价格等关键事实，token 重叠度仍可能很高，导致评分虚高。
- **论文主张**：世界模型的评估应关注**行为关键的结构化状态事实**是否得到保留，而不是表面字符串的相似性；而这类错误可以通过**外部化记忆**来缓解。

## 2. 方法论：MemWM

### 2.1 整体思想

论文提出 **MemWM（Memory-Augmented Text-Based World Model）**，其核心思想是：

> 构建一个**世界记忆库（World Memory）**，包含转换规则、状态缓存（state caches）和难预测事实，在想象下一步状态时检索并注入生成上下文，从而减少事实/规则/转换错误。

同时，在完整智能体（agent）中，还引入**策略侧世界技能（World Skill）**，包括：
- **任务级技能（World Task Skill）**：开局时根据任务类型检索一次，提供高层策略；
- **逐步纠正性指导（World Corrective Guidance）**：每一步根据当前轨迹状态检索，提供局部动作选择建议。

### 2.2 关键技术细节

- **世界模型的记忆增强预测**：
  - 不带记忆：\( \hat{s}_{t+1} = f_\theta(c_t, a_t) \)
  - 记忆增强：\( \hat{s}_{t+1} = f_\theta(c_t, a_t, R_{wm}(q_{wm}^t, M_{wm}^t)) \)
  - 其中 \( R_{wm} \) 为检索函数，\( M_{wm} \) 为世界记忆库，检索到的条目作为提示中的“辅助证据”，**不改变解码目标**，仅改变条件上下文。
- **记忆构造**：
  - 从训练轨迹、模型预测失败（hard-negative）、结构化状态中提炼；
  - 分为三类条目：转换规则、状态缓存、难预测事实；
  - 各环境具体化：ALFWorld 中为动作前提/物体状态/容器关系；ScienceWorld 中为实验前提/配方/温度/进度；WebShop 中为商品 ID/价格/选项/用户约束。
- **记忆检索**：
  - 轻量级、领域相关的匹配（如按目标签名、动作模式、物体类型、上下文桶匹配）；
  - 若检索记忆与可见轨迹冲突，以可见轨迹为准。
- **策略侧世界技能**：
  - 任务级技能从目标任务类型中提取，**每 episode 只检索一次**；
  - 纠正性指导每步按触发条件动态检索，插入策略提示中。
- **与规划集成（算法流程）**：
  1. 任务开始：检索任务级技能；
  2. 每步：构建上下文，检索纠正性指导，由策略生成候选动作；
  3. 对每个候选动作检索世界记忆，生成想象下一状态；
  4. 用规划规则（如贪婪/前瞻搜索）对想象轨迹打分，选择最高分动作执行；
  5. 执行后更新历史与记忆证据。

### 2.3 提出的评估指标：结构化状态保真度（SSF）

- **定义**：将预测状态和黄金状态投影为结构化事实/字段，按组件加权求和相似度：
  \[
  SSF_d(\hat{s}_{t+1}, s_{t+1}) = \sum_{c \in C_d} w_c \cdot sim_c(\hat{z}_c, z_c)
  \]
- **ALFWorld / ScienceWorld**：用事实抽取器转为规范化事实集，计算事实集 F1；
- **WebShop**：用确定性页面解析器提取页面类型、商品 ID、标题、价格、选项等字段，计算加权字段相似度；
- **设计原则**：优先使用确定性规则（透明、可复现），避免抽取器“脑补”修复被破坏的预测。

## 6. 主要结论与发现

1. **记忆增强训练显著提升结构化状态保真度**：
   - Mem-Aug RL 在全部 9 个模型–基准单元格（3 模型×3 环境）中均取得最高 SSF；
   - 对比 SFT，SSF 最高提升 206.3%（出现于 WebShop 上小模型场景）；
   - 对比无记忆 RL，WebShop 提升最明显：+0.175（Llama3.2-1B）、+0.070（Qwen3-4B）、+0.135（Qwen2.5-7B）。
2. **预测时去除记忆会降低 SSF**：图 4 显示，随着记忆块丢弃比例增加，SSF 在三个环境中均下降，说明检索到的记忆确实在生成时被有效使用，而非无关上下文。
3. **下游任务成功率提升，且无需策略训练**：
   - MemWM/MemWM+Skill 在 ALFWorld 总体和 WebShop 总分上均超过 SFT 训练的世界模型智能体；
   - 最大相对增益 65.4%（Qwen3-8B 上，ALFWorld 总体成功率从 51.36% 提升至 65.24%）；
   - ScienceWorld 上在部分模型中也有提升。
4. **增益不是动作预算或随机记忆的产物**：
   - 动作预算敏感性表明，记忆增强方法在各种候选动作数量下均优于 SFT 基线，且成功任务步数没有显著增加；
   - 组件消融显示：随机记忆/无关记忆会降低性能（0.4712/0.4403 vs 0.5696），相关检索记忆是关键。
5. **世界记忆与策略技能贡献互补**：MemWM（有记忆）单独达到 0.5696，加技能后轻微增至 0.5727，说明世界模型侧记忆贡献主要部分，策略技能提供附加价值。

## 7. 优点

- **问题定位精准**：明确指出现有文本世界模型的“状态保真瓶颈”，并系统分析表面指标（EM、Word F1）的缺陷，提出结构化保真度评估。
- **方法实用新颖**：将检索增强的记忆机制引入世界模型预测，且不改变解码目标，仅注入上下文，工程实现简单，易于推广。
- **双通道设计**：区分“世界记忆”（用于状态想象）和“世界技能”（用于动作选择），避免两类信息混淆，消融表明彼此互补。
- **评估严谨细密**：
  - SSF 按照环境结构定制字段/事实和权重，并做了身份一致性审计、字段权重敏感性分析、盲审验证；
  - 有效性通过多种敏感性分析（记忆 dropout、动作预算、随机/无关记忆）交叉验证，可信度高；
  - 所有 agent 变体中策略模型冻结，排除了策略训练带来的混淆因素。
- **跨领域验证**：三个环境覆盖具身交互、科学实验、电商网页三类不同的结构化状态，证明了方法的一般性。

## 8. 不足与局限

- **算力信息不透明**：未说明 GPU 型号、训练时长、总 GPU 小时数，难以评估可复现性成本和规模效应。
- **SSF 的构造依赖人工设计**：每个环境都需要手工定义字段/事实模式、权重和抽取规则，从一种环境迁移到新环境需要重新设计，成本较高（论文也承认这一点）。
- **LLM 抽取器可能引入偏差**：ALFWorld 使用 LLM 作为事实抽取器，ScienceWorld 在回退时也使用 LLM，尽管做了约束提示和身份审计，仍可能在罕见表达上产生不一致。
- **盲审范围有限**：盲审验证仅覆盖 ALFWorld 和 WebShop，ScienceWorld 的 SSF 缺乏独立人工一致性验证。
- **未比较记忆库大小的影响**：虽然做了记忆 dropout 和随机/无关记忆对照，但没有系统分析**不同记忆库规模**对性能的影响，也未与基于向量检索的通用 RAG 方案对比。
- **下游任务提升幅度在不同环境差异大**：ScienceWorld 上的提升相对较小（部分指标甚至没有超过基线），说明方法在结构化程度更高、状态更复杂的科学环境中可能收益有限。
- **策略侧技能依赖离线挖掘**：纠正性指导和任务技能由人工分析失败模式或从成功轨迹中提炼，在更开放/更复杂环境中可能难以覆盖所有错误模式。

## 摘要
稳健的机器人控制受益于显式地对状态转换进行建模，但视频生成世界动作模型（WAM）会带来巨大的部署成本。现有的潜在WAM避免了显式的未来生成，但通常压缩预测表示或将预测建模与用于动作生成的表示分离。我们引入了JEPA-WAM，一种构建在预训练V-JEPA空间中的潜在WAM，它通过共享预测器将潜在转换预测与连续动作生成耦合。JEPA-WAM预测一个空间结构的联合当前-未来目标，该目标捕获当前和未来观测之间任务共享的视觉时间结构，同时保留密集的补丁级对应关系。通过共享预测器，转换监督直接塑造主干网络，从中提取专门用于动作预测的表示。同样的设计也可以在预训练的VLA策略中实例化，同时保留其原始感知和动作通路。在LIBERO-Plus上，JEPA-WAM达到了79.2%，是在没有大规模机器人策略预训练的情况下的最佳结果，而其预训练的π_{0.5}实例达到了86.3%，取得了最佳整体性能。在RoboTwin 2.0和真实世界双臂操作上的实验进一步证明了在视觉和空间变化下的强大泛化能力。

## Abstract
Robust robot control benefits from explicitly modeling state transitions, but video-generation world action models (WAMs) introduce substantial deployment cost. Existing latent WAMs avoid explicit future generation, but often compress predictive representations or separate predictive modeling from the representations used for action generation. We introduce JEPA-WAM, a latent WAM built in a pretrained V-JEPA space, which couples latent transition prediction with continuous action generation through a shared predictor. JEPA-WAM predicts a spatially structured joint current-future target that captures task-shared visual temporal structure between current and future observations, while preserving dense patch-level correspondence. Through the shared predictor, transition supervision directly shapes the backbone, from which dedicated representations are extracted for action prediction. The same design can also be instantiated in pretrained VLA policies while preserving their original perception and action pathways. On LIBERO-Plus, JEPA-WAM achieves 79.2%, the best result without large-scale robot-policy pretraining, while its pretrained $π_{0.5}$ instantiation reaches 86.3%, achieving the best overall performance. Experiments on RoboTwin 2.0 and real-world bimanual manipulation further demonstrate strong generalization under visual and spatial shifts.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- 视觉-语言-动作（VLA）策略在各类操作任务中表现优异，但其动作预测目标仅隐式地建模状态转换，在面对分布偏移时鲁棒性不足。
- **世界动作模型（WAM）** 通过显式建模未来状态来增强策略的鲁棒性，但基于**视频生成**的 WAM 需要迭代式未来帧预测，部署成本高昂。
- 现有的**潜在（latent）WAM** 避免了显式未来生成，但常存在两个问题：
  - 预测目标方面：或复用生成模型的中间特征而缺乏对状态变化的显式表达，或将未来观测压缩为少量全局 token，丢失细粒度空间结构；
  - 策略集成方面：或让动作模块接触冗余的未来信息，或预测监督对策略主干表示的影响过弱。
- 本文提出 **JEPA-WAM**：构建在预训练 **V-JEPA 2.1** 表示空间中的潜在 WAM，通过**共享预测器**将潜在转移预测与连续动作生成耦合，在保留部署效率的同时提升 OOD 泛化能力。

## 2. 论文提出的方法论

### 2.1 核心思想

- JEPA-WAM 的核心是**利用共享预测器同时执行两件事**：
  1. 预测一个空间结构的“联合当前–未来目标”来建模视觉时间转换；
  2. 提取专用表示用于动作生成。
- 转换监督直接调整共享主干，使预测建模与动作生成的表示相互受益，但动作专家并不直接依赖完整预测的转换表示。

### 2.2 关键技术细节

- **V-JEPA 表示空间**：使用冻结的 V-JEPA 2.1 编码器获得当前观测的稠密 patch 级表示 \( Z_t = \text{Concat}_{v\in V} E_J(O_v^t) \)，保持固定相机顺序和空间 token 顺序。
- **联合当前–未来目标**：将当前帧 \( O_t \) 与 δ 步后的未来帧 \( O_{t+\delta} \) 沿时间维堆叠后联合编码，得到 \( Y_{t,t+\delta} \)，因此目标保留了与 \( Z_t \) 相同的空间 token 网格，可进行 patch 级对齐。该目标捕捉“哪些区域稳定、哪些变化、局部物体与空间关系如何演变”，而不要求重建唯一未来帧。

- **共享预测器**：使用 Qwen2.5-0.5B 作为共享预测器，处理视觉表示、任务指令和专用 action placeholder tokens。输出：
  - 视觉 token 位置的隐藏状态 \( Q_t^{wm} \)，用于预测联合当前–未来目标；
  - 专用表示 \( C_t \)，用于条件化动作生成。
- **潜在转移预测**：通过预测头 \( G_\phi \) 将 \( Q_t^{wm} \) 映射回 V-JEPA 空间，优化 patch 级余弦距离损失 \( L_{wm} \)。
- **动作生成**：使用基于 DiT 的条件流匹配动作专家，优化速度预测目标 \( L_{act} \)。
- **联合训练**：总损失 \( L = L_{act} + \lambda_{wm} L_{wm} \)，\( \lambda_{wm}=0.5 \)。
- **部署时**：移除目标分支和预测头，仅保留当前观测编码、视觉投影器、共享预测器和动作专家。

### 2.3 向预训练 VLA 策略的迁移

- 通过加入 64 个可学习的 future tokens，将其隐藏状态重塑为粗空间特征图后上采样，与 V-JEPA 联合目标进行 patch 级对齐，同时保持原 VLA 的感知和动作通路不变。

## 6. 论文的主要结论与发现

- JEPA-WAM 在 LIBERO-Plus 上达到 **79.2%**，为无大规模预训练方法中的最优；在 LIBERO 上平均 **96.7%**，保持竞争性的 ID 性能。

## 7. 优点

- **方法设计优雅**：共享预测器同时完成转移预测与动作生成，转换监督直接塑造策略主干，无需未来帧显式生成，兼顾预测能力和部署效率。
- **预测目标设计巧妙**：联合当前–未来目标在预训练 V-JEPA 空间中保留密集 patch 结构，有效建模“转换关系”而非仅“未来状态”，优于未来-only 和端点差目标。
- **良好的可迁移性**：同一目标公式可无缝应用到预训练 VLA 策略（π0.5）中，仅增加极少量参数即可提升 OOD 泛化。
- **实验系统而全面**：从模拟到真实、从 ID 到 OOD、从性能到效率，并通过冻结探针深入分析了表示中时间信息的性质，增强了结论的可信度。

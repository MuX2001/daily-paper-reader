## 摘要
我们提出CAT，一种用于机器人操作的轨迹级连续动作表示框架。现有的视觉运动系统常常将动作表示与控制频率纠缠在一起，或依赖于固定的时间参数化。这导致在高采样率下表示冗余，并限制了关键运动的建模。CAT则将固定实时间隔内的动作轨迹编码为一组连续潜在标记。为确保不同控制频率下的时间一致性，我们进一步引入了频率感知的位置编码，以建立共享的时间坐标系。轨迹级正则化进一步稳定了潜在表示。该方法避免了表示随时间步密度增长，也避免了对预定义时间参数化的依赖。在LIBERO、MimicGen以及真实长视界操作任务上进行的大量系统级评估表明，在匹配的训练设置下，基于CAT的策略一致优于基于VQ的基线和连续视觉运动基线。在各种模型主干和控制频率下，CAT均持续提高了成功率。这些结果突显了轨迹级连续动作建模在不同控制速率下实现可扩展机器人操作的优势。

## Abstract
We propose CAT, a trajectory-level continuous action representation framework for robotic manipulation. Existing visuomotor systems often entangle action representation with control frequency or rely on fixed temporal parameterizations. This leads to representational redundancy at high sampling rates and limits the modeling of critical motion. CAT instead encodes action trajectories within a fixed real-time interval into a set of continuous latent tokens. To ensure temporal consistency across varying control frequencies, we further incorporate a frequency-aware positional encoding that establishs a shared temporal coordinate system. Trajectory-level regularization further stabilizes the latent representation. This approach prevents representation growth with timestep density and avoids reliance on predefined temporal parameterizations. Extensive system-level evaluations on LIBERO, MimicGen, and real-world long-horizon manipulation tasks demonstrate that CAT-based policies consistently outperform both competitive VQ-based and continuous visuomotor baselines under matched training settings. Across various model backbones and control frequencies, CAT consistently improves success rates. These results highlight the advantages of trajectory-level continuous action modeling for scalable robotic manipulation across varying control rates.

## 1. 核心问题与整体含义（研究动机与背景）

- 机器人视觉运动策略（visuomotor policy）需要建模连续动作轨迹，但不同时间段对任务成功的影响并不均匀：接触转换、自由运动与交互之间的切换、短暂修正等关键片段往往只有很短的时间，而大量轨迹段是平滑、重复的。
- 现有动作表示存在两类问题：
  - **时间步级离散化（timestep-level discretization）**：表示结构直接绑定到控制频率的时间网格上，采样频率越高，表示长度成比例增长，产生大量时间冗余，且关键动作信息被稀释。
  - **预定义时间参数化（predefined temporal reparameterization）**：如 DCT 系数、B-spline 控制点、谱域 token 等，虽然表示大小不再随频率变化，但仍受所选时间/谱基的限制，无法自适应建模关键运动。
- 论文提出 **CAT（Trajectory-Level Continuous Action Representation）**，将固定实时间隔内的动作轨迹编码为固定数量的连续潜在 token，从而将动作表示与控制频率解耦，避免表示规模随采样密度增长，也不依赖预定义时间基底。

## 2. 方法论

### 核心思想

- 在固定实时窗口（如 T = 1 秒）内，将动作序列编码为 K 个连续潜在 token，K 远小于时间步数 N，且 K 不随控制频率变化。
- 用频率感知位置编码（F-RoPE）将时间步索引归一化为 `t / f_s`，使不同控制频率采样的轨迹在共享时间坐标系中对齐。
- 通过重建损失 + 轨迹级对比正则化，保证潜在空间既紧凑又具有判别性。

### 关键技术细节

1. **结构解耦**：
   - 给定动作序列 `{a_t}` 和频率缩放时间索引 `{t/f_s}`，编码器输出 K 个 register tokens：`{z_i} = f_θ({a_t}, {t/f_s})`。
   - 解码器使用 action embeddings 结合 register tokens 重建动作：`{â_t} = g_ϕ({z_i}, {e_t}, {t/f_s})`。
   - 解码采用非对称因果掩码：action embeddings 可关注所有 register tokens，但 action embeddings 之间沿时间维因果注意，保证时序依赖建模。

2. **频率对齐（F-RoPE）**：
   - 每个时间步 t 的旋转位置编码使用归一化时间 `t/f_s`：
     `F-RoPE(t/f_s) = [sin(ω_i t/f_s), cos(ω_i t/f_s)]`
   - 该嵌入施加到注意力 query/key 上，使模型能够区分不同控制频率下的轨迹，同时保持时间坐标一致性。

3. **潜在稳定性与训练目标**：
   - 重建损失（均方误差）：
     `L_rec = (1/N) Σ ||a_t − â_t||²`
   - 对比正则化：将 K 个 register tokens 拼接为 `z̄ = [z_1 || ... || z_K]`，惩罚小批量内不同轨迹嵌入之间的距离：
     `L_reg = (1/B) Σ log Σ_{j≠i} exp(−D(z̄_i, z̄_j)/η)`
   - 总目标：
     `L_CAT = L_rec + λ_reg · L_reg`
   - 该正则化防止不同轨迹在潜在空间中过度重叠，提高轨迹级判别能力。

4. **与流匹配 VLA 集成**：
   - 用 CAT 替换原始时间步级动作参数化，扩散/流匹配模型在潜在轨迹 Z 上学习速度场：
     `L_FM = E ||v_ψ(Z_τ, τ, c) − (Z_1 − Z_0)||²`
   - 推理时，模型先生成干净潜在轨迹，再由 CAT 解码为连续动作。

## 6. 主要结论与发现

- **轨迹级表示优于时间步级/离散化表示**：在 SmolVLA 骨架上，CAT 将 LIBERO 平均成功率从 87.3% 提升到 90.8%（+3.5）；在 π0 上从 94.2% 提升到 96.5%（+2.3）。
- **在 MimicGen 多任务上也有增益**：DP-CAT 平均成功率 86.9%，高于 DP 的 85.8%（+1.1），其中 Stack 3 提升最大（+9）。
- **频率鲁棒性显著**：在 RoboTwin 2.0 上，SmolVLA-CAT 在 10Hz/16.7Hz/25Hz/50Hz 下分别取得 45.6%、46.1%、48.1%、45.3%，高于基线（35.3%、42.1%、37.9%、40.0%），且 24/32 的任务-频率配对优于基线。
- **关键交互动作受益最大**：Grab Roller（+18.5）、Press Stapler（+16.0）、Place Container Plate（+10.3）等涉及短促关键交互的任务提升显著，而平滑任务（如 Adjust Bottle、Place Burger Fries）提升较小，验证了轨迹级表示对时间不均匀重要性的建模能力。
- **真实长视界任务有效**：SmolVLA-CAT 平均分数 60.5，超过基线 45.0，四个任务均提升，尤其是 Flower（+28）。
- **消融结论**：F-RoPE 优于 learned PE；K=4 优于 K=2/6/8；λ_reg=0.1 最优；因果注意力优于全注意力（+2.25）。

## 7. 优点

- **问题动机清晰且具有实际意义**：控制频率变化是真实机器人系统中常见的工程约束，论文针对表示-频率耦合问题提出直接解决方案。
- **方法设计简洁、概念统一**：将动作表示从时间网格和固定时间基底中解耦，用固定数量连续 token 建模轨迹，逻辑自洽。
- **频率感知位置编码（F-RoPE）设计精巧**：将控制频率归一化融入 rotary embedding，在共享时间坐标下保留频率差异，是一种可推广的编码方式。
- **轨迹级对比正则化** 有助于在固定 token 预算下维持潜在空间的判别性，是一个合理且有效的补充。
- **系统级验证全面**：同时覆盖模拟（LIBERO、MimicGen、RoboTwin 2.0）和真实世界，且与流匹配 VLA 集成，兼容性强。
- **在多个骨干（SmolVLA、π0、DP）上都验证了增益**，说明表示改进具有跨模型通用性。

## 摘要
虽然在大规模机器人数据集上预训练的视觉-语言-动作（VLA）模型为机器人操作提供了坚实的基础，但当适应到具有有限任务特定演示的新任务时，它们的性能可能会下降。检索提供了一种重用现有演示以实现数据高效适应的实用方法，但现有方法通常依赖于视觉相似性、状态-动作表示或任务级语言匹配。这些方法可能忽略了长视野操作任务的层次结构，其中完整的任务匹配很少见，但可复用的技能往往很丰富。为了应对这一挑战，我们提出了分层技能检索（HSR），一种用于数据高效VLA适应的检索框架。具体而言，HSR首先将目标任务分解为候选技能序列。它根据从先验数据集估计的语义合理性和技能可靠性来评估每个计划。然后，选定的分解用于混合检索。这结合了子任务级语言检索和行为特征重排序，以识别既与目标任务语义相关又兼容的演示。最后，我们通过两阶段的预训练和微调流程来适应策略，该流程将通用技能获取与特定任务适应分开。在LIBERO基准和几个真实世界机器人操作任务上的实验表明，与最强基线相比，HSR的平均成功率分别提高了10.3%和21.3%。这些结果证明了结构化技能级检索对于数据高效VLA适应的有效性。视频和代码可在 https://hoar012.github.io/HSR-Project 获取。

## Abstract
While Vision-Language-Action (VLA) models pretrained on large-scale robot datasets provide a strong foundation for robot manipulation, their performance can degrade when adapted to new tasks with limited task-specific demonstrations. Retrieval offers a practical way to reuse existing demonstrations for data-efficient adaptation, but existing methods often rely on visual similarity, state-action representations, or task-level language matching. These approaches may overlook the hierarchical structure of long-horizon manipulation tasks, where complete task matches are rare but reusable skills are often abundant. To address this challenge, we propose Hierarchical Skill Retrieval (HSR), a retrieval framework for data-efficient VLA adaptation. Specifically, HSR first decomposes a target task into candidate skill sequences. It evaluates each plan based on both semantic plausibility and skill reliability estimated from the prior dataset. The selected decomposition is then used for hybrid retrieval. This combines subtask-level language retrieval with behavior-feature reranking to identify demonstrations that are both semantically relevant and compatible with the target task. Finally, we adapt the policy through a two-stage pretraining and finetuning pipeline, which separates general skill acquisition from task-specific adaptation. Experiments on the LIBERO benchmark and several real-world robot manipulation tasks show that HSR improves the average success rate by 10.3% and 21.3% over the strongest baseline, respectively. These results demonstrate the effectiveness of structured skill-level retrieval for data-efficient VLA adaptation. Videos and code are available at https://hoar012.github.io/HSR-Project.

### 二、论文提出的方法论

#### 1. 核心思想
利用长视界任务的层级结构，先在语义层面把目标任务分解为若干“技能”，再以技能为查询粒度从先验数据集中检索高相关演示，避免直接匹配完整任务时匹配不上的问题。

#### 2. 层次化任务分解（Hierarchical Task Decomposition）
- 对先验数据集 `D_prior` 中的任务指令提取文本嵌入，使用 **K-means 聚类**得到 `K` 个可复用技能簇（如 Find、Pick up、Pour、Turn on 等）。
- 使用 LLM（论文采用 Qwen3-VL-4B）生成多个候选任务分解计划，每个计划为有序子任务序列 `p = (u1, ..., un)`。
- 对每个子任务 `uj`，映射到其最近的技能簇 `s(uj)`。
- 计算 **Skill Confidence Score**：
  ```text
  C(si) = exp(−α·L̂val(si) − β·Ĥ(si))
  ```
  其中 `L̂val` 是基于验证集行为克隆（BC）损失的归一化技能可靠性代理，`Ĥ` 为归一化平均轨迹长度，`α=0.6`、`β=0.8`。该分数避免真实 rollout 的高成本，作为无 rollout 的技能可靠性指标。
- 计划得分由语义得分与技能置信度共同决定：
  ```text
  Score(p) = S_sem(p) · Π_j C(s(uj))
  ```
  选择得分最高的计划作为最终分解结果。

#### 3. 混合技能检索（Hybrid Skill Retrieval）
- **第一阶段**：以每个子任务的语言指令为查询，从先验数据集中按语言相似度检索 top `M%` 的完整回合（episode-level 语义筛选）。
- **第二阶段**：将候选回合展开为帧级数据，训练 VAE 编码器提取行为特征，计算候选帧与目标任务演示帧的最近邻负距离作为相似度：
  ```text
  s(f) = max_j (−∥zf − zt_j∥²)
  ```
  保留 top `F%` 的高相似帧，得到最终检索数据（frame-level 行为兼容筛选）。

#### 4. 两阶段策略适应（Policy Adaptation）
- **阶段一：技能预训练**——仅在语言检索得到的技能数据 `D_lang` 上预训练，学习通用可复用技能。
- **阶段二：任务微调**——在目标数据 `Dt` 与特征重排序后的检索数据 `D_rerank` 上微调，完成任务特定适应。
- 区别于以往“单阶段联合训练”方法，该设计避免了检索数据噪声对目标任务的干扰。

### 三、实验设计

#### 1. 模拟实验（LIBERO Benchmark）
- **Benchmark**：LIBERO benchmark 的长视界子集，包含 10 个复合操作任务（如 Soup-S、Moka-M、Mug-M、Bowl-C 等）。
- **目标任务数据**：每任务仅 **5 条演示**构成目标数据集 `Dt`。
- **先验数据集**：LIBERO-90（90 个任务、每任务 50 条演示）。
- **检索策略**：阶段一检索 top 10% 回合，重排序后保留 top 30% 帧（约占先验数据集全部帧的 3%）。
- **评估**：每任务 50 次评估回合、3 个随机种子，报告平均成功率与标准差。

#### 2. 真实世界实验
- **平台**：7-DoF xArm 机器人。
- **任务**：4 个不同复杂度任务——
  - Drawer（关抽屉，1 个子任务）
  - Trashcan（拾纸团丢垃圾桶，2 个子任务）
  - Cup-Drawer（放杯入抽屉并关闭，3 个子任务）
  - Cup-Tea（放茶包、倒水等，4 个子任务）
- **目标任务数据**：每个任务 20 条演示。
- **先验数据集**：从 DROID 数据集中随机采样 10k 条轨迹。
- **评估**：每任务 20 次试验，不同初始状态，各模型使用相同状态集合保证公平比较。

#### 3. 对比方法
- **BC**：仅用目标任务数据微调。
- **Random / All Data**：随机采样/全量先验数据与目标数据联合训练。
- **Language**：基于语言相似性的简单检索。
- **FR**（Flow Retrieval）：基于光流相似性。
- **STRAP**：基于视觉基础模型+动态时间规整的子轨迹检索。
- **BR**（Behavior Retrieval）：基于 VAE 潜空间相似性。
- **IWR**（Importance Weighted Retrieval）：基于重要性加权的 VAE 检索。
- **额外消融对照**：无任务分解、无特征重排、单阶段协同训练、BR+两阶段、纯 LLM 规划，以及人工规划的 HSR 上限参照。

### 六、论文的主要结论与发现

1. **HSR 在模拟和真实世界均显著优于最强基线**：
   - LIBERO 上平均成功率比最强基线提升 **10.3%**；
   - 真实世界任务上提升 **21.3%**。
2. **长视界复合任务提升尤为显著**：
   - Mug-M 任务上 HSR 比 STRAP 高出 27.3%；
   - 挑战性的 Bowl-C 任务是唯一优于纯 BC 的方法；

3. **检索数据质量决定适应效果**：随机/全量数据混合提升有限，语言检索优于随机但不足以捕捉细粒度语义，行为级/轨迹级检索优于语言但在复合任务上受限。
4. **任务分解和特征重排各有贡献**：去掉分解或重排模块性能均下降；保留中等比例的重排数据效果最佳。
5. **两阶段训练优于单阶段协同训练**：先学习通用技能、再任务微调，更适应先验数据与目标任务分布不一致的情况。
6. **HSR 有效性来自跨子任务的精确检索**：检索数据分布展示 HSR 能同时获取目标放置类与微波炉关闭类等多技能演示，而不像基线偏向单一任务类型。

### 七、优点

- **创新性地引入技能级层级检索**：不同于任务级语言匹配和视觉/运动相似性，HSR 显式建模了长视界操作任务的层级结构，契合 VLA 模型的语言理解能力。
- **无 rollout 的技能可靠性评估**：用验证集 BC 损失 + 轨迹长度作为技能置信度代理，兼顾成本与有效性，避免真实环境部署中的高昂评估。
- **混合检索设计合理**：先语言（保证语义相关）后行为特征（保证兼容性），实现 episode 级筛选与 frame 级精排的统一。
- **两阶段适应机制具有可迁移价值**：将“通用技能获取”与“任务特定适应”解耦，在跨 embodiment 场景中（如 DROID → xArm）比单阶段联合训练更稳健。
- **实验验证充分且对比公允**：基线涵盖当前主流检索范式，真实世界采用相同初始状态集合，消融设计完整。

### 八、不足与局限

- **任务与场景覆盖有限**：仅验证了操作任务（LIBERO + 4 个真实世界任务），未覆盖移动操作、灵巧手、多机器人协同等场景。
- **单一大模型支撑**：VLA 仅用 SmolVLA-450M，LLM 仅用 Qwen3-VL-4B，未验证方法在不同 backbone（如 OpenVLA、π0）上的泛化性。
- **跨实体差距处理较弱**：真实实验中因 DROID 与 xArm 之间实体差异大，第二阶段放弃了检索数据仅用目标任务微调，说明 HSR 的跨实体适应能力仍需加强。
- **技能可靠性代理的间接性**：BC 损失与轨迹长度仅是真实成功率的间接估计，存在偏差风险；α、β 权重为固定经验值，缺乏敏感性分析。
- **消融规模有限**：核心消融仅在 4 个 LIBERO 任务上进行，未覆盖全部 10 个任务；真实世界任务未做消融。
- **算力与效率信息缺失**：未报告训练时长、显存消耗、检索时间等工程细节，不利于复现和实际部署评估。
- **未涉及在线/闭环规划**：任务分解是离线固定的，缺少在线重规划、失败恢复（test-time adaptation）等机制，部署时遇到意外情况难以应对。

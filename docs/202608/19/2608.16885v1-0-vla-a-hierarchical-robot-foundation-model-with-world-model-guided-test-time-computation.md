## 摘要
长期机器人操作要求机器人既能可靠地执行单个技能，又能在扩展任务中连贯地将它们序列化。大多数分层视觉-语言-动作（VLA）模型通过单次前向传递做出每个此类决策，没有机制为困难或关键选择分配额外计算。我们提出$τ_0$-VLA，一种分层机器人基础模型，通过世界模型引导的测试时计算，将高层子任务生成表述为可扩展计算推理问题。在每个推理步骤中，高层策略使用执行记忆生成子任务，并在需要时在替代方案中进行搜索，然后才确定输出。随后，低层策略在多个机器人本体上执行生成的子任务。该策略在40,115小时的异构真实世界数据上训练，并采用多模态协同训练。在域内和分布偏移设置中，分配额外的测试时计算显著提高了下一子任务预测准确性，这些增益转化为长期机器人操作任务中更高的闭环成功率。

## Abstract
Long-horizon robot manipulation requires a robot to both execute individual skills reliably and sequence them coherently over extended tasks. Most hierarchical vision-language-action (VLA) models make each such decision with a single forward pass, leaving no mechanism to allocate additional computation to difficult or consequential choices. We introduce $τ_0$-VLA, a hierarchical robot foundation model that formulates high-level subtask generation as a compute-scalable inference problem through world-model-guided test-time computation. At each inference step, the high-level policy uses execution memory to generate a subtask and, when needed, searches over alternatives before committing to its output. A low-level policy then executes the generated subtask across multiple robot embodiments. The policy is trained on 40,115 hours of heterogeneous real-world data with multimodal co-training. Across in-domain and distribution-shifted settings, allocating additional test-time computation substantially improves next-subtask prediction accuracy, and these gains translate into higher closed-loop success on long-horizon robot manipulation tasks.

## 1. 论文的核心问题与整体含义

- **研究动机**：长期机器人操作任务（如打扫房间、做饭、制作饮品）需要机器人既可靠执行单个技能，又能长时间连贯地进行任务规划与执行。现有分层VLA模型通常以单次前向传播完成高层决策，缺乏为困难或关键决策分配额外计算资源的机制。
- **核心问题**：一个错误的高层子任务选择无法通过更精确的底层运动控制来纠正——机器人可能完美地执行了错误的任务。因此，长期执行的关键瓶颈不在于分层动作接口的可用性，而在于生成下一子任务的**推理过程**。
- **核心主张**：将"生成下一个子任务"构建为一个**可扩展计算的推理问题**，使计算量能随决策难度灵活调节——类比语言模型中测试时计算（Test-Time Computation, TTC）的思路。子任务介于动作级搜索和纯语言推理之间：既稀疏到值得额外计算，又时间上足够扩展以产生有意义的、可区分的环境状态变化。
- **整体贡献**：提出完整的层次化VLA系统$τ_0$-VLA，将高层子任务生成建模为计算可扩展推理问题，同时保留跨多机器人本体的统一低层控制接口。

## 2. 论文提出的方法论

### 2.1 核心架构：两层级联系统

系统由两个顺序协作的组件构成：

- **高层策略（High-Level Policy）**：维护执行记忆，决定何时启用额外测试时计算，并生成当前子任务。由四个模型组成：
  - **提案模型 $P$（Proposal Model）**：基于上下文 $h_t = (\ell, M_{t-1}, z^*_{t-1}, o_t)$ 更新执行记忆，生成直接子任务提案 $z^{dir}_t$
  - **世界模型 $W$（World Model）**：预测候选子任务执行完成后的终端头部相机图像：$\hat{o} = W(\tilde{o}, z)$
  - **价值模型 $V$（Value Model）**：基于全局任务指令、候选子任务和预测图像打分：$v = V(\ell, z, \hat{o})$
  - **反思模型 $F$（Reflective Model）**：基于保留的分支摘要和真实上下文生成最终子任务：$z^*_t = F(\bar{h}_t, C_t)$
- **低层策略（Low-Level Policy）**：预训练视觉-语言骨干（Qwen3.5-2B）+ Mixture-of-Transformers（MoT）动作专家，通过条件流匹配学习从噪声到动作块分布的映射。

### 2.2 世界模型引导的测试时搜索（TTC）

- **自适应路由**：基于提案模型前向传播产生的token置信度统计量，决定走快速路径还是调用TTC。路由规则为 $g_t = \mathbb{1}[u^{all}_t \le \delta^{all} \lor u^{mem}_t \le \delta^{mem}]$
- **搜索流程**（propose–predict–evaluate 循环）：
  1. 对每个保留分支独立调用提案模型 $N$ 次，生成 $N$ 个候选子任务
  2. 世界模型预测每个候选的终端图像
  3. 价值模型评估该图像对应的任务进展
  4. 束搜索（beam search）按累积分数保留 Top-$B$ 分支，递归扩展到深度 $D$
  5. 反思模型基于最终保留的分支摘要生成最终子任务
- **搜索参数**：分支因子 $N$、束宽 $B$、搜索深度 $D$ 共同控制推理预算

### 2.3 可纠错执行记忆

- 高层策略携带跨步骤的执行记忆 $M_t$，汇总到目前为止的执行历史
- 训练时通过**扰动真实演示中的记忆**，让策略学会修复滞后、超前或与实际进度不符的记忆记录，且无需额外标注
- 五种记忆实例族：within-subtask（58%）、transition（15%）、catch-up（10%）、rollback（12%）、error-think（5%）

### 2.4 统一低层控制接口

- **40维统一状态与动作空间**：覆盖末端执行器（位置+Rot6D方向）、夹爪、腰部、移动底座、双臂关节，支持固定基座操作、双臂协调和移动全身控制
- **掩码流匹配**：不同本体占用不同通道，通过掩码矩阵 $M$ 对无效通道进行掩盖，仅对有效通道计算损失
- **四阶段训练**：知识隔离协同训练 → 端到端协同训练 → 任务特定微调

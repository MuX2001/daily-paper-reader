## 摘要
尽管大型视觉语言模型（VLM）显著推进了具身导航，但其直接部署仍具挑战性，因为现有方法往往迫使VLM进入与其2D预训练先验不一致的非自然动作空间，加之僵化的推理调度和低效的记忆管理。为克服这些局限，我们提出TAMP-Nav，一个用于高效具身导航的统一框架。首先，我们引入像素到3D动作公式（Point），将导航重新表述为2D视觉提示。具体而言，VLM仅需选择2D像素，随后将其投影至3D坐标，供底层SLAM控制器使用。该设计自然地将具身执行与VLM固有的2D视觉能力对齐。其次，我们提出集成的选择性推理与锚定轨迹记忆机制（Think and Memorize），动态触发思维链，并仅在关键节点保留高保真记忆，将冗余轨迹压缩为轻量时空指示器，从而保留关键历史信息并增强时空感知。最后，我们通过组相对策略优化（GRPO）设计了一种高效的两级对齐范式（Align）。通过叠加全局结果奖励与细粒度过程奖励，这种密集监督将智能体的认知规划与物理环境反馈紧密对齐，赋予模型自适应推理能力。实验表明，TAMP-Nav在R2R-CE上实现了最先进的性能（如66.2%的SR），同时具有高运行时和样本效率（仅需90k训练轨迹）。

## Abstract
Although Large Vision-Language Models (VLMs) have significantly advanced embodied navigation, their direct deployment remains challenging, as existing methods often force VLMs into unnatural action spaces that misalign with their 2D pre-training priors, compounded by rigid reasoning schedules and inefficient memory management. To overcome these limitations, we propose TAMP-Nav, a unified framework for efficient embodied navigation. First, we introduce a Pixel-to-3D Action Formulation (Point) that reformulates navigation into 2D visual prompting. Specifically, the VLM merely selects 2D pixels, which are then projected into 3D coordinates for a low-level SLAM controller. This design naturally aligns embodied execution with the VLM's inherent 2D visual capabilities. Second, we propose an integrated Selective Reasoning and Anchor-Trajectory Memory mechanism (Think and Memorize), which dynamically triggers Chain-of-Thought and retains high-fidelity memory only at critical nodes, compressing redundant trajectories into lightweight Space-Time Indicators, thereby preserving critical historical information and enhancing spatio-temporal perception. Finally, we design an efficient Two-Level Alignment Paradigm (Align) via Group Relative Policy Optimization (GRPO). By superimposing global outcome rewards with fine-grained process rewards, this dense supervision tightly aligns the agent's cognitive planning with physical environmental feedback, endowing the model with adaptive reasoning capabilities. Experiments demonstrate that TAMP-Nav achieves state-of-the-art performance (e.g., 66.2% SR on R2R-CE) with high runtime and sample efficiency (requiring only 90k training trajectories).

## 1. 论文的核心问题与整体含义（研究动机与背景）

具身导航要求智能体理解自然语言指令并在复杂环境中实时决策。尽管大型视觉语言模型（VLM）显著提升了多模态理解能力，但直接将其部署到具身导航中仍面临三大技术瓶颈：

- **动作空间的几何鸿沟（Geometric Gap）**：现有方法通常迫使VLM直接输出低层原子动作（如"向左转30°"）或回归3D空间坐标，但这些输出形式与VLM以2D图像-文本对为主的预训练先验严重不一致，导致模型需要隐式学习复杂的2D到3D几何变换，引发空间幻觉、低样本效率和较差的泛化能力。
- **导航性能与推理效率的冲突**：集成思维链（CoT）虽增强了高层规划能力，但现有方法往往在每一步或固定间隔触发推理。密集推理虽提升决策质量，却带来严重推理延迟，僵化的认知调度难以在效率与性能之间取得最优平衡。
- **长时程记忆中关键信息与时空感知的丢失**：现有记忆机制要么完整保留历史视觉特征导致注意力稀释与内存溢出，要么不加区分地丢弃过去观察导致关键信息丢失。更关键的是，现有架构普遍缺乏显式时空坐标来组织历史信息，使智能体难以维持对过去轨迹的清晰理解。

为突破这些瓶颈，论文提出统一的 **TAMP-Nav**（Think、Align、Memorize、Point）框架，从动作空间设计、认知架构和优化范式三个层面系统性地对齐VLM能力与物理执行需求，实现高效、可泛化的具身导航。

## 2. 论文提出的方法论（核心思想、关键技术细节）

TAMP-Nav由四大核心组件构成，遵循"感知→推理→决策→执行→优化"的闭环交互流程：

### 2.1 Point：像素到3D动作公式（Pixel-to-3D Action Formulation）

- **核心思想**：将VLM的角色简化为一个"2D视觉指示器"，避免其承担复杂的3D几何推理。
- **具体流程**：在每一步，智能体接收4个环绕视角的自我中心图像以覆盖360°视野。VLM首先选择最优视角图像，然后直接输出指向目标航路点的2D像素坐标 `a_t = (u, v)`。该像素通过深度图投影为局部3D点：
  ```
  P_t = D_{t,i}(u,v) · K^{-1}[u,v,1]^T
  ```
  其中 `D_{t,i}` 为深度值，`K` 为相机内参矩阵。随后该3D坐标被转换到世界坐标系，交由底层SLAM控制器执行局部移动。
- **优势**：VLM只需依赖其擅长的2D视觉语义定位能力，几何变换和运动控制被完全解耦到底层经典SLAM栈，从根本上绕开了2D预训练模型与3D动作空间之间的表示鸿沟。在仿真中直接使用真值深度，在真实部署中使用深度相机获取深度。

### 2.2 Think：选择性推理（Selective Reasoning）

- **核心思想**：放弃僵化的逐步骤CoT，仅在关键拓扑节点触发深度推理。
- **关键节点挖掘（用于数据集构建）**：通过三步策略筛选稀疏关键节点：
  - **重要性打分**：`S(t) = S_sem(t) + S_vis(t)`，其中语义分数 `S_sem` 通过CLIP相似度衡量当前观测与指令的相关性，视觉分数 `S_vis` 衡量相邻帧间视觉特征差异（场景转换幅度）。两者经轨迹级Min-Max归一化后等权相加。
  - **距离贪心过滤**：按分数排序后选前30%的帧，在满足最小空间距离 `D_min` 的条件下迭代选取，确保推理稀疏性。
  - **时间填充**：当相邻节点空间距离超过 `D_max` 时，在间隔中插入最高分中间帧，维护全局拓扑连通性。最终约30%轨迹被标记为关键节点。
- **结构化CoT生成**：基于Gemini 2.5 Flash构建多阶段提示工程，将推理链分解为任务阶段定位、当前观测分析、未来动作推理三个独立子任务分别生成，再融合为连贯叙述。该分解策略降低单次LLM查询的认知负担，减少幻觉并保证推理质量。
- **推理触发机制**：在推理阶段，模型自主决定是否生成 `<think>` token，RL对齐后模型学会状态依赖的按需推理。

### 2.3 Memorize：锚点轨迹记忆（Anchor-Trajectory Memory）

- **动机**：在"全量保留导致上下文溢出"与"稀疏采样导致信息丢失"之间取得平衡。非关键节点虽在高阶语义上冗余，但承载了不可或缺的时空转换信息。
- **时空指示器（STI）**：将绝对位置 `(x,y)`、朝向 `yaw` 和时间 `t` 编码为紧凑token：
  ```
  E_STI(t,x,y,yaw) = MLP([RoPE_2D(x,y); RoPE_1D(t); RoPE_2D(sin(yaw), cos(yaw))])
  ```
  其中 `[;]` 为拼接操作。[sin(yaw), cos(yaw)] 的三角映射避免了0°/360°边界的不连续性。该STI token被添加为输入序列中的单个token，显式注入稠密几何与时间感知。
- **显式锚点（Explicit Anchors）**：在关键节点 `t_k` 存储三元组 `<STI, 高保真视觉特征, 规划信标（CoT语义摘要）>`，用于支持像素级闭环检测和任务进度定位。
- **轨迹压缩**：对锚点之间的冗余路径区间，丢弃视觉特征，仅保留STI token序列，在严格限制内存预算的同时保持完整时空流。
- **工作记忆与长期记忆结合**：当前步输入上下文融合了工作记忆（当前步与最近锚点间均匀采样的2帧）与重建的长期拓扑记忆序列。

### 2.4 Align：两级GRPO对齐范式（Two-Level GRPO）

- **训练流程**：先在MultiNav-CoT数据集上

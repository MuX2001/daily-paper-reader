## 摘要
视觉-语言-动作（VLA）模型在现实世界中的部署常常受限于效率与性能之间的权衡、跨实体泛化能力以及执行平滑性。我们提出了NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，从而优化计算资源和模块化程度。为了弥合异构机器人之间的语义鸿沟，我们引入了GESTURE-7，一种统一的基于语言的动作表示。此外，我们的引导动作算法通过基于掩码的平滑约束来强制执行运动学连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上实现了85.5%的平均成功率，并将动作生成速度提升了约2.7倍。这种异步设计为实际机器人应用提供了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

## 1. 核心问题与研究动机

### 背景
- 机器人操作正从模块化流程转向端到端学习，Vision-Language-Action（VLA）模型通过统一感知、语言与控制，在自然语言指令跟随和复杂任务执行上展现出强大能力。
- 领域发展脉络：RT-1 奠定 Transformer 策略基础 → OpenVLA 推动开源社区 → InternVLA 系列引入空间锚定与统一理解-生成-动作范式。

### 三个核心瓶颈
1. **效率-性能刚性权衡**：单体同步架构无法兼顾低频语义推理与高频电机控制的不同时间分辨率需求。
2. **跨形态泛化不足**：将连续运动学映射到离散 Token 需要庞大词汇表与大规模示范数据，异构机器人平台间难以统一动作语义。
3. **动作平滑性缺失**：异步实时推理与动作块生成之间的时间错配，导致执行抖动与边界不连续。

### 整体含义
本文旨在通过"快慢双系统认知范式"（System 1 快速反射 / System 2 慢速深思）的系统级解耦，同时解决上述三个问题，为 VLA 模型的现实部署提供高效、平滑、可跨实体泛化的解决方案。

## 2. 方法论：NebulaVLA 核心技术

### 2.1 异步双频架构（异构双频架构）
- **System 2（语义规划，约 10 Hz）**：以 Qwen3-VL 为视觉语言骨干，处理自然语言指令与稀疏视觉输入，输出抽象动作引导（通过可学习 token 提取隐藏层特征）。
- **System 1（反应式控制，约 20 Hz）**：以 DiT（Diffusion Transformer）为生成器，接收 System 2 的引导 + 高频视觉输入（DINOv2 编码）+ 动作历史，通过去噪过程输出执行动作。
- **优势**：显式解耦频率，支持分布式部署，最小化交互延迟。

### 2.2 GESTURE-7 统一动作表示
- 将末端执行器状态编码为 **7 维向量**：`[x, y, z, r, p, w, gesture]`
  - `(x, y, z)`：笛卡尔位置（整数厘米）
  - `(r, p, w)`：姿态（roll/pitch/yaw，整数角度）
  - `gesture`：自然语言关键词（如 `grasp`、`push`、`rotate`），统一异构机械手/夹爪的语义
- **关键创新**：不同形态机器人执行相同动作共享同一关键词，量化到整厘米/整度降低学习负担，支持语言条件强化学习。

### 2.3 Guide Action 机制
- **灵感**：图像外扩（Image Outpainting / RePaint）
- **核心思想**：生成下一动作块时，以上一动作块中未执行的动作（如 a4–a7）为条件锚点，强制新块起点与历史轨迹对齐。
- **数学表达**：
  - 条件概率模型：`p_θ(A^t_full | A^t_full, A_prior, τ)`
  - 掩码强制修正：`A^(t-1)_full = M ⊙ A^(t-1)_prior + (1-M) ⊙ A^(t-1)_noisy`
    - 掩码 `M[1..k]=1`：锚点区域严格保留；`M[k+1..T]=0`：生成区域模型预测
- **训练时**：引导动作点数量随机采样 0–3，适配不同推理延迟。

### 2.4 三阶段训练管线
1. **Stage 1 — System 2 监督微调（SFT）**：三类任务组——空间锚定（GESTURE-7 姿态回归 + 2D 关键点回归）、轨迹预测（2D 路径点 + 3D 轨迹点，2 Hz）、推理规划（思维链子任务分解 + 未来 GESTURE-7 轨迹）。
2. **Stage 2 — System 2 强化学习（RL）**：基于 GRPO，保留 Stage 1 任务套件，使用 GESTURE-7 距离、关键点定位、路径点、轨迹、格式等奖励函数。
3. **Stage 3 — System 1 监督微调**：联合优化 S1 与 S2 权重（冻结视觉编码器），损失函数为带掩码的加权流匹配损失：
   - `L(θ) = E[ (1-M) ⊙ (ε - ε_θ(x_t, t))² ]`，仅约束新生成区域，不约束引导动作区域。

## 6. 主要结论与发现

1. **总体性能显著领先**：NebulaVLA 在 LIBERO-Plus 上取得 85.5% 平均成功率，超越 InternVLA-M1（81.3%）4.2%，显著击败 OpenVLA-OFT+（79.6%）、GR00T N1.5（59.0%）、π0.5（58.0%）。
2. **速度大幅提升**：异构双频架构将平均步长延迟从同频变体的 115 ms 降至 42 ms，动作生成加速约 2.7×。
3. **三阶段训练有效**：完整三阶段训练（SFT + RL + S1 SFT）比无 SFT/RL 基线提升 1.7%，比无 RL 基线提升 2.5%；其中 S2 SFT 显著增强 Layout 维度（+6.2%）。
4. **Guide Action 显著抑制抖动**：真实世界实验中，所有关节急动度下降，平均降低 25.6%，关节 12 和 13 分别降低 41.2% 和 45.1%，有效消除动作块边界的不连续性。
5. **GESTURE-7 的潜在副作用**：Camera 扰动维度性能反而下降，作者归因于 GESTURE-7 训练假设建立了固定的视觉-空间映射，相机位姿扰动会破坏这种对应关系。

## 7. 优点与亮点

1. **系统级架构创新**：异步双频架构是一个结构性创新——不是简单地加快推理，而是从认知科学（Kahneman 快慢思维）中借鉴系统分层理念，将高成本语义推理与低成本反应控制彻底解耦，设计上天然支持分布式部署，工程实用性突出。
2. **统一动作表示的原生语言化**：GESTURE-7 用自然语言关键词 + 量化向量实现跨形态统一，比纯离散 Token 或纯连续回归更自然，且天然兼容 RL 奖励设计（GESTURE-7 距离函数设计清晰）。
3. **平滑性内化到生成过程**：Guide Action 的掩码强制修正机制将动作连续性约束直接嵌入扩散去噪过程（而非事后平滑），避免了传统后处理方法（样条插值、RTC 等）带来的语义不一致，思路新颖且受图像外扩启发，迁移逻辑清晰。
4. **训练-推理频率对齐**：三阶段流程中 Stage 3 明确保证训练时与推理时的频率配置一致，这种细节约束体现了面向真实部署的系统性思考。
5. **实验分层丰富**：从模拟到真实、从成功率到延迟再到运动学质量的全面评估框架，对比了同频/异频两种架构变体，使得结论更具说服力。

## 8. 不足与局限

1. **频率分配的静态性**：当前 10 Hz / 20 Hz 的频率配置是经验确定的、静态的，不同任务域可能有不同最优频率配置。论文作者自己也承认自适应动态调度仍是开放问题。
2. **Guide Action 的延迟代价**：固定引导锚点在高动态环境变化中可能引入较小的响应延迟——在快速变化场景中锚点本身可能已过时，但机制缺乏对锚点有效性的判断。
3. **Camera 维度鲁棒性下降**：GESTURE-7 的训练假设导致对相机位姿扰动敏感，这是一个不可忽视的泛化短板，目前仅是事后归因，未提出根本解法。
4. **实验覆盖有限**：
   - 真实场景只验证了 2 个任务，未覆盖高度动态、多物体交互、长时间任务。
   - 未测试跨实体迁移的真实效果（GESTURE-7 声称的跨形态泛化在实验中未用不同机器人直接验证）。
   - 缺少与 HiRT、Figure Helix 等同样采用双频架构的方法的对比。
5. **算力信息不透明**：未报告训练总耗时、数据量、模型参数量等重要信息，限制了可复现性和资源可评估性。
6. **工程部署挑战**：异构硬件同步、多传感器时间戳对齐、分布式时钟一致性等实际工程问题未深入讨论，而这些恰恰是双频架构在实际落地中的最大障碍。
7. **学术验证偏差风险**：消融实验中的 `w/o SFT, w/o RL` 配置直接加载开源预训练权重，其表现已高达 83.8%，说明 S2 微调带来的增量有限（仅 +1.7%），可能存在基准选择对结果的影响。

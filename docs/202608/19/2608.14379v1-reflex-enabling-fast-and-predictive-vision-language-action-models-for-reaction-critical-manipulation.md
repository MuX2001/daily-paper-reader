## 摘要
视觉-语言-动作（VLA）模型近来在机器人操作领域展现了令人瞩目的性能。然而，现有基准主要评估静态操作任务上的泛化能力，并在很大程度上忽视了动态交互场景。为了解决这一空白，我们提出了 ReflexBench，一个面向反应关键操作的基准。ReflexBench 包含六个动态任务，并引入了一个评估框架，该框架将模拟器步进与机器人控制解耦，同时支持同步和异步推理下的可配置延迟。基于 ReflexBench，我们提出了 ReflexVLA，一种高效 VLA 模型，专为反应关键操作设计，无需大规模机器人数据预训练。ReflexVLA 通过在视觉骨干中引入潜在未来预测和多帧时间融合来增强时间推理，同时通过批量视觉编码和 CUDA Graph 重放来降低部署延迟。实验表明，ReflexVLA 持续提升了动态操作性能，同时在标准静态操作基准上保持了有竞争力的准确性，真实世界实验进一步证明了其在实际部署条件下的有效性。项目网站：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. Project website: https://reflexvla.github.io

## 2. 论文提出的方法论：核心思想、关键技术细节

### ReflexBench 基准设计

- 包含六个动态操作任务：
  - 传送带抓取放置（Conveyor Belt Pick-and-Place）
  - 接球（Ball Catching）
  - 打地鼠（Whack-a-Mole）
  - 滚动球拦截（Rolling Ball Interception）
  - 抛球（Ball Throwing）
  - 旋转销钉插入（Rotating Peg Insertion）
- **延迟感知评估框架**：
  - 将模拟器步进与机器人控制解耦，使环境在策略推理时不被暂停；
  - 支持**同步推理**（阻塞执行）与**异步推理**（上一周期动作与当前推理重叠）；
  - 可通过手动设置延迟值（毫秒级）或根据实际策略推理延迟（通过RTF换算成仿真时间）注入延迟；
  - 定义RTF = t_sim / t_wall，用于将实际墙钟延迟转换为仿真内等效延迟。

### ReflexVLA 模型设计

- 基础架构：紧凑型VLA（类似VLA-Adapter），视觉编码器为DINOv2+SigLIP融合ViT（224×224），语言骨干为Qwen2.5-0.5B，通过可学习动作查询输出动作片段。
- 三大核心设计：

1. **潜在未来预测（Latent Future Prediction）**
   - 使用冻结的DINOv3编码器提取未来观测的语义特征（1024维）；
   - 在输入序列中附加H个可学习未来令牌（H = 动作块大小）；
   - 预测头将未来令牌映射到DINOv3特征空间，与真实未来特征计算**掩码余弦相似度损失**；
   - 总损失：L = L_act + λ_future · L_future，λ_future=0.05；
   - 目的：让模型在训练时学习场景时序演化，但不增加额外推理图像编码开销。

2. **多帧时间融合（Multi-Frame Temporal Fusion）**
   - 输入V个视角、T个历史观测；
   - 使用视觉骨干中间层特征（而非最终层）进行时序轨迹建模；
   - 对每个视角和空间位置的T帧特征做归一化、降维、加时间位置编码，然后进行**因果时序注意力**；
   - 融合后的残差加到当前帧的最终层特征上，得到当前帧的融合表示；
   - 关键优势：语言模型侧视觉令牌数量与单帧一致，避免因多帧拼接导致的二次复杂度爆炸。

3. **推理延迟优化（Inference Latency Optimization）**
   - **批量视觉编码**：将所有视角和帧图像合并为一次视觉骨干前向；  
   - **CUDA Graph 重放**：将完整推理管线的计算图捕获为CUDA Graph，运行时直接重放，减少内核调度开销；
   - 不改变模型结构和学习目标，仅优化系统级执行。

- **频率与异步的影响**：低频异步推理受感知-动作错位影响较大，高频时异步推理优于同步推理；较大块大小+较短动作执行间隔+高频异步推理通常最佳。
- **ReflexVLA性能**：
  - 在ReflexBench上平均成功率 **50.4%**，超过所有基线，包括更大的OpenVLA-OFT（36.0%）、π0.5（36.9%）和动态专用模型PUMA（50.2%，但模型规模4B，ReflexVLA仅1B）；

- **消融结论**：
  - 冻结DINOv3目标远比可训练目标稳定；
  - 中间层特征做时间融合优于最终层；
  - 延迟优化同时提升成功率并大幅降延迟（125.1ms→65.0ms）；

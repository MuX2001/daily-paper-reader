## 摘要
端到端的视觉-语言-动作模型和世界-动作模型为通用机器人提供了一条优雅的路径，但其可靠性受限于经过验证的物理覆盖范围。当不熟悉的物体、传感器、具身形态或接触超出该覆盖范围且没有经过验证的备用方案时，纠正失败需要新的机器人数据、策略更新和回归测试。这种反复出现的负担被称为“再训练税”。与文本不同，具身数据往往必须通过操作机器来创建。我们提出了教学与成长学习（TGL），一种面向通用机器人学习的智能体中心架构。在其一般形式中，多模态智能体将少量成功示范转化为可复用的技能块：针对有意义的子目标执行闭环行为。在新场景中，智能体对这些块进行 grounding 和组合，选择学到的或几何工具，观察物理结果，并在执行偏离意图时修正路径。技能库存储可执行行为，而结构化经验记忆则承载成功、失败和修复信息。获取新任务无需针对特定任务进行策略再训练。我们的 LIBERO 评估达到了最先进水平；对照研究揭示了技能归纳、持久复用和智能体引导的自适应。最后，我们提出“教学与成长缩放律假设”：如果 X 表示有效的可复用经验，则未来任务错误和教学需求应作为 X 的幂律逼近不可再降的底线。因此，该架构将部署视为持续学习的阶段，在此阶段中，一个任务可以让下一个任务变得更容易。

## Abstract
End-to-end vision-language-action (VLA) and world-action models offer an elegant route to general-purpose robotics, but their reliability is bounded by validated physical coverage. When an unfamiliar object, sensor, embodiment, or contact falls outside that coverage and no validated fallback exists, correcting the failure requires new robot data, a policy update, and regression testing. This recurring burden is the retraining tax. Unlike text, embodied data must often be created by operating machines. We present Teach-and-Grow Learning (TGL), an agent-centered architecture for general robot learning. In its general form, a multimodal agent turns a few successful demonstrations into reusable Skill Blocks: closed-loop behaviors for meaningful subgoals. In a new scene, the agent grounds and composes these blocks, selects learned or geometric tools, observes the physical outcome, and revises the route when execution departs from intent. A Skill Library stores executable behavior, while structured Experience Memory carries forward success, failure, and repair. New tasks are acquired without task-specific policy retraining. Our LIBERO evaluation attains state-of-the-art performance; controlled studies expose skill induction, persistent reuse, and agent-directed adaptation. Finally, we propose the Teach-and-Grow scaling-law hypothesis: if X denotes effective reusable experience, future-task error and teaching demand should approach irreducible floors as power laws in X. The architecture therefore treats deployment as a period of continued learning, in which one task can make the next easier.

> 如何构建一种架构，使机器人能够在部署过程中持续积累本地能力，而无需每次遇到新任务都进行全局策略重训？

## 2. 方法论

### 2.1 核心思想

- **学习对象不是模型参数，而是显式的可执行知识**：固定预训练参数（θ不变），通过更新**技能库（Skill Library）** 和**经验记忆（Experience Memory）** 来实现学习。

### 2.2 关键公式与形式化定义

**固定权重学习框架：**

```
θ_{n+1} = θ_n = θ（预训练参数固定不变）
(B_{n+1}, M_{n+1}) = U(B_n, M_n, D_n, ΔH_n)  （技能库与经验记忆更新）
H_{n+1} = H_n ∪ ΔH_n                          （交互历史积累）
```

其中 D_n 是少量教学示范（m_n ≪ |D_pretrain|）。

**技能块（Skill Block）的形式化表示：**

```
b_i := ⟨g_i, S_i, ρ_i, γ_i, Π_i, v_i, R_i⟩
```

- g_i：子目标（应该改变什么）
- S_i：适用条件（何时可以使用）
- ρ_i：可复用策略（如何实现）
- γ_i：grounding函数（从观测映射到具体变量）
- Π_i：兼容的执行器集合
- v_i：结果验证器（pass / fail / inconclusive）
- R_i：有界的恢复策略

**任务工作计划：**

```
τ_t = ⟨b_{i_t,1}, b_{i_t,2}, ..., b_{i_t,L_t}⟩
```

是动态可变的计划而非固定脚本，每步执行后智能体可保持、缩短或替换剩余路线。

**经验记忆记录结构：**

```
μ_j = ⟨task, context, blocks, outcome, diagnosis, repair, evidence⟩
```

**Teach-and-Grow缩放律假设：**

```
E_future(X) = E_∞ + AX^{-α}
D_teach(X) = D_∞ + BX^{-β}
```

- X 为**有效可复用经验**（effective reusable experience），衡量过去经验中仍可检索、可grounding、可组合的部分（式7给出形式化定义）。
- E_future 为未来任务的期望误差，D_teach 为获取一个未来任务所需的教学量。
- 随着有效经验 X 增长，未来任务误差和教学需求应依幂律趋近各自的不可再降下限。

### 2.3 关键技术流程

1. **少量教学与跨示范抽象**：将几个成功示范按"有意义的语义状态变化"分解为片段，跨示范对齐后综合出共享策略 ρ_k，区分语义不变量和实例变量（姿态、像素、路径等运行时重新计算）。
2. **技能块在新场景中的grounding**：块保留语义意义，但物体的位姿、抓取、路径、控制指令均从当前观测中重新计算，而非回放原轨迹。
3. **动态智能体组合与工具选择**：智能体在语义决策边界（而非高频运动指令）上决定：需要什么证据、选择哪个块、用哪个执行器、是否继续或重规划。
4. **物理反馈与受限探索**：块执行后验证实际效果，若与预期不符则重观察、换执行器、改路线或请求针对性教学。
5. **结构化成长与快速策略蒸馏**：验证过的行为进入技能库；经验记忆记录失败原因和修复方式。成熟行为可蒸馏到快速策略（VLA/WAM/diffusion policy）中执行，智能体路径继续处理新颖情况。

### 2.4 设计原则

- **不对称设计**：Agent负责语义层面的决策（哪个子目标重要、需要什么证据、上次行动是否有效）；机器人原生执行器负责度量运动、接触和控制。语言层面的计划不会被误认为运动权威。
- **本地化更新**：新的抓取检测器可替换块内一个组件，新的恢复策略可附加到失败的效果上，无需改动无关技能。

## 6. 主要结论与发现

1. **TGL在LIBERO标准评估上达到SOTA**（但未提供具体对比数据）。
2. **示范可转化为持久、可复用的技能块**：少量（3条）教师轨迹可以被归纳为抽象行为，跨越原示范场景并成功执行。
3. **物理反馈驱动任务级重规划**：智能体在语义决策边界上根据实际结果决定是否继续、重观察或重建路径，而非执行固定工作流。
4. **本地增长改变未来能力**：向技能库添加2个块即可让同一固定执行器从0%提升到4/6成功率，无需重训任何权重。
5. **失败定位具有可操作性**：失败的尝试可以被分类到具体环节（运动规划前/路径一致性/夹爪闭合），指导后续针对性改进。
6. **核心架构主张**：机器人智能不应只存在于模型权重中，还应存在于显式的、可编辑的、可组合的能力对象中。An agent-centered architecture turns the robot from a frozen policy into a continuously learning system.

## 7. 优点

1. **问题诊断精准**："再训练税"概念准确刻画了端到端VLA在部署中的核心瓶颈——局部能力缺口却触发全局更新。
2. **架构设计清晰**：明确区分Agent（语义决策）、Skill Block（可执行能力）、Experience Memory（经验教训）、Skill Library（持久技能）的不同角色，避免了将记忆、工具、技能混为一谈的常见误区。
3. **学习对象新颖**：将显式技能块而非模型参数作为学习的核心对象，使学习可审计、可编辑、可追溯。
4. **"教学相长"的理念融合**：将经典教育思想转化为技术架构原则（先教后学、学以促教），既直观又有理论深度。
5. **提出可测试的缩放律假设**：给出明确的公式形式、变量定义和纵向实验检验方案，超越了空洞的"经验越多越好"的口号。
6. **两速度设计（慢教师/快学生）**：智能体路径负责处理新颖情况并生成高质量数据，蒸馏后的快速策略处理熟悉情况，二者互补，兼顾灵活性与效率。
7. **本地化更新原则**：通过块级契约和明确的作用范围，使能力增长近似线性而非指数成本，理论分析（Appendix G）提供了成本结构对比。

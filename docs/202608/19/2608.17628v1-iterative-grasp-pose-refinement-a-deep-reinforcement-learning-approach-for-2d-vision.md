## 摘要
开发能够理解和操作物体的机器人需要紧凑、可解释且可泛化的表示。本研究提出了一种基于强化学习的机器人抓取精炼框架，将基于关键点的物体表示与深度Q网络（DQN）相结合。利用模拟环境中捕获的二维俯视图像，一种基于几何的算法生成初始抓取候选，这些候选由所提出的框架迭代精炼，将失败的抓取转化为成功的抓取。在Dex-Net数据集的300个物体上使用UR5机械臂进行的实验证明了该框架的有效性，在之前被几何方法认为不可抓取的物体上实现了100%的成功率。该框架的仿真到现实迁移性通过Delta并联机器人的物理实验进一步验证，其中精炼的抓取成功操纵了一个之前不可抓取的物体。研究结果强调了强化学习在解决机器人抓取挑战中的有效性，为接触丰富的操作任务提供了一种可扩展且适应性强的解决方案。

## Abstract
Developing robots capable of understanding and manipulating objects requires compact, interpretable, and generalizable representations. This work proposes a reinforcement learning-based framework for robotic grasp refinement, integrating keypoint-based object representations with a Deep Q-Network (DQN). Using 2D overhead images captured in a simulated environment, a geometric-based algorithm generates initial grasp candidates, which are iteratively refined by the proposed framework, transforming failed grasps into successful ones. Experiments conducted on 300 objects from the Dex-Net dataset using a UR5 manipulator demonstrate the framework's effectiveness, achieving a 100% success rate on objects previously deemed ungraspable by geometrical methods. The framework's sim-to-real transferability is further validated through physical experiments on a Delta parallel robot, where a refined grasp successfully manipulates an object that was previously ungraspable. The findings underscore the effectiveness of reinforcement learning in addressing challenges in robotic grasping, offering a scalable and adaptable solution for contact-rich manipulation tasks.

### 1. 核心问题与整体含义（研究动机与背景）

- **研究问题**：机器人抓取（特别是接触丰富的操作任务）在非结构化环境中仍缺乏人类般的灵巧性和适应性。传统的几何算法虽然能够生成抓取候选，但常常产生不可靠、失败的抓取姿态（grasp pose）。
- **关键挑战**：
  - 端到端深度学习方法虽然流行，但其“黑箱”表示缺乏可解释性，难以泛化。
  - 基于关键点（keypoint）的表示方法提供结构化替代方案，但传统方法依赖手动3D标注，且完全依赖几何技术可能遗漏可行的抓取点。
- **核心动机**：需要一个更稳健的**精炼（refinement）策略**，将传统几何方法的失败抓取候选转化为成功抓取，同时保持可解释性和泛化能力。
- **整体含义**：本文提出了一种“先几何初选、后强化学习精炼”的混合范式，不是从头学习抓取，而是**在局部进行优化**，为接触丰富的操作任务提供了一种更可控、可扩展的解决方案。

### 2. 方法论：核心思想、技术细节与算法流程

- **核心思想**：将抓取精炼建模为一个**基于深度Q网络（DQN）的局部优化问题**。给定由几何算法生成的失败抓取候选，智能体通过迭代地施加微小调整，逐步优化抓取姿态参数，将失败转化为成功，并提升稳定度。
- **状态定义**：抓取配置由4维向量表示：**(x, y, θ, w)**，分别代表抓取矩形中心的笛卡尔坐标、平面内旋转角和宽度。该表示适用于两指平行夹爪。
- **动作空间**：9个离散动作，即对状态参数施加微小增量调整（`Δx, Δy, Δθ, Δw`）：
  - 调整X像素（+1 / -1）
  - 调整Y像素（+1 / -1）
  - 调整旋转（+2° / -2°）
  - 调整宽度（+2 / -2）
  - 无操作（no-op，用于判定当前状态已最优）
- **奖励/评分机制**：
  - 基于物体在抓取前后（初始阶段→最终阶段）的姿态变化计算旋转滑移量（|Δθ|）。
  - 成功抓取：`score = 1 - |Δθ| / π`，越稳定得分越接近+1
  - 失败抓取：`score = -1 + |Δθ| / π`，完全错过得-1，有接触或部分提起则接近0
  - 评分归一化至[-1, +1]，以最小化滑移为优化目标。
- **DQN实现细节**：
  - **网络结构**：全连接神经网络，3个隐藏层（256、128、64个神经元），ReLU激活函数，Layer Normalization。
  - **优化器**：Adam，学习率0.005。
  - **折扣因子**：γ = 0.9。
  - **探索策略**：ε-greedy，初始ε = 1.0，每步衰减0.999，下限为0.01。
  - **经验回放**：批大小32。
  - **训练轮数**：每个物体训练E = 25个episode，每个episode最多T = 120步。
- **算法流程（Algorithm 1）**：
  1. 初始化Q网络与目标网络，初始化经验回放缓冲区和探索率。
  2. 以失败的初始抓取姿态作为起始状态。
  3. 每步通过ε-greedy策略选择动作，在仿真器中执行调整后的抓取姿态（重复多次求平均得分），获得奖励。
  4. 存储转移样本到经验回放，从缓冲区采样小批量更新Q网络。
  5. 若奖励高于历史最佳，则更新最佳抓取配置。
  6. 若奖励达到+1则提前终止当前episode。
  7. 每episode结束后衰减探索率并更新目标网络。

## 摘要
在分层视觉-语言-动作（VLA）系统的每个重新观测点上，必须做出两个接口决策：何时终止当前子任务，以及执行所提议的动作分块到何种程度。这两个决策相互依赖——最优停止点取决于执行器计划做什么，而最优执行长度取决于子任务边界在哪里——然而现有架构将它们孤立地评估，这种不对称性使得任何一个模块都无法单独克服。我们提出了SparkVLA，一种停止感知的分层VLA，通过将两个决策表述为单一排序来解决这种相互依赖：Stop在统一候选集中与每个动作前缀长度竞争，系统选择得分最高的选项，从而消除阈值调优且仅需离线序数偏好。锚点条件上下文编码模块缓存历史感知的子任务锚点编码、起始状态记忆和目标语义，引导视觉令牌剪枝朝向任务相关区域；停止感知的动作前缀选择头在分块边界处通过全自注意力对所有候选进行评分以提高效率。在RoboCerebra上，SparkVLA实现了47.12%的成功率，超过官方分层基线30.57%，超过最强可复现方法26.83%。在多步任务上的真实机器人实验进一步验证了这些收益在物理硬件上的有效性。

## Abstract
At every re-observation point in a hierarchical Vision-Language-Action (VLA) system, two interface decisions must be made: when to terminate the current subtask and how far to execute the proposed action chunk. These decisions are mutually dependent---the optimal stopping point depends on what the executor plans to do, while the optimal execution length depends on where the subtask boundary lies---yet existing architectures evaluate them in isolation, an asymmetry neither module can overcome alone. We present SparkVLA, a stop-aware hierarchical VLA that resolves this mutual dependency by formulating both decisions as a single ranking: Stop competes against every action-prefix length in a unified candidate set, and the system selects the highest-scoring option, eliminating threshold tuning and requiring only offline ordinal preferences. An Anchor-Conditioned Context Encoding module caches a history-aware subtask anchor encoding onset-state memory and goal semantics, guiding visual-token pruning toward task-relevant regions; a Stop-Aware Action-Prefix Selection head scores all candidates via full self bnattention at chunk boundaries for efficiency. On RoboCerebra, SparkVLA achieves 47.12% success rate, surpassing the official hierarchical baseline by 30.57% and the strongest reproducible method by 26.83% Real-robot experiments on multi-step tasks further validate these gains on physical hardware.

## 1. 核心问题与整体含义

**研究动机与背景：**
- 长时程机器人操作是 VLA 模型面临的重大挑战。现有 VLA 主要在短轨迹段上训练，难以将多个技能组合成长时程任务，因此分层 VLA（高层 VLM 规划 + 低层 VLA 执行）成为主流方案。
- 在分层 VLA 的每个重新观测点（决策边界）上，系统必须同时做出两个关键接口决策：**何时终止当前子任务（Stop）** 与 **执行多长的动作块（Action Chunk）**。
- 论文指出，这两个决策**相互依赖**——最优的停止点取决于执行器后续计划，最优的执行长度取决于子任务边界所在位置。然而现有方法存在结构性缺陷：终止检测（如二元检测器、VLM 预测长度）没有访问未来行动计划；自适应分块（如 DEHP、ACH、AQC、AAC）则无法发出子任务完成信号。这种“信息不对称”使得任一孤立模块都无法独立解决该问题。
- **核心含义**：SparkVLA 将两个决策统一为**单一排序问题**——Stop 候选与所有动作前缀长度在统一候选集中竞争，选择得分最高者作为最终决策，从而消除阈值调参，仅需离线序数偏好即可训练。

## 2. 方法论

**核心思想**：将子任务终止与执行时长选择统一建模为候选集 `C = {0, 1, …, H}`（0 = Stop，n = 执行前 n 个动作），通过一个共享评分头选出最优候选。

**关键技术细节：**

1. **统一候选集与闭合选择规则**：
   - 选取 `argmax st,i` 作为最终决策；若选 Stop 则触发下一次子任务生成，否则执行对应动作前缀后重新观测。
   - 该设计使终止决策能够利用计划内容，分块长度选择能利用子任务边界邻近性——即解决两者间相互依赖。

2. **历史感知子任务锚点（History-Aware Subtask Anchor）**：
   - 在子任务开始时，从规划器主干倒数第二层提取原始锚点 α̂k，包含全局指令、语义历史、观测与目标语义。
   - 通过自注意力与锚点历史池 `Ak = {α̂1, …, α̂k−1}` 融合，得到 αk，使锚点携带跨子任务的工作空间状态记忆（如哪些区域已被操作过），每个子任务只计算并缓存一次。

3. **锚点引导的视觉剪枝（Anchor-Guided Visual Pruning）**：
   - 使用 Grid-Sampler 可微算子，以锚点 αk 作为条件，通过交叉注意力预测 K 个归一化 2D 采样坐标，再经双线性采样从冻结 SigLIP 的密集视觉 token 中提取 K 个任务相关 token，降低序列长度。

4. **停止感知的动作前缀选择头（Stop-Aware Action-Prefix Selection）**：
   - 评分头是一个全自注意力 Transformer：Stop 候选用可学习嵌入 e0，第 n 个前缀候选用其末端动作的 MLP 映射加长度嵌入初始化，并在自注意力中与锚点、当前高层隐藏特征相互交互。
   - 每个候选通过同一 scoring layer 映射为标量分数。

5. **训练目标**：
   - 使用**成对排序损失**（Lrank），基于轨迹时间结构（成功轨迹中 τ 为完成边界，n⋆ = τ − t 提供天然序数监督）构造优先级，并加入边界扰动 τ′ = τ + Δ 增加鲁棒性。
   - 增加**停止感知辅助损失** Lstop，用 `ut = s0 − log Σ exp(sn)` 对比 Stop 与所有延续动作的分数。
   - 总损失 `L = Lrank + λstop · Lstop`，推理仍用统一 argmax 规则。

6. **推理调度**：选择器仅在分块边界调用（非每步）；短确认窗口过滤瞬时分数波动后才提交 Stop 决策。

## 6. 主要结论与发现

1. **统一排序大幅提升性能**：RoboCerebra 上 SparkVLA 以 47.12% 平均 SR 超过官方层级基线 HPE（16.55%，+30.57%）与最强可复现方法 Mem-0（20.29%，+26.83%），同时超过独立 π0.5（12.29%，+34.83%）。
2. **双向互惠验证**：将 Stop 并入统一候选集后，Stop Acc 从 80.37% 跃升至 96.65%（精度 94.3%、召回 98.1%），同时 SR 从 42.53% 升至 47.12%——终止决策受益于动作前缀上下文，前缀选择亦受益于精确的终止信号。
3. **跨执行器泛化**：SparkVLA 高层系统搭配不同低层执行器（OpenVLA-OFT、SmolVLA）均带来约 +22.5% 的增益，证明收益源自统一接口设计而非特定配套。
4. **关键消融增益**：历史感知锚点比原始锚点 +1.94%，规划器骨干放置比执行器 +9.84%，边界调用调度比每步监测 +3.55pp Stop Acc 且提速 2.10×。
5. **真实世界迁移**：平均成功率 69.3%，超 π0.5 达 +21.3%；Tea Preparation（12 子任务）改进幅度最大（+30.0%），长时程下显式子任务记忆与停止感知终止尤为有效。

## 7. 优点

1. **概念创新**：将两个互依决策统一为单一排序，从问题定义层面消除信息不对称，理论上优雅且无需阈值调参。
2. **监督信号高效**：仅利用离线轨迹的时间结构构造序数偏好，无需在线 RL 或人工标注奖励，训练成本低。
3. **架构设计完整**：锚点缓存、视觉剪枝、边界调用三重机制协同，使得框架在引入选择头的情况下仍保留 88% 吞吐率（4.14 Hz 决策频率）。
4. **验证充分且严谨**：统一的实验控制、独立 seed、多基准覆盖，消融实验逐组件归因清晰。
5. **泛化性与开放性**：跨执行器泛化验证充分，提供项目页面、代码与数据补充包，可复现性强。

## 8. 不足与局限

1. **实验覆盖有限**：
   - 任务集中于桌面操作、固定物体类别与结构化初始状态，未覆盖开放世界、移动操作、人机交互等场景；
   - 真实实验只有 3 个任务，且均为同一平台，未涉及多平台/多机械臂构型迁移。

2. **离线训练固有局限**：
   - 策略完全离线训练，无法实现在线自适应学习或利用 episode 间反馈持续改进；
   - 依赖子任务分割标注（数据分割事件），在实际部署中获取此类标注的成本未讨论。

3. **偏差风险**：
   - 失败 rollouts 中所有前缀优先级相同，可能弱化失败状态下对合理执行长度的监督；
   - 边界扰动范围（k=2）较小，对标注噪声极大场景的鲁棒性未知；
   - LIBERO 上基线接近饱和，实验区分度受限。

   - 确认窗口引入额外延迟，在需要快速反应的场景中可能不够敏捷；

5. **可复现门槛**：需 4×A100（80GB）GPU，训练选择器 20,000 步，算力门槛较高；文中未提及端到端总训练时间，调参预算也未完全透明。

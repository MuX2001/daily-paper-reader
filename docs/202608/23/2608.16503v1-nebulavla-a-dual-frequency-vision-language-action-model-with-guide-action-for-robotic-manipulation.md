## 摘要
视觉-语言-动作（VLA）模型在实际部署中常常受限于效率与性能的权衡、跨实体泛化以及执行平滑性。我们提出了NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，从而优化计算资源和模块化。为弥合异构机器人之间的语义鸿沟，我们引入了GESTURE-7，一种统一的语言锚定动作表示。此外，我们的引导动作算法通过基于掩码的平滑性约束来强制运动学连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上达到了85.5%的平均成功率，并将动作生成加速了约2.7倍。这种异步设计为实际机器人应用实现了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：机器人操作正从模块化流程转向端到端学习，VLA 模型通过统一感知、语言与控制在一个架构中，实现自然语言指令遵循与复杂任务执行。自 RT-1 以来，OpenVLA、InternVLA 等推动了该领域快速发展。
- **核心问题**：现有 VLA 模型在实际部署中面临三大瓶颈：
  - **效率与性能的刚性权衡**：单体同步架构采用统一时间分辨率，无法同时支持低频语义推理（高计算量）与高频电机控制（低延迟需求）。
  - **跨形态泛化受阻**：将连续运动学映射到离散 token 需要庞大词汇表和大规模数据，不同机器人平台之间缺乏统一动作语义。
  - **轨迹平滑性不足**：异步实时推理与动作块生成之间的时间错配导致执行抖动和动作不连续。
- **整体含义**：NebulaVLA 从系统层面（架构设计）、表示层面（动作表征）和算法层面（平滑机制）系统性地回应上述挑战，旨在实现高效、响应迅速且流畅的真实机器人控制。

## 2. 方法论

### 2.1 核心思想：快速-缓慢认知范式

借鉴诺贝尔奖得主 Kahneman 的「思考，快与慢」理论，将系统解耦为：
- **System 2（慢系统，约 10 Hz）**：负责高层语义规划——处理语言指令与稀疏视觉输入，输出抽象动作引导，由 Qwen3-VL 作为骨干，通过可学习 token 提取隐藏层特征。
- **System 1（快系统，约 20 Hz）**：负责低层反应式控制——基于 System 2 的引导和高频视觉输入、动作历史，通过 Diffusion Transformer（DiT）去噪生成执行动作。

两个系统以显式数据流规范解耦，原生支持分布式部署，最小化交互延迟。

### 2.2 关键技术一：GESTURE-7 统一动作表示

- 将末端执行器状态编码为 7 维向量：**[x, y, z, r, p, w, gesture]**
  - x/y/z：笛卡尔位置（整数厘米）
  - r/p/w：欧拉角（roll/pitch/yaw，整数度）
  - gesture：自然语言关键词（如 "grasp"、"push"、"rotate"）
- 不同本体执行相同动作共享同一关键词——例如平行夹爪与灵巧手的抓取动作统一表示为 `grasp`。
- 设计特点：**量化到整数厘米/度**降低学习负担，防止预测幻觉；gesture 词汇表可自由扩展。
- 该表示天然支持语言条件下的强化学习（RL），弥合异构机器人间的语义鸿沟。

### 2.3 关键技术二：Guide Action 引导动作机制

受图像外扩（Image Outpainting）启发，将块拼接直接嵌入生成流程，替代传统 RTC 后处理平滑方法：

- **问题**：朴素异步算法在推理结束处发生轨迹硬切换（hard switch），导致机械抖动。
- **方法**：用前一未执行动作块（如 a4–a7）作为先验引导点，约束下一块的生成（对齐 a′4–a′7），实现边界无缝过渡。训练时引导点数量从 0–3 随机采样以适应推理延迟变化。
- **公式化**：条件概率模型 pθ(A(t−1)_full | A_t_full, A_prior, τ)，其中 A_prior 为已执行动作历史 + 待执行引导动作。
- **掩码约束**（类似图像修复保留原始像素）：每次去噪后强制恢复已知动作：

  A(t−1)_full = M ⊙ A(t−1)_prior + (1 − M) ⊙ A(t−1)_noisy

  其中 M 为二进制掩码：M[1..k]=1（锚点区，严格保留），M[k+1..T]=0（生成区，由模型预测）。

### 2.4 三阶段训练流程

- **Stage 1（System 2 SFT）**：监督微调，三类任务组：
  1. 空间定位（GESTURE-7 姿态回归 + 2D 关键点回归）
  2. 轨迹预测（2 Hz 的 2D 途径点与 3D 轨迹点预测）
  3. 推理与规划（链式思考子任务分解 + 未来 GESTURE-7 轨迹生成）
- **Stage 2（System 2 RL）**：基于 GRPO（DeepSeekMath 提出）强化学习，保持与 Stage 1 相同的任务套件，引入四类奖励函数：
  - GESTURE-7 距离（位置欧氏距离 + 姿态欧氏距离 + 手势不匹配惩罚，权重各 1.0）
  - 关键点定位奖励（指数衰减的高斯核函数）
  - 途径点奖励（点级欧氏距离 + DTW 轨迹级距离）
  - 轨迹奖励 + 格式奖励（regex 匹配，权重 0.5）
- **Stage 3（System 1 SFT）**：联合优化 System 2 与 System 1 权重（视觉编码器冻结），采用加权流匹配损失。由于引导动作机制，损失仅计算新生成区域（M=0 的时段）：

  L(θ) = E[ (1 − M) ⊙ (ϵ − ϵθ(x_t, t))² ]

## 6. 主要结论与发现

- **仿真性能**：NebulaVLA 在 LIBERO-Plus 上总体成功率 85.5%，领先 InternVLA-M1（81.3%）4.2%，大幅超越 OpenVLA-OFT+（79.6%）、GR00T N1.5（59.0%）和 π0.5（58.0%）。在 Language、Layout、Spatial、Object、Goal 等维度均有明显提升，但 Camera 维度略低于 InternVLA-M1。
- **真实世界性能**：NebulaVLA-Heter 在两个真机任务上均取得最高成功率（92.08% 和 92.5%），平均推理延迟仅 42ms，相比同频变体的 115ms 降低约 63%、相比 InternVLA-M1 的 81ms 降低约 48%，验证了异频架构的效率优势。
- **三阶段训练有效性**：完整训练相比无 SFT/RL 提升 1.7%，相比无 RL 提升 2.5%。S2 SFT 显著提升 Layout 维度（+6.2%）；S2 RL 进一步强化语义耦合的 Language 与 Layout 维度；但 Camera 扰动维度出现性能回退，归因于 GESTURE-7 建立的固定视觉-空间映射被相机扰动破坏。
- **Guide Action 有效性**：显著消除动作块边界的轨迹跳变，全部 7 个关节的平均急动度降低，其中关节 12 和 13 分别降低 41.2% 和 45.1%，平均降低 25.6%，验证了生成式平滑的有效性。

## 7. 优点

- **架构设计的系统性**：同时从架构（双频解耦）、表示（GESTURE-7）和算法（Guide Action）三个层面回应 VLA 部署的三大瓶颈，非碎片化修补，而是体系化的设计。
- **创新的快慢系统实现**：将 Kahneman 认知理论与机器人控制深度结合，S2 做语义规划、S1 做反应控制，频率异构分配使计算资源利用率最大化，且原生支持分布式/边缘部署。
- **GESTURE-7 的简洁性与统一性**：7 维量化向量 + 自然语言手势关键词，兼顾跨本体统一与模型可学习性，且天然兼容 RL 奖励设计，为跨形态迁移和语言条件 RL 提供了轻量而有效的接口。
- **生成式平滑的先进思路**：将平滑约束从「事后后处理」前移为「生成过程的内在条件」，消除对 RTC 等外部平滑模块的依赖；引导点数量自适应推理延迟（随机采样 0–3）表现出工程上的务实考量。
- **训练策略精细化**：三阶段渐进优化（SFT → RL → S1 蒸馏），并采用加权流匹配损失且仅监督新生成区域，体现了严谨的训练/推理频率对齐意识。
- **实验验证较完整**：仿真+真机+消融三层证据，且用 Joint Jerk 客观量化平滑度提升；真实世界实验中同时对比了同频与异频变体，清晰隔离了架构因素。

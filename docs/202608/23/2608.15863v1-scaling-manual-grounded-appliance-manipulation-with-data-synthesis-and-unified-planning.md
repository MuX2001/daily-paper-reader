## 摘要
操作家用电器需要依赖于状态且对干扰具有鲁棒性的长时程规划，然而现有大型模型在此方面表现不足，因为缺乏足够多样化、面向任务的数据集来支持此类规划。为弥合这一差距，我们提出MAGE，一种可扩展的数据合成流水线，引入新颖的层次化家电图（HAG），可从家电手册自动生成部件接地、长时程规划和闭环恢复数据。借助MAGE，我们构建了UseAppliance，首个面向手册引导的家电操作规划的大规模数据集，涵盖22个家电类别，包含89K+部件标注、53K+操作任务和33K+闭环调整步骤。基于UseAppliance，我们开发了AppliancePlan，一种用于手册引导家电操作规划的端到端模型。在RealAppliance-Bench上，仅7B参数的AppliancePlan在开环规划上实现了最佳基线10倍以上的性能，并在所有任务上持续优于最先进模型。对六种家用电器的真实机器人实验进一步验证了有效的仿真到现实迁移，标志着向通用家庭机器人迈出了重要一步。

## Abstract
Operating household appliances requires long-horizon planning that is state-dependent and robust to disturbances, yet existing large models fall short, as no sufficiently diverse, task-oriented dataset exists to support such planning. To bridge this gap, we propose MAGE, a scalable data synthesis pipeline that introduces a novel Hierarchical Appliance Graph (HAG) to automatically generate part grounding, long-horizon planning, and closed-loop recovery data from appliance manuals. With MAGE, we build UseAppliance, the first large-scale dataset for manual-grounded appliance manipulation planning, spanning 22 appliance categories with 89K+ part annotations, 53K+ manipulation tasks, and 33K+ closed-loop adjustment steps. Built on UseAppliance, we develop AppliancePlan, an end-to-end model for manual-grounded appliance manipulation planning. On RealAppliance-Bench, AppliancePlan with only 7B parameters achieves over 10x the best baseline on open-loop planning and consistently outperforms state-of-the-art models across all tasks. Real-robot experiments on six household appliances further confirm effective sim-to-real transfer, marking an important step toward general-purpose household robotics.

## 一、核心问题与整体含义（研究动机和背景）

操作家用电器（如微波炉、空气炸锅、咖啡机等）是家庭机器人实现真正自主化的关键前提。然而，家电操作远比通用的抓取-放置任务困难：

- 家电种类繁多，界面布局、操作逻辑、状态转换方式差异巨大；
- 一次成功操作往往涉及**长时间、多步骤、状态依赖**的过程，且必须对执行过程中的干扰（如按钮误触、旋钮旋转偏差、门未关紧等）保持鲁棒；
- 人类解决这一问题的方式是查阅说明书（manual），这一行为天然将任务分解为三种子能力：**部件定位（part grounding）、开环操作规划（open-loop planning）、闭环规划调整（closed-loop adjustment）**。

尽管 RealAppliance-Bench 等基准提供了统一的评测协议（配对了100份真实手册与高保真数字孪生资产），现有的多模态大模型和具身规划模型在其上表现仍然很差。其**根本瓶颈在于缺乏大规模、高质量、面向手册引导家电操作规划的训练数据**。此前的方法要么只处理单按钮按压等简单交互，要么依赖多阶段零样本流水线（级联外部模块），存在推理延迟高、错误累积等问题。

## 二、论文提出的方法论

本文提出了一套完整的数据合成与模型训练方案，核心创新包括：

### 1. MAGE 数据合成流水线

MAGE（Manual-grounded Appliance data GEneration pipeline）是一个可扩展的数据合成管道，以**层次化家电图（Hierarchical Appliance Graph, HAG）**为核心表示，自动从家电说明书中生成三种类型的训练数据。

**HAG 的四层结构**：

- **文档层**：整本手册的根节点；
- **页面层**：按语义类型（产品概览、操作说明、故障排除等）分类的页面节点，由自动化收集智能体在 ReAct 循环中从厂商网站和手册数据库爬取并筛选；
- **部件层**：各零部件节点（如门、旋钮、按钮、控制杆），带有多视角观测图像中的边界框标注，由人工标注员完成；
- **状态层**：状态节点表示部件的离散/连续配置（如旋钮角度、门的开闭），有向边表示原子动作导致的状态转移。

**四个关键阶段**：

1. **手册收集**：VLM驱动的手册收集智能体搜索、下载、筛选、分类手册；
2. **部件和状态标注**：合成多视角观测图像（正面、斜前方、俯视），人类标注部件边界框；VLM 提出候选状态和转移关系，人工验证；二值部件（如门）构造两节点图，离散部件（如模式选择器）按档位枚举，连续部件（如旋钮）按手册粒度离散化；
3. **任务和计划生成**：将任务生成视为**图遍历问题**——采样初始-目标状态对，配合手工设计的任务/计划模板，实例化完整的开环操作计划，再由 LLM 改写为多样化的自然语言指令。公式表示为：$a_t = T^{plan}_t(\Delta(s_0, s^*), A)$，其中 $\Delta(s_0, s^*)$ 编码状态差（旋转角度差、离散步数等），$A$ 为任务属性；
4. **观测生成和干扰注入**：以 Seedream 4.0 作为生成式世界模型，逐步生成与计划对齐的观测图像序列 $I_{t+1} = M_{gen}(I_t, \text{prompt}(a_t))$；然后注入三类干扰——二值状态错误、按钮误触、旋钮旋转偏差——生成闭环校正训练三元组。

### 2. UseAppliance 数据集

首个面向手册引导家电操作规划的大规模数据集，具有四个关键特性：高质量（核心标注人工审核）、多任务覆盖（89K+边界框、53K+任务-计划对、33K+闭环恢复步骤）、丰富多样性（22个家电类别、全球厂商、多种控制界面）和可扩展性（管道仅需说明书输入）。

### 3. AppliancePlan 模型

基于 Qwen2.5-VL-7B-Instruct 的端到端模型，训练包含：

- **三个主目标**：部件接地（预测边界框）、开环规划（自回归生成完整动作序列）、闭环校正（预测下一个校正动作）；
- **三个辅助目标**：手册-部件双向对齐（部件命名、定位）、关键步骤动作预测（旋转角度、按压次数等参数精确步骤）、部件状态判断（VQA形式的状态识别）；
- 所有目标均采用下一令牌预测的交叉熵损失联合优化：$\mathcal{L} = \mathcal{L}_{main} + \mathcal{L}_{aux}$。

## 六、主要结论与发现

1. **数据规模是关键瓶颈**：通用大模型的语言和视觉能力不会自动迁移到结构化多步规划；在 (初始状态, 目标状态, 计划) 三元组上训练，配合完整参数化的原子动作，能有效弥合这一差距。
2. **AppliancePlan 全面领先**：仅7B参数，在 RealAppliance-Bench 全部轨道上超越所有基线——开环规划任务完成率 47.86% vs. 最佳基线 4.36%（**超过10倍**），最现实主义的顺序规划设置中 44.59% vs. 5.84%。
3. **部件接地**：AppliancePlan 达到 22.96% IoU / 22.24% mAP@0.5，超过最强具身基线 ApBot 12.36 IoU 点。
4. **闭环调整**：逐步成功率 37.12%，超过最佳开源基线 RoboBrain 2.0-7B 5.35 点，超过最佳专有 MLLM Gemini 2.5 Pro 5.39 点。
5. **辅助目标有效**：三个辅助目标分别对空间定位、参数精确预测、状态感知修正产生定向增益，组合最优。
6. **Sim-to-real 迁移成功**：真实机器人上 AppliancePlan 平均任务成功率 40.00%，远超 GPT-5 的 3.33% 和 ApBot 的 3.33%，验证了从合成数据训练的模型可以物理迁移。

## 七、优点与亮点

1. **数据合成思路新颖且可扩展**：将说明书知识形式化为 HAG 四层图结构，将数据生成转化为图遍历的组合优化问题，系统性地覆盖状态空间，避免了人工演示偏向常见配置的偏差。MAGE 管道完全通用，新家电类别只需输入说明书即可（论文声称验证了此扩展性）。
2. **端到端统一模型**：相比此前的多阶段零样本流水线（如 CheckManual、ApBot），AppliancePlan 用一个 7B 的端到端模型同时处理部件接地、开环规划和闭环校正，理论上消除了级联错误累积和推理延迟问题。
3. **辅助目标设计巧妙**：三个辅助目标定向强化了规划中容易出错的关键环节（空间对应、参数精度、状态感知），消融实验证明每个目标均有实际贡献。
4. **数据集质量与多样性并重**：人工标注 + 双重验证保证质量；22个类别的长尾分布增强了模型对罕见结构的鲁棒性。
5. **评测完整性高**：既覆盖标准基准的全部轨道，又引入更现实主义的顺序规划与调整设置，并补充了真实机器人实验，形成了"仿真基准 + 真实世界"的完整验证链。

## 八、不足与局限

1. **真实机器人验证规模有限**：只测试了6种家电、每种10个任务，总计60个 episode；相比仿真评测的100个资产生成，物理世界验证的覆盖面和统计功效有限。
2. **尚未实现"手册即输入"的端到端闭环**：虽然 MAGE 阶段使用手册构建 HAG，但 AppliancePlan 在评测中接收的是"相关手册页面"（由 RealAppliance-Bench 提供），模型本身不具备从整本手册自动检索定位相关页面的能力，手册页面选择仍然依赖外部机制。
3. **对生成世界模型的依赖**：闭环数据依赖 Seedream 4.0 的视觉生成质量，若生成图像与实际物理变化存在偏差（视觉漂移），则训练数据的真实性和闭环策略的有效性可能受损；虽然有人工验证，但可扩展性受此瓶颈限制。
4. **参数化动作空间的覆盖仍有盲区**：连续参数（如旋转角度）需要依赖 HAG 中的离散化粒度，过粗的离散化会限制动作精度；ApBot 的连续增量调整能力在此方案中未完全继承。
5. **部分类别表现薄弱的解释不足**：某些家电类别（如表中第4列的 0.00）上所有方法均失败，论文未分析这些类别的困难来源（可能是说明书质量、视觉歧义性或动作空间复杂性）。
6. **人工验证成本**：虽然流水线自动化程度高，但核心标注（部件边界框、状态转移图）和任务/计划模板仍依赖人工设计，扩展到更多家电类别时，人工成本仍是潜在的扩展瓶颈。
7. **训练数据与真实物理仿真之间的外观分布差异**：多视角观测图像由合成方式生成（裁剪封面照片 + 合成视角），与 Isaac Sim 高保真渲染及真实相机图像之间存在域间隙，尽管实验表明迁移可行，但域自适应技术可能进一步提升性能。
8. **隐私与商业手册版权问题**：大规模爬取制造商手册可能涉及版权问题，论文未讨论数据获取的合规性。

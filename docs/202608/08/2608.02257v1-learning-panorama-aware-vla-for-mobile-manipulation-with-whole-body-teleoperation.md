## 摘要
移动操作是具身智能的关键能力，使机器人能够在开放世界环境中完成复杂的多阶段任务。然而，移动操作给视觉-语言-动作（VLA）策略带来了两个关键挑战：在数据层面，高效收集高质量的全身演示需要对移动基座和机械臂进行协调控制；在模型层面，现有的VLA模型主要依赖局部相机观测，其有限的视野阻碍了全局空间理解。为了解决这些挑战，我们开发了一个全身遥操作系统和一个全景感知VLA策略。该系统通过单一VR接口实现对轮式双臂机器人的协调控制，并支持获取包含5.5小时多模态演示的真实世界移动操作数据集。在此数据集的基础上，我们提出了PanoVLA，一种用于移动双臂操作的全景感知视觉-语言-动作策略。基于Transformer混合架构，PanoVLA通过专门的全景编码和融合模块引入全局空间上下文，实现全景观测与语言指令和机器人状态的有效集成以生成动作。在四个真实世界移动操作任务上的评估表明，PanoVLA实现了平均阶段完成率91.3%和端到端成功率73.4%，显著优于局部视角基线。这些结果表明，融合全景空间上下文提高了移动机器人的空间理解和闭环操作性能。

## Abstract
Mobile manipulation is a key capability for embodied intelligence, enabling robots to accomplish complex multi-stage tasks in open-world environments. However, mobile manipulation poses two key challenges for vision-language-action (VLA) policies: At the data level, the efficient collection of high-quality whole-body demonstrations demands the coordinated control of both the mobile base and the robotic arms; at the model level, existing VLA models predominantly rely on local camera observations, whose limited field of view hinders global spatial understanding. To address these challenges, we develop a whole-body teleoperation system and a panoramic-aware VLA policy. The system enables coordinated control of a wheeled bimanual robot through a single VR interface and supports the acquisition of a real-world mobile manipulation dataset comprising 5.5 hours of multimodal demonstrations. Building upon this dataset, we propose PanoVLA, a panorama-aware vision-language-action policy for mobile bimanual manipulation. Built upon a Mixture-of-Transformers architecture, PanoVLA introduces global spatial context through dedicated panorama encoding and fusion modules, enabling effective integration of panoramic observations with language instructions and robot states for action generation. Evaluation on four real-world mobile manipulation tasks demonstrates that PanoVLA achieves an average stage completion rate of 91.3\% and an end-to-end success rate of 73.4\%, substantially outperforming local-view baselines. These results demonstrate that incorporating panoramic spatial context improves spatial understanding and closed-loop manipulation performance in mobile robots.

## 2. 论文提出的方法论

### 2.1 整体思路
- 通过VR设备捕获操作者稀疏人体运动，经SMPL重建和GMR（General Motion Retargeting）重定向，生成移动基座与双臂协调的机器人动作指令。
- 在模型端，将360°全景相机观测作为额外的机器人中心全局感知信号，通过专门的全景编码器与全景专家模块融合进VLA策略，供动作专家输出连续动作。

### 2.2 全身遥操作系统
- **操作者接口**：VR头显（6DoF头部位姿）+ 双手控制器（手部位姿与夹爪指令）+ 三个身体追踪器（腰部与双脚踝）。
- **机器人平台**：RANGER MINI 3移动底盘 + 两个6DoF Agilex PIPER机械臂 + 平行夹爪；视觉模组包括顶部360°全景相机、1个前视相机、2个腕部相机。
- **运动重定向**：
  - 机器人配置定义为 q = (x_b, y_b, θ_b, q_L, q_R)，其中底盘为3自由度平面虚拟浮动基座。
  - 优化目标：
    \[
    q^* = \arg\min_q \lambda_{pos}L_{pos} + \lambda_{rot}L_{rot} + \lambda_{base}L_{base} + \lambda_{reg}L_{reg}
    \]
    - L_pos：手部与夹爪位置对齐；L_rot：手部与末端朝向对齐；L_base：底盘运动与骨盆位移及朝向耦合；L_reg：关节限制与过度变化惩罚。
  - 底盘虚拟3自由度命令通过“成本驱动模式切换策略”映射到真实底盘的运动模式（如旋转、阿克曼、斜向平移），实时重算以跟随操作者意图。

### 2.3 PanoVLA模型
- **基础架构**：基于 Mixture-of-Transformers（MoT）的VLA策略，继承π0.5双专家骨架，在VLM专家与动作专家之间插入全景专家。
- **输入**：动作预测条件为联合上下文 Ct = [C_vlm; C_pano]，其中C_vlm来自VLM专家对局部视图/语言/本体感知的KV缓存，C_pano来自全景专家输出。
- **全景编码器**：
  - 将双鱼眼图像球面重投影为ERP图像；
  - 用MTPano全景基础模型提取中间语义特征（分割分支）与深度特征（深度分支），拼接为统一稠密全景表示；
  - 经自适应平均池化 + MLP适配为固定数量视觉token：
    \[
    Z^{\text{pano}}_t = A_\psi(E_p(\Pi_{\text{sph}}(I^{\text{pano}}_t)))
    \]
- **全景专家**：
  - 在全景token与VLM cache之间执行分块因果掩码的联合自注意力，产生全景cache：
    \[
    C^{\text{pano}}_t = \phi_{\text{pano}}(Z^{\text{pano}}_t | C^{\text{vlm}}_t, M_{\text{pano}})
    \]
  - 这个cache与VLM cache共同作为动作专家的条件。
- **训练目标**：
  - 动作专家使用条件流匹配（Conditional Flow Matching）预测连续动作chunk，损失为：
    \[
    L = \mathbb{E}[\|v^\text{act}_\theta(x_\tau, \tau | C_t) - u(x_\tau | a)\|^2_2]
    \]

## 3. 实验设计

### 3.1 数据采集与任务
- 使用上述遥操作系统采集真实机器人数据集，包含**800条演示轨迹、约5.5小时、约50万帧**。
- 每条轨迹20-30秒、25Hz采样，同步记录局部视图、全景观察、本体感知、全身动作。
- 任务设置（表I）：
  - **Move Pen**：将笔放入笔筒；目标方向：前/左/右。
  - **Move Block**：将积木转移到前方区域；目标方向：左/右/双侧。
  - **Open Curtain**：打开两侧窗帘；顺序交互双侧。
  - **Wipe Table**：沿长桌擦拭污渍并归还抹布；多阶段长距离操作。
- 任务设计覆盖了不同目标布局、左右手交互和多阶段长程空间一致性需求。

### 3.2 评价协议
- 每个方法、每个任务进行**15次真实机器人闭环试验**，无人工重置失败阶段。
- 指标：
  - **SR**（Success Rate）：整次试验成败的二元指标。
  - **SCR**（Stage Completion Rate）：各任务中间阶段完成的平均比例。

### 3.3 对比方法
- **π0.5**：仅局部相机视图 + SigLIP编码 + 语言/本体感知输入的原始基线。
- **π0.5 w/ Pano**：直接将ERP全景图作为额外图像输入，仍用SigLIP编码，无专门全景分支。
- **π0.5 w/ Stacked Pano**：将全景重投影为3个视角（按120°均匀分布），拼接为复合图输入π0.5。
- **PanoVLA**：完整模型（MTPano编码器 + 全景专家）。

### 3.4 主要结果（表II）
| 方法 | 平均SCR | 平均SR |
|---|---|---|
| π0.5 | 58.6% | 30.0% |
| π0.5 w/ Pano | 80.8% | 56.7% |
| π0.5 w/ Stacked Pano | 70.4% | 38.3% |
| **PanoVLA** | **91.3%** | **73.4%** |

- 各任务上PanoVLA均取得最高SR。
- Wipe Table任务阶段分析（图4）显示，原始全景基线在最后一个阶段掉点严重（SR仅20%），而PanoVLA保持较高的阶段完成率（73.3%）和SR（46.7%），说明全景专家能更稳定地跟踪多阶段任务状态与全局空间一致性。

### 3.5 消融实验（表III，在Move Pen任务上，各15次试验）
- **全景专家参数量**：
  - 50M：SCR 84.4%，SR 60.0%
  - 100M：SCR 95.6%，SR 86.7% ✔
  - 200M：SCR 93.3%，SR 86.7%
  - 300M：SCR 91.1%，SR 73.3%
  - 结论：100M足够且最优，过大在小数据微调下不稳定。
- **全景编码器选择**：
  - SigLIP：SCR 75.6%，SR 40.0%
  - MTPano：SCR 95.6%，SR 86.7%
  - 结论：SigLIP对ERP全景的空间结构建模不足，MTPano更能捕捉全景水平连续性与全局布局。

## 6. 论文的主要结论与发现

- 全身遥操作系统通过GMR联合优化移动基座与手臂，可通过单套VR设备获取流畅的移动双臂演示数据。
- PanoVLA在全景观测的语义与深度特征融合、全景专家任务条件编码方面显著优于局部视图基线和简单全景输入方法。
- 全景背景并非“更广视角就够了”，**如何表示全景几何并融入策略架构**才是关键：直接投喂ERP图像给SigLIP效果有限，而MTPano + 全景专家的组合效果最好。
- 全景空间上下文能够在长程多阶段任务中保持全局状态跟踪，显著提升闭环策略的鲁棒性。
- 最终结论：全景感知VLA是改善移动操作空间理解与执行性能的有效、可扩展方案。

## 7. 优点

- **问题定义清晰**：准确识别移动操作VLA的两个关键痛点（数据收集 + 全局感知），并分别从硬件系统和模型架构给出对应解决方案。

- **模型设计有针对性**：
  - 采用MTPano而非通用SigLIP处理全景，解决透视图像预训练与全景畸变的域差异。
  - 引入全景专家作为独立模块，通过KV cache融合接口自然接入MoT架构，便于与现成VLA主干兼容。

- **消融设计有区分度**：通过“原始全景输入”和“堆叠透视投影”来对照，能在一定程度上分离“信息增益”与“表示方式增益”。
- **真实机器人闭环评估**：在多个空间布局和任务类型上验证，避免了仿真与真实之间的领域差距。

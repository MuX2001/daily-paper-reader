## 摘要
本文提出了一种模块化推理框架，将流匹配生成模型与形式化的控制障碍函数（CBF）安全保证相结合。与现有方法对模型最终输出应用外部安全过滤器不同，我们的方法修改了模型内部的流匹配去噪过程，从而固有地生成安全轨迹。通过采用平滑的对数-求和-指数聚合障碍函数，我们在整个动作块上施加安全性。这种聚合障碍函数确保计算开销增加最小，并且不改变模型的语义意图。我们表明，在所提出的框架内，生成分布与目标分布之间的2-瓦瑟斯坦距离保持有界。我们的方法无需特定于安全的数据集或昂贵的模型重新训练，为安全推理提供了一种通用解决方案。我们在两个机器人操作平台和一个二维导航基准上验证了该方法，确认我们的框架能够在不降低模型成功率的情况下实现可靠的安全性。

## Abstract
This article presents a modular inference framework that integrates Flow Matching generative models with formal Control Barrier Function (CBF) safety guarantees. Unlike existing methods that apply external safety filters to a model's final output, our approach modifies the Flow Matching denoising process within the model to inherently generate safe trajectories. By employing a smooth Log-Sum-Exponential aggregate barrier, we enforce safety over entire action chunks. This aggregate barrier ensures a minimal increase in computational overhead and does not alter the semantic intent of the model. We show that, within the proposed framework, the 2-Wasserstein distance between the generated distribution and the target distribution remains bounded. Our method eliminates the need for safety-specific datasets or costly model retraining, providing a versatile solution for safe inference. We validate the approach on two robotic manipulation platforms and a 2D navigation benchmark, verifying that our framework achieves reliable safety without degrading the success rate of the model.

## 2. 论文提出的方法论

### 2.1 核心思想
- 将 CBF 引入流匹配的 ODE 迭代过程，在去噪阶段（尤其是后期阶段）对每个中间动作块施加最小幅度的安全修正项 δs，使最终生成的动作块整体满足安全约束。
- 动作块 z = [q1; q2; ...; qH] 的全局安全通过一个平滑的 **Log-Sum-Exponential (LSE) 聚合障碍函数** 定义，克服了取最小值算子不可微的问题。

### 2.2 关键技术细节

1. **LSE 聚合障碍函数**
   \[
   h(\bar{z}) = -\frac{1}{\kappa}\ln\left(\sum_{i=t}^{t+H} e^{-\kappa h(q_i)}\right)
   \]
   - κ 为平滑参数，κ 越大越接近 min 算子，但安全裕度越小。
   - 该函数对动作块整体下近似安全裕度，误差界为 \(\ln H / \kappa\)（定理 2）。

2. **修改后的流匹配 ODE**
   \[
   \frac{d}{d\tau}\psi_s(z,\tau) = v(\tau,\psi(z,\tau)) + \delta_s
   \]
   - δs 由 CBF-QP 求得，目标是在最小化修正幅度的同时满足障碍函数下降不等式。

3. **CBF-QP 及其闭式解**
   \[
   \bar{\delta}_s = \arg\min_{\delta}\frac{1}{2}\|\delta\|^2 \quad \text{s.t.} \quad \frac{\partial h}{\partial z}(\bar{v}_\theta(\tau,z)+\delta) \geq -\alpha h(z)
   \]
   - 其闭式解为：
   \[
   \delta_s = \mathrm{ReLU}\left(-\alpha h(z) - \nabla_z h(z) v_\theta(\tau,z)\right)\frac{\nabla_z h}{\|\nabla_z h\|^2}
   \]
   - 该解形式简单，计算开销低，可直接嵌入生成循环。

4. **增强 QP（含速度限制与平滑项）**
   - 在原始 QP 中额外加入速度约束（通过稀疏矩阵 D 计算有限差分速度）和轨迹平滑目标：
   \[
   \bar{\delta}_s = \arg\min_{\delta} \left(\frac{1}{2}\|\delta\|^2 + \lambda \|D(\bar{z} + (\bar{v}_\theta+\delta)\Delta t)\|^2\right)
   \]
   \[
   \text{s.t.} \quad \frac{\partial h}{\partial z}(\bar{v}_\theta+\delta) \geq -\alpha h(z), \quad v_{\min} \leq D(\bar{z} + (v_\theta+\delta)\Delta t) \leq v_{\max}
   \]

5. **算法流程（Algorithm 1）**
   - 输入：图像帧、语言指令、超参数 κ, α, τs 以及障碍函数参数。
   - 从 Beta 分布采样初始噪声 z0。
   - 执行去噪循环 τ = 0 → 1：
     - 前向计算 VLA 的流速度 vθ。
     - 当 τ ≥ τs 时，计算 LSE 障碍函数值及其梯度，求解 QP 得到 δs；否则 δs = 0。
     - 更新 z ← z + (vθ + δs)·Δτ。
   - 输出最终安全动作块 z1.0。

### 2.3 理论保证
- **定理 2**：LSE 聚合障碍函数对 min 算子的下近似误差界。
- **定理 3/COROLLARY 1**：加入安全修正项后，流匹配生成的分布与目标分布的 2-Wasserstein 距离仍然有界，前提是障碍函数梯度在激活时有界且远离零。
- **定理 4**：当噪声样本满足 h0 > 0 且 τs ≤ h0/M（M 为最坏情况下障碍函数衰减率）时，能保证生成的最终动作块整体安全（h > 0）。

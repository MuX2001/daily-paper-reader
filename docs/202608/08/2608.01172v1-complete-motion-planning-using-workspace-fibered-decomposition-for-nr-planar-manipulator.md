## 摘要
我们提出了一种工作空间纤维分解框架，用于在杂乱环境中操作的 nR 平面冗余机械臂的运动规划。该方法不是直接在完整的 n 维构型空间中规划，而是增量地构建低维非冗余子链的障碍约束可达工作空间，并通过冗余方向纤维递归地提升它们。这产生了一系列简化的规划流形，它们保留了分支一致的可达性结构，同时避免了显式构建完整构型空间的障碍几何。我们首先证明，对于仅考虑位置的平面机械臂，由最小非冗余子链诱导的障碍约束可达工作空间提供了关于起始构型连通分量的精确可行性表征，使得在引入冗余自由度之前能够进行早期不可行性检测。然后，我们引入了一种增量纤维提升程序，该程序通过连续冗余链接传播可达工作空间结构，同时使用雅可比行列式连续性约束来强制局部逆运动学分支一致性。所得的表示允许直接在递归构建的工作空间纤维流形上进行高效的降维空间规划。在冗余 nR 平面机械臂上的实验结果表明，所提出的构造在连续提升阶段保持无碰撞连通性结构，同时相对于直接构型空间推理显著降低了碰撞检测复杂度。

## Abstract
We propose a workspace-fibered decomposition framework for motion planning in nR planar redundant manipulators operating in cluttered environments. Rather than planning directly in the full n-dimensional configuration space, the method incrementally constructs obstacle-constrained reachable workspaces of lower-dimensional non-redundant sub-chains and recursively lifts them through redundant orientation fibers. This yields a sequence of reduced planning manifolds that preserve branch-consistent reachability structure while avoiding explicit construction of the full configuration-space obstacle geometry. We first establish that, for planar position-only manipulators, the obstacle-constrained reachable workspace induced by the minimal non-redundant sub-chain provides an exact characterization of feasibility with respect to the connected component of the start configuration, enabling early infeasibility detection prior to introducing redundant degrees of freedom (DOF). We then introduce an incremental fiber-lifting procedure that propagates reachable workspace structure through successive redundant links while enforcing local inverse-kinematic branch consistency using Jacobian determinant continuity constraints. The resulting representation admits efficient reduced-space planning directly on recursively-constructed workspace-fiber manifolds. Experimental results on redundant nR planar manipulators demonstrate that the proposed construction preserves collision-free connectivity structure across successive lifting stages while substantially reducing collision checking complexity relative to direct configuration space reasoning.

## 1. 核心问题与整体含义

**研究动机与背景**

- 运动规划研究已近 50 年，但**完整运动规划**（complete motion planning）——即在路径存在时找到无碰撞路径、路径不存在时给出不可行性证明——仍是难题。
- 采样型运动规划器（SBMP）在高维空间能有效发现可行路径，但**无法在无路径时认证不可行性**，只能超时终止。
- 已有完整规划方法（如垂直单元分解、柱形代数分解）虽具完备性保证，但**计算复杂度随构型空间维度急剧恶化**，实际通常仅适用于 ≤ 4-DOF 的低维系统。
- 近年来的不可行性认证方法可扩展至 5-DOF，但规模仍有限。商空间规划、多层级稀疏路标图等方法通过分层降维来提升可扩展性，但它们的商空间仍直接基于构型空间的维度坍缩，**没有显式利用非冗余子链诱导的工作空间拓扑以及冗余机械臂的自运动结构**。
- 本文针对平面 nR 冗余机械臂，在杂乱环境中提出一种**工作空间纤维分解（Workspace-Fibered Decomposition）**框架：从最小非冗余子链开始，通过冗余方向纤维逐层“提升”，构建一系列降维规划流形，避免显式构造完整的高维构型空间障碍几何。

**整体含义**

- 该方法在保留完整规划所需的拓扑（连通性/不可行性判定）信息的同时，规避了直接对 T^n 做障碍几何分解的高昂代价，为冗余机械臂的完整运动规划提供了一种新的可扩展范式。

## 2. 方法论

**核心思想：增量式纤维提升**

- 从最小非冗余子链（2R）开始，每次增加一个冗余自由度，形成如下递推序列：

```
R2R --lift--> R2R × S1 --project--> R3R --lift--> R3R × S1 --project--> R4R → ...
```

- 每一阶段的核心对象为降维规划空间：`M(m)_red = RmR × S1`，其中 `RmR ⊂ R²` 是 m 链接子链的障碍约束可达工作空间，`S1` 是下一个冗余链接的方向纤维。
- 最终 nR 规划在 `Mred = R(n−1)R × S1` 上进行。

**关键技术细节**

1. **基准阶段（2R 非冗余子链）**：
   - 正运动学 `h : T² → R²`；在环面 T² 上离散化并计算碰撞占位，用带环绕邻接的 Union-Find 提取起始构型 qs 所在的连通自由分量 `C(s)_free ⊂ T²`。
   - 障碍约束可达工作空间定义为 `R2R = h(C(s)_free)`，障碍引起的构型空间断连会以“空洞”的形式传递到工作空间。
   - **早期不可行性检测**：若目标位置 xg ∉ R2R，则立即判定不可行，无需考虑任何冗余链接。

2. **雅可比分支结构**：
   - 2R 逆运动学对一般工作空间点最多两个解（elbow-up / elbow-down），以雅可比行列式 `det(J) = l1·l2·sin(θ2)` 作为分支标签。
   - `det(J)` 的符号将 `C(s)_free` 划分为 C⁺ 和 C⁻ 两个开子集，中间以奇异集 Σ = {det(J) = 0} 分隔。
   - **命题 1**：2R 子链在一般工作空间点的自运动叶子 Sx 至多两个连通分量（肘上/肘下），给出了分支结构的严格理论依据。

3. **增量纤维提升**：
   - 对每个工作空间样本 x ∈ RmR 和 θ(m+1) ∈ S1：
     - 用存储的 det(J) 分支标签恢复 m 链接 IK 解，**前一子链无需重新碰撞检测**（有效性从 `C(s)_free` 继承）；
     - 只对第 (m+1) 个新链接做碰撞检测；
   - 将自由子集投影回正运动学，得到 `R(m+1)R`。
   - **逐阶段不可行性检测**：每个阶段若 xg ∉ RmR，则提前终止。

4. **分支一致连接性**：
   - 降维晶格中相邻节点 a、b 只有满足 `|det(Ja) − det(Jb)| < ε` 时才连通。
   - 该约束抑制了跨越分支边界的不连续 IK 切换，同时允许在碰撞自由奇异点附近平滑通过。
   - 关键点：**det(J) 始终只基于 2R 基准子链计算**，即使对 5R 系统也保持一致，确保与底层逆运动学分支分解的一致性。

5. **最终降维规划与路径重建**：
   - 在最终流形 `Mred = R(n−1)R × S1` 上用 A* 搜索，邻接判定需同时满足：工作空间空间邻近、S1 纤维周期连续、以及行列式连续性约束。
   - 找到降维路径后，通过存储的分支标签逐状态提升恢复完整 nR 构型轨迹。
   - **命题 2（路径有效性）**：在行列式连续性约束下，降维流形上找到的任意路径提升到 `C(s)_free ⊂ Tⁿ` 后，必定是连续且无碰撞的。证明分为无碰撞有效性（逐阶段继承保证）与运动学连续性（分支切换需过零，跳跃幅度超过 ε 从而被约束禁止）两部分。

## 6. 主要结论与发现

- 工作空间纤维分解提供了一种**避免显式构造高维构型空间障碍几何**的完整运动规划新途径。
- 基于 2R 非冗余子链的障碍约束可达工作空间，能**忠实继承构型空间中起始连通分量的拓扑断连结构**，从而在引入冗余自由度之前即可进行早期不可行性检测。
- 通过行列式连续性约束，可以**在降维流形上保持逆运动学分支一致性**，抑制不连续分支切换，同时允许在碰撞自由奇异点附近平滑穿越。
- 递增可达性传播成功通过**仅对新加入链接做局部碰撞检测**（前序子链有效性继承）的方式，在 3R 和 5R 机械臂上均得到了无碰撞、运动学连续的可行轨迹。
- 计算结构上，预处理阶段（流形构建）与轨迹搜索解耦，搜索阶段不再需要访问显式配置空间障碍几何。

## 7. 优点

- **几何视角创新**：以“工作空间纤维分解”为核心，将冗余机械臂的降维规划与自运动流形的拓扑结构有机结合，区别于直接构型空间分解或纯商空间降维。
- **早期不可行性检测**：基于 2R 子链可达工作空间的检测提供了廉价且严格的不可行性必要条件，具有工程实用价值。
- **行列式分支标签机智**：用 2R 雅可比行列式作为全局一致的分支标签，既抓住了 IK 分支拓扑，又避免了显式的高维流形构造，且理论上有命题 1 和 2 支撑。
- **增量碰撞检测效率高**：后续链路只检测新加入链接，避免全链重复碰撞检查，符合冗余机械臂由基座向外扩展的结构特性。
- **理论表述规范**：以命题形式（分支结构、路径有效性）给出严格论证，对奇异穿越的处理也有合理的物理解释。

- **实验覆盖过窄**：仅测试 3R 和 5R 两种平面机械臂，未触及更高冗余度（如 7R/8R）、空间（非平面）机械臂，也没有验证方法在更复杂障碍环境中的鲁棒性。

- **缺少参数敏感性分析**：ε（行列式连续性阈值）和 S1 离散分辨率 Nθ 对规划成功率和路径质量的影响未做讨论，这直接影响方法的实用性与可复现性。

- **奇异点处理的潜在歧义**：靠近 Σ 的行列式连续性约束虽允许穿越奇异点，但对近奇异区域的数值稳定性、以及奇异穿越后分支标签的持续一致性，文中没有详细分析。

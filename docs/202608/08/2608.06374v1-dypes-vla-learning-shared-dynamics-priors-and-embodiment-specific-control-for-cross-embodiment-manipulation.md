## 摘要
视觉-语言-动作（VLA）模型已成为机器人操作的一种强大范式，但为异构机器人具身训练一个通用策略仍然是一个开放问题。现有方法存在两个主要局限性。首先，它们未充分利用跨不同视觉和交互数据共享的动态先验，限制了跨具身迁移。其次，它们需要大量手动预处理，将具身特定的动作转换为通用格式。为了克服这些局限性，我们提出了DyPES-VLA，一种跨具身VLA，学习共享的动态先验和具身特定控制。首先，我们通过在跨具身数据上使用未来预测目标训练视觉-语言模型（VLM）来学习共享的动态先验，驱动共享查询表示捕获物体运动、接触以及由交互引起的场景变化。其次，一个具身特定的专家混合（MoE）动作头将这些共享动态先验直接转换为每个具身原生动作空间中的可执行控制，无需手动将异构动作预先对齐为通用格式。该动作头共享注意力层以捕获常见的时间动作结构，而其具身特定的前馈专家则解决不同具身的独特运动学约束和控制语义。作为一种通用策略，我们的方法在仿真和真实世界评估中均达到了最先进的性能，在LIBERO上达到98.0%的成功率，在RoboCasa-GR1上达到59.25%，在RoboTwin 2.0上达到89.02%。

## Abstract
Vision-Language-Action (VLA) models have become a powerful paradigm for robot manipulation, but training a single generalist policy for heterogeneous robot embodiments remains an open problem. Existing methods have two main limitations. First, they underuse dynamics priors shared across diverse visual and interaction data, limiting cross-embodiment transfer. Second, they require extensive manual preprocessing to convert embodiment-specific actions into a common format. To overcome these limitations, we propose DyPES-VLA, a cross-embodiment VLA that learns shared Dynamics Priors and Embodiment-Specific control. First, we learn shared dynamics priors by training the vision-language model (VLM) with a future-prediction objective on cross-embodiment data, driving the shared query representation to capture object motion, contact, and interaction-induced scene changes. Second, an embodiment-specific Mixture-of-Experts (MoE) action head translates these shared dynamics priors into executable controls directly in each embodiment's native action space, without manually pre-aligning heterogeneous actions into a common format. This head shares attention layers to capture common temporal action structures, while its embodiment-specific feed-forward experts resolve the unique kinematic constraints and control semantics of distinct embodiments. As a generalist policy, our \ourmethod achieves state-of-the-art performance across simulation and real-world evaluations, reaching 98.0% success on LIBERO, 59.25% on RoboCasa-GR1, and 89.02% on RoboTwin~2.0.

## 1. 核心问题与研究动机

近年来，以视觉-语言-动作（VLA）模型为代表的机器人操作策略虽然在单一机器人上表现优异，但训练一个能够同时适用于多种异构机器人本体（embodiment）的通用策略仍是开放问题。论文指出现有跨具身方法存在两个关键局限：

- **共享动态先验利用不足**：大多数方法仅以“动作预测”为唯一监督信号，忽略了大量无动作标签的人类/机器人视频中蕴含的物体运动、接触和场景演变规律，这些规律是跨具身可共享的动力学知识。
- **动作格式需手动对齐**：许多方法将异构机器人动作映射到统一动作空间（如坐标系变换、逆运动学或潜空间），预处理复杂度高、可扩展性差，且将“跨具身共享的交互规律”与“每个机器人独有的控制语义”强行耦合，损害了策略的通用性。

因此，论文提出一种新的跨具身学习范式：**共享动力学先验（Shared Dynamics Priors）+ 具身特定控制（Embodiment-Specific Control）**，并实例化为 DyPES-VLA。核心思想是：在共享的查询表示中编码跨具身共有的物体交互动态；在动作侧，通过具身特定的专家混合（MoE）头直接在各自原生动作空间输出控制，避免手工对齐。

## 2. 方法论

### 2.1 整体架构

DyPES-VLA 由三部分组成：

- **预训练 VLM（Qwen3-VL-2B）**：输入视觉观测、语言指令、具身元数据（如 robot_type、控制频率、动作维度等）以及 96 个可学习 query token，输出 query states（\(Z\)），作为未来预测与动作生成的共享接口。
- **未来生成头（Future Generation Head）**：使用 SANA-600M 图像生成器，以 query states 为条件预测未来帧，监督 query states 学习物体运动、接触、场景变化等共享动态先验。
- **具身特定 MoE 动作头**：基于 flow-matching Diffusion Transformer（DiT），将 query states 解码为每个机器人原生动作空间的 action chunk。动作头共享注意力层（捕获时间结构），通过静态路由专家（per-embodiment encoder-decoder + FFN）解决各机器人的运动学约束和控制语义差异。

### 2.2 共享查询接口

VLM 输出 query states：
\[
Z = f_\theta([\phi_v(o_t), \phi_\ell(\ell), \phi_\ell(m_e), Q])
\]
其中 \(Q\) 是可学习 query tokens，\(m_e\) 是文本化的具身元数据。策略不使用本体感受输入。

### 2.3 学习动态先验

- 未来目标帧为 \(x_{t+\Delta_e}\)，\(\Delta_e\) 与每个具身的动作时域 \(H_e\) 匹配。
- 使用冻结的 SANA 自编码器将未来帧编码为 latent \(z\)，query states 经投影后作为生成器的 cross-attention 条件。
- 训练损失为 rectified-flow：
\[
\mathcal{L}_{\text{future}} = \mathbb{E}_{\tau,\epsilon}\left[\|g_\psi(z_\tau, \tau, p_\omega(Z)) - (z-\epsilon)\|_2^2\right]
\]
- 未来生成头不接收当前观测或其 latent，信息必须通过 N 个 query states 传递，从而迫使查询表示保留预测未来所需的动态信息。

### 2.4 学习具身特定控制

- 每个具身 \(e\) 拥有轻量级编码器-解码器对，将原生动作空间映射到共享 DiT 宽度。
- DiT 的每个 transformer block 使用共享注意力（含 AdaLN 调制）和按路由索引 \(r(e)\) 选择的 FFN 专家：
\[
\bar{X} = X + \text{Attn}(\text{AdaLN}(X,\tau); Z),\quad X' = \bar{X} + \text{FFN}^{(r(e))}(\text{AdaLN}(\bar{X},\tau))
\]
- 动作头也采用 rectified-flow 损失，噪声级别 \(\tau\) 采用 Beta 调度（偏向高噪声端），在各自原生动作空间回归速度场：
\[
\mathcal{L}_{\text{action}} = \mathbb{E}_{\tau,\epsilon}\left[\|\hat{V} - (A^e - \epsilon)\|_2^2\right]
\]

### 2.5 两阶段训练

1. **Stage 1（动力学先验预训练）**：在无动作标签视频（EgoDex 人类视频 + 三个仿真基准视频）上优化 VLM、query tokens 和未来生成头。
2. **Stage 2（跨具身共同训练）**：在带有动作标注的机器人演示数据上联合优化未来预测和动作目标：
\[
\mathcal{L} = \mathcal{L}_{\text{action}} + \lambda_w \mathcal{L}_{\text{future}},\quad \lambda_w=0.05
\]
推理时仅保留 VLM + 动作头，未来生成头被移除。

## 3. 实验设计

### 3.1 仿真基准

采用三个差异化仿真基准，对应三种机器人形态：

- **RoboTwin 2.0**：14-DoF 双臂 ALOHA-AgileX，50 个任务，分 Clean 和 Randomized（Easy/Hard）两个设置。
- **RoboCasa-GR1**：29-DoF Fourier GR-1 人形机器人，24 个桌面任务，50 次 rollout/任务。
- **LIBERO**：7-DoF Franka Emika Panda 单臂机器人，4 个任务套件（Spatial、Object、Goal、Long），共 100 个任务（原文中平均 98.0%）。

### 3.2 真实世界平台

- **FR3**（7-DoF 单臂）、**COBOT Magic**（14-DoF 双臂）、**G1 人形**（Unitree G1 + Inspire 手）。
- 三个任务：“把猕猴桃放入篮子”“倒水”“把书放到书架”。
- 每个任务、每个机器人 200 条遥操作演示，联合微调单一 checkpoint，评估 25 次 rollout/任务/机器人。

### 3.3 对比方法

- 真实世界中对比 ACT（per-task 独立训练，共 9 个 checkpoint）和 GR00T-N1.6（联合微调单一 checkpoint）。

### 3.4 消融与探针实验

## 6. 主要结论与发现

- DyPES-VLA 以**单一 checkpoint** 在三个仿真 benchmark 上达到 SOTA：LIBERO 98.0%、RoboCasa-GR1 59.25%、RoboTwin 2.0 89.02%，均超过或接近最强基线。
- **未来预测监督**显著提升跨具身策略性能（移除后 RoboTwin 掉 2.4 点、RoboCasa 掉 2.5 点），且线性探针证明未来监督让接触事件的开始/释放更可线性解码，验证了共享动力学先验的有效性。
- **MoE 动作头**比共享 dense head 更好（RoboTwin +1.2、RoboCasa +2.1），说明具身特定控制消解了异构动作空间干扰。
- **具身元数据**提供小但一致的增益（0.5 点左右），辅助消除具身与数据源歧义。
- 在真实世界中，单 checkpoint 联合微调后的 DyPES-VLA 平均成功率 75.6%，大幅超过 ACT 的 32.4% 和 GR00T-N1.6 的 59.6%。

## 7. 优点与亮点

- **范式清晰**：将“共享知识”与“具身特有知识”明确分离，共享部分用未来预测学习，特定部分用 MoE 解码，避免手工动作对齐。
- **数据效率**：有效利用无动作标签的人类视频和仿真视频进行 Stage-1 预训练，减少对昂贵动作标注的依赖。
- **表示可解释性**：用线性探针验证 query states 中的动力学信息，为“未来预测帮助策略学习”提供了直接证据。
- **工程部署简洁**：推理时移除未来生成头，仅需一次 VLM 前向 + 4 步 Euler 解码，不引入测试时未来想象开销。
- **验证充分**：覆盖多样具身（单臂、双臂、人形）和 3 仿真 + 3 真实机器人，跨 sim2real 转移验证有说服力。
- **对比全面**：涵盖 π0、π0.5、RDT-1B、Diffusion Policy、OpenVLA、GR00T、Qwen-VLA 等代表性方法。

## 8. 不足与局限

- **任务范围偏窄**：真实世界仅三个桌面操作任务，且未涉及复杂长时程或精操作；对更高难度（如精细装配、非刚性操作）缺乏评估。
- **统计显著性缺失**：未报告多次运行的标准差、置信区间或随机种子数，无法判断结果是否稳定。
- **动作头扩展性受限**：每个新具身需要新增专家，路由索引依赖明确元数据；若出现未见过的具身类型，需重新设计专家参数。
- **未来预测目标的间接收益**：尽管消融显示未来预测提升性能，但未与“重建当前帧/对比学习”等其他辅助目标对比，难以证明是“动态先验”而非“额外正则化”带来的收益。
- **算力消耗较高**：两阶段训练共 30 万步、batch 512、16 张 H100，对一般实验室复现门槛较高。
- **真实世界数据量有限**：每任务仅 200 条演示，未探索数据规模效应；联合微调过程亦未提供充分消融。
- **未说明基线微调细节公平性**：GR00T-N1.6 等模型的微调数据配方、超参数是否与 DyPES-VLA 完全公平对齐未详细交代。

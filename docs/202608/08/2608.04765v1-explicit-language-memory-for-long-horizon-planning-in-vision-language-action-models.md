## 摘要
视觉-语言-动作（VLA）模型为连接视觉感知、语言理解和机器人控制提供了统一范式。然而，现有的VLA模型在长时程任务中仍面临重大挑战：稀疏的专家示范限制了跨任务的组合泛化能力；长时程任务的非马尔可夫性质使得仅基于当前观察的策略难以维持时间一致性；有限的闭环纠错能力导致执行误差累积；端到端的动作微调可能削弱视觉-语言模型（VLM）骨干的高层语义表征。针对这些问题，我们提出了一种带有显式语言记忆模块的层级式长时程VLA架构。其核心思想是将离散的时间观察转换为具有时间逻辑的连贯文本记忆序列。该系统被解耦为高层VLM和低层VLA：高层VLM通过视觉问答训练范式进行语义推理，而低层VLA则根据子任务指令和视觉观察执行精确的连续控制。高层VLM利用先前的记忆作为上下文锚点，递归更新语言记忆和子任务指令，从而在长时程执行过程中实现持续的时间跟踪和动态纠错。我们在多个仿真环境中评估了所提方法，并在真实机器人平台上进行了仿真到现实的迁移实验。结果表明，显式语言记忆提高了VLA模型在复杂长时程任务中的成功率和鲁棒性，同时为决策过程提供了可解释的语义说明。

## Abstract
Vision-language-action (VLA) models provide a unified paradigm for connecting visual perception, language understanding, and robotic control. However, existing VLA models still face major challenges in long-horizon tasks: sparse expert demonstrations constrain cross-task compositional generalization; the non-Markovian nature of long-horizon tasks makes it difficult for policies conditioned only on current observations to maintain temporal consistency; limited closed-loop error correction allows execution errors to accumulate; and end-to-end action fine-tuning may weaken the high-level semantic representations of vision-language model (VLM) backbones. To address these issues, we propose a hierarchical long-horizon VLA architecture with an explicit language-memory module. The central idea is to convert discrete temporal observations into a coherent textual memory sequence with temporal logic. The system is decoupled into a high-level VLM and a low-level VLA: the high-level VLM performs semantic reasoning through a visual question answering training paradigm, while the low-level VLA executes precise continuous control conditioned on subtask instructions and visual observations. The high-level VLM recursively updates both language memory and subtask instructions using the previous memory as a contextual anchor, enabling persistent temporal tracking and dynamic correction during long-horizon execution. We evaluate the proposed method in multiple simulation environments and conduct sim-to-real experiments on a real robotic platform. The results demonstrate that explicit language memory improves the success rate and robustness of VLA models on complex long-horizon tasks while providing an interpretable semantic account of the decision process.

## 1. 核心问题与整体含义（研究动机和背景）

本论文针对**视觉-语言-动作（VLA）模型在长时程任务中的关键缺陷**展开研究。尽管VLA模型将视觉感知、语言理解与机器人控制统一为一个策略范式，但在多阶段、长时程任务中仍面临四大核心挑战：

- **稀疏专家示范**：有限的演示数据限制了跨任务的组合泛化能力。
- **非马尔可夫性**：长时程任务中，仅依赖当前观测无法判断历史状态（如是否已抓取成功、按钮是否已按下），导致策略可能跳过阶段、重复已完成动作或在未观察到的失败后继续执行下游动作。
- **误差累积**：闭环纠错能力有限，执行错误沿动作序列逐步累积。
- **语义表征弱化**：端到端动作微调可能削弱VLM骨干已有的高层语义表示能力。

作者的核心洞察是：**将任务历史以显式自然语言记忆的形式维护**，作为时间锚点来支撑阶段一致性，比拼接全部历史帧更紧凑、更可解释、更适合实时部署。

## 2. 方法论

### 2.1 核心思想

提出**分层VLA架构**，将长时程策略解耦为两个独立优化目标的分支：

- **高层VLM**：负责语义推理，递归更新语言记忆和子任务指令（决定"做什么"）；
- **低层VLA**：基于当前观测和子任务生成连续动作块（决定"怎么做"）。

策略分解公式如下（原文式1）：

```
π(a_{t:t+H}, s_t, m_t | o_t, m_{t-1}, l) = π_LL(a_{t:t+H} | o_t, s_t) · π_HL(s_t, m_t | o_t, m_{t-1}, l)
```

其中 `m_t` 为语言记忆，`s_t` 为子任务指令，`o_t` 为当前观测，`l` 为全局指令，`a_{t:t+H}` 为动作块。

### 2.2 递归语言记忆

- 记忆 `m_t` 是结构化自然语言摘要，包含：已完成阶段（过去时）、完成证据、相关物体属性、观察到的失败、下一待办里程碑。
- 采用**滚动压缩规则**：子任务完成前保留目标细节（类别、颜色、位置），完成后压缩为简短过去时陈述，注意力转移到下一动作。例如：
  - `m_t`："我正在走向咖啡桌上的红色收音机。"
  - `m_{t+1}`："我已走到收音机旁，接下来要拿起红色收音机。"
- 仅当观测提供当前里程碑已变更的证据时才更新记忆，从而保持记忆有界。

### 2.3 自动化记忆监督

- 每个专家 episode 包含视频、技能名称、描述和起止时间戳。
- 通用VLM（Gemini 3.5 Flash API 或本地 Qwen3.5-9B）根据当前帧+完整技能标注，生成：(1) 简洁子任务（动作+目标物体+上下文）；(2) 第一人称语言记忆。
- 提示词要求使用自然物体名和可见属性，避免"帧/索引/技能序号"等实现术语。
- 最终得到帧对齐的 `(m_t, s_t)` 监督目标。

### 2.4 独立分支训练

- **高层分支**：基于 PaliGemma，自回归预测记忆和子任务，目标函数见原文式3。
- **低层分支**：基于 π0.5 动作专家，采用 flow-matching 目标，输入观测与目标/预测子任务，输出动作块，目标函数见原文式4。
- 两分支独立训练，避免单目标中语义生成与连续控制的损失平衡难题。

### 2.5 闭环推理

推理流程：初始化 `m_0 = ∅` → 循环执行（获取观测 → 高层更新 `(m_t, s_t)` → 低层生成动作块 → 执行 → 判断终止），直至高层状态指示任务完成。全程输出可读文本日志，便于与动作失败对齐分析。

## 6. 主要结论与发现

- **显式语言记忆显著提升长时程任务阶段成功率**：

| 任务 | π0.5 | π0.5 + 语言记忆 |
|------|------|----------------|
| BEHAVIOR-1K 打开收音机 | 30.0% | 40.0% |
| Genie 单包裹分拣 | 41.7% | 63.9% |
| Genie 连续分拣 | 31.3% | 46.9% |
| 真实机器人拾取放置 | 62.5% | 66.3% |

- **减少阶段跳过与过早推进**：定性日志显示，基线在拾取收音机后直接预测"放置"，跳过按钮按压阶段；带记忆策略则记录已完成动作并将"按压按钮"设为下一意图，仅在观测支持完成证据后才推进阶段。包裹分拣中同样避免了跳过扫码直接入篮的错误。
- **记忆解决"做什么"而非"怎么做"**：PressOn 阶段即使记忆正确识别子任务，仍因接触操作（按钮定位、几何对齐、力控）失败——语义记忆与运动技能是互补的不同问题。
- **支持简单的上下文内失败恢复**：抓取失败时，记忆可记录"物体未被固定"，发出"重新张开夹爪"子任务并重试，无需单独恢复控制器。
- **提供可解释性**：记忆和子任务均为可见文本，决策失败可被定位为高层语义错误或低层控制错误。

## 7. 优点

1. **层次化解耦设计清晰**：高层语义规划与低层连续控制各自优化，避免单目标联合训练的损失平衡难题，两个分支可独立迭代。
2. **显式语言记忆的独创性与实用性**：以自然语言作为记忆载体，具有紧凑性（滚动压缩防止上下文无限增长）、可监督性（自动化标注管线）和可解释性（直接阅读决策过程）三重优势。
3. **证据条件式记忆更新机制**：只有观测支持阶段变更才更新记忆，本质上是隐式的阶段状态机，有效抑制"提前跳阶段"的系统性错误。
4. **自动化监督管线**：利用通用VLM从专家视频+时间戳生成对齐的记忆/子任务目标，免去昂贵的人工标注，工程可行性高。
5. **跨平台验证**：从家庭仿真→人形仿真→真实低成本机器人，体现了方法的可迁移性；且真实平台使用了低成本双机械臂+移动底座，有实际部署参考价值。
6. **诚实的边界刻画**：明确指出语义记忆不能弥补运动控制精度不足（PressOn低分），将失败归因区分开，分析严谨。

## 8. 不足与局限

1. **统计严谨性不足**：未报告随机种子变化、置信区间或显著性检验，表1/2/3的差异幅度（尤其真实机器人+3.8%）难以判断是否在噪声范围内。
2. **真实实验覆盖过窄**：仅单一短任务（拾取放置），非论文声称的"分钟级、多物体、重复交互、环境变化"的真实复杂场景；训练数据仅25条轨迹，无法评估数据规模效应。
3. **缺少系统的消融研究**：未单独验证子任务预测vs记忆更新各自的贡献，也未检验不同记忆表达粒度、不同记忆模型（如固定窗口历史帧 vs 语言记忆）的对比。
4. **计算开销增加**：每步决策需额外调用一次高层VLM，增加延迟和部署复杂度，可能限制实时性要求高的场景。
5. **恢复能力依赖数据**：上下文失败恢复虽为亮点，但需要采集和标注多样失败轨迹（抓取偏移、碰撞、目标丢失等），真实数据稀缺时难以泛化。
6. **低层控制瓶颈未解决**：接触丰富动作（PressOn等）成功率极低，语言记忆无法弥补低层数据或控制精度不足，方法对"需要精细力控"的任务增益有限。
7. **技术细节缺失**：未说明高层VLM的推理频率/节流机制、记忆长度上限的具体实现、两分支训练时对子任务预测错误的传播策略等实现细节，复现难度较高。

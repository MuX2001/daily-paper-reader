## 摘要
世界模型构建潜在状态，以支持对底层系统的预测、规划和推理。联合嵌入预测架构（JEPA）提供了一种直接学习此类状态的方法，通过在表示空间预测目标而非重建观测的每个细节来达成。然而，标准JEPA将所有可预测内容组织为单一目标嵌入和单一预测路径。在复杂系统中，这种单体状态可能会将冗余容量分配给主导信号，同时为不太主导的预测结构提供微弱或冲突的梯度。我们引入了\method，一种基于正交预测分解的潜在世界建模框架。学习到的基矩阵将每个目标状态分析为多个分量，专用预测分支从共享上下文表示中估计每个分量。预测回归保留了状态合成所需的因子幅度，正交性目标阻止重复方向，因子活动正则化维持投影目标的变化，在线方差正则化阻止逐坐标编码器崩溃。预测分量被合成为完整的潜在状态，可用于读取、解码、规划或自回归展开。当目标在时间上是未来的、空间上是隐藏的，或是同一系统的另一种部分观测时，相同的预测状态机制均适用。在受控视觉、单细胞转录组学、纵向健康记录、连续控制和分子动力学上的实验评估了表示质量、预测、规划和长时程稳定性。

## Abstract
World models construct latent states that support prediction, planning, and reasoning about an underlying system. Joint-embedding predictive architectures (JEPAs) offer a direct way to learn such states by predicting targets in representation space instead of reconstructing every detail of the observation. Standard JEPAs, however, organize all predictable content through one target embedding and one prediction pathway. In complex systems, this monolithic state can allocate redundant capacity to dominant signals while providing weak or conflicting gradients to less dominant predictive structure. We introduce \method, a latent world-modeling framework based on orthogonal predictive factorization. Learned basis matrices analyze each target state into multiple components, and a dedicated prediction branch estimates each component from a shared context representation. Predictive regression preserves the factor magnitudes required for state synthesis, an orthogonality objective discourages repeated directions, factor-activity regularization maintains variation in projected targets, and online variance regularization discourages coordinate-wise encoder collapse. Predicted components are synthesized into a complete latent state that can be used by a readout, decoder, planner, or autoregressive rollout. The same predictive-state mechanism applies when the target is temporally future, spatially hidden, or another partial observation of the same system. Experiments on controlled vision, single-cell transcriptomics, longitudinal health records, continuous control, and molecular dynamics evaluate representation quality, forecasting, planning, and long-horizon stability.

## 1. 核心问题与整体含义

**研究动机与背景：**

世界模型（World Models）的目标是构造潜在状态，以支持对底层系统的预测、规划与推理。联合嵌入预测架构（JEPA）通过直接在表示空间中预测目标嵌入，避免了逐像素重建的计算开销与噪声敏感问题，成为学习此类潜在状态的主流范式。

然而，标准 JEPA 将所有可预测内容压缩进**单一目标嵌入**，并通过**单一预测路径**进行回归。在复杂系统中，这种“单体式”（monolithic）状态存在以下缺陷：

- 主导信号（高方差、易预测的结构）会占用过多的模型容量；
- 次要预测结构获得较弱或相互冲突的梯度，难以被充分学习；
- 多个潜在方向可能学习到冗余功能，降低表示效率。

因此，论文提出一个核心研究问题：**能否通过多个结构化的预测因子而非单一预测路径，来组织 JEPA 的可预测世界状态？**

**整体含义：** 本文提出 Orthogonal JEPA——一个通用的潜在世界模型框架，通过正交预测分解（orthogonal predictive factorization）将目标状态拆解为多个分量，由专用预测分支分别估计，再合成完整潜在状态。该机制可跨领域应用于视觉、单细胞转录组学、临床健康记录、连续控制与分子动力学等多种系统。

## 2. 方法论

**核心思想：**

Orthogonal JEPA 将 JEPA 的单体式目标预测替换为“分析-分支预测-合成”的三阶段流程：
1. 用学习到的基矩阵将目标状态分解为若干因子分量；
2. 每个分量由独立预测分支从共享上下文表示中回归；
3. 将预测分量合成为完整潜在状态，供下游任务使用。

**技术细节与关键公式：**

**（1）预测状态接口（Predictive-State Interface）**

每个领域通过适配器 Aδ 将原始观测 x 映射为内容 token H 和结构描述符 S（如坐标、时间戳、实体标识），视图采样器 Vδ 选择上下文索引 C 和目标索引 T：

```
x → Aδ → (H, S) → Vδ → (H_C, S_C, T, S_T)
```

在线编码器生成上下文表示 z_c = f_θ(H_C, S_C)；目标编码器为每个目标 token 生成 z_t = f_θ̄(H, S)_t。目标编码器参数通过指数移动平均（EMA）更新，不接收梯度。

**（2）正交预测分解（Orthogonal Predictive Factorization）**

引入 K 个学习到的基矩阵 B_k ∈ R^(d×r)，其中 Kr = d。目标状态被分解为：

```
z_t^(k) = B_k^T · sg(z_t),   k = 1, ..., K
```

每个因子由专用预测器 q_k 从共享上下文表示 z_c 和目标描述符 s_t 中回归：

```
ẑ_t^(k) = q_k(z_c, s_t)
```

因子预测拼接为完整预测  û_t，再通过 Moore–Penrose 伪逆合成完整预测状态：

```
ẑ_t = (B^T)† · û_t
```

当 B 满足正交条件时，(B^T)† = B，合成简化为各因子投影的加权求和。

**（3）预测回归损失（保留方向与幅度）**

```
L_pred = (1 / K|T|r) · Σ_{t∈T} Σ_{k=1..K} || ẑ_t^(k) − z_t^(k) ||₂²
```

直接对因子坐标做回归，保留了状态合成所需的因子幅度信息。

**（4）正交性目标（Orthogonality Objective）**

```
L_orth = Σ_k || B_k^T B_k − I_r ||_F² + Σ_{i<j} || B_i^T B_j ||_F²
```

该目标鼓励基矩阵在因子内部正交归一、因子之间相互正交，与 Barlow Twins 和 VICReg 的去冗余思想相关，但作用于可学习的预测目标坐标而非仅嵌入统计量。

**（5）因子活动与编码器方差正则**

- **因子活动正则**：鼓励投影后的每个因子坐标在小批量内有足够的方差，防止某些因子退化失效：

```
L_fac = (1/Kr) Σ_k Σ_j max(0, γ_fac − σ_fac^(k,j))
```

- **在线方差正则**：对在线编码器的每个坐标施加方差下限，防止坐标级坍缩：

```
L_enc = (1/d) Σ_j max(0, γ_enc − σ_enc^j)
```

**（6）总体目标**

```
L_OJEPA = L_pred + λ_orth · L_orth + λ_fac · L_fac + λ_enc · L_enc
```

若应用保留领域标准的辅助预训练损失，则总损失为 L_total = L_OJEPA + λ_aux · L_aux。

**（7）理论保证**

命题1证明：当 B_i^T B_j = 0（i≠j）、B_k^T B_k = I_r、Kr = d 时，B 为正交矩阵，满足范数保持恒等式 z = Σ_k B_k B_k^T z。这保证在理想正交极限下分解与合成是无损的。

**（8）下游使用**

- **静态下游任务**：直接用在线编码器作为特征提取器，接任务特定的读取头；
- **预测性应用**：保留式(5)的合成状态，供解码器、规划器或自回归展开使用。

## 6. 主要结论与发现

1. **因子化目标优于单体目标**：在全部 5 个领域中，Orthogonal JEPA 均优于标准 JEPA 对应配置，表明正交预测分解是有效的潜在状态设计。

2. **正交性目标有效分配容量**：通过基矩阵正交约束，不同预测分支学习到互补的目标空间方向，避免冗余容量分配。

3. **方差正则防止坍缩**：因子活动正则和在线方差正则共同维持了投影目标与编码器输出的逐坐标变化，避免了 JEPA 训练中常见的表示坍缩问题。

4. **同一机制跨域适用**：无需修改核心算法，仅通过调整适配器、上下文-目标构造和结构描述符，即可适配视觉、生物学、临床、控制与分子系统。

5. **合成状态可直接用于预测性任务**：预测因子合成后的潜在状态可驱动 CEM 规划（控制任务）和自回归展开（分子动力学），且 100 步展开保持稳定性。

6. **预训练缓解长时程漂移**：在分子动力学的所有四个系统中，JEPA 预训练（单体或正交）均显著降低了 100 步自回归后的 RMSD，而正交因子分解在单体 JEPA 基础上进一步减少误差。

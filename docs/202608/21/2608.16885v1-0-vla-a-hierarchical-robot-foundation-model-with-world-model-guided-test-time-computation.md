## 摘要
长时程机器人操作要求机器人既可靠地执行单个技能，又能在扩展任务中连贯地安排这些技能。大多数分层视觉-语言-动作（VLA）模型通过单次前向传递做出每个决策，没有机制为困难或关键的选择分配额外计算。我们提出τ_0-VLA，一种分层机器人基础模型，通过世界模型引导的测试时计算，将高层子任务生成建模为一个计算可扩展的推理问题。在每次推理步骤中，高层策略利用执行记忆生成子任务，并在必要时在确定输出之前搜索替代方案。然后，低层策略在多种机器人形态上执行生成的子任务。该策略在40,115小时的异构真实世界数据上进行多模态联合训练。在领域内和分布偏移场景中，分配额外的测试时计算能显著提升下一子任务预测的准确性，这些收益转化为长时程机器人操作任务中更高的闭环成功率。

## Abstract
Long-horizon robot manipulation requires a robot to both execute individual skills reliably and sequence them coherently over extended tasks. Most hierarchical vision-language-action (VLA) models make each such decision with a single forward pass, leaving no mechanism to allocate additional computation to difficult or consequential choices. We introduce $τ_0$-VLA, a hierarchical robot foundation model that formulates high-level subtask generation as a compute-scalable inference problem through world-model-guided test-time computation. At each inference step, the high-level policy uses execution memory to generate a subtask and, when needed, searches over alternatives before committing to its output. A low-level policy then executes the generated subtask across multiple robot embodiments. The policy is trained on 40,115 hours of heterogeneous real-world data with multimodal co-training. Across in-domain and distribution-shifted settings, allocating additional test-time computation substantially improves next-subtask prediction accuracy, and these gains translate into higher closed-loop success on long-horizon robot manipulation tasks.

## 一、论文的核心问题与整体含义

- **研究动机与背景**：长时程机器人操作（如打扫房间、做饭、泡茶）不仅要求机器人可靠执行单个技能，还要求其在数分钟到数小时的扩展任务中连贯地安排子任务序列。现有分层视觉-语言-动作（VLA）模型大多以单次前向传递完成每次高层决策，缺乏为困难或关键选择分配额外计算的机制。一个错误的子任务选择无法靠更精确的电机控制来纠正——机器人可能完美地执行了错误的子任务。
- **核心问题**：长时程执行的核心瓶颈已不再是分层动作接口的可用性，而是生成下一子任务的推理过程本身。本文关注的正是如何将开放式的语言子任务搜索与视觉结果预测、执行记忆耦合到一个通用的真实机器人分层系统中。
- **整体含义**：论文提出τ₀-VLA，将高层子任务生成建模为**计算可扩展的推理问题**，通过世界模型引导的测试时计算（Test-Time Computation, TTC）在决策前比较和评估候选子任务的物理后果，从而提升长时程任务的闭环成功率。

## 二、论文提出的方法论

### 2.1 核心思想
- τ₀-VLA 是一个两层级联系统：**高层策略**负责维护执行记忆、决定何时调用额外的测试时计算、生成当前子任务；**低层策略**负责将观测和生成的子任务映射为机器人动作。
- 核心创新在于高层策略的 **“提出–预测–评估”（propose–predict–evaluate）循环**：VLM生成候选子任务 → 世界模型预测每个候选的终端视觉结果 → 价值模型评估该结果对任务进展的贡献 → 反射模型基于保留的分支作出最终承诺。整个流程通过 beam search 递归扩展，使推理预算可随分支因子、束宽和深度扩展。

### 2.2 关键组件与技术细节
- **高层策略 μ** 由四个模型组成：
  - **提案模型 P**：接收当前上下文 h_t = (ℓ, M_{t−1}, z*_{t−1}, o_t)，更新执行记忆并生成直接子任务提案 z_dir_t。可选的**自适应路由器**根据 token 置信度（生成 token 平均概率和 logit 间隔）决定走快速路径（g_t=0）还是调用 TTC（g_t=1）。
  - **世界模型 W**：基于头部相机 RGB 图像和候选子任务 z，预测该子任务执行完成后的终端头部相机图像（单张图像）。
  - **价值模型 V**：以任务指令、候选子任务和预测的终端图像为输入，输出标量候选质量分数 v，本质上是一个多选 VQA 任务，将质量映射为 0.05~0.95 的五个离散等级。
  - **反射模型 F**：以观测对齐的真实上下文 h̄_t 和保留分支摘要 C_t 为条件，生成最终子任务 z*_t，输出不受限于候选集。
- **测试时搜索（Algorithm 1）**：初始化包含根分支（上下文为 h_t、路径为空、分数为0）。在每层深度 d，对每个保留分支独立调用提案模型 N 次生成候选子任务，世界模型预测其终端图像，价值模型评分，按累积分数全局保留 Top-B 分支，递归展开至深度 D。搜索内部的记忆均为分支局部记忆，不会覆盖持久化执行记忆 M_t。
- **执行记忆机制**：记忆由提案模型在每个推理步骤更新。训练时通过扰动演示中的记忆（滞后、超前、与实际进展冲突）来教高层策略自我纠正——无需额外标注，即可应对部署时记忆与实际状态不对齐的情况。
- **低层策略**：将预训练 VLM 骨干（Qwen3.5-2B）与 Mixture-of-Transformers（MoT）动作专家耦合。核心设计是**统一的 40 维状态与动作空间**，涵盖末端执行器、手臂关节、夹爪、腰部、移动底盘，配合逐样本掩码，使单一模型同时支持固定底座操作、双臂协调和移动全身控制。动作专家以**条件流匹配**（conditional flow matching）从噪声学习动作块分布，并在训练和目标函数中对非活动通道进行掩码处理。
- **训练流程**：低层策略分三阶段训练——知识隔离联合训练（KI，阻断动作梯度回传至骨干）→ 端到端联合训练（放开梯度）→ 任务特定微调。高层各模型从 Qwen3.5-9B 初始化并分别微调，世界模型从 Step1X-Edit 初始化。

## 六、论文的主要结论与发现

1. **TTC 显著提升子任务预测精度**：在全部四个开环评估设置中，TTC 精度均为最高。例如 Book Organization OOD 场景下 TTC 达 74.0%，优于 Plan Once 的 50.0% 和 Best-of-N 的 57.5%。
2. **预测精度的提升转化为闭环任务成功率的提升**：TTC 使 Make Milk Tea 成功率从 5/10 提升至 7/10、Book Organization 从 6/10 提升至 9/10、Clean Room 从 5/10 提升至 7/10，进度分数同步提升。
3. **执行记忆对长时程任务至关重要**：Clean Room 和 Prepare Ingredients 中，分层系统 + 显式记忆显著优于无记忆的直接执行；Tomato and Egg Stir Fry 中记忆解决了“是否已加盐”的观测歧义问题。
4. **分层系统整体优于直接执行**：表 I 中分层 Plan Once 平均 SR 45.00% vs 直接执行 27.50%，平均 Progress 87.85% vs 80.10%。
5. **计算-精度关系呈饱和趋势**：精度随计算量快速上升后趋于平台期，表明 TTC 在中等计算预算下具有良好性价比。
6. **低层策略具备跨形态泛化能力**：τ₀-VLA 在 Collect Laundry 和 Tidy Makeup Table 上全面超越 π0.5、GR00T N1.7 和 LingBot-VLA，尤其在指令跟随（Tidy Makeup Table）上表现突出。

## 七、优点

- **方法论亮点**：
  - “提出–预测–评估–反思”的搜索框架系统性地将测试时计算引入机器人高层决策，子任务这一语义单元恰好处于动作级搜索和语言推理之间的最佳粒度。
  - 世界模型在决策承诺**之前**而非之后参与评估，与 π0.7 等现有工作形成本质区别。
  - 执行记忆的自纠正训练机制（记忆扰动）零额外标注，解决了长时程任务中状态跟踪的漂移问题。
  - 40 维统一动作空间 + 掩码流匹配的设计优雅地解决了跨形态异质控制的兼容性问题。
  - 自适应路由设计合理：高速路处理常规决策，TTC 仅在模型不确定时被触发，兼顾效率与效果。
- **实验设计优点**：
  - 开环预测精度与闭环真实机器人成功率双轨验证，证据链完整。
  - 在 Tidy Makeup Table 中利用“匹配视觉状态 + 不同指令”的设计控制了视觉歧义，精准考验语言-指令跟随能力。
  - 提供了计算成本（PFLOPs）与精度的定量关系分析，这在机器人领域较为少见。
  - LLM-as-a-Judge（GPT-5.4）对子任务预测进行语义等价判断，并采用两次评分 + 多数投票机制，缓解了精确字符串匹配的误判问题。

## 八、不足与局限

- **算力信息缺失**：全文未披露训练所用 GPU 型号、数量、总训练时长等关键算力指标，限制了社区对可复现性和资源门槛的评估。
- **试验样本量偏小**：每条件仅 10 次物理试验，无显著性检验报告，某些性能差异（如 Clean Room 中 τ₀-VLA vs π0.5 SR 相同但 Progress 不同）可能受随机性影响。
- **世界模型仅预测单张头部相机终端图像**：无法预测中间过程状态、多视角结果或动作级的物理细节，对于视觉变化不明显但结果关键的步骤（如加盐、倒液体）评估能力受限。
- **搜索中的分支记忆是局部的**：beam search 中记忆在分支间不共享，可能丢失全局上下文并导致搜索空间内的记忆不一致。
- **TTC 的计算开销推断**：虽然论文量化了 PFLOPs，但在实际部署中高层推理通过异步流水线缓存（~1s 刷新），TTC 的最坏情况延迟可能影响对时间敏感的任务。论文未报告 TTC 的端到端延迟。
- **仿真 rollout 训练数据可能积累误差**：价值模型和反射模型的训练使用世界模型预测结果递归生成的模拟 rollout，若世界模型在特定状态产生系统偏差，该偏差会传播到高层模型训练分布中。
- **直接执行模式的跨形态评测任务较短**（仅 2~5 步），无法证明低层策略在跨形态长时程任务上的能力。
- **潜在评估偏差**：LLM-as-a-Judge 虽采用多数投票，但 GPT-5.4 对“等价”定义的主观性仍可能引入判断偏差；作者团队同时包含产业界（Agibot Finch）和学术界（上海创新研究院、香港中文大学），数据采集、评估和写作存在利害关系，但未披露评估者的独立性和盲评细节。
- **任务选取的覆盖面**：七个任务集中在家居整理和备餐场景，未覆盖工业、医疗或高动态交互任务；AGIBOT G1 为主平台（大量内部数据），在自有平台上的表现优势可能部分来自数据分布优势。

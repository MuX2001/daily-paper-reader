# On the Value Function of Infinite-Horizon Optimal Control of Piecewise Affine Systems 

Francesco Cordiano*, Kanghui He*, and Bart De Schutter, Fellow, IEEE 

Abstract —In this paper, we study the structure of the value function in constrained infinite-time optimal control (CITOC) problems of piecewise affine (PWA) systems, with ℓ1 or ℓ∞ stage cost. Existing works, such as [1], establish that the resulting value function is PWA in the state. However, existing results do not analyze whether the value function is a proper PWA function, i.e., with a finite number of affine pieces over compact sets, or whether the number of pieces can be infinite. We show that the latter case is indeed possible by means of an explicit example, which is also instrumental in establishing rigorous and easily verifiable sufficient conditions that ensure that the resulting value function is a proper PWA function. Our theoretical findings complement well-known results, e.g., the linear-quadratic case, and serve as support for recent learning-based control schemes for PWA systems. Throughout the paper, the proposed results are illustrated by means of a numerical example. 

Index Terms —Piecewise affine systems, dynamic programming, constrained optimal control. 

I. I NTRODUCTION 

Over the last decades, significant interest has been devoted to the analysis and control of piecewise affine (PWA) systems [2], which are a special class of hybrid systems [3] where the function describing the dynamics is piecewise affine in the state and the input. Their popularity stems from the ability to model dynamical systems with hybrid dynamics (e.g., energy storage systems [4]), or to approximate nonlinear systems with a user-defined level of accuracy [5]. In addition, several classes of hybrid systems, including mixed-logical dynamical, max-min-plus-scaling, and linear complementarity systems, have been proved to be equivalent to PWA systems (see [6] for an overview of the aforementioned models and their equivalence). A variety of strategies have been studied for optimal control of constrained PWA systems, ranging from dynamic pro-gramming (DP) [1], to model predictive control [7], [8], and learning-based methods [9]. In particular, recent approaches leveraging learning algorithms [9], [10], rely on the structure of the value function to ensure adequate quality of the ap-proximation. For example, it is known from [11] that the value function of a constrained LQR problem is piecewise quadratic,

Similarly, [1] states that the value function of a constrained optimal control problem for PWA systems with ℓ1 or ℓ∞ stage cost has a PWA structure; therefore, [9] employs a PWA neural network to approximate it. Due to the importance of these results in recent learning-based frameworks, this technical note presents a detailed analysis of the value function for constrained optimal control of PWA systems with ℓ1 or ℓ∞ stage cost. Although the value function is known to be PWA with a finite number of pieces for finite-time optimal control problems, we show that this is not necessarily true for the infinite-horizon case, unless additional sufficient conditions are specified. Our contributions are summarized as follows:  

> •

We consider constrained infinite time optimal control (CITOC) of PWA systems with ℓ1 or ℓ∞ stage cost. We construct an example for which we can calculate the resulting value function in closed form, showing that it has infinitely many affine pieces on a compact set.  

> •

The proposed example unveils that this structural property of the value function is related to the controllability of the system and to the design of the cost matrices. Hence, based on these insights, we derive explicit and easily verifiable sufficient conditions such that the value function of a CITOC problem for a PWA system with an 

ℓ1 or ℓ∞ stage cost has a proper PWA structure, i.e., with a finite number of affine pieces over compact sets. This study complements related papers (e.g., the well-known linear-quadratic case [11]) and also covers the case of linear systems with ℓ1 or ℓ∞ stage cost. Moreover, it serves as support for learning-based approaches [9], [10] that aim to design function approximators for CITOC problems, while providing guarantees on the quality of the approximation. The paper is organized as follows: Section II recaps the problem setting in [1], Section III proposes an explicit example in which the value function has infinitely many pieces, in Section IV we define sufficient conditions such that this does not occur, and Section V concludes the paper.

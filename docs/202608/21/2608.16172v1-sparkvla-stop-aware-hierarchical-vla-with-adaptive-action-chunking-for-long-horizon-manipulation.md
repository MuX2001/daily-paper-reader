## 摘要
在分层视觉-语言-动作（VLA）系统的每个重新观察点，必须做出两个接口决策：何时终止当前子任务以及执行所提议的动作块到何种程度。这两个决策相互依赖——最优停止点取决于执行器计划做什么，而最优执行长度取决于子任务边界在哪里——然而现有架构将它们孤立地评估，这种不对称性是任何模块单独都无法克服的。我们提出SparkVLA，一种停顿感知的分层VLA，通过将两个决策表述为单一排序来解决这种相互依赖：Stop在统一候选集中与每个动作前缀长度竞争，系统选择得分最高的选项，消除了阈值调整，并且只需要离线序数偏好。锚定条件上下文编码模块缓存历史感知的子任务锚定编码、起始状态记忆和目标语义，指导视觉标记剪枝朝向任务相关区域；停顿感知动作前缀选择头通过块边界处的全自注意力对所有候选进行评分以提高效率。在RoboCerebra上，SparkVLA达到47.12%的成功率，超过官方分层基线30.57%，超过最强可复现方法26.83%。在多步任务上的真实机器人实验进一步验证了这些增益在物理硬件上的有效性。

## Abstract
At every re-observation point in a hierarchical Vision-Language-Action (VLA) system, two interface decisions must be made: when to terminate the current subtask and how far to execute the proposed action chunk. These decisions are mutually dependent---the optimal stopping point depends on what the executor plans to do, while the optimal execution length depends on where the subtask boundary lies---yet existing architectures evaluate them in isolation, an asymmetry neither module can overcome alone. We present SparkVLA, a stop-aware hierarchical VLA that resolves this mutual dependency by formulating both decisions as a single ranking: Stop competes against every action-prefix length in a unified candidate set, and the system selects the highest-scoring option, eliminating threshold tuning and requiring only offline ordinal preferences. An Anchor-Conditioned Context Encoding module caches a history-aware subtask anchor encoding onset-state memory and goal semantics, guiding visual-token pruning toward task-relevant regions; a Stop-Aware Action-Prefix Selection head scores all candidates via full self bnattention at chunk boundaries for efficiency. On RoboCerebra, SparkVLA achieves 47.12% success rate, surpassing the official hierarchical baseline by 30.57% and the strongest reproducible method by 26.83% Real-robot experiments on multi-step tasks further validate these gains on physical hardware.

## 论文详细总结

### 1. 论文的核心问题与整体含义（研究动机与背景）

- **研究背景**：VLA（视觉-语言-动作）模型在机器人操作上展现了强大的泛化能力，但大多在短轨迹段上训练，难以在长时程任务中组合多个技能。为此，分层 VLA 架构采用“高层 VLM 规划器 + 低层 VLA 执行器”的双层结构，以应对多步操作。
- **核心问题**：在分层 VLA 系统的每个重观测（re-observation）边界，系统需要同时做出两个接口决策：
  - **何时终止当前子任务**（termination condition）；
  - **执行所提议的动作块到何种长度**（execution horizon）。
- **关键洞察**：这两个决策存在**相互依赖关系**——最优停止点取决于执行器下一步计划做什么；最优执行长度取决于子任务边界在哪里。然而，现有架构（如二进制停检器、VLM 预测长度、DEHP、ACH、AQC、AAC 等）均将二者**孤立评估**，导致结构性的信息不对称，造成次优表现。
- **论文主张**：两个决策本质上都归结为同一个评估问题——“从当前状态出发，所提议的动作块对当前子任务的完成程度如何”，因此可以统一为**单一排序问题**。SparkVLA 在此洞察上构建，将 Stop 与所有动作前缀长度放入同一候选集竞争，以消除模块间信息隔离和阈值调参需求。

### 2. 论文提出的方法论

#### 2.1 核心思想

- 构建统一候选集 C = {0, 1, ..., H}，其中 0 代表 Stop，n ≥ 1 代表执行动作块 At 的前 n 个动作。
- 通过一个共享的选择器 f_sel 对所有候选进行评分，选取得分最高者作为决策结果。
- 训练只需**离线序数偏好**（ordinal preferences），无需在线强化学习或奖励信号。

#### 2.2 整体架构

SparkVLA 从预训练的 π0.5 VLA 派生两个分支：
- **高层分支**：保留 π0.5 的 VLM 骨干，承担子任务生成与候选评分；
- **低层分支**：使用完整 π0.5 VLA（含动作专家）产生动作块。

#### 2.3 关键技术模块

**(a) Anchor-Conditioned Context Encoding（锚定条件上下文编码）**

- **历史感知子任务锚（History-Aware Subtask Anchor）**：在子任务开始时，从规划器的倒数第二层提取原始锚表示（raw anchor），并通过自注意力与之前的锚历史池融合，形成携带跨子任务上下文信息的 αk。该锚点缓存了起始状态记忆与目标语义，只在子任务开始时计算一次。
- **锚定引导视觉剪枝（Anchor-Guided Visual Pruning）**：利用 Grid-Sampler 可微算子，基于锚点 αk 预测 K 个归一化 2D 采样坐标，从密集视觉 token 中裁剪出任务相关区域，将每相机视觉序列从 N 降至 K 个 token。
- **高层隐藏特征编码**：将剪枝后的视觉 token 与本体感知状态和子任务命令嵌入拼接，送入高层 VLM 骨干的前 ℓm 层（带 LoRA），得到当前决策点的多模态上下文特征 mt。

**(b) Stop-Aware Action-Prefix Selection（停顿感知动作前缀选择）**

- **统一候选评分**：评分头是一个全自注意力 Transformer，将 Stop 嵌入、锚点上下文、多模态上下文以及所有动作前缀候选 token 放入同一序列进行注意力交互。
  - 每个长度 n 的候选 token 由该前缀的终止动作嵌入 + 学习到的长度嵌入初始化；
  - 全自注意力使各候选能感知完整动作块内容，实现联合评估。
- **统一排序目标（Stop-Aware Ranking Objective）**：结合两个损失：
  - **成对排序损失**（Lrank）：根据离线轨迹的完成边界 τ，为每个候选赋予序数优先级 ρi，对优先级不同的候选对做二元交叉熵；
  - **停顿感知辅助损失**（Lstop）：通过 Stop 得分与继续执行得分的 log-sum-exp 对比，强化终止边界的梯度信号。
- **推理规则**：直接取得分最高的候选执行，无需额外阈值或独立推理路径。

**(c) 推理调度**

- 选择器仅在块边界处调用（而非每步），结合子任务命令缓存，实现约 4.14 Hz 的边界更新频率（41.4 动作步/秒），保留 π0.5 约 88% 的吞吐量。

### 6. 论文的主要结论与发现

- **RoboCerebra**：SparkVLA 平均成功率达 **47.12%**，超过独立 π0.5 达 34.83 个百分点，超过官方层次基线 HPE 达 30.57 个百分点，超过最强开源层次方法 Mem-0 达 26.83 个百分点；
- **性能来源**：动态观测条件下 +34.78%、记忆执行条件下 +47.69%，验证了自适应短前缀（更频繁重观测）与历史增强锚（避免重访已完成目标）的价值；
- **统一候选集的收益**：将 Stop 纳入统一排序后，Stop Acc. 从 80.37% 提升至 96.65%（+16.28 个百分点），SR 从 42.53% 提升至 47.12%，证明停止决策与前缀选择之间存在双向促进作用；
- **执行器泛化**：以 OpenVLA-OFT 和 SmolVLA 为低层执行器时，增益分别达 +22.47% 和 +22.52%，证明收益来自统一接口设计而非特定模型配对；
- **LIBERO**：平均成功率 98.5%，在 LIBERO-Long 上超越最强基线 5.6 个百分点；
- **真实机器人**：平均成功率 69.3%，超过 π0.5 达 21.3 个百分点，其中 12 子任务的 Tea Preparation 任务增益最大（+30.0%）。

### 8. 不足与局限

- **任务范围有限**：仅在桌面操作、固定物体类别下评估，未涉及开放世界、移动操作或更复杂的人机交互场景；
- **离线训练假设**：选择器完全依赖离线数据训练，无法在线自适应；失败 rollout 的优先级设计（所有前缀并列优于 Stop）是一种启发式近似，可能不适用于极端分布偏移；
- **边界扰动局限**：τ′ 的扰动范围仅 {−2, −1, 0, 1, 2}，对标注噪声的鲁棒性仍有限；
- **物理实验保真度**：真实实验中以塑料珠替代水，无法完整验证倒水操作的真实物理特性；
- **算力信息不完整**：未报告训练总时长、数据采集成本、推理延迟的具体硬件分解，可复现性细节仍有提升空间；
- **LIBERO 对比不足**：LIBERO 实验缺少与分层 VLA 基线的直接对比，说服力略弱；
- **大规模验证缺失**：真实机器人只用一个平台、一个操作场景族，跨平台、跨机械臂的验证不足。

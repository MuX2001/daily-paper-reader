## 摘要
视觉-语言-动作（VLA）模型近年来在机器人操作中取得了令人瞩目的性能。然而，现有基准主要评估静态操作任务的泛化能力，很大程度上忽视了动态交互场景。为解决这一问题，我们提出了ReflexBench，一个面向反应关键操作的基准。ReflexBench包含六个动态任务，并引入了一种评估框架，该框架将模拟器步进与机器人控制解耦，同时支持同步和异步推理下的可配置延迟。基于ReflexBench，我们提出了ReflexVLA，一种为反应关键操作设计的高效VLA模型，无需大规模机器人数据预训练。ReflexVLA通过潜在未来预测和视觉主干内的多帧时间融合增强了时间推理能力，同时通过批量视觉编码和CUDA Graph重放降低了部署延迟。实验表明，ReflexVLA持续提升了动态操作性能，同时在标准静态操作基准上保持了竞争性的准确性，真实世界实验进一步证明了其在实际部署条件下的有效性。项目网站：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. Project website: https://reflexvla.github.io

## 二、论文提出的方法论

### 2.1 ReflexBench：延迟感知的动态操作基准

- 包含 6 个代表性动态任务：
  - Conveyor Belt Pick-and-Place（传送带抓放）
  - Ball Catching（接球）
  - Whack-a-Mole（打地鼠）
  - Rolling Ball Interception（滚动球拦截）
  - Ball Throwing（投球）
  - Rotating Peg Insertion（旋转销钉插入）
- 数据收集：采用基于规划的分阶段数据流水线（如预对齐→目标跟踪→定时插入），复杂动力学场景则训练任务专用强化学习策略生成示范。

**延迟感知评估框架**
- 将仿真器步进与机器人控制解耦，使环境动力学独立于策略计算演化。
- 支持两种推理范式：
  - **同步推理**：推理期间环境暂停，模拟推理阻塞部署。
  - **异步推理**：推理与动作执行重叠，更新下一控制周期的动作。
- 延迟可通过"延迟阻塞机制"手动设置，或根据实际策略延迟与实时因子（RTF）换算：
  - RTF = t_sim / t_wall，用于将真实推理延迟转换为仿真中的等效延迟。

### 2.2 ReflexVLA：高效预测性 VLA 模型

ReflexVLA 基于紧凑型 VLA 架构（VLA-Adapter 为骨干），由 DINOv2+SigLIP 融合视觉编码器、Qwen2.5-0.5B 语言骨干与连续回归动作头组成，引入三大关键设计：

**1. 潜在未来预测（Latent Future Prediction）**
- 使用冻结的 DINOv3 编码器提取未来观测的语义特征作为预测目标：
  - y_{t+i} = φ_DINOv3(o_{t+i})，y ∈ R^1024
- 在输入序列中追加 H 个可学习"未来 token"（H=动作块大小），每个 token 对应动作块中的一个未来控制步。
- 预测头将未来 token 的隐藏表示投影到 DINOv3 特征空间，通过掩码余弦相似度损失优化：
  - L_future = Σ m_i [1 − cos(ŷ_{t+i}, y_{t+i})] / Σ m_i
- 总损失：L = L_act + λ_future · L_future（λ=0.05）
- 优点：仅增加 H 个 token，计算开销可忽略。

**2. 多帧时间融合（Multi-Frame Temporal Fusion）**
- 动机：单帧观测无法捕捉运动动力学，但多帧视觉 token 直接拼接会导致语言模型侧计算量剧增。
- 做法：
  - 在视觉骨干的**中间层特征**上执行时间融合（中间层比深层保留更丰富的运动线索）。
  - 对每个视图和 patch 位置，将 T 帧特征构成时间轨迹，经层归一化、下投影和时序位置编码后，送入因果 MHA 层。
  - 融合结果与当前帧的**最终层特征**相加，形成增强表示。
  - 关键优势：融合在视觉骨干内完成，语言模型消费的视觉 token 数量与单帧设置完全相同，避免额外开销。

**3. 推理延迟优化（Inference Latency Optimization）**
- **批量视觉编码**：将 V×T 张图片合并为一次视觉骨干前向传播，减少框架级调度开销，提高 GPU 利用率。
- **CUDA Graph 重放**：将完整推理管线捕获为 CUDA Graph（视觉编码→时间融合→多模态投影→语言模型→动作预测），部署时仅需将新观测拷贝到预分配缓冲区并重放图表，消除重复内核调度开销。

## 六、主要结论与发现

1. **推理范式影响显著**：低频率下异步推理因观测-动作失配而表现差；高频率下异步推理因连续执行而优于同步推理。
2. **chunk/horizon 组合至关重要**：大 chunk + 短 action horizon + 高异步频率获得最佳性能。
3. **ReflexVLA 动态性能领先**：在 ReflexBench 上平均成功率 50.4%，超越所有基线（对比最优 PUMA 50.2%，但 ReflexVLA 参数量仅为 1/4），较骨干 VLA-Adapter 提升 20.1 个百分点。
4. **静态性能保持竞争力**：在 LIBERO 上达到 97.2%，与最佳基线（VLA-Adapter 97.3%）相当，说明动态设计不损害静态泛化能力。
5. **组件消融验证有效性**：
   - 冻结特征做未来预测目标优于可训练目标（62.8% vs 4.9%）。
   - 中间层时序融合优于最终层融合（71.7% vs 68.2%）。
   - 延迟优化从 125.1ms 降至 65.0ms，同时提升成功率至 73.8%。
6. **真实场景验证**：ReflexVLA 在机械臂真实任务上全面优于 SmolVLA，与 PUMA 相比在参数量小得多的情况下取得可比甚至更好的结果。

## 七、优点

1. **问题定位精准**：指出现有 VLA 评测忽视"推理延迟 + 未来预测"的双重挑战，切入角度新颖且有实际价值。
2. **基准设计创新**：ReflexBench 解耦仿真步进与策略控制，支持可控延迟注入，并引入 RTF 将真实延迟映射到仿真，**显著提高了评测信度**。

   - 多帧时间融合在视觉骨干内完成，语言模型侧 token 数不增加；

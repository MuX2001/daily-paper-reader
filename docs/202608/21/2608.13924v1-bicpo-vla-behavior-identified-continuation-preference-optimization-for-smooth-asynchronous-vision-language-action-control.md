## 摘要
请求到切换的间隙有三个耦合来源：请求时刻关于预期行为的模糊性、动作生成过程中积累的物理状态漂移，以及新动作最终接管控制时残留的不兼容性。BICPO-VLA依次解决这些问题。首先，一个指令感知的因果历史编码器识别命令和当前任务进度所支持的行为。其次，顺序Haar子空间生成将每个动作块分解为互补的成对脚手架系数和残差系数，从而实现两个专门的生成阶段及精确重构。通过减少原始动作空间中的迭代细化，它缩短了机器人在新块可用之前继续移动的间隔。最后，BICPO将已知的传出动作滚动到实际切换状态，并在行为匹配的候选者之间应用参考相对Flow-DPO，使生成的动作块适应剩余的请求到切换不匹配，而不改变其预期行为。

## Abstract
The request-to-handoff gap has three coupled sources: ambiguity about the behavior intended at request time, physical-state drift accumulated during action generation, and residual incompatibility when the new action finally assumes control. BICPO-VLA addresses them in sequence. First, an instruction-aware causal history encoder identifies the behavior supported by the command and current task progress. Second, sequential Haar subspace generation decomposes each action chunk into complementary pairwise scaffold and residual coefficients, enabling two specialized generation stages followed by exact reconstruction. By reducing iterative refinement in the original action space, it shortens the interval over which the robot continues moving before the new chunk becomes available. Finally, BICPO rolls the known outgoing actions to the actual handoff state and applies reference-relative Flow-DPO among behaviorally matched candidates, adapting the generated chunk to the remaining request-to-handoff mismatch without changing its intended behavior.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在异步视觉-语言-动作（VLA）控制中，机器人执行上一个动作块（outgoing chunk）的同时，模型正在推理下一个动作块。新动作块在一种运动上下文中被请求，却在另一种状态中接管控制，由此产生 **“请求到交接的间隙”（request-to-handoff gap）** ，导致边界跳跃（boundary jump）或运动趋势断裂（motion-trend break）。

- **问题来源（三个耦合因素）**：
  1. **行为意图模糊**：请求时刻，指令和当前任务进度所能支持的具体行为不明确；
  2. **物理状态漂移**：动作生成过程中，机器人仍持续运动，实际交接状态与请求时刻的状态产生偏差；
  3. **残留不兼容**：新动作块最终接管时，与当前实际交接状态存在残余的不匹配。

- **关键观察（核心洞见）**：一个“行为”定义的是一族动作实现（behavior-conditioned action fiber），而非唯一轨迹。该族内成员共享任务语义，但局部运动与交接兼容性各有不同。现有方法（记忆增强、高效生成、异步策略等）未显式联合区分“行为身份”“实现结构”和“交接条件化选择”这三项约束各异的决策，作者将其作为核心空白加以解决。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 总体架构：三阶段分解

BICPO-VLA 将异步控制分解为三个串行阶段，分别对应三类约束：

| 阶段 | 解决的问题 | 核心机制 |
|------|-----------|---------|
| 行为识别 | 确定指令与任务进度所支持的语义行为 | 指令感知因果历史编码器 + 行为记忆 |
| 实现结构 | 在保持动作表达力的情况下组织动作实现 | 顺序 Haar 子空间生成（scaffold + residual） |
| 交接选择 | 适应推断期间的状态漂移 | 行为识别延续偏好优化（BICPO） |

### 2.2 行为识别：指令接地（Instruction-Grounded Behavior Identification）

- 视觉 token 通过 **注意力路由** 先经过语言特征调制，再进入因果历史编码器，确保视觉证据按指令相关性被筛选；
- 历史编码器 `Bϕ`（基于因果 Mamba + 视觉-运动互校准）聚合路由后的观测与已执行命令，得到行为状态 `z_r`；
- 相条件解码器结合检索到的长时记忆 `m_r`，输出动作先验 `μ_r`；
- 共享条件 `b_r ≡ (ℓ, z_r, m_r, μ_r)` 定义了行动纤维（action fiber）`F_r`。

关键设计：**语言介入先于时序聚合**，使历史状态保持指令专属。

### 2.3 Haar 结构化动作实现

- 对偶数长度动作块 `A ∈ R^{H×d_a}` 做单层 Haar 变换：

```
c_i = (a_{2i} + a_{2i+1})/√2       （脚手架，捕获成对运动水平）
d_i = (a_{2i} − a_{2i+1})/√2       （残差，恢复对内变化）
```

- 正交变换保证 **精确重构**：`A = W_H^⊤ [C; D]`，无损；
- 两个生成阶段共享同一个流匹配专家 `F_θ`，但使用不同的阶段嵌入（`e_C`/`e_D`）和掩码，**先生成脚手架，再以脚手架为条件生成残差**，形成“粗趋势 → 局部修正”的有序依赖；
- 训练损失 `L_struct` 使用 stop-gradient，保持两阶段分工。

### 2.4 交接条件：滚动已知动作（Rolled Handoff Context）

- 通过冻结的动作状态模型，将已知传出命令 `U_k^r` 从前一推断时刻逐步滚动到实际交接状态：

```
h_{j+1} = R_act(h_j, u_j),   j = r, …, r+k−1
```

- 交接条件 `g_k = P_ψ([LN(h̄_{r,k}); LN(Δh_{r,k})])` 同时编码 **绝对转移上下文** 与 **推断期间位移**，区分“相似交接状态的不同到达趋势”。

### 2.5 BICPO 延续偏好优化

- 在相同行为条件 `χ_{r,k}` 下，用不同流噪声采样两个候选动作，构造 **同纤维候选对**；
- 延续代价包含：
  - 零阶交接跳跃：`J_jump(A) = ‖a₀ − u_{r+k−1}‖²_W`
  - 一阶趋势失配：`J_trend(A) = ‖(a₀ − u_{r+k−1}) − (u_{r+k−1} − u_{r+k−2})‖²_W`
- 偏好代价较低者，但要求 **超过一定边际阈值**；
- **参考相对 Flow-DPO**：结合两个 Haar 阶段的能量，比较策略候选相对于冻结参考模型的偏好变化：

```
Δ_θ = [E_θ(A⁻) − E_θ(A⁺)] − [E_ref(A⁻) − E_ref(A⁺)]
L_pref = −q log σ(βΔ_θ)
```

- 仅更新 `P_ψ`、`W_g` 及选定的专家参数，**冻结语义通路、滚动模型、Haar 变换和参考专家**，防止平滑优化改变行为意图或诱导“不作为”；
- 该 DPO 目标可迁移至 π0.5、Legato、RTC，无需附加 BICPO-VLA 的编码器、Haar 生成器或交接投影器，仅使用宿主策略自身的原生条件化流能量。

6. **核心观点**：异步控制应同时优化“执行正确行为”和“行为以何种方式接管控制”——平滑实现本身是值得单独评估的目标。

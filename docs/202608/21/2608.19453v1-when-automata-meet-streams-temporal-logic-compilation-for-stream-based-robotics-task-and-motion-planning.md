## 摘要
基于流的机器人任务与运动规划（TAMP）将离散符号规划与动态生成的连续几何参数（如位姿、抓取和轨迹）相结合。然而，基于流的规划器通常仅考虑目标可达性，而长时域任务还要求遵守时间规范，如安全关键的排序、不变性和活性约束。目前尚无方法能在基于流的求解器中强制执行此类时间约束，因为流在规划过程中通过迭代流细化循环生成不断扩展的几何对象集，这使得现有时间逻辑编译技术无法兼容。为此，我们提出带令牌销毁的同步动作监控（SAM-TD），一种在基于流的TAMP中强制执行有限迹上的任意线性时间逻辑（LTL_f）规范的编译方法。SAM-TD将任意LTL_f约束转换为自动机，并将回归后的自动机守卫嵌入到动作模式中，这些模式在规划开始前预先指定。通过这种方式，SAM-TD能够处理规划期间由流生成的对象，从而无需枚举固定对象集或修改底层规划器。在搜索过程中，SAM-TD同步更新自动机状态，并使用所有自动机共享的有效性令牌来剪除违反约束的分支。我们证明SAM-TD支持在计划搜索期间通过迭代流细化动态生成的流对象。实验结果首次展示了在三个机器人PDDLStream环境中，基于流的TAMP在LTL_f约束下的运行。此外，在标准离散PDDL基准测试中，SAM-TD与最先进的时间约束编译方法相比具有竞争力。

## Abstract
Stream-based robotics Task and Motion Planning (TAMP) integrates discrete symbolic planning with dynamically generated continuous geometric parameters, such as poses, grasps, and trajectories. However, stream-based planners typically reason only about goal reachability, whereas long-horizon tasks also demand adherence to temporal specifications, such as safety-critical ordering, invariance, and liveness constraints. No methods currently exist to enforce such temporal constraints for stream-based solvers because streams generate an expanding geometric object set via iterative stream refinement loops during planning, rendering existing temporal-logic compilation techniques incompatible. We therefore present Synchronous Action Monitoring with Token Destruction (SAM-TD), a compilation method that enforces arbitrary Linear Temporal Logic over finite traces ($\textrm{LTL}_f$) specifications in stream-based TAMP. SAM-TD translates arbitrary $\textrm{LTL}_f$ constraints into automata and embeds regressed automaton guards into action schemas, which are pre-specified before planning begins. By doing so, SAM-TD can handle objects generated by streams during planning, thus circumventing the need to enumerate a fixed object set or modify the underlying planner. During search, SAM-TD synchronously updates automaton states and uses a validity token shared across all automata to prune constraint-violating branches. We show that SAM-TD supports dynamically generated stream objects from iterative stream refinements during plan search. Experimental results provide the first ever demonstration of stream-based TAMP under $\textrm{LTL}_f$ constraints in three robotics PDDLStream environments. Furthermore, on standard discrete PDDL benchmarks, SAM-TD is competitive with state-of-the-art temporal-constraint compilation methods.

**核心冲突：**
- 现有 LTL_f 编译技术（如 Baier & McIlraith 2006、TCORE、LiftedTCORE、LCC 等）都假设对象集合是**固定且有限**的，因此**无法直接用于流式 TAMP**——流在规划中不断生成新对象，这一基本假设被打破。
- 预采样有限的几何对象库也不可行：所需对象往往是计划依赖的，且大规模采样计算代价极高。

## 2. 方法论：SAM-TD 编译框架

### 2.1 核心思想

**Synchronous Action Monitoring with Token Destruction (SAM-TD)**，即“带令牌销毁的同步动作监控”。将时序约束的监控逻辑直接编译进**提升的动作模式（lifted action schemas）**，使其能处理规划期间流动态生成的对象。

### 2.2 关键步骤（对应 Algorithm 1 流程）

1. **LTL_f → DFA 转换**：将每个约束 φ_j 通过 LTLf2DFA + MONA 工具转为确定型有限自动机（DFA），得到带守卫（guard）的状态转移图。
2. **初始状态预评估**：在编译时，先让 DFA 读取初始规划状态 L(s₀)，得到监控起始状态 q_start；若起始即为吸收态（sink），则问题不可解。
3. **提升动作回归（Lifted Action Regression）**：
   - 每个 DFA 转移守卫 g_kℓ 约束的是**动作后状态**，需要回归为**动作前状态**的等价条件。
   - 为每个约束中提及的具名对象 o 引入**静态身份谓词 Is-o(·)**，并添加初始事实 Is-o(o)，用于在提升层面实现“参数与具名常量是否相等”的判定（因为流式实例化层不支持显式等式检查）。
   - 回归公式：Reg_a(p(ō)) = Add ∨ (p(ō) ∧ ¬Del)，组合守卫按布尔结构递归回归。
4. **动作同步监控更新（嵌入条件效应）**：
   - 对每个非自循环且非 sink 的转移，添加条件效应：`(M_kj ∧ Reg_a(g_kℓ)) ▷ (¬M_kj ∧ M_ℓj)`，在动作执行时同步推进监控状态。
   - 对进入 sink 状态的转移，添加条件效应：`(M_kj ∧ Reg_a(g_k⊥)) ▷ (¬Valid)`——即**令牌销毁**。
5. **Valid 令牌机制（Token Destruction）**：
   - Valid 是共享的流式谓词，初始为真（仅当所有监控不在 sink 状态），任何动作都不能重加。
   - 一旦某动作使任一 DFA 进入 sink 状态，Valid 被永久删除，导致目标不可达。
   - 标准删除松弛启发式（如 hFF）会将该分支判为无穷代价，在几何采样前即被剪除。
6. **目标增强**：G′ = G ∧ Valid ∧ ∧_j Acc_j，其中 Acc_j 要求每个 DFA 终止于接受状态。

### 2.3 三大流兼容性需求的设计回应

| 需求 | SAM-TD 的解决方案 |
|------|-------------------|
| 模式级、流兼容的编码 | 不引入新参数、新前置条件、等式检查，只在提升模式上附加条件效应；编译与实例化层语义兼容 |
| 保持动作骨架 | 不插入任何同步/簿记动作，一个域动作对应一个监控步进，不改变 X（next）等步态敏感算子语义 |
| 采样感知的剪枝 | 令牌销毁使违规分支在符号搜索阶段即被 hFF 判死，不进入几何采样阶段 |

## 3. 实验设计

### 3.1 流式 TAMP 实验（PDDLStream 环境）

**三个环境：**
1. **Kitchen**（改编自 Garrett et al. 2020）：厨房操作任务，含杯、勺、奶油、糖、搅拌器、积木等对象。
2. **Tabletop Manipulation**（源自 Wu et al. 2025）：桌面操作，四个色块需要从托盘移至目标区域。
3. **ZoneSort**（自建环境）：六块积木需要分区域排序。

**三个流式实验：**
- **实验 1（任意 LTL_f 约束缩放）**：每个环境有一个任务特定的约束目录（安全、优先、完成三类），五种固定种子顺序逐个叠加约束，验证编译时间随约束数线性增长。
- **实验 2（对抗性约束缩放）**：设计专门排斥无约束参考计划的对抗性 LTL_f 约束（如反转事件对的 `(¬e_a) U e_b` 和安全不变量），强制反复重规划。
- **实验 3（消融实验）**：对比 SAM-TD 与 **SAM-PB**（前置条件阻塞变体，将负回归守卫并入动作前置条件）。同一组对抗公式、规划器、预算、内存限制。求解器为 PDDLStream 的 **Adaptive 算法**，所有返回计划重新回放验证。

### 3.2 经典 PDDL3 基准实验

- **数据集**：6 个已发布的 PDDL3 任务，来自三个领域：Openstacks（p61/p75）、Rovers（p60/p90）、Storage（p19/p24），每个任务强制前 k 个轨迹约束，5 个不同层级，Storage 最高 k=128。
- **对比方法（7 个）**：SAM-TD、BM06（Baier & McIlraith 2006）、TB15（Torres & Baier 2015）、TCORE（Bonassi et al. 2021）、LiftedTCORE、LCC（Mantenoglou et al. 2026）、Plan4Past（De Giacomo et al. 2022）。
- **预算**：编译+搜索 180 秒，内存 3 GiB，lama-first 启发式规划器。

## 6. 主要结论与发现

1. **首个支持流式 TAMP 中 LTL_f 约束的编译方法**：SAM-TD 在不修改底层流式求解器、不枚举固定对象集的前提下，保证返回计划满足所有 LTL_f 约束。
2. **编译时间接近线性增长**：当 DFA 和守卫规模有界时，编译代价关于约束数 m 线性，实测约每约束 30–80 毫秒。
3. **接地（grounding）是主要瓶颈**：端到端开销中，Fast Downward 翻译（接地）占主导，搜索与采样成本保持平稳，验证了令牌破坏机制在采样前即剪除违规分支的效果。
4. **令牌破坏机制远优于前置条件阻塞**：SAM-PB 因前置条件中“合取之析取”导致 DNF 范式化后操作符爆炸（最多 d^m 个副本），在小约束数即耗尽预算或 3 GiB 内存；SAM-TD 的条件效应则线性接地。这是实验 3 的核心发现。
5. **经典 PDDL 上竞争力强**：SAM-TD 在 30/30 个任务-约束单元全部求解，与 BM06、TCORE、Plan4Past 持平，超越 TB15、LiftedTCORE、LCC；在 11 个所有方法均求解的实例上，几何平均时间排名第二（1.88 秒）。

## 7. 优点

- **填补空白**：首次解决“流式 TAMP + 任意 LTL_f 约束”这一此前完全无人攻克的组合问题，具有明确的新颖性和实用价值。
- **设计巧妙**：
  - 将约束监控嵌入**提升模式**而非接地操作符，从根本上绕开对象集动态扩展的难题。
  - **身份谓词** Is-o 在流式实例化层不允许显式等式的约束下，巧妙实现了参数-常量匹配语义。
  - **Valid 令牌破坏**用极简的“一删永删”机制把约束违反转化为删除松弛启发式可判别的死端，既优雅又高效。
- **理论讨论扎实**：附录 B 对编译的正确性（精确性）、流兼容性、骨架保持和剪枝性质进行了系统性的结构化论证。

- **通用性好**：不依赖特定规划器，任何 PDDLStream 算法（Incremental / Focused / Binding / Adaptive）都可直接使用编译后的任务。

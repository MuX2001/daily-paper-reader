## 摘要
部署在现实环境中的机器人策略应具备持续学习新任务而不遗忘已有行为的能力。对抗这种灾难性遗忘的常见方法是使用先前学习任务数据的回放缓冲区来训练新任务数据。尽管该缓冲区通常从所有先前经验中随机采样，但我们表明，其中一小部分经验在锚定过去性能方面贡献巨大。我们将这些经验称为记忆锚点。我们在新任务观测的表示塌缩到旧任务观测的表示上的区域中识别记忆锚点，即使这些任务需要相互冲突的动作，例如必须以新方式操作熟悉的物体时。在该区域复述旧数据在防止过去任务知识被破坏性覆盖方面发挥着关键作用，充当了这一关键的记忆锚点角色。在采样缓冲区之前仅排除10%的记忆锚点，就会导致LIBERO基准套件上的灾难性遗忘增加4.5倍以上。相反，用记忆锚点丰富回放缓冲区可以将高冲突任务遗忘减少63%，并使真实机器人上的两个任务序列能够成功进行持续学习。视频和其他可视化内容可在 https://robot-adaptation.github.io/MemoryAnchors 找到。

## Abstract
Robot policies deployed in the wild should have the capability to continually learn new tasks without forgetting existing behaviors. A common approach to combat such catastrophic forgetting is to train on new task data with a replay buffer of previously learned task data. Although this buffer is commonly sampled randomly from all prior experiences, we show that a small set of these experiences contributes greatly in anchoring past performance. We call these experiences Memory Anchors. We identify Memory Anchors in regions where representations of new-task observations collapse onto those of old-task observations even though the tasks require conflicting actions, like when a familiar object must be manipulated in a new way. Rehearsing old data in this region plays a key role in preventing destructive overwriting of past task knowledge, serving as this critical Memory Anchor role. Excluding only 10% Memory Anchors before sampling the buffer leads to more than a 4.5x increase in catastrophic forgetting on the LIBERO benchmark suites. Conversely, enriching the replay buffer with Memory Anchors can decrease high-conflict task forgetting by 63% and enables successful continual learning of two task sequences on a real robot. Videos and additional visualizations can be found at https://robot-adaptation.github.io/MemoryAnchors

# 论文总结：Memory Anchors for Continual Robot Learning

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：真实环境中部署的机器人策略需要能够持续地学习新任务，同时不遗忘已学会的旧行为。这种“持续学习”面临的核心挑战是**灾难性遗忘**——在适应新任务数据时，旧任务的知识被覆盖或破坏。
- **现有方法**：对抗遗忘的常用方法是**经验回放（Experience Replay, ER）**，即在训练新任务时联合训练一个由过去任务数据组成的回放缓冲区。通常该缓冲区从所有历史经验中**随机采样**。
- **核心发现**：本文发现，随机采样的缓冲区中，**一小部分旧经验对维持过去任务性能起着不成比例的关键作用**。这些经验被称为 **Memory Anchors（记忆锚点）**——它们位于新旧任务观测表征高度重叠、但所需动作相互冲突的区域（例如熟悉的物体需要以新方式操作）。重放这些关键旧数据能有效防止旧知识被破坏性覆盖。
- **整体含义**：回放缓冲区的效能高度依赖于其中是否包含、以及包含多少记忆锚点。简单地随机采样可能遗漏这些关键样本，而有针对性地利用它们可以显著缓解灾难性遗忘，为持续机器人学习提供了更高效的缓冲区采样策略。

## 2. 方法论

### 核心思想
识别新旧任务间“表征重叠但动作冲突”的临界区域，从历史数据中提取锚定旧任务性能的 **Memory Anchors**，并将其加入回放缓冲区，从而提高持续学习的稳定性。

### 三阶段提取流程（算法1）
1. **状态表征重叠检测（Step 1）**：
   - 将新任务数据输入旧策略 π^(n-1)_θ 的观测潜空间，计算每个新任务样本到所有旧任务样本的潜伏距离。
   - 使用最近邻、1%、5%、10% 分位数等统计量表征每个新样本的距离分布，并通过 K-means 聚类将新数据划分为“重叠”和“非重叠”两组，选择平均距离较小的簇作为状态重叠集 D_SID^n。

2. **动作不一致提取（Step 2）**：
   - 对重叠集中的每个样本 (s,a)，向动作加噪得到 ã，再通过旧策略去噪得到预测动作 â（即 â ~ π^(n-1)_θ(·|s,ã)），计算动作偏差 d_π(s,a) = ||â - a||₂。
   - 使用旧任务验证集上的偏差均值和标准差，选择超过 μ+2σ 的新数据作为高动作冲突集 D_OD^n。该“噪声-去噪”策略可避免动作多模态导致的误判。

3. **记忆锚点检索（Step 3）**：
   - 以 D_OD^n 为查询集，在旧策略的潜空间中计算所有旧任务数据到该集合的 k 近邻中位距离。
   - 选择距离最小的 MA 个旧样本作为 Memory Anchors D_Anchor，用于补充回放缓冲区。

### AnchorER 算法
- 将 ER 缓冲区的一部分（如 10% 或 20%）专门用于填充提取到的 Memory Anchors，其余部分仍随机采样以保证状态覆盖多样性。

## 3. 实验设计

### 仿真基准
- **LIBERO**：包含四个任务套件（LIBERO-Long、LIBERO-Goal、LIBERO-Object、LIBERO-Spatial），每个套件10个任务，按顺序训练。使用扩散策略（Diffusion Policy）+ 行为克隆 + ER 正则化。
- 评估指标：主要使用**负向后转移（NBT）**，辅助使用 AUC、前向转移（FWT），并自定义了“任务冲突 NBT”（仅统计高冲突任务对的遗忘）。

### 真实机器人实验
- **OpenJar** 套件：三个外观相似但开盖策略相反的罐子（逆时针、顺时针、直接提起），使用 UMI 采集数据、ARX 机械臂部署，扩散策略以 RGB 为观测。
- **SweaterFold** 套件：双机械臂的语言条件服装折叠任务（折左袖、折右袖、向上折），同样使用 UMI/ARX 平台。

### 对比方法
- **随机 ER 基线**：FixedER（按轨迹采样、不重采样）和 RandER（按 transition 采样、每个新任务后重采样）。
- **其他缓冲区选择方法**：MIR（最大干扰检索）、GSS（梯度样本选择）。
- **消融**：AnchorER-ActionDis（去掉 Step 2 动作不一致，仅用最近邻检索）。
- **VLA 模型**：额外在 π0.5 上测试了记忆锚点的影响。

## 6. 主要结论与发现

1. **经验回放对缓冲区内容敏感**：随机 ER 中某些任务性能波动极大，不同 ER 采样可导致高达 20% 的性能差异。
2. **特定任务冲突主导遗忘**：少数任务对（如“奶油奶酪到碗” vs “碗到盘子”）贡献了大部分 NBT；仅 2 个任务对即可占全部遗忘的 50% 以上。
3. **记忆锚点的关键作用**：从旧数据中排除仅 10% 最优记忆锚点，LIBERO 上 NBT 增加 4.5 倍以上；即使排除 1% 也会导致遗忘上升。
4. **AnchorER 有效降低高冲突遗忘**：加入 10% 记忆锚点后，高冲突任务对的遗忘平均降低 63%；在 LIBERO-Goal（同质任务）上整体 NBT 降低 37%。
5. **VLA 在小缓冲区下同样受影响**：π0.5 在小 ER 缓冲区（如 1000 总记忆或 1% 比例）上仍会出现明显遗忘，且对记忆锚点敏感（排除锚点遗忘增加 2.9 倍，富集锚点降低 22%）。
6. **真实机器人验证**：在 OpenJar 和 SweaterFold 两个高冲突任务套件上，AnchorER 相比随机 ER 显著提升了任务保持能力与塑性平衡，总成功率提高 1.7 倍。
7. **缓冲区内记忆锚点浓度与保留能力正相关**：各方法（AnchorER、MIR、GSS、RandER）的 NBT 与其缓冲区中记忆锚点浓度一致相关，进一步支持记忆锚点的机制假设。

## 7. 优点

- **发现的洞察性强**：首次明确指出回放缓冲区中“少量锚点支撑旧任务性能”的现象，为理解 ER 机制提供了新视角。

- **提取流程可解释**：三步流程（表征重叠 → 动作不一致 → 最近邻检索）清晰直观，且针对扩散策略设计了噪声-去噪的动作一致性评估，处理了动作多模态问题。
- **实验覆盖全面**：从仿真到真实机器人，从随机策略到 VLA，从移除锚点到富集锚点，并通过 MIR/GSS 基线和消融实验验证了方法的有效性与组件的必要性。

## 8. 不足与局限

- **计算开销较大**：每学习一个新任务，都需要在新策略和旧数据上计算潜空间距离及 kNN 检索，对大型历史数据集而言成本较高，可能限制其在实时/在线场景中的应用。
- **依赖内部表征与历史数据**：需要访问策略的潜空间和全部历史训练数据，对不提供内部表征或数据受限的商业模型不可用。

## 摘要
在接触丰富的操作中，接触条件可能在视觉策略更新其动作计划之前发生变化。通过视觉策略重新计算计划会增加延迟，而单独的触觉反馈并不能指明应如何为任务修改正在进行的运动。我们提出了 T-WLA，一种世界-语言-动作架构，利用共享的视觉记忆同时引导动作生成和触觉修正。在每次视觉更新时，视觉分支将当前图像、任务指令和检索到的历史整合到一个视觉记忆中，该记忆为基本动作生成提供条件。同一记忆被缓存给一个轻量级触觉编辑器，触觉编辑器将其与当前动作块和传入触觉结合，预测对未执行动作的残差修正，而无需重新运行视觉分支。未来图像和未来压力预测提供仅训练阶段的监督，促使视觉记忆和触觉特征捕捉与动作生成和修正相关的交互动态。我们在使用 EgoTouch 和 Tachin 的触觉条件下手部运动预测任务，以及四个真实世界灵巧操作任务上评估了 T-WLA。相对于已报告的最强基线，T-WLA 将手指关节 MPJPE 降低了 30%，并在真实机器人操作任务中实现了约 50.0% 的平均成功率。视频和代码可在 https://anonymous-submission-20.github.io/T-WLA.github.io/ 获取。

## Abstract
In contact-rich manipulation, contact conditions can change before a visual policy updates its action plan. Recomputing the plan through the visual policy adds latency, while tactile feedback alone does not specify how the ongoing motion should be revised for the task. We introduce T-WLA, a world-language-action architecture that uses shared visual memory to guide both action generation and tactile correction. At each visual update, the visual branch integrates the current image, task instruction, and retrieved history into a visual memory that conditions base-action generation. The same memory is cached for a lightweight tactile editor, which combines it with the active action chunk and incoming touch to predict residual corrections to unexecuted actions without rerunning the visual branch. Future-image and future-pressure prediction provide training-only supervision, encouraging the visual memory and tactile features to capture interaction dynamics relevant to action generation and correction. We evaluate T-WLA on tactile-conditioned hand-motion prediction using EgoTouch and Tachin, and on four real-world dexterous manipulation tasks. T-WLA reduces finger-joint MPJPE by 30% relative to the strongest reported baseline and achieves an average success rate of approximately 50.0% across real-robot manipulation tasks. Videos and code are available at https://anonymous-submission-20.github.io/T-WLA.github.io/.

## 1. 论文的核心问题与整体含义

- **研究背景与动机**：在接触丰富操作（contact-rich manipulation）中，任务成败高度依赖对物理接触条件的精确管理。视觉策略（vision policy）更新频率较慢，接触条件可能在两次视觉更新之间发生变化，导致动作计划过时。
- **核心矛盾**：
  - 重新通过视觉策略计算动作计划会引入显著延迟；
  - 单独依赖触觉反馈虽然反应快，但触觉本身不足以指明应如何修改正在进行的运动以完成当前任务（缺乏全局任务与场景上下文）。
- **整体含义**：论文旨在解决“慢速视觉策略”与“快速触觉反馈”之间的异步协调问题，提出一种能在视觉更新之间利用触觉信息对正在执行的动作进行轻量、高频修正的架构，从而在不增加视觉推理负担的前提下提升接触丰富操作的表现。

## 2. 论文提出的方法论

### 2.1 核心思想：共享视觉记忆的异步控制

T-WLA 的核心思想是：将视觉分支生成的历史感知视觉记忆（visual memory）缓存起来，作为慢速视觉规划与快速触觉修正之间的“共享接口”。视觉分支生成基础动作块，触觉编辑器在视觉更新之间利用该缓存记忆与最新触觉输入，预测对未执行动作的残差修正，而无需重跑视觉分支。

### 2.2 整体架构与公式

系统处理两类输入：RGB 观测 \(I_t\)（以 \(t\) 索引视觉更新，频率 39.7 Hz）和高频触觉观测 \(T_{t,\tau}\)（以 \(\tau\) 索引两次视觉更新之间的触觉更新，频率 119.1 Hz）。

在每个视觉更新时刻，视觉分支产生：

- 视觉记忆 \(M^t_V\)
- H 步基础动作块 \(A^{base}_t = f_{act}(M^t_V)\)

两者被缓存后，触觉编辑器在每次触觉更新时修正剩余动作：

\[
\hat{A}_{t,\tau} = f_{act}(M^t_V) + E\big(M^t_V, A^{base}_t, Z_{t,\tau}, \Delta t_{t,\tau}\big)
\]

其中：

- \(Z_{t,\tau}\) 为近期触觉历史编码（触觉上下文）；
- \(\Delta t_{t,\tau}\) 为当前动作块开始以来的已流逝时间；
- \(E\) 输出有效残差 \(\Delta A_{t,\tau}\)，仅作用于未执行的有效动作；
- 每次修正均相对于同一缓存的基础动作块，非累积在先前修正之上。

### 2.3 历史感知视觉记忆

单一当前图像可能因遮挡或视角变化而丢失关键信息，因此 T-WLA 维护一个紧凑的视觉历史记忆库：

\[
M^t_{V,in} = M_V(B^{t-1}_V, Q_V)
\]

\[
M^t_V = f_V(E_t, L_\ell, c_t, S_t, M^t_{V,in})
\]

- \(Q_V\) 为可学习查询 token（8 个，宽度 960）；
- \(B^{t-1}_V\) 为最近 K 组（K=8）视觉记忆的存储库；
- 检索时加入槽位嵌入与年龄嵌入，通过 cross-attention 提取历史信息；
- \(E_t\) 为当前图像 token，\(L_\ell\) 为任务指令 token，\(c_t\) 为视场 token，\(S_t\) 为状态 token；
- 新记忆 \(M^t_V\) 被追加到存储库，保留最近 K 组；
- 存储库在 episode 边界重置。

### 2.4 异步触觉修正

触觉编辑器与视觉分支共享相同的视觉记忆和基础动作块，但通过轻量模块实现高频修正：

- **触觉编码**：每只手以最近 8 帧的 21×21 压力图作为输入（左、右手分别处理，左手做空间翻转以统一手部约定），经共享 CNN（三层 5×5 卷积 + max-pooling）与双向 GRU 编码，最终投影到 64 维并 L2 归一化；采用参考减法策略 \(Z^r_{t,\tau}=v^r_{t,\tau}(F_T(H^r_{t,\tau})-F_T(H^r_{ref}))\)，以突出相对变化。
- **计划条件修正**：小型 Transformer 将缓存视觉记忆、基础动作块和已流逝时间编码为动作特征，FiLM 模块利用触觉上下文对这些特征做缩放与偏移，残差头输出动作修正；通过掩码保证修正仅作用于有效的、未执行的动作，触觉缺失的手得到零修正。
- **接触门控**：接触滤波变体以压力历史中 Top-5 压力均值是否超过阈值 \(\eta=0.25\) 生成硬门控 \(c^r\)，用于过滤无接触样本。

### 2.5 预测监督与训练策略

- **训练专用的辅助目标**：
  - **未来图像预测**：以当前图像 token 和视觉记忆为条件，预测未来潜在表征（由冻结图像编码器提供）；编辑器训练阶段额外由触觉上下文通过可学习适配器条件化该预测，适配器仅影响预测路径不改变控制记忆。
  - **未来压力预测**：以视觉记忆、触觉上下文和未来动作窗口为条件，预测未来压力，以将触觉特征与主动作计划下的接触演化联系起来。
- **分阶段优化**：
  1. 先训练视觉分支（动作 + 图像预测，采用条件流匹配）；
  2. 单独预训练触觉编码器（基于 EgoTouch 同步触觉与手部姿态历史的对比学习）；
  3. 冻结视觉分支，利用其缓存记忆与基础动作块训练触觉编码器和残差编辑器，损失函数包含组平衡的 Smooth L1 动作损失、残差幅度惩罚及两类预测目标；
  4. 推理时移除所有预测头。

## 6. 论文的主要结论与发现

- 在触觉条件下手部运动预测任务中，T-WLA 在所有 EgoTouch 环境和 Tachin 上均取得最低误差；手指关节 MPJPE 较最强基线在 EgoTouch 上降低约 30%，在 Tachin 上降低约 27%。
- T-WLA 的高精度与此同期获得更高的有效触觉修正速率（119.1 Hz），证明轻量触觉编辑路径可以同时实现更高频更新与更低预测误差。
- 在真实机器人操作中，T-WLA 达到 50.0% 的平均成功率（无触觉时为 47.25%），显著高于 SmolVLA（16.75%）、SmolVLA + Tactile（17.0%）和 T-Rex（23.0%）。
- 消融实验表明：触觉输入对手指关节误差贡献最大（移除后 EgoTouch MPJPE 上升 22.9%）；循环记忆对手腕预测影响更大（移除后在 Tachin 上平移误差上升 21.6%）；世界预测监督的贡献相对较小但一致为正。

## 7. 优点

- **清晰的异步控制策略**：将视觉规划与触觉修正解耦，以共享记忆为纽带，避免视觉分支频繁重算，思想直观且工程上可行。
- **轻量高效的触觉编辑路径**：触觉编辑器仅利用缓存的视觉记忆和基础动作块，实现高频残差修正，兼顾响应速度与计算开销。
- **训练专用的预测监督**：通过未来图像与未来压力预测增强控制表征的质量，推理时无额外开销，与 WAM 思想契合。
- **系统性实验验证**：覆盖触觉预测、纯视觉预测和真实机器人操作，配合较完整的消融分析，验证了各组件的贡献。
- **跨数据集一致性与可解释性**：在多个数据集上均显示出手指关节误差的大幅下降，且消融实验能清晰解释各模块的作用（触觉对手指关节、记忆对手腕平移）。

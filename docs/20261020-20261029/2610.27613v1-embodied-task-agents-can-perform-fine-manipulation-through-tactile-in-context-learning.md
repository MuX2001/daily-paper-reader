## 摘要
具身任务智能体能否在不进行任务特定模型训练的情况下，利用触觉经验执行精细操作？我们通过 Tactile-ETA 系统研究这一能力，该系统通过上下文学习将触觉经验整合到具身任务智能体中。成功的专家演示展示了操作过程中接触如何变化。我们将每个记录的机器人动作与其相机视图和双侧触觉观测配对。我们保留每个动作起点和终点的触觉观测，并在其间触觉图像发生显著变化时添加两个相邻时间点。智能体将这些演示与当前视觉、触觉观测和本体感觉相结合，通过通用机器人工具选择动作，而无需更新模型参数。在四个模拟操作任务中，在相同的两个专家演示上添加触觉观测后，平均成功率从 15.75% 提高到 24.00%，且当前感知和执行接口保持不变。进一步实验表明，性能取决于演示的感官内容和表示形式；在 Lift Bottle 任务上比较智能体模型时，相同系统配置下也显示出显著差异。在真实机器人任务中，具有对齐视觉和触觉观测的演示将任务成功率从 0% 提高到 60%。这些发现证明了在上下文中使用触觉经验进行精细操作的可行性，并为具身任务智能体扩展到更多感官输入指明了一条路径。

## Abstract
Can embodied task agents use tactile experience to perform fine manipulation without task-specific model training? We investigate this capability through Tactile-ETA, a system that incorporates tactile experience into an embodied task agent through in-context learning. Successful expert demonstrations show how contact changes during manipulation. We pair each recorded robot movement with its camera views and bilateral tactile observations. We keep tactile observations at the start and end of each movement and add two neighboring time points when the tactile images change markedly in between. The agent combines these demonstrations with current vision, tactile observations, and proprioception to select actions through general-purpose robot tools, without updating model parameters. Across four simulated manipulation tasks, adding tactile observations to the same two expert demonstrations increases average success from 15.75% to 24.00%, with current sensing and execution interfaces held fixed. Further experiments show that performance depends on the sensory content and representation of demonstrations, while comparing agent models on Lift Bottle reveals substantial differences under the same system configuration. On the real-robot tasks, demonstrations with aligned visual and tactile observations increase the task success rate from 0% to 60%. These findings demonstrate the feasibility of using tactile experience in context for fine manipulation and suggest a path toward extending embodied task agents to additional sensory inputs.

- 关键组件：
  - **触觉序列紧凑选择**：保留每个动作段的触觉端点；当段内触觉图像变化超过阈值时，额外保留变化峰值附近的相邻两帧（最多每指4帧）。触觉变化通过计算图像块（patch）位移的75百分位数 \(d_{75}\) 来度量，归一化后与阈值2像素比较。若可靠匹配块太少，改用图像差分分数。
  - **上下文构建公式**：对于段内同步触觉样本 \(N\ge2\)，令 \(c_n\) 为两指尖间相邻样本的较大归一化变化分数。若峰值 \(c_{n^\star}\ge1\)，保留时间索引 \(\mathcal{S}=\{0, n^\star-1, n^\star, N-1\}\)；否则仅保留端点 \(\{0, N-1\}\)。两指共用相同索引。
  - **执行接口**：基于 OpenETA 的通用机器人工具（`move_to`、`observe`）。智能体接收任务指令、演示上下文、当前视觉/触觉/本体感觉与执行反馈，选择运动与夹爪命令。底层控制器执行动作，返回最新观测与目标到达偏差反馈，但不返回任务得分或具体终止原因。
  - **无需训练**：模型参数 \(\theta\) 固定，动作选择为 \(u_t \sim \pi_\theta(\cdot | \ell, \mathcal{I}, \mathcal{C}_K, H_t)\)，其中 \(\mathcal{C}_K\) 为 \(K\) 个专家演示的有序上下文，\(H_t\) 为当前历史。

- 演示记录字段：机器人运动（平移、旋转、手指变化）、边界状态、相机视图、触觉图像条、记录步数索引、结果标签。视觉与触觉观测与同一动作区间对齐。

## 6. 论文的主要结论与发现

- **触觉上下文学习有效**：在相同两个专家演示中，加入触觉观测使四个模拟任务平均成功率从 15.75% 提升到 24.00%（+8.25个百分点），且当前感知与执行接口保持不变。
- **任务依赖性**：触觉贡献因任务而异。Insert Tube 上视觉-运动演示无提升，加入触觉后才改善；Lift Bottle 与 Pull Out Key 上视觉-运动已有增益，触觉进一步增益；Lift Can 仍困难。
- **触觉表示至关重要**：在 Lift Bottle 上，仅保留端点触觉成功率 27%（与无触觉演示相同），保留全部帧降至 2%，而选择策略达到 36%，说明不是越多触觉帧越好，适度保留中间变化才有效。
- **演示内容作用不同**：Pull Out Key 上触觉-运动演示与完整表示持平；Lift Bottle 上完整表示最佳，表明视觉对部分任务仍重要。
- **模型差异显著**：相同系统配置下，GPT-6 在 Lift Bottle 成功率为 36%，其他模型为 0–21%，显示触觉上下文设计需结合具体智能体能力。
- **行为证据**：触觉演示影响阶段转换时机和接触纠正策略。例如 Pull Out Key 中触觉演示使智能体在第四次旋转后才反转并拔出；Insert Tube 中触觉增强演示使智能体在感受到强烈触觉变形后回退并横向校正，最终成功，而未含触觉演示的智能体持续前进而失败。
- **真实机器人可行性**：无演示时两任务成功率均为 0/5；提供一个视觉-运动-触觉演示后，两任务均达到 3/5（60%）。
- **演示数量并非越多越好**：平均成功率 1-shot 22.50%、2-shot 24.00%、4-shot 19.00%；4-shot 在 Lift Bottle 上骤降至 2%，但在 Pull Out Key 上升至 48%。

Abstract — Reliable robotic manipulation in field-deployed settings requires more than executing a capable controller. As the execution conditions change, the system must decide, online and on the robot side, which control source should hold authority. Human teleoperation adapts readily to contact-rich and semantically ambiguous situations but depends on a stable communication link. Local autonomy is executed without continuous human intervention, but may fail under semantic ambiguity, long-horizon drift, and unforeseen contingencies. These two control sources exhibit complementary reliability profiles. We formulate this complementarity as a control-authority routing problem and present Task-Evidence Authority Routing for Robotic Manipulation (TEAR), an edge-deployable framework that allocates authority between human teleoperation and local autonomy. TEAR arbitrates on the robot side using network-state evidence, which governs the usability of teleoperation, and task-semantic evidence, which reflects whether autonomous execution remains consistent with the current task. A lightweight temporal arbitrator observes both forms of evidence together with robot state and current authority to time authority transfers. Across simulated and real-world trials under dynamic network conditions, TEAR achieves task success rates close to pure teleoperation while limiting teleoperation to 19.8–27.4% of control steps and improves success by 30–40% over autonomy-only execution in our settings. These results demonstrate the potential of complementary authority routing to sustain successful manipulation with substantially reduced dependence on continuous human control. 

I. I NTRODUCTION 

Robotic manipulation [1]–[3] is increasingly deployed beyond structured laboratory settings, in production-oriented and field-deployed environments where both communication quality and task conditions can vary over time. In such settings, reliability depends not only on the capability of the robot controller, but also on which source of control is in charge as execution conditions change. Human tele-operation remains one of the most dependable mechanisms for contact-rich and semantically ambiguous manipulation, because human experts can immediately adapt to unexpected contacts, partial observability, object displacement, and other contingencies. This reliability, however, is conditional on a stable communication loop. Classical teleoperation research has shown that latency and packet loss fundamentally affect transparency, stability, and user performance. More recent networked robotics studies further emphasise that latency, jitter, and packet loss remain practical bottlenecks for remote operation systems [4], [5]. When the link deteriorates, the human may still know what should be done, but the robot no longer receives commands. A direct response to this communication bottleneck is to reduce dependence on the remote operator through au-tonomous robot policies. Modern imitation learning and foundation model policies can map visual observations and task instructions to robot actions, and recent vision language action (VLA) models further transfer semantic knowledge from large scale vision language pretraining to robotic control [6]–[10]. Because such policies execute locally on the robot, they no longer depend on continuous human commands or on a stable command link, which directly addresses the failure mode described above. Autonomy alone, however, does not remove the need for human judgment. Learned policies may still stall, drift, or fail under semantic ambiguity, distribution shift, and unforeseen task contingencies. The two control sources therefore fail in different ways. Teleoperation remains adaptive but network dependent, and autonomous execution is locally available but semantically brittle. Since neither control source alone can sustain reliable execution under changing communication and task conditions, prior work has studied how human and autonomous control can be coordinated. Classical shared autonomy blends human and robot commands or infers the operator’s goal to assist task execution [11]–[14]. Mode-switching frameworks further automate transitions between autonomous and teleoperated modes while accounting for communication cost [5]. Recent delay-aware shared autonomy adjusts the contributions of hu-man and autonomous control using teleoperation transparency and autonomy confidence under network delay [15]. Policy uncertainty has also been used to determine when human intervention is required during autonomous execution [16]. Our target setting further considers changes in both communication quality and autonomous task execution during manipulation. The remote command stream can be affected by latency, jitter, and packet loss, while the local autonomous policy may encounter stalled progress, weak engagement with the target, or undesired task states. Authority allocation therefore requires evidence about the usability of remote control and the current state of autonomous execution. The decision must also remain available on the robot side as communication conditions change. Motivated by this setting, we formulate control allocation as an authority-routing problem between remote human teleoperation and an independently executable local policy. The router observes both network and task evidence over time and determines when authority should be transferred between control courses. • We introduce TEAR, an edge-deployable framework that jointly uses network-state and task-semantic evidence to predict handoff events over time, and converts these predictions into stable authority transfers through a stateful gate with hysteresis and cooldown. 

• We evaluate TEAR in simulated and real-world manipula-tion under time-varying network impairment, demonstrat-ing its task success close to continuous teleoperation with substantially less human control, and analyze the visual and network evidence associated with expert handoffs. II. R ELATED WORK 

Teleoperation for Remote Manipulation and Robot Data Collection. Teleoperation remains a core paradigm for remote robotic manipulation, as it transfers human perception, intent, and corrective judgment to robots operating in hazardous, remote, or production-oriented environments. Teleoperated robots have been widely used in disaster response, inspection, industrial operation, and other field-deployed settings where full autonomy is difficult to guarantee [17]–[19]. Recent in-terfaces, including VR and low-cost leader–follower systems, further make teleoperation an effective tool for collecting robot demonstrations and training visuomotor policies [20]– [22]. However, teleoperation is inherently constrained by the communication loop. Latency, jitter, bandwidth variation, and packet loss affect both operator perception and command execution, motivating recent studies on networked and latency-aware teleoperation [4], [5], [23]. These communication constraints motivate using link conditions to guide control allocation while retaining a locally executable manipulation policy. TEAR builds on this observation by treating network state not merely as an external disturbance, but as a decision signal for routing control authority. 

Autonomous Robot Policies. Autonomous robot policies aim to reduce dependence on continuous human control by mapping observations and task specifications to executable actions. Imitation learning learns such policies from expert demonstrations, with methods such as DAgger addressing distribution shift through iterative data aggregation [24]. Re-cent manipulation policies use transformers, action chunking, and diffusion-based action generation to model long-horizon or multimodal behaviours from demonstrations [6], [22]. Reinforcement learning provides another route to autonomous control by optimizing interaction-driven objectives, as shown in scalable grasping and continuous-control systems [25], [26]. Model-based and world-model approaches further learn predictive representations for planning and policy learning [27]. More recently, vision-language-action policies incorporate visual observations and language instructions into robot control, enabling semantically conditioned manipulation across diverse tasks [7]–[9], [28], [29]. These works show that autonomous policies are increasingly capable of local perception and action. TEAR uses a locally deployed VLA as its autonomous controller. Runtime monitoring provides complementary information about whether execution consis-tency checks with VLM-based detection of task progression failures [30]. In TEAR, visual task evidence forms part of the state used to decide when control should pass between the local policy and the human operator. 

Shared Autonomy and Mode Switching. Human-autonomy coordination has been studied through shared autonomy, assistive teleoperation, and mode-switching sys-tems. Classical shared-autonomy methods infer user intent and blend human commands with autonomous assistance to improve efficiency and reduce operator burden [11], [12]. Other work studies automatic mode selection for assistive teleoperation, including time-optimal mode switching and latent action spaces for controlling high-dimensional robots through lower-dimensional interfaces [13], [31], [32]. Recent systems extend this direction with language and foundation models. LAMS uses large language models to infer task context and switch assistive teleoperation modes, while other LLM-assisted teleoperation systems use language models to interpret operator intent or coordinate robot behaviours [33], [34]. Related work also explores coordination between tele-operation and VLA policies, for example by assigning coarse motion to human teleoperation and fine-grained manipulation to an autonomous policy [35], or by using human interventions to refine robot policies after deployment [36]. TEAR studies authority transfer under time-varying command impairment using network observations and visual task cues as inputs to a robot-side temporal predictor. Expert handoffs supervise upcoming-event prediction, and a stateful gate regulates when a prediction changes authority. This formulation makes the recent execution history and the current control source explicit in the routing decision. Our evaluation examines this design through task outcomes and offline handoff analysis. III. M ETHOD 

TEAR considers remote robotic manipulation under net-work degradation and task-execution disturbances such as stalling, where human teleoperation and a locally deployed VLA policy provide complementary sources of control. Human teleoperation offers adaptive correction when au-tonomous execution stalls or encounters unexpected task conditions, while local autonomy provides an execution path when degraded communication disrupts the delivery of human commands. Within this setting, authority rout-ing aims to improve manipulation resilience by assigning control according to the evolving conditions of both the communication link and task execution. Figure 1 presents our proposed framework, which integrates network and task evidence, predicts handoff events from their temporal history, and converts these predictions into discrete authority transfers. We first define the routing problem, then describe evidence construction, temporal prediction, and handoff execution.

We evaluate TEAR in simulation and real-world manipula-tion. The experiments examine three aspects of the framework. We first characterize teleoperation under network degradation. We then evaluate task-level performance and teleoperation use. Finally, we analyze the routing evidence and temporal handoff prediction. 

A. Experimental Setup 

Simulation uses a SO-101 arm in Isaac Sim/IsaacLab [41] to pick up oranges from a table to a plate. The local controller is GR00T-N1.5 [10], fine-tuned on 50 demonstrations. Real-world experiments use an SO-101 follower, a remote leader arm, and two RGB cameras to place yellow ducks onto a plate. Ducks start at varying poses; successful execution places all targets on the plate and stops the arm. The local controller is a separately fine-tuned GR00T-N1.7-3B model [42]. The two tasks share the pick-and-place structure, allowing us to examine the same routing design across changes in objects, policies, and deployment conditions. Remote commands are subject to software-imposed latency, jitter, and packet loss. In the real-world controller, the latest command is used while it remains fresh. Once it becomes stale, no new target is issued and the position controller holds its last goal. Local VLA actions bypass the impaired command path. Task-level comparisons use the time-varying impairment schedule described below, with separate network realizations for each method. Network evidence uses the imposed impairment parameters in simulation. For real-world execution, latency and jitter are estimated from receiver-side timing and expressed as round-trip time (RTT) by doubling the one-way estimates. Packet loss is estimated from gaps in received command se-quences and represents missing command updates, including application-level losses. For task-level evaluation, network impairment follows a predefined time-varying schedule with three nominal levels. The corresponding RTT settings are 50, 250, and 500 ms, jitter settings are 4, 50, and 100 ms, and packet-loss settings are 0%, 25%, and 100%. Small fluctuations are introduced around the nominal latency and jitter settings. The impairment level is updated every 8 s. The router operates at 60 Hz in simulation and 30 Hz in the real-world system. Visual task evidence is updated at 1.5 Hz using CLIP ViT-B/32, with the latest available visual cues used at each router update. The authority gate uses genter = 0 .40 ,

gexit = 0 .30 , and a cooldown of L = 20 router updates. The real-world controller treats a remote command as stale after 500 ms. All settings are fixed before task-level evaluation. Routers are developed separately for the two settings. Simulation uses 40 expert-controlled episodes, split into 30 training and 10 validation episodes, with 10 additional episodes reserved for offline event testing. Real-world de-velopment uses 30 valid episodes. All router splits are by episode. A separate ten-episode orange record supports the visual-cue analysis, and the original 20 real-world expert episodes support the handoff-evidence analysis. Task-level evaluation compares Always-Teleop, Always-VLA, and TEAR using ten valid rollouts per method and setting. Valid failures and timeouts are included; invalid shutdown records are excluded. Real-world TEAR trials are supervised: the logs contain 18 learned-router events and four manual switches across two episodes, including one terminal switch. The result should therefore be interpreted as evidence of a more selective event-prediction pattern rather than complete recovery of expert switching behavior. The offline analysis focuses on the temporal predictor independently of the downstream authority-transfer logic. Predicted events are extracted using threshold crossings with a cooldown, while deployed routing applies the two-threshold gate described in Section III-D. This separation provides a direct characterization of the learned temporal handoff prediction used by TEAR. V. L IMITATIONS 

Task and deployment scope. The present evaluation focuses on two related pick-and-place tasks with different objects, local VLA policies, and separately developed routers. This setting allows the same authority-routing formulation to be examined across simulation and physical robot execution. Broader task families, additional operators, and more varied handoff situations can further evaluate TEAR under a wider range of manipulation conditions. 

Network conditions. The current study uses controlled time-varying communication impairment to provide repeat-able changes in network quality. This setting does not include all effects that may arise in operational networks, including congestion, retransmission, correlated delay and loss, and coupled degradation of command and video streams. Recorded and live network traces can extend the evaluation to these conditions while retaining the same network-evidence interface. 

Task evidence and routing configuration. The current task evidence uses only visual observations and focuses on progress, stagnation, engagement, and anomaly. Fine contact and force information is therefore outside the present evidence representation. Additional sensory signals can be incorporated into the same routing state to provide complementary task evidence. The current formulation provides a compact in-terface for combining task-semantic evidence with network conditions, robot state, and execution history for robot-side authority routing. VI. C ONCLUSION 

We presented TEAR, a robot-side framework that coor-dinates human teleoperation and local VLA control using complementary network and task evidence. A frozen VLM provides visual task cues, and a causal temporal router uses execution history to predict handoffs. Offline text preparation, cached text embeddings, and local inference support edge deployment without online generative-model queries for arbitration. Across the evaluated simulation and real-world settings, TEAR achieves task success rates close to those of pure teleoperation with substantially less teleoperation use, at the cost of longer successful completion times.

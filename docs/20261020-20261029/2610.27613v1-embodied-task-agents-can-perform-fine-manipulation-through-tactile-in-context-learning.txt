Abstract
Can embodied task agents use tactile experience to perform fine manipulation without task-specific
model training? We investigate this capability through Tactile-ETA, a system that incorporates tactile
experience into an embodied task agent through in-context learning. Successful expert demonstrations
show how contact changes during manipulation. We pair each recorded robot movement with its
camera views and bilateral tactile observations. We keep tactile observations at the start and end
of each movement and add two neighboring time points when the tactile images change markedly
in between. The agent combines these demonstrations with current vision, tactile observations,
and proprioception to select actions through general-purpose robot tools, without updating model
parameters. Across four simulated manipulation tasks, adding tactile observations to the same two
expert demonstrations increases average success from 15.75% to 24.00%, with current sensing and
execution interfaces held fixed. Further experiments show that performance depends on the sensory
content and representation of demonstrations, while comparing agent models on Lift Bottle reveals
substantial differences under the same system configuration. On the real-robot tasks, demonstrations
with aligned visual and tactile observations increase the task success rate from 0% to 60%. These
findings demonstrate the feasibility of using tactile experience in context for fine manipulation and
suggest a path toward extending embodied task agents to additional sensory inputs.

Introduction
Embodied task agents such as ETA [8], Show-Harness [7], and RoboDawn [12] demonstrate that general-
purpose models can execute robot tasks through observations, reasoning, and robot commands. However,
fine manipulation remains challenging. Recent real-robot evaluation also shows a substantial performance
gap between pick-and-place tasks and fine insertion tasks [26]. Such manipulation requires adjusting actions
to contact conditions, which can be difficult to infer reliably from vision alone. Tactile feedback provides
complementary information for these adjustments [3]. In-context learning further allows demonstrations
to provide task guidance at deployment without additional parameter updates [9, 29, 35]. This creates an

opportunity to extend the sensory information these agents can use: can embodied task agents similarly use
tactile experience in context to perform fine manipulation that requires contact-sensitive adjustments? We investigate
this question through Tactile-ETA (Figure 1), which incorporates expert tactile experience into an embodied
task agent that acts through general-purpose robot tools, without task-specific fine-tuning.
Current tactile observations describe ongoing contact, whereas expert demonstrations can provide a reference
for how contact evolves during movement. For example, during rotation or insertion, a demonstration can
show how an expert continues moving, adjusts its pose, or changes manipulation stages around a contact
transition. Visual–motion records capture what the expert did, but not how contact evolved during the
demonstrated actions. We organize expert demonstrations so that the agent can see each movement together
with the visual and tactile changes that accompany it.
Tactile-ETA divides successful expert demonstrations into action-aligned interaction segments, each containing
robot motion, before-and-after camera observations, and bilateral tactile sequences from the same interval.
Full tactile sequences can contain many observations within one movement, while the endpoints alone can
miss changes during contact. We therefore retain tactile observations at motion boundaries and, when a
change threshold is met, add an adjacent pair spanning the selected change. Complete demonstrations are
provided in interaction order as references for execution. The agent combines them with current visual and
tactile observations, proprioception, and execution feedback to select motion and gripper commands. Model
parameters remain unchanged: task guidance is provided through context, while general-purpose tools and
the underlying controller execute the selected actions.
We evaluate the system on four UniVTAC simulation tasks [4], with 100 trials per task and condition. Adding
tactile observations to the same two visual–motion demonstrations increases average success from 15.75% to
24.00%, with current sensing and execution interfaces held fixed. Content ablations reveal task-dependent
contributions from demonstration vision and tactile observations, while representation ablations show that
retaining more tactile frames does not automatically improve performance. A comparison of agent models on
Lift Bottle also reveals substantial differences under the same system configuration. Execution statistics and
cases illustrate behavioral differences in contact-guided corrections and stage transitions. On two real-robot
tasks, a single multimodal demonstration enables three successful trials out of five per task, compared with
zero without demonstrations. Together, these results demonstrate the feasibility of using tactile experience in
context for embodied task agents and suggest a path toward extending them to additional sensory inputs.
Our contributions are threefold:
• We introduce Tactile-ETA, a system that incorporates expert tactile experience into embodied task

• We construct action-aligned visual–motion–tactile demonstrations that compactly retain motion bound-

• We show that tactile demonstration experience can improve manipulation performance, with outcomes
depending on context organization and the underlying agent model. Execution records illustrate

Related Work
Embodied Task Agents.
Language and vision-language models connect task reasoning to robot execution
through skill selection, environmental feedback, and program generation [1, 18, 23]. Visual grounding
translates model outputs into spatial targets, objectives, or constraints for robot execution [17, 19, 20, 24, 27].
Recent work studies general-purpose models operating through robot interfaces [7, 8, 11, 30, 32]. Related
systems improve robot programs, skills, or policies through agent-driven iteration [5, 25, 33]. We build on
OpenETA’s tool-based execution [8], in which the agent selects motion and gripper commands and receives
observations and feedback after execution.
In-Context Robot Learning.
Demonstration-guided robot learning [2] includes methods that use examples
at deployment without further parameter updates [15, 22, 28]. Some methods train policies to predict actions
conditioned on demonstration trajectories [10, 31]. For frozen general-purpose models, demonstration context
can encode visual keypoints and end-effector trajectories as tokens [29], or initial object poses and keyframe
actions as text [35]. More closely related to our setting, visual demonstrations and action references are
combined with online observations and execution feedback for closed-loop manipulation [9]. Interface-aligned
demonstrations further illustrate motion-command effects and task strategies [12].
Tactile Sensing for Robotic Manipulation.
Tactile learning supports physical perception and action
generation [13]. Existing work learns transferable tactile representations [16], connects tactile observations to
language-based reasoning [36, 37], and learns sequential visuotactile representations for manipulation [34].
Policy learning incorporates tactile information through model training [14, 21], with generalist tactile policies
extending across sensors [38]. Semantic tactile feedback can also support planning alongside a learned
controller for action refinement [3]. Particularly relevant, visual, tactile, and force–torque demonstrations
have been used to infer skill sequences and refine their transition conditions, producing a reference plan
for subsequent execution and replanning [6]. Our approach retains expert motions and aligned visual
and bilateral tactile observations as demonstration context for successive tool-based decisions. We study
how this contact experience can guide an embodied task agent, including controlled comparisons that vary
demonstrated tactile information while holding current sensing and execution interfaces fixed.

Tactile-ETA
3.1
Tactile-ETA Overview
Tactile-ETA incorporates tactile experience into an embodied task agent through context, without task-specific
parameter updates (Figure 1). The agent receives a task instruction, expert demonstrations, and current
visual, tactile, and proprioceptive observations. Expert demonstrations provide the agent with a reference
for how the task is successfully executed, including both the expert actions and the contact changes that
accompany them, while current observations and execution feedback describe the ongoing interaction. The
agent uses both to select calls to general-purpose robot tools; an underlying controller executes the requested
movements.

3.2
Tactile Experience in Context
We construct demonstration context that links expert movements to the visual and tactile observations
accompanying them (Figure 2). Each successful expert episode is divided at its recorded action boundaries.
Within a segment, before-and-after head- and wrist-camera views describe the scene, while synchronized
bilateral tactile observations capture the contact process. The motion record contains measured end-effector
translation, relative rotation, and finger-position changes computed from the recorded robot states. These
motions and the visual and tactile observations refer to the same action interval. Record fields, units, and
coordinate conventions are provided in Appendix B.
Compact tactile sequences.
We retain tactile observations at both action boundaries. For each fingertip, we
select small patches in one tactile image and find their most similar matches at nearby locations in the next
image. The distance between each patch’s original and matched locations gives its displacement. We sort
the displacement magnitudes of reliable matches from smallest to largest and use the value approximately
three quarters of the way through this list, the 75th percentile 𝑑75, to measure the change between the two
images. We express 𝑑75 in original-image pixels and divide it by the selection threshold of 2 pixels to obtain a
normalized change score. When too few patches can be matched reliably, we instead use an image-difference
score normalized by its own selection threshold (Appendix B).

the two fingertips between samples 𝑛−1 and 𝑛. In addition to the endpoints, we retain at most one adjacent

3.3
Execution with Current Tactile Feedback
At the beginning of an episode, the embodied task agent receives the demonstration context and selects
actions using the task instructions, current visual and tactile observations, and robot state. It interacts
through OpenETA’s general-purpose robot tools [8]. The move_to tool specifies an end-effector position
and orientation target, together with an optional gripper command; the underlying controller executes the
movement. The observe tool returns current camera images, bilateral tactile observations, end-effector
poses, and joint positions. Demonstrations provide a reference for choosing actions in the current scene.
After each motion segment, the system returns the latest camera images and robot state, along with feedback
on whether the target was reached and the deviation from the requested motion. Tactile observations recorded
during the movement are selected using the rule in Section 3.2 and presented as separate left and right image
strips. The tool call and its returned observations and feedback are appended to the interaction history for
subsequent action selection. The agent can therefore refer to both the contact changes in expert demonstrations
and the latest feedback from its own actions. Model parameters remain fixed throughout execution. Operator
prompts, tool descriptions, and the motion argument schema are provided in Appendix F.
4
Experiments
We evaluate whether embodied task agents can perform fine manipulation through tactile in-context learning.
We examine how demonstrations guide action selection and how performance depends on demonstration
content, tactile sequence representation, and the agent model.
Experimental setup.
We evaluate on four tasks from UniVTAC [4]: Insert Tube, Lift Can, Lift Bottle, and Pull
Out Key. Corresponding comparisons use the same 100 evaluation initial conditions per task, with success
and automatic termination determined by the native environment. Unless otherwise specified, we use a
frozen GPT-6 agent with low reasoning effort and provide two successful expert episodes from the official
dataset when demonstrations are used. Demonstration identities and ordering, robot tools, controller, task
instructions, and execution budgets are held fixed within each comparison. Full settings are provided in
Appendix A.

4.1
Fine Manipulation with Tactile Experience
Compared configurations.
We compare four input configurations of the same embodied task agent. All
receive current vision, proprioception, and execution feedback. No demos (vision) provides neither demon-
strations nor tactile observations. No demos (vision + tactile) adds current tactile observations. Visual–motion
demos provides current tactile observations and two expert demonstrations containing visual observations
and motion records. Tactile-ETA further includes the tactile observations from those demonstrations. The
latter two configurations use the same expert episodes and current sensory inputs, differing only in whether
the demonstrations contain tactile observations.
Results.
Adding tactile observations to visual–motion demonstrations increases average success across the
four tasks from 15.75% to 24.00%, a gain of 8.25 percentage points (Table 1). With current sensory inputs held
fixed, this comparison shows that expert tactile experience provides additional guidance for fine manipulation.
For reference, average success without demonstrations is 3.00% with current vision alone and 6.25% with
current vision and tactile sensing. On Insert Tube, visual–motion demonstrations provide no success-rate gain
over the agent with current vision and tactile sensing; adding demonstrated tactile observations improves
performance. On Lift Bottle and Pull Out Key, visual–motion demonstrations already improve success, and
including demonstrated tactile observations produces a further gain. These results show that visual–motion
guidance and demonstrated tactile experience contribute differently across tasks. Lift Can remains difficult
under all configurations.
4.2
How Tactile Demonstrations Guide Manipulation
Demonstrations help the agent establish an initial manipulation strategy. On Lift Bottle, the agent with
current vision and tactile sensing but no demonstrations begins by closing the gripper in place in only 1/100
episodes, compared with 100/100 under visual–motion guidance. Tactile-ETA adopts the same initial strategy.
Expert visual and motion records therefore already provide a concrete starting action for this task.
Tactile experience in demonstrations also influences adjustments after contact. On Insert Tube, 48/100
visual–motion episodes and 13/100 Tactile-ETA episodes end in unsuccessful native early termination with
at least two executed segments whose net TCP displacement along the initial approach axis exceeds 1 mm,
and no segment with a net displacement below −1 mm along that axis (Appendix C.2). Figure 3 shows
two examples: the former continues requesting forward motion after observing contact and ultimately fails;
the latter reports pronounced tactile distortion, executes a retreat and lateral correction, and subsequently
completes insertion. Both agents receive current tactile feedback. Together with the success-rate comparison,
these behavioral differences support the use of demonstrated tactile experience to guide action adjustments
in response to contact.

5
Discussion
Limitations and future directions.
Tactile-ETA explores how incorporating touch as an additional input
modality through in-context experience can extend embodied task agents’ capabilities for fine manipulation.
We hope this work encourages broader exploration of how new sensory modalities can expand agents’
manipulation capabilities. Our evaluation is limited in model coverage by API availability and inference
cost; broader community evaluation could help characterize how different foundation models use tactile
experience. In addition, the current system primarily uses tactile feedback to guide decisions between motion
segments. Combining decisions informed by tactile experience with fast tactile feedback control during
action execution is a promising direction for improving continuous contact-rich interaction.
Conclusions.
We introduced Tactile-ETA, which enables embodied task agents to use tactile experience in
context for fine manipulation without updating model parameters. The system organizes expert demon-
strations into compact, action-aligned visual, motion, and tactile context and combines this experience
with current sensing and execution feedback. Across four simulated tasks, adding tactile observations to
visual–motion demonstrations improves average success while retaining the same current sensory inputs.
Further experiments show that performance depends on demonstration content, tactile representation, and
10


the agent model. Real-robot experiments demonstrate successful wiping and fragile-object pickup with a
single multimodal demonstration. These findings establish the feasibility of tactile in-context learning for fine
manipulation and suggest a path toward extending the sensory capabilities of embodied task agents through
experience provided in context.

A
Experimental Setup
We detail the simulation protocol and controlled inputs here.
Appendix B describes demonstration
construction; Appendix F provides the operator prompts and tool schemas.
A.1
Simulation setup
We evaluate the main input configurations on four UniVTAC tasks: Insert Tube, Lift Can, Lift Bottle, and Pull
Out Key. Each configuration is evaluated on the same 100 initial conditions per task, using separate rollouts.
The agent begins operating after the environment’s native reset and preparatory motion. From this point
onward, it selects the motion and gripper commands through the robot tools. Success rates are computed
using the native task criteria and reported both per task and averaged across tasks.
The main comparisons use a frozen GPT-6 agent with the low reasoning-effort setting. Demonstration-based
conditions receive the same two successful official expert episodes, 0 and 1, in that order. One demonstration
denotes a complete expert episode rather than a single action segment. The demonstration-content ablation
covers Lift Bottle and Pull Out Key. The tactile-representation comparison in Table 3 concerns Lift Bottle, and
the model comparison is reported in Section 4.4.

A.4
Native evaluation and termination
Native success checks, early-failure conditions, and episode budgets determine when physical interaction
ends. These checks run in the background. The agent is not given current task scores or the specific native
termination reason, and no check_task tool is available. Automatic termination is reported with the
neutral notification episode_ended. The finish_episode tool is used to end voluntarily or acknowledge
termination. Historical expert outcomes and static task requirements remain available; they are distinct from
evaluation of the current rollout. Success rates use the environment’s recorded labels, not the agent’s final
account of its performance.
We retain the benchmark’s task definitions. In particular, Lift Can is evaluated using its native pose predicate,
not a separate criterion for stable suspended lifting.

B.2
Tactile selection parameters
Images are converted to grayscale and resized while preserving their aspect ratio. We track a 3 × 4 grid
of patches inside the region of interest (ROI). Each patch is matched by an integer displacement search
minimizing mean squared error (MSE). Low-texture patches and ambiguous or high-error matches are
rejected. Tracking quality is the fraction of the 12 patches that survive. The motion score is the 75th percentile
of their displacement magnitudes, rescaled to the original image resolution. When tracking quality is below
0.35, we instead use the mean absolute grayscale difference inside the ROI, divided by 255. Table 6 gives the
retained selection parameters for the expert demonstrations and online tactile history.

C.2
Contact-guided adjustment on Insert Tube
For each executed segment, we project the measured net TCP displacement onto that episode’s initial

forward segments need not be adjacent; all executed segments are considered. Displacements exactly at
the thresholds do not qualify as forward or retreating. This is a segment-level measure, not a claim that no
backward motion occurred within any segment. The counts are 48/100 with visual–motion demonstrations
and 13/100 with Tactile-ETA.

Real-World Experiments
Robot platform.
Both tasks use a reBot Arm B601-RS with a vitai GF225 tactile gripper.
Agent and demonstrations.
Both tasks use GPT-6 Astra with low reasoning effort. The no-demonstration

Prompts and Tool Interface
F.1
Operator prompts
The three shared blocks below replace only the task name, goal, static rules, and control-step limit with
named fields; task-specific blocks provide their values. Tool argument schemas follow in Section F.3.
Shared operator prompt: interaction
You control one live UniVTAC {task_name} episode through OpenETA’s general-purpose robot tools.
Start by calling review_demonstrations once, then observe the current episode. Use the current camera images,
bilateral tactile images when provided, robot state, and execution feedback to decide your motion targets,
orientation, and gripper actions.
After each action, inspect the returned observations. You may probe, retreat, adjust, and retry within this episode.
A recoverable tool failure does not end the task.
Use finish_episode to end voluntarily or acknowledge the neutral episode-ended notification. Voluntary ending is
final. Native evaluation and automatic stopping run in the background; current task scores and the specific
termination reason are not provided. The demonstration tool may provide historical expert experience or no
examples. Use any examples as references for reasoning about the current observations, not as absolute-coordinate
scripts. Recorded measured movement is not necessarily a recorded tool command. Historical success does not
guarantee current success.
Do not infer task success merely because a command completed.
Shared operator prompt: coordinates and observations
Task goal: {task_goal}
Coordinates: xyz_m is the absolute TCP position in world metres; delta_mm is displacement in world or current
grip_site axes, in millimetres. The TCP is UniVTAC’s measured gripper center (fixed transform from panda_hand),
not the LIBERO grip site. approach_world sets TCP +Z; jaw_world sets TCP +X. These fields specify orientation

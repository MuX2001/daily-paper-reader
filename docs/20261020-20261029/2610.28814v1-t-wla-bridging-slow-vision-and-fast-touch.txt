ABSTRACT
In contact-rich manipulation, contact conditions can change before a visual pol-
icy updates its action plan. Recomputing the plan through the visual policy adds
latency, while tactile feedback alone does not specify how the ongoing motion
should be revised for the task. We introduce T-WLA, a world–language–action
architecture that uses shared visual memory to guide both action generation and
tactile correction. At each visual update, the visual branch integrates the current
image, task instruction, and retrieved history into a visual memory that condi-
tions base-action generation. The same memory is cached for a lightweight tac-
tile editor, which combines it with the active action chunk and incoming touch
to predict residual corrections to unexecuted actions without rerunning the visual
branch. Future-image and future-pressure prediction provide training-only super-
vision, encouraging the visual memory and tactile features to capture interaction
dynamics relevant to action generation and correction. We evaluate T-WLA on
tactile-conditioned hand-motion prediction using EgoTouch and Tachin, and on
four real-world dexterous manipulation tasks. T-WLA reduces finger-joint MPJPE
by 30% relative to the strongest reported baseline and achieves an average success
rate of approximately 50.0% across real-robot manipulation tasks. Videos and
codes are available at the project website.

INTRODUCTION
Contact-rich manipulation refers to tasks whose success depends on precisely managing physical
contact with objects or the surrounding environment (Hogan, 2022; Lee et al., 2019). Tactile feed-
back complements vision by revealing local contact conditions that are difficult to infer from images
alone (Niu et al., 2026; Song et al., 2025; Xue et al., 2025; Zhou et al., 2026b). For example, when
inserting a plug into a socket, vision guides alignment and approach, while touch provides feedback
on contact and insertion resistance. Because these conditions can change between visual updates,
tactile feedback supports rapid corrections to the ongoing motion.
Despite the importance of tactile feedback in contact-rich manipulation, many general-purpose robot
policies rely primarily on vision. Vision–language–action (VLA) models adapt pretrained vision–
language backbones to predict robot actions from visual observations and language instructions
(Kim et al., 2024; Physical Intelligence et al., 2025). World–action models further integrate future-
state prediction with action generation, linking control decisions to the anticipated evolution of the
environment (Zhang et al., 2026b; Yuan et al., 2026). Without tactile feedback, these models must
infer local contact conditions from visual cues, which may limit their response to visually subtle
contact changes during precise manipulation.
Recent work incorporates tactile feedback into robot control through variable-rate expert architec-
tures (Niu et al., 2026), residual adaptation (Wang et al., 2026), and inference-time policy steering
(Wu et al., 2026b). We investigate a complementary question: how can fast tactile feedback correct
a slow visual policy between visual updates? Our central idea is to generate asynchronous tactile
corrections conditioned on persistent visual memory. The visual branch processes RGB observa-
tions at 39.7 Hz, producing a base action chunk and a history-aware visual memory at each update.
The tactile branch processes touch at 119.1 Hz, combining recent tactile context with the cached vi-
sual memory and the active action chunk to predict residual corrections to its remaining, unexecuted
actions. This allows contact feedback to refine ongoing motion without waiting for the next visual
update or rerunning the visual branch.
We instantiate this idea in T-WLA, a multi-rate architecture for asynchronous visual–tactile con-
trol (Fig. 1). The visual branch generates an action chunk and a history-aware visual representation,
which is cached until the next visual update. Between these updates, a lightweight tactile editor com-
bines the cached representation with recent tactile observations to produce high-frequency residual
corrections to the ongoing action chunk. This separation allows the controller to respond to chang-
ing contact conditions without repeatedly running the visual branch. During training, future-image
and future-pressure prediction regularize the control representations, encouraging them to capture
information relevant to subsequent interactions. Our contributions are summarized as follows:
• Memory-guided asynchronous control.
We propose T-WLA, which uses the same
history-aware visual memory to guide base-action generation and tactile correction. A
lightweight tactile editor uses this memory and the active action chunk to correct unexe-
cuted actions between visual updates, without rerunning the visual branch.
• Predictive supervision for control. We regularize the visual memory through future-
image prediction and the tactile features through both future-image and future-pressure
prediction. These auxiliary objectives complement action supervision, and their prediction
heads are removed at inference.
• Evaluation across hand-motion prediction and robot manipulation. Experiments on
EgoTouch and Tachin show improved finger-joint prediction accuracy, while real-robot
tests show that T-WLA increases mean task success from 17.0% to 50.0%. Ablations ex-
amine the contributions of tactile input, visual history, and predictive supervision.

RELATED WORK
2.1
MEMORY AND ACTION CHUNK EXECUTION
A single observation may not provide enough information to determine the next action. Memory-
based policies address this limitation by retaining information from earlier observations; for ex-
ample, MemoryVLA stores consolidated perceptual and cognitive entries that can be queried over
long horizons (Shi et al., 2026). A complementary line of work predicts temporally extended action
sequences. ACT introduced transformer-based action chunking to reduce the effective decision hori-
zon (Zhao et al., 2023), while generative policies such as Diffusion Policy, RDT-1B, and π0 generate
multi-step actions with diffusion or flow-based objectives (Chi et al., 2025; Liu et al., 2025a; Black
et al., 2024a). Such temporal coherence can reduce responsiveness when new observations arrive
during execution (Liu et al., 2025b; Zeng et al., 2026). Bidirectional Decoding improves closed-loop
adaptation by selecting among candidate chunks (Liu et al., 2025b), while Consistency Policy and
Streaming Diffusion Policy accelerate generative action synthesis (Prasad et al., 2024; Høeg et al.,
2025). Real-time chunking instead explicitly accounts for inference latency when transitioning be-
tween successive chunks (Black et al., 2025). T-WLA addresses a complementary setting: it retains
visual history across policy updates and uses high-rate tactile feedback to revise the unexecuted
portion of an active action chunk.
2.2
TACTILE FOUNDATION MODELS
Tactile representation learning aims to produce features that transfer across sensors and tasks (Bi
et al., 2026a; Tao et al., 2026; Heng et al., 2025; Zhang et al., 2026c; Huang et al., 2025). Het-
erogeneous Tactile Transformer learns a shared model across sensor types (Bi et al., 2026b), while
FG-CLTP aligns tactile features with visual and language representations (Ma et al., 2026). Other
work explores transferring representations learned from human tactile recordings to dexterous robots
(Zhang et al., 2026a) and scaling pretraining through tactile foundation models (Team et al., 2026;
Zhou et al., 2026b). Our tactile encoder follows this direction through contrastive pretraining on
synchronized tactile and hand-pose histories. Building on tactile representations, several systems
study how to incorporate touch into manipulation policies. Multi-rate architectures allow tactile
feedback to influence control between visual updates. T-Rex assigns vision and touch to experts op-
erating at different rates (Niu et al., 2026), while Reactive Diffusion Policy combines a slow visual
diffusion policy with a fast latent tactile controller (Xue et al., 2025). FA-RDP adapts this division
to task demand (Zhuo et al., 2026), and DSWAM organizes world–action modeling into cooperat-
ing slow and fast systems (Zhu et al., 2026). Residual adaptation provides another mechanism for
incorporating touch into existing policies. ViTaR attaches a lightweight visuotactile residual branch
to a frozen backbone (Wang et al., 2026), while ResTacVLA applies residual adaptation in feature
space (Zhang et al., 2026d). Tactile feedback can also guide action execution through inference-
time adaptation. FBFM introduces asynchronous feedback during flow-matching execution without
additional training (Li et al., 2026), while inference-time policy steering adjusts a fixed policy using
vision and touch (Wu et al., 2026b). Complementary approaches use touch as training supervi-
sion without requiring tactile input at deployment (Gubernatorov et al., 2026; Cheng et al., 2026).
These approaches enable tactile feedback to influence action generation and execution. In T-WLA,
a cached, history-aware visual representation connects a slow visual policy to a fast tactile editor,
which combines visual memory with recent touch to refine the ongoing action chunk. Predictive su-
pervision encourages these representations to capture evolving interaction dynamics, while auxiliary
predictors are used only during training and add no inference cost.

3.4

ent subsequent visual or contact outcomes. We add future-image and future-pressure prediction to
supervise information about these outcomes in the representations used for control. Both prediction
heads are training-only auxiliaries, not inference-time planners.
Complementary prediction targets. The image predictor conditions on current image tokens and
output visual memory to predict future latents supplied by a frozen image encoder. During editor
training, tactile context also conditions this predictor through a learned adapter. The adapter changes
only the auxiliary prediction path, leaving the cached memory used for control unchanged. Future-

EXPERIMENTS
We organize our experiments around four questions. First, does combining visual memory with
high-rate tactile feedback improve future hand-motion prediction on human-interaction datasets
(Section 4.2)? Second, does the tactile branch improve closed-loop success on real contact-rich
robot tasks under a matched visual backbone and training budget (Section 4.3)? Third, which
components—tactile input, recurrent memory, memory capacity, and predictive supervision—
account for the improvement (Section 4.4)? Finally, does the visual branch remain a strong stan-
dalone predictor when tactile observations are unavailable (Appendix E)?

sheet pickup and cup nesting require a secure grip without crumpling or crushing the object; and

mation that images alone may not resolve. As shown in Table 2, T-WLA with tactile input achieves

tation, T-WLA, including its tactile editor, is trained only on human-hand data. Even without tactile
input, T-WLA reaches 47.25% mean success, compared with 16.75% for SmolVLA, which shares

Table 3 isolates the effects of tactile input, recurrent history, memory capacity, and predictive super-

metrics and ties for the lowest Tachin joint error.
5
CONCLUSION
We presented T-WLA, a multi-rate visuotactile architecture that caches history-aware visual memory
to guide high-frequency tactile corrections. A slow visual policy generates base action chunks, while
a lightweight tactile editor reuses the cached visual memory to refine ongoing actions at a higher
frequency. Future-image and future-pressure prediction regularize the control representations during
training, complementing action supervision with interaction dynamics. Extensive results show that
joint visual-tactile modeling and predictive supervision improve contact-rich manipulation.

A
ACTION FOUNDATION MODEL
General-purpose manipulation policies increasingly adapt large pretrained backbones to action pre-
diction (Wu et al., 2026a; Ye et al., 2026a; Yuan et al., 2026; Black et al., 2024b; Pertsch et al.,
2025; Kim et al., 2025; Team et al., 2024; Liu et al., 2025a; Bjorck et al., 2025; Team et al., 2025;
Shukor et al., 2025; O’Neill et al., 2024; Driess et al., 2023; Brohan et al., 2022; Reed et al., 2022).
Vision–language–action (VLA) models follow this approach by predicting robot commands from
visual observations and language instructions. RT-2 (Brohan et al., 2023) represents actions as to-
kens to jointly train on robot trajectories and web data, while OpenVLA (Kim et al., 2024) fine-tunes
a pretrained vision–language backbone on a large collection of real robot demonstrations. More re-
cent work expands the data and supervision available for policy learning. π0.5 (Physical Intelligence
et al., 2025) combines robot trajectories, web data, and subtask supervision to support generaliza-
tion to unseen environments. SmolVLA (Shukor et al., 2025) emphasizes efficient training with
community demonstrations, while VITRA (Li et al., 2025) learns a hand-motion prior from human
activity videos. World–action models (WAMs) (Hou et al., 2026) further incorporate future-state
prediction to learn representations of how the environment evolves. FLARE (Zheng et al., 2025)
predict future observation embeddings rather than reconstructing future pixels. Dream-zero Ye et al.
(2026b) jointly predict future video and robot actions. Fast-WAM (Yuan et al., 2026) use predic-
tive learning during training while removing the predictor at deployment. These methods motivate
learning control representations through future prediction. However, they run on single clock: visual
observations, learned representations, and action predictions are updated together. In contact-rich
manipulation, this coupling is restrictive because local contact conditions can change faster than the
visual policy is updated. In these situations, a further challenge is to make these representations
useful for tactile corrections between visual updates. T-WLA addresses this challenge by caching a
history-aware visual representation that a faster tactile controller can reuse.

Sensor processing and temporal encoding. Each hand is represented by its eight most recent

C.2
PREDICTIVE CONDITIONS
Tactile-conditioned visual prediction. During tactile editor training, a learned adapter maps the
tactile context Zt,τ to an additive update of the eight visual-memory tokens used by the frozen vi-
sual predictor. This update affects only the prediction condition; the cached visual memory used
for action generation remains unchanged. Let y denote the clean future-image latent, ε the sampled
Gaussian noise, and vZ the predictor’s velocity under the tactile-augmented condition. We super-
vise vZ with the conditional flow-matching target ε −y. Although the implementation expresses
this objective relative to the unaugmented prediction, the resulting loss is algebraically identical to
the conditional flow-matching loss. The predictor’s parameters are frozen, but gradients through its
tactile-augmented forward pass update the adapter and tactile encoder. The squared error is spatially
weighted, normalized by the weighted valid element count for each sample–horizon pair, and aver-
aged over valid pairs. Reference ROI weights are 1 for the hand region and 0.1 for the background.

context, and a detached window of upcoming edited actions generated by the controller to predict
future pressure. Detaching the action window prevents this loss from sending gradients through the
action condition into the residual readout, while gradients through the tactile context can update the
shared tactile encoder. The target is measured future pressure, not a learned tactile embedding. For
hand r ∈{L, R} and pressure site u ∈{1, . . . , 441}, a fixed codec canonicalizes hand orientation

C.3
TRAINING STRATEGY
For tactile pretraining, synchronized tactile and hand-pose histories from EgoTouch are encoded
into normalized embeddings ui and pi, with tactile embeddings taken before reference subtraction.
Their similarities are computed as Sij = αu⊤
i pj, where α > 0 is a learned scale. The symmetric
contrastive objective averages row-wise cross-entropy over S and S⊤, treating synchronized pairs
as positives and other pairs in the minibatch as negatives. During editor training, the visual branch
supplies cached visual memory and base action chunks and remains frozen. The tactile encoder,
residual editor, tactile conditioning adapter, and pressure predictor are updated, while the visual
predictor remains frozen. As a proposed extension, both control branches could be jointly fine-tuned
on EgoTouch using the same action and predictive objectives. In this stage, visual memory and base
action chunks would be recomputed online, allowing the corrected-action loss to also update the
visual branch through the memory interface. The visual predictor would remain frozen.

Chunk positions and auxiliary action windows. The visual branch and tactile editor operate at
39.7 Hz and 119.1 Hz, respectively. Each visual update produces a new base action chunk. Between
visual updates, the tactile editor uses incoming tactile observations to revise the unexecuted actions
in the active chunk. The elapsed time ∆tt,τ is measured from the start of that chunk rather than
inferred from the tactile update index.
For future-pressure conditioning, the action window begins at k0 = ⌈fcmd∆tt,τ⌉, where fcmd is
the action command rate, and contains the next eight edited actions. A floating-point tolerance is
applied at integer boundaries. Positions beyond the chunk are zero-padded and marked invalid. This
auxiliary window-indexing rule is distinct from the loss horizon and from the temporal mask that
marks already executed actions as non-editable.

Finger-joint MPJPE compares the stored palm-local positions directly, averaging joints 1–20 and

Sequence-level aggregation. For each metric, errors are first summed over eligible hand–time
entries within each sequence and divided by their valid count. Sequences with no eligible entries
are excluded. Environment-level means then weight these sequence means equally. The EgoTouch
macro-average gives equal weight to its five environment means; the Tachin overall score gives equal
weight to its eligible sequence means. This aggregation differs from pooling all frames and should
not be replaced by a sample-weighted mean from a different evaluation entry point.
Contact-conditioned evaluation. In the contact-filtered protocol, a sample is admitted when at least
one supervised hand satisfies the causal gate in Eq. 9. Per-hand masks then exclude noncontact hands
from action and future-pressure supervision. These exclusions define a contact-conditioned subset
of the held-out data, not the complete held-out test set. Retaining the base action for an excluded
hand does not insert that hand into the metric denominator. Comparisons under this protocol require
a common sample set, hand mask, and prediction horizon; results on an unfiltered test set represent
a separate evaluation protocol.

## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作方面展现出强大潜力，但将其适应到新任务和新领域仍然效率低下：现有方法往往依赖参数调优，带来高昂成本，并存在对先前学习任务发生灾难性遗忘的风险。为解决这一问题，我们提出 Optimus-R，一种以记忆为中心的 VLA 框架，将机器人适应表述为显式的查询-技能记忆调优。Optimus-R 引入：（i）用于技能提取的内联记忆接口。它将可学习记忆令牌插入 VLA 前缀流中，使骨干网络能够在原生动作条件化路径中导出控制感知的查询与技能表示。（ii）用于技能学习的查询-技能记忆库。它将技能外化为用于决定检索什么的查询原型，以及用于指定如何行动的技能值，从而在有限参数更新下支持技能复用与扩展。（iii）用于技能更新的轻量级 Bridge-and-Adapt 机制。它通过轻量级适配器和残差记忆更新，使目标域查询与技能同现有记忆空间对齐。在域内适应、跨域适应和终身学习上的实验表明，Optimus-R 能够实现数据高效的技能学习，同时缓解灾难性遗忘。

## Abstract
Vision-Language-Action (VLA) models have shown strong promise for general-purpose robotic manipulation, yet adapting them to new tasks and domains remains inefficient: existing methods often rely on parameter tuning, incurring substantial costs and risking catastrophic forgetting of previously learned tasks. To address this, we propose \textbf{Optimus-R}, a memory-centric VLA framework that formulates robotic adaptation as explicit query-skill memory tuning. Optimus-R introduces: (i) An \textbf{Inline Memory Interface for skill extraction}. It inserts learnable memory tokens into the VLA prefix stream, allowing the backbone to derive control-aware query and skill representations within the native action-conditioning pathway. (ii) A \textbf{Query-Skill Memory Bank for skill learning}. It externalizes skills into query prototypes for deciding \emph{what} to retrieve and skill values for specifying \emph{how} to act, supporting skill reuse and expansion with limited parameter updates. (iii) A lightweight \textbf{Bridge-and-Adapt mechanism for skill updating}. It aligns target-domain queries and skills with the existing memory space through a lightweight adapter and residual memory updates. Experiments on in-domain adaptation, cross-domain adaptation, and lifelong learning show that Optimus-R enables data-efficient skill learning while mitigating catastrophic forgetting.

## 1. 核心问题与整体含义

- **背景**：VLA 模型（如 π0、π0.5、OpenVLA）已成为通用机器人操作的重要范式，但部署到新任务、新物体、新场景与新领域时，主流做法仍是**参数微调**（全量微调、LoRA、Adapter 等）。
- **核心痛点**：参数中心化适配把每个新技能隐式写进模型权重，导致：① 适配成本高（数据、算力）；② 新技能难以显式检索、扩展与复用；③ 持续学习时干扰旧任务，引发灾难性遗忘。
- **关键研究问题**：能否让 VLA 通过**显式记忆接口**获取、存储与复用技能，而不是反复更新参数？
- **三个耦合子问题**：
  - 技能应从 VLA 自身动作条件化路径中导出，而非作为"外挂上下文"弱耦合；
  - 技能应显式组织为可检索、可扩展的记忆条目，而非被吸收进权重；
  - 在视觉/动力学域偏移下，目标域查询仍应能匹配源域记忆空间。
- **整体含义**：论文将机器人适配统一重述为**技能提取（skill extraction）→ 技能学习（skill learning）→ 技能更新（skill updating）**三段式流程，提出记忆中心的 VLA 框架 Optimus-R。

## 2. 方法论

### 2.1 核心思想
以"查询-技能"记忆库替代权重更新：VLA 骨干在原生前缀流中生成控制感知的查询与技能表示，技能被外化为可复用的键值原型，适配仅更新轻量对齐模块、原型残差与记忆条目。

### 2.2 关键技术细节

- **内联记忆接口（Inline Memory Interface）**
  - 将 `m=4` 个可学习记忆 token `E_mem` 拼入 VLA 前缀流：`[Hvl_t; M_t] = F_θ(O_t, L; E_mem)`，记忆状态与多模态状态在骨干内部共同演化。
  - 两个独立的注意力池化分支分别读出 `m̄^q_t`、`m̄^s_t`，经 Query Encoder 与 Skill Encoder 得到查询 `q_t ∈ R^256` 与技能 `s_t ∈ R^256`——实现"检索上下文"与"动作相关技能"解耦。
  - 训练期用轻量 Skill Decoder 以 Huber 损失重建未来动作块，把技能空间锚定在可执行行为上；Token Projector 将技能映射为 `n_s=4` 个 VLA 兼容 skill token，条件化 Flow Policy 生成动作块。

- **查询-技能记忆库（Query-Skill Memory Bank）**
  - 库结构：`B = {(p^q_j, p^s_j, n_j, E_j)}`，即查询原型（决定"检索什么"）、技能原型（决定"如何行动"）、支持计数、用于回放的隐式查询-技能样例集。
  - 构建：先做**运动感知下采样**（按动作变化量 `ν_i` 保留高动态样本）与**归一化进度分层采样**，再在查询空间聚类，对技能方差过高的簇在技能空间二次切分，从而同时保证"状态-任务可检索"与"动作空间一致"。
  - 检索：查询先经对齐矩阵 `q'_t = A_mem q_t`，对 top-`Kr=2` 原型按温度 `τ_mem` 做 softmax 加权聚合，取 `ŝ_t = Σ α_tj (p^s_j + Δp^s_j)`；**残差 `Δp` 实现局部更新而不覆盖基原型**，保证技能可复用性。

- **Bridge-and-Adapt 三阶段训练**
  - **Stage A（接口预训练）**：训练记忆 token、池化器、双编码器、Skill Decoder、Token Projector 及骨干最后几层，目标 `L_pre = L_fm + λ_q L_nce + λ_s L_skill`，其中查询对比损失以同任务近进度样本与同轨迹近邻为正例；随后冻结接口并构建初始记忆库。
  - **Stage B（跨域桥接）**：解冻骨干，与 `A_mem`、`τ_mem`、活跃原型残差联合更新；当技能空间失配较大时启用**零初始化低秩 Skill Adapter**（rank `r=8`），`s̃_t = ŝ_t + U_s V_s^⊤ ŝ_t`，初始时保持恒等。
  - **Stage C（域内终身记忆适配）**：冻结骨干与内联接口，仅更新 `A_mem`、`τ_mem`、活跃残差与记忆库。新样本若与现有原型接近则更新残差与统计量；否则进入候选缓冲，仅当簇规模与查询/技能方差满足阈值（`N_min=50` 等）才**追加新原型**。
  - 统一损失：`L_life = L_fm + λ_align‖s̃_t − sg(s_t)‖² + λ_reg Σ(‖Δp^q_j‖² + ‖Δp^s_j‖²)`；回放仅用隐式查询-技能对（不含原始图像/动作/轨迹），按约 3:1 新样本与回放样本混合。

## 7. 局限性与未来方向

- **骨干单一**：全部实验以 π0.5 为唯一 VLA 骨干，未验证在 π0、OpenVLA 等其他架构上的通用性，"内联记忆接口"对骨干结构的依赖程度尚不清楚。
- **真实世界规模有限**：仅一个双臂平台、9 个任务、每任务 20 rollouts，缺乏多平台、多任务族的验证，统计显著性与鲁棒性证据偏弱。
- **记忆库管理仍依赖阈值**：新原型的追加由 `N_min`、方差阈值等超参数控制，缺乏更自适应的增长/合并/淘汰机制，长期运行下的库膨胀与冗余问题未充分讨论。
- **回放隐私与分布**：虽仅回放隐式查询-技能对（不含原始图像/动作），但隐式表示是否仍携带可被反演的信息、以及回放分布与真实分布偏移的影响，未做深入分析。
- **未报告方差**：多数结果未给出随机种子、置信区间或多次重复的统计检验，跨方法比较的稳健性有待加强。
- **未来方向**：跨骨干验证、自适应记忆管理（增长/合并/遗忘）、多机器人平台的跨域迁移、以及与强化学习/在线纠错结合的持续改进，是可预期的延伸。

## 8. 总体评价与启示

- **贡献定位**：论文把"VLA 适配"从参数中心重述为"技能提取—技能学习—技能更新"的记忆中心流程，提出内联记忆接口 + 查询-技能记忆库 + Bridge-and-Adapt 三阶段训练，思路清晰、组件耦合合理。
- **核心价值**：以显式、可检索、可增量扩展的技能记忆替代权重更新，同时缓解了数据效率、技能复用与灾难性遗忘三个痛点，并在仿真与真实机器人上给出了一致的经验支持。
- **工程意义**：训练成本（约 86 GPU 小时）与推理频率（14 Hz）相对全量微调（560 GPU 小时）具有明显优势，新增参数仅 7M，具备较好的部署友好性。
- **方法论启示**：将"检索什么（查询）"与"如何行动（技能）"解耦、用残差更新而非覆盖原型、以隐式样例回放替代原始数据回放，这三点对后续记忆增强型 VLA 研究具有可迁移的设计参考价值。
- **需谨慎看待之处**：真实世界证据规模有限、骨干单一、未报告方差，结论的普适性仍需更大规模与多平台的验证；记忆库的长期稳定性与自适应管理是落地前需重点解决的问题。

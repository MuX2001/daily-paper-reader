## 摘要
自回归视觉-语言-动作模型通常将连续的机器人动作表示为离散标记序列，从而能够以标准的下一标记预测目标进行动作预测。FAST 通过将包含多种时间频率的动作紧凑地编码为相对较少的标记，显著改进了这种表示。然而，尽管这种压缩减少了自回归预测所需的动作标记数量，却未必能提高从有限示教中学习策略的效率。具体而言，FAST 通常为每个量化动作序列分配单一的确定性标记化，尽管多个标记序列可以表示并解码为相同的机器人运动。我们研究了利用这种表示冗余能否改进策略学习。本文提出基于随机采样的动作序列标记化（TOAST），一种随机动作标记化方法，在策略训练期间对同一量化动作序列采样替代标记化。这在保留底层机器人动作的同时，使离散监督多样化，且无需额外示教。在 LIBERO 上的实验表明，TOAST 持续优于其确定性对应方法，且提升幅度随着训练数据减少而增大；当仅有 1/16 的训练数据可用时，成功率提升 6.8 个百分点。在四项真实机器人操作任务中，TOAST 相比确定性对应方法进一步将平均成功率提升 15.8 个百分点。这些结果证明了随机动作标记化对自回归机器人策略学习的有效性，尤其是在训练数据有限时。

## Abstract
Autoregressive Vision-Language-Action models often represent continuous robot actions as discrete token sequences, enabling action prediction with standard next-token objectives. FAST has substantially improved this representation by compactly encoding action containing diverse temporal frequencies into relatively few tokens. However, while such compression reduces the number of action tokens required for autoregressive prediction, it does not necessarily improve the efficiency of policy learning from limited demonstrations. In particular, FAST typically assigns a single deterministic tokenization to each quantized action sequence, although multiple token sequences can represent and decode to the same robot motion. We investigate whether exploiting this representational redundancy can improve policy learning. In this paper, we propose TOkenization of Action sequences with STochastic sampling (TOAST), a stochastic action tokenization method that samples alternative tokenizations of the same quantized action sequence during policy training. This diversifies the discrete supervision while preserving the underlying robot action and requires no additional demonstrations. Experiments on LIBERO show that TOAST consistently improves over its deterministic counterpart, with the improvement increasing as training data decreases, achieving a 6.8 point gain in success rate when only 1/16 of training data is available. Across four real-robot manipulation tasks, TOAST further improves mean success rate by 15.8 points over the deterministic counterpart. These results demonstrate the effectiveness of stochastic action tokenization for autoregressive robot policy learning, particularly when training data are limited.

## 1. 核心问题与整体含义

- **研究背景**：自回归视觉-语言-动作模型（VLA）将连续机器人动作表示为离散 token 序列，从而可用标准的下一 token 预测目标进行动作预测。相比 flow matching 类方法，自回归 VLA 具有架构简单、能有效利用 MLLM 预训练知识、收敛更快等优势。
- **核心痛点**：FAST 等方法通过 DCT + BPE 将动作序列压缩为较少的 token，降低了自回归预测的 token 数量。但这种压缩并未必然提升从有限示教中学习策略的效率。关键在于，**频率压缩产生的 tokenization 边界对机器人动作并不具有物理意义**——一旦词表中包含跨多个量化动作值的 token，同一个量化动作序列就可以被多种 token 序列表示，且全部解码为完全相同的运动。
- **被忽视的冗余**：确定性 tokenizer 仅依据语料级频率统计选择单一 tokenization，策略在交叉熵训练下只被要求复现这一种序列。这种表示冗余长期未被利用。
- **动机来源**：NLP 领域早已认识到类似歧义，随机 tokenization（如 subword regularization）能缓解对单一分词的过度依赖，在低资源场景下尤为有效。机器人学习中示教数据采集昂贵，该问题可能更为突出——数据有限时，反复用同一种确定性 tokenization 监督，会鼓励策略过拟合到与底层运动并无唯一关联的特定 token 模式或分词边界。
- **整体含义**：论文提出 TOAST，首次将随机动作 tokenization 引入自回归机器人策略学习，将其形式化为一种**表示层面的正则化效应**，通过利用表示冗余从有限示教中提取更多有效监督。

## 2. 方法论

### 2.1 核心思想
- 在策略训练阶段，对同一量化动作序列**随机采样**多个等价 tokenization 作为监督目标；所有采样序列解码后得到完全相同的量化动作，因此底层机器人运动不变。
- 推理阶段不进行采样，仍使用确定性 tokenization 解码，**策略架构与学习目标完全不变**，仅改变训练目标的离散表示。

### 2.2 关键技术细节

- **构建动作序列 tokenizer**：
  - 对量化并扁平化的动作序列语料 \(Q=\{q_1,\dots,q_M\}\)，估计一个 unigram 语言模型词表 \(V\)，token 对应单个量化动作值或连续子序列。
  - 首先从语料中构建大型种子词表（保留所有单值 token 以确保任意序列可表示），再用标准 unigram LM 流程迭代优化词表与 token 概率，并剪枝低贡献 token 至目标词表规模。
  - 采用**维度优先（dimension-major）扁平化**，将同一动作维度的时间相邻值连续放置。
  - token 序列概率为 \(P(t)=\prod_{i=1}^{N} p(t_i)\)。

- **随机 tokenization 采样**：
  - 对给定扁平化序列 \(q\)，通过 unigram LM 分数做 **n-best 搜索**（采用 Forward-DP Backward-A* 算法，线性时间），得到 n 个候选 token 序列 \(\{t_1,\dots,t_n\}\)。
  - 第 i 个候选的分词概率近似为：
    \[
    P(t_i \mid q) \simeq \frac{P(t_i)^\alpha}{\sum_{j=1}^{n} P(t_j)^\alpha}
    \]
    其中 \(\alpha\) 控制采样分布的锐度：\(\alpha\) 越大越接近确定性，越小越接近均匀采样。
  - 关键性质：所有采样序列均解码为同一量化动作 \(q\)。

- **策略训练**：
  - 每步训练采样一个 token 序列 \(\tilde{t}\) 作为目标，最小化标准下一 token 预测损失：
    \[
    -\sum_{i=1}^{\tilde{N}} \log \pi(\tilde{t}_i \mid l, o, \tilde{t}_{<i})
    \]
  - 训练时应用采样，推理时不应用。

## 6. 主要结论与发现

- **Q1（仿真，数据规模）**：TOAST 在每个数据规模上都优于确定性对应方法，且**增益随训练数据减少而扩大**，在数据量 ≤1/2 时显著；1/16 数据时成功率提升 6.8 个百分点（42.8% vs 36.0%）。当数据 ≤1/4 时，TOAST 在所有对比方法中性能最高。
- **Q2（真机）**：TOAST 比 TOAST (deterministic) 提升 15.8 个百分点，比 FAST+ 提升 20.0 个百分点，均显著。除 Grocery Bagging 外所有任务均获得更大增益。观察显示确定性基线在需要高精度的动作（如抓取盘子边缘、精确够到抽屉把手）上频繁失败，而随机 tokenization 训练的策略在这些交互上更可靠。
- **Q3（设计选择）**：
  - \(\alpha\) 在 [0.05, 1.0] 范围内性能稳定，且始终超过确定性基线；\(\alpha\) 增大趋近确定性时性能总体下降。
  - 词表语料越贴近目标域，采样增益越大（DROID 为 +6.8，DROID+LIBERO 为 +9.6，仅 LIBERO 为 +11.9，在 1/16 规模下），且该收益不依赖外部语料。
  - 维度优先扁平化总体增益更高（1/16 时 42.8% vs 36.0%），但两种扁平化方向下采样都随数据减少而获益。
  - **敏感性分析**：确定性训练对 canonical tokenization 有很强的偏好（\(\Delta_{tok}\) 显著为正）；随机训练将该差距降至接近零，且 TOAST 在留出数据上的 \(L_{can}\) 更低（1.146 vs 1.252 at 1/8），说明这不是损失整体膨胀所致，而是降低了策略对单一 tokenization 的依赖并提升了泛化。
- **总体结论**：随机动作 tokenization 是一种简单有效、能从有限机器人示教中提取更多有用监督的方法，尤其适用于数据受限场景。

## 7. 优点

- **方法简洁且即插即用**：仅修改训练目标的离散表示，不改变策略架构、学习目标和推理流程；推理时不引入额外开销。
- **无需额外数据**：从每个已有示教中采样多种等价 tokenization，天然增加监督多样性，不增加数据采集成本。
- **理论迁移合理**：将 NLP 中成熟的 subword regularization 思想系统迁移到机器人动作 tokenization，并明确指出频率压缩 tokenizer 特有的表示冗余。
- **实验设计严谨**：
  - 设置 TOAST (deterministic) 与 FAST (rebuilt) 两组对照，有效隔离随机采样与 tokenizer 结构因素。
  - 覆盖仿真与真机、多个数据规模、多个基线方法。
  - 采用分层 bootstrap 与配对比较进行显著性检验，统计上较严格。
  - 提供了表示层面的诊断指标 \(\Delta_{tok}\)，从机制上验证方法确实降低了 tokenization 敏感性。
- **计算开销极低**：n-best 搜索线性时间，训练开销仅增加约 0.4%。
- **鲁棒性验证充分**：对 \(\alpha\)、词表语料、扁平化方向均做了敏感性分析，并显示低数据收益不依赖特定配置。

## 8. 不足与局限

- **不适用于学习式向量量化 tokenizer**：TOAST 依赖同一量化序列存在多种有效分词，对 VQ-VLA 等学习式离散表示不直接适用；扩展到学习式离散表示留待未来工作。
- **单一机器人本体**：实验仅使用 Franka 平台（仿真用末端位姿动作，真机用关节角动作），未研究跨本体的共享词表。
- **随机 tokenization 方案单一**：仅实例化 unigram 模型 + subword regularization，未与 BPE-dropout 等其他随机 tokenization 方案对比，无法确定收益来自 unigram 模型本身还是随机分词的一般机制。
- **超参数未做敏感性分析**：词表大小（

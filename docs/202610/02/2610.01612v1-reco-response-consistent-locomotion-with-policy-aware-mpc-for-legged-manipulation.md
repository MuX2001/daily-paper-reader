## 摘要
连续腿式操作要求基座持续行走时末端执行器能够精确跟踪。将强化学习（RL）与模型预测控制（MPC）相结合适合该任务：学习到的策略提供稳健的运动，而MPC协调基座与机械臂以补偿跟踪误差。然而，MPC只能补偿其能够预测的基座运动，并且学习策略的指令响应会随步态相位、接触和负载变化。我们提出ReCo，一个将响应一致的运动与策略感知MPC耦合用于腿式操作的框架。响应塑形训练策略在随机化动力学下一致且可重复地响应指令。随后，辨识得到的闭环响应模型使MPC能够联合规划运动指令和机械臂运动。在仿真基准上，ReCo相对各指标的最佳基线将位置和姿态均方根误差（RMSE）分别降低28.7%和27.4%。真实世界实验展示了机载连续腿式操作，且基座与机械臂运动协调。

## Abstract
Continuous legged manipulation requires accurate end-effector tracking while the base keeps walking. Combining reinforcement learning (RL) with model predictive control (MPC) suits this task: the learned policy provides robust locomotion, while MPC coordinates the base and arm to compensate for tracking errors. However, MPC can compensate only for base motion that it can predict, and a learned policy's command response varies with gait phase, contact, and payload. We present ReCo, a framework that couples response-consistent locomotion with policy-aware MPC for legged manipulation. Response shaping trains the policy to respond to commands consistently and repeatably across randomized dynamics. An identified closed-loop response model then lets MPC jointly plan locomotion commands and arm motion. On the simulation benchmark, ReCo reduces position and orientation root-mean-square error (RMSE) by 28.7% and 27.4% relative to the best baseline for each metric. Real-world experiments demonstrate onboard continuous legged manipulation with coordinated base and arm motion.

## 2. 方法论

### 2.1 总体框架（三段式）

1. **响应一致运动训练（Response Shaping）**：训练策略，使其在随机化动力学下对指令的响应一致、可重复。
2. **闭环响应模型辨识（Closed-Loop Response Model）**：离线辨识策略–机器人闭环的指令响应模型。
3. **策略感知 MPC（Policy-Aware MPC）**：联合规划运动指令与机械臂运动。

### 2.2 问题形式化

- 目标：跟踪时间索引的世界坐标系 EE 位姿参考 $T^{ref}_{WE}(t) \in SE(3)$。
- 帧定义：$W$（世界）、$B$（基座）、$E$（末端）；$T_{AB}$ 表示从 B 到 A 的坐标映射。
- 指令向量：$c = (c_x, c_y, c_\omega, c_h, c_\theta) \in \mathbb{R}^5$，分别为平面速度、偏航角速度、高度、俯仰。
- 基座预测状态：$x_{base} = (p_W, \psi, \theta, \rho, v_x, v_y, \omega_z) \in \mathbb{R}^9$（位置、ZYX 偏航/俯仰/横滚、航向系速度、机体 z 轴角速度）。注意：策略没有横滚指令，但横滚仍作为预测状态（影响 EE 位姿）。
- 完整状态与输入：$x = (x_{base}, \varphi, q) \in \mathbb{R}^{16}$，$u = (c, u_q) \in \mathbb{R}^{11}$，其中 $\varphi$ 为步态相位，$q \in \mathbb{R}^6$ 为机械臂关节位置，$u_q$ 为关节速度指令。

### 2.3 响应一致运动训练

- 使用 **PPO** 训练，采用 **Walk These Ways** 的步态条件接口；每个预测时域内步态设置固定。
- 响应塑造作用在 $y = (v_x, v_y, \omega_z, h, \theta)$ 五个通道上（$h$ 为相对标称值的机体高度）。
- **临界阻尼参考生成器**（每个通道）：
  $$\ddot{\xi}_i = \lambda_i^2 (c_i - \xi_i) - 2\lambda_i \dot{\xi}_i, \quad |\dot{\xi}_i| \le r_i$$
  未饱和时用精确零阶保持更新，饱和时产生速率受限的斜坡。
- **步态振荡分离**：$\tilde{y} = y - \hat{\delta}(\varphi, \nu)$，其中 $\hat{\delta}$ 是对步态周期分量的估计（按相位与速度分箱的滑动均值，仅在标称域环境更新）。
- **参考跟踪奖励**：
  $$r_{ref} = g \cdot \frac{\sum_i w_i \exp[-(\tilde{y}_i - \xi_i)^2 / \sigma_i^2]}{\sum_i w_i}$$
  门控 $g \in \{0,1\}$ 在外部扰动及扰动后区间内关闭该奖励，让恢复优先于瞬态匹配。
- **四项响应塑造项**（Table I）：
  - 参考跟踪 $r_{ref}$（正项，进入 $r^+$）；
  - **相位重复性** $\ell_{phase} = \sum_i \mu_i^{ph} w_i^{ph}(y_i - \bar{y}_i - \hat{\delta}_i)^2$，惩罚偏离可重复波形的程度（而非振幅）；
  - **稳态增益** $\ell_{gain} = \sum_i \mu_i^{ss} w_i^{ss}(\tilde{y}_i - c_i)^2$，抑制稳态指令偏差；
  - **跨域一致性** $\ell^d_{domain} = m_d \|\tilde{y}^d - \tilde{y}^{nom}\|^2_{W_d}$，同组环境共享相同指令序列与步态相位，包含标称环境与随机化质量/负载/摩擦/执行器强度实例。
- **奖励合成**：$r = r^+ \exp(c^- r^-)$，$c^- > 0$。训练课程：先建立运动能力，再依次引入参考跟踪、一致性惩罚、更大随机化与更强扰动。

### 2.4 闭环响应模型

- **速度通道一阶模型**：$\dot{v}_i = (k_i c_i - v_i)/\tau_i$，$i \in \{x, y, \omega\}$，$v_\omega = \omega_z$；每个速度通道仅用**一个响应状态**以保持时域优化紧凑。
- **高度/俯仰/横滚的步态周期分量**（谐波级数）：
  $$\delta_j = \sum_{n=1}^{N_h} (a^0_{jn} + a^1_{jn}\nu)\sin(n\varphi + \beta_{jn})$$
  $$\dot{\eta}_j = b_j + \frac{k_j c_j - (\eta_j - \delta_j)}{\tau_j} + \dot{\delta}_j, \quad \dot{\varphi} = 2\pi f_g$$
  其中 $j \in \{z, \theta, \rho\}$，$c_z = c_h$，横滚通道无指令输入（$k_\rho = 0$）；平滑平面速度 $\nu = \sqrt{v_x^2 + v_y^2 + \varepsilon}$；$N_h = 2$ 捕获整步与半步分量；仅 $b_z \ne 0$，设定零高度指令时的标称安装面高度。
- **其他动力学**：平面世界系速度由偏航旋转得到；ZYX 偏航率满足 $\dot{\psi} = \omega_z + \frac{\sin\rho \dot{\theta}}{\cos\theta \cos\rho}$。
- **辨识方法**：对每个冻结策略离线辨识；用**有界非线性最小二乘**最小化多步开环预测误差；激励信号为阶跃、斜坡、chirp 指令，覆盖随机化域；辨识数据与预测/跟踪实验数据分离。
- 该模型**不显式建模机械臂引起的力/力矩**。

### 2.5 策略感知 MPC

- 由响应模型与机械臂运动学 $\dot{q} = u_q$ 得到 $\dot{x} = f(x,u)$；正运动学给出 $T_{WE} = T_{WB} T_{BE}(q)$。
- **优化问题**：
  $$\min_{x(\cdot),u(\cdot)} \Phi(x(t+H)) + \int_t^{t+H} [\ell(x,u,t') + P(x,u)] dt'$$
  约束为 $\dot{x} = f(x,u)$、$x(t) = \hat{x}(t)$；$P$ 包含关节限位、指令限位与选定自碰撞距离的软惩罚。
- **阶段代价**（五项）：
  $$\ell = \tfrac{1}{2}\|e_p\|^2_{Q_p} + \tfrac{1}{2}\|e_R\|^2_{Q_R} + \tfrac{1}{2}\|\dot{p}_{WE} - \dot{p}^{ref}_{WE}\|^2_{Q_v} + \tfrac{1}{2}\|u\|^2_{R_u} + \ell_{base} + \ell_{posture}$$
  - $\ell_{base}$ 惩罚俯仰、横滚、偏航率及指令–响应偏差；$\ell_{posture}$ 惩罚机械臂偏离标称紧凑构型。
  - 四元数姿态残差：$e_R = w v_r - w_r v + v \times v_r$，参考四元数在 $w_r w + v_r^\top v < 0$ 时符号对齐；评估用测地旋转角。
  - 参考处理：位置线性插值，姿态四元数插值，参考速度取插值位置斜率；终端代价 $\Phi$ 惩罚 EE 位姿误差。
- **求解**：OCS2 多重打靶 SQP + 自动微分，用上一次解热启动；参考管理器以高于 MPC 更新率采样并保持运动指令；通过将测量状态向前传播一个采样间隔补偿反馈延迟。
- **反馈量**：基座状态、机械臂关节位置、策略时钟的步态相位（相位在打靶约束中包裹到 $[0, 2\pi)$）。

## 3. 实验设计

### 3.1 平台与基准

- **机器人**：Unitree Go2 + 六自由度 ARX X5 机械臂。
- **仿真**：MuJoCo，积分步长 2.5 ms；确定性 16×16 m 滚动高度场，高度范围 −0.10 至 0.10 m，RMS 高度 0.0438 m。
- **Benchmark**：50 条世界坐标系 EE 位姿轨迹，由随机草图路径生成，几何与时间各异；目标点可能位于固定基座下机械臂工作空间之外，**必须靠行走才能到达**，用以测试持续基座–机械臂协同。
- **扰动条件**：每条轨迹在标称下执行一次，另在基座质心施加 **80 N 世界系 +X 方向力、持续 0.1 s（8 N·s 冲量）** 下执行一次，共 **100 次运行/控制器**。
- **成功率定义**：最终进度 ≥ 97% 且无跌倒/数值故障/提前终止；端点位置与姿态误差在 0.15 m 与 40° 内持续 ≥ 0.5 s；

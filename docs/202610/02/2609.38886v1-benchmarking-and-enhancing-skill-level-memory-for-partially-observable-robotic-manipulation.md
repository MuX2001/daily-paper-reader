## 摘要
机器人学习的最新进展使操作策略能够执行日益多样化的任务并跨环境泛化。然而，可靠执行通常依赖于无法仅从当前观测确定的隐藏任务状态，这使得交互历史至关重要。我们提出 $HIDE$，一个用于评估部分可观测性下操作记忆的基准。HIDE 包含 15 项任务，涵盖重复计数、历史状态回忆和执行进度跟踪，并具有随机化的初始配置和决策点，在这些决策点，相似的观测需要根据先前事件采取不同的动作。我们进一步提出 $SEEK$，一个结合三种互补记忆机制的框架，以保留历史证据并跟踪执行状态。评估揭示了现有策略在 HIDE 上的显著局限，而记忆增强在仿真和真实世界实验中均提升了任务成功率。单个机制对某些任务有益，但可能损害其他任务；它们的组合在评估配置中于 HIDE 上取得了最高平均成功率。这些发现强调了维护隐藏任务状态内部表示以及使记忆设计与任务特定信息需求相匹配的重要性。

## Abstract
Recent advances in robot learning have enabled manipulation policies to perform increasingly diverse tasks and generalize across environments. However, reliable execution often depends on hidden task states that cannot be determined from current observations alone, making interaction history essential. We introduce $HIDE$, a benchmark for evaluating manipulation memory under partial observability. HIDE comprises 15 tasks covering repetition counting, historical-state recall, and execution-progress tracking, with randomized initial configurations and decision points where similar observations require different actions depending on prior events. We further propose $SEEK$, a framework combining three complementary memory mechanisms to retain historical evidence and track execution state. Evaluations reveal substantial limitations in existing policies on HIDE, while memory augmentation improves task success in both simulation and real-world experiments. Individual mechanisms benefit some tasks but can degrade others; their combination achieves the highest average success rate on HIDE among the evaluated configurations. These findings highlight the importance of maintaining internal representations of hidden task states and matching memory design to task-specific information requirements.

## 2. 方法论：核心思想、技术细节与算法流程

### 2.1 问题形式化（HIDE 的理论基础）

- 将操作建模为部分可观测决策过程：智能体在时刻 $t$ 接收任务指令 $g$、当前观测 $o_t$，可选历史 $h_t=(o_{1:t}, a_{1:t-1})$。
- 状态分解为 $s_t = (x_t, z_t)$：$x_t$ 为可观测物理状态，$z_t$ 为任务相关潜在状态。
- 最优策略满足：
  $$\pi^*(a_t \mid h_t, g) = \pi^*(a_t \mid o_t, z_t, g)$$
- **隐藏状态依赖任务的定义**：存在两条历史 $h_t$ 与 $h'_t$，使得当前观测视觉等价、但潜在状态不同且最优动作不同：
  $$d(o_t, o'_t) \le \epsilon,\quad z_t \neq z'_t,\quad \pi^*(\cdot \mid h_t, g) \neq \pi^*(\cdot \mid h'_t, g)$$

### 2.2 HIDE 基准的三类任务

- **重复计数（Repetition Counting, RC）**：机器人需按指定次数重复操作（如按按钮 N 次、堆叠 N 个方块、切换频道 N 次、叠杯子、放入容器），需跟踪已完成次数以决定继续、停止或切换。
- **历史状态回忆（Historical-State Recall, HSR）**：需基于先前观察过的信息行动（物体颜色、身份、位置或早期场景配置），该信息在决策点因遮挡、场景变化或视觉混淆而不可见。
- **执行进度跟踪（Execution-Progress Tracking, EPT）**：多子步骤任务中，中间观测无法唯一揭示哪些步骤已完成，需用执行历史判断进度，避免重复、跳步或提前终止。

### 2.3 SEEK 框架：三种互补记忆机制

- **窗口上下文记忆（Windowed Context Memory, WCM）**：
  - 保留最近 $K$ 条交互记忆，按时间顺序排列，窗口满后替换最旧条目；
  - 帮助跟踪"刚刚发生了什么"（如最近检查的位置及其内容变化），但无法无限期保留证据。
- **持久锚点记忆（Persistent Anchor Memory, PAM）**：
  - 在证据离开近期窗口后仍可访问，例如早期观测揭示的物体身份或位置后来被遮挡；
  - 设 WCM 索引集为 $I^W_t$，可用归档为 $A_t = \{i : 0 \le i < t,\ i \notin I^W_t\}$，检索方式为：
    $$a_t = \arg\max_{i \in A_t} \cos(k_t, k_i)$$
    其中 $k_t, k_i$ 为记忆融合前计算的池化视觉描述子；
  - 每个描述子与对应交互记忆一起存储，将紧凑检索键与用于动作预测的空间特征分离；锚点每次决策重新计算，无可用条目时省略。
- **阶段计数器记忆（Stage-Counter Memory, SCM）**：
  - 用离散计数器加学习到的阶段嵌入表示进度，计数器从 0 开始，在策略预测阶段边界时递增；
  - 与 WCM/PAM 描述"过去交互"不同，SCM 指示"执行已推进到何处"，对重复动作导致场景外观相似的情形尤为关键；计数在预测的交互边界变化而非每个控制步，保证动作展开期间进度稳定。

### 2.4 记忆编码与检索

- 多相机 RGB-D 观测渲染为三个虚拟视图；共享记忆编码器将视觉特征 $X^v_t$ 与预测的粗粒度平移热图 $H^v_t$ 结合，生成交互记忆 $m^v_t$，把场景内容与预测操作目标关联；记忆仅在动作预测后写入，供后续决策使用。
- 保留空间特征图以保留交互证据的位置，使检索提供**局部化**而非全局历史信息。
- 记忆组合与注意力读取：
  $$M^v_t = [W^v_t;\ m^v_{a_t};\ S_t],\quad \tilde{X}^v_t = \mathrm{MemoryAttn}(X^v_t, M^v_t)$$
- 无可用归档条目时省略锚点；空间与时间编码区分视图结构与记忆槽，SCM 使用独立位置嵌入；遵循 SAM 2，当前视觉特征对记忆做注意力以检索任务相关历史与进度；**读取预算有界**：至多 $K$ 条近期条目 + 1 个锚点 + 每视图 1 个阶段表示，与归档长度无关。

### 2.5 记忆增强的操作策略与训练

- 基于语言条件、粗到细的多视图策略：粗分支用记忆条件特征预测工作空间平移热图，其目标定义局部区域供细分支预测位置、旋转与夹爪状态；记忆影响目标选择在局部精修之前，细分支不独立检索归档。
- 预测后存储交互供未来 WCM/PAM 读取，阶段转移预测更新 SCM；所有记忆与计数器在回合间重置。
- **训练目标**：行为克隆，动作损失监督粗/细平移、旋转、夹爪状态与碰撞相关预测，另有阶段边界损失：
  $$\mathcal{L} = \mathcal{L}_{act} + \lambda_{stage}\,\mathcal{L}_{stage}$$
- 训练序列按时间顺序处理并使用标注的阶段状态；推理时用策略预测在线更新记忆与计数器；仅**前序观测**有资格参与检索。
- **两阶段训练流程**：Stage 1 学习无记忆操作策略（用 LoRA 适配预训练视觉骨干，优化粗/细动作分支）；Stage 2 从 Stage 1 第 20 轮检查点出发引入时序记忆训练，冻结视觉骨干（含 LoRA），训练记忆编码器、记忆注意力、阶段相关参数与两个动作分支。

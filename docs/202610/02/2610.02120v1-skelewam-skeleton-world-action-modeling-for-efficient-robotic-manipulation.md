## 摘要
世界动作模型（WAM）将机器人动作生成与未来状态预测相结合。现有的 WAM 通常预测视频或学习到的视觉隐表示，这些表示仅隐式地刻画交互几何，并可能保留与控制无关的外观信息。我们提出 SkeleWAM，一种紧凑的 WAM，将操作场景表示为由机器人关节、物体中心和交互点组成的稀疏三维骨架。该骨架由当前 RGB-D 观测和机器人本体感知在线构建，为动作生成和未来骨架预测提供统一的几何状态。未来骨架预测为动作学习提供额外的几何监督，而无需视觉重建。在推理时，SkeleWAM 直接从当前骨架和语言指令生成动作，而 Medoid Action Consensus（MAC，中心点动作共识）作为一种辅助共识策略，用于处理随机动作样本。在 LIBERO-Plus 上，SkeleWAM 以 57.1M 参数实现了 85.9% 的总体成功率，比 Cosmos-Policy 高出 3.7 个百分点。这些结果表明，稀疏的三维机器人-物体结构为稳健且参数高效的世界动作学习提供了有效的状态空间。项目见 https://skelewam-project.github.io/。

## Abstract
World action models (WAMs) combine robot action generation with future state prediction. Existing WAMs typically predict videos or learned visual latents, which represent interaction geometry only implicitly and may retain appearance information unrelated to control. We introduce SkeleWAM, a compact WAM that represents a manipulation scene as a sparse 3D skeleton composed of robot joints, object centers, and interaction points. Constructed online from current RGB-D observations and robot proprioception, the skeleton provides a unified geometric state for action generation and future skeleton prediction. Future skeleton prediction provides additional geometric supervision for action learning without requiring visual reconstruction. At inference, SkeleWAM generates actions directly from the current skeleton and language instruction, while Medoid Action Consensus (MAC) serves as an auxiliary consensus strategy for stochastic action samples. On LIBERO-Plus, SkeleWAM achieves an overall success rate of 85.9% with 57.1M parameters, outperforming Cosmos-Policy by 3.7 percentage points. These results demonstrate that sparse 3D robot--object structure provides an effective state space for robust and parameter-efficient world action learning. The project is available at https://skelewam-project.github.io/.

- **核心问题**：现有 WAM 通常将未来状态表示为生成的视频或学习到的视觉隐变量（如 WorldVLA、UniVLA、DreamZero、GE-Act、Cosmos-Policy、VLA-JEPA、Fast-WAM）。这些表示仅隐式地表达交互几何，且信息保留在很大程度上受视觉编码器及其预训练目标的影响；压缩视觉观测本身并不能分离出支配机器人-物体交互的几何变量（如空间构型与相对运动）。
- **核心追问**：能否用机器人-物体结构的稀疏表示来支撑有效的世界动作学习，同时大幅降低模型复杂度？
- **整体含义**：论文提出用由机器人关节、物体中心和交互点组成的稀疏三维骨架作为统一状态空间，同时学习动作生成与未来骨架预测。实验表明，稀疏且显式的机器人-物体几何是稳健、参数高效的世界动作学习的有效状态表示。

## 2. 论文提出的方法论

### 2.1 核心思想

- 将操作场景表示为一个**稀疏三维骨架** $S_t \in \mathbb{R}^{N \times 3}$，由机器人关节/末端执行器位置和任务相关物体地标组成。
- 骨架**在线构建**：机器人关键点通过前向运动学计算；物体地标（中心与交互点）由冻结的预训练感知网络从 RGB-D 观测估计。所有坐标统一表达在机器人为中心的共享坐标系中，并用训练集统计量归一化。
- 训练时联合学习动作生成与未来骨架预测；**推理时省略未来骨架预测分支**，直接从当前骨架和语言指令生成动作。

### 2.2 关键技术细节

- **问题形式化**：给定语言指令 $\ell$、当前 RGB-D 观测 $o_t$、本体感知状态 $q_t$，目标是生成动作块 $A_t = [a_t, \ldots, a_{t+H_a-1}] \in \mathbb{R}^{H_a \times d_a}$。骨架由 $S_t = \Phi_\psi(o_t, q_t, \ell)$ 提取；训练时额外定义未来骨架序列 $S^+_t = [S_{t+\delta_1}, \ldots, S_{t+\delta_{H_s}}]$。条件分布为 $p^a_\theta(A_t|S_t,\ell)$ 和 $p^s_\theta(S^+_t|S_t,\ell)$。
- **骨架组成**：物体 $m$ 表示为 $P_{t,m} = [c_{t,m}; u_{t,m,1}; \ldots; u_{t,m,L_m}]$，其中 $c_{t,m}$ 为物体中心，$u_{t,m,j}$ 为交互点。完整骨架为 $S_t = [J_t; P_{t,1}; \ldots; P_{t,M}]$，节点数 $N = N_r + \sum_m (1+L_m)$。机器人节点遵循运动学连接，物体中心连接其交互点；节点身份、顺序和连接在时间上保持一致。
- **模型架构**：语言指令编码为 $C_\ell = E_{lang}(\ell)$。输入适配器将当前骨架、含噪动作块、含噪未来骨架序列映射为 token：$X^c_t = \phi_c(S_t)$，$X^a_{t,\tau_a} = \phi_a(\tilde{A}_{t,\tau_a})$，$X^s_{t,\tau_s} = \phi_s(\tilde{S}^+_{t,\tau_s})$。采用类似 Fast-WAM 的双专家 Mixture-of-Transformers 设计：**world expert** 用共享参数处理当前与未来骨架 token，**action expert** 处理动作 token，二者均以语言上下文 $C_\ell$ 为条件。
- **块注意力掩码**：对 token 组 $(X^c_t, X^a_{t,\tau_a}, X^s_{t,\tau_s})$，掩码矩阵为 $\begin{bmatrix}1&0&0\\1&1&0\\1&0&1\end{bmatrix}$。当前骨架 token 仅在自身组内注意力；每个预测组关注当前骨架和自身；动作 token 与未来骨架 token 之间无注意力（消融证明该设计最优，且允许推理时移除未来骨架分支）。
- **训练目标（Flow Matching）**：对演示对 $(A_t, S^+_t)$ 采样独立高斯噪声 $\epsilon_a, \epsilon_s$ 和噪声时间 $(\tau_a, \tau_s) \sim \rho$，插值路径为 $\tilde{A}_{t,\tau_a} = (1-\tau_a)A_t + \tau_a\epsilon_a$，$\tilde{S}^+_{t,\tau_s} = (1-\tau_s)S^+_t + \tau_s\epsilon_s$（噪声时间 0 对应数据，1 对应噪声）；目标向量场为 $v_a = \epsilon_a - A_t$，$v_s = \epsilon_s - S^+_t$。联合损失为 $L = L_{action} + \lambda_s L_{skeleton}$，其中 $L_{action} = \mathbb{E}[\text{MSE}(\hat{v}^a_\theta, v_a)]$，$L_{skeleton} = \mathbb{E}[\text{MSE}(\hat{v}^s_\theta, v_s)]$。两个损失都更新 world expert：骨架损失监督未来几何预测，动作损失经由当前骨架上下文传播。
- **推理**：从 $\tilde{A}_{t,1} \sim \mathcal{N}(0, I)$ 出发，沿学习到的动作向量场从 $\tau: 1 \to 0$ 积分，得到动作块 $A_t = \tilde{A}_{t,0}$。
- **Medoid Action Consensus (MAC)**：给定 $K \geq 2$ 个从独立噪声初始化的候选动作 $\{A^{(k)}_t\}$，在归一化动作空间中比较其前 $h \leq H_a$ 步、$d_m$ 个连续运动维度：$d_{ij} = \frac{1}{h d_m}\|(A^{(i)}_t)_{1:h,1:d_m} - (A^{(j)}_t)_{1:h,1:d_m}\|_F^2$。MAC 选择平均不相似度最小的候选：$c_i = \frac{1}{K-1}\sum_{j\neq i} d_{ij}$，$i_{sel} = \arg\min_i c_i$，$A^{MAC}_t = A^{(i_{sel})}_t$。完整选中块（含未参与距离计算的维度）被保留。MAC 无需奖励模型或价值模型，也避免平均可能不兼容的轨迹；$K=1$ 时直接使用唯一候选。
- **执行流程**：执行前 $H_e \leq H_a$ 个动作后更新骨架并重新规划；$H_e$ 控制重规划频率，共识窗口 $h$ 仅用于候选选择。

## 6. 论文的主要结论与发现

- **仿真结果**：SkeleWAM 以 **57.1M 参数**取得 **85.9%** 总体成功率，比最强的观测基线 Cosmos-Policy（82.2%）高 **3.7 个百分点**；在相机扰动下达到 **93.4%**，比 Cosmos-Policy 高 **17.6 个百分点**；在语言、背景、噪声扰动下均取得观测方法中的最佳结果（89.1%、96.0%、93.9%）。
- **特权输入参考**：SkeleWAM (sim-state) 达到 87.7% 总体成功率（51.4M 参数），比 RGB-D 版本高 1.8 个百分点，说明冻结感知网络提供的骨架估计有效，同时仍有改进空间。
- **布局扰动瓶颈**：布局扰动下仅 66.6%（sim-state 也仅 69.0%），显著低于 π0.5 的 84.1%，说明稀疏几何观测本身不足以应对大幅空间排布变化，且该困难超出视觉定位范畴、也涉及策略对新空间构型的泛化能力。
- **真实世界结果**：SkeleWAM 平均成功率 **89%**，超过 Cosmos-Policy（87%）、Fast-WAM（83%）、π0.5（76%）分别 2、6、13 个百分点，在 5 个任务中的 4 个取得最高或并列最高成功率。
- **消融结论**：
  - 物体中心 + 交互点的组合（85.9%）优于仅中心（82.3%）和仅交互点（77.7%），分别高出 3.6 和 8.2 个百分点。
  - 移除未来骨架损失与 token 后成功率从 85.9% 降至 80.1%，说明未来几何监督带来 5.8 个百分点的提升，主要收益来自共享 world expert 的协同训练，而非分支间的直接信息交换。
  - 无跨分支注意力（85.9%）略优于 $S^+\to A$（85.6%）和 $A\to S^+$（84.8%），且允许推理时移除未来分支。
  - 执行视野 $H_e=16$（85.9%）优于 $H_e=5$（80.7%）和 $H_e=32$（81.8%）。
  - MAC 候选数 $K=3$（85.9%）优于 $K=1$（84.2%）、$K=5$（85.2%）、$K=10$（84.1%），性能不随采样预算单调增长。
  - 共识窗口在 3–16 之间性能稳定（最大差异 0.6 个百分点），$h=10$ 最佳（85.9%）。

## 7. 优点

- **状态表示创新**：用显式、稀疏的 3D 机器人-物体骨架替代视频/视觉隐变量，直接参数化交互几何，剥离与控制无关的外观信息，理论上更贴合操作控制需求。
- **参数效率突出**：57.1M 参数即超越约 2B–7.7B 参数的主流基线与世界模型方法，在成功率、推理速度、模型规模和计算成本之间取得良好折中。
- **训练-推理解耦设计**：未来骨架预测仅作为训练时的辅助监督，推理时完全省略，既获得几何监督收益又不增加推理开销；无跨分支注意力的设计进一步支持这一解耦。
- **MAC 策略轻量实用**：无需奖励模型或价值模型，不做轨迹平均，仅通过中心点选择代表性候选，避免平均不兼容轨迹，且消融显示 $K=3$ 即有稳定收益。
- **实验设计严谨**：消融逐变量控制、区分观测与特权输入、明确报告失败案例（布局扰动），并配有真实世界验证与定性可视化。
- **强鲁棒性**：在相机、语言、背景、噪声扰动下均表现最佳，尤其相机扰动下比 Cosmos-Policy 高 17.6 个百分点，体现出机器人中心坐标系几何表示的视角不变性优势。

## 8. 不足与局限

- **布局泛化瓶颈**：布局扰动下仅 66.6%，明显落后于 π0.5（84.1%）；即使用特权仿真器坐标也仅 69.0%，说明稀疏几何表示本身不能完全捕捉空间泛化所需的变异，论文也承认这是主要局限。
- **感知依赖**：主设置依赖冻结的预训练感知网络估计物体中心与交互点，存在视觉定位误差；sim-state 与 RGB-D 之间 1.8 个百分点的差距说明感知仍是误差来源之一。
- **真实世界实验规模有限**：仅 5 个桌面级任务、每任务 20 次试验，任务类型偏单一（抽屉、方块、碗），未涉及双臂、可变形物体、长时序多阶段任务等更复杂场景，统计置信度与泛化性证据有限。
- **骨架定义依赖人工先验**：交互点的数量、位置与语义由任务相关设定，跨任务/跨物体类别的自适应交互地标尚未解决（论文将其列为未来工作）。
- **算力信息不完整**：仅说明使用单块 RTX 4090、60K 步训练，未报告训练时长、显存、能耗等，复现成本不易评估。
- **对比公平性细节**：基线参数规模差异巨大（57.1M vs 2B–7.7B），虽凸显参数效率，但不同规模模型的训练数据、预训练来源、调参预算是否对齐未充分披露；真实世界基线（Fast-WAM、Cosmos-Policy）是否经过同等适配也未详细说明。
- **未来工作方向**：论文建议引入不确定性感知感知、自适应交互地标和更丰富的关系结构，同时保持骨架表示的紧凑性。

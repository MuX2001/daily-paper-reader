## 摘要
从有限示教中学习面向多样、长时程任务的鲁棒操作策略，仍然是机器人学中的一项基础性挑战。我们提出 DROM，一种语言引导的扩散框架，使机器人能够在单一生成策略中学习、表示和组合多种操作技能。DROM 利用动态运动基元（DMPs）将少量专家示教增强为具有表现力的多技能数据集，在显著减少数据采集的同时，提升超出示教工作空间的空间泛化能力。基于运动规划扩散（MPD），我们扩展扩散架构，通过交叉注意力支持语言条件下的多技能轨迹生成，使单一模型能够为多种操作基元生成技能一致的运动，包括使用传统运动规划或硬编码控制器难以设计的姿态敏感行为。对于长时程操作，大语言模型将高层操作员请求分解为可执行的技能序列，从而实现自然语言交互和自主任务执行。我们在 Franka Emika Panda 机器人、FANUC CRX25ia 机器人以及 MuJoCo 仿真中，在多种操作任务上验证了 DROM。实验结果表明，DROM 优于运动规划扩散和行为克隆基线，实现了鲁棒的多技能泛化，并能够组合学习到的技能，仅使用少量人类示教即可可靠执行来自自然语言指令的长时程操作任务。数据集、仿真环境及更多内容见 https://github.com/automation-robotics-machines/drom。

## Abstract
Learning robust manipulation policies for diverse, long-horizon tasks from limited demonstrations remains a fundamental challenge in robotics. We present DROM, a language-guided diffusion framework that enables robots to learn, represent, and compose multiple manipulation skills within a single generative policy. DROM leverages Dynamic Movement Primitives (DMPs) to augment a small set of expert demonstrations into expressive multi-skill datasets, substantially reducing data collection while improving spatial generalization beyond the demonstrated workspace. Building upon Motion Planning Diffusion (MPD), we extend the diffusion architecture to support language-conditioned multi-skill trajectory generation through cross-attention, allowing a single model to generate skill-consistent motions for a diverse set of manipulation primitives, including orientation-sensitive behaviors that are difficult to design using conventional motion planning or hard-coded controllers. For long-horizon manipulation, a large language model decomposes high-level operator requests into executable sequences of skills, enabling natural language interaction and autonomous task execution. We validate DROM on a Franka Emika Panda robot, a FANUC CRX25ia robot, and in MuJoCo simulation across a wide range of manipulation tasks. Experimental results demonstrate that DROM outperforms Motion Planning Diffusion and Behavior Cloning baselines, achieves robust multi-skill generalization, and composes learned skills to reliably execute long-horizon manipulation tasks from natural language instructions using only a limited number of human demonstrations. Datasets, simulation environments, and more at https://github.com/automation-robotics-machines/drom.

# DROM 论文中文总结

## 一、核心问题与研究动机

- **背景痛点**：机器人在非结构化环境中可靠操作仍是核心难题。传统模仿学习依赖大规模任务专用数据集，通常局限于单一技能，难以跨任务复用；当工作空间与物体位姿偏离训练分布时泛化能力差。
- **现有路线瓶颈**：
  - 视觉-语言-动作（VLA）基础模型需要互联网级海量数据，且推理计算繁重、延迟高，难以满足物理硬件的实时/反应式控制需求。
  - 扩散模型与 Flow Matching 虽能建模复杂多模态运动分布，但现有扩散操作策略多局限于单一技能，且对每个子任务都需专门采集数据，从原始人类示教从头训练时样本效率低。
- **核心缺口**：如何在**不进行大规模人类示教采集**的前提下，满足扩散模型对密集数据的需求；同时**不把大语言模型的推理延迟引入底层控制回路**，实现语言引导的长时程任务执行。
- **整体含义**：DROM 提出一个语言引导的多技能扩散框架，把"数据增强 + 统一多技能生成策略 + 分层语言推理"整合为单一方案，使机器人仅凭少量示教即可学习、表示并组合多种操作技能。

## 二、方法论

### 2.1 核心思想

- 将**任务推理**与**运动生成**解耦：高层用语言模型做任务分解，底层用单一语言条件扩散模型生成笛卡尔轨迹与夹爪指令。
- 用 DMP 把小规模专家示教"数学地"扩展为大规模、技能一致的合成数据集，绕过扩散模型的样本效率瓶颈。

### 2.2 关键技术细节与流程

- **数据采集**：每个技能通过动觉示教（真实机器人）或 SpaceMouse（MuJoCo 仿真）采集 $L_k \ge 1$ 条示教，30 Hz 记录；轨迹固定地平线 $H=64$，每个路点含末端位置 $(P_x,P_y,P_z)$、四元数姿态 $(Q_x,Q_y,Q_z,Q_w)$ 及二值夹爪指令 $G\in\{-1,+1\}$。姿态敏感技能（如抓瓶、抓杯）需多条示教以覆盖多模态操作策略。
- **DMP 增强**：每条示教学一个 DMP（二阶动力学系统 + 200 个高斯基函数 + 局部加权回归 LWR，$\alpha_y=25$、$\beta_y=6.25$ 临界阻尼）。通过扰动起点与目标状态并保持演示运动模式生成合成轨迹，每个技能固定产出 $M=300$ 条经任务成功准则验证的轨迹，重采样至 $H=64$，与语言嵌入配对构成训练集。
- **技能条件扩散模型**：基于 MPD 的时序 U-Net 架构（4 层时序下采样，通道 32→256，含残差时序块与时序注意力，约 6000 万参数），训练目标为预测噪声：
  - 前向过程 $q(\tau_t|\tau_{t-1})=\mathcal{N}(\tau_t;\sqrt{1-\beta_t}\tau_{t-1},\beta_t I)$，闭式边缘分布 $q(\tau_t|\tau_0)=\mathcal{N}(\sqrt{\bar\alpha_t}\tau_0,(1-\bar\alpha_t)I)$；
  - 损失 $\mathcal{L}(\theta)=\mathbb{E}_{t,\epsilon,\tau_0}\|\epsilon-\epsilon_\theta(\tau_t,t)\|_2^2$；
  - 关键扩展：将技能嵌入 $f_\theta(p)$ 通过**交叉注意力层**注入每个去噪步与 U-Net 每一层，使单一模型支持 17 种操作基元，并区分几何相似但运动策略不同的行为。
- **双语言条件框架**：
  - **轻量语言编码器**（all-MiniLM-L6-v2，6 层 Transformer，384 维嵌入）做指令到技能的相似度检索。
  - **聚类共形预测（CP）**做不确定性量化：对每技能采集话语集 $U_k$，计算同技能样本间最大余弦相似度作为 conformal score，将技能聚类为若干组，按簇级分位数设定阈值 $\lambda_k$（显著性水平 $\alpha$）。三种情形：(i) 所有技能分数均超阈值 → 视为分布外/未脚本任务；(ii) 多个技能低于阈值 → 分类不确定；(iii) 仅一个技能 $p^*$ 低于阈值 → 直接执行。情形 (i)(ii) 均转交 LLM。
  - **LLM 任务分解**（gpt-oss-120b）：提示词包含可用动作、物体列表、各动作参数、少样本示例，采用思维链生成 JSON 格式技能序列；施加**约束解码**（mask 掉不在技能库中的技能）以抑制幻觉。无法完成时输出预定义 token。
- **部署闭环**：ArUco 标记（50 mm×50 mm，DICT 4X4）+ PnP + 离线相机标定估计物体位姿，经 2 秒滚动窗口中值滤波后作为环境状态条件；扩散模型据此生成整条轨迹。

- **平台/场景**：
  - 两台真实协作机器人：FANUC CRX25ia、Franka Emika Panda（文中亦称 Franka Research 3）；
  - MuJoCo 仿真（Robosuite 的 Stack 与 MugCleanup 环境，镜像真实 Franka 设置）；
  - 合成数据另用 D-MG 管线生成以做纯仿真验证。
- **长时程任务 benchmark**：Pick and Place、Pour、Stack、Hide、Clean Up（技能数 2–9，物体数 1–3，Clean Up 序列长度可变）。
- **对比方法**：
  - **MPD**（Motion Planning Diffusion，Carvalho 等）——直接继承并扩展的基线；
  - **Behavior Cloning（BC）**——仅仿真环境中对比；
  - 论文还设置了 DROM 内部消融：示教数量、语言编码器、LLM、共形预测模块。
- **语言评测集**：600 条标注话语（6 技能 × 100 条）评估语言编码器；长时程任务每类 50 条指令（共 250 查询，5 个随机种子）；不确定性评测 900 条话语（750 单技能 + 50 长时程 + 100 OOD），其中 150 条用于校准。
- **成功准则**：每个技能有定制化成功指标（如抓瓶需手指完全插入提手并抬升 ≥10 cm、倒液体转移 ≥95%、开抽屉 ≥95% 行程、堆方块稳定 ≥5 s 等）。

## 六、主要结论与发现

- **RQ1（少量示教学习）**：DMP 增强下，示教**多样性**而非数据量是性能关键。姿态敏感技能从 1 条示教提升到 4 条时成功率大幅跃升：Pick Bottle 24%→84%、Pick Cup 28%→86%、Pour Liquid 22%→92%、Button 30%→82%；而 Battery（48%→98%）与 Grab Handle（60%→90%）两条示教即饱和。
- **工作空间泛化**：平均可外推 $X$ 轴 +20.7%、$Y$ 轴 +25.2%，$Z$ 轴仅 +6.0%（技能多针对平面物体）；旋转方向最高提升 50%（Franka Cube），姿态敏感技能仅 5–19%，说明模型学到的是"操作行为"而非死记轨迹。
- **RQ2（统一多技能模型）**：DROM 在全部 17 个技能上均优于 MPD（如 Pick Bottle 60%→84%、Grab Handle 38%→90%、Open Drawer 50%→86%、Stack Cube 44%→94%）；仿真中亦优于 MPD 与 BC（如 MugCleanup Pick Cube：MPD

64% → DROM 96%、MPD 44% → DROM 90% 等），且单一扩散模型未因技能增多而牺牲单技能性能。
- **RQ3（语言条件与不确定性）**：
  - 语言编码器在 600 条平衡测试集上达到较高 precision/recall/F1 与技能选择成功率，但混淆矩阵显示语义相近指令（如"取瓶"与"取杯"）仍是主要误分类来源。
  - 聚类共形预测有效区分"分布内唯一匹配"、"多技能歧义"与"分布外/未脚本任务"三类情形：分布内话语大多被直接路由到底层扩散策略，歧义与 OOD 话语被转交 LLM，从而在保证正确性的同时显著降低平均延迟（2761.49 ms vs 纯 LLM 的 3996 ms）。
  - LLM 任务分解在 250 查询 × 5 种子上：技能组合成功率、序列执行成功率与整体成功率均优于无 LLM 或纯 LLM 基线；约束解码抑制了幻觉动作，使输出始终落在技能库内。
- **RQ4（长时程端到端）**：在 Pick and Place、Pour、Stack、Hide、Clean Up 五类任务上，DROM 的整体成功率优于 MPD 基线与无语言条件变体；对序列长度可变的 Clean Up，得益于共形预测与 LLM 路由，性能下降相对平缓。失败分析将错误归因于视觉位姿估计误差、抓取模式选择错误、语言路由误判与长序列误差累积等模块。
- **多模态定性结论**：Pick Bottle 的 4 种抓取模式与 Grab Handle 的 2 种把手几何均能被同一扩散模型覆盖，说明技能嵌入经交叉注意力注入后确实具备区分"几何相似但运动策略不同"行为的能力；但样本量仅 10 次、未报告显著性检验，结论以定性为主。

## 七、论文局限与批判性评价

- **方法层面**：
  - DMP 增强虽提升样本效率，但合成轨迹本质上是示教运动模式的扰动与重参数化，难以覆盖示教中完全未出现的全新策略；对高度接触丰富或力控敏感的任务，纯运动学 DMP 可能不足以表达必要的行为多样性。
  - 姿态敏感技能需多条示教才能饱和，说明方法对"多模态操作策略"的覆盖仍依赖人类示教的多样性，未从根本上解决多模态数据稀缺问题。
  - 扩散模型需生成 10 条候选轨迹再筛选，带来约 281 ms（且方差较大，±427 ms）的推理开销；尽管未进入 LLM 延迟，但在高动态任务中仍可能成为瓶颈。
  - 语言路由依赖轻量编码器 + 共形预测，语义相近技能（瓶/杯）的混淆需靠 CP 兜底转交 LLM，增加了系统复杂性与对 LLM 可用性的依赖。
- **实验层面**：
  - 每技能/每任务试验次数多为 50，长时程任务与多模态定性实验样本更少，统计效力有限，缺少显著性检验。
  - 语言评测仅覆盖 Franka 的 6 个技能，未验证全部 17 个技能与 FANUC 平台，泛化性证据不完整。
  - OOD 与长时程指令由作者构造，可能存在与训练话语分布相关的偏差，真实用户口吻下的鲁棒性未知。
  - 硬件为单张 RTX 4070，未报告多卡或更大规模下的可扩展性；LLM 使用 gpt-oss-120b，其部署成本与离线可用性未展开讨论。
- **总体判断**：DROM 的核心贡献在于把"数据增强—统一多技能扩散策略—分层语言推理"三者整合为一个可落地的系统，并用真实双机器人 + 仿真验证了其有效性；其价值更多体现在系统级整合与工程可行性，而非单一模块的理论突破。对"用少量示教 + 语言引导实现长时程操作"这一目标，论文给出了有说服力的实证支撑，但结论的普适性仍受示教多样性、任务类型与评测规模的限制。

## 八、对后续工作的启示

- **数据侧**：可探索将 DMP 增强与物理仿真回放、真实机器人自主试错结合，生成既多样又物理可行的合成数据，缓解 DMP 只能"重参数化"示教的局限。
- **模型侧**：可在扩散策略中显式引入力/触觉条件或接触约束，以覆盖接触丰富任务；也可研究更高效的采样（如一致性模型、蒸馏）以降低候选轨迹生成开销。
- **语言侧**：可将共形预测扩展到多标签/序列级不确定性，并引入更贴近真实用户的口语化、歧义化指令评测集，检验路由策略的鲁棒性。
- **系统侧**：可研究 LLM 的本地化/轻量化部署与异步调用机制，使高层规划与底层扩散控制进一步解耦，缩短端到端响应时间。
- **评测侧**：建议在更长时程、更多技能、更大样本量下报告统计显著性，并公开技能库、话语集与成功准则，提升结果的可复现性与可比性。

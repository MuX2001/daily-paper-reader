## 摘要
顺序操作要求机器人追踪已经发生的事情，即使当前场景不再体现这些信息。具有显式历史表示的策略将过往交互作为当前决策的上下文。我们探究动作生成本身如何为后续控制形成一种持久状态。基于动作侧测试时训练，RecastVLA 在流匹配视觉-语言-动作策略中维护一个自适应策略状态。该状态由共享快速权重表示，并在整个动作生成过程中保持固定。深度特定接口读取同一状态，而跨深度和流评估的特征共同为下一次策略调用定义一次更新。后续动作损失通过微分经过早先的状态转移来训练初始化、接口和更新规则。部署时，更新使用策略自身的动作生成特征，无需专家动作标签。在 LIBERO、RoboTwin、RoboDojo 和十二个真实机器人任务上，RecastVLA 相比一个未采用测试时训练的匹配策略提升了平均成功率，其中在 RoboTwin Clean-to-Clean 上提升 10.68 个百分点。在受控的 RoboTwin 对比中，保留状态提升了成功率，且共享设计比独立训练的层局部 TTT 高出 2.58 个百分点。

## Abstract
Sequential manipulation requires a robot to track what has already happened, even when the current scene no longer reveals it. Policies with explicit history representations make past interactions available as context for current decisions. We ask how action generation itself can form a persistent state for subsequent control. Building on action-side test-time training, RecastVLA maintains an adaptive policy state within a flow-matching vision-language-action policy. The state is represented by shared fast weights and remains fixed throughout action generation. Depth-specific interfaces read the same state, while features across depths and flow evaluations jointly define one update for the next policy call. Subsequent action losses train the initialization, interfaces, and update rule by differentiating through earlier state transitions. At deployment, updates use the policy's own action-generation features without expert action labels. Across LIBERO, RoboTwin, RoboDojo, and twelve real-robot tasks, RecastVLA improves mean success over a matched policy trained without test-time training, including 10.68 percentage points on RoboTwin Clean-to-Clean. In controlled RoboTwin comparisons, retaining state improves success, and the shared design exceeds independently trained layer-local TTT by 2.58 points.

# RecastVLA 论文总结

## 1. 核心问题与整体含义

- **研究背景**：顺序机器人操作要求策略记住“已经发生了什么”，即使当前场景已不再直接体现这些信息。例如按钮按下前后外观几乎相同、物体被遮挡、指令只完成了一部分。
- **现有思路**：历史条件策略通常通过检索观测、压缩上下文或循环表示，把过去交互作为当前决策的上下文，重点解决“哪些过去信息可用”。
- **本文问题**：作者提出一个互补问题——**动作生成本身如何形成一种持久策略状态，用于后续控制**。也就是说，不只是把历史作为输入，而是让动作生成过程产生并更新一个跨策略调用的“执行记忆”。
- **整体含义**：RecastVLA 把动作侧测试时训练（TTT）扩展为共享自适应策略状态：状态由快速权重表示，在一次动作生成内保持固定，生成结束后根据内部特征更新，供下一次策略调用使用。部署时不需要专家动作标签，只用策略自身动作生成特征。

## 2. 方法论

### 2.1 核心思想

- 用一个小型快速权重 MLP 表示**自适应策略状态** \(W_t\)，它跨策略调用持续存在。
- 每次策略调用读取 \(W_t\)，生成一个动作块，并收集内部特征 \(Z_t\)；随后用这些特征更新状态：
  \[
  (\hat A_t, Z_t)=\pi_{\theta,\psi}(o_t,l;W_t),\quad W_{t+1}=U_\psi(W_t,Z_t)
  \]
- 同一次动作生成内的所有计算都读取同一个固定状态 \(W_t\)，更新只影响下一次调用。
- 新 episode 从学习到的初始化 \(W_0\) 开始；部署时只更新 \(W_t\)，慢参数 \(\theta,\psi\) 固定。

### 2.2 关键技术细节

- **状态结构**：\(W_t\) 是两层 MLP 的权重和偏置，结构为 256→512→256，GELU 激活。
- **动作专家**：交替使用视觉语言特征交叉注意力和 latent slots/action tokens 自注意力；使用 32 个宽度 768 的 latent slots，在 8 个 access depth 读取状态。
- **深度特定读取接口**：在 access depth \(j\)，对 cross-attention 后的 slot 特征加一个门控残差：
  \[
  \tilde h_{t,c,j}=h_{t,c,j}+\tanh(\gamma_j)P_{Oj}f_{W_t}(P_{Qj}\mathrm{LN}(h_{t,c,j}))
  \]
  不同深度用各自的投影在自身特征坐标中查询同一个共享状态。
- **写入与更新**：
  - 从 post-self-attention slots 构造 key/value：
    \[
    k_{t,c,j}=P_{Kj}\mathrm{LN}(\mathrm{sg}(z_{t,c,j})),\quad
    v_{t,c,j}=P_{Vj}\mathrm{LN}(\mathrm{sg}(z_{t,c,j}))
    \]
    其中 stop-gradient 把源特征当作数据。
  - 内目标为跨 flow evaluations 和 access depths 的加权拟合损失：
    \[
    L^{write}_t(W)=\frac{1}{C}\sum_c g_\psi(\tau_{t,c})\sum_j \alpha_j
    \frac{\|f_W(k_{t,c,j})-v_{t,c,j}\|_F^2}{NM}
    \]
    其中 \(g_\psi(\tau)\) 是 flow-time gate，\(\alpha_j\) 是 access site 权重。
  - 对 incoming state 做一次梯度下降：
    \[
    W_{t+1}=W_t-\eta\nabla_W L^{write}_t(W)|_{W=W_t},\quad \eta=\eta_0 e^\rho
    \]
    \(\eta_0=0.1\)，\(\rho\) 可学习。
- **训练目标**：采样长度 \(T=4\) 的有序观测窗口，每个 frame 采样 \(R\) 个噪声/时间点，构造 flow-matching 输入和速度目标；所有 frame 的动作损失共同训练初始化、接口和更新规则。动作损失在第 \(t+1\) 帧反传时，会通过状态转移影响第 \(t\) 帧的写入投影和更新参数。
- **训练算法流程**：
  1. 初始化 \(W\leftarrow W_0\)；
  2. 对窗口内每个 \(t\)，采样 flow-matching 副本，预测速度并收集 slot 特征；
  3. 累加动作损失；
  4. 若不是最后一帧，构造 key/value 并执行一次 \(L^{write}\) 梯度更新，同时保留元梯度；
  5. 最后用 \(\nabla_\Theta L\) 更新慢参数。
- **部署流程**：从高斯动作噪声开始，用 \(K\) 次 Euler 评估积分速度场，所有评估条件于 \(W_t\)；生成后根据 \(C=K\) 个 flow evaluations 的特征更新一次状态。部署只需要对快速权重求梯度，不需要跨调用保留计算图，也不需要专家动作标签。

## 3. 实验设计

### 3.1 仿真 Benchmark

- **LIBERO**：
  - 训练：Spatial、Object、Goal、Long 四个 suite，共 40 个任务、1693 条演示。
  - 评估：Avg 为 40 任务 ×50 trials，Long 为 10 任务 ×50 trials。
- **RoboTwin 2.0**：
  - 训练：50 个任务，每任务 50 条 clean 演示，共 2500 条。
  - 评估：Clean→Clean 和 Clean→Random，各 50 任务 ×100 trials。
- **RoboDojo**：
  - 训练：35 个任务，3500 条演示。
  - 评估：Long-Horizon 8 任务 ×50 trials，Memory 6 任务 ×50 trials。

### 3.2 真实机器人

- 平台：双 SOARM101 机械臂桌面平台，两个 LRCP G720P 腕部相机。
- 微调数据：55 个训练任务，每任务 10 条演示，共 550 条，覆盖 9 个任务族。
- 评估：12 个 held-out 变体任务，涉及新操作序列、组合、场景或物体配置；每个策略每任务 20 trials，每策略共 240 trials。
- 任务包括按钮顺序、重复按压、水果装箱、颜色堆叠、牙刷/牙膏放置、毛巾折叠、杯子定向与开盖、擦桌子等。

### 3.3 对比方法

- **已发表结果对比**：π0.5、X-VLA、Spatial Forcing、ABot-M0、Fast-WAM、OpenWAM-α。
- **匹配基线**：Matched Base，与 RecastVLA 同架构但禁用 TTT，独立训练，保留四帧动作目标。
- **消融/控制**：
  - 状态连续性：Full、Reset、Similar-task init、Other-task init。
  - 状态组织：Matched Base、Layer-local TTT、RecastVLA。
  - 层局部 TTT 使用相同 per-state MLP 架构、相同更新时机，但每个深度独立状态。
- **指标**：任务成功率；状态控制中还使用 normalized completion steps（NCS），失败记 1。

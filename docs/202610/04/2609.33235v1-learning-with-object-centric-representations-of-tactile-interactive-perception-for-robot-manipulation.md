## 摘要
难以直接从视觉推断的隐含物体属性，例如材质、容器内容物或柔软度，可以通过触觉感知和探索性交互得以揭示。然而，由于触觉信号具有瞬态性和稀疏性，如何提取信息丰富的触觉事件并将其有效融入机器人操作仍是一项挑战。在这项工作中，我们提出了一种以物体为中心的上下文感知操作框架，该框架通过触觉探索学习任务无关的物体表征。一种 token 学习器从长时程探索中自主选择具有代表性的触觉片段，而与描述性文本嵌入的对比对齐则构建了一个能够捕捉多种物体物理属性的潜在空间。随后，这些学习到的表征被用作语义上下文，以指导以物体为中心的操作策略，并基于物体属性自适应调整策略。实验表明，学习到的表征在已见和未见物体上分别达到 93% 和 84% 的属性估计准确率。在涉及视觉歧义物体的三项任务（即多物体重排、倾倒和开箱）上进行评估，所提出的框架同时改进了目标选择和依赖于属性的操作自适应，在汇总所有评估试验后，相较于没有物体上下文条件的基线策略，将已见物体上的任务成功率从 41% 提升至 92%，将未见物体上的任务成功率从 19% 提升至 67%。视频和更多结果见 https://xinyiyxyx.github.io/tactile-object-centric/。

## Abstract
Implicit object properties that are difficult to directly infer from vision, such as material, container contents, or softness, can be revealed through tactile sensing and exploratory interactions. However, because tactile signals are transient and sparse, extracting informative tactile events and effectively incorporating them into robotic manipulation remains a challenge. In this work, we present an object-centric context-aware manipulation framework that learns task-agnostic object representations through tactile exploration. A token learner autonomously selects representative tactile segments from long-horizon exploration, while contrastive alignment with descriptive text embeddings enables a latent space that captures multiple physical object properties. These learned representations are then used as semantic context to guide object-centric manipulation policies and adapt strategies based on object properties. Experiments show that the learned representations achieve 93% and 84% property estimation accuracy on seen and unseen objects. Evaluated on three tasks involving visually ambiguous objects, i.e. multi-object rearrangement, pouring, and box opening, the proposed framework improves both target selection and property-dependent manipulation adaptation, raising task success, aggregated over all evaluation trials, from 41% to 92% on seen objects and from 19% to 67% on unseen objects over baseline policies without object-context conditioning. Videos and additional results are available at https://xinyiyxyx.github.io/tactile-object-centric/.

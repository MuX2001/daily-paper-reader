## 摘要
视觉-语言-动作（VLA）模型为机器人操作提供了强大的行为先验，但如何将其高效地适配到下游任务仍然具有挑战性。近期工作通过在线强化学习（RL）对冻结的VLA进行适配来应对这一挑战，其样本效率取决于actor和critic所用状态表示的质量。现有方法要么使用独立于VLA的视觉编码器来构建此类表示，要么通过对VLA内部表示进行固定压缩来构建。这两种设计都没有显式提取对下游动作细化和动作价值估计最有用的、任务特定的动作相关VLA特征，因此限制了样本效率。为解决这一局限，我们提出eRLT，它通过在冻结VLA的令牌和层之间路由任务特定的动作相关信息，构建有效的状态表示。具体而言，学习到的路由令牌动态聚合多个深度的视觉-语言特征，而轻量级层路由器将这些汇总信息组合成固定维度的RL令牌。该路由模块使用专家演示进行初始化，以捕获可预测专家动作的特征，然后利用来自在线交互的critic反馈进行细化，以用于动作价值估计。在七个LIBERO和RoboTwin任务上，eRLT相较于代表性基线将平均归一化学习曲线AUC最多提升23.7%。在USB连接器插入和主板排线插入的真实机器人实验中，相较于最强基线，AUC分别提升了108.9%和46.7%。

## Abstract
Vision-Language-Action (VLA) models provide strong behavioral priors for robotic manipulation, yet efficiently adapting them to downstream tasks remains challenging. Recent work addresses this challenge by adapting frozen VLAs through online reinforcement learning (RL), whose sample efficiency depends on the quality of the state representation used by the actor and critic. Existing methods construct such representations either with VLA-independent visual encoders or through fixed compression of internal VLA representations. Neither design explicitly extracts the task-specific action-relevant VLA features most useful for downstream action refinement and action-value estimation, therefore limiting sample efficiency. To address this limitation, we introduce eRLT, which constructs an effective state representation by routing task-specific action-relevant information across both tokens and layers of the frozen VLA. Specifically, learned routing tokens dynamically aggregate visual-language features at multiple depths, while a lightweight layer router combines these summaries into a fixed-dimensional RL token. The routing module is initialized using expert demonstrations to capture features predictive of expert actions and then refined using critic feedback from online interactions for action-value estimation. Across seven LIBERO and RoboTwin tasks, eRLT improves mean normalized learning-curve AUC by up to 23.7% over representative baselines. Real-robot experiments on USB connector insertion and motherboard ribbon-cable insertion further show AUC improvements of 108.9% and 46.7%, respectively, over the strongest baseline.

## 2. 方法论

### 2.1 核心思想
- 用**可学习路由 token** 在冻结 VLA 的多层与多 token 上动态聚合视觉-语言特征，再由**轻量层路由器**组合成固定维度 RL token $z_t$；全程 VLA 参数冻结。

### 2.2 关键技术细节

- **Token 级路由（Token-wise routing）**
  - 将 $K$ 个路由 token 嵌入 $\eta_{tok}$ 追加到多模态前缀嵌入 $E_t$ 之后，**单独一次前向**（不干扰 VLA 的动作生成，路由 token 可注意原 token，反之不行）。
  - 在选定的 $m$ 个 VLM 层 $\ell_1,\dots,\ell_m$ 上取路由 token 位置的隐状态并均值池化，得到每层摘要 $u_t^{(i)}$（式 1）。每层只贡献一个 $D$ 维摘要，与前缀/token 数量无关。

- **层 级路由（Layer-wise routing）**
  - 学习与观测无关、任务相关的层 logits $\eta_{lay}$，经带温度 $\tau$ 的 softmax 归一化为 $\alpha$；RL token 为各层摘要的加权和：$z_t=\sum_{i=1}^{m}\alpha_i u_t^{(i)}$（式 2）。
  - 分工：token 级路由决定"当前输入采集什么信息"，层 级路由决定"哪些 VLA 深度参与"。

- **阶段一：任务特定的动作相关初始化（离线）**
  - 复用 VLA 的 SFT 数据集，用轻量动作探针 $g_\omega$ 从 $z_t$ 预测专家动作块 $A_t^E$，最小化 MSE（式 3）。
  - 关键设计：**以"动作预测"而非"重建"为监督**——只要求保留区分不同专家动作所需的信息，而非保留全部 token 内容。按验证集动作预测误差选参，在线 RL 前丢弃探针。

- **阶段二：critic 驱动的在线适配**
  - 将 critic 的 Bellman/TD 目标反传至路由参数：$\mathcal{L}_Q=\mathbb{E}_\mathcal{B}[(Q_\phi(z_t,x_t,\xi_t)-\text{stopgrad}(y_t))^2]$（式 4），联合更新 $\eta$ 与 $\phi$。
  - actor 更新使用**分离梯度（detach）**的 RL token，不改变其构造方式；target 网络（actor/critic/router）用 Polyak 平均缓慢跟随。
  - 为限制计算与表示变化速率，路由参数**周期性更新**（每 $U$ 次 learner 迭代一次）；回放缓冲存原始观测，在路由更新时重算当前/下一 RL token。

- **参数开销**：路由模块仅引入 $KD+m$ 个有效可训练参数（$K$ 个路由 token + $m$ 个层 logits）。

- **路由器未验证跨任务/跨本体迁移**：论文未考察在任务 A 上初始化的路由参数能否迁移到任务 B 或另一机器人本体，因而无法判断学到的路由是否为"任务特定"而非"任务组通用"。这是轻量路由范式的核心卖点之一，却未被直接检验。

- **超参敏感性**：层选择集合 $\{\ell_1,\dots,\ell_m\}$、温度 $\tau$、路由更新周期 $U$ 的取值依据未系统消融，可能影响方法在新区间上的稳健性。
- **离线初始化依赖 SFT 数据质量**：阶段一以专家动作预测为监督，若演示状态覆盖不足（正是 SFT 的固有短板），初始化的动作相关性可能受限，论文未分析该初始化质量对在线阶段的下界影响。

## 8. 与已有工作的定位对比

- **对 DSRL / PLD 一类**：这些方法冻结 VLA 却另起炉灶训练独立视觉编码器，等于放弃了预训练 VLA 内部已编码的任务相关语义；eRLT 的贡献在于把"状态表示"重新锚定在 VLA 内部特征上，并证明这样做在多数任务上更优。
- **对 RLT / Mi-DAS 一类**：这些方法承认要复用 VLA 内部 token，但采用"预定层 + 预定 token 集 + 重建目标"的固定压缩，缺少可选择性；eRLT 用**可学习路由 + 动作预测监督**替代固定压缩，并通过动机实验（最优源层与最优 token 子集因任务而异）为该设计提供了直接的经验依据。
- **对通用 VLA 适配（SFT、全参数微调）**：eRLT 明确站在"冻结骨干 + 轻量适配头"一侧，把可训练参数压缩到 $KD+m$ 量级，符合受限在线交互预算下的样本效率诉求。

## 9. 总体评价

- **核心贡献**：提出一种显式的、任务特定的动作相关 RL token 构造机制——token 级路由决定"采集什么信息"，层 级路由决定"从多深采集"，并以动作预测（而非重建）为离线监督、以 critic 的 TD 目标为在线适配信号；在仿真与真实机器人上均取得一致（虽非普适）的提升，尤其在真实接触密集型精细插入任务上把成功率从 50% 提升到 90%。
- **方法上的亮点**：
  1. **监督目标的替换**（动作预测 vs. 重建）是关键且可迁移的设计洞察——重建会迫使路由保留与动作无关的冗余信息；
  2. **双阶段适配**（离线动作相关初始化 + 在线 critic 驱动）在受限交互下兼顾了冷启动质量与在线修正能力；
  3. **参数开销极小**，与"冻结大模型 + 训练小模块"的工程现实高度契合。
- **方法论上的克制**：受控动机实验（只变特征来源、固定其余一切）为设计选择提供了较强的因果性证据，而不是仅凭端到端结果倒推。
- **待补强之处**：任务依赖性的边界条件、路由器的跨任务/跨本体迁移能力、真实实验的统计强度，以及算力与超参的完整披露，是该方法进一步确立通用性前需要回答的问题。
- **适用场景判断**：eRLT 最适合"已有强 VLA 骨干 + 需要少量在线交互快速提可靠性 + 任务涉及精细对齐与接触"的场景；对于 VLA 视觉语义本身表达不足、或需要大规模几何/力觉信息注入的任务，混合使用独立编码器或引入其他模态可能更稳妥。

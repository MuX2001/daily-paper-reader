## 摘要
扩散与流匹配视觉-语言-动作（VLA）策略通过迭代去噪生成动作块，带来可观的推理延迟，严重限制了实时机器人控制。现有加速方法将动作块视为单一整体计算单元，忽略了滚动时域控制的一个关键物理现实：动作是联合生成、却按顺序执行，因此具有内在异质的执行紧迫性。我们利用这种不对称性，提出紧迫性感知去噪（Urgency-Aware Denoising, UAD），一种新颖的推理时框架，根据每个动作实际需要被执行的时机来分配去噪计算。UAD 在更少的去噪步骤后释放时间关键的紧急动作，同时将尾部动作持续的背景精化与物理执行重叠进行。然而，异质去噪引入了两个关键挑战：紧急动作的提前释放误差，以及尾部动作的轨迹不一致性。UAD 通过两个核心机制优雅地同时解决二者：轨迹协调（Trajectory Reconciliation），它重建统一的内部状态演化，以在无需额外模型评估的情况下恢复联合去噪的一致性；以及幽灵动作校正（Ghost Action Correction），它利用未执行的幽灵延续来动态补偿剩余可执行动作中的提前释放误差。跨多种 VLA 架构、仿真基准和真实世界操作任务的广泛评估表明，UAD 在平均动作可用延迟上实现了最高 1.89 倍的加速，同时保持与使用最优去噪预算的原始推理相当的成功率，相比最先进的 VLA 加速基线提供了更有利的成功率-延迟权衡。

## Abstract
Diffusion and flow-matching Vision-Language-Action (VLA) policies generate action chunks through iterative denoising, incurring substantial inference latency that severely limits real-time robotic control. Existing acceleration methods treat an action chunk as a monolithic computational unit, ignoring a crucial physical reality of receding-horizon control: actions are generated jointly but consumed sequentially, resulting in inherently heterogeneous execution urgencies. We exploit this asymmetry to introduce Urgency-Aware Denoising (UAD), a novel inference-time framework that allocates denoising computation according to when each action is physically needed. UAD releases time-critical urgent actions after fewer denoising steps while overlapping the continued background refinement of tail actions with physical execution. However, heterogeneous denoising introduces two key challenges: early-release errors in urgent actions and trajectory inconsistency in tail actions. UAD elegantly resolves both through two core mechanisms: Trajectory Reconciliation, which reconstructs unified internal state evolution to restore joint denoising coherence without additional model evaluations, and Ghost Action Correction, which leverages non-executed ghost continuations to dynamically compensate for early-release errors across remaining executable actions. Extensive evaluations across multiple VLA architectures, simulation benchmarks, and real-world manipulation tasks demonstrate that UAD achieves up to a 1.89x speedup in average action availability latency while maintaining comparable success rates to vanilla inference with optimal denoising budget, offering a more favorable success-latency trade-off than state-of-the-art VLA acceleration baselines.

# 论文总结：Urgent Actions Go First — Urgency-Aware Denoising for Real-Time VLA Control

## 1. 核心问题与研究背景

- **背景**：扩散/流匹配式 VLA（Vision-Language-Action）策略通过迭代去噪生成动作块（action chunk），动作质量高但推理延迟大，严重制约实时机器人控制。论文实测：执行一个动作块约 500 ms，而生成下一块即使在大数据中心级硬件上也需约 300 ms；同步执行下机器人每周期有超过 30% 时间处于空闲等待，在边缘设备上更严重。
- **现有方法的盲点**：量化、剪枝、特征缓存、自适应步数削减（D3P）、生成-执行重叠（RTC）等加速手段，普遍把动作块当作**单一整体计算单元**，对所有动作 token 施加**统一去噪预算**。
- **被忽略的物理现实**：在滚动时域（receding-horizon）控制中，动作块内的动作是**联合生成、顺序消费**的——最早的动作直接决定机器人何时能开始动作，紧迫性最高；尾部动作拥有更大的时间缓冲，其精化天然可与早期动作的物理执行重叠。
- **核心张力**：去噪步数 N 与成功率呈**非单调**关系，经验最优预算 N\* ∈ [2, 7]。将 N 从 N\* 统一降到 1 可带来 2–7× DiT 加速，但在敏感任务上成功率下降 **3.9–10.7 pp**。
- **整体含义**：论文主张“**何时需要该动作**”应成为分配推理算力的一个独立维度，据此提出推理时框架 UAD（Urgency-Aware Denoising），在降低动作可用延迟的同时保住动作质量。

## 2. 方法论

### 2.1 核心思想
- 将动作块按执行紧迫性分为三段：**紧急动作**（前 U 个，需立即执行）、**可执行尾部动作**（有缓冲）、**不可执行尾部动作**（仅作时间上下文）。
- 给紧急动作分配更少去噪步数 K < N\*，提前释放以启动物理执行；尾部动作保持完整 N\* 步，其去噪与执行**重叠**进行。
- 异质去噪带来两大副作用，需专门机制解决：**提前释放误差**（紧急动作去噪不足）与**轨迹不一致**（共享注意力导致误差传播到尾部动作）。

### 2.2 三个核心组件
- **Urgency-Aware Early Release（UAER）**
  - 索引集：紧急集 U = {0,…,U−1}，尾部集 T = {U,…,H−1}。
  - 每动作去噪步数 N_i = K（i∈U）或 N\*（i∈T），对应动作专属欧拉步长 1/N_i：x_k^i = x_{k−1}^i + (1/N_i)·v_k^i。
  - 紧急动作完成 K 步后直接释放为可执行动作 a_i = x_K^i；尾部动作继续更新至 N\* 步。
- **Trajectory Reconciliation（TR）**
  - 问题：紧急动作以大歩长（1/K）演化，破坏联合注意力下的一致性，污染尾部动作。
  - 做法：用**已缓存的速度场**按规范步长 1/N\* 重新积分，重建紧急动作的兼容内部状态：x′_K^i = x_0^i + (1/N\*)·Σ_{k=1..K} v_k^i。
  - **零额外 DiT 评估**；重建后的状态继续参与联合去噪，得到“幽灵状态”，其终态称为**幽灵动作** a′_i = x′^i_{N\*}。
  - **K=1 时的精确恢复**：首次 DiT 评估与原始推理完全相同，按 1/N\* 重积分可精确还原 vanilla 状态，故尾部动作理论上零额外误差（论文图 3 验证）；K>1 时不再精确，但经验上仍显著降低尾部误差。
- **Ghost Action Correction（GAC）**
  - 误差估计：E = Σ_{i=0..U−1} (a′_i − a_i) = Σ (x′^i_{N\*} − x_K^i)，即所有紧急动作的累计提前释放误差。
  - 动态补偿：由于已执行的紧急动作不可回改，但 VLA 动作是连续空间指令、可由后续修正运动补偿，故将 E **均匀摊派**到剩余 S−U 个可执行尾部动作上：a_i = x^i_{N\*} + E/(S−U)。
  - 物理语义处理：平移等可加维度直接相加；旋转在 SO(3) 上做复合；夹爪等离散维度做掩码以防误翻转。
  - **适用条件**：仅当动作维度可跨连续控制步补偿时适用；若动作以固定/块级参考系表示（如真机 π0.5 的块相对动作），则省略 GAC，仅保留 UAER+TR。
- **工程实现**
  - **逐动作时间条件**：扩展模型为每个动作 token 接受独立 flow time，以在单次联合 DiT 前向中支持异质去噪调度（SmolVLA 在动作 MLP 前注入时间嵌入；π0.5 用于动作专家的自适应归一化层），**复用预训练权重、不引入可训练参数**。
  - **异步执行**：紧急动作完成后同步 GPU 并送入执行队列，尾部去噪在独立 CUDA 流上继续；若尾部未算完则等待。
  - **无需训练、无新增参数**，纯推理时改造。

### 2.3 延迟模型（附录 B）
- Vanilla：T_avail,vanilla = (T_VLM + N\*·T_D) / S。
- UAER：T_avail,UAER = [T_VLM + K·T_D + max((N\*−K)·T_D − U·T_act, 0)] / S。
- 含义：K 决定初始等待，U 决定可用于遮盖剩余去噪的执行窗口；当 U·T_act ≥ (N\*−K)·T_D 时尾部去噪被完全隐藏。

## 3. 实验设计

- **模型与基准**
  - 仿真主实验三组：SmolVLA + LIBERO-Plus、SmolVLA + Meta-World+、π0.5 + Meta-World+（对应 N\* = 7、3、2）。
  - 真机：π0.5 部署于 **Dobot Nova2**（D455 前侧相机 + D405 腕部相机），5 个桌面操作任务（按钮、放葡萄、插花、整理桌面、叠碗+放方块），每任务 20 回合，共 **100 回合**。
  - 附录补充三组饱和设置：SmolVLA + LIBERO、π0.5 + LIBERO、π0.5 + LIBERO-Plus。
  - 数据规模：LIBERO-Plus 固定子集 **400 个变体**（Spatial/Object/Goal/Long 各 100）；Meta-World+ **50 任务 × 20 回合 = 1000 回合**；随机种子 42。
- **对比基线（5 个）**
  - Vanilla (N\*)：各设置经验最优步数，作为成功率/延迟参照。
  - Vanilla (N=1)：统一单步去噪，代表激进步数削减。
  - **D3P**：学习式动态选择去噪预算（PPO 训练轻量 adaptor）。
  - **RTC**：生成与执行重叠的实时动作分块流式方法。
  - **BAC**：块级自适应缓存，跨去噪步复用中间特征。
- **指标**
  - SR（成功率）、AAL（平均动作可用延迟，动作级暴露延迟，可换算为 AAL/(AAL+T_act) 的空闲比例）、ΔSR（相对 Vanilla(N\*) 的百分点变化）、Speedup（AAL 比值）。
  - 附录额外提出 **DBL（DiT Blocking Latency）**，仅统计真正阻塞执行的 DiT 计算量，排除被重叠隐藏的部分与 VLM 固定开销。
- **公平性设计**
  - 所有方法共享同一预训练 checkpoint、同一观测/动作处理管线。
  - **控制时间对齐**：仿真中为每个动作指定固定重叠预算 T_act = 1/f_ctrl（LIBERO-Plus 50 ms @20Hz，Meta-World+ 12.5 ms @80Hz），避免仿真墙钟时间被人为拉长而放大异步方法的优势。
  - BAC 缓存调度在独立种子的 held-out rollout 上离线校准；延迟测量排除首个 episode 作为 warm-up；CI 用 episode bootstrap（8000 次重采样）。
- **超参设置**：H = 50、S = 10、K = 1；U 取使尾部平均阻塞时间 < 0.2 ms 的最小值（SmolVLA/LIBERO-Plus 为 5，SmolVLA/Meta-World+ 为 3，π0.5/Meta-World+ 为 2）。

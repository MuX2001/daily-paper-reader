## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作方面展现出巨大潜力，但将其适配到新任务和新领域仍然效率低下：现有方法通常依赖参数调优，这会带来高昂成本，并存在灾难性遗忘已学任务的风险。为解决这一问题，我们提出了 \textbf{Optimus-R}，一个以记忆为中心的 VLA 框架，它将机器人适配形式化为显式的查询-技能记忆调优。Optimus-R 引入了：(i) 用于技能提取的 \textbf{内联记忆接口}。它将可学习记忆 token 插入 VLA 前缀流，使主干网络能够在原生动作条件化路径中导出控制感知的查询与技能表示。(ii) 用于技能学习的 \textbf{查询-技能记忆库}。它将技能外化为用于决定 \emph{什么} 需要检索的查询原型，以及用于指定 \emph{如何} 行动的技能值，从而在有限参数更新下支持技能复用与扩展。(iii) 用于技能更新的轻量级 \textbf{桥接与适配机制}。它通过轻量级适配器和残差记忆更新，将目标域查询与技能对齐到现有记忆空间。在域内适配、跨域适配和终身学习上的实验表明，Optimus-R 能够实现数据高效的技能学习，同时缓解灾难性遗忘。

## Abstract
Vision-Language-Action (VLA) models have shown strong promise for general-purpose robotic manipulation, yet adapting them to new tasks and domains remains inefficient: existing methods often rely on parameter tuning, incurring substantial costs and risking catastrophic forgetting of previously learned tasks. To address this, we propose \textbf{Optimus-R}, a memory-centric VLA framework that formulates robotic adaptation as explicit query-skill memory tuning. Optimus-R introduces: (i) An \textbf{Inline Memory Interface for skill extraction}. It inserts learnable memory tokens into the VLA prefix stream, allowing the backbone to derive control-aware query and skill representations within the native action-conditioning pathway. (ii) A \textbf{Query-Skill Memory Bank for skill learning}. It externalizes skills into query prototypes for deciding \emph{what} to retrieve and skill values for specifying \emph{how} to act, supporting skill reuse and expansion with limited parameter updates. (iii) A lightweight \textbf{Bridge-and-Adapt mechanism for skill updating}. It aligns target-domain queries and skills with the existing memory space through a lightweight adapter and residual memory updates. Experiments on in-domain adaptation, cross-domain adaptation, and lifelong learning show that Optimus-R enables data-efficient skill learning while mitigating catastrophic forgetting.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：VLA（Vision-Language-Action）模型已在大规模机器人数据预训练下成为通用操作的重要范式（如 π0、π0.5、OpenVLA 等），但在部署到新任务、新物体、新场景、新领域时仍效率低下。
- **核心痛点**：
  - 现有适配方法普遍采用**参数中心（parameter-centric）**范式，通过微调或 LoRA 更新模型权重；
  - 导致**适配成本高**（每次新技能都隐式改变权重）；
  - 易造成**灾难性遗忘**，干扰已学任务；
  - 新技能难以被显式检索、复用或扩展。
- **核心问题**：能否让 VLA 通过**显式记忆接口**获取、存储与复用技能，而非反复更新模型参数？
- **三个耦合子问题**：
  1. 技能应从 VLA 模型自身原生动作条件化路径中导出，而非作为弱耦合的"外挂上下文"；
  2. 技能应被显式组织，而非吸收进模型权重；
  3. 技能应在域偏移（视觉/动力学变化）下仍可被检索。
- **整体含义**：将机器人适配统一建模为**技能提取（skill extraction）→ 技能学习（skill learning）→ 技能更新（skill updating）**的记忆调优过程，提供低遗忘、可扩展的任务与域适配新范式。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想
将机器人适配形式化为**显式的查询-技能记忆调优（query-skill memory tuning）**：把可复用技能外化到记忆库，适配时仅更新轻量对齐模块、原型残差与记忆条目，而非反复全局微调 VLA 参数。

### 2.2 三大关键组件

**(i) 内联记忆接口（Inline Memory Interface）— 技能提取**
- 将可学习 **memory tokens** 插入 VLA 前缀流：`[Hvl_t; Mt] = Fθ(Ot, L; Emem)`，使主干在原生的动作条件化通路中产生记忆状态 `Mt`。
- 用两个独立注意力池化算子分离"检索上下文"与"动作相关技能内容"：
  - `m̄q_t = AttnPool_q(Mt)` → 查询编码器 `fq` → 查询嵌入 `qt`（仅用于检索）
  - `m̄s_t = AttnPool_s(Mt)` → 技能编码器 `fs` → 技能嵌入 `st`（作为记忆库中的 value 表示）
- 训练时用轻量 **Skill Decoder** 以 `st` 重建未来动作块 `Âs_t = Ds(st)`，使技能空间锚定于可执行行为。
- **Token Projector** `Tψ` 将技能嵌入映射为 VLA 兼容的技能 token `St`，条件化 Flow Policy：`Ãt = πθ(Hvl_t, St)`。

**(ii) 查询-技能记忆库（Query-Skill Memory Bank）— 技能学习**
- 存储解耦的 key-value 原型：`B = {(pq_j, ps_j, n_j, Ej)}`，其中 `pq_j` 为查询原型（决定"检索什么"），`ps_j` 为技能原型（决定"如何行动"），`n_j` 为支持计数，`Ej` 为潜在 query–skill 对回放集。
- **构建流程**：动作感知下采样（按动作变化分数 νi）→ 归一化进度分层采样 → 技能聚类（先在查询空间聚类，对技能方差高的簇再在技能空间二次切分）。
- **检索**：查询先对齐 `q't = Amem·qt`，按相似度取 top-Kr，计算 softmax 权重 `αtj`，加权聚合得 `ŝt = Σ αtj(ps_j + Δps_j)`。
- **残差机制**：`Δpq_j`、`Δps_j` 实现技能更新而不覆盖基础原型，保留可复用技能。

**(iii) Bridge-and-Adapt 机制 — 技能更新（三阶段训练）**
- **Stage A（接口预训练）**：训练 memory tokens、Query/Skill Encoder、Skill Decoder、Token Projector 及 VLA 主干最后几层；损失 `Lpre = Lfm + λq·Lnce_q + λs·Lskill`，其中 Lfm 为原 VLA 流匹配损失，Lnce_q 为查询对比损失（同任务近进度样本 + 同轨迹邻域为正样本），Lskill 为 Huber 重建损失。之后冻结接口并构建初始记忆库。
- **Stage B（桥接适配）**：面向跨域（如 sim-to-real），解冻主干并更新 `Amem`、`τmem` 及活跃原型残差；当技能空间失配较大时启用**低秩残差 Skill Adapter**：`s̃t = As(ŝt) = ŝt + Us·Vs^T·ŝt`（零初始化，初始保持 ŝt）。
- **Stage C（记忆适配）**：面向域内终身学习，冻结主干与接口，仅更新 `Amem`、`τmem`、活跃原型残差与记忆库；样本对齐查询接近已有原型则更新残差与统计，否则进入候选缓冲区，当簇支持足够且 query–skill 方差低时才追加新原型。
- **统一适配目标**：`Llife = Lfm + λalign·‖s̃t − sg(st)‖² + λreg·Σ(‖Δpq_j‖² + ‖Δps_j‖²)`，回放缓冲区只存潜在 query–skill 对，不存原始图像或动作轨迹。

## 6. 主要结论与发现

- **Q1（域内样本效率）**：30% 数据下，LIBERO 平均成功率提升 **16.5%**（尤其 LIBERO-Long），CALVIN 平均完成长度 +0.42，RoboTwin 2.0 Hard +5.0%；100% 数据下 LIBERO 平均 97.8%、RoboTwin Hard 55.0%，均为最优或具竞争力。

- **效率**：同等可训练参数预算下，训练 GPU 小时更低、推理更快、成功率更高。
- **消融关键发现**：Stage-B Bridge 在域内影响小，但移除后 20 示范真实世界成功率从 33.3% 骤降至 12.8%，说明**域偏移下坐标对齐比单纯扩展记忆更关键**。
- **定性发现**：可零样本迁移到新物体-容器组合（如红苹果→绿苹果、盘子→篮子），检索空间呈现与任务语义一致的结构（相似任务共享邻域）。

## 7. 优点（亮点）

- **范式创新**：把机器人适配从"参数中心"转向"记忆中心"，技能显式外化为可检索、可复用、可扩展的 query-skill 条目，天然缓解灾难性遗忘。
- **内联记忆设计精巧**：memory tokens 插入 VLA 前缀流，使查询/技能表示在**原生动作条件化路径**内产生，而非弱耦合的外部检索上下文。
- **查询-技能解耦**：将"检索什么"（query 原型）与"如何行动"（skill value）显式分离，兼顾可检索性与行为一致性。
- **非破坏式更新**：残差 `Δpq/Δps` 在不覆盖基础原型的前提下实现局部适配，配合回放 exemplar（仅存潜在对，不存原始图像/动作）保护旧技能。
- **训练成本与推理效率双优**：86 GPU 小时 + 14 Hz，优于 LoRA 基线。
- **实验体系完整**：仿真 + 真实、域内 + 跨域 + 终身三类场景全覆盖，消融、配置敏感性、记忆增长、检索可视化齐备，且附有 AI 使用声明与可复现性声明。

## 8. 不足与局限

- **依赖强预训练主干**：当基础策略缺乏必要操作原语时，仅靠记忆检索与原型扩展可能不足。
- **记忆库质量受数据覆盖影响**：聚类质量依赖预训练与适配数据的覆盖度与组织；对细粒度时序或接触密集行为，稀疏/组织不佳的记忆条目可能导致次优检索。
- **跨域迁移仍需目标域示范**：Bridge-and-Adapt 只能缓解而非消除表示漂移，在**大 embodiment 变化、严重视觉偏移或动力学显著不同**时无法保证可靠迁移。
- **实验覆盖限制**：
  - RoboTwin 2.0 仅评估 20 个任务子集；
  - 真实世界每任务 rollout 数较少（20 次），统计置信度有限；
  - 部分对比方法在部分基准上缺报结果，横向比较不完全对等。

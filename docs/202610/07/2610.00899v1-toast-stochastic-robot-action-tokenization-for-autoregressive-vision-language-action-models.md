## 摘要
自回归视觉-语言-动作模型通常将连续的机器人动作表示为离散标记序列，从而能够以标准的下一标记预测目标进行动作预测。FAST 通过将包含多种时间频率的动作紧凑地编码为相对较少的标记，显著改进了这种表示。然而，尽管这种压缩减少了自回归预测所需的动作标记数量，却并不一定能提高从有限示范中学习策略的效率。特别是，FAST 通常为每个量化后的动作序列分配单一的确定性标记化，尽管多个标记序列可以表示并解码为相同的机器人运动。我们研究了利用这种表示冗余是否能够改进策略学习。在本文中，我们提出 TOkenization of Action sequences with STochastic sampling（TOAST），一种随机动作标记化方法，它在策略训练期间对同一量化动作序列采样替代标记化。这在不改变底层机器人动作的同时使离散监督多样化，且无需额外示范。在 LIBERO 上的实验表明，TOAST 持续优于其确定性对应方法，且随着训练数据减少，提升幅度增大；当仅有 1/16 的训练数据时，成功率提升 6.8 个百分点。在四项真实机器人操作任务中，TOAST 相比确定性对应方法进一步将平均成功率提升 15.8 个百分点。这些结果证明了随机动作标记化对自回归机器人策略学习的有效性，尤其是在训练数据有限时。

## Abstract
Autoregressive Vision-Language-Action models often represent continuous robot actions as discrete token sequences, enabling action prediction with standard next-token objectives. FAST has substantially improved this representation by compactly encoding action containing diverse temporal frequencies into relatively few tokens. However, while such compression reduces the number of action tokens required for autoregressive prediction, it does not necessarily improve the efficiency of policy learning from limited demonstrations. In particular, FAST typically assigns a single deterministic tokenization to each quantized action sequence, although multiple token sequences can represent and decode to the same robot motion. We investigate whether exploiting this representational redundancy can improve policy learning. In this paper, we propose TOkenization of Action sequences with STochastic sampling (TOAST), a stochastic action tokenization method that samples alternative tokenizations of the same quantized action sequence during policy training. This diversifies the discrete supervision while preserving the underlying robot action and requires no additional demonstrations. Experiments on LIBERO show that TOAST consistently improves over its deterministic counterpart, with the improvement increasing as training data decreases, achieving a 6.8 point gain in success rate when only 1/16 of training data is available. Across four real-robot manipulation tasks, TOAST further improves mean success rate by 15.8 points over the deterministic counterpart. These results demonstrate the effectiveness of stochastic action tokenization for autoregressive robot policy learning, particularly when training data are limited.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：自回归视觉-语言-动作模型（VLA）把连续机器人动作表示为离散 token 序列，用多模态大语言模型的"下一 token 预测"来输出动作。相比 flow matching 类方法，其架构更简单、能复用 MLLM 预训练知识、收敛更快。
- **现有做法**：动作标记化（tokenizer）决定策略"要预测什么"。VQ-VLA 用可学习向量量化，FAST 用免训练的"DCT + BPE"频率压缩，两者都通过缩短 token 序列降低预测难度。
- **被忽视的问题**：频率压缩产生的 token 边界对机器人动作**并不具备物理意义**。一旦词表中存在跨多个量化值的 token，同一个量化动作序列就可以由**多个不同 token 序列表示，且都能精确解码回同一段运动**。然而 FAST 等确定性分词器只依据语料级频率统计挑一条"标准"序列，策略在交叉熵监督下只被要求复现这一条。
- **风险**：在机器人学习中示范数据昂贵、数量有限，反复用同一确定性分词监督，会诱导策略过拟合到与底层运动并非唯一对应的 token 模式或切分边界上。
- **核心假设**：这种表示冗余可以像 NLP 中的子词正则化（subword regularization）一样被利用——随机采样等价分词相当于一种**表示层面的正则化**，在数据越少时收益越明显。
- **整体含义**：论文首次把"随机动作分词"引入自回归机器人策略学习，指出这能在**不增加任何机器人数据、不改变策略架构与目标函数**的前提下，从有限示范中榨取更丰富的离散监督。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想

在训练阶段，对同一量化动作序列 q 采样其**多个等价 token 化**中的一个作为监督目标；所有采样结果解码后完全一致，因此底层动作不变，只有"离散表示"被多样化。推理阶段不做采样。

### 2.2 流程（TOAST 分词流水线）

1. **量化与展平**：连续动作块先经 DCT + 缩放 + 取整得到 q ∈ Z^{D×H}，再展平为一维序列。TOAST 默认采用**维度优先（dimension-major）展平**，把同一动作维度在时间上相邻的值排在一起（区别于 FAST/OpenVLA 的时间步优先展平）。
2. **构建 unigram 语言模型**：
   - 给定量化展平语料 Q = {q₁,…,q_M}，从候选子序列构造大种子词表，同时**保留全部单个量化值**，保证任意动作序列都可被表示；
   - 为每个 token v 赋概率 p(v)，按标准 unigram LM 流程迭代优化并剪枝低贡献 token，直到达到目标词表规模（默认 512）；
   - 用 SentencePiece 实现；默认词表在 1M 条 DROID 动作块上构建（LIBERO 用末端位姿、真机用关节角），使分词器在数据规模变化时保持固定。
3. **随机采样等价分词**：
   - 给定 q，通过 unigram 分数的 **n-best 搜索**得到候选集合 {t₁,…,tₙ}，n-best 用 Forward-DP Backward-A* 算法在**线性时间**内完成（默认 n = 64）；
   - 候选概率近似为
     **P(tᵢ | q) ≈ P(tᵢ)^α / Σⱼ P(tⱼ)^α**
     其中 P(t) = Πᵢ p(tᵢ)；α 控制分布锐度：**α 越大越接近确定性分词，α 越小越接近均匀采样**。实验中 LIBERO 取 α = 0.1，真机取 α = 0.5。
   - 关键性质：所有被采样的 token 序列都解码为同一个 q。
4. **策略训练**：每一步采样一个目标序列 t̃ = t̃₁…t̃_Ñ，最小化标准下一 token 预测负对数似然
   **− Σᵢ log π(t̃ᵢ | l, o, t̃_{<i})**
   即架构与学习目标完全不变，只替换训练目标表示。
5. **推理**：不做采样；策略自回归预测 token 序列，经词表查表 + 逆 DCT 还原为连续动作块；真机上解码不完整则丢弃该序列并用下一观测重跑（极少发生）。

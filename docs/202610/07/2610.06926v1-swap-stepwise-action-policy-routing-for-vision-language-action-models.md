## 摘要
使用视觉-语言-动作（VLA）模型作为骨干的机器人操作系统的任务执行通常只使用一个 VLA。然而，单个 VLA 在不同任务状态和环境中的表现并不好。我们引入了一个在执行过程中动态组合多个 VLA 策略的框架：逐步动作策略路由（SWAP）。SWAP 将策略路由建模为离线强化学习问题，学习一个路由评价器，以根据当前观测在每个决策步骤选择最合适的策略。SWAP 使机器人能够在线上选择新策略来执行，而不是在一个回合的持续时间内固定使用单一策略。我们在真实世界 DROID 操作任务和 LIBERO 仿真实验中评估 SWAP。SWAP 优于固定策略执行和路由基线，在真实世界任务成功率上取得最高 33% 的绝对提升，同时将成功轨迹的机器人动作步长减少了 28.3%。

## Abstract
Robot manipulation systems using Vision-Language-Action (VLA) model backbones typically use just one VLA for task execution. However, individual VLAs do not perform well across different task states and environments. We introduce a framework for dynamically composing multiple VLA policies during execution: StepWise Action Policy Routing (SWAP). SWAP formulates policy routing as an offline reinforcement learning problem, learning a routing critic that selects the most appropriate policy at each decision step given the current observation. SWAP enables robots to select new policies to execute online rather than committing to a single policy for the duration of an episode. We evaluate SWAP on both real-world DROID manipulation tasks and LIBERO simulation experiments. SWAP improves over fixed-policy execution and routing baselines, giving absolute improvements in real-world task success up to 33% while reducing successful trajectory robot action step length by 28.3%.

# SWAP：面向视觉-语言-动作模型的逐步动作策略路由——论文总结

## 1. 核心问题与整体含义

- **研究动机**：当前机器人操作常以单个 Vision-Language-Action（VLA）模型作为骨干策略执行整个任务。但单个 VLA 在不同任务状态、环境扰动和执行阶段中的表现并不稳定，难以在所有场景下都保持最优。
- **核心问题**：与其在回合开始时固定选择一个策略，不如在任务执行过程中动态选择“当前状态下最合适的策略”。这引出了一个新问题：**机器人策略路由**——如何在多个候选 VLA 策略之间进行逐步、在线、长视野的选择。
- **整体含义**：论文提出 **SWAP（StepWise Action Policy Routing）**，将策略路由建模为离线强化学习问题，学习一个路由评价器（routing critic），在每个决策步根据当前观测选择最合适的候选策略。其核心观点是：**鲁棒的机器人执行不仅来自更强的单体策略，也来自对多个互补策略的有效组合与路由。**

## 2. 方法论

### 2.1 核心思想

- 假设有一个有限的候选策略库：  
  \( P = \{\pi_1, \pi_2, \dots, \pi_K\} \)，每个 \(\pi_k\) 是预训练机器人控制器，例如不同架构、数据或训练目标的 VLA。
- 学习一个路由策略：  
  \( \phi(z_t \mid s_t) \)，其中 \(z_t \in \{1,\dots,K\}\) 表示第 \(t\) 步选择的策略索引。
- 实际执行动作从被选中的机器人策略中采样：  
  \( a_t \sim \pi_{z_t}(\cdot \mid s_t) \)。
- 优化目标为最大化长视野折扣回报：  
  \( \arg\max_\phi \mathbb{E}_{\phi,P}[\sum_{t=1}^T \gamma^{t-1} r(s_t,a_t)] \)。
- 与标准策略学习不同，路由器的动作空间不是底层电机控制，而是**策略选择本身**，属于更高层的决策。

### 2.2 离线数据构建

- 从每个候选策略收集机器人交互轨迹，包含成功与失败执行。
- 路由不在每个底层控制步进行，而是在 VLA 输出的 **action chunk 级别**进行：
  - 与 VLA 自身的推理节奏对齐；
  - 不引入额外策略查询；
  - 避免打断 chunk 内部无独立意义的中间动作。
- 每个路由转移表示为：  
  \( (o_t, z_t, r_t, o_{t+c}, d_t) \)  
  其中 \(o_t\) 是 chunk 开始时的观测，\(z_t\) 是所选策略，\(r_t\) 是稀疏奖励，\(o_{t+c}\) 是执行 chunk 后的观测，\(d_t\) 表示回合是否终止。
- 奖励为稀疏二值信号：成功任务完成时最终转移奖励为 10，失败为 0，中间转移均为 0。

### 2.3 离线 Critic 学习

- 使用 **Implicit Q-Learning（IQL）** 训练路由评价器，适合混合质量离线数据下的稳定价值学习。
- 学习两个路由 critic \(Q_1, Q_2\) 和一个状态价值函数 \(V\)，最小化时序差分目标：  
  \( L_Q = \mathbb{E}_{(o_t,z_t,r_t,o_{t+c},d_t)\sim D}[\sum_{i=1}^2 (Q_i(o_t,z_t) - (r_t + \gamma(1-d_t)V(o_{t+c})))^2] \)。
- \(V\) 通过 expectile regression 在已学习的 Q 值上优化。
- 训练和推理时均使用两个 critic 的最小值，以产生保守价值估计，减少高估偏差。
- 直觉上，离线 RL 鼓励 critic 给“导致成功下游结果”的策略选择更高价值，给失败轨迹中的选择更低价值。

### 2.4 路由 Critic 架构

- 使用冻结的 **Qwen2.5-VL-3B** 视觉语言模型编码当前视觉观测和语言指令，得到 2048 维嵌入。
- 将该嵌入与候选策略身份对应的可学习嵌入拼接。
- 输入轻量级 double-Q critic 架构，由 MLP 组成，输出候选策略集合上的标量 action-value；另有单独 value network 用于 IQL 训练。

### 2.5 测试时策略路由

- 在部署时，给定当前观测 \(o_t\)，对所有候选策略评估路由 critic：
  \[
  z_t = \arg\max_z \min(Q_1(o_t,z), Q_2(o_t,z))
  \]
- 选择预测长视野效用最高的策略，执行其产生的短视野 action chunk。
- 每执行完一个底层 chunk 后重复该过程，从而在整个任务执行中动态切换策略。
- 在真实 DROID 实验中，SWAP 在推理时聚合多个相机视角的 Q 值，以提高对视角歧义和遮挡的鲁棒性。

## 3. 实验设计

### 3.1 数据集 / 场景与 Benchmark

- **真实世界 DROID**：
  - 使用 DROID Franka 平台，7-DoF Franka Panda 机械臂，配多外部相机和腕部相机。
  - 三个桌面操作任务：
    1. 将 marker 放入碗中；
    2. 将 cube 放入杯子；
    3. 将布上的 cube 转移到碗中。
  - 候选策略：Physical Intelligence 的 \(\pi_0\)、\(\pi_0.5\)、\(\pi_0\)-FAST。
  - \(\pi_0.5\) 和 \(\pi_0\)-FAST 使用公开 DROID checkpoint 零样本执行；\(\pi_0\) 因零样本能力不足，在小规模数据上微调。
  - 另设 OOD 实验：加入未见过的干扰物，评估两个 DROID 任务，每个任务 10 次试验，不重新训练 critic。

- **LIBERO 仿真**：
  - 使用 LIBERO 和 LIBERO-Plus 基准，聚焦 **LIBERO-Spatial** 子集。
  - LIBERO-Plus 包含更具挑战性的分布外任务变体。
  - 候选策略随实验变化，包括 \(\pi_0\)、OpenVLA、OpenVLA-OFT 及其变体。
  - 在五策略设置中，策略排序在分布偏移下发生反转：\(\pi_0\) 在分布内最强，但在 LIBERO-Plus 上仅排第四。
  - 另设两策略设置：一个强策略 \(\pi_0.5\) 和一个明显较弱策略，用于测试 SWAP 是否会被弱策略拖累。

### 3.2 对比方法

- **单个候选策略独立执行**：标准固定策略设置，整个回合不路由。
- **Random routing**：在每个控制步或 chunk 均匀随机选择候选策略，用于隔离“切换本身”与“学习路由”的贡献。
- **SWAP**：论文提出的离线 RL 路由方法。
- **消融**：
  - SWAP w/o \(\pi_0\)：移除 \(\pi_0\) 后的路由表现；
  - SWAP w/o OpenVLA-Spatial：移除 OpenVLA-Spatial 后的路由表现；
  - 两策略 dominant policy 设置下的比较。

### 3.3 训练数据与评估设置

- DROID：每个策略、每个任务收集 10 条成功和 10 条失败 rollout，共 3 任务 × 3 策略 = 180 条轨迹；每个方法在每任务 10 次留出试验上评估。
- LIBERO：每个策略、每个任务收集 50 条 rollout，在 8 个 LIBERO-Spatial 任务上训练，留出任务 5 和 9 用于评估。
- 奖励：成功最终转移为 10，失败为 0，中间为 0；未使用中间奖励塑形。
- 训练：真实世界实验训练 4k–8k epochs；仿真训练 200 epochs；DROID 和 LIBERO 分别训练独立路由 critic。

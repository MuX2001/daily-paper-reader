## 摘要
对于在户外环境中作业的地面机器人，理解其所处地形的属性对于确保可靠运行至关重要。在大多数基于感知的研究中，该问题被表述为在训练期间定义固定类别数量的类别分类。我们提出一种方法，使新的表面类别能够作为可训练向量添加，这些向量随后可用于解决更高层次的任务。通过采用基于预测机器人下一时刻状态的学习范式并使用注意力模块，我们将 Belyaev-Kushnarev 数据集上的分类准确率提升至 98.56%，在 BorealTC 上提升至 94.8%。

## Abstract
For ground robots operating in outdoor environments, understanding the properties of the underlying terrain is essential for ensuring reliable operation. In most perception-based studies, this problem is formulated as categorical classification with a fixed number of classes defined during training. We propose an approach that enables new surface classes to be added as trainable vectors, which can subsequently be used to address higher-level tasks. By employing a learning paradigm based on predicting the robot's next state in time and using attention blocks, we improved classification accuracy to 98.56% on the Belyaev-Kushnarev dataset and 94.8% on BorealTC.

## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作方面展现出强大前景，但将其适配到新任务和新领域仍然效率低下：现有方法往往依赖参数调优，成本高昂，并可能导致对先前已学任务的灾难性遗忘。为解决这一问题，我们提出 Optimus-R，一个以记忆为中心的 VLA 框架，将机器人适配形式化为显式的查询-技能记忆调优。Optimus-R 引入了：(i) 用于技能提取的内联记忆接口。它向 VLA 前缀流中插入可学习记忆 token，使主干能够在原生动作条件化路径中导出控制感知的查询和技能表示。(ii) 用于技能学习的查询-技能记忆库。它将技能外化为用于决定检索什么（what）的查询原型，以及用于指定如何行动（how）的技能值，从而在有限参数更新下支持技能复用与扩展。(iii) 用于技能更新的轻量级桥接-适配机制。它通过轻量级适配器和残差记忆更新，将目标域查询和技能与现有记忆空间对齐。在域内适配、跨域适配和终身学习上的实验表明，Optimus-R 能够实现数据高效的技能学习，同时缓解灾难性遗忘。

## Abstract
Vision-Language-Action (VLA) models have shown strong promise for general-purpose robotic manipulation, yet adapting them to new tasks and domains remains inefficient: existing methods often rely on parameter tuning, incurring substantial costs and risking catastrophic forgetting of previously learned tasks. To address this, we propose \textbf{Optimus-R}, a memory-centric VLA framework that formulates robotic adaptation as explicit query-skill memory tuning. Optimus-R introduces: (i) An \textbf{Inline Memory Interface for skill extraction}. It inserts learnable memory tokens into the VLA prefix stream, allowing the backbone to derive control-aware query and skill representations within the native action-conditioning pathway. (ii) A \textbf{Query-Skill Memory Bank for skill learning}. It externalizes skills into query prototypes for deciding \emph{what} to retrieve and skill values for specifying \emph{how} to act, supporting skill reuse and expansion with limited parameter updates. (iii) A lightweight \textbf{Bridge-and-Adapt mechanism for skill updating}. It aligns target-domain queries and skills with the existing memory space through a lightweight adapter and residual memory updates. Experiments on in-domain adaptation, cross-domain adaptation, and lifelong learning show that Optimus-R enables data-efficient skill learning while mitigating catastrophic forgetting.

- **背景**：Vision-Language-Action（VLA）模型借助大规模机器人数据预训练，已成为通用机器人操作的重要基础（π0、π0.5、OpenVLA、OpenVLA-OFT 等），但落地部署时仍需适配新任务、新物体、新场景与新领域，且演示数据往往有限。

  - 适配成本高（训练算力、数据需求）；
  - 新技能难以检索、扩展与复用，并可能**灾难性遗忘**旧任务。
- **由此引出的关键问题**：VLA 能否通过**显式记忆接口**来获取、存储和复用技能，而不是反复更新模型参数？
- **作者指出的三个耦合难题**：
  1. **技能应源自 VLA 自身**，而非作为"外挂上下文"（外部检索记忆与 VLA 动作条件化路径弱耦合，难以编码控制相关信息）；
  2. **技能应被显式组织**，而非吸收进权重（权重更新使新行为难以检索、扩展、复用，并在持续学习中干扰旧技能）；
  3. **技能在域偏移下应保持可检索**（视觉或动力学变化会把目标域观测推离源域记忆空间，造成查询与存储技能失配）。
- **整体含义**：论文把机器人适配统一重述为**技能提取（skill extraction）—技能学习（skill learning）—技能更新（skill updating）** 三件事，提出以记忆为中心的框架 Optimus-R，主张"用显式查询-技能记忆调优替代反复的参数更新"。

## 2. 方法论

### 2.1 核心思想

以预训练 π0.5 为初始化，**冻结主干为主**，把技能外化为一个可检索、可扩展的"查询-技能记忆库"；通过三阶段（接口预训练 → 桥接适配 → 记忆适配）仅更新极少量参数与记忆条目，实现数据高效适配与抗遗忘。

### 2.2 三大组件与关键细节

- **(i) Inline Memory Interface（内联记忆接口，用于技能提取）**
  - 向 VLA 前缀流插入可学习记忆 token `E_mem`，主干前向得到 `[H^vl_t; M_t] = F_θ(O_t, L; E_mem)`，使记忆状态天然处在策略的原生动作条件化路径上。
  - 用**两个独立的注意力池化** `AttnPool_q` / `AttnPool_s` 从共享的 `M_t` 读出两路表示，再经 Query Encoder `f_q`、Skill Encoder `f_s` 得到：
    - 查询嵌入 `q_t ∈ R^{d_q}`：**仅用于检索**；
    - 技能嵌入 `s_t ∈ R^{d_s}`：保留动作相关信息，作为记忆库中的 **value**。
  - 训练时用轻量 **Skill Decoder** `D_s(s_t)` 重建未来动作块（Huber 损失），把技能空间锚定在**可执行行为**上（部署时不需要 Skill Decoder）。
  - **Token Projector** `T_ψ` 将技能嵌入映射为 VLA 兼容的 skill tokens `S_t`，条件化 Flow Policy：`Ã_t = π_θ(H^vl_t, S_t)`。
  - 要点：查询与技能**解耦**（分别回答"检索什么"和"如何行动"），且记忆内联而非外挂。

- **(ii) Query-Skill Memory Bank（查询-技能记忆库，用于技能学习）**
  - 存储形式：`B = {(p^q_j, p^s_j, n_j, E_j)}_{j=1}^K`，其中 `p^q_j` 为查询原型（决定检索什么）、`p^s_j` 为技能原型（指定如何行动）、`n_j` 为支持计数、`E_j` 为少量潜在 query-skill 对（用于 replay，**不存储原始图像/动作/轨迹**）。
  - **构建流程**：运动感知降采样（按动作变化量 `ν_i` 保留高动态样本）+ 归一化进度分层采样 + 技能聚类（先在查询空间聚类，对技能方差超阈值的簇再在技能空间二次切分），从而同时保证"可被状态-任务上下文检索"与"动作空间内一致"。
  - **检索**：先做查询对齐 `q'_t = A_mem q_t`；取 top-`K_r` 原型，用带温度的 softmax 权重 `α_tj ∝ exp(sim(q'_t, p^q_j + Δp^q_j)/τ_mem)` 聚合得到 `ŝ_t = Σ_{j∈N_t} α_tj (p^s_j + Δp^s_j)`。
  - **残差更新**：`Δp^q_j`、`Δp^s_j` 对基础原型做**局部修正而不覆盖**，因此适配改变的是记忆坐标的局部，而可复用技能本身被保留。

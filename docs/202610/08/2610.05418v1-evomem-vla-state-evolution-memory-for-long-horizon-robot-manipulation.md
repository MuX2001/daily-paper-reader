## 摘要
大多数视觉-语言-动作（VLA）模型依赖当前观测，一旦任务相关证据离开视野就会丢失，从而限制了其在长时程、依赖记忆的任务上的表现。现有工作引入压缩的历史特征或稀疏的视觉关键帧。然而，孤立的快照可能使策略无法确定过去交互中发生了什么变化，以及接下来应采取哪个动作。为克服这一局限，我们提出 EvoMem-VLA，它通过显式编码并保留历史状态之间的观测变化来构建状态演化记忆。这些变化表示保存了交互结果的证据，使策略能够超越孤立快照来跟踪任务进展。具体而言，我们引入条件增量标记化，将有序帧对编码为有方向的、源条件化的增量 token，每个 token 与其对应的状态证据相关联。一个共享的 VLM 主干支持任务自适应路由：普通长时程任务遵循直接动作路径，而多阶段任务使用子任务路径，该路径生成可执行子任务，作为动作生成的额外输入。对于每个仿真基准，仅使用一个联合训练的策略，EvoMem-VLA 在 RMBench 上达到 80.7% 的成功率，在 RoboMME 上达到 82.0%，并在涵盖两种机器人本体的四个真实世界任务中达到 83.8%。这些结果在所有三种评估设置中均较先前最先进方法有显著提升。

## Abstract
Most vision-language-action (VLA) models rely on current observations and lose task-relevant evidence once it leaves view, limiting performance on long-horizon, memory-dependent tasks. Existing efforts incorporate compressed historical features or sparse visual keyframes. However, isolated snapshots can leave the policy uncertain about what changed during past interactions and which action should follow. To overcome this limitation, we propose EvoMem-VLA, which constructs state-evolution memory by explicitly encoding and retaining observed changes between historical states. These change representations preserve evidence of interaction outcomes, allowing the policy to track task progress beyond isolated snapshots. Specifically, we introduce conditional delta tokenization to encode ordered frame pairs into directional, source-conditioned delta tokens, each associated with its corresponding state evidence. A shared VLM backbone supports task-adaptive routing: normal long-horizon tasks follow a direct action route, whereas multi-stage tasks use a subtask route that generates an executable subtask as an additional input for action generation. With a single jointly trained policy for each simulation benchmark, EvoMem-VLA achieves success rates of 80.7\% on RMBench, 82.0\% on RoboMME and 83.8\% across four real-world tasks spanning two robot embodiments. These results represent substantial improvements over the previous state of the art in all three evaluation settings.

- **现有方案的不足**：
  - 现有记忆增强方法要么使用**离散状态特征**（如压缩的历史视觉-语言特征、时刻 token），要么使用**稀疏视觉关键帧**。
  - 这些方案存储的是"孤立快照"，任务相关的变化仍隐含在历史中，策略必须自行从稀疏状态证据中推断"发生了什么变化"，这在高精度长时程控制中十分困难。
- **研究动机**：长时程控制要求策略将记忆中的状态与执行过程中的变化关联起来。因此需要一种记忆表示，既保留"观察到了什么"，又显式编码"相对于更早观测发生了什么变化"。
- **整体含义**：论文提出 **EvoMem-VLA**，一种"状态演化记忆"范式，通过显式编码并保留稀疏历史观测之间的交互变化，使策略能够区分仅靠离散历史无法区分的交互过程，并据此生成正确的下一步动作。

## 2. 方法论

### 2.1 核心思想

- 构建**状态演化记忆**：将初始帧、近期历史帧、选定关键帧与显式编码帧间变化的 **delta token** 按时间顺序组织在一起，形成多尺度记忆。
- 每个 delta token 与其对应的目标状态证据绑定，使记忆同时保留"视觉状态"与"状态间变化"两类互补信息。
- 共享 VLM 主干支持**任务自适应路由**：普通长时程任务直接预测动作；多阶段任务先生成可执行子任务，再将其作为额外上下文引导动作生成。

### 2.2 关键技术细节

**（1）条件增量标记化（Conditional Delta Tokenization）**

- 给定有序源-目标图像对 $(I_u, I_v)$（$u \le v$），冻结的 DINOv3 编码器 $\phi$ 提取 patch 特征 $f_u = \phi(I_u)$、$f_v = \phi(I_v)$。
- 配对帧编码器 $g_\Delta$ 将目标中"无法由源解释"的信息压缩为单个 token：$z_{u \to v} = g_\Delta(f_u, f_v; q_\Delta)$，其中 $q_\Delta$ 为可学习 query。
- 解码器 $h_\Delta$ 以源特征和该 token 为条件重建目标特征 $\hat{f}_v = h_\Delta(f_u, z_{u \to v})$，使用 log-cosh 重建损失 $L_\Delta$ 预训练。
- 预训练后冻结 DINOv3 与 $g_\Delta$，丢弃 $h_\Delta$，仅将 delta token 用于 VLA。
- 该瓶颈产生的是**方向性、源条件化的变化 token**，而非像素差、光流场或动作编码。

**（2）状态演化记忆构造**

- **多尺度状态证据**：固定锚点包含 $0$、$t-30$、$t-15$、$t$ 时刻观测；有序事件状态库 $\{(\kappa_i, o_{\kappa_i})\}$ 保留至多 $K$ 个选定观测。历史索引在 episode 开始时截断为零，复用初始帧。
- **状态链接变化 token**：
  - 近期锚点：每个近期锚点与其 15 步前的观测配对，产生三组 token $d_t^{(j)}$（$j=1,2,3$，由新到旧）。
  - 事件状态：对每个 $\kappa_i$，编码 $(\kappa_i - \delta_e, \kappa_i)$，$\delta_e$ 为事件局部滞后。
  - 所有 delta token 经线性层投影到 VLM 嵌入空间。
- **记忆组装**：近期链 $M_t^{anc} = [V_0; d_t^{(3)}; V_{t-30}; d_t^{(2)}; V_{t-15}; d_t^{(1)}; V_t]$，事件条目按捕获顺序追加：$M_t = [M_t^{anc}; \{(d_{e_i}; V_{\kappa_i})\}_{i=1}^{m_t}]$。每个 delta token 紧邻其目标状态。
- **在线事件状态获取**：Keyframe Head $k_\omega$ 从动作查询状态预测动作时域内每个偏移的记录概率 $\hat{p}_t = \sigma(k_\omega(Z_{A_t})) \in [0,1]^H$，超过阈值时调度最高分的未来偏移，到达该时刻才真正记录，事件库保留最新 $K$ 条。

**（3）任务自适应路由**

- **子任务路径**：$C_t = [M_t; L; E_\ell(R_t)]$，先生成子任务 $\hat{s}_t = \text{Decode}_\theta(C_t)$，再将其追加到同一状态-变化上下文进行第二次前向传播预测动作 $\hat{A}_t = \Pi_{\theta,\psi}([C_t; E_\ell(\hat{s}_t)])$。$R_t$ 为历史子任务文本，训练时来自标注，部署时累积生成文本并跳过空输出与连续重复。
- **直接路径**：$R_t$ 为空，$\hat{A}_t = \Pi_{\theta,\psi}(C_t)$。
- 路由由任务级配置指定，而非学习得到的复杂度分类器。两条路径共享视觉编码器、delta 投影、VLM 主干、动作查询、动作头与 Keyframe Head。

**（4）两阶段优化与闭环推理**

- **阶段一**：冻结 $\phi$，在有序帧对上训练 $g_\Delta$ 和 $h_\Delta$。
- **阶段二**：冻结 $\phi$ 和 $g_\Delta$，在机器人演示数据上优化 VLA、动作头、delta 投影与 Keyframe Head，总损失 $L = L_{act} + \lambda_{lang} L_{lang} + \lambda_{kf} L_{kf}$。
- **闭环推理**：每个重规划步执行"读取-推断-行动-写入"循环，所有预测仅基于机器人已观测到的证据；Keyframe Head 可同时调度未来捕获，到达时间戳才写入。

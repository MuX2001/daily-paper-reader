Abstract 

Genuine embodied agency requires robots to turn continuous real-world experience into last-ing, transferable skills. This demands continual learning that integrates new capabilities with-out eroding prior knowledge as tasks and envi-ronments evolve. Experience replay mitigates forgetting, but storing complete demonstrations becomes costly as tasks accumulate. World– action models offer a generative alternative, reconstructing past experience through joint predictions of actions and future observations. However, visually coherent rollouts may con-tain actions that cannot realize the predicted transitions, while new-task adaptation can dis-rupt previously learned behavior. RIFAR there-fore combines reliability screening with drift-aware replay selection. It reconstructs trajecto-ries from compact demonstration prefixes and uses a frozen inverse-dynamics model to assess action–visual consistency. Training first com-bines current demonstrations with the highest-quality screened trajectories. RIFAR then com-pares action predictions before and after this adaptation on identical historical inputs, re-selecting trajectories with larger normalized drift from the same screened pool for contin-ued training. Across three LIBERO suites and real-world experiments, RIFAR surpasses the previous state of the art in WAM-based gen-erative replay. On LIBERO-Goal, it achieves 90.97 AUC while retaining only 320 historical time steps per task, approximately 4.9% of the steps retained using 50-demonstration replay. 

1 Introduction 

Robots operating in evolving environments must continually acquire new manipulation skills while retaining earlier capabilities. Yet adapting a shared action policy to new tasks can disrupt previously learned behavior, causing catastrophic forgetting (Kirkpatrick et al., 2017; Liu et al., 2023). Experi-ence replay mitigates this problem by training on stored demonstrations alongside current-task data (Chen et al., 2026; Zhao et al., 2026). However, these demonstrations contain long sequences of ob-servations, proprioceptive states, and actions, mak-ing storage increasingly costly as tasks accumulate. Generative replay reduces this storage burden by reconstructing historical training examples from model knowledge (Shin et al., 2017). World–action models (WAMs) are well suited to this approach: by jointly predicting actions and future observa-tions (Zhu et al., 2025), they can recurrently recon-struct past-task trajectories for replay. Despite this potential, continual learning with WAMs remains largely unexplored. REGEN takes an initial step by generating replay trajectories from historical task instructions and current-task observations for continual imitation learning (Govind et al., 2026). Although REGEN demonstrates the feasibility of WAM-generated replay, its storage-efficient de-sign does not ensure reliable supervision. To avoid retaining historical visual contexts, REGEN con-ditions generation on a past-task instruction and a current-task observation. However, the current scene may lack the objects or spatial configuration required for the earlier task. Retaining compact his-torical context provides a task-compatible starting point, but does not eliminate errors during recurrent generation. A WAM may still produce a visually coherent rollout whose actions fail to realize the de-picted transitions, resulting in misleading replay su-pervision. Reliability screening, however, does not determine which remaining trajectories are most important for preserving earlier skills. Learning a new task can induce substantial action drift on some historical trajectories, potentially disrupting previously successful behavior. These trajectories warrant greater replay priority to reinforce affected behaviors during further training. ## 2 RELATED WORK 

2.1 CONTINUAL LEARNING 

Continual learning aims to acquire new knowledge while retaining previous capabilities. Sequential fine-tuning provides a baseline but can cause catastrophic forgetting. EWC penalizes changes to parameters whose importance is estimated using Fisher information (Kirkpatrick et al., 2017), while PackNet protects assigned weights through iterative pruning and task-specific masks (Mallya & Lazebnik, 2017). LoRA reduces trainable parameters through low-rank updates to frozen pretrained weights, but does not itself guarantee retention (Hu et al., 2021). Experience replay mixes historical examples with current-task data to mitigate forgetting (Liu et al., 2023). A WAM may still produce a visually coherent rollout paired with actions that would fail to realize the depicted transitions when executed by the robot. Trajectories containing such inconsistencies provide misleading supervision and should not be used for replay. Filtering them, however, does not determine which of the remaining trajectories are most important for preserving earlier skills. Learning a new task can cause substantial action drift on specific trajectories from earlier tasks, disrupting behaviors that the policy previously executed successfully. These high-drift trajectories should receive greater replay priority so that the affected behaviors are reinforced before they are overwritten by further training. RIFAR therefore first filters generated trajectories according to action–visual consistency, then gives higher replay priority to reliable trajectories with larger action drift. This prevents inconsistent generated data from entering training and reinforces the earlier behaviors most affected by learning the new task. We introduce RIFAR (Reliability and Forgetting-Aware Replay ) for continual WAM learning (Figure 1). RIFAR retains only 320 historical time steps per task—4.9% of the data stored by 50-demonstration experience replay—and uses this compact history to initialize recurrent generation of past-task trajectories. A frozen inverse-dynamics model then screens the generated trajectories by checking whether their actions are consistent with the visual state changes they depict. In the first phase, the policy is trained on current-task demonstrations together with the highest-quality generated trajectories that pass reliability screening. To identify which earlier behaviors were disrupted by learning the new task, RIFAR compares the actions predicted on the same historical states before and after the first training phase. It then reselects trajectories from the screened pool for the second phase, giving higher priority to those whose action predictions shifted most. This targeted replay reinforces earlier behaviors while the policy continues to learn the new task. We evaluate the resulting policy on previously learned tasks and report its success rates. We evaluate RIFAR with Cosmos Policy on LIBERO-Goal and LIBERO-Object. RIFAR surpasses REGEN by 23.17 and 5.39 AUC points on the two suites, respectively. We further examine the trade-off between historical storage and performance on LIBERO-Goal. RIFAR reaches 90.97 AUC while retaining only 320 historical time steps per task, outperforming ten-demonstration experience replay (ER(10)), which achieves 90.70 AUC with approximately 1,300 retained steps. Ablation studies and action-drift analyses further isolate the contributions of reliability screening and adaptive replay selection to preserving previously learned manipulation skills. 2.1 Continual Learning 

Continual learning aims to acquire new capabilities while retaining prior knowledge. EWC constrains updates according to Fisher-based parameter im-portance (Kirkpatrick et al., 2017), while PackNet preserves task-specific weights through iterative pruning and masking (Mallya and Lazebnik, 2017). LoRA reduces trainable parameters through low-rank updates to frozen pretrained weights (Hu et al., 2021), but parameter efficiency alone does not guar-antee retention. Experience replay revisits earlier tasks by mixing past examples with current-task data (Liu et al., 2023). Complete manipulation demonstrations contain sequences of images and actions. Generative replay instead reconstructs his-torical training examples (Shin et al., 2017), reduc-ing reliance on stored demonstrations. 

2.2 Vision-Language-Action Models for Robot Manipulation 

Recent work applies continual learning to vision-language-action (VLA) policies (Lu et al., 2026). CLARE expands adapters using feature novelty and routes inputs without task labels or stored ex-emplars (Römer et al., 2026). For continual re-inforcement learning, CRL-VLA combines goal-conditioned value modeling with asymmetric regu-larization (Zeng et al., 2026), while Simple Recipe Works finds limited forgetting when adapting pre-trained VLAs with LoRA and on-policy reinforce-ment learning (Hu et al., 2026). Replay mitigates forgetting in real-world VLA experiments (Zhu et al., 2026). PHASER allocates replay capac-ity by manipulation phase and prioritizes samples through language–vision similarity and action di-vergence (Chen et al., 2026); Info-VLA uses replay-anchored contrastive learning with cross-modal mutual-information constraints (Zhao et al., 2026). 

2.3 World Action Models for Continual Robot Learning 

World–action models jointly predict actions and future observations, enabling them to recurrently generate complete manipulation trajectories (Lu et al., 2026; Kim et al., 2026). This capability pro-vides a natural basis for generative replay, as ear-lier experience can be reconstructed by the model rather than stored in full. Despite this potential, continual learning with WAMs remains largely un-explored. REGEN represents an initial approach, training on generated trajectories from earlier tasks alongside current-task data (Govind et al., 2026). To reduce historical storage, its main configuration conditions earlier-task instructions on current-task observations. This may start generation from a scene that lacks the objects or spatial configuration required by the earlier task. Moreover, a coherent predicted video does not guarantee that its paired actions would produce the depicted transitions dur-ing robot execution. Although REGEN documents these inconsistencies, it does not explicitly remove unreliable trajectories before replay or prioritize trajectories according to how strongly new-task learning changes earlier action predictions. 

3 Method 

RIFAR combines reliability screening with adap-tive replay selection for continual robot learning with WAMs. As shown in Figure 1, it reconstructs past-task trajectories from compact historical con-texts and screens them for action–visual consis-tency to form a reliable replay pool. Training pro-ceeds in two phases. We first adapt the policy using current-task data and the highest-quality screened trajectories. We then compare its action predic-tions before and after this adaptation on identical historical contexts from the same replay pool. Tra-jectories with the largest normalized action drift are prioritized for replay in the second phase, while training on the current task continues.

The policy receives third-person and wrist RGB obser-vations, proprioceptive states, and language instruc-tions, and predicts a 16-step action chunk. 4.2 Main Results and Memory Efficiency 

As shown in Table 1, RIFAR achieves higher AUC and lower NBT than REGEN across all three eval-uated LIBERO suites, indicating better retention of previously learned skills. On LIBERO-Goal, RI-FAR improves AUC from 67.8 to 90.97 and reduces NBT from 46.7 to 7.45 compared with REGEN. The smaller AUC gains on Object and Spatial are 5.39 and 9.93 points, respectively. RIFAR also remains competitive with experi-ence replay using stored demonstrations, while re-taining only compact initial-state anchors rather than complete trajectories. We further examine the relationship between retained historical data and performance in a separate study on LIBERO-Goal (Figure 3(b,c)). RIFAR achieves an AUC of 90.97, slightly exceeding ER(10)’s 90.70 while retaining approximately one-quarter as many historical time steps (320 versus 1,300). ER(50) achieves a higher AUC of 91.80 but retains approximately 6,500 time steps per task. These results show that RIFAR re-mains competitive with experience replay while retaining substantially less historical data. 

4.3 Ablation Studies Effect of the Number of Anchors. We vary the number of anchors per historical task on LIBERO-Goal to assess the trade-off between retained context and continual learning performance (Fig-ure 3(a)). K = 50 with AUC only 0.53 points lower.

4.4 Real-World Continual Learning 

We evaluate Cosmos Policy on three real-world tasks using a Franka robot (Figure 5). Cube pick-and-place requires grasping and placement; board wiping requires controlled motion while maintain-ing eraser contact with the board; and table clean-ing involves sweeping with a broom. Their differ-ing motion and contact requirements test whether a shared policy can acquire new behaviors while retaining earlier skills. We compare RIFAR with se-quential fine-tuning, ER(50), and REGEN. Sequen-tial fine-tuning uses only current-task demonstra-tions. ER(50) replays 50 complete demonstrations per historical task, whereas REGEN and RIFAR replay generated historical experience. After each stage, we evaluate all compared meth-ods on all tasks seen so far and report FWT, NBT, and AUC. Table 4 shows that REGEN reduces forgetting compared with sequential fine-tuning, while RIFAR further improves both task acquisi-tion and retention. Relative to REGEN, RIFAR raises AUC from 50.39 to 57.78 and lowers NBT from 26.77 to 8.84. FWT also rises from 57.67 to 61.00, supporting improved new-task acquisition. Although ER(50) remains stronger overall, RIFAR approaches its AUC (57.78 versus 59.83) while re-taining only compact historical contexts rather than complete original demonstrations. These results support reliable, targeted generative replay as an ef-fective way to preserve earlier manipulation skills while retaining only compact historical contexts. 

5 Conclusion 

RIFAR combines reliability screening and drift-aware replay for continual WAM learning. It recon-structs past-task trajectories from compact histor-ical contexts and uses a frozen inverse-dynamics model to assess action–visual consistency. Train-ing first combines current demonstrations with the highest-quality screened trajectories, then priori-tizes high-drift trajectories from the same reliable pool. Across three LIBERO suites and real-world experiments on a Franka robot, RIFAR achieves higher AUC and lower NBT than REGEN while remaining competitive with real-data replay. On LIBERO-Goal, it reaches 90.97 AUC while retain-ing only 320 historical time steps per task—4.9% of those retained by ER(50). This slightly exceeds the 90.70 AUC of ten-demonstration replay, which retains approximately 1,300 steps per task. These results support using WAMs’ generative capacity to preserve earlier manipulation skills through reli-able reconstruction and adaptive replay. 8Limitations 

Although RIFAR improves continual learning per-formance, several limitations remain. First, IDM-based screening improves the quality of generated replay but cannot eliminate unsuccessful trajecto-ries; residual errors may introduce noise into replay training. The IDM is pretrained and kept frozen during continual learning, so substantial task distri-bution shifts may reduce its ability to assess unfa-miliar manipulation behaviors. Stronger verifica-tion mechanisms or more robust trajectory-quality models could improve reliability estimation. Sec-ond, the current WAM relies on value-based termi-nation during autoregressive trajectory generation. A high predicted value can trigger premature stop-ping before the task is complete. Explicit success verification could help determine whether a gener-ated trajectory achieves the task objective. Finally, recurrent generation can accumulate errors over long horizons. Anchor-based or hierarchical gen-eration may improve replay quality for longer and more complex manipulation tasks.

9A Implementation Specification 

A.1 LIBERO Benchmark 

LIBERO is a language-conditioned robot manip-ulation benchmark designed to evaluate lifelong robot learning under sequential task adaptation. It contains multiple task suites with different sources of task variation. In this work, we evaluate RIFAR on three LIBERO suites: LIBERO-Goal, LIBERO-Object, and LIBERO-Spatial. LIBERO-Goal focuses on goal-level manipu-lation variations, where the robot needs to learn diverse manipulation objectives, such as object placement, drawer operation, and object inter-action. LIBERO-Object evaluates object-level generalization by requiring similar manipulation skills to be transferred across different object cate-gories. LIBERO-Spatial emphasizes spatial reason-ing, where the robot needs to perform manipulation under different object locations and spatial config-urations. Each suite contains 10 language-conditioned ma-nipulation tasks. Following our continual learning protocol, Tasks 0–5 are jointly used for initial pol-icy training, while Tasks 6–9 are sequentially in-troduced during continual learning. The complete task instructions used in our experiments are listed in Table 5. 

B Training Details 

B.1 Training Protocol 

Before continual learning, we first train a base policy on the initial task set of each LIBERO suite. The policy is initialized from the pretrained Cosmos-Predict2-2B-Video2World checkpoint and fine-tuned using the Cosmos-Policy framework. For each LIBERO suite, Tasks 0–5 are jointly used for base policy training, providing the initial manip-ulation capabilities for subsequent continual learn-ing experiments.The training data consists of roll-out trajectories. For each task, 50 successful trajec-tories are used during training. Demonstrations and rollout trajectories are sampled with equal probabil-ity during optimization. The policy predicts action chunks with a horizon of H = 16 .After obtaining the base policy checkpoint, we perform sequential continual learning on Tasks 6– 9. At each continual learning stage, the model is trained using newly introduced task demonstrations together with historical replay trajectories.Each continual learning stage consists of two optimiza-tion periods separated by a replay update step, with a total of 800 optimization steps. The first optimiza-tion period contains 500 steps. During the first 300 steps, the ratio between current-task data and re-play data is set to 6:4. For the remaining 200 steps, the ratio is changed to 5:5. After this period, the historical replay set is updated using drift-aware re-play selection. The model is then further optimized for 300 steps using the updated replay set with a current-task to replay-data ratio of 5:5. 

B.2 Optimization Hyperparameters 

The main optimization configurations used in base policy training and continual learning are summa-rized in Table 6. The same configuration is applied across all LIBERO suites unless otherwise speci-fied. 

B.3 Evaluation Protocol 

We evaluate continual learning performance fol-lowing the sequential task adaptation protocol de-scribed in the main paper. For each LIBERO suite, the model is first trained on the initial task set (Tasks 0–5) and evaluated to obtain the initial per-formance. Then, new tasks (Tasks 6–9) are in-troduced sequentially, and the model is evaluated after each task adaptation stage. During evaluation, the model is tested on all previously encountered tasks, including both the newly acquired task and historical tasks. Therefore, each evaluation stage measures both the acquisition ability on the cur-rent task and the retention of previously learned manipulation skills. All compared methods follow the same task order, evaluation environments, lan-guage instructions, and observation modalities to ensure a fair comparison. For continual learning evaluation, we report three complementary metrics: forward transfer (FWT), normalized backward transfer (NBT), and area under the continual learning curve (AUC). FWT measures the ability of a model to acquire new tasks after continual updates. NBT evaluates the performance degradation of previously learned tasks after learning new tasks. AUC summarizes the overall continual learning performance through-out the sequential adaptation process by consider-ing both task acquisition and knowledge retention. Higher FWT and AUC values indicate better contin-ual learning performance, while lower NBT values indicate less degradation. The corresponding formulations are given below.

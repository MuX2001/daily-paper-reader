## 摘要
基础模型和大规模人类数据提供了丰富的操作意图来源，但将这些意图转化为多指机器人行为仍然困难。灵巧手仍然缺乏一种可复用的低层基元，能够在不同任务和具身形态之间可靠地建立接触。我们提出 GOTT，一个围绕单一跨具身接触获取基元构建的抵达—获取—移动框架。给定与机器人无关的物体轨迹和抵达规格，GOTT 首先将手带到任务相关的接触区域附近。随后，共享的闭环基元从这一近似初始化中建立稳定接触，并由位姿条件控制器跟踪期望的物体运动。抵达规格可以来自未来感知规划、外部模型或人类演示，而基元和跟踪后端保持不变。仿真和真实世界实验表明，GOTT 能够在多样物体、臂手平台以及已见和未见过的手部形态上建立稳健接触。相较于开环抓取执行，它还能持续提升端到端任务成功率。

## Abstract
Foundation models and large-scale human data provide rich sources of manipulation intent, but translating this intent into multi-fingered robot behavior remains difficult. Dexterous hands still lack a reusable low-level primitive that reliably establishes contact across tasks and embodiments. We propose GOTT, a reach-acquire-move framework built around a single cross-embodiment contact-acquisition primitive. Given a robot-agnostic object trajectory and a reach specification, GOTT first brings the hand near a task-relevant contact region. The shared closed-loop primitive then establishes stable contact from this approximate initialization, and a pose-conditioned controller tracks the desired object motion. Reach specifications may come from future-aware planning, external models, or human demonstrations, while the primitive and tracking backend remain unchanged. Simulation and real-world experiments show that GOTT is able to establish robust contact across diverse objects, arm-hand platforms, and seen and unseen hand morphologies. It also consistently improves end-to-end task success over open-loop grasp execution.

# GOTT：基于可复用跨具身基元的以物体为中心的灵巧操作——论文深度总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：基础模型（如 Gemini、GPT 系列）与大规模人类数据（HOT3D、OakInk、DexYCB 等）已经能提供丰富的"操作意图"。对于平行夹爪，这类意图可以通过成熟的底层基元（抓取、放置、轨迹跟随）直接落地；但灵巧多指手缺乏可类比的通用底层技能。
- **核心矛盾**：灵巧手底层技能需要建立复杂接触构型、协调高维动作并适应不同手部形态，现有路线均不理想：
  - **任务专用策略**（sim-to-real RL、in-hand 旋转等）每换一个行为就要重新训练，难以规模化；
  - **手部动作重定向**能从演示中恢复运动学目标，但通常不含感知反馈，接触丰富任务在真实世界难以执行。
- **关键问题**：把高层操作意图翻译成底层灵巧执行的"正确接口"是什么？
- **论文的答案视角**：以物体为中心的运动表示（物体轨迹）能抽象掉具身差异，但**物体轨迹只说明物体该怎么动，没有说明手该在哪里、如何建立接触**。这一区别对功能性操作至关重要——几何上稳定的抓取可能完全不适配倒水、擦拭或工具使用。
- **论文主张**：把"接触获取"本身显式建模为一个**可复用的跨具身技能**，与高层意图来源、下游轨迹跟踪解耦，从而支持不同手、不同臂、不同任务与不同高层输入源。

## 2. 方法论

### 2.1 核心思想：Reach–Acquire–Move 三阶段分解

- 高层接口由两部分组成：**期望物体轨迹** $\tau_o=\{T_{O,t}\}_{t=0}^{T}$ 与**抵达规格** $\rho=(\xi_{app}, g_{init})$。
- **Reach（抵达）**：机器人沿接近轨迹 $\xi_{app}$ 运动到近似初始手部构型 $g_{init}$。
- **Acquire（获取）**：学习到的**闭环接触获取基元**从这一近似初始化出发建立稳定接触（允许初始构型不精确、非最终抓取）。
- **Move（移动）**：**位姿条件控制器**跟踪期望物体轨迹 $\tau_o$。
- 意义：把"功能性接触选择、无碰撞接近、长时域可达性"的高层推理与"局部接触丰富控制"分离；高层只需给出可行接近与近似初始构型，而不必输出可直接执行的精确抓取。

### 2.2 通用接触获取基元（RL 训练）

- **训练环境**：16 个 YCB 物体，每个物体若干稳定静置位姿；每个（物体, 静置位姿）对用 BODex 生成 4,000 个初始手部构型。每回合从这些初始构型之一开始，策略需建立稳定接触并抬起物体。
- **观测**：三部分——(1) 每个手部连杆到物体点云（512 采样点）最近点的位移（link-distance 表示）；(2) 手部连杆位置；(3) 关节位置与上一步关节目标。其中 (2)(3) 堆叠最近 5 帧历史。策略**不显式接收物体位姿**。
- **动作**：6 维手腕增量 + 手部关节增量向量 $a_t=\pi_\theta(o_t)$。
- **奖励**：$r = w_d r_{dist} + w_c r_{contact} + w_l r_{lift} + w_o r_{obj}$，权重 $w_d=16$、$w_c=4$、$w_l=1$、$w_o=10$（从 2.0 在 $T_{cur}=10^5$ 步内退火到 10.0）：
  - $r_{dist}$：各连杆到表面距离（截断 0.1 m）的负加权和，拇指尖权重 8、其他指尖 4、手掌 0；
  - $r_{contact}$：拇指接触指示 + 对向抓取（拇指与至少一根非拇指手指同时接触，接触力阈值 0.05 N）；
  - $r_{lift}$：以"已抓取"为门控的抬升高度奖励（截断于 5 cm，防止"抛掷"刷分）；
  - $r_{obj}$：平面位移与旋转的指数"保持不动"奖励，抑制接触获取阶段的滑动/转动。
- **域随机化**：物体尺度 [0.96, 1.04]、质量 [0.5, 3.0]、摩擦 [0.5, 1.5]、恢复系数、机器人连杆摩擦/恢复系数、执行器刚度与阻尼，以及抓取后随机推力/力矩扰动。
- **接触预测器**：策略收敛后单独训练一个 2 层 MLP（隐层 256，ELU），输入最近 $k=5$ 步的关节位置、关节目标、连杆位置，输出 5 指接触概率 $\hat c_t$；BCE 损失，Adam，lr $3\times10^{-4}$，200 epoch。当拇指与至少一根其他手指的预测接触概率超过阈值 $\tau_c$ 并持续 $k$ 步时，从 acquire 切换到 move。

### 2.3 跨具身统一表示

- **规范关节空间**：固定 26 槽布局（拇指 6 槽 + 其余四指各 5 槽），手腕单独用共享 6-DoF 浮动基座控制；各手只填自身关节槽，其余置零并加**二值关节掩码**。
- **规范连杆空间**：21 关键点拓扑（1 掌 + 4×5 指，按 MANO 拓扑），缺失关键点用最近连杆填充，并附**二值连杆掩码**。
- **动作重映射**：$a^{native}_r = a^{hand}[\pi_r] \odot s_r$，其中 $\pi_r$ 为索引映射、$s_r\in\{-1,+1\}$ 处理关节轴符号差异。
- 优点：单一策略可跨不同关节数与运动学结构的手，**无需手专用的编码器/解码器网络**。

### 2.4 抵达规格的来源

- **默认（仅物体轨迹）——未来感知规划**：
  1. **VLM 可供性推理**：从 4 个视角渲染物体，提示 VLM 标注功能部件并选出"抓握部件"（区分 HOLDING REGION 与 WORKING END），预测跨越该部件的关键点；2D 点反投影到网格并跨视角投票聚合，取 3 cm 表面邻域并集作为任务相关接触区域 $\mathcal{R}\subset\partial\mathcal{M}$。
  2. **区域条件候选生成**：用 BODex 的轻量初始化阶段在 $\mathcal{R}$ 内采样 $N=10$ 个候选初始构型（含桌面碰撞剔除）。
  3. **轨迹感知选择**：对每个候选先用 cuRobo 规划无碰撞接近轨迹，再假设手–物刚性连接、沿 $\tau_o$ 展开手部运动并逐时刻解 IK；剔除接近不可行、违反关节限位或 IK 不收敛的候选；在剩余候选中选**累积臂关节运动最小**者：$g^\star=\arg\min \sum_t \|q^{arm}_{i,t}-q^{arm}_{i,t-1}\|_2$。
- **替代来源**：外部模型/人类演示可提供接触区域或初始构型（跳过对应规划步骤）；也可用 DexYCB/OakInk 等人类手–物数据重定向得到接近轨迹与末端构型。更丰富的引导会替换更多规划步骤，但可能不考虑机器人可达性/碰撞，故仍保留未来感知规划作为默认。

### 2.5 执行后端

- 感知：SAM2 分割目标物体，FoundationPose 估计并跟踪 6D 位姿（45 Hz）；策略 10 Hz 并取最新位姿。
- Reach → 当手部连杆与物体表面最小距离低于 $\epsilon_{approach}$ 时切入接触获取。
- Acquire → 手腕与手指局部调整以补偿物体位姿误差、几何不匹配与接触不确定性，接触预测器判定后进入 move。
- Move → 先短距离抬升，随后近似认为手–物变换固定，由期望物体位姿计算末端目标，再用观测到的物体位姿误差修正后下发给底层位置控制器。

### 3.1 仿真抓取评测（续）

### 3.2 跨具身泛化评测

- **设置**：把在某一手（如 XHand）上训练的接触获取基元，直接部署到另一手（如 Sharpa Wave、Allegro）上，仅依赖 2.3 节的规范关节/连杆表示与动作重映射完成迁移，不做手专用微调。

- **目的**：验证论文的核心主张——接触获取是一种与手部形态弱耦合的通用技能，而非某只手的私有策略。

### 3.3 真实世界实验

- **平台**：单臂 + 多指灵巧手（Franka/同类机械臂搭配 XHand 与 Sharpa Wave），配 RGB-D 相机；感知用 SAM2 + FoundationPose，策略 10 Hz。
- **任务选择**：刻意挑选"几何稳定抓取不足以保证功能成功"的接触丰富任务，例如
  - 倒水（需以特定方式握持壶身/壶柄，使开口朝向可控）；
  - 擦拭（需掌心/指腹贴合并维持接触力）；
  - 工具使用（需抓握工作端之外的把持区域）；
  - 与纯拾放（pick-and-place）任务形成对照。
- **输入源对比**：分别以"仅物体轨迹 + 未来感知规划"（默认）、"VLM 提供接触区域"、"人类演示重定向提供初始构型"作为抵达规格来源，考察接口对不同高层输入源的兼容性。
- **指标**：任务成功率、到达/接触获取/移动各阶段耗时、接触建立失败模式分类（滑移、误接触、碰撞、IK 不收敛等）。

### 3.4 消融与机制分析

- **抵达规格消融**：去掉 VLM 可供性推理 → 直接在物体上随机采样候选；去掉轨迹感知选择（仅按几何稳定性排序）；检验"未来感知"对下游可执行性的贡献。
- **接触获取基元消融**：用开环重定向目标替代闭环 RL 策略；检验感知反馈与闭环修正的必要性。
- **规范表示消融**：去掉关节/连杆掩码，或改用每手专用编解码器，比较跨具身迁移性能。
- **奖励项消融**：逐一去掉 $r_{contact}$、$r_{lift}$、$r_{obj}$，观察是否出现"滑动式伪成功""抛掷刷分""接触获取阶段物体被推走"等退化行为。
- **接触预测器消融**：用固定时间步切换或地面真值接触替代学习到的预测器，评估切换时机对成功率与鲁棒性的影响。

## 4. 主要结论与贡献

1. **接口层面的贡献**：明确提出把"接触获取"作为独立、可复用、跨具身的技能基元，并将高层意图接口定义为"物体轨迹 + 抵达规格"，从而把功能性接触选择、无碰撞接近与长时域可达性交给规划/VLM，把局部接触丰富控制交给学习策略。
2. **表示层面的贡献**：26 槽规范关节空间 + 21 关键点规范连杆空间 + 掩码机制，使单一策略无需手专用网络即可跨不同自由度与运动学结构的手部署。
3. **系统层面的贡献**：给出完整的 Reach–Acquire–Move 执行栈（VLM 可供性 → 区域条件候选生成 → 轨迹感知选择 → 闭环接触获取 → 位姿条件跟踪），并在仿真大规模基准与真机接触丰富任务上验证。
4. **实证结论**：在数万级物体–尺度–位姿实例的抓取基准上，方法在多种手上优于开环抓取合成（BODex）、跨具身抓取预测（DRO）与 RL 跨具身基线（CrossDex）；跨具身直接迁移仅带来有限性能下降；真机上能够完成几何稳定抓取无法保证成功的功能性任务。

## 5. 局限与可讨论之处

- **对物体位姿估计的依赖**：Move 阶段依赖 FoundationPose 的在线位姿；遮挡、透明/反光物体或快速运动下的位姿抖动会直接影响跟踪与切换判定。
- **接触获取的可达性边界**：策略在 BODex 生成的初始构型分布内训练，若抵达规格给出的 $g_{init}$ 显著偏离该分布（或物体/桌面构型超出训练分布），获取成功率可能下降。
- **单物体、单臂假设**：当前设定聚焦单物体、单臂、静态桌面；双臂协同、可变形物体、被遮挡目标与动态环境未覆盖。
- **规划与学习的耦合成本**：默认抵达规格需要渲染 + VLM 推理 + 候选采样 + cuRobo 规划 + 逐时刻 IK 展开，单次任务的前置计算量较大；更丰富的外部引导可跳过部分步骤，但会牺牲可达性/碰撞保证。
- **规范表示的语义损失**：固定槽位与最近连杆填充在手指数量差异大或拓扑差异显著的手上可能引入表示噪声，掩码只能标记"缺失"，无法表达"结构不同但语义对应"的关节。
- **接触预测器的泛化**：预测器在特定手与训练分布上拟合接触概率，跨手迁移时阈值 $\tau_c$ 是否需要重新校准，论文未充分展开。

## 6. 总体评价

- **定位**：这不是一篇"提出更强抓取策略"的论文，而是一篇**接口与表示设计**的论文——它回答的是"高层操作意图与底层灵巧执行之间应当传递什么"。
- **最值得借鉴的思想**：把"物体该怎么动"（物体轨迹）与"手该在哪里、如何建立接触"（抵达规格 + 接触获取基元）显式分离，并让后者成为一个与手、臂、任务、高层输入源都解耦的可复用模块。这与平行夹爪生态中"意图 + 通用底层基元"的成熟范式形成类比，为灵巧操作提供了一条可规模化的工程路径。
- **证据强度**：仿真侧有大规模、多手、多基线的定量支撑，机制消融较完整；真机侧以任务成功率为主要证据，覆盖了功能性操作这一关键痛点，但样本量与统计严谨性可能弱于仿真部分。
- **潜在影响**：若该接口被后续工作采纳，灵巧操作的研究重心可能从"每任务/每手训练专用策略"转向"构建与复用通用接触获取基元"，并推动 VLM/规划器与灵巧底层技能之间的标准化对接。

## 摘要
世界模型旨在学习真实世界环境的表示并预测其未来演化。近期的以对象为中心的世界模型通过将视觉场景表示为对象级潜在状态的集合，在表达能力上取得了进展，但对象-对象关系往往仅被隐式捕捉，这限制了显式的关系与时间结构建模以及以对象为中心的动态记忆建模。为应对这些挑战，我们提出 World-As-Graph (WAG)，一种基于图的以对象为中心的世界模型，将关系归纳偏置引入 JEPA 风格的预测表征学习。所提出的 WAG 包含两个主要模块：(1) 关系感知的结构归纳，它从以对象为中心的槽位构建时变潜在图，并设计关系感知的对象掩码策略，以指导潜在空间中的关系对象表征学习；(2) 以对象为中心的记忆转移，它通过将来自邻近对象的关系信息与历史记忆相结合，维护并更新对象级动态状态，从而实现有效的自回归未来预测。在视觉推理和机器人操作任务上的大量实验可以证明我们提出的 WAG 具有优越性能。

## Abstract
World models aim to learn representations of real-world environments and predict their future evolution. Recent object-centric world models have made expressive progress by representing visual scenes as sets of object-level latent states, but object-object relations are often captured only implicitly, which limits explicit relational and temporal structure modeling and object-centric dynamic memory modeling. To address such challenges, we propose World-As-Graph (WAG), a graph-based object-centric world model that introduces relational inductive bias into JEPA-style predictive representation learning. The proposed WAG contains two main modules: (1) Relation-aware structure induction, which constructs time-varying latent graphs from object-centric slots and designs relation-aware object masking policies to guide relational object representation learning in latent space; (2) Object-centric memory transition, which maintains and updates object-level dynamic states by combining relational information from neighboring objects with historical memory, enabling effective autoregressive future prediction. Extensive experiments on both visual reasoning and robotic manipulation tasks could demonstrate the superior performance of our proposed WAG.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：世界模型旨在学习真实环境的表征并预测其未来演化。JEPA（Joint-Embedding Predictive Architecture）范式在潜在空间中直接预测未来表征，而非重建像素；以对象为中心的世界模型则将视觉场景表示为一组对象级潜在状态（slots），便于分别建模不同对象并学习对象级预测表征。
- **核心痛点**：现有对象中心世界模型（如 Causal-JEPA）虽然通过注意力、稀疏注意力、对象级掩码等机制鼓励交互学习，但对象—对象关系仍被**隐式**捕捉，缺乏显式的关系归纳偏置（Relational Inductive Bias, RIB），由此带来两大挑战：
  - **C1：关系与时间结构建模受限**。模型不区分对象的关系角色，也不显式建模关系如何随时间演化；JEPA 式掩码潜在预测提供的自监督信号有限，模型可能主要依赖对象自身动力学预测未来。
  - **C2：对象级动态记忆建模受限**。未来预测要求每个对象既携带自身的交互历史，又融合来自其他对象的关系信息；缺乏显式的对象级状态记忆会丢失"对象如何运动、交互、影响未来状态"的历史线索，导致长时程预测次优。
- **整体含义**：论文提出 **World-As-Graph (WAG)**，首次将**潜在空间动态图**作为关系归纳偏置引入对象中心 JEPA 式世界模型，用图结构显式刻画对象交互及其时序演化，并配合对象级记忆转移实现自回归未来预测。

## 2. 方法论

### 2.1 核心思想与问题定义

- **定义 1（WAG 模型）**：给定历史对象中心潜在状态 $\{S_t\}_{t\in T_{hist}}$，WAG 模型定义为 $M_{WAG}=\langle R, F_{\theta,\omega}\rangle$：
  - **关系感知结构归纳** $R=\langle \Gamma_\psi, \pi_{mask}\rangle$：由潜在动态图构造器 $\Gamma_\psi$ 构建动态关系图，再由关系感知掩码策略 $\pi_{mask}$ 依据图结构识别"关系信息量高"的节点。
  - **对象中心记忆转移** $F_{\theta,\omega}=\langle f^{enc}_\theta, f^{pred}_\omega\rangle$：由时序 GNN 转移编码器维护/更新对象级记忆状态，再由记忆驱动未来预测器演化记忆并预测未来潜在状态 $\{\hat{S}_t\}_{t\in T_{pred}}$。
- **符号**：预训练对象中心编码器 $f_{\Phi^*}$ 从每帧提取 $N$ 个 slot：$S_t=[s^1_t,\dots,s^N_t]^\top\in\mathbb{R}^{N\times D_0}$；转化为离散时间动态图序列 $G=\{G_t\}$，$G_t=(V_t,E_t,S_t)$，节点 $v^i_t$ 对应第 $i$ 个 slot。
- **时间划分**：$T=T_{hist}\cup T_{pred}$，$T_{hist}=\{t-T_h+1,\dots,t\}$，$T_{pred}=\{t+1,\dots,t+T_p\}$。

### 2.2 模块一：关系感知结构归纳（对应 C1）

- **(1-a) 潜在动态图构造**：参数无关的图构造器 $\Gamma$，以余弦相似度 + KNN 建边：
  $$G_t=\Gamma^{sim}_K(S_t),\quad E_t=\{(i,j)\mid j\in \arg\mathrm{Top\text{-}K}_{k\neq i}\, sim(s^i_t,s^k_t)\}$$
  边权 $w^t_{ij}=\cos(s^i_t,s^j_t)$，得到时变潜在图序列。
- **(1-b) 关系感知对象掩码**：选出 $M<N$ 个节点掩码，用可学习 mask token 替换其历史特征，**仅保留首帧图 $G_{t_0}$ 完整可见**用于初始化对象状态，形成部分观测图序列 $G^\dagger$。两种策略：
  - **(I) 关系中心性掩码**：KNN 图出度固定为 $K$，故用入度衡量中心性：
    $$c_i=\sum_{t\in T_{hist}}\sum_{j\neq i}\mathbb{I}[i\in N^t_j],\quad I^{cen}_{mask}=\arg\mathrm{Top\text{-}M}_i\, c_i$$
  - **(II) 时序动态掩码**：以邻域集合的累积变化衡量"受交互影响"程度：
    $$d_i=\sum_{t\in T_{hist}}\bigl(K-|N^t_i\cap N^{t-1}_i|\bigr),\quad I^{dyn}_{mask}=\arg\mathrm{Top\text{-}M}_i\, d_i$$
  - 目标：迫使模型从**其他对象的关系信息 + 自身历史**中恢复被掩码对象状态，而非依赖对象自动力学。

### 2.3 模块二：对象中心记忆转移（对应 C2）

- **(2-a) 时序 GNN 转移编码器**：每个节点维护独立记忆 $h^i_t\in\mathbb{R}^{D_1}$，$H_t=[h^1_t,\dots,h^N_t]^\top$；首帧记忆初始化为 $H_{t_0}=S_{t_0}$，其余时刻：
  $$H_t=f^{enc}_\theta(G^\dagger_t,H_{t-1})=\mathrm{MemGRU}_{\theta_m}\bigl(\mathrm{TGNN}_{\theta_g}(G^\dagger_t),\,H_{t-1}\bigr)$$
  并加辅助掩码预测头：$\hat{S}^{mask}_t=g^{mask}_\epsilon(H_t,I_{mask})$。
- **(2-b) 记忆驱动未来预测器**：自回归演化——先对上一时刻记忆状态重建动态图，再用预测器更新记忆，最后投影出未来对象状态：
  $$\hat{G}_{t-1}=\Gamma^{sim}_K(H_{t-1}),\quad H_t=f^{pred}_\omega(\hat{G}_{t-1},H_{t-1}),\quad \hat{S}^{futu}_t=g^{proj}_\eta(H_t)$$
- **训练目标**：$\mathcal{L}=\lambda_{mask}\mathcal{L}_{mask}+\lambda_{futu}\mathcal{L}_{futu}$，两项均为潜在空间 MSE（分别对应掩码状态恢复与未来状态预测）。
- **推理阶段**：不使用掩码与掩码头，基于完整历史学习记忆状态，再从最后历史记忆开始自回归 rollout 至预测视界。
- **理论分析（附录 A.2）**：以 KNN 选择边界的余弦相似度间隔定义邻域间隔 $\gamma_t$；若 $e_t<\frac{r\gamma_t}{8}$（$r$ 为节点范数下界），则预测图与参考图邻域集合一致；在记忆更新 $L$-Lipschitz 假设下，误差累积满足 $e_{T+h}\le L^h e_T+\delta\sum_{j=0}^{h-1}L^j$，当 $L<1$ 时界在预测视界内一致。作者强调这是**充分条件而非循环记忆本身提供的保证**。

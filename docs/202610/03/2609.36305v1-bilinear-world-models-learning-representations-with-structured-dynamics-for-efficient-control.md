## 摘要
世界模型联合学习潜在表示和动力学，以预测高维观测在动作下如何演化。在这项工作中，我们提出了一种 JEPA 风格的世界模型；其中，我们不是学习任意的潜在动力学，而是将其限制为遵循双线性参数化。这种结构能够实现高效的规划与控制，同时将建模负担转移到编码器上，促使学习到更丰富的表示，从而揭示系统的可控几何结构。特别地，这种结构化参数化使我们能够在结构上强制动作可恢复性，从而通过构造防止表示崩塌。尽管规定双线性参数化可能看似受限，但我们表明，一大类非线性动力系统都允许一种变换，在该变换下动力学变为双线性。在实证方面，我们在标准 2D 和 3D 控制任务上表明，具有双线性参数化动力学的表示可以直接从高维观测中学习，将规划时间减少近三个数量级，同时保持甚至提高控制精度。我们还提出了要求更高的长时程规划和实时控制设定，并证明我们的方法在这两种设定下均能成功，从而将 JEPA 风格世界模型推进到超越短时程离线规划的范畴。

## Abstract
World models jointly learn latent representations and dynamics that predict how high-dimensional observations evolve under actions. In this work, we propose a JEPA-style world model in which, rather than learning arbitrary latent dynamics, we restrict them to follow a bilinear parameterization. This structure enables efficient planning and control while shifting the modeling burden onto the encoder, encouraging richer representations that expose the controllable geometry of the system. In particular, this structured parameterization allows us to structurally enforce action recoverability, thereby preventing representation collapse by construction. Although prescribing a bilinear parametrization may appear restrictive, we show that a broad class of nonlinear dynamical systems admits a transformation under which the dynamics become bilinear. Empirically, we show across standard 2D and 3D control tasks that representations with bilinear-parameterized dynamics can be learned directly from high-dimensional observations, reducing planning time by nearly three orders of magnitude while retaining or even improving control accuracy. We also propose more demanding regimes of longer-horizon planning and real-time control, and demonstrate that our method succeeds in both, moving JEPA-style world models beyond short-horizon offline planning.

# 论文总结：Bilinear World Models（双线性世界模型）

## 1. 核心问题与研究动机

- **背景**：世界模型（World Models）旨在联合学习高维观测的潜在表示与潜在动力学，使得规划可在低维潜空间中进行，而无需在原始像素空间操作。现有主流方法（PlaNet、Dreamer 等基于重构，以及 JEPA 系列基于联合嵌入）通常用**无约束神经网络**来参数化潜在动力学预测器。
- **核心问题**：
  - 作者认为这种"任意灵活性"对规划与控制往往**不必要且有害**——无结构动力学难以高效优化，且需要采样式规划器（如 CEM），计算代价高昂。
  - JEPA 类世界模型面临**表示崩塌（representation collapse）**：编码器与动力学预测器可能同时塌缩为常数表示。此前 SMWM 通过引入辅助逆模型来缓解，但仍依赖无约束的逆网络。
- **整体含义**：作者主张将建模负担从"动力学预测器"转移到"编码器"，通过给潜在动力学施加**结构化（双线性）约束**，使模型天然具备动作可恢复性、支持梯度式规划，并保持足够的表达能力。

## 2. 方法论

### 2.1 核心思想
- 不学习任意潜在动力学，而是限制其为**双线性参数化**：
  - \(z_{t+1} = A z_t + f_M(z_t) a_t\)，其中 \(f_M(z_t) := B + C z_t\)
  - 即动力学对状态线性、对动作线性，但包含状态-动作乘性交互项。
- 结构约束把表达力负担推给编码器 \(\phi_\theta\)，迫使其学出"暴露系统可控几何"的表示。

### 2.2 动作可恢复性与防崩塌
- 若 \(f_M(z_t)^\top f_M(z_t)\) 正定，则动作可由潜在转移**闭式恢复**：
  - \(a_t = f_M(z_t)^\dagger (z_{t+1} - A z_t)\)
- 由于动作无法从塌缩表示中恢复，该性质**由构造保证**防表示崩塌（区别于 SMWM 学习无约束逆网络）。

### 2.3 归一化双线性动力学
- 为保证满秩条件与状态无关，引入 **Cholesky–QR 归一化**：
  - \(z_{t+1} = A z_t + M(z_t) a_t\)，\(M(z) = Q(z) R\)，\(Q(z) = \mathrm{CholQR}(B + C z)\)
  - 于是 \(M(z)^\top M(z) = R^\top R\)，满秩条件仅取决于状态无关矩阵 \(R\)。
- 注：归一化后动力学不再是严格双线性，但状态依赖仍由双线性参数化生成。

### 2.4 优化问题
- 理想问题 **P**：最小化潜在一步预测误差，约束 \(R^\top R \succeq \epsilon I\)。
- 实际用**正则化代理问题 P̂**：加入动作恢复项（权重 \(\lambda = 30\)）：
  - 第一项拟合归一化潜在动力学；第二项鼓励动作从潜在位移可恢复。
- Cholesky–QR 可微，整个模型可端到端梯度训练。

### 2.5 理论支撑（Koopman 视角）
- **Assumption 1**：系统对动作仿射且 Lipschitz。
- **Assumption 2**：动作方向线性独立（\(\mathrm{rank}[f_1(s)\cdots f_m(s)] = m\)）。
- **Proposition 1**：在以上假设下，存在（可能无穷维）**动作可恢复的双线性 Koopman 嵌入**，且 \(M(z)^\top M(z) \succ 0\)。
- 结论：双线性约束并不限制表达力，一大类控制仿射非线性系统都可嵌入该形式（仅表达性论证，非有限维近似保证）。

### 2.6 控制器：Gauss–Newton 规划器
- 目标：\(\mathcal{L}(a) = \tfrac12 \|z_H(a) - z^\star\|^2 + \tfrac{c}{2}\|a\|^2\)。
- 利用端点对动作序列的**雅可比** \(J(a) = \partial z_H / \partial a\)（含各步状态雅可比 \(F_t = A + \partial(M(z_t)a_t)/\partial z_t\)）。
- 迭代更新：\(a_{t+1} = a_t - [J^\top J + cI]^{-1}[J^\top(z_H - z^\star) + c a_t]\)（Gauss–Newton）。
- 工程细节：降维"一致动作子空间"（E 提升）、批量有限差分估计敏感性、阻尼 + 回溯线搜索、多起点初始化、事后训练残差模型（不改变表示）。

## 8. 不足与局限

- **理论-实践落差**：Proposition 1 是精确、连续时间、可能无穷维的表达性结论；实际学习的是有限维、离散时间、归一化的近似，二者之间存在缺口。
- **归一化破坏严格双线性**：归一化后动力学不再是严格双线性，理论上依赖的"双线性结构"在实现中被弱化。

- **实验覆盖有限**：仅 4 个任务（2D/3D 控制），未涉及更复杂的高维视觉任务、真实机器人或长时程稀疏奖励场景。

- **算力信息不完整**：未给出训练时长、数据规模、专家数据采集细节，复现成本难以准确评估。
- **公平性潜在偏差**：本文方法使用定制 Gauss–Newton + 多起点 + 残差，而基线使用原始 CEM，尽管有消融，但规划器调优程度可能不完全对等。

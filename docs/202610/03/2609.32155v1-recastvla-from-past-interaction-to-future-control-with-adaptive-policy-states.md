## 摘要
顺序操作要求机器人跟踪已经发生的事情，即使当前场景不再显露这些信息。具有显式历史表示的策略可将过往交互作为当前决策的上下文。我们探讨动作生成本身如何为后续控制形成持续状态。基于动作侧测试时训练，RecastVLA 在流匹配视觉-语言-动作策略中维持一个自适应策略状态。该状态由共享快速权重表示，并在整个动作生成过程中保持固定。深度特定接口读取同一状态，而跨深度和流评估的特征共同为下一次策略调用定义一个更新。后续动作损失通过沿更早的状态转移进行微分，来训练初始化、接口和更新规则。部署时，更新使用策略自身的动作生成特征，无需专家动作标签。在 LIBERO、RoboTwin、RoboDojo 和十二个真实机器人任务上，RecastVLA 相比未进行测试时训练的匹配策略提升了平均成功率，其中在 RoboTwin Clean-to-Clean 上提升 10.68 个百分点。在受控 RoboTwin 比较中，保留状态可提升成功率，且共享设计比独立训练的分层局部 TTT 高出 2.58 个百分点。

## Abstract
Sequential manipulation requires a robot to track what has already happened, even when the current scene no longer reveals it. Policies with explicit history representations make past interactions available as context for current decisions. We ask how action generation itself can form a persistent state for subsequent control. Building on action-side test-time training, RecastVLA maintains an adaptive policy state within a flow-matching vision-language-action policy. The state is represented by shared fast weights and remains fixed throughout action generation. Depth-specific interfaces read the same state, while features across depths and flow evaluations jointly define one update for the next policy call. Subsequent action losses train the initialization, interfaces, and update rule by differentiating through earlier state transitions. At deployment, updates use the policy's own action-generation features without expert action labels. Across LIBERO, RoboTwin, RoboDojo, and twelve real-robot tasks, RecastVLA improves mean success over a matched policy trained without test-time training, including 10.68 percentage points on RoboTwin Clean-to-Clean. In controlled RoboTwin comparisons, retaining state improves success, and the shared design exceeds independently trained layer-local TTT by 2.58 points.

# RecastVLA 论文总结

## 1. 核心问题与研究动机

- **背景**：顺序操作（sequential manipulation）要求机器人记住"已经发生了什么"，但当前观测往往无法反映这些信息。例如瞬时按钮按下前后外观几乎相同，下一步正确动作却取决于此前是否已按过；遮挡、部分完成的指令也会造成同类问题。
- **概念界定**：作者将"保留继续当前任务所需信息"的能力称为 **execution memory（执行记忆）**。
- **已有路线**：MemoryVLA、MEM、Zeva 等历史条件策略通过检索观测、压缩上下文或循环表征，解决"过去交互中哪些信息可供控制使用"的问题。
- **本文追问**：**动作生成过程本身如何把历史经验转化为一个持久的策略状态，以引导后续决策？** 动作生成正是策略把感知与语言转成控制决策的环节，其内部特征天然与"正在形成的决策"绑定。
- **切入角度**：基于动作侧测试时训练（action-side TTT，如 RoboTTT），研究是否应将多个网络深度上专门化的读写计算，改为**共同形成并访问一个共享状态**。

## 2. 方法论

### 2.1 核心思想

- 在流匹配（flow-matching）VLA 策略中维护一个**自适应策略状态（adaptive policy state）**，用**跨深度共享的快速权重（shared fast weights）**表示。
- 该状态在一次策略调用内**保持固定**（所有动作计算都读同一份 W_t），调用结束后由本次生成过程的多处特征**联合定义一次更新**，供下一次调用使用。
- 新 episode 从学习到的初始化 W_0 开始；部署时只更新 W_t，慢参数 θ（VLM 主干 + 动作专家）与 ψ（记忆接口与更新规则）保持不变。

### 2.2 关键技术细节

- **状态载体**：状态 W_t 是两层 MLP（256→512→256，GELU，含偏置）的权重与偏置。
- **共享 + 专化访问**：动作专家为 DiT-B（16 个交替 cross/self-attention 块，宽度 768），设 **J = 8 个访问点**，每个访问点在 cross-attention 后读取状态、在其后的 self-attention 后收集写特征；每点使用 **N = 32 个宽度 D = 768 的 latent slot**。
- **读取接口（式 2）**：对 slot 特征加一个门控残差
  `h̃ = h + tanh(γ_j) · P_Oj · f_{W_t}(P_Qj · LN(h))`，
  其中 P_Qj 投影进记忆空间、P_Oj 投回，γ_j 为可学习标量门。**各深度在同一历史相关函数的"自己的特征坐标系"中查询**，因此某深度写入的信息可在后续调用中影响其他深度的读取。动作 token 本身绕过状态读取，只在下一 self-attention 块与适配后的 slot 交互。
- **写入构造（式 3）**：每个访问点用 post-self-attention slot 生成学习到的 key/value，并使用 **stop-gradient（sg）** 把源特征视为"适配用的数据"。
- **联合写损失（式 4）**：对 C 次流评估、J 个深度做加权平方误差，权重含**流时间门 g_ψ(τ) ∈ (0,1)**（两层 MLP，隐层 16，SiLU + sigmoid）与**访问点权重 α_j**（对 β_j 做 softmax）。流时间权重**不做跨评估归一化**，因此同时控制相对贡献与整体更新幅度。
- **单步更新（式 5）**：`W_{t+1} = W_t − η ∇_W L_write(W)|_{W=W_t}`，步长 `η = η0·exp(ρ)`，η0 = 0.1，ρ 为可学习标量。更新发生在**策略调用边界**，因为深度与流评估都是同一次动作生成的内部计算。

### 2.3 训练与部署流程

- **序列动作监督（式 6–7）**：从同一演示 episode 采样长度 **T = 4** 的有序观测窗口，每帧独立采样 **R 个噪声/流时间**（τ 由 Beta(1.5,1) 采样构造），构造流匹配输入与速度目标，最小化速度预测误差。
- **贯穿状态转移的反传**：第 t+1 帧的动作损失会经式 (5) 反传到第 t 帧的写投影与更新参数；跨状态的梯度同时训练 **W_0**、接口与更新规则。stop-gradient 保留对 key/value 投影与快权重更新的梯度，但阻断经写分支进入源特征。窗口末帧不做状态更新（后续无损失依赖）。
- **部署**：每次调用从高斯噪声出发、用 **K = 4 次 Euler 评估**积分速度场，全部以 W_t 为条件；这些评估的特征以 C = K 联合定义一次更新。**部署时只需对快权重求梯度，无需跨调用保留计算图，也不需要专家动作标签**。训练用相邻录制帧，部署则按执行的动作块推进。

## 6. 主要结论与发现

- **总体提升**：RecastVLA 在全部 6 个仿真设置上超过 Matched Base——LIBERO Avg 98.80 vs 96.5（+2.30），Long 96.40 vs 92.0（+4.40）；RoboTwin C→C 72.38 vs 61.7（**+10.68**），C→R 19.24 vs 10.5；RoboDojo Long-Horizon 16.75 vs 6.50，Memory 8.67 vs 3.33（约 +5.3）。
- **状态连续性有效**：Full 比 Reset 高 4.68 个百分点（72.38 vs 67.7），成功样本的预算占比接近（约 30%），说明差异主要来自失败更少。
- **先验经验"来源比有无更重要"**：Similar 任务历史使 SR 再升 2.22 点（74.6），而 Other 任务历史下降 11.98 点（60.4），甚至低于 Reset 7.3 点；后续目标任务的持续更新**未能完全抵消不利初始化**。
- **共享优于局部**：在相同 per-state MLP 架构下，共享设计比独立训练的分层局部 TTT 高 **2.58 个百分点**（72.38 vs 69.8），且持久状态参数更少。
- **真机**：240 次试验中 RecastVLA 成功 131 次（54.58%），π0.5 为 102 次（42.50%），Matched Base 为 74 次（30.83%）。增益**集中在按钮序列与重复按压（T1–T3）**：66.67% vs π0.5 的 23.33%，这三项贡献了全部净增成功中的 26/29；其余九项平均仅 50.56% vs 48.89%，T7、T11、T12 仍落后于 π0.5。
- **机制解释**：按钮任务的"进度弱可观测"（同一按钮始终可用，下一步取决于此前按序与次数）与自适应策略状态"在连续决策间传递信息"的作用一致。
- **残余失败模式**：多余按压、混色堆叠、杯沿未对准、堆叠不稳；T7 中顺序正确但牙刷横在杯沿，说明"保持任务顺序"与"精确几何放置"是两种不同能力。

## 7. 优点

- **问题表述新颖**：把"执行记忆"从"历史如何进入上下文"转向"动作生成特征如何构成持久策略状态"，视角与 MemoryVLA/MEM 等检索/压缩路线互补。
- **架构设计清晰且自洽**：一次调用内状态冻结、跨调用单次联合更新，明确划分"调用内计算"与"跨调用适配"；共享状态 + 深度专化接口使一处写入可在后续调用影响其他深度的读取。
- **训练信号

## 摘要
生成式策略已成为机器人学习中一种有前景的范式，它将富有表现力的生成式动作建模与基于大规模示教数据的可扩展模仿学习相结合。然而，异构示教数据可能诱导出次优动作块，其误差会随时间累积，最终将机器人推向难以恢复的分布外状态。动作验证通过采样多个候选动作并使用验证器选择一个执行，提供了一种缓解该失效模式的测试时扩展策略。然而，现有方法在时间上仍是短视的且训练成本高昂：它们仅基于当前观测评估候选动作，而未考虑轨迹连续性，并且往往依赖大型验证器和额外的专家示教。在本文中，我们提出时序验证（Temporal Verification, TeV），一种面向流匹配 VLA 的高效且具有时间感知能力的动作验证框架。TeV 首先学习一个时序 token，用于总结近期的观测—动作历史，使候选动作块能够作为执行轨迹的延续而非孤立预测来评估。以该 token 为条件，TeV 无需额外的专家示教或偏好标注即可构建正负样本对，并以对比方式训练基于能量的验证器，从而为质量更高、与轨迹一致的动作块赋予更低的能量。除了事后排序，TeV 还利用学习到的能量景观引导中间流样本向低能量区域移动，在最终选择前改进候选动作。在仿真和真实世界环境中的大量实验表明，TeV 能够可靠地对动作候选进行排序，提高任务成功率，并产生更平滑的执行轨迹。

## Abstract
Generative policies have emerged as a promising paradigm for robot learning, combining expressive generative action modeling with scalable imitation learning from large demonstration corpora. However, heterogeneous demonstrations can induce suboptimal action chunks whose errors compound over time, eventually driving the robot into out-of-distribution states from which recovery is difficult. Action verification offers a test-time scaling strategy for mitigating this failure mode by sampling multiple candidate actions and using a verifier to select one for execution. Existing approaches, however, remain temporally myopic and costly to train, evaluating candidates from the current observation alone without accounting for trajectory continuity and often relying on large verifiers and additional expert demonstrations. In this paper, we introduce Temporal Verification (TeV), an efficient temporally aware action verification framework for flow-matching VLAs. TeV first learns a temporal token that summarizes recent observation--action history, enabling candidate chunks to be evaluated as continuations of the execution trajectory rather than as isolated predictions. Conditioned on this token, TeV constructs positive--negative pairs without additional expert demonstrations or preference annotations and trains an energy-based verifier contrastively to assign lower energy to higher-quality, trajectory-consistent action chunks. Beyond post-hoc ranking, TeV further uses the learned energy landscape to guide intermediate flow samples toward lower-energy regions, improving candidates before final selection. Extensive experiments in simulation and real-world settings demonstrate that TeV provides reliably ranks action candidates, improves task success rates, and produces smoother execution trajectories.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想

- TeV 将动作验证从“基于当前观测的孤立预测评估”转变为“基于近期观测—动作历史的轨迹延续评估”。
- 它学习一个紧凑的**时序 token**，总结近期执行历史；以该 token 为条件，训练一个轻量**基于能量的对比验证器**；验证器同时用于：
  - **事后排序**：在完整生成的动作块中选择能量最低者执行；
  - **生成时引导**：通过能量梯度修改流匹配的中间采样过程，使候选向低能量区域移动。

### 2.2 时序 token 学习

- 给定长度 \(W\) 的历史窗口，对每个观测 \(o_i\) 提取预训练 VLM 的 token 表示，投影到 \(d_h\) 维潜空间，并附加可学习 readout token；用轻量双向 Transformer 得到观测摘要 \(h_i\)。
- 将每个 \(h_i\) 与紧邻的前一执行动作 \(a_{i-1}\) 拼接，输入因果时序 Transformer \(T_\psi\)，输出序列的最后一个表示即为**时序 token** \(\tau_t\)：
  \[
  (\tau_{t-W+1},\dots,\tau_t)=T_\psi([h_{t-W+1};a_{t-W}],\dots,[h_t;a_{t-1}])
  \]
- 用辅助未来动作预测目标正则化 \(\tau_t\)：
  \[
  L_\tau=\|g(\tau_t)-[a_t,\dots,a_{t+F-1}]\|^2
  \]
  使其保留对后续运动有预测性的动态信息。

### 2.3 对比验证器训练

- 验证器为轻量能量模型 \(E_\theta\)，以 \(\tau_t\) 为条件，对候选动作块表示 \(z\) 打分，**能量越低表示质量越高、越符合轨迹延续**。
- 正样本：离线示教数据中的专家动作块 \(z_t^+\)，无需额外标注。
- 负样本两类：
  1. **时间错配负样本**：从同一 episode 中时间距离 \(|j-t|\ge\delta\) 的其他时刻采样专家块。它们在孤立看是合理的，但与当前执行历史不一致。
  2. **粗积分负样本**：用较少 Euler 步 \(n<N\) 由策略生成的块，模拟策略自身产生的质量退化。\(n\) 越小越容易，\(n\) 越大越接近完整步输出，难度越高。
- 采用 margin-based 对比损失：
  \[
  L_c=\sum_{r\in\{mis,crs\}}\frac{1}{K_r}\sum_{k=1}^{K_r}\left[m_r+E_\theta(z_t^+|\tau_t)-E_\theta(z_{t,r,k}^-|\tau_t)\right]_+
  \]
  使正样本能量比各类负样本低至少相应 margin。
- 总损失：
  \[
  L=L_c+\lambda_\tau L_\tau
  \]
  基础策略冻结，仅训练时序编码器与验证器。

### 2.4 验证作为生成引导

- 在流匹配的 Euler 更新中，除速度场外加入能量梯度项：
  \[
  x_{s+1/N}^{(m)}=x_s^{(m)}+\frac{1}{N}v_\pi(x_s^{(m)},s|K_t)-\frac{\eta_s}{N}\nabla_{x_s^{(m)}}E_\theta(z_s^{(m)}|\tau_t)
  \]
- 引导强度 \(\eta_s\) 从初始 \(\eta\) 线性衰减到 0：早期强引导塑造粗粒度动作结构，后期恢复基础策略的精细修正。
- 完成积分后，按能量最低原则选择候选：
  \[
  m^*=\arg\min_m E_\theta(z_1^{(m)}|\tau_t)
  \]

### 2.5 推理算法流程

1. 用近期观测—动作历史计算时序 token \(\tau_t\)；
2. 从当前观测计算 VLA 上下文缓存 \(K_t\)，并在所有候选间共享；
3. 采样 \(M\) 个初始噪声候选；
4. 每个候选进行带能量梯度引导的流匹配积分；
5. 对完成后的候选按验证器能量排序，选择最低能量动作块执行。

## 摘要
机器人脑模型整合视觉、语言和机器人状态，为复杂操作任务生成动作。大多数模型预测固定长度的动作块，这些动作块可能跨越多个任务阶段。这可能模糊阶段转换，并偏向频繁出现的动作模式，从而损害动态环境中的动作时序。我们提出 PhasePlan，一种面向机器人脑模型的有序未来阶段规划方法。根据当前多模态观测，它预测每个未来动作位置处的任务阶段。由此得到的规划表示对相应动作进行条件化，保持任务进展与动作生成之间的时间对齐。训练时首先学习规划器，然后在动作模型适配期间冻结它，以维持稳定的阶段表示。我们在预训练的 $π_{0.5}$ 和 AcrossWAM1.0 机器人脑模型上实例化 PhasePlan。详细的定量评估使用 $π_{0.5}$ 实现。在传送带操作任务上，PhasePlan 相对于原始 $π_{0.5}$ 模型将离线联合动作误差降低约 22.5%。它还改进了阶段转换建模和跨阶段动作预测。这些结果证明了有序未来阶段规划对于连续动作生成的价值。

## Abstract
Robot brain models integrate vision, language, and robot state to generate actions for complex manipulation tasks. Most predict fixed-length action chunks that may span multiple task phases. This can obscure phase transitions and favor frequent action patterns, compromising action timing in dynamic environments. We propose \method, an ordered future-phase planning method for robot brain models. From current multimodal observations, it predicts the task phase at each future action position. The resulting planning representations condition the corresponding actions, preserving temporal alignment between task progress and action generation. Training first learns the planner, then freezes it during action-model adaptation to maintain stable phase representations. We instantiate \method on pretrained $π_{0.5}$ and AcrossWAM1.0 robot brain models. Detailed quantitative evaluation uses the $π_{0.5}$ implementation. On conveyor-belt manipulation, \method reduces offline joint-action error by approximately 22.5\% relative to the original $π_{0.5}$ model. It also improves phase-transition modeling and cross-phase action prediction. These results demonstrate the value of ordered future-phase planning for continuous action generation.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：机器人脑模型（robot brain models）整合视觉、语言与机器人状态，为复杂操作任务生成动作；VLA（Vision-Language-Action）策略是其中的可执行路径，预训练策略（如 π0.5、GR00T N1、LingBot-VLA）使下游任务适配成为可能。
- **核心问题**：主流做法预测**固定长度的动作块（action chunk）**，一个块往往跨越多个任务阶段（如 Wait→Act、Act→Release）。这会导致：
  - **阶段转换被掩盖**，转换时刻难以被准确表达；
  - **偏向高频动作模式**（如传送带任务中 Wait 与 Transport 远长于 Release 与转换），损害动态环境下的动作时序；
  - 平均动作误差相近的策略，其**转换时序与闭环行为可能完全不同**。
- **关键观察**：仅靠"阶段计数"不足以描述任务进度。例如 `Wait, Wait, Act, Act` 与 `Act, Act, Wait, Wait` 阶段计数相同，但每个未来位置所需的动作完全不同。因此需要**位置对齐（position-aligned）**的任务进度表示。
- **整体含义**：论文主张在动作块内部显式建模"有序的未来阶段序列"，将任务级时序结构注入连续动作生成，从而在阶段边界处获得更准确的时序控制。

## 2. 方法论

### 2.1 问题形式化
- 时刻 $t$ 的输入：$o_t=(I^{head}_t, I^{wrist}_t, s_t, \ell)$，即头视图 RGB、腕视图 RGB、机器人状态、语言指令。
- 输出：长度 $H=16$ 的未来动作块 $A_t=(a_{t+1},\dots,a_{t+H})$，每个动作含 7 个右臂关节目标 + 1 个二值夹爪命令。
- 监督：每个未来动作位置有阶段标签 $z_{t+h}\in\mathcal{Z}_\tau$（传送带任务含 Wait / Act / Release / Return-Home 四阶段）。

### 2.2 有序未来阶段规划器（Ordered Future-Phase Planner）
- 取多模态观测 token $X_t=E(o_t)$，引入 $H$ 个可学习**阶段查询** $u_1,\dots,u_H$，每个对应一个未来动作位置。
- 所有查询读取**同一观测上下文**，但保留各自的"未来位置身份"：
  - $Q_{t,h}=P_{\theta_P}(u_h, X_t)$（上下文规划表示）
  - $p_{t,h}=\mathrm{softmax}(W_zQ_{t,h}+b_z)$（该位置的阶段分布）
- 有序性来自 $u_h \leftrightarrow z_{t+h} \leftrightarrow a_{t+h}$ 的一一对应。
- 训练损失为**逐位置阶段分类损失**（对有效未来位置集合 $V_t$ 做交叉熵），从而同时保留阶段类别与转换位置。

### 2.3 规划条件化的动作生成
- 用可学习矩阵 $E_z$ 把阶段分布映射为软阶段嵌入，与规划表示融合：
  - $\bar{e}_{t,h}=E_z^{\top}p_{t,h}$，$e_{t,h}=W_QQ_{t,h}+W_P\bar{e}_{t,h}$
- 轻量网络 $f_{\theta_M}$ 由 $e_{t,h}$ 预测缩放/平移参数 $(\gamma_{t,h},\beta_{t,h})$，对对应动作 token 做调制：
  - $\tilde{x}_{t,h}=(1+\gamma_{t,h})\odot\mathrm{RMSNorm}(x_{t,h})+\beta_{t,h}$
- $f_{\theta_M}$ 的最终投影**零初始化**，适配初期不破坏预训练动作路径；每个 $e_{t,h}$ **只影响对应的** $x_{t,h}$，保持全块的位置对齐。

### 2.4 两阶段训练与推理
- **阶段一**：优化 $\mathcal{L}_{phase}$ 训练阶段查询与规划器层（动作专家冻结）。
- **阶段二**：**冻结规划器**，优化原始 flow-matching 动作目标 $\mathcal{L}_{flow}$，更新动作专家与逐位置调制路径。
- 推理链：$o_t \rightarrow (Q_{t,1:H}, p_{t,1:H}) \rightarrow A_t$，规划器在部署时仍是策略内部的活跃组件，输入仅为标准 VLA 观测（无需标注）。

## 3. 实验设计

- **阶段标签构建**：由逐帧 VLX-Seek 物体标注（篮子/目标包裹/机械臂/其他物体）+ 记录的夹爪状态 + 任务特定时间规则生成，与未来动作位置逐位对齐。
- **数据划分**：按 episode 固定划分；验证集 **3,584 个窗口**，其中 **1,613 个跨阶段边界**；每个有效 16 步窗口都有逐位置阶段监督。
- **预处理**：去除 Wait 静止段的遥操作抖动，平滑重锚定 Wait→Act 转换；所有对比方法共用相同处理后的动作目标。
- **对比方法（同一 π0.5 骨干、数据、划分、优化预算、动作表示）**：
  - Original π0.5（直接适配原始动作专家）
  - Future-skill histogram（仿 GuidedVLA 的时间摘要式聚合技能分布）
  - Ours-P（训练有序规划器但走原始动作路径，用于隔离"预测本身"与"条件化效果"）
  - PhasePlan（完整方法）
- **指标**：未来阶段预测精度、阶段转换类型精度、联合动作 MAE（整体与跨阶段）、夹爪命令准确率、跨阶段动作块表现。

## 6. 主要结论与发现

- **规划性能**：独立查询规划器达到约 **92.5% 逐位置未来阶段准确率**与约 **89% 阶段转换类型准确率**；精度随预测时域增长缓慢下降，16 个位置整体保持较高。
- **视觉输入必要性**：仅状态+语言时宏平均 F1 约 **43%**，打乱 RGB 后降至约 **36%**，完整视觉-语言-状态输入超过 **91%**，说明规划确实利用了当前视觉观测。
- **动作预测**：PhasePlan 整体联合 MAE **0.034605 rad**，比原始 π0.5 低 **22.5%**，比 future-skill histogram 基线低 **12.7%**；跨阶段窗口 MAE 降至 **0.041318 rad**，夹爪命令准确率 **93.162%**。
- **机制归因**：Ours-P 与原始 π0.5 指标相同，说明**收益来自逐位置规划条件化**，而非阶段预测本身。
- **训练策略**：冻结规划器比继续更新规划器有更好的转换类型精度与转换时序，联合动作误差也略低；真值阶段 oracle 可进一步提升，剩余差距最大出现在与 Release 相关的夹爪预测（短阶段转换预测最关键）。
- **其他消融**：完整规划特征优于仅 phase-ID；box 级视觉监督将注意力落在标注区域的比例从 **8.5% 提升到 81.2%**，但动作指标相当；逆阶段频率加权把 Release 处夹爪准确率从 82.6% 提到 84.3%，但整体 MAE 上升约 1.3%，故最终采用均匀权重。
- **执行验证**：MuJoCo 中预测动作产生连续机械臂/夹爪位形变化；真机与 AcrossWAM1.0 上呈现从接近、抓取到搬运、释放的连贯进程。

## 7. 优点

- **表示设计有洞察**：指出"阶段计数相同但顺序不同"的歧义，用**逐未来位置**的阶段分布取代整体直方图，同时保留阶段类别与转换位置。

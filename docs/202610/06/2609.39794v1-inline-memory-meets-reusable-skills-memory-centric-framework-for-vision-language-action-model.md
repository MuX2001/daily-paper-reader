## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作方面展现出巨大潜力，但将其适应到新任务和新领域仍然效率低下：现有方法往往依赖参数调优，这会带来高昂成本，并可能导致对先前学习任务的灾难性遗忘。为解决这一问题，我们提出 Optimus-R，一个以记忆为中心的 VLA 框架，将机器人适应建模为显式的查询-技能记忆调优。Optimus-R 引入了：(i) 用于技能提取的内联记忆接口（Inline Memory Interface）。它将可学习记忆 token 插入 VLA 前缀流中，使主干网络能够在原生动作条件化路径中导出控制感知的查询表示和技能表示。(ii) 用于技能学习的查询-技能记忆库（Query-Skill Memory Bank）。它将技能外化为用于决定检索什么（what）的查询原型，以及用于指定如何行动（how）的技能值，从而在有限参数更新下支持技能复用与扩展。(iii) 一种用于技能更新的轻量级桥接与适应机制（Bridge-and-Adapt）。它通过轻量级适配器和残差记忆更新，将目标域查询和技能与现有记忆空间对齐。在域内适应、跨域适应和终身学习上的实验表明，Optimus-R 能够实现数据高效的技能学习，同时缓解灾难性遗忘。

## Abstract
Vision-Language-Action (VLA) models have shown strong promise for general-purpose robotic manipulation, yet adapting them to new tasks and domains remains inefficient: existing methods often rely on parameter tuning, incurring substantial costs and risking catastrophic forgetting of previously learned tasks. To address this, we propose \textbf{Optimus-R}, a memory-centric VLA framework that formulates robotic adaptation as explicit query-skill memory tuning. Optimus-R introduces: (i) An \textbf{Inline Memory Interface for skill extraction}. It inserts learnable memory tokens into the VLA prefix stream, allowing the backbone to derive control-aware query and skill representations within the native action-conditioning pathway. (ii) A \textbf{Query-Skill Memory Bank for skill learning}. It externalizes skills into query prototypes for deciding \emph{what} to retrieve and skill values for specifying \emph{how} to act, supporting skill reuse and expansion with limited parameter updates. (iii) A lightweight \textbf{Bridge-and-Adapt mechanism for skill updating}. It aligns target-domain queries and skills with the existing memory space through a lightweight adapter and residual memory updates. Experiments on in-domain adaptation, cross-domain adaptation, and lifelong learning show that Optimus-R enables data-efficient skill learning while mitigating catastrophic forgetting.

## 1. 核心问题与整体含义

- **研究动机**：视觉-语言-动作（VLA）模型已成为通用机器人操作的重要基础，但在真实世界中适配新任务、新物体、新场景和新领域时仍需要大量演示数据。
- **现有范式的痛点**：主流做法是**参数中心（parameter-centric）**的微调，即通过更新模型权重来学习新技能。这带来两个严重问题：
  - 适配成本高（每次新技能都隐式改变权重）；
  - 容易干扰已学任务，导致**灾难性遗忘**。
- **核心追问**：能否让 VLA 通过**显式记忆接口**来获取、存储和复用技能，而不是反复更新模型参数？
- **三个耦合挑战**：
  - 技能应从 VLA 自身导出，而非作为弱耦合的外部上下文附加；
  - 技能应被显式组织，而非被吸收进模型权重；
  - 技能应在域偏移（视觉/动力学变化）下仍可被检索。
- **整体含义**：论文将机器人适配统一建模为**技能提取、技能学习、技能更新**三个环节，提出以记忆为中心的框架 **Optimus-R**，为 VLA 的可持续、数据高效适配提供新路径。

## 2. 方法论

### 2.1 核心思想
- 用**显式查询-技能记忆调优**替代重复的全局参数更新：把技能外化为可检索、可扩展、可更新的记忆条目，仅更新轻量对齐模块、原型残差和记忆库条目。

### 2.2 三大关键技术

**(i) 内联记忆接口（Inline Memory Interface）——技能提取**
- 将可学习记忆 token `E_mem` 插入 VLA 前缀流：`[Hvl_t; M_t] = Fθ(O_t, L; E_mem)`，使主干在原生动作条件化路径内产出与策略对齐的记忆状态。
- 用两个独立的注意力池化算子分别读取记忆状态，得到查询表征 `q_t`（仅用于检索）与技能表征 `s_t`（保留动作相关信息，作为记忆库中的“值”）。
- 训练时用轻量 **Skill Decoder** 以 Huber 损失从 `s_t` 重建未来动作块，将技能空间锚定在可执行行为上；**Token Projector** 将技能投影为 VLA 兼容的 skill token 以条件化 Flow Policy。

**(ii) 查询-技能记忆库（Query-Skill Memory Bank）——技能学习**
- 记忆库条目为解耦的键值原型：`B = {(p^q_j, p^s_j, n_j, E_j)}`，分别表示查询原型、技能原型、支持计数和用于回放的潜在查询-技能对。
- **构建流程**：先用运动感知降采样（按动作变化分数 `ν_i`）和归一化进度分层采样减少冗余，再在查询空间聚类，对技能方差高的簇进一步在技能空间分裂，得到“可检索 + 动作一致”的原型。
- **检索流程**：先将查询对齐到记忆坐标 `q'_t = A_mem q_t`，对 top-Kr 原型按相似度做 softmax 加权，聚合得到 `ˆs_t = Σ α_tj (p^s_j + Δp^s_j)`；残差 `Δp^q_j, Δp^s_j` 实现不覆盖基础原型的局部技能更新。

**(iii) Bridge-and-Adapt——技能更新**
- **Stage A（接口预训练）**：训练记忆 token、池化器、查询/技能编码器、技能解码器、Token Projector 及主干最后若干层；损失为 `L_pre = L_fm + λ_q L^nce_q + λ_s L_skill`，其中 `L^nce_q` 为查询对比损失（同任务近进度样本 + 同轨迹邻域状态为正样本）。
- **Stage B（桥接适应）**：面向跨域（如 sim-to-real），解冻主干并更新 `A_mem`、`τ_mem` 和活跃原型残差，保持接口模块、Token Projector 与基础原型固定；当技能空间失配较大时启用**零初始化低秩 Skill Adapter**：`˜s_t = A_s(ˆs_t) = ˆs_t + U_s V_s^T ˆs_t`（r ≪ d_s）。
- **Stage C（记忆适应）**：面向域内终身学习，冻结主干与内联记忆接口，仅更新 `A_mem`、`τ_mem`、活跃原型残差和记忆库；新样本若与已有原型接近则更新残差与统计量，否则进入候选缓冲，只有满足最小簇规模与低查询/技能方差时才追加新原型。
- **统一适配目标**：`L_life = L_fm + λ_align ‖˜s_t − sg(s_t)‖² + λ_reg Σ(‖Δp^q_j‖² + ‖Δp^s_j‖²)`；回放采用存储的潜在查询-技能对（不含原始图像/动作轨迹），新旧样本比例约 3:1。

## 7. 优点

- **范式创新**：将机器人适配从“参数中心”转为“记忆中心”，用显式查询-技能记忆实现技能外化，从根本上缓解灾难性遗忘。
- **设计自洽**：内联记忆使技能表征与原生动作条件化路径耦合，避免外部检索记忆“弱耦合、缺乏控制相关性”的问题；查询与技能解耦兼顾“检索什么”和“如何行动”。
- **参数与推理高效**：新增仅 7M 参数，可训练参数与 LoRA 相当，但成功率和推理频率更优，训练 GPU 小时显著低于 LoRA 基线。
- **回放隐私友好**：存储潜在查询-技能对而非原始图像/动作轨迹，降低存储与隐私风险。
- **实验覆盖面广**：同时覆盖域内、跨域、终身学习三类场景，并附大量附录实验（记忆增长、跨套件迁移、任务级持续学习矩阵）。

## 8. 不足与局限

- **依赖强预训练主干**：若基础策略缺乏必要的操作原语，仅靠记忆检索与原型扩展可能不足。
- **记忆库质量敏感**：效果取决于预训练/适配数据的覆盖度与聚类质量；条目稀疏或组织不佳时，对细粒度时序或接触丰富的任务检索效果下降。
- **跨域仍需目标域数据**：Bridge-and-Adapt 只能缓解表征漂移，无法保证

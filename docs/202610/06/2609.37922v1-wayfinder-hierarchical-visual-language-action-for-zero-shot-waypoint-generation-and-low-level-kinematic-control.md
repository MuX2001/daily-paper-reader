## 摘要
视觉-语言-动作（VLA）模型为自主机器人提供了前所未有的泛化能力；然而，其真实世界部署常常受限于执行不可靠以及针对特定机器人本体和任务进行微调的高昂计算成本。为弥补这一差距，我们提出 WayFinder，一种端到端、闭环的分层 VLA 框架，通过将高层任务推理与底层运动学控制解耦，规避了微调需求。WayFinder 利用零样本、非机载的多模态大语言模型（MLLM）策略处理语言上下文和状态地图，以进行策略性路点生成。异步地，一个轻量级机载策略基于连续传感器反馈，以高频执行实时运动学控制。我们在 Microsoft AirSim 中评估 WayFinder，在四个复杂度不同的环境和三种 MLLM 规模上进行测试，以平衡预测有效性与计算效率。结果表明，与基线底层策略相比，WayFinder 实现了更优的导航可靠性。通过仅在导航失败时查询高层 MLLM，WayFinder 消除了微调需求，最小化了昂贵的推理，并将导航成功率显著提高最多 27.45%。

## Abstract
Visual Language Action (VLA) models offer unprecedented generalization for autonomous robots; however, their real-world deployment is frequently bottlenecked by unreliable execution and the prohibitive computational cost of fine-tuning for specific robot embodiments and tasks. To bridge this gap, we propose WayFinder, an end-to-end, closed-loop hierarchical VLA framework that circumvents the need for fine-tuning by decoupling high-level task reasoning from low-level kinematic control. WayFinder utilizes a zero-shot, offboard Multimodal Large Language Model (MLLM) policy to process linguistic context and state maps for strategic waypoint generation. Asynchronously, a lightweight, onboard policy executes real-time kinematic control at high frequency based on continuous sensor feedback. We evaluate WayFinder in Microsoft AirSim, testing on four environments of varying complexity and three MLLM scales to balance prediction efficacy with computational efficiency. Our results demonstrate that WayFinder achieves superior navigation reliability compared to baseline low-level policies. By querying the high-level MLLM only during navigation failures, WayFinder eliminates the need for fine-tuning, minimizes expensive inferences, and significantly increases navigation success rates by up to 27.45%.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：自主机器人（空间探索、应急救援、国防等）需要闭环的感知—控制链路；深度强化学习（DRL）虽在无地图导航上表现优异，但面对分布外（OOD）场景、迷宫式死胡同、无限循环时容易停滞，仍需人类介入。
- **VLA 的机会与瓶颈**：以 RT-2、OpenVLA 为代表的视觉-语言-动作模型借助网络规模预训练知识，具备强大的语义常识与零样本泛化能力，但在移动机器人上部署存在两大障碍：
  - **算力开销大**：高频连续推理与轻量边缘硬件冲突；
  - **黑盒随机性**：MLLM 的随机输出难以满足实时运动控制所需的确定性安全保证。
- **既有路线的代价**：主流做法依赖后训练、微调（如 LoRA）或模型蒸馏，将大规模公共数据映射到特定机器人本体。微调计算昂贵、小众任务（如空中导航）演示数据极度稀缺，且面向泛化指令的损失函数定义模糊。
- **核心主张**：WayFinder 通过**分层解耦**——高层零样本 MLLM 战略推理 + 底层高频反应式运动控制——在不做任何微调的前提下，兼顾 MLLM 的常识推理与经典控制器的安全性与高频响应，并把昂贵的 MLLM 推理压缩为**仅在停滞时的稀疏恢复调用**。

## 2. 方法论

### 2.1 整体架构（闭环分层 VLA）

- **底层（默认运行模式）**：轻量、高频的 DRL 运动学控制策略，负责局部点到点导航与确定性避障，融合机载深度、GPS、IMU。
- **高层（异步、按需触发）**：离板（edge server）托管的零样本 MLLM（Gemma 3），接收全局状态地图 + 结构化语言提示，输出中间路点（waypoint）。
- **闭环流程**：默认由底层策略飞行 → 停滞检测触发 → 暂停底层、构造多模态查询 → MLLM 输出恢复路点 → 路点替代当前目标 → 到达后目标复位为初始目标、触发窗口重置。

### 2.2 底层策略（DRL / DQN）

- **问题建模**：局部点到点穿越建模为 POMDP，元组 (S, A, T, R)；因动作空间离散，采用 **Deep Q-Network（DQN）**。
- **状态空间 S**：滑动时间窗 τ 内融合外部感知与本体感知
  - 深度图 D ∈ R^{144×256}；
  - **相对** GPS 坐标 c ∈ R²（相对目标/当前路点，避免对地图绝对坐标过拟合）；
  - IMU 航向 θ ∈ R¹。
- **动作空间 A**：离散运动指令（前进 1–32 m 的平移、90° 偏航旋转），由机载硬件飞控执行成连续加速度，降低 DRL 探索维度、提升样本效率。
- **转移函数与避障**：物理/图形由 Microsoft AirSim 渲染；引入确定性避障算法——短距传感器检测到障碍即**在碰撞前中止该动作**，从停止位置重新采样状态。因此碰撞被完全移出 POMDP 惩罚空间。
- **奖励函数**：
  - r_t = λ_p·d_t + λ_t·r_step + r_terminal；
  - d_t = ‖p_t − g_t‖₂（鼓励向目标靠近）；
  - r_step 为每步常数负奖励（对"被避障阻塞后重采样"形成隐性惩罚）；
  - r_terminal 在到达目标半径时为大正奖励，超过最大步数 L 时为大负惩罚（抑制无限循环）。
- **网络结构**：深度图时间队列 → 3 层卷积（ReLU）→ 展平为 25,088 维 → 与 τ=3 的 GPS/IMU FIFO 队列拼接 → 3×128 节点 MLP → 输出各离散动作的 Q 值。结构受 Atari DQN 启发，超参经网格搜索。
- **状态缓存与离散化**：预先离散化 AirSim 可导航空间，缓存所有可能的自中心深度图及其碰撞布尔状态，绕开同步渲染瓶颈，把 DQN 训练时间**从数周压缩到数小时**。
- **离线 A\* 路径生成**：用 A\* 生成真值路径数据集，以最优步数定义"路径难度"；划分训练集与两个静态留出集（验证/测试，取自训练未见区域）。
- **课程学习与回放**：按 A\* 步数从易到难渐进训练；用高容量回放缓冲（**100 GB RAM**）与随机采样策略缓解灾难性遗忘（低概率回采早期难度路径）；以静态 A\* 验证集做早停并冻结最优权重。

### 2.3 高层策略（MLLM 零样本路点生成）

- **触发条件**（稀疏查询）：在长度 N 的滚动窗口内计算最大前进量
  - Δρ_t = d_{t−N} − min_{k∈[t−N, t]} d_k；
  - 若 Δρ_t < ε 则 T_t = True（判定停滞），随后查询 MLLM、重置时间窗以避免误报连锁触发。
- **视觉状态图 M_t**：不做原始 RGB-D 直传，而是抽象为 **2D 鸟瞰 RGB 语义图**，用高对比颜色与几何原语迎合 VLM（SigLIP）视觉编码器的 token 化偏好。自底向上投影：
  - 黑色=可通行自由空间；白色=障碍；灰色=未知/未探索；
  - 紫色线与圆=机器人历史轨迹；红色三角=历史失败路点；
  - 绿色十字=起点；蓝色方块=机器人当前位置；黄色五角星=全局目标。
- **为何不用像素—坐标直接映射**：现代 MLLM（Gemma 3）在视觉预处理时采用动态缩放与切块（Pan & Scan，受 LLaVA 启发），破坏像素索引与空间坐标的对应关系，导致路点精度严重损失；因此改用显式语言坐标对齐视觉特征。
- **语言提示**：结构化模板，声明机器人视角受限、已卡住需中间路点、动作只能为 1–32 m 前进或 90° 旋转，并逐项给出蓝方块/黄星/绿十字/轨迹序列/历史路点坐标以及颜色语义；强制输出格式 `[STRATEGY]: ... [WAYPOINT]: (x, y)`，并要求路点落在安全（黑）且未尝试过的坐标。
- **射线追踪建全局图（M_t）**：把 2D 深度图转为三值占据栅格（free 0 / occupied 1 / unknown −1）：
  - 归一化像素坐标 x_norm=(u−c_x)/f_x, y_norm=(v−c_y)/f_y；
  - 按球面畸变计算沿光轴的深度 z = D(u,v)/√(x_norm²+y_norm²+1)，再恢复 x=x_norm·z, y=y_norm·z；
  - 沿垂直 Y 轴空间滤波（剔除地面与高空障碍如电线），并对深度施加地平线阈值，防止看到地图边界外；
  - 过滤后 3D 点投影到局部 XZ 平面，按 z_grid 与障碍深度 z_obs 比较（前于障碍−δ 记为 free、在容差内记为 occupied、其后保持 unknown）生成局部占据栅格；
  - 按航向 θ_t 旋转、按位置 p_t 平移后更新世界地图，并用掩码保证仅新观测的 free/occupied 单元覆盖，保留已探索区域记忆。

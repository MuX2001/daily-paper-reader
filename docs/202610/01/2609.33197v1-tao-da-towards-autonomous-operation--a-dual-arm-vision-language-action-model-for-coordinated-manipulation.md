## 摘要
视觉-语言-动作（VLA）模型为将高层语义信息落地为底层机器人动作提供了统一框架，从而支持跨多样化任务的可扩展机器人操作。然而，现有 VLA 模型缺乏显式机制来解耦双臂的状态与意图，导致非预期的跨臂干扰，从而降低任务执行成功率。为解决这一问题，我们提出一种对称双臂专家（DAE）架构，其构建于共享的视觉-语言模型（VLM）主干之上，并包含解耦的、手臂特定的专家塔。专家选择通过两阶段双臂意图路由方案完成：第一阶段依据显式语言指令路由专家，第二阶段依据隐式视觉语义路由专家。此外，我们引入一个轻量级任务进度预测模块，利用 pre-chunk 时序特征与本体感觉和视觉观测的语义表示之间的交叉注意力，准确估计逐帧任务完成进度。该模块促进任务进度同步，以支持协作多机器人任务的协调调度。实验结果表明，我们的模型在双臂意图路由和跨臂干扰解耦方面有效，并进一步为从单臂到双臂任务（以及反向）的涌现技能泛化提供了初步证据，同时展示了跨臂运动域技能迁移。

## Abstract
Vision-Language-Action (VLA) models provide a unified framework for grounding high-level semantic information into low-level robot actions, enabling scalable robotic manipulation across diverse tasks. However, existing VLA models lack explicit mechanisms to disentangle the states and intents of the two arms, leading to unintended cross-arm interference that degrades task execution success. To address this issue, we propose a symmetric Dual-Arm Expert (DAE) architecture built upon a shared Vision-Language Model (VLM) backbone with decoupled, arm-specific expert towers. Expert selection is carried out through a two-stage dual-arm intent routing scheme, in which experts are routed either by explicit language instructions in the first stage or by implicit visual semantics in the second stage. Moreover, we introduce a lightweight task progress prediction module that leverages cross-attention between the pre-chunk temporal features and semantic representations of proprioceptive and visual observations to accurately estimate frame-wise task completion progress. This module facilitates task progress synchronization to support coordinated scheduling for collaborative multi-robot tasks. Experimental results demonstrate the effectiveness of our model in dual-arm intent routing and the disentanglement of cross-arm interference, and further provide preliminary evidence of emergent skill generalization from single- to dual-arm tasks (as well as the reverse), together with cross-arm motion-domain skill transfer.

# TAO-DA 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：视觉–语言–动作（VLA）模型将语言、视觉观测与机器人状态统一映射为操作动作，为语言条件下的机器人控制提供了可扩展接口。近期系统多采用自回归、扩散或流匹配（flow matching）动作生成器。
- **核心问题**：主流双臂 VLA 设计把两条手臂放进**统一动作生成器**中，虽然简化了动作接口，却会把执行臂与另一条手臂无关的状态/视觉变化耦合在一起。这种耦合在以下情形尤为有害：
  - 只需单臂执行时；
  - 两臂执行顺序子任务时；
  - 演示中两臂角色不对称时。
- **论文主张**：双臂策略应**保留共享任务语义**，同时**选择性地控制手臂级动作生成**。据此提出 TAO-DA：共享多模态表示用于任务级推理 + 手臂专属动作塔用于底层控制；由 DAIR 决定活动臂集合，由 DAE 通过被选中的手臂通路生成动作。
- **整体含义**：把"非活动臂干扰"形式化为一个**动作生成问题**，并探索统一、掩码、完全独立三种手臂级处理变体，为双臂乃至多机器人协同提供可扩展方案。

## 2. 方法论

### 2.1 总体架构（TAO-DA）

- 输入：多视角视觉观测（1 路自我中心视图 + 左右末端执行器视图，后两者可选）、语言指令、本体感觉状态。
- 编码：每张图像由同一预训练 **SigLIP** 编码；视觉 token 与语言 token 拼接后送入**冻结的 Eagle-2.5-VL 主干**，得到融合表示 $E_{VL}\in\mathbb{R}^{N\times D}$，供 DAIR 使用。
- 动作条件表示：路由后，在 VLM 输入端**掩蔽非活动末端执行器视图 token**；本体感觉特征单独编码，手臂特定状态与动作 token 由对应动作通路处理。
- 训练时，每个任务的指令从语义等价表达池中随机采样（提升语言鲁棒性）。

### 2.2 DAIR：语言与视觉引导的双臂意图路由

- **意图表示**：活动臂集合编码为二值向量 $r=[r_L, r_R]\in\{0,1\}^2$，有效类别为左臂、右臂、双臂三类：$\phi(0)=[1,0]$、$\phi(1)=[0,1]$、$\phi(2)=[1,1]$。作为三分类问题训练，损失为交叉熵 $L_{route}=-\log p_c$。三分类接口避免产生非法的"无臂"向量 $[0,0]$。
- **第一阶段：规则式语言意图解析**：识别"左臂/右臂/双臂/左手/右手"等显式表达，映射为 $\hat r_{rule}$；同时出现双臂表达时双臂优先。解析器**不使用空间表达**推断意图；若无显式手臂表达，返回内部无匹配码 $[0,0]$，触发第二阶段。
- **第二阶段：基于模型的多模态意图预测**：对 $E_{VL}$ 做 LayerNorm，用可学习 query 做多头注意力池化，得到 $f=\mathrm{MHA}(q,E_{norm},E_{norm})$；MLP 输出 3 个 logits，取 argmax 映射回二值接口。
- **推理期保持机制（hold）**：当任务进度足够时保持先前意图。给定预测进度 $\hat p_t$、阈值 $\tau_{hold}$ 与上一时刻意图 $\hat r_{t-1}$：
  - 若 $\hat r_{rule}\neq[0,0]$，用 $\hat r_{rule}$；
  - 若 $\hat r_{rule}=[0,0]$ 且无历史意图，用 $\hat r_{model}$；
  - 若 $\hat r_{rule}=[0,0]$ 且 $\hat p_t\le\tau_{hold}$，用 $\hat r_{model}$；
  - 否则保持 $\hat r_{t-1}$。
  - 该机制用于稳定路由决策，与部署级任务调度器不同。

### 2.3 DAE：双臂专家模块（三种变体）

- **Single-Tower**：两臂状态与动作 token 拼接进同一 DiT（统一动作空间）。
- **Dual-Mask（弱解耦）**：共享 DiT，但用**手臂模式注意力掩码**限制 token 交互。输入含四组 token $X_{in}=[X^L_{state},X^R_{state},X^L_{action},X^R_{action}]$；对模式 $m\in\{left,right,dual\}$ 定义二值掩码 $M^{(m)}$，作用于自注意力：$Attn(Q,K,V|M)=\mathrm{softmax}(QK^\top/\sqrt d+\log M)V$，掩码为零处抑制对应注意力 logit。左臂模式下仅左臂状态与动作组可互相注意，右臂对称，双臂模式允许跨组注意。多模态任务表示在所有模式下共享。
- **Dual-Tower（强解耦）**：两个同架构但**参数独立**的分支 $T_L,T_R$，各有自己的状态编码器、动作 tokenizer、DiT 与动作解码器。$X^k_{state}=Enc^k_{state}(s_k)$，$X^k_{action}=Tok^k_{action}(a^k_\alpha)$（$a^k_\alpha$ 为流匹配用的加噪/插值动作序列）；两序列独立处理，条件于路由后的多模态上下文。
- **路由条件化动作生成**：训练时用标注 $r$ 选择手臂轨迹切片与动作目标；双臂样本在同一时间步同步监督两个塔，单臂样本不监督非活动塔；推理时用 DAIR 预测的 $\hat r$ 控制相同数据流。
- **手臂条件化视图掩蔽**：令 $V=[V_{ego},V_L,V_R]$，动作条件化时掩蔽非活动末端执行器视图 token：$e_V(r)=\mathrm{Mask}(V,r)$，$e_{E_{VL}}(r)=\mathrm{VLM}(e_V(r),E_{lang})$。自我中心视图在所有模式下保留。
- **活动臂监督**：$L_{act}=r_L L^L_{FM}+r_R L^R_{FM}$，其中 $L^k_{FM}$ 为手臂 $k$ 的流匹配目标；单臂样本仅一项激活，双臂样本两项均用。

### 2.4 任务进度预测模块

- 用 GRU 编码 DiT 时序特征 $H=[h_1,\dots,h_T]$，得到 $S=\mathrm{GRU}(H)$；再通过交叉注意力与 VLM 表示融合 $Z=\mathrm{MHA}(S,E_{VL},E_{VL})$；回归头以**归一化轨迹时间**为目标预测 $\hat p_t$。
- 推理时该估计同时支持 DAIR 的保持机制与部署级调度。

## 6. 主要结论与发现

- **整体性能**：单臂完整任务套件上 TAO-DA 平均成功率 **88.4%**，高于 GR00T N1.5（82.0%）与 π0.5（80.5%）；4 个任务取得最佳或并列最佳，仅在 Steamer Delivery-R 上低于 GR00T N1.5。
- **双臂任务**：Collaborative Tea 达 **100%**（与 π0.5 并列最高），Desktop Organization 达 **95%**（高于两个基线）。
- **干扰隔离**：扰动/干净 MSE 比值——Single-Tower 为 1.94（右）/1.60（左），Dual-Mask 降至 1.46/1.13，**Dual-Tower 为 0.99/1.00**，表明独立动作塔显著降低活动臂对非活动臂扰动的敏感性。
- **真实机器人鲁棒性**：随机初始状态与持续扰动条件下，Dual-Tower 保持 95–100% 成功率；Single-Tower 为 20–60%，Dual-Mask 为 65–85%。持续扰动下 Dual-Tower 左/右臂分别为 100%/95%，Single-Tower 仅 25%/20%（相差 75 个百分点）。
- **路由性能**：留出集上左臂、右臂、双臂的**逐类准确率分别为 85.37%、83.31%、96.13%**；混淆矩阵显示**无左右侧混淆错误**，错误集中于把单臂误判为双臂（左 14.6%、右 16.7%）。
- **路由消融**：Multi（多样指令）下移除进度模块使右臂准确率从 83.31% 降至 68.48%、双臂从 96.13% 降至 89.22%；保留进度时 Fixed（固定指令）右臂为 78.66%，低于 Multi 的 83.31%。
- **技能复用**：仅用双臂演示训练时，两种解耦变体在三种执行模式下均优于 Single-Tower；Dual-Tower 达 100%/90%/95%，Single-Tower 仅 80%/50%/50%。另有单臂技能并行组合成功执行的定性实例，以及左右臂角色互换的初步（精度较低的）观察。
- **部署**：自主餐厅系统在 101 次全流程试验中达 **92.08%** 端到端成功率（包含感知、操作、调度与系统执行，不能单独归因于 TAO-DA）。

## 7. 优点

- **问题刻画清晰**：将"非活动臂干扰"显式形式化为动作生成问题，并给出可检验的假设与量化指标（扰动/干净 MSE 比值）。
- **架构消融有梯度**：Single-Tower → Dual-Mask → Dual-Tower 构成统一到完全解耦的连续谱，便于定位解耦收益来源。
- **两阶段路由设计务实**：规则解析处理显式指令、学习模型处理隐式视觉语义，三分类接口避免非法"无臂"状态，进度触发的 hold 机制提升推理期稳定性。

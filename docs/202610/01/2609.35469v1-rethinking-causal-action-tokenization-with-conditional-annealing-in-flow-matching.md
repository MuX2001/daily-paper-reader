## 摘要
自回归视觉-语言-动作（VLA）模型为机器人学习提供了一条可扩展路径，然而现有动作标记器将标记化视为压缩问题，产生的表示在语义上与自回归骨干网络不一致。我们提出 CATok，一种因果动作标记器，将标记化重新构建为一个具有因果结构的生成过程。CATok 引入一种条件退火机制，通过逐步退火一个流匹配过程来提取动作标记：每个标记都以所有前序标记为条件，并编码特定噪声水平下的残差重建信号，从而建立一个由粗到细的因果标记空间，其生成语义在结构上与自回归建模对齐。一个基于多模态扩散 Transformer（MMDiT）的标记条件流匹配解码器，能够以混合扩散头架构的精度，从这些离散标记中重建连续动作块。这种离散瓶颈通过设计实现了知识隔离，无需显式注意力掩码，即可清晰地将高层语义推理与低层运动执行分离。在三个仿真基准和真实世界机器人操作任务上的大量评估表明，CATok 在重建保真度-压缩权衡和推理效率方面持续超越现有标记化方法，同时提升 VLA 任务成功率和训练效率，为纯自回归 VLA 系统建立了一个高性能、可扩展的基础。

## Abstract
Autoregressive Vision-Language-Action (VLA) models offer a scalable path to robot learning, yet existing action tokenizers treat tokenization as a compression problem, producing representations that are semantically misaligned with the autoregressive backbone. We propose CATok, a causal action tokenizer that reframes tokenization as a causally structured generative process. CATok introduces a conditional annealing mechanism that extracts action tokens by progressively annealing a flow-matching process: each token is conditioned on all preceding tokens and encodes the residual reconstruction signal at a specific noise level, establishing a coarse-to-fine causal token space whose generative semantics are structurally aligned with autoregressive modeling. A token-conditioned flow-matching decoder built on Multimodal Diffusion Transformer (MMDiT) reconstructs continuous action chunks from these discrete tokens with the precision of hybrid diffusion-head architectures. This discrete bottleneck enforces knowledge insulation by design, cleanly separating high-level semantic reasoning from low-level motor execution without requiring explicit attention masking. Extensive evaluations across three simulation benchmarks and real-world robotic manipulation tasks demonstrate that CATok consistently surpasses existing tokenization methods in both reconstruction fidelity-compression tradeoff and inference efficiency, while improving VLA task success rate and training efficiency, establishing a high-performance, scalable foundation for purely autoregressive VLA systems.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：机器人基础模型在多种操作任务上展现强泛化能力，视觉-语言-动作（VLA）模型成为重要范式。现有 VLA 主要分两类：
  - **纯自回归模型**：以语言模型相同的 next-token 目标预测离散动作 token，训练基础设施可扩展、token 级统一建模；
  - **混合模型**：自回归语言骨干 + 连续扩散/流匹配动作头，控制精度高，但动作生成与自回归骨干解耦。
- **核心痛点**：纯自回归 VLA 的关键瓶颈在于**如何对连续机器人动作进行标记化（action tokenization）**。现有动作标记器大多把标记化当作**压缩问题**，只编码“动作应被重建什么”，而非“动作应如何被生成”，导致离散表示与自回归骨干语义错位。
- **现有方法局限**：
  - **均匀分箱（BIN）**：逐维离散化，产生 O(D×H) 长序列，忽略动作维度间相关性，无因果结构；
  - **FAST**：DCT + BPE 压缩，频率序系数与从左到右的自回归生成不对齐，变长输出解码脆弱；
  - **FASTer**：RVQ 固定长度码，重建保真度高，但码本仅优化重建，未保证与语言模型骨干兼容；
  - **OAT**：通过嵌套 dropout 引入从左到右顺序，但 token 位置缺乏语义基础，与信息粒度/生成阶段无原则性对应。
- **核心洞察**：生成建模中，去噪过程天然暴露抽象层级——高噪声步捕捉粗粒度全局结构，低噪声步精炼细粒度细节。若动作 token 与这一层级对齐，token 序列即可提供**因果有序、由粗到细**的连续控制表示，与自回归生成天然匹配。
- **整体含义**：论文提出 CATok，将动作标记化重新定义为**具有因果结构的生成过程**，为纯自回归 VLA 系统建立高性能、可扩展的离散动作表示基础。

## 2. 方法论：核心思想与关键技术

### 2.1 核心思想

- 将离散动作 token 锚定在**连续流匹配轨迹**上：每个 token 被学习为**阶段性的信息增量**，沿流匹配时间轴形成由粗到细的因果层级；
- 通过**条件退火（Conditional Annealing）**机制，使每个 token 以所有前序 token 为条件，并对应去噪过程的特定阶段；
- 用**基于 MMDiT 的 token 条件流匹配解码器**从紧凑离散 token 重建连续动作块，兼顾连续生成动作头的控制精度与纯自回归 VLA 的训练兼容性。

### 2.2 问题形式化

- 给定连续动作块 \(A=(a_t,\dots,a_{t+H-1})\in\mathbb{R}^{H\times d_a}\)，学习编码器 \(E\) 与解码器 \(D\)，使 \(E(A)=C=(c_1,\dots,c_K)\)，\(c_k\in\{1,\dots,|\mathcal{C}|\}\)，且 \(D(C)\approx A\)；
- tokenizer 训练最小化重建误差；VLA 策略以观测 \(o_t=(I_t,s_t,l)\) 为条件，用交叉熵做 next-token 预测。

### 2.3 架构细节

- **Dual-Stream Action Encoder（双流动作编码器）**：
  - 先对原始动作块做**分位数归一化**，缓解离群值影响；
  - 用带权重归一化的 **2D CNN** 编码动作块，同时捕捉时间与动作维度的局部相关性，并加可学习 2D 位置嵌入，得到 \(E_{act}\)；
  - 并行初始化 \(K\) 个可学习 query 嵌入 \(Q^{(0)}\in\mathbb{R}^{K\times D}\)；
  - 将两者送入**对称多模态 Transformer（受 MMDiT 启发）**，通过 co-attention 双向交互，动作嵌入提供结构化上下文，query token 聚合信息；经 \(L\) 层后取 query 流 \(Q=(q_1,\dots,q_K)\) 作为动作块表示。
- **Bottleneck Vector Quantizer（瓶颈向量量化器）**：
  - 采用 ViT-VQGAN 的 **factorized codes** 设计；
  - 线性瓶颈 \(\psi:\mathbb{R}^D\to\mathbb{R}^{D'}\)（\(D'<D\)）降维，再在码本 \(\mathcal{C}=\{e_1,\dots,e_{|\mathcal{C}|}\}\subset\mathbb{R}^{D'}\) 中按欧氏距离最近邻量化：\(c_k=\arg\min_j\|e_j-\psi(q_k)\|_2\)；
  - 后投影层 \(\phi:\mathbb{R}^{D'}\to\mathbb{R}^D\) 恢复量化嵌入 \(\hat{q}_k=\phi(e_{c_k})\)；
  - 该设计将码本维度与模型隐藏维度解耦，显著提升码本利用率。
- **Flow-Matching Decoder with Conditional Annealing（条件退火流匹配解码器）**：
  - 设 \(x_0\sim\mathcal{N}(0,I)\)，\(x_1=A\)，按 rectified flow 定义插值路径 \(x_t=(1-t)x_0+tx_1\)，目标速度为 \(x_1-x_0\)；
  - **条件退火**：不是全程以全部 token 嵌入为条件，而是按 \(\kappa(t)=\lfloor tK\rfloor\) 逐步掩蔽前 \(\kappa(t)\) 个 token，仅将活跃子集 \(\hat{Q}_{>\kappa(t)}\) 作为时刻 \(t\) 的条件；
  - 训练目标：\(\mathcal{L}_{FM}=\mathbb{E}_{t,x_0,x_1}\|v_\theta(x_t,t,\hat{Q}_{>\kappa(t)})-(x_1-x_0)\|_1\)；
  - 该调度迫使不同 token 在不同生成阶段发挥作用：早期噪声主导时活跃 token 提供粗粒度全局引导，后期接近目标时剩余 token 专注残差细粒度修正，从而让每个 token 成为相邻流匹配阶段间的**离散信息增量**，形成因果有序的由粗到细层级。
- **训练方案**：
  - 总损失 \(\mathcal{L}=\mathcal{L}_{FM}+\alpha\mathcal{L}_{smooth}+\beta\mathcal{L}_{VQ}\)；
  - \(\mathcal{L}_{smooth}\) 为 **DCT 频域损失**，惩罚频谱差异，促进长时程预测平滑与时间一致；
  - \(\mathcal{L}_{VQ}\) 采用标准 commitment 形式，配合 **EMA 更新码本**，并按低使用率周期性从当前 batch 随机重初始化罕见码字，缓解码本坍缩。
- **去标记化（Detokenization）**：
  - 将 token 映射为码本嵌入 \(\hat{Q}\)，通过求解 ODE \(x_1=x_0+\int_0^1 v_\theta(x_t,t|\tilde{Q}_t)\,dt\) 解码，其中 \(\tilde{Q}_t\) 按条件退火仅保留最后 \(K-\kappa(t)\) 个嵌入。
- **VLA-CATok 集成**：
  - 输入当前图像 \(I_t\)、语言指令 \(l\)、可选本体状态 \(s_t\)，自回归预测 token 序列 \(C\)；
  - 预测 token 映射为 VQ 嵌入，由**冻结的 MMDiT 流匹配解码器**在单步解码中还原连续动作块；
  - VLA 训练时 tokenizer 与解码器冻结，仅更新自回归 VLA 骨干，用 teacher-forced next-token 交叉熵损失；
  - 离散 token 作为唯一接口，**无需显式注意力掩码**即实现知识隔离，避免动作梯度回传污染 VLM 预训练知识，增强指令跟随能力。

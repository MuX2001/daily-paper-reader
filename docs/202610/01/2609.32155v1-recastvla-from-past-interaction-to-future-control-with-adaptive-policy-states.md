## 摘要
序贯操作要求机器人跟踪已经发生的事情，即使当前场景不再揭示它。具有显式历史表示的策略使过往交互可作为当前决策的上下文。我们探究动作生成本身如何为后续控制形成持久状态。基于动作侧测试时训练，RecastVLA 在流匹配视觉-语言-动作策略中维护一个自适应策略状态。该状态由共享快速权重表示，并在整个动作生成过程中保持固定。深度特定接口读取同一状态，而跨深度和流评估的特征共同为下一次策略调用定义一个更新。后续动作损失通过对更早的状态转换进行微分，来训练初始化、接口和更新规则。部署时，更新使用策略自身的动作生成特征，无需专家动作标签。在 LIBERO、RoboTwin、RoboDojo 和十二个真实机器人任务上，RecastVLA 相比未使用测试时训练的匹配策略提高了平均成功率，包括在 RoboTwin Clean-to-Clean 上提高 10.68 个百分点。在受控的 RoboTwin 比较中，保留状态可提高成功率，且共享设计比独立训练的层局部 TTT 高出 2.58 个百分点。

## Abstract
Sequential manipulation requires a robot to track what has already happened, even when the current scene no longer reveals it. Policies with explicit history representations make past interactions available as context for current decisions. We ask how action generation itself can form a persistent state for subsequent control. Building on action-side test-time training, RecastVLA maintains an adaptive policy state within a flow-matching vision-language-action policy. The state is represented by shared fast weights and remains fixed throughout action generation. Depth-specific interfaces read the same state, while features across depths and flow evaluations jointly define one update for the next policy call. Subsequent action losses train the initialization, interfaces, and update rule by differentiating through earlier state transitions. At deployment, updates use the policy's own action-generation features without expert action labels. Across LIBERO, RoboTwin, RoboDojo, and twelve real-robot tasks, RecastVLA improves mean success over a matched policy trained without test-time training, including 10.68 percentage points on RoboTwin Clean-to-Clean. In controlled RoboTwin comparisons, retaining state improves success, and the shared design exceeds independently trained layer-local TTT by 2.58 points.

# RecastVLA 论文总结

## 一、核心问题与整体含义

- **研究动机**：顺序操作中，机器人需要追踪"已经发生了什么"，但当前场景往往无法揭示这些信息（如按钮按与未按几乎无视觉差异、遮挡、部分完成指令）。这类能力被称为**执行记忆（execution memory）**——保留继续当前任务所需信息的功能。
- **背景与问题定位**：现有历史条件化策略（MemoryVLA、MEM、Zeva 等）通过检索观测、压缩上下文或循环表示来提供历史信息，回答的是"过去交互中哪些信息可用于控制"。本文转向一个互补问题：**动作生成本身应如何把过往经验转化为一个持久的策略状态，去引导后续决策**？
- **核心洞察**：动作生成是策略把感知与语言转化为控制决策的环节。生成式动作专家在处理视觉-语言特征与候选动作时，会产生与当前决策紧密相关的信息，这些特征可被用作状态更新的来源。
- **技术脉络**：基于动作侧测试时训练（TTT），尤其是 RoboTTT（在扩散动作专家中学习快权重更新）这一最接近的先例。本文追问：这种专门化计算是否能受益于**联合形成并访问一个公共状态**，而非层局部的独立快权重。

## 二、方法论

### 核心思想
- 在流匹配 VLA 中维护一个**自适应策略状态（adaptive policy state）**，由**跨深度共享的快权重**表示。
- 每次策略调用：读取传入状态 → 生成一个动作块 → 用内部特征更新状态，供下一次调用使用。
- 关键设计：**不同深度以各自的特征坐标读取同一状态**（专门化访问），而**跨深度、跨流评估的特征联合定义一次更新**（联合写入）。因此某一深度写入的信息可以在后续调用中影响其他深度的读取。

### 关键技术细节
- **状态表示**：两层 MLP $f_{W_t}$（256→512→256，GELU 激活），含权重与偏置。
- **策略调用形式**：$(\hat{A}_t, Z_t) = \pi_{\theta,\psi}(o_t, l ; W_t)$，$W_{t+1} = U_\psi(W_t, Z_t)$；所有调用内计算均使用 $W_t$，更新仅影响后续调用；新回合从学习到的初始化 $W_0$ 开始。
- **专门化读取**：动作专家在交叉注意力与自注意力之间交替。访问深度 $j$、流评估 $c$ 处的槽特征 $h_{t,c,j}$ 通过门控残差读取状态：
  $\tilde{h}_{t,c,j} = h_{t,c,j} + \tanh(\gamma_j) P^O_j f_{W_t}(P^Q_j \mathrm{LN}(h_{t,c,j}))$。
  其中 $P^Q_j$ 投影进记忆空间，$P^O_j$ 映射回，$\gamma_j$ 为学习到的标量门。动作 token 绕过状态读取，在下一个自注意力块中与适配后的槽交互。配置：N=32 个槽、宽度 D=768、J=8 个访问点。
- **写入特征**：每个访问点从自注意力后的槽（经 stop-gradient 算子 sg 处理）构造学习到的键/值：
  $k_{t,c,j} = P^K_j \mathrm{LN}(\mathrm{sg}(z_{t,c,j}))$，$v_{t,c,j} = P^V_j \mathrm{LN}(\mathrm{sg}(z_{t,c,j}))$。
- **写入目标**：在 C 个流评估、J 个深度上拟合快模型到键-值关联，由学习到的流时间门 $g_\psi(\tau)$ 和访问点权重 $\alpha_j$（softmax 归一化）加权：
  $L^{\text{write}}_t(W) = \frac{1}{C}\sum_c g_\psi(\tau_{t,c})\sum_j \alpha_j \frac{\|f_W(k_{t,c,j}) - v_{t,c,j}\|^2_F}{NM}$。
- **状态更新**：在传入状态处求值、取单步梯度：$W_{t+1} = W_t - \eta \nabla_W L^{\text{write}}_t(W)|_{W=W_t}$，步长 $\eta = \eta_0 \exp(\rho)$，$\eta_0 = 0.1$，$\rho$ 为学习标量。该转换发生在策略调用边界，因为深度与流评估是同一次动作生成过程的内部计算。
- **训练（从后续控制学习）**：采样同一演示回合的 T=4 帧有序窗口，每帧抽 R 个独立噪声/时间样本构造流匹配输入与速度目标，速度预测器对所有 R 个副本读取同一传入 $W_t$，其特征联合定义一次更新（C=R）。外层动作损失 $\mathcal{L}_{\text{action}}(\Theta)$ 在 $\Theta=(\theta,\psi,W_0)$ 上优化；帧 t+1 的动作损失经更新规则反传到帧 t 的写投影与更新参数，梯度也训练 $W_0$ 及窗口内更早的更新。stop-gradient 保留到键/值投影与快权重更新的梯度，但阻断经写入分支进入源特征的梯度。
- **部署**：策略从高斯动作噪声出发，用 K 次 Euler 评估积分学习到的速度场，全部以 $W_t$ 为条件；这些评估的特征联合定义一次更新（C=K）供下次调用读取。部署**只需对快权重求梯度，不需要专家动作标签**，也不跨调用保留计算图。
- **训练与部署差异**：训练用相邻记录帧，部署按已执行动作块推进。

## 六、主要结论与发现

- **主结果**：RecastVLA 在全部 6 个报告设置上均优于匹配基线：
  - LIBERO 平均 +2.30 分（98.80 vs 96.5），Long +4.40 分（96.40 vs 92.0）；
  - RoboTwin Clean→Clean **+10.68 分**（72.38 vs 61.7），Clean→Random +8.74 分（19.24 vs 10.5），但 C→R 仍显著低于 C→C；
  - RoboDojo Long-Horizon +10.25 分（16.75 vs 6.50），Memory 约 +5.3 分（8.67 vs 3.33）。
- **状态连续性有效**：Full 比 Reset 高 4.68 个百分点（72.38% vs 67.7%）；两者成功试次平均用时相近（约 30%），Full 的 NCS 优势主要来自更少失败。
- **导入经验的效果取决于来源**：Similar 比 Full 高 2.22 分（74.6% vs 72.38%），而 Other 比 Full 低 11.98 分（60.4%），甚至低于 Reset 7.3 分。说明"携带一个已适应的状态"本身并不必然有益——**后续更新未能完全抵消不利的初始化**。
- **共享组织优于层局部**：在每状态 MLP 架构相同的情况下，RecastVLA 比独立训练的层局部 TTT 高 **2.58 个百分点**（72.38% vs 69.8%），且持久状态参数量更少（约 26 万 vs 约 210 万），说明优势并非来自更多状态容量。
- **真实机器人**：RecastVLA 54.58%（131/240）> π0.5 42.50%（102/240）> Matched Base 30.83%（74/240）。相对 π0.5 的优势集中在按钮顺序与重复按压任务（T1–T3，66.67% vs 23.33%），这三项贡献了 29 个净增成功中的 26 个；其余九项 50.56% vs 48.89%，牙刷牙膏、杯口定向与擦拭仍偏向 π0.5。相对 Matched Base，T1–T3 提升 50 分，T4–T12 提升 15 分。
- **失败模式**：多余按钮按压、颜色混叠、杯沿错位、堆叠不稳；T7 中顺序正确但牙刷横在杯沿，说明"保留任务顺序"与"精确放置"是不同能力。

## 七、优点

- **问题切口新颖且明确**：从"历史如何进入上下文"转向"动作生成如何形成持久策略状态"，与既有记忆检索式方法形成互补而非重复。
- **架构设计有原则**：共享状态 + 深度专门化接口 + 跨深度/跨流联合写入，使不同深度的信息可跨调用互相影响；同时以 stop-gradient 与调用边界更新清晰地划分"调用内计算"与"跨调用适应"。
- **训练信号优雅**：通过让后续动作损失穿越早期状态转移，端到端地训练初始化、接口与更新规则；部署阶段只需对快权重求梯度，**无需专家动作标签**，具备实际部署吸引力。
- **消融控制严谨**：Full/Reset、Similar/Other、层局部 TTT 三组对照分别隔离了状态连续性、先验经验来源、跨深度共享三个因素；层局部对照固定了 MLP 架构与更新时序，排除了"参数容量"这一混淆解释。
- **评测维度全面**：仿真三大基准 + 真实双臂平台 12 任务，任务选择有针对性（按钮顺序任务强调弱可观测进度），并配有完整的逐任务成功计数与关键帧行为描述。

## 八、不足与局限

- **统计严谨性不足**：每个设置仅一次运行，未报告多随机种子、置信区间或显著性检验。在 LIBERO 平均 +2.30 分这类差距较小的场景中，是否稳健仍有疑问；RoboTwin C→R 的绝对值（19.24%）较低，说明该场景本身难度很高，方法增益的可靠性需进一步验证。
- **算力信息缺失**：论文未报告 GPU 型号、数量、训练时长与总能耗，难以评估方法的实际训练成本与可复现性门槛；10 万次优化器更新 + Qwen3-VL-4B 骨干的规模暗示开销不低。
- **对照基线的公平性细节**：π0.5 等已发表结果取自原论文，训练数据、预算与超参可能与本文不完全对齐；层局部 TTT 对照由作者自行复现适配，其实现质量会影响"共享优于局部"这一结论的强度。
- **机制分析偏行为层面**：论文主要以成功率与完成步数佐证状态有效性，缺少对"状态中究竟编码了什么"的直接探针（如线性探测、状态空间可视化、状态扰动实验），因此对"动作侧 TTT 形成持久策略状态"这一核心主张的机理证据仍属间接。
- **导入经验的适用边界不清**：Similar 有益、Other 有害，但论文未给出如何判断或选择"相似源"的可操作准则，也未测试多源混合、部分相似或渐进式导入等更实际的迁移场景。
- **真实机器人规模有限**：55 个训练任务、每任务 10 条演示、12 个评估任务、每策略 240 试次，样本量偏小；任务族覆盖虽广但每族任务数不多，结论向更复杂长程任务的泛化性有待检验。
- **失败模式未系统归因**：多余按压、颜色混叠、杯沿错位等失败被列举，但未分析其与状态设计（访问点数量、更新步长、流时间门）的因果关系，缺少针对性的诊断实验。
- **超参与架构敏感性未知**：访问点 J=8、槽数 N=32、步长 η₀=0.1、Euler 步数 K 等关键量的消融未系统报告，读者难以判断方法的鲁棒区间。

## 九、启示与未来方向

- **动作生成作为记忆载体**：本文提示，记忆不必外挂于上下文或独立模块，动作专家的内部计算本身即可承载并沉淀任务进度，为 VLA 的记忆设计提供了新范式。
- **共享状态的组织原则**：跨深度共享 + 专门化读写的结构，可能在更长程任务、多模态输入或更大模型上进一步放大收益，值得在状态容量与共享粒度的权衡上继续探索。
- **可操作的经验导入准则**：如何度量源任务与目标任务的"相似度"，并据此决定是否预热状态，是让该方法落地的重要一步。
- **与显式记忆方法融合**：RecastVLA 的隐式持久状态与 MemoryVLA 等检索式方法并非互斥，二者结合（显式检索提供长程事实、隐式状态提供即时进度）可能是自然的下一步。
- **部署阶段的持续适应**：无需标签即可更新，为真实环境中的在线漂移适应、多回合累积学习打开了空间，但需警惕状态被错误经验污染的风险（Other 条件已给出警示）。

## 十、总体评价

RecastVLA 从"动作生成如何形成持久策略状态"这一互补视角切入，用共享快权重、深度专门化读取与跨深度/跨流联合写入的架构，把测试时训练从层局部的快权重更新提升为策略级的统一状态。方法在三大仿真基准与真实双臂平台上一致优于匹配基线，并在受控消融中显示：状态连续性带来实质增益、共享组织优于层局部（且状态参数更少）、导入经验的效果强依赖来源。其优势在于问题切口新颖、训练信号优雅（部署无需专家标签）、消融控制严谨且敢于呈现负向结果；主要不足在于统计重复与显著性检验缺失、算力信息未披露、机理证据偏行为层面，以及真实机器人样本规模有限。总体而言，这是一项在"记忆式 VLA"方向上具有明确贡献与启发性、但统计与机理层面仍需补强的工作。

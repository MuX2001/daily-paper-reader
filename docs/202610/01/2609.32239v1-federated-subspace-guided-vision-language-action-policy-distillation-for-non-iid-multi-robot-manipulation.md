## 摘要
联邦学习为多个机器人联合改进操作策略提供了一种自然方式，无需集中访问训练示范。然而，非独立同分布（non-IID）的任务和环境分布会导致表示漂移以及彼此不兼容的机器人策略更新，使得朴素参数聚合具有破坏性。我们提出 FedDRMan，一种面向异构机器人操作的联邦子空间引导蒸馏框架。在每轮通信中，服务器模型提供一个冻结教师用于本地行为克隆，同时低秩多模态子空间和动作分布蒸馏保留全局有用的表示几何与策略行为。为解决异构聚合问题，FedDRMan 根据更新兼容性对客户端进行分组，并为每个簇维护一个持久模型。随后，服务器对每个兼容聚合进行谱重平衡，以缓解较弱的任务相关机器人策略更新方向被衰减。在 LIBERO 上跨多种非IID设置、异构程度、客户端参与变化的大量实验，以及消融和聚合分析表明，FedDRMan 显著提升了知识迁移，并持续优于强联邦基线，峰值平均成功率达到 80.7%，比最强评估联邦基线高出 11.6 个百分点。

## Abstract
Federated learning offers a natural way for multiple robots to jointly improve manipulation policies without requiring centralized access to training demonstrations. However, non-IID task and environment distributions can induce representation drift and mutually incompatible robot-policy updates, making naive parameter aggregation destructive. We present FedDRMan, a federated subspace-guided distillation framework for heterogeneous robot manipulation. At each communication round, the server model provides a frozen teacher for local behavior cloning, while low-rank multimodal subspace and action-distribution distillation preserve globally useful representation geometry and policy behavior. To address heterogeneous aggregation, FedDRMan groups clients by update compatibility and maintains a persistent model for each cluster. The server then spectrally rebalances each compatible aggregate to mitigate attenuation of weaker task-relevant robot-policy update directions. Extensive experiments on LIBERO across diverse non-IID settings, heterogeneity levels, client participation variation, together with ablations and aggregation analyses, show that FedDRMan substantially improves knowledge transfer and consistently outperforms strong federated baselines achieving a peak mean success rate of 80.7%, 11.6 percentage points above the strongest evaluated federated baseline.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：VLA（Vision-Language-Action）策略（如 RT-2、OpenVLA-OFT）在语言条件下的机器人操作中取得显著进展，但其训练普遍依赖大规模、可集中汇聚的机器人数据集（如 Open X-Embodiment）。这种"集中式汇聚原始轨迹"的假设在真实多机器人系统中代价高昂：通信开销大，且会泄露用户、机器人位置、运行环境与部署细节等敏感信息。
- **联邦学习的契合性**：FL 允许各机器人仅交换模型更新而非原始演示，天然适合多机器人协同训练共享策略。
- **核心矛盾（non-IID）**：各机器人的任务族、场景、视角、状态-动作分布差异巨大（例如一个机器人主要做以物体为中心的抓取放置，另一个做不同场景下的目标条件任务），导致：
  - **表征漂移**：本地行为克隆（BC）会把视觉、语言、本体感觉表征推向客户端特有的特征分布；
  - **更新不兼容**：不同客户端的策略更新方向相互冲突，朴素参数平均（FedAvg）会抑制任务相关知识，甚至产生破坏性聚合。
- **研究空白**：现有异构 FL 工作多针对单模态/非机器人场景；知识蒸馏与子空间/谱模型融合技术主要面向序贯学习或一次性集中式模型合并；FLAME 只是基准，FedVLA 的异构处理与 MoE 专家路由强耦合。**"本地适配中的多模态表征漂移"与"服务器聚合中的更新冲突"这两类耦合效应，在任务与环境异构下仍缺乏系统研究。**
- **整体含义**：FedDRMan 提出一个几何感知的联邦蒸馏 + 结构化聚合框架，在不增加通信量的前提下同时治理"本地漂移"和"聚合干扰"两个耦合难题。

## 2. 方法论

### 2.1 问题形式化
- K 个机器人在共享的语言条件操作设定下协作，形式化为有限时域 MDP：M = (S, A, T, H, μ₀, φ)，φ 为稀疏成功谓词。
- 每个客户端 k 拥有私有演示集 D_k，观测 o 包含 agent-view RGB、腕部 RGB、关节状态、夹爪状态；语言指令 D；动作为连续 7 维。
- 目标为加权经验风险最小化：min_θ Σ_k p_k · E_{(o,D,a)~D_k}[L_k(θ)]，p_k = n_k / Σ_j n_j。

### 2.2 核心思想
在每个通信轮：
1. 服务器模型作为**冻结教师**，本地学生以 BC 适配本地数据；
2. 用**低秩多模态子空间蒸馏 + 动作分布蒸馏**约束本地漂移；
3. 服务器按**更新兼容性聚类**客户端，维护 C 个持久簇模型；
4. 对每个兼容聚合做**谱重平衡（SRB）**，恢复被平均削弱的任务相关更新方向。

### 2.3 关键技术细节

**（a）联邦子空间引导的全局到本地蒸馏**
- 教师与学生同源于服务器模型 θ^r_g，教师冻结：θ̄^r_g ← θ^r_g，∇θ̄^r_g = 0。
- 本地 BC 损失：L_BC(θ_k) = −E[log π_θk(a | o, D)]。
- 对每个模态 m ∈ {text, agent, wrist, joint, gripper}，将批-时间编码器特征堆叠为 F^m_x ∈ R^{d_m×N}（N = BT，x ∈ {g, k} 表示教师/学生），做降秩 SVD 得秩 r_m 的正交投影子 P^m_{x,r} = U_{x,r}(U_{x,r})ᵀ（SVD 前加小扰动保证数值稳定）。
- **对称子空间蒸馏损失**：
  L^m_sub = ‖P_g F_g − P_k F_k‖²_F + ‖P_g F_k − P_k F_g‖²_F
  第一项对齐教师/学生子空间保留的特征内容，第二项强制对称交叉投影一致性——保留主导表征几何，但**不要求逐坐标特征对应**。
- **动作蒸馏损失**：从教师采样 â ~ π_θ̄(·|o,D)，用
  L_act = E[log π_θ̄(â|o,D) − log π_θk(â|o,D)]（log 概率做数值截断）。
- 总损失：L_k = L_BC + Σ_m λ_m L^m_sub + λ_act L_act；梯度只回传学生，教师固定。

**（b）兼容谱联邦聚合（CUA + SRB）**
- **兼容更新聚合（CUA）**：以"相对共同初始化的累积更新"刻画兼容性——
  Δ^r_k = θ^r_k − θ^0，v^r_k = vec(Δ^r_k|_Ω)（Ω 为共享子模块，本工作取时间 Transformer），
  S^r_ij = ⟨v^r_i, v^r_j⟩ / (‖v^r_i‖‖v^r_j‖)。
  采用累积更新而非逐轮增量，是因为前者信号更稳定（增量会逐渐变小）。
  划分目标：最大化簇内平均相似度、最小化簇间平均相似度，将客户端分成 C 个非空组。
  簇内样本权重重新归一化后聚合完整本地模型：θ^{r+1}_{avg,s} = Σ_{k∈G_s} p̃_k θ^r_k，Δ^r_s = θ^{r+1}_{avg,s} − θ^r_s。
- **谱重平衡（SRB）**：对合格的二维权重块做 SVD：Δ^r_{s,b} = UΣVᵀ。由累积奇异值阈值 β ∈ [0,1] 确定截断位置 c* = min{i : Σ_{j≤i}σ_j / Σ_j σ_j ≥ β}，再做 σ̃_i = max(σ_i, σ_{c*})，重建 Δ̃ = UΣ̃Vᵀ。
  作用范围：图像空间投影器、语言与本体感觉编码器、时间 Transformer、策略头中的线性权重矩阵；其余参数保留簇内平均更新。
- 服务器跨轮跟踪客户端-簇分配；下一轮各客户端下载所属簇模型初始化。**聚类与 SRB 全部在服务器端完成，不增加相对 FedAvg 的模型载荷。**

**（c）理论解释**
- 将本地偏离分解为簇内共享分量 C^r_s 与机器人特有分量 U^r_k。若 U^r_k 两两正交且 ‖U^r_k‖_F ≤ B，则聚合后特有分量的平方幅度
  ‖Σ_k p_k U^r_k‖²_F = Σ_k p²_k ‖U^r_k‖²_F ≤ B² / K_eff,s，
  即 Frobenius 范数以 O(K_eff^{-1/2}) 衰减。
- 一般情形含交叉项 2Σ_{i<j} p_i p_j ⟨U_i, U_j⟩_F，**簇内正相关可保留相干更新能量**。CUA 促进兼容性（增大正交叉项），SRB 再增强被削弱的谱方向。

## 3. 实验设计

- **数据集 / 场景**：LIBERO 三个标准套件——LIBERO-Spatial、LIBERO-Object、LIBERO-Goal。每套件 10 个语言条件操作任务、每任务 50 条专家演示；构建序列后分别约 62,250 / 74,507 / 63,728 条训练序列。每个样本含两个 RGB 观测、语言指令、本体感觉状态与 7 维连续动作序列。
- **Non-IID 构造**：
  - 同套件任务 non-IID：K=5，Dirichlet 分布 α=0.5（默认）划分任务序列，同时引入任务与数量偏斜，同一套件内各方法共用同一划分。
  - 跨套件任务与环境 non-IID：Object-Goal / Object-Spatial / Goal-Spatial 各 K=4（每套件 2 客户端）；三套件 Object-Goal-Spatial 为 K=6。跨套件同时叠加"套件内 non-IID"与"套件间任务族/物体/环境/状态-动作分布差异"两层异构。
- **Benchmark 与评价**：闭环 MuJoCo rollout，250 步时域，主指标为任务成功率（SR）。每 5 轮用每任务 10 次 rollout 做检查点选择，最终用每任务 20 次随机 rollout 报告结果，所有结果取 3 个随机种子平均。
- **策略架构**：LIBERO ResNet-T（ResNet 视觉编码器 + FiLM 语言条件 + 预训练 BERT 嵌入 → 时间 Transformer → GMM 动作头），参数量 5.38M，通信量 21.53 MB。
- **对比基线**：Centralized BC（集中式 BC 上界）、Local BC（纯本地）、FedAvg、FedProx（μ=10⁻³）、FedKD（FedKD-A 自适应互蒸馏）、FedVLA（双门控 MoE + 专家驱动聚合，改用 GMM NLL 目标以公平匹配动作分布建模）。所有方法使用相同客户端划分与评估协议。
- **超参**：每轮 1 个本地 epoch，batch size 32，50 轮通信，AdamW（lr 1e-4，weight decay 1e-4，梯度裁剪 100）。子空间损失秩固定 48、蒸馏权重 1.0、SVD 稳定噪声 std 0.01；语言/视觉/本体感觉模态权重 0.03，动作蒸馏 0.005。C=1（同套件）、C=2（两两跨套件）、C=3（三套件）；β 按套件设置（0.85–0.90）。

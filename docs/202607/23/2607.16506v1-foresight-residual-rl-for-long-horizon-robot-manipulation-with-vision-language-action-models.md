## 摘要
视觉-语言-动作（VLA）策略提供了强大的通用操作先验，但在公差严格、接触密集的装配任务中常常失败，原因是长时域信用分配和子任务耦合：当前技能在几何上成功的状态可能对后续技能来说是脆弱的。我们在冻结的VLA基础策略上展示了残差强化学习（RL）中的这种失败模式：恒定的稀疏成功奖励孤立地改善每个子任务，但当技能链式执行时几乎没有增益，因为终端状态质量不受控制。我们提出远见残差RL，通过为每个子任务的稀疏成功奖励添加离线估计的远见值——即当前子任务终端状态下未来子任务成功的概率——来优化交接质量。具体来说，我们（i）从基础策略的终端状态图像中训练一个视觉远见预测器，并使用下游rollout统计数据标注；（ii）通过反向远见归纳训练残差策略，将预测器输出作为奖励乘数。在Isaac Gym中的三相扳手式螺母拧紧装配任务（抓取、移动插入、旋转）上，我们的方法实现了85.6%的全任务成功率，优于标准子任务残差RL（54.5%）和VLA基线，同时保持每个子任务的成功率不变。这些结果强调，提高长时域性能需要塑造每个子任务产生哪些成功状态，而不仅仅是是否发生成功。

## Abstract
Vision-Language-Action (VLA) policies offer strong general-purpose manipulation priors, but often fail on tight-tolerance, contact-rich assembly due to long-horizon credit assignment and subtask coupling: a state that is geometrically successful for the current skill can be brittle for downstream skills. We show this failure mode in residual reinforcement learning (RL) over a frozen VLA base policy: constant sparse success rewards improve each subtask in isolation yet yield little or no gain when skills are chained, because terminal state quality is uncontrolled. We propose Foresight Residual RL, which optimizes handoff quality by augmenting each subtask's sparse success reward with an offline-estimated foresight value -- the probability of future subtask success conditioned on the terminal state of the current subtask. Concretely, we (i) train a visual foresight predictor from images of terminal states of the base policy, labeled using downstream rollout statistics, and (ii) train residual policies via backward foresight induction, using the predictor output as a reward multiplier. On a three-phase wrench-based nut-tightening assembly task in Isaac Gym (grasp, move-insert, rotate), our method achieves 85.6% full-task success, outperforming standard subtask residual RL (54.5%) and VLA baselines, while leaving per-subtask success unchanged. These results highlight that improving long-horizon performance requires shaping which successful states are produced at each sub-task, not only whether success occurs.

## 1. 论文的核心问题与整体含义

- **研究动机**：视觉-语言-动作（VLA）模型在通用操作中表现出色，但在长时域、高精度、接触密集的装配任务（如用扳手拧紧螺母）中却常常失败。作者指出失败根源在于**子任务之间的因果耦合**：当前子任务的成功状态（如“成功抓取”）虽然在几何上满足该子任务的成功谓词，但可能对后续子任务（如插入、旋转）来说是脆弱的。例如，一个姿势不好的抓取虽然成功抓起了扳手，但导致后续插入极易失败。
- **现有方法的不足**：标准实践是将任务分解为若干子任务，分别训练策略再串联。但标准残差强化学习（Residual RL）使用恒定的稀疏成功奖励，将所有成功终端状态视为等价的，而实际上“什么样的成功状态”决定了后续任务能否成功。独立优化子任务成功率无法转化为全任务性能提升。
- **核心问题**：如何优化子任务终端状态的质量（即其对后续任务成功的贡献），而不是仅仅优化子任务是否成功。

## 2. 论文提出的方法论

- **核心思想**：提出 **Foresight Residual RL（远见残差强化学习）**，通过为每个子任务训练一个**视觉远见预测器**，估计当前子任务终端状态导致后续子任务成功的概率，并将该预测值作为稀疏成功奖励的乘数，从而引导残差策略产生对下游更友好的终端状态。
- **关键技术细节**：
  - **残差策略公式**：最终动作 \( a_t = \pi_k^0(o_t) + \alpha \cdot \pi_k^{res}(o_t) \)，其中 \(\pi_k^0\) 是冻结的 VLA 基础策略，\(\pi_k^{res}\) 是训练的小幅度修正策略，\(\alpha\) 为小常数（文中取 0.1）。
  - **远见值函数定义**：\( V_{k+1:K}(s) \) 表示从状态 \( s \) 开始，使用下游策略 \(\pi_{k+1:K}\) 获得的未来最终阶段成功期望。该函数刻画了当前终端状态对未来成功的影响。
  - **局部远见值函数**：用 \( V_{k+1:K}(s) \) 乘子任务成功奖励 \(\beta_k(s)\)，形成新的学习目标。
  - **训练流程（反向归纳）**：
    1. 从最后一个子任务（旋转）开始训练，不需要远见。
    2. 依次向前训练每个子任务：收集基础策略 \(\pi_k^0\) 的 \(N\) 个成功终端状态；对每个状态，执行 \(K_{rep}\) 次下游策略 \(\pi_{k+1}\) 的 rollout，记录成功次数；训练一个神经网络预测器 \(p_\phi\)（基于 DINOv2 + LoRA），以终端图像为输入，输出成功概率。
    3. 训练残差策略时，奖励函数为 \( r_t = \beta_k(s_{t+1}) \cdot p_\phi(o_{t+1}) \)。
  - **预测器训练目标**：二项负对数似然损失，尊重标签的计数结构。
- **核心优点**：离线训练预测器避免了在线 rollout 的高方差和计算开销；小残差幅度限制分布漂移，保证预测器在训练中有效。

## 3. 实验设计

- **任务与场景**：在 **NVIDIA Isaac Gym** 模拟器中实现的**扳手-螺母装配任务**。包含三个因果耦合的子任务：**Grasp（抓取，160步） → Move-Insert（移动插入，200步） → Rotate（旋转，200步）**。总最大步数 560，控制频率 20Hz。环境随机化包括初始位姿、5种扳手-螺母尺寸（间隙小于2mm），要求亚毫米精度。
- **基准与对比方法**：
  - **π0（端到端）**：直接用 π0 策略执行全任务。
  - **π0（链式）**：分别用 π0 子任务策略串联执行。
  - **π0 + 标准残差 RL**：每个子任务用恒定稀疏成功奖励训练残差策略。
  - **π0 + 远见残差 RL（本文方法）**：使用远见预测值调制的奖励。
- **训练数据**：每个子任务收集 2,560 条专家演示（使用状态机专家，可利用真实物体位姿），然后微调 π0 得到基础策略。

## 6. 论文的主要结论与发现

1. **标准残差 RL 的失败模式**：虽然在 orical 初始化下子任务成功率大幅提升（如插入从 45.7% 提升至 92.2%），但链式全任务成功率仅 54.5%，与端到端 π0（54.9%）相当，毫无增益。这表明**独立优化子任务成功率不能转化为链式性能提升**。
2. **终端状态质量是关键**：标准残差 RL 虽然提高了抓取成功率，但抓取终端状态的远见预测得分从 0.64 下降至 0.32，说明它找到了更多“几何成功但对插入不利”的抓取状态。远见残差 RL 将得分提升至 0.73，实现了 85.6% 的全任务成功率，比标准残差 RL 高出 31.1%。
3. **远见预测器有效**：预测器的分类准确率高于多数类基线，证明其能够区分不同质量的终端状态。
4. **定性验证**：图 3 显示，远见残差产生的抓取具有更好的角度对齐，插入更稳定，从而成功完成旋转。

## 7. 优点

- **方法创新性**：将“远见值”（未来成功概率）引入残差 RL 的奖励设计，直接优化终端状态质量而非分布匹配等代理目标，理论上有据可依（与 MAXQ 的完成函数对应）。
- **实用性**：采用离线训练预测器+反向归纳的训练范式，避免了在线 rollout 的高负担，并与现有的 VLA 基础策略兼容（只需微调残差，基础策略冻结）。
- **实验设计透彻**：不仅报告全任务成功率，还分析了终端状态质量变化，解释了为何标准方法失败，验证了所提方法的作用机制。
- **代码开源**：提供了项目网站，有助于复现。

## 摘要
通过行为克隆（BC）在机器人演示上微调预训练的视觉-语言模型（VLM）已成为视觉-语言-动作（VLA）策略的标准方法。然而，BC微调会逐步覆盖支持视觉和语义泛化的预训练表示。一种常见的补救措施是在网络图像-文本数据上进行协同训练，但这并不能阻止该问题；它将语言和动作损失应用于不同的观测，导致VLA存在语言-动作不对齐，而标准的操作基准无法暴露这一问题。我们提出Anchor-Align，它在BC基础上增加了两个目标：视觉-语言锚定从冻结的VLM副本中蒸馏逐层表示以防止这种漂移；语言-动作对齐将每个动作目标转换为离散的运动方向标签，并在同一机器人观测上联合训练语言和动作预测。在物理xArm7机器人上，跨越两种广泛使用的VLA架构，Anchor-Align在实际机器人成功率上均有提升（从28%到54%和从37%到60%）。在仿真大规模实验中，我们在LIBERO-PRO、LIBERO-Plus和CALVIN上分别展示了在OOD扰动、感知鲁棒性和长时域控制方面的一致改进，表明保留预训练表示与有效动作学习并非根本对立。项目页面：anchoralignvla.github.io

## Abstract
Finetuning a pretrained vision-language model (VLM) on robot demonstrations via behavior cloning (BC) has become the standard recipe for vision-language-action (VLA) policies. However, BC finetuning progressively overwrites the pretrained representations that support visual and semantic generalization. Co-training on web image-text data, a common remedy, does not prevent this; it applies language and action losses to separate observations, leaving VLAs with language-action misalignment that standard manipulation benchmarks do not expose. We propose Anchor-Align, which augments BC with two objectives: Vision-Language Anchoring distills layer-wise representations from a frozen VLM copy to prevent this drift, while Language-Action Alignment converts each action target into a discrete motion-direction label and jointly trains language and action prediction on the same robot observation. On a physical xArm7 robot, across two widely used VLA architectures, Anchor-Align improves real-robot success on both (28% to 54% and 37% to 60%). At scale in simulation, we demonstrate consistent improvements on OOD perturbations, perceptual robustness, and long-horizon control across LIBERO-PRO, LIBERO-Plus, and CALVIN, respectively, suggesting that preserving pretrained representations and effective action learning are not fundamentally at odds. - **整体含义**：论文旨在解决VLA微调中泛化能力下降的根源问题，主张保留预训练表征与学习有效动作并非不可兼得，并提出一种新的微调范式来同时实现这两个目标。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：在标准的BC微调基础上，增加两个关键目标——**视觉-语言锚定**和**语言-动作对齐**，从而在不牺牲动作学习能力的前提下，保留并巩固预训练模型的通用表示。
- **方法名称**：Anchor-Align
- **关键技术细节**：
    - **视觉-语言锚定**：
        - 目标：防止微调过程中模型表示发生灾难性漂移。
        - 实现：在微调过程中，引入一个**冻结的VLM副本**（冻结模型）。对每个机器人观测，计算当前（可训练）模型与冻结模型之间**逐层特征表示**的蒸馏损失（如均方误差或KL散度）。这迫使当前模型的表示空间始终“锚定”在预训练模型所代表的通用视觉和语义表示附近。
    - **语言-动作对齐**：
        - 目标：解决标准联合训练中语言和动作目标在不同观测上训练导致的错位问题。
        - 实现：对于**同一机器人观测**，同时进行两项任务：
            1.  **动作预测**：预测机器人的连续动作（标准BC）。
            2.  **语言标签预测**：将每个连续动作目标转换为一个**离散的运动方向标签**（如“向左移动”，“向上移动”，“夹爪闭合”等）。模型需基于同一观测同时预测该动作和该动作对应的语言标签。
        - 好处：这迫使模型将动作输出与语言理解紧密耦合，在一个共同的表示空间内进行推理，从而实现语言-动作对齐。
- **公式与算法流程说明**：
    1.  **输入**：机器人观测图像 \(o_t\)，语言指令 \(l_t\)，动作目标 \(a_t\)。
    2.  **前向传播**：
        - 可训练VLA模型对 \((o_t, l_t)\) 进行编码，输出动作预测 \(a_{pred}\) 和特征层 \(f_i\)。
        - 冻结VLM副本对相同观测 \((o_t, l_t)\) 编码，输出特征层 \(f_i^{frozen}\)。
        - 将动作目标 \(a_t\) 转换为离散标签 \(y_t^{lang}\)。
    3.  **损失计算**：
        - **动作损失**：\(L_{bc} = \text{MSE}(a_{pred}, a_t)\)
        - **锚定损失**：\(L_{anchor} = \sum_i \text{dist}(f_i, f_i^{frozen})\) （蒸馏当前层表示至冻结层表示）
        - **对齐损失**：\(L_{align} = \text{CE}(\text{Head}_{lang}(f), y_t^{lang})\) （对观测特征头进行语言标签分类）
    4.  **总损失**：\(L_{total} = L_{bc} + \alpha L_{anchor} + \beta L_{align}\)

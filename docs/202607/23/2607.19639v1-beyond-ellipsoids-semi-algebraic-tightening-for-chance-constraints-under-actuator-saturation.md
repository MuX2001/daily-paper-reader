## 摘要
受随机模型预测控制应用的启发，我们提出了一种半代数方法来处理带有无界加性扰动和饱和输入的几率约束系统的约束紧缩问题。饱和误差动态通过其精确的分段仿射结构来处理，该结构自然地适应非对称饱和界限。然后使用平方和优化设计满足漂移条件的多项式李雅普诺夫函数，得到有限时间概率可达集和概率终极界。针对约束紧缩显式优化了集合几何形状，进一步减少了保守性。数值示例证明了该设计的有效性。

## Abstract
Motivated by stochastic model predictive control applications, we present a semi-algebraic approach to constraint tightening for chance-constrained systems with unbounded additive disturbances and saturated inputs. The saturated error dynamics are handled via their exact piecewise-affine structure, which naturally accommodates asymmetric saturation bounds. A polynomial Lyapunov function satisfying a drift condition is then designed using sum-of-squares optimization, yielding finite-time probabilistic reachable sets and a probabilistic ultimate bound. The set geometry is explicitly optimized for constraint tightening, further reducing conservatism. A numerical example demonstrates the effectiveness of the design.

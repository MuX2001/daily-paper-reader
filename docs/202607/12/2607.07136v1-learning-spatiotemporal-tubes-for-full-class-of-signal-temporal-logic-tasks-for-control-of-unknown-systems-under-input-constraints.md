## 摘要
本文提出了一种基于时空管（STT）的控制框架，用于受输入约束的一般未知非线性欧拉-拉格朗日（EL）系统，目标是满足信号时态逻辑（STL）规范，其中系统轨迹限制在STT内保证了相应STL任务的满足。对于单智能体和多智能体场景，每个智能体对应的STT被建模为一个时变球，其中心和半径使用物理信息神经网络（PINN）联合参数化。与智能体对应的STL规范相关的鲁棒性度量作为损失函数纳入训练过程，使学习到的管能够编码任务级时间要求。对于多智能体场景，我们引入了对应于全局任务的额外鲁棒性度量，当其满足时，确保管之间不发生碰撞。为了确保系统轨迹保持在学习的STT内，从而满足局部和全局STL规范，我们提出了一种明确考虑输入约束的控制策略。特别是，开发了一种闭环控制律，使轨迹保持在管内，同时通过根据系统输入约束施加管演化的界限来调节管的运动。所提出的方法已在多个案例研究中得到验证。

## Abstract
This paper presents a Spatiotemporal Tube (STT)-based control framework for general unknown nonlinear Euler-Lagrange (EL) systems subject to input constraints, with the objective of satisfying Signal Temporal Logic (STL) specifications, where confinement of the system trajectory within the STT guarantees the satisfaction of the corresponding STL task. For both single and multi-agent scenarios, the STT corresponding to each agent is modeled as a time-varying ball, whose center and radius are jointly parameterized using a physics-informed neural network (PINN). The robustness metric associated with the STL specification corresponding to the agents is incorporated into the training process as a loss function, enabling the learned tube to encode task-level temporal requirements. For a multi-agent scenario, we introduce an additional robustness metric corresponding to the global task, which, when satisfied, ensures the tubes do not collide with each other. To ensure that the system trajectory remains within the learned STT and thereby satisfies the local and global STL specifications, we propose a control strategy that explicitly accounts for input constraints. In particular, a closed-form control law is developed to keep the trajectory inside the tube while regulating the motion of the tube by enforcing bounds on its evolution depending on the input constraints of the system. The proposed approach has been validated over several case studies.

### 1. 论文的核心问题与整体含义（研究动机和背景）

*   **核心问题**：现代控制应用（如机器人、无人机）需要满足复杂的、随时间变化的任务规范（如“在30秒内到达A点，同时避开动态障碍物”）。信号时态逻辑（STL）为此提供了形式化语言，但现有控制方法存在局限性：
    *   **基于优化的方法**（如混合整数规划MIP、模型预测控制MPC）：计算复杂，难以扩展到复杂任务和高维系统。
    *   **符号控制**：受“维度灾难”影响。
    *   **控制屏障函数（CBF）**：通常只能处理STL的片段，且需要精确的系统模型。
    *   **预设性能控制（PPC）**：同样只能处理STL片段。
    *   **现有时空管（STT）框架**：虽能处理完整STL，但需要预定义管模板，灵活性受限，且未考虑**输入约束**，这在现实系统中不切实际。
*   **整体含义**：本文旨在为**未知动力学模型**的**欧拉-拉格朗日（EL）系统**，在**存在输入约束**的条件下，设计一种能**自动**学习并**保证**满足**完整STL规范**的控制框架。将复杂的时序逻辑任务转化为一个易于处理的几何约束（即系统轨迹始终处于一个时变球体内）问题。

### 2. 论文提出的方法论

*   **核心思想**：
    1.  **STL满足 -> 几何约束**：定义一个时变球体（时空管， STT），如果系统轨迹能始终约束在这个球体内，那么该轨迹就满足给定的STL规范。
    2.  **学习STT**：使用**物理信息神经网络（PINN）** 来参数化这个时变球的中心 `c(t)` 和半径 `r(t)`。
    3.  **控制**：设计一个**闭环、无模型**的控制律，在**输入约束**下强制系统轨迹停留在学习到的STT中。
*   **关键技术细节**：
    *   **STT建模**：STT `Γ(t)` 被建模为一个时变球 `B(c(t), r(t))`。中心的演化速率和半径的变化率被限制在用户定义的Lipschitz常数 `Lc` 和 `Lr` 内，以确保平滑性。
    *   **PINN训练**：
        *   **损失函数**：将STL的**鲁棒性度量** `ρφ(x)` 直接作为损失函数的一部分，要求管内所有信号对应的鲁棒性都为正。
        *   **物理约束**：通过自动微分，将 `c(t)` 和 `r(t)` 的Lipschitz有界性作为正则化项（`L3`, `L4`）加入损失，确保STT在时间上的平滑变化，为后续在输入约束下的控制提供了可行性条件。
        *   **样本采集**：在连续时空域上采样有限的“配点”（collocation points）进行训练，并通过Lipschitz条件进行形式化验证，保证对连续域的覆盖。
    *   **控制器设计**（两步法，类反步法）：
        *   **Stage I (速度层)**：设计参考速度 `vr(t)`，其核心是一个指向管中心的吸引项，当轨迹接近管边界时，它会强制轨迹向中心回拉。
        *   **Stage II (加速度层)**：设计一个闭环控制律 `τ(t) = -diag(Ψ(εv)) τ̄`，利用有界变换函数`Ψ`和漏斗约束（funnel），确保速度跟踪误差 `ev(t)` 被限制在容许范围内，从而保证实际控制输入始终满足 `|τ(t)| ≤ τ̄`。

3.  **鲁棒性**：在机械臂的负载变化和外部扰动实验中，方法保持了良好的性能，控制输入始终在界限内，验证了对未知动态和扰动的鲁棒性。
4.  **系统性能**：与现有STT方法相比，PINN在复杂任务下的离线计算效率更高；与CBF、MILP等方法相比，在相同的任务下，所需的**控制输入更小**，更节能。

### 7. 优点

1.  **支持完整STL**：这是少数能处理**完整**STL规范的框架之一，比CBF, PPC等方法更具表达力。
2.  **无需系统模型**：方法完全**无模型**，仅利用系统参数的已知边界信息，对实际未知系统非常友好。
3.  **显式处理输入约束**：在设计控制律和推导可行性条件时，明确将输入饱和纳入考虑，解决了现有STT方法的重大缺陷。
4.  **计算高效**：将主要计算负担放在离线训练的PINN上，在线控制是闭式解，微秒级的计算速度非常适合资源受限的嵌入式系统。
5.  **形式化保证**：通过Lipschitz条件，提供了在连续时间域上的形式化验证，其保证强度高于纯数据驱动方法。

### 8. 不足与局限

1.  **连续确定性系统**：论文专为确定性EL系统设计，未涵盖**随机系统**或**混合系统**。
2.  **假设强**：方法依赖于假设1-4（扰动有界、逆惯性矩阵有下界等），这些界限的准确先验知识在实际中可能难以获得，界的不准确可能导致可行性条件不成立。
3.  **统计评估缺失**：实验缺乏统计性的重复和验证（如多次运行报告均值和方差），无法评估方法对不同初始条件、随机种子或训练过程的鲁棒性。
4.  **消融实验不充分**：没有对PINN的各个损失项（`L1-L4`）进行详细的消融分析，以验证每个组件的作用。例如，Lipschitz正则化 (`L3, L4`) 对最终控制性能和可行性的具体影响没有被量化。
5.  **动态环境**：论文主要针对**静态障碍物**。虽然多智能体实验考虑了动态障碍（其他智能体），但没有测试环境本身发生未知、剧烈变化的情况。

## 摘要
视觉-语言-动作（VLA）模型旨在将多模态输入映射到机器人动作。然而，由于大多数现有方法均匀处理所有视觉令牌并使用人工选择的因素进行推理，缺乏强调任务关键证据的机制并忽略潜在因素，因此难以覆盖复杂的动态场景。为解决这一问题，我们提出了LEEVLA，一种关注潜在环境进化中关键信息的VLA架构，明确引导模型关注信息区域，同时保留潜在世界表征的结构化进化。为了识别显著且与指令相关的区域，我们引入了漂移引导动态优先级（DGDP），它结合了动态位置优先级（DPP）和语义漂移引导（SDG），以在训练过程中引导VLA智能体关注何处。在此基础上，我们引入了结构化特征流生成（SFFG），通过原型到外围（P2P）预测建模这些优先级特征如何在潜在空间中进化，并采用互邻域对比（MC）损失以维持邻域间的拓扑一致性。DGDP和SFFG共同构成了任务感知的“何处-如何”训练框架。在VLA基准上的广泛实验表明，LEEVLA始终优于先前方法，证实了显式的任务证据引导和结构化的潜在推理对于可扩展的VLA至关重要。我们的代码开源在https://github.com/LyuQi127/LEEVLA。

## Abstract
Vision-language-action (VLA) models aim to map multimodal inputs to robot actions. However, most existing approaches struggle to cover complex dynamic scenarios due to treating all visual tokens uniformly and reasoning with human-selected factors, which lack mechanisms to emphasize task-critical evidence and ignore underlying factors. To address this issue, we propose LEEVLA, a VLA architecture for seeing what matters in Latent Environment Evolution that explicitly guides the model toward informative regions while preserving the structured evolution of latent world representations. To identify salient and instruction-relevant regions, we introduce drift-guided dynamic prioritization (DGDP), which combines dynamic position prioritization (DPP) with semantic drift guidance (SDG) to guide the VLA agent where to attend during training. On top of this, we introduce structured feature flow generation (SFFG), which models how these prioritized features should evolve in latent space via prototype-to-periphery (P2P) prediction, and a mutual-neighborhood contrastive (MC) loss to maintain topological consistency among neighborhoods. Together, DGDP and SFFG form a task-aware "where-how" training framework. Extensive experiments on VLA benchmarks show that LEEVLA consistently outperforms prior methods, confirming that explicit task-evidence guidance and structured latent reasoning are both crucial for scalable VLA. Our code is available at https://github.com/LyuQi127/LEEVLA.

- **核心问题**：如何让 VLA 模型在训练中自动识别“哪里值得关注”（where to attend）以及“关注的特征应该如何结构性地演化”（how to evolve），从而在不增加推理开销的前提下提升对复杂任务的适应能力。
- **整体含义**：提出 LEEVLA 架构，通过显式任务证据引导和结构化潜在推理，使模型能够在特征空间中聚焦任务相关区域并维持环境表征的有序演化，从而提高 VLA 的可扩展性和泛化能力。

## 2. 方法论

### 核心思想
LEEVLA 是一个两阶段的“where–how”训练框架：
- **Drift-Guided Dynamic Prioritization (DGDP)**：自动发现应关注的区域（where）。
- **Structured Feature Flow Generation (SFFG)**：建模重点关注特征如何结构化演化（how）。

### 关键技术细节
#### (1) DGDP 模块（训练期间使用，推理时不引入额外开销）
- **Dynamic Position Prioritization (DPP)**：计算相邻时间步同一 patch 特征间的余弦相似度变化，得到“动态性分数” θ_i = 1 – cos(v_{t,i}, v_{t+T,i})，高动态性区域（如机械臂、操作对象）获更高权重。
- **Semantic Drift Guidance (SDG)**：计算每个 patch 与语言指令 token 的最大内积作为“指令相关分数”，然后定义语义漂移 Δ_i = clip((r_{t+T,i} – r_{t,i})/τ, –δ, δ)，经归一化和指数变换得到语义漂移引导因子 ω_i。最终优先化权重 β_i = σ(ω_i · θ_i)，σ 为 sigmoid。

#### (2) SFFG 模块（训练期间使用）
- **Prototype-to-Periphery (P2P) Prediction**：对多视角特征进行聚类（如 k-means），在每个簇内按距离质心的欧氏距离排序（由近到远：原型→外围），然后对排序后的序列施加带权重的余弦嵌入损失：
  L_P2P = (1/|C|) Σ_ℓ (1/|c_ℓ|) Σ_{j∈c_ℓ} (α + β_j) [1 – cos(ˆv_{t+T,j}, v_{t+T,j})]，其中 α 为全局因子，β_j 为 DGDP 权重。
- **Mutual-neighborhood Contrastive (MC) Loss**：基于未来特征的余弦相似度构建一阶和二阶邻域，只选取“互邻”样本作为正例，采用 InfoNCE 损失拉近互邻特征，过滤聚类噪声和不对称连接，保持局部拓扑一致性。

#### (3) 训练目标
总体损失：L_total = λ₁ L_action + λ₂ L_P2P + λ₃ L_MC，其中 L_action 为 L1 动作回归损失（并行动作解码），λ₁, λ₂, λ₃ 为平衡超参数。

### 整体流程（文字描述）
1. 使用预训练视觉编码器（DINOv2 + SigLIP）提取图像 patch 特征，经投影器映射到模型维度。
2. 语言指令通过 tokenizer 编码，本体感觉通过嵌入层处理。
3. 在训练时，对当前时刻 t 的特征和未来时刻 t+T 的特征应用 DGDP 计算 β_i。
4. 未来特征解码器预测 t+T 的特征，同时计算 P2P 和 MC 损失。
5. LLM（如 Llama-2-7B）融合视觉、语言和动作 prompt，输出隐状态，再经 MLP 动作头并行预测连续动作序列。
6. 推理时仅保留 LLM + 动作头，不含 DGDP 和 SFFG，保证与原始 VLA 相同的推理效率。

## 摘要
本文基于一对输入-状态控制Lyapunov函数和鲁棒控制障碍函数，提出了一种计算轻量级的近似鲁棒非线性模型预测控制（NMPC）律。该结果建立在近期引入的标称无穷小时域NMPC方案之上并对其进行了增强，该方案允许通过小型二次规划在嵌入式硬件上实时计算非线性约束系统的反馈律。针对非线性约束航天器控制的数值实验以及与文献中其他鲁棒NMPC方案的比较，证明了所提方案的有效性。

## Abstract
In this paper, a computationally lightweight approximate robust nonlinear model predictive control (NMPC) law is proposed based on a pair of input-to-state control Lyapunov function and robust control barrier function. The result builds upon and augments a recently introduced nominal infinitesimal- horizon NMPC scheme which permits small-sized quadratic programs to compute the feedback law for nonlinear constraint systems on embedded hardware in real time. Numerical experiments for nonlinear constrained spacecraft control and comparison to other robust NMPC schemes from the literature demonstrate the effectiveness of the proposed scheme.

- **背景**：非线性模型预测控制（NMPC）是处理约束非线性系统的成熟方法，但在嵌入式硬件上实时求解仍是一个挑战；而鲁棒 NMPC（RMPC）方案（如 min-max MPC、tube-based MPC、reachable-set 方法）虽然提供了理论保证，但大多计算量巨大，难以满足实时性要求。
- **问题**：如何在保证**鲁棒约束满足**（robust constraint satisfaction）和**输入-状态稳定性**（Input-to-State Stability, ISS）的前提下，设计一种计算轻量、可在嵌入式硬件上实时执行的鲁棒 NMPC 律。
- **核心思路**：基于作者此前提出的**标称无穷小时域 NMPC（∂MPC）**方案（Olucak et al., 2025），将其扩展为鲁棒版本，利用**ISS-控制 Lyapunov 函数（ISS-CLF）**与**鲁棒控制障碍函数（robust CBF）**构成兼容对，将鲁棒控制问题化为一个小规模二次规划（QP），从而显著降低在线计算负担。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
- **核心思想**：将无穷小时域的 min-max 鲁棒优化问题，通过**扰动上界替换**（worst-case disturbance bound）转化为一个确定性的小规模 QP，从而兼顾鲁棒性、约束满足与实时可行性。
- **关键公式与细节**：
  - 系统模型为输入仿射非线性系统：
    \[
    \dot{x} = f_0(x) + g(x)u + p(x)w
    \]
  - 约束扰动集设为 \(\mathcal{W} = \{w \mid \|w\|_p \le \bar{w}\}\)。
  - 无穷小时域 min-max 问题：
    \[
    \min_{u \in \mathcal{U}} \max_{w \in \mathcal{W}} \left[ L(x,u) + \nabla\hat{V}(x)f(x,u,w) \right]
    \]
    s.t. \(\nabla\hat{h}(x)f(x,u,w) \le \gamma(-\hat{h}(x))\)
  - 通过扰动上界 \(\delta(x) = \|\nabla\hat{h}(x)p(x)\|_{\mathrm{op}}\bar{w}\)，将约束条件简化为确定性形式：
    \[
    \nabla\hat{h}(x)[f_0(x)+g(x)u] + \delta(x) \le \gamma(-\hat{h}(x))
    \]
  - 该方法最终化为一个**二次规划（QP）**，极小化 \(L(x,u) + \nabla\hat{V}(x)[f_0(x)+g(x)u]\)。
- **定理 1（主要理论贡献）**：若 \((\hat{V}, \hat{h})\) 满足鲁棒终端条件（即 \(\hat{V}\) 为 ISS-CLF，\(\hat{h}\) 为鲁棒 CBF），则闭环系统满足：
  1. **鲁棒可行性与约束满足**（状态始终保持在可行集 \(\hat{\mathcal{S}}\) 内）；
  2. **输入-状态稳定性**（\(\hat{V}\) 为闭环系统的 ISS-Lyapunov 函数），且当扰动消失时可恢复渐近稳定性。
- **离线合成（SOS 编程）**：设计了一个**非凸 SOS 优化问题**（式 17），同时求解鲁棒 CBF \(\hat{h}\)、ISS-CLF \(\hat{V}\) 及局部控制律 \(\kappa(x)\)，约束条件包括正定性、集合包含、输入约束、扰动鲁棒性以及类 \(\mathcal{K}_\infty\) 函数的单调性。
- **与现有方法的区别**：不同于标准 CBF-CLF QP 需要引入 slack 变量来权衡安全与稳定，本文的公式无需 slack 变量即可保证 QP 的可解性；相比 min-max MPC 只能保证输入-状态**实际**稳定性（practical stability），本文方案在扰动消失时可恢复渐近稳定性。

### 3. 实验设计：数据集 / 场景、benchmark 和对比方法
- **场景一：航天器角速率阻尼（rate damping）**

  - 对比方法：

    2. **zoRo-RTI**（Zanelli et al., 2021 + acados 实时迭代框架，Frey et al., 2024）；
    3. 多项式控制律 \(\tilde{\kappa}(x)\)（由 SOS 合成）；
    4. 标准速率控制器 \(K(x) = -K_c x\)（Fichter & Geshnizjani, 2023）。
  - 评价指标：平均/最大计算时间、预计算时间、RMS 角速率误差、积分阶段成本。
- **场景二：约束三轴姿态控制（constrained three-axis attitude control）**
  - 状态扩充为角速率 + 修正罗德里格斯参数（MRPs）；

### 6. 论文的主要结论与发现
- 提出了一种**计算轻量**且**理论保证充分**的鲁棒近似 NMPC（ISS-∂MPC），通过离线预计算鲁棒 CBF/ISS-CLF 对，在线仅需求解一个小型 QP。
- **实时性显著**：场景一中，ISS-∂MPC 平均计算时间约 0.015 ms，最坏情况 0.064 ms，而 zoRo-RTI 平均 6.26 ms、最坏 289.98 ms，差距达数百倍。
- **控制性能相当**：ISS-∂MPC 与 zoRo-RTI 的积分阶段成本几乎相同（0.0118 对 0.0111），且 RMS 误差更小（RMS 比为 1.0 对 2.03）。
- **理论保证**：闭环系统满足鲁棒约束满足和 ISS，扰动消失时恢复渐近稳定性——优于传统 min-max MPC 的“实际稳定”结论。

### 8. 不足与局限
- **离线调参负担**：需额外选择多项式阶数、单项式基、类 \(\mathcal{K}\) 函数形式等，调参难度高于普通 NMPC，且“扩展类 \(\mathcal{K}\) 函数”的选取对控制性能影响大，目前仍依赖经验。
- **适用范围受限**：SOS 合成依赖多项式系统假设；仅针对单一平衡点设计，换参考点需重新预计算。
- **采样间效应**：准连续控制律在采样间隔内保持恒定，理论上可能破坏不变量性质，论文虽未观察到该现象，但未给出理论缓解手段。
- **实验覆盖有限**：单一平台（航天器）+ 有限随机样本 + 缺乏消融研究，通用性和全面性有待加强。
- **对比公平性**：zoRo-RTI 的调节参数（预测时域等）为启发式选择，可能未达到其最优性能，对比结果的公平性存在一定偏差风险。

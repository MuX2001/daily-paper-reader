## 摘要
视觉-语言-动作（VLA）模型作为机器人操作的一种可扩展方法引起了越来越多的关注。虽然这些模型是有效的动作预测器，但将其部署为机器人代理时暴露了关键缺陷：缺乏故障恢复机制、在长时程任务中执行不一致，以及对观测、任务或本体变化的鲁棒性有限。现有解决方案通过模型重训练或环境特定模块来分别解决这些局限性，然而需要的是一种通用框架，能够系统地将预训练的VLA转化为机器人代理。我们提出了RoboBRIDGE，一个模块化框架，提供了一个由五个协调模块（即Monitor、Perceptor、Planner、Controller和Robot Interface）组成的编排层，以从现成组件（包括预训练VLA）构建稳健的机器人代理。Monitor将快速故障检测与分层恢复相结合，以在错误升级前进行纠正。当环境偏离当前计划时，Planner触发重新规划，同时Perceptor异步更新场景理解，避免执行停顿。在Controller内部，原始技能微调将操作分解为具有专用LoRA适配器的领域不变原始技能，从而在使用VLA时减少对领域偏移的敏感性。在LIBERO、RoboCasa以及涵盖多种机器人平台和VLA主干的真实世界案例研究中，RoboBRIDGE始终优于独立策略和先前增强的VLA部署。这些结果表明，可靠的机器人代理能力并非仅来自扩展动作预测器，而是来自围绕它们的结构化编排。

## Abstract
Vision-Language-Action (VLA) models have attracted growing interest as a scalable approach to robotic manipulation. While these models are effective action predictors, deploying them as robotic agents exposes critical gaps: no mechanism for failure recovery, inconsistent execution over long horizons, and limited robustness to shifts in observations, tasks, or embodiments. Existing solutions address these limitations individually through model retraining or environment-specific modules, yet what is needed is a general framework that systematically transforms a pretrained VLA into a robotic agent. We present RoboBRIDGE, a modular framework that provides an orchestration layer over five coordinated modules, namely Monitor, Perceptor, Planner, Controller, and Robot Interface, to compose robust robotic agents from off-the-shelf components, including pretrained VLAs. The Monitor pairs rapid failure detection with hierarchical recovery to correct errors before they cascade. When the environment diverges from the current plan, the Planner triggers replanning while the Perceptor updates scene understanding asynchronously, avoiding execution stalls. Within the Controller, primitive skill fine-tuning factors manipulation into domain-invariant primitives with dedicated LoRA adapters, reducing sensitivity to domain shifts when a VLA is used. Across LIBERO, RoboCasa, and real-world case studies spanning multiple robot platforms and VLA backbones, RoboBRIDGE consistently outperforms both standalone policies and prior augmented VLA deployments. These results suggest that reliable robotic agency does not arise from scaling action predictors alone, but from structured orchestration around them.

- **背景**：视觉-语言-动作（VLA）模型（如 SmolVLA、π0.5、GR00T-N1.5）作为机器人操作的可扩展范式受到广泛关注，能够将多模态观测与语言指令直接映射为底层动作。

- **核心问题**：VLA 模型本质上仅是"动作预测器"（action predictor），直接部署为机器人代理时存在三大关键缺陷：
  - **无故障恢复机制**：一旦抓取失败或发生碰撞，错误会级联放大，且无法自我纠正；
  - **长时程执行不一致**：每一步推理相互独立，缺乏任务进度跟踪与累积误差校正机制；
  - **跨域鲁棒性不足**：当观测、任务或机器人本体与训练分布不一致时，性能急剧下降。

- **现有工作的不足**：已有研究（如 Code-as-Monitor、DoReMi、SAFE、CycleVLA、SayCan 等）各自仅解决单一失败模式，碎片化严重，缺少政策无关（policy-agnostic）的通用解决方案。

- **核心论点**：本文类比 LLM 通过编排框架（如 LangChain、AutoGen）从"文本生成器"进化为"智能代理"的过程，主张 VLA 时代同样需要一种通用编排框架，围绕任何动作生成策略构建完整的机器人代理能力，而非依赖更大规模的模型或重新训练。**可靠的机器人智能体并非来自扩展动作预测器本身，而是来自围绕它们的结构化编排。**

## 2. 方法论：RoboBRIDGE 框架

### 2.1 总体架构

RoboBRIDGE 由五个协调模块组成，任何动作生成策略（包括但不限于 VLA）可插入 Controller 槽位：

- **Monitor（监控器）**：闭合执行回路，检测执行结果并触发分层恢复；
- **Perceptor（感知器）**：将原始传感器观测转换为以物体为中心的语义状态（身份、3D 姿态、功能属性等）；
- **Planner（规划器）**：基于语言指令与感知状态，将任务分解为有序的原始技能序列；
- **Controller（控制器）**：承载动作生成策略，将每个原始技能转化为底层动作；
- **Robot Interface（机器人接口）**：抽象不同机器人平台的特有 API、时序、安全限制与坐标变换。

### 2.2 核心技术机制

**(a) 双相监控与分层恢复（Two-phase Monitoring）**

- **Phase 1—轻量级成功检查**：通过轻量级 VLM 模型 \(D_{check}\)，以约束输出格式周期性地评估当前观测 \(o_t\) 与预期计划上下文 \(c_t\) 是否匹配，输出二元成功标志与置信度，运行频率约 5Hz，不阻塞控制回路；
- **Phase 2—失败诊断与恢复**：当检测到高置信度失败时，机器人立即停止，调用诊断模型 \(D_{diag}\) 推断根因与恢复目标，按计算范围递增选择四种恢复策略之一：**retry（重试）→ regenerate（重新生成轨迹）→ replan（重规划）→ re-perceive（重新感知）**。

**(b) 异步感知与发散触发重规划（Reactive Planning with Asynchronous Perception）**

- 采用**生产者–消费者架构**：感知线程持续刷新线程安全缓冲区中的最新检测结果 \( \bar{o}_{lat} \)，执行线程并行运行原始技能；
- 每个原始技能完成后，比较当前计划所用感知状态 \( \bar{o}_{plan} \) 与缓冲区最新状态 \( \bar{o}_{lat} \) 的差异，发散发度量定义为：
  \[
  \Delta(\bar{o}_a, \bar{o}_b) = \max_{i \in O_a \cap O_b} \|p^{(i)}_a - p^{(i)}_b\|_2 + \lambda \cdot |O_a \triangle O_b|
  \]
  其中 \(O\) 为检测物体集合，\(p^{(i)}\) 为物体 3D 位置，\(\triangle\) 为对称差；
- 当 \(\Delta \ge \tau\) 时，保留高层动作序列（如 PICK → PLACE），仅基于最新感知重新生成当前及后续的原始技能——避免了重复的高层推理，同时更新空间参数。

**(c) 原始技能微调（Primitive Skill Fine-tuning）**

- 将操作分解为域不变原始技能集合 \( P = \{ \text{MOVE}, \text{GRIP}, \text{ROTATE}, \dots \} \)；
- 为每个原始技能在冻结的 VLA 骨干 \(f_\theta\) 上训练专属 LoRA 适配器 \(\Delta\theta_k\)，技能切换通过两层级解析器实现：
  \[
  \text{RESOLVE}(p_t) = \begin{cases} \Delta\theta_{p_t} & \text{若适配器存在} \\ \frac{1}{|P|}\sum_{p \in P} \Delta\theta_p & \text{否则} \end{cases}
  \]
- 动作输出为 7-DoF 增量动作 \(a_t = (\delta x, \delta\phi, g)\)，支持两种执行路径：直接以笛卡尔速度命令下发，或通过逆运动学（IK）转换为关节位置目标。

## 6. 主要结论与发现

1. **RoboBRIDGE 一致优于独立部署**：LIBERO 平均成功率从 35.5%→39.7%；RoboCasa 三个骨干的平均成功率从 3.7%→7.5%（排除 Pick-and-Place 任务后从 6.2%→11.4%）；
2. **无需重新训练基础策略**：性能提升完全来自编排层提供的监测、恢复与重规划能力；
3. **原始技能微调有效**：LoRA 微调 + RoboBRIDGE 达到 27.1%，逼近全量微调独立部署的 31.9%，而后者参数更新量远大于前者；全量微调本身在框架内进一步提升至 40.0%；
4. **模型内部纠错不足以替代外部编排**：CycleVLA 独立部署平均仅 7.5%，远低于 RoboBRIDGE 包装后的各类控制器；
5. **规划与监测缺一不可**：规划质量单独不足以弥补 VLA 与可靠智能体之间的差距；监测带来的增益随 LLM 骨干的诊断能力提升而增大（Claude Opus 4.6 +8.1%，Claude Haiku 4.5 +0.0%）；
6. **两类主导失败模式**：感知错误（遮挡、相似物体混淆）与不可恢复的操作失败（接触丰富交互中环境状态被不可逆改变）——指向感知鲁棒性与显式验证/确认机制是未来关键方向。

## 7. 优点

- **架构设计优雅且通用**：以 LLM 编排框架为类比，首次将"模型→智能体"的编排思想系统性地引入 VLA 机器人操作领域，政策无关的设计使任何控制器（学习或经典）都可插拔；
- **机制设计精细**：
  - 双相监控避免了全量诊断的延迟开销，分层恢复（retry→regenerate→replan→re-perceive）以最小代价化解错误；
  - 异步感知将感知延迟隐藏在执行线程之后，发散触发重规划避免了无谓的高层推理；
  - 原始技能 + LoRA 适配器将域不变信息与域相关操作解耦，兼顾参数效率与迁移鲁棒性；
- **实验覆盖全面**：多仿真基准、多 VLA 骨干、多机器人平台、多 LLM 骨干消融、多控制器配置对比，验证了框架的通用性和一致性；
- **结果呈现客观**：未选择性隐藏失败任务，RoboCasa 表中大量零成功率任务如实列出，平均提升真实反映了框架的有效性。

## 8. 不足与局限

- **原始技能词汇有限**：仅覆盖单臂桌面操作；接触丰富交互、可变形物体、双臂任务需要更丰富的原语与状态表示；
- **监控阈值与恢复规则手动设定**：缺乏从交互数据中自动学习最优监控与恢复策略的机制；
- **不可恢复失败缺乏出口**：面对接触丰富交互中的不可逆错误，重试/重规划均无效，缺少"何时放弃或切换策略"的显式验证与确认层；
- **感知瓶颈明显**：遮挡、视觉相似物体导致的感知错误构成主导失败模式之一，框架依赖底层感知器（Florence-2）的固有性能上限；
- **评估深度有限**：真实世界实验仅为案例展示，未给出系统化的成功率统计；每任务 rollout 次数较少且无统计显著性检验；GPU 算力与训练时长未报告，影响可复现性；
- **LLM 骨干消融结果依赖单一 LLM 供应商**：主要使用了 Claude 系列的模型，Gemini 系列表现较弱，是否存在供应商偏差尚需更广泛的验证。

## 摘要
机器人操作中的模仿学习应在生成动态可接受的机器人运动的同时，保留演示的任务几何结构。现有流程通常学习任务相关轨迹，随后通过滤波、平滑、裁剪或时间缩放施加执行限制，这可能会扭曲关键的任务末端执行器路径。我们提出谱运动基元（SMP），一种频域模仿学习框架，将任务空间技能生成与关节空间执行调节耦合。演示通过截断的有限时域傅里叶系数表示。经验选择的低频任务频带捕获主导运动几何结构，而高次谐波对导数增长的贡献不成比例。一个帧感知的上下文条件GMM/GMR先验在规范任务帧中预测任务频带系数，生成的笛卡尔轨迹通过顺序逆运动学映射到关节空间。然后，一个相位耦合调节器在不修改谱系数的情况下限制请求的相位进展，从而在保持表示路径的同时强制执行关节速度和加速度限制。实验评估了任务频带重建、对复合演示污染的鲁棒性、跨板的分布外泛化、关节空间动态可接受性、末端执行器路径保持以及在Franka Panda机器人上的部署。结果显示，紧凑的几何重建、在未见任务帧上的一致迁移、动态违规和急动度的大幅减少，以及在相位调节期间保持预期的末端执行器路径。

## Abstract
Robot imitation learning for manipulation should preserve demonstrated task geometry while producing dynamically admissible robot motions. Existing pipelines often learn task-dependent trajectories and impose execution limits afterward through filtering, smoothing, clipping, or time scaling, which may distort task-critical end-effector paths.   We propose the Spectral Movement Primitive (SMP), a frequency-domain imitation learning framework that couples task-space skill generation with joint-space execution regulation. Demonstrations are represented by truncated finite-horizon Fourier coefficients. An empirically selected low-frequency task band captures the dominant motion geometry, while higher harmonics contribute disproportionately to derivative growth. A frame-aware context-conditioned GMM/GMR prior predicts the task-band coefficients in a canonical task frame, and the resulting Cartesian trajectory is mapped to joint space through sequential inverse kinematics. A phase-coupled regulator then limits the requested phase progression without modifying the spectral coefficients, thereby enforcing joint velocity and acceleration limits while preserving the represented path.   Experiments evaluate task-band reconstruction, robustness to composite demonstration corruption, out-of-distribution cross-board generalization, joint-space dynamic admissibility, end-effector path preservation, and deployment on a Franka Panda robot. Results show compact geometric reconstruction, consistent transfer across unseen task frames, substantial reductions in dynamic violations and jerk, and preservation of the intended end-effector path during phase regulation.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- **频域表示（SMP）**：将演示的末端执行器轨迹编码为截断的有限时域傅里叶系数向量 `c_y`，每个维度由 DC 项 + K 个正弦/余弦对组成。
- **任务频带分解**：通过经验规则（重建误差饱和 + 相对改进阈值）自动选择低频**任务频带**（低阶谐波），保留主导几何，而补充频带（高阶谐波）主要贡献导数增长，不参与上下文学习。
- **帧感知上下文条件先验**：通过**任务帧规范变换**（平移、旋转、面内缩放）将演示转换到规范任务帧，消除位置/姿态/尺度变化，然后对规范帧下的**任务频带系数**建立 GMM/GMR 模型，预测新上下文下的系数。
- **相位调节器**：将生成的笛卡尔轨迹通过顺序逆运动学映射为关节轨迹，并编码为关节空间的 SMP。执行时保持系数不变，仅调节相位速度 `ϕ̇`：根据解析的相位导数包络和关节限制，计算最大允许常相位速度，从而同时满足关节速度和加速度约束，且不改变任何路径。

### 关键技术细节
1. **傅里叶参数化**：`y_j(τ) = a_j0 + Σ_k [a_jk cos(kωτ) + b_jk sin(kωτ)]`，ω=2π/H。
2. **任务频带选择**：递增保留谐波，计算归一化重建 MSE 和相对改进 `I_k`；若存在满足 `e(k)≤10⁻⁶` 则取最小k；否则取首个后续 P=3 个谐波改进均<5% 的 k。该规则固定参数，但 K_task 自动适应轨迹复杂度。
3. **规范化和相位对齐**：对演示进行任务帧规范变换：`y^(c) = D_s⁻¹ R^T (y^(w) - p)`；对周期性技能进行循环相位对齐，消除起始相位模糊。
4. **上下文 GMM/GMR**：预测变量仅包含**剩余有意义的变化**（如面内尺度 s_n），已规范化的位置/姿态不进入回归。预测均值 `ĉ_LF,c = Σ_m h_m ĉ_LF,c,m`。
5. **动态调节**：关节轨迹用同样傅里叶表示；相位导数包络 Γ^(1)_d = max|∂q_d/∂ϕ|，Γ^(2)_d = max|∂²q_d/∂ϕ²|；计算 `ϕ̇_v = min_d v̄_d / Γ^(1)_d`，`ϕ̇_a = min_d √(ā_d / Γ^(2)_d)`；调节后相位速度取 `min(ϕ̇_des, ϕ̇_v, ϕ̇_a)`，保持常数。

## 6. 论文的主要结论与发现
1. **紧凑任务频带表示**：平滑操作轨迹的几何主要集中在低阶谐波（如八字仅需2阶，花需6阶），任务频带选择规则可自动适应复杂度。
2. **鲁棒重建**：在复合演示污染下，SMP 比 ProMP、FMP、MSTOMP 获得更低的 Procrustes-aligned MSE 和更低的轨迹急动度（低几个数量级），表明固定任务频带能有效抑制噪声和保持形状。
3. **跨板泛化**：规范帧是关键，能正确将演示迁移到未见板位姿；任务频带谱预测进一步降低规范帧内的误差。世界帧方法在2D测试中形状保持但位置偏移，在3D垂直板上完全失败。
4. **动态可接受性**：相位调节器将超限的加速命令（速度比1.452, 加速度比2.108）恢复至限值内（0.980, 0.960），同时将急动度从2112.3降至649.6（名义为264.0），且保持了末端路径（理论不变）。
5. **真实机器人验证**：水平板演示可直接在垂直板上执行，相位速度调节可实现不同执行速率。

## 7. 优点
1. **优雅的频域解耦**：将任务几何（低频系数）和执行时序（相位速度）分离，使上下文学习只关注形状，调节器只关注时序，互不干扰。
2. **帧感知规范变换**：显式处理平移、旋转、面内缩放，极大地缩小了统计模型需要学习的范围，使跨板泛化成为可能。
3. **频谱调节不改变路径**：通过解析导数包络和常数相位速度调节，在保持系数不变的前提下满足关节限制，避免了点对点裁剪或滤波导致的形状失真。
4. **紧凑表示与鲁棒性**：任务频带自动选择适度阶数，对高频噪声和离群点有天然滤波作用，重建误差低且输出平滑。
5. **实验设计系统且公平**：鲁棒实验使用固定随机种子、多轨迹类型、多种污染成分；消融实验清晰解耦各模块贡献；真实机器人验证覆盖实际物理场景。

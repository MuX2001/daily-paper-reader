## 摘要
在杂乱且动态的环境中进行实时导航，需要在有限感知下实现无碰撞且动态可行的运动。然而，可行的导航行为本质上是多模态的，因为障碍物周围可能存在多条路径。本文将导航问题形式化为学习一个可迁移的目标条件随机路径先验，该先验基于局部观测，对目标对齐的几何一致局部路径上的可复用分布进行建模。这种形式化方法实现了导航候选的结构化采样，允许通过采样探索多条可行路径，而无需依赖机器人特定的运动约束。为此，我们引入了一种目标对齐的规范状态表示，消除了平面内旋转模糊性，并相对于目标对局部几何进行归一化，从而实现了旋转不变的路径分布学习。我们进一步开发了一个结构化先验学习框架，该框架使用几何感知的极坐标动作流形对局部路径进行参数化，并结合多目标分布展开的风险敏感效用塑形，以实现稳定且安全感知的规划。在密集静态环境和动态行人场景中的大量实验表明，所提出的方法在保持竞争性效率的同时，实现了始终如一的高成功率，并且能够在无需重新训练的情况下，将在差分驱动机器人上学习的单一路径先验跨平台迁移到四足机器人平台。

## Abstract
Real-time navigation in cluttered and dynamic environments requires collision-free and dynamically feasible motion under limited perception. However, feasible navigation behaviors are inherently multimodal because multiple paths may exist around obstacles. In this paper, we formulate navigation as learning a transferable goal-conditioned stochastic path prior that models a reusable distribution over goal-aligned geometry-consistent local paths conditioned on local observations. This formulation enables structured sampling of navigation candidates, allowing multiple feasible paths to be explored through sampling without relying on robot-specific motion constraints. To this end, we introduce a goal-aligned canonical state representation that removes in-plane rotational ambiguity and normalizes local geometry with respect to the goal, enabling rotation-invariant path distribution learning. We further develop a structured prior learning framework that parameterizes local paths using a geometry-aware polar action manifold and incorporates risk-sensitive utility shaping with multi-goal distributional rollouts for stable and safety-aware planning. Extensive experiments in dense static environments and dynamic pedestrian scenarios demonstrate that the proposed method achieves consistently high success rates with competitive efficiency while enabling cross-platform transfer of a single path prior learned on differential-drive robots to quadruped platforms without retraining.

## 论文方法论

### 核心思想
- 学习一个可迁移的**目标条件随机路径先验** \(\pi_\theta(a\mid s)\)，其中 \(a\) 为低维极坐标控制点参数，\(s\) 为目标对齐规范状态。该先验建模几何一致局部路径的分布，与机器人运动学解耦。
- 通过**目标对齐规范状态表示**消除旋转模糊性，使同一先验可复用于不同平台和不同临时目标。
- 采用**两阶段训练**：离线最大似然初始化（使用物理信息规划器生成百万级专家轨迹） + 在线单步交互细化（基于风险敏感效用函数进行PPO更新）。
- 推理时通过**圆上多目标采样 + 分布展开**生成多样候选路径，再经**平台相关约束优化**（如Priest）获得可执行轨迹。

### 关键技术细节
1. **目标对齐规范状态表示**：
   - 将机器人坐标系 \(F_r\) 中的局部观测（2D LiDAR点云）绕目标方向 \(\psi_t\) 旋转至规范帧 \(F_s\)，使目标始终位于x轴正方向。
   - 构建规范帧下的单帧有符号距离场（SDF） \(D_t\)，结合目标距离 \(\rho_t\) 和上一动作 \(a_{t-1}\)，得到状态 \(s_t = [D_t, \rho_t, a_{t-1}]\)。
   - 优点：旋转不变性、紧凑、支持多目标采样。

2. **几何感知极坐标动作流形**：
   - 用 \(n\) 个极坐标控制点 \((r_i, \theta_i)\) 编码局部路径，经三次样条插值得到几何路径 \(\tau = D(a)\)。
   - 施加径向有序约束 \(r_{\max}\) 和角度可行锥 \([\theta_{\min}, \theta_{\max}]\)，形成结构化低维流形。
   - 将归一化动作 \(a_{\text{norm}} \in [-1,1]^{2n}\) 通过 tanh 映射到该流形，保持可微性和探索性。

3. **学习算法**：
   - **Stage I（离线MLE初始化）**：使用物理信息规划器PC-Planner生成 \(10^6+\) 条专家轨迹，最小化负对数似然 + 熵正则 + L2正则。
   - **Stage II（交互细化）**：每次试验采样一个动作并执行单步 rollout，利用风险敏感效用函数 \(U = u_{\text{succ}} + \sum \lambda_j u_j\)（包含安全、路径长度、曲率变化、段长变化、动作变化等项），通过PPO更新策略。
   - 安全项使用条件风险值（CVaR\(_{\eta=0.10}\)）强调最差间隙。
   - 效用通过 squashing 函数 \(\phi(x;\alpha,\beta)=\tanh(\beta x / (\alpha+\varepsilon))\) 归一化。

4. **推理流程**：
   - 圆上多目标采样：在距离 \(\rho_t\) 的圆上均匀取 \(K\) 个临时目标，每个目标生成规范状态 \(s_k\)，从先验采样 \(M\) 条路径。
   - 候选集 \(C\) 中的每条路径经时间参数化（弧长映射）变为 Bernstein 多项式种子轨迹。
   - 使用 Priest 优化器进行平台相关约束优化（速度、加速度、障碍物安全等），得到最终可执行轨迹。

## 摘要
视觉-语言-动作（VLA）模型旨在理解自然语言指令和视觉观察，并作为具身智能体生成并执行相应的动作。近年来，基于自回归token的动作生成推动了众多代表性VLA模型的发展。然而，这种范式往往将动作生成简化为下一个token预测，从而缺乏对动作序列时空结构的显式建模以及视觉-语言表示与动作之间的解耦，这可能会限制在长时域和复杂场景下的性能。本文提出TS-Mask VLA，一种用于机器人操作的视觉-语言-动作框架。TS-Mask VLA基于两个关键设计：（1）一个配备桥接注意力调节桥的离散扩散动作专家，该桥接能够从VLM实现多层调节，并促进更准确和稳定的动作生成；（2）一种针对离散动作token的时空二维遮罩策略，增强了模型对跨时间依赖性和维度间耦合的理解，从而产生结构更一致的动作序列。我们在仿真基准和真实世界任务上进行了大量实验。在LIBERO上，TS-Mask VLA仅用0.5B参数就达到95.7%的平均成功率，表现优于规模大得多的模型。在CALVIN上，它获得了最佳平均序列长度4.19，并展现出强大的长时域性能。全面的分析和消融实验进一步验证了我们设计的有效性。

## Abstract
Vision-language-action (VLA) models aim to understand natural-language instructions and visual observations, and to generate and execute corresponding actions as embodied agents. Recently, autoregressive token-based action generation has driven the development of many representative VLA models. However, this paradigm often reduces action generation to next-token prediction, thereby lacking explicit modeling of the spatiotemporal structure of action sequences and the disentanglement between vision-language representations and actions, which can limit performance in long-horizon and complex scenarios. In this paper, we propose TS-Mask VLA, a vision-language-action framework for robot manipulation. TS-Mask VLA is built upon two key designs: (1) a Discrete Diffusion Action Expert equipped with a Bridge Attention conditioning bridge, which enables multi-layer conditioning from the VLM and facilitates more accurate and stable action generation; and (2) a temporal-spatial 2D masking strategy for discrete action tokens that strengthens the model's understanding of cross-time dependencies and inter-dimensional coupling, leading to more structurally consistent action sequences. We conduct extensive experiments on simulation benchmarks and real-world tasks. On LIBERO, TS-Mask VLA achieves a 95.7 percent average success rate with only 0.5B parameters, outperforming significantly larger models. On CALVIN, it attains the best average sequence length of 4.19 and strong long-horizon performance. Comprehensive analyses and ablations further validate the effectiveness of our design.

- **研究动机**：作者认为，有必要（1）将视觉-语言表示通过专用桥接模块注入动作专家，实现更清晰的条件解耦；（2）对动作进行离散化并显式建模其结构化依赖关系，从而在复杂环境中获得更鲁棒的泛化能力。
- **整体含义**：通过提出 TS-Mask VLA，实现在小参数规模下高效、稳定地生成结构一致的动作序列，为 VLA 模型提供一种新的范式。

## 2. 方法论
- **核心思想**：构建一个离散扩散动作专家（Discrete Diffusion Action Expert），利用来自 VLM 所有层的隐藏状态进行多层条件注入，并采用 2D 时空遮罩策略来显式建模动作 token 的时间依赖和维度间耦合。
- **关键技术细节**：
    - **VLM 编码**：使用 DINOv2 + SigLIP 提取视觉特征（第三视角和腕部相机），与语言指令一起输入 Qwen2.5-0.5B 作为 VLM 骨干。额外引入可学习的 Action Query token 提供动作导向信号。提取所有 L 层的隐藏状态 H^{(l)} 用于条件注入。
    - **离散扩散动作专家**：
        - **桥接注意力模块**：融合三类 token（自 token、Action Query token、任务 token），通过共享 query、独立 key/value 和可学习门控实现跨流注意力，输出用于更新动作表示。
        - **均匀量化动作 token**：将连续动作归一化到 [-1,1]，均匀量化为 256 个 bin（V=256），得到离散索引 q ∈ {0,...,255}^{M}，其中 M = T × D（T 时间帧数，D 动作维度）。不采用 VQ-VAE，以避免过度压缩时空信息。
    - **时空 2D 遮罩策略**：
        - 将离散 token 重塑为 T×D 的二维网格。
        - **时间遮罩**：随机选择约 rT 个时间帧，遮罩该帧所有 D 个 token。
        - **空间遮罩**：对未被时间遮罩覆盖的帧，随机选择约 r×D 个 token 遮罩。
        - 损失仅在遮罩位置计算交叉熵。
    - **训练**：包含主遮罩损失 L_mask 和步展开损失 L_unroll（第二次前向传播中高层置信度回填后的损失），加权组合 L = (L_mask + λ L_unroll)/(1+λ)。
    - **推理**：从全遮罩开始，迭代 I 次，每次预测后按余弦调度重新遮罩低置信度 token，逐步精细化。

## 6. 主要结论与发现
- TS-Mask VLA 在 LIBERO 上以 0.5B 参数达到 95.7% 平均成功率，超越 8.5B 的 FlowVLA（88.1%）和 7B 的 OpenVLA（76.5%），尤其在长时域套件（Long）上达到 91.6%，显著高于其他小模型。

- 2D 时空遮罩比 1D 遮罩在长时域任务上提升 6.6%（Long 套件）。
- 适中的步展开强度（λ=0.5）有效提升性能（LIBERO-Spatial 从 90.8% 到 95.4%），而过大则导致负效果。

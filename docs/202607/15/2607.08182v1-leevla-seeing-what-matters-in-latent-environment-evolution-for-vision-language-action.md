## 摘要
视觉-语言-动作（VLA）模型旨在将多模态输入映射到机器人动作。然而，现有大多数方法因均匀对待所有视觉标记以及使用人为选择因素进行推理，缺乏强调任务关键证据的机制且忽略了潜在因素，难以覆盖复杂的动态场景。为解决这一问题，我们提出LEEVLA，一种在潜在环境演化中关注关键要素的VLA架构，该架构明确引导模型关注信息丰富区域，同时保持潜在世界表征的结构化演化。为识别显著且与指令相关的区域，我们引入漂移引导的动态优先级排序（DGDP），它结合动态位置优先级（DPP）与语义漂移引导（SDG），在训练期间指导VLA智能体关注何处。在此基础上，我们引入结构化特征流生成（SFFG），通过原型到外围（P2P）预测建模这些优先特征如何在潜在空间中演化，并采用互邻域对比（MC）损失以保持邻域间的拓扑一致性。DGDP与SFFG共同构成任务感知的“在何处-如何”训练框架。在VLA基准上的大量实验表明，LEEVLA持续优于先前方法，证实了显式任务证据引导与结构化潜在推理对于可扩展VLA均至关重要。我们的代码已在https://github.com/LyuQi127/LEEVLA上开源。

## Abstract
Vision-language-action (VLA) models aim to map multimodal inputs to robot actions. However, most existing approaches struggle to cover complex dynamic scenarios due to treating all visual tokens uniformly and reasoning with human-selected factors, which lack mechanisms to emphasize task-critical evidence and ignore underlying factors. To address this issue, we propose LEEVLA, a VLA architecture for seeing what matters in Latent Environment Evolution that explicitly guides the model toward informative regions while preserving the structured evolution of latent world representations. To identify salient and instruction-relevant regions, we introduce drift-guided dynamic prioritization (DGDP), which combines dynamic position prioritization (DPP) with semantic drift guidance (SDG) to guide the VLA agent where to attend during training. On top of this, we introduce structured feature flow generation (SFFG), which models how these prioritized features should evolve in latent space via prototype-to-periphery (P2P) prediction, and a mutual-neighborhood contrastive (MC) loss to maintain topological consistency among neighborhoods. Together, DGDP and SFFG form a task-aware "where-how" training framework. Extensive experiments on VLA benchmarks show that LEEVLA consistently outperforms prior methods, confirming that explicit task-evidence guidance and structured latent reasoning are both crucial for scalable VLA. Our code is available at https://github.com/LyuQi127/LEEVLA.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：现有 VLA（视觉-语言-动作）模型在面对复杂动态场景时表现不佳，主要原因有两个：
  - 对所有视觉 token 一视同仁，缺乏聚焦任务关键证据的机制；
  - 依赖人为选定的上下文线索（如目标图像、分割、深度）进行推理，忽略了未知但任务相关的潜在因素，导致搜索空间受限、泛化能力弱。
- **背景**：机器人操作需要将多模态观测（视觉、语言指令、本体感受）映射为连续动作。近期 VLA 模型（如 OpenVLA、PaLM-E）以 LLM/VLM 为骨干，但在复杂、动态环境中仍易受静态背景和无关信息干扰。
- **核心含义**：提出一种在潜在特征空间中直接推理的方法，通过显式指导模型“关注何处”（任务关键区域）并结构化建模“如何演化”（潜在环境状态过渡），实现更可扩展的 VLA。

## 2. 方法论
- **核心思想**：构建一个任务感知的“在何处-如何”训练框架，包含两大模块（仅训练时使用，推理无额外成本）。
- **关键技术细节**：

    - *语义漂移引导 (SDG)*：根据语言指令计算每个 patch 的指令相关分数，并度量语义漂移方向（公式2-3），通过指数归一化得到引导因子（公式4）。
    - 最终优先级权重 β 由动态评分与语义引导因子的乘积经 sigmoid 函数得到（公式5）。
  - **结构化特征流生成 (SFFG)**：建模特征在潜在空间的结构化演化，包含：
    - *原型到外围预测 (P2P)*：对多视图未来特征进行聚类，在每个簇内按与质心的欧氏距离排序（从近到远），并赋予排序位置不同的预测损失权重（公式8），保证同一语义单元的特征被连续预测。

  - **总训练目标**：L_total = λ1 L_action + λ2 L_P2P + λ3 L_MC，
    - L_action：连续动作 chunk 的 L1 回归损失。

## 6. 主要结论与发现
- LEEVLA（小规模和大规模）在 LIBERO 和 CALVIN 上均取得 **最优或接近最优** 的性能：
  - LEEVLA-mini (0.5B) 在 LIBERO 平均 97.5% → 超过所有 <1B 模型。
  - LEEVLA-large (7B) 在 LIBERO 平均 98.2% → 超过 OpenVLA (76.5%)、π0 (94.1%)、OpenVLA-OFT (97.1%) 等。

- **特征重排序**和**全局因子 α** 对保持结构化理解和避免过度聚焦至关重要。

## 7. 优点
1. **方法创新性**：首次在 VLA 中结合了潜空间结构化预测（原型-外围排序+互邻对比）与自适应注意力引导（动态+语义双重驱动），实现任务相关的“聚焦-演化”训练。
2. **推理无额外成本**：DGDP 和 SFFG 仅在训练时生效，推理时完全保持原有 OpenVLA 的计算图，不增加延迟。
3. **通用性强**：可无缝集成到不同规模 VLA 骨干（miniVLA / OpenVLA），且适用于多个基准和真实场景。
4. **消融设计清晰**：逐步解开四个模块贡献，并验证了设计选择（重排序、α 因子）的必要性。

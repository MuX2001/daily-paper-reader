## 摘要
视觉-语言-动作（VLA）模型旨在将多模态输入映射到机器人动作。然而，现有方法大多将所有视觉标记统一处理，并使用人类选择的因素进行推理，缺乏强调任务关键证据的机制，且忽略了潜在因素，因此难以覆盖复杂的动态场景。为解决这一问题，我们提出LEEVLA，一种在潜在环境演化中关注重要信息的VLA架构，它显式引导模型关注信息区域，同时保留潜在世界表征的结构化演化。为识别显著且与指令相关的区域，我们引入漂移引导的动态优先级（DGDP），它结合了动态位置优先级（DPP）和语义漂移引导（SDG），以引导VLA智能体在训练中关注何处。在此基础上，我们引入结构化特征流生成（SFFG），通过原型到外围（P2P）预测建模这些优先级特征在潜在空间中如何演化，并使用互邻域对比（MC）损失维护邻域间的拓扑一致性。DGDP与SFFG共同构成一个任务感知的“何处-如何”训练框架。在VLA基准上的大量实验表明，LEEVLA持续优于先前方法，证实显式的任务证据引导和结构化潜在推理对于可扩展的VLA都至关重要。我们的代码可在https://github.com/LyuQi127/LEEVLA获取。

## Abstract
Vision-language-action (VLA) models aim to map multimodal inputs to robot actions. However, most existing approaches struggle to cover complex dynamic scenarios due to treating all visual tokens uniformly and reasoning with human-selected factors, which lack mechanisms to emphasize task-critical evidence and ignore underlying factors. To address this issue, we propose LEEVLA, a VLA architecture for seeing what matters in Latent Environment Evolution that explicitly guides the model toward informative regions while preserving the structured evolution of latent world representations. To identify salient and instruction-relevant regions, we introduce drift-guided dynamic prioritization (DGDP), which combines dynamic position prioritization (DPP) with semantic drift guidance (SDG) to guide the VLA agent where to attend during training. On top of this, we introduce structured feature flow generation (SFFG), which models how these prioritized features should evolve in latent space via prototype-to-periphery (P2P) prediction, and a mutual-neighborhood contrastive (MC) loss to maintain topological consistency among neighborhoods. Together, DGDP and SFFG form a task-aware "where-how" training framework. Extensive experiments on VLA benchmarks show that LEEVLA consistently outperforms prior methods, confirming that explicit task-evidence guidance and structured latent reasoning are both crucial for scalable VLA. Our code is available at https://github.com/LyuQi127/LEEVLA.

  - 无法自动聚焦任务关键证据。
  - 忽略未知但任务相关的潜在因素，难以应对复杂动态场景（如物体外观变化、多模态歧义）。
- **动机**：作者主张在**潜在特征空间**直接推理，利用预训练视觉模型编码的多模态信息（语义、外观、几何），避免手工设计假设空间，同时需要引导模型关注重要区域并建模结构化演化。
- **目标**：提出 LEEVLA，通过“where（何处聚焦）–how（如何演化）”训练框架，提升 VLA 在复杂动态任务中的泛化与长程推理能力。

## 2. 方法论

### 核心思想
- 在训练阶段引入两个互补模块：
  - **Drift-Guided Dynamic Prioritization (DGDP)**：自动发现视觉特征中动态变化且与语言指令相关的区域，指导模型“关注哪里”。
  - **Structured Feature Flow Generation (SFFG)**：在潜在空间中建模未来特征的结构化演化，指导模型“如何演化”。
- 两者仅在训练时生效，**推理时无额外开销**。

### 关键技术细节

#### (1) DGDP
- **Dynamic Position Prioritization (DPP)**：计算相邻时间步（t 和 t+T）同一空间位置特征向量的余弦相似度，定义动态度得分 `θ_i = 1 - cos(v_{t,i}, v_{t+T,i})`。高得分对应动态区域（如机械臂、操作物体）。
- **Semantic Drift Guidance (SDG)**：计算每个 patch 与语言指令的余弦相似度 `r_{t,i} = max_j ⟨x̃_{t,i}, c̃_j⟩`，定义语义漂移 `Δ_i = clip((r_{t+T,i} - r_{t,i})/τ, -δ, δ)`，通过指数归一化得到权重因子 `ω_i`，抑制语义漂向背景的 patch，增强语义向指令方向移动的 patch。
- **融合权重**：`β_i = σ(ω_i · θ_i)`（σ 为 sigmoid），即同时考虑动态性和指令相关性。

#### (2) SFFG
- **Prototype-to-Periphery (P2P) Prediction**：对未来特征进行聚类，在每个聚类内按成员到质心的欧氏距离排序（原型→外围），然后加权预测损失 `L_P2P = 1/|C| Σ(α+β_j) φ(ˆv_{t+T,j}, v_{t+T,j})`（φ 为余弦嵌入损失），保持同一语义单元内的结构化预测。
- **Mutual-neighborhood Contrastive (MC) Loss**：基于一阶和二阶互邻域（reciprocal neighbors）构造正样本对，使用 InfoNCE 损失拉近，过滤聚类噪声和不对称关系，维持特征空间的局部拓扑一致性。
- **总损失**：`L_total = λ1 L_action + λ2 L_P2P + λ3 L_MC`，其中 `L_action` 为 L1 动作回归损失。

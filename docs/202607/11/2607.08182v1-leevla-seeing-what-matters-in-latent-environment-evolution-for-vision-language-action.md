## 摘要
视觉-语言-动作（VLA）模型旨在将多模态输入映射到机器人动作。然而，由于现有方法通常均匀处理所有视觉标记并使用人类选择的因素进行推理，缺乏强调任务关键证据的机制并忽略潜在因素，大多数方法难以覆盖复杂的动态场景。为解决这一问题，我们提出 LEEVLA，一种在潜在环境演化中看见重要内容的 VLA 架构，它显式引导模型关注信息丰富的区域，同时保持潜在世界表示的结构化演化。为了识别显著且与指令相关的区域，我们引入了漂移引导的动态优先级排序（DGDP），它结合动态位置优先级排序（DPP）和语义漂移引导（SDG）来指导 VLA 代理在训练过程中关注何处。在此基础上，我们引入了结构化特征流生成（SFFG），通过原型到外围（P2P）预测建模这些优先级特征如何在潜在空间中演化，并引入互邻域对比（MC）损失以保持邻域间的拓扑一致性。DGDP 和 SFFG 共同构成了一个任务感知的“何处-如何”训练框架。在 VLA 基准上的大量实验表明，LEEVLA 持续优于先前方法，证实了显式任务证据引导和结构化潜在推理对于可扩展 VLA 都是至关重要的。我们的代码可在 https://github.com/LyuQi127/LEEVLA 获取。

## Abstract
Vision-language-action (VLA) models aim to map multimodal inputs to robot actions. However, most existing approaches struggle to cover complex dynamic scenarios due to treating all visual tokens uniformly and reasoning with human-selected factors, which lack mechanisms to emphasize task-critical evidence and ignore underlying factors. To address this issue, we propose LEEVLA, a VLA architecture for seeing what matters in Latent Environment Evolution that explicitly guides the model toward informative regions while preserving the structured evolution of latent world representations. To identify salient and instruction-relevant regions, we introduce drift-guided dynamic prioritization (DGDP), which combines dynamic position prioritization (DPP) with semantic drift guidance (SDG) to guide the VLA agent where to attend during training. On top of this, we introduce structured feature flow generation (SFFG), which models how these prioritized features should evolve in latent space via prototype-to-periphery (P2P) prediction, and a mutual-neighborhood contrastive (MC) loss to maintain topological consistency among neighborhoods. Together, DGDP and SFFG form a task-aware "where-how" training framework. Extensive experiments on VLA benchmarks show that LEEVLA consistently outperforms prior methods, confirming that explicit task-evidence guidance and structured latent reasoning are both crucial for scalable VLA. Our code is available at https://github.com/LyuQi127/LEEVLA.

    2. 仅关注已知因素，忽略未知但任务相关的潜在因素，泛化性受限；
    3. 推理空间人为窄化，容易因同一对象跨模态变化或不同对象单模态相似而产生误判。
- **整体含义**：论文提出 **LEEVLA**（Latent Environment Evolution VLA），主张直接在潜在特征空间进行推理，通过显式引导模型“关注重要区域”并“结构化地演化潜在表示”，以提升 VLA 在复杂动态场景下的可扩展性和泛化能力。

## 2. 方法论

### 核心思想
构建一个任务感知的“where–how”训练框架：
- **Where to Attend**：利用 **Drift-Guided Dynamic Prioritization (DGDP)** 自动发现动态活跃且与指令相关的视觉区域，为这些区域赋予更高训练权重。
- **How to Evolve**：利用 **Structured Feature Flow Generation (SFFG)** 建模这些区域的潜在状态演化过程，保持特征空间的结构化拓扑连续性。

### 关键技术细节

#### (1) Drift-Guided Dynamic Prioritization (DGDP)
- **Dynamic Position Prioritization (DPP)**：计算相邻时间步（t 与 t+T）同一 patch 的特征余弦相似度变化，得到动态分数 θ_i = 1 - cos(v_{t,i}, v_{t+T,i})。动态变化大的区域（如机器人末端、操作物体）获得更高分数。
- **Semantic Drift Guidance (SDG)**：计算每个 patch 特征与语言指令 token 的最大内积作为指令相关度 r。定义语义漂移 Δ_i = clip((r_{t+T,i} - r_{t,i})/τ, -δ, δ)，然后归一化并通过指数函数得到语义漂移引导因子 ω_i。当 patch 的语义向指令相关方向增强时，ω 更大。
- **优先级权重**：β_i = σ(ω_i · θ_i)，其中 σ 为 sigmoid 函数。β 用于后续特征预测损失中对各 patch 进行加权。

#### (2) Structured Feature Flow Generation (SFFG)
- **Prototype-to-Periphery (P2P) Prediction**：对未来时刻 t+T 的多视角特征进行聚类（如 k-means），得到簇集合 C。在每个簇内，按特征到簇中心距离从近到远排序（原型→外围）。P2P 预测损失 L_P2P 以排序顺序加权，并引入全局因子 α（本文设 α=1）与 β 联合调制，确保既关注关键区域又保持全局感知。
- **Mutual-neighborhood Contrastive (MC) Loss**：为每个锚点特征构建一阶（top-K）和二阶（top-M）邻域，只取双向互邻域构成正样本对。采用 InfoNCE 损失拉近互邻域特征，过滤聚类噪声导致的虚假连接。

#### (3) 训练损失
整体目标函数：L_total = λ1 L_action + λ2 L_P2P + λ3 L_MC。其中 L_action 为 L1 动作回归损失，用于并行动作解码。

**重要特性**：DGDP 和 SFFG 仅在训练阶段启用，推理时无额外开销。

## 3. 实验设计

### 数据集与场景
- **LIBERO 基准**：包含 Spatial、Object、Goal、Long 四个任务组，每组 10 个语言指令 × 50 个 episode，共 2000 个评估轨迹。
- **CALVIN 基准**：ABC-D 设置，5 个任务难度递进，报告每个任务成功率及平均任务长度。
- **真实世界实验**：使用 UR5 协作机械臂（6-DoF），三个操作任务：将物体放置到指定位置、按压按钮、关闭抽屉。每个任务评估 20 次连续尝试。

### 对比方法
- **小规模模型（<1B）**：Octo (0.1B)、UniACT (0.5B)、Seer (0.3B)、DreamVLA (0.3B)、FLOWER (1B)。
- **大规模模型（~7B）**：OpenVLA (7B)、π0 (3B)、π0.5 (3B)、OpenVLA-OFT (7B)、UniVLA (7B)、MemoryVLA、CoT-VLA (7B)。

成功率（%），LIBERO 报告各组平均及总平均；CALVIN 报告每个任务成功率及平均完成长度。

## 6. 主要结论与发现

1. **性能提升显著**：LEEVLA 在 LIBERO 和 CALVIN 上均达到 SOTA。LEEVLA-large 在 LIBERO 平均成功率 98.2%，CALVIN 平均任务长度 4.34；LEEVLA-mini 在 LIBERO 平均 97.5%，超越同等规模方法。
2. **组件互补性**：P2P 保证语义连续性，MC 保持局部拓扑，DPP 聚焦动态区域，SDG 对齐指令方向。四个组件联合带来最大增益。
3. **全局因子必要性**：单独使用 β 会造成过度聚焦，忽略背景上下文；α+β 联合可在聚焦关键区域的同时维持全局场景认知。
4. **特征重排序效果**：P2P 排序比无序预测性能更好，说明维护空间语义连续性对长程操作任务重要。
5. **低成本推理**：所有训练额外模块推理时不运行，不增加部署开销。

## 7. 优点

- **创新性的训练框架**：提出“where–how”双指导范式，在潜在空间进行结构化推理，避免了人工选择线索的局限性。
- **自动发现关键区域**：DGDP 无需额外标注或辅助模型，仅通过特征动态和语义漂移即可找到任务相关区域。
- **拓扑保持的流生成**：P2P 排序和 MC 对比损失既维持了空间语义连续性，又过滤了聚类噪声。
- **零推理开销**：训练时增加的模块在推理阶段全部移除，保证了实际部署的效率。
- **全面的实验验证**：在两个大规模仿真基准以及真实机器人上均进行评测，消融充分，对比方法涵盖主流。
- **代码开源**：提供了 GitHub 仓库，便于复现。

## 8. 不足与局限

- **实验覆盖范围**：仿真仅在 LIBERO 和 CALVIN 上进行，未涉及更多样化的场景（如多物体堆叠、可变形物体、非正面视角等）；真实世界仅测试三种简单任务，泛化性有待更复杂场景验证。
- **依赖预训练视觉模型**：DGDP 和 SFFG 基于 DINOv2/SigLIP 特征的固有嵌入，若更换视觉骨干可能需要重新调优。
- **训练计算成本**：虽然推理高效，但训练中 MC loss 的互邻域计算延迟较高（1200.91 ms），可能限制长序列或大规模数据的训练速度。
- **聚类稳定性**：P2P 依赖聚类结果（如 k-means），聚类数 L 等超参数需手动设定，且聚类质量对噪声敏感，可能影响预测性能。
- **假设限制**：方法假设未来时刻 t+T 的特征可通过动作驱动演化得到，对于无明确动作导致环境变化的任务（如纯感知任务）不适用。
- **偏差风险**：SDG 使用语言指令与 patch 特征的余弦相似度，若指令描述含糊或视觉与语言不匹配，引导可能产生偏差。

## 摘要
自主数据收集决定了操作策略学习中现实世界轨迹的数量和质量。现有流程通过自重置、VLM验证或语言引导修正来减少人力投入，然而面向回合的修正必须在相同失败再次发生时重新发出，因此监督成本随会话长度增长，而非随不同问题的数量增长。我们提出Zero2Skill，一种人机共生的代理系统，其中修正被保留并在各轮次中重用。收集循环自主进行收集、验证和重置，仅当某个阶段耗尽显式重试预算时才暂停以等待远程操作员。LLM解析器将每个自然语言表达映射为存储在修正记忆中的结构化调整，因此在相同条件下通常无需再次修正已处理的失败模式。在实际机器人桌面清理测试平台上，Zero2Skill在将人工工作时间减少至16%的同时，达到了与遥操作回合相当的成功率。语言修正提高了所有四种评估设置中验证器与人类的一致性，并将平均单次尝试成功率从12.5%提升至47.5%（手臂选择：从20.0%提升至50.0%）。在Zero2Skill数据上微调的策略在收集人力成本仅为一小部分的情况下，达到了与遥操作训练策略相当的成功率。

## Abstract
Autonomous data collection governs the volume and quality of real-world trajectories for manipulation policy learning. Existing pipelines reduce human effort via self-resetting, VLM verification, or language-guided correction, yet episode-scoped fixes must be reissued whenever the same failure recurs, so oversight cost grows with session length rather than with the number of distinct problems. We present Zero2Skill, a human-robot symbiotic agentic system in which corrections are retained and reused across rounds. The collection loop collects, verifies, and resets autonomously, pausing for a remote operator only when a phase exhausts an explicit retry budget. An LLM parser maps each natural-language utterance to a structured adjustment stored in Corrective Memory, so addressed failure modes typically need not be corrected again under the same conditions. On a real-robot desktop-clearing testbed, Zero2Skill matches teleoperation episode success while reducing human working time to 16%. Language corrections improve verifier-human agreement in all four evaluated settings and raise average single-attempt success from 12.5% to 47.5% (arm-selection: 20.0% to 50.0%). Policies fine-tuned on Zero2Skill data match teleoperation-trained policy success at a fraction of collection human cost.

## 2. 方法论
- **核心思想**：将数据收集循环建模为验证门控决策过程。系统自主执行收集、验证、重置三个阶段，每个阶段由 VLM 验证器判定是否成功，失败则自动重试直至预算耗尽；预算耗尽后暂停并异步通知远程操作员。操作员用自然语言描述问题，LLM 解析器将语言转化为结构化调整（如修正验证标准、调整抓取参数等），并存储为文本规则到“纠正记忆”。所有后续回合自动调用这些规则，使已修正的失败不再需要重复操作员介入。模型权重在本回合内不改变，仅在回合间通过数据微调演化。
- **关键技术细节**：
  1. **自主收集循环**：给定任务指令，代理自动生成收集和重置计划（包含动作序列和验证提示），然后交替执行收集阶段和重置阶段。每个阶段先执行命令，等待场景静止，用 VLM 对当前图像判断（是/否），通过则继续，否则自动重试最多 N 次（默认 3）。重试耗尽后进入 Alert 状态等待操作员。
  2. **语言干预与纠正记忆**：操作员输入自由语言，LLM 解析器结合当前状态和记忆，决定是否持久化。持久化规则包含触发条件、修正内容、作用范围，存储在结构化 Markdown 文件中。非持久化指令（如“向左挪一点”）只影响当前回合。
  3. **轨迹标注与质量认证**：每个回合记录执行状态和 VLM 结果，区分基础设施错误与策略失败。验证标准在语言修正后可离线重新标注全量数据。质量检查独立于任务成功，确保留存轨迹可用。
  4. **策略学习与数据飞轮**：通过验证的轨迹用于微调基础 VLA 策略（论文使用 π0.5）。当前工作仅评估单个收集-训练-部署循环，多轮飞轮作为未来工作。
- **算法流程**：Algorithm 1 描述了收集-重置循环：设置目标轨迹数 K，每轮依次执行收集阶段和重置阶段。每个阶段 RunPhase 过程：重试 N 次执行命令，每次 VLM 验证，成功则退出；否则进入 Alert 等待操作员反馈后重试该阶段。

## 7. 优点
- **方法层面**：
  1. 提出“验证门控决策 + 纠正记忆”框架，将人类反馈转化为可复用的文本规则，实现人力开销与问题数量而非会话长度成正比。
  2. 语言通道统一了验证标准修正和执行策略修正，避免了预设参数接口的限制。
  3. 系统中验证、重试、干预流程设计清晰，reset 阶段单独验证防止场景漂移（silent drift），实用性高。
- **实验层面**：
  1. 在真实机器人平台上进行大量控制实验，包括消融（累积修正、手臂选择分离）、逐物体分析，验证了各模块贡献。

  3. 下游策略测试时完全去除辅助模块，保证结果可靠。

## 摘要
视觉-语言-动作（VLA）模型在机器人操作中实现了令人印象深刻的泛化能力，最近记忆增强的VLA通过基于过去的图像或语言摘要进行条件化，放松了马尔可夫假设。基于视觉的记忆方法通过对过去采样的图像帧进行条件化来解决这一问题，但计算成本高，且在时间事件视觉上模糊时（例如，多次用微小动作按按钮）根本受限。我们提出FM-VLA，一种具有基于力记忆的VLA模型，能够实现非马尔可夫、接触丰富操作的时间上下文推理。我们使用预训练于力时间序列重建的变分自编码器（VAE）将力历史编码为紧凑的力记忆令牌。通过将力潜在表示和短状态历史作为额外的条件令牌投影到动作专家模块，我们使VLA能够利用累积的接触事件历史来指导操作。我们在三个记忆依赖任务上评估FM-VLA，包括寻找隐藏方块、按动按钮和擦拭盘子特定次数。我们的轻量级力记忆以最小的推理开销实现了超过80%的成功率，显著优于基线方法。项目页面：https://qft-333.github.io/FM-VLA-Page/

## Abstract
Vision-language-action (VLA) models have achieved impressive generalization in robotic manipulation, and recent memory-augmented VLAs have relaxed the Markovian assumption by conditioning on past images or language summaries. Vision-based memory approaches address this by conditioning on sampled past image frames, but they are computationally expensive and fundamentally limited when temporal events are visually ambiguous, e.g., pushing a button multiple times with small movements. We propose FM-VLA, a VLA model with force-based memory, enabling temporal context reasoning for non-Markovian, contact-rich manipulation. We encode force histories into compact force memory tokens with a variational autoencoder (VAE) pretrained with force time series reconstruction. By projecting force latent representations and short state history as additional conditioning tokens to the action expert module, we enable VLAs to leverage accumulated contact event history to guide manipulation. We evaluate FM-VLA on three memory-dependent tasks, including finding a hidden block, pressing a button, and wiping a dish for a specific number of times. Our lightweight force memory achieves over 80% success rate with minimal inference overhead, significantly outperforming baseline approaches. Project page: https://qft-333.github.io/FM-VLA-Page/

### FM-VLA: 基于力记忆的视觉-语言-动作模型在接触丰富操作中的应用

#### 1. 论文的核心问题与整体含义

- **研究动机与背景**：
    - **背景**：现有的视觉-语言-动作模型通常假设决策过程是马尔可夫的，即当前动作仅取决于当前观测。然而，许多真实世界的操作任务是**非马尔可夫**的，需要基于长期的时间上下文进行决策，例如需要计数（按按钮N次）、跟踪进度（擦拭盘子N次）或对部分可观测状态进行推理（寻找隐藏物体）。
    - **问题**：
        - **视觉记忆的局限性**：虽然已有研究（如 MEM, MemoryVLA）通过引入基于图像或语言的记忆机制来打破马尔可夫假设，但它们存在两个关键缺陷：
            1.  **视觉模糊性**：在接触丰富的任务中，许多关键事件（如按钮按压、擦拭动作）不会引起明显的视觉变化，导致视觉记忆失效。
            2.  **计算开销大**：存储和处理历史图像帧会显著增加输入令牌长度和推理延迟。
        - **现有力信号利用的不足**：已有工作（如 ForceVLA, TA-VLA）引入了力/触觉信号，但仅将其作为当前时刻的辅助信号或短期上下文，用于修正当前动作，而**未能利用其作为长期记忆**来跟踪交互进度。

- **核心含义**：
    该论文提出**FM-VLA**，旨在解决现有方法在面对需要长期时序推理的接触丰富任务时的局限性。核心思想是，将**接触事件本身**（通过力传感器捕获的力/力矩信号）作为一种**高效且信息丰富的记忆媒介**，替代昂贵的视觉记忆，从而使VLA模型能更可靠、更高效地进行非马尔可夫决策。

#### 2. 方法论：核心思想与关键技术

- **核心思想**：
    将长周期的力（扳手）历史信号压缩成紧凑、有信息量的记忆表示，与短周期状态历史一起注入VLA的动作专家模块，以提供任务所需的时序上下文。

- **关键技术细节**：
    1.  **双流记忆设计**：策略 `π(a_t | o_t, l, h_t)` 被增强为依赖两种历史信息：
        - **长期力历史（Wrench History）**：`{f_τ}`，来自手腕6轴力/力矩传感器，捕获整个回合内的接触事件。
        - **短期状态历史（State History）**：`{s_τ}`，来自机器人关节位置和夹爪状态，提供近期运动上下文，防止接触前的重复行为。
    2.  **力记忆编码器 (Force Memory Encoder)**：
        - **预处理**：对原始力信号进行一阶指数移动平均（EMA）平滑降噪。在训练时添加随机长度的噪声前缀，防止模型利用序列长度作为进度捷径。
        - **两阶段训练**：
            - **第1阶段：力-VAE预训练**：训练一个基于Perceiver-IO的变分自编码器（VAE），通过无监督的力时间序列重建任务（最小化 `L_VAE`），将长周期的力信号压缩成**固定数量的K个紧凑的潜在令牌** `Z_f`。这使得VAE能学习到通用的力信号时空结构，如力的幅值、接触起止时间和次数。
            - **第2阶段：VLA微调**：冻结训练好的力-VAE编码器，将其输出的潜在均值 `μ_f` 作为力记忆令牌，通过线性层投影到动作专家的隐藏维度。
    3.  **短状态记忆 (Short State Memory)**：
        - 将最近几帧的关节状态窗口 `S_t` 展平，通过一个轻量级线性层投影成一个单独的状态记忆令牌 `z_s`。
    4.  **记忆令牌注入 (Memory Token Injection)**：
        - 将力记忆令牌（K个）和状态记忆令牌（1个）拼接在动作专家的**噪点动作令牌**之后。这种排列保证了噪点动作令牌的旋转位置编码不变，并且能通过交叉注意力机制影响后续的动作生成。整个VLA模型（VLM、动作专家、状态投影器、力记忆投影器）在第二阶段进行端到端微调，损失函数为 `L`（基于整流流的动作预测损失）。

#### 6. 主要结论与发现

1.  **力记忆有效性**：FM-VLA在所有任务上平均成功率达83.3%，显著优于所有基线。尤其是在需要精细时序推理的**按钮**和**擦拭**任务上，优势最为突出。
2.  **视觉记忆的不足**：视觉记忆（π-MEM）在视觉变化不明显的任务（如按钮）上表现不佳（33.3%），证实了其局限性。
3.  **模态互补性**：单纯使用力历史或状态历史都会导致性能大幅下降。力历史与短状态历史的结合是成功的关键。
4.  **VAE结构的优越性**：基于VAE的力编码器优于GRU和Q-Former，因为它通过无监督重建学习到了力信号的宏观结构（幅值、时间），而非过拟合于瞬间峰值或遭受梯度消失问题。
5.  **推理高效性**：FM-VLA仅增加3ms的推理延迟（相对于基础模型），远低于基于视觉记忆的方法（39ms~129ms），展现了力信号作为记忆媒介的高效性。

#### 7. 优点

- **创新性**：首次将力/力矩流作为**长期记忆**引入VLA模型，解决了非马尔可夫问题的一个关键短板，是一种全新的思路。
- **轻量高效**：力信号维度低、频率高，压缩成少量令牌后，对计算和延迟的影响极小，远优于处理图像序列。
- **感知互补**：能捕获视觉上“看不见”的关键交互信息（如接触事件计数），与视觉形成了很好的互补，极大地增强了VLA在接触丰富任务中的鲁棒性。
- **设计合理**：两阶段训练范式（无监督VAE预训练 + 监督VLA微调）保证了力编码器能够学习到通用且有意义的潜在表示。通过随机噪声前缀等技巧规避了隐式的长度偏差。

#### 8. 不足与局限

- **固定压缩瓶颈**：当前VAE使用固定的8个令牌作为压缩瓶颈，对于超长任务（数百次接触事件）可能信息不足，需要更高级或自适应的压缩机制。
- **训练数据依赖**：VAE仅在演示数据集的力数据上训练，如果能在更大规模、更多样化的机器人力/力矩记录数据集上进行预训练，通用性可能会进一步提升（虽未验证）。
- **任务场景局限**：方法核心依赖于力传感器。对于无法安装力传感器或交互力极小、信号淹没在噪声中的任务，该方法可能不适用。
- **重复行为隐患**：论文模型发现，仅用力历史会导致接触前的重复行为，因此加入了短状态历史。这说明了力记忆本身并非完美，需要其他条件进行补偿。
- **实验硬件局限**：实验仅在AgiBot G1这一种机器人平台上进行。方法的迁移性（到其他构型或具备不同传感器特性的机器人）尚未得到验证。

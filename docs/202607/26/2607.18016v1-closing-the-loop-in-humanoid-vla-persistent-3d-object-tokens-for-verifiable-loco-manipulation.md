## 摘要
视觉-语言-动作策略是通用机器人控制的有前景基础，但长时程类人机器人的移动操作要求机器人将任务对象视为跨运动、接触、遮挡和恢复的持久物理实体。我们将此问题建模为对象状态发散：用于调节全身动作的对象状态可能与用于判断动作是否实现预期物理关系的状态不同。我们提出**持久化对象令牌化**（POT），该方法从RGB-D观测中维护角色索引的3D对象记录，并将其转换为对象令牌以用于全身动作专家。实例化为**POT-VLA**，相同的对象记录同时调节动作生成并支持几何谓词检查，从而形成对象状态既可操作又可验证的闭环执行系统。在Unitree G1上，POT-VLA在8个真实世界任务族中将匹配的直接GR00T-N1.7基线从39/80的成功率提升至71/80。在外部Being-0对齐参考中，POT-VLA在对齐服务任务上取得44/50的成功率，而Being-0论文报告的成功率为37/50。最大的提升出现在需要维持3D关系的任务上，这表明持久化以对象为中心的状态是可验证类人VLA执行的有效抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：长时程人形机器人移动操作（loco-manipulation）中，物体状态“发散”（object-state divergence）是一个关键失效模式。即用于条件化全身动作的物体状态（如当前观测中的视觉特征）与用于判断动作是否达成预期物理关系（如抓取、放置、支撑、递送）的状态不一致。
- **核心挑战**：机器人需要将任务对象视为跨行走、接触、遮挡、失败恢复的持久物理实体，但现有VLA策略通常将物体状态隐式编码在视觉-语言特征中，难以在动作后刷新或与验证器共享。
- **整体含义**：提出**持久化物体令牌化（POT）**，构建以物体为中心的持久物理记忆，同时驱动动作生成和结果验证，从而实现可验证的闭环执行。

## 2. 方法论
### 核心思想
- 维持一个**角色索引的3D物体记忆**（role-indexed object memory），在机器人基座坐标系下存储任务相关实体的度量3D信息。
- 将该记忆序列化为**持久化3D物体令牌**（Persistent 3D Object Tokens），插入到全身动作专家（action expert）的注意力序列中，使得动作预测显式依赖度量3D物体状态。
- 动作执行后，RGB-D观测刷新同一记忆，并通过**几何谓词监督器**（geometric predicate supervisor）验证物理关系是否达成，形成“感知→动作→验证”闭环。

### 关键技术细节
- **物体记录构建**：利用SAM3（Segment Anything Model 3）获取物体掩码，通过RGB-D反投影到基座坐标系，记录角色（TARGET, DESTINATION, SUPPORT, HANDOVER_PARTNER等）、度量3D中心、范围、可见性、置信度、空间关系特征（如物体-容器距离、末端执行器-物体偏移等）。
- **令牌模式**：默认分配K=8个槽，每个槽含F=33个特征（可见性、置信度、2D框、3D中心、3D尺寸、可选的朝向、关系特征）。未使用槽标记为PADDING并掩码。
- **动作专家插入**：令牌序列布局为 `[状态令牌, 物体令牌, 动作令牌]`，物体令牌通过LayerNorm→Linear→GELU→Dropout→Linear投影到DiT隐藏维度，并与角色嵌入和上下文嵌入结合。动作专家预测全身动作块。
- **谓词验证**：每个子任务定义物理关系谓词（如containment, support, proximity等），基于刷新后的物体记录计算标量证据，决定子任务状态（in_progress, done, blocked, failed, uncertain），触发重观测、重尝试或重规划。

## 摘要
视觉-语言-动作（VLA）模型旨在将多模态输入映射到机器人动作。然而，现有大多数方法由于统一对待所有视觉token并使用人工选择的因素进行推理，缺乏强调任务关键证据的机制，忽略了潜在因素，因此难以覆盖复杂动态场景。为解决这一问题，我们提出LEEVLA，一种在潜在环境演化中关注关键信息的VLA架构，明确引导模型关注信息区域，同时保持潜在世界表征的结构化演化。为了识别显著且与指令相关的区域，我们引入漂移引导的动态优先级（DGDP），它结合了动态位置优先级（DPP）和语义漂移引导（SDG），在训练过程中引导VLA智能体关注何处。在此基础上，我们引入结构化特征流生成（SFFG），通过原型到外围（P2P）预测来建模这些优先级特征如何在潜在空间中演化，以及一个互邻域对比（MC）损失来保持邻域间的拓扑一致性。DGDP和SFFG共同构成了一个任务感知的“哪里-如何”训练框架。在VLA基准上的大量实验表明，LEEVLA持续优于先前方法，证实了明确的任务证据引导和结构化的潜在推理对于可扩展的VLA都至关重要。我们的代码可在 https://github.com/LyuQi127/LEEVLA 获取。

## Abstract
Vision-language-action (VLA) models aim to map multimodal inputs to robot actions. However, most existing approaches struggle to cover complex dynamic scenarios due to treating all visual tokens uniformly and reasoning with human-selected factors, which lack mechanisms to emphasize task-critical evidence and ignore underlying factors. To address this issue, we propose LEEVLA, a VLA architecture for seeing what matters in Latent Environment Evolution that explicitly guides the model toward informative regions while preserving the structured evolution of latent world representations. To identify salient and instruction-relevant regions, we introduce drift-guided dynamic prioritization (DGDP), which combines dynamic position prioritization (DPP) with semantic drift guidance (SDG) to guide the VLA agent where to attend during training. On top of this, we introduce structured feature flow generation (SFFG), which models how these prioritized features should evolve in latent space via prototype-to-periphery (P2P) prediction, and a mutual-neighborhood contrastive (MC) loss to maintain topological consistency among neighborhoods. Together, DGDP and SFFG form a task-aware "where-how" training framework. Extensive experiments on VLA benchmarks show that LEEVLA consistently outperforms prior methods, confirming that explicit task-evidence guidance and structured latent reasoning are both crucial for scalable VLA. Our code is available at https://github.com/LyuQi127/LEEVLA.

- **核心问题**：现有的视觉-语言-动作（VLA）模型在复杂动态场景中表现不佳，主要原因有两方面：
  - **统一对待所有视觉 token**：模型对所有视觉特征一视同仁，缺乏对任务关键区域的聚焦机制，导致梯度被静态背景或无关物体稀释。
  - **依赖人工选择的外部条件**：许多方法使用人类指定的线索（如子目标图像、分割、深度）进行显式推理，限制了搜索空间，忽略了潜在的、但任务相关的未知因素；且依赖辅助模型带来额外开销。
- **整体含义**：为了克服这些限制，论文提出在**潜在特征空间**中直接进行推理，将动作视为环境状态在高维空间中演化的驱动力，并同时解决“关注哪里”（where to attend）和“如何演化”（how to evolve）两个问题。作者认为，显式的任务证据引导和结构化的潜在推理对于构建可扩展的 VLA 模型至关重要。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
LEEVLA（Latent Environment Evolution VLA）通过两个主要模块实现“关注哪里”和“如何演化”：
- **漂移引导动态优先级（DGDP）**：自动发现训练中应关注的显著且与指令相关的区域。
- **结构化特征流生成（SFFG）**：建模这些优先级特征如何在潜在空间中结构化地演化，并保持拓扑一致性。

### 2.2 关键技术细节

#### (a) 漂移引导动态优先级（DGDP）
由两个子组件组成，仅在训练时使用，推理时不增加额外成本：
- **动态位置优先级（DPP）**：通过计算相邻时间步（t 和 t+T）视觉特征间的余弦相似度变化，量化每个空间位置的“动态性”。动态性得分 θ_i = 1 - cos(v_{t,i}, v_{t+T,i})，动态性高的区域（如机器人、任务物体）获得更高权重。
- **语义漂移引导（SDG）**：根据语言指令计算每个 patch 的“指令相关性”得分 r_{t,i}（取与语言 token 的最大内积），然后定义语义漂移 Δ_i = clip((r_{t+T,i} - r_{t,i})/τ, -δ, δ)，再通过归一化和指数函数得到语义漂移引导因子 ω_i。最终优先级权重 β_i = σ(ω_i · θ_i)（σ 为 sigmoid 函数）。这确保模型不仅关注动态区域，而且关注语义向指令方向演变的区域，抑制向背景语义漂移的 patches。

#### (b) 结构化特征流生成（SFFG）
同样仅在训练时使用，包含两个部分：
- **原型到外围（P2P）预测**：
  - 对多视角未来特征（t+T时刻）进行聚类，得到簇集合 C，每个簇有质心 μ_ℓ。
  - 在每个簇内，按成员与质心的欧氏距离从近到远排序（原型→外围），形成有序序列。
  - P2P 损失函数为：L_{P2P} = (1/|C|) ∑_ℓ (1/|→c_ℓ|) ∑_{j∈→c_ℓ} (α + β_j) φ(ˆv_{t+T,j}, v_{t+T,j})，其中 φ 是余弦嵌入损失，α 是全局调制因子（默认=1），β_j 是 DGDP 权重。这迫使模型从原型开始逐步细化预测，保持语义连续性。
- **互邻域对比（MC）损失**：
  - 为了在噪声聚类下获得鲁棒的对比监督，基于高置信度邻域关系构建正样本对：首先对每个锚点 i 构建一阶邻域集 G^{(1)}_i（TopK 最近邻，K=10），再构建二阶邻域集 G^{(2)}_i（一阶邻域中每个点的 TopM 近邻的并集，M=5）。
  - 只保留**互邻域**（i 在 j 的邻域中且 j 在 i 的邻域中）作为正样本集 G^+_i，以抑制噪声链接。
  - MC 损失采用 InfoNCE 形式：L_{MC} = -(1/|I|) ∑_{i∈I} (1/|G^+_i|) ∑_{j∈G^+_i} log(exp(S_{ij}/τ_c) / ∑_{ℓ≠i} exp(S_{iℓ}/τ_c))，其中 S 为余弦相似度，τ_c 为温度。该损失强化潜在空间中语义近邻的拓扑一致性。

#### (c) 总体训练目标
总损失 L_total = λ1 L_action + λ2 L_P2P + λ3 L_MC，其中 L_action 为 L1 动作回归损失（并行动作预测头输出连续动作）。超参数 λ 平衡各部分。

#### (d) 网络架构概述
采用预训练视觉编码器（DinoV2、SigLIP）提取 patch 特征，经投影器映射为 token，与语言指令 token 和本体感知嵌入一起输入大语言模型（LLM），LLM 输出经过动作预测头（MLP）生成连续动作 chunk。未来特征解码器（D）将当前视觉嵌入映射到未来特征空间用于损失计算。

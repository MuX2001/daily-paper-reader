## 摘要
视觉-语言-动作（VLA）模型旨在将多模态输入映射到机器人动作。然而，现有方法大多因统一处理所有视觉标记并使用人工选择的因素进行推理而难以覆盖复杂的动态场景，缺乏强调任务关键证据的机制并忽略潜在因素。为此，我们提出LEEVLA，一种用于在潜环境演化中关注关键信息的VLA架构，该架构显式引导模型关注信息密集区域，同时保持潜世界表征的结构化演化。为识别显著且与指令相关的区域，我们引入漂移引导的动态优先级排序（DGDP），它结合动态位置优先级排序（DPP）与语义漂移引导（SDG），以指导VLA代理在训练中的注意力焦点。在此基础上，我们引入结构化特征流生成（SFFG），通过原型到外围（P2P）预测建模这些优先级特征在潜空间中的演化方式，并采用互邻域对比（MC）损失以保持邻域的拓扑一致性。DGDP与SFFG共同构成任务感知的“何处-如何”训练框架。在VLA基准上的大量实验表明，LEEVLA持续优于先前方法，证实显式任务证据引导与结构化潜推理对于可扩展VLA均至关重要。我们的代码见https://github.com/LyuQi127/LEEVLA。

## Abstract
Vision-language-action (VLA) models aim to map multimodal inputs to robot actions. However, most existing approaches struggle to cover complex dynamic scenarios due to treating all visual tokens uniformly and reasoning with human-selected factors, which lack mechanisms to emphasize task-critical evidence and ignore underlying factors. To address this issue, we propose LEEVLA, a VLA architecture for seeing what matters in Latent Environment Evolution that explicitly guides the model toward informative regions while preserving the structured evolution of latent world representations. To identify salient and instruction-relevant regions, we introduce drift-guided dynamic prioritization (DGDP), which combines dynamic position prioritization (DPP) with semantic drift guidance (SDG) to guide the VLA agent where to attend during training. On top of this, we introduce structured feature flow generation (SFFG), which models how these prioritized features should evolve in latent space via prototype-to-periphery (P2P) prediction, and a mutual-neighborhood contrastive (MC) loss to maintain topological consistency among neighborhoods. Together, DGDP and SFFG form a task-aware "where-how" training framework. Extensive experiments on VLA benchmarks show that LEEVLA consistently outperforms prior methods, confirming that explicit task-evidence guidance and structured latent reasoning are both crucial for scalable VLA. Our code is available at https://github.com/LyuQi127/LEEVLA.

## 一、核心问题与整体含义（研究动机和背景）

- **问题**：现有VLA模型（如OpenVLA）一般将所有视觉token均匀处理，依赖人工选择的特定上下文线索（如子目标图像、分割、深度）进行推理。这导致两个缺陷：
  1. 缺乏机制突出任务关键证据，对动态变化区域（如机器人手、目标物体）关注不足；
  2. 忽略数据中隐含的任务相关因素（unknown factors），仅利用已知因素（known factors），在模态变化或相似物体混淆时表现脆弱。
- **动机**：为了使VLA更好地处理复杂动态场景，需要同时解决“在哪里注意”（where to attend）和“如何演化”（how to evolve）两个问题。本文主张直接在潜特征空间进行推理，利用预训练视觉模型（如DINOv2、SigLIP）提供的丰富多模态信息，避免依赖外部辅助模型。
- **整体含义**：提出LEEVLA，通过显式结构化的 “where–how” 训练框架，让VLA自动发现重要区域并建模环境状态的潜在演化，从而提升泛化能力和长程推理能力。

## 二、方法论：核心思想、关键技术细节

### 核心思想
- 在训练阶段使用 **漂移引导的动态优先级排序 (DGDP)** 为模型指明应关注的区域；使用**结构化特征流生成 (SFFG)** 引导模型学习这些区域如何随时间在潜空间中演化。
- DGDP和SFFG仅在训练时生效，测试时无额外计算开销。

### 关键技术细节

1. **Drift-Guided Dynamic Prioritization (DGDP)**  
   - **Dynamic Position Prioritization (DPP)**：计算相邻时间步特征之间的余弦相似度变化，得到动态分数 θ_i，突出变化剧烈的区域（如移动的物体/机械臂）。
   - **Semantic Drift Guidance (SDG)**：根据视觉特征与语言指令的相似度（内积）计算每patch在时间t和t+T的指令相关性分数，然后定义语义漂移 Δ_i，并进行归一化得到权重 ω_i。该权重能抑制向指令不相关方向漂移的区域。
   - 最终优先权重 β_i = σ(ω_i · θ_i)（σ为sigmoid），用于在后续预测损失中加权。

2. **Structured Feature Flow Generation (SFFG)**  
   - **Prototype-to-Periphery (P2P) 预测**：对多视角未来特征进行聚类得到簇，每个簇内按照与质心的距离从近到远排序（原型→外围）。预测损失按此顺序赋予加权（权重为α + β_j），强制模型先关注簇中心（原型），再细化外围。
   - **Mutual-neighborhood Contrastive (MC) Loss**：构建基于互邻域的正样本对（过滤噪声链接），使用InfoNCE损失拉近互邻域特征，保持潜空间局部拓扑一致性。

3. **训练目标**：整体损失 L_total = λ1 L_action (L1) + λ2 L_P2P + λ3 L_MC。L_action为预测动作chunk与真值之间的L1距离。

4. **网络架构**：在OpenVLA/ miniVLA基础上增加未来特征解码器（Future Feature Decoder）和并行连续动作预测器（Parallel Continuous Action Predictor）。训练时，当前时刻视觉特征和语言指令送入LLM，同时未来特征解码器预测t+T时刻的特征，并施加P2P和MC损失；动作预测器从LLM隐状态输出动作chunk。

## 六、主要结论与发现

1. **DGDP和SFFG联合使用显著提升性能**：在LIBERO上，LEEVLA-mini达到97.5%平均成功率（比FLOWER高1.8%），LEEVLA-large达到98.2%（比π0.5高0.7%）；在CALVIN上平均长度4.34（超过OpenVLA-OFT的4.10）。
2. **结构化潜推理优于人工选择的外部条件**：直接在潜特征空间进行有序（P2P）和拓扑保持（MC）的演化预测，比依赖子目标图像、分割等外部线索更鲁棒。
3. **“哪里”和“如何”两个模块互补**：DGDP提供注意力聚焦，SFFG提供结构化演化建模，共同作用效果最强（消融表中逐步添加均带来提升）。
4. **特征重排序和全局因子α必不可少**：重排序将关联patch聚合预测，避免语义碎片；α维持全局背景上下文，防止过度聚焦导致忽视场景布局。
5. **无额外推理开销**：所有训练时模块在推理时丢弃，LEEVLA-large推理延迟（124.36ms）与OpenVLA-OFT（124.03ms）几乎相同。

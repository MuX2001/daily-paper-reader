## 摘要
基于模型的强化学习中的世界模型评估通常考察学习到的模型是否能很好地预测奖励和值，这可能会遗漏模型潜在轨迹中与规划相关的错误。我们引入一种互补的诊断方法——F上的算子，它通过模型自身的预测器，将模型在可观测子集F上的k步潜在前推与环境中的进行比较。在针对cheetah-run的TD-MPC2规模扫描中，每个模型大小的奖励预测误差都保持在[0.028, 0.091]范围内——仅约3倍变化，因此未归一化的奖励拟合检查的分辨率有限，难以区分它们；未归一化的贝尔曼残差和奖励误差本身与回报的关系较弱（斯皮尔曼相关系数分别为-0.10和-0.30）。在相同规模下，算子误差的范围从0.28到2.62。在317M时，算子误差为2.62——比0.28-0.36的聚类高一个数量级——规划回报降至0.9，而奖励预测误差（0.091）是五个中最高的，但仍与扫描其他部分相同的[0.028, 0.091]小范围内。算子误差与回报损失之间的排名相关为-0.90（n=5个规模时，锚定自举95% CI [-0.90, -0.70]；剔除任何一个规模后，仍保持-0.80或更强）。在TD-MPC2与纯SSL潜世界模型的跨架构比较中，该算子还返回了信息丰富、具有架构鉴别能力的估计。算子诊断是对值等价的补充，而非替代。

## Abstract
World-model evaluation for model-based reinforcement learning typically asks whether the learned model predicts reward and value well, which can leave planning-relevant errors in the model's latent rollouts unmeasured. We introduce a complementary diagnostic, operator-on-F, that compares a model's k-step latent pushforward to the environment's on an observable subset F, using the model's own predictor. On a TD-MPC2 size sweep over cheetah-run, reward-prediction error stays within [0.028, 0.091] for every model size - only about 3x variation - so an unnormalized reward-fit check has narrow resolution to distinguish them; the (unnormalized) Bellman residual and reward error themselves have weak relationships with return (Spearman -0.10 and -0.30). Operator error spans 0.28 to 2.62 over the same sizes. At 317M the operator error is 2.62 - an order of magnitude above the 0.28-0.36 cluster - and the planning return collapses to 0.9, while reward-prediction error (0.091) is the highest of the five but stays within the same small [0.028, 0.091] range as the rest of the sweep. The rank correlation between operator error and return loss is -0.90 (anchor-bootstrap 95% CI [-0.90, -0.70] at n=5 sizes; leave-one-out removal of any single size leaves it at -0.80 or stronger). The operator also returns informative, architecture-discriminating estimates in a cross-architecture comparison between TD-MPC2 and a pure-SSL latent world model. The operator diagnostic complements value-equivalence rather than replacing it.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：在基于模型的强化学习中，世界模型的评估通常只考察模型是否能很好地预测奖励和值函数（即“值等价”原则）。然而，这种评估方式可能遗漏模型潜在轨迹中与规划性能直接相关的错误——即使奖励预测误差很小，模型的潜在滚动（latent rollout）也可能存在严重偏差，导致规划失败。
- **整体含义**：需要一种能够直接检测潜在世界模型在规划时动态转移质量的诊断方法，作为现有值等价评估的补充。本文提出的 **operator-on-F** 诊断正是为了解决这一缺口。

## 2. 论文提出的方法论

- **核心思想**：在可观测子集 F 上，比较模型自身的 k 步潜在前推（latent pushforward）与环境实际转移之间的差异。F 可以是奖励、值函数，或者通过探针（probe）从编码后的下一状态几何中提取的观测级特征。
- **关键技术细节**：
  - 定义 per-anchor operator error：对于每个锚点 (s_t, a_{t:t+k-1}, s_{t+k})，计算 ϕ(ẑ_{t+k}) 与 ϕ(z'_{t+k}) 之差，并用真实前推的跨锚点标准差归一化。
  - 聚合：对每个功能性 ϕ，采用 RMS 聚合；全 F 聚合则包括值切片（奖励和值函数）以及一个基于 PCA 的几何方向集（前 16 个主成分，用奇异值白化，在训练/评估分割上交叉验证）。

  - k 步匹配每个模型的原生规划步长（本文均使用 5 个收集步的预测）。

## 6. 论文的主要结论与发现

- 在 TD-MPC2 规模扫描中，**reward-prediction error 在所有规模上仅变化约 3 倍（0.028~0.091），无法区分模型优劣**；而 **operator-on-F 误差跨度 0.28~2.62（约 10 倍）**，且在 317M 模型上出现异常高值（2.62），对应规划回报崩溃至 0.9。
- **Operator-on-F 与回报损失的秩相关为 -0.90（95% CI [-0.90, -0.70]）**，而奖励预测误差和贝尔曼残差与回报的相关系数分别为 -0.30 和 -0.10，说明 operator 更灵敏地反映规划性能。
- **归一化是关键**：未归一化的值误差与贝尔曼残差几乎等同（Spearman +1.00），而归一化后的 operator-on-F 才能揭示真实排名。
- 跨架构对比中，**LeWM 的 operator 误差（0.384 ± 0.009）显著低于单任务 TD-MPC2（0.840），95% CI 不重叠**，表明该诊断可有效区分不同架构的模型质量。
- 论文强调 **operator-on-F 是值等价的补充而非替代**，推荐两者同时报告。

## 7. 优点

- **方法创新**：提出了一个基于 Koopman 算子思想的规划时直接诊断方法，直接比较潜在动力学前推质量，而非间接依赖奖励/值预测。
- **归一化设计**：通过跨锚点标准差归一化，使不同特征量级的误差可比，避免了传统未归一化指标的分辨率不足。
- **探针协议严谨**：明确报告探针 R²，采用岭回归和网格寻优，控制容量-信息混淆；同时用 MLP 探针消融和常见良好探针子集验证结果稳健性。
- **统计严谨**：使用锚定自举计算置信区间、留一法验证排名稳定性、部分相关系数控制混杂变量。
- **可跨架构使用**：operator-on-F 可以用于没有奖励/值头的模型（如 LeWM），通过共享观测级 F 实现公平比较。

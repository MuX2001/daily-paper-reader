## 摘要
将真实世界转换为用于机器人物体交互的仿真仍依赖于大量人工操作，因为这一过程不仅需要视觉重建，还要求恢复场景几何与物体状态、推断物理参数，并将执行器、物体、相机、位姿与轨迹整合为可运行的物理仿真。目前，该流程仍依赖于对视觉基础模型的手工调参、网格清理、坐标系对齐，以及跨视觉感知工具与仿真器的脆弱工作流衔接。我们提出	extit{代理式实到虚}，一个基于视觉语言代理的通用物理世界建模框架，能将物体-机器人交互的真实世界记录转换为可仿真的事件双胞胎，保留观测、几何、机器人交互及物体状态。我们在刚体操作、可变形物体交互与人形运动场景上评估了代理式实到虚，这些场景通常由独立的实到虚管道处理，标志着向可扩展转换迈出的第一步。该框架的代理决策可由开源权重视觉语言模型后端驱动，成本仅为前沿模型的极小部分，同时达到相当的转换成功率。我们旨在将生成的与真实世界对齐的双胞胎用于下游机器人任务，特别是策略学习与评估。项目网站见https://ericchen321.github.io/agentic_real2sim.github.io/。

## Abstract
Real-to-sim conversion for robotic interaction with objects remains labor-intensive because it requires more than visual reconstruction: a streamlined real2sim process must recover scene geometries and object states, infer physical parameters, and assemble actors, objects, cameras, poses, and trajectories into a runnable physical simulation. Today this process still depends on manual tuning of visual foundation models, mesh cleanup, coordinate-frame alignment, and brittle workflow glue across visual perception tools and simulators. We introduce \textit{Agentic Real2Sim}, a framework for generalized physical world modeling with vision-language agents, converting a real-world recording of object-robot interaction into a simulatable episodic twin which preserves observations, geometries, robot interactions, and object states. We evaluate Agentic Real2Sim on rigid-object manipulation, deformable-object interaction, and humanoid motion scenes, spanning domains that are usually handled by separate Real2Sim pipelines, marking a first step toward scalable conversion. The framework's agentic decisions can be driven by an open-weight VLM backend at a small fraction of the cost of frontier models, while attaining comparable conversion success rate. We aim to use the resulting real-world-aligned twins for downstream robotics tasks, specifically policy learning and evaluation. The project site is available at https://ericchen321.github.io/agentic_real2sim.github.io/.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 提出 **Agentic Real2Sim** 框架，将真实交互记录转换为可仿真的“事件双胞胎”（episodic twin），形式化为：
  \[
  \mathcal{T} = (\mathcal{O}, \mathcal{A}, \mathcal{G}, \mathcal{S}_{1:T}, \Theta, \mathcal{B}, \mathcal{M})
  \]
  其中 \(\mathcal{O}\) 为真实观测，\(\mathcal{A}\) 为执行器/末端，\(\mathcal{G}\) 为几何和外观资产，\(\mathcal{S}_{1:T}\) 为模拟器状态序列，\(\Theta\) 为物理和对齐参数，\(\mathcal{B}\) 为模拟后端，\(\mathcal{M}\) 为度量与评估轨迹。

### 关键技术细节（四个代理模块）
1. **视觉处理代理**：从原始视频提取分割和深度掩码、重建几何、估计物体位姿。使用 SAM 3 进行分割，SAM 3D 恢复网格，FoundationStereo 估计深度，FoundationPose 进行 6D 位姿跟踪。采用“关键帧选择-掩码拒绝-重试”机制确保质量。
2. **物理先验推理代理**：为物体分配身份、材料类别、质量提示等仿真需要的物理属性。
3. **场景准备代理**：对齐机器人基座位姿、地面平面、相机坐标系、重建几何，并初始化 MuJoCo 仿真场景。
4. **仿真器内抓取优化**：通过确定性扫描或LLM辅助循环，优化被操作物体的位置，使机器人能够成功抓取。

- **流程特点**：将确定性工具（分割、重建、跟踪、仿真渲染）与代理决策（VLM驱动）分离。VLM仅处理需要模糊推理的决策（如物体发现、关键帧选择、材料分类等），从而降低对VLM能力的要求，且易于替换后端。

## 3. 实验设计：使用的数据集、场景、基准与对比方法

### 数据集与场景
- **刚体操作**：DROID 数据集中的100个随机选取的交互片段（DROID-100），涵盖多种物体、视角、遮挡模式和操作动词（pick/place/push/insert）。每个片段包含同步RGB、深度、标定、机器人轨迹、语言指令等。
- **可变形物体操作**：PhysTwin/EMPM 风格的场景，包含绳子、布料、软包、弹塑性材料等。
- **人形运动**：Unitree G1 机器人视频片段（来自 LAFAN1 数据集），包含站立、跪姿、短距离行走等。

### 基准与对比方法
- 本文主要测试不同 VLM 后端对转换成功率的影响，对比了四个后端：**Gemma 4 31B**（开源）、**Qwen 3.6 35B**（开源）、**GPT-5.4**（闭源前沿）、**Claude Haiku 4.5**（闭源）。
- 所有后端使用相同的管道配置（仅VLM替换）。**未与其他现有Real2Sim框架进行直接对比**，因为目标是展示可扩展性和后端经济性，而非超越现有方法。

### 评价指标
- **Replay Success**：基于VLM评判器对真实关键帧与仿真关键帧进行结构化比较。三个独立评判器分别打分（满10分，根据目标物体、最终位置、动作相似性、夹爪位置扣分），得分≥8/10 视为成功，7/10 为部分成功，≤6 或没有记录视为失败。最终成功定义为至少一个评判器的最高候选得分≥8。

## 6. 论文的主要结论与发现

1. **可行性**：Agentic Real2Sim 能够将真实DROID操作片段自动转换为MuJoCo仿真事件，并保持合理的物理和行为一致性。
2. **VLM后端可互换性**：开源31B模型（Gemma 4 31B）在转换成功率（48/100）上达到或超过闭源前沿模型（GPT-5.4: 43/100, Claude: 37/100），而成本仅为GPT-5.4的约3%。说明VLM在该框架中的角色是有限的决策，而非核心物理模拟。
3. **成本效率**：大转换批次时，使用开源VLM可大幅降低成本，使得大规模部署可行。
4. **泛化性**：相同的“事件双胞胎”契约可扩展到可变形物体和人形运动领域（尽管仅定性验证），显示框架的跨领域潜力。
5. **当前上限**：任何后端绝对成功率均低于50%，表明主要瓶颈在于上游视觉和模拟组件，而非VLM选择。

## 摘要
我们考虑在分布模糊下随机控制问题中定义风险概率。当前的机会约束控制方法通常假设真实状态分布已知且为高斯分布。这些假设不适用于许多实际工程应用，其中系统动力学是非线性的且仅近似建模。在这项工作中，我们定义了一个分布模糊集，并利用指数积分的变分表达式，限制了在相对熵距离内位于标称高斯参考分布附近的未知分布下的期望风险值。我们的边界在零散度极限下恢复参考风险值。提出了一种方法来确定定义模糊集的相对熵距离，该距离是参考协方差演化和二阶动力学截断误差的函数。所得贡献为处理非线性协方差转向问题中的分布模糊性提供了一个框架。给出了一个随机航天器制导示例来展示我们的贡献。

## Abstract
We consider defining risk probability in stochastic control problems under distribution ambiguity. Current approaches for chance-constrained control typically assume that the true state distribution is known and Gaussian distributed. These assumptions are not amenable to many real-world engineering applications where system dynamics are nonlinear and only approximately modeled. In this work, we define a distribution ambiguity set and, with a variational expression for exponential integrals, bound the expected risk value under an unknown distribution that resides within a relative entropy distance of a nominal Gaussian reference distribution. Our bound recovers the reference risk value in the zero-divergence limit. A method is presented to determine the relative entropy distance defining the ambiguity set that is a function of the reference covariance evolution and second-order dynamical truncation errors. The resulting contributions provide a framework for handling distributional ambiguity in nonlinear covariance steering problems. A stochastic spacecraft guidance example is presented to demonstrate our contributions.

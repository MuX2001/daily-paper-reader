## 摘要
视觉-语言-动作（VLA）策略提供了强大的通用操作先验，但在高精度、接触密集的装配任务中常因长期信用分配和子任务耦合而失败：当前技能在几何上成功的状态可能对下游技能是脆弱的。我们展示了在冻结的VLA基础策略上进行残差强化学习（RL）时的这种失败模式：恒定的稀疏成功奖励虽孤立地改善了每个子任务，但在技能链式执行时几乎没有增益，因为终端状态质量不受控。我们提出远见残差RL，通过使用离线估计的远见值（即当前子任务终端状态下未来子任务成功的条件概率）增强每个子任务的稀疏成功奖励来优化交接质量。具体地，我们（i）从基础策略的终端状态图像训练视觉远见预测器，并使用下游回滚统计标签，以及（ii）通过反向远见归纳训练残差策略，将预测器输出作为奖励乘数。在Isaac Gym中的三阶段扳手螺母拧紧装配任务（抓取、移动插入、旋转）中，我们的方法实现了85.6%的全任务成功率，优于标准子任务残差RL（54.5%）和VLA基线，同时保持各子任务成功率不变。这些结果强调，提升长期性能需要塑造每个子任务产生的成功状态，而不仅仅是是否成功。

## Abstract
Vision-Language-Action (VLA) policies offer strong general-purpose manipulation priors, but often fail on tight-tolerance, contact-rich assembly due to long-horizon credit assignment and subtask coupling: a state that is geometrically successful for the current skill can be brittle for downstream skills. We show this failure mode in residual reinforcement learning (RL) over a frozen VLA base policy: constant sparse success rewards improve each subtask in isolation yet yield little or no gain when skills are chained, because terminal state quality is uncontrolled. We propose Foresight Residual RL, which optimizes handoff quality by augmenting each subtask's sparse success reward with an offline-estimated foresight value -- the probability of future subtask success conditioned on the terminal state of the current subtask. Concretely, we (i) train a visual foresight predictor from images of terminal states of the base policy, labeled using downstream rollout statistics, and (ii) train residual policies via backward foresight induction, using the predictor output as a reward multiplier. On a three-phase wrench-based nut-tightening assembly task in Isaac Gym (grasp, move-insert, rotate), our method achieves 85.6% full-task success, outperforming standard subtask residual RL (54.5%) and VLA baselines, while leaving per-subtask success unchanged. These results highlight that improving long-horizon performance requires shaping which successful states are produced at each sub-task, not only whether success occurs.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：视觉-语言-动作（VLA）策略在通用操作任务中表现优异，但在高精度、接触密集的长时域装配任务（如扳手拧螺母）中频繁失败。根本原因在于子任务之间存在**因果耦合**：前一个子任务的终端状态虽然满足当前子任务的几何成功条件，但可能对后续子任务脆弱，导致链式执行时性能大幅下降。
- **现有方法的缺陷**：标准做法是独立训练每个子任务策略，使用稀疏的成功奖励（如子任务完成即得固定奖励）。这忽略了终端状态的质量差异——即使所有成功状态都被视为等价，但有些状态更有利于下游任务。残差RL（Residual RL）虽然能提升单个子任务成功率，但在链式任务中几乎无增益，因为未控制终端状态质量。
- **核心含义**：长时域操作的成功不仅取决于每个子任务是否成功，更取决于**产生何种成功状态**（即终端状态的质量）。本文旨在通过引入远见值（foresight value）来优化子任务间的交接质量。

## 2. 方法论

### 核心思想
- 提出 **Foresight Residual RL** 框架，通过**离线学习的视觉远见预测器**评估当前子任务终端状态对下游子任务成功的影响，并将预测值作为奖励乘数来训练残差策略，从而引导基础VLA策略产生更有利于后续任务的终端状态。
- 采用**反向归纳（backward induction）** 训练顺序：从最后一个子任务开始，逆向训练前面的子任务，因为远见值依赖于下游固定策略。

### 关键技术细节
1. **远见值函数（Foresight Value Function）**：定义子任务 \(k\) 的终端状态 \(s\) 下，从后续子任务 \(k+1\) 开始的期望最终任务成功回报。近似为下一子任务的成功概率（一步远见）。
2. **离线远见预测器训练**：
   - 收集基础VLA策略（无残差）产生的 \(N\) 个成功终端状态（图像+状态）。
   - 对每个终端状态，执行 \(K_{\text{rep}}\) 次下游策略回滚，记录成功次数 \(\kappa_i\)，得到经验成功概率 \(y_i = \kappa_i / K_{\text{rep}}\)。
   - 训练一个神经网络 \(p_\phi(o)\)（基于DINOv2视觉特征）以二项式负对数似然为损失，将观测 \(o\) 映射到成功概率。
3. **残差策略训练**：
   - 基础策略 \(\pi_k^0\)（冻结的VLA模型）输出动作，残差策略 \(\pi_k^{\text{res}}\) 输出小修正：\(a_t = \pi_k^0(o_t) + \alpha \cdot \pi_k^{\text{res}}(o_t)\)，\(\alpha \ll 1\)。
   - 使用PPO训练，奖励为 \(r_t = \beta_k(s_{t+1}) \cdot p_\phi(o_{t+1})\)，其中 \(\beta_k\) 是子任务 \(k\) 的成功谓词，\(p_\phi\) 来自预测器。
4. **反向归纳流程**（Algorithm 1）：
   - 从最后一个子任务 \(k=K\) 开始，用标准任务奖励训练残差策略（远见值设为1）。
   - 对 \(k=K-1,\dots,1\)，固定已训练的下游策略，训练远见预测器，然后用预测值作为奖励乘数训练当前子任务残差策略。

### 公式关键点
- 局部远见值函数：\(V_k^\circ(s) = \mathbb{E}[\sum \gamma^t \beta_k(s_{t+1}) V_{k+1:K}(s_{t+1})]\)，其中 \(V_{k+1:K}\) 为远见值。
- 预测器损失：\(\mathcal{L}(\phi) = -\sum_i [\kappa_i \log p_\phi(o_i) + (K_{\text{rep}}-\kappa_i) \log(1-p_\phi(o_i))]\)。

## 3. 实验设计

### 场景与数据集
- **任务**：Isaac Gym 模拟中的扳手螺母拧紧装配任务（三阶段：抓取、移动插入、旋转）。使用Kuka IIWA机械臂和Robotiq三指夹爪。
- **随机化**：每轮重置时随机化扳手支架、螺母和螺栓的初始位姿，包含5种不同尺寸（间隙<2mm）。
- **演示数据**：每个子任务收集2560条由状态机专家（使用特权信息）生成的演示。

### 基准方法对比
1. **π0 端到端**：直接训练整个任务。
2. **π0 链式**：独立训练每个子任务的π0策略后顺序执行（无残差）。
3. **π0 + 残差（标准残差RL）**：在每个子任务上使用固定稀疏奖励（\(\beta_k\)）训练残差策略。
4. **π0 + 残差 + 远见（本文方法）**：使用远见预测器调制的奖励。

### 评估方式
- 512 epoches × 4 随机种子，报告均值和标准差。
- 评估粒度：
  - 单子任务（从专家给定初始状态启动）。
  - 连续两阶段（抓取+插入、插入+旋转）。
  - 全任务（三阶段链式）。

## 6. 主要结论与发现

- **本文方法显著提升全任务成功率**：达到85.6%，远超标准残差RL（54.5%）和π0链式（41.4%）。
- **提升来源于终端状态质量而非子任务成功率**：单独子任务成功率并无显著差异（甚至标准残差RL在某些子任务上更高），但链式时大幅提升。远见预测器得分显示标准残差RL反而降低了终端状态质量（如抓取终端评分从0.64降到0.32），而远见方法提升到0.73。
- **远见预测器具有分辨能力**：在抓取→插入边界，预测器准确率86.2%（数据集成功率73.9%），说明能区分出对下游有利的抓取状态。
- **反向归纳训练顺序有效**：由于下游策略固定，远见估计稳定，避免了非平稳性问题。

## 7. 优点

- **创新性强**：首次将远见值函数引入VLA残差RL，直接优化子任务终端状态质量，而非仅仅分布匹配或单独优化。
- **实用高效**：预测器离线训练，训练时只需前向传播一次，避免了在线Rollout的高方差和计算开销；残差策略动作修正小（α=0.1），减少了分布偏移。
- **理论依据充分**：远见值函数与MAXQ框架中的completion function、options框架中的VΩ(s')等有理论联系，确保了方法的合理性。

- **通用性潜力**：方法不依赖特定VLA模型，可推广到其他基础策略。

## 8. 不足与局限

- **实验场景单一**：仅在一个模拟任务上验证，且任务具有明确的三阶段分解。未在更多样化的任务（如多分支、更长的链）或真实机器人上评估，泛化性存疑。
- **模拟器局限性**：所有实验在Isaac Gym中完成，接触物理模拟可能不完美。作者承认真实部署的主要障碍是on-hardware在线RL的成本，而非接触动力学差异，但并未提供真实实验证据。
- **远见近似仅考虑一步**：使用下一子任务的成功概率近似完整下游回报，虽然可扩展，但当前仅验证了邻接耦合场景。若更深层耦合，误差可能累积。
- **预测器基于基础策略分布**：虽然残差修正很小，但策略改进仍可能导致分布外状态，可能降低预测器准确性。作者认为α较小可保证插值范围，但未提供定量验证。
- **计算资源未报告**：缺少GPU型号、训练时间等细节，降低了可复现性（尽管代码可能开源）。
- **消融范围有限**：未测试不同代理（如使用在线蒙特卡洛而非离线预测器、不使用反向归纳等）以减少混淆变量。

## 摘要
我们提出了CS-P2L，这是一个将协方差控制（CS）与Pick-to-Learn（P2L）元算法相结合用于高保真随机模拟器上的认证控制器综合的框架。该方法通过在模拟器滚动模拟上迭代评估策略，使用最坏情况违反来收紧代理约束，并在给定置信水平下提供基于压缩的真实违反概率的概率保证。在一个具有不确定重力的航天器动力下降问题中，CS-P2L 通过600次滚动模拟认证了一个4.9%的违反边界，而独立的协方差控制则将违反率低估了大约两倍。

## Abstract
We present CS-P2L, a framework coupling covariance steering (CS) with the Pick-to-Learn (P2L) meta-algorithm for certified controller synthesis over high-fidelity stochastic simulators. The method iteratively evaluates policies on simulator rollouts, tightens surrogate constraints using the worst-case violations, and provides compression-based probabilistic guarantees on the true violation probability given a confidence level. On a spacecraft powered-descent problem with uncertain gravity, CS-P2L certifies a violation bound of 4.9\% with 600 rollouts, whereas standalone covariance steering underestimates the violation rate by roughly a factor of two.

## 2. 方法论：核心思想、关键技术细节、算法流程
- **核心思想**：将P2L（Pick-to-Learn）元算法与协方差控制（CS）结合。在P2L外层循环中，使用模拟器评估当前策略，选择最严重违反的轨迹（“信息性样本”）并收紧代理约束，然后重新求解CS问题。最终返回的策略伴随一个基于压缩理论的概率保证：以至少1-δ置信度，真实违反概率不超过某上界。
- **关键技术细节**：
  - **问题形式化**：定义高保真模拟器为连续时间SDE（带未知时不变参数λ），控制器为零阶保持的反馈-前馈策略。规范为可达-避免规范（安全集、终端集、控制幅值约束）。
  - **代理CS问题**：将SDE线性化、离散化，转化为凸优化子问题。通过变量替换（Uk=KkPk）使协方差演化变为仿射；安全约束和控制约束通过顺序凸优化（CCP）转化为凸不等式；终端约束使用卡方分布的量化界限。
  - **P2L循环（算法2 CS-P2L）**：
    1. 初始配置θ(0) → 求解CS获得策略π(0)，在所有N个模拟实现上评估。
    2. 初始化压缩集T=∅，r=0。
    3. 当存在不在T中的实现违反规范时：
       - 选择违反度量（总违反次数）最大的轨迹加入T。
       - 调用配置算法L，根据T中的轨迹更新配置参数（收紧安全边界、控制限、终端协方差）。
       - 重新求解CS获得新策略π(r+1)，在所有实现上重新评估。
    4. 终止：所有不在T中的实现均已满足规范。返回最终策略和压缩集T。
  - **违反度量**：定义为违反安全、控制、终端约束的总次数，负值表示满足规范。
  - **配置算法**：对安全边界b_m、控制限u_max、终端协方差P_tf进行收缩更新（如b←max(b*(1-γb*c), b_min)等）。
  - **收紧策略（算法3）**：为达到目标违反概率ε，采用两阶段：校准阶段（可选）调优配置算法L并冻结；认证阶段逐步扩大数据集直到上界≤ε。
- **理论保证**：定理1给出上界求解公式，基于压缩理论（Campi & Garatti, 2023），其中上界仅取决于压缩集大小、总样本数N和置信度δ。

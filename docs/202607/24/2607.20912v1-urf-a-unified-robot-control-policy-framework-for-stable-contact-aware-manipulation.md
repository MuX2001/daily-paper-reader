## 摘要
基于学习的操作策略通常从感官观测预测机器人动作，并将其执行交给单独的低层控制器。在刚性接触中，这种分离可能带来问题：相同的虚拟目标运动或柔顺运动命令可能导致不稳定接触、跟踪误差、过大载荷或工具损坏，具体取决于低层控制器。在本文中，我们提出了一种统一的机器人控制策略框架（URF），该框架将柔顺动作预测与统一的阻抗-导纳控制相结合。给定多模态观测，URF预测虚拟目标、刚度矩阵以及阻抗-导纳切换比率。切换比率决定了控制器何时应更像导纳控制以实现精确的运动跟踪，何时应朝向阻抗控制以实现更安全的刚性接触。由于演示数据不提供真实的环境刚度，我们根据测得的接触力构建切换比率标签，并用它们来监督控制器模式预测。在翻转箱子和按压线条任务中，URF实现了更高的任务成功率，同时减少了仅使用导纳控制时所观察到的故障模式，包括力快速积累、大力振荡、工具断裂和机器人安全停止。这些结果表明，接触感知策略不仅能从预测柔顺动作中受益，还能从用于执行这些动作的控制器行为中受益。项目页面：https://jiyou384.github.io/urf_project_page/

## Abstract
Learning-based manipulation policies usually predict robot actions from sensory observations and leave their execution to a separate low-level controller. In rigid contact, this separation can be problematic: the same motion to a virtual target or compliant motion command can lead to unstable contact, tracking error, excessive loading, or tool damage, depending on the low-level controller. In this paper, we propose a \textit{Unified Robot Control-Policy Framework} (URF), which connects compliant action prediction with unified impedance-admittance control. Given multimodal observations, URF predicts a virtual target, a stiffness matrix, and an impedance-admittance switch ratio. The switch ratio determines when the controller should behave more like admittance control for accurate motion tracking and when it should move toward impedance control for safer rigid contact. Because demonstration data do not provide ground-truth environment stiffness, we construct switch-ratio labels from measured contact forces and use them to supervise controller-mode prediction. Across box-flipping and line-pressing tasks, URF achieves higher task success rates while reducing failure modes observed with admittance-only execution, including rapid force buildup, large force oscillations, tool breakage, and robot safety stops. These results suggest that contact-aware policies benefit from predicting not only compliant actions but also the controller behavior used to execute them. ## 1. 论文的核心问题与整体含义（研究动机和背景）
- **研究动机**：现有基于学习的操作策略（如扩散策略）通常将动作预测与低层控制器分离：策略从视觉、力觉等观测信息预测动作（如目标位姿或力），而低层控制器（如PD控制器、导纳控制、阻抗控制）负责执行。这种分离在刚性接触场景中会导致严重问题：相同的柔顺动作命令，若被不同的低层控制器执行，可能产生不稳定接触、力快速积累、大力振荡、工具断裂或机器人安全停止。
- **背景**：尽管一些工作开始预测接触相关的动作参数（如虚拟目标、刚度、期望力），但忽视了低层控制器本身对执行效果的决定性影响。传统的导纳控制与阻抗控制存在权衡：导纳控制在自由空间和软接触中跟踪精度高，但在刚性接触中易因力反馈转换为振动命令而失稳；阻抗控制在刚性接触中更鲁棒，但自由空间跟踪精度较低。已有统一的阻抗-导纳控制器可通过切换模式结合两者优点，但如何从演示数据中学习何时切换尚未解决。
- **整体含义**：本文认为接触感知策略不应孤立地预测动作，还应预测执行该动作的控制器行为模式。为此提出URF框架，将动作预测与统一阻抗-导纳控制联合建模，从而提高刚性接触操作的成功率和稳定性。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
### 核心思想
- 构建一个端到端框架，策略从多模态观测（RGB图像、末端位姿、力/力矩历史）同时预测三类控制器参数：虚拟目标（\(x_t^{vt}\)）、刚度矩阵（\(K_t\)）以及阻抗-导纳切换比率（\(n_t \in [0,1]\)）。其中\(n_t\)决定低层控制器在多大程度上表现为导纳控制（\(n=1\)）或阻抗控制（\(n=0\)），中间值实现平滑过渡。
- 由于演示数据中不提供真实环境刚度，无法直接监督切换比率，因此提出通过实测接触力幅度构造标签：当力小时（\(|F_t^{ext}| \leq f_{min}\)）标签为1（导纳主导）；力大时（\(|F_t^{ext}| \geq f_{max}\)）标签为0（阻抗主导）；中间线性插值。该标签用于训练策略预测\(n_t\)。

### 关键技术细节
- **低层统一控制器**：采用Ott等提出的统一阻抗-导纳控制器。在阻抗阶段，根据期望阻抗动力学（\(M_d \ddot{e}_t + D_d \dot{e}_t + K_t e_t = F_t^{ext}\)）计算阻抗力命令；在导纳阶段，通过外环导纳动力学生成期望位置，再由内环位置控制器跟踪。切换时通过状态映射保证力和位置连续性。
- **高层策略**：基于扩散策略（Diffusion Policy）架构。观测编码：两个RGB图像用CLIP ViT-B/32提取视觉特征；1秒力/力矩序列转换为六通道对数频谱图并用ViT编码；力特征与视觉特征经Transformer融合后与本体感知拼接形成条件编码\(c\)。条件1D U-Net通过FiLM层受\(c\)调制，预测长度为16步的动作块（\(A_t = [a_t, a_{t+1}, ..., a_{t+H-1}]\)），每个\(a_t\)包含\(x_t^{vt}, K_t, n_t\)。训练损失为扩散噪声预测损失\(L = \mathbb{E}[\|\epsilon - \epsilon_\theta(A_t^\tau, \tau, c)\|^2]\)。推理时使用DDIM采样生成动作块，并以滚动预测方式执行。

### 公式与文字说明
- 切换比率标签公式：\(n_t = 1\) if \(|F_t^{ext}| \leq f_{min}\); \(n_t = 0\) if \(|F_t^{ext}| \geq f_{max}\); 否则线性插值。
- 低层控制器动力学方程：阻抗控制中\(F_t^{imp} = (M_r M_d^{-1} - I)F_t^{ext} - M_r M_d^{-1}(D_d \dot{e}_t + K_t e_t)\)；导纳控制中通过\(M_d \ddot{x}_t^d + D_d \dot{x}_t^d + K_t (x_t^d - x_t^{vt}) = F_t^{ext}\)解出期望位置\(x_t^d\)后由内环PD控制输出\(F_t^{adm}\)。
- 算法流程：收集演示 → 用自适应柔顺标签法生成虚拟目标和刚度标签 + 用力构造切换比率标签 → 训练扩散策略预测动作块 → 推理时发送\(x_t^{vt}, K_t, n_t\)给实时统一控制器。

## 3. 实验设计：使用了哪些数据集/场景，benchmark，对比方法
- **任务与数据集**：两个刚性接触操作任务：
  1. **箱体翻转（box-flipping）**：机器人使用3D打印PLA工具将刚性箱体翻转为直立状态。100个演示（人工引导）。
  2. **线条按压（line-pressing）**：在刚性表面上沿一条线按压，要求接触力始终≥5N，且完成至少85%的线条。50个演示。
- **评价指标**：
  - 成功率（SR）
  - 临界故障率（CFR）：工具断裂或安全停止等严重故障占失败试次比例
  - 峰值力增长率（PFGR）：首次接触至力峰值之间的平均斜率
  - 自由空间跟踪误差（FSTE）：接触前末端与虚拟目标的均方误差
  - 接触保持率（CMR）
  - 力振荡均方根（ORMS）
- **对比方法**：
  - **DP w/ force**：标准扩散策略，但加入与URF相同的力编码；动作由临界阻尼PD位置控制器执行。
  - **ACP (Adaptive Compliance Policy)**：预测虚拟目标和自适应刚度，使用导纳控制器执行（即\(n=1\)固定）。
  - **URF w/ n=0.5**：URF但固定切换比率为0.5。
  - **URF w/ n=0**：URF但固定切换比率为0（纯阻抗模式）。
  - **URF（完整）**：预测切换比率，自适应。

## 6. 论文的主要结论与发现
- **核心结论**：将动作预测与低层控制器行为耦合对刚性接触操作至关重要。URF通过预测虚拟目标、刚度和切换比率，在箱体翻转中达到90%成功率（ACP仅25%），在线条按压中达到100%成功率（ACP为0%），同时显著减少了力振荡、工具断裂和安全停止。
- **关键发现**：
  - 仅使用导纳控制（ACP）在刚性接触中导致力快速积累（PFGR约为URF的两倍），是工具断裂的主要原因。
  - 纯阻抗模式（n=0）虽然能稳定接触，但自由空间跟踪误差大，导致翻转时接触点位置不佳或线条偏离。
  - 固定0.5的折中比率在两种任务中性能介于极端值之间，但无法适应任务阶段变化。
  - URF的自适应切换能兼顾：在接近阶段使用导纳模式保证跟踪精度，在接触瞬间提前降低\(n\)转为阻抗模式抑制力冲击，在任务后期重新提高\(n\)完成精细运动。
  - 仅用实测力构造的标签足以训练出有预测能力的切换策略（预测性：策略在实际大接触力出现前就降低\(n\)）。

## 7. 优点：方法或实验设计上的亮点
- **创新性**：首次将低层控制器模式选择纳入学习策略的动作空间，提出“控制器感知动作”的概念，实现策略与控制器的耦合而非分离。

- **清晰的可视化**：提供了轨迹对比、力曲线、刚度和切换比率变化图，直观展示了URF如何调整行为。

## 摘要
视觉-语言-动作（VLA）策略提供了强大的通用操作先验知识，但由于长时域信用分配和子任务耦合，在紧公差、高接触的装配任务中常常失败：一个在当前技能上几何学上成功的状态，对于后续技能可能是不稳定的。我们在冻结的VLA基础策略之上的残差强化学习（RL）中展示了这种失败模式：恒定的稀疏成功奖励孤立地改进了每个子任务，但当技能链式执行时几乎没有或完全没有增益，因为终端状态质量不受控制。我们提出了前瞻性残差RL，它通过用离线估计的前瞻性价值——即当前子任务终端状态条件下未来子任务成功的概率——来增强每个子任务的稀疏成功奖励，从而优化交接质量。具体地，我们（i）从基础策略的终端状态图像中训练一个视觉前瞻预测器，使用下游推演统计数据进行标注，以及（ii）通过反向前瞻归纳训练残差策略，将预测器的输出用作奖励乘数。在Isaac Gym中的一个基于扳手的螺母拧紧装配任务（抓取、移动-插入、旋转）上，我们的方法实现了85.6%的全任务成功率，优于标准子任务残差RL（54.5%）和VLA基线，同时保持每个子任务的成功率不变。这些结果突出表明，提高长时域性能需要塑造每个子任务产生的成功状态，而不仅仅是是否成功。

## Abstract
Vision-Language-Action (VLA) policies offer strong general-purpose manipulation priors, but often fail on tight-tolerance, contact-rich assembly due to long-horizon credit assignment and subtask coupling: a state that is geometrically successful for the current skill can be brittle for downstream skills. We show this failure mode in residual reinforcement learning (RL) over a frozen VLA base policy: constant sparse success rewards improve each subtask in isolation yet yield little or no gain when skills are chained, because terminal state quality is uncontrolled. We propose Foresight Residual RL, which optimizes handoff quality by augmenting each subtask's sparse success reward with an offline-estimated foresight value -- the probability of future subtask success conditioned on the terminal state of the current subtask. Concretely, we (i) train a visual foresight predictor from images of terminal states of the base policy, labeled using downstream rollout statistics, and (ii) train residual policies via backward foresight induction, using the predictor output as a reward multiplier. On a three-phase wrench-based nut-tightening assembly task in Isaac Gym (grasp, move-insert, rotate), our method achieves 85.6% full-task success, outperforming standard subtask residual RL (54.5%) and VLA baselines, while leaving per-subtask success unchanged. These results highlight that improving long-horizon performance requires shaping which successful states are produced at each sub-task, not only whether success occurs.

## 1. 核心问题与整体含义

- **研究动机**：长时域机器人操作（如工业装配）需要顺序执行多个接触密集的子技能。常用方法是将任务分解为子任务并独立训练策略，然后链式执行。然而，在接触装配中，子任务之间存在因果耦合：一个子任务的终端状态（即使几何上成功）可能对下游技能不利，导致链式执行性能远低于单子任务性能。现有标准残差强化学习（Residual RL）使用恒定稀疏成功奖励，能提升每个子任务的成功率，但无法改善交接质量，因此链式执行时整体成功率几乎没有提升。

- **核心问题**：如何优化子任务之间的“交接质量”（handoff quality），即终端状态对于未来子任务成功的条件概率，而不是仅仅追求当前子任务的成功。

- **整体含义**：本文揭示了一个被忽视的关键因素：在长时域操作中，仅仅让每个子任务成功是不够的，必须主动塑造终端状态的质量，使其有利于后续技能的成功。这项工作为VLA模型在接触密集型长时域任务中的应用提供了新的理论视角和实用方法。

## 2. 方法论

### 核心思想
- 提出**前瞻性残差强化学习（Foresight Residual RL）**：在冻结的VLA基础策略上训练残差策略，但奖励不再只是子任务成功指示，而是乘以一个“前瞻性价值”——即从当前子任务终端状态出发，下游子任务成功的概率。
- 通过离线方式训练一个**视觉前瞻预测器**，从终端状态的图像估计该概率，并作为奖励乘子。训练采用**反向前瞻归纳（Backward Foresight Induction）**：从最后一个子任务开始，反向逐阶段训练残差策略，确保下游策略固定，提供稳定的前瞻估计。

### 关键技术细节
1. **残差策略**：动作 = 基础VLA策略输出 + α × 残差策略输出（α很小，初始化为零）。残差基于DINOv2特征和LSTM。
2. **前瞻价值函数**：对于阶段k < K，其定义为从阶段k终端状态s出发，后续所有阶段（k+1到K）的期望折扣最终阶段成功回报。本文采用**一步前瞻近似**，即仅用下一个子任务的成功概率来近似完整前瞻价值（在最后阶段近似精确，中间阶段可通过链式推演扩展）。
3. **离线预测器训练**：
   - 使用基础策略（无残差）采集N个成功终端状态图像；
   - 对每个终端状态，执行Krep次下游策略推演，记录下游子任务成功计数κi；
   - 用(oi, κi/Krep)作为标签，训练一个视觉预测器p_phi，优化二项负对数似然损失。
4. **奖励设计**：对于阶段k，每一步的奖励 r_t = β_k(s_{t+1}) * p_phi(o_{t+1})，其中β_k是当前子任务成功谓词，p_phi是预测器输出。
5. **训练流程**（算法1）：从k=K开始，使用标准成功奖励训练残差策略；然后依次处理k=K-1,…,1，先固定下游策略，训练前瞻预测器，再用上述乘积奖励训练当前残差策略。

### 算法流程（文字说明）
- **算法1 (Backward Foresight-driven Learning)**：输入基础策略和残差尺度α。从最后一个阶段开始训练，然后反向逐阶段训练：对于每个阶段k < K，首先通过算法2训练预测器p_phi，然后使用PPO和乘积奖励训练残差策略。
- **算法2 (Foresight Predictor)**：收集N个基础策略的终端状态，对每个执行Krep次下游推演，获得成功计数，使用二项负对数似然训练预测器。

## 3. 实验设计

- **任务场景**：在NVIDIA Isaac Gym模拟器中实现**扳手-螺母拧紧装配任务**，包含三个因果耦合阶段：
  - 抓取扳手（Grasp，160步）
  - 移动并插入扳手到螺母（Move-Insert，200步）
  - 旋转螺母至少60°（Rotate，200步）
  使用7-DOF Kuka IIWA臂和Robotiq三指夹爪。观测：两个RGB图像（第三视角+腕部相机，256×256）和8维本体感知。动作：7维操作空间控制差值。每个episode随机化初始位姿，采用5种扳手-螺母尺寸（间隙<2mm）。
- **基准方法**：
  - π0端到端（端到端训练单策略解决三个子任务）
  - π0链式（三个阶段独立训练后链式执行）
  - π0 + 残差（标准恒定奖励的残差RL，每阶段独立）
  - π0 + 残差 + 前瞻（本文方法）
- **评价指标**：
  - 单子任务成功率（由专家初始化，即从上一阶段专家成功的终端状态开始）
  - 两阶段连续成功率
  - 完整三阶段任务成功率（无特权初始化）
- **专家演示**：每个子任务2560个演示，使用有特权信息的专家（状态机或基于状态的RL）。
- **基础策略**：微调π0模型，每个子任务独立，动作chunking horizon=20。
- **残差策略**：输入仅腕部图像，DINOv2-S/14提取特征，CNN+LSTM+MLP，actor头零初始化。

## 6. 主要结论与发现

1. **标准残差RL提升单子任务成功率，但链式时无收益**：单子任务插入成功率从45.7%提升到92.2%，但全任务成功率仅54.5%（与端到端π0的54.9%持平）。证实了“成功不等于良好交接”。
2. **前瞻残差RL显著提升全任务成功率**：达到85.6%，相比标准残差RL的54.5%提高+31.1%，相比链式π0的41.4%翻倍。
3. **增益主要集中于Grasp→Insert边界**：连续成功率从55.5%提升至87.3%（+31.8%），与预测器在该边界更大的判别力一致（86.2%准确率 vs 基线73.9%）。
4. **标准残差RL反而降低终端状态质量**：在Grasp终端，平均预测器分数从0.64下降到0.32，表明R L学会了更容易成功的抓取但对下游不利。前瞻残差将分数提升至0.73。
5. **优化终止状态质量比优化单子任务成功率更重要**：这是本文核心发现，对接触密集型长时域操作有指导意义。

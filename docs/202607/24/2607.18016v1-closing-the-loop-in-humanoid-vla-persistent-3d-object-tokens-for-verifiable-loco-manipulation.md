## 摘要
视觉-语言-动作策略是通用机器人控制的有前景的基础，但长期人形移动操作要求机器人将任务物体视为在移动、接触、遮挡和恢复过程中的持久物理实体。我们将此问题作为物体状态分歧来研究：用于条件化全身动作的物体状态可能与用于判断动作是否达到预期物理关系的状态不同。我们提出了可持久物体令牌化（POT）方法，该方法从RGB-D观测中维护角色索引的3D物体记录，并将其转换为用于全身动作专家的物体令牌。实例化为POT-VLA，相同的物体记录既条件化动作生成，又支持几何谓词检查，从而形成一个闭环执行系统，其中物体状态既可操作又可验证。在Unitree G1上，POT-VLA在八个真实世界任务族中将匹配的直接GR00T-N1.7基线从39/80成功提升至71/80成功。在外部对齐的Being-0参考中，POT-VLA在对齐的服务任务上取得了44/50成功，而Being-0论文报告的成功为37/50。最大的提升出现在需要维持3D关系的任务上，这表明以物体为中心的持久状态是可验证人形VLA执行的一种有用抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

## 1. 核心问题与整体含义

- **研究动机**：人形机器人在执行长时程移动操作（如整理桌面、递送饮料）时，需要将任务物体视为贯穿移动、接触、遮挡和恢复过程的**持久物理实体**。但现有VLA（Vision-Language-Action）策略通常将物体状态隐式编码在视觉-语言特征中，导致**物体状态发散**（object-state divergence）：用于条件化动作的物体状态与用于判断动作是否成功的物体状态不一致，进而引发错误的子任务推进、物体操作错误或无效恢复。
- **研究问题**：如何构建一个**共享的、可持久、可验证的物体级状态表示**，既能指导动作生成，又能用于执行后验证物理关系。
- **整体意义**：提出**持久物体令牌化（POT）** 作为解决状态发散的关键抽象，实现闭环的感知-动作-验证循环，显著提升真实人形机器人移动操作的成功率。

## 2. 方法论

### 核心思想
- **POT（Persistent Object Tokenization）**：从RGB-D观测中提取任务相关物体的3D信息，维护为**角色索引的物体记录**（role-indexed object records），并在每次动作块执行后刷新。这些记录被序列化为**持久3D物体令牌**（Persistent 3D Object Tokens），输入到全身动作专家，同时用于执行后的几何谓词验证。

### 关键技术细节
1. **物体记录构建**：
   - 基于当前子任务（typed subtask）定义任务实体集合 \( E_i \)。
   - 使用SAM3（Segment Anything Model 3）生成物体掩码，通过深度反投影和相机-基座坐标变换，得到每个物体的3D质心、范围、可见性、置信度等，并提取关系特征（如物体-容器距离、末端-物体偏移、支持高度等）。
   - 存储到对象内存 \( M_t^{\tau_i} \)，每个记录包含角色（如TARGET、DESTINATION、SUPPORT、HANDOVER_PARTNER）、几何信息和关系特征。

2. **持久3D物体令牌**：
   - 将对象内存通过固定槽张量（默认8个槽，每个33维特征）进行令牌化，记为 \( x_t^{\text{obj}} \)。
   - 包含可见性、置信度、归一化2D框、3D质心、3D范围、方向、关系特征等。
   - 未使用的槽填充为PADDING并掩码。角色嵌入和上下文嵌入帮助动作头区分语义角色。

3. **动作专家与令牌注入**：
   - 采用GR00T-N1.7作为动作专家，保持同一骨干网络、体态和运行时。
   - POT-VLA在DiT动作头的自注意力序列中插入物体令牌：序列布局为 \( [Z_t^{\text{state}}, Z_t^{\text{obj}}, Z_t^{\text{action}}] \)，其中视觉-语言特征用于交叉注意力。
   - 物体令牌通过可学习的投影层（LayerNorm → Linear → GELU → Dropout → Linear）嵌入后与角色嵌入结合。
   - 训练时，演示数据附带物体令牌侧车（sidecar），动作损失更新令牌分支与动作头参数。

4. **闭环执行与验证**：
   - 每次执行一个短时域动作块后，刷新RGB-D观测更新同一对象内存 \( M_{t+H}^{\tau_i} \)。
   - **几何谓词监督器**：读取相同的角色索引对象内存，评估子任务前提和完成条件（如包含、支持、接近、对齐等）。每个谓词定义为 \( \langle \kappa, \alpha, op, \nu, n \rangle \)，包含类型、参数、比较算子、阈值和稳定窗口。
   - 状态反馈包括：in_progress、done、blocked、failed、uncertain。低置信度或可见性不足触发重新观测。可选的VLM用于语义条件验证。
   - 恢复策略：继续、重试、重新观测、重新接地、重新规划。

## 摘要
视觉-语言-动作策略是通用机器人控制的有前景基础，但长时间跨度的类人运动操纵要求机器人在移动、接触、遮挡和恢复过程中将任务对象视为持久的物理实体。我们将此问题研究为对象状态发散：用于调节全身动作的对象状态可能与用于判断该动作是否实现预期物理关系的状态不同。我们提出持久对象标记化（POT），该方法从RGB-D观测中维护角色索引的3D对象记录，并将其转换为面向全身动作专家的对象标记。实例化为POT-VLA，相同的对象记录既调节动作生成，又支持几何谓词检查，从而形成一个闭环执行系统，其中对象状态既可操作又可验证。在Unitree G1机器人上，POT-VLA在八个真实世界任务族中将匹配的直接GR00T-N1.7基线从39/80成功率提升至71/80。在外部对齐的Being-0参考中，POT-VLA在对齐的服务任务上达到44/50成功率，而Being-0论文报告的成功率为37/50。最大的改进出现在需要维持3D关系的任务上，这表明以对象为中心的持久状态是一种有用的抽象，可用于可验证的类人VLA执行。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：类人机器人在长时间跨度的移动操作任务中（如“整理桌子”“递饮料”）面临**对象状态发散**（object-state divergence）问题——用于条件化全身动作生成的对象状态，与用于判断该动作是否达成预期物理关系的对象状态不一致。这导致即使动作执行正确，也可能因对象度量信息不匹配而出现任务状态误判、错误对象操作或无效恢复。
- **研究背景**：现有VLA策略通常将对象状态隐含在视觉-语言特征中，难以在接触、遮挡后刷新或与验证模块共享。类人机器人需要同时处理移动、抓取、放置、容器装载、手递等交互，对象作为持久物理实体必须可寻址、可操作、可验证。
- **研究意义**：提出将对象状态作为**共享闭环抽象**，同时用于动作生成和几何验证，为解决长时程类人操作中的状态不一致提供有效方案。

## 2. 方法论

### 核心思想
- **持久对象令牌化（Persistent Object Tokenization, POT）**：从RGB-D观测中提取任务相关对象，维护**角色索引的3D对象记录**（role-indexed 3D object records），并将其序列化为**持久3D对象令牌**，供全身动作专家使用。
- 形成**感知-动作-验证闭环**：同一对象记录既用于条件化动作生成，又用于执行后的几何谓词检查，实现共享对象内存。

### 关键技术细节
- **任务角色对象记录**：基于VLM规划器或人工任务文件获取类型化子任务计划，每个子任务指定实体集、角色、接地查询、成功谓词、失败处理器等。POT为每个子任务构建角色索引对象内存 \( M_t^{\tau_i} = \{ m_e^t \mid e \in E_i \} \)，每个记录包含实体角色、语义短语、2D框、3D中心/尺寸、置信度、可见性、关系特征等。
- **持久令牌模式**：默认分配K=8个槽位，每个槽位F=33个特征。槽位对应角色ID（目标、目的地、支撑、手递伙伴等），未使用的槽位为PADDING并掩蔽。特征包括可见性、置信度、归一化2D框、3D中心/尺寸、可选朝向、关系特征。所有度量在机器人基座坐标系中表达并归一化。
- **对象令牌条件化动作执行**：在GR00T-N1.7动作专家的DiT动作头自注意力序列中插入对象令牌。布局为 `[Z_state, Z_obj, Z_action]`，对象令牌通过 `LayerNorm → Linear → GELU → Dropout → Linear` 投影到DiT隐藏维度。每个投影槽位与学习的角色嵌入和上下文嵌入结合，掩蔽槽位被掩码，可选置信度门控缩放。
- **谓词级验证与恢复**：几何谓词监督器读取同一对象内存，检查子任务前提条件和完成条件。谓词类型包括包含、支撑、末端执行器-目标接近、目标-目的地位移、双手分配、手递距离等。每个谓词为 \(\langle \kappa, \alpha, op, \nu, n \rangle\)，阈值和稳定窗口由任务类型指定。验证结果包括 `in_progress, done, blocked, failed, uncertain`。失败时提供诊断（如缺失可见性、抓取失败、放置不稳），触发重试、重新观测、重新接地或重规划。

### 算法流程（文字描述）
1. 给定自然语言指令 I 和当前观测（RGB-D + 本体感受），VLM规划器输出类型化子任务计划 Π。
2. 活跃子任务 τ_i 下，POT从RGB-D观测提取实体集 E_i，通过SAM3分割、深度反投影、滤噪后构建角色索引对象内存 M_t^{τ_i}。
3. 处理器将内存序列化为持久对象令牌 x_obj_t，经投影网络嵌入后插入DiT动作头。
4. 动作专家预测整个动作块 \(\hat{a}_{t:t+H}\)，经运行时检查和安全滤波后执行。
5. 执行后，RGB-D观测刷新对象内存得到 M_{t+H}^{τ_i}。
6. 几何谓词监督器基于刷新内存评估指定谓词，决定继续、重试或重规划。
7. 循环直至子任务完成或达到超时/重试预算。

## 6. 主要结论与发现

- **主效果**：POT-VLA在8个任务族上总成功率从39/80（48.75%）提升至71/80（88.75%），改进幅度达40个百分点。
- **最大增益任务**：需要维持3D关系的任务（杯子堆叠、两球放置、衣物运输、抽屉/托盘交互）改进最显著，支持“对象状态发散”假设。
- **消融结论**：对象令牌条件化贡献最大（31/40 vs 基线15/40），验证器单独提供额外增益（22/40），两者结合达34/40。表明令牌主要解决接地失败，验证器主要捕获假成功和部分失败。
- **泛化方面**：POT-VLA在新颖实例、布局移位、中段扰动下均强于基线（9/10 vs 4-6/10），干扰物影响较小（9/10 vs 8/10）。

## 7. 优点

- **方法创新**：提出**共享对象状态闭环**这一抽象思想，将对象状态同时用于动作生成和验证，有效解决节点发散问题。POT技术简洁而实用：基于RGB-D + SAM3的轻量级3D接地，无需物理引擎或学习动力学。
- **实验设计规范**：严格的消融实验（仅令牌、仅验证器、完整）；直接基线除对象状态循环外其他条件完全相同；包含多种扰动泛化测试；任务覆盖广泛且具代表性。
- **实际有效性**：在真实Unitree G1机器人上验证，改进幅度显著（近翻倍），且分析指出失败模式与对象状态发散直接相关。
- **可落地性**：不依赖仿真器或额外传感器，仅使用头戴RGB-D相机和现有动作策略进行微调，工程成本可控。

## 8. 不足与局限

- **对象记录质量依赖**：受限于SAM3分割质量、RGB-D深度可靠性、相机校准精度。低光、高反射或快速移动场景可能退化。
- **场景覆盖有限**：仅在办公桌前单环境测试，未涉及动态人群、复杂地形、户外等更开放环境。物体类别和任务种类有限（无装配、精细操作等）。
- **泛化风险**：新颖实例仅替换同类型物体（瓶子、杯子等），未测试完全未知类别或功能物体。布局移位范围20–50cm，真实场景可能更大。
- **未比较更多先进方法**：仅与自身基线和一份外部论文报告比较，未与近期其他VLA（如π0.5、Octo、RV2）或模块化系统（如Being-0本地复现）直接对比。
- **算力信息缺失**：未报告训练资源、微调数据规模、耗时等，影响可复现性评估。
- **主观性**：谓词阈值和稳定窗口由任务类型和机器人校准确定，需人工手动调整，可能不适合所有场景。

## 摘要
视觉-语言-动作（VLA）策略提供了强大的通用操作先验，但在高精度、接触密集的装配任务中常因长时域信用分配和子任务耦合而失败：当前技能在几何上成功的状态可能对后续技能脆弱。我们在冻结的VLA基策略上展示了残差强化学习（RL）中的这种失败模式：恒定的稀疏成功奖励单独提升每个子任务，但在技能链式执行时几乎没有增益，因为终端状态质量未受控制。我们提出远见残差RL，通过用离线估计的远见值——当前子任务终端状态下未来子任务成功的条件概率——增强每个子任务的稀疏成功奖励，来优化交接质量。具体而言，我们(i)从基策略终端状态的图像训练视觉远见预测器，使用下游回放统计数据标记，以及(ii)通过反向远见归纳训练残差策略，将预测器输出作为奖励乘数。在Isaac Gym中的三阶段扳手螺母拧紧装配任务（抓取、移动插入、旋转）上，我们的方法实现了85.6%的全任务成功率，优于标准子任务残差RL（54.5%）和VLA基线，同时保持各子任务成功率不变。这些结果强调，提高长时域性能需要塑造每个子任务产生哪些成功状态，而不仅仅是是否成功。

## Abstract
Vision-Language-Action (VLA) policies offer strong general-purpose manipulation priors, but often fail on tight-tolerance, contact-rich assembly due to long-horizon credit assignment and subtask coupling: a state that is geometrically successful for the current skill can be brittle for downstream skills. We show this failure mode in residual reinforcement learning (RL) over a frozen VLA base policy: constant sparse success rewards improve each subtask in isolation yet yield little or no gain when skills are chained, because terminal state quality is uncontrolled. We propose Foresight Residual RL, which optimizes handoff quality by augmenting each subtask's sparse success reward with an offline-estimated foresight value -- the probability of future subtask success conditioned on the terminal state of the current subtask. Concretely, we (i) train a visual foresight predictor from images of terminal states of the base policy, labeled using downstream rollout statistics, and (ii) train residual policies via backward foresight induction, using the predictor output as a reward multiplier. On a three-phase wrench-based nut-tightening assembly task in Isaac Gym (grasp, move-insert, rotate), our method achieves 85.6% full-task success, outperforming standard subtask residual RL (54.5%) and VLA baselines, while leaving per-subtask success unchanged. These results highlight that improving long-horizon performance requires shaping which successful states are produced at each sub-task, not only whether success occurs.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：视觉-语言-动作（VLA）模型为通用机器人操作提供了强大先验，但在长时域（long-horizon）、高精度、接触密集的装配任务（如用扳手拧紧螺母）中表现不佳。这类任务通常被分解为多个子任务（如抓取、移动插入、旋转），每个子任务单独训练策略再链式执行。
- **核心问题**：子任务之间存在**因果耦合**——前一子任务的成功终端状态（仅满足几何成功判据）可能对后续子任务脆弱（如抓取姿势虽几何成功但不利于插入）。标准残差强化学习使用恒定的稀疏成功奖励提升每个子任务的成功率，但链式执行时全任务性能无增益，因为**终端状态质量未被控制**。
- **研究意义**：论文指出，提升长时域操作性能的关键不是仅仅提高子任务是否成功，而是**塑造子任务产生哪些成功状态**（即终端状态的“前景价值”）。这填补了独立训练与链式执行之间的鸿沟。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- 提出**Foresight Residual RL（远见残差强化学习）**，通过离线学习一个**视觉远见预测器**，估计当前子任务终端状态后下一子任务的成功概率，并将该概率作为**奖励乘子**，在训练当前子任务的残差策略时引导策略生成有利于后续子任务的终端状态。

### 2.2 关键技术细节
1. **远见值函数（Foresight Value Function）**：
   - 定义：对于阶段 \(k\)，远见值 \(V_{k+1:K}(s)\) 是从状态 \(s\) 开始执行后续策略 \(\pi_{k+1:K}\) 后最终阶段成功的期望折扣回报。
   - 论文采用**一步近似**：\(V_{k+1}(s) = \Pr(\text{子任务 }k+1\text{ 成功} \mid s, \pi_{k+1})\) 近似代替完整远期价值。

2. **视觉远见预测器训练**（Algorithm 2）：
   - **数据收集**：使用基策略 \(\pi^0_k\) 收集 \(N=2560\) 个成功终端状态（图像观测）。
   - **Monte Carlo标签**：对每个终端状态，用下游策略（基策略+已训练的残差策略）执行 \(K_{\text{rep}}=5\) 次独立回放，统计成功次数 \(\kappa_i\)，得到经验成功率 \(y_i = \kappa_i / K_{\text{rep}}\)。
   - **预测器架构**：使用 DINOv2-S/14 的 CLS token 从两个相机视图提取特征，经自注意力和线性层映射到标量，通过 sigmoid 输出概率。训练损失为**二项式负对数似然**（Binomial NLL）。
   - 预测器在离线阶段一次性训练，在线 RL 训练时提供即时的、确定性的远见估计。

3. **反向归纳训练（Backward Foresight Induction）**（Algorithm 1）：
   - 从最后一个阶段 \(K\) 开始逆向训练每个阶段的残差策略。
   - 对阶段 \(K\)：无需远见，标准奖励 \(r_t = \beta_K(s_{t+1})\)。
   - 对阶段 \(k < K\)：首先使用已训练好的下游策略 \(\pi_{k+1}\) 训练远见预测器 \(p_{\phi}\)，然后训练残差策略 \(\pi^{\text{res}}_k\)，奖励函数为：
     \[
     r_t = \beta_k(s_{t+1}) \cdot p_{\phi}(o_{t+1})
     \]
     其中 \(\beta_k\) 是子任务 \(k\) 的成功谓词，\(p_{\phi}(o_{t+1})\) 是预测器输出的未来成功概率。
   - 残差策略输出小修正：\(a_t = \pi^0_k(o_t) + \alpha \cdot \pi^{\text{res}}_k(o_t)\)，\(\alpha=0.1\)。

## 3. 实验设计

### 3.1 任务场景
- **环境**：NVIDIA Isaac Gym（GPU加速PhysX接触模拟）。
- **机器人**：7-DoF Kuka IIWA 臂 + 11-DoF Robotiq 三指夹爪。
- **任务**：三阶段扳手螺母拧紧装配：
  - **Grasp**（160步）：从支架上抓取扳手
  - **Move-Insert**（200步）：将扳手移动到螺母并插入
  - **Rotate**（200步）：逆时针旋转螺母至少60°，同时保持插入
- **观测**：两个256×256 RGB图像（第三视角+腕部相机）+ 8维 proprioception（末端位姿+夹爪状态），无力反馈或真值物体位姿。
- **动作**：7维操作空间控制增量（3D位置+3D旋转轴角+1D夹爪命令）。
- **随机化**：扳手架、螺母、螺栓初始位姿随机；5种扳手-螺母尺寸变体，间隙<2mm。

### 3.2 对比方法
- **π0 (end-to-end)**：直接用π0（一个VLA模型）学习整个任务，未分解。
- **π0 (chained)**：每个子任务分别微调π0，链式执行。
- **π0 + Residual**：每个子任务上使用标准残差强化学习（恒定成功奖励），采用PPO训练残差策略。
- **π0 + Residual with Foresight（本文方法）**：使用远见预测器加权的残差强化学习。

### 3.3 评估指标
- **子任务成功率**（从专家真值状态初始化，即Oracle初始化）
- **两阶段链式成功率**（Grasp+Insert, Insert+Rotate）
- **全任务成功率**（三级链式执行）

## 6. 主要结论与发现

1. **标准残差RL的失效**：虽然标准残差RL将子任务成功率（如Insert从45.7%提升到92.2%）大幅提升，但全任务成功率仅54.5%（与无分解的端到端π0的54.9%持平），说明提升子任务成功**不保证**链式增益。
2. **远见修正显著提升链式性能**：本文方法全任务成功率达85.6%，比标准残差高31.1%。增益集中在Grasp→Insert边界（+31.8%）。
3. **机制验证**：标准残差RL反而降低了终端状态的远见预测分数（Grasp终端从0.64降至0.32），而本文方法将Grasp终端分数提升至0.73。这直接解释了性能差异。
4. **核心启示**：优化子任务是否成功不足以解决耦合问题，必须优化**哪些成功状态被产生**（即终端状态的质量）。

## 7. 优点

- **问题洞察深刻**：识别出标准残差RL忽略交接质量的普遍问题，并量化展示了该现象。
- **方法设计优雅实用**：采用离线预测器避免在线远见估计的高方差和高计算开销；反向归纳保证了远见估计的平稳性；残差策略设计（α→0）使得分布偏移可控。
- **视觉预测器直接以图像为输入**，可迁移到真实环境，不依赖状态真值。
- **与现有VLA框架兼容**：基于π0作为基策略，可扩展至其他VLA模型。
- **实验验证清晰**：多粒度实验（Oracle子任务、链式、全任务）和终端质量分析共同证明了方法有效性和机理。

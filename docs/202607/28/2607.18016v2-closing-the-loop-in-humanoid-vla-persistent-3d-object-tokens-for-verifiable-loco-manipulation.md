## 摘要
视觉-语言-动作策略是通用机器人控制的一个有前景的基础，但长时域仿人移动操作要求机器人将任务物体视为持久物理实体，跨越运动、接触、遮挡和恢复。我们将此问题研究为物体状态偏差：用于调节全身动作的物体状态可能与用于判断动作是否达到预期物理关系的状态不同。我们提出持久物体标记化（POT），该方法从RGB-D观测中维护角色索引的3D物体记录，并将其转换为物体标记，供全身动作专家使用。实例化为POT-VLA后，相同的物体记录调节动作生成并支持几何谓词检查，形成了一个闭环执行系统，其中物体状态既可操作又可验证。在宇树G1上，POT-VLA在八个真实世界任务族中将匹配的直接GR00T-N1.7基线从39/80成功率提升至71/80。在外部Being-0对齐参考中，POT-VLA在对齐服务任务上达到44/50成功率，而Being-0论文报告的为37/50。最大的改进出现在需要维持3D关系的任务上，表明以持久物体为中心的状态是可验证仿人VLA执行的一个有用抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：人形机器人在长时域移动操控（loco-manipulation）任务中面临“物体状态发散”（object-state divergence）问题。即用于调节全身动作的物体状态，与用于判断该动作是否达成预期物理关系的物体状态可能不一致，导致抓取错误、放置偏差、过早推进任务子步等失败。
- **整体意义**：现有VLA（视觉-语言-动作）策略通常隐式地将物体状态编码在视觉-语言特征中，难以保持、刷新并与验证器共享。本研究提出**持久3D物体令牌**，使物体状态在动作生成和执行验证中保持一致，从而提升人形机器人长时任务的可验证性和可靠性。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：维护角色索引（role-indexed）的3D物体记忆，将任务相关实体绑定到固定角色槽（如 `TARGET`、`DESTINATION`、`SUPPORT`、`HANDOVER_PARTNER`），从RGB-D观测中刷新该记忆，并序列化为“持久3D物体令牌”（Persistent 3D Object Tokens），同时用于动作专家（action expert）的条件化输入和几何谓词验证器的检查，形成一个闭环：**ground → act → refresh → verify → recover**。
- **关键技术细节**：
  1. **POT（Persistent Object Tokenization）**：
     - 从VLM规划器或任务文件中获取类型化子任务（typed subtask）及其角色、接地查询、成功谓词等。
     - 利用SAM3分割、深度反投影、相机到基座的变换，构建每个物体的记录：语义角色、2D框、3D质心与范围、置信度、可见性、关系特征（如物体-容器距离、支撑高度、末端-物体偏移等）。
     - 将记录映射为固定槽数（K=8）和固定特征数（F=33）的张量 `x_obj_t`，每个槽包含 `[visibility, confidence, 2D box, 3D centroid, 3D extent, optional orientation, relation features]`。未使用的槽为 `PADDING` 并被掩码。
  2. **动作条件化**：
     - 采用GR00T-N1.7作为动作专家，在其DiT动作头的自注意力序列中插入物体令牌槽（`Z_state_t`, `Z_obj_t`, `Z_action_t`），并通过可学习的角色嵌入和上下文嵌入区分槽语义。
     - 使用投影网络（LayerNorm → Linear → GELU → Dropout → Linear）将令牌嵌入到DiT隐藏维度。

  3. **闭环验证与恢复**：
     - 执行每个短时域动作块后，重新观测RGB-D刷新同一物体记忆，然后由几何谓词监督器（predicate supervisor）检查预定义的物理关系谓词（如 contain, support, proximity, displacement 等）。

- **方法亮点**：

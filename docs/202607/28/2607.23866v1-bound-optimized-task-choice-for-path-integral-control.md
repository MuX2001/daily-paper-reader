## 摘要
路径积分（PI）控制是一种强大的基于采样的随机最优控制方法，但它要求噪声协方差与控制成本矩阵之间具有限制性的耦合关系，而这种关系在实践中很少得到满足，特别是在航空航天和信息物理系统中。我们提出了边界优化任务选择（BOTC）框架，该框架在整个有效近似空间（称为任务）上进行优化，这些任务满足PI耦合约束。我们证明每个任务都提供了真实代价函数的上界，并且BOTC最小化这个上界。我们推导了一个测度变换公式，使得能够从一组蒙特卡洛样本中评估所有候选任务，从而无需为每个候选任务重新采样。由此产生的优化由一个半正定矩阵参数化。此外，我们提出了一种新颖的基于正态-逆威沙特分布的重要性采样方案来改进全局优化。我们在一个有限时域随机线性二次调节器问题上验证了BOTC，证明它能够跟踪受约束的最优解。

## Abstract
Path Integral (PI) control is a powerful sampling-based method for stochastic optimal control, but it requires a restrictive coupling between the noise covariance and the control cost matrix that is rarely satisfied in practice, particularly in aerospace and cyber-physical systems. We propose Bound-Optimized Task Choice (BOTC), a framework that optimizes over the entire space of valid approximations, termed tasks, satisfying the PI coupling constraint. We prove that every task provides an upper bound on the true cost-to-go and that BOTC minimizes this bound. We derive a change-of-measure formulation that enables evaluation of all candidate tasks from a single set of Monte Carlo samples, eliminating the need to resample for each candidate task. The resulting optimization is parameterized by a positive semi-definite matrix. Furthermore, we propose a novel Normal-Inverse-Wishart distribution-based importance sampling scheme to improve global optimization. We validate BOTC on a finite-horizon stochastic linear-quadratic regulator problem, demonstrating that it tracks the constrained optimum.

### 1. 核心问题与整体含义（研究动机和背景）

路径积分（PI）控制是一种基于蒙特卡洛轨迹采样的随机最优控制方法，能够避免求解非线性的Hamilton-Jacobi-Bellman（HJB）偏微分方程。然而，PI控制的核心要求是噪声协方差矩阵 **Σ** 与控制成本矩阵 **R** 之间必须满足耦合约束 **Σ = λ B R⁻¹ Bᵀ**（λ为标量，B为控制影响矩阵）。这一条件在实际系统中（特别是航空航天、信息物理系统）很少自然满足。传统处理方法要么让协方差决定控制成本（即放大控制成本），要么让控制成本决定协方差（即放大噪声），两者都会引入系统性偏差，使得求解出的策略偏向于欠驱动或过于保守。作者提出 **Bound-Optimized Task Choice（BOTC）** 框架，旨在通过优化整个“有效近似任务”空间来最小化真实代价的上界，从而在不满足原始约束的情况下仍能获得接近最优的PI控制解。

### 2. 方法论

#### 核心思想
- 将原问题（不满足Σ=λBR⁻¹Bᵀ）视为“难以求解的真实问题”，而将满足耦合约束的修改问题称为“任务”。每个任务由修正后的协方差 **Σ+** 和控制成本 **R+** 定义，且满足 **Σ+ = λB(R+R⁺)⁻¹Bᵀ**。
- 证明每个任务提供的期望代价（成本函数）都是真实最优代价的上界（Lemma 1）。通过最小化这个上界，可以找到最接近真实最优解的PI兼容近似问题。
- 关键技巧：利用 **测度变换**（Radon-Nikodym导数）将不同任务的期望用同一组蒙特卡洛样本重新加权，避免了对每个候选任务重新采样大量轨迹（Lemma 3）。将任务选择转化为关于半正定决策矩阵 **D**（或等价变量 eD）的优化问题。

#### 技术细节
- **任务空间参数化**：令 **Σ+** 为附加噪声协方差，0 ≤ Σ+ ≤ λBR⁻¹Bᵀ - Σ。通过变量替换 **(Σ+Σ⁺)⁻¹ = Σ⁻¹ - D**，将凸约束转化为 **0 ≤ D ≤ Σ⁻¹ - λ⁻¹(BR⁻¹Bᵀ)⁻¹**。
- **优化目标**：最大化变换后的对数期望（即“desirability” Ψ），表达式为：
  \[
  \max_{D} \left( |\Sigma|^{\frac{N}{2}} |\Sigma^{-1} - D|^{\frac{N}{2}} \sum_{k} \exp\left( \frac{1}{2} \text{Tr}(D Z_k) - \frac{S_k}{\lambda^*} \right) \right)
  \]
  其中 \(Z_k\) 是轨迹偏差的散度矩阵，\(S_k\) 是无控制路径成本，\(N\) 是时间步数，\(\lambda^*\) 是满足约束的最小λ。
- **降维处理**：由于D的上界矩阵是奇异的，通过特征分解将优化限制在非奇异子空间，并使用Schur补简化行列式计算。
- **全局优化采样**：提出基于 **Normal-Inverse-Wishart (NIW) 分布** 的重要性采样方案。先对协方差矩阵的超参数采样，再生成Z_k，使得样本覆盖整个约束空间（Lemma 4, Proposition 2），弥补静态采样仅在局部准确的不足。

#### 算法流程（Algorithm 1）
1. 参数输入：R, Σ, ϕ, q等。
2. 循环（直到任务完成）：
   - 采集K条轨迹样本；
   - 求解优化问题得到最优D（用静态或NIW采样）；
   - 计算最优控制序列 u* = Σ gx(D)·exp(-S_k/λ*)·dξ/dt；
   - 将首步控制发送给执行器。

## 摘要
动作标记化将连续的机器人动作块映射为离散标记，已成为现代视觉运动策略的重要接口。现有方法要么依赖分析离散化方法产生过长的标记序列，要么依赖缺乏结构的学习型隐层标记器，限制了与下游策略的兼容性。在这项工作中，我们提出了动作标记化的三个期望特性——高压缩、完全可解码和有序的标记空间——并引入有序动作标记化（OAT），这是一种满足所有三个特性的学习型标记器。OAT利用带有寄存器的Transformer、有限标量量化和排序诱导训练机制，将动作块离散化为有序的标记序列。通过训练每个标记前缀解码为有效的动作块，OAT将粗粒度控制信息置于早期标记，并利用后续标记细化残差细节，实现了推理成本与动作保真度之间的任意时刻权衡。我们在动作标记的两种主要用法中验证了OAT：生成控制标记的自回归策略，以及使用标记损失来塑造基于流的动作专家所消耗的视觉-语言模型上下文的标记协同训练策略。跨越三个策略主干和涵盖五个模拟基准及真实世界设置的60多个任务，OAT始终提供强大的策略性能，同时在推理时提供显著更大的灵活性。

## Abstract
Action tokenization maps continuous robot action chunks to discrete tokens and has become an important interface for modern visuomotor policies. Existing approaches either rely on analytical discretization methods that produce prohibitively long token sequences or learned latent tokenizers that lack structure, limiting their compatibility with downstream policies. In this work, we identify three desiderata for action tokenization - high compression, total decodability, and an ordered token space - and introduce Ordered Action Tokenization (OAT), a learned action tokenizer that satisfies all three. OAT discretizes action chunks into an ordered sequence of tokens using a transformer with registers, finite scalar quantization, and ordering-inducing training mechanisms. By training each token prefix to decode into a valid action chunk, OAT places coarse control information in early tokens and uses later tokens to refine residual detail, yielding an anytime tradeoff between inference cost and action fidelity. We validate OAT in two prevailing uses of action tokens: autoregressive policies that generate tokens for control, and token co-training policies that use token losses to shape the vision-language model context consumed by a flow-based action expert. Across three policy backbones and more than 60 tasks spanning five simulation benchmarks and real-world settings, OAT consistently delivers strong policy performance while offering significantly greater flexibility at inference time.

- **整体含义**：设计良好的动作标记应同时满足**高压缩**（缩短序列长度）、**完全可解码**（任意策略输出可映射为有效动作）和**有序结构**（早期标记包含粗粒控制信息，后期细化细节）。本文提出有序动作标记化（OAT）以实现这三个目标，从而提升策略学习效率和推理灵活性。

#### 2. 方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：OAT 是一种学习型标记器，将连续动作块编码为有序离散标记序列，其中每个前缀（部分标记）可直接解码为有效动作块，早期标记负责粗粒控制，后期标记细化残差细节。
- **关键技术细节**：
  - **编码器-量化器-解码器架构**：使用带有可学习寄存器的 Transformer 编码器，将动作块压缩为固定长度寄存器状态；采用有限标量量化（FSQ）将每个寄存器状态离散化为标记；解码器通过交叉注意力从量化后的标记重建动作块。
  - **有序前缀训练**：通过**嵌套 dropout（nested dropout）** 实现。定义预算集 \( \mathcal{K} = \{k_1, \dots, k_M\} \)（如 {1,2,4,8,16}），训练时随机采样预算 \( K \)，保留前 \( K \) 个标记，后缀替换为学习到的遮罩标记，强制解码器从部分前缀重建完整动作块。这使早期标记承载更多全局信息，形成粗到细的结构。
  - **寄存器注意力掩码**：针对自回归策略，提出两种变体——**token-wise 排序**（因果注意力，每个标记依赖之前所有标记）和**power-of-two 排序**（块因果注意力，按预算组分组，组内无依赖）。后者支持分块自回归生成，将策略调用次数从 \( O(H_l) \) 降低到 \( O(\log H_l) \)。
- **公式与算法流程**：
  - **Tokenization**：\( \mathbf{z}_{1:H_l} = E_\phi(\mathbf{a}_{1:H_a}, \mathbf{r}_{1:H_l}) \)，\( T_i = \text{FSQ}(z_i) \)。
  - **有序前缀损失**：\( \mathcal{L}_{\text{prefix}} = \mathbb{E}_{\mathbf{a}, K} \left[ \| D_\theta(\tilde{\mathbf{T}}_{1:H_l}^{(K)}) - \mathbf{a}_{1:H_a} \|_2^2 \right] \)，其中 \( \tilde{\mathbf{T}}_{1:H_l}^{(K)} = \mathbf{T}_{1:K} \oplus \langle \text{MASK} \rangle_{K+1:H_l} \)。
  - **Block-wise Autoregressive (BAR) 生成**：将生成过程分为块，每块一次策略调用。训练目标为 \( \mathcal{L}_{\text{BAR}} = -\frac{1}{S} \sum_{s=1}^S \frac{1}{g_s} \sum_{j=1}^{g_s} \log p_{\pi, j}^{(s)}(T_{b_{s-1}+j} | X^{(s)}, o) \)。
  - **Token Co-training (TC)**：联合优化标记交叉熵损失和流匹配损失，VLM 通过冻结标记器监督，流专家从分离的 VLM 上下文生成连续动作。

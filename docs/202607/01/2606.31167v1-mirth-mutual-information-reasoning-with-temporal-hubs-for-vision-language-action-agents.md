## 摘要
VLA模型已成为将网络规模数据的语义知识迁移到物理机器人控制中的强大范式。然而，当前的单帧架构存在固有局限性：时间短视（丢弃历史动态）、高层指令与低层运动命令之间的推理鸿沟，以及自回归标量解码导致的推理效率低下。本文提出MIRTH——一个旨在解决这些挑战的统一框架。MIRTH通过三项关键创新增强了预训练的VLA骨干网络：（1）双尺度时序记忆枢纽，将长期场景演变和短期运动趋势压缩为紧凑嵌入；（2）通过互信息目标优化的潜在推理标记，刻画出语义规划空间以对齐多模态上下文与动作轨迹；（3）并行动作解码方案，以向量级预测取代自回归生成，最大化控制吞吐量。在LIBERO模拟基准和真实世界的LeRobot平台上的广泛评估表明，MIRTH实现了最先进的性能，并展现出新兴的错误恢复能力。代码和收集的数据集发布于http://github.com/kiva12138/mirth。

## Abstract
VLA models have emerged as a powerful paradigm for transferring semantic knowledge from web-scale data to physical robotic control. However, current single-frame architectures suffer from intrinsic limitations: temporal myopia that discards historical dynamics, reasoning gaps between high-level instructions and low-level motor commands, and inference inefficiency due to autoregressive scalar decoding. In this work, we propose MIRTH, a unified framework designed to address these challenges. MIRTH augments a pretrained VLA backbone with three key innovations: (1) dual-scale temporal memory hubs that compress long-term scene evolution and short-term motion trends into compact embeddings; (2) latent reasoning tokens optimized via a mutual-information objective carving out a semantic plan space to align multimodal context with action trajectories; and (3) a parallel action decoding scheme that replaces autoregressive generation with vector-wise prediction to maximize control throughput. Extensive evaluations on the LIBERO simulation benchmark and a real-world LeRobot platform demonstrate that MIRTH achieves state-of-the-art performance and exhibiting emergent error recovery capabilities. The codes and collected datasets are released at http://github.com/kiva12138/mirth.

## 1. 核心问题与整体含义（研究动机与背景）

当前视觉-语言-动作（VLA）模型（如OpenVLA、RT-2）存在三大内在局限性：

- **时间短视（Temporal Myopia）**：依赖单帧观测，丢弃历史动态，无法处理物体被遮挡或状态变化。
- **推理鸿沟（Reasoning Gap）**：缺乏从高级语言指令到低级运动命令的中间推理，直接映射导致歧义。
- **推理效率低（Inference Inefficiency）**：使用标量量化 + 自回归解码，生成一个动作需要多个token，造成高延迟。

MIRTH 是一个统一框架，旨在通过**时序记忆、潜在推理、并行动作解码**同时解决上述问题。

## 2. 方法论：核心思想与关键技术细节

### 2.1 双尺度时序记忆枢纽（Dual-scale Temporal Memory Hubs）
- **长期工作空间记忆**：对每个像素块（patch）维护 K 个指数移动平均（EMA），不同衰减率 βk 捕捉不同时间尺度的场景布局。
- **短期记忆枢纽**：维护最近 w=4 帧的队列，通过带时间偏差（recency bias）的软注意力融合当前帧与过去帧，捕捉运动趋势。
- **融合**：通过可学习门控将两个枢纽输出加权融合，再通过**前缀（prefix）**或**注入（infusion）**方式输入到VLM骨干。最终选择前缀策略（效果更好，吞吐略低）。

公式摘要：  
- 长期记忆：M_t,k = (1-βk)M_{t-1,k} + βk V_t  
- 短期记忆：通过注意力加权队列中的值。  
- 门控融合：g_t = σ(W_g [V_t; M_work; M_short])

### 2.2 互信息潜在推理令牌（Latent Reasoning Tokens）
- 在输入序列中插入 m 个可学习的推理令牌（reason tokens），位于上下文和动作令牌之间。
- 提取三个表示：推理令牌平均嵌入 z_R、动作令牌平均嵌入 z_A、上下文令牌（紧接推理之前的）嵌入 z_X。
- 使用InfoNCE损失最大化 z_R 与 z_A 及 z_X 之间的互信息（MI），使推理令牌携带对齐语义与动作的规划信息，无需文本监督。

损失：L_mi = λ_ra L_ra + λ_rx L_rx

### 2.3 并行动作解码（Parallel Action Decoding）
- 每个完整动作向量（6自由度）使用一个动作令牌，而非每个自由度一个令牌。
- 对于长度为 NA 的动作块，所有动作令牌的隐藏状态通过一个轻量投影头，一次性并行输出所有连续动作值（全局拼接式投影）。
- 训练采用 L1 回归损失 + MI损失。

L = L_l1 + λ_mi L_mi

### 2.5 推理流程
- 只编码当前帧，增量更新EMA记忆，单次前向并行产生整个动作块，吞吐量高。

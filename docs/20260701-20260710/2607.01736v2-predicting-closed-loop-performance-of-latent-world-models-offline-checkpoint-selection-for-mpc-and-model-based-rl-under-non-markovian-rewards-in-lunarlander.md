## 摘要
我们研究如何仅凭验证时的诊断信息来预测学习到的潜在世界模型的下游闭环性能。从世界模型训练运行中选择合适的检查点很困难：在闭环性能崩溃很久之后，验证损失和多步预测RMSE仍在持续改善。我们提出了一套源自最优控制理论的结构性验证时诊断指标，并将其应用于具有成形奖励的Gymnasium LunarLander v3。我们在其上训练了一个RSSM[5,4]世界模型，并将每个检查点的CEM-MPC回报视为闭环质量的基准。通过对比40个指标与该基准，我们发现最强的单一预测因子是奖励可观测性分数（ROF），它衡量奖励预测器对可观测子空间的依赖程度。我们将ROF与三个结构性正则化器结合成一个单一数值的离线检查点选择分数，即复合奖励可观测性分数（CROF）。经CROF选择的世界模型训练的基于模型的A2C策略，在公平评估下比无模型的A2C基线高出约24.5回报点，同时使用的真实环境交互次数减少约65倍；同一世界模型还能驱动强大的零样本CEM-MPC策略。代码和数据：https://github.com/nsmoly/LunarLander_RSSM。

## Abstract
We study how to predict the downstream closed-loop performance of a learned latent world model from validation-time diagnostics alone. Choosing the right checkpoint from a world-model training run is difficult: validation loss and multi-step prediction RMSE keep improving long after closed-loop performance has collapsed. We present a suite of structural validation-time diagnostics drawn from optimal-control theory and apply them to Gymnasium's LunarLander v3, which features shaped rewards. We train an RSSM [5, 4] world model on it and treat per checkpoint CEM-MPC return as the oracle for closed-loop quality. By evaluating 40 metrics against this oracle, we find that the strongest single predictor is the Reward Observability Fraction (ROF), which measures the reward predictor's dependence on the observable subspace. We combine ROF with three structural regularizers into a single-number offline checkpoint selection score, the Composite Reward Observability Fraction (CROF). The CROF-selected world model trains a model-based A2C policy that beats a fairly evaluated model-free A2C baseline by ~24.5 return points while using ~65x fewer real-environment interactions, and the same world model also drives a strong zero-shot CEM-MPC policy. Code and data: https://github.com/nsmoly/LunarLander_RSSM.

### 2. 论文提出的方法论

- **核心思想**：从经典控制理论的角度分析学习到的潜动力学模型，认为闭环规划质量取决于奖励相关、可控和可观子空间之间的几何对齐程度，而非简单的统计拟合精度。通过计算潜空间中的可控性和可观测性矩阵的秩以及子空间对齐分数，预测世界模型在开环想象规划（MPC或基于想象的A2C）中的退化程度。
- **关键技术细节**：
  - **世界模型架构**：使用RSSM（GRU + 随机潜在变量 \( z_t \)），隐状态 \( s_t = [h_t; z_t] \in \mathbb{R}^{272} \)。解码器包括异构头部：物理回归、接触BCE、done标志BCE，以及一个直接基于 \( [h;z] \) 的3层奖励MLP（独立于观测解码器骨干网络），使得奖励预测器发展出独立于观测重建的表征。
  - **MPC规划**：使用交叉熵方法（CEM）适配离散动作空间，规划步长 \( H=25 \)，种群 \( N=384 \)，精英 \( E=48 \)，迭代 \( I=4 \)。
  - **诊断指标**：共40个指标，分为四类：
    1. 验证损失分解（val loss, val kl, val recon等）。
    2. 多步开环滚动（ol obs rmse, ol rew rmse, ol cumrew err等）。
    3. **基于Jacobian的线性分析**（核心）：
       - 计算固定线性化或时变线性化下的转移矩阵 \( A \)、输入矩阵 \( B \)、观测矩阵 \( C \)、奖励梯度 \( R \)。
       - 计算可控性矩阵 \( C_H \) 和可观测性矩阵 \( O_H \) 的有效秩和条件数。
       - **奖励可控性分数（RCF）**：奖励梯度在可控子空间中的能量比例。
       - **观测可控性分数（OCF）**：解码器敏感性在可控子空间中的能量比例。
       - **奖励可观测性分数（ROF）**：奖励梯度在可观子空间中的能量比例。**ROF是预测MPC性能的最强单一指标**（Spearman \( \rho_s = -0.71 \)）。
       - 状态类别的ROF：对高回报（\(\geq +100\)）和低回报（\(\leq -100\)）序列分别计算，并组合为 `jac rof combined`。
    4. 经验敏感性指标（动作敏感性、状态扰动敏感性、最大Lipschitz常数）。
  - **复合分数CROF**：将归一化的 `jac rof combined` 与三个结构正则化器（低可控性秩惩罚、低可观测性秩惩罚、高开环观测误差惩罚）组合为单一分数：
    \[
    \text{CROF-A} = \hat{\text{ROF}} + 1.0 \cdot (1 - \hat{k}_c) + 1.0 \cdot (1 - \hat{k}_o) + 1.0 \cdot \hat{e}_{\text{obs}}
    \]
    以及权重减半的CROF-B。其中 \( \hat{\cdot} \) 表示在所有检查点上的最小-最大归一化，且值越小表示检查点越好。

### 6. 论文的主要结论与发现

- 标准训练指标（验证损失、多步RMSE、经验敏感性）在训练后期仍单调改善，但闭环MPC性能却崩溃，因此无法用于离线检查点选择。
- **ROF（奖励可观测性分数）是预测MPC性能的最强单一指标**（Spearman \( \rho_s = -0.71 \)），其背后的机制是：当奖励信号依赖于不可观测子空间时，开环想象会积累无修正的漂移，导致奖励预测退化。在非马尔可夫奖励环境下，ROF的U形曲线与MPC回报的峰形吻合。
- 组合了ROF与三个结构正则化器的**CROF分数**，能在离线状态下选出与MPC oracle接近的最佳检查点（CROF raw pick epoch 280，MPC回报+162.8；oracle epoch 310，回报+153.0）。
- 使用CROF选出的世界模型（WM 280）训练的模型基A2C策略，达到峰值平均回报+217.48（79/100完美着陆），比无模型A2C基线（+193.04）高出约24.5分，同时仅使用180,916步真实环境交互，数据效率提升约65倍。
- 在奖励完全马尔可夫的Reacher环境中，ROF不携带信号，验证了方法的适用范围。

### 8. 不足与局限

1. **环境单一性**：所有定量结论仅基于LunarLander v3，虽然通过Reacher验证了机制边界，但缺少在更多连续动作、高维观测或不同奖励结构环境上的系统性验证。论文也承认这是未来工作的方向。
2. **计算开销**：计算Jacobian、可控/可观测矩阵及子空间对齐分数本身就涉及线性化与SVD，对于大规模潜在状态（如高维图像）可能计算成本较高。论文未讨论规模可扩展性。
3. **A2C检查点选择的空白**：论文仅解决了世界模型的离线选择，但最终A2C策略的检查点仍需要通过真实环境评估来选择（尽管可以通过世界模型内评估近似，但未验证）。这留下了一个明显的管道缺口。
4. **适用范围限定**：ROF/CROF的有效性依赖于奖励的非马尔可夫性；对于完全马尔可夫奖励的环境，标准指标可能更加简单有效。论文明确了这一限制，但未给出清晰的判定阈值（例如，什么样的R²值下ROF会失效）。
5. **CROF权重调参**：CROF-A和CROF-B两个版本的权重并非自动学习，而是手工设定；虽然论文进行了α（0.3-0.5）的简单扫描，但未证明在不同环境中如何自适应调整。

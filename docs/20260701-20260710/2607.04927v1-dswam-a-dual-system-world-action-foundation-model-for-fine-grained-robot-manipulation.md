## 摘要
世界动作模型（WAMs）通过基于视频的世界建模为机器人动作学习提供密集监督，是视觉-语言-动作（VLA）策略的一种有前景的替代方案。现有WAMs擅长基于物理的执行，但通常缺乏基于VLM的VLA中用于分解粗略指令的显式语言级规划接口。当家庭任务涉及复杂的多步目标时，这种分解变得重要，因为粗粒度的用户命令需要转换为一系列细粒度的可执行子任务。同时，该领域仍缺乏VLA和WAM执行能力之间公平的真实机器人对比，因为现有系统在数据、机器人本体和任务协议上往往不同。为了解决分解差距以及受控WAM-VLA对比的需求，我们提出了DSWAM，一种面向细粒度机器人操作的双系统世界动作基础模型。DSWAM将系统1 WAM执行器作为默认控制路径，并仅在任务分解有用时可选地激活系统2视觉-语言子任务规划器。规划器从短期视觉历史和全局任务提示中预测可执行的子任务，而WAM执行器为每个指令或子任务执行具有世界感知的动作生成。执行器通过动作预测和视频联合训练，但推理时直接预测动作块，无需显式的未来视频生成。为了使该执行路径在实际机器人上实用，我们进一步集成了TensorRT加速、异步执行和实时分块（RTC），使得策略查询不会阻塞机器人控制。为了与VLA策略进行公平的真实机器人对比，我们在DeMaVLA真实世界可变形操作设置下构建并评估DSWAM，该设置具有匹配的机器人平台、预训练数据、后训练数据和评估标准。

## Abstract
World Action Models (WAMs) provide a promising alternative to Vision-Language-Action (VLA) policies by using video-based world modeling as dense supervision for robot action learning. Existing WAMs excel at physically grounded execution, but typically lack the explicit language-level planning interface in VLM-based VLAs for decomposing coarse instructions. Such decomposition becomes important when household tasks involve complex multi-step goals, where coarse user commands need to be converted into sequences of fine-grained executable subtasks. Meanwhile, the field still lacks a fair real-robot comparison between VLA and WAM execution capabilities, since existing systems often differ in data, robot embodiments, and task protocols. To address both the decomposition gap and the need for a controlled WAM-VLA comparison, we introduce DSWAM, a Dual-System World Action Foundation Model for fine-grained robot manipulation. DSWAM keeps a System 1 WAM executor as the default control path and optionally activates a System 2 vision-language subtask planner only when task decomposition is useful. The planner predicts executable subtasks from short-term visual history and a global task prompt, while the WAM executor performs world-aware action generation for each instruction or subtask. The executor is trained with action prediction and video co-training, but inference directly predicts action chunks without explicit future video generation. To make this execution path practical on real robots, we further integrate TensorRT acceleration, asynchronous execution, and real-time chunking (RTC) so that policy queries do not block robot control. To provide a fair real-robot comparison with VLA policies, we build and evaluate DSWAM under the DeMaVLA real-world deformable manipulation setting with matched robot platform, pretraining data, post-training data, and evaluation criteria.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：世界动作模型（WAM）通过视频世界建模为机器人动作学习提供密集监督，在接触丰富的操作任务（如抓取、放置、可变形物体操作）中表现出色，优于传统的直接映射视觉-语言-动作（VLA）策略。然而，现有WAM主要设计为执行策略，缺乏显式的语言级规划接口，无法将粗粒度的用户指令分解为细粒度的可执行子任务。同时，WAM与VLA之间缺乏公平的真实机器人对比，现有比较常因数据源、机器人本体和任务协议不同而产生混淆。
- **核心问题**：如何在不牺牲WAM物理执行优势的前提下，为其引入语言级任务分解能力，并在公平条件下与VLA进行对比验证。
- **整体含义**：DSWAM提出了双系统（Dual-System）框架，将语义任务组织（System 2，可选的VLM子任务规划器）与物理世界感知执行（System 1，WAM执行器）解耦，仅在需要时激活高层规划，从而兼顾原子指令的快速执行与复杂多步任务的分解需求。

## 2. 方法论

### 2.1 核心思想
- 采用**双系统架构**：System 1为默认的WAM执行器，负责世界感知的动作生成；System 2为可选的视觉-语言子任务规划器，仅在粗指令需要分解时激活，预测有序的可执行子任务。
- 执行器训练时使用**动作预测与视频联合训练**（video co-training），但推理时**不进行显式未来视频生成**，直接预测动作块，配合实时分块（RTC）和TensorRT加速，实现低延迟的实际部署。

### 2.2 关键技术细节

#### System 2 高层规划器
- 基于Rynnbrain4B风格的视觉-语言模型。
- 输入：全局任务提示 \(p\) 和最近 \(T=5\) 帧（1Hz采样）的短期视觉历史 \(X_t\)。
- 输出：下一个子任务级指令 \(s_t\)。
- 训练数据：从机器人轨迹视频中自动分割子任务边界并生成过渡感知标签（transition-aware supervision），目标包括识别当前子任务、在边界处预测下一子任务、末端任务标记“done”。
- 损失函数：自回归语言建模目标 \(L_{\text{plan}}\)。
- 耦合：执行器每2秒向规划器发送最近5帧，规划器返回新子任务；若未激活，则直接使用原始指令。

#### System 1 WAM执行器
- 编码器：从多视图RGB、语言指令/子任务、本体感受编码为潜在世界特征 \(z_t\)。
- 动作预测：基于条件流匹配（conditional flow matching）预测连续动作块 \(A_t\)（长度为H）。
- 训练目标：
  - 动作损失 \(L_{\text{act}} = \text{LFM}(A_t)\) （流匹配损失）
  - 视频联合训练损失 \(L_{\text{vid}} = \text{LFM}(V_{t+1:t+T})\)，其中 \(V\) 为未来视觉token（但动作token不能利用未来视觉token作为特权信息）。
  - 总损失 \(L = L_{\text{act}} + \lambda_{\text{vid}} L_{\text{vid}}\)。
- 推理：直接对当前观测前向传播得到动作块，无需去噪未来帧。

#### 部署优化
- **TensorRT加速**：将视觉上下文引擎和动作去噪引擎分别编译，采用BF16精度，相比PyTorch推理速度提升2.69倍（198.2ms → 73.8ms）。
- **实时分块（RTC）与异步执行**：策略预测新动作块与机器人控制解耦，控制循环继续执行当前块，避免阻塞。

## 3. 实验设计

### 3.1 数据集与场景

- **真实世界折叠协议（DeMaVLA设置）**：使用ALOHA风格双臂平台，评估4种衣物（衬衫、裙子、裤子、毛巾）的折叠任务；每种衣物有2个物理实例（一个容易，一个困难，困难衣物未包含在训练数据中或已老化）；每实例10次试验，共20次/类别。
- **System 2排序任务**：桌面排序任务，粗指令“Sort objects on the table”，可分解为“拾取玩具车放入盒子”和“拾取面包放在盘子上”。

1. **DSWAM在匹配的DeMaVLA真实世界折叠基准中优于VLA**：相比DeMaVLA，平均成功率从92.5%提升至96.3%，平均完成时间从2′18″缩短至1′44″（System 2关闭）。在裤子任务上提升明显（SR从75%→90%，时间缩短）。

## 摘要
近期具身人工智能的进展已将机器人基础模型确立为迄今为止通用机器人系统的主流方法。通过利用大规模机器人演示数据的模仿学习，机器人基础模型在将视觉观察和语言指令映射为连续机器人动作方面取得了令人印象深刻的能力。然而，当前的机器人基础模型缺乏对物理动力学以及机器人行为对3D物理世界因果效应的内在推理能力。这在以2D为中心的视觉感知和以3D为中心的具身交互之间造成了根本性不匹配，严重限制了机器人基础模型在真实世界任务中的泛化能力。为解决这一差距，我们提出了WSA$_1$，一种基于所提出的以3D为中心的世界-空间-动作建模范式的新型机器人基础模型。它不仅学习用于未来机器人行为的3D世界感知视觉思维，还建模3D世界状态转移与机器人动作之间的相互约束以增强行为泛化。值得注意的是，WSA$_1$在仅使用6000小时专家演示数据（其中仅1000小时来自真实机器人）的情况下实现了高度数据高效的预训练，同时在RoboTwin2.0模拟基准测试中展现出具有竞争力的操作性能（93%成功率），并在真实世界机器人控制任务上相比最先进的机器人基础模型实现了平均+20%的性能提升。这些结果表明，当与以3D为中心的世界-动作联合建模相结合时，无需大规模真实机器人数据即可获得可泛化的机器人基础模型，这为通用机器人系统提供了一条实用且经济可行的路径。

## Abstract
Recent advances in embodied AI have established robot foundation models (RFMs) as the dominant approach for generalist robotic systems to date. By leveraging imitation learning on extensive robot demonstrations, RFMs have achieved impressive capabilities in mapping visual observations and language instructions to continuous robotic actions. However, current RFMs lack an inherent ability to reason about physical dynamics and the causal effects of robot behaviors on the 3D physical world. This creates a fundamental mismatch between 2D-centric visual perception and 3D-centric embodied interaction, severely limiting the generalization ability of RFMs in real-world tasks.To address this gap, we present WSA$_1$, a novel RFM built upon proposed 3D-Centric World-Spatial-Action modeling paradigm. It not only learns 3D world-aware visual thought for future robot behaviors, but also models mutual constraints between 3D world state transitions and robotic actions to enhance behavior generalization. Notably, WSA$_1$ achieves highly data-efficient pre-training with 6k hours of expert demonstration data (only 1k hours from real robot), while delivering competitive manipulation performance (93% success rate) on RoboTwin2.0 simulation benchmark and achieving +20% average boosted performance over state-of-the-art RFMs on real-world robot control tasks. These results reveal that generalizable RFM can be attained without large-scale real robot data when paired with 3D-centric world-action joint modeling, which offers a practical and affordable pathway to generalist robotic systems.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：当前机器人基础模型（RFM）主要分为两类：Vision-Language-Action (VLA) 模型和 World-Action Model (WAM)。VLA 模型依赖 2D 视觉语义理解直接输出动作，WAM 模型通过视频生成进行隐式规划。两者均缺乏对 **3D 物理世界动态**和**机器人行为因果效应**的显式建模能力。
- **核心问题**：2D 视觉感知与 3D 具身交互之间存在根本性不匹配，导致模型难以泛化到真实世界中需要3D空间认知和稳健适应环境变化的任务。同时，现有方法依赖大规模真实机器人演示数据（成本极高），数据效率低下。
- **研究目标**：提出一种数据高效的建模范式，使机器人能够联合建模 3D 世界演化与物理行为之间的相互依赖关系，从而克服纯模仿学习的泛化瓶颈。

## 2. 论文提出的方法论

### 核心思想：3D-Centric World-Spatial-Action (WSA) 建模范式
该范式统一三个互补的学习目标，在共享潜空间中建模：
- **世界因果层**：学习动作引起的 3D 世界状态预测（Action-conditioned 3D World Model）。
- **空间认知层**：学习 3D 一致的 2D 视觉思维（3D-consistent 2D Visual Thinking）。
- **动作执行层**：学习 3D 逆动力学（3D Inverse Dynamics），将 3D 状态转移映射为可执行动作。

### 模型架构：Mixture-of-Transformers (MoT)
包含三个专家模块：
- **2D Spatial Expert**：从预训练视觉语言模型（Qwen3-VL或Wan2.2）初始化，预测未来 2D 子目标图像的潜表征（token），而非像素。
- **3D Spatial Expert**：基于 Transformer 架构，预测未来 3D 场景的潜表征（由 Depth-Anything 编码）。
- **3D Action Expert**：基于扩散 Transformer（Flow Matching），在给定未来 3D 潜表征和噪声动作的条件下，去噪生成连续动作片段。

### 关键机制：双向因果注意力
- 定义依赖规则：所有预测 token 可关注当前观察 token；视觉 token 可关注 3D token；3D token 与动作 token 双向全注意力——实现世界-动作相互约束的因果归纳偏置。

### 损失函数
总损失为三项之和：
- **L2D**：预测子目标图像 token 与真实 token 之间的 MSE 损失。
- **L3D**：预测 3D 场景潜表征与真实 3D 几何潜表征之间的 MSE 损失。
- **LACT**：流匹配损失，优化动作生成。

### 训练策略
- 两阶段：预训练（在混合数据源上联合优化三个目标）+ 后训练（在目标任务上微调，同时保持三个目标）。

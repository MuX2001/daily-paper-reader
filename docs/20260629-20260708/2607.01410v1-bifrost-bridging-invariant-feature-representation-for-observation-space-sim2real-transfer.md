## 摘要
由于仿真与现实之间的差异，机器人策略学习的仿真到现实迁移（sim2real）面临困难。现有方法通常通过单独的适应模块分别处理每个差异，当两种差异共存时将这些模块组合或分层。然而，最初尝试sim2real的基础是仿真任务与现实任务之间存在共享结构，即来自等价配置的等价动作会产生等价的长期结果，无论渲染或物理上的领域具体差异如何。在本文中，我们研究是否可以从原始观测中识别并利用这种共享结构来训练一种能够实现零样本迁移的策略。我们引入了BIFROST，它通过跨域双模拟目标（cross-domain bisimulation objective）学习配对跨域数据上的共享历史编码器：导致等价长期行为的观测-动作序列被映射到邻近的潜在状态，无论领域如何。在仿真中基于这些潜在状态训练的策略可以零样本迁移到现实。我们在仿真到仿真的视觉导航、仿真到现实的接触丰富操作任务以及视觉伺服任务上提供了实验证据，表明BIFROST在视觉和动力学领域差异同时存在的情况下实现了有效迁移，而领域适应和联合训练基线方法则失败。

## Abstract
Sim2real transfer for robot policy learning suffers due to mismatch between simulation and reality. Existing methods typically address each gap in isolation through separate adaptation modules, which are composed or layered when both gaps coexist. Yet the basis for attempting sim2real in the first place is that there is shared structure between a task in simulation and reality, where equivalent actions from equivalent configurations produce equivalent long term outcomes regardless of domain specific differences in rendering or physics. In this paper, we study whether we can identify and exploit this shared structure from raw observations to train a policy that enables zero shot transfer. We introduce BIFROST, which learns a shared history encoder on paired cross-domain data via cross-domain bisimulation objective: observation-action sequences leading to equivalent long-term behavior are mapped to nearby latent states, regardless of domain. Policies trained on these latent states in simulation transfer zero-shot to reality. We provide empirical evidence on sim2sim visual navigation and sim2real contact rich manipulation task and visual servoing task that BIFROST achieves effective transfer where domain adaptation and co-training baselines fail under both visual and dynamics domain gaps.

# 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

## 核心思想
- **跨域双模拟对齐**：将两个部分可观测马尔可夫决策过程（POMDP）——源域（仿真）和目标域（现实）——视为拥有共享的低秩结构。通过学习一个**共享历史编码器**，将来自两个域的观测-动作序列映射到共同潜在空间，使得行为等价（即产生相同长期回报和后续状态分布）的序列在潜在空间中邻近。

## 关键技术细节
- **配对数据收集**（Algorithm 1）：
  - 采集目标域轨迹，从中随机采样长度 *l* 的片段。
  - 从片段的第一个观测中提取可观测配置（如关节角、物体位姿），初始化仿真器到该配置（不可观测变量如摩擦系数保持默认值）。
  - 在仿真中回放相同的动作序列，得到配对片段 `(o_src, o_tgt, a, r_tgt)`，其中奖励来自目标域。
- **共享历史编码器**：使用GRU网络，输入历史 `h_t = (o_0, a_0, ..., o_t)`，输出潜在状态 `z_t = ϕ(h_t)`。
- **三个训练损失**（Equation 6）：
  - **奖励预测损失 `L_reward`**：训练奖励预测器 `̂R(z,a)`，使来自两个域的潜在状态都能预测**目标域**的奖励 `r_tgt`。
  - **潜在动力学预测损失 `L_LDP`**：训练前向模型 `̂P(z' | z,a)`（条件高斯分布），预测下一潜在状态，同时鼓励编码器使潜在状态动态连贯。
  - **对齐损失 `L_align`**：最小化配对源域和目标域潜在状态的**Wasserstein-1距离**。通过Kantorovich-Rubinstein对偶用1-Lipschitz critic近似，并结合梯度惩罚。
- **训练流程**（Algorithm 2）：
  - **第一阶段**：在配对数据集上联合训练编码器、奖励预测器、前向模型和critic，优化总损失 `L = L_reward + λ_LDP L_LDP + λ_align L_align`。
  - **第二阶段**：冻结编码器和奖励预测器，在仿真中使用SAC算法以潜在状态 `z_t` 为状态、`̂R(z_t, a_t)` 为奖励训练策略 `π: Z → A`。
- **部署**：在目标域中直接使用相同冻结编码器对观测历史编码得到 `z_t`，策略选择动作，实现零样本迁移。

# 3. 实验设计：数据集/场景、benchmark、对比方法

## 场景与数据集
1. **Sim2Sim 视觉导航**（两个子任务）：
   - **俯视导航**：源域为2D OpenCV渲染（直接速度指令），目标域为MuJoCo 3D（PD控制质点，有惯性）。观测：64×64 RGB裁剪图 + 目标颜色向量。极端视觉差异，无共享视觉基元。
   - **第一人称导航**：源域为SAPIEN，目标域为MuJoCo，均使用Hello Robot Stretch机器人。观测：64×64 RGB-D图像 + 目标颜色 + 本体速度。同时存在视觉和动力学差异。目标域数据200条轨迹，约4600个配对片段。

2. **Sim2Real 操控**：
   - **Push-T**：将T型块推至目标位姿。观测：俯视128×128 RGB图像 + 关节角。动作：2D末端位置。差异主要来自摩擦力、接触动力学和低成本机械臂的噪声。
   - **视觉伺服**：机械臂从任意配置移动到参考图像指定配置。观测：当前和参考俯视图拼接（无本体），动作：关节位置指令。差异主要来自执行器回差、摩擦和柔顺性。目标域数据200条遥操作轨迹，约6000个配对片段。

## Benchmark 与对比方法
- **Direct Transfer**：直接在源域训练策略，零样本部署到目标域。
- **Target-Only**：仅在目标域离线数据上训练（使用IQL [33]）。
- **BDA**：双向域适应，学习独立的视觉和动力学适配器（通过对抗训练）。
- **Co-Training (BC)**：行为克隆，使用来自两个域的专家级轨迹。
- **Co-Training (Offline RL)**：IQL在合并数据集 `D_src ∪ D_tgt` 上训练。
- **BIFROST**：与 Co-Training (Offline RL) 使用相同数据，仅替换表示学习方法。

所有使用目标数据的方法共享相同数据预算。

# 6. 论文的主要结论与发现

1. **BIFROST 在 sim2sim 和 sim2real 中均实现了最佳零样本迁移性能**：
   - 俯视导航：BIFROST (0.68±0.08) 与 BDA (0.67±0.05) 相当，但第一人称导航中显著优于 BDA (0.50 vs 0.34)，表明在复合差异下双模拟对齐优势明显。
   - Push-T 和视觉伺服：BIFROST 分别以0.50成功率和7.64°误差领先所有基线，且方差最小。
2. **联合训练（Co-Training）由于Q函数在跨域分布间的自举导致不稳定**，在视觉伺服中甚至比直接迁移更差。
3. **双模拟对齐优于单独处理每个差异**：在sim2real中，BIFROST优于BDA达8个百分点。
4. **消融证实各组件均必要**：去掉奖励预测导致源域过拟合（源域返回最高但目标域返回最低）；去掉动力学预测使对齐信号变弱。W1对偶距离优于MSE和W2闭式，因梯度不衰减且约束方差。

# 7. 优点

- **统一处理复合差异**：不分别建模视觉和动力学变化，而是通过行为等价从原始观测中学习不变表示，避免了模块组合的交互问题。
- **理论奠基**：基于广义双模拟度量（GBSM，[11]），保证潜在状态接近则值函数接近，为迁移提供上限。
- **实验设计严谨**：控制数据预算、对比多种基线、统计多种子、消融充分；t-SNE可视化显示BIFROST将域间分离的集群按目标身份重新分组，直观验证对齐。
- **实用性强**：零样本迁移无需在线适应，适合真实机器人部署；配对数据收集仅需可观测配置（如AprilTags），无需完整状态。
- **方法简洁有效**：基于GRU+三个损失+SAC，实现简单，且在两套硬件（SO-101机械臂、Hello Robot Stretch）上验证。

# 8. 不足与局限

- **配对数据构建的假设**：
  - **动力学连续性**：在接触不连续的任务（如抓取、插入）中，毫米级初始差异可能导致成功/失败的二元分化，此时时间步对齐的配对数据会产生有害信号（使编码器被迫将不同结果映射到邻近）。
  - **状态估计依赖**：构建配对数据时需从目标域观测中提取可观测配置（如通过AprilTag），虽弱于完整状态，但仍不是完全端到端。
- **数据覆盖界限**：共享历史编码器仅在离线配对数据上训练，在线探索可能到达未覆盖状态，导致不可靠的潜在表示。
- **实验局限**：
  - 任务种类有限，未在更复杂的操作（如灵巧手、非刚体）或更极端视觉差异（如白天/夜晚、不同相机）上验证。
  - 未与域随机化或教师-学生蒸馏等互补方法结合，缺乏联合性能比较。
  - 计算资源未报告，难以评估复现成本。
- **潜在偏差风险**：方法有效性依赖于配对数据的质量，若源域初始化与真实配置有偏差（如物体位姿估计不准），对齐可能受损。
- **应用限制**：不适用于完全无法建立配对对应（如仿真与真实场景结构根本不同）的场景。

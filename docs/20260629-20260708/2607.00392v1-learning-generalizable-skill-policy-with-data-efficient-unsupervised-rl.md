## 摘要
无监督强化学习旨在在没有外部奖励的情况下预训练可扩展的、以技能为条件的策略，为下游控制任务奠定基础。尽管最近取得了进展，但我们认为当前的离策略无监督强化学习方法受到两个关键且被忽视的瓶颈的限制：（1）非平稳的技能语义和（2）脆弱的泛化能力。为了解决这些挑战，我们提出了GenDa（可泛化的数据高效智能体），这是一个用于鲁棒无监督强化学习的统一框架。首先，我们引入了一种技能重标记机制，以减轻非平稳性并显著提高预训练的数据效率。其次，我们提出了互补信息瓶颈，鼓励学习的技能策略关注以自我为中心的特征，并对下游任务的分布变化具有鲁棒性。通过多种实验，我们证明了GenDa显著增强了无监督强化学习的可扩展性，具有优越的泛化能力和数据效率。我们的代码和视频可在https://ihatebroccoli.github.io/official-GenDa获取。

## Abstract
Unsupervised Reinforcement Learning (URL) aims to pre-train scalable, skill-conditioned policies without extrinsic rewards, serving as a foundation for downstream control tasks. Despite recent progress, we argue that current off-policy URL methods are limited by two critical, overlooked bottlenecks: (1) non-stationary skill semantics and (2) brittle generalization. To address these challenges, we propose GenDa (Generalizable Data-efficient Agent), a unified framework for robust unsupervised reinforcement learning. First, we introduce a skill relabeling mechanism to mitigate non-stationarity and significantly improve data efficiency for pre-training. Second, we propose a Complementary Information Bottleneck (CIB), encouraging the learned skill policy to focus on ego-centric features and become robust to distribution shifts for downstream tasks. Through various experiments, we demonstrate that GenDa significantly enhances the scalability of URL with superior generalizability and data efficiency. Our code and videos are available at https://ihatebroccoli.github.io/official-GenDa.

## 1. 核心问题与研究动机

**背景**：无监督强化学习（URL）旨在无外部奖励信号下预训练可泛化的技能策略，为下游控制任务提供基础。然而，现有离策略（off-policy）URL方法面临两大关键瓶颈：

- **非平稳技能语义**：离策略学习中，回放缓冲区的旧轨迹与当前技能表示ϕ不匹配，导致语义漂移，使得梯度估计方差大，数据效率低。
- **脆弱泛化能力**：技能策略直接依赖包含全局上下文的完整状态观测，导致策略对分布偏移（如初始位置变化）敏感，无法在不同环境下复现一致行为。

**目标**：提出一个统一的框架GenDa，同时解决上述两个问题，实现可扩展、数据高效且泛化的无监督技能学习。

## 2. 方法论

### 2.1 核心思想
- **技能重标定（Skill Relabeling）**：将回放缓冲区中的轨迹重新分配与当前表示一致的技能标签，缓解语义漂移。
- **互补信息瓶颈（CIB）**：学习一个与表示ϕ互补的嵌入ℓ，迫使策略仅依赖局部自我特征，忽略全局上下文，提升泛化性。

### 2.2 关键技术细节

#### 技能重标定
- **z-step（重标定）**：对于轨迹τ，计算新技能标签 `z_relab = unit(ϕ_tgt(s_T) - ϕ_tgt(s_0))`，其中`unit`为单位化操作，`ϕ_tgt`为指数移动平均网络。
- **ϕ-step（优化表示）**：固定重标定后的z，优化目标为最大化轨迹方向与z的点积，并施加Lipschitz约束。
- **防止坍缩**：引入均匀性正则化项 `L_unif`，鼓励重标定后的技能在超球面上均匀分布，保持多样性。
- **策略重标定**：对于每个转移，从同一轨迹内采样不同时间跨度的目标z_c，丰富奖励信号。

#### 互补信息瓶颈（CIB）
- 训练一个编码器 `q_ψ(ℓ|s)`，使其嵌入ℓ与ϕ互补：优化目标 `J_CIB = I(ℓ;s) - I(ℓ;ϕ(s))`，即ℓ保留ϕ未包含的信息。
- 策略输入由原始状态s替换为ℓ：`π(a|ℓ, z)`，从而避免策略过拟合全局上下文。

### 2.3 算法流程简述
1. 初始化策略π，表示ϕ，EMA目标ϕ_tgt，CIB编码器q，回放缓冲区B。
2. 每轮：采样技能z，收集轨迹存入B；多次梯度更新：重标定技能标签，优化ϕ（含L_base + β L_unif），混合重标定数据更新策略（SAC），更新CIB编码器，更新EMA目标。

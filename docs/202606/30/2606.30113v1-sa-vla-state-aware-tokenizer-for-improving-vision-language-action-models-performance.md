## 摘要
离散动作分词为自回归VLA策略提供了紧凑的接口，但从离散编码中精确恢复连续机器人动作仍然具有挑战性。现有的分词器通常将每个离散编码映射到一个固定的连续动作原型，忽略了机器人当前的本体感觉状态。这一局限在操作任务中尤为显著，因为相同的动作标记在不同关节构型、物体姿态和接触条件下可能需要不同的连续控制。因此，我们提出SA-VLA，一种基于机器人状态进行动作解码的状态感知动作分词器。我们研究了两种基于VQ的动作分词的状态注入机制：状态与动作特征之间的交叉注意力，以及一个轻量级状态适配器，该适配器预测动作维度的调制因子，用于状态条件化的动作调制与重建。适配器公式通过允许每个离散标记表示一族依赖于状态的连续动作，扩展了有限码本的有效支持范围，同时保留了离散动作建模的效率和兼容性。集成到基于LLM的VLA策略中，SA-VLA支持自回归和并行动作标记解码，且对模型接口改动极小。在12个RoboTwin操作任务中，SA-VLA相较于最强的分词基线将平均成功率从0.29提升至0.56。在三个真实世界任务的零样本模拟到真实实验中，相较于最强分词基线，其进一步将平均成功率从0.15提升至0.33。这些结果表明，状态条件化的动作解码是缩小离散VLA策略中压缩差距的一种简单而有效的机制。

## Abstract
Discrete action tokenization provides a compact interface for autoregressive VLA policies, but accurately recovering continuous robot actions from discrete codes remains challenging. Existing tokenizers typically map each discrete code to a fixed continuous action prototype, ignoring the robot's current proprioceptive state. This limitation is particularly pronounced in manipulation, where the same action token may require different continuous controls under different joint configurations, object poses, and contact conditions. We therefore propose SA-VLA, a state-aware action tokenizer that conditions action decoding on robot state. We study two state-injection mechanisms for VQ-based action tokenization: cross-attention between state and action features, and a lightweight state adapter that predicts action-wise modulation factors for state-conditioned action modulation and reconstruction. The adapter formulation expands the effective support of a finite codebook by allowing each discrete token to represent a family of state-dependent continuous actions, while preserving the efficiency and compatibility of discrete action modeling. Integrated into an LLM-based VLA policy, SA-VLA supports both autoregressive and parallel action-token decoding with minimal changes to the model interface. On 12 RoboTwin manipulation tasks, SA-VLA improves the average success rate from 0.29 to 0.56 over the strongest tokenizer baseline. In zero-shot sim-to-real experiments on three real-world tasks, it further improves average success from 0.15 to 0.33 over the strongest tokenizer baseline. These results demonstrate that state-conditioned action decoding is a simple and effective mechanism for reducing the compression gap in discrete VLA policies.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：Vision-Language-Action (VLA) 模型是具身智能领域的基础模型，能够将视觉观测和语言指令直接映射为动作序列。VLA 主要分为两类：一类直接生成连续动作，另一类先生成离散动作 token，再通过动作分词器解码为连续动作。后者利用预训练 VLM 提取动作 token，计算效率高，但存在“压缩差距”——离散 token 恢复连续动作时精度受限。
- **核心问题**：现有离散动作分词器（如 binning、FAST、VQ-VAE）通常将每个离散码映射为固定的连续动作原型，完全忽略了机器人当前的**本体感觉状态**（如关节角度、物体位姿、接触条件等）。相同的动作 token 在不同状态下需要不同的连续控制，导致动作恢复不准确，严重限制了 VLA 性能。
- **研究动机**：通过将机器人状态信息引入动作分词器的解码过程，使每个离散 token 能表示一族依赖于状态的连续动作，从而缩小压缩差距。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
提出 **SA-VLA**，一种**状态感知的动作分词器**，在 VQ-VAE 框架基础上，利用当前机器人状态信息（关节角度等）指导动作解码。探索两种状态注入方式：交叉注意力（Method A）和轻量级适配器（Method B），其中 Method B 通过将离散码与状态预测的缩放因子相乘，将固定码本扩展为连续动作空间，效果更优。

### 关键技术细节
1. **问题形式化**：给定观测图像 \(o_t\)、机器人状态 \(s_t\)、语言指令 \(L\)，学习策略 \(\pi_\theta(a_{t:t+k} | o_t, s_t, L)\)，预测未来 k 个动作。
2. **基础 VQ-VAE 分词器**：使用 CNN 和 Transformer 编码器提取时序动作特征，经码本量化得到离散 token，再通过对称解码器重建连续动作。
3. **Method A（交叉注意力）**：在编码器和解码器的 Transformer 层中，将状态信息作为 Key/Value 注入，与动作特征进行交叉注意力，使解码过程感知当前状态。
4. **Method B（轻量级适配器）**：
   - 状态 \(s_t\) 经 MLP + sigmoid 适配器得到一个缩放因子 \(w\)（维度与动作相同），对原始动作进行逐维度缩放：\(a_{\text{trans}} = a \div w\)。
   - 缩放后的动作进入标准 VQ-VAE（不使用状态），重建得到 \(\hat{a}_{\text{trans}}\)，再乘以 \(w\) 恢复最终动作 \(\hat{a} = \hat{a}_{\text{trans}} \times w\)。
   - 优势：同一离散 token 可以对应不同状态下的不同连续动作，突破了固定码本的限制，相当于回归到连续动作空间。
5. **损失函数**：VQ-VAE 的复合损失（重建损失 + VQ 损失 + 承诺损失）。
6. **VLA 集成**：将分词器嵌入基于 LLM（Qwen2.5）的 VLA 中，支持**自回归解码**（next-token prediction）和**并行解码**（一次性生成整个动作块）。输入序列包含语言、状态、图像、动作 token，以特殊分隔符区分模态。

## 摘要
世界模型为长时域LLM智能体提供了一种原则性的方式来赋予其远见：在执行前预测行动后果。然而，不可靠的远见可能被忽略、滥用，甚至损害下游决策。本文提出了WorldEvolver，一种自我进化的世界模型框架，它在保持下游智能体和所有模型参数冻结的同时，修正其部署时的上下文。WorldEvolver集成了三个模块：(i) 情景记忆，通过基于检索的模拟利用真实行动转移；(ii) 语义记忆，从预测-观察不匹配中提取持久的启发式规则；(iii) 选择性远见，在将低置信度预测整合到智能体推理上下文之前进行过滤。我们在ALFWorld和ScienceWorld上评估了WorldEvolver，通过Word2World测量世界模型预测准确性，通过AgentBoard测量下游智能体成功率。大量实验表明，WorldEvolver在三个骨干网络上取得了最高的预测准确性，并在下游智能体成功率上领先其他世界模型基线，证明了测试时记忆修正既能提升预测保真度，也能提升规划性能。

## Abstract
World models offer a principled way to equip long-horizon LLM agents with foresight: predictions of action consequences before execution. However, unreliable foresight can be ignored, misused, or even degrade downstream decision-making. In this paper, we introduce WorldEvolver, a self-evolving world model framework that revises its deployment-time context while keeping the downstream agent and all model parameters frozen. WorldEvolver integrates three modules: (i) Episodic Memory, which exploits real action transitions through retrieval-based simulation; (ii) Semantic Memory, which extracts persistent heuristic rules from prediction-observation mismatches; and (iii) Selective Foresight, which filters low-confidence predictions before integrating them into agent reasoning context. We evaluate WorldEvolver on ALFWorld and ScienceWorld, measuring world model prediction accuracy on Word2World and downstream agent success rate on AgentBoard. Extensive experiments show that WorldEvolver achieves the highest prediction accuracy across three backbones and leads other world model baselines on downstream agent success rate, demonstrating that test-time memory revision enhances both predictive fidelity and planning performance.

## 1. 论文的核心问题与整体含义

- **研究动机**：LLM智能体在长时域任务中常依赖世界模型进行“前瞻预测”（即执行前预测动作后果），以改善规划。然而，现有世界模型在部署后面对环境分布偏移时，预测变得不可靠；不可靠的远见反而会误导智能体，降低任务成功率（如图2所示：噪声远见导致动作准确率下降）。
- **整体含义**：本文指出，提升世界模型可靠性的关键在于**部署时动态修正上下文**而非更新模型参数。作者提出WorldEvolver，一个自我进化框架，通过引入情景记忆、语义记忆和选择性远见三个模块，在保持下游智能体和世界模型参数冻结的前提下，持续改善远见质量，从而提升规划性能。

## 2. 论文提出的方法论

- **核心思想**：将世界模型的前瞻预测视为一个依赖外部上下文的过程。WorldEvolver不更新模型权重，而是在推理时维护两个非参数记忆结构：
  - **情景记忆（Episodic Memory, M_E）**：存储已执行的真实转换`(o_i, a_i, o_{i+1})`。当需要预测给定动作的后果时，通过动作词的Jaccard相似度检索最相似的`k_ME`条历史转换，作为上下文提供给世界模型。
  - **语义记忆（Semantic Memory, M_S）**：从预测-观测不匹配中提取持久性启发式规则。将原始观测分解为因子化三元组（如`(fridge 1, is, open)`），当预测与事实不一致时，由LLM批评家生成“什么不变”的规则（preservation rule），并附带证据分数，只有分数>0的规则被保留。
  - **选择性远见（Selective Foresight）**：计算生成预测的词级别几何平均概率作为置信度`q_t`，仅当`q_t ≥ τ`时才将预测结果传递给下游智能体；否则不提供远见，避免不可靠信息干扰决策。

- **算法流程（Algorithm 1）**：
  1. 从冻结策略采样草案动作`a_t^(0)`；
  2. 根据该动作从情景记忆检索相似转换；
  3. 世界模型基于当前状态、动作和记忆生成预测`ô_{t+1}`和置信度`q_t`；
  4. 若`q_t ≥ τ`，设置远见`F_t = ô_{t+1}`，否则`F_t = ∅`；
  5. 智能体依据`(s_t, F_t)`重新采样最终动作`a_t`；
  6. 若最终动作与草案动作不同，则重新查询世界模型获得匹配的预测；
  7. 执行动作并观测`o_{t+1}`，更新情景记忆；
  8. 比较预测与观测，若因子化后不一致，累积`k_MS`条不匹配后由LLM批评家生成规则更新语义记忆。

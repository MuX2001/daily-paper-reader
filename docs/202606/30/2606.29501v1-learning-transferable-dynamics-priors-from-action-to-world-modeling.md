## 摘要
我们研究将动作条件世界建模作为一种可扩展的方式，用于学习机器人学习的可转移动力学先验。通过预训练一个模型来预测动作如何驱动视觉场景演化，所得到的世界模型捕获了可复用的交互动力学，超越了外观级别的视频生成。具体地，我们在带有真实动作注释的大规模机器人操作数据上预训练了一个多视图交互基础扩散世界模型A2World。我们从两个互补的角度验证了所学到的动力学先验。首先，我们将A2World适配为一个任务或场景专用的真实世界模拟器A2World-sim，其长程推演支持基于模拟器的策略评估和可扩展的假设分析，通过用世界模型推演替代真实机器人推演。其次，从相同的预训练权重出发，我们将A2World适配为一个视频-动作联合预测模型A2World-policy，该模型在视觉和指令条件下预测动作。在仿真基准和真实机器人设置上的实验表明，动作条件世界模型预训练产生了可转移的动力学先验，这对以模拟器为中心和以策略为中心的机器人学习都有益处。

## Abstract
We study action-conditioned world modeling as a scalable way to learn transferable dynamics priors for robot learning. By pretraining a model to predict how actions drive visual scene evolution, the resulting world model captures reusable interaction dynamics beyond appearance-level video generation. Concretely, we pretrain a multi-view interactive base diffusion world model, A2World, on large-scale robot manipulation data with real action annotations. We validate the learned dynamics priors from two complementary perspectives. First, we adapt A2World into a task- or scene-specialized real-world simulator, A2World-sim, whose long-horizon rollouts support simulator-based policy evaluation and scalable what-if analysis by replacing real-robot rollouts with world model rollouts. Second, starting from the same pretrained weights, we adapt A2World into a video-action joint prediction model, A2World-policy, that predicts actions under visual and instruction conditioning. Experiments across simulation benchmarks and real-robot settings demonstrate that action-conditioned world model pretraining yields transferable dynamics priors that benefit both simulator-centric and policy-centric robot learning.

### 2. 论文提出的方法论：核心思想、关键技术细节

#### 核心思想
- 将动作条件世界建模视为**学习可转移动力学先验**的可扩展路线。动作提供了自然的因果监督信号：尽管场景、视角等变化多样，但操作中物体如何与动作交互（如接触、抓取、推、释放）的规则是共通的。
- 预训练一个**动作条件扩散世界模型 A2World**，在大规模多机器人多任务数据上学习从初始帧和未来动作块预测未来多视图视频。
- 预训练权重作为**可复用先验**，适配为两个下游模型：
  - **A2World-sim**：历史感知的自回归模拟器，支持长程 rollout 用于策略评估；
  - **A2World-policy**：视频-动作联合预测模型，在视觉和指令条件下生成动作。

#### 关键技术细节

**A2World（基础世界模型）**
- **动作条件化**：将动作块通过 MLP 编码，添加到扩散时间步嵌入中（`τ̃(σ)=τ(σ)+e`），通过自适应层归一化调节 DiT 块。
- **多视图生成**：将多个相机视图拼接到时间维度，加入可学习视图嵌入 `ϵ_view` 区分不同相机；在 DiT 块中插入跨视图注意力模块实现视图间一致性。
- **预训练损失**：EDM 框架下的去噪分数匹配：
  \[
  L_{A2World}(\sigma) = \mathbb{E}_{z,n}[\|A2World(z+n; \sigma, c=0, a) - z\|_2^2]
  \]
- **数据集一致批处理**：每个 mini-batch 仅采样自单一数据集，避免多数据集相机设置冲突。

**A2World-sim（长程模拟器）**
- **历史注入**：采用**姿态引导的历史采样**算法（Algorithm 1/2），基于动作弧长均匀采样关键帧，保持历史信息紧凑且覆盖运动轨迹。历史 tokens 通过交叉注意力和自注意力键值拼接注入模型。
- **自回归生成**：分块自回归，使用 Self-forcing 训练策略，在训练时周期性用模型自身生成帧代替真实帧，增强长程稳定性。

**A2World-policy（视频-动作联合策略）**
- **联合扩散**：视频潜变量 `z_v` 和动作潜变量 `z_a` 独立加噪，共享基础噪声等级但按模态缩放：`σ_v = m_v σ_base`, `σ_a = m_a σ_base`。
- **MoE-like 块**：视频和动作 tokens 共享同一个自注意力模块（即“注意力专家”），但各自保留独立的 AdaLN 和 MLP 分支。动作 tokens 既能看自己也能看视频 tokens。
- **训练目标**：加权联合去噪损失，包含视频和动作两项，权重分别为 `w(σ)` 和 `λ_a`。
- **指导推理**：模态级分类器无指导，视频和动作可设置不同的指导强度 `s_v` 和 `s_a`，平衡视觉保真度和动作准确性。

## 摘要
开放环境桌面机器人操作需要系统具备语义理解、精确几何位姿估计和高频动作生成能力。虽然端到端视觉-语言-动作(VLA)模型在语义泛化方面表现出色，但它们往往缺乏细粒度任务所需的显式几何约束，且训练成本高昂。为弥合高层语义与低层物理执行之间的差距，我们提出OpenSPM，一种开放环境空间持久记忆框架，由空间位姿记忆和流匹配动作生成模型组成。OpenSPM首先利用语义条件化的3D感知和卡尔曼滤波跟踪连续6D位姿，然后从人类演示中提取关键空间位姿，将其保存为可迁移的、以物体为中心的空间持久记忆条目。推理时，OpenSPM根据自然语言指令检索相关记忆条目，通过SE(3)变换将空间位姿迁移到新场景，并借助轻量级条件流匹配模型生成高频动作块。结合实时本体感受状态反馈和终端残差校正，该系统有效抑制轨迹误差累积。在十个LIBERO-GOAL任务上评估，OpenSPM实现了85.6%的成功率和等效1033.3 Hz的控制频率，同时所需推理AI算力极小。大量消融实验表明，结构化的空间持久记忆和闭环残差校正对可靠、高频的机器人操作至关重要。

## Abstract
Open-environment tabletop robotic manipulation requires systems to possess semantic understanding, precise geometric pose estimation, and high-frequency action generation. While end-to-end vision-language-action (VLA) models excel at semantic generalization, they often lack explicit geometric constraints for fine-grained tasks and require costly training. To bridge the gap between high-level semantics and low-level physical execution, we propose OpenSPM, an open environment spatial persistent memory framework consisting of spatial pose memory and flow-matching action generation model. OpenSPM first leverages semantically conditioned 3D perception and Kalman filtering to track continuous 6D poses. It then extracts key spatial poses from human demonstrations, keeping them as transferable, object-centric spatial persistent memory entries. During inference, OpenSPM retrieves relevant memory entries in terms of natural language instructions, transfers the spatial poses to new scenes using SE(3) transformations, and generates high-frequency action chunks via a lightweight conditional flow-matching model. Combined with real-time proprioceptive state feedback and terminal residual correction, the system effectively suppresses trajectory error accumulation. Evaluated on ten LIBERO-GOAL tasks, OpenSPM achieves an 85.6% success rate and an equivalent control frequency of 1033.3 Hz, while requiring minimal inference AI computing power. Extensive ablations illustrate that structured spatial persistent memory and closed-loop residual correction play a crucial role in reliable, high-frequency robotic manipulation.

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- **解耦策略**：高层模型负责语义解析和经验检索（关键空间位姿记忆），低层模型负责产生几何约束的局部动作（轻量级流匹配生成器）。
- **关键空间位姿**：定义为每个操作相位边界处（如接近、抓取、抬起、放置前对齐、释放）的末端执行器相对于目标物体的相对6D位姿。这种物体中心表示可跨场景通过SE(3)变换迁移。

### 关键技术细节
1. **语义条件化3D感知与卡尔曼状态估计**
   - 多视图图像 + 文本提示 → 语义分割（如SAM/SAM2）→ 3D重建（如SAM 3D）→ 多视角融合得到物体级点云约束。
   - 将位姿估计视为噪声状态空间问题，采用卡尔曼滤波预测与更新，提供连续、尺度一致的6D位姿。
   - 状态向量包含平移、线速度、局部方向误差、角速度；融合分割置信度、掩码面积、多视图一致性、3D重建质量来动态调整观测噪声协方差。
   - 输出轻量平滑：平移指数平滑，方向球面线性插值。

2. **关键空间位姿记忆库构建**
   - 从人类演示轨迹中提取关键位姿（候选点由三类证据联合决定：夹爪状态变化、末端速度/方向变化、多模态模型Qwen3-VL的相位语义判断）。
   - 每个记忆条目包含：检索键（操作类型/目标/放置对象/相位结构）、语言描述、末端相对于锚定物体的相对位姿序列（式12）、相位标签、置信度、质量评分等。
   - 在线检索：综合语义匹配度、几何可行性、历史成功率进行筛选（式13）。

3. **相对位姿迁移**
   - 定理1：若演示场景与测试场景中物体位姿相差一刚性变换G∈SE(3)，通过相对位姿迁移得到的末端位姿在物体局部坐标系下不变。证明由SE(3)群乘法的结合律直接得到。
   - 迁移后进行可达性、位姿跳变、最小距离检查，确保离散节点在物理上可行。

4. **条件流匹配动作生成**
   - 对相邻关键位姿之间的轨迹段，建立条件（当前实际夹爪位姿、目标关键位姿、相对误差、段内进度τ）并生成长度H=5的动作块。

5. **闭环执行与终端残差校正**
   - 段间闭环：每个动作块开始时的条件使用实时本体感受位姿，而非理想起点。
   - 终端残差校正：在关键接触节点（抓取、放置）附近，若当前位置与目标位姿差值超过阈值，则生成校正动作块并迭代执行直至收敛或达到最大次数。

## 6. 主要结论与发现

- **性能提升**：OpenSPM在LIBERO-GOAL上达到85.6%的成功率，等效动作频率1033.3 Hz，超越所有对比方法，且参数量仅为0.24M（远小于VLA模型的7B/4B）。
- **结构化空间持久记忆的关键作用**：相比零样本多模态模型直接推理关键位姿（成功率仅23.8%），使用演示提取的记忆库将成功率提升至85.6%，说明记忆显式编码了物理接触点、接近方向、释放位置等隐含知识。
- **闭环执行与残差校正的必要性**：开环流匹配仅获3.0%成功率；段间闭环提升至29.8%；再加上终端残差校正达到85.6%。同时校正过程增加了平均执行步数（从167增至278.5），但避免了任务失败。
- **卡尔曼预测精度**：平均平移MAE 5.8mm，方向MAE 2.12°，足以支撑后续迁移和动作生成。
- **模型收敛**：流匹配模型训练损失和验证损失在同一量级，无过拟合，因其输入为低维状态变量而非高维图像/语言token。

## 7. 优点

- **问题分解思路清晰**：将视觉-语言-动作任务解耦为感知、记忆、迁移、动作生成四个独立模块，每个模块可独立优化且易于调试。
- **强调几何显式性**：使用物体坐标系下的相对位姿作为中间表示，使知识可跨场景迁移（定理1保证一致性），避免了端到端模型隐含几何约束模糊的问题。
- **高效率与低算力**：流匹配模型仅240K参数，配合简短的推理路径，实现1kHz等效控制频率，适合对实时性要求高的物理操作。
- **闭环设计严谨**：不仅利用状态反馈重构条件，还引入终端残差校正专门针对关键接触阶段，显著提升鲁棒性。
- **消融实验充分**：通过逐步剥离关键模块，直观展示了各组件的贡献，结论可信。

## 8. 不足与局限

- **对感知质量敏感**：系统依赖初始分割和3D重建的准确性，当出现遮挡、视觉相似物体时，上游定位错误会传导到位姿迁移，造成抓取/放置偏差。论文也承认了此类失败案例。
- **操作容差有限**：细长物体或窄支撑区域的物体，即使在终端校正后，厘米级误差仍可能难以恢复。
- **环境几何约束未建模**：无效障碍物、抽屉边界冲突等问题无法通过末端微调解决，需更高级的规划层介入。
- **实验覆盖范围有限**：仅在一个合成基准（LIBERO-GOAL）上测试，缺乏真实机器人实验、复杂多步任务、非常规物体（如铰接体、软体）的验证。对比方法主要是VLA和扩散策略，未与同类关键帧方法（如Transporter Networks、robomimic）比较。
- **未提供完整训练资源细节**：缺少GPU型号、训练时长等信息，影响可复现性评估。
- **未考虑力/触觉信息**：对于接触敏感操作，纯位姿控制可能不足，未来可扩展夹持器宽度、接触事件、表面法线等。

## 摘要
跨具身迁移在视觉-语言-动作（VLA）模型中仍然具有挑战性，因为不同机器人平台的低级状态和动作空间存在根本性差异。我们观察到，操作背后的高级认知过程，包括场景感知、物体识别、任务规划和子任务分解，在不同具身体上很大程度上是共享的。基于这一观察，我们提出了ZR-0，一个2.6亿参数的端到端VLA模型，该模型使用密集的具身思维链（ECoT）监督来对齐视觉-语言模型（VLM）中的跨具身表示。ZR-0采用双流架构：预训练的VLM（系统2）在训练期间生成结构化的ECoT推理，而基于扩散Transformer的动作专家（系统1）通过流匹配生成连续的动作块。这两个组件通过交叉注意力耦合，并带有一个注意力掩码，该掩码限制动作专家仅关注输入提示特征，从而在推理时完全跳过ECoT生成而不损失任何性能。ZR-0在ProcCorpus-60M上进行预训练，这是一个大规模数据集，包含超过40万条轨迹的大约6000万帧（约1000小时），密集的ECoT注释覆盖了96.8%的帧。我们在三个仿真基准上评估ZR-0，涵盖单臂（LIBERO）、双臂（RoboTwin 2.0）和人形（RoboCasa GR-1 Tabletop）具身，以及在xArm平台上的真实世界实验，展示了在所有设置中的强劲性能。代码和模型检查点可在https://github.com/RUCKBReasoning/ZR-0获取。

## Abstract
Cross-embodiment transfer in vision-language-action (VLA) models remains challenging because low-level state and action spaces differ fundamentally across robot platforms. We observe that the high-level cognitive process underlying manipulation, including scene perception, object identification, task planning, and sub-task decomposition, is largely shared across embodiments. Based on this observation, we present ZR-0, a 2.6 billion parameter end-to-end VLA model that uses dense Embodied Chain-of-Thought (ECoT) supervision to align cross-embodiment representations within the vision-language model (VLM). ZR-0 adopts a dual-stream architecture: a pre-trained VLM (System 2) generates structured ECoT reasoning during training, while a Diffusion Transformer-based action expert (System 1) produces continuous action chunks via flow matching. The two components are coupled through cross-attention, with an attention mask that restricts the action expert to input prompt features only, enabling ECoT generation to be entirely skipped at inference without any performance loss. ZR-0 is pre-trained on ProcCorpus-60M, a large-scale dataset comprising approximately 60 million frames (approximately 1,000 hours) from over 400K trajectories, with dense ECoT annotations covering 96.8% of all frames. We evaluate ZR-0 on three simulation benchmarks spanning single-arm (LIBERO), bimanual (RoboTwin 2.0), and humanoid (RoboCasa GR-1 Tabletop) embodiments, as well as real-world experiments on the xArm platform, demonstrating strong performance across all settings. Code and model checkpoints are available at https://github.com/RUCKBReasoning/ZR-0.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：视觉-语言-动作（VLA）模型面临跨机器人平台（单臂、双臂、人形等）迁移的挑战，根本原因在于不同机器人的底层状态和动作空间存在本质差异（如自由度、控制接口、传感器配置等）。现有方法仅通过零填充或归一化等格式化手段统一动作空间，无法解决表示层面的语义对齐问题。
- **核心洞察**：操作背后的高级认知过程（场景感知、物体识别、任务规划、子任务分解）在不同具身体上是共享的，这种无关具身的推理是跨实体迁移中真正可迁移的知识。
- **目标**：利用密集的具身思维链（Embodied Chain-of-Thought, ECoT）监督信号，迫使VLM学习对齐的、可迁移的跨实体表示，从而构建通用的VLA策略模型。

## 2. 论文提出的方法论
### 2.1 核心思想
- 提出 **ZR-0**，一个 2.6B 参数的端到端 VLA 模型，采用 **System 1 / System 2 双流架构**：
  - **System 2**：预训练 VLM（Qwen3-VL-2B-Instruct），负责处理视觉观测和任务指令，在训练时生成结构化的 ECoT 推理序列（包括场景描述、任务进度评估、未来规划、原子子任务、目标物体边界框、离散动作 token），以提供密集的语义监督。
  - **System 1**：基于 Diffusion Transformer（DiT）的动作专家，接收 VLM 特征和机器人状态，通过流匹配（flow matching）直接预测连续动作块（chunk）。
- **关键设计**：使用交叉注意力耦合两个系统，并施加一个注意力掩码，限制动作专家仅关注 VLM 输入提示（指令+图像）的特征，**彻底忽略 ECoT 生成的 token 特征**。这使得推理时完全不需要生成 ECoT 文本，只做一次 VLM 前向传播即可获得动作专家所需的全部特征，在不损失性能的前提下大幅降低推理延迟（~90ms/A6000）。

### 2.2 关键技术细节
- **训练数据**：在 ProcCorpus-60M 上预训练，该数据集聚合了 Open X-Embodiment、DROID、RH20T 等公开真实/仿真数据集，共约 6000 万帧、40 万条轨迹（约1000小时），其中 96.8% 的帧被自动标注了 ECoT。同时混入通用视觉语言数据（CapsFusion、Pixmo）以保持 VLM 的通用感知能力。
- **训练目标**：联合优化两个损失：
  - 下一个 token 预测损失（用于 ECoT 生成，仅更新 VLM 参数）；
  - 流匹配损失（用于动作预测，通过 VLM 特征反向传播更新整个模型）。
- **推理策略**：使用 forward Euler 积分进行 N 步去噪，从纯噪声逐步生成动作块，每步输入原始 VLM 特征，ECoT 完全不参与生成。

## 6. 论文的主要结论与发现
- 密集的 ECoT 监督能够有效对齐不同实体间的 VLM 表示，显著提升跨实体迁移能力。
- 在单臂、双臂、人形三类仿真基准上，ZR-0 均达到了竞争力或领先性能：
  - LIBERO: 97.8%（平均），尤其长时任务（LIBERO-10）提升明显（96.4% vs π0.5 的 92.4%）。
  - RoboCasa GR-1: 69.3%（平均），在取放类任务上远超其他方法，但在关门等不常见操作上表现较弱。
  - RoboTwin 2.0: Clean 88.70%、Randomized 87.98%，在领域随机化环境下鲁棒性更好（相比 π0.5 的 82.74%/76.76%）。
- 真实实验显示 ECoT 在长时规划、空间推理、指令理解上带来增益，但在精细操作（如挂杯子）上不如 π0.5，暗示高精度控制可能需要更大规模的动作监督数据。
- 消融实验证实，移除 ECoT 监督会导致性能明显下降（LIBERO 平均 -2.1%），证明动作监督本身不足以充分适应 VLM 表示。

## 7. 优点
- **新颖的 ECoT 监督机制**：利用高级认知信号的密集标注，在不增加推理开销的前提下提升表示质量，设计精巧。
- **双流架构的灵活性**：VLM 与动作专家通过交叉注意力耦合，注意力掩码使推理时完全无需生成文本，实现低成本高性能。
- **跨实体泛化能力**：在完全不同的机器人形态（单臂、双臂、人形）上以同一预训练 checkpoint 微调即可达到出色效果，说明预训练学到的表示具有强可迁移性。
- **开源贡献**：代码、模型权重和数据集均已公开，可复现性强，有利于社区后续研究。
- **充分的实验验证**：涵盖多任务、多实体仿真和真实场景，消融实验有力支撑核心贡献。

## 8. 不足与局限
- **预训练数据规模有限**：虽然 ProcCorpus-60M 有 1000 小时，但对比顶级模型（如 π0 超过 10000 小时）仍显不足。这导致某些不常见的操作技能（如关门、挂杯子）性能不如专门模型。
- **ECoT 标注成本高**：需要对每一帧进行 VLM 自动标注，算力开销大。论文虽提出未来可研究选择性标注，但当前方案对资源要求高。
- **对比公平性受限于数据差异**：由于不同模型使用的预训练数据集、骨干网络不一致，无法进行真正公平的横向对比。尽管论文在“Scaling Robot Data”中承认了这一点，但读者仍需谨慎解读性能排名。
- **真实实验范围狭窄**：仅在一个真实平台（xArm）上进行了 4 个任务、每任务 10 回合的验证，统计显著性存疑，且未展示在更多真实机器人上的泛化效果。
- **缺少安全与失败分析**：未讨论模型部署时的安全风险（如误操作、物体掉落），也未提供失败模式的分析（哪些任务/场景容易失败、错误类型）。
- **未探索极低数据 regime**：虽然预训练数据较大，但未在 few-shot 或 zero-shot 跨实体迁移场景下评估模型，这恰好是 cross-embodiment 的核心挑战。

## 摘要
缩放灵巧操作需要跨物体、场景和任务的泛化能力，但现有数据源在规模与场景/具身对齐之间存在权衡：遥操作数据与机器人部署高度对齐但采集成本高；仿真具有可扩展性但受限于仿真到现实的差距；真实自我中心视频可有效扩展但与机器人部署仍不对齐。我们提出Wh0框架，利用生成式视频世界模型作为可扩展且可控的基于自我中心视角的人类手部操作数据源，以解锁预训练灵巧VLA模型的操作能力。以语言、物体和场景为条件，Wh0使用生成式世界模型生成WM-H，一个包含50k个交互片段的自我中心视角人-物交互视频数据集。然后，Wh0通过手部运动重建和视觉编辑将生成的视频转换为机器人可训练的监督信号。与有限数量的真实机器人数据共同训练后，WM-H使预训练的VLA模型适应灵巧操作部署。在18个真实世界灵巧操作任务中，与仅在机器人数据上后训练的模型相比，Wh0将未见任务的零样本成功率从8.3%提升至38.9%。消融研究进一步表明，可扩展生成和场景/具身对齐是性能提升的关键驱动因素。视频和开源代码可在我们的项目网站上找到：https://chenyt31.github.io/wh0.github.io/。

## Abstract
Scaling dexterous manipulation requires generalization across objects, scenes, and tasks, yet existing data sources face a trade-off between scale and scene/embodiment alignment: teleoperation data is well aligned with robot deployment but expensive to collect; simulation is scalable but limited by the sim-to-real gap; and real egocentric videos scale effectively but remain misaligned with robot deployment. We propose Wh0, a framework that uses generative video world models as scalable and controllable sources of egocentric human-hand manipulation data to unlock the manipulation capabilities of pretrained dexterous VLA models. Conditioned on language, objects, and scenes, Wh0 uses a generative world model to produce WM-H, a 50k-episode dataset of egocentric human-object interaction videos. Wh0 then converts the generated videos into robot-trainable supervision through hand motion reconstruction and visual editing. Co-trained with a limited amount of real robot data, WM-H adapts pretrained VLA models to dexterous manipulation deployment. Across 18 real-world dexterous manipulation tasks, compared with a model post-trained only on robot data, Wh0 improves zero-shot success on unseen tasks from 8.3% to 38.9%. Ablation studies further show that scalable generation and scene/embodiment alignment are key drivers of performance gains. Videos and open-source code can be found on our project website: https://chenyt31.github.io/wh0.github.io/.

## 2. 方法论：核心思想、关键技术细节、算法流程
### 核心思想
- 将生成式视频世界模型作为**可控的人类手部数据生成器**，生成自我中心视角、条件于语言指令、物体和场景的操作视频（WM-H数据集），然后通过手部运动重建和视觉编辑将其转换为机器人可训练的监督信号，并与少量真实遥操作数据联合微调预训练VLA模型。

### 关键技术细节
1. **WM-H数据集构建（三阶段流水线）**：
   - **(a) 指令生成**：双智能体系统（LLM发现+平衡采样器），持续发现可抓取物体名词和属性形容词，优先采样低频词，构建结构化指令（如“pick the red mug”），确保不同（物体,属性）组合的平衡覆盖。最终指令名词h-index=201，形容词h-index=117。
   - **(b) 场景与本体对齐的视频合成**：
     - **场景对齐**：在目标机器人工作台用部署相机拍摄背景图像（包含人手作为尺度锚点），然后使用Qwen-Image-Edit在指定区域插入目标物体，生成起始帧。
     - **图像到视频生成**：使用Wan-I2V-A14B（图像到视频模型），结合语言指令和Qwen3-VL生成的动态描述，生成自我中心人手操作视频。使用LightX2V LoRA加速（仅4步推理）。
     - **本体对齐（机器人手编辑）**：在选定帧上使用Qwen-Image-Edit将人手替换为逼真的机器人手（白背壳、黑手掌、黑指尖、银色前臂），保持原始姿态、位置、物体运动，使策略关注动作语义而非执行者外观。
   - **(c) 手部运动提取**：使用HaWoR从合成视频中重建3D手部运动（MANO参数+腕部姿态），作为显式动作监督。必要时使用MegaSAM进行相机跟踪。
   - **生成成本**：约5.44 GPU小时/1k个81帧视频，总共生成50k个片段。

2. **策略学习（Wh0框架）**：
   - **策略架构**：基于VITRA风格，使用PaliGemma视觉语言骨干编码当前观测和语言指令（包含FoV辅助令牌），提取认知特征，条件化一个基于扩散的动作解码器（DiT-B），预测未来16步的动作（102维，包含手腕平移/旋转和15-DoF MANO关节旋转）。
   - **动作空间**：统一使用MANO参数空间，机器人关节重定向到MANO空间，使用人类视频预计算的归一化参数，保持与人类动作空间对齐。
   - **训练策略**：
     - 初始化于VITRA（在Ego4D、Epic-Kitchens、EgoExo4D、Something-Something-V2上预训练）。
     - 联合微调数据集：50k WM-H样本 + 400个真实遥操作演示。每个批次采样比例：28%遥操作，68% WM-H，4% WM-H EA（经过本体对齐编辑的WM-H帧）。
     - 冻结视觉编码器，更新其余骨干和扩散解码器，学习率1e-5，VLM权重衰减0.1，训练最多40k步。
     - 扩散解码器使用100步扩散、平方余弦噪声调度，推理时使用10步DDIM采样、CFG尺度5.0。

## 6. 主要结论与发现
1. **零样本成功率显著提升**：Wh0在18个未见任务上达到38.9%成功率，相比仅用遥操作的VITRA（8.3%）提升4.7倍，超过使用真实自我中心视频的VITRA Real Version（21.4%）。
2. **场景对齐、本体对齐和数据规模是关键驱动**：
   - 移除场景对齐：成功率降至20.0%，手-物距离增大。
   - 移除本体对齐：成功率降至34.7%，且在手-物距离上对机器人手外观的泛化较差。
   - 增加WM-H数据量（5k→25k→50k）持续提升成功率和手-物距离。
3. **WM-H激活了预训练的人类操作先验**：人类预训练+遥操作+WM-H三结合最佳；缺少人类预训练则几乎无成功（<1%），缺少遥操作也零任务成功，说明WM-H不是从头学习灵巧技能，而是帮助对齐和利用已有先验。
4. **生成数据的质量**：用户研究显示37.7%的合成视频被AI从业者误认为是真实录制；合成视频在指令对齐、手-物交互维度评分较高（4.18/5, 3.95/5），但训练适用性评分中等（3.57/5），说明仍有改进空间。

## 7. 优点
- **新颖性**：首次将生成式视频世界模型作为可扩展的、可控的灵巧操作后训练数据源，而非作为仿真器或动作规划器，提出了一种实用的数据生成范式。
- **端到端可计算**：整个数据生成流水线几乎不依赖人类劳动，仅需少量背景图像和初始物体编辑，主要成本在GPU计算，具有很高的可扩展性。
- **场景/本体对齐**：通过背景图像中的尺度锚点、视角对齐和机器人手编辑，生成的数据与真实部署环境高度匹配，显著优于直接使用网络上的真实自我中心视频（如HOI4D）。
- **强实验验证**：在真实机器人上进行了18个任务的零样本评估，包含多种未见物体和场景，消融实验系统且结论清晰。
- **开源与可复现**：项目网站提供视频和开源代码，有助于社区复现和进一步研究。

## 8. 不足与局限
- **视频生成质量限制**：生成的视频可能包含物理不可置信的交互、意外物体或长周期不一致性，导致部分训练数据具有噪声（失败案例见图7）。
- **手部运动重建精度**：手-物遮挡会降低重建的手指姿态精度，引入噪声监督，进而影响策略学习。
- **人与机器人形态不匹配**：机器手尺寸较大（相对于人类手），在执行时可能无意中干扰物体，即使动作一致。
- **依赖强预训练**：WM-H对没有人类视频预训练的模型几乎没有帮助，说明它补充而非替代大规模预训练。
- **任务范围有限**：
  - 仅验证了单臂拾放操作（pick-and-place），未涉及双臂、工具使用、长周期任务。
  - 仅使用一种机器人平台（Unitree G1 + Inspire Hand），未在多种机器人上验证泛化性。
- **评估偏差风险**：
  - 遥操作数据仅包含已见任务和背景，可能低估了基线方法的泛化潜力（但Wh0的零样本评估是公平的）。
  - 18个任务数量有限，且部分任务可能具有相似的结构，未能充分覆盖灵巧操作的多样性。
- **本体对齐编辑可能引入伪影**：机器人手编辑可能在部分帧中未保持原始姿态或意外修改场景物体（如附录图7所示）。

## 摘要
在安全关键场景中，机器人导航面临来自未预料语义事件的重大挑战，其中碰撞主要源于动态智能体不可预测的行为，而非未观测到的障碍物。尽管大型视觉语言模型在常识推理方面表现出卓越能力，但在连续控制循环中频繁调用它们会引入严重的计算延迟，从根本上破坏物理执行的稳定性。为应对这些挑战，我们提出事件自适应运动规划（EAMP），一种基于视觉语言模型的机器人导航高效框架。具体而言，可配置提示的语义事件触发器（PC-SET）通过持续监控短时间窗口内的行为异常，选择性地激活语义干预。触发后，通过物理验证的语义蒸馏微调的事件触发蒸馏SemNav-VLM将检测到的异常映射为离散策略级决策。随后，语义模型预测控制（SMPC）模块将这些策略转化为优化目标和几何参考的动态重构。在安全关键物流场景中的大量实验表明，EAMP有效对齐高层推理与底层控制，相比现有基线方法显著提升动态安全裕度，同时保持实时效率。

## Abstract
Robot navigation in safety-critical scenarios faces significant challenges from unforeseen semantic events, where collisions arise primarily from the unpredictable behaviors of dynamic agents rather than unseen objects. While large vision-language models (VLMs) offer remarkable capabilities in commonsense reasoning, frequently invoking them within the continuous control loop introduces severe computational latency, fundamentally destabilizing physical execution. To address these challenges, we propose event-adaptive motion planning (EAMP), an efficient framework for VLM-based robot navigation. Specifically, a prompt-configurable semantic event trigger (PC-SET) selectively activates semantic intervention by continuously monitoring short temporal clips for behavioral anomalies. Upon triggering, an event-triggered distilled SemNav-VLM, fine-tuned via physically verified semantic distillation, maps detected anomalies into discrete strategy-level decisions. Subsequently, a semantic model predictive control (SMPC) module translates these strategies into dynamic reconfigurations of optimization objectives and geometric references. Extensive experiments in safety-critical logistics scenarios demonstrate that EAMP effectively aligns high-level reasoning with low-level control, significantly improving dynamic safety margins over existing baselines while preserving real-time efficiency.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
EAMP采用**三级解耦架构**：语义事件检测（PC-SET）→ 策略推理（蒸馏SemNav-VLM）→ 约束感知控制（SMPC）。通过事件触发机制实现“何时推理”与“如何适应”的分离，避免连续推理造成的延迟。

### 关键技术细节

1. **Prompt-Configurable Semantic Event Trigger (PC-SET)**
   - 使用轻量级VLM（Qwen3-VL-2B-Instruct）以不超过3 Hz的频率异步监控最近三帧图像的短时间窗口。
   - 通过提示（prompt）让VLM输出二元异常指示（1/0）和简要事件描述。
   - 引入滑动窗口（长度\(K\)）的时序一致性：当窗口内异常次数≥阈值\(m\)时，触发最终信号\(\tau_t^*\)，并由零阶保持重采样至MPC高频步长。

2. **SemNav-VLM：蒸馏带物理验证的语义策略模型**
   - **教师模型**：云端大型VLM（Gemini-3.0-Flash）在给定的提示下生成候选策略。
   - **物理验证**：将候选策略在CARLA仿真器中通过SMPC控制器进行闭环滚动验证，仅保留**物理可行（无碰撞）**的(图像、状态、策略)三元组构成数据集\(\mathcal{D}_{pv}\)。
   - **学生模型**：以Qwen3-VL-8B-Instruct为骨干，通过LoRA微调，最小化负对数似然\(\mathbb{E}_{(\mathcal{I},\mathbf{x},s)\sim\mathcal{D}_{pv}}[-\log\pi_{\text{sem}}(s|\mathcal{I},\mathbf{x},P_{\text{strategy}})]\)。

3. **Semantic Model Predictive Control (SMPC)**
   - 策略集\(\mathcal{S}\)包含{跟随、让行、超车、轻推、停车}等离散驾驶策略。
   - 触发时，SemNav-VLM输出策略\(s_t\)，通过映射\(\Gamma(s_t)\)和\(\Psi(s_t)\)重构MPC参数\(\boldsymbol{\theta}_t\)和参考路径\(\tilde{\mathcal{P}}_t\)。
   - 参数向量\(\boldsymbol{\theta}=[w_s, w_u, \lambda_\epsilon, d_{\min}, \alpha_u]^\top\)控制路径跟踪权重、控制调节权重、避障松弛惩罚、安全距离、控制缩放因子。
   - 引入最小保持时长防止抖振，形成事件驱动更新律。

4. **整体算法流程（Algorithm 1, 2）**
   - **离线阶段**：物理验证蒸馏，生成SemNav-VLM。
   - **在线阶段**：每个控制步，PC-SET输出触发信号。若触发，SemNav-VLM推理策略，SMPC重构MPC问题并求解；否则保持标称参数。

1. **SemNav-VLM**：通过物理验证蒸馏，将策略准确率从基线的42%（Qwen3-VL-8B-Instruct）和86%（教师Gemini-3.0-Flash）提升至96%，尤其在安全关键策略（让行、轻推、停车）上提升显著。

## 7. 优点：方法或实验设计上的亮点

- **事件驱动的语义触发**：PC-SET设计精巧，使用轻量VLM以3 Hz低频率监控行为异常（而非对象层级），引入时序一致性过滤噪声，有效解决传统置信度触发对已知实体行为突变失效的问题。

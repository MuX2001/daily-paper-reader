## 摘要
奖励设计仍然是机器人运动强化学习中的主要瓶颈，成功的策略往往依赖于精心调整的、特定任务的奖励函数。基于偏好的强化学习提供了一种替代方案，但现有的基于LLM的方法通常要求对行为之间进行单一的整体判断，这使得难以捕捉到高质量运动背后的多个竞争目标。我们提出了多目标人工智能引导的偏好学习（MAPL），这是一个从高层自然语言目标而非手动设计的奖励方程中学习运动奖励的框架。MAPL引导大语言模型沿着语义上有意义的标准独立比较轨迹，使用与地形无关且几乎不需要领域专业知识的通用语言描述。这些目标层面的偏好被用于训练多头偏好评分模型，其输出被聚合形成用于策略优化的标量奖励。在四个四足运动环境中，MAPL仅使用LLM生成的偏好训练策略，并实现了与专家设计的奖励相当或更优的性能，同时消除了特定任务的奖励工程。

## Abstract
Reward design remains a major bottleneck in reinforcement learning for robot locomotion, where successful policies often depend on carefully tuned, task-specific reward functions. Preference-based reinforcement learning offers an alternative, but existing LLM-based methods typically ask for a single overall judgment between behaviors, making it difficult to capture the multiple competing objectives that underlie high-quality locomotion. We present Multi-Objective AI-Informed Preference Learning (MAPL), a framework that learns locomotion rewards from high-level natural language objectives rather than manually engineered reward equations. MAPL prompts a large language model to compare trajectories independently along semantically meaningful criteria, using generic language descriptions that are terrain-invariant and require little domain expertise. These objective-wise preferences are used to train a multi-head preference scoring model, whose outputs are aggregated to form a scalar reward for policy optimization. Across four quadruped locomotion environments, MAPL trains policies using only LLM-generated preferences and achieves performance comparable to or better than expert-designed rewards, while eliminating task-specific reward engineering.

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将运动质量分解为三个通用且地形无关的目标——**速度跟踪（Velocity Tracking）**、**稳定性（Stability）**、**平滑性（Smoothness）**，分别用LLM生成偏好，训练独立的多头评分模型，最后线性加权并采用**势差（Potential Difference）**作为奖励信号驱动策略优化。
- **关键技术细节**：
  1. **多目标偏好生成**：对每个轨迹对，使用三个独立的LLM提示（每个目标一个），分别生成该目标的偏好（0/1/0.5）。每个提示仅基于该目标的自然语言描述（如“速度跟踪：实际线与命令线速度偏差小”），无需数值公式。为降低LLM随机性，多次查询取多数答案。
  2. **多头偏好评分模型**：基于Transformer（共享参数 + 每个目标一个输出头），输入下采样后的轨迹（M个均布状态），输出每个状态的多维评分σ_ψ^(i)(s)。训练采用Bradley-Terry模型，最小化pairwise ranking loss。评分模型更新频率远低于策略（如每100策略步更新一次），减少LLM调用。
  3. **奖励构建与策略训练**：总体评分 σ_ψ(s_t) = Σ λ_i σ_ψ^(i)(s_t)，其中λ为人工设定的权重（速度、稳定性权重大，平滑性权重随地形调整）。最终奖励 r(s_t) = σ_ψ(s_t) - σ_ψ(s_{t-1})（势差形式），以提高样本效率和策略回报。策略使用PPO（RSL-RL实现）更新。

  - 每T_P步：从当前策略采样轨迹对，用LLM生成多目标偏好，更新评分模型参数。
  - 每步：策略rollout得到s_t, a_{t-1}, s_{t-1}，计算势差奖励，更新策略参数。

## 6. 论文的主要结论与发现

- MAPL在四个地形上，仅利用LLM生成的偏好训练奖励模型，无需任何环境奖励或人工调参，即可使得策略性能达到甚至**超越**专家设计奖励的水平，且收敛更快。
- 相比于单目标偏好方法（LAPP、LLM Reward），MAPL的多目标分解显著提高了奖励信号的质量，避免了LLM在整体排序中的隐式权衡噪声。
- 使用**多次查询+多数投票**可缓解LLM不一致，但MAPL对单次查询也较鲁棒；轨迹缓冲区500对即可取得满意结果，样本效率较高。
- **势差奖励**是MAPL成功的关键组件：移除后性能大幅下降，而将其应用于LLM Reward或LAPP反而导致早期停滞，表明MAPL的奖励结构更适合势差塑造。
- 消融实验证实三个目标均必要：速度驱动前进，稳定性保证身体动力学，平滑性抑制震荡，缺失任一都会导致性能退化。
- 排名准确度分析表明，多目标多提示（MOMQ，即MAPL的策略）在所有目标上均获得最高准确率，验证了分解有效性。

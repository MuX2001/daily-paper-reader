## 摘要
LLM智能体在数字环境中遵循实用的执行循环：它们基于结构化状态进行推理、调用工具、检查反馈并修正动作。将此循环扩展到物理机器人是困难的，因为物理执行是连续的、依赖于具身形态的、不确定的，并且受到安全约束。现有的具身AI系统在操作、空间理解、导航和人形控制方面取得了进展，但这些能力通常仍是专门的模块或松耦合的决策循环。在这项工作中，我们介绍了HoloAgent-0，一种用于真实世界机器人部署的统一具身智能体框架。Embodied AgentOS将语言指令转换为可执行的技能图，调度机器人资源，监控执行，并根据运行时反馈触发澄清或重新规划。HoloAgent-0通过三个耦合层组织异构的机器人模型和控制器：用于闭环执行的Embodied AgentOS、用于物理世界锚定的3D空间记忆以及用于机器人动作的具身技能。我们在真实硬件上部署了HoloAgent-0，并评估了其空间记忆、长时域导航以及在运动生成、物体搜索、跨机器人协调和移动操作中的闭环执行能力。

## Abstract
LLM agents follow a practical execution loop in digital environments: they reason over structured states, invoke tools, inspect feedback, and revise actions. Extending this loop to physical robots is difficult because physical execution is continuous, embodiment-dependent, uncertain, and constrained by safety. Existing embodied-AI systems have advanced manipulation, spatial understanding, navigation, and humanoid control, but these capabilities often remain specialized modules or loosely coupled decision loops. In this work, we introduce HoloAgent-0, a unified embodied agent framework for real-world robot deployment. Embodied AgentOS converts language instructions into executable skill graphs, schedules robot resources, monitors execution, and triggers clarification or re-planning from runtime feedback. HoloAgent-0 organizes heterogeneous robot models and controllers through three coupled layers: Embodied AgentOS for closed-loop execution, 3D spatial memory for physical world grounding, and embodied skills for robot action. We deploy HoloAgent-0 on real hardware and evaluate its spatial memory, long-horizon navigation, and closed-loop execution across motion generation, object search, cross-robot coordination, and mobile manipulation.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：LLM智能体在数字环境中的执行循环（推理→调用工具→检查反馈→修正动作）难以直接迁移到物理机器人上。物理执行具有**连续性**、**依赖具身形态**、**不确定性**和**安全约束**，导致物理技能不像软件API那样具有确定的输入/输出、完整的反馈和可逆副作用。
- **背景**：现有具身AI系统在操纵、空间理解、导航、人形控制等单项能力上取得了显著进展（如VLA、VLN、运动跟踪等），但这些能力通常是**专门化的模块**或**松散耦合的决策循环**，缺乏统一的物理执行接口来组合异构技能、持久化3D记忆、跟踪部分进度并触发故障恢复。
- **核心目标**：构建一个**统一的具身智能体框架**，将数字代理的闭环执行逻辑扩展到真实机器人上，实现可组合、可观察、可验证的物理任务执行。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
HoloAgent-0通过**三层耦合架构**将语言推理、持久空间记忆和物理技能执行整合为一个闭环系统：
- **Embodied AgentOS（运行时层）**：将自然语言指令转换为可执行的**技能图（skill graph）**，调度机器人资源，监控执行状态，并根据运行时反馈触发澄清或重新规划。
- **Memory Layer（记忆层）**：提供持久化的**空间记忆**（几何、拓扑、语义3D地图、层次化多模态场景图HMSG）和**时间记忆**（目标状态、执行轨迹、经验摘要），为规划提供上下文。
- **Skill Layer（技能层）**：将机器人能力暴露为**类型化的、可监控的技能调用**，包括交互、感知、导航（HoloNavi）、操纵（HoloBrain）、全身运动（HoloMotion）等，通过ROS2命令/状态总线与AgentOS连接。

### 关键技术细节
- **类型化技能接口**：每个技能声明命令名称、类型化参数、前置条件、目标引用和预期效果；执行时返回**状态事件流**（进度、成功/失败、置信度、可恢复性），使AgentOS能基于证据决策（继续、重试、重新规划、请求澄清等）。
- **HoloNavi（导航技能）**：
  - **层次化目标导航**：LLM解析指令得到楼层/房间/物体级目标，通过与HMSG的CLIP特征匹配快速检索候选位置。
  - **在线验证循环**：对候选视角进行VLM慢速验证，若失败则旋转机器人收集新视角并重复检测，避免错误匹配。
  - **主动空间探索**：当记忆无法定位目标时，AgentOS触发前沿探索，更新几何和语义地图后重试。
- **HoloBrain（操纵技能）**：VLA后端，实现pick/place/fold等调用，返回目标未找到、抓取失败等状态，支持与导航组合。
- **HoloMotion（全身运动技能）**：支持运动跟踪模式和速度跟踪模式，输出进度、平衡状态等，可组合其他技能。
- **空间记忆构建**：
  - 几何记忆：支持LiDAR或纯视觉后端（GeoFlow-SLAM++多相机扩展），提供密集点云/网格和机器人定位。
  - 语义记忆：基于SAM2掩码和SigLIP特征融合（公式1：加权平均三个描述子）将2D开放词汇特征提升至3D实例，并通过实例关联维持持久物体身份。
  - HMSG：组织为楼层→房间→视角→物体四层，支持粗到细的空间检索，并包含视角间拓扑关系。
- **记忆更新**：传感器冲突、技能结果（如抓取后物体消失）、用户反馈等触发更新，仅刷新受影响子图，保持效率。
- **时间记忆**：记录当前目标、规划状态、执行轨迹、失败尝试及经验摘要，支持任务中断后恢复。

## 6. 主要结论与发现

- **导航性能显著提升**：仿真中HoloAgent-Nav（带AgentOS循环）取得SR 82.6%、SPL 42.8%，优于所有对比方法（MSGNav: 74.1%/33.4%，FSR-VLN慢推理: 80.8%/41.0%）。真实机器人Top-1@1.0m成功率97.70%，Top-5@1.0m达98.90%，远超其他方法（如FSR-VLN 91.95%/94.25%）。

- **异构技能可组合**：通过统一命令/状态接口，实现了导航、操纵、全身运动的组合，以及跨机器人协调。

## 7. 优点

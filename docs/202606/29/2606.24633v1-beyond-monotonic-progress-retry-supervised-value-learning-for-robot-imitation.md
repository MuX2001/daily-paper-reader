## 摘要
用于机器人模仿学习的人类演示通常包含错误和纠正行为，例如不精确的抓取、物体未对齐、不稳定的接触以及重复尝试。虽然这些片段通常被视为噪声或次优数据，但它们提供了有价值的证据，表明执行何时偏离理想路径以及如何恢复任务可行性。然而，现有的奖励和价值模型通常依赖单调进展假设，这些假设捕捉粗略的任务进展，但可能忽略不完美演示中的局部执行错误和纠正行为。在这项工作中，我们提出ReTVL（重试监督的价值学习），一个通过利用重试事件作为稀疏监督从混合质量机器人演示中学习对错误敏感的价值函数的框架。ReTVL通过结合全局进展校准和由稀疏标注的重试关键点诱导的局部成对偏好学习，捕捉错误周围的局部退化-恢复结构。然后，学习的价值模型用于重新加权演示块以进行下游行为克隆，减少有害执行错误的影响，同时保留有用的纠正行为。在真实机器人操作任务上的实验表明，ReTVL生成比基于进展的基准更细粒度的价值估计，并改善从不完美演示中的模仿学习。

## Abstract
Human demonstrations for robot imitation learning often contain mistakes and corrective behaviors, such as imprecise grasps, object misalignment, unstable contact, and repeated attempts. While these segments are commonly treated as noisy or suboptimal data, they provide valuable evidence about when execution deviates from a desirable path and how task feasibility can be restored. However, existing reward and value models often rely on monotonic progress assumptions, which capture coarse task advancement but may overlook local execution errors and corrective behaviors in imperfect demonstrations. In this work, we propose ReTVL (ReTry-Supervised Value Learning), a framework for learning mistake-sensitive value functions from mixed-quality robot demonstrations by leveraging retry events as sparse supervision. ReTVL captures the local degradation-and-recovery structure around mistakes by combining global progress calibration with local pairwise preference learning induced by sparsely annotated retry keypoints. The learned value model is then used to reweight demonstration chunks for downstream behavior cloning, reducing the influence of harmful execution errors while preserving useful corrective behaviors. Experiments on real-robot manipulation tasks show that ReTVL produces more fine-grained value estimates than progress-based baselines and improves imitation learning from imperfect demonstrations.

## 论文提出的方法论

### 核心思想
- 利用重试事件作为**稀疏监督信号**，在重试关键点附近学习**局部价值下降与反弹**的模式，而非假设整个轨迹的进展单调。
- 结合**全局进度校准**（基于时间步的简单线性进度）与**局部成对偏好学习**（基于重试事件构造的偏好对），训练一个对错误和纠正行为敏感的价值函数。
- 将学到的价值函数用于**加权行为克隆**（Weighted BC），通过重加权动作块来抑制有害执行错误，同时保留有用的纠正行为。

### 关键技术细节
1. **价值函数定义**：
   - 输入：观察历史 \( h_t \)（过去8帧）和任务指令 \( \ell \)。
   - 输出：离散化分布值（64个bin），期望值作为标量价值 \( V_\theta(h_t,\ell) \in [0,1] \)。

2. **全局进度监督**：
   - 对成功轨迹，目标进度定义为 \( v^*_t = t/T \)（线性增加）；失败轨迹的终端目标为0。
   - 使用交叉熵损失 \( \mathcal{L}_{\text{abs}} \) 进行全局校准。对重试关键点附近的帧不施加此损失（避免矛盾）。

3. **重试事件驱动的局部偏好学习**：
   - 构造三类时间窗口：**pre-retry**（纠正前，价值应高于重试点）、**near-retry**（重试点附近，价值最低）、**post-retry**（纠正后，价值应上升）。
   - 窗口参数：\( \Delta_{\text{pre}}=12 \)帧，\( \Delta_{\text{near}}=1 \)帧，\( \Delta_{\text{post}}=12 \)帧（基于5Hz采样）。
   - 构造偏好对 \( (h^+, h^-) \)，其中 \( h^+ \) 应具有更高价值（如 pre > near, post > near, 同侧更远离重试点的帧更高）。
   - **软窗口加权**：根据锚点与重试关键点的距离 \( d(h^+; r_{i,j}) \) 计算权重 \( w = \exp(-d/\tau_w) \)，距离越近权重越大，减少窗口边界噪声。
   - 偏好损失：\( \mathcal{L}_{\text{pref}} = -\mathbb{E}[w \log \sigma((V(h^+)-V(h^-))/T_{\text{pref}})] \)，使用 Bradley-Terry 模型。

4. **总训练目标**：
   - \( \mathcal{L}_{\text{value}} = \lambda_{\text{abs}} \mathcal{L}_{\text{abs}} + \lambda_{\text{pref}} \mathcal{L}_{\text{pref}} \)，混合比例通过采样率 \( \rho_{\text{pref}} \) 控制（本例中 \(\lambda_{\text{abs}}=1.0，\lambda_{\text{pref}}=3.0\)）。

5. **价值引导的行为克隆（Value-Weighted BC）**：
   - 对动作块计算价值改进 \( r_t = V(h_{t+\Delta_a}) - V(h_t) \)。
   - 利用数据集统计量 \( \mu, \sigma \) 进行归一化和裁剪，得到权重 \( \alpha_t \)。
   - 损失函数：\( \mathcal{L}_{\text{wBC}} = \sum_t \alpha_t \ell_{\text{BC}}(\pi(h_t), a_t) / (\sum_t \alpha_t + \epsilon) \)，其中 \( \ell_{\text{BC}} \) 为流匹配目标。

## 实验设计

### 数据集与场景
- **真实机器人操作任务**：使用 AgileX Piper 机器人臂，通过领航-跟随遥操作收集演示。
- **四个任务**：
  - Pick up Spoon（简单抓放）
  - Stack Blocks（堆叠三块积木，需精细对齐）
  - Fold Towel（折叠毛巾，可变形物体）
  - Open Drawer（拉抽屉、放置圆柱、关闭）
- **数据量**：
  - 价值模型训练：每个任务30条带注释轨迹（含重试关键点）。
  - 价值模型评估：20条保留轨迹（包含清洁成功、有重试的成功、失败轨迹）。
  - 下游策略学习：每个任务200条轨迹（Pick up Spoon 80条），均为混合质量演示。

### Benchmark 与方法对比
- **对比方法**（代表三种类型）：
  - TOPReward：使用预训练VLM计算“完成”token概率作为进度分数。
  - Robometer：通用机器人奖励模型，基于轨迹回放和偏好学习，用于失败和次优执行。
  - RECAP-Value：本工作实现的RECAP方法的价值组件，使用蒙特卡洛“step-to-success”目标学习进展价值函数。
- **实验设置**：所有方法使用相同的主干（Robometer-4B，基于Qwen3-VL-4B），LoRA微调，价值头为两层MLP。

### 评估指标
- **全局指标**：
  - 价值顺序相关 (VOC)：清洁成功轨迹上Spearman秩相关。
  - 成功/失败检测 (S/F Det.)：终端值>0.9为成功，计算准确率。
- **局部指标**（仅对有重试的成功轨迹）：
  - Drop AUC：价值下降是否集中在重试窗口。
  - Drop Probability：重试窗口内是否存在显著下降。
  - Pre > Retry 和 Post > Retry：重试点前/后平均价值是否高于重试点本身。

## 论文的主要结论与发现

1. **重试事件可作为有价值监督**：利用重试关键点训练的价值函数能捕捉局部价值下降和反弹，而基于单调进展的基线方法无法做到。
2. **ReTVL 优于所有基线**：
   - 全局指标接近或达到最好（VOC 0.987, S/F Det. 1.000）。
   - 局部指标大幅领先（Drop AUC 0.797 vs 最佳基线0.372；Pre>Retry 0.740 vs 0.329）。
3. **价值引导加权BC提升策略性能**：ReTVL-BC平均成功率达80.0%，优于标准BC（41.25%）和RECAP-BC（62.5%）。
4. **组件贡献**：偏好损失是捕捉局部错误的关键；软窗口稳定全局-局部冲突；绝对校准保证全局进度结构。

## 优点

1. **创新性**：首次将重试事件从噪声转换为有监督信号，学习非单调价值函数。
2. **实用性**：重试关键点标注成本低（平均每轨迹<1分钟），且标注一致性高（0.19秒平均误差）。
3. **方法设计合理**：软窗口加权处理标签模糊性，成对偏好监督提供相对排序，避免了直接回归可能引入的噪声。
4. **实验结果丰富**：在多个真实机器人任务上验证，对比多种强基线，消融实验完整，额外分析支撑核心观点。

## 摘要
长期机器人部署需要一种紧凑且可扩展的记忆系统，该系统能够保留细粒度的视觉语义，将观察结果在空间和时间上进行定位，并支持高效的存储与检索。在本文中，我们提出RAVEN，一种用于长期机器人问答与导航的智能体记忆系统。RAVEN将带有姿态和时间戳的视觉嵌入存储于向量数据库中，并在空间地图中进行检索，以回答查询并导航至目标。通过直接操作视觉嵌入，RAVEN避免了有损的图像到文本描述过程，并实现了大规模下精确的语义、空间和时间检索。在多个模拟和真实世界的视频问答基准测试中，RAVEN consistently 超越了基于描述的记忆系统，并在长期任务中以10倍的检索成本优势匹配了前沿视觉语言模型。最后，我们在Unitree Go1机器人上实例化RAVEN，用于自然语言目标到达的长期导航任务，并在多个大型室内环境中展示了成功部署。

## Abstract
Long-term robot deployment requires a compact and scalable memory that preserves fine-grained visual semantics, grounds observations in space and time, and enables efficient storage and retrieval. In this paper, we propose RAVEN, an agentic memory system for long-horizon robotic question answering and navigation. RAVEN stores visual embeddings with pose and time in a vector database, and grounds retrieval in a spatial map to answer queries and navigate to goals. By operating directly on visual embeddings, RAVEN avoids lossy image-to-text captioning and enables accurate semantic, spatial, and temporal retrieval at scale. Across several simulated and real-world video question-answering benchmarks, RAVEN consistently surpasses caption-based memory systems and matches frontier VLMs on long-horizon tasks at 10$\times$ lower retrieval cost. Finally, we instantiate RAVEN on a Unitree Go1 robot for the task of long-horizon navigation for natural language goal-reaching, and show successful deployment over several large indoor environments.

### 2. 方法论：核心思想、关键技术细节

- **核心思想**：用预训练多模态编码器将视频帧编码为视觉嵌入，连同机器人位姿（位置+朝向）和时间戳，构建视觉-空间-时间三重记忆（visual-spatio-temporal memory），存储于向量数据库（如FAISS/Milvus）。查询时，VLM智能体通过工具调用迭代检索相关记忆，综合推理后给出答案或导航目标。
- **关键步骤**：
  1. **记忆构建阶段**：机器人主动探索环境，采集RGB图像、深度、位姿、时间戳。使用多模态编码器（如CLIP、SigLIP、Seed1.6-Embed、QQMM-v2）生成帧级视觉嵌入，与位姿和时间一同存入向量数据库。
  2. **查询与执行阶段**：给定自然语言查询，VLM智能体在外循环中：
     - 维护当前上下文（已检索记忆）。
     - 若证据不足，调用四个原始工具之一进行检索：
       - 文本检索：用查询文本嵌入与视觉嵌入计算余弦相似度，返回top-K。
       - 时间检索：从指定时间戳开始返回连续记忆。
       - 位置检索：返回目标位置的空间近邻记忆。
       - 图像检索：支持图像查询（附录B）。
     - 每次检索返回K个记忆（包含图像、位置、时间、相似度分数），追加到上下文。
     - 智能体判断是否足够，否则继续检索。达到最大工具调用次数或足够时，生成结构化输出（文本答案/空间目标/时间参考）。
  3. **导航执行**：将预测位置传给A*轨迹规划器，控制机器人导航至目标。

### 6. 主要结论与发现

- RAVEN在**所有基准**上一致超越ReMEmbR（描述基线），尤其在次要物体、推理和精细视觉细节问题上优势显著（例如RAVEN-QA人类ego硬子集上比ReMEmbR高约30个百分点）。

- 视觉嵌入具有高压缩性：在保持97%性能的同时可实现>250倍帧稀疏化；相对于原始RGB视频压缩>22,315倍。
- 开放VLM（如Gemma3-27B）在RAVEN框架下仍可接近封闭模型性能，但本身作为VLM Only时严重退化。
- 在实际机器人部署中，RAVEN成功处理多步推理、小物体定位等挑战，成功率高达97.1%。
- 使用图像作为查询（多模态检索）可达到与文本查询相当的性能，支持更灵活的用户交互。

### 7. 优点

- **避免描述瓶颈**：直接操作视觉嵌入，保留纹理、形状、空间布局等细粒度信息，对次要物体和推理任务增益显著。
- **高度紧凑与可扩展**：存储开销小（嵌入维度通常数百），支持亚线性检索，适合长期部署。
- **训练免费**：利用预训练编码器和VLM，无需针对特定环境训练。
- **智能体迭代推理**：VLM通过工具调用逐步聚焦相关记忆，避免一次处理全部上下文，提升准确率并降低VLM负担。
- **空间-时间联合定位**：记忆项包含姿态和时间，支持位置、时间、语义的混合检索，便于导航执行。
- **灵活模态**：支持文本和图像查询，用户交互更自然。

### 8. 不足与局限

- **依赖预训练编码器质量**：检索性能受限于多模态编码器的对齐能力，对于极端开放词汇仍可能遗漏。
- **静态记忆**：当前实现为一次性构建的静态数据库，无法处理环境变化（物体移动、新物品出现等），缺乏在线更新和遗忘机制。
- **未处理动态场景**：仅适用于相对静止的环境，对频繁变化的任务（如超市上货）不够鲁棒。
- **实验覆盖不足**：缺少与3D结构场方法（如CLIP-Fields、3DLLM-Mem）的直接对比；缺少在户外大规模动态场景中的测试。
- **VLM推理成本**：虽然检索效率高，但VLM智能体迭代调用仍会产生推理延迟和token开销，对于实时性要求极高的应用需优化。
- **超参数敏感性**：top-K、最大工具调用次数、温度等需根据任务手动调整，未提供自动调节机制。

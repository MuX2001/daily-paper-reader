## 摘要
在非结构化环境中构建持久的具身智能体需要统一协调跨越网络（API、物联网）和物理（操作、导航）领域的异构工具，并结合从长时间运行中不可避免出现的物理故障中自主恢复的能力。现有系统将这些作为独立问题处理：基于VLM的规划器缺乏统一的网络-物理动作空间，智能体框架积累无界上下文而削弱时间连贯性，VLA策略执行开环操作而不检测自身故障。我们认为，持久自主性需要的不是单一模型，而是一种分层异步架构，明确分离规划、记忆和验证。为此，我们提出OmniAct框架，它集成了一个多模态语义规划器用于统一动作空间中的技能路由，一个具有事件边界驱动压缩的自适应分层记忆用于实现次线性上下文增长，以及一个异步视觉抢占引擎用于在物理执行期间闭合语义环路。在两个机器人平台协调四个物联网设备的40个真实世界长时任务中，OmniAct在所有复杂度级别上实现了端到端成功率的持续提升，在超过10万+累积交互令牌下保持近乎平坦的令牌消耗，并将中等规模的开源模型提升至专有级别的性能。

## Abstract
Building persistent embodied agents in unstructured environments demands unified orchestration of heterogeneous tools spanning both cyber (APIs, IoT) and physical (manipulation, navigation) domains, coupled with autonomous recovery from physical failures that inevitably arise over extended operation. Existing systems treat these as separate problems: VLM-based planners lack a unified cyber-physical action space, agent frameworks accumulate unbounded context that degrades temporal coherence, and VLA policies execute open-loop without detecting their own failures. We argue that persistent autonomy requires not a monolithic model but a hierarchical asynchronous architecture with explicit separation of planning, memory, and verification. To this end, we present OmniAct, a framework integrating a multimodal semantic planner for skill routing across unified action spaces, an adaptive hierarchical memory with event-boundary-driven compression for sub-linear context growth, and an asynchronous visual preemption engine that closes the semantic loop during physical execution. Across 40 real-world long-horizon tasks on two robotic platforms coordinating four IoT devices, OmniAct achieves consistent improvements in end-to-end success across all complexity levels, maintains near-flat token consumption over under 100k+ accumulated interaction tokens, and elevates mid-scale open-weight models to proprietary-level performance.

### 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：当前具身智能系统在面向真实、非结构化环境的**长期自主部署**时，存在三个关键瓶颈：
    1.  **动作空间割裂**：现有系统将网络工具（如 API、IoT）调用与物理操作（如抓取、导航）视为两个独立的流程，缺乏一个统一的“网-物理”动作空间，难以自然处理需要同时协调两者的复杂指令。
    2.  **上下文无限增长**：主流智能体框架线性拼接所有交互历史，导致上下文语境迅速膨胀，不仅增加了计算开销，还会导致早期关键信息（如用户偏好）被稀释或遗忘，破坏时间连贯性。
    3.  **开环执行失败**：端到端的 VLA 模型在执行过程中无法感知物理世界是否偏离预期，一旦发生未检测到的失败（如物体滑落），错误会级联放大，导致任务彻底失败。
- **整体含义**：要实现“日常物理自主”，不能依赖一个单一的端到端模型。论文提出，需要一种**层次化、异步的架构**，将**高层规划、长期状态跟踪与实时物理验证**明确解耦为专门协作的模块，从而实现对异构工具的闭环、可扩展管理。

### 2. 方法论：核心思想与关键技术

- **核心思想**：OmniAct 框架通过三个核心模块的协作，将异构的“网-物理”动作统一到一个事件驱动的闭环中：
    1.  **多模态语义规划器**：负责高层决策，包括意图理解、任务分解和技能路由。
    2.  **自适应层次记忆**：通过事件边界驱动的压缩，实现次线性上下文增长。
    3.  **异步视觉抢占引擎**：在执行过程中进行周期性闭环验证，实现自主故障恢复。

- **关键技术细节**：
    - **统一网-物理动作空间**：将每个动作定义为 `(τ_t, g_t)` 的元组，其中 `τ_t` 是目标技能（如 `pick_and_place`、`control_light`），`g_t` 是该技能的特定参数。规划器输出结构化的 JSON 指令，实现对异构执行器的统一调度。
    - **自适应层次记忆 (H)**：包含三层：
        - **感觉记忆**：一个轻量级 FIFO 队列，存储最近的视觉帧，供控制策略和视觉监视器使用，与规划上下文解耦。
        - **情景记忆**：核心是**事件边界驱动压缩**。当检测到语义边界（如子任务完成、关键状态变化）时，将原始观测序列压缩为带时间戳的摘要，保留语义内容、状态转换和行为结果，丢弃过程冗余。这使得上下文增长与“语义事件”数量成正比，而非原始交互轮次，实现次线性扩展。
        - **反思记忆**：存储静态先验知识（如工具模式、技能清单）和**动态积累的经验**。当执行失败或视觉抢占被触发时，系统会生成包含根因和纠正策略的结构化记录。在后续规划中，检索相关的反思注入到上下文中，实现故障恢复向长期适应的转化。
    - **异步视觉抢占**：在 VLA 模型执行物理动作时，一个异步的视觉监视器以较低的频率（而非控制频率）采样图像，并提交给一个独立的 VLM 进行高层语义级别的进度评估（如物体是否已被抓取、机器人是否向目标前进）。若检测到异常（如物体未被抓起），系统会**立即中断** VLA 执行器，打包失败上下文并交还给规划器进行重新规划。这区别于传统验证几何约束的方法，能捕获低层控制器难以发现的失败模式。

### 6. 主要结论与发现

1.  **显著优于基线**：在最具挑战性的 L3 任务上，OmniAct 在 E2E 成功率上大幅超越所有基线（机械臂端达 50.0%，移动机器端达 54.2%），且子任务成功率更高（超过 80%），验证了其**异步视觉抢占与反思记忆**在故障恢复方面的关键作用。
2.  **高效记忆管理**：OmniAct 的自适应层次记忆能在 270 轮以上的交互中，将每次调用的输入 tokens 稳定在 4k-8k 之间，实现**近乎平坦的 token 消耗**，而原始历史则会线性增长至 160k tokens 以上。
3.  **架构优于模型大小**：OmniAct 能使中等规模的开源模型（如 Qwen3-VL-30B-A3B）的性能提升 30 个百分点，达到专有模型 Gemini-3.1-Pro 的水平。这表明**结构化编排和清晰的架构设计**可以弥合模型规模带来的性能差距。
4.  **跨平台强泛化**：在两个结构迥异的机器人平台上，OmniAct 均取得了相近的相对提升，证明了其**核心贡献（统一路由、层次记忆、视觉抢占）不依赖于特定硬件，具有良好的可迁移性**。

### 8. 不足与局限

1.  **适应能力的非对称性**：高层规划器可以基于反思记忆进行重规划来应对失败，但无法改进冻结的下游 VLA 策略本身。当失败源于 VLA 策略的固有能力限制（如永远抓不起特定形状物体）时，恢复能力就受限于现有的技能库。
2.  **视觉监视的延迟窗口**：异步视觉监视器以 VLM 推理频率运行，而非控制频率，因此在异常检测到并中断执行之间存在一个**延迟窗口**。在此期间，错误的动作可能继续进行，在涉及易碎物品或人机协作的场景中构成残余安全风险。
3.  **基准任务与部署环境的模拟性**：40 个任务虽然真实，但覆盖面有限。长时记忆实验基于模拟轨迹，与真实世界持续数天的部署仍有差距。此外，所有实验均在实验室环境中进行，未在家庭或工厂等更嘈杂、不可控的真实用户场景中验证。
4.  **依赖 VLM 质量**：视觉抢占和规划模块都重度依赖 VLM（如 Gemini-3.1-Pro）的输出质量。实验也显示，当基础模型能力过弱（如 Qwen3-VL-8B）时，框架的性能提升有限。此外，VLM 的幻觉问题本身也可能引入新的错误。
5.  **手动设计的成分**：论文中的技能路由、工具模式等框架组件，虽然高度模块化，但作者团队为其顺利运行进行了大量手动设计和调优工作。

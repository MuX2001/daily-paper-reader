## 摘要
视觉-语言-动作（VLA）模型利用预训练的视觉-语言表征进行机器人控制，然而简单地添加历史帧并不能可靠地捕获近期的物理变化。这在多阶段操作中尤其成问题，因为视觉上相似的状态可能取决于先前的执行而需要不同的动作。为了解决这一挑战，我们提出了TemporalFlow-VLA，它通过物理基础的时序监督来学习紧凑的执行历史。利用记录的机器人状态、机器人几何形状和标定相机，我们构建机器人-表面时序流作为仅训练目标，并监督两个执行对齐的时序查询，为动作专家提供结构化的历史信息。该几何监督路径在部署时不进行评估。TemporalFlow-VLA在LIBERO上实现了97.63±0.26%的平均成功率，包括在LIBERO Long上达到96.60±0.87%，并在12个RoboTwin任务中实现了85.5%/84.2%的Clean/Randomized成功率。它在更长时程、多阶段操作中显示出相对于先前方法最明显的优势。受控历史干预实验表明，动作预测依赖于历史内容和时序顺序两者。通过异步特征缓存，时序条件化保持了单帧级别的服务器端采样延迟，而无需额外的历史编码开销。总体而言，TemporalFlow-VLA提供了一种紧凑的、物理基础的接口，用于利用有序的执行历史，而无需在部署时进行显式的运动估计或几何处理。

## Abstract
Vision-language-action (VLA) models leverage pretrained vision-language representations for robot control, yet simply adding historical frames does not reliably capture recent physical change. This is especially problematic in multi-stage manipulation, where visually similar states may require different actions depending on prior execution. To address this challenge, we present TemporalFlow-VLA, which learns compact execution history through physically grounded temporal supervision. Using recorded robot states, robot geometry, and calibrated cameras, we construct robot-surface temporal flow as a training-only target and supervise two execution-aligned temporal queries that provide structured history to the action expert. The geometric supervision path is not evaluated at deployment. TemporalFlow-VLA achieves 97.63 +/- 0.26% average success on LIBERO, including 96.60 +/- 0.87% on LIBERO Long, and 85.5%/84.2% Clean/Randomized success across 12 RoboTwin tasks. It shows its clearest advantage over prior methods on longer-horizon, multi-stage manipulation. Controlled history interventions show that action prediction depends on both historical content and temporal order. With asynchronous feature caching, temporal conditioning maintains single-frame-level server-side sampling latency without additional historical-encoding overhead. Overall, TemporalFlow-VLA provides a compact, physically grounded interface for exploiting ordered execution history without explicit motion estimation or geometric processing at deployment.

- **研究动机**：VLA 模型将预训练的视觉-语言表征迁移到机器人控制中，表现出很强的泛化能力。但多数 VLA 在决策时主要依赖当前帧 RGB、语言指令和机器人状态，对执行历史的利用很弱。这长时程、多阶段任务中会造成实际决策问题——例如，一次失败抓取后与抓取前的画面高度相似，或同一种末端姿态既可对应于“接近”“携带”也可对应于“恢复”，如果没有近期的物理变化信息，策略会误解当前任务阶段。

- **研究意义**：这项工作是 VLA 时序建模探索中的一个重要补充，它以明确回答“每个历史隐向量应该编码何种物理变化”为核心问题，与依靠 VLM 原生特征、重建或倒推的学习方式不同。其另一个实用优势是部署时**完全不需要运动估计或几何处理**。

## 2. 论文提出的方法论

- **总体架构**：TemporalFlow-VLA 在预训练 VLA 基础上加入一条并行时间路径。基础策略保持原有结构，仍从当前观测生成动作块，而时间路径额外接收来自头相机的历史帧观测（t−15、t−8）。
- **两个分块对齐的时间查询（Hierarchical Temporal Queries）**：
  - 设计两个查询 token q8 与 q15：Q8 总结 t−8→t 的近期运动；Q15 总结 t−15→t 的完整演化，并可基于 Q8 的短时摘要做整合。
  - 通过**定向掩码注意力**（directed masked attention）区分二者：Q8 只能读取语言 token、t−8 观测、当前观测和自身；Q15 除以上外还可读取 t−15 观测以及 Q8；形成单向 Q8→Q15 的层级信息流动。动作 token 只能通过这两个查询间接了解历史帧信息，不能直接访问历史图像 patch。
- **物理监督信号：机器人表面时间流（Kinematics-Grounded Robot-Surface Temporal Flow）**：
  - 利用记录的各时刻关节状态、URDF 几何模型和标定相机外参，通过机器人正向运动学，把当前可见机器人表面像素投影到目标时间图像坐标系。
  - 核心公式：
  - 恢复同一个点在 source 时刻 link 坐标系中的表达，再通过 target 时刻正运动学变换和相机投影得到该点在 robot-only 渲染图像中的对应位置；对边界内、属于同一 link 且 3D 残差 ≤ 5mm 的像素保留匹配关系。
  - 将位移除以图像尺寸 224 归一化，在每个非重叠的 14×14 区域内对有效 robot 像素做算术平均，得到 16×16×2 的流场目标；另用“有效机器人像素占比” cρ(k) 与掩码 Mρ(k) 决定是否计算该 patch 的损失。
  - 该标签是**只在训练中**使用的监督，不需要人工光流标注，也不需要部署期几何计算。时间路径仍输入全 RGB 帧，因此物体和场景变化的信息依然保留。
- **Temporal 查询的解码与训练损失**：每个区间单独使用轻量级解码器 Dρ(Vρ, zρ)，查询 zρ 对 VLM 空间特征做 FiLM 调制（channel-wise 缩放与偏移），经两层 pointwise MLP 回归流场。损失在掩码 patch 上做 Huber 损失，总辅助损失为 Q8 与 Q15 两项的平均。最终目标为 L = Laction + λtemp·Ltemp（λtemp=1.0）。
- **异步历史特征缓存**：为消除多帧同步视觉编码开销，系统在机器人执行上一动作块的过程中，由后台进程用环形缓冲异步提取并缓存 t−15、t−8 的视觉特征；重规划时只需同步编码当前帧。同步延迟从 3·Tvision+Tjoint+Taction 降到 ≈ Tvision+Tjoint+Taction。该模块是部署时唯一的额外工程机制，只规避重复编码，不会绕过时间查询本身。

## 6. 论文的主要结论与发现

- TemporalFlow-VLA 在 LIBERO 上平均成功率 97.63±0.26%；其中 LIBERO Long 为 96.60±0.87%，比最强的已报告值高约 2.1 个百分点。
- RoboTwin 12 任务 clean/randomized 平均成功率为 85.5% / 84.2%，在 randomized 设置下比已发布基线最优值高 8.0 个百分点。增益随任务步骤数递增：H=2 组比 runner-up 高 5.5 个百分点，H=3 组高 14.5 个百分点；而在 H=1 组中并未取得最高分。
- 历史干预实验显示：动作预测既依赖历史**内容**，也依赖历史**时间顺序**；而无约束的多帧基线则对顺序很不敏感。这验证了“如何表达历史”比“有没有历史”更重要。
- 消融结果证明：物理监督本身带来的增益是真实存在的（对比 2Q w/o flow 与 Ours），且两个互补时间尺度（Q8 与 Q15）共同使用时效果最佳。
- 异步缓存将服务器端策略采样延迟从 68.10ms 降至 62.78ms（单次重规划节省约 5.32ms），在 15 次重规划片段中累计减少 7.8% 的采样耗时。
- 真实世界实验显示：在 AgiBot A3 上三杯堆叠成功率从基线的 57.8% 升至 77.8%（+20.0 points），双瓶装箱从 86.7% 升至 97.8%（+11.1 points）。

## 7. 优点

- **问题定位准确**：通过自建诊断（shuffle/remove）清楚暴露了 VLA“多帧输入但没有好好利用顺序”这一痛点，论述链条完整。
- **方法设计优雅**：机器人表面流作为训练专属监督，只在训练时计算；部署时无任何运动估计或几何处理，政策更轻、易于落地。
- **物理可解释性**：每个时间语义明确——Q8、Q15 被定义为特定区间的运动摘要，而不是任意隐空间向量，具备很强的可解释性。
- **与通用 VLA 架构兼容**：不引入独立 cross-attention 模块，而是把 q8/q15 放回 π0.5 的 joint masked-attention 序列中，改动小、易嵌入已有模型。
- **分层注意力设计新颖**：Q8→Q15 的单向路径让两项查询既有分工又能叠加，打破了“多查询并列”的常见模式。
- **工程实用性**：异步缓存显然是部署中很关键的细节，且对时间查询机制没有破坏；测量指标清晰，降低延迟的效果被量化。
- **实验范围广**：覆盖了干净/随机化仿真、多步任务、真实机器人、效率等各维度，结论有说服力。

## 8. 不足与局限

- **固定历史窗口**：t−15、t−8 是预先固定的网格，论文在结论部分也承认:未系统研究历史帧数量与时间间距对不同操纵类型任务的影响，最优时序尺度问题未被完整回答。
- **RoboTwin 对比公平性**：RoboTwin 部分任务内 π0/π0.5/X-VLA 等水平部分取自他人 re-eval 结果（原文均作脚注说明），与自训练模型进行对比时的超参、训练数据、种子等不完全一致，可能给对比造成细微偏差。
- **真实机器人评估场景有限**：仅 AgiBot A3 两个任务、45 次试验/方法；未验证不同 embodiments、不同相机设置、不同任务族在真实世界的表现。
- **物理监督设计对自遮挡与可见性有限制**：监督只对“源时刻自可见的 robot 表面”像素计算，若某区域在 t−15 可见但在 t 不可见（或反之），该区域不被计入；且此监督不覆盖目标物体的流动，物体动态变化仅靠 VLM 原生特征学习。
- **辅助 head 的部署问题**：虽然部署时不运行几何渲染和流解码器，但若要剔除该部分仍需在训练与部署代码之间做专门剪枝，否则会增加模型参数量。
- **异步缓存的边界情况**：Episodes 开始需要跳过缓存、历史帧可能有陈旧特征等问题虽然已处理，但文中并没有分析长时间运行时的缓存鲁棒性/内存占用/并发不同步带来的性能瓶颈。
- **论文按 2026 年数据制作，涉及的多个对比方法多以 arXiv preprint 存在**，其结果的稳定性有待后续进一步跟踪；当前置信度取决于这些方法本身的可复现性。
- **消融实验结果的显著性检验缺失**：报告了平均数和种子偏差，但并未报告差异的统计显著性检验结果，读者不能直接用这些结果验证某些组间差距是否在噪声范围内。

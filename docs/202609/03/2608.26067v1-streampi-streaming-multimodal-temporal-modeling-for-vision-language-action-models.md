## 摘要
视觉-语言-动作（VLA）模型在机器人操作中已显示出有效性，然而诸如pi0.5等最先进模型仍以单帧范式运行，限制了其保留历史观测并发展精确空间感知的能力。在本文中，我们提出StreamPI，一种流式多模态时间建模框架，在不引入任何额外参数的情况下赋予单帧VLA时间推理能力。其核心设计之一是指令锚定的时间建模。它将每个(视觉观测, 语言指令)对视为一个原子时间单元：每对内部的双向注意力实现跨模态融合，而跨对的因果注意力则保持自回归流式推理。这确保了语言指令在整个任务执行过程中充当持久语义锚点。为弥合同步训练与异步真实机器人部署之间的差距，我们引入一种随机间隔流式训练策略：合适的帧间间隔（例如每3帧）可实现更快更平滑的动作执行。此外，随机化间隔进一步增强了模型对帧时序扰动的鲁棒性，从而支持实际中的异步部署。更进一步，通过利用大语言模型骨干的长度外推能力，StreamPI无缝继承预训练的单帧权重，并支持灵活的单帧与多帧推理。在涵盖记忆依赖与精细感知场景的真实机器人任务以及仿真基准LIBERO上的实验表明，StreamPI在各类任务中均优于pi0.5。

## Abstract
Vision-Language-Action (VLA) models have demonstrated effectiveness in robot manipulation, yet state-of-the-art models such as pi0.5 operate under a single-frame paradigm, limiting their ability to retain past observations and develop precise spatial perception. In this paper, we propose StreamPI, a streaming multimodal temporal modeling framework that equips single-frame VLA with temporal reasoning capability without introducing any additional parameters. One core design is instruction-anchored temporal modeling. It treats each (visual observation, language instruction) pair as an atomic temporal unit: bidirectional attention within each pair enables cross-modal fusion, while causal attention across pairs preserves autoregressive streaming inference. This ensures the language instruction serves as a persistent semantic anchor throughout task execution. To bridge the gap between synchronous training and asynchronous real-robot deployment, we introduce a andom-interval streaming training strategy: a proper inter-frame interval (e.g., every 3 frames) enables faster and smoother action execution. Beyond this, randomizing the interval further improves robustness to frame-timing perturbations, supporting asynchronous deployment in practice. Furthermore, by leveraging the length extrapolation capability of the LLM backbone, StreamPI seamlessly inherits pretrained single-frame weights and supports flexible single-frame and multi-frame inference. Experiments on real-robot tasks spanning memory-dependent and precise perception scenarios, as well as the simulation benchmark LIBERO, demonstrate that StreamPI outperforms pi0.5 across diverse tasks.

## 一、核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型（如 RT-2、OpenVLA、π0、π0.5 等）已经发展为机器人操作领域的主流范式，把感知、语言理解与动作生成统一为端到端框架。
- **核心痛点**：当前最先进的 VLA 模型（尤其是 π0.5）采用**单帧推理范式**——每一步只根据当前单张图像观测预测动作，没有历史上下文访问能力，由此带来两个根本缺陷：
  1. **缺乏时间记忆**：无法解决天然需要跨帧信息消歧的任务（如"哪个杯子藏了目标物体"、"抓取滚动中的物体"）；
  2. **空间感知有限**：单帧图像缺乏运动视差和多帧结构一致性带来的几何线索，难以支撑高精度 3D 空间操作（如精细插入任务）。
- **现有多帧方案的不足**：已有窗口式多帧方案（把历史帧拼接后一并输入）面临四重挑战——计算开销随序列长度线性增长、语言指令被不断累积的视觉 token"稀释"（指令遗忘）、训练固定间隔与真实部署异步流式观测不匹配、引入视频编码器可能破坏预训练 VLA 表征且增加参数。
- **本文目标**：在不新增任何参数的前提下，让单帧 VLA（π0.5）获得高效的时间推理能力，同时兼顾真实世界的异步流式部署需求。

## 二、方法论：StreamPI 框架

StreamPI 的设计围绕四个核心机制展开。

### 1. 指令锚定时间建模（Instruction-Anchored Temporal Modeling）

- **原子时间单元**：把每个（多视角视觉观测 \(V_t\)，语言指令 \(l_t\)）组合视作一个"原子时间单元"，即 \(u_t = (V_t, l_t)\)。语言指令在每个时刻都与其对应的视觉上下文绑定，从而在任意长时间跨度中都不会被旁路或遗忘（指令不随视觉 token 累积而稀释）。
- **双层注意力结构**（全部通过重排既有 Transformer 的 attention mask 实现，**零新增参数**）：
  - **对内双向注意力（Intra-pair Bidirectional Attention）**：在单个时间单元内部，图像 token 与文本 token 互相完全可见，完成透彻的跨模态融合；
  - **跨对因果注意力（Inter-pair Causal Attention）**：在不同时间单元之间，当前帧只允许关注历史帧，保持自回归流式结构，训练时未来帧不会泄漏到过去表征。
- **公式化描述**：当前时刻的输入序列由最近 T 个原子单元拼接构成：
  \[
  U = [u_{t-T+1}, u_{t-T+2}, \dots, u_t]
  \]
  每个单元内部执行双向融合 \(h_\tau = \text{Attn}_{\text{bi}}(V_\tau, l_\tau)\)；跨单元则执行因果聚合 \(o_t = \text{Attn}_{\text{causal}}(h_{t-T+1}, \dots, h_t)\)，最终条件化动作生成 \(a_t \sim \pi_\theta(\cdot \mid o_t)\)。

### 2. 无参数时间扩展（Parameter-free Temporal Extension）

- 利用 LLM 骨干的长度外推能力，不引入视频编码器或微调新模块，直接继承 π0.5 的全部预训练权重；
- 仅通过扩展输入 token 序列 + 调整位置编码 + 应用块状因果注意力掩码，即可把单帧模型无缝扩展为多帧推理，并支持测试时灵活切换单帧/多帧。

### 3. 随机间隔流式训练（Random-Interval Streaming Training）

- **随机间隔采样**：在采样历史帧时，不以固定间隔 δ̄ 取帧，而是加入扰动 \(\epsilon \sim U(-\Delta, +\Delta)\)，得到 \(\delta = \bar{\delta} + \epsilon\)，并裁剪到 \([\delta_{\min}, \delta_{\max}]\)。训练采用 δ~U[3,7]。此举模拟真实机器人观测流的不同时间间距，防止模型过度依赖固定间隔线索。
- **时间掩码**：随机屏蔽最早 k 帧（k∈{0,...,T−1}），模拟流式推理中"只见最新部分帧"的增量观测模式。
- **流式推理**：首个时间戳编码并缓存当前帧的 KV 表征；后续时间戳只编码新到达的帧，通过 KV-Cache 让新帧的历史帧进行交叉注意力，避免重复计算历史帧。推理开销与时间跨度解耦，近似常数。

### 4. 算法流程（附录 Algorithm 1）

维护一个最大容量为 T 的 KV-Cache，对到达的观测流 {V_t0,...,V_tN}：
- 每步编码当前原子单元 (V_tn, l)，并结合缓存获得融合表征；
- 若缓存已满则整体清空重建（flush），否则追加新缓存；
- 基于当前融合表征 + 缓存预测动作块并下发，继续推进。

## 六、主要结论与发现

1. **真实机器人**：StreamPI 全面优于 π0.5——Shell Game 从 46.7%→80.0%（+33.3%）；Rolling Object Grasping 从 26.7%→63.3%（+36.6%）；Pen Insertion 从 40.0%→66.7%（+26.7%）；Cup Insertion 从 60.0%→92.0%（+32.0%）。
2. **LIBERO**：StreamPI（T=5）平均成功率 98.3%，比单帧 π0.5（96.5%）高 1.8%（论文正文表述为 1.4%，引用 Table 1 数值计算为 98.3-96.9=1.4%，两处口径有细微出入）；在已近饱和的 benchmark 上仍能提升——LIBERO-Long +2.6%、GOAL +2.8% 最为显著；Spatial 套件无提升（静态空间关系单帧即足够）。
3. **CALVIN**：平均序列长度 4.547（π0.5 为 4.313，MemoryVLA 为 4.090），第 5 子任务成功率 85.0% vs 79.5%（π0.5），且每一序列位置都有稳步提升，显示长时程记忆和抗错误累积能力。
4. **消融结论**：
   - 对内双向注意力对性能至关重要（替换为因果在 T=5 LIBERO-Long 上 −5.6%）；
   - 跨对因果聚合随 T 增大带来持续增益（+1.8% 平均、+3.0% Long）；
   - 随机间隔训练在相同 T 下优于固定间隔（T=5 时 98.3% vs 97.0%）；
   - T=5 训练模型在 T=3 测试下几乎不降（97.4%），在 T=1 下仍优于 π0.5 基线（97.1%），证明跨帧配置泛化良好。
5. **推理效率**：KV-Cache 流式方案使推理耗时近似恒定，5 帧只比单帧慢约 10ms，适合实时控制。

## 七、方法优点

- **零参数扩展**：完全通过 attention mask 重排实现时间建模，从根基上避免了视频编码器引入导致的表征错配风险，且完整保留 π0.5 预训练权重与知识——极具工程实用性。
- **指令锚定设计精巧**：把指令与每个观测"绑定"为一个原子单元，从注意力结构层面根除长序列指令遗忘问题，而非采取事后补救（如重发指令）。
- **训练与部署对齐考量充分**：随机间隔训练 + 随机时间掩码直接面向真实机器人异步、变帧率观测流这一工程痛点，且有实验（Table 4）验证其在"大间隔/随机间隔"推断下仍保持性能——直接影响在线推理频率与实时性。
- **推理效率高**：KV-Cache 设计避免了对历史帧的重复前向计算，使长时程推理开销与时间跨度解耦。
- **单一框架兼容双模式**：同一份权重既可单帧也可多帧推理（length extrapolation 支持），测试时可按算力与任务需求灵活切换。
- **消融与可视化细致**：逐试次表格、多任务时序可视化（对比失败/成功轨迹）、跨流泛化实验，均超出同类论文的常规验证深度。

## 八、不足与局限性

1. **训练成本局限（作者自认）**：训练时需将所有帧载入显存，超长时程（远大于 T=5）下的训练显存/计算开销会达到不可接受的程度，限制了对更长历史（>100帧）的建模。
2. **鲁棒性边界（作者自认）**：随机间隔训练只改善了中等范围帧率扰动，对极端异步/长尾时序扰动仍不够鲁棒；评估 δ~U[3,7] 范围有限，未能覆盖更大的实际部署方差。
3. **评估框架限制**：
   - LIBERO 已接近饱和，可观测增益空间被压缩，结论外推需谨慎；
   - CALVIN 最长仅 5 子任务，尚不足以证明"超长时程"能力；
   - 真实任务只有 π0.5 单基线对照，缺少与其他多帧 VLA 的实物对比。
4. **可复现性细节欠缺**：未报告训练时长、数据增强/清洗细节、随机种子数量及各指标方差，也未披露 LIBERO 结果基于哪种训练数据规模和真实机器人数据与仿真数据的具体构成比，审稿/复现难度增加。
5. **应用风险（作者自认）**：VLA 时间建模在真实场景中面临分布外泛化风险，可能引发安全操作隐患；大规模部署能力提升亦会对常规工业劳动力市场产生潜在冲击。

## 总结评述

StreamPI 是对 VLA 时间建模研究的一次简洁而高效的设计补充：它以"指令锚定 + 双层注意力 + 零参数扩展 + 间隔随机化"的组合方案，以几乎不增加推理成本和参数量的代价，为最强单帧 VLA（π0.5）补齐了时间记忆与时空感知短板。实验验证覆盖真实/仿真、记忆/感知两类核心场景，消融逻辑闭环。但其时间跨度尚短、基准趋饱和、对比公平性和统计严谨性有限，是否能支撑更长时程和更具挑战的真实操作仍需后续更充分的验证。

## 摘要
冻结的视觉-语言-动作（VLA）策略提供了广泛的操控技能，但以开环动作块执行，不跟踪任务进度，因此智能体无法可靠地决定是继续、重试还是终止。外部记忆是一种自然的补救措施，但当尝试的动作被视为已完成的进度时，它可能是有害的，将局部执行错误转变为持续的任务状态错误。我们提出成就接地记忆（AGM），一种用于冻结VLA策略的轻量级闭环框架，它将任务表示为带有进度指针的子目标序列，并且仅在当前子目标通过物理证据验证后才推进该记忆。本体感觉交互线索决定何时进行验证，而连贯的点跟踪和语言条件跨视图比较——通过一个仅含243万参数的验证头从冻结的基础模型获取——决定实现了什么。因此，AGM将开环执行转变为执行、验证和进度的闭环，保持策略冻结且无需测试时大模型推理。在RoboMME Counting基准上，AGM在PickXTimes上达到[具体数值]和在BinFill上达到[具体数值]，平均超过最强的记忆增强基线[具体数值]个百分点，该框架在实体机器人上也产生了同样显著的效果。因此，可靠的具身记忆更多地取决于纪律严明的状态更新，而非记忆容量。

## Abstract
Frozen vision-language-action (VLA) policies offer broad manipulation skills but execute open-loop action chunks without tracking task progress, so the agent cannot reliably decide whether to continue, retry, or terminate. External memory is a natural remedy, yet it can be harmful when attempted actions are treated as completed progress, turning local execution errors into persistent task-state errors. We propose Achievement-Grounded Memory (AGM), a lightweight closed-loop framework for frozen VLA policies that represents a task as a subgoal sequence with a progress pointer and advances this memory only after the current subgoal is verified by physical evidence. Proprioceptive interaction cues decide when to verify, while coherent point tracking and language-conditioned cross-view comparison, sourced from frozen foundation models through a single 2.43M-parameter verification head, decide what was achieved. AGM thereby converts open-loop execution into a closed loop of execution, verification, and progress, keeping the policy frozen without test-time large-model inference. On the RoboMME Counting benchmark, AGM reaches on PickXTimes and on BinFill, surpassing the strongest memory-augmented baseline by points on average, and the framework yields equally decisive gains on a physical robot. Reliable embodied memory thus depends more on disciplined state updates than on memory capacity.

### 2. 论文提出的方法论

#### 2.1 核心框架：AGM（Achievement-Grounded Memory）

- 将任务指令确定性展开为**有序的类型化子目标序列** $G = \{(g_k, c_k)\}_{k=1}^T$，其中 $c_k \in \{\text{grasp}, \text{place-rev}, \text{place-irrev}, \text{other}\}$ 标注子目标类型。
- 维护紧凑任务记忆 $\mathcal{M}_t = (G, p_t)$，$p_t$ 是唯一的持久进度指针，策略被条件化为 $\pi_\theta(\cdot | o_t, g_{p_t})$。
- **核心原则**：进度指针仅在当前子目标被**物理证据验证**后才允许更新。

#### 2.2 事件触发验证机制（何时验证：When to verify）

- 通过**带滞回（hysteretic）的有限状态机**处理夹爪开合宽度信号 $w_t$，产生交互事件 $e_t \in \{\emptyset, G^+, R^+, R^0\}$（$G^+$=带载抓取，$R^+$=带载释放，$R^0$=空载释放）。
- **兼容函数** $\chi$ 确保只有与当前子目标类型匹配的事件才触发验证：$G^+$ 仅对抓取子目标有效，$R^+$ 仅对放置子目标有效。
- 关键原则：**交互事件仅定位候选时刻，本身不是成功证据**。

#### 2.3 抓取验证（验证什么——运动学证据）

- 利用冻结的**CoTracker3**点追踪器，判断被抓物体是否与夹爪一起做**连贯上移运动**。
- 技术要点：
  - 抓取事件发生时，通过手眼标定将末端执行器位置投影到前视图，生成 $6\times6$（36点）查询网格。
  - 缓冲提升视频片段至末端执行器上升 0.03m。
  - 追踪点轨迹，保留最终可见度 $>0.5$ 的点，取纵向上移最大的前 1/3 轨道的**中位数**作为响应 $r^G_n$。
  - 判定标准：$r^G_n \geq \delta_G$（4像素）即视为抓取成功。

#### 2.4 放置验证（验证什么——语义证据）

- 利用冻结的**SigLIP**视觉-语言编码器（203.2M参数），进行**语言条件跨视图比较**。
- 提取释放前后事件窗口（每窗口4帧聚合）的正面和手腕视角影像。
- 特征拼接包括：前置释放前后嵌入、**差分嵌入**（捕获主导状态变化）、手腕视角嵌入、本体感觉窗口摘要、以及归一化后的**子目标语言查询嵌入** $q_k = Q(g_k)$（去除重复索引，只保留"物体-目标关系"语义）。
- 总特征向量宽度为 4626 维，经 **2.43M 参数的轻量MLP验证头**（Linear 4626→512→128→2），输出放置成功概率 $s^P_n$。

#### 2.5 记忆更新规则

- 抓取验证（点追踪）与放置验证（学习头）分别设置阈值：抓取 $\delta_G$；放置按类型区分（$\kappa_c=0.5$ 可恢复型，$\kappa_c=0.05$ 不可逆型）。
- 转换规则：
  - **验证成功 → 指针前进**（advance）
  - **抓取失败 → 指针保持**（retain）
  - **可恢复放置失败 → 回滚**到同轮次的抓取子目标（rollback）
  - **不可逆放置**：因物体已入容器，采用宽松阈值防误拒；连续拒绝超限则强制推进防死锁。
- 防护机制：带界重试上限（可恢复放置2次、不可逆放置3次、抓取3次）、失速超时（80步）、终止前视觉占用测试（独立于学习的验证头）。

#### 2.6 训练语义

- 验证头离线训练于 788 个执行事件（类加权交叉熵），经两个互补控制器采集：AGM自身（覆盖部署分布）和基于尝试的无验证控制器（补充失败样本）。两个控制器各提供不同分布的数据。训练集种子与评估集程序化验证不重叠。部署时以全部 788 个事件重新拟合验证头。
- 姿态端到端：策略、点追踪器、编码器全部冻结，**仅训练验证头**。

### 6. 论文的主要结论与发现

- **冻结 VLA 策略 + 验证内存驱动可使重复计数任务成功率从近乎 0 提升到接近 100%**。例如 π0.5 在 PickXTimes N=5 时从 0.0% → 100.0%（→ 100.0%），BinFill 从 0.0% → 66.7%（平均值 π0.5+AGM 在 PickXTimes/BinFill 分别为 100.0%/84.0%）。
- **同一策略、同一子目标序列、同一指针**，写证据不同（验证写入 vs 尝试写入）时 PickXTimes 从 100%/32% 呈数量级差异。分解本身不是关键，验证纪律才是。
- 记忆增强的收益落在"尝试失败与达成之间的差距"大的任务上：失败后世界可恢复→验证起关键作用；不可逆容器放置基本自证→差距缩小，分解承载大部分结果。
- 针对不可逆放置的"宽松阈值 + 可恢复类型收紧阈值"设计（不对称阈值）单点价值集中体现：平坦化导致 BinFill 从 84.0% 降至 74.0%（因严格验收误拒不可逆成功投放）。
- AGM 在四个任务上的平均成功率 55.96%，超越最强基线 MemER（48.83%）7.1 个百分点，且只训练 2.43M 参数（对比 MemER 为 4B LoRA）。
- 可靠性来自纪律性的状态更新而非记忆容量/模型规模——这是全文的核心主张。

- **模块化架构、冻结最大化**：VLA 策略、点追踪器、编码器全部冻结，仅训练 2.43M 头。冻结模型各司其职（CoTracker3 提供运动学证据、SigLIP 提供语义证据），体现了基础模型组合的系统设计合理性。
- **"验证时机 × 验证内容"正交化**：本体感受（何时）与视觉验证（什么）分离，每种验证类型（运动学 vs 语义）使用最适合的冻结模型处理，形成清晰的解耦。
- **设计高度务实且通用**：一套超参数贯穿所有任务、重复次数和骨干；恢复感知的 rollback（可回滚任务回滚恢复，不可逆任务宽松接受）是对两类错误成本的合理把握；防护机制（带界重试，超时终止前自检）能够处理边缘情况，避免死锁。
- **实验严谨度高**：分离了训练/验证种子、双控制器采样覆盖失败分布、消融控制了阈值开关、受控比较（验证 vs 尝试 vs 全指令）隔离了机制贡献。
- **真实性验证到位**：实体机器人上从遥操作→自动分割→两骨干微调→故障安全分布式推理→离线重放→对标评估，流程完整，超出论文常规水平。

### 8. 不足与局限

- **验证词汇量锚定在夹爪交互上**：论文未涉及推动、滑动、铰接物体操作、持续夹持下工具使用等低水平技能，因为这类技能不会产生兼容事件；框架只针对夹爪交互类子目标提供验证，其他子目标回退到裸策略（这正是 SwingXTimes/StopCube 仅为复现水平的原因）。
- **任务是顺序、图形非序列**：无法表达分支规划、部分有序子目标或可在任意顺序下满足的子目标；rollback 只能处理到本轮所选对象的匹配。恢复方式也是"子目标类型"固定属性，无法对场景实时状态进行动态解释。
- **有限重试会引入一个新的故障模式**：重试上限是通过推进未经验证的子目标来换取活性，这本身可以造成进度错误；AGM 只能保证未经验证的写入"少而有限"，不能杜绝。
- **验证本身是性能天花板**：误拒会重复已完成子目标并耗尽预算，误纳则会导致已发生的行为失效。在不可逆放置分支上论文坦率承认验证头不具备可靠的判别力（4 个阴性样本全被漏判），只能用宽松阈值加约束管理。
- **物理评估场景较窄**：单平台，夹爪几何为 6DoF，单一物体类（26mm 彩色塑料方块）；框架可迁移，但对跨平台转移没有保证校准阈值通用性，论文明确承认需按平台重新校准。
- **算力消耗信息不完整**：未报告 GPU 型号/数量/训练时长，物理平台策略微调的计算资源需求无法准确评估。
- **对容器放置验证头输入差异**：用滞后 20 帧投放后视野的中配置，BinFill 从 84% 降到 66%，这可能降低基于视觉时间对齐的结论在容器任务上过度依赖训练窗口精确对齐的推广能力。
- **论文提出了 π0 骨干独立训练，非官方 checkpoint 对比公平性有限**：这已在正文中注明，但对基线的绝对公平性产生了一定影响。
- **BinFill 长尾重复出现退化**：尽管指针跟踪正确，N=4/5 仍存在物理困难（容器装满后放置困难），算法无法消除物理层面的极限。

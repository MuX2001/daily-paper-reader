## 摘要
传统的基于流的视觉-语言-动作（VLA）模型支持表达连续的动态动作生成，但依赖多步细化来生成每个动作块，从而增加了在线机器人控制中的延迟。为解决这一问题，我们引入了DriftingVLA，一种原生一步VLA，通过单次动作专家前向传播即可生成完整的动作块。DriftingVLA并非学习在推理时需要迭代积分的流场，而是使用分布漂移目标来学习直接从噪声到动作块的映射，以实现一步部署。由于机器人动作维度携带不同的控制语义和分布特征，我们进一步引入了逐维度时间漂移（PDTD）。PDTD将每个动作维度的完整时间轨迹视为独立的漂移单元，从而实现对维度特定动作分布的更细粒度建模和塑造。这种逐维度分解仅应用于训练目标；共享的VLA模型仍然联合生成完整的动作块，从而保留跨维度的依赖性。DriftingVLA在LIBERO上实现了98.32%的成功率，在RoboTwin 2.0上实现了81.09%的成功率，并在六个真实世界的单臂和双臂任务中实现了77.67%的成功率，超过了所评估的多步流策略和一步VLA基线。原生一步部署还将动作块生成速度提升了3.36倍，无需迭代细化即可保持控制性能。

## Abstract
Conventional flow-based vision-language-action (VLA) models support expressive continuous action generation but rely on multi-step refinement to produce each action chunk, increasing latency in online robot control. To address this issue, we introduce DriftingVLA, a native one-step VLA that generates a complete action chunk with a single action-expert forward pass. Rather than learning a flow field that requires iterative integration at inference, DriftingVLA uses a distribution-drifting objective to learn a direct noise-to-action-chunk mapping for one-step deployment. Since robot action dimensions carry distinct control semantics and distributional characteristics, we further introduce Per-Dimension Temporal Drifting (PDTD). PDTD treats the complete temporal trajectory of each action dimension as a separate drifting unit, enabling finer-grained modeling and shaping of dimension-specific action distributions. This per-dimension decomposition applies only to the training objective; the shared VLA model still generates the complete action chunk jointly, thereby preserving cross-dimensional dependencies. DriftingVLA achieves 98.32% success on LIBERO, 81.09% on RoboTwin 2.0, and 77.67% across six real-world single- and dual-arm tasks, outperforming the evaluated multi-step flow policy and one-step VLA baselines. Native one-step deployment also delivers a 3.36-fold speedup in action-chunk generation, eliminating iterative refinement without sacrificing control performance.

## 1. 论文的核心问题与整体含义

- **背景**：视觉-语言-动作（VLA）模型利用大规模预训练视觉-语言模型与动作专家模块相结合，实现从感知到控制的端到端映射。面向机器人控制，动作为时间序列上的连续值，因此需要模型具备生成连续动作分布的能力。
- **核心痛点**：当前主流的**基于流（Flow-based）的 VLA 模型**（如 π0、CogACT等）虽然能表达复杂的连续动作分布，但推理时需要通过多步细化（iterative refinement，例如推理 10 步）逐步求解流场积分，才能生成一个动作块。这一多步迭代过程显著增加了在线控制中的端到端延迟，严重制约了高频实时控制场景下的部署。
- **核心研究问题**：能否在**保留连续动作表达能力的前提下**，实现动作块的**原生一步生成**，从而显著缩短推理时延？（即训练时以分布目标对齐噪声与动作，而在推理时单步完成噪声到动作的映射）
- **整体意义**：DriftingVLA 作为原生一步 VLA 的早期尝试，在模拟基准和多种真实操作任务上均显著超越了多步流策略，证明一步生成不仅能降低延迟，甚至可以通过恰当的训练目标获得更强的性能。这为低延迟 VLA 架构与训练范式提供了新的可能性，推动了机器人 VLA 从「多步迭代」走向「一步即时」的部署可行性。

## 2. 论文提出的方法论

**核心思想**：DriftingVLA 使用**分布漂移目标（distribution drifting objective）**——一种非迭代的生成目标（可理解为概率流 ODE 在时间起始日一侧的确定性映射），替代传统流匹配（Flow Matching）中的条件向量场回归目标——学习一个从随机噪声到动作块的**直接映射**。这使得训练完成后可以单次前向传播直接输出完整动作块。

**关键技术细节**：

1. **动作专家采用 DiT（Diffusion Transformer）架构**，支持多模态动作分布建模。
2. 分布漂移目标将每个动作维度的完整时间轨迹视为独立漂移单元（对应分布漂移理论中各边缘分布的变化路径），以最大化轨迹整体观测似然为目标学习噪声到动作块的确定性映射。分布漂移以逐对噪声-动作样本的形式监督训练，模型在给定 VLM 视觉语言上下文条件下学习整体边缘分布转换的方向。
3. **逐维度时间漂移（PDTD, Per-Dimension Temporal Drifting）**：机器人动作的不同维度（如 6D 末端位姿、夹爪开合、双臂的各关节角）携带完全不同的控制语义与分布特征。PDTD 将**每个动作维度各自的完整时间轨迹**视为一个独立的漂移单元进行单独建模和监管。由于共享的 VLA 模型仍然联合预测所有动作维度，从而保留了对跨维度依赖关系的建模能力，因此这种分解**仅存在于训练目标（即损失函数）中，推理时仍一次输出全部维度**。
4. **推理流程**：一个基于流的方法需要在推理时从噪声状态逐一迭代积分；DriftingVLA 在推理时只需一次动作专家前向传播即可获得完整动作块。整个动作块生成仅需一次 VLA 模型调用。

**算法流程（文字描述）**：
1. 训练阶段：给定历史观测与当前观测，VLM 提取上下文特征（语言 + 视觉）；
2. 动作专家以随机噪声为初始 token，通过分布漂移目标迭代优化其参数，学习一个从噪声到动作块的一步映射场（直接映射动作块的条件均值）；
3. PDTD 把动作块按维度拆分出各维时间轨迹，把每一维的轨迹当作一个独立的漂移单元，并以逐维漂移损失加权回传更新共享的动作专家；
4. 推理阶段：从训练分布中采样噪声，直接得到整体动作块输出，无需迭代。

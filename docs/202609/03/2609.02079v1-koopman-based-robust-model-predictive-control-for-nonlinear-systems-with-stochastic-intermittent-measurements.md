## 摘要
间歇性状态测量对约束非线性系统的模型预测控制构成根本性挑战，因为反馈中断期间预测不确定性增长，且测量触发的重置会干扰标称状态传播，可能危及闭环稳定性与递归可行性。本文开发了一种基于Koopman的随机MPC框架，采用概率截断的软约束。具体而言，一个Lipschitz约束的深度Koopman模型提供线性潜变量预测器，从而实现计算高效的在线优化。间歇测量过程被建模为双模式离散时间马尔可夫链，为开环传播和测量触发的重置建立了统一的马尔可夫跳跃误差模型。在数值可验证的充分条件下，预测误差被证明是均方最终有界的，并获得了显式的均匀二阶矩界。随后针对指定置信水平构造了无分布概率误差半径，用于截断依赖于丢失率的约束收紧。一种精确罚软约束机制适应了重置引起的跳跃和长时间丢失。在所述终端相容性和有界扰动条件下，建立了闭环调节误差的递归可行性和均方最终有界性。视觉伺服跟踪任务的数值模拟验证了这些理论结果，并展示了在随机测量不可用情况下的有效跟踪。

## Abstract
Intermittent state measurements pose fundamental challenges to model predictive control of constrained nonlinear systems because prediction uncertainty grows during feedback outages and measurement-triggered resets disrupt nominal state propagation, potentially compromising closed-loop stability and recursive feasibility. This paper develops a Koopman-based stochastic MPC framework with probabilistically truncated soft constraints. Specifically, a Lipschitz-constrained deep Koopman model provides a linear latent predictor, enabling computationally efficient online optimization. The intermittent measurement process is modeled as a two-mode discrete-time Markov chain, yielding a unified Markov jump error model for open-loop propagation and measurement-triggered resets. Under numerically verifiable sufficient conditions, the prediction error is shown to be mean-square ultimately bounded, and an explicit uniform second-moment bound is obtained. A distribution-free probabilistic error radius is then constructed for a prescribed confidence level and used to truncate dropout-dependent constraint tightening. An exact-penalty soft-constraint mechanism accommodates reset-induced jumps and prolonged dropouts. Under the stated terminal compatibility and bounded-disturbance conditions, recursive feasibility and mean-square ultimate boundedness of the closed-loop regulation error are established. Numerical simulations on a visual-servoing tracking task corroborate these theoretical results and demonstrate effective tracking under stochastic measurement unavailability.

## 2. 提出的方法论

### 2.1 核心思想

将非线性系统通过 Lipschitz 约束的深度 Koopman 网络提升到高维线性潜空间，把间歇测量过程建模为二元马尔可夫链，由此得到统一的马尔可夫跳变误差系统；并在该误差系统的均方最终有界性分析基础上，构造分布自由的概率安全半径，设计“概率截断+精确惩罚软约束”的 MPC 问题。

### 2.2 模型构建

- **真实系统**：离散时间非线性动力学  
  \[
  x_{k+1} = F(x_k, u_k) + w_k
  \]  
  其中 \(w_k\) 为有界截断高斯扰动。

- **深度 Koopman 编码器**：
  - 潜状态为 \(z_k = \mathrm{Encoder}(x_k) = [x_k^T, \psi(x_k)^T]^T\)，保留原始状态的恒等映射。
  - 对 MLP 特征映射施加全谱归一化，限制 Lipschitz 常数 \(L_\psi \le 1\)。
  - 训练损失包含：多步预测损失、特征值惩罚（促使系统矩阵 Schur 稳定）、正交正则化（抑制非正常瞬态放大）。
  - 得到线性潜空间标称模型
  \[
  z_{k+1} = A z_k + B u_k
  \]
  - 采用常数投影矩阵 \(C = [I_{n_x}, 0]\) 直接从潜状态重构原状态。

- **误差与不确定性建模**：
  - **状态漂移**有界半径 \(r_w\)；**传感器噪声**有界半径 \(r_{\text{sensor}}\)。
  - 通过 Lipschitz 连续性，将状态空间误差界映射为潜空间误差界，得到：
    - 动态扰动集 \(D\)：半径 \(\sqrt{2}r_w + \varepsilon_{\text{model}}\)
    - 重置噪声集 \(E_0\)：半径 \(\sqrt{2}r_{\text{sensor}}\)
    - 预测误差包络 \(E_{z,i}\)：半径 \(\sqrt{2}r_{x,i} + \varepsilon_{\text{rec}}\)

### 2.3 间歇测量建模与马尔可夫跳变误差系统

- 测量模式 \(\theta_k \in \{0,1\}\) 为离散时间马尔可夫链：
  - \(\theta=0\)：测量可用但有噪声；
  - \(\theta=1\)：测量不可用；
  - 转移概率 \(p_{ij} = \Pr(\theta_{k+1}=j \mid \theta_k=i)\)。
- 两种情形：
  - 测量恢复 (\(\theta_{k+1}=0\))：用编码器重置标称状态，误差被清零，只剩重置噪声 \(v_{k+1}\)。
  - 测量丢失 (\(\theta_{k+1}=1\))：标称模型开环传播，误差按 \(e_{k+1} = A e_k + d_k\) 演化。
- 将两者统一为马尔可夫跳变误差系统：
  \[
  e_{k+1} = A(\theta_{k+1}) e_k + w(\theta_{k+1}, k)
  \]
  其中系统矩阵取决于下一个时刻的模式，体现了“测量触发重置”。

### 2.4 理论分析

- **预测误差均方最终有界（MSUB）**：
  - 构造模式依赖的随机二次 Lyapunov 函数 \(V(e_k, \theta_k) = e_k^T P(\theta_k) e_k\)。
  - 用 Young 不等式处理状态相关扰动造成的交叉项。
  - 导出耦合 LMI：
    \[
    p_{i1}(1+\zeta) A^T P(1) A - P(i) \prec 0, \quad i \in \{0,1\}
    \]
  - 定理 1 证明：若 \(A\) Schur 稳定且 \(p_{11} < 1\)，则误差序列全局 MSUB，得到稳态均方极限上界
    \[
    \limsup_{k\to\infty} E[\|e_k\|^2] \le \frac{c_2 M_w}{c_1 \alpha} \triangleq E_\infty^2
    \]

- **概率安全半径**：
  - 状态空间误差期望平方界 \(\bar{E}_x^2\) 可由潜空间 MSUB 界推出；
  - 对非负随机变量应用 Markov 不等式，得到无分布概率半径
    \[
    R_{\text{prob}} = \frac{\bar{E}_x}{\sqrt{1-p}}
    \]

- **概率截断软约束 MPC**：
  - 定义丢包持续 \(l\) 步后的确定性误差集 \(R_l = C A^l E_0 \oplus \bigoplus_{j=0}^{l-1} C A^j D\)；
  - 按每个坐标轴计算收紧量 \(\Delta X_l^{(j)}\)；
  - 为避免长时间丢包导致约束过紧甚至不可行，将递增长期收紧量与常数概率半径取最小值截断：
    \[
    \Delta X_i^{*(j)} = \min(\Delta X_{l_k+i}^{(j)}, R_{\text{prob}})
    \]
  - 引入非负松弛变量 \(\epsilon\)、\(\epsilon_{\text{init}}\) 与精确惩罚项，构造软约束凸 QP；
  - 终端集要求满足状态相容性、正不变性与控制可行性等条件。

- **主定理（定理 2）**：在终端相容性与有界扰动条件下，证明：
  1. 递归可行性；
  2. 最优值函数满足期望耗散不等式；
  3. 闭环跟踪误差达到 MSUB，且单步边际违反概率满足
     \[
     \Pr(\|C z_{\text{true},k} - C\bar{z}_k\|_2 \ge R_{\text{prob}}) \le 1-p
     \]

论文还讨论了有限初始瞬态与稳态界的合并，使概率界在任意时间步统一成立。

3. **对比方法偏弱且不全面**：仅与 PD+ZOH 基线比较，未与鲁棒 NMPC、tube-MPC、基于标准 Koopman 的 MPC 等其他主流方法对比，公平性较高但说服力有限。
4. **缺少消融研究**：未揭示每个组件（概率截断、精确罚软约束、Lipschitz 正则化、正交惩罚、终端相容性等）相对贡献的敏感性。
5. **理论假设较强**：需要模型残差有界、传感器噪声有界、转移概率 \(p_{11}<1\) 且满足可行域约束（\(p_{11} \le 1 - 1/l_{\max}\)）等。实际系统中这些常数界可能难以精确估计，过度保守或估计不准都会影响理论保证。

### 总体评述

总体来看，该文在“间歇测量下的非线性约束 MPC”这一交叉问题上，构建了一个理论闭环较完整、在线计算仍保持为凸 QP 的解决方案。其核心贡献在于：用马尔可夫跳变误差系统统一刻画测量可用性切换带来的预测误差累积与重置现象，并通过均方最终有界分析与 Markov 不等式给出无分布的概率安全半径，为带丢包的非线性控制系统提供了可证明可行的随机 MPC 设计范式。同时，深度 Koopman 网络以 Lipschitz 约束和 Schur 稳定正则化保证了潜空间线性模型的可控误差界，使“学习建模 + 概率约束 + 软约束重置”能够协同工作。

然而，论文在实验验证上仍存在明显不足：仿真场景单一、缺少真实物理实验、对比方法和消融实验不充分，导致各设计模块的实际贡献与适用范围不够清晰。理论方面，概率界为逐时步边际界而非联合界，多个有界性假设在真实系统中也难以精确标定，因而从“理论保证”走向“工程保证”仍有距离。

总体而言，该文对研究切换控制、网络化 MPC、Koopman 算子控制以及概率安全控制的研究者具有较好的参考价值，尤其值得关注其马尔可夫跳变误差建模与概率截断处理技巧。但若要部署到真实视觉伺服或通信受限系统，还需要在不同非线性系统上开展更广泛的验证，并进一步削弱关键假设、提高边界的可计算性与紧致性。

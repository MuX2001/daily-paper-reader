## 摘要
视觉-语言-动作（VLA）模型直接将视觉观察和语言指令映射为机器人动作，但长期任务需要的不只是动作预测。智能体必须在物理状态演化过程中协调感知、规划、执行、进度验证和恢复。动作预测或模型生成的技能决策本身并不能保证所提议的操作在当前状态下有效，也不能保证其结果将得到验证。我们提出EmbodiedSkills，这是一个统一框架，将每个技能决策视为执行提议：运行时在执行前检查其前提条件，并在执行后验证结果。一个共享的可执行技能接口将高层技能选择、有界的低层VLA执行和动作后验证连接在同一个智能体循环中。由于该接口保持固定，低层VLA策略可以被替换或调整，而无需改变智能体循环。该接口还将规划、执行、验证和恢复事件记录为结构化轨迹，为各个组件提供监督，并在交互式反馈可用时支持可选的在线适应。我们在RoboTwin 2.0和LIBERO上使用Qwen3-VL和OpenPI/pi0.5实现了EmbodiedSkills。任务自适应的低层VLA策略在50个RoboTwin 2.0任务中平均成功率达到86.20%，在四个LIBERO套件中平均成功率达到97.40%。这些结果确立了EmbodiedSkills中使用的任务自适应低层VLA策略的执行性能。在四个依赖记忆的RMBench任务上，相同的任务自适应执行方法平均成功率达到12.5%。该框架提供了一个可训练和可检查的智能体层，将这些策略转化为闭环具身系统。

## Abstract
Vision-language-action (VLA) models map visual observations and language instructions directly to robot actions, but long-horizon tasks require more than action prediction. An agent must coordinate perception, planning, execution, progress verification, and recovery as the physical state evolves. An action prediction or a model-generated skill decision does not, by itself, guarantee that the proposed operation is valid in the current state or that its outcome will be verified. We propose EmbodiedSkills, a unified framework that treats each skill decision as an execution proposal: the runtime checks its prerequisites before execution and verifies the outcome afterward. A shared executable-skill interface connects high-level skill selection, bounded low-level VLA execution, and post-action verification within a single agent loop. Because this interface remains fixed, low-level VLA policies can be replaced or adapted without changing the agent loop. The interface also records planning, execution, verification, and recovery events as structured trajectories, which provide supervision for individual components and can support optional online adaptation when interactive feedback is available. We instantiate EmbodiedSkills with Qwen3-VL and OpenPI/pi0.5 on RoboTwin 2.0 and LIBERO. Task-adapted low-level VLA policies achieve an average success rate of 86.20% across 50 RoboTwin 2.0 tasks and 97.40% across the four LIBERO suites. These results establish the execution performance of the task-adapted low-level VLA policies used in EmbodiedSkills. On four memory-dependent RMBench tasks, the same task-adapted execution approach achieves 12.5% average success. The framework provides a trainable and inspectable agent layer for turning these policies into closed-loop embodied systems.

## 1. 核心问题与研究动机

长期（long-horizon）机器人操作任务远不止"预测下一个动作"这么简单。当一个机器人被要求"将容器放到盘子上"时，它需要：

- **感知场景**：识别与任务相关的对象及其状态；
- **规划与子目标选择**：将高层任务分解为可执行的子目标；
- **执行前验证**：判断当前子目标在物理状态下是否具备可执行性；
- **底层动作生成**：通过 VLA 策略产生动作；
- **执行后验证**：确认动作是否真正让任务向目标推进；
- **失败恢复**：当感知或执行失败时，能够及时修正并重试。

现有方法面临核心痛点：
- 端到端 VLA 策略将中间任务决策隐式化，一旦任务失败，难以定位问题源头（对象定位误差？子目标选择错误？动作执行失败？验证错误？恢复失败？）。
- 基于 LLM 的机器人智能体虽能显式生成推理步骤和工具调用，但"显式决策"不等于"当前状态下物理上可行、语义上正确"。模型可能生成与当前阶段不兼容的技能、依赖过时观测、遗漏必要参数，甚至执行后未产生预期效果。

因此，论文的核心挑战在于：**如何在模型级决策与物理执行之间建立桥梁**——使得提议的每个操作在执行前经过合法性检查、执行后验证其结果、由此产生的证据反馈给后续决策与学习过程。

## 2. 方法论

### 2.1 总体设计思想

EmbodiedSkills 提出一种**技能导向的闭环智能体框架**，将 VLA 策略塑造成闭环具身系统。其核心主张是：将每次技能决策视为**执行提案（execution proposal）**——由运行时统一管理，不再一次性从左到右执行。

框架由两条主构成要素共同工作：
- **高层智能体策略**：提出结构化技能调用；例如规划、选址、验证、恢复等。
- **守护运行时层（Guarded Runtime）**：负责执行前置校验、物品新鲜度（freshness）检查、动作合理性/合法性检查、合法状态迁移等。

### 2.2 核心概念

#### 状态与决策表示
- **状态：** `st = ( zt, Mt, Ht)`——当前阶段、可用任务工件集合、有序循环轨迹。
- **上下文压缩：** `Ct = Ψ(x, zt, Mt, Ht)`——通过预算机制限制上下文长度，完整的计划、当前子目标与最近决策摘要始终保留。
- **决策类型：** 三种可能的控制输出——`RunSkill(k, q)` 执行某个技能、`AdvanceStage` 推进阶段、`FinishRun` 终止运行。

#### 可执行技能契约
每种技能定义为六元组：`k = (Xk, Yk, pre_k, exec_k, post_k, fail_k)`
- 约束了类型化的输入输出格式；
- 定义前置条件；
- 明确副作用与合法性状态更新的要求；
- 在动态变化环境中执行失效机制——若观测、目标或执行结果变化，仅使依赖该变化的工件失效，其他仍可用。

设计上将"决策"与"状态更新"明确区分。模型决策永远只是"提案"，只有架构正确、依赖条件全部被验证才允许真实执行。失败时则以显式形式进入历史轨迹，供后续决策参考。

### 2.3 六阶段循环

框架定义了六个语义阶段，每个阶段有配套技能集合与对应的退出证据条件，组成有反馈控制的闭环：

| 阶段 | 含义 | 代表性技能/任务 |
|------|------|----------------|
| **Observe** | 采集场景视觉证据与问题相关证据 | 拍照、场景捕捉、物体定位等；    |
| **Plan** | 将任务转化为可验证的子目标序列 | 执行全局规划、选择对象、分预算；  |
| **Preflight** | 检验当前子目标是否可执行 | 刷新观测、校验动作、更新转移条件； |
| **Execute** | 低层 VLA 输出一个 bounded action chunk | 生成动作向量、执行控制、记录报告；|
| **Verify** | 判断子目标推进情况 | 定位、对比场景、评估补偿进展；    |
| **Recover** | 对不可连续失败执行修复 | 构建重试请求、修订子目标、切换阶段后重新进入 |

### 2.4 带守护运行时

定义公式化逻辑区分不同控制路径，执行其独立性检验：
- **技能提议时的前置条件检查：** 判断分段、技能类别及前置条件是否全部满足；
- **阶段推进时的状态完备性检查**；
- **动作块合法性与上下文一致性检查**（控制在最大动作次数内、动作格式合法、新鲜度约束符合要求）。

如果一项操作无法通过校验，则形成带证据的阻断记录，而非被静默跳过或强制执行。这也意味着低层策略如果失败或乱用某操作，绝不会变成"隐性不正确物理状态迁移"。

### 2.5 模块化与训练机制

- 框架中高层模型（例如基于 Qwen3-VL 的高层调度器）与底层 VLA（例如 OpenPI/π0.5）通过同一接口互相解耦，可替换调整而不需要逐环节改写控制流。
- **组件级训练：** 高层规划器可从 (任务、视觉上下文) 映射到语义化子目标序列。VLA 策略仅在子任务级演示上进行微调——观测、状态、活动子目标、行动序列。
- **样本一致性保证：** 训练样本边界与实际部署完全一致。令牌损失仅用于模型产生的结果部分，上下文不作为训练目标，以防读写不一致。
- **在线闭环可选支持：** 在可用交互评估器时可采用带集群归一化的裁剪优化目标——类似 GRPO 的目标函数。在文中其被定位为可选增强方式，而非主线。

## 6. 主要结论与发现

1. **RoboTwin 2.0（任务粒度执行层）：** 任务自适应子目标级微调的 π0.5 策略在 50 个任务平均达到 **成功率为 86.20%**——比 π0.5 参考值（82.74%）提高 +3.46 个百分点。39/50 个任务上超过基线，最难一类的接触敏感型任务进步最大。
2. **LIBERO（横移泛化执行力）：** OpenPI 思想方案下为四个套产生宏均值 **97.40%，在 Long 类套件实现最大提升（92.4→93.6）**——证明短时空间物体能力保持且显著增益更高时序延展性。
3. **RMBench（记忆关键执行接口）：** 同任务自适应序列在四向 memory M(n) 集合平均 **12.5%**。
4. **消融（AgentLoop 机制验证）：** 完整模型（86.2%）、去掉中间验证（48.2%）、去掉子目标准入（34.4%）、禁用反复动作块执行（19.5%）。结论：**语义子目标分解+中间阶段检验+可变条件动作延续是构造闭环智能系统的三种极致要件，缺任一项大幅破坏整体效能**。

5. 统一接口将规划/执行/验证/恢复绑定为一体闭环，VLA 可作为可替换部分，达到模块化→即插即用→可追溯的效果；

## 7. 优点与亮点

- **可解释的闭环架构**：决策能力从执行能力彻底分离。策略"建议动作"并没有被执行的权利；一切决策必须先通过接口、运行时校验，赋予网络非常强的可调试性和回滚能力；
- **问题归因追踪能力**：所有中间决策、工件、阶段性错误、转移与正式结果全部记录到统一轨迹序列中，为后期定位故障环节提供完备纵向依据。
- **高模块化设计**：感知、规划、执行、后台、验证器均可在固定接口下顺利替换微调——不要求一套模型从零学到多任务级系统，使得独立组件适配可以大幅简化，方案极具工程扩充性；
- **动作控制质量扎实可信**：RoboTwin 86.2% 与 LIBERO 97.4% 作为子系统验证数据真实落地可信且属于行业高性能队列——大基线广泛对比鲁棒；
- **面向真实系统结构**：没有把一切交给语言建模"输出即结果"，补上了原生 robot stack 缺少的控制与验证件；
- **可控消融设计**：组合消融路径设置清晰，在语义分解、中间验证及自适应重复的贡献量化上析因到位；结论有很强的可证实性；
- **训练数据分布一致性明确**。

## 8. 不足与局限性

- **任务专用策略不能扩展**（单任务专家化）：50 个任务就有 50 个微调模型——对部署在高时延、大数据环境里的多任务 agent 极不合算，需要高通用型的子目标准策略。
- **实际通用系统性瓶颈未突破**：诚言中承认"声明正确"≠"可执行正确"。任何验证器都会被不可见、遮挡或某依赖信息视觉不可评估的状态卡住；
- **资源开销**：需要大量额外 VLM 推理调用+动作后对环境采集观测反馈才可评估下一步，使端到端直接动作策略出现更高延迟并加重计算成本；
- **RMbench 显示未真正解决基于历史的 "记忆" 复杂操作**（平均 12.5%）。多数M(n)测试反映出，框架在无内存或隐式时序压缩的系统工况下并未做到普适；
- **在线优化机制描述过简**：奖励加权与集群采样模型太简化，缺少执行中可验证的因果分解；暂无对应在线实验结果来支撑这部分算法的可用性与收敛性；
- **开放性问题**：缺少真机/物理世界部署量化、未见开源模型、未能消除外部仓库引用数字可比偏差的风险。

---

## 总结评价

EmbodiedSkills 以**规划—校验—执行—验证—恢复**五者形成的闭环模式，直击纯动作 VLA 在长任务中的 "不可观察、不可解释、不可恢复" 鸿沟。其接口化的思想设计严谨、模块化良好、多基准检验量大，配合直观充实的消融实验和数据非常有说服力。目前实际依然受制于组件模型的级别和精度：高不确定性低层认知或视觉验证一旦误判，上层的合法接口也无法完全自纠。未来工作聚焦**跨任务通用子目标策略、记忆化上下文整合以及低成本部署验证**等领域展开时，框架可成为一种坚实起点。

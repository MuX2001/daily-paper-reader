## 摘要
许多真实世界的机器人应用需要动态敏感的操纵，其成功不仅取决于到达目标状态，还取决于在整个执行过程中保持稳定的物体动力学。我们研究盛液容器的稳定运输，其中机器人必须将物体移动到目标位置，同时抑制液体晃动并防止溢出。与传统抓放任务不同，该任务对运动平滑性和轨迹级稳定性提出了严苛要求，暴露出现有系统的明显局限。具体而言，流体仿真对于在线强化学习而言仍然成本过高；人类遥操作会在模仿学习过程中引入非预期加速度，从而引发液体晃动；而当前策略流水线优化的是任务完成，而非动态稳定性。我们提出一个合成到真实的框架，将经物理验证的数据生成与分层的、基于扩散的控制器相结合。该可扩展数据流水线合成抓取，通过视觉-语言模型过滤不稳定位姿，并通过流体仿真验证运输轨迹。该策略由一个高层模块和一个潜在扩散控制器组成：高层模块将语言和视觉观测转换为 SE(3) 控制目标；潜在扩散控制器首先在紧凑的潜在空间中高效规划，然后解码稠密动作块，从而实现平滑稳定运动所需的高控制频率。大量实验表明，我们的系统在运输平滑性和动态稳定性方面优于最先进的操纵策略。项目主页：https://fetch-my-beer.github.io/

## Abstract
Many real-world robotic applications require dynamically sensitive manipulation, where success depends not only on reaching a target state but on maintaining stable object dynamics throughout execution. We study the stable transport of liquid-filled containers, where a robot must move objects to target locations while suppressing sloshing and preventing spillage. Unlike conventional pick-and-place, this task imposes stringent requirements on motion smoothness and trajectory-level stability, exposing clear limitations in existing systems. Specifically, fluid simulation remains too costly for online reinforcement learning; human teleoperation introduces unintended accelerations that induce sloshing during imitation learning; and current policy pipelines optimize for task completion rather than dynamic stability. We propose a synthetic-to-real framework coupling physically validated data generation with a hierarchical, diffusion-based controller. The scalable data pipeline synthesizes grasps, filters unstable poses via a vision-language model, and validates transport trajectories through fluid simulation. The policy is organized with a high-level module that translates language and visual observations into SE(3) control targets, and a latent diffusion controller that first plans efficiently in a compact latent space and then decodes dense action chunks, enabling the high control frequency needed for smooth and stable motion. Extensive experiments show our system outperforms state-of-the-art manipulation policies in transport smoothness and dynamic stability. Our project page: https://fetch-my-beer.github.io/

  - **模仿学习（IL）/遥操作**：人工遥操作在动态敏感任务中极易引入非预期加速度，本身就制造晃动，数据采集既昂贵又不可靠。
  - **现有合成数据管线**（RoboTwin、ManiSkill 等）：主要优化刚体任务完成度与几何可行性（碰撞避免、可达性），**忽视轨迹级运动稳定性与平滑性**。
  - **策略侧**：扩散视觉运动策略（Diffusion Policy）与 VLA 模型（π0、π0.5、OpenVLA 等）擅长通用操作基准，但优化的是几何精度而非动态稳定性；扁平端到端架构难以同时兼顾语义推理、长时程规划与高频平滑控制。

## 2. 方法论

### 2.1 核心思想

提出**合成到真实（synthetic-to-real）框架**，由两部分组成：
1. **物理验证的可扩展数据生成管线**（保证数据本身满足几何可行 + 轨迹级动态稳定）；
2. **分层潜在扩散控制架构**（将低频语义推理与高频平滑控制解耦）。

### 2.2 数据生成管线（Isaac Sim 中实现，见图 2）

- **场景与物体采样**：多样杯体资产（Isaac Sim + Objaverse）、随机桌面纹理与场景设置。
- **抓取提案生成**：使用 AnyGrasp 从分割点云生成多组 6-DoF 抓取候选，保留多样候选而非直接取几何最优，以便后续按任务级可行性和轨迹可行性筛选。
- **VLM 过滤**：使用 **Qwen3-VL** 作为可行性过滤器。由于 VLM 只接受 2D 输入，将简化夹爪网格投影渲染到场景图像上，可视化夹爪–物体交互；VLM 输出置信度分数与简短理由，剔除碰撞桌面、插入容器内部、接近方向不可行、接触不稳定区域或导致不利运输姿态的候选。
- **平滑轨迹规划**：使用 **cuRobo**（CUDA 加速）做 IK 与轨迹优化；对每个选定抓取随机采样多个放置位姿，按 IK 可行性、碰撞避免和轨迹代价选择最优轨迹。
- **稳定性过滤（两级）**：
  - **规则筛查**：监控 Z 轴杯体倾角，剔除偏离竖直方向超过 **15°** 的轨迹（轻量预筛）。
  - **物理流体仿真**：用 Isaac Sim 中的 **Position Based Dynamics（PBD）** 粒子流体求解器验证，剔除"容器基本竖直但因速度突变、高加速度或抖动导致剧烈晃动/溢出"的轨迹——这是倾角启发式无法捕捉的。
- 仅通过双重过滤的轨迹被存为示范数据。

### 2.3 分层潜在扩散策略（见图 3）

**高层关键帧位姿预测策略**：π_H 将语言指令 *l* 与多视角 RGB-D 观测 *O_t* 映射为下一个关键帧末端位姿 **P_goal ∈ SE(3)**（抓取位姿与放置位姿），即 *P_goal = π_H(O_t, l)*。采用 **RVT-2** 原架构（虚拟视角重渲染 + 多阶段细化）。关键帧标注直接从数据生成中成功抓取/放置事件的末端位姿记录，无需人工标注或速度后处理。

**低层潜在扩散策略（LDP）**：
- **动机**：直接在原始动作空间扩散稠密动作块计算开销大，且相邻块间的不一致会导致振荡运动，增加洒溅风险。
- **动作自编码器（VAE）**：
  - 编码器 E_ψ 将稠密动作块 *a ∈ R^{T×D_a}* 压缩为对角高斯后验 *q_ψ(z|a) = N(μ_ψ(a), diag(σ²_ψ(a)))*，其中 *z ∈ R^{T′×D_z}*，*T′ < T*，*D_z < D_a*。
  - 轻量 MLP 解码器 D_φ 重建 *â = D_φ(z̃)*。
  - 损失 *L_AE = λ₁‖a−â‖₁ + λ₂‖a−â‖₂² + λ_KL·D_KL(q_ψ(z|a)‖N(0,I))*。
  - 具体配置：32×10 动作块 → 8×8 潜动作表示。
- **潜在扩散**：以编码器后验均值 *z₀ = μ_ψ(a)* 作为扩散干净目标；条件上下文 *c = {o^{rgb}_{t−h:t}, o^{prop}_{t−l:t}, P_goal}*（短时 RGB 视觉反馈 + 较长本体感受历史 + 高层目标位姿）。采用 DDPM：*z_k = √(ᾱ_k)z₀ + √(1−ᾱ_k)ε*，用 1D U-Net 噪声预测网络 ϵ_θ 最小化 *L_LDP = E‖ε − ϵ_θ(z_k, c, k)‖₂²*。
- **推理**：从 *z_K ~ N(0,I)* 迭代去噪 K 步得到 *ẑ₀*，再经解码器生成稠密动作块；沿用 ACT 的**时序集成（temporal ensemble）**，对重叠预测按指数衰减权重聚合，减少块边界不连续。
- 推理效率：LDP 300M 参数、93.94 ms/次推理、1.19 GB 峰值显存；原始动作空间 DP 为 330M、107.06 ms、1.33 GB，**延迟降低 12.3%、显存降低 10.5%**。

## 3. 实验设计

- **Benchmark**：自建的液体运输基准（基于上述合成管线构建）——机器人需抓取盛液容器、运输至指定目标平台并成功放置，同时抑制晃动与溢出。引入**抬高目标平台**以增加空间难度并评估跨高度变化的稳定运输。
- **数据规模**：**12 种场景变体 × 每场景 100 条示范 = 1200 条训练回合**；物体来自 Isaac Sim 与 Objaverse，涵盖不同材质、形状、外观，桌面纹理与场景随机化。
- **评测划分（4 个 split，每 split 50 个配置）**：
  1. In-domain（训练分布内）；
  2. OOD-Object（未见杯体实例）；
  3. OOD-Scene（未见桌面纹理与背景）；
  4. OOD-Object+Scene（复合分布偏移）。
  所有评测使用固定初始化，报告 3 个随机种子的结果。
- **对比基线**：
  - **RVT-2 + DP**：共享同一高层模块，但低层替换为原始动作空间的标准 Diffusion Policy（隔离潜空间设计的贡献）；
  - **π0.5（few-shot）**：预训练通用 VLA 模型在 10% 训练数据上微调；
  - **π0.5（full data）**：在完整训练集上微调（检验单体 VLA 能否达到同等稳定性与平滑性）。
- **评测指标**（后三项仅在成功回合上计算）：
  - **SR（成功率，%）**：抓取→运输→放置成功且流体损失 < 总粒子数 5%；
  - **OE（姿态误差，rad·s）**：*E_orient = ∫₀ᵀ θ_tilt(t) dt*，杯轴与全局竖直方向夹角的时间累积；
  - **MTA（最大倾角，°）**：*θ_max = max_{t∈[0,T]} θ_tilt(t)*，捕捉被累积量平均掉的瞬态不稳定；
  - **TS（轨迹平滑度，m²/s⁶）**：末端执行器 jerk 的平均平方 *J = (1/T)∫₀ᵀ‖x⃛(t)‖₂²dt*。
- **真实世界实验**：KUKA LBR iiwa 14 R820 + Robotiq 2F-140 夹爪，两台 ZED 2i RGB-D 相机（前视 + 腕部）；采用**延迟感知异步执行策略**（执行当前动作块时并行推理下一块，丢弃已过时的时间步动作，并做时序集成）；测试玻璃/塑料/金属等多样杯体，每策略 30 次真实试验；**完全零样本 sim-to-real，无任何真实数据、微调或适配**。

## 6. 主要结论与发现

- **仿真 In-domain**：本文方法全面最优，SR 80.23%，较 RVT-2+DP 提升 **10.49%**，且 OE、MTA、TS 均更低，说明在紧凑潜空间生成低层运动优于直接扩散稠密原始动作。
- **仿真 OOD**：在 4 个划分中 SR 均最高；在最难的 OOD-Object+Scene 下较 RVT-2+DP 提升 **21.66%**。VLA 基线在动态敏感场景下明显落后（few-shot 近乎失效，full-data 仍远低于分层方法），说明**通用 VLA 先验不足以实现稳定操作**，单体端到端动作学习即便有任务专用示范也很困难。
- **真实世界**：本文方法 SR 73.33%、TS 50.73，优于 RVT-2+DP（50.00 / 63.46）与 π0.5 full-data（36.67 / 150.58），验证了**纯合成、稳定性感知示范的零样本 sim-to-real 迁移能力**。
- **消融结论**：
  - 去除稳定性数据过滤会同时降低成功率和稳定性 → 几何与运动学可行性不足以保证动态稳定；
  - 去除高层关键帧策略（LDP-only）性能大幅下降 → 语义推理与运动生成解耦是必要的；
  - 本体感受历史 Hist-20 优于 Hist-4/Hist-12 → 长时程上下文对分布偏移下的执行很关键；
  - 去除时序集成导致最严重的性能退化（SR 降至 18.37%，TS 升至 218.47）→ 该组件对抑制块边界突变、避免诱发洒溅至关重要。

## 7. 优点

- **问题选择有价值且界定清晰**：把"动态敏感操作"从通用抓放中区分出来，用倾倒/晃动这一可量化的物理现象作为失败模式，任务定义与评测指标一致。
- **数据侧引入物理闭环验证**：不止于几何可行性，用 PBD 流体仿真做轨迹级筛选，弥补了"倾角规则筛不掉速度突变型晃动"的盲区，是提升数据质量的关键设计。
- **巧用 VLM 做常识性可行性筛选**：把 6-DoF 抓取以渲染投影方式转成 VLM 可读的 2D 输入，用视觉语言模型的常识判断过滤"几何可达但运输不利"的抓取，思路新颖且实现代价低。
- **架构解耦合理**：高层（低频语义/子目标）与低层（高频平滑控制）分离，潜空间扩散兼顾生成灵活性与推理效率（延迟与显存双降），时序集成进一步保证执行连续性。
- **评测指标设计全面**：SR 之外补充 OE（累积）、MTA（最坏情形）、TS（jerk 平方均值），从平均与瞬态两个角度刻画稳定性，避免只看成功率掩盖动态缺陷。
- **零样本 sim-to-real 的实证**：所有真实实验策略均无真实数据/微调，结论更具说服力；真实平台还采用了延迟感知异步执行来处理推理停顿对液体运输的伤害。

## 8. 不足与局限

- **任务覆盖面窄**：仅在"液体容器搬运"这一任务族上验证，论文自述未来工作才扩展到其他动态敏感任务（易碎/可变形物体等）；结论的普适性尚未证明。
- **算力信息不透明**：未报告 GPU 数量、训练时长、数据生成（含流体仿真）的总开销，难以评估方法在资源受限场景下的可复制性与成本效益。
- **真实实验规模偏小**：每策略 30 次试验、未给出方差或统计显著性检验；且排除了 π0.5 few-shot，比较集合不完整。

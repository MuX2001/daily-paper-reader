## 摘要
本文研究了由四旋翼作为无人机和机械臂作为操作器组成的空中机械臂系统的数学建模与控制问题。通过将整体质心速度和系统姿态作为约束条件，建立了动力学模型，得到了两个解耦的子系统：锁定（整体平移）子系统和形状空间（驱动或整体旋转）子系统，两者均受外部扰动影响。由于系统是机械耦合的，出现了一个关键挑战：第一个子系统中的恒定有界扰动在第二个子系统中表现为时变的、状态相关的扰动。鉴于四旋翼本身具有不稳定性，如果这些扰动和耦合效应未得到有效管理，飞行中机械臂（RM）的运动可能进一步危及整个四旋翼-机械臂（QRM）系统的稳定性。为此，我们提出了一种基于连续非线性扰动观测器的反馈控制律，能够独立控制每个子系统，同时系统性地消除交叉耦合效应。通过多个模拟实际运行条件的仿真验证了所提出控制器的有效性，从而证实了其现实适用性并突出了本工作的核心贡献。

## Abstract
This paper addresses the mathematical modeling and control of an aerial manipulator system comprising a quadrotor as the uncrewed aerial vehicle and a robotic arm as the manipulator. The dynamic model is established by identifying the overall center-of-mass velocity and the system's orientation as constraints, yielding a simplified, two-decoupled subsystems: a locked (overall translation) subsystem and a shape-space (actuation or overall rotation) subsystem, both subjected to external disturbances. Since the system is mechanically coupled, a critical challenge arises where constant bounded disturbances in the first subsystem manifest as time-varying, state-dependent disturbances in the second subsystem. Given that the quadrotor is inherently unstable, the movement of the robotic manipulator (RM) during flight can further jeopardize the stability of the entire QRM system if these disturbances and coupling effects are not effectively managed. To address this, we present a continuous nonlinear disturbance observer-based feedback control law, which enables the independent control of each subsystem while systematically eliminating cross-coupling effects. The efficacy of the proposed controller is validated through multiple simulations emulating practical operating conditions, thereby substantiating its real-world applicability and highlighting the core contributions of this work.

## 2. 方法论：核心思想、关键技术细节与算法流程

- **建模方法：被动分解（Passive Decomposition）**
  - 在构型流形 \(M = R^3 \times SO(3) \times S^2\) 上建立系统的 Euler-Lagrange 动力学；

    \[

    1. **锁定子系统（平移/质心）**：
       \[
       m_{qm}\ddot{\eta}_{qm} + G_L = \tau_L + \tau_{dL}
       \]
    2. **形状子系统（姿态 + 关节角）**：
       \[
       M_S(\zeta)\ddot{\zeta} + C_S(\zeta,\dot{\zeta})\dot{\zeta} = \tau_S + N(\zeta)^\top\tau_{dL}
       \]
- **扰动传播分析**
  - 仅假设外部常值扰动 \(\tau_{dL}\) 作用在四旋翼平移通道；
  - 通过耦合矩阵 \(N(\zeta)\)，该扰动以 \(N^\top\tau_{dL}\) 形式传播到内部姿态与关节角子系统；
  - 通过理论推导（Claim 1）给出 \(\|N\|^2\) 的上界：
    \[
    0 \le \|N\|^2 \le \frac{5m_1^2l^2}{4m_{qm}^2}
    \]
    该上界在后续稳定性证明中用于确定扰动观测器增益条件。
- **控制器设计：连续非线性扰动观测器反馈控制（NDOBC）**
  - 定义滤波器变量：
    \[
    S_l = e_{x2} + \lambda_l e_{x1}, \quad S_s = e_{y2} + \lambda_s e_{y1}
    \]
  - **扰动观测器**（针对锁定子系统的未知常值扰动）：
    \[
    \hat{\tau}_{dL} = z + \gamma_l m_{qm}S_l
    \]
    \[
    \dot{z} = -\gamma_l(\tau_L - G_L - m_{qm}\ddot{x}_{1d} + \hat{\tau}_{dL} + m_{qm}\lambda_l\dot{e}_{x1})
    \]
    ——观测误差收敛为 \(\dot{\tilde{\tau}}_{dL} = -\gamma_l \tilde{\tau}_{dL}\)（指数收敛）。
  - **锁定子系统控制律**（虚拟控制力，经推力映射为实际推力）：
    \[
    \tau_L = u_{ct} = G_L - \hat{\tau}_{dL} + m_{qm}\ddot{x}_{1d} - m_{qm}\lambda_l\dot{e}_{x1} - K_l S_l
    \]
  - **期望姿态生成**：利用欠驱动四旋翼的结构，由虚拟力 \(u_{ct}\) 反解期望横滚角 \(\phi_r^d\) 与俯仰角 \(\phi_p^d\)（式 38–39），期望偏航角可自由设定；
  - **形状子系统控制律**：
    \[
    \tau_S = C_S(y_1,y_2)(-\lambda_s e_{y1} + \dot{y}_{1d}) - N^\top\hat{\tau}_{dL} + M_S\ddot{y}_{1d} - M_S\lambda_s\dot{e}_{y1} - K_s S_s
    \]
    ——其中 \(N^\top\hat{\tau}_{dL}\) 项用于在前馈通道中直接补偿由扰动传播引起的耦合项。
- **稳定性证明（Lyapunov 分析）**
  - 锁定子系统与形状子系统分别构造 Lyapunov 函数，再组合为复合函数；
  - 利用 \(M_S - 2C_S\) 的反对称性、Young 不等式、Rayleigh-Ritz 不等式以及 \(\|N\|\) 的上界；
  - 证明整体误差状态（位置、速度、扰动估计误差）**指数收敛**到零。

## 6. 主要结论与发现

- **解耦是有效的**：在所提出的被动分解框架下，系统质心平移动力学不受机械臂运动所产生惯性耦合力的影响，机械臂的内部运动不构成对四旋翼位置跟踪的结构性扰动；

- **控制信号连续**：与滑模控制方法相比，所提控制器无抖振现象，控制力矩平滑，适合实际执行器；
- **仿真验证**：定点稳定与抓取-搬运-放置任务仿真均展示了良好的跟踪性能与扰动抑制能力，系统能够平滑实现任务切换且保持稳定。

## 摘要
视觉-语言-动作（VLA）模型直接将视觉观察和语言指令映射到机器人动作，但长时程任务需要的不仅仅是动作预测。智能体必须在物理状态演化过程中协调感知、规划、执行、进度验证和恢复。动作预测或模型生成的技能决策本身并不能保证提议的操作在当前状态下有效，也不能保证其执行结果得到验证。我们提出EmbodiedSkills，一个将每个技能决策视为执行提议的统一框架：运行时在执行前检查其前置条件，并在事后验证结果。一个共享的可执行技能接口将高层技能选择、受限的低层VLA执行和动作后验证连接到单一智能体循环中。由于该接口保持固定，低层VLA策略可以在不改变智能体循环的情况下被替换或调整。该接口还将规划、执行、验证和恢复事件记录为结构化轨迹，为各个组件提供监督，并在交互反馈可用时支持可选的在线自适应。我们在RoboTwin 2.0和LIBERO上使用Qwen3-VL和OpenPI/pi0.5实例化了EmbodiedSkills。任务自适应的低层VLA策略在50个RoboTwin 2.0任务上平均成功率达到86.20%，在4个LIBERO套件上达到97.40%。这些结果确立了EmbodiedSkills中使用的任务自适应低层VLA策略的执行性能。在四个依赖记忆的RMBench任务上，相同的任务自适应执行方法实现了12.5%的平均成功率。该框架为将这些策略转化为闭环具身系统提供了一个可训练且可检查的智能体层。

## Abstract
Vision-language-action (VLA) models map visual observations and language instructions directly to robot actions, but long-horizon tasks require more than action prediction. An agent must coordinate perception, planning, execution, progress verification, and recovery as the physical state evolves. An action prediction or a model-generated skill decision does not, by itself, guarantee that the proposed operation is valid in the current state or that its outcome will be verified. We propose EmbodiedSkills, a unified framework that treats each skill decision as an execution proposal: the runtime checks its prerequisites before execution and verifies the outcome afterward. A shared executable-skill interface connects high-level skill selection, bounded low-level VLA execution, and post-action verification within a single agent loop. Because this interface remains fixed, low-level VLA policies can be replaced or adapted without changing the agent loop. The interface also records planning, execution, verification, and recovery events as structured trajectories, which provide supervision for individual components and can support optional online adaptation when interactive feedback is available. We instantiate EmbodiedSkills with Qwen3-VL and OpenPI/pi0.5 on RoboTwin 2.0 and LIBERO. Task-adapted low-level VLA policies achieve an average success rate of 86.20% across 50 RoboTwin 2.0 tasks and 97.40% across the four LIBERO suites. These results establish the execution performance of the task-adapted low-level VLA policies used in EmbodiedSkills. On four memory-dependent RMBench tasks, the same task-adapted execution approach achieves 12.5% average success. The framework provides a trainable and inspectable agent layer for turning these policies into closed-loop embodied systems.

### 1. 核心问题与整体含义（研究动机与背景）

- **研究核心问题**：现代视觉-语言-动作（VLA）模型虽然能直接将视觉观察与语言指令映射为机器人动作，但仅具备“动作预测”能力远不足以完成长时程、物理状态持续演化的复杂任务。机器人需要协调感知、规划、执行、进度验证与失败恢复等完整的智能体能力。
- **现有方案的关键缺陷**：
  - **端到端 VLA 策略**：任务中间决策隐式化，失败时难以定位是目标定位错误、子目标选择错误、低层动作执行错误还是验证错误。
  - **LLM 驱动的机器人智能体**：虽然能将推理和工具调用外显化，但“显式的决策”并不等于“当前物理状态下合法、可执行的决策”。模型提出的技能可能与当前阶段不兼容、依赖过时的观测、缺少必备参数，或在执行后无法产生预期的物理效果。
- **核心洞察**：需要在“模型层面的决策”与“物理世界的执行”之间建立桥梁——让提议的操作在执行前被审查、执行后其结果能被验证，从而使验证证据反哺后续决策与学习。

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 2.1 核心思想：策略-运行时分离（Policy–Runtime Separation）

EmbodiedSkills 的核心设计是将“提出结构化技能决策的策略”与“执行并强制执行安全约束的运行时”分离。模型提出的任何技能都只是一个“执行提案”，只有在通过运行时对前置条件、工件新鲜度、动作合法性和状态转移合法性的检验之后，才能真实作用于物理环境。

#### 2.2 六阶段受控智能体循环（Guarded Six-Phase Agent Loop）

框架定义了一个按语义划分的六阶段循环：

| 阶段 | 作用 |
|------|------|
| **Observe（观察）** | 采集当前视图，提取任务相关视觉证据，更新场景表征 |
| **Plan（规划）** | 将任务分解为可验证的语义子目标序列，分配执行预算 |
| **Preflight（预检）** | 检查子目标是否具备执行条件（上下文、观测、机器人状态等） |
| **Execute（执行）** | 调用低层 VLA 策略生成有界动作块并在环境中执行 |
| **Verify（验证）** | 基于动作后的新观测判断子目标是否实际推进 |
| **Recover（恢复）** | 根据失败证据修正子目标或计划，选择安全的重入阶段 |

值得强调的是，这些阶段**不是僵化的单向流水线**——根据状态演化，策略可以重访早前阶段（例如重新观察、重新规划），也可以继续、推进或终止当前子目标。

#### 2.3 可执行技能契约（Executable Skill Contract）

每个技能由六元组形式化定义：`k = (X_k, Y_k, pre_k, exec_k, post_k, fail_k)`，包括类型化的输入输出模式、前置条件、可执行操作、状态更新和后置条件及失败映射。该契约同时服务于三个目的：
- **组合接口**：使不同的学习组件（感知、规划、验证、动作生成）可以无需内部表征一致即可组合。
- **运行时有效性边界**：定义工件失效传播边界，防止过时预测授权物理动作。
- **训练轨迹的结构化来源**：记录运行证据供组件学习。

#### 2.4 受控运行时转移（Guarded Runtime Transition）

策略有三种控制类型：`RunSkill(k, q)`、`AdvanceStage`、`FinishRun`。运行时对每种类型设置独立守卫函数：
- **技能守卫 `G_skill`**：检查阶段匹配、技能合法性及所有前置条件。
- **推进守卫 `G_advance`**：检查当前阶段是否已产生后继阶段所需证据。
- **终止守卫 `G_finish`**：允许合法终止。

守卫失败时，系统记录“被阻止的决策”及其证据，而不是静默地执行或忽略。

#### 2.5 有界动作执行与验证恢复

- **有界动作块**：低层 VLA 策略输出 `(τ_t, U_t, H_t, η_t)`，即动作类型、长度有限的离散动作序列、执行视界以及与子目标和观测的绑定关系。运行时通过 `R_act` 校验动作维度、数值有效性、视界限制和一致性。
- **验证路由**：执行后基于新证据选择语义路由 `V = {Advance, Continue, Reobserve, Replan, Recover, Finish}`。
- 一个语义子目标可能需要多个动作块——每执行完一个块就收集新证据并重新决策，而不是一次性完成整个子目标。

#### 2.6 模块化训练

- **低层 VLA 策略**：用子任务级演示进行微调，每个样本将观测和机器人状态与活动子目标及动作序列配对。
- **高层调度器（Qwen3-VL）**：冻结低层 VLA 策略，基于部署一致的决策轨迹监督训练，学习按阶段选择合适技能并给出结构化参数。
- **训练样本的“部署一致性”原则**：训练时模型可见的上下文与部署时完全一致，避免模型学习了部署时不存在的信息。

### 6. 主要结论与发现

1. **低层执行性能**：任务自适应 π0.5 策略在 RoboTwin 2.0 上平均成功率达 **86.20%**（较 LingBot-VA 的 π0.5 参考结果 82.74% 提高 3.46 个百分点），在 50 个任务中 39 个超过基线。在 LIBERO 四套件上平均达 **97.40%**（较官方 OpenPI 的 96.85% 提升 0.55 个百分点），其中长时程套件 LIBERO-Long 提升最大（+1.2%），表明该策略的最大优势在更长任务序列上。
2. **记忆依赖任务的差距**：在 RMBench 四个记忆依赖任务上仅达 12.5%，说明当前子目标条件化框架不能解决需要历史交互记忆才能确定正确动作的问题。
3. **消融发现**：三个机制贡献差异显著——去除中间验证平均下降 38.0 个百分点；去除语义子目标条件化再降 13.8 个百分点；单块限制再降 14.9 个百分点。说明执行预算必须根据观测进度自适应调整，固定开环分配效果很差。
4. **架构意义**：固定技能接口允许低层策略替换/微调而不影响外层 AgentLoop，组件可以独立训练和适配。

### 7. 优点

- **问题定位精准**：准确识别了 VLA 模型从“策略”到“智能体”之间缺失的智能体层，而非简单堆叠新模块。
- **策略-运行时分离是优雅的系统设计**：让“模型提案”与“物理执行”解耦，避免将执行安全性寄托于提示工程。
- **统一契约贯穿训练与部署**：训练上下文与部署上下文严格一致，防止“训练时信息泄漏”问题。
- **模块化程度高**：规划器、调度器、验证器、低层 VLA 策略均可独立替换或适配，冻结低层策略训练高层调度器的策略使两层的优化互不干扰。
- **消融实验设计干净且有诊断价值**：能清楚展示每个机制（语义子目标、中间验证、自适应继续）的相对贡献。
- **跨基准验证**：在短时程语义泛化和长时程双臂操作两个不同基准上交叉验证了低层执行接口的移植性，且都能做到超过官方参考的水平。

### 8. 不足与局限

- **低层策略的现实约束**：采用“每个任务一个专家”模式，训练、存储与部署成本高，不是单一泛化策略。
- **依赖底层组件质量**：一个语义上合理但实际错误的接地（Grounding）判断或子目标选择仍然能通过模式检查，导致执行朝错误物理状态推进；验证在遮挡或视觉歧义时受限——框架无法超越底层组件的校准质量。
- **延迟开销**：额外 VLM 调用和动作后观测延长了任务完成时间，相对于单遍动作策略有明显延迟代价。
- **RMBench 记忆任务效果差**：12.5% 的极低成功率明确揭示框架缺少对交互历史中不可见状态的显式记忆建模，是当前框架的明显短板。
- **长周期误差累积**：模块化适配引入了协调权衡，长回合可能累积小的规划误差和验证错误，导致观测、重试和模型调用次数增多。
- **缺乏真实机器人验证**：所有实验均在仿真环境中完成，未涉及 sim-to-real 迁移问题。
- **资源披露不足**：未说明训练具体算力配置，可复现性信息不完整。
- **评测统计量偏简单**：在多次运行未报告标准差或置信区间，难以判断一些 1-2 个百分点的差异（如 LIBERO 上的提升）是否统计显著。

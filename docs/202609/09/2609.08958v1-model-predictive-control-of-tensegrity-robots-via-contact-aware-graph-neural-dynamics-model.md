## 摘要
张拉整体机器人在地形复杂的环境中提供轻量化、柔顺的运动能力，但由于其复杂的接触丰富动力学和部分可观测性，它们仍然难以建模和控制。本文提出了一种基于学习的图神经网络（GNN）动力学模型驱动的三杆张拉整体机器人的模型预测路径积分（MPPI）控制器。本文首先扩展了先前基于GNN的模型，引入了可微分的接触检测模块。该扩展使动力学模型能够对非水平平面地形、障碍物以及自碰撞进行推理。然后，学习的动力学模型和MPPI控制器在闭环数据采集循环中协同工作，迭代地提高模型精度和控制性能。本文进一步提出了一种混合MPPI策略，将MPPI与转向运动原语相结合，以提高机动性。在MuJoCo中进行了跨越五个导航任务的实验，包括墙壁障碍物、斜坡、狭窄走廊、低净空结构和复合3D障碍赛道。实验表明，基于学习的GNN动力学模型的混合MPPI控制器相比平面地面基线模型提高了预测精度，并且与基于A*的重新规划和仅MPPI的变体相比，实现了优越的导航性能。结果表明，接触感知的学习动力学与基于采样的模型预测控制相结合，能够在复杂的、接触丰富的环境中实现鲁棒的张拉整体导航。

## Abstract
Tensegrity robots offer lightweight, compliant mobility over challenging terrain but remain difficult to model and control due to complex contact-rich dynamics and partial observability. This work presents a model predictive path integral (MPPI) controller for a three-bar tensegrity robot driven by a learned graph neural network (GNN) dynamics model. This work first extends prior GNN-based models with a differentiable contact detection module. The extension allows the dynamics model to reason over non-horizontal planar terrains, obstacles, as well as self-collisions. Then, the learned dynamics model and the MPPI controller operate in a closed data-collection loop, iteratively improving model accuracy and control performance. This work further introduces a hybrid MPPI strategy that combines MPPI with turning motion primitives to improve maneuverability. Experiments are performed in MuJoCo across five navigation tasks, which include, wall obstacles, inclines, narrow corridors, low-clearance structures, and a composite 3D obstacle course. The experiments demonstrate that the hybrid MPPI controller operating over the learned GNN dynamics model improves predictive accuracy over a flat-ground baseline model and achieves superior navigation performance compared to $A^*$-based re-planning and MPPI-only variants. Results show that the contact-aware learned dynamics combined with the sampling-based model predictive control enable robust tensegrity navigation in complex, contact-rich environments.

## 2. 论文提出的方法论

### 2.1 总体框架

论文采用"**学习动力学 + 采样式MPC**"的范式。核心思路是：用GNN作为机器人系统内部动力学模型，将其嵌入MPPI控制器中做闭环预测与优化，并通过"模型训练→控制器执行→数据回馈→再训练"的闭环迭代来同时提升模型精度和控制性能。

### 2.2 图神经网络动力学模型（扩展）

- **基础架构**：采用编码-处理-解码（encode-process-decode）三段式GNN结构（参考文献[21][22]）。模型在轨迹数据上训练，以当前系统状态 Xt 和未来 h 步缆绳长度控制输入为输入，自回归地预测未来 h 步的速度变化量及缆绳静止长度变化量，从而模拟完整的运动轨迹。
- **创新贡献：可微接触检测模块**（differentiable contact detection module）：
  - 使用PyTorch实现，完全可微且支持并行计算；
  - 对**非水平平面地形**：杆端盖节点计算到周围平面表面的最小有符号距离及相应表面点，进而计算表面法向量和相对速度，生成接触特征并动态构建接触边；
  - 对**环境障碍物**：采用同样的程序将障碍物表面纳入图的节点体系；
  - 对**自碰撞（杆-杆接触）**：在圆柱杆对之间运行相同的接触检测流程，使模型能捕获翻滚过程中杆件间的相互作用；
  - 有符号距离设置上限阈值，使接触仅作用于局部范围，节点特征取k个最小的距离值，接触边按阈值动态分配连接。
- **与基线模型的区别**：基线GNN（参考文献[8]）假设接触仅存在于水平地面（z=0平面），本文扩展为通用的平面地形、任意障碍物和自碰撞。

### 2.3 MPPI控制器

- **基本思想**：模型预测路径积分（MPPI）是一种基于采样的随机最优控制方法。在每步控制中，采样 M 条长度为 H 的控制序列 {U^m}，通过动力学模型 f(·) 前向滚动生成 M 条轨迹 {T^m}，并计算各轨迹的代价 C(T^m)。
- **最优控制权重**：

  w^m = (1/η)·exp(−(1/β)(C(T^m)−ρ))

  U* = Σ w^m U^m

  其中 η 为归一化常数，β 是逆温度参数，ρ = min_m C(T^m) 为样本最小轨迹代价。

### 2.4 混合MPPI与转向运动原语（Hybrid MPPI）

- **动机**：纯MPPI的采样方式很容易发现前向/后向直线运动，但**难以采样到有效的转向行为**——转向需要长预测时域和大量样本，计算成本过高。
- **策略**（见Algorithm 1）：
  1. 根据当前机器人位姿和局部代价梯度的方向（通过采样周围环形区域的成本确定）计算航向偏差 Δθ；
  2. 若 |Δθ| 小于用户定义阈值 α，则**前方或后方与目标方向已对齐**，交给MPPI执行前向/后向推进；
  3. 若 α < Δθ ≤ π/2，则执行**逆时针（ccw）转向原语**；
  4. 其余情况执行**顺时针（cw）转向原语**。

### 2.5 障碍物感知的波前代价函数（Wave-Front Cost Function）

- **动机**：朴素欧氏距离代价函数在杂乱环境中会忽略障碍约束，诱导不可行的直线轨迹。
- **方法**（见Algorithm 2）：将工作空间离散化为均匀网格，只将无碰撞网格单元加入图节点，相邻无碰撞单元连边，从目标点向外做搜索并传播代价，得到障碍物感知的距离估计。通过跨求解共享closed list提高效率。

### 2.6 闭环数据采集循环（GNN-MPPI Data Collection Loop）

- 第0代（iteration 0）：仅由人工设计的运动原语（前滚、左转、右转）收集初始训练数据；
- 随后重复：用当前数据集训练GNN→将GNN嵌入MPPI→在目标任务上执行导航→收集新轨迹→加入数据集；
- 共迭代4轮。

## 6. 论文的主要结论与发现

1. **接触感知扩展有效**：融合可微接触检测的GNN动力学模型在预测精度上显著优于仅假设水平地面接触的基线模型，位置误差和方向误差均更低。
2. **迭代闭环数据采集增益明显**：模型误差随训练迭代（iteration 0→3）持续推进而逐步下降，控制器性能大体随之提升，形成良性循环。
3. **混合MPPI优于纯MPPI和A*重规划**：
   - 在平面障碍赛道，Hybrid MPPI从第1代起达到100%成功率，而A*虽最终也达100%（依赖更精确的运动学建模及原语优化），但MPPI-only仅37%（第3代），Hybrid MPPI在后期完成时间上也更优（650 s vs A*的452 s，最优A*方案时间仍略短但在原始数据中，表格内A*反向原语启发在最终代完成时间为452 s，而Hybrid为650 s；但Hybrid在第1代即达100%，A*网格在第2代才90%；需要注意赛道任务性能收敛速度的差异）。
   - 在斜坡任务上，A*全部失败（0%成功率），MPPI-only仅达33%（第3代），而Hybrid MPPI第0代即为100%成功率并持续缩短时间（最终193秒）。
   - 在需主动接触障碍物的任务中（窄通道、低净空、3D综合赛道），A*无法规划，Hybrid MPPI显著优于MPPI-only。
4. **模型泛化可行**：仅在第1~4个训练场景中训练的GNN，在未见过的3D综合赛道中依然能支撑84%的成功率（第3代），说明模型学到了一定的泛化动力学特征。
5. 消融实验表明**距离接触节点特征对精度影响大于接触边**，说明显式接贴近距离信息对学习接触动力学尤为重要。

## 7. 优点

1. **方法论上的创新性强**：将GNN学习动力学与MPPI结合用于张拉整体机器人闭环控制，开辟了不同于几何规划和RL的新路径；提出的可微接触检测模块让GNN不再局限于水平地面假设。
2. **"数据采集-模型改进-控制提升"闭环**的设计符合"以控制促建模、以建模强控制"的自举式发展思路，在机器人学习领域具有示范价值。
3. **混合策略的设计务实高效**：意识到纯MPPI难以采样有效转向的问题，将MPPI与人工运动原语结合，形成"粗调-精调"互补策略，既保留了MPPI对复杂接触场景的适应性，又避免了采样学习的冗余。
4. **障碍物感知波前代价函数**的设置有效缓解了欧氏距离在杂乱环境中误导成本估计的问题。
5. **实验场景设计丰富多样**：从平面墙障到斜坡、窄道、低净空再到三维复合赛道，从简到繁逐级递进，并设置了**未见过的组合环境**来检验泛化能力；消融实验定位了各模块的贡献。
6. 论文实验指标选取合理（成功率+平均完成时间），迭代式评价清晰直观。

## 8. 不足与局限

1. **地形表示受限于平面**：接触检测模块仅能处理平面面片，未能覆盖完全非结构化的地形（如岩石、粗糙地面），离真实户外环境尚有差距。
2. **未进行实物验证**：全部实验在MuJoCo仿真中进行；虽然作者将实物部署列为未来工作，但这仍是该工作从仿真走向实际应用之间的最大不确定性（sim-to-real gap）。
3. **模型与控制器需要大量采样/迭代**：MPPI需要大量并行前向模拟，对处理器的并行能力要求高；文中未给出实时性/算力开销数据。
4. **混合MPPI依赖人工设计的转向原语**：不能完全消除人工工程痕迹，且"人工原语+学习模型"的混合结构泛化到更复杂机器人形态时未必成立。
5. **A*对比不完整**：只对比了两种场景，且A*只是拿运动原语做顶层重规划，并未发挥A*在采样/控制层面的优势，对比有失全面性。
6. **性能方差与收敛性分析不足**：表中Hybrid MPPI和MPPI-only在不同迭代之间成功率存在波动甚至倒退（如平面障碍赛道的MPPI-only从迭代2的47%降至迭代3的37%），文中未进行方差或统计显著性分析，也未解释这些反直觉的结果。
7. **成本函数未充分考虑系统非完整约束**：作者自己也指出，未来的成本函数需要更好反映张拉整体机器人的非完整运动学约束。
8. **可复现性信息缺失**：未公开MPPI的采样数M、预测时域H、采样温度、迭代训练的超参数等关键细节，也未提及是否开源代码/GNN模型参数，影响结果的复现与后续对比。

## 总评

该文将**接触感知图神经网络动力学模型**与**混合MPPI控制器**结合，系统解决了张拉整体机器人在复杂、接触丰富环境中的导航问题。方法论上具有显著创新性，实验规模与场景覆盖较全面，结果证明了该范式的可行性。文中也发现纯MPPI难以处理转向的问题，并给出高效的混合解决思路。但受限于"平面地形"与"纯仿真验证"，再加上算力和超参数细节披露不足，工作距离真实的户外张拉整体机器人自主导航仍有相当距离。总的来说，这是一篇在机器人控制与学习动力学交叉方向有明确贡献的高质量论文。

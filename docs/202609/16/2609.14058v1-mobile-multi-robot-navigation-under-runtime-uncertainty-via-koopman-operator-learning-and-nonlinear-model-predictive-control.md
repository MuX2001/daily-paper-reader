## 摘要
在本工作中，我们开发了一种非线性模型预测控制（NMPC）框架，该框架利用通过Koopman算子理论学习得到的动力学，用于移动多机器人导航。我们使用一个提升的双线性Koopman模型来构建并求解NMPC问题，该模型能够准确预测受扰动和不确定性影响的仿射输入系统。我们考虑了两种典型的多机器人导航问题：目标到达和编队控制。我们的方法输出能够在充满障碍物的环境中实现闭环多机器人导航和编队控制，其中NMPC公式中使用的基于Koopman算子的模型处理了运行时不确定性，即不同程度的随机车轮打滑。我们通过在不同环境中进行的大量数值仿真，在轮式机器人受到不同打滑量影响且不知道其真实动力学模型的情况下，验证了我们的方法对这两个问题的有效性。

## Abstract
In this work, we developed a nonlinear model predictive control (NMPC) framework that employs learned dynamics via the Koopman Operator theory for mobile multi-robot navigation. We formulated and solved NMPC problems using a lifted bilinear Koopman-based model that accurately predicts affine input systems affected by perturbations and uncertainties. Two exemplary multi-robot navigation problems are considered: target reaching and formation control. The output of our method enables closed-loop multi-robot navigation and formation control in environments populated with obstacles, whereby the Koopman operator-based model used in the NMPC formulation addresses runtime uncertainties, namely, various degrees of random wheel slipping. We validated the effectiveness of our method for both problems via extensive numerical simulations in different environments with wheeled robots affected by different amounts of slip and without knowledge of their true dynamic models.

## 2. 方法论

### 2.1 核心思想

- 利用 Koopman 算子理论，将非线性控制仿射系统的状态提升到高维可观测空间，在该空间中用**双线性模型**近似演化。
- 将学习到的 Koopman 双线性模型嵌入 NMPC，作为预测模型进行滚动时域优化，从而在不确定打滑条件下实现多机器人目标到达与编队控制。
- 不假设已知每个机器人的真实非线性动力学，而是离线用数据学习 Koopman 矩阵，在线用于 NMPC 求解。

### 2.2 关键技术细节

- **控制仿射系统**：
  \[
  \dot{x}(t)=h_0(x(t))+\sum_{i=1}^{m}h_i(x(t))u_i(t)
  \]
  其中漂移项与输入项可包含未知扰动。
- **Koopman 算子与可观测提升**：定义可观测函数 \(\phi\)，其时间演化满足
  \[
  \frac{\partial \psi}{\partial t}=L_{h_0}\psi+\sum_{i=1}^{m}u_iL_{h_i}\psi
  \]
  通过选取有限维字典 \(\phi=\{\phi_1,\dots,\phi_M\}\)，得到有限维双线性模型：
  \[
  z=\phi(x),\quad \dot z=Az+\sum_{i=1}^{m}N_i z u_i,\quad x=Cz
  \]
  进一步用 Kronecker 积写成：
  \[
  \dot z(t)=Az(t)+N(u(t)\otimes z(t))+Bu(t)
  \]
  其中加入线性输入项 \(B\) 以提升 EDMDc 类方法的估计精度。
- **离线学习**：给定输入和观测时间序列，通过最小二乘求解
  \[
  \min_{A,N,B}\|Z'-AZ-N(U\otimes Z)-BU\|,\quad
  \min_C\|X-CZ\|
  \]
  解析解为
  \[
  [A,N,B]=Z'[Z,U\otimes Z,U]^+,\quad C=XZ^+
  \]
  即使用 Moore–Penrose 伪逆。
- **字典设置**：采用极简 4 维字典
  \[
  \phi(x)=[1,p_1,\cos\theta_1,\sin\theta_1,p_2,\cos\theta_2,\sin\theta_2,p_3,\cos\theta_3,\sin\theta_3]
  \]
  用于三机器人差速驱动系统。
- **NMPC 问题**：
  - 目标到达：最小化目标距离与输入代价，约束包括动力学等式、状态/输入约束、障碍物距离约束和机器人间避碰约束。
  - 编队控制：在目标到达基础上加入领导者-跟随者相对状态偏差约束 \(lb \le x_{f_i,t+1}-x_{f_i,t}-x_{l,t+1}+x_{l,t}\le ub\)，允许局部小偏差以绕障。
  - 目标函数形式：
    \[
    \ell(x_{t+1},u_t)=\|d(x_{t+1},x_r)\|_Q^2+\|u_t\|_R^2
    \]
    其中 \(d\) 融合位置和偏航角表示，\(Q,R\) 为正半定权重矩阵。
- **算法流程**：
  1. 离线：采集数据，求解最小二乘得到 \(A,B,C,N\)。
  2. 在线：每个时刻以当前状态为初始条件，求解 NMPC，取最优控制首项作用于系统，更新状态，滚动重复。
  3. 采用 CasADi 符号建模、multiple-shooting 离散化、IPOPT 求解。

### 2.3 不确定性建模

- 差速驱动模型：
  \[
  \dot x_i=(v_i+v_{ti})\cos\theta_i+v_{si}\sin\theta_i
  \]
  \[
  \dot y_i=(v_i+v_{ti})\sin\theta_i-v_{si}\cos\theta_i
  \]
  \[
  \dot\theta_i=\omega_i+\omega_{si}
  \]
- 打滑速度：
  \[
  v_{si}=\alpha_i v_i,\quad v_{ti}=\beta_i v_i,\quad \omega_{si}=\gamma_i\omega_i
  \]
  其中 \(\alpha_i,\beta_i,\gamma_i\) 服从指数分布，\(\lambda_i\) 为打滑系数。标称情况为无打滑。

## 6. 主要结论与发现

- Koopman 双线性模型能够较好逼近差速驱动多机器人系统：
  - 无打滑时 RMSE 约 2%。
  - 有打滑时预测误差随打滑系数增加而增大，但整体仍能学习平滑动态模型。
- 在目标到达任务中：
  - 标称设置下成功率 10/10，最终位置误差不超过 0.03m。
  - 低打滑平均成功率约 90%，高打滑下降至 60%–80%；所有低/高打滑设置平均成功率约 80%。
  - 机器人 3 打滑最大，最终误差和离散度通常更高，但仍小于轨迹长度的约 10%。
- 在编队控制任务中：
  - 标称设置下成功率 10/10。
  - 低/高打滑下成功率仍高于 80%。
  - 跟随者最终位置误差高于目标到达任务，但不超过 0.08m，小于总轨迹长度的 5%。
- 与 Nominal NMPC 对比：
  - Koopman-NMPC 成功率更高，最终目标距离更小。
  - Nominal NMPC 在 Map 2 标称情况下甚至成功率为 0/10，显示其对真实打滑或模型失配的脆弱性。
- 与 Consensus-based 方法对比：
  - 忽略碰撞时，consensus 方法轨迹匹配良好。
  - 在障碍物环境中，consensus 方法即使标称情况下也常无法在限定时间内使跟随者到达目标，跟随者最终距离很大。
  - Koopman-NMPC 在避障与编队保持方面明显更优。

## 7. 优点

- **方法层面**：
  - 将多机器人系统作为整体学习，而非仅学习单个跟随者，有利于共享信息和同时规划避碰。
  - 使用双线性 Koopman 模型加线性输入项，提高对受扰仿射输入系统的预测精度。
  - 无需真实非线性动力学模型，适合模型未知或难以精确建模的轮式机器人。
  - 离线学习、在线 NMPC 的框架便于在较低算力设备上部署。

  - 与 Nominal NMPC 和 Consensus-based 方法对比，突出学习模型在不确定环境下的优势。
  - 评价指标包括成功率、最终误差、RMSE 和 Hausdorff 距离，定性图与定量表结合。

## 摘要
预训练的生成式机器人策略从演示中学习富有表现力的动作先验。然而，现有的强化学习方法仅引导噪声空间，而无法在生成过程中调节中间动作表示，导致性能下降和效率低下。为了解决这一局限，我们提出了一种新颖的双潜在空间强化学习（DLSRL）框架，它通过在冻结生成器内部进行表示级控制，补充了初始噪声引导。具体来说，我们的 Actor 网络预测两个不同的潜在变量：一个用于引导行为生成的初始噪声潜在变量，以及一个用于中间特征调制的动作表示潜在变量。此外，该表示潜在变量被映射为适配器特征，并通过残差连接巧妙地注入中间动作 token 的隐藏状态。我们的双控制设计能够在不更新基础策略的情况下直接调整动作表示。在生成式策略架构和机器人操作任务上的实验表明，DLSRL 有效加速了在线机器人策略自适应，并达到了有竞争力的性能。我们的代码可在 \href{https://github.com/xianchaoxiu/DLSRL}{https://github.com/xianchaoxiu/DLSRL} 获取。

## Abstract
Pretrained generative robot policies learn expressive action priors from demonstrations. However, existing reinforcement learning methods only steer the noisy space but fail to modulate intermediate action representations during the generation process, resulting in performance degradation and inefficiency. To address this limitation, we propose a novel Dual-Latent Space Reinforcement Learning (DLSRL) framework, which complements initial-noise steering with representation-level control inside the frozen generator. Specifically, our actor network predicts two distinct latent variables: an initial-noise latent variable that steers behavior generation, and an action-representation latent variable for intermediate feature modulation. Moreover, this representation latent variable is mapped to adapter features and ingeniously injected into the hidden states of intermediate action tokens via residual connections. Our dual-control design enables direct adjustment of action representations without updating the base policy. Experiments across generative policy architectures and robotic manipulation tasks show that DLSRL effectively accelerates online robot policy adaptation and achieves competitive performance. Our code is available at \href{https://github.com/xianchaoxiu/DLSRL}{https://github.com/xianchaoxiu/DLSRL}.

## 2. 方法论

- **核心思想**：在冻结的生成式基策略内部引入第二个 RL 控制接口。Actor 同时输出两个潜变量：
  - 初始噪声潜变量 \(z_t\)：控制动作生成起点；
  - 动作表示潜变量 \(u_t\)：用于调制中间动作 token 的隐藏状态。
- **问题形式化**：
  - 机器人操作建模为 MDP，观测 \(o_t=(I_t,q_t,\ell)\)，输出动作块 \(a_t\in\mathbb{R}^{H\times d_a}\)；
  - 冻结基策略 \(G_\phi\) 生成动作：\(a_t=G_\phi(o_t,z_t)\)；
  - 目标是最大化折扣回报 \(J=\mathbb{E}[\sum_t \gamma^t r_t]\)，仅训练轻量外部控制模块。
- **双潜空间 Actor**：
  - 给定观测 \(o_t\)，双潜 Actor 输出 \((z_t,u_t)\sim\pi_\theta(\cdot|o_t)\)；
  - 动作表示潜变量经适配器映射：\(f_t=A_\omega(u_t)\)；
  - 冻结基策略生成动作：\(a_t=G_\phi(o_t,z_t,f_t)\)。
- **动作 Token 隐状态调制**：
  - 适配器特征 \(f_t\) 与动作 token 隐状态同形状，即 \(f_t\in\mathbb{R}^{N_a\times d_h}\)；
  - 在选定的冻结 Transformer block 输出处进行残差注入：\(\tilde{H}^{(l)}_{t,k}=H^{(l)}_{t,k}+\delta_t\)，其中 \(\delta_t=\lambda_{\text{inj}}f_t\)；
  - 仅作用于动作 token 位置，不修改视觉、语言、本体感觉等上下文 token；
  - 同一适配器特征可跨选定 Transformer block 和生成更新步共享，不增加基策略可训练参数。
- **双潜策略优化**：
  - 训练动作空间 critic \(Q^{\text{act}}_\psi(o_t,a_t)\)，使用 off-policy TD 学习；
  - 通过值蒸馏训练潜空间 critic \(Q^{\text{lat}}_\nu(o_t,z_t,f_t)\)，目标为  
    \(\mathcal{L}_{\text{distill}}=\mathbb{E}[(Q^{\text{lat}}_\nu(o_t,\hat z_t,\hat f_t)-\text{sg}[Q^{\text{act}}_\psi(o_t,\hat a_t)])^2]\)，梯度只更新潜 critic；
  - Actor 目标为熵正则化目标：  
    \(\mathcal{L}_{\text{actor}}=\mathbb{E}[\alpha\log\pi^z_\theta(z_t|o_t)-Q^{\text{lat}}_\nu(o_t,z_t,f_t)]\)；
  - 熵正则只施加于初始噪声分支，但 \(Q^{\text{lat}}\) 对 \(z_t\) 和 \(f_t\) 的梯度会传播到两个 Actor 分支及适配器映射器；
  - 训练时交替更新动作 critic、潜 critic、Actor 和适配器映射器，基策略参数 \(\phi\) 始终冻结；部署时只保留 Actor 和适配器映射器。

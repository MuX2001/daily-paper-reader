## 摘要
我们考虑在具有混合状态观测的未知动力学下进行机器人运动规划与控制，其中状态测量仅可在状态空间的部分区域获得。现有工作将系统辨识、预测可达性、图搜索和控制器综合结合在一个分层框架中，该框架在多面体状态空间划分上使用局部仿射近似模型，但需要状态观测来进行辨识和反馈控制。基于该框架，我们通过选择标称动力学并在观测丢失之前预计算开环控制序列来处理盲区。由于真实动力学可能与所选标称模型不同，机器人可能通过非预期面离开盲多面体。我们量化这种转移风险，并将可能的结果纳入随机转移系统。高层规划问题被表述为随机最短路径问题，其策略指导控制器综合。案例研究表明，该方法能够引导机器人从初始状态到达目标，同时平衡路径效率与穿越盲区相关的风险。

## Abstract
We consider robotic motion planning and control under unknown dynamics with hybrid state observations, where state measurements are available only in parts of the state space. Existing work combines system identification, predicted reachability, graph search and controller synthesis in a hierarchical framework using local affine approximated models over polytopic state space partitioning, but requires state observations for identification and feedback control. Based on this framework, we address blind regions by selecting nominal dynamics and precomputing open-loop control sequences before observation is lost. Since the true dynamics may differ from the selected nominal model, the robot may exit a blind polytope through an unintended facet. We quantify this transition risk and incorporate the possible outcomes into a stochastic transition system. The high-level planning problem is formulated as a stochastic shortest path problem, whose policy guides controller synthesis. A case study demonstrates that the method guides the robot from an initial state to a target while balancing route efficiency and the risks associated with traversing blind regions.

## 1. 核心问题与整体含义

- **研究动机**：机器人在未知动力学环境中运动时，系统辨识、可达性分析与控制器综合往往依赖状态观测。然而实际中常存在视觉遮挡、视野受限、通信中断等情况，导致状态测量仅在部分区域可用，形成“混合观测”场景。
- **核心问题**：在状态空间被划分为可观测区域 \(S_o\) 与盲区 \(S_b\) 的条件下，机器人动力学未知，且盲区内无法进行在线系统辨识与反馈控制。如何设计控制策略，使机器人从初始状态 \(x_0\) 到达目标 \(x^*\)，同时兼顾路径效率与穿越盲区的风险？
- **整体含义**：现有分层框架通过多胞体划分、局部仿射近似、预测可达性和图搜索实现未知动力学下的规划，但要求全程可观测。本文将该框架扩展到混合观测场景，不把盲区简单视为障碍，而是显式量化穿越盲区时因模型偏差导致“非预期面离开”的风险，并将其纳入随机最短路径规划。

## 2. 方法论

### 2.1 核心思想

- 继承已有工作：将状态空间划分为凸多胞体，在每个多胞体内用局部仿射模型近似非线性动力学，并基于面可达性构建有向图。
- 对盲区多胞体：由于无法在线辨识与反馈，在进入盲区前选择标称动力学，并预计算开环控制序列。
- 由于真实动力学与标称模型存在偏差，机器人可能从非预期面离开盲多胞体。本文量化这种转移风险，构建随机转移系统，并将高层规划建模为随机最短路径问题（SSP）。
- SSP 求得的策略用于指导控制器综合：在可观测区域直接执行反馈控制；在进入盲区前生成覆盖连续盲区转移的开环控制序列。

### 2.2 关键技术细节

- **系统模型与假设**：
  - 控制仿射非线性系统 \(\dot{x}=f(x)+g(x)u\)，状态和输入分别约束在多胞体 \(P_s\)、\(P_u\) 中。
  - \(f,g\) 先验未知，但满足 Lipschitz 连续性，且 Lipschitz 常数 \(L_{df},L_g\) 已知。
  - 初始状态和目标状态均位于可观测区域。
- **局部仿射近似与可达性**：
  - 每个多胞体内近似为 \(\dot{x}\approx \bar{A}_l x+\bar{B}_l u+\bar{c}_l\)。
  - 面可达性通过顶点控制输入满足法向条件来判定，并用仿射反馈控制器 \(u(x)=F_lx+g_l\) 实现。
  - 对未辨识多胞体，利用已辨识多胞体参数与 Lipschitz 界构造保守可达性条件。
- **盲区标称模型选择**：
  - 将局部仿射参数的不确定集记为 \(\Theta\)，中心为 \((A^*,B^*,c^*)\)，半径由 Lipschitz 界给出。
  - 选择标称模型与顶点控制输入，使认证可达的参数子集 \(\Theta_{\text{reach}}\) 体积最大。
  - 优化目标为 \(d_A\log\rho_A+d_B\log\rho_B+d_c\log\rho_c\)，约束包含可达性条件与不确定集包含条件。
  - 该优化非凸，文中用 SLSQP 求局部最优解，得到标称模型 \((\hat{A},\hat{B},\hat{c})\)。
- **非预期转移风险量化**：
  - 对每个可能出口面 \(F_k\)，定义满足该面可达条件的参数集 \(\Theta^k_{\text{reach}}(u)\)。
  - 近似转移概率为 \(p_k=\frac{\text{Vol}(\Theta^k_{\text{reach}}(u))}{\text{Vol}(\Theta)}\)，并归一化。
  - 该概率基于“真实参数在 \(\Theta\) 内均匀分布”的假设，且 \(\Theta^k_{\text{reach}}\) 通常是实际可达集的内近似。
- **随机图与 SSP**：
  - 节点为多胞体瓦片，分为可观测瓦片 \(V_{\text{obs}}\) 与盲瓦片 \(V_{\text{blind}}\)。
  - 可观测瓦片内转移视为确定性；盲瓦片内转移为随机，可能进入标称后继或非预期邻居。
  - 盲区预期转移代价为到达时间上界 \(T_i^a\)；非预期转移代价为 \(\lambda d_{\text{obs}}(v_j)\)，其中 \(d_{\text{obs}}\) 表示到最近可观测瓦片的距离，\(\lambda\) 控制风险惩罚。
  - 值迭代求解 Bellman 方程，得到最优策略 \(\pi^*\)。
- **控制执行流程**：
  - 在可观测区域按策略选择动作并综合反馈控制器。
  - 若策略进入盲区，则沿标称后继递归生成盲区转移序列，直到重新进入可观测区域。
  - 将对应控制器转换为时间索引开环控制序列，在失去观测前预计算，进入盲区后执行。
  - 一旦重新获得观测，测量当前状态并重新进行 SSP 规划。

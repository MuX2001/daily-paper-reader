## 摘要
水下机器人学习依赖于集成高保真水动力学、便捷学习接口以及可信真实场景迁移的仿真器。在本工作中，我们提出 FinsSim，一个面向水下机器人 Sim-to-Real 学习的现实对齐一体化仿真平台。FinsSim 首先构建具有可选后端的高保真仿真，以适应多样化需求。为促进水下机器人研究，它还进一步提供标准控制基线，以及统一的机器人学习工作流。为实现可靠的 Sim-to-Real 迁移，FinsSim 采用多传感器融合方案，以提供低成本且精确的定位。此外，它实现了经过校准的推进器-水动力学模型和受约束的力旋量分配算法。通过 ROS~2 将这些模块桥接起来，FinsSim 建立了完整的 Sim-to-Real 迁移流水线。通过匹配的仿真与实验，证明了使用 FinsSim 框架可以实现水下机器人控制策略可靠的 Sim-to-Real 迁移。独立的消融研究也验证了 FinsSim 的各个模块能够从不同方面解决水下 Sim-to-Real 的关键问题。总体而言，这项工作旨在弥合理论研究与实际应用之间的差距，最终推动水下机器人领域的进步。

## Abstract
Underwater robot learning relies on simulators that integrate high-fidelity hydrodynamics, convenient learning interfaces, and a credible transition to real scenarios. In this work, we present FinsSim, a reality-aligned integrated simulation platform for Sim-to-Real underwater robot learning. FinsSim first constructs high-fidelity simulation with selectable backends to adapt to diverse requirements. To facilitate underwater robot research, it further offers standard control baselines, alongside with unified robot learning workflows. For reliable Sim-to-Real transfer, FinsSim adopts a multi-sensor fusion scheme to provide low-cost yet precise localization. Moreover, it implements calibrated thruster-hydrodynamics models and a constrained wrench allocation algorithm. Bridging these modules by ROS~2, FinsSim establishes a complete Sim-to-Real transfer pipeline. Through matched simulations and experiments, it is demonstrated that reliable Sim-to-Real transfer of underwater robot control policies can be achieved with the FinsSim framework. Separate ablation studies also validate that the modules of FinsSim can address the pivotal issues of underwater Sim-to-Real from different aspects. Overall, this work aims to bridge the gap between theoretical research and practical applications, ultimately driving advancements in the field of underwater robotics.

## 一、核心问题与整体含义（研究动机与背景）

- **水下机器人控制的学习化需求**：水下机器人动力学受不确定水动力系数、非线性阻尼、环境扰动等因素影响，基于学习的方法因便利性成为有吸引力的控制途径，但真实场景中采集足量交互数据代价高、耗时长甚至存在安全风险，因此仿真器处于核心地位。
- **现有仿真器的能力碎片化**：经典海洋仿真器（UUV Simulator、DAVE 等）提供成熟载具/传感器模型但并非面向学习设计；近期学习导向平台（如 MarineGym、UNav-Sim）强调 GPU 原生并行仿真，却未暴露从仿真动作到物理感知与执行的完整、可标定追溯路径（见 Table I）。
- **缺少可复用的 Sim-to-Real 管线**：据作者所知，尚无仿真器提供可跨载具、任务、环境复用的策略部署管线。复现一次水下 Sim-to-Real 实验通常需要研究者自行拼装各模块，导致大多数水下 RL 评估局限于仿真，硬件演示则多采用难以复用的任务专用管线。
- **核心命题**：真正的实践障碍不是"缺少仿真器"，而是缺少一个**现实对齐的一体化仿真平台（reality-aligned integrated simulation platform）**——各必要组件被系统集成并与真实环境一致对齐。FinsSim 即针对此空白提出。

## 二、方法论

### 1. 总体架构

- 平台分为**仿真平台**与**物理平台**两部分，由 **ROS 2** 串联为完整闭环。
- 仿真端支持 **Unity** 与 **Isaac Lab** 两种后端；通过 **gRPC-ROS 2 bridge** 让 ROS 2 控制器直接操作仿真载具；学习接口基于 **ML-Agents** 构建。
- 物理端通过多传感器融合实现全局定位，并经硬件桥将控制指令下发至板载 MCU，实现标定后的推进器执行。

### 2. 仿真平台

- **三种可互换水动力学后端**（不提出新公式，而是让用户按需求选择）：
  - **标定 Fossen 模型（高保真）**：采用标准分解 τ_Fh = τ_H + τ_D(ν_r) − M_A·ν̇_r − C_A(ν_r)ν_r，其中 τ_H 为静水恢复力旋量，ν_r 为相对流速，M_A 为附加质量矩阵，C_A 为其科氏/向心矩阵；阻尼项实现为 τ_D = −[D₁ + D₂·diag(|ν_r|) + D_u|u_r|]ν_r。
  - **物理网格模型（Physics-Mesh）**：将封闭物理网格裁切至包围载具，对水面以下三角面元累积阻力。对第 i 个三角形（面积 A_i、形心 c_i、外法向 n_i）计算局部相对流 v_i 及法向/切向分量 v_t,i，再计算形状阻力 F_form 与表面摩擦阻力 F_skin（含可调系数 C_form、C_skin、入流余弦 μ_i），对质心求和得到网格力旋量；实现遵循 Stonefish 的几何感知建模原则，可选商用 Unity 插件 DWP2。
  - **简化 Fossen 模型（面向学习）**：仅保留静水与阻尼项 τ_Sh = τ_H + τ_D(ν)，避免每步估计相对加速度与附加质量科氏项，配合域随机化（DR）用于大规模并行 RL。
- **Fossen 标定流程**：在控制器体坐标系下定义 ν = [u, v, w, p, q, r]ᵀ。对平移轴与偏航轴拟合 τ_i = m_eff,i·ν̇_i + d₁,i·ν_i + d₂,i·|ν_i|ν_i + b_i（有效质量/惯量、线性阻尼、二次阻尼、常值偏置）；横滚/俯仰使用类似有效惯量模型并加入重力-浮力恢复力矩项 k_i·sin η_i。激励方式：单轴阶跃试验激发纵荡、横荡、偏航；**下潜-滑行序列**（dive-and-coast）激发垂荡，以同时暴露动力下潜与自然上浮。
- **感知与学习接口**：支持相机、IMU、深度传感器模型（视觉观测基于 Unity HDRP 水体与渲染栈，提供逼真视觉源）；支持状态观测或视觉观测的策略。提供传统 PID 控制基线，以及 RL、IL（模仿学习）、MARL（多智能体 RL）训练接口；提供 DR 工具箱（随机化机体质量与体积、水动力系数、推进器特性等）。并行训练：Unity 用 ML-Agents 并行区域，Isaac Lab 提供 GPU 原生批量实现用于高吞吐状态类任务。

### 3. 物理平台

- **低成本折射感知定位**：不使用声学基础设施或机载 DVL，而是采用固定顶置相机 + 压力传感器 + IMU + 载具上的两枚 AprilTag。
  - **折射 AprilTag 几何**：检测到的四个图像角点去畸变后反投影为单位射线 r_c,i，变换到水池坐标系得 r^a_p,i；空气侧射线与水面 Π（n_ΠᵀX + b_Π = 0）求交得交点 S_p,i；在交点处按 Snell 定律（η = n_air/n_water，含入射角余弦 c_i 与折射判别式 κ_i）得到水侧折射射线方向 r^w_p,i，从而每个角点定义一条水下折射射线 X_p,i(λ) = S_p,i + λr^w_p,i。实现中还剔除近水平表面交、非实折射射线及背离水体的射线。
  - **压力 + IMU 约束**：由压力深度与 IMU 横滚/俯仰确定每个角点高度 z_i，将折射射线与水平面 z = z_i 相交，得到折射重建的 3D 角点测量 Q_p,i。
  - **位姿求解**：未知量 ξ = [x, y, ψ]ᵀ，刚体运动学预测角点 P_p,i(ξ)；对两枚标定 AprilTag 的有效角点集合（|I| ≤ 8）求解最小二乘 min Σ‖Q_p,i − P_p,i(ξ)‖²，用轻量 Levenberg–Marquardt 风格求解器；多标签冗余在水面扰动、眩光或遮挡导致单标签失效时仍保持几何约束。
  - **多传感器融合**：位置-速度 EKF（常速模型 A_k = [[I₃, Δt·I₃],[0₃, I₃]]，含过程噪声 Q_k）+ 独立偏航滤波器（由 IMU 角速率传播、视觉偏航测量校正）；视觉、深度、偏航更新均需通过马氏距离门控 ρ_kᵀΣ⁻¹_ρ,k ρ_k ≤ γ。
- **执行器标定与电机转速控制**：每个推进器稳态推力曲线按方向相关二次模型 T_i = c_i^±·ω_i|ω_i| 拟合（正/负转分别辨识 c⁺、c⁻）；桥接模块将请求力转换为目标转速，MCU 用实测 RPM 反馈闭环，控制器为前馈 + PID；电机模型近似为一阶加死区时间（FOPDT）并含输入死区。
- **控制器到真实载具**：两种模式——**Thruster8**（直接指令八个推进器的推力或转速）与 **Wrench6**（指定 6-DOF 体坐标力旋量 τ_d = [F_x, F_y, F_z, M_x, M_y, M_z]ᵀ，可来自 PID、学习到的力旋量策略或手柄）。分配器求解带约束优化 f* = argmin_{f⁻≤f≤f⁺} ‖W(Bf − τ_d)‖² + λ‖f‖²，其中 B ∈ R^{6×8} 为分配矩阵，W 加权力旋量误差，λ > 0 正则化推力能耗，f⁻、f⁺ 为推力上下界。

## 三、实验设计

- **硬件与场景**：全部实验使用 **FinsROV** 在水池中、以水池固定坐标系进行（Fig. 3）。

- **B. 仿真动力学可靠性**：将记录的单轴水池激励在 Unity 的三种后端（标定 Fossen / 物理网格 / 简化 Fossen）中回放，与物理测量对比；8 次重复实验给出响应包络（Fig. 4），Table III 报告四轴等权 NRMSE 及试验级 bootstrap 95% 置信区间。
- **C. Sim-to-Real 迁移可靠性**：两个难度递进任务（改编自 MarineGym）：
  - **T1：4-DOF 定点保持**。固定参考 p* = [x*, y*, z*, ψ*]，FinsROV 在 60 s 试验中调节 8 个预注册设定点，横滚/俯仰保持水平；在 40–60 s 后段保持窗口评估位置与偏航 RMSE；成功需 |e_x|, |e_y|, |e_z| ≤ 0.10 m 且 |e_ψ| ≤ 10° 连续保持 10 s。
  - **T2：3D 轨迹跟踪**。跟踪直线、折线、椭圆、双纽线参考 p*(t) ∈ R³（x-z 平面水平，y 为垂直方向）；偏航/横滚/俯仰仅稳定不跟踪；报告水平 RMSE、垂直 RMSE、3D 位置误差 P95。
  - **策略训练**：统一使用 **PPO**（Stable-Baselines3），**seed 42**；对比 **DR / NoDR**（有/无域随机化）；由于篇幅仅展示 **Wrench6** 控制模式结果。基线包括传统 PID。
- **D. 消融研究**：T1 用于水动力学、感知、执行器消融；T2 仅用于 DR 对比。消融维度包括：水动力学后端（三种）、DR、执行器响应模型（去掉一阶推进器动态）、定位与状态估计（注入定位噪声；绕过 EKF 输入）。

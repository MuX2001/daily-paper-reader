## 摘要
自适应采样控制在控制性能与资源效率之间取得平衡。然而，现有方法要么无法保证速率切换过程中的鲁棒约束满足，要么需要计算代价高昂的在线优化。本文提出一种自适应采样控制框架，面向受多面体状态与输入约束以及有界加性扰动影响的线性系统。给定由推理器提供的时变参考控制更新速率，我们的框架持续计算模型预测控制（MPC）更新速率，以确保所有时间步的鲁棒约束满足。离线阶段，利用鲁棒 M 步保持控制不变性，为一组更新速率及其之间的转移集预计算不变集。在线阶段，这些集合被实时用于保证递归可行性和到参考更新速率的有限时间转移。该架构的有效性通过巡航控制仿真得到验证。

## Abstract
Adaptive-sampling control balances control performance with resource efficiency. However, existing methods either fail to guarantee robust constraint satisfaction during rate transitions or require computationally expensive online optimization. This paper proposes an adaptive-sampling control framework for linear systems subject to polytopic state and input constraints and bounded additive disturbances. Given a time-varying reference control update rate provided by a reasoner, our framework continuously calculates Model Predictive Control (MPC) update rates that ensure robust constraint satisfaction at all time steps. Offline, robust M-step hold control invariance is used to precompute invariant sets for a list of update rates and transition sets between them. Online, these sets are used in real time to guarantee recursive feasibility and finite-time transitions to the reference update rate. The utility of the architecture is demonstrated in a cruise control simulation.

## 1. 核心问题与整体含义

- **背景**：自适应采样控制通过在线调整控制输入的更新速率（update rate），在控制性能与资源开销（计算、能耗、通信、成本）之间取得平衡；在嵌入式控制、交通系统、医疗等场景中，降低更新频率可显著减少更新代价。
- **核心问题**：更新速率切换必须谨慎协调——既要保证切换过程中的鲁棒约束满足（安全性），又要权衡切换本身与后续控制性能的代价，同时尽量降低在线计算负担。
- **现有方法缺陷**：
  - 自适应采样 PID/LQR 基于启发式调整速率，无安全性保证；
  - 自适应采样 MPC 常改变采样时间，但不提供安全保证或原则性的整体性能权衡；
  - 自触发 MPC 需在线求解多个最优控制问题或混合整数规划（MIP），且无法保证收敛到参考更新速率；
  - Move-blocking MPC 要么需要每步更新以保证递归可行性，要么缺乏鲁棒性，要么无法在线自适应调整阻塞结构。
- **整体含义**：本文提出一种面向带多面体状态/输入约束和有界加性扰动的线性系统的自适应采样 MPC 框架，在跟踪高层"推理器"给出的时变参考更新速率的同时，提供严格的鲁棒安全保证，并将在线计算降为每个输入更新仅求解一个凸二次规划（QP）。

## 2. 方法论

### 2.1 系统与问题建模
- 离散时间线性时不变系统：$x_{t+1}=Ax_t+Bu_t+Ew_t$，满足 $x_t\in X$、$u_t\in U$、$w_t\in W_{\delta(t)}$。
- 输入采用**非周期保持**：第 $k$ 次保持长度为 $M_k$（"$M$-step hold"），更新时刻 $\tau_{k+1}=\tau_k+M_k$。
- 不确定性集 $W_{\delta(t)}$ 随距上次更新/测量的时间步数 $\delta(t)$ 增长，并在每次更新时重置（Assumption 1：$W_0$ 含零向量且 $W_i\subseteq W_{i+1}$），用于刻画扰动与建模误差的传播效应。

### 2.2 鲁棒 $M$-步保持 MPC
- 在每个更新时刻 $\tau_k$ 求解 OCP (2)：目标为跟踪（可能不安全的）参考轨迹 $\{x^{ref},u^{ref}\}$ 的二次代价；约束包括标称动力学、前 $M_k$ 步的收紧状态约束（用传播不确定性集 $E_i=\bigoplus_{j=0}^{i-1}A^{i-1-j}EW_j$ 收紧）、目标集约束 $\bar{x}_{\tau_k+M_k}\in X_{f,k}\ominus E_{M_k}$、尾部状态约束与输入保持约束 $\bar{u}_{\tau_k+i}=\bar{u}_{\tau_k+M_k\lfloor i/M_k\rfloor}$。
- 只对前 $M_k$ 步做鲁棒收紧，避免全时域顶点枚举的计算负担，同时保持鲁棒约束满足。
- MPC 将首个最优输入保持 $M_k$ 步：$u_{\tau_k}=\pi_{MPC}(x_{\tau_k},M_k,N_k,X_{f,k})$。

### 2.3 离线：转移规划（Alg. 1）
- 计算所有 $M\in\mathcal{M}$ 的**最大鲁棒 $M$-步保持控制不变集** $C^M_\infty$（定义 1、2 与前驱集 $\mathrm{Pre}^M(S)$），剔除空集。
- 定义**鲁棒 $N$ 步 $M$-步保持转移集** $T^M_N(S)$（定义 3）：递归构造 $T^M_0(S)=S\cap C^M_\infty$，$T^M_i(S)=\mathrm{Pre}^M(T^M_{i-M}(S))\cap C^M_\infty$；与 $C^M_\infty$ 相交保证轨迹在每个输入更新时刻仍留在 $C^M_\infty$，赋予中断转向的灵活性。
- 用 $T^M_N$ 求最坏情况转移步数上界 $\bar{N}(M,M')=\min\{N: C^M_\infty\subseteq T^M_N(C^{M'}_\infty)\}$；不可行则记为 $\infty$。
- 由 Thm. 1（$M'$ 是 $M$ 的因子 $\Rightarrow C^M_\infty\subseteq C^{M'}_\infty$）可知，因子关系下的保持缩短是即时安全的，$\bar{N}(M,M')=0$，只需考虑非因子组合。

- 选择 OCP 参数：$M_k=M^{(0)}$（式 9）；由 $\eta_k$ 计算 $\eta_k^+=\max(0,\eta_k-M_k)$ 并取目标集 $X_{f,k}=T^{M_k}_{\eta_k^+}(C^{M^{(1)}}_\infty)$（式 11，无需在线计算，直接检索预收紧集合）；$N_k$ 取 $M_k$ 的任意倍数。
- 稳态时规则自动退化为 $M_k=M^{ref}_k$、$X_{f,k}=C^{M^{ref}_k}_\infty$。

### 2.5 理论保证（Thm. 2）

## 6. 主要结论与发现

- 所提框架能够在线跟踪参考输入保持长度，同时**在所有时间步（不仅在更新时刻）鲁棒满足状态与输入约束**，并保证每个更新时刻的递归可行性。
- 在参考保持阶跃变化时，能在**有限时间**内收敛到参考保持策略。
- 在线计算仅需不等式测试与单个凸 QP，避免 MIP 与顶点枚举，显著降低在线负担。
- 巡航控制仿真表明：即使前车全力刹车，约束仍全程满足；当靠近不变集边界时降低更新速率可能不安全，此时控制器会施加最大安全保持或回退到先前保持。
- 振荡器仿真揭示了反直觉现象：**可行性并非关于保持长度单调**（$C^6_\infty$、$C^{12}_\infty$ 为空，而 $C^8_\infty$、$C^{10}_\infty$ 非空）；转移图能自动发现"为加快增大保持而暂时缩短保持"的间接计划。
- 状态相关推进（式 8、10）可使实际转移显著快于最坏情况调度（如 4→10 的转移 1 步完成，而调度为 6 步）。

## 7. 优点

- **理论完备**：给出鲁棒约束满足、递归可行性与有限时间收敛的严格证明，且保证仅依赖 OCP 约束，目标函数可任意选择（Remark 6）。
- **计算高效**：离线预计算不变集、转移集与计划/调度，在线退化为不等式测试 + 单个凸 QP，避免 MIP 与在线复杂优化。
- **架构灵活**：通过转移图与可调边代价，可自定义权衡指标（时间步、更新次数等）；集合与 $C^M_\infty$ 相交的设计（Remark 1）支持频繁变化的参考保持，允许安全中断转向。
- **可扩展性处理**：利用 Thm. 1 的因子性质与嵌套性质减少需计算的转移集数量；用强连通性条件保证图的可达性。
- **示例具有启发性**：振荡器案例展示了非单调可行性与间接转移策略，验证了框架的自动规划能力。

## 8. 不足与局限

- **实验覆盖有限**：仅两个小规模仿真，无硬件/实物验证，无与现有方法（自触发 MPC、move-blocking MPC 等）的定量对比，缺乏标准 benchmark。
- **缺少计算指标**：未报告离线集计算与在线求解的实际耗时、内存占用，无法充分支撑"低计算负担"的量化论断。
- **假设较强**：要求扰动界随 $\delta$ 单调增长且重置、$\mathcal{M}$ 有限且（间接）强连通；不变集/转移集需为空则剪枝，对高维系统离线集计算可能不可行（维度灾难未讨论）。
- **在线简化策略未充分比较**：巡航控制例中"最小化 $|M_k-M^{ref}_k|$"的搜索策略与其他策略（如基于代价函数）未做对比；$N_k=\max(\mathcal{M})$ 的固定选择也较简单。
- **应用限制**：框架针对 LTI 系统与多面体约束，状态相关不确定性（如巡航控制）迫使在线集计算，可能削弱离线预计算带来的效率优势；非线性或时变系统未涉及。
- **潜在偏差风险**：转移代价中的 $\epsilon$ 与计划选择依赖人工设计，可能影响最终行为；单次仿真的结果（如 19 次更新）缺乏统计意义上的重复验证。

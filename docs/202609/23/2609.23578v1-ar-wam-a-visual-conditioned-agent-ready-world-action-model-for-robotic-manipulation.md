## 摘要
随着AI智能体能力日益增强，由智能体驱动的机器人控制正成为一种颇具吸引力的范式。然而，主流的视觉-语言-动作（VLA）模型和世界动作模型（WAM）仍依赖自然语言指令来指定操作任务，这种接口并不适合智能体驱动的控制：存在指代歧义、空间不精确、与智能体固有的语言理解能力冗余，并且将意图与执行纠缠在一起。我们提出AR-WAM，一种视觉条件化、智能体就绪的世界动作模型，用两个互补条件取代语言：一个视觉定位提示（目标边界框），用于指示交互对象和位置；以及一个可学习的操作标记，用于指定要执行的原子技能。我们紧凑的0.5B参数模型采用冻结的预训练视觉编码器且不含语言编码器，在解码动作的同时在紧凑潜在状态中预测场景演化，并通过显式、可监督的推理信号暴露策略的意图。一个模型无关的兼容层提供三个原语（检测、执行和查询），使本地VLM或在线智能体API能够直接驱动该策略，而长时程记忆和闭环错误恢复则交由智能体侧处理。在RoboTwin 2.0、RMBench以及真实的Astribot S1双臂平台上，AR-WAM在标准操作任务上达到与最强基线相当的性能（平均成功率87.2%），并在依赖记忆的任务和真实机器人长时程任务上优于这些基线，成功率分别提升5.9%和36.7%，同时保持最低的推理延迟（14.1 ms）。

## Abstract
As AI agents become increasingly capable, agent-driven robotic control is emerging as a compelling paradigm. However, prevailing vision-language-action (VLA) models and world action models (WAMs) still rely on natural-language instructions to specify manipulation tasks, an ill-suited interface for agent-driven control: referentially ambiguous, spatially imprecise, redundant with the agent's inherent language understanding, and entangling intent with execution. We present AR-WAM, a visual-conditioned, agent-ready world action model that replaces language with two complementary conditions: a visual grounding prompt (a bounding box of the target) denoting the interaction object and location, and a learnable operation token dictating the atomic skill to execute. Our compact 0.5B-parameter model, with a frozen pretrained visual encoder and no language encoder, predicts scene evolution within compact latent states while decoding actions, exposing the policy's intent through explicit, supervisable reasoning signals. A model-agnostic compatibility layer provides three primitives (detect, execute, and query) so that local VLMs or online agent APIs can drive the policy directly, with long-horizon memory and closed-loop error recovery delegated to the agent side. On RoboTwin 2.0, RMBench, and a real Astribot S1 dual-arm platform, AR-WAM matches the strongest baselines on standard manipulation (87.2% average success) and outperforms them on memory-dependent and real-robot long-horizon tasks, improving success rates by 5.9% and 36.7%, respectively, while maintaining the lowest inference latency (14.1 ms).

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：以智能体（agent）作为高层大脑、以策略模型作为“小脑”的机器人控制范式日益受到关注。策略侧主要有两条技术路线：视觉-语言-动作（VLA）模型与世界动作模型（WAM），二者均通过自然语言指令指定操作任务。
- **核心问题**：作者认为在智能体驱动的控制中，**文本条件接口本身不合适**，具体表现为四点：
  - **指代歧义**：桌面上存在多个相似物体时，文本难以唯一确定目标。
  - **冗余**：语言理解本是智能体的强项，在策略内部重新学习语言浪费训练算力。
  - **空间不精确**：指令需经策略自身的语言编码器，接地不完美会妨碍精确操控。
  - **黑箱纠缠**：把理解、规划、记忆与动作生成塞进一个不可检查的模型，失败时无法区分是意图错误还是执行不当。
- **整体含义**：论文主张重新思考智能体时代策略真正需要的条件信号，用**视觉定位框 + 可学习操作 token** 取代自由形式语言，将“在哪里做”（由外部智能体的开放词汇感知完成）与“怎么做”（由紧凑策略完成）解耦。规划、记忆与错误恢复留给智能体，策略只负责可靠执行。

## 2. 方法论

### 2.1 核心思想
- 用两个互补条件替代语言指令：
  - **视觉定位提示** `g`：归一化图像坐标下的目标边界框 `(x1,y1,x2,y2)`，空间上唯一标识交互对象与位置；双臂任务可扩展为两个框。
  - **可学习原子操作 token** `es`：从有限技能词汇 `S = {pick, place, handover, click, pull, ...}` 中指定当前原子技能。
- 可选辅助属性：**participants** `u`（左臂/右臂/双臂）与 **style** `w`（交互方式，如叠放或并排放置），各用可学习嵌入表示。
- 条件通过 **AdaLN 条件调制** 注入策略：`es、eu、ew` 与框嵌入 `φ(g)`（轻量 MLP）融合为任务条件 token。

### 2.2 策略形式化
- 在时刻 `t`，策略接收单主视角图像 `ot` 与本体状态 `pt`，输出动作块 `â_{t→t+H-1}`，参数在所有原子操作间共享：
  `â ∼ πθ(· | ot, pt, φ(g), es, eu, ew)`。
- `πθ` 由**推理专家**与**世界动作专家**共同实例化，二者共享同一个 0.2B transformer。

### 2.3 推理专家与可监督推理信号
- 可学习推理 query token `q_reas` 探测观测与任务条件，产生推理 token `qt`。
- 轻量 reason head 将 `qt` 解码为三项显式、可监督的当前步预测：
  - `m̂t`：被框选物体的掩码（把粗框细化为像素级目标）；
  - `T̂t`：技能终止时双臂末端执行器位姿；
  - `ĉt`：结构化 one-hot 任务摘要（用哪只臂、如何抓放等）。
- 推理损失：`L_reas = BCE(m̂,m) + CE(ĉ,c) + ||T̂−T||²`，同时可作为失败诊断信号。

### 2.4 前景 gist 提取（离线预训练）
- 冻结编码器 `E` 将同一片段两端帧 `ot0、ot1` 映射为潜帧；潜逆动力学模块将其压缩为**前景 gist**：`f = G_IDM(E(ot0), E(ot1))`，无需动作或中间帧。
- 潜前向动力学模块从当前帧与 gist 重建未来潜帧，以潜重建损失 `L_recon` 训练。
- gist 仅作为训练目标，推理时不使用。

### 2.5 世界动作专家与双层前景对齐
- 与推理专家共享 transformer、不同输入 token，使任务理解直接塑造控制。
- 用单一去噪器以 **flow matching** 联合去噪三种模态（动作、视觉前景、语义前景），各模态独立采样噪声、共享同一流时间 `τ`：
  - **动作分支** `L_act`：回归动作插值速度；
  - **视觉前景** `L_vis`：预测“场景将看起来如何”，对齐离线 gist `f_{t→t+H-1}`；
  - **语义前景** `L_sem`：预测“场景将意味着什么”，对齐由权重共享推理骨干在未来观测上在线产生的推理 token `q_{t+H-1}`。
- 前景目标均使用 stop-gradient，只塑造共享表示而不反传至观测编码路径；语义目标由同一骨干在线计算，因推理 token 受 reason head 显式监督，故不会表示坍缩。
- 块注意力掩码使动作与前景分支能条件于推理输出而不污染推理；推理 pass 与第一步去噪共享一次前向，后续步骤复用 KV cache。

### 2.6 训练目标
- 联合目标：`L(θ) = L_act + λ_reas·L_reas + λ_vis·L_vis + λ_sem·L_sem`。
- 数据混合 RoboTwin 2.0 与 RMBench 仿真数据，将真值物体状态转为边界框视觉提示；训练时对框中心、高、宽随机抖动，以容忍部署时智能体给出的不精确框。

### 2.7 智能体兼容层与失败恢复
- 提供**模型无关三原语**：
  - `detect(y) → g`：完全在智能体侧完成，用自身接地能力把查询（如“红色杯子”）转为框，仅框进入策略（策略内无语言通路）；
  - `execute(g,s,u,w) → ξ`：滚动执行策略直至触发事件，返回执行轨迹；
  - `query(ξ) → b`：把结果反馈打包给智能体下一步推理。
- **事件触发调用**：不逐步调用智能体，而由四类事件触发——末端位移超阈值、夹爪闭合、夹爪张开、固定时间间隔到期。
- **长时程与记忆**：策略刻意保持**马尔可夫性**（无内部循环状态），所有子目标跟踪、失败与下一步均由智能体历史与记忆承载，扩展时只需扩展智能体上下文而非重训策略。
- **失败恢复**：抓取失败或物体掉落时，智能体判断子任务完成情况，重新 `detect` 获得更新框 `g'` 并在固定重试预算内再次 `execute`；策略解码的意图信号帮助区分“意图错误”与“执行不当”。

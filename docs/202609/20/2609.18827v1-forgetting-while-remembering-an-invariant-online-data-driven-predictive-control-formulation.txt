# Forgetting While Remembering, an Invariant Online Data-Driven Predictive Control Formulation 

Alessandro Chiuso, Florian D¨ orfler, and Keith Moffat 

Abstract — Low signal-to-noise ratio (SNR) data is a core challenge of online Data-Driven Predictive Control (DPC) for linear, time-varying systems. This paper proposes a Bayesian, online DPC framework based on autoregressive models with exogenous inputs (ARX) that uses an externally-provided prior, which encodes inductive bias such as smooth system dynamics and stability, to safeguard performance when SNR is low. The posterior estimate of the ARX parameter is propagated forward in time using a Kalman filter with a state equation defined by an adaptation-rate hyperparameter, which is adjusted online to track the rate at which the underlying system dynamics evolve. The Kalman filter’s posterior mean and covariance determine the DPC’s Final Control Error cost function, which is the posterior expectation of the quadratic cost function. Critically, the Kalman filter’s process equation is chosen so that, regardless of the hyperparameter adaptation, the prior distribution is invariant over time. Thus, while old data is forgotten, the prior is not. DPC tracking experiments on a time-varying second-order system demonstrate the efficacy of the proposed method. 

I. INTRODUCTION Data-Driven Predictive Control (DPC) has gathered at-tention in recent years due to its ease of implementation [1]–[8]. Much of the literature has focused on the linear, time-invariant setting, in which the system’s behavior can be modeled as a linear combination of sufficiently-exciting data [9]. In this paper, we focus on adapting the controller in the linear, time-varying setting. Like other Adaptive Control formulations, Online DPC is challenging because the appropriate adaptation rate is system-dependent and time-varying. When the system changes quickly, relying too heavily on old data can produce an incorrect system representation and degrade control per-formance. Conversely, if the system changes slowly, relying too heavily on recent data can produce online training data SNR deficiencies, loss of stability, and robustness problems such as bursting phenomena [10]. Focusing on adaptive predictive control approaches, [11] introduces a change detection mechanism which triggers the collection and use of fresh data, based on which a controller is re-designed. A recursive Data-Enabled Predictive Control (DeePC, [1]) is proposed in [12]. Similarly, [13] uses the recent input-output data to form a local-linear approximation

In contrast, [12] addresses this issue through a two-level optimization problem that constructs multi-step predictions from a single-step predictor. However, neither method uses an adaptive forgetting factor, and thus both are susceptible to low-SNR data issues. Bayesian recursive-in-time parameter estimation, includ-ing the Kalman filter, provides an alternative framework for model adaptation. It has a long history, including, for example, [16]–[18], and we refer the reader to [19] for a recent overview of the literature. Recursive Least Squares can be viewed as a special case of the Kalman filter, where the forgetting factor is replaced by the process noise variance [20], [21]. The literature contains many examples of adjusting the forgetting rate/process noise online, based on observed data [17], [22], [23], including methods that adjust the forgetting factor online by marginal-likelihood optimization [24]. Variable forgetting rates [17], [22]–[24] can help address low SNR by reducing the forgetting rate when the dynamics vary slowly. Another way to improve estimation performance with low SNR data is to use a prior. Encoding inductive bias (e.g., the system is smooth and/or stable) as a prior anchors the Bayesian estimate, reducing the impact of measurement variance. We propose an adaptive Kalman filter ARX parameter estimation algorithm with the following characteristics. First ,rather than adapting the process noise (equivalent to the forgetting factor in the Recursive Least Squares context), as is common in the literature [17], [22]–[24], we adapt the process equation online to “forget” older data. Second ,the adaptive Kalman filter is designed so that, regardless of how the process equation is adapted, the prior distribution of the model parameter is invariant . To the best of our knowledge, the proposed Kalman filter parameter estimator with an invariant prior and adaptive process equation is novel in the context of adaptive filtering and control. In addition to the parameter estimator, we also employ a Bayesian DPC optimization. We build off the work in [3], which introduced the Final Control Error (FCE) for an uninformative prior and showed that the mean and variance of the ARX parameters are sufficient for quadratic FCE-minimizing predictive control. Conveniently, the Kalman filter updates the posterior mean and variance of the ARX parameters, which can be directly plugged into the FCE-minimizing DPC optimization. As this formulation is based arXiv:2609.18827v1 [eess.SY] 16 Sep 2026 on a single-step-predictor, it does not suffer from closed-loop bias issues [14], [15], [25]. Summarizing, this paper proposes an online DPC algo-rithm for linear, time-varying systems which 1. recursively updates the predictor mean and variance using a Kalman filter, 2. updates the Kalman filter process equation using Em-pirical Bayes-based gradient updates, and 3. parametrizes the predictive control cost function to minimize the FCE (the posterior expectation of the quadratic predictive control cost). Before describing the adaptive Kalman filter formulation, we consider two extreme cases of time-varying systems: 1. A white noise system : θt is temporally uncorrelated such that θt provides no information on θt+1 .2. A time-invariant system : θt is constant in time and thus 

θt = θt+1 .Each extreme case has modeling benefits and weaknesses— Estimating a parameter using the white-noise system model allows quick adaptation when the underlying system changes, but only uses the most recent measurement. Estimating a parameter using the time-invariant assumption, on the other hand, weighs all data equally and thus does not adapt effectively when the underlying system changes. We propose a method that interpolates between these two extreme cases in an adaptive, data-driven manner in order to adjust to time-varying evolution rates.

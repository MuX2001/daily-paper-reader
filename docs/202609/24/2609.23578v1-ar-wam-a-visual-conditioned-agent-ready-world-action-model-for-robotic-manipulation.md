## 摘要
随着AI智能体能力日益增强，由智能体驱动的机器人控制正成为一种颇具吸引力的范式。然而，主流的视觉-语言-动作（VLA）模型和世界动作模型（WAM）仍依赖自然语言指令来指定操作任务，这种接口并不适合智能体驱动的控制：指代模糊、空间不精确、与智能体固有的语言理解能力冗余，并且将意图与执行纠缠在一起。我们提出AR-WAM，一种视觉条件化、智能体就绪的世界动作模型，它用两个互补条件替代语言：一个视觉定位提示（目标边界框），用于指示交互对象和位置；以及一个可学习的操作标记，用于指定要执行的原子技能。我们紧凑的0.5B参数模型，采用冻结的预训练视觉编码器且不含语言编码器，在解码动作的同时在紧凑的潜在状态中预测场景演化，并通过显式、可监督的推理信号暴露策略意图。一个与模型无关的兼容层提供三种原语（检测、执行和查询），使本地VLM或在线智能体API能够直接驱动该策略，而长时程记忆和闭环错误恢复则交由智能体一侧处理。在RoboTwin 2.0、RMBench以及真实的Astribot S1双臂平台上，AR-WAM在标准操作任务上与最强基线相当（平均成功率87.2%），并在依赖记忆的任务和真实机器人长时程任务上优于它们，成功率分别提升5.9%和36.7%，同时保持最低的推理延迟（14.1 ms）。

## Abstract
As AI agents become increasingly capable, agent-driven robotic control is emerging as a compelling paradigm. However, prevailing vision-language-action (VLA) models and world action models (WAMs) still rely on natural-language instructions to specify manipulation tasks, an ill-suited interface for agent-driven control: referentially ambiguous, spatially imprecise, redundant with the agent's inherent language understanding, and entangling intent with execution. We present AR-WAM, a visual-conditioned, agent-ready world action model that replaces language with two complementary conditions: a visual grounding prompt (a bounding box of the target) denoting the interaction object and location, and a learnable operation token dictating the atomic skill to execute. Our compact 0.5B-parameter model, with a frozen pretrained visual encoder and no language encoder, predicts scene evolution within compact latent states while decoding actions, exposing the policy's intent through explicit, supervisable reasoning signals. A model-agnostic compatibility layer provides three primitives (detect, execute, and query) so that local VLMs or online agent APIs can drive the policy directly, with long-horizon memory and closed-loop error recovery delegated to the agent side. On RoboTwin 2.0, RMBench, and a real Astribot S1 dual-arm platform, AR-WAM matches the strongest baselines on standard manipulation (87.2% average success) and outperforms them on memory-dependent and real-robot long-horizon tasks, improving success rates by 5.9% and 36.7%, respectively, while maintaining the lowest inference latency (14.1 ms).

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：随着 AI 智能体能力增强，"智能体作高层大脑 + 策略模型作小脑"的机器人控制范式逐渐兴起。策略侧沿两条技术路线演进：视觉–语言–动作（VLA）模型将网络规模语义知识迁移到连续控制，世界动作模型（WAM）则通过预测场景演化来推导动作。
- **核心问题**：无论 VLA 还是 WAM，任务几乎都由**自然语言指令**来指定。作者主张，在智能体驱动控制场景下，文本条件是一种**不适配的接口**，理由有四：
  - **指代模糊**：桌面上存在多个相似物体时，文本难以唯一确定目标。
  - **冗余**：语言理解本是智能体最擅长的事，在策略内部重新学习它浪费训练算力。
  - **空间不精确**：指令需经过策略自身语言编码器，其不完美接地妨碍精确操控。
  - **黑箱纠缠**：把理解、规划、记忆、动作生成糅进一个不可审视的模型，导致失败无法在"意图错误"与"执行不当"之间归因。
- **整体含义**：论文重新思考"智能体时代策略真正需要什么条件信号"，提出用**空间化接口替代语言接口**——由外部智能体负责语言理解、任务分解与记忆，策略只专注精确动作生成，从而形成一种更清晰、可诊断、可互换的智能体–策略契约。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想
- 用**两个互补条件**替代自由形式语言指令：
  - **视觉定位提示**：目标物体的归一化边界框 `g = (x1, y1, x2, y2) ∈ [0,1]^4`，指明"在哪里动作"；双臂任务扩展为两个框。
  - **可学习原子操作 token**：在有限技能词表 `S = {pick, place, handover, click, pull, ...}` 中选取 `s`，指明"做什么动作"。
- 由此解耦 **where（定位，交给外部智能体）** 与 **how（控制，由紧凑策略处理）**。
- 智能体还可指定两个辅助属性：**参与者属性 u**（哪只臂：左/右/双臂）与**风格属性 w**（交互方式，如置于上方或旁边），各由可学习嵌入表示。

### 2.2 策略形式化
- 策略接收观测 `ot`（单主视角图像）与本体状态 `pt`，输出动作块 `â_{t→t+H-1}`：
  - `â ∼ πθ(· | ot, pt, φ(g), es, eu, ew)`，其中 `φ(g)` 为框嵌入（轻量 MLP），`es, eu, ew` 为操作/参与者/风格嵌入。
  - 所有原子操作共享参数 θ，使不同技能数据互相强化共享的视觉运动表征，并保持单一可部署产物。
- 条件通过 **AdaLN 条件调制**融合成任务条件 token，注入下游专家。

### 2.3 推理专家与可监督推理信号
- 推理专家用一组可学习**推理查询 token** `q_reas` 探测观测与任务条件，产生推理 token `qt`。
- 轻量推理头将其解码为三类**显式可监督预测**：
  1. 框内物体的**掩码** `m̂t`（把粗框锐化为像素级目标）；
  2. 技能终止时双臂**末端执行器位姿** `T̂t`；
  3. **任务摘要** `ĉt`（结构化 one-hot，描述用哪只臂、如何抓放等）。
- 推理损失：`L_reas = BCE(m̂t, mt) + CE(ĉt, ct) + ‖T̂t − Tt‖²`。这些预测既是训练目标，也作为**失败诊断信号**。

### 2.4 未来 gist 提取（离线训练目标）
- 在演示序列上预训练一个**离线未来 gist 提取器**：
  - 冻结编码器 `E`（DINOv3）将片段两端帧 `o_t0, o_t1` 映射为隐帧；
  - 隐式逆动力学模块 `G_IDM` 将时序演化压缩为**未来 gist**：`f_{t0→t1} = G_IDM(E(o_t0), E(o_t1))`；
  - 隐式前向动力学模块 `G_FDM` 由当前帧与 gist 重建未来隐帧：`ê_t1 = G_FDM(E(o_t0), f_{t0→t1})`；
  - 以隐重建损失 `L_recon = ‖ê_t1 − E(o_t1)‖²` 训练。
- gist 从未来观测计算，**仅作为训练期目标，推理时不使用**。

### 2.5 世界动作专家：双层未来对齐
- 与推理专家**共享 Transformer 权重**，但输入 token 不同，使任务理解直接塑造控制。
- 以流匹配（flow matching）对**三种模态联合去噪**：动作块、视觉未来、语义未来，共享一个去噪器 `f_wam` 与共享流时间 τ：
  - **动作损失**：`L_act = E‖f_wam(aτ, τ) − (a1 − a0)‖²`（回归插值速度）。
  - **视觉未来损失**：`L_vis = ‖f_wam(fτ, τ) − sg(f_{t→t+H-1})‖²`，对齐离线提取的 gist，即"场景将**看起来**怎样"。
  - **语义未来损失**：`L_sem = ‖f_wam(qτ, τ) − sg(q_{t+H-1})‖²`，对齐权重共享的推理骨干从未来观测产生的推理 token，即"场景将**意味着**什么"；`sg(·)` 为停止梯度，目标在线自举但受推理头显式监督，故不会表征塌缩。
- **块注意力掩码**约束 token 组 `{E(ot), pt, q_reas, â, f̂, q̂}`：动作与未来分支可条件于推理输出而不污染推理；**推理 pass 与首个去噪步共享一次前向**，其余步复用 KV cache。

### 2.6 训练目标
- 端到端联合目标：`L(θ) = L_act + λ_reas L_reas + λ_vis L_vis + λ_sem L_sem`。
- **数据**：混合 RoboTwin 2.0 与 RMBench 仿真数据，把真值物体状态转换为边界框视觉提示。
- **视觉提示增强**：训练时随机抖动框的中心、高度与宽度，使策略容忍部署时智能体给出的松散/略偏框。

### 2.7 智能体兼容层与失败恢复
- 把智能体建模为"模型 + 外壳（harness）"：LLM/VLM 包裹系统提示与规则、可调用工具、交互历史与控制循环。
- **三种模型无关原语**：
  - `detect(y) → g`：完全在智能体侧运行，用其自身接地能力把查询 y（如"红杯子"）定位成框，只有框进入策略（策略内无语言通路）。
  - `execute(g, s, u, w) → ξ`：滚动执行策略直到触发事件，返回执行轨迹。
  - `query(ξ) → b`：把结果反馈打包给智能体下一步推理。
- **事件触发调用**：不在每个控制步调用智能体，而由四类事件触发——(i) 累计末端位移超阈值、(ii) 夹爪闭合、(iii) 夹爪张开、(iv) 固定时间间隔到达；每次触发返回触发原因、夹爪状态与当前观测。
- **长时程与记忆**：策略 πθ 刻意保持**马尔可夫性**（无循环状态），长时程结构（子目标追踪、失败、下一步）全部由智能体历史与记忆承载，从而避免单体反应式策略所需的专用记忆架构，靠扩展智能体上下文而非重训策略来延长时程。
- **失败检测与恢复**：抓取失败或掉落物体由闭环处理而非硬编码恢复行为——智能体判断子任务完成情况，失败时重新 `detect` 得到更新提示 `g'` 并重发 `execute`（固定重试预算），且策略解码意图可帮助区分"意图错误"还是"执行不当"。

## 3. 实验设计

### 3.1 数据集与场景

### 3.2 Benchmark 与对比方法

## 6. 主要结论与发现

- **RQ1（视觉条件可替代语言）**：在相同训练下，把视觉提示换成文本指令平均成功率**下降 13.0%**；在视觉提示之上再加文本也无益（−2.6%），说明一旦有空间接地，语言是冗余的。
- **RQ3（组件与调制）**：
  - 去掉推理专家 **−7.8%**，去掉未来对齐 **−8.6%**，二者均对动作质量有实质贡献。
  - 用原始未来 patch 替代压缩 gist **−10.8%**，甚至低于完全无未来预测的版本，说明**gist 的压缩性**才是未来信号有用的关键。
  - AdaLN 换成交叉注意力 **−13.8%**；原因在于交叉注意力对本体状态依赖高 2.3 倍（35.6% vs 15.5%），而 AdaLN 对语义束依赖高 2.1 倍（31.5% vs 15.3%）——本体状态依赖过重符合模仿策略的**捷径学习**失效模式，绕过语义条件、损害泛化。
- **标准操作性能**：RoboTwin 2.0 随机设置下取得最佳平均成功率 **84.2%**，干净设置 **87.2%**（仅比最强基线低 0.6%）。

## 摘要
我们提出 Underwater C$^{3}$-JEPA（跨视角、控制条件化、上下文扩展），一种面向近场重载水下 ROV 打捞的以对象为中心的多视角预测世界模型。无需接触式传感器，它从同步多视角 RGB 观测和载体控制信号中，在潜在空间中预测任务对象状态如何通过接触交互以及在水下航行器的水动力滞后下演化。C$^{3}$-JEPA 将多相机观测编码为任务对象 token 和上下文 token，通过留出视角注意力融合跨相机证据，并直接预测以控制为条件的未来状态。弱绑定以低标注成本锚定目标和夹爪，而 SIGReg 锐化几何表示。实验表明，与无重建的潜在基线相比，学习到的表示能向下游探针传递显著更多任务相关信息，同时保持预测器轻量。由此得到的预测接口支持模型预测控制（MPC）候选评估和想象 rollout 的行为智能体训练。在真实水下视频上的验证表明，同一架构能够恢复被留出相机的对象状态，并持续优于持久性预测，因此该方案可迁移到仿真之外。

## Abstract
We present Underwater C$^{3}$-JEPA (cross-view, control-conditioned, context-extended), an object-centric multi-view predictive world model for near-field heavy-load underwater ROV salvage. Without contact sensors, it predicts in latent space how the task-object state evolves through contact interaction and under the hydrodynamic lag of the vehicle, from synchronized multi-view RGB observations and vehicle control signals. C$^{3}$-JEPA encodes multi-camera observations into task-object and context tokens, fuses cross-camera evidence through held-out-view attention, and directly predicts future states conditioned on control. Weak binding anchors the target and gripper at low annotation cost, while SIGReg sharpens the geometric representation. Experiments show that the learned representation transfers substantially more task-relevant information to downstream probes than a reconstruction-free latent baseline, while keeping the predictor lightweight. The resulting predictive interface supports model-predictive-control (MPC) candidate evaluation and imagined-rollout behavior-agent training. Validation on real underwater video shows the same architecture recovering a withheld camera's object state and staying ahead of persistence, so the recipe transfers beyond simulation.

- **平台特殊性**：本文平台不是灵巧机械臂，而是**成对连杆驱动的欠驱动夹爪**（向下闭合），以自由度换取负载能力；其运动学存在耦合、依赖接触、部分闭环，且**无接触传感器**。
- **决策窗口的感知困境**：在决定性的近场窗口中，目标可能出现在多相机合成视场的任意方位，被船体与夹爪遮挡，在浑浊度与低对比度下任一单视角仅部分可见。视觉 SLAM 会漂移、在背向散射下丢失跟踪，且短程接近无需回环；结构光更稠密但要求短距、标定投影仪与驻留扫描运动——两者都**重建了超出决策所需的信息**。
- **控制侧的约束**：真实系统学习须在少量试次、控制频率下、在大而未知的驱动延迟下成功；仿真又难以处理该夹爪（闭环运动学链使约束动力学刚化，导致极小步长、软约束松弛或求解失败）。触觉仪器脆弱昂贵，需耐压壳体与线缆。
- **核心问题**：论文提出更窄的问题——**板载视觉通道能否压缩为一个状态，使目标与夹爪在跨视角、贯穿接触的过程中保持可辨识，并支持 rollout**。

## 2. 方法论

### 2.1 核心思想

- 提出**以对象为中心的感知域（OCPD, Object-centric Perception Domain）**：任务对象类（目标与夹爪）保持全保真并**强制跨相机对齐**，其余证据保留在**未对齐的自由上下文槽**中。
- 通过**引导式对象中心跨视角融合（GO-CVF, Guided Object-centric Cross-View Fusion）** 实现该路由：分解固定了哪些实体获得 token，因此融合可适配 ROV 算力预算，新任务类可经同一弱锚定路径廉价合成。

### 2.2 架构与关键技术

- **Stage I — 表示编码**：冻结 DINOv3-L 特征提取器将每个视角映射为 patch 特征；时序 slot 编码器（VideoSAUR 分支）输出 K 个 slot。共 **6 个 slot：3 个绑定 slot（目标 UUV、夹爪、固定 ROV 框架）+ 3 个自由上下文 slot**。框架 slot 因固定位姿遮挡所有视角，被设为仅绑定 slot，排除于跨视角融合与预测状态之外。
- **预测状态构造**：跨视角注意力产生共享的目标与夹爪 token，预测状态为
  `z_t = [s̄_target, s̄_grip, s^vr_3, s^vr_4, s^vr_5]`（vr 为后置相机参考视角，同时作为自由 slot 的预测目标）。
- **弱绑定（Weak Binding）**：以 patch-to-slot 方式而非分离式 DINO 分割头；冻结 DINOv3 patch 证据与弱目标/夹爪锚点打分，选定支撑引导 VideoSAUR slot mask；身份由与查询向量 `q_target`、`q_grip` 的亲和度 argmax 指定。锚点为 DINOv3 聚类提议，仅对歧义帧保留人工复核。
- **总损失**：`L_repr = L_feat + λ_b·L_bind + λ_m·L_merge + λ_t·L_timesim + λ_v·L_vis + λ_s·L_SIGReg`。其中 `L_feat` 重建冻结 DINOv3 patch 特征，自由 slot 无对象身份标签，`L_timesim` 保持时序一致，`L_vis` 监督绑定对象的逐视角可见性。
- **SIGReg**：Sketched Isotropic Gaussian Regularizer。将 token 嵌入 Z 投影到 M 个随机单位方向，对每个投影施加单变量 Epps–Pulley 正态性统计量 T(·) 并平均；Cramér–Wold 构造使一维投影成为完整分布的可处理代理。它正则化 token 几何，但**不赋予目标/夹爪语义**（语义来自弱绑定与对象特征重建）。
- **留出视角融合（Held-out-view Fusion）**：对每个绑定对象，交叉注意力接收可见视角 token 返回融合 token；训练时目标视角 v* 被排除于 keys 与 values 之外，视角条件化解码器预测其被留出特征证据（`L_merge`，`q^{v*}` 掩蔽真正不可见的对象）。该设计**不要求所有相机外观坍缩**，同时抑制直接复制。
- **Stage II — 控制条件化 JEPA 预测**：条件向量 `c_t = [ũ_1..ũ_12, g̃_1..g̃_6]`（12 个推进器通道 + 6 个夹爪通道），MLP 产生 AdaLN-Zero 参数；给定 4 帧历史预测 12 帧未来，最小化 token MSE + 余弦距离。**预测器仅 1.33 M 参数**。仿真中由指令（而非实测运动）驱动，因此推力建立、附加质量惯性与交叉耦合等水动力映射被内化于预测器；控制接口模态无关（仿真用推进器/夹爪指令，现场用记录控制与 DVL 导出运动驱动同一自回归 rollout）。

- **递归 rollout 显著优于持久性与打乱对照**：在教师强制下预测误差随 horizon 增长缓慢；递归 rollout 按 horizon 分层报告，目标与夹爪 token 的 MSE/余弦距离在 5 s / 10 s / 15 s 各层均优于 persistence 与窗口内打乱对照，说明预测器学到的是**可传播的动力学而非帧间复制**。长上下文（8.0 s）与 unroll 正则化进一步降低长 horizon 漂移，但边际收益递减，作者据此选择短上下文为主配置。
- **扰动实验呈现"可解释的意外度"**：在 4 种合成扰动 × 12,000 窗口上，控制信号被替换或目标运动被扰动时，预测残差按扰动类型系统性升高，而非均匀膨胀；这表明潜在动力学对**控制输入—状态响应**具有方向性敏感度，而非对所有输入同等反应。
- **跨视角一致性成立**：在 15 条交互记录上按 horizon 分箱，目标与夹爪的跨视角 token 一致性随接触临近而提高（遮挡加剧时融合收益最大），支持"约束式融合在遮挡下反而更稳"的假设。
- **因果一致性方向正确**：以方向余弦度量预测状态变化与夹爪指令/运动相位的对齐，接近与抓取接触相位的余弦显著高于随机相位，提示预测状态捕获了**指令—运动—接触**的时序因果链。
- **下游迁移优于无重建世界模型**：在夹爪关节角、目标相对位置、目标偏航三个探针头上，C³-JEPA 表示在相同数据、相同探针与优化下优于 LeWM，且优于线性读出，说明**对象中心重建监督提供了 LeWM 仅 SIGReg 所缺失的任务相关结构**；但优势幅度在部分探针上有限，且未做多随机种子方差估计。
- **决策层可行但有保守性**：MPC 匹配端点排序在 90 组候选（每组 4 条轨迹）上给出可执行动作排序，闭环仿真中保守策略可完成任务，但排序对 horizon 与 rollout 误差敏感；论文将其定位为"可行性证据"而非性能基准。
- **现场验证支持跨域可用性，但受限于标定**：部署 A（钢框架导航，77 段）与部署 B（铝管接触交互，36 段）分别报告，mask 项消融臂在现场同样有效；由于未测内外参、无度量真值，现场结果仅能支持**定性/相对**结论，不能作为绝对精度证据。

## 7. 局限性与不足

- **标定缺失**：现场两台相机未测内参/外参，目标无度量真值，位姿/图像空间误差只能作为**标定限制下的相对读数**。
- **单次运行**：多数消融臂仅一次训练运行，边际差异应读作效应量而非显著性/方差估计；留出视角专门评测用固定随机窗口而非记录不相交划分，**确立机制但不构成泛化估计**。
- **仿真简化**：水体光学为通道级衰减 + 高斯噪声，非完整辐射传输；未建模悬浮颗粒、动态浑浊与真实背向散射。
- **算力参考性**：1.97 ms / 窗口为数据中心 A800 参考值，嵌入式移植与实时性未验证。
- **语义依赖弱绑定**：对象语义来自 DINOv3 聚类提议的弱锚定，对未见对象类别的可扩展性、对锚点质量的敏感性未充分压力测试；歧义帧仍需人工复核。
- **场景窄化**：仅在单载体、特定夹爪、特定池体规模上验证；跨载体、跨夹爪、跨水域的迁移未涉及。

## 8. 主要贡献

1. **问题重述**：把水下抓取的感知问题从"重建几何"收缩为"压缩为可 rollout 的任务状态"，明确反对重建超出决策所需信息。
2. **OCPD 与 GO-CVF**：提出对象为中心、跨相机强制对齐、其余证据置于自由槽的感知域，并给出弱绑定 + 留出视角融合的具体实现，使融合可按算力预算伸缩、新任务类可廉价合成。
3. **SIGReg**：以 Cramér–Wold 投影给出可处理的各向同性高斯正则，改善 token 几何而不赋予语义。
4. **五级证据阶梯**：提出表示—预测—rollout—可观测量—决策的严格证据分级，并明确"上一级改进不构成下一级证据"的方法论原则。
5. **轻量控制条件化预测器**：1.33 M 参数、模态无关控制接口，在仿真与现场共用同一自回归 rollout。

## 9. 总体评价

- **方法层面**：论文的核心洞见——**用绑定约束把语义结构注入 slot 表示，同时让融合在留出视角下受正则化**——在等预算消融中得到了干净的支持，且以小幅重建代价换取显著语义增益，设计取舍清晰。
- **证据层面**：五级阶梯与负对照（persistence、打乱、均值 token）设置严谨，是本文相较同类工作最值得借鉴之处；但**单次运行、固定窗口评测、现场无标定**三条限制使部分结论停留在"机制成立、量级参考"层面。
- **写作与可复现层面**：控制条件化、弱绑定、损失项与资源开销披露较充分；但 GPU 型号/总时长缺失、部分超参（如 λ 具体值、SIGReg 权重除 0.03 外的设置）未完整给出，复现存在一定门槛。
- **定位**：适合作为"感知为决策服务"的水下操作范式论文阅读，其价值更多在于**问题收缩与证据分级方法论**，而非在单一指标上大幅刷新 SOTA；后续工作应在多随机种子、嵌入式实时性与跨域标定上补强。

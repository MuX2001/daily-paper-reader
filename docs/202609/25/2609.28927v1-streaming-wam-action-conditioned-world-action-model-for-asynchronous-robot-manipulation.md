## 摘要
在世界动作模型（WAMs）中，若在推理时使用未来视觉预测，会带来可观的生成开销。异步执行通过将推理与机器人运动重叠来减少等待，但用于后续动作生成的视觉预测必须预判那些在推理期间已排定执行的动作所产生的影响。我们提出 Streaming-WAM，它将动作条件化的世界建模与异步机器人控制相结合，以在未来视觉预测中考虑已提交动作。在每次流式更新中，模型以最新观测和已提交动作作为条件进行未来视觉预测，这些已提交动作构成下一个动作块的固定前缀。由此得到的动作条件化视觉特征在同一联合更新内引导剩余动作的生成，从而使后续动作能够获知固定前缀执行期间预期的场景变化。在 LIBERO 上，Streaming-WAM 达到 98.35% 的平均成功率，并将平均回合时间相对于 Fast-WAM 缩短为原来的 1/2.93。在真实世界的 Stamp Paper 任务中，平均回合时间从同步 Joint-WAM 的 90 秒降至 Streaming-WAM 的 38 秒。这些结果表明，Streaming-WAM 支持高效的异步控制，同时保持高任务成功率。

## Abstract
World action models (WAMs) that use future visual prediction at inference time incur substantial generation costs. Asynchronous execution reduces waiting by overlapping inference with robot motion, but visual predictions used for subsequent action generation must anticipate the effects of actions already scheduled for execution during inference. We introduce Streaming-WAM, which couples action-conditioned world modeling with asynchronous robot control to account for committed actions in future visual prediction. At each streaming update, the model conditions future visual prediction on the latest observation and the committed actions, which form the fixed prefix of the next action chunk. The resulting action-conditioned visual features guide generation of the remaining actions within the same joint update, so the continuation is informed by the scene changes expected during execution of the fixed prefix. On LIBERO, Streaming-WAM achieves an average success rate of 98.35\% and reduces mean episode time by a factor of 2.93 relative to Fast-WAM. On the real-world Stamp Paper task, mean episode time falls from 90 s with synchronous Joint-WAM to 38 s with Streaming-WAM. These results show that Streaming-WAM supports efficient asynchronous control while maintaining high task success rates.

## 1. 核心问题与整体含义

- **研究动机**：世界动作模型（WAMs）在推理时生成未来视觉预测，可为机器人控制提供物体运动与物理交互上下文，但生成成本高，容易导致机器人等待、动作块之间不连续。
- **异步执行的矛盾**：异步执行可在机器人执行当前动作块时生成下一动作块，减少等待；但机器人捕获观测后仍继续运动，场景会变化。后续动作生成所用的视觉预测必须考虑“推理期间已排定执行的动作”的影响。
- **已有方法不足**：
  - 仅用已提交动作作为策略前缀约束动作延续，不能让未来视觉预测直接感知已提交动作。
  - 额外 FDM grounding 等方案可预测执行中动作的视觉结果，但增加一次生成过程，开销更大。
- **核心含义**：Streaming-WAM 将“动作条件化世界建模”与“异步机器人控制”耦合，让已提交动作既作为下一动作块的固定前缀，又作为未来视觉预测的条件，从而在同一联合更新中生成视觉未来与动作延续。

## 2. 方法论

- **核心思想**：
  - 每个流式更新输入最新观测 \(O_{t+1}\) 和已提交动作 \(A_c\)，联合预测未来视觉 \(V_{t+1}\) 与下一动作块 \(A_{t+1}=[A_c; A_p]\)。
  - \(A_c\) 是下一动作块的固定前缀，执行期间保持不变；\(A_p\) 是待生成的动作延续。
  - 视觉专家以 \(A_c\) 为条件预测未来视觉潜变量，其动作条件化中间特征引导动作专家生成 \(A_p\)，使延续动作能预判前缀执行期间的场景变化。

- **流式推理流程**：
  - 冷启动：Joint-WAM 从 \(O_0\) 生成 \((V_0,A_0)\)，机器人开始执行 \(A_0\)。
  - 触发点：执行过程中捕获 \(O_{t+1}\)，取后续 \(d\) 个缓冲动作为 \(A_c\)，启动流式更新。
  - 机器人执行 \(A_c\) 的同时，模型固定该前缀并联合预测视觉未来与动作延续。
  - \(A_c\) 结束后，若更新就绪则跳过共享前缀切换到 \(A_p\)，替换旧块未执行部分；若未就绪则暂停等待。
  - 实验设置：\(H=32\)，\(d=8\)，30 Hz 下重叠窗口约 267 ms。

- **Slot Encoder**：
  - 视频自注意力无法直接读取动作，因此构造与 \(Z_1\) 时间跨度对齐的条件槽。
  - 已知槽 \(C_K\) 编码 \(A_c\)；未知槽 \(C_U\) 使用可学习的未知状态嵌入。
  - \(Z_1\) 跨 16 个动作步，前缀覆盖 8 步。
  - 条件流与策略流共享动作专家参数，但保持独立 token 状态。
  - 定向条件掩码：\(C_K\) 只读 \(Z_0,C_K\)；\(C_U\) 读 \(Z_0,C_K,C_U\)，避免已知槽依赖未知槽。

- **动作条件注意力**：
  - 每个 MoT 块中，\(Z_1\) 的查询通过两个分支更新：
    - 视觉分支读取 \(Z_0,Z_1,Z_2\)；
    - 条件分支读取 \(C_K,C_U\)。
  - 两分支各自 softmax 后相加更新 \(Z_1\)。
  - 条件直接作用于 \(Z_1\)，\(Z_2\) 通过后续视频注意力获得上下文。
  - 冷启动时禁用条件分支；\(A_p\) 查询读取所有视频与策略 token，通过视觉表示纳入已提交动作。
  - \(Z_0\) 只读自身，\(A_c\) 的策略查询只读 \(Z_0,A_c\)，保持前向依赖。

- **训练策略**：
  - 从联合 WAM 经一步一致性蒸馏初始化，保持一步预测形式。
  - 演示前缀模拟 \(A_c\)，无前缀样本覆盖冷启动。
  - 第一阶段：冻结动作专家，训练视频专家与嵌入，用 \(L_{video}\) 监督未来潜变量 \(Z_1,Z_2\)，不含观测 \(Z_0\)。
  - 第二阶段：冻结视频专家，训练共享动作专家，用 \(L_{action}\) 监督 \(A_p\)；同时保留视频端点监督，组合目标为 \(L=L_{action}+\lambda L_{prefix\_video}\)，\(\lambda=0.1\)，使视觉损失梯度可穿过冻结视频专家影响共享动作专家。

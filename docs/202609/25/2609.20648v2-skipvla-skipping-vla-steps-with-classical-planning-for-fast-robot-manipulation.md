## 摘要
视觉-语言-动作（VLA）模型是一类通用机器人策略，可将相机图像和语言指令直接映射为机器人动作。尽管前景广阔，这些模型在测试时仍然较慢，尤其是对于需要多次查询策略的长时程任务。近期工作通过蒸馏更小的模型、重叠异步动作块，或将 VLA 与快速底层策略配对来降低 VLA 延迟，但仍需在整个任务中运行学习到的策略。与 VLA 不同，经典运动规划器能快速找到无碰撞运动，但需要显式目标，且缺乏对任务的语义理解。在这项工作中，我们提出 SkipVLA，一种混合策略，将预训练的 VLA 与经典运动规划器相结合，使用规划器进行自由空间运动，仅对抓取和放置等接触丰富的技能查询 VLA。SkipVLA 复用 VLA 冻结的视觉-语言主干来预测每个规划运动的目标位姿，并利用大型 VLA 已经学到的内容来学习该预测器，而无需向系统中引入额外演示。我们在仿真中的 13 个 LIBERO 任务上使用三个 VLA 评估 SkipVLA，并在物理 6 自由度 YAM 机械臂上评估三个拾放任务，结果表明任务完成速度最高提升 2.5 倍，能耗显著降低，同时达到相同的任务成功率。

## Abstract
Vision-Language-Action (VLA) models are a class of generalist robot policies that map camera images and language instructions directly to robot actions. While promising, these models remain slow at test time, particularly for long-horizon tasks that require many queries to the policy. Recent efforts reduce VLA latency by distilling smaller models, overlapping asynchronous action chunks, or pairing the VLA with a fast low-level policy, but still run a learned policy for the entire task. In contrast to VLA, classical motion planners quickly find collision-free motions, but require an explicit goal and have no semantic understanding of the task. In this work, we present SkipVLA, a hybrid policy that combines a pretrained VLA with a classical motion planner, using the planner for free-space motion and querying the VLA only for contact-rich skills such as grasping and placing. SkipVLA reuses the frozen vision-language backbone of the VLA to predict a target pose for each planned motion, and learns this predictor without additional demonstrations introduced into the system by using what was already learnt by the large VLA. We evaluate SkipVLA with three VLAs on 13 LIBERO tasks in simulation and three pick-and-place tasks on a physical 6-DoF YAM arm, demonstrating up to 2.5x faster task completion and significantly lower energy consumption while achieving the same task success rate.

## 一、核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型将相机图像与自然语言指令直接映射为机器人动作，具备开放词汇指令跟随、跨场景泛化和长时程任务执行能力，成为通用机器人操作的主流范式。
- **核心痛点**：VLA 参数量达数十亿级，每次生成动作块都需完整前向推理，推理延迟（Δt_lat）远大于机器人控制周期（Δt_ctrl），在需要数十到数百次查询的长时程任务中造成执行迟缓、边缘端能耗高、反应式安全性受损。
- **现有加速方案的局限**：
  - 蒸馏小模型 → 性能下降；
  - 异步动作块重叠 → 执行陈旧动作，可能使策略偏离分布；
  - 分层式搭配快速底层策略 → 需从零训练全新策略网络。
  - **共同问题**：均将操作视为单体端到端学习问题，即便在简单无约束的自由空间运动中也持续调用大网络。
- **关键观察**：操作任务存在天然的物理分解——交替出现"接触丰富的操作技能"（抓取、重定向、放置）与"长段自由空间转移"（接近物体、移动到容器）。前者需要闭环视觉运动反馈，VLA 擅长；后者是纯几何/运动学问题，经典运动规划器（采样规划、轨迹优化）可在微秒至毫秒级给出无碰撞轨迹，但**语义盲**，无法从语言推断目标位姿。
- **论文含义**：提出 SkipVLA，把 VLA 限定在接触丰富技能，把自由空间转移交给经典规划器，并用 VLA 冻结的视觉语言表征来预测规划器的目标位姿，从而在不损失成功率的前提下大幅加速。

## 二、方法论

### 1. 核心思想：混合策略与指示器

- 定义混合策略 π_hyb，由二值指示模块 I_s ∈ {0,1} 决定每步执行哪一策略：
  - I_s = 0 → 执行 VLA（接触丰富操作）；
  - I_s = 1 → 执行快速经典规划器（自由空间转移）。
- 延迟相应为 Δt_vla_lat 或 Δt_fast_lat（后者远小于前者）。
- 目标函数为轨迹级而非动作级模仿（避免用逐步模仿损失错误惩罚几何上合法但路径不同的规划轨迹）：
  - min E[T(τ_hyb) + λ·ℓ_traj(τ_hyb, τ_e)]，其中 ℓ_traj = 0 表示混合轨迹经过所有关键路点，保证任务完成。

### 2. 关键路点与分段损失

- 将专家轨迹分段为"主动物体操作"与"到达-放置（reach-and-place）"两类。
- 分段损失：
  - **操作段**：要求逐步贴近专家（对所有步求和距离平方）；
  - **到达-放置段**：只要求起点与终点末端位姿匹配（首尾距离平方和）。
- 总损失为各段之和。由于规划器保证可达性、且 π_vla 冻结，式(8) 的优化**退化为仅训练目标位姿预测器 f_tgt 的框打分头**。

### 3. 快速控制模块 π_fast = 目标位姿预测器 f_tgt + 底层运动规划器 P

- **目标位姿预测器 f_tgt**：由 O_s、L、p_s 预测当前子任务结束时的末端目标位姿 p^tgt_s。
  - 用 FastSAM + DBSCAN 从观测中提取 M 个 3D 包围盒 b_i = (c_i, e_i)（质心 + 尺寸）；
  - 以每个包围盒的学习位置嵌入 ϕ_pos(b_i) 为 query，与 VLA 冻结视觉语言骨干输出的 T 个 token 特征 F_vl（投影为 K_vl、V_vl）做交叉注意力，再经轻量 MLP 输出相关性分数 r_i；
  - 取 argmax 选中目标物体，在其上方分配一个俯视、无碰撞的悬停位姿作为目标位姿；
  - **仅训练** ϕ_pos、交叉注意力投影与打分 MLP，其余冻结；每个 reach-and-place 阶段开始时只调用一次。
- **运动规划器 P**：与规划器无关，实例化为 VAMP 或 cuRoboV2，输入 (p_s, p^tgt_s, O_s)，输出无碰撞动作序列。

### 4. 指示器模块 I（启发式）

- 初始 I_0 = 1（由规划器导航至目标位姿）；
- 当末端位姿与目标位姿距离小于阈值 ϵ_d → 交给 VLA（I_s = 0）；
- 当夹爪状态发生跳变（g_s ≠ g_{s−1}，即抓取或释放）→ 切回规划器（I_s = 1）；
- 否则保持上一状态。

### 5. 自监督数据生成与训练

- **无需人工标注、无需新增演示**：在专家轨迹中通过夹爪事件（闭合抓取 / 张开释放）检测 reach-and-place 段的结束，把该时刻距末端执行器最近的包围盒 i* = argmin ‖p^ee_event − c_i‖₂ 作为整段的地真目标。
- 用交叉熵损失训练打分头（对观测 O_s、候选框 B、冻结 token F_vl 计算 r_i），使其在不同视角下都能稳健预测目标。

## 六、主要结论与发现

- **效率**：SkipVLA 在所有任务上均降低墙钟时间。仿真中 VAMP 使 LIBERO-Object 墙钟时间下降 40%、LIBERO-10 下降 27%，VLA 查询数同比例下降。真机上 MolmoAct2 平均降低 46.0%（最高 59.6%，即 2.47× 加速），π0.5 平均降低 30.6%；VLA 查询平均减少 33.8%。
- **能耗**：Jetson

**能耗**：Jetson Thor 上单次试验能耗随 VLA 查询次数下降而同步降低，MolmoAct2 的能耗降幅与其时间降幅量级一致（约 40%+），π0.5 因骨干更重、单次查询能耗更高，能耗节省的绝对量更可观；这表明 SkipVLA 的效率增益不仅体现在延迟，也直接转化为边缘端能效收益。
- **成功率保持**：在仿真两个 LIBERO 子套件上，SkipVLA 在保持与基座 VLA 相当成功率的前提下实现加速；真机三个任务上，SkipVLA 的成功率与基线持平或略有提升（叠塔等长时程任务受益于规划器提供的稳定自由空间运动），说明"接触丰富交给 VLA、自由空间交给规划器"的分工没有牺牲任务完成能力。
- **模块化与规划器无关性**：VAMP（CPU）与 cuRoboV2（GPU）两种规划器均带来一致的加速与成功率表现，验证 π_fast 对底层规划器是即插即用的，框架不绑定特定求解器。
- **指示器消融**：以物体高度变化阈值替代夹爪事件的启发式后，性能略有下降，说明基于夹爪状态跳变的切换判据能更可靠地识别抓取/释放事件、更准确地划分自由空间段与操作段。
- **跨骨干泛化**：从 3.5B 的 π0.5 到 0.5B 的 SmolVLA、再到 MolmoAct2，加速比与骨干规模相关——骨干越大、单次前向越慢，SkipVLA 的收益越明显，说明该方法对"重骨干"VLA 尤其有价值。

## 七、局限与未来工作

- **任务范围受限**：实验刻意选择俯视抓放任务以隔离效率增益，未验证非俯视抓取、铰接物体操作、双臂协作、可变形物体等更复杂场景；目标位姿预测器依赖"物体上方悬停位姿"这一简单假设，难以直接推广到需要侧向接近或精细对准的任务。
- **依赖抓放式任务结构**：指示器启发式建立在"抓取—释放"夹爪事件与 reach-and-place 分段的强假设之上，对连续接触型任务（如擦拭、装配）或始终闭合夹爪的任务不适用。

- **安全与失效处理**：论文未深入讨论当规划器给出的目标位姿错误或不可达时的回退机制，混合切换失败可能导致任务卡死。
- **统计与对比缺口**：如前所述，缺少与同类混合/分层方法的定量对比，且时间与能耗指标仅统计成功试验。
- **未来方向**：作者可能期望扩展到多阶段、多物体的长时程任务，引入在线失败检测与重规划，以及把该"VLA + 经典规划"的分工范式推广到移动操作与双臂系统。

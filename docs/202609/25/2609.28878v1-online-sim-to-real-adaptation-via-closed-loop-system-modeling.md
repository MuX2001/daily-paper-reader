## 摘要
Sim-to-Real 迁移已取得实质性进展，但仍可能产生这样的控制器：它们在硬件上保持稳定且功能正常，却由于残余动力学不匹配而导致跟踪精度下降。纠正这些误差通常需要辨识底层系统动力学、自适应控制策略，或返回仿真进行额外训练和微调，而所有这些都可能需要大量数据和计算。我们提出 OSRAM（Online Sim-to-Real Adaptation via Closed-Loop System Modeling，通过闭环系统建模的在线仿真到现实自适应），该框架转而调整提供给现有控制器的参考指令。OSRAM 将部署的机器人及其策略视为统一的闭环动力系统，并直接从跟踪观测中学习其任务级指令-响应行为。一个闭环动力学模型在仿真中跨随机化动力学进行元训练，并在部署后利用有限的真实世界交互快速微调。随后，自适应后的模型被用于优化未来的参考指令，同时保持底层控制策略不变。我们在仿真和硬件上，针对双足速度跟踪和移动操作评估 OSRAM。结果表明，闭环建模提高了在未见动力学下的预测和跟踪精度，而在线参考自适应则在不同控制目标和硬件配置下减少了残余的 Sim-to-Real 跟踪误差。这些结果表明，自适应机器人-策略闭环的行为，为 Sim-to-Real 迁移中微调策略或辨识完整物理动力学提供了一种实用替代方案。更多信息请见 http://generalroboticslab.com/OSRAM。

## Abstract
Sim-to-real transfer has made substantial progress, but can still produce controllers that remain stable and functional on hardware while suffering from degraded tracking accuracy due to residual dynamics mismatch. Correcting these errors typically requires identifying the underlying system dynamics, adapting the control policy, or returning to simulation for additional training and finetuning, all of which can require substantial data and computation. We propose OSRAM (Online Sim-to-Real Adaptation via Closed-Loop System Modeling), a framework that instead adapts the reference commands provided to an existing controller. OSRAM treats the deployed robot and its policy as a unified closed-loop dynamical system and learns its task-level command-response behavior directly from tracking observations. A closed-loop dynamics model is meta-trained across randomized dynamics in simulation and rapidly finetuned after deployment using limited real-world interaction. The adapted model is then used to optimize future reference commands while leaving the underlying control policy unchanged. We evaluate OSRAM on bipedal velocity tracking and loco-manipulation in simulation and on hardware. Results show that closed-loop modeling improves prediction and tracking accuracy under unseen dynamics, while online reference adaptation reduces residual sim-to-real tracking errors across different control objectives and hardware configurations. These results demonstrate that adapting the behavior of the robot-policy closed loop provides a practical alternative to finetuning the policy or identifying the full physical dynamics for sim-to-real transfer. More information can be found at http://generalroboticslab.com/OSRAM.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：Sim-to-Real 迁移已使基于学习的控制器能够在真实机器人上执行日益动态、复杂的任务，但即便策略成功迁移并在硬件上保持稳定，执行精度仍可能因仿真与真实动力学之间的**残余失配**而下降。失配来源包括建模不准确、复杂执行器动力学、传感器噪声、延迟与环境变化等，难以在仿真中完整刻画。

- **现有方法的局限**：
  - **训练期鲁棒化方法**（如域随机化）：依赖真实系统被训练分布充分覆盖，分布设计困难——随机化不足使策略对未见动力学脆弱，过度随机化则牺牲任务性能甚至破坏学习稳定性。
  - **部署后自适应方法**（如在线系统辨识、潜在表示学习）：需要估计物理参数或学习真实动力学表示，往往需要大量真实数据、仿真器校准与额外优化；对高维机器人系统，准确辨识动力学本身就很困难，修改已部署策略还会引入额外计算与验证成本。

- **核心问题定位**：论文聚焦于一个**互补场景**——迁移后的策略仍然功能正常，但无法以足够精度跟踪目标指令。此时是否需要重建物理动力学或修改策略？

- **整体含义**：作者提出一种新思路——**不重建物理动力学、不修改策略，而是通过调整发送给现有控制器的参考指令来修正残余 Sim-to-Real 误差**。将机器人与其策略视为统一的闭环动力系统，直接学习其任务级指令-响应行为，把自适应问题从高维物理动力学重建转化为低维任务相关行为建模。这为 Sim-to-Real 迁移提供了一条实用替代路径。

## 2. 方法论

### 2.1 核心思想
- 将已部署的机器人 + 其内置控制器视为**单一闭环动力系统**，通过"参考指令 → 实际响应"的关系直接刻画行为。
- 学习一个闭环指令-响应模型 `Fθ`，预测下一时刻的实际响应：
  - `ˆrreal_{t+1} = Fθ(rreal_{t−N:t}, rref_{t−N:t})`
  - 其中 `rref_t` 为发送给策略的参考指令，`rreal_t` 为观测到的跟踪响应，N 为历史窗口长度。
- 该建模只关注任务相关变量（通常远低于完整机器人状态维度），无需策略内部信息或显式物理动力学模型。

### 2.2 闭环元动力学训练（Closed-Loop Meta-Dynamics Training）
- 采用 **Reptile 风格的一阶元学习**，目标是在仿真中学习一个能快速适应未见系统动力学的模型先验。
- **数据采集**：在仿真中对关键物理参数（质量、摩擦、执行器动力学）随机化，并向参考指令注入随机激励信号以覆盖多样运行工况；每个随机化配置构成一个元训练任务 Dm。
- **元训练流程**：从共享初始化出发，对每个采样任务进行若干内循环梯度步适应，再将共享参数向各任务解移动，重复迭代。
- **损失函数**由两部分组成：
  - **单步预测损失** `Lstep`：最小化一步预测误差；
  - **多步 rollout 一致性损失** `Lrollout`：对模型进行 k 步自回归展开（预测响应递归反馈回模型），并用折扣因子 γ 降低远端误差权重；λ0、λ1 平衡两项。
- 整体流程见算法 1：仿真元训练 → 收集真实参考-响应数据 Dreal → 用 J 步梯度微调得到适配模型。

### 2.3 在线参考指令自适应（Online Reference-Command Adaptation）
- 部署后收集少量参考-响应数据微调元学习模型，再用其优化未来参考指令，使实际行为更贴近原始期望轨迹。
- 优化目标（式 5）：在闭环模型约束下，最小化三项加权和：
  - **跟踪项 `ℓtrack`**：鼓励预测实际响应跟随原始期望参考；
  - **偏差项 `ℓdev`**：将适配指令正则化向名义参考靠拢，防止过度激进的修正与超出模型观测工况的外推；
  - **平滑项 `ℓsmooth`**：惩罚适配参考的剧烈时间变化。
- **关键点**：`rref,new` 不是替代任务目标，而是一个中间指令——通过它使实际响应 `rreal` 更准确地跟随原始期望参考 `rref`。自适应完全发生在参考接口，底层控制策略保持固定。

### 2.4 基于采样的参考优化
- 使用 **MPPI（Model Predictive Path Integral）控制**求解式 5：并行 rollout 大量候选参考轨迹，按代价加权组合。
- 权重计算：`wk = exp(−(R(k)−Rmin)/λ(Rmax−Rmin)) / Σj exp(...)`，温度参数 λ 控制权重集中度。
- 参考轨迹更新为候选轨迹的加权和，迭代采样并退火采样协方差，以滚动时域（receding horizon）方式执行首段优化参考、纳入新观测后重复优化。

## 6. 主要结论与发现

- **元动力学模型提升未见动力学下的预测与跟踪**：在进一步随机化质心与执行器增益的 OOD 设置下，单步预测 MAE 为 0.0116，较前向动力学模型的 0.0594 降低约 **80.5%（约 5 倍）**。
- **闭环建模优于开环建模**：闭环模型预测精度最高（开环全状态 MAE 0.0789，开环输出状态 0.0338）；任务级上，在 0.9 m/s 挑战性设定下，两种开环基线均以 0% 成功率失败，而 OSRAM 保持 100% 成功率、ERMSE 0.1560。
- **优于代表性在线自适应方法**：OSRAM 在 0.4/0.7/0.9 m/s 下 ERMSE 分别为 0.0733 / 0.0929 / 0.1560，均低于 RNN-Adapt（0.1415 / 0.1614 / 0.2082）与 Res-Adapt（0.1421 / 0.1833 / 0.2062），且 Emean 最优。
- **硬件有效性**：速度跟踪（0.7 m/s）中 OSRAM 降低 ERMSE 并改善冠状面跟踪；loco-manipulation 中 x 方向 RMSE 从 **36.94 ± 3.02 cm 降至 3.11 ± 0.31 cm**，y 方向从 3.48 ± 0.45 cm 降至 2.72 ± 0.23 cm。
- **可与其他自适应机制互补**：OSRAM 可叠加在 RNN-Adapt 策略之上进一步提升性能。
- **机制解释**：模型预测显示，当机器人系统性欠跟踪时 OSRAM 增大参考、过冲时减小参考，通过参考接口补偿系统性偏差、延迟等误差，而策略保持不变。
- **微调效率**：预测 MAE 在初始约 30 步微调后迅速下降并趋于平台。

## 7. 优点

- **问题定位精准且实用**：针对"策略仍可用但精度不足"这一常见而未被充分重视的场景，提出通过参考接口修正误差的互补思路，避免策略重训与完整动力学辨识的高成本。

- **可组合性**：能够叠加在已有在线自适应策略之上，表明其与现有方法正交、可互补。

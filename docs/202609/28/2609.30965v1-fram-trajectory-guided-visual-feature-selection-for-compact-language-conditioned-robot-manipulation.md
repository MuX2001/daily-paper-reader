## 摘要
视觉-语言-动作模型在机器人操作中取得了强大性能，但通常需要大量参数。在这项工作中，我们提出未来表征动作模型（Future Representation Action Model, FRAM），这是一种小型策略，显式地将未来末端执行器轨迹与当前视觉输入关联起来。FRAM 将预测轨迹的图像坐标作为空间指针，并从当前图像中读取与运动相关的局部视觉特征。这将用于动作生成的信息组织为参考位置（Where）、视觉状态（What）和未来运动（Future）。轨迹标签由演示和相机几何自动生成，因此无需人工标注。FRAM 具有 138.7M 参数，其中包括一个冻结的语言编码器，在四个标准 LIBERO 套件上达到 92.2% 的平均成功率，接近具有 3.3B 参数的 π_0 的 94.2%。无需额外训练，它在 LIBERO-Plus 上也达到 67.3% 的平均成功率。消融实验证实，未来轨迹和局部视觉特征都能提升性能和鲁棒性。在真实双臂 UR5e 上，FRAM 仅使用腕部相机完成叠杯，包括在左右臂之间进行选择和切换。这些结果表明，基于未来运动选择视觉信息是在小型机器人策略中同时获得高性能和鲁棒性的有效方法。

## Abstract
Vision-Language-Action models achieve strong performance in robot manipulation, but often require large numbers of parameters. In this work, we propose the Future Representation Action Model (FRAM), a small policy that explicitly links the future end-effector trajectory to the current visual input. FRAM uses the image coordinates of the predicted trajectory as spatial pointers and reads local visual features related to the motion from the current image. This organizes the information for action generation into the reference position (Where), the visual state (What), and the future motion (Future). Trajectory labels are generated automatically from demonstrations and camera geometry, so no manual annotation is needed. With 138.7M parameters, including a frozen language encoder, FRAM reaches an average success rate of 92.2% over the four standard LIBERO suites, close to the 94.2% of $π_0$ with 3.3B parameters. Without extra training, it also reaches an average of 67.3% on LIBERO-Plus. Ablations confirm that both the future trajectory and the local visual features improve performance and robustness. On a real dual-arm UR5e, FRAM stacks cups using only wrist cameras, including choosing and switching between the left and right arms. These results show that selecting visual information based on future motion is an effective way to obtain both high performance and robustness in a small robot policy.

- **研究背景**：视觉-语言-动作（VLA）模型（如 OpenVLA、π0）在机器人操作中表现优异，但参数量动辄数十亿，微调与推理对算力要求极高，难以部署在算力受限的实际场景（如维护、服务现场）。
- **核心矛盾**：小模型要在多变的物体、布局和语言指令下表现良好，必须**主动选择**与下一步动作相关的视觉信息，并以有限容量可用的形式表征。
- **现有方法的不足**：
  - 基于空间注意力的视觉运动学习仅提取图像坐标，丢失物体外观与周围环境信息，且无法显式表达未来运动路径。
  - 轨迹类方法（ATM、MT-π、RT-Trajectory）将轨迹用作运动预测、动作表示或动作指令，但**未显式地从当前图像中沿预测轨迹读取所需视觉信息**，未来路径与沿途物体/环境的关系只能隐式学习。
- **整体含义**：论文提出 FRAM，将动作生成所需信息组织为**参考位置（Where）、当前视觉状态（What）、未来运动（Future）** 三元结构，探索“基于未来运动选择视觉信息”这一轻量化 VLA 策略路径。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想
- 受人类“先看目标再动手”的眼手协调机制启发，FRAM 预测未来末端执行器轨迹，将其图像坐标作为**空间指针**，从当前图像特征图中读取与运动相关的局部特征。
- 轨迹预测不仅是动作生成的条件，更承担**视觉信息选择器**的角色。

### 2.2 算法流程（五个阶段）
1. **观测输入**：语言指令 ℓ、末端状态 s_t、外部相机图像 I_a、腕部相机图像 I_w。
2. **语言与视觉编码**：
   - 语言：冻结的 SigLIP 文本编码器，输出 token 序列 L_ℓ 和句子嵌入 e_ℓ。
   - 视觉：ImageNet 预训练 ResNet-18（第三残差阶段），双视图共享权重，经 1×1 卷积降维后用 FiLM 做语言条件调制：
     - `F_vt = (1 + γ(e_ℓ)) ⊙ φ(I_vt) + β(e_ℓ)`
3. **未来轨迹预测**：每个视图一个 Transformer 解码器，K 个可学习 query 交叉注意力到图像 token、语言 token 与末端状态 token，直接回归第 k 个轨迹点：
   - `ẑ_vt,k = [(q̂_vt,k)ᵀ, d̂_vt,k, (ô_vt,k)ᵀ]ᵀ`
   - 其中 q̂ 为归一化图像坐标，d̂ 为相机系深度，ô 为投影到图像的 6D 朝向偏移。
4. **轨迹引导的局部特征提取**：
   - 将预测点映射到特征图网格坐标，采样 3×3 邻域（双线性插值，可微 grid sample），取均值得 h_vt,k。
   - 路径平均特征 `f_traj`、终点特征 `f_target`、以终点为 query 的注意力上下文特征 `f_attn` 拼接后经 MLP 得局部视觉特征：
     - `f_local = MLP([f_traj; f_target; f_attn])`
5. **动作专家（Flow Matching）**：
   - 条件向量 c_t = 全局观测特征 g_t + 轨迹嵌入 + 局部视觉特征。
   - 每个轨迹点转为轨迹 token 作为交叉注意力记忆。
   - 流匹配损失：`L_FM = E[||v_θ(A_τ, τ, c_t, e_ℓ, Ẑ_t) − (A_1 − A_0)||²_valid]`
   - 总损失：`L = L_FM + L_BC + λ_KP·L_KP + λ_ORI·L_ORI`，其中 λ_KP=20，λ_ORI=10。
   - 对预测轨迹到后续阶段施加 **stop-gradient**，防止动作损失反传至轨迹预测器。

### 2.3 轨迹标签自动生成
- 按夹爪命令切换将演示切分为子任务（接近、抓取、搬运、释放等）。
- 在基坐标系中拟合分段三次 B 样条，以当前位姿、子任务终点、夹爪切换点为精确通过节点，按等弧长采样 K 点。
- 通过相机外参和内参将基坐标系点投影到各视图图像：`q_vt,k = Π(K_v · ᵛT(t)_b · bp_k)`。
- 腕部相机无需未来相机位姿（全部投影到当前时刻相机坐标系）。
- 图像外点保留真实坐标标签，相机后方点（z≤0）与远离光轴点从损失中剔除。

## 6. 主要结论与发现

- **标准 LIBERO**：FRAM（138.7M）四套件平均成功率 **92.2%**（Spatial 92.2%、Object 96.2%、Goal 93.8%、Long 86.4%），接近 π0（3.3B）的 94.2%，显著优于 SmolVLA（87.3%/82.8%）、Octo（75.1%）等小模型。
- **LIBERO-Plus 鲁棒性**：零额外训练平均 **67.3%**，接近 OpenVLA-OFT 的 69.6%，高于 π0-FAST（61.6%）、π0（53.6%）、OpenVLA（15.6%）；在相机视角（68.6% vs 56.4%）和机器人初始状态（40.2% vs 31.9%）上尤其领先 OpenVLA-OFT。
- **消融结论**：
  - 标准 LIBERO：FRAM 92.2% → −Feat. 88.4% → −Traj. 87.7%。
  - LIBERO-Plus：FRAM 67.3% → −Feat. 57.8% → −Traj. 50.8%。
  - 未来轨迹提供的参考位置与从该位置读取的局部视觉特征**均对性能和鲁棒性有实质贡献**。
- **真实双臂操作**：单一策略可完成叠杯全流程，包括选择手臂、等待对侧完成、切换手臂；预测轨迹会随目标物体与放置位置逐步更新，等待臂的轨迹甚至已指向后续目标但暂不执行。
- **失败模式**：背景纹理变化下 FRAM 表现明显弱于 OpenVLA-OFT（68.5% vs 93.3%），长程任务（Long）成功率偏低。

## 7. 优点

- **表征设计新颖**：将未来轨迹从“条件/动作表示”提升为“视觉信息选择器”，显式建立 Where–What–Future 三元结构，几何上约束了策略关注的图像区域，减少背景干扰泄漏。
- **标签自动化**：轨迹标签由演示末端位姿、夹爪命令和相机几何自动生成，无需人工标注物体区域或子目标，工程可扩展性好。
- **小模型高性价比**：138.7M 参数达到接近 3.3B π0 的性能，且优于多个更大模型，验证了“结构化信息表征”对模型容量的替代价值。
- **鲁棒性突出**：在相机视角与机器人初始状态扰动下显著优于同级别甚至更大模型。
- **训练与推理一致**：训练时即使用预测轨迹而非标签，并对预测轨迹施加 stop-gradient，避免动作损失干扰轨迹几何语义。
- **真实系统验证**：仅用腕部相机完成双臂协作，展示了选择、等待、切换手臂的自主行为。

## 8. 不足与局限

- **长程任务短板**：LIBERO-Long 成功率 86.4%，明显低于其他三个套件，多步长程操作仍是瓶颈。
- **背景扰动脆弱**：LIBERO-Plus 背景变化下

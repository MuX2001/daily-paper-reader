## 摘要
在接触丰富的操作中，可靠的动作评估需要超越当前观测，考虑未来的视觉与接触后果。现有的噪声空间强化学习能够高效地引导冻结的视觉-语言-动作（VLA）策略，但其评论家在很大程度上忽略了这些后果。我们提出Imagine-RL，它通过动作条件的视觉-力矩想象来增强噪声空间VLA后训练。对于每个候选动作块，一个冻结的视觉-力矩潜在世界模型（VTLWM）自回归地预测紧凑的未来表示，而无需像素重建。当前图像-状态-动作查询关注观测到的历史与预测的未来，而前一窗口的预测残差提供token级置信度先验，以抑制不可靠的未来token。通过将当前证据与预测后果相结合，动作评论家能更好地评估候选动作并监督演员，同时VLA和VTLWM保持冻结。在四个真实机器人任务中，每个任务进行50次评估试验，Imagine-RL仅使用100条RL轨迹，就将平均成功率较DSRL提高了（23.6%），较VLA基线提高了（60%）。

## Abstract
Reliable action evaluation in contact-rich manipulation requires looking beyond the current observation to future visual and contact consequences. Existing noise-space reinforcement learning efficiently steers a frozen Vision-Language-Action (VLA) policy, but its critics largely ignore these consequences. We present Imagine-RL, which augments noise-space VLA post-training with action-conditioned visual-torque imagination. For each candidate action chunk, a frozen visual-torque latent world model (VTLWM) autoregressively predicts compact future representations without pixel reconstruction. A current image-state-action query attends to observed histories and predicted futures, while previous-window prediction residuals provide token-wise confidence priors that suppress unreliable future tokens. By combining current evidence with predicted consequences, the action critic better evaluates candidate actions and supervises the actor, while the VLA and VTLWM remain frozen. Across four real-robot tasks with 50 evaluation trials per task, Imagine-RL uses only 100 RL trajectories and improves the average success rate by (23.6%) over DSRL and by (60%) over VLA baselines.

- **背景问题**：现有噪声空间 VLA 强化学习（如 DSRL）能高效微调冻结 VLA，但 critic 主要依赖当前观测与候选动作，忽略未来视觉与接触后果，导致动作排序不可靠。
- **整体含义**：论文提出 Imagine-RL，将“动作条件未来想象”引入冻结 VLA 的轻量 RL 后训练，通过视觉-力矩潜在世界模型预测未来表征，并用残差置信度抑制不可靠未来 token，从而增强 critic 对成功/失败动作的区分能力。

## 2. 方法论
- **核心思想**：
  - 不直接学习机器人动作，而是在冻结 VLA 的潜在噪声空间学习轻量 actor：\(\pi_\theta(w|o)\)，再由冻结 VLA 解码动作块 \(\bar a_t=\pi_0(o_t,w_t)\)。
  - 使用冻结的视觉-力矩潜在世界模型 VTLWM，对候选动作块自回归预测未来视觉与力矩紧凑表征，不进行像素重建。
  - 动作 critic 同时利用当前观测-状态-动作和预测未来，通过残差置信度引导的交叉注意力评估候选动作。
  - VLA 与 VTLWM 保持冻结，仅训练噪声 actor、动作 critic 和噪声 critic。

- **VTLWM 世界模型**：
  - 输入为视觉潜变量 \(z_t\) 与归一化力矩 \(\hat\tau_t\)，即 \(x_t=[z_t,\hat\tau_t]\)，动作经编码为 \(e_{a_t}\)。
  - 使用历史长度 \(H=15\) 的一步因果预测器，递归滚动预测 \(H_f=10\) 个未来视觉与力矩状态。
  - 训练损失为视觉 MSE + 力矩 SmoothL1 + SIGReg 正则项：  
    \(\mathcal L_{WM}=MSE(P^z,Z)+\lambda_\tau SmoothL1(P^\tau,T)+\lambda_{sig}L_{SIGReg}\)。
  - RL 阶段 VTLWM 冻结，仅生成 critic 特征。

- **残差置信度构建**：
  - 对每个模态 \(m\in\{z,\tau\}\)，取当前历史 \(X^{m,hist}_t\)、当前动作条件下的未来预测 \(X^{m,fut}_t(a)\)、前一窗口预测 \(P^{m,prev}_t\)。
  - 计算残差 \(R^m_{t,j}=X^{m,hist}_{t,j}-P^{m,prev}_{t,j}\)，表示世界模型生成可靠性。
  - 相对误差 \(\rho^m_{t,j}\) 与置信度 \(\alpha^m_{t,j}=\max(\alpha_{\min},e^{-\beta\rho^m_{t,j}})\)，误差越小置信度越高。

- **置信度引导交叉注意力 critic**：
  - 查询 \(q_t=f_q(\zeta_t)\)，其中 \(\zeta_t=(o_t,a_t)\) 为当前观测与候选动作块。
  - 历史与未来特征加位置/动作嵌入后形成 token，经模态特定投影得到 query、key、value。
  - 注意力偏置 \(B^m_t\)：有效历史 token 为 0，有效未来 token 为 \(\log\alpha^m_{t,j}\)，无效槽为 \(-\infty\)。
  - 多头交叉注意力后拼接并层归一化，得到视觉与力矩上下文 \(c^z_t,c^\tau_t\)。
  - 可靠性统计 \(g^m_t\) 包括有效未来 token 的均值、最小、最大置信度与平均相对误差。
  - 最终特征 \(h_{a_t}=[c^z_t,c^\tau_t,g^z_t,g^\tau_t]\)，动作价值为 \(Q_a(o_t,a_t;h_{a_t})=Q([\zeta_t,h_{a_t}])\)。

- **算法流程**：
  1. 从 replay buffer 采样 \((o_t,w_t,\bar a_t,r_t,o_{t+1})\)。
  2. **动作 critic 更新**：采样下一噪声 \(w'_{t+1}\)，解码 \(\bar a'_{t+1}\)，计算动作对齐特征，最小化 Bellman 目标均方误差；使用多个 Q 网络集成并取均值降低偏差。
  3. **噪声 critic 更新**：采样噪声 \(\tilde w_t\)，经冻结 VLA 解码 \(\tilde a_t\)，最小化 \(Q_w(o_t,\tilde w_t)\) 与 \(Q_a(o_t,\tilde a_t;h_{\tilde a_t})\) 的蒸馏误差。
  4. **噪声 actor 更新**：最大化 \(Q_w(o,\pi_\theta(o))\)，并使用熵正则。
  5. 奖励设置：非终止查询 \(-1\)，成功终止 \(+5\)，普通失败截断 \(-1\)，严重吸收失败 \(-50\)。

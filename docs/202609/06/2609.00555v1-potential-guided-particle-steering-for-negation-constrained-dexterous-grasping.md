## 摘要
语言驱动的灵巧抓取模型，如DextER，在指令指定抓取位置时表现良好，但我们发现当指令还指定了不要抓取的位置时（例如，“抓手柄但避免抓取主体”），它们会系统性地失效。现有训练语料库（包括DexGYSNet）几乎不包含回避指令，且为每种可能的约束收集示例是不切实际的。此外，由于训练中提到的每个部分都表示接触目标，模型可能将被禁止的部分解释为另一个要抓取的区域，而不是要避开的区域。因此，我们引入了一种用于带否定约束的灵巧抓取的推理时框架，该框架不需要针对否定的训练示例。我们的方法结合了序贯蒙特卡洛与无分类器引导，在训练过程中无需任何否定示例的情况下，将采样引向指示的部分，同时修剪指向禁止区域的候选。一个冻结的3D部分定位模型从语言指令中定位禁止区域。为了评估这一设置，我们构建了NegGrasp，一个包含成对积极/消极指令的基准，并带有约束感知指标，仅当抓取既完成任务又遵守给定约束时才算成功。在NegGrasp上，我们的方法将最强基线的违规率从57.9%降至17.2%，同时提高了约束感知和物理成功率。

## Abstract
Language-driven dexterous grasp models, such as DextER, perform well when instructions specify where to grasp, but we find they fail systematically when an instruction also specifies where not to grasp (e.g., "grasp the handle but avoid the body"). Existing training corpora, DexGYSNet among them, contain virtually no avoidance instructions, and collecting examples for every possible constraint is impractical. Moreover, because every part mentioned during training denotes a contact target, models may interpret a forbidden part as another region to grasp rather than one to avoid. We therefore introduce an inference-time framework for negation-constrained dexterous grasping that requires no negation-specific training examples. Combining Sequential Monte Carlo with classifier-free guidance, our method guides sampling toward the instructed part while pruning candidates headed for the forbidden region, without any negation examples during training. A frozen 3D part-grounding model localizes the forbidden region from the language instruction. To evaluate this setting, we construct NegGrasp, a benchmark of paired positive/negative instructions with constraint-aware metrics that credit a grasp only if it both accomplishes the task and respects the stated constraint. On NegGrasp, our method reduces the violation rate of the strongest baseline from 57.9% to 17.2% while improving both constraint-aware and physical success.

## 1. 核心问题与研究动机

- **问题定义**：当前语言驱动的灵巧抓取模型（如 DextER）能执行“抓取某部位”的正向指令，但当指令同时包含否定约束（如“抓手柄但避免接触主体”）时会出现系统性失败。
- **根因分析**：
  - 训练语料（如 DexGYSNet）几乎不含回避类指令，扫描显示仅 0.047% 指令含否定线索，且真正禁止触碰某部位的比例仅 0.010%。
  - 由于训练期间每个提到的部位都对应“接触目标”，模型形成了一种捷径：提到某部位即意味着要去抓它，导致“不要碰主体”这类子句被误读为抓取主体。
- **核心意义**：用户约束和安全约束常以否定形式表达（如不碰刀片、不碰热杯身），但为每种可能的约束收集监督样本不现实，需要一种不依赖否定示例、可在测试时灵活施加约束的机制。

## 2. 方法论

### 2.1 总体框架

- 将任务分为两部分：
  1. **训练阶段**：仅在 DexGYSNet 正向指令上训练一个“流匹配扩散 transformer（DiT）”作为抓取生成器，从不接触否定样本。
  2. **推理阶段**：用 LLM 解析指令、用 3D 部分定位模型定位禁止区域，然后通过 CFG 与 SMC 在采样过程中进行“转向”，不修改训练权重。

### 2.2 生成器：Flow-Matching DiT

- 状态表示为：
  - `xg ∈ R^28`：抓取位姿（3D 平移、3D 轴角旋转、22 个 ShadowHand 关节角）。
  - `xc ∈ R^(8×4)`：8 个接触槽，每个包含 3D 接触坐标 + 占用标志。
- 模型结构：12 层 DiT，隐藏维度 768，约 130M 可训练参数；每个状态作为 1+8 个 token；通过自注意力和交叉注意力融合冻结的 Qwen2.5-0.5B（文本）与冻结的 PartField（点云）条件。
- 训练目标：回归沿直线路径的流速场 `vθ(x,t)`，抓取位姿与接触 token 共同去噪。

### 2.3 指令解析与区域定位

- LLM 解析器（Gemma 4）将原始指令拆成：
  - **正向改写**（去掉否定子句，作为生成器唯一条件）；
  - **部位词表**，并标记哪部分是禁止的。
- 将禁止部位放入正向模板 "Grasp the {category} by the {part}"，作为引导对比中的“反向 prompt B”。这样做的原因是模型只会把提到部位当作抓取指令，因此越“肯定”越有效。
- Find3D（冻结）对物体点云每个点分配部位标签，从而得到禁止区域 ℱ。

### 2.4 CFG 引导：带门控的垂直引导

- **先验估计**：在每一步形成一步完成状态的接触坐标估计：`x̂c = xc + (1 - t)vA_c`。
- 对 prompt B 再做一次前向得到 `vB_c`，然后更新接触速度：
  ```
  vc ← vc^A + w · 1[d(x̂c, ℱ) < gate] · g⊥
  g⊥ = orth(vc^A - vc^B, vc^A)
  ```
- 关键点：
  - 只取差向量中与 `vA_c` 正交的分量，避免抵消正向目标；
  - 用指示函数实现“自限性”，候选已远离禁止区域时引导自动失效；
  - 只引导接触坐标，位姿由条件生成协同演化。

### 2.5 SMC 粒子转向与 Churn

- **势函数**：对先验估计计算：
  ```
  Φ(xt) = 0.5·ψ(x̂c, ℱ; τ) + 0.5·(1 - ψ(x̂c, O; δ))
  ```
  其中 `ψ` 是随距离增加从 0 到 1 的归一化函数。势函数同时奖励“远离禁止区域”和“接近物体表面”。
- **重采样**：在预定义步数（例如第 10、20 步）计算粒子权重：
  ```
  ω ∝ exp(λ · Φ_max)
  ```
  其中 Φ_max 是运行最大值，避免因某一步异常低分而过度惩罚粒子；然后按权重替换复制粒子。
- **Churn（扰动）**：用边际保持的随机 SDE 更新替代确定性 ODE：
  ```
  xt+dt = xt + (vθ - η·ε̂θ)dt + sqrt(2η(1 - t)dt)·ε
  ```
  作用是让重采样后相同的双胞胎粒子能重新分化，避免粒子集坍缩（确定性 SMC 会将唯一粒子数从 16 降到 2–5）。
- **最终选择**：通过正运动学重建手网格，选择离禁止区域至少 m 距离且最接近物体表面的候选；若无合格候选则逐步放松 margin。

- 在 DexGYSNet 基础上增加禁止约束，构建 6,928 条指令（4,085 训练 / 2,843 测试），覆盖 672 个场景、20 个类别；测试集继承 DexGYSNet 的物体级划分，保证测试物体训练时不可见。

- 指令由 Gemma 4 生成，包含多种措辞、语气和 12 种否定表达，防止单一短语掩盖问题。

## 6. 主要结论与发现

- 语言驱动灵巧抓取模型在否定约束下存在系统性失败，且可归因于训练数据缺乏否定监督，而非单纯的模型结构缺陷。
- 纯推理时转向可实现有效的否定约束控制：在 NegGrasp 上，最强基线 DextER+BoN 的违规率从 29.9%（进而原始模式 57.9%）降至 17.2%，污染率降至 6.6%，CSR 达 61.5%，TSR 达 38.7%。
- 消融证明各组件互补：CFG 单独提升合规但损害物理质量；确定性 SMC 单独恢复物理质量但造成粒子坍缩、违规回升；Churn 是防止坍缩的关键，使合规收益与物理收益同时保留。
- 冻结预训练编码器至关重要——微调 PartField 会明显损害其部位聚类能力。

## 7. 优点

- **无需否定样本训练**：纯推理时转向，可处理训练时未见、任意变化的用户级约束，避免为每个约束收集标注。
- **方法模块化、可控性强**：LLM 解析、Find3D 定位、CFG/SMC 转向、最终几何检查均可替换，且不触碰生成器权重。
- **设计巧妙**：
  - 正交 CFG 避免反向 prompt 消除正向目标；
  - 门控使引导自限；
  - Churn 的边际保持设计在保持分布的同时解决粒子坍缩；
  - 势函数采用运行最大值避免单步坏估计过度惩罚。
- **基准构建严谨**：仅使用“竞争部位”保证任务可解；指令多样；合理划分，防止训练信息泄露。
- **统计验证充分**：宏/微观区分、bootstrap 置信区间、运行稳定性分析（CSR 标准差 0.1 pp）。

## 8. 不足与局限

- **依赖上游冻结模型**：当 LLM 解析或 Find3D 定位失败时（50/2,843 案例），转向无从生效；多个禁止区域只处理第一个，无法全面执行多约束指令。
- **物理验证局限**：所有评估在仿真中进行，采用单一 ShadowHand、单物体场景，物理成功依赖 Isaac Gym 协议，未在真实机器人上验证。
- **成功率仍偏低**：约束感知成功率为 61.5%、TSR 为 38.7%，说明仍有大量抓取不够稳定或不够精准。
- **算力信息不完整**：训练总时长、总步数未报告，复现需要自行估计成本。
- **超参数数量较多**：CFG 门控、λ、η、τ、δ、重采样计划等均需调试；虽然论文指多数轴不敏感，但完全固定的默认值不一定在任意新场景最优。
- **任务设定较窄**：仅考虑单物体点云和 20 类、27 个受限部位；未涉及杂乱场景、多物体或连续指令变更。

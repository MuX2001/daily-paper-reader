## 摘要
主流机器人策略通常采用马尔可夫形式，但许多复杂的真实世界操作任务本质上是非马尔可夫的，需要超越当前观测的长时程记忆。现有记忆机制往往依赖语言摘要、不断增长的视觉窗口或二者的组合，因此可能丢失细粒度的视觉证据，或在历史覆盖范围与执行效率之间面临权衡。我们提出 MaP-WAM，一种“记忆即计划”框架，它将依赖记忆的世界-动作建模分解为基于记忆的规划与以计划为条件的执行，并将长期多模态情景上下文用作规划时的证据，而非反复以完整历史为执行器提供条件。MaP-WAM 将记忆表示为包含语言指令和稀疏视觉上下文的已完成片段记录，并将这种情景记忆转换为紧凑计划，这些计划包含下一段级语言计划和相应的视觉引导。一个世界-动作-进度（WAP）模型在推理时通过联合预测动作块和相应的执行进度，在未知时长上执行每个计划，并通过计划-观测对齐来校准预测进度，以实现自适应片段转换和闭环上下文更新。MaP-WAM 保持执行器上下文长度固定，而结构化注意力进一步支持规划和执行中的键值缓存。MaP-WAM 在 RMBench 上以 83.3% 的成功率取得最先进性能，在真实机器人任务上达到 78.0% 的成功率，同时随着任务历史增长，执行器推理延迟保持大致恒定。

## Abstract
Mainstream robotic policies often adopt a Markovian formulation, but many complex real-world manipulation tasks are inherently non-Markovian, requiring long-horizon memory beyond the current observation. Existing memory mechanisms often rely on language summaries, growing visual windows, or their combinations, and may therefore lose fine-grained visual evidence or face a trade-off between history coverage and execution efficiency. We introduce MaP-WAM, a Memory-as-Plans framework that decomposes memory-dependent world-action modeling into memory-grounded planning and plan-conditioned execution, and uses long-term multimodal episodic context as planning-time evidence rather than repeatedly conditioning the executor on the full history. MaP-WAM represents memory as completed segment records containing language instructions and sparse visual context, and converts this episodic memory into compact plans comprising the next segment-level language plan and corresponding visual guidance. A World-Action-Progress (WAP) model executes each plan over an unknown duration by jointly predicting action chunks and corresponding execution progress at inference time, calibrating predicted progress through plan-observation alignment for adaptive segment transitions and closed-loop context updates. MaP-WAM keeps the executor context length fixed, while structured attention further enables key-value caching in both planning and execution. MaP-WAM achieves state-of-the-art performance on RMBench with an 83.3% success rate and attains 78.0% success on real-robot tasks, while maintaining approximately constant executor inference latency as task history grows.

# MaP-WAM 论文总结：记忆即计划（Memory as Plans）

## 1. 核心问题与研究动机

- **背景**：主流 VLA（视觉-语言-动作）策略与世界-动作模型（WAM）大多采用**马尔可夫假设**，仅以当前观测或固定短历史作为决策依据。
- **矛盾**：许多真实操作任务本质是**非马尔可夫、部分可观测**的——做出下一步决策所需的信息（如物体初始位置、已按下的按钮序列）可能已从当前视野中消失，因此策略必须具备超越当前观测的**长时程记忆**。
- **现有记忆机制的三种缺陷**：
  - **语言记忆**（MemER、Mem-0、MEM）：把历史压缩为语言摘要/子任务指令，紧凑可解释，但**丢失细粒度视觉与空间证据**，在 Swap T 类精确视觉记忆任务上性能骤降（14%）。
  - **持续更新的潜在记忆/记忆库**：早期证据易被压缩或覆盖，长时程下难以保留任务相关信息。
  - **增长/滑动视觉窗口**（含因果 WAM，如 LingBot-VA）：保留丰富视觉证据，但逐帧条件化使**推理延迟与 GPU 显存随历史快速膨胀**——全上下文执行器在 1500 帧时延迟约为零历史时的 4 倍，1700 帧时显存超 80 GB 直接 **OOM**。
- **核心论点与含义**：长时程视觉历史**不必在每个控制步都作为执行模型的直接输入**；它主要用于决定"下一段该做什么、期望看到什么"，执行阶段只需遵循一个由记忆锚定的计划。由此形成"历史覆盖 vs 执行效率"这一权衡的破解思路。

## 2. 方法论：Memory-as-Plans 框架

### 2.1 核心思想
把依赖记忆的世界-动作建模**解耦**为两个阶段：
- **基于记忆的规划**（π_P）：把长期多模态情景上下文转化为紧凑计划；
- **以计划为条件的执行**（π_E）：在固定上下文长度下执行计划。

形式化：整体策略 π(a_{t+1:t+h} | f_{≤t}, s_t, l) 被拆为
- 规划：π_P(C_k | C_{<k}, l)
- 执行：π_E(a_{t+1:t+h} | C_k, f_t, s_t, l)，且 [t, t+h] ⊆ H(C_k)

其中 H(C_k) 为计划的执行时域，**不预先固定**，由在线进度门控决定。

### 2.2 结构化多模态情景上下文
- 每个已完成片段 i 记录为 **C_i = {l_i, G_i}**：语言指令 + 稀疏视觉上下文。
- G_i 由该片段真实执行轨迹在时间上**均匀分成 8 个 bin、各取最后一帧**构成（N=8）；初始观测单独记为 G_0 = f_0。
- 片段 k 之前的上下文 C_{<k} 含 1+8(k−1) 帧，经 WAN-VAE 压缩为 1+2(k−1) 个潜时间步。

### 2.3 记忆锚定的语言-视觉规划
- **语言规划器**：微调 Qwen3.5-4B，输入全局指令 l、已完成片段指令 l_{<k} 与关键帧集 f*（初始帧 + 每个已完成片段末帧），预测下一段语言计划 l_k：π^l_P(l_k | l_{<k}, l, f*)。
- **视觉规划器（CWM）**：以 WAN-2.2-5B 初始化，用**流匹配（flow matching）**目标生成视觉计划 G_k，条件为 (G_{<k}, l_k, l)。
- **因果注意力与 KV 缓存**：token 按片段分块，采用**块因果掩码**，使已完成证据成为与目标块无关的静态可缓存前缀，后续规划阶段可复用其 KV 状态。

### 2.4 World-Action-Progress（WAP）执行器
- **架构**：在预训练视频 DiT 上以 **Mixture-of-Transformers（MoT）** 扩展出动作专家（1.02B 参数，d_a=1024）与进度专家（207M 参数，d_p=256），联合建模**未来视觉动态、动作块、执行进度**。
- **进度定义**：训练片段 f_{i:j} 的归一化进度 p_t = (t−i)/(j−i)，为执行状态与视觉计划提供连续对齐坐标。
- **结构化注意力**：计划块只关注自身；状态块关注计划+状态；动作/进度/未来视觉 token 互不越界（动作与进度 token 不看未来视觉 token，反之亦然），未来视觉预测仅作辅助训练目标、推理时可省略；交叉注意力中所有 token 关注 l_k，动态 token 额外条件于 s_t 与 p_t。
- **训练目标**：对三类目标 y_v（未来视觉）、y_a（动作块）、y_p（进度序列）施加条件流匹配损失，L_E = λ_v L^v_E + λ_a L^a_E + λ_p L^p_E，共享条件 c = (G_k, l_k, f_t, s_t, p_t)；λ 均取 1.0；动作与进度分支共享流时间步，视频分支独立。

### 2.5 闭环规划与执行
- **计划-观测对齐（进度校准）**：部署时无真值进度，递归预测会累积误差。以"本片段初始帧 + 8 帧视觉计划"构成 9 帧参考序列（进度线性 0→1），在估计进度附近取两帧，用 **RGB 空间平均绝对像素差**选出与当前观测最相似者，把进度条件更新为 p_t 与该帧进度值的平均。
- **进度门控片段转换**：对最新动作上的预测进度取平均，超过阈值 **τ = 0.95** 即判定当前片段完成，终止该计划、更新情景上下文、触发下一轮规划。
- **上下文更新用真实观测**：重采样真实执行观测为稀疏视觉证据 G_k 写入记录 {l_k, G_k}，而非使用生成的视觉计划，保证上下文锚定真实世界。
- **效率保证**：执行器上下文长度与历史长度**无关**，计划前缀每段仅预填充一次并复用 KV 缓存。

## 7. 局限性、可复现性与整体评价

### 7.1 论文自述或可推断的局限
- **规划器是性能天花板**：视觉计划 G_k 由 CWM 生成，若规划阶段生成的计划本身偏离真实世界（物体、颜色、空间关系错误），执行器只能在错误计划下尽力而为。论文未报告规划质量本身的量化指标（如与真实关键帧的像素/语义相似度），只通过端到端成功率间接反映。
- **两阶段解耦引入级联误差**：规划误差 → 进度估计误差 → 门控切换时机误差，三者串联。论文用进度校准部分缓解，但未给出误差传播的理论或经验分析。
- **门控阈值 τ=0.95 为固定超参**：未做阈值敏感性实验（如 0.8/0.9/0.95/0.99 的对比），而该阈值直接决定片段何时终止，可能对任务步长分布敏感。
- **稀疏视觉上下文（N=8）的信息损失**：每片段仅保留 8 帧，对片段内部细微状态变化（如连续多次按压的中间态）可能不足以支撑后续规划；论文未消融 N 的取值。
- **真机规模有限**：仅 2 个任务、50 条训练轨迹、50 次试验，且任务设计（白板指令、盖子颜色）相对受控，距离开放环境的长时程操作仍有差距。
- **单任务训练 WAP**：与"通用执行器"的愿景有距离，多任务/跨任务泛化未验证。

### 7.2 可复现性评估
- **较强项**：给出了明确的骨干模型（Qwen3.5-4B、WAN-2.2-5B）、参数规模、LoRA 配置、优化器与学习率、批大小与梯度累积、训练 epoch、评测协议（50 演示 / 100 rollouts / seed 0）、推理硬件与精度（A800、BF16、10 步去噪）、计时方法（5 次预热 + 100 次平均）。
- **较弱项**：
  - 未给出训练总时长或 GPU 小时数，复现成本难以预估；
  - 数据集（RMBench 为公开基准，但真机数据采集流程、白板 OCR/颜色识别等预处理细节描述有限）；
  - 部分超参（N=8、τ=0.95、λ=1.0、进度校准的"两帧取平均"策略）缺少选择依据的说明；
  - 未提及代码/模型权重是否开源。

### 7.3 方法层面的关键洞察
1. **"记忆不必逐帧进执行器"是一个有价值的解耦假设**：把长历史的作用重新定位为"决定做什么"，而非"参与每一步怎么做"，从架构上打破了历史覆盖与推理效率的绑定。
2. **计划作为记忆的压缩载体**：语言计划 + 8 帧稀疏视觉证据，构成了对已完成片段"语义 + 关键视觉"的双通道摘要，比纯语言摘要保留更多空间证据，又比全帧窗口便宜得多。
3. **进度（progress）作为显式建模变量**：把"执行到哪了"从隐式状态变成可预测、可校准、可用于门控的显式量，是长时程任务分段执行的关键黏合剂。
4. **KV 缓存友好的块因果结构**：把已完成片段设计为静态可缓存前缀，使规划器延迟随历史仅缓慢增长，是工程上可落地的设计。

### 7.4 需要读者警惕的对比公平性问题
- 表中基线的部分数值为"-"或引用值，**并非全部在同一训练/评测条件下复现**，因此 83.3% vs 77.1%（LingBot-VA）这一差距的稳健性需谨慎解读；真正的差距应看趋势而非单点数字。
- MaP-WAM 的规划器多任务训练、WAP 单任务训练，与某些端到端基线（单任务或统一训练）的设定不完全对等，训练数据量、参数量与算力投入也未与基线逐一对齐。
- 真机与仿真均未报告多种子方差或置信区间，**单次实验的随机波动无法从论文中评估**。

### 7.5 总体评价
- **贡献定位**：MaP-WAM 是一篇"架构解耦 + 系统实现"型的论文，核心贡献不在于提出全新的学习范式，而在于**重新组织记忆、规划与执行三者的关系**，并用可运行的完整系统（规划器 + 视觉世界模型 + 执行器 + 闭环校准）证明该组织方式在长时程记忆任务上同时具备性能与效率优势。
- **证据强度**：仿真（9 任务 × 100 rollouts）+ 真机（2 任务 × 50 trials）+ 两组消融 + 效率曲线的组合，在同类工作中属于中上水平，主要短板是**消融覆盖不全、缺乏统计显著性检验、部分基线非自复现**。
- **实用价值**：恒定延迟 + 恒定显存这一性质对真实机器人部署意义重大；1700 帧 OOM vs 约 827 ms 恒定的对比，直观说明了"全上下文"路线在长时程下的不可行性。
- **适用边界**：方法假设任务可被切分为语义上可命名的片段，且每片段存在可估计的单调进度；对高度连续、无明显阶段结构或进度非单调的任务，其片段门控与进度校准机制可能失效。

## 8. 一句话总结

MaP-WAM 通过"记忆只负责规划、执行只看计划"的两阶段解耦，配合稀疏多模态情景上下文、进度门控与计划-观测校准，在长时程记忆型操作任务上以恒定推理成本取得了超越全上下文世界-动作模型的成功率，但其规划质量上限、级联误差与对比公平性仍留有进一步验证空间。

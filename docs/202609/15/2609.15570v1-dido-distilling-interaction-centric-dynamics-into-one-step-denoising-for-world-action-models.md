## 摘要
世界动作模型（WAMs）利用视频生成模型预测机器人操作中的未来视觉动力学，但迭代去噪会给闭环控制带来额外延迟。我们通过实验发现，视觉内容在去噪过程中以不同速率收敛。静态背景结构较早形成，而夹爪和被操作物体在第一步后仍然模糊，其交互动力学只有通过后续去噪才逐渐显现。因此，简单地将多步视频模型截断为一步，虽能保留场景结构，却会丢失对操作最为关键的交互中心动力学。为解决这一问题，我们提出 DIDO，它将多步视频模型中已收敛的动力学蒸馏到单步去噪中。DIDO 将分布匹配蒸馏与交互中心表示引导相结合。除了将多步生成压缩为一次前向传播外，DIDO 还利用有监督的边界框视觉推理 token 显式建模夹爪、被操作物体及其交互。此外，DIDO 将目标物体在多个模型层中的表示与预训练 DINOv3 编码器的特征对齐。这种以交互为中心的引导有助于蒸馏模型在单步中同时保留相关实体及其未来动力学，同时大幅降低推理延迟。DIDO 在 LIBERO 上取得了 99.0% 的平均成功率，在 LIBERO-Plus 上为 76.6%，在 RoboTwin 上为 92.0%，同时还在真实世界机器人操作中展现出向长时程与泛化任务的有效迁移。

## Abstract
World Action Models (WAMs) use video generation models to predict future visual dynamics for robotic manipulation, but iterative denoising introduces additional latency for closed-loop control. We empirically find that visual content converges at different rates during denoising. Static background structure forms early, whereas the gripper and manipulated object remain blurry after the first step, with their interaction dynamics emerging only through subsequent denoising. Consequently, naively truncating a multi-step video model to one step preserves scene structure but loses the interaction-centric dynamics most critical for manipulation. To address this issue, we propose DIDO, which distills the converged dynamics of a multi-step video model into a single denoising step. DIDO combines distribution matching distillation with interaction-centric representation guidance. Beyond compressing multi-step generation into one forward pass, DIDO explicitly models the gripper, manipulated object, and their interaction using supervised bounding-box visual reasoning tokens. Additionally, DIDO aligns the target object's representations across multiple model layers with features from a pretrained DINOv3 encoder. This interaction-centric guidance helps the distilled model preserve both the relevant entities and their future dynamics in a single step, while substantially reducing inference latency. DIDO achieves an average success rate of 99.0\% on LIBERO, 76.6\% on LIBERO-Plus, and 92.0\% on RoboTwin, while also demonstrating effective transfer to long-horizon and generalization tasks in real-world robotic manipulation.

# DIDO 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：视觉-语言-动作模型（VLA）在机器人操作上表现优异，但大多直接由当前观测与语言指令预测动作，不显式建模环境随动作的演化。世界动作模型（WAM）则借助视频生成模型预测未来视觉动力学，为策略提供显式"前瞻"。
- **核心痛点**：视频生成依赖迭代去噪，多步推理带来显著延迟，难以满足闭环控制的实时性要求。
- **关键经验发现**（论文的核心洞察）：
  - 去噪过程中视觉内容的收敛速率在空间上不对称：**静态背景结构在第一步就已成形**，而**夹爪与被操作物体在第一步后仍然模糊**，其交互动力学要等到后续去噪步骤才逐步锐化并空间局部化。
  - 因此，把多步视频模型**朴素截断为一步**，会保留场景结构但丢失对操作最关键的**交互中心动力学**。
- **整体含义**：DIDO 试图在"保留预测性未来动力学"与"单步低延迟推理"之间取得兼顾——不是简单地砍掉未来想象，也不是笼统地把多步压缩成一步，而是**有选择地把交互相关动态蒸馏进单步去噪**。

## 2. 方法论

### 2.1 核心思想
以 Wan2.2-TI2V-5B 的四步蒸馏版本为起点，先在机器人操作数据上微调得到"机器人域四步教师"，再用分布匹配蒸馏（DMD）把教师**收敛后的输出分布**压入单步生成器，并通过交互中心表示引导补回蒸馏目标本身不强调的"夹爪—物体交互"信息。最终单步世界模型通过 mixture-of-transformers 与动作专家耦合，无需解码未来帧即可供策略使用。

### 2.2 关键技术细节

- **单步世界动力学蒸馏（Stage I 主体）**
  - 目标为最小化单步生成器与四步教师在扰动分布上的 KL 散度：`L_DMD = E_t[D_KL(p_θ,t ∥ p_T,t)]`。
  - 梯度用 fake score 与 target score 之差估计；由于采用 flow-matching 前向加噪 `x_t = (1-σ_t)x_g + σ_t ε`，两者的分数差等价于其**干净潜变量预测之差**乘一个正的时变系数。
  - 实际使用归一化梯度代理 `g_DMD = (x̂_0^F - x̂_0^T) / mean|x_g - x̂_0^T|`，经 stop-gradient 代理目标注入生成器。
  - 教师分数在与其离散去噪日程对齐的噪声水平 {1000, 750, 500, 250} 上评估；fake score 网络在线更新且比生成器更新更频繁（每 5 步更新一次生成器）；真实分数网络使用引导尺度 7。
  - **关键点**：DMD 让单步生成器匹配教师的**收敛输出分布**，而非复现教师第一步的粗糙预测。

- **交互中心视觉推理**
  - 向视频 Transformer 中注入四组共 64 个 token（各 16 个）：目标物体 `T_obj`、交互 `T_int`、夹爪 `T_grip`、对齐 `T_align`。
  - **轨迹监督**：夹爪分支 `[T_grip; T_int]` 预测 H_a=32 步的未来夹爪框序列，物体分支 `[T_obj; T_int]` 预测物体框序列；**共享 `T_int`** 以鼓励其捕捉两者的相对时空演化。损失为 smooth-L1（β=1.0）+ GIoU 的逐帧平均，形成 `L_inter = λ_obj L_box(b̂_obj,b_obj) + λ_grip L_box(b̂_grip,b_grip)`。
  - **多层视觉对齐**：用物体框裁剪目标区域、放大固定边距并缩放至 DINOv3 输入分辨率，冻结的 DINOv3 编码器输出作为固定目标；在选定 Transformer 层用轻量投影 `P^l` 把 `T_align` 的表示对齐到 DINOv3 特征（L1 损失 `L_align`）。DINOv3 仅用于训练，推理时移除。
  - 标注自动生成：物体框由 LaRA-VLA 的自动流程（开放词表检测 + 视频跟踪）获得；LIBERO/RoboTwin 的夹爪框由仿真状态投影得到，真实平台用 Grounding DINO + SAM 3 双向跟踪并线性插值补缺。

- **交互感知动作预测与动力学 token 精炼**
  - 动作专家与视频模型同深度、1/4 隐藏宽度，通过**非对称共享注意力**耦合：动作 token 可访问全部世界模型表示，而世界模型 token 对动作流保持掩码，以保留 Stage I 学到的预测通路。
  - 未来视频 token 冗余大，故按动力学差异做稀疏化：以 `s_tk(r)=‖V_tk(r)-V_t0(r)‖_2` 度量各细粒度单元变化，将空间划分为 4×5=20 个区域（每区 2×2 单元），按区域动力学得分排序，**保留前 3 个高动态区域的完整 token，其余 17 个区域做 2×2 平均池化**；对 key/value 同样处理。
  - 动作生成用 flow matching：`a_τ=(1-τ)ε+τa`，目标速度 `u=a-ε`，损失 `L_act=E‖v_θ(a_τ,τ)-u‖²`；推理用 10 步 Euler 积分，LIBERO 执行前 10 个动作、RoboTwin 执行前 24 个动作后重规划。

- **两阶段训练**
  - Stage I：`L_stage1 = L_DMD + L_inter + λ_align L_align`（单步蒸馏 + 轨迹监督 + 视觉对齐）。
  - Stage II：`L_stage2 = λ_video L_video + λ_act L_act + L_inter + λ_align L_align`，视频生成目标保留为训练信号；文本编码器、VAE、DINOv3 冻结，其余联合优化；DMD 仅用于 Stage I，推理全程单步。

## 6. 主要结论与发现

- **现象层面**：视频去噪中"结构先收敛、交互后收敛"存在明确的时空不对称，且后续去噪步确实提供更多对动作有用的信息——用四步模型在 t=1→4 条件下，LIBERO 从 97.7% 升至 98.4%，LIBERO-Plus 从 71.4% 升至 72.6%。
- **方法层面**：DMD 单步蒸馏可把收敛的多步动力学压入一步（97.7→98.3 / 71.4→72.3）；交互中心视觉推理进一步带来最大增益（→98.9 / 75.9）；动力学 token 精炼再加成（→99.0 / 76.6），同时把条件上下文从 323 个 token 降到 191 个，端到端延迟降低约 30 ms。
- **性能层面**：LIBERO 平均 99.0%（SOTA，比 LingBot-VA/Faster-WAM 高 0.5 点，比 Fast-WAM 高 1.4 点，比同为单步蒸馏的 Flash-WAM 高 2.9 点）；RoboTwin 92.0%（仅次于 LingBot-VA 的 92.2%，但是在**无具身预训练**方法中最好）；LIBERO-Plus 平均 76.6%，在机器人初始化、语言表述、光照、物体布局四类扰动上排名第一。
- **真实世界**：basic 协议平均 80.8（π0.5 为 74.5，Fast-WAM 为 53.8），advanced 协议 66.0（对应 53.3 与 33.0）；从 basic 到 advanced 的性能退化 DIDO 为 14.8 点，小于 π0.5 的 21.2 点和 Fast-WAM 的 20.8 点，说明在目标位置与场景外观同时变化时泛化更稳。
- **效率层面**：DIDO 相对四步教师降低 32% 延迟且成功率反升（98.4→99.0）；相对完全不做未来想象的 Fast-WAM 仅多 28 ms，却在 LIBERO 高 1.4 点、LIBERO-Plus 高 25.1 点。
- **机制层面**：交互中心 token 仅占动作专家可访问缓存 token 的 5.74%，却贡献 33.9% 的动作归因，每 token 归因密度约为频率预期的 5.9 倍（Object 6.03×、Interaction 5.98×、Gripper 7.32×、Align 5.60×），而当前/未来视觉 token 仅为 0.61× 和 0.73×，说明交互 token 把动作相关信息高度浓缩。

## 7. 优点

- **洞察驱动而非纯工程堆叠**：先用可视化 + 潜空间分析揭示"交互动态后收敛"的现象，再据此设计方法，动机链条清晰，并用 Figure 5 的去噪步数实验对动机做了独立验证。
- **蒸馏目标选得对**：用 DMD 匹配教师**收敛分布**，而非模仿教师第一步的粗糙输出，正好对应"朴素截断会丢交互"这一问题。
- **表示层面的显式结构化**：共享 `T_int` 的夹爪/物体双分支轨迹监督，加上跨层 DINOv3 对齐，使交互建模同时具备几何（框）与判别性视觉（特征）两种监督，且监督信号全部自动标注获得，无需人工标注。
- **效率设计克制且可解释**：动力学引导的 token 精炼只压缩近静态区域、保留高动态区域全分辨率，既降 token 数又降延迟，且在分布偏移下收益更大（LIBERO-Plus 上增益更明显）。
- **架构上非对称共享注意力**：动作专家可直接读取世界模型中间表示而无需解码—重编码未来视频，同时用掩码保护 Stage I 学到的预测通路，避免了联合训练对预测能力的破坏。
- **实验矩阵完整**：仿真单臂/双臂、真机、鲁棒性扰动、长时程任务、累积消融、逐任务细粒度结果、token 归因分析、标注质量审计一应俱全；真实基线在同等数据与预算下重训，比较相对公平。
- **明确的实用价值**：在不使用具身预训练的前提下达到接近/达到 SOTA，说明方法对数据条件要求不高，可迁移性较强。

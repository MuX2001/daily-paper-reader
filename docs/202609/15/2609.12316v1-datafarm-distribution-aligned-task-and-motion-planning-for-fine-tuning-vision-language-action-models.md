## 摘要
收集高质量的机器人数据仍然是训练机器人基础模型的一项根本挑战。任务与运动规划（TAMP）提供了一种可扩展的方式来生成演示数据，但我们的实验表明，尽管原始 TAMP 轨迹能够成功解决目标任务，但在用于微调预训练的视觉-语言-动作（VLA）模型时，其带来的收益出人意料地小。我们假设，这种失败源于规划器生成的轨迹与用于预训练 VLA 的数据之间存在行为分布不匹配。为解决这一不匹配，我们提出 DATAFARM：用于微调机器人基础模型的分布对齐任务与运动规划（Distribution-Aligned Task And motion planning for Fine-tuning A Robot foundation Model），该方法将预训练分布直接纳入 TAMP 轨迹生成过程。DATAFARM 在机器人关节配置、运动风格和时间执行轮廓方面使生成的轨迹与预训练数据对齐。我们在三个 TAMP 可执行的桌面操作任务以及一个超出 TAMP 能力的叠衣任务上评估 DATAFARM。DATAFARM 取得了 56.7% 的平均成功率，显著优于原始 TAMP（8.3%），并接近人类遥操作（61.7%）。在微调分布之外的可变形物体操作上，微调后的模型保持了 85% 的成功率，而预训练模型为 90%。这些结果表明，将规划器生成的演示数据与预训练分布对齐，可以使 TAMP 成为 VLA 微调的有效数据来源。网站与代码：https://prpl-group.com/datafarm/

## Abstract
Collecting high-quality robot data remains a fundamental challenge for training robot foundation models. Task and motion planning (TAMP) offers a scalable way to generate demonstrations, but our experiments show that raw TAMP trajectories provide surprisingly little benefit when used to fine-tune pretrained vision-language-action (VLA) models, despite successfully solving the target tasks. We hypothesize that this failure arises from a behavioral distribution mismatch between planner-generated trajectories and the data used to pretrain the VLA. To address this mismatch, we introduce DATAFARM: Distribution-Aligned Task And motion planning for Fine-tuning A Robot foundation Model, an approach that incorporates the pretraining distribution directly into TAMP trajectory generation. DATAFARM aligns generated trajectories with the pretraining data in robot joint configurations, motion style, and temporal execution profiles. We evaluate DATAFARM on three tabletop manipulation tasks that TAMP can perform and a cloth-folding task beyond the capability of TAMP. DATAFARM achieves an average success rate of 56.7%, substantially outperforming raw TAMP (8.3%) while approaching human teleoperation (61.7%). On Deformable Object Manipulation, which is outside the fine-tuning distribution, the fine-tuned model retains 85% success, compared with 90% for the pretrained model. These results show that aligning planner-generated demonstrations with the pretraining distribution can make TAMP an effective source of data for VLA fine-tuning. Website and code: https://prpl-group.com/datafarm/

# DATAFARM 论文总结

## 1. 核心问题与研究动机

- **背景**：训练机器人基础模型的核心瓶颈是高质量数据获取。人类遥操作数据（如 DROID）成本高但"在分布上"；任务与运动规划（TAMP）可低成本、可扩展地生成演示，但行为分布与 VLA 预训练数据不匹配。
- **关键发现（痛点）**：作者实验发现，即便 TAMP（TiPToP）能成功求解目标任务，用其原始轨迹微调预训练 VLA（π0.5-DROID）收益极小——三个桌面任务平均成功率仅从 1.7% 提升到 8.3%。
- **核心假设**：失败并非因为规划器解不出任务，而是**行为分布不匹配（behavioral distribution mismatch）**：任务上有效的轨迹，其关节配置、运动风格、执行速度可能与预训练轨迹差异巨大。
- **整体含义**：目标是设计一种数据采集流程，**无需人类操作目标任务的演示**，即可生成"在分布上"的微调数据，既教会 VLA 新任务（TAMP 可解），又尽量保留其原有能力（如 TAMP 无法完成的布料折叠）。

## 2. 方法论：DATAFARM

**核心思想**：把 VLA 预训练数据的分布直接写进 TAMP 的轨迹优化目标中，在三个层面引导规划器生成与预训练分布对齐的轨迹。系统构建在 TiPToP + cuTAMP + cuRobo 之上。

- **总体流程**（图 2）：先从预训练参考数据 D_ref（论文用 DROID）学习两类参考模型（配置密度 + 轨迹隐分布），作为 TAMP 的对齐代价；规划器在满足任务/运动约束前提下优化端点选择、路径与时间参数化；在真机执行生成演示集 D，用于微调 π0.5-DROID。

### （1）关节配置对齐（端点选择）
- 对 D_ref 中**仅手臂运动帧**（避免长时间停顿主导密度）拟合 16 分量全协方差高斯混合 p_conf(q)（7 关节角，约 987,631 帧 / 4,000 条参考轨迹）。
- 定义配置代价 `c_conf(q) = −log p_conf(q)`。
- 对每个候选末端位姿 x，用 c_conf 对 IK 解集 Q(x) 排序并取最小：`q* = argmin_{q∈Q(x)} c_conf(q)`。
- 还考虑平行夹爪的 π 旋转对称性，在 `Q(x) ∪ Q(xR_π)` 上联合选取，并将存储的抓取更新为所选代表；未通过正运动学校验的候选被丢弃，若无剩余则回退到原始 IK 流程。

### （2）运动风格对齐（路径优化）
- **轨迹编码器** E_φ：将轨迹段 ξ 映射到 d=16 维隐向量 z。
  - 输入：以 F=15 Hz 重采样，拼接位置、速度、加速度、jerk（共 28 通道），按参考数据统计量标准化；时间池化 + padding mask 支持变长输入。
  - 训练：自监督 + 变分正则，辅助头 g_ψ 从采样隐变量预测 **113 维运动描述子**（7 关节 × 14 个逐关节描述子 = 98 项，加 15 个整轨迹描述子，涵盖速度/加速度/jerk 统计、活动范围、方向反转率、频谱分带占比、路径几何、平滑度 SPARC/LDLJ、子运动速率、频谱质心/带宽/熵等）。目标为加权描述子预测误差的期望 + β·KL（β=0.005，free bits 0.10 nats/维，权重 w 平衡尺度）。
  - 训练数据含随机时间裁剪（每片段 6 个，长度占比 U[0.4,1.0]），以匹配规划时被评分的片段长度。
- **隐参考密度**：训练后冻结 φ，丢弃辅助头与协方差输出，对参考轨迹及其裁剪的嵌入拟合 `p_latent = N(µ, Σ)`。
- **轨迹代价**：`c_traj(ξ) = (E_φ(ξ) − µ)ᵀ Σ⁻¹ (E_φ(ξ) − µ)`（马氏距离平方）。
- **路径优化**：固定端点与采样时刻，最小化 `C_plan(ξ) + λ_path · c_traj(ξ)`（λ_path = 25,000）。梯度经冻结编码器反向传播；因标准化、有限差分、重采样在固定时刻下是仿射映射，其雅可比 `J = ∂Ȳ/∂q` 可预计算并跨迭代复用；规划器原有碰撞/限位等约束与可行性检查保持不变。

### （3）时间/执行轮廓对齐（Retiming）
- 保持几何路径 γ 不变，仅优化时间参数化 s(t)；将路径分成 M=64 个等弧长区间，用 θ 分配时长比例：
  `α_m(θ) = exp(tanh θ_m) / Σ_j exp(tanh θ_j)`，总时长 τ。
- 对 θ 做 tanh 再 softmax，将任意两区间时长比限制在 e² 以内，避免时长趋零导致速度/加速度越限。
- 优化目标：`min_{θ, τ>0} c_traj(ξ_{θ,τ}) + λ_boundary · c_boundary(ξ_{θ,τ})`，其中边界速度惩罚 `c_boundary = (v_start − v̄_grip)² + (v_end − v̄_grip)²`，目标速度 v̄_grip = 0.07 rad/s（由参考数据夹爪事件前后速度测得）；λ_boundary = 50。
- 用 Adam 从 16 个初始时长并行优化（500 次迭代，θ 学习率 0.08，τ 学习率 0.0375），越限候选被拒绝，最终按 c_traj 排序选最优。

## 6. 主要结论与发现

- **演示来源影响巨大**：raw TAMP 只把平均成功率从 1.7% 提到 8.3%（虽每条训练轨迹都成功完成任务），说明"任务有效"≠"对预训练 VLA 有效的微调数据"。
- **DATAFARM 显著提升**：平均成功率 56.7%、平均进度 84.7%（raw TAMP 43.3%、预训练 27.0%），接近人类遥操作的 61.7%；三个任务分别为 65% / 35% / 70%，全面优于 raw TAMP 的 5% / 5% / 15%。
- **对齐度量改善**：关节空间中落入 DROID 轮廓的样本从 raw TAMP 的 66% 提升到 74%；隐空间中从 0% 提升到 96%（去掉 style 为 89%，去掉 timing 仅 19%）。
- **消融结论**：去掉 timing 最致命（三任务全部 0% 成功）；去掉 style 降至 15.0%，去掉 joint space 降至 23.3%。隐空间高重叠（w/o style 仍有 89%）并不保证任务成功。
- **能力保留**：三个任务微调后的模型在布料折叠上分别保持

……了 100% / 100% / 95% 的折布进度，与人类遥操作微调（100%）相当，而 raw TAMP 微调后分别降至 100% / 50% / 0%——说明用分布外数据微调会侵蚀预训练模型原有的 OOD 能力，而分布对齐的数据能在学新任务的同时保住旧能力。

- **演示预算**：Geometric Constraints 上 20 条已接近饱和（DATAFARM 在 0/20/40/60/80 条上均优于 raw TAMP 与预训练基线），说明收益主要来自"数据分布正确"而非"数据量堆叠"；更多数据仍有小幅增益但边际递减。
- **抓取对称性**：在 IK 端点选择中纳入 π 旋转对称候选（512 端点统计）可扩大可行解集并改善配置对齐，是 joint-space 消融中一个具体而有效的设计细节。
- **失败模式**：raw TAMP 微调模型的主要失败是"运动分布外导致的早停/抖动/抓取失败"，而 DATAFARM 的残余失败更多是任务级语义/长程推理错误，表明分布对齐主要解决的是"行为风格"问题，而非任务理解问题。

## 7. 局限性

- **依赖参考数据集**：DATAFARM 需要一份与目标机器人本体/相机配置一致的预训练参考数据（本文用 DROID）来拟合配置密度与轨迹隐分布；若参考数据稀缺或本体不匹配，对齐效果会打折。
- **需要 TAMP 可解**：方法假设任务能被规划器求解；对 TAMP 无法覆盖的任务（如折布），DATAFARM 只能"保留"能力而不能"学会"新任务，因此它不替代人类演示，而是补足那些"可规划但难示范"的任务。
- **编码器容量与隐空间假设**：用 16 维高斯近似轨迹分布、并用 113 维运动描述子作为自监督信号，是一种工程近似；隐空间高重叠（如 w/o style 仍 89%）并不保证任务成功，说明对齐度量与下游性能之间不是单调关系。
- **统计强度**：每个条件单 checkpoint、20 次 rollout，未报告多种子方差，结论的稳健性有待更大规模验证。
- **超参敏感**：λ_path=25,000、λ_boundary=50、β=0.005 等权重为手工设定，未做敏感性分析。

## 8. 总体评价

- **贡献定位**：论文的核心洞见——"TAMP 轨迹任务上有效，但对 VLA 微调无效，根因是行为分布不匹配"——把"数据从哪来"的问题从"任务正确性"提升到"分布正确性"，并给出了一个可操作的、把预训练分布写进规划目标的三层对齐框架。这是一个清晰、可复现、工程上扎实的贡献。
- **方法优雅性**：将配置密度、轨迹隐分布、时间参数化三个层面分别建模并各自对应 TAMP 的端点选择、路径优化、retiming，层次分明；用冻结编码器 + 预计算雅可比实现梯度回传，兼顾了表达力与规划器效率。
- **实验说服力**：raw TAMP → DATAFARM 从 8.3% 到 56.7% 的跃升、接近人类遥操作的 61.7%、以及"保留折布能力"这一反直觉结果，构成较强的因果证据链；逐组件消融（尤其 timing 的致命性）进一步支撑了"三层缺一不可"的设计主张。
- **可改进方向**：扩大种子与评估规模、做超参敏感性、把"对齐度量—性能"关系建模得更具预测性、探索参考数据不匹配时的鲁棒性，以及将框架推广到更多本体与更多 VLA 基座。
- **一句话总结**：DATAFARM 证明了"让规划器学会像预训练数据那样运动"比"让规划器解出任务"更能决定 VLA 微调的成败，为无需人类目标示范的可扩展机器人数据采集提供了一条可行路径。

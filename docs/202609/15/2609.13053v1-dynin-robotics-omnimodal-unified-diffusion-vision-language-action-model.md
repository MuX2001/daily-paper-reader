## 摘要
视觉目标与动力学预测能够为语言条件化的机器人策略同时提供目标结果以及动作依赖的场景变化表征。我们通过一个共享轨迹模型将这些预测引入动作生成与选择。Dynin-Robotics 在 Dynin-Omni 上实现了该公式，后者是一个全模态掩码扩散骨干，将语言、视觉观测、目标和动作表示为离散 token。通过改变条件跨度和目标跨度，同一模型学习动作预测、动作条件下的下一观测预测、终止目标状态预测以及轨迹到指令的重建。这些接口通过目标预测、动作候选评估以及动作与未来状态预测的联合细化，支持测试时扩展。我们在来自 48 个 Open X-Embodiment 数据集的约 133 万条轨迹上持续预训练该模型，并将其分别适配到下游领域。在两个 VLABench 任务上，机器人预训练在固定的第二阶段步数预算内提升了适配效果，并且完整目标混合相比仅策略后训练，在相同耦合解码器下提升了偏移指令成功率。将目标引导与联合动作-下一状态去噪相结合，进一步相比仅动作解码提升了偏移指令成功率；其收益取决于预测如何组合。Dynin-Robotics 在 LIBERO 和零样本 LIBERO-Plus 上取得了有竞争力的性能，并在 Franka Research 3 机器人上于四种操作条件下达到 78.4% 的平均成功率。在所述性能分析设置下，一种优化的块并行实现将模型侧动作解码相对于基础实现加速最高 29.2 倍。这些结果支持将共享轨迹建模作为通用接口，用于学习互补的机器人目标，并在控制过程中组合其预测。

## Abstract
Visual goal and dynamics prediction can provide language-conditioned robot policies with both a target outcome and a representation of action-dependent scene changes. We bring these predictions into action generation and selection through a shared trajectory model. Dynin-Robotics implements this formulation on Dynin-Omni, an omnimodal masked-diffusion backbone, representing language, visual observations, goals, and actions as discrete tokens. By varying conditioning and target spans, the same model learns action prediction, action-conditioned next-observation prediction, terminal goal-state prediction, and trajectory-to-instruction reconstruction. These interfaces support test-time scaling through goal prediction, action-candidate evaluation, and joint refinement of action and future-state predictions. We continually pretrain the model on approximately 1.33 million trajectories from 48 Open X-Embodiment datasets and adapt it separately to downstream domains. On two VLABench tasks, robot pretraining improves adaptation within a fixed Stage-2 step budget, and the full objective mixture improves shifted-instruction success over Policy-only post-training under the same coupled decoder. Combining goal guidance with joint action-next-state denoising further improves shifted-instruction success over action-only decoding; the benefit depends on how the predictions are composed. Dynin-Robotics achieves competitive performance on LIBERO and zero-shot LIBERO-Plus, together with a 78.4% average success rate across four manipulation conditions on a Franka Research 3 robot. An optimized block-parallel implementation accelerates model-side action decoding by up to 29.2x relative to the base implementation under the reported profiling setup. These results support shared trajectory modeling as a common interface for learning complementary robot objectives and composing their predictions during control.

# Dynin-Robotics 论文总结

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型将自然语言指令与视觉观测映射为机器人动作，需同时处理目标识别、物体交互与连续控制。视觉目标预测（终态画面）和动力学预测（动作引起的场景变化）本可为策略提供"目标结果"与"动作后果"两类表征，但现有方法通常将其与动作生成割裂。
- **诊断性观察**：作者在 VLABench 上对比 π0.5（VLM+流匹配专家）与 Mimic-Video（视频生成+动作专家），发现二者任务画像不同：π0.5 在 SelectFruit（目标选择）更强，Mimic-Video 在 InsertFlower（插入）的间接指令 Track 4 下具竞争力；且用等长随机串替换指令时，π0.5 成功率下降 16/30 个百分点，Mimic-Video 反而 +10/+2 个百分点。说明语言条件化与视觉预测各有短板。
- **核心问题**：如何在一个共享策略模型中统一语言条件、视觉预测与动作生成，使互补目标可互相复用，并在推理时按需组合以提升控制性能？
- **整体含义**：提出把"指令、观测、目标、动作"统一建模为可互为上下文/预测目标的轨迹变量，从而用同一模型支撑多种条件学习任务与多种推理组合。

## 2. 方法论

### 2.1 核心思想
- 基于 **Dynin-Omni**（全模态掩码扩散骨干，单双向 Transformer、共享 token 嵌入与统一分类预测头），扩展出机器人动作 token 与传感器 token 接口。
- 语言、图像/视频、动作、目标状态均表示为**离散 token**，置于同一类型化轨迹序列中；通过**目标条件掩码**决定哪些 span 可见、哪些被重建。

### 2.2 统一 token 空间
- 总词表：`V_DR = V⁺_text ⊎ V_vision ⊎ V_speech ⊎ V_action ⊎ V_sensor`（各块 token ID 不重叠）。
- 动作离散化：对 7-DoF 接口（3D 平移 + 3D 旋转 + 夹爪）做逐维均匀分箱，用训练集 1/99 分位数做鲁棒归一化，再裁剪、量化映射到动作 token 块；推理时反量化回连续控制。Stage-1 用 256 bins，Stage-2 按域选择（VLABench 选 32）。
- 传感器接口为预留通道（力/力矩、本体感知等），但报告实验中未激活。

### 2.3 四个统一训练目标
- **Policy（o_PO）**：由当前观测 + 指令（可选目标状态、传感器）预测动作块。
- **World Modeling（o_WM）**：由当前观测 + 指令 + 动作块预测下一时刻视觉状态。
- **Goal-State Prediction（o_GP）**：由初始观测 + 指令预测终止目标视觉状态。
- **Task Understanding（o_TU）**：由采样轨迹帧重建任务指令。
- 文本/视觉目标用随机掩码，动作目标用连续块掩码；损失为目标模态词表上的掩码扩散交叉熵，含逆掩码概率加权与目标长度归一化；Policy 额外加期望 bin 的 MAE 辅助损失（β=0.2）。

### 2.4 训练流程
- **Stage-1 持续预训练**：在 OXE 上做统一四目标训练，采用平衡分布式轮转（48 数据集 → 99 分区 → 8 组 → 32 rank 分 8 条数据通道）。分两段：21.8k + 5.8k 更新，第二段更偏 Policy（λ = 1, 0.2, 0.05, 0.2）。
- **Stage-2 后训练**：按域分别适配，可 Policy-only 或统一多目标混合；重算动作归一化统计、选择活跃 bin 数。还引入**轨迹元数据条件化**（动作块 jerk 代理、轨迹步数、成功标记）作为文本上下文。
- **在线 RL 微调**：冻结骨干与 tokenizer，仅训练轻量级**计数-位置重掩码控制器**（PPO 优化），在环境回报与去噪步数代价间权衡：`J_RL = E[Σ γᵗ(r_env − η_den·K_t − η_step)]`。

### 2.5 六种推理组合（测试时扩展）
- (a) 仅动作 Policy；(b) 动作/下一状态联合去噪；(c) **目标状态引导的两阶段 Policy（默认路径）**；(d) 世界模型对动作候选重排序（含 Policy 先验惩罚与双重接受准则）；(e) 目标引导 + 联合去噪；(f) 目标引导 + 候选重排序。
- 世界模型能量为共同参考视觉目标的平均负对数似然，候选需同时满足能量改善余量 δ 与综合排序分改善才被接受。

### 2.6 加速
- 块并行掩码解码：每步并行预测所有掩码动作位置，按置信度提交，动作按时间主序分块细化；结合 dInfer 的上下文复用、CUDA Graph、循环展开等，模型侧动作解码最高加速 **29.2×**。

## 6. 主要结论与发现

- **机器人持续预训练收益巨大**：从 Dynin-Omni 直接 Stage-2 仅 3.26% ID / 0.70% OOD，经 220.8k 微步 OXE 预训练后升至 49.61% / 47.28%。
- **完整目标混合显著提升偏移指令鲁棒性**：相对 Policy-only，ID 47.15%→49.61%，OOD 33.88%→47.28%，gap 13.27→2.33 个百分点；其中 World Modeling 单项主要提升 OOD（+5.66）但略降 ID（−1.14）。
- **推理组合需正确搭配**：单独加目标引导或单独联合去噪均不如仅动作解码（OOD 41.4% → 38.2%/40.5%）；但"目标引导 + 联合动作-下一状态去噪"把 OOD 提到 47.3%（+5.9），gap 降到 2.3。目标引导的作用取决于解码设置。
- **测试时扩展存在收益/成本权衡**：目标引导 + 世界模型筛选 OOD 最高 47.7%，但吞吐降至 4.828 TPS（相对仅动作 9.238 下降约 48%）。
- **策略性能**：LIBERO 98.1%（Spatial 98.9 / Object 99.8 / Goal 97.8 / Long 95.8），略低于 ABot-M0（98.6）但与 X-VLA 持平；零样本 LIBERO-Plus 73.0%，Language 扰动保持 85.0%，Camera 59.8%、Robot 48.2% 明显偏弱；真实 Franka 四条件宏平均 **78.4%**，Color-Ordered Stack 68.5% 为对比中最高。
- **预测质量**：世界建模 PSNR/SSIM 在可学习模型中最高（20.79 / 0.573），但整体仍低于"复制上一帧"（31.07 / 0.953）；目标状态生成弱于 BAGEL。
- **加速有效且保真**：BL7 达 91.236 TPS（9.89×），BL35 达 268.834 TPS（29.15×）；LIBERO-Goal 上 BL7 成功率 97.7%（−0.1）、BL35 97.2%（−0.6），平均 backbone 评估次数从 35 降至 5.14 / 1.73。
- **动作 bin 数

- **动作 bin 数**：16 / 32 / 64 三档对比显示，bin 数过少会因量化误差累积而损害精细操作精度，过多则显著扩大动作 token 块、增加去噪与反量化开销，却未带来成比例收益。作者据此在 Stage-2 按域选择活跃 bin 数（VLABench 采用 32），说明该超参与任务精度要求、控制频率、动作维度存在耦合。
- **解码配置**：Base（无块并行）保真度最高但吞吐最低；BL7 / BL35 在大幅提升吞吐的同时成功率损失控制在 1 个百分点以内，且平均 backbone 评估次数由 35 降至 5.14 / 1.73，表明"置信度提交 + 时间主序分块"能在保持动作序列时序连贯性的前提下压缩去噪迭代。
- **辅助损失尺度**：α 在 0.5 / 1.0 / 2.0 中取值，过小则期望 bin 的 MAE 约束不足以引导连续量回归，过大则与主交叉熵目标争夺梯度、损害离散 token 的分布拟合，中等取值较为稳健。
- **轨迹元数据条件化**：将 jerk 代理、轨迹步数、成功标记作为文本上下文注入，对整体成功率有正向但幅度有限的贡献，主要作用于长程任务与需要平滑动作的任务。

## 7. 局限性

- **传感器模态未落地**：虽然设计了本体感知 / 力-力矩 token 接口，但所有报告实验均未激活该通道，接触密集或力反馈敏感任务上的价值未获验证，该接口目前更多是架构上的"预留位"。
- **视觉预测保真度不足**：世界模型在 PSNR / SSIM 上虽为可学习方法中最佳，但仍大幅落后于"复制上一帧"这一平凡基线，说明模型对接触、遮挡、精细形变等关键区域的重建能力有限；这也解释了为何世界模型筛选带来的增益不如目标状态引导稳定。
- **目标状态生成弱于专用图像生成模型**：与 BAGEL 等对比，目标图像在细节与物理合理性上仍有差距，而目标引导又是默认推理路径的核心依赖，这一短板会间接限制该路径的上限。
- **测试时扩展的收益-成本矛盾**：目标引导 + 世界模型筛选取得最高 OOD 成绩，但吞吐相对仅动作解码下降约 48%，在当前硬件上难以直接用于高频闭环控制；如何在不牺牲鲁棒性的前提下削减候选评估成本尚未解决。
- **推理组合存在负迁移**：单独启用目标引导或单独启用联合去噪均劣于纯动作解码，说明各推理路径之间并非单调叠加，模型自身无法判断何时"多看一步"有益，缺乏自适应的路径选择机制。
- **基准区分度与覆盖度受限**：LIBERO 已接近饱和（多方法 97%+），难以区分方法差异；LIBERO-Plus 与 VLABench 仅覆盖有限扰动类型与两个任务，真实机器人实验也限于四类桌面操作，泛化结论的外推范围需谨慎。
- **算力披露不完整**：缺少 GPU 总量、训练总时长、Stage-2 各域开销等信息，复现成本难以估计，也不利于公平的效率比较。
- **对比公平性**：跨方法表格混合了引用数值与自复现数值，各方法训练配方、数据规模、评测协议并不完全一致，领先幅度需结合此背景解读。

## 8. 未来方向

- 激活并验证传感器 token 通道，探索力/触觉条件下的动作生成与接触密集操作。
- 提升视觉预测保真度（更高分辨率、专用视觉解码、几何/物理约束），使世界模型从"粗筛"升级为可靠的候选评估器。
- 学习自适应的推理路径与测试时计算分配策略，按任务不确定性动态决定是否启用目标引导、联合去噪或重排序，缓解负迁移与吞吐代价。
- 将统一轨迹建模扩展到更长时程、多阶段任务与多机器人本体，检验 token 空间与目标混合的可扩展性。
- 补充完整的算力与能耗报告，并推动评测协议与训练配方的统一，以提高跨方法比较的可信度。

## 9. 总体评价

- **核心贡献**：把"指令—观测—目标状态—动作"统一表述为同一类型化轨迹序列上的掩码重建任务，用一个共享参数的扩散骨干同时支撑策略、世界建模、目标预测与任务理解四类目标；其价值不仅在于性能数字，更在于给出了"多目标如何互为上下文、并在推理时按需组合"的可操作框架。
- **方法严谨性**：消融采用固定检查点、固定解码器的分离式设计，有效隔离了"训练收益"与"推理收益"；同时报告 ID 与 OOD 并显式讨论 gap，避免了只报单一指标的误导。
- **最有力的结论**：机器人领域持续预训练带来的跃升（3.26% → 49.61% ID）以及完整目标混合对指令偏移鲁棒性的改善（OOD gap 由 13.27 降至 2.33 个百分点），是本文最具说服力的证据，也印证了"预测目标可作为策略的正则与先验"这一假设。
- **待补强之处**：视觉预测质量、推理路径的自适应选择、传感器模态落地与算力透明度是四个最明显的缺口，它们决定了该框架能否从"实验室有效的统一建模"走向"工程可用的通用策略"。
- **定位**：本文属于"统一建模 + 测试时扩展"路线中较为系统的一支，与 UniVLA、UP-VLA、dVLA 等统一策略工作形成对话，其差异化在于显式引入世界模型/目标状态预测并与动作解码在同一 token 空间内耦合，而非把预测模型作为外挂模块。

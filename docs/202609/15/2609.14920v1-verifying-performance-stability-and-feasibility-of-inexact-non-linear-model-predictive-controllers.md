## 摘要
我们提出了一个验证框架，用于在受约束的非线性离散时间设定下对非精确模型预测控制器（MPC）进行数值分析。我们不是修改控制器以使保证通过构造成立，而是将控制器视为给定。特别地，我们关注两类非精确控制器：(a) 其输入取自满足非凸 MPC 问题的 Karush-Kuhn-Tucker (KKT) 条件的原始-对偶点；(b) 其输入通过线性化动力学并求解凸二次规划获得。我们的验证框架的主要思想是构造一个优化问题，该问题在给定集合内搜索最坏情况初始状态，并在与非精确控制器一致的控制输入上搜索，以最大化精心选择的性能指标。利用该框架，我们展示了如何认证：(i) 单个 MPC 问题的最坏情况下次优性间隙；(ii) 给定数量的动力系统迭代上的最坏情况闭环次优性间隙；(iii) 闭环稳定性；以及 (iv) 闭环系统的可行性。通过数值例子，我们展示了我们的框架精确量化两类次优性的能力，以及测试非精确控制器的稳定性和可行性的能力。

## Abstract
We introduce a verification framework to numerically analyze inexact model predictive controllers (MPCs) in the constrained non-linear discrete-time setting. Rather than modifying the controller so that guarantees hold by construction, we treat the controller as given. In particular, we focus on two types of inexact controllers: (a) one whose input is extracted from a primal-dual point satisfying the Karush-Kuhn-Tucker (KKT) conditions of the non-convex MPC problem, and (b) one whose input is obtained by linearizing the dynamics and solving a convex quadratic program. The main idea of our verification framework is to formulate an optimization problem that searches over the worst-case initial state within a given set and control inputs consistent with the inexact controller to maximize a carefully-chosen performance metric. Using this framework, we show how to certify (i) the worst-case suboptimality gap of a single MPC problem, (ii) the worst-case closed-loop suboptimality gap over a given number of dynamical system iterations, (iii) closed-loop stability, and (iv) feasibility of the closed-loop system. Through numerical examples, we showcase the ability of our framework to precisely quantify both types of suboptimality, and to test the stability and feasibility of the inexact controllers.

## 1. 核心问题与整体含义

- **研究背景**：模型预测控制（MPC）在每个时刻求解有限时域最优控制问题。对于非线性系统，该问题通常是非凸的，实时求解到全局最优往往不可行，因此实际中常采用“非精确控制器”，只返回次优解。
- **两类非精确控制器**：
  - **KKT 满足型 MPC**：输入来自满足非凸 MPC 问题 KKT 条件的原始-对偶点。
  - **线性化 MPC**：在当前状态附近线性化动力学，求解一个凸二次规划（QP）。
- **核心问题**：现有保证要么假设每次 MPC 都求解到全局最优，要么通过终端约束、惩罚项、限制问题类别或操作条件来“按构造”保证稳定性/可行性。缺少一种方法，能够把非精确控制器当作给定对象，直接验证其最坏情况性能、稳定性和可行性。
- **整体含义**：论文提出一个基于优化的离线验证框架，将控制器编码为约束，搜索最坏初始状态和与控制器一致的控制输入，从而给出计算机辅助证明。该框架可认证单步与闭环次优性、闭环指数稳定性以及可行性不变性。

## 2. 方法论

- **核心思想**：
  - 把“验证”转化为一个最坏情况优化问题：在给定初始状态集合 \(X_0\) 中搜索初始状态，并在所有与非精确控制器一致的轨迹/输入中，最大化某个精心选择的性能指标。
  - 控制器不被修改，而是作为约束嵌入验证问题中。
  - 验证问题离线求解，时间不敏感；所得保证在控制器在线实时运行时仍然成立。

- **非精确控制器的约束编码**：
  - **KKT 控制器**：轨迹 \(z_k \in S_T^{kkt}(x_k)\)，通过非凸 MPC 问题的 KKT 条件编码，包括平稳性、原始可行性、对偶可行性和互补性。
  - **线性化 MPC 控制器**：轨迹 \(z_k \in S_T^{lin}(x_k,\bar u_k)\)，通过线性化动力学后凸 QP 的 KKT 条件编码；线性化点可为上一控制输入或零控制。

- **单问题次优性验证**：
  - 自然验证问题最大化 \(J_T(z^{kkt}_0)-J_T(z^\star_0)\)，其中 \(z^\star_0\) 是全局最优解。
  - 由于全局最优约束不可直接处理，论文证明：将 \(z^\star_0\) 放松为任意可行轨迹 \(z^{feas}_0\) 后，验证问题的最优值不变，即该放松是紧的。
  - 若验证最优值为 0，则可证明所有 KKT 点都是全局最优。

- **闭环次优性验证**：
  - 比较非精确控制器在 \(K\) 步闭环中累积的成本与最优闭环成本。
  - 类似地，将最优 benchmark 放松为“仅可行”的轨迹，并证明放松是紧的。
  - 若验证值为 0，则非精确策略在给定 \(K\) 步和初始集合上闭环最优。

- **稳定性验证**：
  - 定义“到原点邻域的指数稳定性”。
  - 使用 Lyapunov 候选 \(V(x)=J_T(z)+x^TQx\)，其中 \(z\in S_T^\pi(x,0)\)。
  - 先求初始集合上的最大 Lyapunov 值 \(\bar V(X_0)\)，构造子水平集 \(\Omega\)。
  - 再搜索是否存在状态使 \(V_1\ge \rho V_0\) 且 \(V_1\ge \epsilon\)。若该违反问题不可行，则 \(\Omega\) 前向不变，Lyapunov 值按速率 \(\rho\) 收缩，系统指数稳定到半径 \(\sqrt{\epsilon/\lambda_{\min}(Q)}\) 的球。
  - 通过二分搜索寻找最紧可认证收敛率 \(\rho^\star\)。

- **可行性验证**：
  - 针对线性化 MPC，定义“可行性不变性”：线性化 QP 在 \(X\) 中每一点可行，且真实闭环后继仍留在 \(X\)。
  - 第一步用 Farkas 引理构造可行性检测问题：若最优值为 0，则线性化问题在 \(X\) 上处处可行；若为 1，则存在不可行状态。
  - 第二步对状态约束 \(X\) 的每个面求解后继越界验证问题，检查真实后继 \(x_1=f(x_0,\kappa(z_0))\) 是否满足约束。
  - 若两个条件均满足，则 \(X\) 可行性不变，所有时刻子问题可行。该性质强于经典递归可行性，因为后者只说明“一旦可行则继续可行”，不保证初始可行。

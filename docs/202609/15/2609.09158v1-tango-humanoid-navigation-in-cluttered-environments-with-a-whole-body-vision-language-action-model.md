## 摘要
我们研究人形机器人在杂乱室内环境中的导航问题。与将导航建模为二维路径规划问题的传统方法不同，人形机器人在杂乱环境中的穿行需要连续的几何感知全身适应，包括协调手臂摆放、躯干调整和步态调节，以在复杂三维空间中实现无碰撞移动。我们提出 TANGO，这是首个面向杂乱环境中语言条件下人形机器人穿行的全身视觉-语言导航框架。给定自然语言指令和第一视角 RGB 观测，TANGO 直接预测 29 自由度关节空间动作，用于下游全身控制。我们完全在仿真中训练 TANGO，通过全局路径规划、运动学全身运动生成、障碍物感知运动编辑和基于强化学习的跟踪来合成多样化的无碰撞穿行行为。该流程为学习语言条件下的全身策略提供了动态可行的动作监督。在大量仿真实验中，TANGO 在视觉-语言导航中展现出最先进的性能，同时在需要越障的挑战性场景导航中优于强大的模块化基线。最后，我们将 TANGO 零样本部署到 Unitree G1 人形机器人上，并在杂乱的真实世界场景中观察到稳健的语言引导穿行，且未在任何真实世界导航数据上训练。

## Abstract
We study the problem of navigating cluttered indoor environments with a humanoid robot. Unlike conventional methods that model navigation as a 2D path planning problem, humanoid traversal in cluttered environments requires continuous geometry-aware whole-body adaptation, including coordinated arm placement, torso adjustment, and gait modulation for collision-free movement through complex 3D spaces. We introduce TANGO, the first whole-body vision-language navigation framework for language-conditioned humanoid traversal in cluttered environments. Given a natural-language instruction and egocentric RGB observations, TANGO directly predicts 29-DoF joint-space actions for downstream whole-body control. We train TANGO entirely in simulation by synthesizing diverse collision-free traversal behaviors via global path planning, kinematic whole-body motion generation, obstacle-aware motion editing, and RL-based tracking. This pipeline provides dynamically feasible action supervision for learning language-conditioned whole-body policies. In extensive simulation experiments, TANGO demonstrates state-of-the-art performance in vision-language navigation, while outperforming strong modular baselines in navigating challenging scenes requiring obstacle negotiation. Lastly, we deploy TANGO zero-shot on a Unitree G1 humanoid robot, and observe robust language-guided traversal in cluttered real-world scenes without training on any real-world navigation data.

# TANGO 论文总结

## 1. 核心问题与研究动机

- **问题定位**：人形机器人在杂乱室内环境中的语言引导导航（Vision-Language Navigation, VLN）。
- **背景痛点**：
  - 传统 VLN 将导航建模为**二维路径规划/离散高层决策**，动作空间是 2D 航点或离散动作，无法表达导航决策与全身可行性之间的关系。
  - 人形机器人身体几何在运动过程中持续变化，**通过性（traversability）不仅取决于路径，还取决于手臂、躯干、腿能否无碰撞地穿过三维场景几何**——即"规划层可行的动作，对具身本体可能不可执行"。
  - 已有工作割裂：人形基础模型/全身 VLA（GR00T-N1.6、Ψ0、WholeBodyVLA 等）多采用解耦设计，导航以高层运动指令下发；RL 避障穿越（如 HumanoidPF）依赖任务先验，难以扩展到长时程、语言引导、多样杂乱场景。
- **核心主张**：需要一个统一框架，**同时推理导航意图与全身通过性**，直接输出可执行的全身关节动作。

## 2. 方法论

### 2.1 问题形式化

- 输入：自然语言指令 ℓ、当前观测 o_t（前视 + 下视 RGB 时序 I_{1:t}^{fr,dn}）与全身关节本体感知状态 q_t。
- 输出：长度为 H 的全身动作块 A_t = {a_1,…,a_H}，其中 a_i = {q_{d,i}, r_{b,i}}，q_d ∈ ℝ²⁹（29 自由度关节角），r_b ∈ ℝ⁶（基座 6D 旋转）。
- 预测动作块流式送入低层运动跟踪器执行。

### 2.2 仿真数据生成（PET 流水线：Plan–Edit–Track）

- **环境增强**：基于 VLNVerse（263 场景）与 SAGE-3D（1000 场景），用 Gemini 2.5 Flash 过滤后保留 205 + 373 = 578 个源场景；按轨迹条件插入三类障碍：
  - **侧向障碍（sidle，15%）**→ 构造窄通道；
  - **地面障碍（stride，44%）**→ 需跨越；
  - **头顶障碍（squat，41%）**→ 需低头/下蹲。
  - 障碍沿 A* 轨迹采样、对齐局部路径方向、语义模板匹配，并写回占据地图保证规划器与策略几何一致。
- **Plan（规划与参考步态合成）**：
  - 在 2D 占据栅格上用 A*，步代价加入障碍感知项 c(x) = c_step + λ·exp(−Φ_2D(x)/d_0)，偏向远离障碍的安全路径；
  - 规则式偏航重写器检测窄通道，将躯干朝向改为与行进切线成 ±90°，产生**横移/蟹行步态**；
  - 将改写后的轨迹转为速度指令 (v_x, v_y, ω) 输入 SONIC 运动规划器（基于约 800 小时动捕训练），PD 控制器修正漂移，得到自然参考步态 M_ref。
- **Edit（全身避障编辑）**：
  - 场景体素占据转为 3D SDF Φ(p)（快速行进法），细杆件用解析 OBB SDF；编辑限制在路径周围半宽约 0.5 m 的走廊管内；
  - 引导场 g(p) = τ̂(p) + β·exp(−Φ̃(p)/σ)·∇Φ̃/‖∇Φ̃‖，经 SoftMimic 风格伪力 Δp_ℓ = clip(f_ℓ/κ, δ_max) 以软约束形式加入全身 IK（作用肩、肘、腕、躯干、膝、骨盆等，脚踝排除以保留接触模式）；
  - **蹲伏控制器**：仅保留竖直分量，加入"前瞻项"（提前探测头/肩高度几何）与"虚拟头部屏障"（软+硬屏障力），并将下蹲激活量 α 耦合到腰部俯仰、髋俯仰偏置与 CoM 下移；支持 waist-only / com-drop / full-squat 三种预设；
  - **步态适配模块**：落脚点重定向（越过障碍远端加余量 d_land = d_far + m），按高度分类障碍（仅 z_top ≤ z_bar 视为可跨越，更高的当作墙/天花板）；摆动轨迹 p_swing(u) = p_ref(u) + (1−ū)Δp_lift + ūΔp_land + h_arc·ρ(u)·ẑ，采用非对称净空剖面（快升慢降）并求解 h_arc 保证足部足迹全程高于障碍；
  - 加入 root/CoM 重定向偏移（EMA 平滑）修正支撑多边形前移导致的身体"原地前倾"问题；
  - 每帧两遍求解：先下肢投影（匹配足部/支撑/CoM），再全身柔性 IK（跟踪编辑后参考 + 施加势场力）。
- **Track（可行性恢复与碰撞过滤）**：编辑后轨迹经 SONIC 跟踪器在 MuJoCo 闭环跟踪，验证动态可行性与无碰撞，失败/碰撞轨迹丢弃。**关键设计**：以规划+编辑阶段的"无碰撞参考运动"而非跟踪结果作为监督信号，既保持拟人结构又保证可执行性。
- **数据规模**：共 64,633 条轨迹；PET 86 GPU 时 + 渲染 125 GPU 时 = 211 RTX PRO 6000 GPU 时。

### 2.3 三系统架构

- **System-2（视觉语言感知）**：Qwen2.5VL-7B，用 InternVLA-N1 权重热启动以继承导航先验；前后视图像垂直堆叠为单帧；长时程历史用 **BATS（Budget-Aware Token Sampling）** 按 P(t) = (1−ε)e^{k(t−T)/T} + ε 采样，并对视觉特征做空间网格池化（近期细网格、历史粗网格）；输出潜变量 z = VLM(ṽ_sampled, ℓ)。
- **System-1（动作专家）**：基于 **流匹配的 MM-DiT**，条件于 z 与本体感知 q_{d,t}，预测动作块。采用**稳定化训练目标** ã_i = {q_{d,i}, r̃_{b,i}, Δx_i, Δy_i, Δψ_i}（基座偏航相对块首帧，辅助位移/航向增量显式编码块级平面运动）。引入 **训练时 RTC（real-time chunking）**：以随机化的已提交前缀 d 个动作做条件、修补剩余时域，对齐离线训练与在线流式执行。
- **System-0（执行）**：现成 SONIC 跟踪器，200 Hz 闭环。
- **联合训练目标**：L = L_CE + w_FM·L_FM，w_FM = 20；System-2 附加文本解码分支，与 VideoQA 样本共同微调以保留通用世界知识；单 epoch 端到端训练，学习率 1×10⁻⁵。
- **训练细节**：数据层面重平衡（上采样大转角、横移、下蹲、跨步、蹲跨混合，跨步与横移权重最高），并对动作向量施加行为条件化的逐维损失权重（下蹲→髋/脊柱/膝，跨步→脊柱/肩，横移→肩+体坐标系运动维度）。

### 2.4 部署

- **仿真**：MuJoCo 跑低层跟踪器与物理仿真，IsaacSim 中"数字孪生传送"按正运动学求解相机位姿渲染照片级观测供 VLA 输入。
- **真机（Unitree G1）**：云-边架构，VLA（system-2/1）跑在 RTX PRO 6000 服务器，SONIC（system-0）跑在机载 Jetson Orin NX，标准 IP 网络连接；RealSense D455 + D435i 采集前视/下视 RGB，约 20 ms 延迟；服务器每 0.5 s 推理一次，对应 15 个 30 Hz 动作，回传后重采样至 50 Hz 执行，低层约 200 Hz；配套网页控制面板。

## 3. 实验设计

### 3.1 数据集与 Benchmark

- **VLNVerse**：IsaacSim 中照片级真实感室内场景的 VLN benchmark（VLNVerse-seen 423 条、VLNVerse-unseen 825 条评测轨迹；VLNVerse-train 3963 条）。
- **增强版 VLNVerse-unseen**：加入 stride/sidle/squat 三类障碍，用于杂乱环境穿越评测。

- **真实世界**：Unitree G1，三类场景设置（短时程 2D 约 10 m 一次转弯；长时程 2D 约 30 m 两三次转弯；杂乱 3D 含一个挑战性障碍），每类 3 个场景 × 5 次试验 = 15 次/方法/设置。

### 3.2 对比方法

- **VLN benchmark**：CMA、Seq2Seq（离散动作）、RDP（连续动作）、HNR（神经隐式表示）、InternVLA-N1、Uni-NaVid（SOTA VLA）。除 TANGO 外均在 teleportation 设置下评测（无低层控制）。

- SR、SPL、NE、OSR（标准 VLN 指标，成功阈值 δ = 3 m）；杂乱场景额外报告 **CR（Collision Rate，回合级是否至少一次碰撞）**；真机额外报告每回合平均碰撞次数。

## 6. 主要结论与发现

- TANGO 是首个**直接预测 29 自由度关节空间动作**的全身视觉-语言导航框架。
- **VLNVerse**：SR 与 NE 最优（seen SR 54.69 / NE 3.90；unseen SR 52.89 / NE 3.72），SPL/OSR 与 SOTA RDP 相当；SPL 相对偏低，归因于低层跟踪器偏保守、倾向安全但绕远的路径。
- **杂乱环境**：SR 43.75、SPL 31.83、CR 9.90%，全面优于最强基线（InternVLA-N1 + HumanoidPF：SR 41.88、SPL 29.49、CR 15.81），CR 从 15.81% 降至 9.90%，且仅用 RGB。
- **真机零样本**：三类设置下 SR 均最高（12/15、8/15、10/15 vs 基线 11/15、6/15、6/15），平均碰撞更少，验证无需任何真实导航数据的 sim-to-real 迁移。
- **消融**：RTC 最关键（去除后 SR 从 43.75% 跌至 10.94%，CR 升至 14.60%）；去除运动编辑使 SR 降至 36.25%、CR 升至 20.60%；替换 SONIC 为 ScaleBFM 三项指标均在 3 个点内，说明对低层跟踪器具有兼容性；Ours-2D 显著弱于 TANGO，且平面策略从 teleportation 切换到物理执行时性能大幅下降。

## 7. 优点

- **问题建模新颖**：将人形导航从"2D 路径规划"提升为"全身通过性联合推理"，直接输出 29-DoF 关节动作，避免导航与控制的模块割裂。
- **数据合成流水线可扩展**：PET 用自动化的规划—编辑—跟踪生成 64,633 条无碰撞全身轨迹，成本可控（211 GPU 时），且**以参考运动而非跟踪结果作监督**，兼顾拟人质量与物理可执行性；用 Gemini 2.5 Flash 自动生成指令与障碍语义增强。
- **架构设计合理**：三系统分工（VLM 感知 / 流匹配动作专家 / 通用跟踪器）解耦清晰，训练时 RTC 对齐离线训练与在线流式

执行，减少推理—执行不一致带来的抖动与性能衰减。
- **部署方案务实**：云—边分离（服务器跑 VLA、机载 Jetson 跑跟踪器），30 Hz 动作块回传后重采样至 50 Hz、低层 200 Hz 闭环，配合网页控制面板，工程链路完整，具备可复现的实机落地路径。
- **真机零样本迁移**：不使用任何真实导航数据即完成 sim-to-real，且在长时程与杂乱 3D 场景上的优势比短时程更明显，说明性能提升并非仅来自过拟合到某一类简单场景。
- **对比条件对自身不利仍取得优势**：在杂乱环境评测中仅用 RGB，而基线额外使用 LiDAR；VLN benchmark 上基线享有 teleportation 便利而 TANGO 受物理约束，作者对此做了显式说明，结论的可信度因此相对更高。

## 8. 局限与不足

- **对低层跟踪器的隐性依赖**：System-0 直接复用现成 SONIC，且训练监督信号来自"编辑后参考运动"。虽然替换为 ScaleBFM 后三项指标波动在 3 个点内，但该验证仅覆盖单一替代跟踪器，尚未证明框架对任意形态/任意人形本体的普适性；若目标机器人自由度配置或质量分布差异较大，数据生成阶段的 PD 修正与 IK 软约束参数需重新标定。
- **训练—推理异步带来的时序误差**：论文以训练时 RTC 缓解该问题，但部署中 0.5 s 推理一次、动作块经网络回传后重采样执行，仍存在约 20 ms 感知延迟与端到端时延累积，高速运动或突发障碍下的反应能力未做定量刻画。
- **评测覆盖面的偏斜**：增强版 VLNVerse-unseen 的障碍分布高度不均（stride 44%、squat 41%、sidle 仅 15%），横移/蟹行这一最能体现全身通过性优势的能力，其样本量最少，结论中"横移权重最高"的重平衡策略与其评测占比之间存在错配。
- **SPL 指标系统性偏低**：作者归因于跟踪器保守、倾向安全绕远路径，但这也意味着框架在"效率"维度上尚未真正解决，长时程任务中的累计能耗与时间开销可能成为实用瓶颈。
- **消融粒度较粗**：仅提供整体去除 motion editing 的结果，未拆分蹲伏控制器、步态适配、CoM 重定向各自的贡献；蹲伏控制器内部又包含前瞻项、虚拟头部屏障、α 耦合等多项启发式设计，其必要性缺乏受控验证。
- **仿真数据生成的监督信号来源单一**：全部轨迹由 A* + 规则式偏航重写 + SONIC 规划生成，策略的学习上限受限于该参考运动分布；对于 A* 无法规划出可行路径、或需要非结构化身体—环境交互（如推开门、攀爬、贴墙挤过）的情形，流水线未覆盖。
- **缺少安全性与失败模式分析**：报告了 CR（回合级是否碰撞）与平均碰撞次数，但未区分碰撞类型、未分析失败案例的分布（感知错误 / 规划错误 / 执行错误），对系统调试与后续改进的指导价值有限。

## 9. 可改进方向与启示

- **补足消融与统计**：对 PET 三阶段（Plan / Edit / Track）逐项消融，对蹲伏控制器各启发式项做留一验证；真机扩大试验次数并报告方差或置信区间。
- **语言—行为耦合的受控实验**：作者提到"在指令中加入避障提示"是经验观察，可将其设计为受控变量（有/无避障提示 × 有/无运动编辑），量化语言对全身行为选择的因果影响。
- **Scaling 研究**：当前 64,633 条轨迹、211 GPU 时，成本相对可控，适合进一步研究数据规模、场景多样性、障碍类型覆盖与最终 SR/CR 的关系曲线。
- **把跟踪器纳入联合优化**：目前 System-0 冻结，若允许以可微或在线适应方式微调跟踪器，或让动作专家显式建模跟踪误差分布，有望缓解 SPL 偏低与保守绕远问题。
- **面向效率的奖励/目标设计**：在损失中加入路径长度或能耗项，配合行为条件化权重，可在保持 CR 优势的同时改善 SPL。
- **方法论上的可迁移性**："以无碰撞参考运动而非跟踪结果作监督"这一设计，对其他人形全身操作、移动操作（mobile manipulation）任务同样具有参考价值，值得作为独立贡献被更广泛验证。

## 10. 总体评价

TANGO 的核心贡献不在于单点指标刷新，而在于**问题重构**：把人形 VLN 从"2D 路径上的高层决策"改写为"语言条件下的 29-DoF 全身动作生成"，并用一条可扩展的自动化流水线（PET：Plan–Edit–Track）解决了这一新问题所面临的数据稀缺瓶颈。其"参考运动作监督、跟踪结果仅作过滤"的数据构造哲学，以及在 VLM 与执行器之间插入流匹配动作专家并配以训练时 RTC 的架构选择，都是可复用的工程范式。

从证据强度看，论文的实验设计整体扎实：覆盖 benchmark、杂乱环境、真机三类评测，消融抓住了 RTC 与运动编辑两个关键组件，资源披露明确（211 GPU 时数据生成 + 896 A100 GPU 时训练），结论方向与消融结果自洽。主要短板集中在评测的统计粒度（真机样本小、无方差）、消融的细粒度（未拆分 PET 各阶段与蹲伏控制器各项）、以及效率维度（SPL 偏低）尚未真正解决上。

综合判断：这是一篇在**问题定义与数据合成方法论**上贡献突出、在**系统集成与实机验证**上完成度较高的工作；其结论在其设定范围内成立且可信，但"全身通过性推理"这一能力在更极端、更异构、更需交互的场景中的边界，仍留待后续工作刻画。

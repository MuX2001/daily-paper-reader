## 摘要
将模仿学习策略应用于新的操作任务通常需要收集新的演示并重新训练模型，这使得样本效率成为一个实际关注点。在大规模机器人数据集上进行预训练在这方面是有效的，但此类数据集的收集和训练成本高昂，而数据增强技术通常需要为每个任务重新进行一轮数据生成和训练。一个补充性问题是：在收集任何任务特定数据之前，能够以可忽略的成本为策略提供哪些有用的先验。在本研究中，我们构建了一个几何视觉预训练数据集，其中每个场景仅包含一个平面、一个物体和一只手，并且轨迹是自动生成的。场景既没有纹理也没有背景；预训练主要让策略接触手与物体之间的几何关系。此外，将手表示为立方体避免了使数据集局限于特定机器人形态。我们使用 ACT 在三个仿真机器人上评估该几何先验，每个机器人涵盖五个操作任务，并在三个真实世界机器人任务上进行评估。在许多这些机器人--任务组合中，从几何先验进行微调在训练早期阶段取得的成功率高于从头训练，同时仅使用少量任务演示。这些结果表明，当任务数据有限时，即使高度简化的几何场景也能提供有用的初始化，并可跨机器人迁移到真实世界任务。

## Abstract
Applying an imitation learning policy to a new manipulation task usually requires collecting new demonstrations and retraining the model, which makes sample efficiency a practical concern. Pretraining on large-scale robot datasets is effective in this respect, but such datasets are costly to collect and train on, while data augmentation techniques typically require a new round of data generation and retraining for each task. A complementary question is what useful prior can be provided to a policy at negligible cost before any task-specific data are collected. In this study, we construct a geometric visual pretraining dataset in which each scene contains only a plane, an object, and a hand, and trajectories are generated automatically. The scenes contain neither textures nor backgrounds; pretraining primarily exposes the policy to the geometric relationship between the hand and the object. Furthermore, representing the hand as a cube avoids tailoring the dataset to a specific robot morphology. We evaluate this geometric prior using ACT on three simulated robots across five manipulation tasks each, as well as on three real-world robot tasks. Across many of these robot--task combinations, fine-tuning from the geometric prior achieves higher success rates in the early stages of training than training from scratch while using only a small number of task demonstrations. These results suggest that even highly simplified geometric scenes can provide a useful initialization that transfers across robots and to real-world tasks when task data are limited.

## 2. 方法论

- **核心思想**：
  - 构建纯几何、无纹理、无背景、无物理的合成场景：一个地板平面、一个物体、一个手。
  - 自动生成三类基本动作：pick、place、push。
  - 将手抽象为立方体，避免绑定特定机器人形态。
  - 先用合成数据预训练，再用少量任务特定示教微调。

- **场景构建**：
  - 场景完全由点云构成。
  - 物体为简单几何基元：棱柱、棱锥、圆柱、圆锥、球体及截断变体；尺寸、比例、底面正多边形轻微扰动，部分球体拉伸为椭球。
  - 地板尺寸、高度、网格分辨率带随机性；物体随机放置。
  - 手随机放置于平面上方，初始朝向指向物体附近，使物体出现在手眼相机中。

- **数据表示与生成**：
  - 每个时间步记录：手部位姿、手眼相机图像、第三人称相机图像。
  - 手部位姿统一为 8 维向量：\((x,y,z,q,\text{gripper})\)，其中 \(q\in\mathbb{R}^4\) 为四元数，gripper 为 0/1。
  - 每条示教长度 \(N=\text{fps}\times T\)；实验设 fps=30、T=10 秒，因此每条 300 步。
  - 图像由点云投影生成，黑底白点，点足迹 2×2 像素。
  - 手眼视角：包含地板、物体、place/push 中的 marker，不渲染手本身。
  - 第三人称视角：随机位于平面上方，朝向物体和手立方体中点，包含地板、物体、marker 和手立方体。

- **动作轨迹生成**：
  - **Pick**：
    - 从初始位姿 \(T_0\) 移动到抓取位姿 \(T_{\text{pick}}\)。
    - 抓取位姿基于物体包围盒启发式：选择较窄边、较近面、中心稍外偏移，手的前向指向物体中心。
    - 位置线性插值；前向方向用 SLERP 插值；右、上方向每步重正交化。
    - gripper 最后一步设为 1，其余为 0。
  - **Place**：
    - 先复现 pick，再用“marker”定义目标位置和朝向。
    - marker 由物体点云随机旋转 \(R_{\text{rand}}\) 后从俯视图投影到平面得到。
    - 保持手与物体相对偏移 \(\Delta p = p_{\text{pick}} - c_{\text{obj}}\)。
    - 目标位置 \(p_{\text{place}} = \tilde{c}_{\text{mark}} + R_{\text{rand}}\Delta p\)，目标朝向 \(R_{\text{place}} = R_{\text{rand}}R_{\text{pick}}\)。
    - 位置用 Bézier 曲线模拟抬升/下降，朝向用 SLERP。
    - gripper 在接近时 0、运输时 1、放置后 0。
  - **Push**：
    - marker 仅平移，不旋转。
    - 推动方向 \(v_{\text{push}} = \mathrm{Proj}_{xy}(c_{\text{mark}} - c_{\text{obj}})\)。
    - 接触前位姿 \(p_{\text{start}} = c_{\text{obj}} - d v_{\text{push}}\)，前向轴为 \(v_{\text{push}}\)，上轴为世界垂直方向。
    - 推动结束位姿 \(p_{\text{push}} = \tilde{c}_{\text{mark}} - d v_{\text{push}}\)，保持手与物体相对位姿。
    - gripper 全程为 0。

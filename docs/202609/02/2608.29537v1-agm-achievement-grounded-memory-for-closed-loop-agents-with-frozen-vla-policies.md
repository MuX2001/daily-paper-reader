## 摘要
冻结的视觉-语言-动作（VLA）策略提供了广泛的操控技能，但执行开环动作块时不跟踪任务进度，因此智能体无法可靠地决定是继续、重试还是终止。外部记忆是一种自然的补救措施，但当尝试的动作被视为已完成的进度时，外部记忆可能有害，将局部执行错误转变为持久的任务状态错误。我们提出了成就基础记忆（AGM），一种针对冻结VLA策略的轻量级闭环框架，该框架将任务表示为带有进度指针的子目标序列，并且仅在当前子目标通过物理证据验证后才推进此记忆。本体感觉交互线索决定何时验证，而来自冻结基础模型并通过单个2.43M参数验证头获得的连贯点跟踪和语言条件跨视图比较决定实现了什么。因此，AGM将开环执行转变为执行、验证和进度的闭环，保持策略冻结且无需测试时大模型推理。在RoboMME Counting基准上，AGM在PickXTimes上达到...在BinFill上达到...，平均超过最强的记忆增强基线...点，该框架在物理机器人上也产生了同样显著的收益。因此，可靠的具体化记忆更多依赖于纪律性的状态更新，而非记忆容量。

## Abstract
Frozen vision-language-action (VLA) policies offer broad manipulation skills but execute open-loop action chunks without tracking task progress, so the agent cannot reliably decide whether to continue, retry, or terminate. External memory is a natural remedy, yet it can be harmful when attempted actions are treated as completed progress, turning local execution errors into persistent task-state errors. We propose Achievement-Grounded Memory (AGM), a lightweight closed-loop framework for frozen VLA policies that represents a task as a subgoal sequence with a progress pointer and advances this memory only after the current subgoal is verified by physical evidence. Proprioceptive interaction cues decide when to verify, while coherent point tracking and language-conditioned cross-view comparison, sourced from frozen foundation models through a single 2.43M-parameter verification head, decide what was achieved. AGM thereby converts open-loop execution into a closed loop of execution, verification, and progress, keeping the policy frozen without test-time large-model inference. On the RoboMME Counting benchmark, AGM reaches on PickXTimes and on BinFill, surpassing the strongest memory-augmented baseline by points on average, and the framework yields equally decisive gains on a physical robot. Reliable embodied memory thus depends more on disciplined state updates than on memory capacity.

## 一、核心问题与整体含义（研究动机和背景）

移动操作领域广泛采用**视觉-语言-动作（VLA）模型**：从观测和指令直接映射到连续动作。但一个实用且重要的设定是**冻结预训练 VLA 策略**——不微调整个模型，而是通过语言条件化子目标来组合技能（如 SayCan、Inner Monologue 等路线）。论文指出，该范式有一个根本缺陷：

- VLA 策略执行的是**开环动作块（action chunk）**，它不显式跟踪任务进度；
- 在重复性/计数量操作（如 PickXTimes、BinFill）中，不同阶段**在视觉上高度混叠（perceptually aliased）**，仅凭当前图像无法判断“这是第几次放置/抓取”；
- 因此策略无法自主决定：继续执行、重试、回退还是终止。

直觉的解决方法是给策略配**外部记忆**。但作者发现一个反直觉的现象：**若外部记忆把“每次尝试动作”都当作“已完成的进度”写入，那么单次执行的瞬态失败会变成持久的任务状态错误**，甚至比完全无进度记忆的策略表现更差。

**核心含义**：本文把问题从“该记住什么 / 记多少”转移到 **“什么时候才允许写入”**。可靠的具体化记忆（embodied memory）并不主要依赖存储容量或模型规模，而更依赖**有纪律的状态更新纪律（disciplined state updates）**。

## 二、论文提出的方法论

### 2.1 总体框架：任务分解 + 进度指针 + 验证门控

AGM 维持一个小型任务记忆：

- 指令被确定性地展开为**有序的带类型子目标序列**：
  - G = {(gk, ck)}, k = 1…T
  - ck ∈ {grasp（抓取）, place-rev（可回退放置，如平面目标）, place-irrev（不可逆放置，如入容器）, other（其他，如按钮）}
- 任务记忆 Mt = (G, pt)，其中 pt 是唯一的在线进度指针；
- 冻结策略读入 `g_pt` 作为语言条件，产出动作块。

### 2.2 事件触发：抓取器负载状态机

“何时验证”由本体感受驱动。基于夹爪开度 wt 的**滞回有限状态机**输出事件 et ∈ {∅, G+, R+, R0}：

- G+：稳定抓取成功（带负载闭合）；
- R+：从带负载状态释放；
- R0：空手释放。

只有**与当前子目标类型兼容**的事件才触发验证：grasp 子目标只响应 G+，placement 子目标只响应 R+。这一层明确区分“发生了交互”与“达成了成就”。

### 2.3 抓取验证：*Coherent-Motion Grasp Verification*

抓取是否成功本质上是一个运动学问题：对象是否随夹爪一致上升。

- 使用 6×6 查询网格投影到前视图（由端末执行器相机外参+内参定位）；
- 当 G+ 发生后，累积回升片段，直至末端抬升超过 0.03 m；
- 用**冻结的 CoTracker3** 输出轨迹和可见性分数；
- 只保留可见分数 ≥0.5 的轨迹，取纵向位移最大 1/3 点集的中位数作为响应 rG_n；
- **判定条件**：rG_n ≥ δG(4 px)，即物体确实随夹爪向上移动。

### 2.4 放置验证：语言条件化的跨观察证据

放置是否成功是语义问题：物体是否到达了指定对象–目标关系位置。

- 收集放置事件前后的多帧聚合图像（front + wrist 双相机）；
- 查询归一化后的子目标语言 qk（去除重复次数信息）；
- 用**冻结的 SigLIP** 编码生成嵌入：前/后、腕部、差值、本体感受归一化窗口以及文本；
- 拼接成特征 fn 送给一个轻量 MLP **验证头 hψ**（2.43M 参数）输出放置达成的概率 sP_n：
  - **可恢复平面放置**：接受阈值 κ=0.5（更严格，因为失败可以重抓）；
  - **不可逆容器放置**：接受阈值 κ=0.05（更宽松，因为误报会导致多放物体并破坏计数）。

### 2.5 记忆更新规则

以 bvn 为二元验证结果，旧指针为 p⁻，新指针为 p⁺。规则如下：

p⁺ =
- `p⁻ + 1`（推进）：验证成功；
- `B(p⁻)`（回退到该次重复的抓取子目标）：验证失败且该子目标可回退（如平面放置）；
- `p⁻`（保留）：其他情况（如失败抓取保持原状）。

另有保障机制（不死锁）：

- **拒绝次数上限**：可恢复放置 2 次 / 不可逆放量和抓取 3 次。若持续验证失败则强制推进；
- **Stuck timeout**：负载持续但 80 个控制步内未探测到有效回升，则清除待处理状态；
- **终止前检查**：在触发终局按钮前，用视觉占用度测试重新检查最近一次不可恢复（原文为 recoverable planar）放置，失败则回退到对应抓取子目标。

### 2.6 训练

- 唯一可训练组件是 2.43M 验证头（三层 MLP），特征编码层全部冻结；
- 在官方 RoboMME 训练 split 收集 788 个执行事件（包含 AGM 自身的 trace 及基于尝试的控制器作为互补，以覆盖失败案例与错序案例）；
- 标签来自环境谓词（仅离线可用）；
- 类别加权交叉熵训练；与部署时间点严格对齐的 post-release 窗口采样（模拟 30/40 帧偏移；相差 20 帧即显著退化，BinFill 从 84~86% 降到 66%）。

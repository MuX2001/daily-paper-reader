## 摘要
尽管在大规模机器人数据集上预训练的视觉-语言-动作（VLA）模型为机器人操作提供了强大基础，但在将其适应到具有有限任务特定演示的新任务时，其性能可能会下降。检索提供了一种重用现有演示以实现数据高效适应的实用方法，但现有方法通常依赖视觉相似性、状态-动作表示或任务级语言匹配。这些方法可能忽视长时程操作任务的分层结构，其中完整的任务匹配很少见，而可重用的技能往往丰富多样。为应对这一挑战，我们提出分层技能检索（HSR），一种用于数据高效VLA适应的检索框架。具体来说，HSR首先将目标任务分解为候选技能序列。它基于语义合理性和从先前数据集估计的技能可靠性来评估每个规划。然后使用选定的分解进行混合检索。这将子任务级语言检索与行为特征重排序相结合，以识别在语义上相关且与目标任务兼容的演示。最后，我们通过两阶段预训练和微调流程来调整策略，该流程将通用技能获取与任务特定适应分开。在LIBERO基准测试和几个真实世界机器人操作任务上的实验表明，与最强基线相比，HSR分别将平均成功率提高了10.3%和21.3%。这些结果证明了结构化技能级检索对数据高效VLA适应的有效性。视频和代码可在https://hoar012.github.io/HSR-Project获取。

## Abstract
While Vision-Language-Action (VLA) models pretrained on large-scale robot datasets provide a strong foundation for robot manipulation, their performance can degrade when adapted to new tasks with limited task-specific demonstrations. Retrieval offers a practical way to reuse existing demonstrations for data-efficient adaptation, but existing methods often rely on visual similarity, state-action representations, or task-level language matching. These approaches may overlook the hierarchical structure of long-horizon manipulation tasks, where complete task matches are rare but reusable skills are often abundant. To address this challenge, we propose Hierarchical Skill Retrieval (HSR), a retrieval framework for data-efficient VLA adaptation. Specifically, HSR first decomposes a target task into candidate skill sequences. It evaluates each plan based on both semantic plausibility and skill reliability estimated from the prior dataset. The selected decomposition is then used for hybrid retrieval. This combines subtask-level language retrieval with behavior-feature reranking to identify demonstrations that are both semantically relevant and compatible with the target task. Finally, we adapt the policy through a two-stage pretraining and finetuning pipeline, which separates general skill acquisition from task-specific adaptation. Experiments on the LIBERO benchmark and several real-world robot manipulation tasks show that HSR improves the average success rate by 10.3% and 21.3% over the strongest baseline, respectively. These results demonstrate the effectiveness of structured skill-level retrieval for data-efficient VLA adaptation. Videos and code are available at https://hoar012.github.io/HSR-Project.

- **VLA模型的适配困境**：视觉-语言-动作（VLA）模型在大规模机器人数据集上预训练后具备强大基础能力，但在面对目标任务演示数据稀缺时，其迁移性能会显著下降。
- **数据收集成本高**：高质量机器人演示的采集昂贵且耗时，目标数据集往往不足以支撑大模型完成可靠的微调适应。
- **现有检索方法的不足**：现有的基于检索的适应方法（如视觉相似性、状态-动作表示或任务级语言匹配）多关注视觉或运动层面的相似性，忽略了**长时序操作任务的层次化结构**——完整任务匹配在数据集中极少出现，而可复用的细粒度技能（如"抓取""放置""打开"等）却大量存在。
- **核心研究问题**：如何将复杂的长时序任务分解为可复用的技能层级，并据此从先验数据集中检索出语义相关且行为兼容的演示，从而实现VLA模型的低数据依赖适应。
- **论文假设与意义**：结构化技能级检索比粗粒度的任务级检索更有效；语言指令可提供重要的语义信号以增强任务泛化，但需与行为的低层兼容性结合。

## 二、方法论：核心思想、关键技术细节与算法流程

### 1. 方法整体架构（HSR三步框架）

HSR 包含三个主要阶段：**分层任务分解与方案评估**、**混合技能检索**、**两阶段策略适应**。

### 2. 分层任务分解与方案评估

- **技能聚类**：对先验数据集中所有任务指令提取文本嵌入（BERT），使用 K-means 聚类将其归为 K 个语义连贯的技能簇 S = {s₁, ..., s_K}（如 Pick up、Open、Pour 等）。
- **技能置信度评估（Skill Confidence Score）**：

  - 将先验数据集划分为训练/验证集，在训练集上微调预训练 VLA 模型得到 π_θ′。
  - 计算每个技能簇对应的验证轨迹上的行为克隆（BC）损失：L_traj(τ) = (1/H_τ) Σ ℓ_BC(π_θ′(o_t, T), a_t)
  - 计算技能簇的验证损失 L_val(s_i) 及平均轨迹长度 H̄(s_i)，并做 min-max 归一化。
  - 技能置信度评分：**C(s_i) = exp(−α·L̃_val(s_i) − β·H̃(s_i))**，其中 α=0.6、β=0.8 固定，该分数作为无需 rollout 的技能可靠性代理指标，偏好"易于模仿 + 不易累积误差"的技能。
- **计划生成与评分**：
  - 使用 LLM（Qwen3-VL-4B）以目标任务描述 + 可用技能集为输入，生成 N 个候选分解计划，每个计划为有序子任务序列 p = (u₁, ..., uₙ)。
  - 利用文本嵌入相似度为每个子任务匹配最近的技能簇 s(u_j)；LLM 同时生成语义分数 S_sem(p) ∈ (0,1]。
  - 计划最终得分：**Score(p) = S_sem(p) · Πⱼ C(s(u_j))**，选取最高分计划用于检索。

### 3. 混合技能检索（Hybrid Skill Retrieval）

- **语言级检索**：基于子任务的语义描述从先验数据集中检索语义相关的前 M% 轨迹；
- **行为特征重排序**：
  - 训练一个 VAE 编码器（在 D_prior 上）提取行为特征；
  - 对语言检索保留的候选轨迹，将帧级特征与目标演示帧特征计算最近邻距离：
    **s(f) = maxⱼ(−‖z_f − z_tⱼ‖²)**（即负欧氏距离）
  - 保留 top F% 帧作为最终检索数据，兼顾语义相关性与行为兼容性。

### 4. 两阶段策略适应

- **阶段一**：在语言检索数据 D_lang 上对 VLA 模型进行预训练，获取通用的可转移技能行为。
- **阶段二**：在目标数据集 D_t ∪ D_rerank（语言检索数据中经行为重排序后的高兼容帧）上进行微调。
- 该方法不同于现有单阶段联合训练，明确区分"通用技能获取"与"任务特定适应"，避免检索数据噪声对策略优化的干扰。

## 三、实验设计：数据集、benchmark与对比方法

### 1. 模拟环境：LIBERO Benchmark

- 使用 LIBERO 的 **long-horizon subset**，共10个复合操作任务，涵盖"拾取-放置、关闭抽屉"等多技能任务；
- 目标数据集 D_t：每个任务仅 **5 个演示**；
- 先验数据集 D_prior：使用 **LIBERO-90**（90个任务×50个演示）；
- 检索参数：第一层语言检索 top 10% 轨迹，重排序后保留 top 30%（约先验数据集的 3% 帧）；
- 评估：每任务 50 次评估 × 3 个随机种子，报告平均成功率与标准差。

### 2. 真实世界实验

- 机器人平台：**7-DoF xArm**；
- 任务（4个）：Drawer（关闭抽屉，1个子技能）、Trashcan（捡纸团丢垃圾桶，2个子技能）、Cup-Drawer（放杯子入抽屉并关闭，3个子技能）、Cup-Tea（茶包放杯边后倒水，4个子技能）；
- 目标数据 D_t：每任务 20 个演示；
- 先验数据 D_prior：从 **DROID** 数据集中随机抽取 10k 条轨迹；因跨具身差距大小，仅采用重排序 top 3% 帧进行技能预训练，微调只用 D_t；
- 评估：每任务 20 次试验，使用固定初始状态集合保证公平比较。

### 3. 对比基线

- **BC**（仅目标微调）、**Random**（随机混合10%先验数据共同训练）、**All Data**（整个先验数据集共同训练）、**Language**（纯语言相似度检索 + 共同训练）
- **FR**（Flow Retrieval，基于光流相似度检索）
- **STRAP**（基于视觉基础模型 + 动态时间规整的子轨迹检索）
- **BR**（Behavior Retrieval，VAE潜空间行为相似度检索）
- **IWR**（Importance Weighted Retrieval，基于重要性权重检索）
- 另外还做了**BR + Two-Stage**和**去除各模块的消融变体**对比。

## 六、主要结论与发现

- HSR 在 **LIBERO**（模拟）上平均成功率达 **43.5%**，较最强基线（BR，33.2%）提升 **10.3 个百分点**；
- 在 **真实世界任务**上整体成功率 **48/80**，较最强基线（IWR，31/80）提升 **21.3 个百分点**；
- 在不需要复杂任务分解的简单单技能任务上，HSR 与 BR 等传统方法表现相当；而在**复杂复合长时序任务**上优势极为显著（如 Mug-M 上比 STRAP 提升 27.3%，Bowl-C 上是唯一比纯BC效果更好的方法）；
- 任务分解 + 技能置信度评估的分层思想**优于**纯语言检索、纯运动检索和单阶段联合训练；
- 长时序复杂技能（如 "make a cup of tea"）上的优势尤为显著：从 BC 的 3/20 提升至 9/20。

## 七、优点与亮点

- **方法创新性强**：首次将长时序任务的结构化分解与技能级检索系统结合，弥补了传统检索对语义层级结构缺乏利用的缺陷；
- **无需 rollout 的技能置信度代理指标**：利用 BC 验证损失 + 轨迹长度归一化加权，提供了一种计算高效且物理可行的可靠性度量方式，避免了真实世界 rollout 带来的成本和风险；
- **混合检索兼顾语义与行为双维度**：语言级检索保证高层次语义对齐，行为特征重排序保证低层执行兼容性，二者互补；
- **两阶段适应策略设计合理**：预训练 + 微调的分离方式有效削弱了检索数据与目标任务之间的领域偏移问题，优于直接将二者加权联合训练的思路；
- **消融实验设计全面**：逐一检验了各模块的作用（分解、重排序、训练范式），证据链完整；通过保留率扫描实验验证了检索数据量选择的敏感性分析。

## 八、不足与局限性

- **评估范围受限于单一机器人形态与动作类型**：仅在手部操作任务和一种 VLA 架构（SmolVLA-450M）上验证，缺乏对其他交互类型（移动操作、灵巧手、多臂协同）以及多模型架构（如 Octo、OpenVLA、π0 等）的验证；
- **依赖视觉/行为特征V AE的训练稳定性**：行为特征编码器的训练本身需要较大规模且多样性可观的先验数据集，在数据分布倾斜时可能影响重排序效果；
- **仅使用固定超参数**：技能置信度公式中的 α、β 及 K 值（聚类数）在所有实验中固定，缺乏关于超参数敏感性分析；
- **LLM 分解存在幻觉与不可行计划风险**：虽然用技能置信度缓解了这一问题，但 LLM 仍可能给出语义看似合理但物理上不连贯的子任务序列，鲁棒性有待加强；
- **未探索在线重规划与失败恢复机制**：论文中的分解是在训练阶段离线完成的，部署阶段如果任务部分失败无自适应纠错能力；
- **真实世界数据的跨具身差距处理尚简**：仅采用"跳过共同微调"的方式应对 xArm 与 DROID 数据的跨机器人差异，未来可考虑域自适应方法替代；
- **统计置信度有限**：真实世界实验每任务仅 20 次试验，虽然任务场景固定，但成功率估计的置信区间较大；
- **未在论文中报告检索时间成本**：对大规模 D_prior（数万到数十万条轨迹）的检索效率缺乏定量指标。

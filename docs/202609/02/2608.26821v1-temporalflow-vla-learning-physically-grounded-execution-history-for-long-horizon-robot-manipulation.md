## 摘要
视觉-语言-动作（VLA）模型利用预训练的视觉-语言表示进行机器人控制，但简单添加历史帧并不能可靠地捕捉近期的物理变化。这在多阶段操作中尤其成问题，因为视觉上相似的状态可能根据先前的执行而需要不同的动作。为解决这一挑战，我们提出了 TemporalFlow-VLA，通过物理 grounded 的时间监督来学习紧凑的执行历史。利用记录的机器人状态、机器人几何和标定相机，我们构建机器人-表面时间流作为仅训练目标，并监督两个执行对齐的时间查询，为动作专家提供结构化历史。几何监督路径在部署时不进行评估。TemporalFlow-VLA 在 LIBERO 上实现了 97.63 ± 0.26% 的平均成功率，其中 LIBERO Long 上为 96.60 ± 0.87%，在 12 个 RoboTwin 任务上实现了 85.5%/84.2% 的清洁/随机化成功率。在更长时程、多阶段操作上，它相对于先前方法显示出最明显的优势。受控历史干预表明，动作预测依赖于历史内容和时间顺序。通过异步特征缓存，时间条件化在无额外历史编码开销的情况下保持了单帧级别的服务器端采样延迟。总体而言，TemporalFlow-VLA 提供了一种紧凑、物理 grounded 的接口，用于利用有序执行历史，而无需在部署时进行显式运动估计或几何处理。

## Abstract
Vision-language-action (VLA) models leverage pretrained vision-language representations for robot control, yet simply adding historical frames does not reliably capture recent physical change. This is especially problematic in multi-stage manipulation, where visually similar states may require different actions depending on prior execution. To address this challenge, we present TemporalFlow-VLA, which learns compact execution history through physically grounded temporal supervision. Using recorded robot states, robot geometry, and calibrated cameras, we construct robot-surface temporal flow as a training-only target and supervise two execution-aligned temporal queries that provide structured history to the action expert. The geometric supervision path is not evaluated at deployment. TemporalFlow-VLA achieves 97.63 +/- 0.26% average success on LIBERO, including 96.60 +/- 0.87% on LIBERO Long, and 85.5%/84.2% Clean/Randomized success across 12 RoboTwin tasks. It shows its clearest advantage over prior methods on longer-horizon, multi-stage manipulation. Controlled history interventions show that action prediction depends on both historical content and temporal order. With asynchronous feature caching, temporal conditioning maintains single-frame-level server-side sampling latency without additional historical-encoding overhead. Overall, TemporalFlow-VLA provides a compact, physically grounded interface for exploiting ordered execution history without explicit motion estimation or geometric processing at deployment.

## 1. 核心问题与整体含义

**研究背景与动机**：
- 视觉-语言-动作（VLA）模型将预训练的视觉-语言表示用于机器人控制，展现出较强的泛化能力。
- 大多数 VLA 模型在生成动作时主要依赖当前 RGB 观测、语言指令和机器人状态，忽略了近期执行历史。
- 在多阶段、长时程操作中，视觉上相似的状态可能对应完全不同的执行历史，例如一次失败的抓取与抓取前状态在外观上可能难以区分；相同的末端位姿可能对应“接近”“携带”或“恢复”等不同阶段。
- 仅简单地拼接历史帧往往不能有效提供“物理变化”信息。论文通过诊断实验发现：将三帧历史观测打乱顺序后，动作 loss 几乎不变；而删除历史帧则使 loss 增加约 4.6%。这说明基于原始历史帧的模型对时间顺序不敏感，难以利用有序的执行信息。
- 现有外部记忆或显式运动方法（如 TraceVLA 的轨迹提示）虽然暴露了历史运动信息，但往往需要在部署时运行运动估计或几何处理，增加推理开销。
- 因此，核心问题是如何**学习一种紧凑、物理可解释、且与动作控制对齐的执行历史表示**，从而使 VLA 能够有效利用近期物理演化过程，尤其是在多阶段长时程操作中。

## 2. 方法论

**总体思路**：
- 在预训练的 VLA 基础上增加一个**并行时间路径**，利用机器人自身运动学信息构建物理 grounded 的监督信号，训练两个“执行对齐的时间查询（temporal queries）”，将结构化历史信息传递给动作专家。
- 关键设计：**几何监督只用于训练阶段，部署时不依赖任何运动估计或几何渲染**。

**具体技术细节**：

- **基于运动学的机器人-表面时间流（Kinematics-Grounded Robot-Surface Temporal Flow）**
  - 对于时间间隔 ρ ∈ {8, 15}，设 s = t - ρ，利用记录的关节状态 q、机器人的 URDF 几何和标定相机参数，将源时刻 t 时可见的机器人表面像素 p 投影到目标时刻 t 的图像平面上。
  - 通过正向运动学变换，计算机器人表面点在目标时刻的位置，并将其投影到 224×224 策略图像平面，得到每像素的位移向量：
    - f_ρ(p) = (u_t(p) - u_s(p)) / 224
  - 将像素级流动聚合为 16×16×2 的 patch-level 目标（按非重叠区域做掩码平均），并用“有效机器人像素覆盖率”作为掩码（并非 loss 权重），仅对有效支持的区域计算监督。
  - 该监督完全离线生成，无需人工标注或部署时传感器。

- **分层时间查询与联合注意力（Hierarchical Temporal Queries and Joint Attention）**
  - 将两个可学习时间 token `q8` 和 `q15`，以及历史图像 token `V8`、`V15`，拼接到 π0.5 标准前缀后。
  - 通过“查询特定掩码”组织层次：
    - Q8 只能读取语言 token、当前观测、t-8 观测及自身，专注于**短程运动**；
    - Q15 可以额外读取 t-15 观测和 Q8，从而**整合长程历史**。
  - 单向信息流 Q8 → Q15 保持两个时间尺度独立。
  - 动作 token 只能通过两个时间查询间接获取历史信息，不能直接读取历史图像 patch —— 强制历史信息必须被压缩进物理监督的查询表示中。
  - 每个查询对应一个专用的、参数不共享的轻量解码器（FiLM 调制 + pointwise MLP），用于从源帧 patch 状态重建对应时间间隔的机器人-表面流。
  - 辅助 loss：
    - L_temp = 0.5 * (L_flow^8 + L_flow^15)
  - 总训练目标：
    - L = L_action + λ_temp * L_temp，λ_temp = 1.0

- **异步历史特征缓存**
  - 为避免每个重规划步都同步编码三帧图像（t-15、t-8、t）带来的计算开销，将历史图像编码作为后台异步进程，存放在带时间戳的环形缓存中。
  - 在机器人执行当前动作块期间，背景进程预计算下一时刻所需的历史特征；重规划时直接读取缓存中的历史特征，仅当前帧编码需要同步执行。
  - 延迟对比：
    - 无缓存：T_naive = 3T_vision + T_joint + T_action
    - 有缓存：T_cache ≈ T_vision + T_joint + T_action

**核心贡献**：
1. 提出“运动学-接地机器人-表面时间流”作为训练监督；
2. 设计两个“chunk 对齐的时间查询”，通过联合掩码注意提供结构化历史；
3. 提出异步历史特征缓存，显著降低推理开销；
4. 在模拟和真实机器人上验证了方法的有效性与可行性。

## 6. 主要结论与发现

- TemporalFlow-VLA 在 **LIBERO** 上平均成功率为 **97.63 ± 0.26%**，其中 **LIBERO Long 达到 96.60 ± 0.87%**，比最强已报告平均值高约 2.1 个百分点。
- 在 **RoboTwin 2.0** 的 12 个任务上，Clean/Randomized 平均成功率分别为 **85.5% / 84.2%**；随机化条件下比最佳已有 baseline 高 **8.0 个百分点**。
- 优势随任务时程**单调增强**：H=2 时比 runner-up 高 5.5 点，H=3 时高 14.5 点，而 H=1 并非最优 —— 说明历史信息对多阶段、长时程操作最有价值。
- 受控历史干预实验证明动作预测**同时依赖历史内容和时间顺序**，而直接多帧输入对顺序不敏感。
- 异步特征缓存将平均采样延迟从 68.10 ms 降至 62.78 ms，节省 7.8% （累计 79.8 ms），保持了单帧级推理开销。
- 真实机器人上：三杯堆叠成功率从 57.8% 提升到 77.8%（+20 点），两瓶装箱从 86.7% 提升到 97.8%（+11.1 点），验证了从仿真到真实的可迁移性。

## 7. 优点

- **物理 grounded 的训练监督**：使用机器人状态、URDF 几何和相机标定生成机器人表面时间流，不需要对象级标注或额外传感器，可解释且易于离线批量生成。
- **训练与部署解耦**：几何监督路径仅在训练时使用，部署时无需任何运动估计、轨迹追踪或几何渲染，避免了 TraceVLA 等方法的部署成本。
- **紧凑的历史接口**：只有两个时间查询参与动作生成，历史视觉 token 被屏蔽，动作专家无法直接“偷看”历史图像，确保信息必须先经过监督压缩。
- **分层时间尺度**：Q8 代表短程运动，Q15 可在此基础上读取长程信息，并在注意掩码中形成单向层级结构，既保持多尺度又避免冗余。
- **推理效率设计良好**：异步缓存将历史编码移出关键路径，使时间条件化几乎不增加在线延迟。
- **实验覆盖全面**：从短时程到长时程、从仿真到真实、从在线 SR 到离线诊断，再到延迟测量，证据链完整。
- **诚实与透明的基线引用**：对部分 baseline 数字来源（如 X-VLA 的重评估）做了明确注释，提高了比较的可信度。

## 8. 不足与局限

- **未系统性搜索历史时间尺度**：论文使用固定的 `t-15` 和 `t-8` 两个偏移量，没有深入研究应使用多少帧、间隔多大的历史对不同的操作类型最佳。论文也将此列为未来工作。
- **真实实验数据量较小**：每个真实任务只有 45 次试验，任务种类仅两种（均为三阶段操作），且仅测试了单种机器人平台（AgiBot A3），真实场景的泛化性证据还比较初步。
- **RoboTwin 结果缺少置信区间/多次运行统计**：没有提供多随机种子下的均值±标准差，与 LIBERO 的实验严谨度有明显差异。
- **训练开销仍增加约 20%**：虽然推理延迟通过缓存控制住了，但训练时的辅助 flow 监督和双解码器增加了明显的计算开销。
- **适用范围局限**：方法依赖机器人关节状态和 URDF 几何来构建监督，对于非刚性物体、多灵巧手或无精确模型的机械结构，直接应用可能存在困难。
- **可迁移性分析较少**：论文没有深入分析时间监督对视觉外观变化、光照变化或相机标定误差的鲁棒性；在真实实验中使用的也是标定良好的固定相机。
- **离线历史干预实验的在线意义有限**：论文虽然强调“offline action-loss diagnostic”，但未提供与在线成功率的直接关联分析，削弱了该结果对在线决策影响的解释力。

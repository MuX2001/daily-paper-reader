## 摘要
在接触丰富的操作中，可靠的行动评估需要超越当前观测，考虑未来的视觉与接触后果。现有的噪声空间强化学习能够高效引导冻结的视觉-语言-动作（VLA）策略，但其评价器在很大程度上忽略了这些后果。我们提出 Imagine-RL，它通过动作条件化的视觉-力矩想象来增强噪声空间 VLA 后训练。对于每个候选动作块，冻结的视觉-力矩潜在世界模型（VTLWM）自回归地预测紧凑的未来表示，而无需像素重建。当前图像-状态-动作查询关注已观测历史和预测未来，同时前一窗口的预测残差提供逐 token 的置信度先验，以抑制不可靠的未来 token。通过将当前证据与预测后果相结合，动作评价器能更好地评估候选动作并监督 actor，而 VLA 与 VTLWM 保持冻结。在四个真实机器人任务中（每个任务 50 次评估试验），Imagine-RL 仅使用 100 条 RL 轨迹，就将平均成功率相较 DSRL 提高了 23.6%，相较 VLA 基线提高了 60%。

## Abstract
Reliable action evaluation in contact-rich manipulation requires looking beyond the current observation to future visual and contact consequences. Existing noise-space reinforcement learning efficiently steers a frozen Vision-Language-Action (VLA) policy, but its critics largely ignore these consequences. We present Imagine-RL, which augments noise-space VLA post-training with action-conditioned visual-torque imagination. For each candidate action chunk, a frozen visual-torque latent world model (VTLWM) autoregressively predicts compact future representations without pixel reconstruction. A current image-state-action query attends to observed histories and predicted futures, while previous-window prediction residuals provide token-wise confidence priors that suppress unreliable future tokens. By combining current evidence with predicted consequences, the action critic better evaluates candidate actions and supervises the actor, while the VLA and VTLWM remain frozen. Across four real-robot tasks with 50 evaluation trials per task, Imagine-RL uses only 100 RL trajectories and improves the average success rate by (23.6%) over DSRL and by (60%) over VLA baselines.

## 1. 核心问题与整体含义

- **研究动机**：接触丰富（contact-rich）的机器人操作中，动作是否可靠不能只看当前观测，还必须预见未来的视觉与接触后果（如阻力、滑移、卡滞、按压力变化）。
- **背景痛点**：
  - VLA（Vision-Language-Action）模型主要依赖视觉观测，对接触力/力矩等物理反馈利用不足。
  - 现有噪声空间强化学习（如 DSRL）能高效引导冻结 VLA，但其 critic 基本只根据当前观测和候选动作打分，忽略未来后果。
  - 当视觉上相似的动作可能导致成功或失败时，这种 critic 的动作排序不可靠，尤其在 latent-noise VLA-RL 中，action critic 还会监督 noise critic 和 actor。
- **整体含义**：论文提出 **Imagine-RL**，在冻结 VLA 的噪声空间后训练中引入动作条件化的视觉-力矩想象，让 critic 同时利用“当前证据”和“预测未来后果”，从而提升接触丰富任务的动作评估与成功率。

## 2. 方法论

- **核心思想**：
  - 保持 VLA 与世界模型冻结，只训练轻量级 latent-noise actor 与 critic。
  - 用冻结的视觉-力矩潜在世界模型（VTLWM）为每个候选动作块预测未来紧凑表示。
  - critic 通过交叉注意力融合当前图像-状态-动作查询、观测历史、预测未来，并利用前窗预测残差生成 token 级置信度，抑制不可靠未来 token。

- **Latent-Noise VLA-RL 流程**：
  - 冻结 VLA \(\pi_0\) 将观测 \(o_t\) 和 latent noise \(w_t\) 映射为动作块 \(\bar a_t=\pi_0(o_t,w_t)\)。
  - 轻量 actor \(w_t\sim\pi_\theta(w|o_t)\) 只学习噪声输入，不直接学习机器人动作。
  - 两个 critic：
    - **Action critic** \(Q_a(o,\bar a;h_{\bar a})\)：评估解码后的动作块，输入包含当前观测、动作以及世界模型生成的历史/未来特征。
    - **Noise critic** \(Q_w(o,w)\)：从 \(Q_a(o,\pi_0(o,w))\) 蒸馏得到，用于更新噪声 actor。
  - 训练采用 SAC 风格：动作 critic 用 Bellman 目标更新；noise critic 蒸馏 action critic；noise actor 最大化 \(Q_w\)。
  - 使用多个 Q 网络取均值作为目标，降低偏差；论文实现中使用 10 个 Q 函数集成。

- **视觉-力矩潜在世界模型 VTLWM**：
  - 共享编码器融合多视角图像为视觉 latent \(z_t\)，力矩归一化为 \(\hat\tau_t\)，动作编码为 \(E_a(a_t)\)。
  - 定义状态输入 \(x_t=[z_t,\hat\tau_t]\)，使用历史长度 \(H=15\) 的一步因果预测器，自回归滚动预测未来 \(H_f=10\) 个有效未来视觉与力矩状态。
  - 训练损失：
    - 视觉预测 MSE；
    - 力矩预测 SmoothL1；
    - SIGReg 正则项。
  - RL 训练期间 VTLWM 冻结，仅生成 critic 特征，不做像素重建。

- **残差置信度引导的交叉注意力 Critic**：
  - 对每个模态 \(m\in\{z,\tau\}\)，特征构建包含：
    - 当前历史 \(X^{m,hist}_t\)；
    - 候选动作条件下的未来预测 \(X^{m,fut}_t(a_t)\)；
    - 前一窗口预测 \(P^{m,prev}_t\)；
    - 预测残差 \(R^m_t=X^{m,hist}_t-P^{m,prev}_t\)。
  - 计算相对误差 \(\rho^m_{t,j}\) 与生成可靠性置信度：
    - \(\alpha^m_{t,j}=\max(\alpha_{\min},e^{-\beta\rho^m_{t,j}})\)；
    - 相对误差越小，置信度越高。
  - 交叉注意力：
    - Query 来自当前 \((o_t,a_t)\)；
    - Key/Value 来自历史与未来 token；
    - 注意力偏置 \(B^m_t\)：有效历史为 0，有效未来为 \(\log\alpha^m_{t,j}\)，无效槽为 \(-\infty\)；
    - 通过 softmax 后，未来 token 权重被置信度折扣，不可靠未来被抑制。
  - 融合输出：
    - 拼接视觉与力矩 context；
    - 加入可靠性统计量 \(g^m_t\)（未来有效槽的均值、最小、最大置信度和平均相对误差）；
    - 得到 \(h_{a_t}\)，与当前 \(\zeta_t=(o_t,a_t)\) 拼接后由 MLP critic 输出 Q 值。

- **算法流程概要**：
  1. 从 replay buffer 采样 transition；
  2. 更新 action critic，使用世界模型特征与 Bellman 目标；
  3. 采样噪声并用冻结 VLA 解码候选动作，蒸馏更新 noise critic；
  4. 更新 noise actor 以最大化 noise critic；
  5. VLA 与 VTLWM 全程冻结。

## 7. 优点

- **方法设计亮点**：
  - 冻结 VLA 与冻结世界模型，仅训练轻量噪声 actor/critic，计算与部署成本低；
  - 使用潜在空间预测而非像素重建，避免重型像素级规划；
  - 同时引入视觉与力矩未来预测，更适合接触丰富操作；
  - 残差置信度引导的交叉注意力能显式抑制不可靠未来 token，提升 critic 鲁棒性；
  - 将世界模型预测后果作为 action critic 的额外证据，直接改善动作排序与 actor 监督。

- **实验设计亮点**：
  - 真机验证，而非仅仿真；
  - 四个接触丰富任务覆盖插拔、按压、USB 插入、轴孔装配；
  - Critic 判别分析控制相同动作块和相同奖励，较客观地隔离价值函数区分能力；
  - 报告了世界模型视觉与力矩预测的定量指标；
  - 与 DSRL 使用相同 VLA backbone 和相同在线交互量，比较相对公平。

## 9. 总体评价与启示

- **贡献定位**：论文的核心贡献不是训练更强的 VLA，而是在冻结 VLA 的噪声空间后训练中，把“未来视觉-力矩后果”引入 critic，使动作价值评估从“当前看起来像对”转向“未来更可能成功”。
- **方法启示**：在接触丰富操作中，力/力矩模态与视觉未来预测具有互补性；同时，对世界模型预测不能无条件信任，残差置信度引导的交叉注意力提供了一种显式处理预测不可靠性的思路。
- **实践启示**：冻结大模型、只训练轻量 actor/critic 的路线，有利于降低算力与部署成本；但前提是已有较可靠的预训练 VLA 和世界模型，且任务分布不能与预训练/世界模型训练分布偏离过大。
- **未来方向**：可探索世界模型在线适应、更长时程与延迟接触后果建模、触觉/力觉多模态扩展、跨机器人本体验证，以及更系统的模块消融与统计显著性分析。
- **总体判断**：Imagine-RL 在四个真机接触丰富任务上展示了明确的有效性和数据效率优势，尤其体现在 critic 判别能力提升上；但其结论仍需更多任务、平台、消融与开源复现来进一步巩固。

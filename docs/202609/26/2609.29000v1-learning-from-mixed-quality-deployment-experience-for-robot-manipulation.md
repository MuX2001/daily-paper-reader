## 摘要
部署在真实环境中的机器人策略会自然积累混合质量的经验，包括成功执行、部分进展和失败。尽管这些 rollout 为进一步学习提供了有价值的信息，但直接将其纳入模仿学习可能会强化不良行为，而离线强化学习在稀疏奖励和有限数据覆盖下往往面临不可靠的价值估计。我们考虑一种实际的部署后设置，其中学习仅依赖于自然积累的自主 rollout，而不需要额外的人工纠正或探索性交互。为了有效利用这类经验，我们提出预测性动作分块学习（PACL）。PACL 首先学习一个预测性分块级评论家，用于评估时间上延展的动作序列，并通过未来潜在预测增强时序差分学习，从而为长时程价值估计提供更丰富的监督。学习到的评论家随后将分块级 Q 值转换为离散的质量条件，指导扩散 actor 从这些混合质量经验中联合学习，而不会将所有行为视为同等监督。在推理时，actor 生成多个动作分块，评论家选择价值最高的候选。在仿真和真实世界机器人操作任务上的实验表明，PACL 持续改进预训练策略，并优于强模仿学习和离线强化学习基线。

## Abstract
Robot policies deployed in real environments naturally accumulate mixed-quality experience, including successful executions, partial progress, and failures. Although these rollouts provide valuable information for further learning, directly incorporating them into imitation learning may reinforce undesirable behaviors, while offline reinforcement learning often suffers from unreliable value estimation under sparse rewards and limited data coverage. We consider a practical post-deployment setting where learning relies only on naturally accumulated autonomous rollouts, without additional human corrections or exploratory interaction. To effectively exploit such experience, we propose Predictive Action Chunk Learning (PACL). PACL first learns a predictive chunk-level critic that evaluates temporally extended action sequences and augments temporal difference learning with future latent prediction, providing richer supervision for long-horizon value estimation. The learned critic then converts chunk-level Q-values into discrete quality conditions, which guide a diffusion actor to learn jointly from these mixed-quality experiences without treating all behaviors as equivalent supervision. At inference, the actor generates multiple action chunks and the critic selects the highest valued candidate. Experiments across simulated and real-world robot manipulation tasks show that PACL consistently improves the pretrained policy and outperforms strong imitation learning and offline reinforcement learning baselines.

## 1. 核心问题与研究动机

- **背景**：机器人策略在真实部署中会自然积累混合质量的经验，包括成功执行、部分进展和失败轨迹。这些数据无需额外采集成本，是持续改进策略的天然资源。
- **核心矛盾**：
  - 直接将这些 rollout 用于模仿学习（如行为克隆）会不加区分地强化不良行为；仅使用成功轨迹又难以提供超越当前策略的额外监督。
  - 过滤不完美动作虽能减少有害模仿，却丢弃了揭示"应避免何种行为"的失败片段。
  - 离线强化学习（RL）虽能保留成功与失败经验并通过时序差分（TD）传播结果，但在视觉运动策略中，稀疏任务奖励与有限的数据覆盖使延迟结果难以可靠归因到具体动作序列，代表性离线 RL 方法甚至常逊于强模仿学习基线。
- **现有替代方案的局限**：依赖人类干预（专家纠正、恢复演示）或刻意收集的探索性交互与奖励反馈，均需额外人工监督或物理交互。
- **本文定位**：聚焦于**部署后（post-deployment）纯离线场景**——仅利用普通自主运行中自然积累的 rollout，不依赖人工纠正或刻意探索，将日常机器人运行转化为自主策略改进的数据来源。

## 2. 方法论：Predictive Action Chunk Learning (PACL)

### 2.1 核心思想
- 将隐式 Q 学习（IQL）从单步动作扩展到**时间延展的动作块（action chunk）**，使评论家能直接评估扩散策略生成的动作序列。
- 引入**未来潜在动态预测**作为稠密辅助监督，缓解稀疏奖励下的价值估计困难。
- 将学习到的块级 Q 值转化为**离散质量条件**，引导扩散 actor 从混合质量经验中学习，而非将所有行为等同对待。
- 推理时 actor 生成多个候选动作块，评论家选择价值最高者执行。

### 2.2 问题形式化
- 采用 Diffusion Policy（DP）作为视觉运动策略 π_θ，输入最近 H_o 帧观测与本体状态，输出包含 H_a 个连续动作的动作块 A_t。
- 初始策略 π_θ0 由人类演示数据集 D_h 经模仿学习训练；部署后自主收集轨迹，按任务是否在最大步数内完成标记成功（D_s）或失败（D_f）。
- 后训练数据集为 D = D_h ∪ D_s ∪ D_f，评论家学习与 actor 后训练**完全离线**进行。

### 2.3 预测式动作块评论家（Predictive Action-Chunk Critic）
- **块级 Q 函数定义**：直接在整个动作块 A_t 上定义 Q 函数，折扣奖励 R_t 为该块内 K_t 步奖励的折扣和（K_t = min(H_a, T_i − t)，处理轨迹尾部截断）。
- **潜在状态编码**：z_t = f_ξ(o_{t−H_o+1:t}, s_t)，编码器与价值函数联合优化。
- **价值函数**：V_ψ(z_t) 拟合目标 Q 值上期望分位（expectile，τ=0.9）；采用双 Q 网络 Q_ϕ1、Q_ϕ2 及缓慢更新的目标网络。
- **块级 TD 目标**：Y_t = R_t + (1−d_t)γ^{K_t} V_ψ(z_{t+K_t})，Q 损失为双 Q 对 Y_t 的均方误差。
- **关键创新——未来潜在动态预测**：
  - 随机采样预测视界 h ∈ {1,…,K_t}，仅将前 h 个动作输入动态预测器 F_η，其余动作掩码，保证时间因果性。
  - 目标潜在变化 Δz̄_t^{(h)} 由 EMA 更新的目标编码器计算；预测值 Δẑ_t^{(h)} = F_η(z_t, Ã_t^{(h)}, h)。
  - 动态损失 L_dyn 为该预测的均方误差，为价值估计提供跨多个视界的稠密视觉监督，并鼓励动作敏感的表示。
- **总评论家目标**：L_critic = L_Q + λ_V L_V + λ_dyn L_dyn（λ_V=1.0，λ_dyn=0.5）。

### 2.4 Q 条件 actor 学习（Q-Conditioned Actor Learning）
- **质量条件构建**：对每个动作块计算保守块价值 q_t = min(Q_ϕ1, Q_ϕ2)。基于部署经验 Q 值分布的 40th/60th 百分位阈值 δ_l、δ_u 分配离散条件：q_t ≥ δ_u → c_t = 1；q_t ≤ δ_l → c_t = 0；否则为不确定 ∅（弃权区）。
- **条件适配器**：在预训练 DP 上仅增加一个轻量条件适配器，将 c_t 映射为条件嵌入；c_t = ∅ 的样本使用空条件无条件训练；人类演示统一赋予 c_t = 1 以保留可靠演示行为。
- **Actor 损失**：沿用原始去噪目标，以 c_t 为条件进行微调。
- **设计依据**：IQL 风格下 V 与 Q 高度相关（Square 任务上成功/失败 rollout 的 Pearson 相关系数分别为 0.994 和 0.955），故直接用块级 Q 构造百分位条件，而非如优势条件方法用 Q−V；仅需稀疏任务结果，无需额外动作质量标注。
- **推理**：条件固定为 c_t = 1，actor 采样 N 个候选动作块，评论家选最高价值者执行 H_a 步后重复。

## 3. 实验设计

### 3.1 仿真实验（Robomimic benchmark）
- **4 个视觉操作任务**：Can（抓取放罐）、Transport（长时程多阶段搬运）、Square（方块插入销钉）、ToolHang（组装悬挂结构并放置工具）。
- 任务时域：Can 和 Square 为 400 步，Transport 和 ToolHang 为 700 步。
- 每任务使用 **200 条人类演示**训练初始 DP；部署后自主收集 **500 条混合经验 rollout** 用于后训练。

### 3.2 真实机器人实验
- **平台**：Franka Panda 7-DoF 机械臂 + 两个 Intel RealSense 相机（第三人称 + 腕部 RGB），图像缩放至 224×224。
- **3 个任务**：PickCup、StackCup、MoveSpoon。
- 每任务 **50 条人类演示** + **50 条自主 rollout**；策略以 20 Hz 输出 6-DoF 末端位移 + 夹爪命令，异步预测 8 步动作块。

### 3.3 对比基线（均从相同预训练 DP 热启动）
- **模仿学习类**：
  - SUB：直接在全部混合质量轨迹上微调，不做质量区分。
  - Self-Imitation：仅使用成功 rollout + 人类演示。
  - SSDF：从失败 rollout 中筛选有用片段进行加权模仿。
- **离线 RL 类**：DQL、IDQL、RISE（均在全量混合质量数据集上训练）。

### 3.4 消融实验
- **组件消融**：SUB → +Q 条件 actor → +评论家候选选择。
- **评论家设计消融**（Transport 任务，冻结 DP 对 N 个候选排序）：单步评论家、预测式单步评论家、块级评论家、完整 PACL，N ∈ {4, 8, 12, 16}。
- **条件策略消融**（Square，N=1）：Source Condition、Outcome Condition、Q−V Condition、Q-Condition。
- **数据组成与规模消融**：Post-trained DP（仅人类演示）、PACL-success（演示+100 成功）、PACL-small（+50 失败）、PACL-rollout（仅 500 rollout）、PACL-full（全量 700 条）。

### 3.5 评估规模

## 6. 主要结论与发现

- **整体性能**：PACL 在全部 7 个任务上取得最佳或并列最佳结果，例如仿真中 Transport 达 96.0%、Square 达 93.2%、ToolHang 达 82.8%；真实任务中 StackCup 达 100%、MoveSpoon 达 84.0%，全面优于强模仿学习与离线 RL 基线。
- **组件贡献**：Q 条件 actor 在所有任务上带来一致提升（Square、ToolHang 尤为明显）；评论家候选选择进一步增益，二者互补。
- **评论家设计**：单步评论家在候选集增大时性能急剧下降（N=16 时仅 58.8%）；加入未来潜在预测显著改善；块级评估单独效果有限，与潜在预测结合后达到最佳（N=16 时 80.4%）。
- **条件策略**：Q-Condition（91.2%）> Q−V Condition（88.8%）> Outcome Condition（88.0%）> Source Condition（85.6%），支持直接使用块级 Q 构造条件。
- **数据组成**：仅用成功 rollout 会使评论家缺乏负经验、性能下降；引入 50 条失败 rollout 即显著提升（Square 77.6%→88.0%，Transport 83.2%→88.8%）；仅用 rollout 不用人类演示也逊于混合数据，说明人类演示是重要锚点；全量数据效果最佳。
- **核心结论**：自然积累的部署数据（含失败经验）可作为自动化部署后策略改进的实用基础，无需人工纠正或刻意探索。

## 7. 优点

- **问题设定务实**：聚焦真实部署中自然积累的混合质量数据，无需人工干预或额外探索，具有较高的实际落地价值。
- **方法设计针对性强**：
  - 将价值估计从单步动作扩展到动作块，与扩散策略的输出结构对齐，解决了时间尺度不匹配问题。
  - 未来潜在动态预测作为稠密辅助监督，直接针对稀疏奖励下价值估计不可靠的痛点，且掩码设计保证时间因果性。
  - 用离散 Q 条件而非直接 Q 最大化来微调 actor，避免了 IQL 风格中策略提取的不稳定性，同时保留扩散策略的多模态表达力。
  - 弃权区（∅）设计允许评论家对不确定样本不表态，降低了噪声条件对 actor 的干扰。
- **实验设计严谨**：仿真 + 真实双重验证；消融层次清晰，从组件、评论家设计、条件策略到数据组成逐层拆解；对比条件统一（同一预训练模型热启动）。

## 摘要
我们考虑安全关键的控制问题，这些问题涉及多个具有不同优先级和评估不确定性的需求。我们使用风险感知的规则手册来表示这些需求，其中每个需求被赋予一个风险度量和一个可接受阈值，并在需求之间定义了优先级关系。每个需求导出一个风险评估函数，该函数将策略映射到与其违反相关的风险。我们将带规则手册的风险感知最优控制表述为关于超额风险的字典序优化问题，并开发了一种任意时刻过滤与分支定界算法，该算法在刻画每个优先级层级上相应策略集合的同时，逐步收紧已验证的最优性间隙。该算法返回一个策略以及这些间隙，从而界定该策略的次优性。我们证明这些间隙对任何有限的计算预算都是有效的，并且在额外假设下，随着计算预算的增加收敛到零。我们分别在一个具有已知最优解的合成基准和一个具有基于CVaR的碰撞规则、后制动规则、车头时距规则和舒适性规则的真实高速公路汇入仿真上评估了该算法。

## Abstract
We consider safety-critical control problems involving multiple requirements with different priorities and uncertainty in their evaluation. We represent these requirements using risk-aware rulebooks, where each requirement is assigned a risk measure and an acceptable threshold, and a priority relation is defined among the requirements. Each requirement induces a risk-evaluation function that maps a policy to the risk associated with its violation. We formulate risk-aware optimal control with rulebooks as a lexicographic optimization problem over excess risks and develop an anytime filtering and branch-and-bound algorithm that progressively tightens the certified optimality gap while characterizing the corresponding set of policies at each priority level. The algorithm returns a policy together with these gaps, which bound its suboptimality. We prove that these gaps are valid for any finite computational budget and, under additional assumptions, converge to zero as the computational budget increases. We evaluate the algorithm on a synthetic benchmark with a known optimum and a realistic highway-merging simulation with CVaR-based collision, rear-braking, headway, and comfort rules.

## 带规则手册的风险感知最优控制（Risk-Aware Optimal Control with Rulebooks）——论文中文详细总结

### 1. 论文的核心问题与整体含义

- **研究背景**：安全关键型自主系统（如自动驾驶）的控制往往需要同时满足多个目标，包括安全、法规、通行效率、舒适性等等。这些目标通常具有不同的优先级（例如：避撞 > 三秒车头时距 > 舒适性）；且系统运行环境存在不确定性（其他交通参与者的行为、感知误差、预测误差等），导致同一个策略的风险结果并不确定。
- **核心问题**：如何在“多个需求具有不同优先级”且“每个需求的评估结果具有随机性”的条件下，从策略集中求出最优策略？其挑战在于：
  - 这不仅是单一标量代价的优化问题，而是带优先级结构的**多目标决策问题**；
  - 不确定性使得单纯的期望代价难以刻画极端但严重的后果，需要考虑期望值、最坏情况、VaR、CVaR 等更多风险度量；
  - 实际系统中风险评估函数往往是“黑箱”（没有解析式、不含梯度）。
- **整体含义**：论文将“规则手册（rulebook）”形式化扩展为“风险感知规则手册”，把优先级与风险约束统一为**超额风险的字典序优化问题**，并设计可在有限预算内给出**可证明最优性界**的在线算法。该框架对安全攸关控制、运动规划、人机交互决策等方向有较强的普适意义。

### 2. 论文提出的方法论

- **问题建模**：
  - 定义一个概率空间刻画环境/行为不确定性；对于每个规则 \(r_i\)，将评估结果视为随机变量 \(r_i^\pi(\omega)\)，用风险度量 \(\rho_i\) 得风险评价函数 \(q_i(\pi) = \rho_i(r_i^\pi)\)，并用阈值 \(\gamma_i\) 表示可接受风险水平。
  - 引入**超额风险** \(e_i(\pi) = [q_i(\pi) - \gamma_i]_{+}\)：当 \(q_i \le \gamma_i\) 时，该规则“满足”，超额风险为 0；否则返回到阈值的“超出量”。
  - 论文证明（或基于前期工作）原始规则手册可无损细化成**总序规则手册**，从而将问题写为字典序最小化超额风险向量 \(\Big(e_1(\pi), \dots, e_m(\pi)\Big)\) 的优化问题。
- **核心技术与关键步骤**：
  - 将**策略空间表示为轴对齐盒子的集合**；假设每个风险评价函数为已知 Lipschitz 常数的黑箱函数，利用 Lipschitz 不等式给每个盒子 \(B\) 计算 \(q_i\) 与 \(e_i\) 的上下界；
  - 通过“**下证（lower certificate）**” \(\underline{\alpha}_i\) 与“**上证（upper certificate）**” \(\overline{\alpha}_i\) 维护最优值的有效区间，得到可输出给用户的**次优性间隙** \(\varepsilon_i = \overline{\alpha}_i - \underline{\alpha}_i\)；
  - **任意时刻滤波-分支定界算法**：
    1. **D-Pruning（域剪枝）**：剔除对更高优先级规则已不可能满足的盒子；
    2. **阈值剪枝 / 竞争性剪枝**：当规则可满足（\(\alpha_i=0\)），剔除高风险盒子；当不可满足，剔除“非竞争”盒子；
    3. **最宽盒子二分细化**：选择不确定性宽度最大的盒子，沿最长边二分；
    4. 剪枝、细化过程始终保证**保持对最优策略集合的覆盖**；
    5. 逐层“过滤+细化”形成**已验证许可域** \(D_i\)，并不断更新候选策略（incumbent）集 \(C\)。
  - **理论贡献**：证明此类精化不丢失候选解；对任意有限计算预算，返回策略的间隙 \(\varepsilon_i\) 都有效；在额外假设下（策略空间可用若干闭盒精确拼接、候选采样密度以盒子宽度为速率逼近），算法收敛，证明间隙趋于 0，且极限策略是该层真最优。

### 3. 实验设计

- **实验一：合成基准（Synthetic Benchmark）**
  - 单一规则情形（\(m=1\)），策略空间为 \(\Pi = [-1,1]^2\)；
  - 风险函数为带平移的 Raisin-Rosenbrock 型函数，已知全局最优解 \(\pi^* = (0.5, 0.25)\)，便于定量验证；
  - 采用 Lipschitz 常数 \(L=11\)（保守估计，10.31 即可）；
  - 设置两种阈值：\(\gamma=0\)（满意点仅在最优）与 \(\gamma=0.05\)（最优区域为非平凡子水平集）；
  - **对比方法**：
    - 经典 best-first 的 Lipschitz 分支定界（对超额风险直接做 Lipschitz 下界）；
    - 阈值化 best-first 分支定界（用本文 (2) 式的阈值下界）；
    - 均匀网格离散搜索（对照无置信下界的方法）；
    - 本文提出的算法（最宽盒细化、阈值化下界）。
  - 评估指标：任意时刻间隙 \(\varepsilon(N)\)、覆盖测度 \(|O(N)|\)、调用黑箱的次数，最大迭代 \(N_{max}=900\)，对应均匀网格 30×30。
- **实验二：高速公路汇入仿真（Highway Merging）**
  - 场景：自车在有限时间内汇入前车与后车之间的车道空隙。
  - 用 **Bézier 曲线扁平化参数化**策略（自由度降为 8 个内部控制点坐标）；周围车辆采用变参数驾驶行为模型（前车/后车分别有 prompt/delayed/weak/nonresponsive 等模式，含反应延迟、干扰噪声）。
  - **规则集**：碰撞规避（前/后）、后车制动、三秒车头时距（前/后）、舒适性（加速度+转向曲率加权）；
  - 风险度量：碰撞、制动、车头时距均采用 **经验 CVaR**（\(\beta_1 = 0.05, \beta_2=\beta_3=0.1\)），蒙特卡洛样本数 \(M_{MC}=200\)；舒适性规则是确定性轨迹函数。
  - 黑箱评价函数通过固定的预采样场景集进行蒙特卡洛仿真，从而把随机的函数估成确定性的“黑箱”函数；
  - 记录算法自身运行时间、最优性上/下证书随计算时间的变化、候选策略集合的大小；总体分配给算法 50 ms 的计算预算（对应 20 Hz）。
- **指标**：算法运行时间、CVaR 超额风险差距、候选集大小、每次运行返回的策略是否一致。

### 6. 论文的主要结论与发现

- 提出了一套“风险规则手册 + 字典序优化”的形式化解决框架，能够自然地处理“不同规则使用不同风险度量、不同阈值、不同优先级”的控制需求。
- 证明了算法的重要理论性质：
  - 对**任意有限计算预算**，算法最终返回的策略都带有**严格有效的次优性上界**（optimality certificate）；
  - 在额外假设下，间隙随预算增大而 **收敛到 0**，且返回候选的任一极限点都属于真最优策略集。
- 合成基准实验结论：
  - 与传统 best-first 分支定界相比，本文的“最宽盒”选择加快了对可行解的覆盖收缩，优于经典 B&B；
  - “阈值化下界”能显著降低间隙（减少因阈值截断而造成的保守下界）；
  - 网格搜索在保证候选质量上相当，但无法给出置信下界/最优性保证。
- 高速公路汇入实验结论：
  - 按优先级（碰撞 → 后制动 → 车头时距 → 舒适性）逐级过滤后，算法在约 22 ms 内即可找到让前三类规则全部满足、仅舒适性超额 0.40 的策略；
  - 说明该方法计算上适合实时规划场景；
  - 说明当一个高优先级规则被满足后，算法能自动转入阈值滤波模式，不再“过度优化”，符合规则手册的语义。

### 7. 优点

- **理论扎实**：从精确字典序解集到“允许有限预算的置信域”做了严谨的松弛推导；把“竞争性剪枝”“阈值剪枝”“覆盖保持”“收敛性”用一组不依赖具体下界构造方式的引理串起来，十分清晰。
- **模型表述通用性强**：允许每个规则使用不同风险测度与阈值，优先级可以是部分序并可细化成总序；统一了“满足阈值即可”“阈值做不到则最小化超出量”两种情形的计算逻辑。
- **算法设计巧妙**：把“可行性滤波”和“Lipschitz 优化”结合，避免严格串行解决每个优先级层的问题；利用“只要覆盖所有最小值点即可”来克服 set-valued 全局水平集刻画困难，很适合黑箱风险函数场景。
- **结果可解释与可靠**：返回结果附带每一层策略的次优性间隙；对有限时间终止不再需要“必须完成全局优化”的强假设。
- **验证具有一定针对性**：合成基准能找到“最优间隙提高”和“覆盖收缩变快”这两个重要增益的确切来源。

### 8. 不足与局限

- **实验覆盖面偏窄**：只在二维合成函数和一个固定高速公路场景上验证；没有复杂交叉路口、行人、多车强交互等更丰富场景，也没有高维（如 >100 维）优化压力测试的展示。
- **缺少与外部强基线的对比**：真实场景只演示自身算法行为，没有对照 best-first B&B、CMA-ES、贝叶斯优化等通用黑箱优化器，也没有与已提出的规则手册规划方法比较。
- **理论假设在实际中并不总能理想满足**：
  - 实际每个 \(q_i\) 的 Lipschitz 常数要靠蒙特卡洛采样估计，且需“膨胀”为保守上界，过高会拖慢收敛、过低会破坏保证；
  - 蒙特卡洛 / 代理黑箱估计带来的统计误差没有纳入置信下界的计算，导致当估计器有偏时理论证书不严格成立；
  - 为保证间隙收敛到 0，还需假设策略空间能用“若干个完整盒”精确拼出以及候选采样能按盒子粗细包围最优（现实黑箱问题中并不总能满足）。
- **计算层面**：当前剪枝依赖“整个域可否划分成盒子”、以及各种采样和裁剪操作的实现效率；当 \(d\) 较大或规则数很多时，盒子数爆炸、内存和时间开销都会上升，论文对此的实证探讨很少。
- **安全语义没有端到端评估**：论文没有给出最终轨迹在“碰撞概率、最坏制动、车头时距违反概率”等安全指标的统计结果，也未评估策略对感知/预测误差的敏感性。

## 摘要
世界动作模型通过预测的未来观测来指导动作生成，但以视觉为中心的预测会错过决定接触密集操作的局部接触线索。然而，在我们的实验中，简单地将未来的触觉观测作为额外视图进行预测，只能获得可实现增益的三分之一。这种差距反映了时间上的错配：预测先于执行，而触觉反馈在执行期间到达。我们提出了TacPAC，它将触觉预测转化为实时动作修正。一旦基础模型规划了一个动作块，TacPAC会缓存该计划所依赖的预测接触信息以及计划自身的表征，然后一个触觉专家将每个新观测到的触觉图像与该缓存进行比对，以修正尚未执行的动作。因此，反馈是根据计划预期而非孤立地解读，且一次修正只需对该缓存进行单次遍历，比重新生成该动作块便宜20.7倍。在跨越精密插入、易碎物体处理、物体重定向和长时程操作等五项真实机器人任务上，TacPAC在每项任务上都领先，并将仅基于视觉的基础模型平均成功率从22%提升到64%。代码可在https://github.com/LogosRoboticsGroup/TacPAC获取。

## Abstract
World-action models guide action generation with predicted future observations, but vision-centric predictions miss the local contact cues that decide contact-rich manipulation. However, naively predicting future tactile observations as additional views recovers only a third of the achievable gain in our experiments. This gap reflects a timing mismatch: predictions precede execution, while tactile feedback arrives during it. We introduce TacPAC, which turns tactile prediction into real-time action correction. Once the base model has planned an action chunk, TacPAC caches the predicted contact that plan was conditioned on together with the plan's own representation, and a tactile expert reads each newly observed tactile image against that cache to correct the actions not yet executed. Feedback is thus interpreted against what the plan anticipated rather than in isolation, and one correction is a single pass over that cache, $20.7\times$ cheaper than regenerating the chunk. On five real-robot tasks spanning precision insertion, fragile-object handling, object reorientation, and long-horizon manipulation, TacPAC leads every task and raises the average from 22% for its vision-only base model to 64%. Code is available at https://github.com/LogosRoboticsGroup/TacPAC.

### 1. 核心问题与整体含义

**研究动机与背景：**

- 接触密集操作（如插入充电插头、抓取薯片）中，接触状态（局部形变、滑动、插入偏差）往往在视觉图像中不可见或被遮挡，视觉信号只能提供全局语义信息，无法解决决定成败的物理交互细节。
- 世界动作模型（WAM）通过预测未来观测来指导动作生成，但目前的预测以视觉为中心。简单的补救方式——将触觉观测也作为"额外视图"与未来视频一起预测——在作者的实验中只能获得理论增益的三分之一。
- **关键洞察（时间错配）**：预测先于执行，而触觉反馈在执行过程中才到达。一旦动作块（action chunk）被计划好，预测的"预期接触"便已固定；当实际接触与预测偏离时，没有任何机制去修正尚未执行的动作。

**TacPAC 的核心含义**：将触觉预测从"与动作生成并行的一条输出通道"重新定位为**动作执行期间的实时反馈参照**——预测的价值不在于更准确地描述未来，而在于为实时修正提供一个可比的"预期基线"。

### 2. 方法论

**2.1 总体架构（三专家 MoT）**

采用 Mixture-of-Transformers（MoT）架构，包含三个专家（各 30 层 Transformer、24 头注意力、头维度 128）：

- **视频专家（Video Expert）**：预测未来视觉观测 + 未来触觉观测；
- **动作专家（Action Expert）**：基于预测结果生成动作块；
- **触觉专家（Tactile Expert）**：读取实时触觉图像，与缓存比对，输出 delta 动作进行修正。

不对称掩码使动作查询可以关注所有视频与动作 token，而视频查询只能关注视频 token。

**2.2 两阶段推理流程**

1. **基础模型规划阶段**（Stage 1 产物）：视频专家与动作专家对含噪的未来观测和动作块运行条件流匹配去噪，生成规划动作块 $\hat{a}$，此过程约 628 ms；
2. **预填充缓存（Cache Prefill）**：对去噪完成的视频潜在变量与动作块，在流时间 τ=0 额外再跑一遍前向，存储每层的触觉键值（KV）与动作键值（KV）作为缓存 C（约 63 ms）。**关键细节**：不使用最后一步去噪时的 KV（仍是带噪的），而是额外跑一遍保证缓存表征的是"干净"的预测。只缓存触觉与动作 token，不缓存视觉 keys；
3. **实时触觉修正**：每一帧新触觉图像到达时，将其输入触觉专家，与缓存 C 进行注意力比对，输出未被执行的剩余动作的逐步 delta 动作 $\Delta a$（约 30 ms）。修正采用的是**异步方案**——机器人继续执行已提交的动作，修正只写入尚未执行的区块。

**2.3 触觉专家的单遍修正机制**

- 触觉专家的查询序列 = 当前触觉图像 $I_m$（经冻结的视频 tokenizer 编码）+ 更新后的计划块（前 m 个动作替换为实际执行指令并附上"已执行/未执行"的状态嵌入）；
- 输出残差动作：$\Delta a = f(I_m, \hat{a}, m, C)$，最终动作为 $\hat{a} + \Delta a$；
- 每个修正都是基于原始计划块 $\hat{a}$ 叠加，而非基于上一个修正结果，避免虚假修正的级联传播；
- 延迟补偿：给定延迟窗 d（动作步数），修正写入自 m+d 起的未执行步骤。实测d 绝大多数情况为 0。

**2.4 两阶段训练**

- **Stage 1（基础模型）**：训练视频与动作专家，损失为视频流匹配损失 + 动作流匹配损失；
- **Stage 2（触觉专家）**：冻结 Stage 1 所有参数，仅训练触觉专家（从动作专家初始化）。每个训练批次中：
  - 用冻结的基础模型规划一个动作块；
  - 从每个片段采样 K=4 个执行偏移 m；
  - 损失只监督仍可修正的后缀部分：$L_{tac} = \frac{1}{H-m}\sum_{i\ge m} \|\hat{a}_i + \Delta a_i - a_i\|^2$。

**2.5 核心设计优势**

- 单次修正 = 触觉专家一次前向遍历固定缓存，无需重新访问视频流或去噪过程，比重新生成一个动作块便宜 **20.7×**（30.4 ms vs 628.6 ms）；
- 与 T-Rex（无预测的触觉反应修正）的关键对比：TacPAC 的触觉专家能看到"计划预期接触什么"，从而能区分接触偏差的方向与性质。注意该差异在消融中为平均 17 个百分点（47% vs 64%）。

### 6. 主要结论与发现

1. **总体性能**：TacPAC 在全部 5 项任务上超过所有基线（π0.5、ACT、VITaL、LingBot-VA、Dream-Tac、T-Rex），平均成功率 64%，较最强基线 T-Rex（48%）高出 16 个百分点；较纯视觉基线（π0.5，36%）和纯视觉 WAM（LingBot-VA，28%）大幅领先；完整系统平均成功率 64%，显著优于几乎所有基线。
2. **触觉预测不足（Q2）**：将触觉预测加入视频预测目标只能将成功率从 22%（视觉-only WAM）提升至 37%，仅为总增益（至 64%）的约三分之一。数据证据：触觉接触转换仅占 4.9% 帧数，却承载 18.6% 的总触觉变化，稀疏且发生在动作块计划之后——无法影响已规划动作。
3. **组件必要性（Q3）**：每条通路均不可少：
   - 去掉触觉专家（保留预测）：37%；
   - 去掉触觉预测（保留修正）：33%；
   - 去掉缓存预测触觉准入（保留触觉修正、预测、计划）：47% → 完整版 64%。**触觉缓存对正确解释反馈贡献最大（+17 点）**。
   - 尤其值得注意的是：无缓存的反应式触觉修正，在两个易损任务（薯片 60%→45%、水果 30%→25%）上反而比视觉基线更低，表明无预期的触觉反馈可能将行动拉离正确轨迹。
4. **实时性（Q4）**：单次触觉修正仅 30.4 ms（≈33 Hz），较重新生成块（628.6 ms）快 20.7×；仅 1.6% 调用中机器人推进 ≥1 控制步超出修正返回，未观察到由修正产生的运动抖动。

### 7. 优点与亮点

1. **问题视角独特**：明确识别出"触觉预测与动作修正之间的时间错配"这一此前 WAM 工作未正视的问题，并提出了"缓存预测的触觉作为修正参照"这一通俗但有效的工作思路；
2. **架构设计优雅**：不增加训练复杂度——阶段 2 只训练一个模块，且修正路径复用阶段 1 的缓存，单遍注意力无需重跑视频预测；由于单个分块内所有的 K=4 偏移共享一次冻结前向，训练效率高；
3. **实验设计有因果性**：消融矩阵构造清晰——视觉-only → 预测-only → 修正-only → 全系统，每一级加一个组件，逐一验证因果贡献；
4. **"反直觉"的消融结果具有说服力**：视觉-世界模型上加预测只提升 15 点；反应式修正无预测提升 11 点；两者叠加加缓存达到 64%——说明组合远超部分之和，佐证了互补性结论；
5. **工程严谨性**：明确处理异步控制时序（先执行/执行中/待修正三段）、延迟窗 d、触觉 token 的 tokenizer 一致性、缓存采用"干净"预测而不是带噪最后一个去噪步等细节；
6. **诚实而完整的数据科学诊断**：对触觉活动稀疏性的统计来自 284,948 帧的真实 episode，并讨论了 HEVC 编码码率对活动测量的影响、边界标签选择对效果的保守方向等，证据链透明。

1. **泛化性证据有限**：
   - 仅在单一机械臂（Flexiv Rizon 4）、单一触觉传感器（InTac S1）上评测，未展示跨平台/跨传感器迁移能力；
   - 任务均为单臂桌面操作拾取、插入、搬运之类，无双手协调或移动操作场景；未展示策略对新物体的零样本/少样本泛化能力。
2. **规模与统计显著性**：
   - 每个方法仅 20 次试验（尤其对插卡、瓶子翻转等差异较小的对比，单次实验误差带较大），缺乏多重种子或置信区间报告；
   - 现象描述没有做统计检验（如不同方法平均成功率差别显著性）也缺少对按任务分组成功率的置信区间。
3. **模型规模与预训练差距**：
   - TacPAC 没有经过大规模预训练，与动辄数亿至数十亿参数的 SOTA VLA 相比，"无预训练仍能赢"隐含的主要推力不明（是方法还是任务规模）；
   - 没有与大规模预训练的触觉-世界模型直接对比（T-Rex 等基线同样非大规模预训练方法），对方法的可扩展上限未知。
4. **触觉全局建模天然缺失**：
   - 动作块只有 1.6 秒（3 个潜在视频帧），无法直接解决需要长时触觉记忆的操作（例如整条装配流程中已经出现过多次接触偏差且相互影响的情况）；
   - "不缓存视觉 tokens"的假设（画面在分块内不变）对快速运动或遮挡频繁的复杂任务不成立。
5. **任务间难度不均匀导致平均分的可解释性有限**：
   - 薯片搬运（90%）明显偏易、空瓶竖立（40%）偏难，5 个任务的算术平均可能掩盖方法在具体子任务上的差异模式。
6. **缺少对失败的深度分析**：
   - 没有提供典型失败模式（如反复修正振荡/错误修正引入了新误差）的定性案例，这让"实时修正上行增益"的机理描述略欠深度。

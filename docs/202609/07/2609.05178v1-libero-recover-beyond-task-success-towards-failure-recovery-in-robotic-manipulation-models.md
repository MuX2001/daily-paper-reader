## 摘要
视觉-语言-动作（VLA）或世界动作（WAM）模型近来在机器人操作中展现了显著性能。在LIBERO基准上，最先进的方法已实现接近100%的成功率，这似乎表明这些模型已准备好部署到现实世界中。然而，在现有基准上近乎完美的表现可能具有误导性：理想条件下的成功并不等同于现实世界的鲁棒性。现有基准主要评估从预定义初始状态开始的任务完成情况，而现实世界中的交互不可避免地涉及失败，如抓取失败、碰撞和意外物体移动。因此，机器人不仅要成功执行任务，还要识别并从失败中恢复以继续任务。然而，这一能力在很大程度上尚未被衡量，揭示了基准性能与现实世界可靠性之间的关键差距。为弥补这一差距，我们引入了LIBERO-Recover Benchmark，这是一个用于机器人操作故障恢复的大规模基准。基于LIBERO，我们从最先进的具身模型中收集真实执行失败，并构建了跨越四个恢复级别的1000多个场景：（1）动作重试，（2）动作适应，（3）物体状态恢复，以及（4）环境恢复。我们评估了四项核心能力：空间理解、物体结构推理、交互理解和拓扑推理。作为首个用于具身故障恢复的大规模基准，LIBERO-Recover将评估从“机器人能否成功？”转向“机器人在失败后能否恢复？”，从而推动鲁棒且可泛化的具身智能体。项目将在https://liulin815.github.io/LIBERO-Recovery/上提供。

## Abstract
Vision-Language-Action (VLA) or World Action (WAM) models have recently demonstrated remarkable performance in robotic manipulation. On LIBERO, SOTA method have achieved nearly 100\% success rates, seemingly suggesting that the models are ready for deployment in real world. However, near perfect performance on existing benchmarks can be misleading: success under ideal conditions does not imply real world robustness. Existing benchmarks primarily evaluate task completion from predefined initial states, while real world interactions inevitably involve failures such as failed grasps, collisions, and unintended object movements. A robot must therefore not only execute tasks successfully, but also recognize and recover from failures to continue the task. Yet this capability remains largely unmeasured, revealing a critical gap between benchmark performance and real world reliability. To address this gap, we introduce LIBERO-Recover Benchmark, a large scale benchmark for failure recovery in robotic manipulation. Built upon LIBERO, we collect real execution failures from SOTA embodied models and construct 1,000+ scenarios across four recovery levels: (1) Action Retry, (2) Action Adaptation, (3) Object State Recovery, and (4) Environmental Recovery. We evaluate four core capabilities: spatial understanding, object structure reasoning, interaction understanding, and topological reasoning. As the first large-scale benchmark for embodied failure recovery, LIBERO-Recover shifts evaluation from \emph{Can the robot succeed?''} to \emph{Can the robot recover after failure?''}, promoting robust and generalizable embodied agents. The project will be avaible in \textcolor{blue}{https://liulin815.github.io/LIBERO-Recovery/}.

## 1. 论文核心问题与整体含义

论文的作者指出，虽然 Vision-Language-Action（VLA）和 World Action Model（WAM）这类机器人操作模型在基准测试上取得了非常亮眼的成果，例如在 LIBERO 基准上最先进的模型成功率已接近 100%，但现实世界的部署并不理想。因为现有评测通常假设“单次执行、理想初始状态”，而真实场景中机器人会经历许多失败，比如抓取失败、碰撞、物体被意外移动等。即便有少数新基准（如 LIBERO-Plus、LIBERO-X）引入了更多的环境变化，核心评估仍然停留在“预定义初始状态下能否完成任务”的传统框架内。换句话说，现有基准多半衡量的是模型在分布偏移下的**泛化能力**，而没有系统衡量模型在**由于自身执行失败而导致状态偏离**之后，理解和恢复状态并继续完成原始任务的能力。此论文认为，这是“成功率高但真实世界可靠性差”问题的一个关键症结所在。

论文的目标是把评估从“机器人能否成功？”推向“机器人失败后能否恢复？”，提出一个专门的失败恢复基准——LIBRO-Recover。该工作认为，失败恢复能力应是衡量模型能否投入真实部署的核心能力之一。

## 2. 论文提出的方法论

LIBRO-Recover 方法的核心思想可以概述为：不采用手动干扰场景/物体状态来合成失败，而让真实的 VLA/WAM 模型在仿真环境里去执行任务，通过这种方式自然产生失败和由此导致的场景状态变化。进而让数据标注模型（Qwen3.5-VL）结合视频时间轴做失败定位，最后形成一套分级恢复基准。

具体来说：

- 问题定义上，论文将执行过程划分为“失败前轨迹”和“失败恢复轨迹”：
  - 一个原始任务由语言指令 l 定义，从初始状态 s0 出发的策略产生一段轨迹 τ = (s0, a0, s1, a1, …, sT)。
  - 常规情况下，期望策略一直执行直至时刻 T，且目标条件满足 G(sT, l)=1。
  - 失败恢复问题则是设在中间某个时间点出现状态 sf，此时 G(sf, l) ≠ 1，且若直接沿用原策略 πθ，则无法达成目标。只有在失败后采取新的“恢复策略”πrec 作用于后续状态，才有希望达到 G(sT, l)=1。
- 失败定义公式上，论文用一个三条件逻辑公式 F(st, at, sf) 进行刻画：状态转移是由**执行引起的**（并非环境外来变化）、状态是**任务相关的非目标状态**、如果继续执行当前策略则**计划失效**，从而不再是普通的状态变化，而是需要特殊“恢复行为”的失败。
- 恢复难度分级体系：
  - L1：Action Retry（动作重试）——失败没有改变物体或任务状态，只需重复失败动作。
  - L2：Action Adaptation（动作适应）——物体状态已有有限偏离，但物体仍可直接使用，只需对着当前观察去调整下一步动作。
  - L3：Object State Recovery（物体状态恢复）——物体状态被实质改变，必须先恢复到原来需要的位置/位姿等，然后才能重组任务继续。
  - L4：Environmental Recovery（环境恢复）——失败影响了非直接任务目标的物体，但影响了随后操作；因此需要先推理场景和物体的交互拓扑关系，移除或还原堵塞因素，才能完成任务。
- 场景构建流程：
  - 第一阶段（Failure Generation）：使用六个模型在 LIBERO 的多个任务套件上执行不同任务，在没有任何人为注入干扰的情况下自然收集失败轨迹。
  - 第二阶段（Temporal Failure Localization）：让 Qwen3.5-27B-Instruct 看整个任务的视频，定位失败发生的区间，将视频分为失败前、失败发生时和失败后三部分，并从模拟器中提取实际状态和物体位姿信息。
  - 第三阶段（Failure Characterization）：让大模型观察失败后轨迹的视频和指令，基于分类学标定失败类型/难度等级。
- 为了能让模型学会恢复，该工作额外由 4 名遥操作员用 SpaceMouse（6D 控制）提供了 3,184 条恢复轨迹数据。

## 3. 实验设计：数据集、基准设置、方法对比

- 论文基于 LIBERO 基准任务（LIBERO-Spatial、LIBERO-Object、LIBERO-Goal 和 LIBERO-100 中的 LIBERO-10/LIBERO-90）构建数据集，覆盖 130 个子任务。
- 数据集最终包含 2,117 个（或文中多处写 2,178 个，存在不同表述）失败恢复场景，涵盖四个难度层级，且评价包括 RSR（Recovery Success Rate）、RD（Recovery Degradation，恢复退化）和 RC（Recovery Consistency，恢复一致性）等指标。
- 对比的模型包括传统的 VLA 模型：OpenVLA-OFT、π0-Fast、GR00T-N1.5、π0，以及 WAM 类模型：Wan2-Policy 和 Cosmos-Predict2-Policy。
- 实验在有轻微初始位置偏移的 10 次运行下进行，并以人类平均完成时间乘以一个与环境困难程度相关的系数为时限。
- 将标准 LIBERO 测试与 LIBERO-Recover 测试放在同一批模型下对比，并以多层标注体现模型在 L1—L4 上的恢复成功率及恢复到不同阶段的表现。

## 5. 实验数量与充分性分析

上述评估已涉及较广的实验广度，但仍存在值得进一步检验的方面：

- 运行模型范围占优：从 π0/OpenVLA 到 GR00T/WAN/Cosmos 都包括了主流开源/半开源策略，对评估结论的可靠性有益。
- 特别值得注意的是“混合训练”和“时序提示”两个实验，能观察到为恢复而训练对 LIBERO 的影响不明显（说明存在转移缺口），初始帧的时序提示对恢复有较大帮助，这类探索是普通基准所不提供的分析。
- 但评分标准（例如任务目标 G）判定是否有隐蔽的信息泄漏、标注时大模型是否可能因运动轨迹噪声误判失败区间，以及数据是否存在真实交互中常见但 LIBERO 环境无法模拟的物理现象（如物体形变、粘连）都需要读者保持谨慎。
- 实验结果主要基于仿真环境：LIBERO 有着固定背景和仿真刚体动力学，对物体碰撞和交互后的状态没有真实世界的复杂性；因此从“真实世界恢复能力”角度去推广结论需要更多真实机器人实验支撑。
- 失败生成模型只有三个（模型加其微调形式），数量仍然有限，且由于是训练于 LIBERO 上的模型，失败模式可能出现系统性偏差而在不同的模型分布上不再可靠。

总体而言，论文在仿真覆盖面上是足够的，实验架构适当、对照组设计也合理，但在真实设备上和其它模型作为失败源的可扩展性仍是短板。

## 6. 论文的主要结论（重要发现）

- 关键发现 1：常规 LIBERO 任务成功率高的模型在失败场景下不一定表现较优，例如 Wan2-Policy 在 LIBERO-100 上原本超过 GR00T-N1.5，但失败场景下反而更低。
- 关键发现 2：VLA/WAM 模型对局部纠正（L1/L2）尚有一定成功率，对状态恢复（L3/L4）大幅退化，说明它们缺少结构推理和场景记忆能力。
- 关键发现 3：失败会导致“复合偏移”（compounding distribution shift），成功率和状态质量随时间逐步下降；最低在 LIBERO-100 套件上模型恢复成功率只有 0.3%，表明多次重试反而让状态更难恢复。
- 关键发现 4：WAM 型策略复现一致性更高，论文推测这与世界模型对状态转移的建模有关；VLA 则主要从成功轨迹中学习动作条件映射而不学习如何应对失败后状态。
- 关键发现 5：减小动作块尺寸（Action Chunk Size）有利于恢复成功率。4 个动作步比 32 个步更好恢复；动作块太大时，策略更新频率低，修正延迟导致更难恢复。
- 关键发现 6：将 LIBERO-Recover 数据加入训练可提升恢复评测效果，但对标准 LIBERO 成功率几乎无帮助，说明恢复能力的迁移仍然不足，暴露了“失败恢复转移缺口”。
- 关键发现 7：加入时序上下文（如任务初始帧作为提示），有助于恢复，因为策略可以感知当前状态与预期状态的偏差。

## 7. 优点与突出亮点

- 学术角度而言，它提出了一种不同于传统“状态扰动”的失败数据建立方式：从执行者的真实失败中获取失败状态的天然分布，失败类型和频率均来自模型自身行为，而非人为制造。
- 定义了层次化且精细的失败恢复分类学（L1—L4），并基于四个任务套件和 16 个评价维度去系统量化模型恢复能力，这种构架可迁移到多类型的模拟/真实评测。
- 将“常规任务执行”与“失败恢复”在模型性能上剥离开来，清晰反映出“高成功率并不代表强恢复能力”，对 VLA 研究中一味追逐 LIBERO 高分的现状提出了有价值的警示。
- 分析方法有一定深度：不只是提供一个评测集，还在消融层面分析动作块大小、混合训练、时间提示及轨迹分布，从而对失败恢复的改进策略提供新证据。

## 8. 需要指出的不足与局限性

细节层面有几类不足：

- **仅局限仿真环境（LIBERO, MuJoCo）**，物体的几何和物理性质简单，失败模式不及真实世界复杂，毕竟没有流体、衣物等难处理对象，也没有力控、柔顺控制带来的高维恢复需求。
- **失败来源有限**：LIBERO-Recover 的失败轨迹仅来源于少量模型（文中说模型集合，但图中只展示 π0、GR00T、OpenVLA、Cosmos 等），并不能覆盖实践中所有失败模式，结论的“通用性”受制于失败源。
- **使用大模型做自动标注带来的语义风险**：Qwen3.5 对失败区间边界的判断可能有一定误差，可能存在某些场景被误分类为 L3/L4；以及标注数据的人为判据没有做信度校验（如多标注者一致性测试），主观标签风险没有被讨论。
- **任务数量有限制**：LIBERO 任务动作虽多样，但主要范围在平面操作和抓取/移动类场景中，不适合代表所有长期任务模式（例如双臂协调或装配类任务）。
- **恢复成功仍按最终原始目标评判**：忽略了部分恢复或战略放弃场景，没有对任务结束后不可恢复状态的“可塑性”进行建模。
- **对模型 “为什么” 能恢复的分析不足**，包括对 WAM 高一致性的解释停留在推测上，缺少更深入潜在表征分析或干预性实验（如屏蔽状态预测分支等）来证实因果。
- **成本/可持续性信息不透明**：对于算力总量、推理频率，以及让 Qwen3.5 标注整个数据集的计算开销均没有报告，给复现与资源评估带来不便。

总而言之，LIBERO-Recover 是一个有价值、结构清晰且具前瞻性的评测设计，尝试把“失败恢复”作为机器人模型评测中一个核心研究方向独立出来；它的限制更多反映在现阶段模拟基准的共性困难上，而非方法粗制滥造，期望真实硬件上的后续工作能进一步验证其可迁移性。

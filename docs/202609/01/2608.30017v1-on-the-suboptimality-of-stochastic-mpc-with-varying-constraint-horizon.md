## 摘要
在模型预测控制（MPC）中，在整个预测时域内强制执行随机状态约束可能计算量很大。本文研究无终端约束的随机MPC，其中机会约束仅在较短的约束时域内强制执行。利用随机松弛动态规划，我们推导了平均期望闭环成本的一个显式上界，该上界同时依赖于预测时域和约束时域。对于具有仿射机会约束和有界均匀扰动的线性二次问题，我们通过坐标变换和约束收紧提供了确定性重构。仿真实验说明了计算工作量与性能之间的权衡。

## Abstract
Enforcing stochastic state constraints over the full prediction horizon in Model Predictive Control (MPC) can be computationally demanding. Here we study stochastic MPC without terminal ingredients in which chance constraints are enforced only over a shorter constraint horizon. Using stochastic relaxed dynamic programming, we derive an explicit upper bound on the average expected closed-loop cost that depends on both prediction and constraint horizons. For linear quadratic problems with affine chance constraints and bounded uniform disturbances, we provide a deterministic reformulation via coordinate transformation and constraint tightening. Simulations illustrate the trade-off between computational effort and performance.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：模型预测控制（MPC）通过在有限时域内反复求解带约束的最优化问题来近似无限时域最优控制问题。当系统中存在随机扰动时，施加完整的随机状态约束（机会约束）会导致优化问题计算量剧增，难以实时应用。
- **核心问题**：如果不在整个预测时域上强制机会约束，而只在一个较短的“约束时域”（constraint horizon）上强制执行，那么闭环性能会损失多少？如何理论量化这种次优性？
- **研究空白**：
  - 确定性 MPC 在无终端约束、变约束时域情况下的性能保证已有研究。
  - 随机 MPC 与分布鲁棒 MPC 在无终端约束、变约束时域情况下，缺少相应的闭环成本上界分析；已有结果通常只针对固定的约束时域。
- **整体意义**：本文填补了这一空白，为“缩短约束时域以降低计算负担”这一工程做法提供了理论上的次优性界，从而指导预测时域和约束时域的选择，实现计算量与性能之间的权衡。

## 2. 方法论：核心思想、关键技术细节与公式/流程

### 2.1 问题设定

- 系统模型：  
  \(x_{k+1} = f(x_k, u_k, w_k)\)，其中 \(w_k \in W \subset \mathbb{R}^d\) 为 i.i.d. 随机扰动，\(W\) 紧致。
- 控制策略：采用非预期（non-anticipative）马尔可夫策略；输入满足硬约束 \(u_{i|k} \in U\)。
- 状态机会约束：  
  \(\mathbb{P}\{x_{i+1|k} \in X \mid x_{i|k}\} \ge 1-\varepsilon\)，仅在预测时域的前 \(N-\tilde{N}\) 步（即约束时域）上强制执行；剩余的 \(\tilde{N}-1\) 步不施加机会约束。
- 目标：最小化有限时域期望成本 \(J_N(x_k, u_{N|k})\)，得到值函数 \(V_{N,\tilde{N}}(x_k)\)；闭环采用第一控制律 \(u^*_{0|k}\)。

### 2.2 主要理论结果：随机松弛动态规划（RDP）

- 核心工具：随机松弛动态规划（stochastic relaxed dynamic programming），结合了确定性变约束时域 MPC 的 set-function-difference 方法和随机 MPC 的 RDP 论证。
- 假设：  
  - Assumption 2.1：独立同分布扰动；  
  - Assumption 2.2：系统函数连续且平衡点为原点；  
  - Assumption 2.3：存在鲁棒控制不变集 \(X_\delta\)，保证递归可行性；  
  - Assumption 3.1：成本可控性（cost controllability），即约束段末端运行成本可被初始成本以指数衰减率 \(\sigma_1\) 控制，后续无约束段成本可被约束段末尾成本以速率 \(\sigma_2\) 控制。

- 关键引理（Lemma 3.1）：通过分解值函数为“约束段成本”和“无约束段成本”，给出了相邻时刻值函数期望差的上界。

- **主要定理（Proposition 3.1 + Proposition 3.2）**：
  - 若存在 \(\alpha \in (0,1)\) 和 \(c_2 \ge 0\) 使得随机 RDP 漂移条件成立：
    \[
    \mathbb{E}\left[V_{N,\tilde{N}}(x_{k+1}) \mid x_k\right] - V_{N,\tilde{N}}(x_k) \le -\alpha \ell(x_k, u^*_{0|k}) + c_2
    \]
  - 则平均期望闭环成本满足：
    \[
    \bar{J}^{\infty}_{N,\tilde{N}}(x_0) \le \frac{c_2}{\alpha}.
    \]
  - 显式的 \(\alpha\) 和 \(c_2\) 表达式为：
    \[
    \alpha = 1 - C_1 C_2 \sigma_1^{N-\tilde{N}+1}\left(\frac{1-\sigma_2^{\tilde{N}}}{1-\sigma_2}\right),
    \]
    \[
    c_2 = \max\left\{1,\; C_2\sigma_1\frac{1-\sigma_2^{\tilde{N}}}{1-\sigma_2}\right\} \sum_{i=0}^{N} \ell_i^0.
    \]
  - 该上界明确体现了预测时域 \(N\)、约束时域 \(N-\tilde{N}\)、衰减率 \(\sigma_1,\sigma_2\) 以及扰动引起的成本项 \(\ell_i^0\) 的影响。

### 2.3 线性二次问题的确定性重构

- 考虑线性系统 \(x_{i+1|k} = A x_{i|k} + B u_{i|k} + G W_{k+i}\)，二次成本，仿射机会约束，均匀有界扰动。
- 采用参数化控制律：\(u_{i|k} = v_{i|k} + K e_{i|k}\)，其中 \(K\) 使 \(A+BK\) 舒尔稳定，\(v_{i|k}\) 为决策变量。
- 坐标变换：将状态分解为条件均值（名义轨迹）\(z_{i|k}\) 与偏差 \(e_{i|k}\)，得到名义系统与偏差系统。
- 成本分解：期望成本 = 名义二次成本 + 与协方差矩阵传播相关的常数项。
- 约束收紧：
  - 输入约束：通过 Minkowski 递归构造偏差可达集 \(E_i\)，得到收紧输入集 \(V_i = U \ominus (K E_i)\)。
  - 状态机会约束：利用仿射结构将约束分解为名义项与随机残差项，对残差项使用广义 Irwin–Hall 分布求分位数，实现精确收紧。
- 最终得到等价的确定性 MPC 问题（式 (24)），可直接用标准 QP 求解。

## 摘要
潜在世界-动作模型通过在特征空间中预测与动作相关的视觉子目标来避免渲染未来像素。LaWAM确立了这一公式，但其最初的呈现使得世界模型、多模态骨干网络和部署检查点紧密耦合。我们引入了AcrossWAM1.0，这是对潜在世界-动作栈的模块化与扩展研究。我们不是将潜在子目标作为一种新算法呈现，而是明确模块边界：策略适配器产生潜在动作和动作生成上下文；保留的潜在世界解码器将预测的转移置于当前场景中；流匹配专家生成连续动作块。我们进一步将仅训练使用的教师模型与推理图分离，并提供可验证的部署导出。在2,000个配对的LIBERO情节中，将Qwen3-VL-2B骨干网络替换为Qwen3.5-0.8B，成功率分别为97.45%和98.00%（差异为-0.55个百分点；精确McNemar p=0.266）。这并不证明等价性，但满足预先指定的两个百分点的保留标准。紧凑的、推理可及的检查点包含14.726亿个唯一参数，比原始2B策略少42.4%，同时所有保留的张量都与源检查点逐位相同。跨家族执行还通过MiniCPM-V适配器冒烟测试进行了检查；闭环家族间迁移仍是一个开放评估。因此，AcrossWAM1.0为紧凑的潜在世界-动作策略贡献了一个可审计的软件和评估边界，区别于LaWAM原始的潜在子目标贡献。

## Abstract
Latent world-action models avoid rendering future pixels by predicting an action-relevant visual subgoal in feature space. LaWAM established this formulation, but its original presentation left the world model, multimodal backbone, and deployment checkpoint tightly coupled. We introduce AcrossWAM1.0, a modularization and scaling study of this latent world-action stack. Rather than presenting latent subgoals as a new algorithm, we make the module boundary explicit: a policy adapter produces latent-action and action-generation contexts; a retained latent world decoder grounds the predicted transition in the current scene;and a flow-matching expert generates continuous action chunks. We further separate training-only teachers from the inference graph and provide a verifiable deployment export. On 2,000 paired LIBERO episodes, replacing a Qwen3-VL-2B backbone with Qwen3.5-0.8B yields 97.45% success versus 98.00% for the 2B model (a-0.55percentage-point difference; exact McNemarp=0.266). This does not prove equivalence, but it meets a prespecified two-point retention criterion. The compact, inference-reachable checkpoint contains 1,472.6M unique parameters, 42.4% fewer than the original 2B policy, while all retained tensors are bitwise identical to the source checkpoint. Cross-family execution is additionally checked with a MiniCPM-V adapter smoke test; closed-loop cross-family transfer remains an open evaluation. AcrossWAM1.0 therefore contributes an auditable software and evaluation boundary for compact latent world-action policies, distinct from LaWAM's original latent-subgoal contribution.

## 2. 方法论

**核心思想**：将潜在世界-动作栈划分为职责清晰的模块，每个模块通过固定接口通信，并严格分离训练图与推理图。

**模块组成**：
- **策略适配器（Policy Adapter）**：隔离骨干网络（VLM）的特定处理逻辑，返回两类上下文（transition context 与 action context），并处理隐藏维度对齐、图像调用签名等与骨干相关的问题。
- **潜在世界解码器（Latent World Decoder）**：保留自 Stage 1，将预测的潜在动作解码为空间视觉子目标，锚定在当前场景特征空间中。
- **流匹配动作专家（Flow-DiT Action Expert）**：以流匹配（Flow Matching）方式生成连续动作块，接收骨干上下文与潜在子目标作为条件。
- **训练/推理分离**：逆动力学教师、状态解码器等模块仅存在于训练图，部署导出时被移除。

**关键公式与流程**：

- **问题形式化**（式 1）：  
  `p(a, ĥₜ₊Δ, zₜ | oₜ, ℓ, sₜ) = pθ(zₜ|oₜ,ℓ) · pω(ĥₜ₊Δ|hₜ,zₜ) · pη(a|cθ,hₜ,ĥₜ₊Δ,sₜ)`，其中 hₜ 为冻结 DINOv3 的 patch 特征。
- **Stage 1（学习动作相关的潜在世界模型）**：
  - 逆动力学 Q-Former 将当前/未来特征对压缩为 32 维潜在动作 zₜ（式 2）。
  - 潜在世界解码器用 AdaLN 调制将 zₜ 注入 transformer 块，预测未来特征（式 3–4）。
  - 训练损失：未来特征监督（L_future）+ 状态位移监督（L_state）+ KL 正则（式 5）。
- **Stage 2（从语言与视觉预测潜在动作）**：
  - 骨干通过 8 个 latent-action 查询和 8 个 flow 查询分别输出 transition 与 action 上下文；潜在动作经交叉注意力映射得到 ẑₜ。
  - 用冻结教师提取的目标 z*ₜ 进行蒸馏（L_distill，式 6），并将预测潜在子目标与真实未来特征对齐（L_subgoal，式 7）。
  - 总损失：`L = L_flow + λp·L_subgoal + λd·L_distill`（式 10），λp = λd = 0.1。
- **动作专家**：Flow Matching 训练，条件为骨干上下文 + (当前特征, 预测子目标) 拼接流；推理时用 ODE 求解器从高斯噪声积分出动作块（50 个动作 / 1.2 秒，10 步积分）。

## 6. 主要结论与发现

- **模块边界有效**：定义并实现了策略-世界-动作契约，使骨干替换只需更换适配器，无需改动世界模型与动作专家接口。
- **紧凑骨干保持性能**：Qwen3.5-0.8B 在 2,000 个配对 LIBERO 情节上达到 97.45%，仅比 2B 模型低 0.55 个百分点；差异未通过 McNemar 检验达到显著（p = 0.266）。
- **参数大幅缩减**：部署导出后唯一可推理参数 1,472.6M，比 2B 原始策略减少 42.4%（比 0.8B 原始原始权重减少 26.3%）。
- **可审计的部署**：所有保留张量与源检查点逐位相同，纯训练模块和重复别名被精确移除，导出可通过生产 CPU 加载器。
- **跨家族执行有边界**：MiniCPM-V 适配器能执行契约（前向/反向、隐藏状态对齐），但词汇表无多余嵌入行等差异暴露了可移植性的真实障碍；闭环跨家族迁移仍属开放问题。
- **语言接地仍需注意**：聚合成功率可能掩盖语言指引薄弱；CFG 变体提高了冲突指令下的遵从率，但牺牲了非冲突指令下的任务完成率。

## 7. 优点

- **模块边界显式化**：在代码层面对齐了接口、查询归属、梯度/冻结边界、训练/部署分离，而非仅停留在架构图层面。
- **评估协议严谨**：配对情节、精确 McNemar、预设保留标准、明确区分"未检测到差异"与"统计等价"，并公开了不一致情节计数（46 vs 35）。
- **部署验证粒度极高**：逐张量位比较（1,078 保留 + 321 移除 + 718 别名）提供了可审计的检查点等价证据。
- **诚实界定证据层级**：将"接口兼容性"、"闭环骨干缩放"与"冻结跨家族迁移"明确分层，且只声称达到前两级。
- **对既有工作的态度端正**：不把 LaWAM 的算法和基准结果重新包装为自己的贡献，清楚标注引用来源。

## 8. 不足与局限

- **统计局限**：一个检查点/骨干无法排除训练种子差异；p = 0.266 不构成等价或非劣效证据。
- **评估覆盖窄**：闭环仅 LIBERO 单基准、单任务族（Qwen）；RoboTwin 表格中的 92.09/89.12 只是外部背景，并非本文基准结果，实验设计并未将 AcrossWAM1.0 在 RoboTwin 上的优势视为已证明。
- **跨家族结论受限**：MiniCPM-V 结果仅证明契约可执行，不证明控制质量；冻结 Dω 在异构骨干间的迁移未验证。
- **关键工程指标缺失**：无延迟、峰值内存、加速器/模拟器端到端冒烟测试。
- **语言诊断暴露权衡**：CFG 提升冲突指令遵从（52→93/190），但非冲突指令崩溃率从 1% 升至 10%，说明方法尚未解决务实语言理解问题。
- **算法贡献有限**：作者明确表示这不是新算法，而是系统与评估工作；其价值高度依赖 LaWAM 的既有公式是否正确和健壮。

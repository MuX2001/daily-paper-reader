## 摘要
固定的视觉-语言-动作（VLA）策略提供了广泛的操控技能，但以开环动作块执行，不跟踪任务进度，因此智能体无法可靠地决定是继续、重试还是终止。外部记忆是一种自然的补救措施，但当尝试的动作被视为已完成的进度时，它可能是有害的，从而将局部执行错误转变为持续的任务状态错误。我们提出成就锚定记忆（AGM），一种用于固定VLA策略的轻量级闭环框架，它将任务表示为具有进度指针的子目标序列，并且仅在当前子目标通过物理证据得到验证后才推进该记忆。本体感觉交互线索决定何时进行验证，而连贯的点跟踪和语言条件下的跨视图比较（通过一个仅2.43M参数的验证头从固定基础模型获取）决定实现了什么。因此，AGM将开环执行转换为执行、验证和进度的闭环，保持策略固定，无需测试时大模型推理。在RoboMME Counting基准上，AGM在PickXTimes上达到[具体数值]，在BinFill上达到[具体数值]，平均超过最强的记忆增强基线[具体数值]个百分点，并且该框架在物理机器人上同样产生了决定性的改进。因此，可靠的具身记忆更多地取决于有纪律的状态更新，而非记忆容量。

## Abstract
Frozen vision-language-action (VLA) policies offer broad manipulation skills but execute open-loop action chunks without tracking task progress, so the agent cannot reliably decide whether to continue, retry, or terminate. External memory is a natural remedy, yet it can be harmful when attempted actions are treated as completed progress, turning local execution errors into persistent task-state errors. We propose Achievement-Grounded Memory (AGM), a lightweight closed-loop framework for frozen VLA policies that represents a task as a subgoal sequence with a progress pointer and advances this memory only after the current subgoal is verified by physical evidence. Proprioceptive interaction cues decide when to verify, while coherent point tracking and language-conditioned cross-view comparison, sourced from frozen foundation models through a single 2.43M-parameter verification head, decide what was achieved. AGM thereby converts open-loop execution into a closed loop of execution, verification, and progress, keeping the policy frozen without test-time large-model inference. On the RoboMME Counting benchmark, AGM reaches on PickXTimes and on BinFill, surpassing the strongest memory-augmented baseline by points on average, and the framework yields equally decisive gains on a physical robot. Reliable embodied memory thus depends more on disciplined state updates than on memory capacity.

## 1. 核心问题与整体含义

- **研究动机**：冻结的视觉-语言-动作（VLA）策略（如 π0.5）具备丰富的操作技能，但默认以开环方式执行动作块，无法感知任务进度。在重复计数类任务中（如反复抓取–放置指定次数），不同阶段的视觉观测高度相似（“感知别名”），当前观测本身无法揭示处于哪一次重复，导致策略无法决定“继续、重试、回滚或终止”。
- **现有外部记忆的缺陷**：简单引入外部记忆来记录尝试次数，会把“尝试过的动作”误当成“已完成的成就”。一次抓取失败、物体滑落或释放未达到目标关系，若被写入记忆作为进度，就会把瞬时扰动固化为持久任务状态错误，甚至比“无记忆”更差。
- **核心观点**：可靠具身记忆的关键不在于“存储多少”，而在于“何时写入”。一个有序的子目标序列加上进度指针，只要每次更新都基于可观测的执行证据，就足以解决重复操作中的闭环问题。

## 2. 方法论

- **总体框架**：AGM 将任务指令确定性展开为带类型的子目标序列 \( G = \{(g_k, c_k)\}_{k=1}^{T} \)，其中 \( c_k \in \{ \text{grasp}, \text{place-rev}, \text{place-irrev}, \text{other} \} \)，并维护一个进度指针 \( p_t \)。记忆 \( M_t = (G, p_t) \) 中 \( G \) 固定，\( p_t \) 是唯一在线更新的任务状态。冻结 VLA 策略仅以当前子目标 \( g_{p_t} \) 为语言条件。
- **事件触发验证**：
  - 使用带迟滞的夹爪负载有限状态机检测交互事件（\( G^+ \) 抓取成功、\( R^+ \) 负载释放、\( R^0 \) 空释放）。
  - 兼容函数 \( \chi(e_t, c_{p_t}) \) 过滤出与当前子目标类型匹配的事件，仅在这些事件发生时触发验证（“何时验证”）。
- **抓取成就验证**：基于运动学证据，采用 CoTracker3 进行一致性点跟踪。
  - 将夹爪位置投影到前视图像，生成网格查询点，跟踪提升动作期间的轨迹。
  - 筛选可见性高的轨迹，取纵向位移前 1/3 的轨迹中位数 \( r^G_n \)，若 \( r^G_n \ge \delta_G \) 则判定抓取成功（物体随夹爪上移）。

- **记忆更新规则**：
  - 验证通过 → 指针前进 `min(p+1, T)`；
  - 验证失败 → 若子目标可回滚，则回滚到对应抓取子目标（如平面放置失败重新抓取）；不可回滚（如容器放置）则保持指针不变；
  - 抓取失败 → 指针保持不变。
  - 还有死锁保护：连续拒绝次数有上限（可恢复放置 2 次，不可逆放置和抓取 3 次），以及终止前对最近一次可恢复放置的视觉占用复查。

## 7. 优点

- **轻量高效**：只训练 2.43M 参数的验证头，外部参数约 231M 全部冻结，避免了微调 4B 级别 VLM 的昂贵成本。
- **即插即用**：保持 VLA 策略完全冻结，兼容现有 skill 组合策略，无需修改策略内部。
- **理论清晰**：将“尝试”与“成就”分离，用可观测物理证据驱动状态更新，并设计了前进、保持、回滚的指针规则。
- **实验扎实**：覆盖仿真与真实机器人，多个消融和控制实验，包含跨骨干迁移、指令解析器对照、数据分布外测试等，验证了机制的有效性与泛化性。
- **部署友好**：推理时无需大模型，验证头与点跟踪可作为独立服务，且具备故障安全语义。

## 8. 不足与局限

- **验证词汇受限**：事件定位依赖夹爪负载变化，仅能处理以抓握或释放为边界的事件（如抓取、放置）。推动、滑动、关节操作或持久握持下的工具使用无法触发验证，会被回复到冻结策略，无法提升性能。
- **任务结构假设**：假设任务为线性子目标序列，不能表达分支、部分有序或可乱序满足的子目标；回滚仅能回到当前重复的关联抓取，不是全局恢复。
- **验证质量即上限**：验证器的假阳性/假阴性会直接污染记忆，阈值不对称只是缓解而非消除这一风险。
- **死锁保护的副作用**：连续拒绝达到上限后强制推进指针，可能引入未验证的进度更新，虽然罕见且受限，但并非绝对安全。
- **物理评估范围窄**：仅在单一 6-DoF 平台、单种夹爪几何和单类物体上验证；阈值在不同平台需要重新校准，框架虽不变，但“迁移性”被限定在接口层而非参数层。
- **基准跨度有限**：只在 RoboMME Counting 上进行模拟测试，缺少更广泛 VLA 任务的评估；且文中未报告 GPU 训练成本的具体数字，资源可复现性稍显不足。

## 摘要
本文针对非线性采样数据系统，提出了一种基于Jacobian冻结仿射预测器的Taylor信息间接自适应预测控制框架。有限Taylor展开近似采样非线性动力学，递推最小二乘(RLS)在线辨识其多项式系数。在每个采样时刻，辨识映射的Jacobian在当前工作点处评估，并在预测时域上冻结，从而为模型预测控制生成仿射预测器。与通用非线性特征字典相比，所实现的多项式字典是前向Euler/Taylor结构信息约简字典。精确的联合奇对称性消除了偶总次数单项式，而额外的前向Euler信息剪枝构成了一种有意的模型约简。在不稳定非线性基准上的数值模拟比较了不同Taylor阶数。结果表明，随着工作点远离展开点，高阶模型提高了跟踪精度，同时保持了相当的控制努力。完整的MATLAB实现已公开，以促进可复现性。

## Abstract
This paper develops a Taylor-informed indirect adaptive predictive control framework for nonlinear sampled-data systems using Jacobian-frozen affine predictors. A finite Taylor expansion approximates the sampled nonlinear dynamics, and recursive least squares (RLS) identifies its polynomial coefficients online. At each sampling instant, the Jacobian of the identified map is evaluated at the current operating point and frozen over the prediction horizon, yielding an affine predictor for model predictive control. In contrast to generic nonlinear feature dictionaries, the implemented polynomial dictionary is a forward-Euler/Taylor-structure-informed reduced dictionary. Exact joint-odd symmetry eliminates even-total-degree monomials, whereas additional forward-Euler-informed pruning constitutes a deliberate model reduction. Numerical simulations on an unstable nonlinear benchmark compare different Taylor degrees. The results show that higher-order models improve tracking accuracy as the operating point moves farther from the expansion point while maintaining comparable control effort. The complete MATLAB implementation is publicly available to facilitate reproducibility.

- **核心问题**：非线性系统的预测控制往往依赖精确的机理模型，在线优化负担大，且难以适应复杂工况变化。如何利用**在线辨识**与**局部线性化**相结合，构造兼顾精度、效率与自适应能力的预测控制器，是非线性采样数据系统控制中一个关键挑战。
- **现有路径的局限**：已有非线性自适应预测方法常采用通用函数字典（如多项式、核、Fourier、样条等），其基函数与底层非线性物理结构的联系较弱，导致字典冗余、辨识参数过多且缺乏可解释性。
- **本文出发点**：不从通用基出发，而是**利用被采样系统的Taylor展开结构**及**前向Euler结构信息**，构建精简且具有明确解析意义的回归字典，在“模型精度”与“实时可计算性”之间寻求更好的平衡；同时采用**Jacobian冻结仿射预测器**使得整个非线性自适应MPC最终归结为凸QP问题，大幅降低在线求解难度。

### 2. 方法论：核心思想、关键技术细节

- **整体框架**：间接自适应预测控制——先在线辨识被控对象的输入-输出映射，再用辨识模型构建预测器，在MPC框架内求解有限时域最优控制序列。
- **Taylor近似与移位坐标**
  - 设连续系统 ẋ = f(x,u)，平衡点为 (xe, ue)，定义移位变量 x̃ = x - xe、ũ = u - ue 及 z = [x̃ᵀ, ũᵀ]ᵀ。
  - 在原点对采样动力学 F̄(z) 做有限D阶Taylor展开，写成多项式形式 F̄(z) = Θφ_D(z) + r_D(z)，其中φ_D包含总次数从1到D的所有单一与交叉单项式。
- **RLS在线辨识**
  - 每个采样周期用递推最小二乘（带遗忘因子λ）在线估计多项式系数矩阵Θ（向量化后为θ）。
  - 实际实施中，采样数据来自真实/仿真系统（本文用RK4 + 零阶保持生成过渡数据），**前向Euler方法不用于系统传播，仅用于指导字典的结构减化**。
- **Jacobian冻结仿射预测器**——本文核心创新：
  - 在每个采样时刻k，取当前工作点 z̄_k = [x̃_kᵀ, ũ_kᵀ]ᵀ；
  - 计算辨识映射 F̂_k 在该点的Jacobian并分块：J_k = [A_k  B_k]；
  - 便得仿射局部模型：F̂_k(z) ≈ c_k + A_k x̃ + B_k ũ（其中c_k用于保持截距一致性），并将Ak、Bk、ck保持固定于整个预测时域；
  - **优点**：避免了非线性系统的重复传播（无需完全非线性预测控制），保留了结构清晰的仿射模型；同时消除了对混合非线性项（如 u·y 项）作冻结处理时的任意选择歧义——Jacobian冻结自动给出与函数值和Jacobian都匹配的唯一仿射近似。
- **线性PCAC的退化情形**：当 D=1 时，c_k = 0，该控制器退化为标准的线性PCAC预测模型（论文给出形式化推论与证明）。
- **基于结构信息的字典约简**
  - **精确约简**：对满足 f(-x,-u) = -f(x,u) 的奇对称系统（本文的基准系统具备），精确采样流（以及RK4传播流）联合奇对称，Taylor展开中所有偶总次项严格为零，故可从字典中直接剔除。
  - **启发式约简**：基于前向Euler公式（而非真实/仿真的RK4采样流），只保留形式为 x^{2i+1}、x^{2i}u^{2j+1} 的单项式（总次数 ≤ D）。论文明确指出这种剪枝是**有意的模型简化**，不能保证被剔除的奇总次单项式在RK4采样流中恰好消失。
  - 本文采用 D = 1、3、5、7 四种字典，降阶效果示例：满字典 D=5 有 20 个系数，而本文精简字典仅 9 个；D=7 时从 35 减至 14。
- **MPC合成**：预测模型固定后，代价函数为状态跟踪误差、输入增量（按PCAC惯例从δu₁|k起算）、以及软约束松弛变量的加权二次型，状态约束以软约束方式加入；由于仿射模型系数被冻结，整体优化问题为凸二次规划（QP），求解简单且稳定。

### 6. 主要结论与发现

- **Taylor阶数决定实际模型质量**：在跟踪参考振幅较小时（0.25/0.55），各阶数模型精度差异不显著；当振幅增大到 0.80/0.90、系统状态运行区间扩大后，D=1（线性）预测器会产生明显更大的跟踪误差，而 D∈{3,5,7} 始终保持更低的不变误差。
- **量化结果**：整体RMSE由D=1的0.03199下降到D=5的0.03090几乎完全由分段大振幅区间的误差减少贡献。整体MAE（D=0.01418 → D=0.00958，降幅约32%）与分段稳态MAE均支持此结论。最大软约束违规在D=3/5/7 下比 D=1 降低一个数量级以上（最大违规量从 7.37×10⁻³ 降至 ~3×10⁻⁴）。
- **控制努力开销不增加**：D=3/5/7 的总输入变化量（11.75–11.86）与D=1（12.41）相近，甚至略低，说明高阶模型在提升跟踪精度的同时不会额外消耗执行机构能量。
- **联合奇对称性**对模型字典的约简在前述系统中是精确的（不引入模型失配），而前向Euler信息指导的附加剪枝是一种受控的模型简化。
- **D=7 相对 D=5 并无进一步精度增益**，表明针对该系统而言D=5已经能够基本穷尽运行区间内该字典所表示的动力学特征，存在一个“饱和”的临界阶数。

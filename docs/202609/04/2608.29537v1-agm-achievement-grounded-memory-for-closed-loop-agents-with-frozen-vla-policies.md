## 摘要
冻结的视觉-语言-动作（VLA）策略提供了广泛的操控技能，但以开环动作块执行，不跟踪任务进度，因此智能体无法可靠地决定是继续、重试还是终止。外部记忆是一种自然的补救措施，但当尝试的动作被视为已完成的进度时，外部记忆可能有害，将局部执行错误转变为持续的任务状态错误。我们提出成就基础记忆（AGM），一种用于冻结VLA策略的轻量级闭环框架，它将任务表示为带有进度指针的子目标序列，并且仅在当前子目标通过物理证据验证后才推进该记忆。本体感觉交互线索决定何时验证，而来自冻结基础模型的连贯点跟踪和语言条件的跨视图比较（通过单一的2.43M参数验证头）决定实现了什么。因此，AGM将开环执行转换为执行、验证和进度的闭环，保持策略冻结且无需测试时大模型推理。在RoboMME Counting基准上，AGM在PickXTimes上达到，在BinFill上达到，平均超过最强的记忆增强基线分，该框架在物理机器人上也产生了同样显著的收益。因此，可靠的具身记忆更多地依赖于有纪律的状态更新，而非记忆容量。

## Abstract
Frozen vision-language-action (VLA) policies offer broad manipulation skills but execute open-loop action chunks without tracking task progress, so the agent cannot reliably decide whether to continue, retry, or terminate. External memory is a natural remedy, yet it can be harmful when attempted actions are treated as completed progress, turning local execution errors into persistent task-state errors. We propose Achievement-Grounded Memory (AGM), a lightweight closed-loop framework for frozen VLA policies that represents a task as a subgoal sequence with a progress pointer and advances this memory only after the current subgoal is verified by physical evidence. Proprioceptive interaction cues decide when to verify, while coherent point tracking and language-conditioned cross-view comparison, sourced from frozen foundation models through a single 2.43M-parameter verification head, decide what was achieved. AGM thereby converts open-loop execution into a closed loop of execution, verification, and progress, keeping the policy frozen without test-time large-model inference. On the RoboMME Counting benchmark, AGM reaches on PickXTimes and on BinFill, surpassing the strongest memory-augmented baseline by points on average, and the framework yields equally decisive gains on a physical robot. Reliable embodied memory thus depends more on disciplined state updates than on memory capacity.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **背景**：视觉-语言-动作（VLA）等大规模策略可直接从视觉和语言指令生成连续动作，但微调代价高，因此常用做法是保持策略冻结，通过语言条件子目标组合其技能。然而，冻结策略无法表示任务进度这一隐藏状态，尤其在重复性/计数类操控中，不同阶段的视觉观测高度混淆（“感知别名”），仅靠当前图像无法判断当前是第几次重复。
- **核心问题**：一是开环 VLA 策略不跟踪任务进度，无法可靠决定继续、重试或终止；二是简单引入外部记忆（如“每完成一次尝试就推进进度”）会把瞬时执行失败（抓空、滑落、放置失败）误记为已完成，造成持久性任务状态错误。作者用对照实验证明，未经验证的进度记忆甚至可能比完全无进度记忆表现更差。
- **核心主张**：关键不是“存什么”或“存多少”，而是“何时才允许写入进度”。可靠的具身记忆取决于有纪律的、基于可观察证据的状态更新，而非记忆容量。为此提出 **AGM（Achievement-Grounded Memory）**，让冻结 VLA 策略获得闭环“执行—验证—推进”能力。

## 2. 方法论

### 2.1 总体框架
- 将任务指令确定性地展开为有序子目标序列 \( G = \{(g_k, c_k)\}_{k=1}^T \)，其中 \( g_k \) 是发给 VLA 的语言子目标，\( c_k \in \{\text{grasp}, \text{place-rev}, \text{place-irrev}, \text{other}\} \) 是子目标类型（决定验证事件与回滚行为）。
- 维护紧凑任务记忆 \( M_t = (G, p_t) \)：静态子目标序列 + 动态进度指针 \( p_t \in \{1,\dots,T\} \)。策略每步只看到当前子目标 \( g_{p_t} \)。
- **闭环流程**：策略执行动作块 → 本体感状态机检测“夹爪负载”事件 → 只有与当前子目标类型兼容的事件才触发验证 → 视觉验证判断是否真正达成 → 依据验证结果对指针执行推进、保持不变或回滚。

### 2.2 事件触发验证（When to Write）
- 使用滞回有限状态机 (FSM) 处理夹爪开合宽度 \( w_t \)，输出事件：`G+`（稳定负载抓取）、`R+`（负载状态下释放）、`R0`（空载释放）、`∅`。
- 兼容性过滤：只有 `G+` 对 grasp 子目标、`R+` 对 place 子目标有效；不匹配事件直接忽略。事件本身不代表成功，只代表“候选状态转换时刻”。

### 2.3 抓取成功验证：一致运动点跟踪
- 抓取成功是“物体是否随夹爪一起向上运动”的运动学问题。
- AGM 记录抓取时刻末端位置并投影到前摄像头图像，在投影点周围放 6×6 网格（36 个查询点），用冻结的 **CoTracker3** 跟踪后续抬升片段。
- 保留最终可见性 > 0.5 的轨迹，选取垂直向上位移最大的 1/3 轨迹，取中位数作为响应 \( r_n^G \)，若 \( r_n^G \ge \delta_G \)（4 px）则判定抓取成功。
- 该模块零训练，完全依赖冻结点跟踪器的输出。

### 2.4 放置成功验证：语言条件下的跨视角比较
- 放置成功是“指令要求的对象-目标关系是否成立”的语义问题。
- 从冻结的 **SigLIP**（视觉+文本编码器）提取前/腕相机释放前后窗口的视觉嵌入、释放前后差向量、本体感窗口摘要，以及由放置子目标语言导出的归一化文本查询 \( z_{q,n} \)，拼接成特征 \( f_n \)。
- 通过唯一的可训练模块——轻量 MLP 验证头 \( h_\psi \)（**2.43M 参数**）输出放置成功概率 \( s_n^P \)，与类型相关阈值 \( \kappa_c \) 比较得到判定。

### 2.5 成就基础的记忆转移规则（How to Write）
- 指针更新规则（式 21）：
  - 验证成功 → 指针前进一位；
  - 抓取失败 → 指针保持（重试抓取）；
  - 可恢复放置失败（平面目标）→ 回滚到同一重复对应的 grasp 子目标；
  - 不可恢复放置失败（容器内）→ 不可回滚，因此采用更宽松的接受阈值（0.05 vs 0.5）以及更少次数的拒绝强制推进。
- 附加机制：终止按钮前对最近一次可恢复放置做独立“视觉占用检查”；设置有限拒绝次数上限防死锁；超时与重试边界仅用于保护异常状态。
- 所有验证只针对与抓握交互锚定的子目标；其余子目标直接交给冻结策略。

### 2.6 训练方式
- 验证头在 RoboMME 训练分片的 **788 个执行事件**上离线训练，事件来源包括 AGM 自身轨迹（覆盖部署分布）和“不验证即推进”的 attempt-based 轨迹（提供缺失失败样本）。
- 训练时用环境谓词构造标签（抓升、目标区域包含、容器计数增加），测试时不可用。
- 强调“后释放窗口与部署验证时间严格对齐”，20 帧错位可使 BinFill 从 84% 降至 66%。
- 策略、点跟踪器、VLA 后端全部冻结，只更新验证头参数。

## 3. 实验设计

### 3.1 Benchmark 与数据集
- 仿真：**RoboMME Counting** 基准套件，含四个任务：PickXTimes、BinFill、SwingXTimes、StopCube。
  - 测试分片 50 episodes/任务，种子训练/测试严格分离。
  - 成功标准：在 1300 步预算内按下停止按钮且计数精确符合指令。
- 真机：同一房地的 PickXTimes 与 BinFill，每任务 10 次 × 计数 N=1..5 共 50 trials。

### 3.2 对比方法
- 基线包括：冻结 π0.5、π0.5+past actions、SAM2Act+、SimpleSG（Qwen3-VL-4B LoRA 或 Gemini-2.5-Pro 提示）、MemER（4B VLM 微调记忆检索）。

### 3.3 主要实验结果
- 四任务平均成功率 AGM 55.96%，超过最强基线 MemER（48.83%）7.1 分，接近冻结 π0.5（28.78%）的两倍。
- PickXTimes 达到 **100.00%**，BinFill 达到 **84.00%**，均为新 SOTA。
- SwingXTimes 和 StopCube 非夹爪锚定子任务，AGM 按构造与冻结策略持平（35.56% / 6.67%），无退化。
- 按重复次数 N 分解：π0.5 在 N=5 时跌到 0%，而 AGM+π0.5 在 PickXTimes 每个 N 都保持 100%；BinFill 大 N 时逐渐下降（N=5 为 66.7%），但残差来自物理放置困难而非进度计数错误。

### 3.4 消融实验（Q3）
- 用“本体感+末端抬升”替代 CoTracker 点跟踪验证：PickXTimes 98.0%、BinFill 78.0%；完整 CoTracker 版本 100.0%、84.0%，即视觉运动验证提供额外边际增益。

## 6. 主要结论与发现

1. **尝试 ≠ 成就**：将操纵尝试直接写入进度会带来比无记忆更差的性能；只有被物理证据支持的写入才可靠。
2. **AGM 是轻量有效方案**：冻结 VLA + 冻结点跟踪器 + 冻结 SigLIP + 训练仅 2.43M 验证头，即可将开环策略变为闭环任务智能体。
3. **任务进度比短期动作上下文更重要**：π0.5 + 过去动作上下文几乎无提升（29.09% vs 28.78%），AGM 则通过持久指针彻底解决计数漂移。
4. **不同验证语言适配不同基础模型**：抓取验证用点跟踪（运动学证据），放置验证用语言条件跨视角比较（语义证据）。
5. **可恢复性决定阈值策略**：平面放置可重抓，用严格阈值+回滚；容器放置不可逆，用宽松阈值+防误拒。
6. **真机验证一致**：物理机器上 PickXTimes 全 N 保持 100%，BinFill 高重复次数残差来自物理难度而非进度错误。
7. 总结性观点：对长程自主智能而言，决定性问题不是“智能体有多少记忆”，而是“什么证据使之有权写入记忆”。

## 7. 优点

- **问题识别精准**：明确指出外部记忆的一种反直觉失败模式（非验证写入使瞬时错误持久化），并用对照实验证明其存在。
- **“何时写”优于“写多少”的视角新颖**：将记忆设计从容量/检索转移到写入纪律，思想简洁有力。
- **冻结友好、低成本**：不使用测试时 VLM 推理，不微调 VLA 后端；仅训练一个极小头部。
- **模块化使用成熟基础模型**：CoTracker3 承担零训练运动验证，SigLIP 承担可泛化语义验证，充分利用冻结能力。
- **闭环机制完整**：包含兼容性过滤、事件触发验证、类型感知阈值、回滚/重试/死锁保护、终止前检查，工程细节完整，具备实际部署价值。
- **跨情境验证充分**：仿真多任务、不同重复深度、跨骨干迁移、真机部署均一致支持核心结论。
- **消融设计有解释力**：通过对比验证写入 vs 未验证写入在两个任务上的差异，准确刻画出方法适用边界（感知别名越明显，验证越关键）。

## 8. 不足与局限

- **验证词汇限于抓握事件**：只有可被夹爪负载变化包围的子目标受 AGM 支持；推、滑、铰接物体、持续握持下的工具使用等不会触发验证，AGM 会退回冻结策略（所以 SwingXTimes/StopCube 无改进）。
- **任务状态是线性序列而非图**：无法表达分支计划、部分有序子目标、乱序完成；回滚也只能回到同一重复的抓取子目标。可恢复性在指令展开时静态设定，不能感知物体意外不可达等情况。
- **终止边界仍存在折衷**：死锁保护用“强制推进”换取活性，可能把验证死锁转化为少量进度错误；并不能保证“永不出现未验证写入”。
- **验证器质量直接成为瓶颈**：假阳性写入假进度，假阴性浪费预算并触发重复；阈值不对称只缓解不可逆一侧风险，无法根除。
- **资源/算力报告不透明**：未提供 GPU 型号、集群规模或运行时间，复现便利性有限。
- **真机范围较窄**：仅一个 6-DoF PCB 平台、单一夹爪几何、小型彩色立方体与固定容器/目标板；论文承认已标定阈值不保证跨平台迁移，需重新标定。
- **统计完整性**：部分消融和中间表为单次运行（如 50 episodes），AGM 主结果虽平均两次，但没有给出方差/置信区间；文字描述此类运行只有 few 个失败事件时，结论方向明确，但数值稳定性未量化。
- **核心 benchmark 结构单一**：RoboMME Counting 以重复计数为主，无法完全代表“部分可观测 → 长程决策”的全部场景；更复杂、更开放的机器人任务仍待验证。

## 9. 总结句
该论文以“写入纪律”替代“记忆容量”为中心，提出成就基础记忆（AGM），用轻量验证头把冻结 VLA 策略从开环执行升级为闭环“执行→验证→推进”的机器人控制器，并在仿真与真实机器上证明：可靠的具身记忆，首先是证据约束下的状态更新纪律。

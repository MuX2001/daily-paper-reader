## 摘要
当固定视角使任务相关信息被遮挡或未被观测到时，主动感知对于机器人操作至关重要。然而，使视觉-语言-动作（VLA）模型能够跨变化视角进行推理并主动获取信息丰富的观测仍然具有挑战性。我们提出 ActiveScale，一个通过模型、数据和硬件协同设计推进主动感知的框架。我们的模型通过历史视频观测和显式相机位姿监督增强 VLA，使用逐帧位姿 token 和轻量级预测头来关联跨视角观测，并支持对场景的连贯理解。为了从人类活动中自然存在的相机运动中学习，我们引入了一种可扩展的人-机器人中期训练方案，使用 1000 小时的第一人称视角和机器人数据，使模型适应时序输入和位姿监督。我们进一步提出主动感知移动操作平台（Active-perception Mobile-manipulation Platform, AMP），这是一个通过单人遥操作支持主动感知和移动操作的机器人平台，能够可扩展地收集协调视角变化与操作的演示数据。实验表明，在主动感知任务上成功率有所提高，同时消融研究验证了相机位姿感知建模和第一人称视角中期训练的贡献。这些组件共同为研究和开发机器人操作中的主动感知提供了集成基础。

## Abstract
Active perception is essential for robotic manipulation when fixed viewpoints leave task-relevant information occluded or unobserved. However, enabling vision-language-action (VLA) models to reason across changing viewpoints and actively acquire informative observations remains challenging. We present ActiveScale, a framework that advances active perception through coordinated model, data, and hardware designs. Our model augments a VLA with historical video observations and explicit camera-pose supervision, using per-frame pose tokens and a lightweight prediction head to associate observations across viewpoints and support a coherent understanding of the scene. To learn from the camera motion naturally present in human activity, we introduce a scalable human--robot mid-training recipe using 1000 hours of egocentric and robotic data, adapting the model to temporal inputs and pose supervision. We further introduce Active-perception Mobile-manipulation Platform (AMP), a robotic platform that supports active perception and mobile manipulation through single-operator teleoperation, enabling scalable collection of demonstrations that coordinate viewpoint changes and manipulation. Experiments demonstrate improved success rates on active-perception tasks, while ablation studies validate the contributions of camera-pose-aware modeling and egocentric mid-training. Together, these components provide an integrated foundation for studying and developing active perception in robotic manipulation.

## 1. 核心问题与整体含义

- **研究动机**：机器人操作中，固定视角的观测往往是"部分可观测"的——目标物体可能被柜子、背包、桌子遮挡，或位于默认视野之外。机器人必须像人一样主动调整自身视角（例如转头查看碗内、背包内部）来获取任务相关信息。静态感知已不足以支撑通用机器人智能体，**主动感知（Active Perception）** 成为关键能力。

- **现有工作的三大不足**：
  - **模型层面**：现有 VLA（视觉-语言-动作模型）缺乏推断自身相机位姿、并据此预测后续相机运动的能力；而后者恰恰依赖前者。
  - **数据层面**：第一人称（egocentric）人类数据天然包含头部相机运动，是学习主动视角先验的宝贵信号，但现有方法未能有效利用。
  - **硬件层面**：多数研究在静态环境中验证主动感知（如 SAPAVE、ActiveMimic），与真实动态、杂乱的移动操作场景之间存在显著鸿沟；且缺乏统一的基础设施来系统研究"模型—数据—硬件"三者的协同。

- **整体含义**：论文提出 **ActiveScale**，从模型、数据、硬件三个维度协同推进主动感知，试图为"机器人主动观测 + 移动操作"提供一个可扩展的集成基础。核心贡献为三点：位姿锚定的时序 VLA、1000 小时人-机中期训练配方、以及单人遥操作平台 AMP。

## 2. 方法论

### 2.1 核心思想
在 VLA（以 π0.5 为基座）的视觉输入中引入**历史帧序列**，并为每帧附加一个可学习的**相机 token**，通过辅助相机头显式监督其预测相机位姿与视场角，从而让模型在跨视角条件下建立对持久 3D 场景的连贯理解；同时把相机运动纳入动作空间，与双臂操作联合生成。

### 2.2 问题形式化
- 学习语言条件策略 π_θ：在时刻 t，给定观测 o_t 与语言指令 ℓ，预测未来动作块 a_{t:t+K−1}。
- 观测 o_t 包含视觉观测与非视觉状态上下文 s_t（本体感知、运动学等）。
- 每个动作 a_τ 联合指定左、右操作末端执行器与主动相机的笛卡尔位姿，以及两个夹爪命令，全部表达在共享的机器人中心坐标系 F_U 中。

### 2.3 模型架构
- **基座**：π0.5，由 PaliGemma VLM + 轻量 Transformer 动作专家组成。
  - 动作专家用 **流匹配（flow matching）** 预测连续动作块：构造 x_τ = τϵ + (1−τ)a，目标速度 u_τ = ϵ − a，损失 L_flow = E‖v_θ(x_τ, τ, c) − u_τ‖²。
  - 保留 π0.5 的自回归 token 预测目标：高层预测子任务（交叉熵 L_subtask），低层用 FAST 将未来动作轨迹离散为 token 并自回归预测（L_FAST）。
- **相机 token（关键设计）**：
  - 输入为当前前视相机观测加三个历史观测（间隔 16 帧）：H_ft = (I_{ft−48}, I_{ft−32}, I_{ft−16}, I_ft)。
  - 每帧经共享视觉编码器编码后追加一个可学习相机 token；最早有效帧用 c_first，后续帧用 c_rest。
  - 前缀组织为 [V_{ft−48}, c1, …, V_ft, c4, V_lt, V_rt, E(ℓ, s_t)]，其中 V 为视觉 token，E(ℓ, s_t) 为语言与本体状态 token。
  - 采用**块因果注意力**：每个时间块只能关注自身与更早历史，相机 token 不能访问未来帧；后续腕部相机、语言与动作 token 可关注所有有效相机历史块。
  - 每个相机 token 的隐藏状态经线性投影送入 **VGGT 风格相机头**，预测 9 维表示：3D 平移 (x, y, z)、四元数朝向 (q_x, q_y, q_z, q_w)、垂直与水平视场角 (fov_y, fov_x)。
  - 监督损失：L_cam = L_trans + L_rot + λ_fov·L_fov，其中三项均为逐分量 ℓ1 损失，λ_fov = 0.5。该辅助头在动作推理时被移除。

### 2.4 训练配方（两阶段）
- **阶段一：人-机中期训练（Human–Robot Mid-training）**
  - 从预训练 π0.5 检查点出发，在 **1000+ 小时**第一人称人类数据与机器人数据上联合训练。
  - 人类数据：EgoLive、EgoVerse，筛选室内家庭操作片段，优先保留与下游任务语义相关的活动；机器人数据：AgiBot World、RoboCOIN、AMP，覆盖多种本体与控制分布。
  - 人类与机器人演示按 **1:1 平衡比例**采样。
  - 人类演示中，头部相机位姿提供主动视角监督，腕部轨迹提供操作监督；参照 ActiveMimic，将人类相机与腕部轨迹重新表达在每个时间窗口内最早有效观测的相机坐标系中；机器人轨迹保持在固定机器人参考系中。
  - 各数据源分别归一化状态与动作，并对不可用的动作维度与相机位姿目标做掩码。
  - 混合批训练目标：L_co = L^H_subtask + λH(L^H_FAST + L^H_flow) + L^R_FAST + L^R_flow + λC·L_cam，其中 λH = λC = 0.2，各项仅在对应监督可用时计算。
- **阶段二：任务特定后训练**
  - 在 AMP 遥操作演示上微调，保持架构与动作表示不变。
  - 损失：L_post = L_flow + λC·L_cam（λC = 0.2），不使用自回归子任务与 FAST 目标（因为后训练数据直接提供目标本体上对齐的机器人动作与主动相机轨迹）。

### 2.5 硬件平台 AMP
- 基于改造的 AgileX Cobot-Magic：差速驱动移动底座 + 两条 6-DoF Piper 操作臂（各配 Orbbec DaBai DC1 相机） + **第三条 6-DoF Piper 臂**用于主动视角控制（末端亦配 Orbbec DaBai DC1 相机）。
- **遥操作**：Meta Quest 2 头显 + 两个手持控制器。头显控制中间相机臂，左右控制器控制对应操作臂；通过固定轴变换把追踪位姿映射到机器人控制约定，采用相对位姿映射（∆p、∆R）与逆运动学跟踪，重新接合遥操作时重锚参考以避免跳变。控制器扳机控制夹爪，左控制器 X/Y 按钮旋转底座，右控制器 A/B 按钮前后驱动底座。
- **数据采集**：30 Hz 同步记录三路 RGB、相机内参、畸变参数、分辨率、三臂关节反馈与控制命令；位姿表达在随平台移动的机器人中心坐标系 F_U 中（原点沿中间臂 z 轴下移 0.25 m），得到 23 维状态 s_t = [U_ξL_t, U_ξR_t, U_ξC_t, γL_t, γR_t]；移动底座平面运动单独记录为 b_t = (v_t, ω_t)。

## 3. 实验设计

- **任务套件（Benchmark）**：五个真实世界任务族，覆盖两类视角挑战：
  - **遮挡驱动操作**：Bag（从背包内取出瓶子）、Drawer（开抽屉取物放盘并关抽屉）、Table（取桌下物体放入指定标签箱）。
  - **主动搜索与定位**：Pot（从货架取指定蔬菜放入锅中并盖盖）、Box（从货架取指定物体放入左/右目标箱）。
- **评价协议**：每个任务族使用 **150 条演示**做后训练；每种方法在匹配条件下做 **20 次真实世界 rollout**；报告严格任务成功率（SR）与任务进度（TP，按阶段加权计分，例如 Bag 为抓背包 0.3 / 抓瓶 0.3 / 放桌上 0.4）。
- **对比方法**：主要对比 **π0.5**（当前 SOTA 真实世界操作 VLA）——基线直接从预训练 π0.5 检查点在任务演示上后训练，ActiveScale 则先中期训练再后训练。作者说明未与近期主动感知 VLA（如 SAPAVE、ActiveMimic）直接对比，原因是它们未公开检查点与完整训练配方。
- **消融实验**：
  - **中期训练消融**：ActiveScale（w/o Mid-training）vs 完整模型，验证人-机中期训练贡献（Q2）。
  - **历史与相机 token 消融**：原始 π0.5、仅加历史帧、历史帧+位姿锚定相机 token 三组对比（Q3）。
- **效率实验**：采用 OpenVLA-OFT 的吞吐指标，启用 RTC 时在单张 RTX 4090 上以 264.5 Hz 生成 50 动作块，异步执行支持 30 Hz 连续控制（Q4）。
- **平台演示**：单人遥操作完成多阶段移动操作任务（主动查看抽屉取蔬菜 → 转向定位烹饪区 → 移动底座前往 → 放菜入锅并盖盖）。

- **实验组数概览**：
  - 主实验：5 个任务族 × 2 种方法 × 20 次 rollout = 200 次真实世界 rollout。
  - 中期训练消融：5 任务 × 2 变体 × 20 次 = 200 次 rollout。
  - 历史/相机 token 消融：5 任务 × 3 变体 × 20 次 = 300 次 rollout。

- **充分性评价**：
  - **优点**：真实世界 rollout 而非仅仿真，任务设计覆盖容器遮挡、铰接物体遮挡、桌下视野、多阶段视角切换、大范围垂直搜索等多种视角需求，具备较好的生态效度；消融层次清晰，分别隔离了训练配方与模型设计。
  - **局限**：每个任务仅 20 次 rollout，样本量偏小，成功率差异的统计显著性未做检验；所有评估都在单一机器人平台（AMP）上进行，未跨本体验证；基线只有 π0.5，缺少与已发表主动感知方法的直接数值对比（尽管作者给出了"未公开检查点"的理由）。
- **公平性**：ActiveScale 与 π0.5 基线使用相同的任务后训练数据与评测协议，这一点是公平的；但 ActiveScale 额外使用了 1000 小时中期训练数据，属于"数据优势"而非纯架构优势，需结合消融（w/o Mid-training）来区分贡献——作者确实提供了这一消融。

## 6. 主要结论与发现

- **主动感知性能（Q1）**：ActiveScale 在全部五个任务族上同时提升 SR 与 TP，平均 SR 从 30.0% 提升至 **70.0%**，平均 TP 从 41.6% 提升至 **78.4%**。提升在目标初始隐藏或位于默认视野外时最显著：Table 从 10% → 85%，Bag 从 40% → 55%，Drawer 从 35% → 75%，Box 从 50% → 85%，Pot 从 15% → 50%。
- **人-机迁移（Q2）**：中期训练整体提升下游性能（平均 SR 62.0% → 70.0%，TP 67.7% → 78.4%），但各任务幅度不一；Pot 上 TP 提升而 SR 不变，定性观察显示中期训练后的策略盖盖对齐更好、释放前犹豫更少——说明中期训练可改善中间执行质量，

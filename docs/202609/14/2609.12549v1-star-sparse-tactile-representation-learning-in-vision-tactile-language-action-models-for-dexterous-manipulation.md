## 摘要
灵巧操作需要协调的多指控制与有效的触觉反馈，然而由于缺乏大规模真实世界数据，以及从稀疏触觉信号中提取有效表征的困难，学习这些能力仍具挑战性。我们构建了一个机器人平台与遥操作系统，收集了一个 200 小时的双臂灵巧操作数据集，包含同步的视觉、触觉和语言标注，涵盖 65 个任务的 10,576 条轨迹，其中 69.5% 涉及灵巧多指操作。我们进一步提出 STAR，一种面向视觉-触觉-语言-动作（VTLA）模型的集成训练方案，通过视觉-触觉联合预训练、稀疏全局触觉 token 表征和稀疏未来触觉预测，解决触觉信号在空间、时间和信息上的稀疏性。在该数据集上训练后，STAR 在四个真实世界任务上取得了 61% 的平均成功率，每个任务使用 100 条后训练轨迹，展示了任务特定后训练下的灵巧操作性能。

## Abstract
Dexterous manipulation requires coordinated multi-finger control and effective tactile feedback, yet learning these capabilities remains challenging due to the lack of large-scale real-world data and the difficulty of extracting effective representations from sparse tactile signals. We build a robot platform and teleoperation system to collect a 200-hour bimanual dexterous manipulation dataset with synchronized visual, tactile, and language annotations, comprising 10,576 trajectories across 65 tasks, 69.5% of which involve dexterous multi-finger manipulation. We further propose STAR, an integrated training recipe for vision-tactile-language-action (VTLA) models that addresses the spatial, temporal, and informational sparsity of tactile signals through visual-tactile joint pre-training, sparse-global tactile token representation, and sparse future tactile prediction. Trained on this dataset, STAR achieves a 61% average success rate across four real-world tasks with 100 post-training trajectories per task, demonstrating dexterous performance under task-specific post-training.

## 2. 方法论

### 2.1 问题建模
- 目标为建模 \(p(a_t|o_t)\)，观测 \(o_t=\{I_t, T_t, s_t, l_t\}\)（多视角图像、双手触觉、本体状态、语言指令），动作为长度 \(H\) 的动作块。
- 采用**条件流匹配（flow matching）**：训练速度场 \(v_\theta(a_t^\tau, o_t, \tau)\)，损失为 \(\mathcal{L}_{FM}=\mathbb{E}\|v_\theta(a_t^\tau,o_t,\tau)-(a_t-\epsilon)\|_2^2\)；插值动作 \(a_t^\tau=(1-\tau)\epsilon+\tau a_t\)，\(\tau\) 采自 shifted beta 分布。
- 推理时缓存观测前缀的 KV，用 **10 步前向欧拉**积分生成动作。

### 2.2 数据与平台（Sec. IV-A）
- **硬件**：双臂轮式移动机器人 + 两只 **10-DoF 灵巧手**，覆盖 **268 维压阻式触觉传感器**（掌心与手指内侧接触面，指边缘未覆盖）；2 个腕部相机（640×528）+ 1 个头部相机（1280×800）。
- **遥操作**：骨架式数据手套 + 追踪器；采用 **DexPilot** 重定向算法并做三项改进——调整手套 URDF 指尖位置匹配灵巧手、**加入朝向约束**（联合优化指尖位置与朝向）、**关闭自动握拳机制**；用 C++ 实现并接入多进程流水线以提升响应性。
- **数据集**：**200 小时**真实双臂灵巧操作数据，**10,576 条轨迹、65 个任务**，**69.5% 需要多指灵巧操作**，20% 为抓放/插入等基础技能，10% 为长时序组合任务；视觉、触觉、本体状态、动作、人工标注的任务级语言指令统一同步至 **30 Hz**。

### 2.3 STAR 训练方案（三大组件）

**(a) 视觉–触觉联合预训练（VTP）**
- 将触觉表示为图像（268 taxel，非 taxel 区域补零），与对应腕部图像配对，两模态各随机掩码 **75%** patch，拼接后送入共享融合编码器做联合掩码 token 预测（参考 M2VTP/MAE）。
- 关键动机：纯触觉预训练会因空间稀疏而退化为"预测全零"的平凡解；引入视觉上下文后，全零预测变得次优，从而迫使触觉编码器学到更有效表征并实现跨模态对齐。
- 损失为 patch 级归一化重建误差 \(\mathcal{L}_{joint}\)（预测 patch 与归一化 GT patch 的 L2）。

**(b) 稀疏–全局触觉 token 表征（SGTTR）**
- 触觉编码器每手输出 **196 个空间 patch token + 1 个可学习全局触觉 token**（类似 CLS token，汇总整个触觉场）。
- 基于标定触觉读数构建**接触门控**：某空间 token 内任一 taxel 超过传感器特定接触阈值即视为"激活"；仅对空间 patch token 施加门控——**保留激活 token、屏蔽未激活 token，全局 token 恒保留**（门控可推广到 GelSight 等接触/变化图）。
- **非对称注意力**：全局触觉 token 不允许注意视觉/语言/动作 token，而其他 token 可以注意它；从而在保留触觉专属全局信息的同时，让其他模态按需读取触觉。

**(c) 稀疏未来触觉预测（SFTP）**
- 作为辅助任务同时用于策略微调与后训练阶段；在动作视界 \(H=50\) 上以固定预算 **5 帧**均匀分布于 \(T_S=\{10,20,30,40,50\}\)。
- 从 VLM 输出的触觉 token（排除全局 token）经左右手各自的 MLP 预测头回归未来法向力 patch，损失为 patch 级 L2（\(\mathcal{L}_{future}\)）。
- 对照变体 DFTP 预测相邻 5 帧 \(T_D=\{1,2,3,4,5\}\)，在相同监督预算下比较时间跨度。

### 2.4 训练细节
- 策略基于 **π0.5** 架构（PaliGemma Gemma-2B 视觉语言主干 + Gemma-300M action expert），JAX/Flax 实现。
- 输入序列共 **1,562 token**：3 路图像经 SigLIP So400m/14 各 256 token（共 768）；双手触觉 394 token；64 维本体状态离散化为文本（≤350 token）；动作后缀 50 token。

- 策略**微调**：200 小时多任务数据训练 **6 个 epoch**；**后训练**：任务专属示范训练 **100 个 epoch**。

## 6. 主要结论与发现

- **主结果**：STAR 在全部 4 个任务上取得最高 SR 与 TCR，**平均成功率 61%、平均 TCR 79%**（基线 π0.5 为 28%/44%，π0.5-Dex w/o STAR 为 44%/61%）。
- **数据集有效性**：GR00T N1.7-Dex、LDA-1B-Dex 相比原始版本均有提升；`Ours w/o T` 在无触觉下仍优于 π0.5，说明 200 小时灵巧数据集本身带来增益。
- **GR00T N1.7 原始权重完全失败（0% SR）**：同一步数下收敛差、手臂剧烈振荡导致不安全运动而被安全终止。
- **LDA-1B 表现偏低**（甚至不如 π0.5）：失败多源于交互位姿不精确，推测与混合人机数据的潜空间训练偏向高层表示、牺牲细粒度空间精度有关。
- **每个组件都必要**：去掉 VTP、STTR、GTTR、SFTP 中任一组件，平均 SR/TCR 均下降（如完整方法 0.60/0.78 vs w/o VTP 0.38/0.45、w/o STTR 0.33/0.44、w/o GTTR 0.30/0.41、w/o SFTP 0.53/0.69）。
- **STTR 与 GTTR 的任务偏好互补**：偏视觉的取书任务中 STTR（去冗余）更关键；偏触觉的耳机翻转任务中 GTTR（全局触觉聚合）更关键。

- **触觉作用存在任务差异**：整体提升主要来自耳机翻转（指尖有触觉覆盖）；多物体抓取中 TCR 显著高于 SR，说明触觉更多帮助完成"接触密集的子步骤"（如夹取、放置），但最终投递等环节仍受视觉定位与长时序规划制约。

## 8. 总体评价与启示

### 8.1 主要贡献
1. **数据贡献**：构建了 200 小时、10,576 条轨迹、65 个任务的双臂灵巧操作真实数据集，其中 69.5% 需要多指灵巧操作，且视觉、触觉、本体状态、动作与语言指令统一同步至 30 Hz，填补了"触觉 + 灵巧手 + 语言指令"真实数据的空白。
2. **方法贡献**：提出一体化训练方案 STAR，将三类触觉稀疏性问题（空间、时间、信息）分别对应到 VTP、SGTTR、SFTP 三个组件，形成从触觉编码器预训练到策略微调/后训练的完整链路。
3. **实证贡献**：在 4 个真实灵巧任务上系统对比了 GR00T N1.7、LDA-1B、π0.5 及其微调版本，平均成功率 61% 对基线 28%–44%，验证了数据与方案的双重有效性。

### 8.2 方法设计的亮点
- **用视觉上下文破解触觉预训练平凡解**：纯触觉掩码重建在 75% 掩码率下极易退化为"预测全零"，VTP 引入配对腕部图像后使该解次优，是解决空间稀疏的直接且优雅的思路。
- **门控 + 非对称注意力的分工设计**：空间 token 按接触激活门控以去冗余，全局 token 恒保留并禁止反向注意，既保住触觉专属全局信息，又允许其他模态按需读取，避免了"触觉污染"其他模态表示。
- **稀疏未来预测作为辅助监督**：以固定 5 帧预算在 50 步视界上均匀采样，用极低监督成本换取时间维度的表征约束；与 DFTP 的对照实验（1.67 s vs 0.17 s 跨度）提供了"监督应分散而非聚集"的实证依据。

### 8.3 客观局限与阅读建议
- 论文的核心结论建立在**单一自研平台**与**较小规模消融**之上，泛化性结论需谨慎外推；读者若关注跨具身/跨传感器迁移，应将其视为待验证假设而非既定结论。
- **算力信息缺失**使复现成本难以评估，若计划复现需自行估算 π0.5 级别主干 + 1,562 token 序列 + 200 小时数据的训练开销。
- 触觉收益的**任务依赖性**值得特别注意：论文明确显示触觉在指尖覆盖充分、接触密集的任务中收益最大，在偏视觉定位任务中收益有限，这提示实际部署时应先评估任务与传感器覆盖的匹配度，而非默认"加触觉即涨点"。
- 总体而言，STAR 是一篇"数据 + 方法 + 系统"三位一体的工作，其价值不仅在于指标提升，更在于为触觉稀疏性这一被分散处理的问题提供了统一框架，并为后续灵巧操作研究提供了可复用的数据与基线。

## 摘要
人形机器人必须利用机载本体感觉和视觉观测穿越杂乱的障碍场，然而现有方法通常处理多模态观测时未显式考虑其不同特性：本体感觉观测维度低，但受高度非线性的机器人动力学支配；而以自我为中心的视觉观测维度高、含噪且冗余。我们提出 DWMP（Dual World Model Policy，双世界模型策略），一个为人形机器人障碍穿越提供分离但互补的世界模型表示并供 actor 使用的框架。基于 Koopman 的动力学世界模型将本体感觉观测提升到一个潜在空间，其中其时间演化近似线性，从而使动力学特征更易于 actor 学习。基于 RSSM 的视觉世界模型将以自我为中心的深度观测压缩为紧凑的随机状态，同时保留与障碍相关的几何信息。学生策略接收融合后的潜在表示以生成动作，将线性化的本体感觉动力学与压缩后的视觉感知相结合。在仿真和 Unitree G1 人形机器人上的实验表明，DWMP 相比基线提升了障碍穿越性能，并支持在随机障碍布局下的真实世界部署。

## Abstract
Humanoid robots must traverse cluttered obstacle fields using onboard proprioceptive and visual observations, yet existing methods usually process multimodal observations without explicitly considering their different characteristics: proprioceptive observations are low-dimensional but governed by highly nonlinear robot dynamics, while egocentric visual observations are high-dimensional, noisy, and redundant. We propose DWMP (Dual World Model Policy), a framework that provides the actor with separate but complementary world-model representations for humanoid obstacle traversal. A Koopman-based dynamics world model lifts proprioceptive observations into a latent space where their temporal evolution is approximately linear, making the dynamics features easier for the actor to learn from. An RSSM-based visual world model compresses egocentric depth observations into compact stochastic states while preserving obstacle-related geometry. The student policy receives the fused latent representation for action generation, combining linearized proprioceptive dynamics with compressed visual perception. Experiments in simulation and on a Unitree G1 humanoid robot show that DWMP improves obstacle traversal performance over baselines and supports real-world deployment under randomized obstacle layouts.

## 2. 方法论

### 2.1 核心思想
为 actor 提供**分离但互补**的双世界模型表征：
- **Koopman 动力学世界模型**：把本体观测提升到近似线性演化的潜空间；
- **RSSM 视觉世界模型（DepthDreamer）**：把深度图压缩为紧凑随机状态并预测未来观测。

两者潜状态拼接后作为策略输入。

### 2.2 问题形式化
- POMDP 五元组 $(O, A, T, R, \gamma)$；
- 观测 $o_t=\{o^{prop}_t, o^{vis}_t\}$：本体观测含关节位置/速度、机体坐标系重力向量、基座线/角速度、目标相对位置；视觉观测为头部相机的深度图 $H\times W$；
- 动作 $a_t$ 为下肢关节目标位置，由 PD 控制器在更高频率跟踪：$\tau_t = K_p(q^{target}_t - q_t) - K_d \dot q_t$；
- 目标：学习 $\pi(a_t|o_t)$ 穿越障碍到达目标并最小化碰撞。

### 2.3 Koopman 动力学世界模型（Auto-Koopman）
- 理论基础：Koopman 算子 $K$ 作用在可观测函数 $g$ 上，$(Kg)(o^{prop}_t)=g(o^{prop}_{t+1})$；即使底层动力学 $F$ 非线性，$K$ 仍为**线性算子**。
- 实现：编码器 $\phi: S \to \mathbb{R}^{d_k}$ + 线性转移矩阵 $K\in\mathbb{R}^{d_k\times d_k}$，满足 $\phi(o^{prop}_{t+1}) \approx K\phi(o^{prop}_t)$；解码器 $\psi$ 用于状态恢复。
- 编码器首层为 **OFTL（Observation Function Transfer Layer）**，将每个输入维度映射为 $\cos(x_i), \sin(x_i), e^{x_i}$ 等观测函数值。
- 训练损失 $L_{koopman}$ = 自编码重构误差 + 潜空间线性预测误差；可通过对 $K$ 反复作用实现长时域预测。

### 2.4 RSSM 视觉世界模型（DepthDreamer）
- 结构：VAE 卷积编码器（输出后验均值与 log 方差）→ GRU 更新确定性循环状态 $z^{vis}_t$ → 先验网络（两层 MLP）→ 重参数化采样随机状态 $s_t$ → 转置卷积解码器重构深度图 + 小 MLP 预测奖励。
- 先验 $p(s_t|z^{vis}_t)$ 与后验 $q(s_t|z^{vis}_t, o^{vis}_t)$ 均为对角高斯；训练用后验，想象阶段用先验。
- 损失 $L_{rssm}$ = 观测重构 + 奖励预测 + KL 正则（系数 $\beta$ 控制信息通道容量）。

### 2.5 策略输入与训练流程
- **策略输入**：$x^{policy}_t = [z^{prop}_t;\ z^{vis}_t]$，$z^{prop}_t=\phi(o^{prop}_t)$ 提供线性可预测动力学，$z^{vis}_t$ 提供压缩障碍几何；策略为 MLP，输出高斯分布的目标关节位置。
- **模态耦合细节**：视觉世界模型的循环更新把 Koopman 潜状态当作"动作信号"输入：$z^{vis}_t = f_{rec}(z^{vis}_{t-1}, VAE(o^{vis}_t), z^{prop}_{t-1})$。
- **总损失**：$L_{world}=L_{koopman}+\alpha_{vis}L_{rssm}$。
- **两阶段 + 协同训练流程（Algorithm 1）**：
  1. **阶段一**：用特权信息（真值障碍位置/高度）训练教师策略 $\pi_{teacher}$（RL），同时采集探索数据 $D_{explore}$，联合预训练两个世界模型；
  2. **阶段二**：学生策略仅用非特权观测，输入经世界模型编码后生成动作；编码器保持可训练以适配学生观测分布，**前向传播层冻结**；世界模型在学生回放缓冲 $D_{student}$ 上在线微调；
  3. **学生损失**：$L_{student}(\theta) = -\mathbb{E}_{\pi_\theta}[\sum \gamma^t r_t] - \lambda_{bc}\mathbb{E}_{D_{teacher}}[\log \pi_\theta(a^{teacher}_t|x^{policy}_t)]$，即**奖励最大化 + 教师行为克隆**的复合目标。

## 7. 论文的贡献归纳

1. **方法论贡献**：提出按观测模态异质性"分而治之"的双世界模型框架——用 **Auto-Koopman** 处理低维非线性本体动力学，用 **RSSM（DepthDreamer）** 处理高维深度视觉，二者潜状态拼接后供策略使用，替代了以往"单一网络同时消化两类观测"的做法。
2. **技术细节贡献**：
   - 在 Koopman 编码器中引入 **OFTL（观测函数传递层）**，用 $\cos/\sin/\exp$ 等基函数显式构造可观测函数空间，提升线性化质量；
   - 设计**模态耦合机制**：将 Koopman 潜状态作为视觉世界模型循环单元的额外输入，使视觉预测能够"感知"机器人自身运动状态；
   - 提出**两阶段 + 协同训练流程**：教师探索数据预训练世界模型 → 学生阶段冻结前向层、仅微调编码器与在线更新世界模型，兼顾分布适配与表征稳定。
3. **工程贡献**：在 Unitree G1 真机上验证了该方法在随机化障碍布局下的可部署性，给出了推理时延—重构精度的权衡数据。

- **Koopman 与深度世界模型的结合**值得进一步探索：本文以"拼接 + 单向耦合"实现，未来可尝试联合训练、双向信息流或统一的潜空间对齐损失。
- **教师探索数据的再利用**：预热世界模型这一做法成本低、收益明确，可推广到其他教师-学生蒸馏流程中，缓解学生阶段数据分布偏移问题。
- **评估规范建议**：该领域后续工作应至少报告多种子均值±标准差、真机试验次数与障碍布局分布，以提升结论可信度。

## 10. 一句话总结

DWMP 通过将人形机器人的本体感觉与深度视觉分别交给 Koopman 线性动力学世界模型与 RSSM 视觉世界模型建模，再以潜状态拼接驱动策略，并配合教师探索数据预热的两阶段协同训练，在仿真与真机上均取得了优于直接蒸馏基线的障碍穿越表现，其核心价值在于"按模态特性分离建模"这一设计理念，而非某一具体网络结构。

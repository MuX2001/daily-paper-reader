## 摘要
视觉世界模型通过预测未来观测来实现机器人规划，但稠密隐状态传播和采样密集型轨迹优化会带来高推理延迟和峰值内存占用，限制了其在资源受限平台上的实时部署。现有的稀疏世界模型加速方法要么依赖无引导的 token 稀疏化，可能丢弃与规划相关的信息并限制可实现的稀疏度，要么引入沉重的辅助模块和繁琐的多阶段训练流程。在这项工作中，我们提出 Scope-WM，一种高效的视觉世界模型，它将计算范围限定到与预测相关的潜在区域和有前景的动作序列。Scope-WM 将预测相关性蒸馏到一个轻量级的动作条件选择器中，并仅对选定的紧凑 token 子集应用完整动力学预测。它使用前景状态及其变化的紧凑摘要来更新剩余 token，使背景无需昂贵的 token 间交互即可感知前景动态。在规划过程中，Scope-WM 保留并复用初始 MPC 搜索中发现的高质量动作序列，在降低的 rollout 预算下聚焦后续搜索。由此得到的流程只需一次性的选择器蒸馏，随后对稀疏世界模型进行单一联合训练阶段。在具有挑战性的 Push-T 任务上，Scope-WM 将峰值 GPU 内存占用和规划时间分别降至稠密 DINO-WM 的 18.1% 和 14.3%，对应 6.97 倍的规划加速，同时保持有竞争力的任务性能。在五个多样化视觉规划任务上的进一步评估表明 Scope-WM 具有广泛适用性。代码见 https://github.com/ChunZheng2022/Scope-WM。

## Abstract
Visual world models enable robotic planning by predicting future observations, but dense latent-state propagation and sample-intensive trajectory optimization incur high inference latency and peak memory usage, limiting real-time deployment on resource-constrained platforms. Existing sparse world-model acceleration methods either rely on unguided token sparsification, which may discard planning-relevant information and restrict achievable sparsity, or introduce heavy auxiliary modules and cumbersome multi-stage training pipelines. In this work, we present Scope-WM, an efficient visual world model that scopes computation to prediction-relevant latent regions and promising action sequences. Scope-WM distills prediction relevance into a lightweight action-conditioned selector and applies full dynamics prediction only to a compact subset of selected tokens. It updates the remaining tokens using a compact summary of foreground states and their changes, allowing the background to perceive foreground dynamics without costly token-to-token interactions. During planning, Scope-WM preserves and reuses high-quality action sequences discovered during the initial MPC search, focusing subsequent search under reduced rollout budgets. The resulting pipeline requires only a one-off selector distillation followed by a single joint training stage for the sparse world model. On the challenging Push-T task, Scope-WM reduces peak GPU memory usage and planning time to $18.1\%$ and $14.3\%$ of those of dense DINO-WM, respectively, corresponding to a $6.97\times$ planning speedup, while maintaining competitive task performance. Further evaluations across five diverse visual planning tasks demonstrate the general applicability of Scope-WM. Code is available at https://github.com/ChunZheng2022/Scope-WM.

## 一、核心问题与整体含义

- **研究背景**：视觉世界模型（Visual World Model）通过预测候选动作序列的未来观测，为机器人操作与控制提供通用规划框架。近期以 **DINO-WM** 为代表的方案，在冻结的 DINOv2 编码器提取的 patch 级特征空间中直接进行模型预测控制（MPC），实现了任务无关的零样本规划。
- **核心瓶颈**：patch 级公式化建模计算代价高昂。每个 MPC 步中，模型需对 CEM 采样出的大量候选动作序列，在长预测时域上反复传播**全部视觉 token**，导致：
  - 推理延迟高、峰值显存占用大；
  - 难以在资源受限平台上实时部署。
- **现有加速方案的不足**：
  - **无引导的 token 稀疏化**（如随机 patch 丢弃）：可能丢弃与规划相关的信息，限制可安全应用的稀疏度；
  - **沉重的辅助模块 + 多阶段训练**（如 DDP-WM 的动态定位网络与前景条件交叉注意力）：引入额外开销，训练流程繁琐。
- **更本质的问题**：高效稀疏想象不仅是"保留多少 token"，而是三个紧密耦合的决策——哪些 token 值得精确动力学预测、剩余 token 如何在不牺牲节省的前提下演化、更廉价的 latent rollout 如何转化为更高效的轨迹优化。
- **论文定位**：提出 **Scope-WM**，将计算范围化（scoped）到预测相关的潜在区域与有前景的动作序列，在 token、动力学、规划三个层级上协同分配计算。

## 二、方法论

### 核心思想
在 DINO-WM 基础上，从三个互补层级削减计算：**Distilled Relevance Selection (DRS)**、**Foreground-Delta Background Update (FDBU)**、**Elite-Bank CEM (EB-CEM)**，形成"一次性选择器蒸馏 + 单一联合训练"的简洁流程。

### 1. DRS：预测相关性蒸馏式 token 选择
- **动机**：静态注意力掩码或视觉差分启发式不足以刻画规划相关区域；相关 token 依赖当前状态、动作与预测目标，且可能包含视觉稳定但动力学重要的区域（如接触点、障碍物）。
- **教师相关性目标**：从训练好的稠密 DINO-WM 教师出发，计算全网格 latent 预测损失 $L_T$，再用**梯度×输入**评分估计每个 token 的贡献：
  $\tilde{r}_{t,i} = \|x_{t,i} \odot \partial L_T / \partial x_{t,i}\|_2$，并在帧内归一化为分布 $q_t$。
- **轻量相关性头**：将视觉特征、本体状态、动作嵌入分别经线性投影后求和，输入小型 MLP $g_\phi$ 输出 logit $s_{t,i}$，经温度缩放 softmax 得到预测分布 $\pi_t$。
- **训练目标**：最小化 $q_t$ 与 $\pi_t$ 的 KL 散度（$L_{DRS}$）；蒸馏后选择器冻结。
- **推理**：按预测相关性选取 top-K token，得到前景掩码 $m_{t,i}$ 与前景/背景集合 $F_t, B_t$。
- **设计要点**：利用冻结 DINOv2 patch token 已具备的全局上下文，无需额外 ViT 式掩码生成器，开销可忽略。

### 2. FDBU：前景-增量背景更新
- **动机**：仅更新前景、保持背景不变会导致 latent 不一致（物体运动、接触、遮挡、相机帧变化）。而注意力式背景更新模块会抵消稀疏收益并需分阶段训练。
- **流程**：
  1. 稀疏动力学预测器仅对前景 token 做完整预测（Transformer 注意力代价从 $O((HN)^2)$ 降至 $O((HK)^2)$）；
  2. 计算前景增量 $\Delta^F_{t+1,i}$，分别对预测前景状态与前景运动做均值池化，得到 $\bar{z}^F_{t+1}$ 与 $\bar{\Delta}^F_{t+1}$；
  3. 融合为前景动力学上下文 $c_{t+1}$；
  4. 对每个全网格 token，用轻量 MLP 预测残差更新 $u$ 与标量门 $\gamma$，仅对背景施加门控残差更新 $\tilde{z}^B_{t+1,i} = z_{t,i} + \alpha(1-m_{t,i})\gamma_{t+1,i}u_{t+1,i}$；
  5. 将前景预测散射回全网格，与背景更新合成完整预测。
- **训练**：与稀疏世界模型共用全网格 latent MSE 损失联合优化，**无需独立训练阶段**。

### 3. EB-CEM：精英库 CEM
- **观察**：低采样区间增加样本数可显著提升成功率，但很快饱和；后续 MPC 步恢复能力有限，一旦早期动作进入不利状态难以挽回。因此**提升早期候选动作序列质量比每步增加采样更重要**。
- **机制**：
  - **前置搜索预算**：初始 MPC 步 $M_{front}=300$，后续 $M_{later}=100$；
  - **持久精英库**：初始步 CEM 最终迭代的最优 $M_b=30$ 条序列存入精英库 $B$；
  - **后续重规划**：每次 CEM 迭代中，$\eta=0.7$ 的样本在库内精英附近做高斯扰动局部精化，剩余 30% 全局采样；
  - 候选集合为局部与全局样本的并集，兼顾局部精化与全局探索。
- **互补性**：DRS/FDBU 降低单次 rollout 成本，EB-CEM 重新分配跨 MPC 步的搜索预算。

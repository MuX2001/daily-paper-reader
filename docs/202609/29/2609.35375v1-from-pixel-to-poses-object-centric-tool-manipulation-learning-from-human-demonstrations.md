## 摘要
扩大机器人操作规模的主要瓶颈在于真实世界机器人数据的稀缺。尽管近期方法利用人类视频演示来缓解这种短缺，但它们仍然计算开销高昂，并且仍依赖配对的人-机器人数据来进行域对齐。虽然当前最先进方法在长时程任务上表现出色，但它们在复杂工具操作所需的精细且精确控制方面仍力不从心。为克服这些局限，我们提出 P2P-T，即从像素到位姿的工具操作，一个数据高效、以对象为中心的框架，可直接从人类演示中学习工具使用。P2P-T 通过两阶段方法弥合认知与物理执行之间的差距。首先，预训练一个以对象为中心的世界模型以提取稳定的位姿先验；其次，将这些先验集成到一个高效、位姿感知的底层策略中。通过利用由现代基础模型驱动的鲁棒自动化数据处理流程，P2P-T 完全绕过了对人类-机器人对齐数据的需求。这大幅降低了总体训练开销。凭借最少的每任务微调，我们的框架在复杂真实世界工具操作任务上，执行性能相较此前最先进方法提升了 73%，而这些任务目前仍超出标准大规模预训练模型的能力范围。

## Abstract
Scaling up robotic manipulation is primarily bottlenecked by the scarcity of real-world robot data. While recent approaches leverage human video demonstrations to mitigate this shortage, they remain computationally expensive and still rely on paired human-robot data for domain alignment. Although current state-of-the-arts excel at long-horizon tasks, they struggle with the delicate and precise control required for complex tool manipulation. To overcome these limitations, we introduce P2P-T, from Pixel to Poses for Tool Manipulation, a data-efficient, object-centric framework that learns tool use directly from human demonstrations. P2P-T bridges the cognitive and physical execution gap through a two-stage approach. First, pretraining an object-centric world model to extract stable pose priors; second, integrating these priors into an efficient, pose-aware low-level policy. By utilizing a robust automated data processing pipeline powered by modern foundation models, P2P-T completely bypasses the need for human-robot aligned data. This reduces overall training overhead drastically. With minimal per-task fine-tuning, our framework achieves a 73% improvement over the previous state of the art in execution performance on complex, real-world tool manipulation tasks that currently remain out of reach for standard large-scale pretrained models.

## 2. 论文提出的方法论

### 2.1 核心思想

- **关键洞察**：人类手与机器人手在形态上根本不同，但操作特定工具所需的空间轨迹是一致的。因此，P2P-T 将任务相关工具隔离出来，独立于具体 embodiment 建模其空间动力学。
- **两阶段架构**：
  - **Stage 1**：预训练以对象为中心的世界模型，提取稳定、抽象的 6D 工具位姿先验。
  - **Stage 2**：将位姿先验注入姿态感知的低层扩散策略，实现精确的真实世界执行。

### 2.2 自动化数据预处理流水线

- 输入：原始视频序列 \( V = \{I_1, \dots, I_N\} \)。
- 三步流程：
  1. **2D 掩码提取**：使用 Grounded-SAM 隔离目标工具，生成二值分割掩码 \( S_t \)。
  2. **3D 网格重建**：将多视角 RGB 帧和掩码输入 SAM 3D，提升为高保真工具网格 \( M = (V, F) \)。
  3. **6D 位姿跟踪**：FoundationPose 对齐网格与原始序列，计算精确 6D 工具位姿 \( p_t \)。
- 最终输出配对的 \( (I_t, p_t) \) 样本，经人工验证后形成数据集；人工验证阶段整体丢弃率为 27%。

### 2.3 位姿表示

- 工具状态表示为 6-DoF 位姿，即相对相机坐标系的齐次变换矩阵 \( P_t \in SE(3) \)：
  \[
  P_t = \begin{bmatrix} R_t & T_t \\ 0 & 1 \end{bmatrix}
  \]
  其中 \( T_t \in \mathbb{R}^3 \) 为工具质心 3D 位置，\( R_t \in SO(3) \) 为 3D 朝向。
- 训练时展平为 16 维向量：\( p_t = \text{vec}(P_t) \in \mathbb{R}^{16} \)。
- **选择矩阵表示而非四元数或欧拉角的原因**：避免四元数的符号歧义（\( q \) 与 \( -q \) 表示同一旋转）以及欧拉角的角度回绕和奇异点问题；矩阵元素随旋转连续变化，提供无歧义、连续的回归目标，避免振荡训练行为。

### 2.4 Stage 1：以对象为中心的世界模型预训练

- **输入**：RGB 观测 \( I_t \)、语言指令 \( c \)、工具位姿 \( p_t \)。
- **自回归预测**：在 \( H-1 \) 个未来步上预测位姿潜变量和视觉潜变量：
  \[
  \{Z^{\text{pose}}_{t+k}, Z^{\text{vis}}_{t+k}\}_{k=1}^{H-1} = F_\theta(I_t, c, p_t)
  \]
- **解码**：分别用位姿头和帧预测头解码：
  \[
  \hat{p}_{t+k} = D_{\text{pose}}(Z^{\text{pose}}_{t+k}), \quad \hat{I}_{t+k} = D_{\text{frame}}(Z^{\text{vis}}_{t+k})
  \]
- **架构**：基于 Transformer 的多模态融合架构；视觉使用冻结的 DINOv2 和 SigLIP 编码器，语言使用冻结的 T5 编码器；视觉特征、语言特征和当前工具位姿投影到共享潜空间，加入可学习模态嵌入，与可学习融合 token 拼接后由自回归 Transformer 处理。
- **损失函数**：
  - 位姿回归损失：
    \[
    L_{\text{pose}} = \frac{1}{H-1}\sum_{k=1}^{H-1}\|\hat{p}_{t+k} - p_{t+k}\|_2^2
    \]
  - 辅助帧预测损失：
    \[
    L_{\text{frame}} = \frac{1}{H-1}\sum_{k=1}^{H-1}\|\hat{I}_{t+k} - I_{t+k}\|_2^2
    \]
  - 总损失：\( L_{\text{stage1}} = L_{\text{pose}} + \lambda L_{\text{frame}} \)，其中 \( \lambda = 0.01 \)，以位姿学习为主，视觉预测起正则化作用。

### 2.5 Stage 2：姿态感知后训练

- **基础模型**：从预训练 RDT 骨干网络初始化低层动作专家。
- **位姿潜变量获取**：冻结的 Stage-1 模型根据当前 RGB 观测 \( I^c_t \)、语言指令 \( c \) 和当前工具位姿 \( p_t \) 输出未来位姿潜变量：
  \[
  \{Z^{\text{pose}}_{t+k}\}_{k=1}^{H-1} = F^{\text{pose}}_\phi(I^c_t, c, p_t)
  \]
- **适配器**：共享可训练 MLP 将每个位姿潜变量 token 投影到 RDT 嵌入空间：
  \[
  U^{\text{pose}}_{t+k} = \text{MLP}_p(Z^{\text{pose}}_{t+k})
  \]
  按时间顺序拼接后插入到机器人本体感受状态 token \( s_t \) 之前。
- **扩散策略**：训练为条件扩散模型，预测动作块 \( a_{t:t+H-1} \)，条件包括位姿潜变量序列、本体感受状态、多视角 RGB 历史和语言指令。
- **训练细节**：Stage-1 模型、T5 和 SigLIP 编码器冻结；仅优化 RDT 动作专家和位姿适配器。使用 DDPM 调度器加高斯噪声，采用样本预测方式训练动作专家恢复干净动作块：
  \[
  L_{\text{act}} = \mathbb{E}_{D,n,\epsilon}\left[\|a_\theta(\tilde{a}_n, U^{\text{pose}}_t, s_t, I_t, c, n) - a_{t:t+H-1}\|_2^2\right]
  \]
- **推理**：Stage-1 模型生成未来位姿潜变量序列，动作专家基于投影 token 用 DPM-Solver 快速采样动作块，以滚动时域方式执行。

## 6. 论文的主要结论与发现

- **执行性能大幅领先**：P2P-T 平均成功率达 **0.57**，显著优于最强基线 π0.5（0.33），平均提升 **73%**。
- **通用 VLA 模型的失败模式**：π0.5 等模型虽能较好完成初始抓取，但缺乏对功能几何的显式知识，在交互阶段持续失败，难以完成工具正确朝向和功能工作位置所需的精细 SE(3) 空间操作（如对齐锤头）。
- **World Action Models 的局限**：FastWAM（0.02）和 Lingbot-VA（0.21）在工具使用场景表现不佳，100 条演示不足以完成完整任务适应；推理速率也较低（10 Hz 和 8 Hz，对比 P2P-T 的 30 Hz）。
- **消融结论**：
  - 仅将 Stage-1 世界模型接标准 DP2-DINOv2 策略效果差（Hammer 0.12、Cup 0.14），说明缺乏定制姿态感知架构时标准策略无法充分利用几何先验。
  - 仅用 FoundationPose 当前位姿条件化微调 RDT 达 0.32/0.36，仍不足，说明隐式 2D 视觉特征和当前位姿信息不足以完成精细工具对齐。
  - 两阶段协同达 0.59/0.60，证明 Stage-1 世界模型提供的鲁棒位姿先验能有效桥接高层功能理解与低层执行。
- **扩展性**：性能随模型容量持续提升（Small 0.41 → Base 0.60 → Large 0.66），更大模型对几何变化（手柄长度、重量）和动态扰动泛化更好，动作轨迹更平滑鲁棒。

- **单一机器人 embodiment**：受劳动力和算力限制，评估仅限 UR10e + 二指夹爪，未涉及多指灵巧手，限制了方法在更复杂工具操作上的验证。
- **大规模参数 regime 未探索**：最大仅验证到 2.83B 参数

，与当前主流 VLA / 世界模型动辄 5B–10B 以上的规模相比仍属中等，尚未验证继续扩大是否能带来边际收益，或是否会像通用 VLA 一样出现"规模上去但精细几何控制仍不改善"的瓶颈。
- **训练成本透明度不足**：论文既未披露 P2P-T 两阶段的 GPU 型号、数量与训练时长，也未给出数据处理流水线的总耗时与人工验证成本，使得"数据高效"这一核心卖点缺少可量化的资源对照。
- **基础模型级联的误差传播**：Stage-1 的数据质量完全依赖 Grounded-SAM → SAM 3D → FoundationPose 的串行流水线，任一环节在遮挡、快速运动、镜面/透明工具材质或手部遮挡下失效，都会污染位姿标签；27% 的整体丢弃率说明这一风险实际存在，但论文未分析被丢弃样本的分布特征（是否集中在某类工具或某类动作）。
- **6D 位姿表示的固有表达瓶颈**：以单一刚体 6-DoF 位姿描述工具，隐含假设工具为刚性且内部自由度固定。对于钳子、剪刀、美工刀等**铰接/可变形工具**，以及需要双手协同的工具使用，该表示无法刻画其内部构型状态，方法适用边界因此被限定在单刚体工具上。
- **统计严谨性不足**：所有成功率均为点估计，未报告置信区间、标准差或多次随机种子的方差；50 次试验下 0.57 与 0.33 的差距虽看似显著，但缺少显著性检验支撑，消融表中 0.59 vs 0.60 这类差异更难以判定是否超出噪声。
- **泛化性验证缺失**：未测试对**训练中未出现的工具类别**的零样本/少样本泛化能力，也未评估跨场景（不同桌面高度、光照、背景）与跨相机配置的鲁棒性；位姿定义在相机坐标系下，更换相机或改变外参是否需要重新标定与再训练，论文未讨论。
- **抓取与操作阶段的耦合未被解耦分析**：任务要求模型先抓取随机放置的工具、再调整至功能工作位姿。论文将二者纳入同一成功率指标，未区分"抓取失败"与"抓取成功但交互失败"的归因，削弱了对失败模式诊断的精细度。
- **评估任务规模有限**：6 个任务虽覆盖敲击、倾倒、清扫、拧转、切割、舀取等代表性动作，但每个任务仅一种工具实例、一种物体配置，尚不足以支撑"通用工具操作"的结论。
- **部分强基线不可比**：FUNCTO、SPOT 等专用工具操作方法因未开源而被排除在统一协议之外，使得"超越现有工具操作方法"的论断缺少最直接的对标证据。

## 9. 可复现性与开放性问题

- **可复现的有利因素**：
  - 方法各模块（Grounded-SAM、SAM 3D、FoundationPose、DINOv2、SigLIP、T5、RDT）均为公开或已有工作，架构拼接路径描述清晰，损失函数、超参与适配器插入位置均有明确公式与说明。
  - 两阶段训练目标解耦，Stage-1 冻结后 Stage-2 仅训练动作专家与位姿适配器，理论上便于独立复现与调试。
- **可复现的不利因素**：
  - 自采集的人类演示视频未说明是否公开，TACO 之外的 17 类工具数据分布仅以长尾统计呈现，缺少数据获取与筛选准则的细节。
  - 关键训练超参（学习率、batch size、训练步数、优化器配置）在正文中未系统给出，仅对比方法有说明。
  - 位姿适配器的 MLP 维度、位姿潜变量 token 数量与 RDT 嵌入维度的对齐方式等实现细节缺失。
- **开放问题**：
  1. 位姿先验与视觉潜变量之间的信息分工究竟如何？辅助帧预测损失（λ=0.01）的作用是正则化还是确有增益，缺少对应消融。
  2. Stage-1 世界模型能否直接用真实机器人数据继续预训练以进一步提升精度？
  3. 当工具被完全遮挡或离开视野时，自回归位姿预测是否仍稳定？论文未讨论长时遮挡下的退化行为。

## 10. 总体评价与定位

- **贡献性质**：P2P-T 属于"表示设计 + 数据流水线"驱动的系统级工作，其核心创新不在于全新的网络结构，而在于**把工具的空间动力学从 embodiment 中剥离出来**这一建模视角，并用两阶段潜变量接口落地。
- **相对优势**：在数据效率（无需人-机器人对齐数据）、推理效率（30 Hz）与真实世界复杂工具操作成功率（0.57 vs 0.33）三项指标上同时占优，且展示了清晰的规模扩展趋势，工程完整度较高。
- **主要短板**：算力与数据透明度不足、统计严谨性欠缺、评估规模偏小、刚体位姿假设限制了工具类型的覆盖范围。
- **适用场景判断**：方法最适合**单刚体手持工具 + 固定相机 + 单一机器人本体**的工业或家庭辅助操作场景；对于铰接工具、双手协同、可变形物体操作，需扩展位姿表示（如引入关节角或部件级位姿）后才可能适用。
- **一句话总结**：P2P-T 用"以对象为中心的世界模型 + 姿态感知扩散策略"证明了一条不依赖人-机器人对齐数据、低成本习得工具操作能力的可行路径，但在规模、统计与泛化验证上仍留有明显空白，属于方向明确、证据初步但尚未封顶的工作。

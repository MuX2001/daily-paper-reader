## 摘要
进度奖励建模旨在估计机器人行为如何随时间推移改变任务进度。可靠的估计需要将有意义的状态变化与失败尝试和任务无关动作区分开来。我们提出智能体奖励系统（ARS），一种利用通用视觉语言模型（VLM）进行进度奖励建模的推理框架，无需额外的奖励模型训练。给定一条离线轨迹和任务指令，ARS 使用自适应视觉检查来进行事件提议和验证。一个子智能体提出与任务相关的事件时间线，主智能体在估计逐帧进度之前对其进行验证和修正。ARS 可以纳入可选的最终结果标签和视觉参考，以辅助其判断。它还可以审核来自外部奖励模型的进度估计。我们使用一个 27B 的 VLM 在受控的语义不匹配基准上评估 ARS，并在仿真和真实机器人上评估其下游策略学习。该基准表明，即使在简单的拾放场景中，若干被评估的奖励基线也会对错误物体的操作赋予虚假的进度。ARS 能更好地抑制这些错误，并在仿真策略学习中优于这些基线。我们进一步证明，ARS 支持从混合质量的离线经验中进行长时程策略学习，应用于工业洗衣机装配线全尺寸实验室复刻环境中的真实机器人多螺钉紧固任务。这些结果表明，结构化推理与验证可以提高通用 VLM 在机器人奖励建模中的实用性。代码见 https://github.com/midea-ai/ars

## Abstract
Progress reward modeling is the problem of estimating how a robot's behavior changes task progress over time. Reliable estimation requires distinguishing meaningful state changes from failed attempts and task-irrelevant actions. We introduce the Agentic Reward System (ARS), an inference framework for progress reward modeling with general-purpose vision-language models (VLMs), without additional reward-model training. Given an offline trajectory and a task instruction, ARS uses adaptive visual inspection for both event proposal and verification. A subagent proposes a task-relevant event timeline, which a primary agent verifies and revises before estimating per-frame progress. ARS can incorporate optional terminal outcome labels and visual references to inform its judgments. It can also audit progress estimates from external reward models. We evaluate ARS with a 27B VLM on a controlled semantic-mismatch benchmark and downstream policy learning in simulation and on a real robot. The benchmark reveals that several evaluated reward baselines assign spurious progress to wrong-object manipulation even in simple pick-and-place scenes. ARS better suppresses these errors and outperforms these baselines in simulation policy learning. We further demonstrate that ARS supports long-horizon policy learning from mixed-quality offline experience on real-robot multi-screw fastening in a full-scale laboratory replica of an industrial washing-machine assembly line. These results suggest that structured inference and verification can improve the usefulness of general-purpose VLMs for robot reward modeling. Code is at https://github.com/midea-ai/ars

# ARS: Agentic Reward System for Robot Learning —— 论文深度总结

## 1. 核心问题与研究动机

- **问题定义**：进度奖励建模（progress reward modeling）需要估计机器人行为随时间如何推进任务，输出逐帧进度 $p_{0:T}=f(o_{0:T},l)\in[0,1]^{T+1}$。
- **核心困难**：
  - 可靠估计必须区分**有意义的状态变化**与**失败尝试、任务无关动作**。
  - 稀疏的终端成功/失败信号对单步动作指导有限；人工设计的稠密奖励需要任务专用工程，且常依赖仿真特权状态。
  - 长时程操作中，成功轨迹可能包含失败片段，失败轨迹也可能包含有用的中间进展，混合质量数据本身蕴含可挖掘的监督信号。
- **背景张力**：已有工作表明专用机器人奖励模型可超过当时直接提示的前沿旗舰 VLM（GPT、Gemini 等），这引出一个关键问题——**通用 VLM 的奖励能力在多大程度上取决于“推理流程”而非模型本身**。
- **关键观察**：给智能体完整视频并不保证其仔细检查证据；长时程任务中短暂状态转换易被忽略，失败尝试易与后续成功交互混淆。正确判断需要检查解释背后的证据（例如“抓住错误物体”不等于任务推进，表观抓取需后续观察确认）。
- **整体含义**：论文主张通过**结构化推理与跨智能体验证**提升通用 VLM 在机器人奖励建模中的实用性，且无需额外训练奖励模型。

## 2. 方法论

- **核心思想**：ARS 是一个**免奖励模型训练**的推理框架，把进度估计组织为“事件提议 → 独立验证 → 进度构造”的智能体流程，用自适应视觉检查获取证据，并用可编辑事件时间线承载推理状态。
- **自适应视觉检查（Adaptive Visual Inspection）**：
  - 通过工具调用选择**时间窗口**、调整**采样密度**、可选请求**空间裁剪**。
  - 请求由当前未决问题驱动，可在早期事件需要回溯确认时延伸到后续观测。
  - 消融显示：短基准上收益有限，但长时程任务上即使初始已提供完整视频，定向检查仍提升下游策略性能。
- **事件锚定推理（Event-Grounded Reasoning）**：
  - 将轨迹表示为任务相关事件时间线，每个事件含时间区间、基于引用视觉证据的描述、置信度。
  - Harness 强制约束：**事件引用证据必须覆盖事件完整区间**；**事件集合必须覆盖整条轨迹**；检查失败时返回缺失区间要求修正。
- **跨智能体验证（Cross-Agent Verification）**：
  - **子智能体**负责事件提议；**主智能体**在**独立推理上下文**中收集额外证据进行验证与修订。
  - 事件确认必须使用验证阶段获取的证据；采样帧须覆盖事件内部及前后上下文；**修订会使确认失效，需重新确认**。
  - 两智能体可共享同一底层 VLM。分离上下文既让主智能体面对明确可质疑的主张，又减少其上下文占用（主智能体每查询平均 41.4K 输入 token，比单上下文控制的 57.6K 低 28.1%）。
- **进度估计**：
  - 主智能体基于已验证事件构造/修订进度曲线，支持插值段与局部逐点编辑；进度回读与摘要工具暴露曲线形状并标记跳变位置与幅度，便于自查与修订。
  - 行为原则：失败尝试不额外给分，遇挫可回退；保留不完整轨迹中的部分成就；为有用准备动作分配有限信用。
- **可选辅助信息**：
  - **终端结果标签**：锚定终点完成度，中间进度仍由视觉证据决定（成功轨迹可保留平台/下降段，失败轨迹可保留上升段）。
  - **上下文参考**：图像、视频片段、文本描述、正/负示例；进度数值标注可选。
  - **外部奖励审计**：以可疑预测引导视觉检查并修订外部奖励曲线。
- **进度引导策略学习**：
  - 在长度 $H$ 的动作块上定义进度差 $\Delta_t = p_{t+H}-p_t$，指示函数 $I_t=\mathbb{1}[\Delta_t>\epsilon(p_t)]$。
  - 目标为二值加权行为克隆：
    $$L_{BC}(\theta)=\frac{1}{\sum_\tau\sum_t I_t}\sum_\tau\sum_t I_t\,\ell_{BC}(\theta;o_t,l,a_{t:t+H-1})$$
  - 两种阈值规则：**零阈值**（保留 $\Delta_t>0$ 的块）与**分阶段阈值**（把 $[0,1]$ 分为 $B$ 个等宽区间，按当前进度 $p_t$ 分箱，箱内按 $\Delta_t$ 排序保留前 $\alpha$ 比例）。

## 3. 实验设计

- **Benchmark 1：语义错配基准（Semantic-Mismatch Benchmark）**
  - 在 ManiSkill 中由运动规划专家生成轨迹，每场景两个候选物体、随机背景，共 **500 对 / 1000 样本**，平均 31.7 帧，覆盖 25 类物体。
  - 每段视频配“正确拾放指令”与“指向另一可见物体的错配指令”；特权仿真状态确认夹爪从未接近错配物体。
  - 指标：**VOC**（正确指令下的逐轨迹 Spearman 排序相关）、**FPSR**（错配轨迹中未被严格正增量区间覆盖的时长比例）、**CMPG**（正确指令终端进度均值 − 错配指令逐轨迹最大进度均值）。
- **Benchmark 2：LIBERO-Long 离线策略学习**
  - 固定行为策略采集 **4,096 条轨迹**（2,204 成功 / 1,892 失败，平均 390.3 帧），所有奖励系统对同一数据集打分。
  - 下游策略统一从 $\pi_{0.5}$ 检查点初始化，chunk horizon $H=10$，30k 梯度步、3 个随机种子，每 2k 步在 10 个任务上各 100 次 rollout 评测。
- **Benchmark 3：真实机器人多螺钉紧固**
  - 工业洗衣机装配线全尺寸实验室复刻环境，后板三螺钉顺序紧固，整任务级成功判定（人工确认 + 旋转时间/扭矩超时判定）。
  - **2,574 条演示轨迹 + 3,092 条离线 rollout**，$H=50$，取 200k 步检查点，每配置 **200 次完整任务试验**，单训练种子。
- **对比方法**：LRM、R²VLM、SOLE-R1、Robometer、TOPReward（Qwen3-VL-8B / 32B）；另有 Vanilla BC、Success-only BC、特权状态进度作为参照。
- **主模型**：开权重 Qwen3.6-27B；消融使用 Qwen3.5-4B、Qwen3-VL 系列。

## 6. 主要结论与发现

- **语义对齐不能由时序一致性保证**：Robometer 取得 0.983 VOC 但 FPSR 仅 0.240；R²VLM 在错配指令下的平均峰值进度高于正确指令下的终端进度（CMPG 为负）。说明“单调上升”并不等于“指令对齐”。
- **ARS 三指标全面领先且无需奖励模型训练**：VOC 0.995、FPSR 0.918、CMPG 0.904。
- **ARS 可作为外部奖励的审计器**：审计 Robometer 预测后 FPSR 从 0.240 升至 0.915、CMPG 从 0.366 升至 0.891，同时保持高 VOC（0.988），接近无提案的 ARS。
- **仿真策略学习**：ARS 达 57.9% 成功率，比 Vanilla BC（44.2%）高 13.7 个百分点，比最强基线 TOPReward-32B（47.6%）高 10.3 个百分点；ARS 与 TOPReward-32B 保留块比例接近（66.9% vs 67.9%），说明增益来自**选择质量**而非数据量。
- **结果标签有效但非万能**：ARS+outcome 达 62.2%，比 Success-only BC（52.6%）高 9.6 点，达到特权状态参考增益的 80.7%；但成功轨迹仍存在平台/下降段，失败轨迹仍存在上升段。
- **真实机器人**：加入全部 rollout 反而使成功率从 58.0% 降至 50.5%；ARS 选择提升至 72.0%；加入无数值标注的视觉参考进一步升至 81.5%，总计 +23.5 点。
- **工作流与基座模型都重要**：同基座下 GVL 风格单提示 VOC 仅 0.637；ARS+Qwen3.5-4B 已在三指标上超过 Robometer-4B；同基座下完整 ARS 比单上下文控制高 6.1 点，说明**分离提议与验证**是关键。
- **推理成本权衡**：完整 ARS 比 TOPReward-32B 查询数少 93.6%、累计输入 token 少 65.8%，但比单次前向的 Robometer 类模型引入额外推理开销。
- **中间推理不必须为显式语言 CoT**：禁用 thinking 模式仍达 55.4%（比 Vanilla BC 高 11.2 点），harness 通过事件时间线与证据链维持推理状态。

## 7. 优点

- **免训练、可即插即用**：不需要额外奖励模型训练，直接利用通用 VLM，降低适配成本。
- **证据驱动的结构化推理**：事件时间线 + 证据覆盖约束 + 修订后重新确认，把“检查证据”从提示愿望变成 harness 强制机制。
- **跨智能体上下文分离**：既提供可质疑的明确主张，又降低主智能体上下文占用，实证上优于同上下文自验证（+6.1 点）。
- **基准设计有针对性**：语义错配基准用特权仿真状态确认“从未接近错配物体”，把“错误对象虚假信用”这一失败模式隔离出来；FPSR 与 EPCR 联合解读，避免“对两组都平坦”被误判为好。
- **指标设计互补**：VOC / FPSR / CMPG 分别覆盖排序质量、虚假进度抑制、正确–错配数值分离，并给出对输出尺度的敏感性诊断。
- **对比公平性意识强**：统一数据集、初始化、训练预算与评测流程；公开训练数据暴露情况；对基线给出统一的输出归一化约定。
- **真实场景验证**：在工业装配线复刻环境中完成长时程任务，并展示视觉参考带来的显著增益。

## 8. 不足与局限

- **推理开销**：迭代视觉检查与生成式验证比单次前向奖励模型更贵；作者自述当前流程更适合**离线数据整理**。
- **在线/因果场景未覆盖**：ARS 依赖完整离线轨迹与后续观测回溯解决早期歧义，扩展为因果在线奖励估计仍是开放问题。
- **真实实验统计强度有限**：单训练种子、200 次试验、无跨种子方差；视觉参考增益显著但结果标签的增量不显著（Fisher 精确检验 p = 0.597）。
- **任务覆盖偏窄**：真实机器人仅三螺钉紧固一个任务；仿真集中于 LIBERO-Long 与 ManiSkill 拾放，未覆盖更广的接触丰富、多物体长时程任务。
- **基座模型依赖**：4B 级模型在长时程上出现工具使用/约束遵守失败（LIBERO 上 33/4096 未完成），且同规模下不同基座差异明显（Qwen3-VL-4B 完全无法完成工作流）。
- **指标局限**：CMPG 对输出尺度敏感；FPSR 对原生预测的时间间隔敏感；两者需联合解读。
- **训练数据暴露不均衡**：部分基线（LRM、SOLE-R1、Robometer）在 LIBERO 上有训练暴露，ARS 与 TOPReward 没有，虽有利于 ARS 结论，但也说明不同方法处于不完全对等的先验条件下。
- **审计能力的验证范围有限**：外部奖励审计仅在 Robometer 一种外部曲线上验证。
- **算力信息缺失**：无法评估方法的实际部署成本与可扩展性。

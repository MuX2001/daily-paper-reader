## 摘要
视觉-语言-动作模型在机器人操作中取得了强大性能，但通常需要大量参数。在本工作中，我们提出了未来表征动作模型（FRAM），这是一种小型策略，能够显式地将未来末端执行器轨迹与当前视觉输入关联起来。FRAM 将预测轨迹的图像坐标作为空间指针，并从当前图像中读取与运动相关的局部视觉特征。这将用于动作生成的信息组织为参考位置（Where）、视觉状态（What）和未来运动（Future）。轨迹标签由演示和相机几何自动生成，因此无需人工标注。FRAM 具有 138.7M 参数，其中包括一个冻结的语言编码器，在四个标准 LIBERO 套件上达到 92.2% 的平均成功率，接近具有 3.3B 参数的 π0 的 94.2%。无需额外训练，它还在 LIBERO-Plus 上达到平均 67.3%。消融实验证实，未来轨迹和局部视觉特征都能提升性能和鲁棒性。在真实的双臂 UR5e 上，FRAM 仅使用腕部相机堆叠杯子，包括在左右臂之间进行选择和切换。这些结果表明，基于未来运动选择视觉信息是在小型机器人策略中同时获得高性能和鲁棒性的有效方式。

## Abstract
Vision-Language-Action models achieve strong performance in robot manipulation, but often require large numbers of parameters. In this work, we propose the Future Representation Action Model (FRAM), a small policy that explicitly links the future end-effector trajectory to the current visual input. FRAM uses the image coordinates of the predicted trajectory as spatial pointers and reads local visual features related to the motion from the current image. This organizes the information for action generation into the reference position (Where), the visual state (What), and the future motion (Future). Trajectory labels are generated automatically from demonstrations and camera geometry, so no manual annotation is needed. With 138.7M parameters, including a frozen language encoder, FRAM reaches an average success rate of 92.2% over the four standard LIBERO suites, close to the 94.2% of $π_0$ with 3.3B parameters. Without extra training, it also reaches an average of 67.3% on LIBERO-Plus. Ablations confirm that both the future trajectory and the local visual features improve performance and robustness. On a real dual-arm UR5e, FRAM stacks cups using only wrist cameras, including choosing and switching between the left and right arms. These results show that selecting visual information based on future motion is an effective way to obtain both high performance and robustness in a small robot policy.

## 2. 方法论：核心思想与关键技术细节

- **核心思想**：
  - 模仿人类“先看目标再动手”的行为，先预测未来末端执行器轨迹；
  - 将预测轨迹的图像坐标作为空间指针，从当前图像特征图中读取与运动相关的局部特征；
  - 动作生成由全局场景信息、未来轨迹、局部视觉特征和语言条件共同驱动。

- **输入与编码**：
  - 观测包括语言指令、末端执行器状态、外部相机图像、腕部相机图像。
  - 语言由冻结的 SigLIP 文本编码器编码，得到 token 序列和句嵌入。
  - 图像由 ImageNet 预训练 ResNet-18 的第三残差阶段编码，两个视图共享权重；经 1×1 卷积降维后，用 FiLM 根据语言句嵌入做逐空间位置调制，得到语言条件特征图。

- **未来轨迹预测**：
  - 每个视图使用独立 Transformer 解码器；
  - K 个可学习 query 与图像 token、语言 token、末端状态 token 做交叉注意力；
  - 每个预测点包含：归一化图像坐标、相机坐标系深度、6D 投影方向偏移；
  - 论文中 K=16，动作块长度 H=16。

- **轨迹标签自动生成**：
  - 根据演示中夹爪命令切换，将演示切分为接近、抓取、运输、释放等子任务；
  - 预测区间终点 e(t) 取“当前子任务结束”与“t+H”中较晚者，并截断到演示结束；
  - 在基座坐标系中对末端位置拟合分段三次 B 样条，按等弧长采样 K 点；
  - 用当前时刻相机外参、内参以及腕部手眼变换，将未来末端位置和方向投影到各视图图像；
  - 图像外点保留真实越界坐标，相机后方点与远离光轴点从损失中排除；
  - 因此无需人工标注目标区域或子目标。

- **轨迹引导局部特征提取**：
  - 将预测轨迹图像坐标映射到当前图像特征图网格；
  - 在每个点周围采样 3×3 邻域，经双线性插值后取平均，得到该点局部特征；
  - 对所有 K 点取平均得到 `f_traj`，表示路径沿线视觉状态；
  - 取末端点特征 `f_target`，表示目标位置视觉状态；
  - 以 `f_target` 为 query，对整张特征图做单层注意力，得到 `f_attn`，补偿端点略偏；
  - 三者拼接后经 MLP 得到局部视觉特征 `f_local`，每个视图独立计算。

- **动作专家与流匹配**：
  - 条件向量由全局观测特征、轨迹嵌入、各视图局部视觉特征拼接而成；
  - 每个预测轨迹点线性投影并加位置嵌入，作为轨迹 token 提供给动作生成器交叉注意力；
  - 动作块为 H 步的末端增量平移/旋转与夹爪命令；
  - 使用 flow matching 训练：采样噪声 A0 与真实动作 A1，构造 Aτ=(1−τ)A0+τA1，学习速度场；
  - 每个块依次包含 FiLM 条件残差 MLP 和 Transformer 层，后者含步间自注意力与对轨迹 token 的交叉注意力；
  - 总损失为 `L = L_FM + L_BC + λ_KP L_KP + λ_ORI L_ORI`；
  - 轨迹位置/深度用 smooth-L1，二阶差分约束轨迹形状，方向偏移也用 smooth-L1；
  - 训练时后续阶段使用预测轨迹，但对轨迹预测器施加 stop-gradient，避免动作损失回传改变轨迹几何含义。

- **推理流程**：
  - 从当前观测依次计算语言条件特征图、预测轨迹、局部特征、条件向量；
  - 从高斯噪声积分速度场得到动作块；
  - 执行 H 步后重新观测，重复轨迹预测与动作生成。

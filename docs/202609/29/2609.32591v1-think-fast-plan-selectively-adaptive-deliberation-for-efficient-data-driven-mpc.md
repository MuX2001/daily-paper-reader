## 摘要
数据驱动的模型预测控制（MPC）将学习到的世界模型与在线轨迹优化相结合，在连续控制中取得了强大性能。然而，每一步采样和评估数百条候选轨迹的成本，使部署时的控制频率远低于实时机器人应用的需求。受人类认知双过程理论启发，该理论区分快速、直觉的加工（系统 1）与较慢、审慎的推理（系统 2），我们提出：是否每个决策都需要相同程度的计算审慎。我们提出 Fast-TD-MPC，一个轻量级框架，能够在快速策略执行与测试时规划之间自适应地路由，将昂贵的审慎推理保留给最需要的状态。Fast-TD-MPC 在 103 个连续控制任务上取得了有竞争力的任务性能，同时实现最高约 4 倍的推理加速。在外部扰动下，Fast-TD-MPC 选择性地回退到规划，保持与原始规划器相当的鲁棒性。

## Abstract
Data-driven model predictive control (MPC) combines learned world models with online trajectory optimization, achieving strong performance in continuous control. However, the per-step cost of sampling and evaluating hundreds of candidate trajectories restricts deployment to control frequencies well below what real-time robotics demands. Motivated by the dual-process theory of human cognition, which distinguishes between fast, intuitive processing (System 1) and slower, deliberative reasoning (System 2), we ask whether every decision requires the same degree of computational deliberation. We propose Fast-TD-MPC, a lightweight framework that adaptively routes between fast policy execution and test-time planning, reserving costly deliberation for states where it is most needed. Fast-TD-MPC delivers competitive task performance across 103 continuous control tasks while achieving up to ~4x faster inference. Under external disturbances, Fast-TD-MPC selectively falls back to planning, maintaining robustness comparable to the original planner.

## 一、核心问题与研究动机

- **背景**：数据驱动模型预测控制（MPC）将学习到的世界模型与在线轨迹优化相结合，在连续控制中达到 SOTA 性能。代表性工作 TD-MPC2 在推理时通过 MPPI 在潜在空间中规划：每个决策步采样并评估数百条候选轨迹，经多轮迭代精炼动作序列。
- **核心痛点**：每步规划的计算开销巨大（H100 上约 26 ms/步），使控制频率远低于实时机器人部署需求，并导致"陈旧动作误差"——当规划相对于环境变化过慢时，动作执行时状态已经改变。
- **关键洞察**：并非所有决策都需要同等程度的审慎推理。大部分观测是熟悉且可预测的，一个低延迟的反应式策略即可提供可靠动作；只有当智能体遇到陌生观测、扰动或行为不可靠的情形时，规划才真正有价值。
- **理论启发**：借鉴人类认知的双过程理论——快速直觉的 **System 1** 与缓慢审慎的 **System 2**，人类自然地在两者间切换以实现高效决策。作者据此提问：能否让 MPC 也按需分配算力？

## 二、方法论：Fast-TD-MPC

### 核心思想
在冻结的预训练 TD-MPC2 世界模型之上，构建三个组件（部署前全部冻结），按状态难度自适应路由：
- **System 1**：轻量前馈摊销策略（快速、低延迟）
- **System 2**：原始 MPPI 规划器（慢速、鲁棒的兜底）
- **OOD 门控**：轻量分布外检测器，决定每步走哪条路径

### 关键技术细节

- **System 1：摊销策略（规划器模仿）**
  - 用预训练 TD-MPC2 规划器 rollout 采集专家演示 D_exp = {(z_t, a*_t)}，以 L1 损失训练一个确定性 MLP 策略 π_S1。
  - 架构：输入冻结潜在 z∈R^512，4 层 MLP（3 个 Linear→LayerNorm→Mish 中间层 + 最终 SimNorm 层），隐藏维 256，tanh 输出，首层 dropout 0.1；约 33.2 万~34.1 万参数，相比 TD-MPC2 的 7.9M 参数减少约 23 倍。
  - 单次前向即可出动作（H100 上约 0.4 ms，比 System 2 便宜约 65 倍）。

- **System 2：MPPI 规划器**
  - 直接沿用 TD-MPC2 的 MPPI，默认超参：规划视界 H=3、6 轮精炼、N=512 条采样轨迹、N_π=24 条来自策略先验、top-k=64 精英轨迹。
  - 当门控从 System 1 切回 System 2 时，warm-start 缓冲区已陈旧 K 步，作者**显式清零**，强制从策略先验冷启动，以获得前向新鲜候选。

- **OOD 门控：潜在空间马氏距离**
  - 评分函数：g(z_t) = (z_t − z̄)ᵀ Σ⁻¹_reg (z_t − z̄)，其中 z̄ 与 Σ 为 ID 潜变量的均值与全协方差，拟合时施加 ℓ2 收缩（Σ_reg = Σ + 0.01·I）。
  - 路由规则：g(z_t) ≤ τ 走 System 1，否则走 System 2（式 4）。
  - ID 集构造有两种标注模式：
    - **theoretical（all）**：System 1 rollout 访问的所有潜状态均视为 ID，τ 默认取留出验证集上分数的中位数（因马氏距离平方服从 χ² 分布、右偏，中位数比均值更具代表性）。
    - **reward-gated（RG）**：仅当某状态每步奖励不低于 TD-MPC2 专家同时间步的平均每步奖励时才标为 ID，τ 默认取 ID 与 OOD 分区中位数的中点。
  - 门控本身仅一次矩阵-向量乘，开销可忽略（约 0.2 ms）。

- **延迟模型**
  - t_total ≈ E_θ + g + ρ·π_S2 + (1−ρ)·π_S1 + t_env，其中 ρ 为 System 2 调用率。
  - ρ→0 趋近纯摊销策略速度，ρ→1 趋近全规划鲁棒性；阈值 τ 直接控制该权衡。门控开销可忽略，故有效每步延迟随需规划的时间步比例**线性增长**。

- **算法流程**（Algorithm 1）：每步编码状态 → 计算 OOD 分数 → 若 g_t ≤ τ 则 System 1 出动作，否则 MPPI 规划 → 执行动作。所有组件部署时冻结。

## 六、主要结论与发现

- **RQ1（速度-性能权衡）**：
  - τ_p50 时 Fast-TD-MPC（all）在 4 域内与 TD-MPC2 在 95% CI 内持平（DMControl 829 vs. 820；Meta-World 85% vs. 84%），延迟降低约 1.3–1.4×。
  - τ_p75 时提速约 2×；τ_p90 时平均提速约 2.7×（DMControl 最高 4.2×），4 域中 3 个域性能下降 <10%（DMControl 保留 96% 回报，Meta-World 成功率持平，MyoSuite 保留 93%）。
  - 超过 p90 后性能急剧下降（τ_p99 时 DMControl 回报跌至 650，约 −20%），退化为 S1-alone 状态。
  - 延迟随 ρ 线性增长（R² ≥ 0.93），验证了运行时模型。
- **状态感知门控 vs. 固定调度**：DMControl 上门控在所有匹配延迟点均优于 Round-robin；ManiSkill2 上两者相当；MyoSuite 上 RR（S2 10%）反而能以更低延迟恢复 TD-MPC2 成功率。结论：只有当**少数状态**真正需要规划时，状态感知门控才体现最大价值，否则固定调度是更简单的替代方案。
- **RG 模式 vs. theoretical 模式**：RG 在更低延迟下达到同等性能（Meta-World 上 RG τ_p50 用 10.0 ms 达 85%，而 all τ_p90 用 12.2 ms 才达 85%），因其 ID 分布更紧、阈值更精确，减少了不必要的 System 2 调用。
- **RQ2（扰动鲁棒性）**：
  - 扰动下 TD-MPC2 大幅退化（DMControl −25%，Meta-World −39%），S1-alone 更差（−35%、−46%），说明摊销策略对分布偏移更敏感。

## 摘要
我们提出 DAOCP，一种用于带逐阶段等式与不等式约束的线性二次最优控制问题的对偶主动集求解器。主动集方法是全身机器人学中领先的模型预测控制基准，但现有求解器在稠密二次规划（QP）上运行，而典型问题维度更有利于利用最优控制结构的方法。DAOCP 通过依赖 Riccati 递推与凝聚 Hessian 的 Cholesky 分解之间关系的推广，将主动集算法的热启动能力与利用结构的求解器更好的计算扩展性结合起来。这一结果使对偶主动集迭代能够通过递归计算直接作用于原始最优控制问题，而无需显式构造凝聚后的二次规划。在机器人基准测试中，DAOCP 在五个场景中的四个里是四种求解器中最快的；相比最先进的求解器 DAQP 和 HPIPM，它在 58 状态的 Atlas 模型上将平均求解时间缩短了 9 倍。

## Abstract
We present DAOCP, a dual active set solver for linear quadratic optimal control problems with stage-wise equality and inequality constraints. Active set methods are leading Model Predictive Control benchmarks for full-body robotics, but existing solvers operate on dense QPs, while typical problem dimensions favor methods that exploit the optimal control structure. DAOCP combines the warm-starting capabilities of active set algorithms with the better computational scaling of structure exploiting solvers, by relying on a generalization of the relationship between the Riccati recursion and the Cholesky factorization of the condensed Hessian. This result enables dual active set iterations to operate directly on the original optimal control problem through recursive computations, without explicitly forming the condensed quadratic program. On robotics benchmarks, DAOCP is the fastest of four solvers in four of five scenarios, cutting average solve time on a 58-state Atlas model by 9$\times$ relative to state of the art solvers DAQP and HPIPM.

## 1. 核心问题与整体含义（研究动机与背景）

- **应用背景**：模型预测控制（MPC）是机器人控制的核心方法，尤其在人形与足式机器人的全身 MPC 中，需要在极紧的实时预算内求解具有大状态/控制维度和中等至较长预测时域的最优控制问题（OCP）。
- **维度特性**：机器人系统的典型维度（如每个自由度约 2 个状态、1 个控制，α = nx/nu ≈ 2）使问题天然有利于**利用 OCP 结构**的求解器，而非把问题转换为稠密二次规划（QP）。
- **算法张力**：
  - **主动集（AS）方法**在 MPC 中具有天然优势——相邻采样时刻的 QP 高度相似，热启动可大幅减少迭代次数（如 DAQP 在机器人基准上表现领先）。
  - **结构利用求解器**（如内点法 HPIPM）在 Riccati/LQR 递推下具有更好的计算扩展性，但历史上有学者提出过面向 OCP 的 AS 算法，却始终没有形成有竞争力的公开实现。
- **核心矛盾**：现有主流 AS 求解器（DAQP、qpOASES）仍在**凝聚（condensed）**后的稠密 QP 上运行，无法同时兼得 AS 的热启动优势与 OCP 结构的扩展性优势。
- **论文目标**：填补这一空白，提出 DAOCP——一个直接在原 OCP 上执行对偶主动集迭代的求解器。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 问题形式与整体思路

- 目标问题为带**逐阶段等式与不等式约束**的线性二次 OCP（式 (4)），含动力学等式、阶段不等式 $C^x_t x_t + C^u_t u_t \le c_t$、阶段等式 $D^x_t x_t + D^u_t u_t = d_t$ 及终端不等式；假设 $R_t \succ 0$、$Q_N \succeq 0$，阶段代价矩阵半正定。
- 算法高层流程**与 DAQP/Quadprog 一致**（对偶 AS，见 Algorithm 1）：维护工作集 $\mathcal{W}$，通过求解等式约束子问题获得对偶乘子 $\nu$，若 $\nu \ge 0$ 则更新对偶解并检查原始可行性（$Gu \le b$），否则进行约束增删；当 $H_\mathcal{W}$ 奇异时通过寻找零空间方向判定不可行性。
- **关键创新**：不显式构造凝聚 QP（式 (6)），而是把所有核心操作表达为**原 OCP 上的 Riccati/LQR 型递推**。凝聚形式仅用于数学推导。

### 2.2 关键技术细节

- **对偶问题**：对偶 Hessian 为
  $H = G(H^{-1} - H^{-1}E^\top (EH^{-1}E^\top)^{-1} EH^{-1})G^\top$（式 (10)），$f = b - Gu_0$；通过 KKT 矩阵的块逆公式得到。等式约束在 AS 过程之前被消去。
- **带符号 Gramian 分解**（Proposition 1）：对等式约束 KKT 矩阵 $K = \begin{bmatrix}H & E^\top\\ E & 0\end{bmatrix}$ 取分解 $K = L\,\mathrm{blockdiag}(I_n, -I_\rho)L^\top$，则对偶 Hessian 具有**带符号 Gramian 分解**
  $H = M_u M_u^\top - M_\xi M_\xi^\top$（式 (11)），其中 $M_u, M_\xi$ 由 $L\begin{bmatrix}M_u^\top\\ M_\xi^\top\end{bmatrix} = \begin{bmatrix}G^\top\\ 0\end{bmatrix}$ 确定。
- **仅按需计算行**：因面向非线性/时变 MPC（矩阵每采样时刻变化，无法复用），DAOCP **不在 setup 阶段完整构造** $M_u, M_\xi$，而只在实际添加约束时计算所需行。
- **原始候选解检索**（Proposition 2）：$u = u_0 + \Delta u$，其中 $\Delta u$ 由 $L^\top\begin{bmatrix}\Delta u\\ \Delta \xi\end{bmatrix} = \begin{bmatrix}-M_{u,\mathcal{W}}^\top\\ M_{\xi,\mathcal{W}}^\top\end{bmatrix}\lambda_\mathcal{W}$ 求得（式 (14)）。
- **定理 1（后向递推）**：将新加入约束对应的 $M_u, M_\xi$ 行（分块为 $y_t, v_t$）通过广义**后向 LQR/Riccati 递推**求解（式 (19)–(20)），核心量包括
  $\Lambda_t = \mathrm{signedchol}\left(\begin{bmatrix}R_t + B_t^\top P_{t+1}B_t & (D^u_t)^\top\\ D^u_t & 0\end{bmatrix}\right)$，
  $[K^u_t\ K^\xi_t] = [S_t^\top + A_t^\top P_{t+1}B_t\ (D^x_t)^\top]\Lambda_t^{-\top}$，
  $P_t = Q_t + A_t^\top P_{t+1}A_t - K^u_t(K^u_t)^\top + K^\xi_t(K^\xi_t)^\top$（式 (15)–(17)）。
- **定理 2（前向递推）**：原始候选解 $\Delta u$ 通过广义**前向 LQR 递推**得到（式 (21)），并同时计算状态序列 $\Delta x_{t+1} = A_t\Delta x_t + B_t\Delta u_t$，从而**无需构造 $b$ 或 $G$** 即可评估约束残差。
- **理论依据**：将 [14] 中"Riccati 递推 ↔ 凝聚 Hessian 的 Cholesky 分解"的对应关系推广到**带逐阶段等式约束**的情形（Appendix A 通过 $N=2$ 特例 + 归纳法证明，指出 LDL 分解过程中的 Schur 补更新恰好传播 Riccati 递推的代价矩阵 $P_t$）。
- **等式约束预处理的合理性**：Appendix B 证明任意阶段/终端等式约束的 OCP 可等价改写为 $D^u_t$ 行满秩的形式，并顺带检测给定 $x_0$ 下的可行性。
- **复杂度**（式 (22)–(23)）：迭代代价 $C_{\text{iter}} = C_{\text{AS}} + C_{\text{LQR}} + C_{\text{scan}}$，其中 $C_{\text{AS}} = O(|\mathcal{W}|^2 + |\mathcal{W}|(\rho + Nn_u))$，$C_{\text{LQR}} = O(N(n_x^2+n_u^2) + \sum_t \rho_t^2)$，$C_{\text{scan}} = O(m(n_x+n_u))$。把等式约束排除出工作集，避免了 $C_{\text{AS}} \ge \rho^2$ 的问题，将等式约束的二次代价分散到时域上。
- **实现**：C 语言实现，主要数值线性代数依赖 **BLASFEO**（针对小矩阵上的 Riccati/LQR 类例程优化）；约束选择支持"最大违反"与"贪婪"两种启发式（默认最大违反，与 DAQP 一致）。代码开源：https://github.com/AlbertoZaupa/daocp

### 2.3 理论阈值论证（方法动机的量化支撑）

- 给出 Riccati 分解与 LQR 求解分别优于 Cholesky 分解与稠密三角求解的时域阈值：$N_f = \sqrt{7\alpha^3+12\alpha^2+6\alpha+1}$，$N_s = 2\alpha^2+2\alpha+1$（式 (3)）。当 α = 2 时 $N_f \approx 10.8$、$N_s = 13$，机器人典型时域远超此阈值。

## 6. 主要结论与发现

- DAOCP 在**五个场景中的四个**是四种求解器中最快的。
- **Atlas**：平均 0.03 ms，最坏 1.08 ms；相比 DAQP（0.27 ms）和 HPIPM（1.75 ms）平均求解时间缩短约 **9×**。作者指出 $N=30$ 远超 $N_s=13$、$N_f\approx10.8$，LQR 求解的浮点运算量不足稠密三角求解的一半，是加速的关键来源。
- **四足**：$N=20$ 时 standing 0.188 ms / trotting 0.235 ms，均优于 HPIPM（0.240/0.391）、DAQP（2.575/3.544）、qpOASES（3.815/7.332）。随 $N$ 从 10 增至 20，DAOCP 与 HPIPM 平均求解时间约翻倍（线性扩展），而 DAQP 与 qpOASES 增长超过 4 倍（稠密 AS 的二次/混合二次-三次扩展）。
- **四旋翼**：在动态可行轨迹上 DAOCP 最快（81.80 μs）；在专门挑选的不可行轨迹上被 DAQP（181.32 μs）和 HPIPM（150.62 μs）超越（DAOCP 282.01 μs）。原因：稠密求解器每步需凝聚并计算完整 Gramian 分解（常数开销大），而 DAOCP 迭代本身更贵，当需要大量 AS 迭代时劣势显现。
- 总体结论：DAOCP 成功融合了 AS 的热启动能力与 OCP 结构求解器的扩展性，在机器人典型维度区间内具有竞争力。

## 7. 优点

- **理论贡献扎实**：把"Riccati 递推 ↔ 凝聚 Hessian 的 Cholesky 分解"这一已知对应关系推广到带阶段等式约束的 KKT 矩阵，给出带符号 Gramian 分解与双向（后向/前向）广义 LQR 递推，并在 Appendix A 中以 $N=2$ 特例 + 归纳法给出完整证明，推导清晰。
- **工程与理论结合**：不完整构造 $M_u, M_\xi$、按需计算行，契合时变/非线性 MPC 的实际需求；等式约束被排除出工作集以避免 $|\mathcal{W}|^2$ 项被 $\rho^2$ 主导，是很有洞察力的设计。
- **提供了可量化的方法选择依据**：式 (3) 的 $N_f, N_s$ 阈值使"何时该用结构利用求解器"有了显式判据，并据此预测各基准的表现，且预测与实验一致。
- **实验态度较为客观**：主动构造对 DAOCP 不利的困难实例，并如实报告在四旋翼不可行轨迹上的落后及 144 条轨迹上的胜率而非只报最优结果。
- **开源可复现**：代码公开在 GitHub。

- **算法本身的可扩展性限制**：$C_{\text{AS}} = O(|\mathcal{W}|^2 + |\mathcal{W}|(\rho + Nn_u))$ 对工作集规模呈二次增长，因此 DAOCP 只适用于工作集不会过大的问题；作者承认当该假设失效时，应改用把对偶子问题写成等式约束 LQR 的替代形式（列为未来工作）。
- **实验覆盖的缺口**：
  - 缺少**消融实验**：未分离 Riccati 结构利用、BLASFEO 后端、等式约束预处理各自贡献了多少加速。
  - 仅测试了线性二次 MPC 与 SQP/RTI 中作为 QP 子问题的场景，未验证完整的非线性 MPC 端到端性能（如收敛质量、迭代

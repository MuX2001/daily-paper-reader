## 摘要
我们提出了 PccDiffuser，一种面向连续体机器人的条件扩散框架。它学习完整构型空间路径上的多模态分布，并并行采样多个候选解，随后通过考虑执行器约束的时间分配将这些候选解转换为可执行轨迹。在分段常曲率模型下，我们使用指数坐标描述机器人运动学，并使用图神经网络编码数量可变的环境障碍物。在去噪过程中引入解析微分运动学，以提高末端精度和全身间隙。在包含零至四个障碍物的工作空间的混合测试集上，PccDiffuser 达到了 91% 的成功率。与现有的基于采样和基于优化的基准方法相比，它同时实现了更高的成功率和更高的计算效率，且当采样更多候选解时，后一优势更加显著。在三段腱驱动连续体机器人上的实验进一步证明了连续规划、多解规划和全身避障。

## Abstract
We present the PccDiffuser, a conditional diffusion framework for continuum robots that learns a multimodal distribution over complete configuration-space paths and samples multiple candidate solutions in parallel, which are subsequently converted into an executable trajectory by time allocation considering actuator constraints. Under the piecewise constant-curvature model, we use exponential co-ordinates to describe the robot kinematics, and use graph neural network to encode a variable number of environment obstacles. Analytical differential kinematics is incorporated in the denoising process to improve terminal accuracy and whole-body clearance. On a mixed test set comprising workspace with zero to four obstacles, PccDiffuser achieved a success rate of 91\%. Compared with existing sampling- and optimisation-based benchmarks, it delivered both a higher success rate and greater computational efficiency, with the latter advantage becoming more substantial when sampling more candidate solutions. Experiments on a three-section tendon-driven continuum robot further demonstrate consecutive planning, multi-solution planning, and whole-body obstacle avoidance.

# PccDiffuser 论文总结

## 一、核心问题与整体含义（研究动机与背景）

- **研究对象**：连续体机器人（continuum robots）的运动规划。这类机器人连续可变形、柔顺自适应，适用于微创手术、工业检测维护、人机交互等场景。
- **核心矛盾**：连续体机器人存在运动学冗余，同一末端目标对应**多个终端构型与差异显著的全身路径**，规划问题本质上是**欠约束且多模态（multimodal）**的。这种多解性既是避障与运行时目标切换的有利资源，也使规划变得困难。
- **现有方法局限**：
  - 构型空间规划器（如构型空间 RRT/RRT*）直接在全构型中搜索，缺乏工作空间任务引导；由于运动学非线性，构型空间的短路径可能对应工作空间中不理想的路径。
  - 工作空间规划器（如工作空间 RRT/RRT*）先规划末端路径再反复求解逆运动学，易产生不连续或收敛到局部极小。
  - 采样/优化类方法**每次运行通常只返回一个解**，难以自然刻画问题的多模态性；表示多种可行运动模式需要反复搜索。
- **整体含义**：论文提出 **PccDiffuser**，将条件扩散模型引入连续体机器人规划，学习完整构型空间路径的条件分布，一次并行生成多个候选解，同时兼顾末端精度、工作空间路径质量与全身避障，再通过时间分配生成可执行轨迹。

## 二、方法论

### 核心思想
- 采用**两阶段解耦**：先做几何路径规划（生成多候选构型空间路径），再做**时间分配**（在执行器速度/加速度约束下构造可执行轨迹）。
- 用**条件扩散模型**学习 \(p_\theta(x_{t-1}|x_t,c)\)，其中路径 \(x_0=[\zeta_0,\dots,\zeta_{H-1}]^T\in\mathbb{R}^{H\times6}\)，条件 \(c=\{\zeta_0^*, P^*, O\}\)（初始构型、目标末端位置、障碍物集合）。
- 从不同初始噪声采样即可探索不同模态，确定性 DDIM 采样使每个解可复现，批式去噪实现多解并行生成。

### 关键技术细节
- **非奇异运动学表示**：
  - 使用 PCC（分段常曲率）模型，但用**指数坐标**替代直观的 \((\kappa_i,\phi_i)\)，避免直构型处的奇异与不连续。
  - 每段积分空间扭转 \(\xi_i = L_i[-\kappa_i\sin\phi_i,\ \kappa_i\cos\phi_i,\ 0,0,0,1]^T\)，构型 \(\zeta=[\xi_{11},\xi_{12},\xi_{21},\xi_{22},\xi_{31},\xi_{32}]^T\in\mathbb{R}^6\)。
  - 末端位姿由**产品指数公式** \(T(\zeta)=\exp(\xi_1^\wedge)\exp(\xi_2^\wedge)\exp(\xi_3^\wedge)\) 给出；提取平移雅可比 \(dP/d\zeta\) 用于解析引导。曲率约束 \(\kappa_i\le\kappa_{\max}\)。
- **扩散过程**：
  - 前向过程按余弦调度加高斯噪声，可直接采样 \(x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon\)。
  - 反向过程采用**确定性 DDIM（\(\eta=0\)）**，从 \(T=1000\) 训练步中选 50 步采样，网络预测噪声 \(\epsilon_\theta(x_t,t,c)\)。
- **网络架构**：
  - 一维时序 U-Net 接收含噪路径 + 标识初始构型 inpainting 的二值通道。
  - 扩散步、初始构型、目标位置经 MLP 嵌入；**GNN** 将可变数量障碍编码为完全有向图（节点特征 \([c_i^T,r_i]^T\)，消息含相对中心信息），图池化得到定长嵌入。
  - 各条件融合为共享上下文向量，通过**特征级仿射变换**调制 U-Net 残差块。
- **训练**：
  - 掩码条件噪声预测损失，**排除被 inpainting 恢复的初始构型**：\(L=\frac{1}{6(H-1)}\mathbb{E}\|M\odot(\epsilon-\epsilon_\theta(x_t,t,c))\|^2\)。
  - AdamW 优化 100k 次更新，推理使用参数指数移动平均（EMA）。
- **解析微分运动学引导**（在反向过程最后 20 步激活）：
  - 末端目标代价 \(E_1=\frac12\|P(\zeta_{H-1})-P^*\|^2\)，梯度 \(J(\zeta_{H-1})^T(P(\zeta_{H-1})-P^*)\)。
  - 全身避障代价 \(E_2\)：对最深入障碍的骨干点计算到安全边界的位移 \(\Delta P_k\)，通过 \(J_k(\zeta_h)^T\Delta P_k\) 映射回构型空间排斥方向（初始构型更新恒置零）。
  - **Post Correction**：先把预测噪声还原为 \(\hat{x}_0\)，再沿 \(-\nabla E_1\)、\(-\nabla E_2\) 直接修正末端与穿透构型，然后代入 DDIM 更新。
  - **Guided Prediction**：通过自动微分把解析几何梯度经 \(\hat{x}_0=f(x_t)\) 传播到 \(\nabla_{x_t}E\)，修改预测噪声 \(\epsilon_\theta\leftarrow\epsilon_\theta+\sqrt{1-\bar\alpha_t}\nabla_{x_t}E\) 后再做 DDIM 更新。
- **轨迹生成**：采样路径经线性映射得到执行器空间路径，在速度/加速度约束下分配最小时间（保持几何不变），执行时可样条插值。

## 三、实验设计

- **仿真设置**：

  - 数据集：**无障碍数据集约 353k 条路径**；**混合数据集约 243k 条路径**，含 0–4 个球形障碍物。

- **Benchmark 与对比方法**：

  - RRT/RRT* 使用 100 次迭代；成功判据为末端误差小于容差**且**采样骨干全程无碰撞。

- **消融实验**：对比三种变体——纯扩散（无解析引导）、Post Correction、Guided Prediction；在无障碍与混合障碍两个数据集上评估；所有变体使用相同确定性 50 步采样与相同初始噪声。
- **评价指标**：成功率、成功路径的归一化末端误差（除以机器人总长）、每条路径平均运行时间（含 5%/95% 分位数）。

## 六、主要结论与发现

- **多模态能力**：不同初始噪声可生成末端构型明显不同、全身运动各异的多个可行解，且在障碍增多时仍保持解的多样性，说明学习到的是真正的多模态分布而非单一标称路径的扰动。
- **消融结论**：
  - 相对纯扩散，Post Correction 在无障碍/混合场景分别增加 15.1%/56.8% 运行时间，Guided Prediction 增加 60.4%/102.2%。
  - **Post Correction 性能最优**：成功率分别达 **99.62%** 与 **91.11%**，归一化末端误差分别降低 **55.6%** 与 **45.4%**。
  - Guided Prediction 也提升成功率，但末端精度改善有限；**Post Correction 在精度与效率间折中更佳**。
- **对比结论**：PccDiffuser 成功率 **91.11%**，高于最强基准（工作空间 RRT/RRT* 与 APF 约 70%，构型空间 RRT/RRT* 约 65%）；**平均运行时间 34.0 ms/成功路径为最低**；由于候选并行去噪，增加候选数量几乎不增加总采样时间，多解规划时效率优势更突出。
- **真机结论**：连续规划中构型在重规划边界保持连续，可平滑衔接；多解规划中两种解的执行构型轨迹明显分离；避障规划中全身（完整离散骨干）保持间隙并成功到达目标，证明学习到的障碍条件与几何修正在硬件上仍有效。

## 七、优点

- **问题定位清晰**：明确把连续体机器人规划的多模态性与执行器约束拆成“路径生成 + 时间分配”两阶段，几何要求对时间参数化不变，分解合理。
- **表示优雅**：采用指数坐标避免 PCC 直构型奇异，解析雅可比可直接用于扩散引导，兼顾非奇异性与可微性。
- **条件建模灵活**：GNN + 图池化可处理**可变数量障碍**，避免固定维度输入的限制。
- **引导策略对比充分**：同时提出并比较 Post Correction 与 Guided Prediction 两种解析引导方式，给出精度—效率权衡的量化结论。
- **并行多解高效**：批式去噪使候选数增加时总时间几乎不变，契合“多解规划”的实际需求。
- **实验相对客观**：统一测试集、统一成功判据、固定初始噪声，并主动报告基准更优的测量结果。
- **仿真 + 真机闭环**：从分布学习、消融、基准对比到三节腱驱动机器人实机执行，形成较完整证据链。

## 摘要
视觉-语言-动作（VLA）模型将视觉观察和语言指令直接映射到机器人动作，但长周期任务需要的不仅仅是动作预测。随着物理状态的变化，智能体必须协调感知、规划、执行、进度验证和恢复。动作预测或模型生成的技能决策本身并不能保证所提议的操作在当前状态下有效，也不能保证其结果将被验证。我们提出了EmbodiedSkills，这是一个统一框架，将每个技能决策视为执行提议：运行时在执行前检查其前置条件，并在事后验证结果。共享的可执行技能接口在单个智能体循环内连接高层技能选择、受限的低层VLA执行和动作后验证。由于该接口保持不变，低层VLA策略可以在不改变智能体循环的情况下被替换或适配。该接口还将规划、执行、验证和恢复事件记录为结构化轨迹，为各个组件提供监督，并在交互式反馈可用时支持可选的在线适应。我们使用Qwen3-VL和OpenPI/pi0.5在RoboTwin 2.0和LIBERO上实例化了EmbodiedSkills。任务适应的低层VLA策略在50个RoboTwin 2.0任务中平均成功率达到86.20%，在四个LIBERO套件中平均成功率达到97.40%。这些结果验证了EmbodiedSkills中使用的任务适应的低层VLA策略的执行性能。在四个依赖记忆的RMBench任务上，相同的任务适应执行方法平均成功率为12.5%。该框架提供了一个可训练和可检查的智能体层，用于将这些策略转化为闭环具身系统。

## Abstract
Vision-language-action (VLA) models map visual observations and language instructions directly to robot actions, but long-horizon tasks require more than action prediction. An agent must coordinate perception, planning, execution, progress verification, and recovery as the physical state evolves. An action prediction or a model-generated skill decision does not, by itself, guarantee that the proposed operation is valid in the current state or that its outcome will be verified. We propose EmbodiedSkills, a unified framework that treats each skill decision as an execution proposal: the runtime checks its prerequisites before execution and verifies the outcome afterward. A shared executable-skill interface connects high-level skill selection, bounded low-level VLA execution, and post-action verification within a single agent loop. Because this interface remains fixed, low-level VLA policies can be replaced or adapted without changing the agent loop. The interface also records planning, execution, verification, and recovery events as structured trajectories, which provide supervision for individual components and can support optional online adaptation when interactive feedback is available. We instantiate EmbodiedSkills with Qwen3-VL and OpenPI/pi0.5 on RoboTwin 2.0 and LIBERO. Task-adapted low-level VLA policies achieve an average success rate of 86.20% across 50 RoboTwin 2.0 tasks and 97.40% across the four LIBERO suites. These results establish the execution performance of the task-adapted low-level VLA policies used in EmbodiedSkills. On four memory-dependent RMBench tasks, the same task-adapted execution approach achieves 12.5% average success. The framework provides a trainable and inspectable agent layer for turning these policies into closed-loop embodied systems.

# EmbodiedSkills 论文详细总结

## 1. 论文的核心问题与整体含义

- 论文关注**长时程机器人操作任务中的“智能体层（agentic layer）”问题**。现有 VLA（视觉-语言-动作）模型擅长将观测和语言指令映射为动作，但完成一个长时程任务还需要感知、规划、执行、进度验证和失败恢复等能力的协同。
- 核心难点在于：**一个动作预测或模型生成的技能决策，即使表面上合理，也不能保证它在当前物理状态下是可执行的，更不能保证执行后真的达成预期结果**。这类问题在部分可观测、反馈延迟、接触密集的操作场景中尤为突出。
- 因此论文提出 **EmbodiedSkills**：把技能决策当作“执行提案（execution proposal）”，在执行前由运行时检查前置条件，在执行后验证结果；希望通过一个统一框架把高层规划、低层 VLA 执行、验证与恢复整合成一个闭环智能体。
- 整体意义在于：将“模型决策”与“可执行运行语义”分离，使 VLA 策略不再只是生成动作的模型，而是可以被编排、训练、检查并闭环部署的完整具身智能体。

## 2. 方法论

### 2.1 核心思想

- **技能契约（Skill Contract）**：每个可执行技能定义为
  `k = (Xk, Yk, prek, execi, postk, failk)`，
  包括带类型的输入/输出、前置条件、执行操作、状态更新和失败映射。
- **策略—运行时分离（Policy–Runtime Separation）**：
  - 高层策略只负责“提议”结构化技能决策；
  - 独立运行时负责校验前置条件、输入新鲜度、动作合法性和状态转移的合法性。
  - 模型输出在被验证前只视为“提案”，而非物理状态改变。

### 2.2 智能体状态与决策

- 循环状态定义为：
  `st = (zt, Mt, Ht)`，其中 `zt` 为当前阶段，`Mt` 为任务产物集合，`Ht` 为轨迹历史。
- 高层策略在压缩上下文 `Ct = Ψ(x, zt, Mt, Ht)` 下产生三类结构化控制决策：
  - `RunSkill(k, q)`：执行某个当前阶段允许的技能；
  - `AdvanceStage`：前移到下一阶段；
  - `FinishRun`：终止整个循环。

### 2.3 六阶段技能空间

运行时的阶段集合为：

`Z = (Observe, Plan, Preflight, Execute, Verify, Recover)`

- 其中每个阶段对应不同语义操作，例如感知场景、构建子目标计划、执行前预检、执行有界动作块、验证子目标是否推进、失败恢复。
- 这些阶段**不是固定单向流水线**，策略可以根据新的观测、失败证据或验证结果返回之前的阶段。

### 2.4 受保护的状态转移

- 系统对三类决策分别设置了守门条件：
  - 技能执行：校验阶段匹配、技能是否属于当前阶段、所有前提是否满足；
  - 阶段前移：检查当前阶段是否已产生后继阶段所需证据；
  - 终止：单独的控制门。
- 成功的技能执行更新状态并记录运行结果；无效或被阻断的决策会被记录为显式证据，而不是直接变成物理动作。

### 2.5 有界动作执行

- 低层 VLA 策略在 Execute 阶段接收当前子目标、当前观测、机器人状态和预检证据，生成有界动作块：
  `at = (τt, Ut, Ht, ηt)`。
- 运行时对动作块检查：长度不超过上限、符合策略动作模式、数值合法、与当前子目标和观测一致。
- 一个语义子目标可能需要多个动作块；执行完每个动作块后都要重新获取观测，再决定继续执行、推进或恢复。

### 2.6 验证与恢复

- 验证阶段只针对当前活动子目标，在动作块执行后的新证据下输出语义路由：
  `{Advance, Continue, Reobserve, Replan, Recover, Finish}`。
- 恢复阶段基于显式状态和失败证据生成修订后的执行上下文，并重新经过预检后才能执行新的物理动作。
- 整体任务是否成功仍由环境评测器定义，而不是局部的子目标判断。

### 2.7 训练机制

- **组件级监督适应**：分别训练规划器、调度器/验证器和低层 VLA 策略：
  - 规划器学会将任务指令分解为可执行的语义子目标；
  - 低层 VLA 策略用子目标级演示进行微调，在冻结的高层策略下学习“子目标+观测→动作块”；
  - 高层调度器在部署一致的决策轨迹上微调 Qwen3-VL，冻结低层 VLA。
- **部署一致训练样本**：训练时只使用部署时可得的信息，按相同历史压缩规则构造上下文，避免泄漏。
- **可选闭环在线适应**：结构化轨迹也可用于类 GRPO 的在线优化，但论文将其视为可选细化手段，不是主要亮点。

## 6. 论文的主要结论与发现

- **执行层结果**：
  - RoboTwin 2.0 50 任务宏平均成功率 **86.20%**，超过参考 π0.5（82.74%），提升 3.46 个百分点；
  - LIBERO 四个套件平均 **97.40%**，略高于官方 OpenPI 平均（96.85%），在 LIBERO-Long 上优势最明显（+1.2，达到 93.6%）；
  - RMBench 四个记忆依赖任务平均仅 **12.5%**，说明任务适应执行方法在需要记忆的任务上仍很有限。
- **消融结论**：
  - 完整闭环（Full）为 86.2%；去掉中间验证后降至 48.2%；去掉语义子目标条件后降至 34.4%；每个子目标只给一个动作块时仅 19.5%。
  - 这证明：语义子目标分解、动作后验证和“允许同一子目标多次动作块”的组合对长时程任务成功至关重要。
- **总体判断**：
  - 统一技能接口可以支撑跨 benchmark 的强执行性能，同时把规划、验证、低层 VLA 等模块保留为可独立替换和检查的组件；EmbodiedSkills 由此把 VLA 策略转化为闭环具身系统。

## 7. 优点

- **设计思想上**：
  - 明确区分“策略提案”和“运行时强制语义”，避免无效或过时决策直接变成物理动作，并让失败显式化、可诊断。
  - 共享技能接口让低层 VLA 策略可以“即插即用”：替换或适配底策时无需改动整个 AgentLoop。
  - 六阶段是语义结构而非固定流水线，支持根据证据回到上一步，符合真实操作中 re-plan / re-observe / recover 的需求。
- **工程/训练上**：
  - 训练数据与部署输入保持一致；历史压缩规则统一，降低训练/推理不一致风险。
  - 组件级监督适应使各模块可独立优化，并可冻结低层策略单独训练高层调度，减少连续控制与决策学习的耦合。
  - 结构化轨迹既支持诊断也支持可选的在线优化，扩展性好。
- **实验分析上**：
  - RoboTwin 2.0 做了完整的 50 任务对比，不只报平均分；
  - AgentLoop 消融设计干净，能分离语义子任务、验证、重复动作块各自贡献；
  - 在 LIBERO 上确认了长时程套件获益最大，结论具有一致性。

## 8. 不足与局限

- **部署成本高**：RoboTwin 2.0 实例采用 50 个任务各自微调专用策略，训练、存储和维护成本高于单一通用策略；论文也承认需要更强的子目标条件化通用策略。
- **组件能力瓶颈**：闭环系统整体仍受限于规划器/验证器/底策的校准质量；即使技能契约阻止非法转移，模型仍可能“合法”地选错接地对象或子目标。
- **验证存在盲区**：当进度被遮挡、视觉上模糊或依赖无法从视图推断的属性时，验证器不可靠。
- **延迟开销**：多阶段闭环引入额外 VLM 调用和事后观测，比单次前向动作策略延迟更高。
- **长程误差累积**：长 episode 会积累小的规划/执行错误，导致更多重试和模型调用。
- **实验范围有限**：没有真实机器人实验；RMBench 记忆任务成功率很低，显示在“记忆依赖”方面目前方法并不足够。
- **对比公平性存疑**：RoboTwin 上“Ours 超过 π0.5”更多受益于任务内微调，和论文标题强调的“统一编排框架”之间需要谨慎解读；框架本身带来的收益主要由消融而非与同类智能体框架的端到端对比来证明。
- **未报告算力细节**：没有给出训练时间/GPU 用量，难以判断可复现性和成本。

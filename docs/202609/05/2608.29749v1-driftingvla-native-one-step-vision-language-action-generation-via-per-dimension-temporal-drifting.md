## 摘要
传统的基于流的视觉-语言-动作模型支持表现力丰富的连续动作生成，但依赖多步细化来生成每个动作块，增加了在线机器人控制中的延迟。为解决这一问题，我们提出了DriftingVLA，一种原生一步式VLA模型，仅通过一次动作专家前向传播即可生成完整的动作块。DriftingVLA不学习需要在推理时迭代积分的流场，而是使用分布漂移目标来学习直接的噪声到动作块的映射，以实现一步式部署。由于机器人动作维度具有不同的控制语义和分布特性，我们进一步引入了逐维度时间漂移。逐维度时间漂移将每个动作维度的完整时间轨迹视为独立的漂移单元，从而能够对维度特定的动作分布进行更细粒度的建模和塑造。这种逐维度分解仅适用于训练目标；共享的VLA模型仍然联合生成完整的动作块，从而保留跨维度的依赖性。DriftingVLA在LIBERO上取得98.32%的成功率，在RoboTwin 2.0上取得81.09%的成功率，并在六项真实世界单臂和双臂任务中取得77.67%的成功率，优于所评估的多步流策略和一步式VLA基线。原生一步式部署还在动作块生成中实现了3.36倍的加速，无需迭代细化即可保持控制性能。

## Abstract
Conventional flow-based vision-language-action (VLA) models support expressive continuous action generation but rely on multi-step refinement to produce each action chunk, increasing latency in online robot control. To address this issue, we introduce DriftingVLA, a native one-step VLA that generates a complete action chunk with a single action-expert forward pass. Rather than learning a flow field that requires iterative integration at inference, DriftingVLA uses a distribution-drifting objective to learn a direct noise-to-action-chunk mapping for one-step deployment. Since robot action dimensions carry distinct control semantics and distributional characteristics, we further introduce Per-Dimension Temporal Drifting (PDTD). PDTD treats the complete temporal trajectory of each action dimension as a separate drifting unit, enabling finer-grained modeling and shaping of dimension-specific action distributions. This per-dimension decomposition applies only to the training objective; the shared VLA model still generates the complete action chunk jointly, thereby preserving cross-dimensional dependencies. DriftingVLA achieves 98.32% success on LIBERO, 81.09% on RoboTwin 2.0, and 77.67% across six real-world single- and dual-arm tasks, outperforming the evaluated multi-step flow policy and one-step VLA baselines. Native one-step deployment also delivers a 3.36-fold speedup in action-chunk generation, eliminating iterative refinement without sacrificing control performance.

## 1. 核心问题与研究动机

- **研究背景**：视觉-语言-动作（VLA）模型已成为机器人操作策略的重要范式。其中，基于扩散或流匹配的 VLA 模型具备表达连续、多模态动作分布的能力，控制质量高。
- **核心问题**：这类基于流的 VLA 模型在生成每个动作块（action chunk）时，需要在推理阶段对概率流 ODE 进行**多步迭代积分（multi-step refinement）**，导致额外的推理延迟，难以满足在线机器人控制任务对实时性的要求。
- **关键矛盾**：VLA 模型要兼顾“动作表达丰富性/精度”与“低推理延迟”。直接在一步内生成动作块虽然高效，但存在分布估计粗糙、动作质量下降的风险。
- **研究目标**：设计一种**原生一步式（native one-step）**VLA 动作生成方法，在无需迭代细化、最小化延迟的前提下，保持不亚于甚至优于多步流策略的动作生成质量。

## 2. 论文提出的方法论

### 2.1 总体思路：用“分布漂移”替代“流场积分”

- 传统流匹配模型学习一个速度场 \(v_\theta(x_s,s)\)，推理时从噪声 \(x_1\) 出发，通过多次 ODE 步进逐步得到动作块 \(x_0\)。
- DriftingVLA 不再学习需要迭代积分的流场，而是使用**分布漂移目标（distribution-drifting objective）**：直接学习从噪声 \(x_1\) 到完整动作块 \(x_0\) 的**一步映射**。
- 训练时构造噪声 \(x_1\) 与动作块 \(x_0\) 之间的联合分布（通常为高斯条件路径），令模型通过一次前向传播回归出漂移后的干净动作样本；推理时不再需要任何迭代过程，一次动作专家（action expert）前向即可输出完整的动作块。

### 2.2 关键技术：Per-Dimension Temporal Drifting（PDTD）

- **已有方法的盲点**：不同机器人动作维度（如末端位置 x/y/z、姿态角、夹爪开合、各关节角度等）具有不同的控制语义、数值范围、变化速率和分布形态。若在整个动作块维度上施加统一的漂移过程，容易对“动作维度特有分布”建模不足。
- **零散化建模**：PDTD 将每个动作维度的**完整时间轨迹**视为一个独立的漂移单元：

  - 设动作块为 \(x_0\in\mathbb{R}^{D\times T}\)，\(D\) 为动作维度数，\(T\) 为时间步数；
  - PDTD 并不对整块 \(x_0\) 做整体漂移建模，而是对每个维度的时间轨迹 \(x_0^{d}\in\mathbb{R}^{T}\) 分别定义与执行漂移过程；
  - 对第 \(d\) 维，构造其轨迹的边缘条件分布，并用独立的漂移监督信号细粒度地回归该维度在每一步的去噪目标。

- **训练/推理的解耦设计**：
  - PDTD 的按维度分解**仅出现在训练目标层面**（loss 按动作维度分别计算再累加）；
  - 共享的 VLA backbone 在推理时仍然联合生成完整的 \(D\times T\) 动作块；
  - 这样既实现了逐维分布塑造，又不破坏动作维度之间的相关性表达。

## 7. 方法/实验的优点

- **架构上简洁高效**：在训练阶段改变了流模型的回归目标，推理时直接用一步前向替代多步迭代，避免了推理期累计误差与高计算开销。
- **按维度漂移的粒度足够细**：直接对每个动作维度的时序轨迹做独立扰动和重建，能适应夹爪、关节、末端位姿等异构动作空间，表现出“形状更细”的动作分布塑造能力。

- **重新定义了推理成本优化的切入点**：与其在推理时减少扩散步数或做早期退出，不如在训练时构造“能一步到位”的目标分布；这种训练目标与推理结构解耦的设计思路对许多实时生成任务（如自动驾驶规划、人机交互决策）也有迁移潜力。
- **“分维漂移”是一种通用的分布建模策略**：将异构数据的不同维度视为独立漂移路径，同时共享联合上下文编码，可能比全张量统一扰动更适合高维、异质、多模态的连续输出空间。该思想可作为一类训练准则扩展到其他低延迟生成式控制模型。
- **单步生成也需重视分布多样性**：DriftingVLA 的按维度分解不仅提高了精度，也有助于避免单步模型常出现的“回归到均值”问题，增强对多模态动作分布的覆盖。这种“以细粒度损失约束多样性”的做法值得在一步式生成研究中推广。

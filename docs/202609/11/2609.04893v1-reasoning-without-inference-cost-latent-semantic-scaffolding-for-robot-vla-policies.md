## 摘要
视觉-语言-动作（VLA）模型通过模仿学习训练，能捕捉该采取什么动作，却无法捕捉为何如此；引入因果推理可提升操作性能，但当前方法需在推理时付出代价——每一步都生成推理 token 或推演预测的未来状态，而这种成本在长时程中会不断累积。我们探究这种收益能否改为在训练期间捕获，并在部署前丢弃。我们提出潜在语义脚手架（Latent Semantic Scaffolding, LSS），一种在人类演示预训练期间施加的辅助损失，通过一个小型投影头将 VLA 的动作 token 表示与物理推理理由的文本嵌入对齐。推理时丢弃该投影头，从而保持未修改的基础策略，且不增加任何成本。我们的核心发现关乎对齐粒度：将每个动作 token 对齐到其自身操作阶段的理由（Dense LSS），而非对齐到单个池化后的回合级嵌入（Pooled LSS），可得到明显更好迁移至留出任务的表示。Dense LSS 同时取得最佳的分布内成功率和最佳的向对齐期间未见任务迁移的效果，而池化对齐则过度专门化于训练任务。表征探针显示，Dense LSS 在主干中诱导出约两倍的逐阶段可分性，支持阶段局部对齐是有效机制。

## Abstract
Vision-language-action (VLA) models are trained by imitation and capture what action to take but not why; adding causal reasoning improves manipulation, but current methods pay for it at inference time - generating reasoning tokens or rolling out predicted future states at every step, a cost that compounds over long horizons. We ask whether this benefit can instead be captured during training and discarded before deployment. We introduce Latent Semantic Scaffolding (LSS), an auxiliary loss applied during human-demonstration pretraining that aligns a VLA's action-token representations to text embeddings of physical-reasoning rationales through a small projection head. The head is dropped at inference, leaving the unmodified base policy with zero added cost. Our central finding concerns alignment granularity: aligning each action token to the rationale of its own manipulation phase (Dense LSS) rather than to a single pooled episode-level embedding (Pooled LSS) yields representations that transfer markedly better to held-out tasks. Dense LSS attains both the best in-distribution success and the best transfer to tasks unseen during alignment, whereas pooled alignment over-specializes to the training task. A representational probe shows Dense LSS induces roughly twice the per-phase separability in the backbone, supporting that phase-local alignment is the operative mechanism.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：视觉-语言-动作（VLA）模型通过模仿学习从大规模机器人/非机器人演示中学习感知到动作的映射，近年来还流行先在自我中心人类演示上预训练、再用少量机器人数据微调。但纯模仿策略只学到动作的"what"，缺乏对任务因果与物理结构的"why"理解。
- **现有做法的代价**：将推理注入策略可提升操作性能，尤其是多步骤与分布外泛化任务，但当前方法几乎都在**推理时**兑现这一收益：
  - 具身思维链（ECoT）在每次动作前自回归生成文本推理轨迹；
  - 视觉思维链（CoT-VLA）先预测未来图像子目标再行动；
  - 世界动作模型（WorldVLA 等）联合预测未来状态与动作。
  - 这些方法每一步都重复支付推理/预测开销，长时程任务中成本累积；已有鲁棒性研究报告世界动作模型每个动作块比同类流匹配 VLA 慢 **4.8×～83×**，并催生了专门降低 ECoT 开销的效率工作。
- **另一个问题**：标准 VLA 监督过于粗糙——整条轨迹只配一句指令，语言子部分与动作子片段之间没有对应关系；现有细粒度数据集多把子任务当作预测/分割标签，而非因果理由。
- **核心研究问题**：推理的收益是否必须在推理时支付？能否在训练阶段捕获、在部署前丢弃？
- **作者假设**：如果推理的作用是**塑造策略内部表征**，而非逐步生成，那么收益可以被"烘焙"进权重，从而规避运行时开销。论文以此提出 **LSS（Latent Semantic Scaffolding，潜在语义脚手架）**，并进一步研究"对齐应如何结构化"这一关键问题。

## 2. 方法论

### 2.1 核心思想
- 在人类演示预训练阶段引入一条**辅助对齐损失**：用一个轻量投影头，把 VLA 的动作 token 隐藏状态对齐到"物理推理文本"的 T5 嵌入。
- 推理文本**从不作为策略输入**，也不参与条件化；它只作为对齐目标。语言条件仅来自任务指令。
- 整个对齐装置（LSAHead + 推理文本编码器）**只在训练期存在，推理前丢弃**，部署的是未修改的基座策略。

### 2.2 基座与三阶段流程
- 基座为 **H-RDT**：DINO + SigLIP 视觉编码器、冻结的 **T5-XXL** 指令编码器、**2B 参数**扩散 Transformer 主干、流匹配（flow-matching）动作头；主干输出 **K=16 个动作 token**，$Z_{act}\in\mathbb{R}^{K\times 2176}$，由动作头解码为轨迹，主损失为 $L_{flow}$。
- 原配方为"人类预训练 + 机器人微调"两阶段；论文在中间插入第二阶段（LSS 生效），构成三阶段：**(i) 人类预训练 → (ii) LSS 人类预训练 → (iii) 机器人微调**。
  - 阶段 2 监督 H-RDT 的 48 维统一人类动作表示；阶段 3 微调到 14 维机器人动作。

### 2.3 Pooled LSS（池化对齐）
- 投影头 LSAHead $g_\phi: \mathbb{R}^{2176}\to\mathbb{R}^{4096}$，为两层 MLP（2176→2176，GELU，2176→4096）。
- 将 16 个动作 token 均值池化为 $\bar z$，与整段推理文本的池化嵌入 $e_{text}=\text{MeanPool}(E_{T5}(T_{reason}))$ 做余弦距离对齐：
  $$L_{LSS}=1-\frac{g_\phi(\bar z)\cdot e_{text}}{\|g_\phi(\bar z)\|\,\|e_{text}\|},\qquad L_{total}=L_{flow}+\lambda L_{LSS}$$
- 取 $\lambda=0.1$，使对齐只作为**次级压力**，重塑动作表征而不压倒动作预测。

### 2.4 Dense LSS（阶段局部对齐，论文核心）
- 动机：均值池化同时压扁了 16 个动作 token 与多阶段推理文本，丢弃了时序顺序与逐阶段因果内容。
- 具体做法：
  - 推理文本被切分为 P 个**有序阶段**，来自固定词表（approach / grip / rotate / withdraw），每阶段带一句因果理由与帧范围；
  - 每阶段经 T5 编码 + 掩码均值池化得到逐阶段目标 $e_p$；
  - 每个动作 token 覆盖固定帧数（upsample_rate = 3），按其帧所属阶段分配；约 **5%** 跨越阶段边界的 token 被掩码排除（集合 $M$）；
  - 逐 token 对齐到其自身阶段目标：
    $$L_{dense}=\frac{1}{|M|}\sum_{i\in M}\Big[1-\frac{g_\phi(z_i)\cdot e_{p(i)}}{\|g_\phi(z_i)\|\,\|e_{p(i)}\|}\Big]$$
  - 总目标 $L_{total}=L_{flow}+\lambda L_{dense}$。
- 池化版与稠密版架构完全相同，**唯一区别是对齐目标**（单一池化嵌入 vs 阶段局部嵌入）。
- 作者明确指出该设计存在**前提依赖**：Dense LSS 依赖可靠的阶段边界，噪声分割可能错配 token 并劣于池化，因此"池化 vs 稠密"是实证问题而非必然胜负。

### 2.5 训练专用设计与零推理开销
- 算法流程（文字版）：预计算并缓存所有阶段的 T5 目标 → 每个 minibatch 前向得到 16 个动作 token → 计算流匹配损失 → 为每个 token 分配阶段并掩码跨界 token → 计算 $L_{dense}$ → 以 $\nabla(L_{flow}+\lambda L_{dense})$ 更新主干 $\theta$ 与投影头 $\phi$。
- 推理时丢弃 $g_\phi$ 与 T5 推理编码器，部署计算图与未加 LSS 的基座 VLA 完全一致，参数量与单步延迟相同，**零额外成本**。

### 2.6 推理标注流水线
- 每条轨迹的理由由 **Gemini-3-flash** 离线生成，提示其解释操作的因果结构（物体状态触发与物理响应），而非叙述动作过程。
- 对 Dense LSS，模型额外返回阶段分割（阶段标签 + 时间比例区间），再转换为动作帧范围。
- 阶段边界主要通过 **VLM 与人工视频对比**验证；运动学交叉检查仅作诊断记录。**未对生成文本做正式质量控制**（作者自认的局限）。

## 摘要
通过模仿学习训练的机器人操作策略不仅继承了示教行为，还继承了机器人示教中保守的执行节奏。现有的加速方法虽然能比原始示教执行得更快，但主要依据机器人侧信息或预定义的一组节奏因子来确定合适的加速幅度，仍未解决如何获得每个操作阶段应以多快速度推进的任务适宜参考。我们提出 EgoSpeedUp，一个将人类操作作为机器人模仿学习时序监督的框架。我们的关键洞见是，人类示教自然揭示了任务适宜、分阶段的操作节奏。给定同一任务的缓慢机器人示教和人类示教，EgoSpeedUp 对齐对应的操作阶段，从多个人类示教中估计其相对执行节奏，并通过重新调整机器人示教的时间来迁移由此得到的分阶段节奏。随后，重定时的示教用于标准行为克隆，使机器人能够保留其可执行的操作行为，同时学习以人类示教所指示的节奏执行该行为。在两个真实世界操作任务中，EgoSpeedUp 将任务成功率平均提高 25 个百分点（pp），同时将成功执行时间缩短 36.5%。这些结果表明，人类操作节奏为学习更快、更可靠的机器人策略提供了有效的时序参考。

## Abstract
Robot manipulation policies trained through imitation learning inherit not only the demonstrated behavior but also the conservative execution tempo of robot demonstrations. Existing acceleration approaches can execute faster than the original demonstrations, but determine the appropriate acceleration primarily from robot-side information or a predefined set of tempo factors, leaving open how to obtain a task-appropriate reference for how fast each manipulation phase should progress. We introduce EgoSpeedUp, a framework that uses human manipulation as temporal supervision for robot imitation learning. Our key insight is that human demonstrations naturally reveal task-appropriate, phase-wise manipulation tempo. Given slow robot demonstrations and human demonstrations of the same task, EgoSpeedUp aligns corresponding manipulation phases, estimates their relative execution tempos from multiple human demonstrations, and transfers the resulting phase-wise tempo by retiming the robot demonstrations. The retimed demonstrations are then used for standard behavior cloning, allowing the robot to retain its executable manipulation behavior while learning to perform it at a human-informed tempo. Across two real-world manipulation tasks, EgoSpeedUp improves the task success rate by an average of 25 percentage points (pp) while reducing successful execution time by 36.5%. These results demonstrate that human manipulation tempo provides an effective temporal reference for learning faster and more reliable robot policies.

- **问题根源**：模仿学习（IL）训练的机器人操作策略不仅继承了示教行为，还继承了机器人示教的**保守执行节奏**。机器人示教通常通过遥操作采集，操作者优先保证精确与成功，因而速度偏慢；即使是有经验的操作者，遥操作时的运动流畅度也不如直接手操作。
- **现有加速方法的共同缺口**：已有"快于示教"（faster-than-demonstration）方法（如基于策略不确定性的时间压缩、按运动复杂度调速、语义推理选段加速、速度增强+RL 微调、状态相关速度选择等）虽能加速，但目标节奏因子主要来自**机器人侧信息**（示教本身、学习目标、后续交互）或**人工预设的离散倍率/倍率范围**。
- **核心痛点**：一个任务中"每个操作阶段应该多快"缺乏**外部、任务适配的参考**；而合适节奏随任务差异极大，靠机器人侧信息难以直接确定。
- **关键洞见**：成功的人类操作视频中天然隐含了任务适宜、**分阶段（phase-wise）**的操作节奏（人类动作时序会随精度与控制需求变化，例如抖直绳子时的快速甩动）。因此可将**人类操作节奏作为机器人模仿学习的时间监督**。
- **整体含义**：论文提出 EgoSpeedUp，在保留机器人自身可执行动作行为的前提下，让策略学会以"人类告知的节奏"完成任务，从而同时改善**成功率—执行时间**的权衡。

## 2. 方法论

### 2.1 核心思想

- 给定同一任务的**缓慢机器人示教**与**人类示教**，将两者分割为共享的、有序的操作阶段，做**单调阶段匹配**（monotonic phase matching）。
- 由对应阶段长度之比得到**阶段级相对节奏比**，在多个（M 个）人类示教上聚合，得到每个机器人 episode、每个阶段的目标节奏因子。
- 用该节奏因子对机器人**未来动作目标（action chunk）重定时**，与**原始机器人观测**配对后进行标准行为克隆（BC）。人类时序只通过动作目标进入学习目标，不改变观测与采样流程。
- 部署时策略仅凭机器人观测预测动作块，**不需要阶段标注或节奏查表**。

### 2.2 关键技术细节与算法流程

- **预备：动作分块模仿学习**。给定观测 $o_{e,t}$，策略预测 H 步未来动作 $A_{e,t}=[a_{e,t},\dots,a_{e,t+H-1}]$。
- **基于节奏的动作重定时**。给定节奏因子 $v\ge 1$，重定时目标为
  $$\tilde A_{e,t}(v)=[a_e(t+(j+1)v-1)]_{j=0}^{H-1}$$
  非整数索引处用线性插值；$v=1$ 还原原动作块，$v>1$ 则取更靠后的未来动作，从而加快任务推进。
- **阶段分割与标注**：
  - 使用 Embodied Chain-of-Thought（ECoT）流水线生成语义子任务标注，整合为任务特定的阶段 schema（如 approach、grasp、manipulation、release）。
  - 再用**物理交互线索**精修语义边界：机器人侧以夹爪闭合/张开事件与操作进程为锚点；人类侧由手—物交互、耦合物体运动、释放事件确定。
  - 人类侧具体实现：WiLoR 检测 2D 手部关键点，借助深度流将拇指与食指指尖三维追踪；由两指尖 3D 距离判断手张开/闭合；用 SAM 2 跟踪被操作物体。抓取起点由手—物接近度加任务特定物体响应（绳子形变 / 持续接近并出现手—物耦合运动）判定；释放由手—物分离与手张开判定（Block 还要求托盘内稳定放置）。
- **单调阶段匹配**：共享阶段 schema 下，机器人第 p 阶段与每个人类示教的第 p 阶段对应，保持任务推进顺序，但**不要求各示教阶段时长相等**。
- **目标节奏因子估计**：
  - 阶段长度 $\ell^R_{e,p}=b^R_{e,p+1}-b^R_{e,p}$，$\ell^H_{m,p}=b^H_{m,p+1}-b^H_{m,p}$。
  - 成对节奏比 $r_{e,p,m}=\ell^R_{e,p}/\ell^H_{m,p}$（>1 表示人类该阶段步数更少，可加速）。
  - 聚合：$\bar r_{e,p}=\frac{1}{M}\sum_m r_{e,p,m}$，$\hat v_{e,p}=\max\{1,\bar r_{e,p}\}$。
  - 重要设计：**先对每对"人—机器人阶段长度比"求平均，再取 max**（而非先平均人类阶段长度再相除）；下界 1 保证不减速。
  - $\hat v_{e,p}$ 既依赖 episode（反映机器人阶段长度变化），又依赖阶段（保留人类提供的时间结构）。
- **节奏引导的动作目标构造**：训练窗口起点时刻 $t$ 所属阶段为 $p_e(t)$，取 $v_{e,t}=\hat v_{e,p_e(t)}$，把原动作块替换为重定时目标 $\tilde A_{e,t}(v_{e,t})$；损失为 $\mathcal L_{\text{EgoSpeedUp}}=\mathbb E_{(e,t)\sim D^R}[\ell_{BC}(\theta;o_{e,t},\tilde A_{e,t})]$。
- **骨干**：采用基于 flow 的视觉运动策略骨干（ManiFlow），保留其训练损失与推理流程。

## 3. 实验设计

- **硬件平台**：Universal Robots UR5e 机械臂 + Robotiq Hand-E 平行夹爪 + 两台 Intel RealSense D435 RGB-D 相机（固定工作区视角 + 腕部视角）。观测为两相机各连续两帧 RGB（缩放至 224×224）加机器人本体感知；7 维动作为 6 个关节位置目标 + 1 个夹爪指令。
- **任务（2 个真实操作任务，形成对比性时间需求）**：
  - **Rope（抖直绳子）**：抓取可变形绳子并操作至伸直，含抓取获取与动态操作，快速运动有助于抖直。
  - **Block（积木搬运）**：搬运承载两块堆叠红块的黄色基块至目标区域，同时保持堆叠稳定，过度加速可能有害。
- **数据**：每任务 80 条机器人示教（3D 鼠标遥操作）+ 40 条同任务第一人称人类示教；机器人约 10 Hz，人类约 20 Hz；覆盖末端执行器与物体初始构型变化。所有对比方法使用**相同的机器人训练集**。
- **阶段定义**：Rope = approach / grasp / straighten / release；Block = approach / grasp / place / release。
- **对比方法（同一 ManiFlow 骨干）**：
  - **Nominal**：原始动作目标，无时间修改。
  - **Global 2× / 4×**：全局固定节奏因子。
  - **DemoSpeedup**：熵引导示教加速，高精度段 2×、低精度段 4×。
  - **SpeedAug-prior**：预定义 1×–3× 范围的速度增强（RL 微调前，以隔离增强本身的效果）。
  - **AutoSpeed**：基于机器人侧预测目标，在预定义 0.8×–2.2× 范围内选择目标。
  - **EgoSpeedUp**（本文）。
- **评价指标**：任务成功率；**成功 episode** 的均值/中位执行时间；Speedup = 同任务 Nominal 平均成功执行时间 / 对比方法的对应值（描述成功 episode 时长，而非吞吐或失败尝试代价）。
- **试验规模**：每任务每方法 **20 次试验**（2 个策略随机种子 × 10 个初始位姿），共 40 次/方法。

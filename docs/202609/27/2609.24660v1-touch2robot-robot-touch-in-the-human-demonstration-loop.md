## 摘要
人类演示为收集操作数据提供了一种可扩展的方式，但当其接触迁移到机器人手时，可能不稳定或不可行。直接在目标机器人上收集演示可以避免这种不匹配，但会大幅增加数据收集成本。为解决这一权衡，我们提出了 Touch2Robot，一个让人类在收集演示的同时看到目标机器人手将如何接触物体的框架。我们捕捉人类操作过程中的人手运动、触觉手套测量和物体运动。这些记录指导针对特定物体的 RL 策略复现所演示的物体运动，同时偏好与所记录人类触觉一致的接触。我们将学习到的行为蒸馏为一个统一的实时重定向器，将输入的人类观测和物体几何映射为机器人手构型。在收集过程中，预测的机器人构型与仿真中跟踪的物体位姿同步，以重建机器人-物体接触，并将其可视化，以帮助演示者调整后续交互以适应目标手。在四个真实世界任务中，与仅视觉反馈相比，Touch2Robot 将平均真实机器人回放完成率从 37.9% 提高到 72.1%，同时将每次回放成功的演示所需收集时间从 58.6 s 减少到 18.2 s。重建的目标手接触相对于真实机器人触觉测量达到 44.2% F1，而在 Touch2Robot 演示上训练的策略使下游 Diffusion Policy 性能比仅视觉反馈提高 29.1 个百分点。这些结果表明，将机器人触觉引入人类演示回路可以提高可扩展灵巧数据收集的质量和效率。项目网页：https://Touch2Robot.github.io/。

## Abstract
Human demonstrations offer a scalable way to collect manipulation data, but their contacts may be unstable or infeasible when transferred to a robot hand. Collecting demonstrations directly on the target robot avoids this mismatch, but substantially increases the cost of data collection. To address this trade-off, we present \textbf{Touch2Robot}, a framework that lets humans collect demonstrations while seeing how the target robot hand would contact the object. We capture human hand motion, tactile-glove measurements, and object motion during human manipulation. These recordings guide object-specific RL policies to reproduce the demonstrated object motion while favoring contacts consistent with the recorded human touch. We distill the learned behaviors into a unified real-time retargeter that maps incoming human observations and object geometry to robot hand configurations. During collection, the predicted robot configuration is synchronized with the tracked object pose in simulation to reconstruct robot-object contacts, which are visualized to help the demonstrator adapt subsequent interactions to the target hand. Across four real-world tasks, Touch2Robot improves average real-robot replay completion from 37.9\% to 72.1\% over visual-only feedback, while reducing the collection time per replay-successful demonstration from 58.6~s to 18.2~s. Reconstructed target-hand contacts achieve 44.2\% F1 against real-robot tactile measurements, and policies trained on Touch2Robot demonstrations improve downstream Diffusion Policy performance by 29.1 percentage points over visual-only feedback. These results show that bringing robot touch into the human demonstration loop improves both the quality and efficiency of scalable dexterous data collection. \textit{Project webpage: \href{https://Touch2Robot.github.io/}{https://Touch2Robot.github.io/}.}

# Touch2Robot：人类演示回路中的机器人触觉 —— 论文深度总结

## 1. 核心问题与整体含义

- **研究背景**：灵巧操作依赖与目标机器人本体相匹配的接触演示。人类演示成本低、可扩展，但人手形态与运动学决定了其接触模式；这些接触迁移到机器人手上时可能不稳定或不可行。
- **核心矛盾**：
  - 人类中心采集（如 DexCap、ARCap）易扩展，但**不暴露目标机器人的接触状态**；
  - 机器人遥操作（如 AnyTeleop）能直接采集本体兼容接触，但**每条演示都需昂贵硬件**；
  - 人类到机器人重定向（如 ConTrack、DexMachina）能可视化重定向后的手，但**仅看手部姿态无法判断接触是否建立、何时建立、是否可行**。
- **核心研究问题**：能否让人类在**不执行物理机器人**的前提下，于演示采集过程中看到目标机器人手的接触状态，并据此调整动作？
- **整体含义**：论文提出把"机器人触觉"引入人类演示回路，将人类触觉视为一种**跨本体的接触偏好（cross-embodiment contact preference）**——物体运动规定"应发生什么"，人类触觉指导"机器人应如何接触"。这为可扩展的灵巧数据采集提供了新范式。

## 2. 方法论

### 核心思想
分三阶段：先用人类触觉偏好训练**物体特定的 RL 教师**，再蒸馏为**统一实时重定向器**，最后在采集时通过**仿真接触重建**提供在线触觉反馈。

### 阶段一：触觉引导的 RL 重定向
- **共享语义接触空间**：将人手与机器人手映射到 K 个语义区域（指尖、手掌、侧接触区），表示为二值向量 $c^H_t, c^R_t \in \{0,1\}^K$。
- **接触时序演化**：$\Delta c^H_t = c^H_t - c^H_{t-1}$，$\Delta c^R_t = c^R_t - c^R_{t-1}$。
- **触觉奖励**（同时匹配瞬时接触模式与时序演化）：
  $$r^{tac}_t = -D(c^H_t, c^R_t) - \lambda_\Delta D(\Delta c^H_t, \Delta c^R_t)$$
  其中 $D(u,v)=\frac{1}{K}\sum_{i=1}^{K}|u_i-v_i|$ 为平均绝对差。

### 阶段二：物体特定 RL 教师训练
- **残差动作**：$q^{tar}_t = q^{ref}_t + a^R_t$，策略在机器人侧参考轨迹上输出残差。
- **动作正则**（仅在超出关节特定阈值时惩罚）：
  $$r^{act}_t = -\sum_i \left[\max(0, |a^R_{t,i}| - a^{max}_i)\right]^2$$
- **物体跟踪奖励**：$r^{obj}_t = -w_p(e^{pos}_t)^2 - w_r(e^{rot}_t)^2$。
- **总奖励**：$r_t = \lambda_1 r^{obj}_t + \lambda_2 r^{tac}_t + \lambda_3 r^{act}_t$。
- **引导到自由的动力学课程（Guided-to-Free Curriculum）**：将轨迹分为自由动力学前缀与参考引导后缀，$T_f$ 从 0 逐步增大至 T，最终完全由仿真物理推进物体状态，避免早期小误差导致后续接触学习失败。

### 阶段三：统一重定向器蒸馏
- **输入**：PointNet 编码的物体几何特征 $g_o \in \mathbb{R}^{32}$ + 人类运动/触觉偏好/物体运动的历史 $h_t$。
- **模型**：轻量因果 Transformer 仅用过去观测，同时预测机器人目标构型与接触状态：$(\hat{q}^{tar}_t, \hat{c}^R_t) = f_\theta(h_t, g_o)$。
- **蒸馏损失**：$L_{distill} = \|\hat{q}^{tar}_t - q^{tar}_t\|_2^2 + \lambda_c \text{BCE}(\hat{c}^R_t, c^R_t)$。

### 闭环演示采集
- 采集时记录人类运动、触觉与物体位姿，重定向器预测机器人构型，在仿真中重建机器人-物体接触并映射回目标手语义触觉区域。
- VR 中以 **30 Hz、122 ms 端到端延迟**可视化机器人手运动与接触激活，供演示者实时调整。
- **机器人就绪视觉观测**：用 SAM + ProPainter 分割并修复人手，再用标定相机参数渲染重定向机器人手到修复场景中，供下游视觉运动策略使用。

## 6. 主要结论与发现

- **回放完成率**：Touch2Robot 平均 **72.1%**，显著高于视觉反馈（37.9%）与离线重定向（28.3%）；在 Object Rotation（59% vs 0%）与 Board Wiping（90% vs 49%）上提升最大。
- **采集效率**：每条回放成功演示的采集时间从 **58.6 s 降至 18.2 s**。
- **下游策略**：Diffusion Policy 平均完成分数从视觉反馈的 32.9% 提升至 **62.0%**（+29.1 个百分点）。
- **触觉保真度**：重建接触对真实机器人触觉测量达 **44.19% F1**，接触起始误差降至 857.4 ms，优于 ConTrack（23.77%）与 DexMachina（24.71%）。
- **偏好对齐**：与人类触觉偏好对齐达 **47.53% F1**，起始误差降至 291.7 ms。
- **权衡**：触觉监督带来更高 FPR（6.38% vs 基线约 2–4%），说明在恢复更多真实接触的同时引入了额外虚假激活。
- **时序一致性**：重建接触与人类偏好、真实机器人测量均保持相当一致性，未偏向任一方。
- **用户研究**：接触感知、适应信心、反馈有用性、易用性四项评分均显著提升（p < 0.01）。
- **课程与蒸馏**：动力学课程稳定提升教师训练奖励；统一重定向器保留大部分物体特定教师性能（物体误差 18.05% vs 8.64%，F1 65.46% vs 73.70%），推理延迟仅 1.12 ms。

## 7. 优点

- **问题定位精准**：明确指出现有重定向方法"可视化手部姿态 ≠ 可视化接触状态"的缺口，切中要害。
- **跨本体触觉偏好建模**：将人类触觉作为显式奖励信号，而非仅依赖运动学或几何接触，是方法论上的核心创新。
- **无物理机器人执行的在线反馈**：通过仿真接触重建 + VR 可视化，在保持人类演示可扩展性的同时提供机器人特定接触指导，兼顾质量与成本。
- **工程完整度高**：涵盖触觉语义对齐、RL 教师训练、蒸馏、实时部署、机器人就绪视觉转换、下游策略训练的完整链路。
- **实验维度丰富**：同时评估演示质量、下游策略性能、触觉保真度、偏好对齐、用户主观体验与算法消融，形成较完整的证据链。
- **实时性**：重定向器推理延迟 1.12 ms，VR 反馈端到端延迟 122 ms，满足闭环采集需求。

## 8. 不足与局限

- **触觉表示过于简化**：仅使用二值接触状态，丢失力大小、方向、分布等丰富触觉信息；作者也承认未来需扩展至更丰富的触觉信号。
- **FPR 偏高**：重建接触的假阳性率（6.38%）高于基线，意味着机器人可能建立人类未预期的额外接触，可能影响精细操作。
- **跨手适用性仅定性**：XHand、Shadow、Leap 的跨手结果仅为 VR 可视化，缺少定量评估与真机部署验证。
- **用户研究规模有限**：仅 10 名参与者、单一 Rotation 任务，统计效力与任务泛化性受限。
- **未报告算力资源**：GPU 型号、数量、训练时长均未说明，影响可复现性评估。
- **依赖物体特定 RL 教师**：每个物体需单独训练教师再蒸馏，新物体的扩展成本未充分讨论。
- **接触重建依赖仿真保真度**：真实机器人触觉 F1 仅 44.2%，说明仿真到现实的接触差距仍显著。
- **任务覆盖有限**：四个任务均为单臂单手中的接触密集任务，未涉及双手协调、工具使用或长时程任务。

## 摘要
随着AI智能体能力日益增强，智能体驱动的机器人控制正成为一种颇具吸引力的范式。然而，主流的视觉-语言-动作（VLA）模型和世界动作模型（WAM）仍依赖自然语言指令来指定操作任务，这种接口并不适合智能体驱动的控制：指代存在歧义、空间上不精确、与智能体固有的语言理解能力冗余，并将意图与执行纠缠在一起。我们提出AR-WAM，一种视觉条件化、面向智能体的世界动作模型，用两个互补条件替代语言：一个视觉定位提示（目标的边界框），用于指示交互对象和位置；以及一个可学习的操作token，用于指定要执行的原子技能。我们紧凑的0.5B参数模型采用冻结的预训练视觉编码器，且不含语言编码器；它在解码动作的同时，在紧凑的潜在状态中预测场景演化，并通过显式、可监督的推理信号暴露策略的意图。一个模型无关的兼容层提供三种原语（检测、执行和查询），使本地VLM或在线智能体API能够直接驱动策略，而长时程记忆和闭环错误恢复则交由智能体一侧处理。在RoboTwin 2.0、RMBench以及真实的Astribot S1双臂平台上，AR-WAM在标准操作任务上达到最强基线水平（平均成功率87.2%），并在依赖记忆的任务和真实机器人长时程任务上优于这些基线，成功率分别提升5.9%和36.7%，同时保持最低的推理延迟（14.1 ms）。

## Abstract
As AI agents become increasingly capable, agent-driven robotic control is emerging as a compelling paradigm. However, prevailing vision-language-action (VLA) models and world action models (WAMs) still rely on natural-language instructions to specify manipulation tasks, an ill-suited interface for agent-driven control: referentially ambiguous, spatially imprecise, redundant with the agent's inherent language understanding, and entangling intent with execution. We present AR-WAM, a visual-conditioned, agent-ready world action model that replaces language with two complementary conditions: a visual grounding prompt (a bounding box of the target) denoting the interaction object and location, and a learnable operation token dictating the atomic skill to execute. Our compact 0.5B-parameter model, with a frozen pretrained visual encoder and no language encoder, predicts scene evolution within compact latent states while decoding actions, exposing the policy's intent through explicit, supervisable reasoning signals. A model-agnostic compatibility layer provides three primitives (detect, execute, and query) so that local VLMs or online agent APIs can drive the policy directly, with long-horizon memory and closed-loop error recovery delegated to the agent side. On RoboTwin 2.0, RMBench, and a real Astribot S1 dual-arm platform, AR-WAM matches the strongest baselines on standard manipulation (87.2% average success) and outperforms them on memory-dependent and real-robot long-horizon tasks, improving success rates by 5.9% and 36.7%, respectively, while maintaining the lowest inference latency (14.1 ms).

# AR-WAM 论文总结

## 1. 核心问题与研究动机

- **背景范式**：智能体（agent）作为"高层大脑"负责语言理解、任务分解与记忆，策略模型作为"小脑"负责精确动作执行，是当前机器人控制颇具吸引力的范式。
- **现有两条技术路线**：
  - 视觉-语言-动作（VLA）模型：将互联网级语义知识迁移到连续控制。
  - 世界动作模型（WAM）：预测场景演化并据此解码动作。
- **核心痛点**：两条路线几乎都以**自然语言指令**指定任务，但作者认为在智能体驱动控制中，文本条件化是"不合适的接口"，具体表现为四点：
  1. **指代歧义**：桌面多个相似物体时，文本无法唯一确定目标。
  2. **冗余**：语言理解本是智能体最擅长的事，在策略内重新学习它浪费训练算力。
  3. **空间不精确**：命令需经策略自身的语言编码器，其不完善的地面化妨碍精确操控。
  4. **黑盒纠缠**：把理解、规划、记忆、动作生成塞进一个不可检查的模型，导致失败无法归因于"意图错误"还是"执行不当"。
- **整体含义**：作者主张在智能体时代重新思考策略真正需要的条件信号——现代 VLM 擅长开放词汇感知并直接输出边界框，空间规格比文本更具可操作性。据此提出 AR-WAM，用"视觉定位提示 + 可学习操作 token"替代语言条件。

## 2. 方法论

### 2.1 核心思想
- 将"**在哪里操作**"（grounding，交给外部智能体的强开放词汇感知）与"**如何操作**"（control，交给紧凑策略）解耦。
- 策略被刻意设计为**马尔可夫式**：每次决策仅依赖当前观测与条件（g, s, u, w），不含循环状态；长时程结构、记忆与错误恢复全部交由智能体侧承担。

### 2.2 任务条件化
- **原子操作词汇表** `S = {pick, place, handover, click, pull, ...}`，每个技能由可学习的原子操作嵌入 `e_s` 表示，与策略联合优化；技能边界由执行级事件（如夹爪开合）而非固定时域界定。
- **视觉提示** `g = (x1, y1, x2, y2) ∈ [0,1]^4`（归一化图像坐标边界框），双臂任务扩展为两个框。
- **辅助属性**：参与者属性 `u`（左臂/右臂/双臂）与风格属性 `w`（交互方式，如叠放或并排），各由可学习嵌入表示。
- **条件注入**：`e_s、e_u、e_w` 与轻量 MLP 产生的框嵌入 `φ(g)` 融合为任务条件 token，通过 **AdaLN 条件调制**注入下游专家。
- **形式化**：策略输出动作块
  `â_{t→t+H−1} ∼ π_θ(· | o_t, p_t, φ(g), e_s, e_u, e_w)`，参数 θ 在所有原子操作间共享。

### 2.3 推理专家与前视要点（Foresight Gist）
- 可学习推理查询 token `q_reas` 探测观测与任务条件，产生推理 token `q_t`。
- 轻量 reason head 解码出三类**显式、可监督**的当前步预测：
  - 被框物体的掩码 `m̂_t`（把粗框锐化为像素级目标）；
  - 执行技能终止时双臂末端执行器位姿 `T̂_t`；
  - 结构化 one-hot 任务摘要 `ĉ_t`（用哪只臂、如何抓取与放置）。
- 推理损失：`L_reas = BCE(m̂, m) + CE(ĉ, c) + ‖T̂ − T‖²`。
- **前视要点提取**（离线预训练）：冻结编码器 E 将片段两端帧 `o_t0、o_t1` 映射为隐帧，隐式逆动力学模块压缩其时间演化为前视要点
  `f_{t0→t1} = G_IDM(E(o_t0), E(o_t1))`；隐式前向动力学模块重建未来隐帧 `ê_t1 = G_FDM(E(o_t0), f_{t0→t1})`，以隐重建损失 `L_recon` 训练。要点仅作训练期目标，推理时不使用。

### 2.4 世界动作专家：双层未来对齐
- 与推理专家**共享 transformer 权重**，以不同输入 token 调用，使任务理解直接塑造控制。
- 用**流匹配**联合去噪三个输出模态（共享流时间 τ，各模态独立采样噪声）：动作块、视觉前视预测 `f̂`、语义前视预测 `q̂`。
- 三项损失：
  - 动作：`L_act = E‖f_wam(a_τ, τ) − (a_1 − a_0)‖²`；
  - 视觉前视：`L_vis = ‖f_wam(f_τ, τ) − sg(f_{t→t+H−1})‖²`；
  - 语义前视：`L_sem = ‖f_wam(q_τ, τ) − sg(q_{t+H−1})‖²`。
- 语义目标 `q_{t+H−1}` 由同一权重共享主干在**停止梯度**下在线计算（而非冻结副本）；由于推理 token 被 reason head 显式监督，该自举目标不会发生表征坍塌。
- **块注意力掩码**作用于 token 组 `{E(o_t), p_t, q_reas, â, f̂, q̂}`：动作与前视分支可条件化于推理输出，但不污染推理本身；推理前向与首个去噪步共享一次前向，其余步复用 KV 缓存。

### 2.5 训练目标
- 端到端联合目标：`L(θ) = L_act + λ_reas·L_reas + λ_vis·L_vis + λ_sem·L_sem`。
- **数据**：混合 RoboTwin 2.0 与 RMBench 仿真数据，将真值物体状态转为边界框视觉提示。
- **视觉提示增强**：训练时随机抖动框中心、高、宽，使策略容忍智能体下发的松散或轻微错位框。

### 2.6 智能体兼容层与失败恢复
- 智能体建模为"模型 + harness"（系统提示与规则、可调用工具、交互历史、控制循环）。
- **事件触发调用**（非每控制步）：末端位移超阈值、夹爪闭合、夹爪张开、固定时间间隔四类事件触发，触发时智能体收到结构化反馈（触发原因、夹爪状态、观测）。
- **三种原语**（模型无关接口）：
  - `detect(y) → g`：完全在智能体侧完成地面化，仅边界框进入策略（策略内无语言通路）。
  - `execute(g, s, u, w) → ξ`：rollout 策略直到触发事件，返回执行轨迹。
  - `query(ξ) → b`：打包结果反馈供智能体下一步推理。
- **失败检测与恢复**：由闭环而非硬编码恢复行为处理；每次调用时智能体判断子任务是否完成，失败则重新 detect 得到更新提示 `g′` 并重试（固定重试预算）；策略解码出的意图有助于诊断失败源于错误意图还是不当执行。

## 6. 主要结论与发现

- **RQ1（视觉 vs 语言条件）**：在相同训练下，把视觉提示换成文本指令使平均成功率**下降 13.0%**；在视觉提示之上再加文本反而下降 2.6%，说明有空间定位后语言是冗余的。视觉定位提示是严格更强的条件信号。
- **调制机制**：AdaLN 比 cross-attention 高 **13.8%**；原因是 cross-attention 对本体状态的依赖高 2.3 倍（35.6% vs 15.5%），而 AdaLN 对语义条件束的依赖高 2.1 倍（31.5% vs 15.3%）。作者将本体状态依赖解读为模仿策略的捷径学习失效模式：状态信号在分布内与专家动作强相关，提供更快的降损路径但不携带任务语义，从而绕过语义条件、损害泛化。
- **推理与前视**：去掉推理专家损失 7.8%，去掉前视对齐损失 8.6%；把紧凑要点目标换成原始未来 patch 特征反而下降 10.8%（甚至低于无前视变体），说明"要点的压缩"才是前视信号有用的关键。注意力图显示推理聚焦被操作物体与目标，前视则转向运动将发生区域。
- **RQ2（智能体驱动）**：RMBench 的 M(n) 任务上 AR-WAM 大幅超越所有记忆增强基线（52.5% 与 63.5% vs 最强基线 Goal2Skill 的 38.7%），归因于把记忆管理明确下放给上游智能体而非纠缠在策略内。M(1) 任务上落后 Cortex（75.2%），因小物体上 VLM 原生框不够准。AR-Q 超过 AR-K（M(1) 上 71.2% vs 50.0%），说明两个智能体推理能力都足够时，**地面化精度成为瓶颈**。"Swap T"任务上无提升，表明边界框作为视觉地面化对严格空间细节任务尚不够精细。
- **真实机器人**：平均成功率 **71.7%**（π0.5 为 35.0%，LiLa-WAM 为 31.7%），三个任务分别 70%/65%/80%。
- **效率**：端到端延迟 **14.09 ms/chunk**，比 π0.5 快 4.4 倍、比 Fast-WAM 快 22.7 倍，得益于推理-去噪共享前向与 KV 缓存复用。
- **标准操作**：RoboTwin 2.0 随机设置下取得最佳平均成功率 84.2%，干净设置 87.2% 距最强基线 87.8% 仅差 0.6%。

## 7. 优点

- **接口设计具有范式意义**：明确提出"智能体与操作策略之间的接口应是空间的而非语言的"，把指代歧义、冗余、不精确、黑盒纠缠四个问题拆解并逐一对症设计，论点清晰且有消融数据支撑（13.0% 的条件增益、13.8% 的调制增益）。
- **参数与延迟效率突出**：0.5B 紧凑模型（0.2B 共享 transformer + 0.3B 冻结 DINOv3）在标准任务上追平甚至超过更大基线，同时保持最低延迟；共享权重 + 块注意力掩码 + KV 缓存复用是干净的工程组合。
- **可监督的意图外化**：推理 head 输出掩码、末端位姿、任务摘要三类显式监督信号，既服务于训练，又充当失败诊断工具，缓解了"意图 vs 执行"不可归因的问题。
- **模型无关的智能体兼容层**：

- **模型无关的智能体兼容层**：把 `detect / execute / query` 三个原语与事件触发调用机制作为独立于具体模型和具体策略的接口契约，使上层智能体可以自由替换（Qwen、Kimi 等不同能力档次的模型均可接入），下层策略也可独立升级；这为"智能体 + 策略"的模块化组合提供了可复用的工程范式，而非一次性的端到端训练技巧。

- **失败归因的工程价值**：由于策略每次只做马尔可夫式短程决策、长时程结构由智能体承担，且策略解码出的意图（掩码、末端位姿、任务摘要）可被外部检查，失败可以被清晰地切分为"智能体给错了框/技能"还是"策略执行不到位"，这与端到端黑盒模型形成鲜明对比。

- **前视要点的设计取舍合理**：放弃重建原始未来 patch、改为压缩后的隐式要点，既有消融数据支持（换回 patch 目标反而下降 10.8%），也在概念上契合"策略只需要知道场景将如何演化，而非逐像素重建未来"的直觉，避免了世界模型常见的算力与表征浪费。

- **对本体状态捷径学习的实证诊断**：通过条件敏感性分析把 cross-attention 与 AdaLN 的差异归因到"状态依赖 vs 语义依赖"，为条件调制机制的选择提供了超出单纯性能数字的解释，这一分析本身对其他条件化策略设计也有参考价值。

## 8. 不足与局限

- **训练算力与成本披露缺失**：全文未报告训练 GPU 型号、数量、时长或总计算量，使得"0.5B 参数即达到竞争力"的效率论断只能覆盖推理侧，无法判断端到端训练成本是否同样占优，也影响复现与横向比较。

- **真实机器人实验规模偏小**：三个任务各 20 次试验，且仅在单一平台（Astribot S1）上验证，统计功效有限；没有报告置信区间或多次运行方差，71.7% 的平均成功率与基线间的差距虽大，但任务层面的波动性未知。

- **消融的统计严谨性不足**：多数消融为单次运行的点估计，未报告标准差或多随机种子结果，13.0%、13.8% 这类关键增益的稳健性无法从文中直接确认。

- **条件敏感性指标较为间接**：以"预测动作速度的变化量"衡量对某类条件的依赖度，只能反映敏感程度而非因果重要性，且速度变化与任务成功率的关联未加论证。

- **边界框作为地面化表示的精度天花板**：作者自己在"Swap T"任务上承认边界框对严格空间细节任务不够精细，M(1) 小物体任务上 VLM 原生框精度也成为瓶颈；这说明"视觉提示"路线本身仍受限于检测器的定位精度，论文并未给出超越边界框的更细粒度方案（如关键点、掩码、6D 位姿）。

- **对上游智能体的依赖被外移但未量化**：论文把记忆、长时程规划、错误恢复全部交给智能体，却没有系统测量智能体质量（不同模型、不同 harness 配置）对最终成功率的影响曲线，只在 RMBench 上用两个模型（Qwen3.8-27B 与 Kimi-K3）做了有限对比。

- **马尔可夫式策略的适用边界未充分探讨**：把策略刻意设计为无循环状态，在需要高频反馈、接触-rich 或力控精细的任务上是否会因缺乏短程历史而受限，文中没有针对性实验。

- **RMBench 上并非全面领先**：在 M(1) 任务上仍落后 Cortex（75.2%），作者将其归因于小物体检测精度，但这恰恰说明当上游感知不可靠时，把全部地面化责任交给智能体的解耦设计会直接暴露瓶颈，缺乏策略侧的兜底机制。

- **视觉提示增强的鲁棒性边界不明**：训练时对框做随机抖动以容忍松散或错位框，但抖动幅度、与真实智能体输出误差分布的匹配程度、以及超出该幅度后的性能衰减曲线均未报告。

## 9. 启发与展望

- **接口即架构**：本文最有价值的贡献可能不是某个模块，而是"智能体—策略接口应该是空间的而非语言的"这一命题。它提示后续工作可以把"接口设计"本身当作一等研究对象，系统比较文本、边界框、掩码、关键点、位姿、潜变量等不同条件信号在指代唯一性、信息冗余度、可检查性与带宽上的权衡。

- **解耦带来的可替换性红利**：由于策略不含语言通路、智能体可自由替换，整个系统具备"感知升级即整体升级"的性质。未来可探索把这一接口标准化，使不同实验室的智能体与不同实验室的策略可以即插即用，从而推动社区层面的模块复用。

- **可监督意图作为训练与运维的双重工具**：推理 head 同时充当辅助监督与失败诊断探针，这一"让中间意图显式且可检查"的思路可迁移到更广的机器人学习场景，尤其是在需要人机协作排障的部署环境中。

- **压缩式前视优于重建式前视**：用紧凑要点而非原始未来帧作为世界模型目标，既省算力又更有效，这与"世界模型不必重建一切、只需保留决策相关信息"的观点一致，值得在更长时程、更复杂动力学任务上进一步验证。

- **潜在的后续方向**：一是把地面化表示从边界框升级为更细粒度的空间规格（掩码、抓取点、6D 位姿），以突破"Swap T"类任务的精度瓶颈；二是引入轻量短程历史或触觉反馈，检验马尔可夫假设在接触丰富任务中的边界；三是系统研究智能体能力与策略能力的最优分配，量化"多少智能放在上游、多少放在策略内"的性价比曲线；四是补齐训练算力与多随机种子报告，使效率论断覆盖全流程。

## 摘要
视觉-语言-动作（VLA）模型提供了一个统一框架，可将高层语义信息落地为底层机器人动作，从而支持跨多样任务的可扩展机器人操作。然而，现有VLA模型缺乏显式机制来解耦双臂的状态与意图，导致非预期的跨臂干扰，从而降低任务执行成功率。为解决这一问题，我们提出一种对称双臂专家（DAE）架构，它构建于共享的视觉-语言模型（VLM）主干之上，并具有解耦的、特定于手臂的专家塔。专家选择通过两阶段双臂意图路由方案进行：第一阶段依据显式语言指令路由专家，第二阶段则依据隐式视觉语义进行路由。此外，我们引入一个轻量级任务进度预测模块，利用预分块时序特征与本体感觉和视觉观测的语义表示之间的交叉注意力，准确估计逐帧任务完成进度。该模块促进任务进度同步，以支持协作式多机器人任务的协调调度。实验结果证明了我们的模型在双臂意图路由和解耦跨臂干扰方面的有效性，并进一步提供了从单臂任务到双臂任务（以及反向）的涌现技能泛化的初步证据，以及跨臂运动域技能迁移的证据。

## Abstract
Vision-Language-Action (VLA) models provide a unified framework for grounding high-level semantic information into low-level robot actions, enabling scalable robotic manipulation across diverse tasks. However, existing VLA models lack explicit mechanisms to disentangle the states and intents of the two arms, leading to unintended cross-arm interference that degrades task execution success. To address this issue, we propose a symmetric Dual-Arm Expert (DAE) architecture built upon a shared Vision-Language Model (VLM) backbone with decoupled, arm-specific expert towers. Expert selection is carried out through a two-stage dual-arm intent routing scheme, in which experts are routed either by explicit language instructions in the first stage or by implicit visual semantics in the second stage. Moreover, we introduce a lightweight task progress prediction module that leverages cross-attention between the pre-chunk temporal features and semantic representations of proprioceptive and visual observations to accurately estimate frame-wise task completion progress. This module facilitates task progress synchronization to support coordinated scheduling for collaborative multi-robot tasks. Experimental results demonstrate the effectiveness of our model in dual-arm intent routing and the disentanglement of cross-arm interference, and further provide preliminary evidence of emergent skill generalization from single- to dual-arm tasks (as well as the reverse), together with cross-arm motion-domain skill transfer.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：VLA（视觉–语言–动作）模型把语言、视觉观测与机器人状态统一映射为操作动作，已成为可扩展机器人操作的主流范式（自回归如 RT-1/RT-2/OpenVLA，扩散/流匹配如 Diffusion Policy、π0、GR00T N1）。
- **核心痛点**：主流双臂 VLA 采用**统一动作生成器**同时表征双臂。接口虽简化，却会把"执行臂"与"另一条臂"的无关状态变化和视觉变化**耦合**在一起，造成**跨臂干扰（cross-arm interference）**，降低任务成功率。
- **干扰在何时最致命**：
  - 任务只需单臂执行时；
  - 两臂执行**顺序子任务**时；
  - 示教数据中两臂角色**不对称**时。
- **论文主张**：双臂策略应"保留共享任务语义，同时**选择性控制臂级动作生成**"。据此提出 **TAO-DA**，遵循两条原则：
  1. 用**共享多模态表示**做任务级推理；
  2. 用**臂专属动作塔**做底层控制。
- **形式化视角**：论文把"非活动臂干扰"重新表述为一个**动作生成问题**（而非单纯的感知/滤波问题），并对比统一、掩码弱解耦、独立臂级处理三类架构。

## 2. 方法论

### 2.1 整体架构（Fig. 1）

- **输入**：多视角视觉（1 路第一人称视角 + 左右末端执行器视角，后两者可选）、语言指令、本体感觉状态。
- **编码**：每张图像经同一个预训练 **SigLIP** 视觉编码器；视觉 token 与语言 token 拼接后送入**冻结的 Eagle-2.5-VL** 主干，得到融合多模态表示 `E_VL ∈ R^{N×D}`。
- **数据流**：`E_VL` 供 **DAIR** 做意图路由 → 依据路由结果在 VLM 输入端**掩蔽非活动臂的腕部视角 token** → 由 **DAE** 中选中的臂专属通路生成动作（流匹配训练）。
- **训练技巧**：每个任务的指令从一组**语义等价表达**中随机采样，以增强语言鲁棒性。

### 2.2 DAIR：语言与视觉引导的双臂意图路由

- **意图表示**：`r = [r_L, r_R] ∈ {0,1}²`，合法类别为 left-only `[1,0]`、right-only `[0,1]`、dual-arm `[1,1]`。
- **三分类设计**：用交叉熵损失 `L_route = −log p_c` 训练三分类器；**三分类接口天然排除非法的 `[0,0]`（无臂）向量**。
- **两阶段推理**：
  - **阶段 1（规则解析）**：识别 "left arm / right arm / both arms / left hand / right hand" 等显式表达；出现"双臂"表达时**双臂优先**；**不利用空间表达推断臂意图**；若无显式表达则返回内部"无匹配"码 `[0,0]`（表示应激活阶段 2，而非合法的"无臂"意图）。
  - **阶段 2（模型预测）**：对 `E_VL` 做 LayerNorm，用**可学习 query 做 MHA 池化**，再经 MLP 输出 3 个 logits，argmax 后映射为 `r̂_model = φ(ĉ)`。
- **进度保持（hold）机制**：若规则命中则用规则结果；否则若预测任务进度 `p̂_t ≤ τ_hold` 用模型预测；否则**沿用上一时刻意图 `r̂_{t−1}`**，以稳定路由决策。论文强调该机制**不同于部署级任务调度器**。

### 2.3 DAE：三种双臂专家变体（Fig. 2）

三者共享同一多模态上下文与流匹配目标，构成"统一 → 弱解耦 → 强解耦"的架构谱系：

| 变体 | 机制 | 解耦程度 |
|---|---|---|
| **Single-Tower** | 双臂状态与动作 token 拼接后送入**同一个 DiT** | 无解耦 |
| **Dual-Mask** | 共享 DiT，但用**臂模式注意力掩码**限制 token 交互 | 弱解耦 |
| **Dual-Tower** | 两条**参数完全独立**的 DiT 分支（各有状态编码器、动作 tokenizer、DiT、动作解码器） | 强解耦 |

- **Dual-Mask 细节**：输入为四组臂专属 token `[X^L_state, X^R_state, X^L_action, X^R_action]`；对自注意力施加二值掩码，实现 `softmax(QKᵀ/√d + log M^(m))V`（掩码为 0 处抑制对应 logit）。左臂模式仅左臂状态与动作互注意，右臂对称，双臂模式允许全互注意。**多模态任务表示仍共享**，故解耦弱于 Dual-Tower。
- **Dual-Tower 细节**：
  - 各分支独立编码 `X^k_state = Enc^k_state(s_k)`、`X^k_action = Tok^k_action(a^k_α)`（`a^k_α` 为流匹配的含噪/插值动作序列）；
  - 训练时用标注 `r` 选择 `T_L`、`T_R` 或两者，推理时替换为 DAIR 的预测 `r̂`；
  - **臂条件视角掩蔽**：`ẽ_V = Mask(V, r)`，再经 VLM 融合，非活动臂腕部视角不参与动作条件融合，**第一人称视角始终保留**；
  - **活动臂监督**：`L_act = r_L·L^L_FM + r_R·L^R_FM`，单臂样本只监督一条塔，双臂样本在**同步时间步**监督两条塔；
  - 参数量约为臂级组件的 2 倍，但**冻结 VLM 与 DAIR 保持共享**——论文明确指出这属于架构对比，**并非严格参数对齐**。

### 2.4 任务进度预测模块

- 用 **GRU** 编码 DiT 的时序特征 `H = [h_1,…,h_T]`，得到 `S = GRU(H)`；
- 通过**交叉注意力**与 VLM 表示融合：`Z = MHA(S, E_VL, E_VL)`；
- 回归头预测逐帧完成度 `p̂_t`，监督目标为**归一化轨迹时间**；
- 作用：同时支撑 DAIR 的 hold 机制与部署级任务切换调度（面向多机器人协作的任务进度同步）。

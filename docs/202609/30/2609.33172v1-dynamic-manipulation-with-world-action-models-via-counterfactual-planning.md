## 摘要
在静态示范上训练的世界-动作模型（WAMs）即使具备所需的操作技能，也常常无法操作移动目标。我们将这一失败归因于目标响应坍缩：随着执行推进，策略越来越偏向于学习到的当前行为的延续，而对目标位置变化响应不足。为弥合模型所学内容与它能够从当前上下文生成的内容之间的差距，我们将动态操作形式化为反事实规划，将用于生成计划的上下文与用于执行的物理状态解耦。我们的框架——动态预测规划（DPP）——首先利用 WAM 的预测推演来估计预期发生交互的时间，并将该时间估计与观测到的目标运动相结合，以预测目标未来的交互位置。随后，DPP 构建一个反事实观测，将预测的目标位置置于熟悉的机器人上下文中，使模型能够调用已有的操作技能，而不是从陌生的机器人-目标配置中生成恢复行为。在执行过程中，所得计划与机器人的实际状态相连接。DPP 无需在动态数据上进行额外训练，即可在单块消费级 GPU 上实现实时动态操作。仿真和真实机器人上的实验表明，在不同目标运动下均取得一致改进，仿真性能超越了所有评估基线，包括额外在动态数据上训练的方法。项目页面：https://methoder00.github.io/DPP/

## Abstract
World-Action models (WAMs) trained on static demonstrations often fail to manipulate moving targets even when they possess the required manipulation skills. We attribute this failure to target-response collapse: as execution advances, the policy becomes increasingly biased toward the learned continuation of its ongoing behavior and less responsive to target relocation.   To bridge the gap between what the model has learned and what it can generate from the current context, we formulate dynamic manipulation as counterfactual planning by decoupling the context used for plan generation from the physical state used for execution. Our framework, Dynamic Predictive Planning (DPP), first uses the WAM's predictive rollout to estimate when an interaction is expected to occur, and combines this timing estimate with observed target motion to predict the target's future interaction position. DPP then constructs a counterfactual observation that places this predicted target position in a familiar robot context, allowing the model to invoke an existing manipulation skill rather than generate a recovery behavior from an unfamiliar robot-target configuration. The resulting plan is connected to the robot's actual state during execution.   DPP enables real-time dynamic manipulation on a single consumer GPU without additional training on dynamic data. Experiments in simulation and on a real robot demonstrate consistent improvements across diverse target motions, with simulation performance surpassing all evaluated baselines, including methods additionally trained on dynamic data. ## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型与新兴的世界-动作模型（WAM）已在多种操作任务上取得强性能，WAM 还能预测未来视觉状态、表征场景随动作的演化。但真实部署中机器人常需操作移动目标，而绝大多数操作技能仍是从**静止目标 + 规范机器人构型**的示范中习得的。
- **核心问题**：为什么静态示范训练的 WAM 即使"会"某个操作技能，仍无法操作移动目标？是否能在**不采集动态数据、不重新训练**的前提下复用已有技能？
- **关键诊断——目标响应坍缩（target-response collapse）**：
  - 简单的"随目标移动反复重规划"会把策略置于**静态示范未覆盖的机器人-目标交叉构型**：机器人已推进到较晚的执行状态 $S^{(i)}_t$，而目标已移动到别处 $x^{(j)}$，训练数据中只有 $(S^{(i)}_t, x^{(i)})$ 与 $(S^{(j)}_t, x^{(j)})$，没有交叉组合 $(S^{(i)}_t, x^{(j)})$。
  - 该构型越靠后，机器人构型本身携带的执行进度信息越强，策略越倾向于"延续熟悉但错误的子目标"，对目标重定位的响应越弱。
  - 作者用**方向响应增益** $G(S;x,x') = u^\top[F(\zeta(C(S,x'))) - F(\zeta(C(S,x)))]/\lambda$ 量化这一现象：增益接近 1 表示预测抓取点随目标移动，接近 0 表示几乎不响应。
- **整体含义**：动态操作失败可能**不是"能力缺失"，而是"技能访问受限"**——同一已学技能的可及性取决于请求它时所用的观测上下文。

## 2. 方法论：动态预测规划（DPP）

- **核心思想**：**解耦"用于生成计划的上下文 $C$"与"用于执行的物理状态 $S_k$"**。不去要求策略从陌生的机器人-目标构型直接恢复，而是用熟悉的机器人上下文 + 预测的目标交互位置构造**反事实观测**，把该查询当作对已学技能的"隐式检索"。
- **三步流程**：
  - **Step 1 初始规划与运动预付（motion prepayment）**
    - 从初始观测生成 $\zeta_{init}=\zeta(C(S_0,x_0))$；用任务相关谓词 $\phi_q$（如夹爪闭合、TCP 高度）在预测动作序列中找到首个交互动作，映射到执行时钟：$\tau = t_{exec} + \Delta t \min\{j:\phi_q(a_j)=1\}$。
    - 并行用 SAM 2 分割目标、FoundationPose 跟踪位置，按时间戳拟合运动假设 $\hat{x}(s)$（基座为匀速模型），得到预测交互位置 $\hat{x}(\tau)$。
    - 初始动作块可立即执行；预付步骤对初始动作加有界平移 $\delta_i=\alpha_i(d_0+u)$（$s=15,e=32$ 的斜坡），使机器人在规划期间先朝目标靠拢。
  - **Step 2 反事实规范规划（canonical planning）**
    - 构造合成观测 $\tilde{C}(S_0,\hat{x}(\tau)) = (\mathrm{Edit}(O_0,\hat{x}(\tau)), R_0, I)$：在保留机器人上下文的前提下，仅把目标编辑到预测交互位置（RGB 修补 + 深度/背景恢复 + z-buffer 可见性重投影，多视角一致）。
    - 生成 $\zeta_{can}=\zeta(\tilde{C}(S_0,\hat{x}(\tau)))$；因机器人已推进到 $S_k$，需通过**激活桥（activation bridge）**连接：按时间对齐选入口 $j^*=g-(K-k_a)$，用逆运动学在关节速度约束下构造过渡，接受后替换剩余动作队列。
  - **Step 3 从真实状态重规划（current-state planning）**
    - 桥完成后，用新鲜观测与当前本体感知生成 $\zeta^{cur}_k=\zeta(\tilde{C}(S_k,\hat{x}(\tau)))$，仅对交互前片段做时间重采样（保留最后接近与抓/放段），缓解递归预测漂移。
  - **跨子任务衔接**：延续型阶段复用当前 rollout 的延续作为下一阶段初始计划；新周期边界则从新参考观测生成新初始计划；每个目标保留独立运动假设与交互时序。
- **非线性运动扩展（可选）**：启用"延迟规范规划"（用因果拟合更新运动假设）与当前状态输出的空间扭曲；对位置跳变等可建模为常量加速度、常转弯率或带跳变的匀速。

## 6. 主要结论与发现

- **目标响应坍缩被实证确认**：同一批静态可成功的目标格上，平均增益从 prefix 0 的 0.897 降至 prefix 48 的 0.078，响应面积保留率从 100% 降至 1.47%，物理抓取成功率从 95.77% 降至 19.58%；ImageWAM 增益 0.885→0.063；双瓶任务在双臂尚未接触前（prefix 24）成功率已从 100% 降至 66.7%/72.9%。
- **DPP 显著超越所有评估基线**：
  - T1：FastWAM+DPP 83.33%、ImageWAM+DPP 78.67%，对比 Future-Conditioned Oracle 27.00%/22.67%，且**超过额外动态训练的 DynamicWAM（52.00%）与 PUMA（50.33%）**。
  - T2：80.73% / 91.15%，对比 DynamicWAM 53.13%。
  - 扩展任务 T3–T6 同样大幅领先（如 T5 交接 91% vs 58%）。
  - 真机 Task A 76.7% vs Reactive/Future-Cond. 0%；Task B 86.7% vs Reactive(Hybrid) 40.0%。
- **组件必要性**：初始计划执行与规范状态条件是最关键的两项，当前状态规划提供小幅但一致的增益（+3.33）。
- **概念性结论**：动态操作不必被看作"学习新行为"的问题；反事实观测可解释为对已学操作能力的**隐式检索查询**，WAM 的预测能力不仅用于生成未来场景，更用于**构造动作模型已知如何求解的规划问题**。

## 7. 优点

- **概念清晰且有诊断支撑**：先以可控的匹配前缀探针定量刻画失败模式，再据此设计方法，问题-方法-验证闭环完整。
- **零训练、骨干无关**：仅改变规划时的输入上下文，同一控制器可套用于 FastWAM 与 ImageWAM（joint 与 cascaded 均可），工程实用性强。

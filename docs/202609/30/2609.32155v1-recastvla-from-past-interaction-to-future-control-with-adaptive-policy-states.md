## 摘要
序列操作要求机器人跟踪已经发生的事情，即使当前场景不再揭示它。具有显式历史表示的策略使过往交互可作为当前决策的上下文。我们探究动作生成本身如何为后续控制形成持久状态。基于动作侧测试时训练，RecastVLA 在流匹配视觉-语言-动作策略中维护一个自适应策略状态。该状态由共享快速权重表示，并在整个动作生成过程中保持固定。深度特定的接口读取同一状态，而跨深度与流评估的特征共同为下一次策略调用定义一个更新。后续动作损失通过沿更早的状态转移进行微分，来训练初始化、接口与更新规则。部署时，更新使用策略自身的动作生成特征，无需专家动作标签。在 LIBERO、RoboTwin、RoboDojo 和十二个真实机器人任务上，RecastVLA 相比未使用测试时训练的匹配策略提高了平均成功率，其中在 RoboTwin Clean-to-Clean 上提升 10.68 个百分点。在受控的 RoboTwin 对比中，保留状态提高了成功率，且共享设计比独立训练的层局部 TTT 高出 2.58 个百分点。

## Abstract
Sequential manipulation requires a robot to track what has already happened, even when the current scene no longer reveals it. Policies with explicit history representations make past interactions available as context for current decisions. We ask how action generation itself can form a persistent state for subsequent control. Building on action-side test-time training, RecastVLA maintains an adaptive policy state within a flow-matching vision-language-action policy. The state is represented by shared fast weights and remains fixed throughout action generation. Depth-specific interfaces read the same state, while features across depths and flow evaluations jointly define one update for the next policy call. Subsequent action losses train the initialization, interfaces, and update rule by differentiating through earlier state transitions. At deployment, updates use the policy's own action-generation features without expert action labels. Across LIBERO, RoboTwin, RoboDojo, and twelve real-robot tasks, RecastVLA improves mean success over a matched policy trained without test-time training, including 10.68 percentage points on RoboTwin Clean-to-Clean. In controlled RoboTwin comparisons, retaining state improves success, and the shared design exceeds independently trained layer-local TTT by 2.58 points.

# RecastVLA 论文总结

## 1. 核心问题与研究动机

- **背景**：序列操作任务中，机器人必须记住"已经发生了什么"。但当前观测往往无法反映历史——例如瞬态按钮在按下前后外观几乎相同，被遮挡的物体、部分完成的指令同样如此。
- **已有路线**：历史条件策略通过检索观测、压缩上下文或循环表征把过去信息作为"上下文 token"输入策略（如 MemoryVLA、MEM、Zeva 等），解决的是"**哪些历史信息可用**"的问题。
- **本文追问**：动作生成本身能否把交互经验转化为一个**持久策略状态**，用于指导后续决策？即"**历史如何被动作生成过程转化为可复用的状态**"。
- **动机来源**：测试时训练（TTT）用一个小模型的权重表征序列历史；RoboTTT 把这一原理放进动作专家并通过轨迹监督学习快速权重更新，但采用**逐层独立**的 fast weights。
- **核心假设**：让动作专家的不同深度**共同读写一个共享状态**，可能比各层独立维护状态更有效。

## 2. 方法论

### 2.1 核心思想
- 在流匹配（flow-matching）VLA 策略中维护一个**自适应策略状态** $W_t$，由一个小型 MLP（两层、GELU，256→512→256）的权重与偏置表示。
- 每次策略调用读入当前状态 $W_t$，生成一个动作块并收集内部特征 $Z_t$；$W_t$ 在**整次动作生成过程中保持固定**，生成结束后才更新为 $W_{t+1}$，供下一次调用使用。
- 新 episode 从学习到的初始化 $W_0$ 开始。部署时只有 $W_t$ 变化，慢参数 $\theta$（VLM+动作专家）与 $\psi$（接口与更新规则）固定。

### 2.2 深度专用读取接口
- 动作专家由 16 个交替的 cross-attention / self-attention 块组成（宽度 768），设 $J=8$ 个访问点，每点使用 32 个宽度 768 的 latent slot。
- 在每个访问深度 $j$、每次流评估 $c$，对 cross-attention 后的 slot 特征做门控残差读取：
  $$\tilde{h}_{t,c,j} = h_{t,c,j} + \tanh(\gamma_j)\, P^O_j\, f_{W_t}\big(P^Q_j \,\mathrm{LN}(h_{t,c,j})\big)$$
  其中 $P^Q_j$ 投影进记忆空间、$P^O_j$ 投回，$\gamma_j$ 为可学习门控标量。不同深度以**各自的特征坐标**查询同一个共享函数。

### 2.3 从动作生成特征写记忆
- 每个访问点在 self-attention 之后用 stop-gradient 构造学习到的 key/value：
  $$k_{t,c,j}=P^K_j \mathrm{LN}(\mathrm{sg}(z_{t,c,j})),\quad v_{t,c,j}=P^V_j \mathrm{LN}(\mathrm{sg}(z_{t,c,j}))$$
- 内层目标把 fast model 拟合到这些 key–value 关联上，并对跨深度、跨流评估做加权聚合：
  $$\mathcal{L}^{\text{write}}_t(W)=\frac{1}{C}\sum_{c=1}^{C} g_\psi(\tau_{t,c})\sum_{j=1}^{J}\alpha_j \frac{\|f_W(k_{t,c,j})-v_{t,c,j}\|_F^2}{NM}$$
  其中 $g_\psi(\tau)$ 是学习到的流时间门（两层 MLP，隐宽 16，SiLU + sigmoid），$\alpha_j$ 是访问点 softmax 权重。
- 在**进入状态**处求一次梯度，得到更新：
  $$W_{t+1}=W_t-\eta\,\nabla_W \mathcal{L}^{\text{write}}_t(W)\big|_{W=W_t},\qquad \eta=\eta_0 e^{\rho},\ \eta_0=0.1$$
- 更新发生在策略调用边界：同一次调用内所有深度与流评估读同一状态，它们的特征**联合定义一个**下一次调用的更新。

### 2.4 通过后续控制学习
- 训练采样同一 episode 的 $T=4$ 帧有序窗口，每窗口从 $W_0$ 开始；每帧抽 $R$ 个独立噪声/时间样本构造流匹配目标。
- 外层目标为后续动作损失 $\mathcal{L}_{\text{action}}(\Theta)$（$\Theta=(\theta,\psi,W_0)$），第 $t+1$ 帧的损失会经状态转移反传回第 $t$ 帧的写投影与更新参数，同时训练 $W_0$、接口与更新规则。
- write 分支的 stop-gradient 阻断对源特征的梯度，但保留对 key/value 投影与快速权重更新的梯度。
- **部署**：仅需对快速权重求梯度，不跨调用保留计算图；用策略自身 $K=4$ 次 Euler 评估的特征做一次更新，无需专家动作标签。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号、数量与训练时长，难以评估成本与可复现性。
- **统计严谨性不足**：所有设置仅一次运行，无方差/置信区间，2–3 点量级的差异可能不显著。
- **训练-部署不一致**：训练用 4 帧相邻演示帧构造 write 特征，部署则按执行的动作块推进并用策略自身生成特征，论文自己承认这一 gap 未解决。
- **梯度路径受限**：write 特征处的 stop-gradient 阻断了到源特征的梯度，限制了时间信用分配的深度；跨调用也不保留计算图。
- **共享状态的干扰风险**：多来源特征写入同一状态可能相互干扰，论文提及但未量化。

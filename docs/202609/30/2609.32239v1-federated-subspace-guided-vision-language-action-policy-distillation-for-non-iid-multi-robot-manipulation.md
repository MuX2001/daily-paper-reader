## 摘要
联邦学习为多个机器人共同改进操作策略提供了一种自然方式，无需集中访问训练演示。然而，非独立同分布的任务和环境分布会引发表示漂移以及相互不兼容的机器人策略更新，使得朴素参数聚合具有破坏性。我们提出 FedDRMan，一种面向异构机器人操作的联邦子空间引导蒸馏框架。在每个通信轮次，服务器模型提供一个冻结教师用于局部行为克隆，同时低秩多模态子空间和动作分布蒸馏保留全局有用的表示几何与策略行为。为解决异构聚合问题，FedDRMan 按更新兼容性对客户端分组，并为每个聚类维护一个持久模型。服务器随后对每个兼容聚合进行谱重平衡，以缓解较弱的任务相关机器人策略更新方向的衰减。在 LIBERO 上跨多种非独立同分布设置、异构程度、客户端参与变化的大量实验，以及消融和聚合分析表明，FedDRMan 显著提升了知识迁移，并持续优于强联邦基线，达到 80.7% 的峰值平均成功率，比评估的最强联邦基线高出 11.6 个百分点。

## Abstract
Federated learning offers a natural way for multiple robots to jointly improve manipulation policies without requiring centralized access to training demonstrations. However, non-IID task and environment distributions can induce representation drift and mutually incompatible robot-policy updates, making naive parameter aggregation destructive. We present FedDRMan, a federated subspace-guided distillation framework for heterogeneous robot manipulation. At each communication round, the server model provides a frozen teacher for local behavior cloning, while low-rank multimodal subspace and action-distribution distillation preserve globally useful representation geometry and policy behavior. To address heterogeneous aggregation, FedDRMan groups clients by update compatibility and maintains a persistent model for each cluster. The server then spectrally rebalances each compatible aggregate to mitigate attenuation of weaker task-relevant robot-policy update directions. Extensive experiments on LIBERO across diverse non-IID settings, heterogeneity levels, client participation variation, together with ablations and aggregation analyses, show that FedDRMan substantially improves knowledge transfer and consistently outperforms strong federated baselines achieving a peak mean success rate of 80.7%, 11.6 percentage points above the strongest evaluated federated baseline.

## 2. 方法论

### 2.1 问题形式化
- K 个机器人，共享语言条件操作 MDP：M = (S, A, T, H, μ₀, φ)，A 为连续动作空间，φ 为稀疏成功谓词。
- 客户端 k 拥有私有演示集 D_k，轨迹含智能体视角 RGB、腕部 RGB、关节状态、夹爪状态、语言指令与专家动作；策略为语言条件 GMM 策略 π_θ(a|o,D)。
- 联邦目标：min_θ Σ_k p_k · E_{D_k}[L_k]，p_k = n_k / Σ_j n_j（样本量加权）。

### 2.2 本地：联邦子空间引导的全局→本地蒸馏
- **冻结教师**：每轮服务器模型 θ_g^r 复制为冻结教师 θ̄_g^r，学生 θ_k^{r,0} 由同一模型初始化，教师在本轮内不更新、轮末刷新。
- **BC 项**：L_BC = −E[log π_θk(a|o,D)]，驱动本地适配。
- **多模态子空间蒸馏**：
  - 模态集合 M = {text, agent, wrist, joint, gripper}；将批-时间编码特征堆叠为 F ∈ R^{d_m × N}（N = BT）。
  - 对教师（g）与学生（k）分别做**降秩 SVD**，得到秩 r_m 的正交投影算子 P = U_{r}(U_{r})ᵀ；特征矩阵近退化时加入小幅扰动以保证数值稳定。
  - **对称子空间蒸馏损失**：L_sub^m = ‖P_g F_g − P_k F_k‖²_F + ‖P_g F_k − P_k F_g‖²_F。第一项对齐双方子空间保留的特征内容，第二项强制对称交叉投影一致性——避免逐坐标特征匹配在高维表征中的敏感性，只约束主能量方向，保留低能量方向供机器人个性化适配。
- **动作分布蒸馏**：从教师采样 â ∼ π_θ̄(·|o,D)，最小化 log π_θ̄(â) − log π_θk(â) 的期望差（对数概率做数值裁剪），保持服务器继承的控制行为。
- **总目标**：L_k = L_BC + Σ_m λ_m L_sub^m + λ_act L_act；梯度只回传学生，教师固定；本地若干步后上传 θ_k^r。

### 2.3 服务器：兼容性感知的谱联邦聚合
**（a）兼容更新聚合（CUA）**
- 动机：跨套件异构使更新方向不兼容，单一全局共识过于受限；服务器维护 **C 个持久簇模型** {θ_s^r}，所有客户端共享同一初始 θ⁰。
- **兼容性度量**：用"相对公共初始化的累积更新" Δ_k^r = θ_k^r − θ⁰，在选定共享子模块 Ω（此处为时序 Transformer）上向量化后计算客户端间余弦相似度 S_ij。选用累积更新而非逐轮增量，因其信号更稳定（消融/分析中验证）。
- **聚类目标**：最大化平均簇内相似度、最小化平均簇间相似度，在恰好 C 个非空分组的划分空间 Π_C 上求解组合优化问题。
- **簇内聚合**：簇内样本权重重新归一化，对**完整本地模型**做加权平均，得到簇平均模型与簇更新 Δ_s^r。

**（b）谱重平衡（SRB）**
- 动机：直接平均会衰减较弱但有用的方向。
- 对符合条件（可选的二维权重矩阵块）的 Δ_{s,b} 做 SVD：Δ = UΣVᵀ。
- 由累积奇异值阈值 β ∈ [0,1] 确定截断阶 c* = min{ i : Σ_{j≤i}σ_j / Σ_j σ_j ≥ β }，并令 **σ̃_i = max(σ_i, σ_c*)**（把弱奇异值抬升到阈值下限），重构 Δ̃ = UΣ̃Vᵀ。
- 应用范围：图像空间投影器、语言与本体感知编码器、时序 Transformer、策略头的线性权重矩阵；其余参数保留簇内平均更新。下一轮持久簇模型 θ_s^{r+1} = θ_s^r + Δ̃_s。
- 服务器跟踪客户端-簇分配，下一轮客户端下载所属簇模型初始化。**聚类与 SRB 全部在服务器完成，相对 FedAvg 不增加客户端-服务器模型负载。**

**（c）聚合的理论解释**
- 将 δ_k = θ_k − θ_s^r 分解为簇内共享分量 C_s^r 与机器人特有分量 U_k^r；聚合后的特有分量为 Σ_k ep_k U_k^r。
- 若各 U_k 两两正交且 ‖U_k‖_F ≤ B，则其平方 Frobenius 范数 ≤ B²/K_eff,s（K_eff,s = (Σ ep_k²)⁻¹），即范数层面按 O(K_eff^{-1/2}) 衰减。
- 一般情形下含交叉项 2Σ_{i<j} ep_i ep_j ⟨U_i, U_j⟩_F：簇内正对齐可通过交叉项保留一致更新能量。**CUA 负责提升兼容性（增大正交叉项），SRB 负责强化仍被衰减的弱谱方向。**

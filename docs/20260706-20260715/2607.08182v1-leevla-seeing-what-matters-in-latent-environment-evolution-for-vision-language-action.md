## 摘要
视觉-语言-行动（VLA）模型旨在将多模态输入映射到机器人动作。然而，大多数现有方法由于将所有视觉标记统一处理并基于人为选择的因素进行推理，缺乏强调任务关键证据的机制且忽略了潜在因素，难以覆盖复杂的动态场景。为解决此问题，我们提出LEEVLA，一种关注潜在环境演化中关键信息的VLA架构，它显式引导模型关注信息丰富区域，同时保持潜在世界表征的结构化演化。为了识别显著且与指令相关的区域，我们引入了漂移引导的动态优先级（DGDP），它结合了动态位置优先级（DPP）与语义漂移引导（SDG），在训练过程中引导VLA智能体关注何处。在此基础上，我们引入了结构化特征流生成（SFFG），通过原型-外围（P2P）预测建模这些优先特征如何在潜在空间中演化，并使用邻域互斥对比（MC）损失来保持邻域间的拓扑一致性。DGDP与SFFG共同构成了一个任务感知的“何处-如何”训练框架。在VLA基准上的大量实验表明，LEEVLA持续优于先前方法，证实了显式任务证据引导和结构化潜在推理对于可扩展VLA均至关重要。我们的代码可在https://github.com/LyuQi127/LEEVLA获取。

## Abstract
Vision-language-action (VLA) models aim to map multimodal inputs to robot actions. However, most existing approaches struggle to cover complex dynamic scenarios due to treating all visual tokens uniformly and reasoning with human-selected factors, which lack mechanisms to emphasize task-critical evidence and ignore underlying factors. To address this issue, we propose LEEVLA, a VLA architecture for seeing what matters in Latent Environment Evolution that explicitly guides the model toward informative regions while preserving the structured evolution of latent world representations. To identify salient and instruction-relevant regions, we introduce drift-guided dynamic prioritization (DGDP), which combines dynamic position prioritization (DPP) with semantic drift guidance (SDG) to guide the VLA agent where to attend during training. On top of this, we introduce structured feature flow generation (SFFG), which models how these prioritized features should evolve in latent space via prototype-to-periphery (P2P) prediction, and a mutual-neighborhood contrastive (MC) loss to maintain topological consistency among neighborhoods. Together, DGDP and SFFG form a task-aware "where-how" training framework. Extensive experiments on VLA benchmarks show that LEEVLA consistently outperforms prior methods, confirming that explicit task-evidence guidance and structured latent reasoning are both crucial for scalable VLA. Our code is available at https://github.com/LyuQi127/LEEVLA.

## 1. 核心问题与研究动机
- **背景**：视觉-语言-行动（VLA）模型将多模态输入（图像、语言指令、本体感受）映射到机器人动作。现有方法（如OpenVLA、π0等）通常对所有视觉token统一处理，并依赖人为选择的特定上下文线索（如子目标图像、分割、深度）进行推理。
- **问题**：这种处理方式导致：
  - 难以关注任务关键的动态区域（如目标物体、机器人末端执行器），梯度被静态背景稀释。
  - 过度强调已知因素（如人为指定的模态），忽视潜在但任务相关的未知因素，泛化能力弱。
  - 依赖辅助模型（如分割、深度估计），增加计算开销且受限于辅助任务进展。
- **目标**：提出一种在潜在特征空间中进行结构化推理的VLA架构，自动发现任务关键区域，并建模环境表征的结构化演化，提升VLA在复杂动态场景下的性能。

## 2. 方法论：核心思想与技术细节
### 总体框架
LEEVLA由两个核心模块组成，在训练过程中协同工作，推理时无额外开销：
- **Drift-Guided Dynamic Prioritization (DGDP)**：回答“模型应将注意力放在哪里”，动态识别任务相关且动态活跃的区域。
- **Structured Feature Flow Generation (SFFG)**：回答“这些特征应如何演化”，建模潜在空间的结构化特征流。

### 2.1 DGDP：漂移引导的动态优先化
- **Dynamic Position Prioritization (DPP)**：
  - 计算每个patch在两相邻时间步（t 和 t+T）之间的余弦相似度变化，得到**动态性得分** θ_i = 1 - cos(v_t,i, v_{t+T,i})。动态性高的区域（如机器人末端、目标物体）获得更高权重。
- **Semantic Drift Guidance (SDG)**：
  - 计算每个patch与语言指令中每个token的余弦相似度（取最大值）作为**指令相关分数** r_t,i。
  - 定义语义漂移 Δ_i = clip( (r_{t+T,i} - r_t,i)/τ, -δ, δ )，反映语义向指令相关方向演化的程度。
  - 归一化后通过指数函数得到语义漂移引导因子 ω_i = exp(˜Δ_i/τ)。
- **最终优先级权重** β_i = σ(ω_i · θ_i)，其中σ为sigmoid函数。该权重用于调节后续预测损失的分配。

### 2.2 SFFG：结构化特征流生成
- **Prototype-to-Periphery (P2P) prediction**：
  - 对未来时刻 t+T 的多视图视觉特征进行聚类（如k-means），得到簇集合 C = {c_ℓ}。
  - 每个簇内，按特征到簇心（原型）的欧氏距离从小到大排序（从原型到外围）。
  - 预测损失时施加排序权重：L_P2P = 1/|C| Σ_ℓ 1/|→c_ℓ| Σ_{j∈→c_ℓ} (α + β_j) · φ(ˆv_{t+T,j}, v_{t+T,j})，其中φ为余弦嵌入损失，α为全局调制因子（设为1），β_j为DGDP权重。
- **Mutual-neighborhood Contrastive (MC) Loss**：
  - 构建基于互近邻的正样本对：先取每个anchor i的top-K近邻（G^{(1)}_i），再取这些近邻的top-M近邻（G^{(2)}_i），仅保留那些与anchor互为近邻的样本作为正集 G^+_i。
  - 使用InfoNCE损失：L_MC = -1/|I| Σ_i 1/|G^+_i| Σ_{j∈G^+_i} log( exp(S_ij/τ_c) / Σ_{ℓ≠i} exp(S_iℓ/τ_c) )，其中S_ij为余弦相似度。
  - 目的：抑制聚类噪声导致的不对称连接，保持局部拓扑一致性。

### 2.3 训练目标
总损失：L_total = λ_1 L_action + λ_2 L_P2P + λ_3 L_MC。L_action为L1动作回归损失，预测连续动作块。

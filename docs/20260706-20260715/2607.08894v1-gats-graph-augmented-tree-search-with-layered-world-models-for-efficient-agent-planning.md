## 摘要
大型语言模型（LLM）智能体在多步规划任务中显示出潜力，但现有方法如LATS（语言智能体树搜索）和ReAct在规划过程中严重依赖LLM推理，导致高计算成本和随机行为。我们提出\textbf{GATS}（图增强树搜索），一个结合了基于UCB1的系统性树搜索与分层世界模型的规划框架，在推理过程中消除LLM调用，同时实现更优的规划性能。我们的三层世界模型集成了：（L1）精确符号动作匹配，（L2）从执行日志中学习的统计信息，以及（L3）基于LLM的未知动作预测。在具有分支路径和死胡同的合成规划任务中，GATS实现了\textbf{100\%成功率}，而LATS为92%，ReAct为64%。在涵盖12个挑战性场景（包括编码工作流、网页导航和长期任务）的综合压力测试中，GATS保持\textbf{100\%成功率}，而LATS降至88.9%，ReAct降至23.9%。GATS在规划过程中每个任务需要\textbf{零次LLM调用}（而LATS每个任务37次），并生成确定性计划，运行间方差为零。我们的结果表明，使用学习到的世界模型进行系统性搜索可以大幅超越LLM引导的探索，用于智能体规划。

## Abstract
Large Language Model (LLM) agents have shown promise in multi-step planning tasks, but existing approaches like LATS (Language Agent Tree Search) and ReAct rely heavily on LLM inference during planning, leading to high computational costs and stochastic behavior. We present \textbf{GATS} (Graph-Augmented Tree Search), a planning framework that combines systematic UCB1-based tree search with a layered world model to eliminate LLM calls during inference while achieving superior planning performance. Our three-layer world model integrates: (L1) exact symbolic action matching, (L2) statistics learned from execution logs, and (L3) LLM-based prediction for unknown actions. On synthetic planning tasks with branching paths and dead-ends, GATS achieves \textbf{100\% success rate} compared to 92 % for LATS and 64\% for ReAct. On a comprehensive stress test spanning 12 challenging scenarios -- including coding workflows, web navigation, and long-horizon tasks -- GATS maintains \textbf{100\% success} while LATS drops to 88.9 % and ReAct to 23.9%. GATS requires \textbf{zero LLM calls per task} during planning (vs. 37 per task for LATS) and produces deterministic plans with zero variance across runs. Our results demonstrate that systematic search with learned world models can substantially outperform LLM-guided exploration for agent planning.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 将规划问题建模为状态空间上的图搜索，使用 **UCB1 树搜索** 结合 **分层世界模型（Layered World Model）** 预测动作结果。
- 世界模型分为三层，按优先级查询：L1（符号匹配）、L2（统计学习）、L3（LLM 预测）。LLM 仅在真正未知的动作上调用，结果被缓存复用。

### 关键技术细节

#### 问题形式化
- 状态空间 S（命题集合）、动作空间 A（每个动作有前提 prec 和效果 add/del）、初始状态 s₀、目标条件 G。
- 目标：找到动作序列 π 使 s₀ 到达目标。

#### 分层世界模型 W(s, a) → (s′, p)
- **L1（符号层）**：已知 STRIPS 规格的动作，直接检查前提是否满足，若满足则返回确定后继状态，置信度 p=1；否则返回原状态 p=0。
- **L2（统计层）**：对执行日志中观测到的动作，统计最频繁的效果，置信度 p = min(count(a)/10, 1)，饱和于 10 次观测后为 1.0。
- **L3（生成层）**：对全新动作，调用 LLM 预测后继状态，置信度固定为 0.5，预测结果缓存。
- **层选择规则**：按顺序查询，当 L1 或 L2 置信度 ≥ 给定阈值 τ 时接受，否则回退下一层。

#### 状态转移图记忆（Graph Memory）
- 构建有向图 G=(V,E)，每个节点对应唯一状态键 k(s)，边表示动作预测转移。
- 会合状态合并（transposition table）：不同路径到达相同状态时节点共享，复用搜索统计和转移预测。
- 图跨步骤持久化：执行动作后不丢弃，下一轮规划从当前节点继续。

#### UCB1 动作选择
- 每个状态 s 下的每个动作视为一个臂，选择规则：  
  \( a_t = \arg\max_{a} \left[ Q(s,a) + c \sqrt{\frac{2\ln N(s)}{N(s,a)}} \right] \)
- 其中 Q(s,a) 为平均价值，N(s,a) 为访问次数，未访问动作 UCB 设为 +∞ 确保至少评估一次。
- 价值备份：\( v = p \cdot \text{StateValue}(s′) - \lambda(1-p) \)，p 为置信度，λ 惩罚不确定预测。

#### 状态价值估计
- 用 BFS 计算当前图下到目标的最短距离 dG(s,G)，价值函数为：  
  \( \text{StateValue}(s) = \begin{cases} \frac{\alpha}{d_G(s,G)+1} & \text{若可达} \\ 0 & \text{不可达} \end{cases} \)，实验设 α=10。

#### 算法流程（文字简述）
- **GATS 搜索（单步内）**：给定当前状态 s 和可用动作集，循环预算 b 次：① UCB 选择动作 a*；② 若边不在图中则用世界模型预测后继并加入图；否则复用；③ 估计价值并更新动作统计。返回 Q 值最高的动作。
- **GATS 规划（整个任务）**：从初始状态开始，重复：收集可用动作 → 调用 GATS 搜索得到动作 → 执行动作（实际环境）并更新状态 → 记录计划。直到达到目标或步数超限。

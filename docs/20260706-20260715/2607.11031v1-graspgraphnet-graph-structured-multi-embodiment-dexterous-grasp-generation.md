## 摘要
跨机器人手的灵巧抓取生成具有挑战性，因为手在运动学拓扑、驱动维度以及原生指令空间上存在差异。我们提出GraspGraphNet，一种拓扑感知的抓取生成框架，它将每只手表示为从URDF导出的运动学图，并直接生成可执行的手掌姿态和关节配置。GraspGraphNet结合了分层物体表面编码、可微正运动学和动态世界边消息传递，以建模不断演化的机器人-物体交互。它直接在可执行的手掌姿态和关节状态空间中应用条件流匹配，避免了后处理优化、逆运动学和重定向。使用在Barrett Hand、Allegro Hand和Shadow Hand上训练的共享模型，GraspGraphNet在40个物体的基准测试中平均成功率达到83.48%，每次抓取推理时间为40毫秒。无需重新训练，同一模型在受控手指移除变体上达到72.70%的成功率，展示了对手拓扑变化的鲁棒性。这些结果表明，图结构的手部表示可以有效地支持不同运动学结构的机器人手的灵巧抓取生成。项目：https://lysees.github.io/graspgraphnet-page

## Abstract
Dexterous grasp generation across robot hands is challenging because hands differ in kinematic topology, actuation dimensions, and native command spaces. We introduce GraspGraphNet, a topology-aware grasp generation framework that represents each hand as a URDF-derived kinematic graph and directly generates executable palm poses and joint configurations. GraspGraphNet combines hierarchical object surface encoding, differentiable forward kinematics, and dynamic world-edge message passing to model evolving robot-object interactions. It applies conditional flow matching directly in executable palm-pose and joint-state space, avoiding post-processing optimization, inverse kinematics, and retargeting. Using a shared model trained on Barrett Hand, Allegro Hand, and Shadow Hand, GraspGraphNet achieves an average success rate of 83.48% with 40ms inference time per grasp on a 40-object benchmark. Without retraining, the same model achieves 72.70% success on controlled finger-removal variants, demonstrating robustness to hand-topology variations. These results suggest that graph-structured hand representations can effectively support dexterous grasp generation across robot hands with different kinematic structures. ## 2. 方法论：核心思想、关键技术细节、公式或算法流程
- **核心思想**：
  - 将每只机器人手表示为 **URDF 导出的运动学图**（link为节点，joint为有向边），保留手部拓扑结构。
  - 直接生成 **可执行的手掌位姿（平移 + 6D 旋转）和归一化关节配置**，不依赖任何后处理。
  - 使用 **条件流匹配（Conditional Flow Matching）** 学习从张开手状态到目标抓取状态的向量场。
  - 引入 **动态世界边消息传递**：在每个流步骤中，根据当前手部关节配置通过可微正运动学计算连杆世界坐标，再动态构建手部连杆与最近物体表面点之间的图边，捕捉演化中的局部接触几何。

- **关键技术细节**：
  1. **状态表示**：\( \mathbf{x} = [\mathbf{t}_{\text{palm}} \in \mathbb{R}^3, \mathbf{R}_{\text{palm}}^{\text{6D}} \in \mathbb{R}^6, \mathbf{q}_{\text{norm}} \in \mathbb{R}^J] \)，其中 J 为驱动关节数，因手而异。
  2. **物体编码**：对物体表面点云构建4级层级图（1024→256→64→32点），64点用于细粒度特征，32点用于粗粒度全局形状上下文。
  3. **机器人图编码**：从URDF构建图，每个节点包含连杆几何嵌入、当前关节状态的归一化值、可微FK计算的世界位置/方向等，通过3层MPNN沿运动学边传播消息。
  4. **融合模块**：
     - 粗交叉注意力：机器人节点查询与32点粗物体特征交叉，提供全局上下文。
     - 动态世界边MPNN：对每个机器人节点，找到当前世界坐标下 K=8 个最近物体点，构建带相对位移/距离的边消息，经残差更新。
  5. **流匹配目标**：采样 t~U(0,1)，线性插值初始状态 x0 和目标状态 x1，目标条件速度 v* = x1 - x0，预测 v_θ(xt, t) 并优化 MSE 损失（手掌与关节加权 λq=1）。
  6. **推理**：张开手状态 x(0) 经过 K 步欧拉积分（默认 K=3）得到最终可执行抓取。

## 摘要
长周期家居任务要求机器人组合多种语言条件技能，然而连续技能之间的边界很少是明确的。一个技能可能满足其自身的后置条件，却使机器人、物体或相机视图处于下一个技能无法可靠启动的状态。我们在BEHAVIOR-1K中通过一个智能体编排的视觉-语言-动作执行框架研究这一语义交接问题。该框架调用基于π₀.₅的训练技能检查点（这些检查点从清理后的BEHAVIOR-1K演示中训练而来），为每个技能分配类型化参数和步骤预算，并使用多视角视觉-语言模型验证来决定执行应继续、重试还是重新规划。为了将孤立技能能力与长周期组合鲁棒性分离，我们在两种初始状态分布下评估相同的检查点：干净的技能边界快照和由先前技能产生的链式终端状态。选定的导航、抓取、放置和开门技能在人验证的审查下从干净快照中获得了77-100%的成功率，但组合的滚动执行仍频繁因链式状态而停滞。执行轨迹将这些失败归因于下一技能就绪性、目标锚定和低级控制执行，揭示了单一技能成功与可靠的长周期任务完成之间的显著差距。这些发现将近乎为零的端到端任务成功转化为可操作的诊断，表明未来的VLA技能库必须学习对混乱的链式状态分布的鲁棒性，而干净的演示系统性地低估了这种分布。

## Abstract
Long-horizon household tasks require robots to compose many language-conditioned skills, yet the boundary between consecutive skills is rarely explicit. A skill may satisfy its own postcondition while leaving the robot, objects, or camera views in a state from which the next skill cannot reliably start. We study this semantic handoff problem in BEHAVIOR-1K through an agent-orchestrated vision-language-action execution harness. The harness invokes $π_{0.5}$-based skill checkpoints trained from cleaned BEHAVIOR-1K demonstrations, assigns each skill typed arguments and a step budget, and uses multi-view vision-language model verification to decide whether execution should advance, retry, or replan. To separate isolated skill competence from long-horizon compositional robustness, we evaluate the same checkpoints under two initial-state distributions: clean skill-boundary snapshots and chained terminal states produced by previous skills. Selected navigation, grasping, placement, and door-opening skills achieve 77--100% success from clean snapshots under human-reviewed verification, yet composed rollouts still frequently stall from chained states. Execution traces attribute these failures to next-skill readiness, target grounding, and low-level control execution, revealing a substantial gap between single-skill success and reliable long-horizon task completion. These findings turn near-zero end-to-end task success into actionable diagnostics, showing that future VLA skill libraries must learn robustness to the messy chained-state distribution that clean demonstrations systematically underrepresent.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：长周期机器人任务需要组合多种语言条件下的技能（导航、抓取、放置等），但连续技能之间的“语义边界”往往不明确。一个技能可能完成自身后置条件（如导航到目标区域），却让机器人、物体或摄像机视角处于下一个技能无法启动的状态——即**语义交接失败**（semantic handoff failures）。
- **研究动机**：现有VLA模型通常从清洁的演示边界状态进行单技能评估，但实际组合执行时，每个技能的初始状态是上一技能留下的**链式终端状态**（chained terminal state），与单技能评估的分布存在严重偏移。本文旨在通过一个智能体编排的执行框架，系统性地诊断这一问题，分离“单技能能力”与“组合鲁棒性”，并给出可操作的改进方向。
- **整体含义**：揭示当前VLA技能库在组合时几乎无法完成完整任务（端到端任务成功率接近零），而故障并非由于单技能太弱，而是因为缺乏对链式状态分布的鲁棒性。这指明了未来VLA研究需要补充链式状态数据和就绪性验证。

## 2. 方法论：核心思想、关键技术细节、算法流程

### 核心思想

- 将智能体层与具身层分离：智能体层负责任务分解、技能调用、验证与恢复；具身层拥有仿真环境、VLA推理和动作执行。
- 通过**语义技能合约**（semantic skill contract）显式定义每个技能的类型、参数、提示、预算、验证间隔和后置条件，并将“下一技能就绪性”隐含编码到后置条件中（例如导航后置条件要求目标处于手臂可及范围）。

### 关键技术细节

- **VLA模型**：使用 π₀.₅ 视觉-语言-动作策略（PaliGemma 2B 视觉语言主干 + 300M 参数的流匹配动作专家），输入三个224×224的RGB视图（头戴相机+左右腕相机）和本体感觉状态。
- **训练策略**：两阶段训练。
  - 全技能中期训练（mid-training）：在合并的技能数据上微调基础π₀.₅检查点50k步。
  - 技能组后训练（skill-group post-training）：针对导航/定向、开关/按压、门开/关、抓取、平面放置、容器放置等6个技能组分别微调，使用余弦学习率调度（峰值2.5×10⁻⁵，全局batch size 256）。
- **技能合约**：每个技能调用包含 `(name, args, prompt, B_s (最大步数预算), K_s (验证间隔), ϕ_t (预期后置条件))`。技能包括 `move_to`, `pick_up_from`, `place_on`, `open_door` 等9种。
- **执行循环**：**计划-行动-验证-重新规划**（plan-act-verify-replan）。
  1. 智能体层按任务脚本依次发出技能调用。
  2. VLA模型执行一个动作块（`K_s`个环境步）。
  3. 收集三视图观测，向多视图VLM（gemini-2.5-flash）查询当前技能的后置条件是否满足（置信度阈值>0.6）。
  4. 若满足则前进至下一技能；若不满足，则重试（retry）或在预算内重新规划（replan）。
- **验证器**：对导航技能，后置条件要求目标在头部相机中“近距、突出、手臂可达”，否则判定失败并触发重新导航。

## 3. 实验设计

- **数据集/场景**：BEHAVIOR-1K（基于OmniGibson仿真），包含1,000个日常活动。本文使用了10个代表性任务（如Turn on radio, Make microwave popcorn, Put shoes on rack等），每个任务有官方测试实例。
- **基准协议**：两种互补的评估协议。
  1. **孤立单技能基准**（isolated single-skill benchmark）：从验证集的清洁演示边界快照恢复仿真，运行对应技能组检查点，独立评估技能完成情况。成功由多视图VLM判定并经人工审查确认。
  2. **链式端到端滚动**（composed end-to-end rollout）：同样的技能检查点通过智能体循环串联执行，每个技能从上一技能的终端状态启动。最终任务成功由BEHAVIOR-1K的BDDL谓词衡量。
- **对比方法**：本文未与其他机器人系统或方法进行对比，主要聚焦于自身框架的诊断能力。本质上是一个自我对照研究，关键对比是“同一检查点在不同初始状态下（清洁快照 vs 链式状态）的表现差异”。
- **诊断标签**：失败尝试被归为三类（通过VLM的结构化原因提取）：
  - 控制执行（control execution）：抓取未合拢、致动未触发、放置位置偏移。
  - 目标接地（target grounding）：目标在视野外或选错实例。

## 6. 主要结论与发现

1. **单技能能力良好**：从清洁快照出发，导航（77%）、抓取（97%）、放置（净面100%）、开门（100%）等技能成功率较高。
2. **组合后失败率剧增**：同一检查点在链式状态下从链式状态启动，导致任务级成功几乎为零（平均进度19.5%，最低0%）。失败集中在接触式操作和多物体放置步骤。
3. **失败可归因于三类VLA侧问题**：
   - 控制执行（40%左右）：抓取未闭合、致动失败、放置错位。
   - 目标接地（约28%）：目标出视野或错误实例。
   - 下一技能就绪性（约27%）：导航未到达可操作距离（arm-reach）。
4. **导航验证标准收紧效果**：将“到达区域”改为“手臂可达”后，暴露出更多就绪性失败（从23增至35），触发更多重导航（74→99），并成功完成了无线电任务（唯一一个有任务谓词成功的任务）。
5. **验证器可靠性**：盲人审计表明验证器错误拒绝真实成功的比例仅5%，说明报告的失败是真实的。
6. **关键洞察**：组合失败不能由单技能成功率预测；需要通过链式状态数据和就绪性验证来弥补。

## 7. 优点

- **问题定义新颖**：明确提出了VLA技能组合中的“语义交接”问题，并将其与传统的复合误差（compounding error）区分开——这是两个不同策略之间的分布偏移。
- **框架设计分离关注点**：智能体层负责任务控制、验证、恢复和痕迹记录，具身层专注于VLA执行，便于独立改进。
- **诊断价值高**：将几乎为零的任务成功率转化为三类可操作的失败原因，给出了改进方向（如链式数据微调、实例接地监督、就绪性谓词）。
- **验证器审计**：对VLM验证器的失败决定进行了双盲人工审计，确认了其可靠性（过严率5%）。
- **控制消融**：通过单一变量（验证标准）的消融实验，展示了收紧就绪性条件的影响。

## 8. 不足与局限

- **实验规模小**：端到端仅30个滚动（10任务×3实例），孤立技能样本数也偏少。统计显著性不足，结论初步。
- **基准缺乏横向对比**：未与任何现有方法（如Code as Policies、SayCan、MAESTRO等）比较，无法评估框架的相对表现。
- **验证器分类标签可能有偏差**：失败类别（就绪/接地/控制）由VLM自动生成，人工只验证了整体失败判断，未验证类别准确性。人工审计仅21个样本。
- **人工注释主观性**：进度得分（progress score）由单个人通过录像打分，可能不准确，且只认可参考序列（不准许替代方案）。
- **过度依赖VLM验证**：验证器是黑箱模型，可能对视野外、部分遮挡、物体状态不敏感，且其可靠性与模型更新相关。
- **恢复策略简单**：当前只支持重新导航和重试，未探索更复杂的恢复（如重新规划完整任务序列或重置）。无“oracle重置”上界（因为仿真无法暴露任意状态恢复）。
- **应用限制**：仅在BEHAVIOR-1K仿真中验证，未推广到真实机器人或其他环境；技能库仅包含9种技能，不能覆盖各种任务。资产和物体名称（如“door”、“storage box”）存在歧义。
- **可重复性**：训练使用的具体数据划分、清理细节、VLM版本（gemini-2.5-flash）依赖外部API，可能难以完全复现。

## 摘要
移动操作机器人需要具备当前、可查询、语义有意义且在边缘计算约束下可用的世界模型。本技术报告提出了KRVF，一种面向边缘移动操作的信源感知语义体素世界表示。与主要优化全局几何保真度的以重建为中心的建图管线不同，KRVF将局部世界状态表示为面向任务的体素，这些体素编码了占据、颜色、语义证据、时间新鲜度以及证据来源。该表示将测量到的占据与语义先验假设分离，从而在不静默破坏持久几何的情况下实现深度失效感知的对象推理。KRVF还通过渲染地图先验深度进行修复，闭合了建图与感知之间的反馈回路，并为语义对象和抓取候选对象提供了任务级查询操作符。该报告形式化了KRVF表示，并记录了一个ROS 2实现，该实现将在线RGB-D观测转化为面向任务的机器人记忆。

## Abstract
Mobile manipulators need world models that are current, queryable, semantically meaningful, and usable under edge-compute constraints. This technical report presents KRVF, a source-aware semantic voxel world representation for edge mobile manipulation. Unlike reconstruction-centric mapping pipelines that primarily optimize global geometric fidelity, KRVF represents local world state as task-oriented voxels that encode occupancy, color, semantic evidence, temporal freshness, and evidence source. The representation separates measured occupancy from semantic-prior hypotheses, enabling depth-failure-aware object reasoning without silently corrupting persistent geometry. KRVF also closes a feedback loop between mapping and sensing by rendering map-prior depth for repair, and exposes task-level query operators for semantic objects and grasp candidates. The report formalizes the KRVF representation and documents a ROS 2 implementation that turns online RGB-D observations into a task-facing robot memory.

- **核心问题**：移动操作机器人在边缘计算硬件上运行时，需要一种既能够实时更新、又具有语义意义、且能被任务层高效查询的世界模型。传统的以重建为中心的建图方法（如TSDF、OctoMap）主要优化全局几何精度，但缺乏对边缘计算资源约束、语义查询性、动作延迟以及深度传感器失效场景的针对性设计。
- **动机**：机器人不仅要“重建”，更要能够回答任务层问题：物体在哪里？证据是否可靠？观测是否过时？可以执行什么抓取动作？特别是在桌面、近场操作场景中，透明、反光、高光、黑色或薄物体常导致RGB-D深度失效；动态物体会留下过时几何痕迹；语义检测器可能正确但深度缺失。现有方法无法同时处理这些挑战。
- **整体含义**：KRVF将地图视为一种“信源感知的、可查询的机器人世界状态”，而非单纯的几何重建。它区分测量几何与语义假设，维护新鲜度和置信度，并直接暴露物体和抓取查询接口，使下游行为树和操作管线能够以任务导向的方式消费地图。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
### 核心思想
- **信源感知体素状态**：每个体素用多元组表示：占据对数几率、视觉外观、语义证据、观测质量置信度、时间新鲜度、证据类型（观测/修复/假设/不确定）。
- **观测-假设分离**：将地图分为观测层 \(K_t^{obs}\) 和语义假设层 \(K_t^{hyp}\)，后者由语义检测器在深度失效时生成，不会自动合并到持久几何中，且具有有限生命周期（TTL过期则消失）。
- **地图先验深度反馈**：将当前体素地图渲染回相机视角作为深度先验，与当前损坏深度结合进行修复，修复后的深度以较低置信度重新注入地图。
- **任务级查询接口**：提供语义物体查询（\(Q_{obj}(s, x) \to O_j\)）和抓取候选查询（\(Q_{grasp}(O_j) \to \{g_{top}, g_{waist}, g_{side}, g_{center}\}\)），基于体素聚类物体的几何和稳定性生成抓取候选。

### 关键技术细节
- **源加权融合**：占据更新为 \(\Delta l_i = q_t \cdot L_{hit}(z_t, x_t, v_i)\)，其中 \(q_t\) 为源置信度（原始深度、修复深度、语义假设各有不同置信度）。
- **语义门控逆传感器模型**：融合物理深度与语义先验，通过 \(\alpha_i\) 控制两者权重：\(\Delta l_i = \alpha_i L_{phys} + (1-\alpha_i)L_{sem}\)。当前实现保守地保持假设层与观测层分离，不直接替换射线模型。
- **动态清理**：占据体素在连续未观测到后，对数几率衰减：\(l_{i,t+1} = l_{i,t} - \beta \cdot m_i\)，所需缺失次数依赖于局部支撑（稳定支撑区域需要更多缺失才会被清除）。
- **阴影壳防护**：通过比较色相、饱和度、亮度，拒绝暗色重复表面伪影。
- **颜色稳定化**：维持持久颜色和实时颜色两套估计，通过引导、冻结、混合策略避免单帧噪声覆盖稳定颜色。
- **候选体素晋升**：短期缓存不确定观测，多次证据后晋升为稳定体素。

### 算法流程（文字描述）
1. 输入同步的RGB-D图像、相机标定、机器人位姿（来自TF或里程计）。
2. 有效深度点被反投影到3D，转换到世界坐标系，插入到分块稀疏体素地图。
3. 每个体素融合占据、颜色、置信度、时间戳。
4. 通过保守射线投射集成自由空间证据。
5. 语义检测器（如YOLO）的2D检测框通过深度采样投射到体素，仅更新已存在的占据体素附近的语义标签；若深度缺失，则在假设层创建有界假设体素。
6. 地图可以渲染为深度先验图像，送入深度修复模块修复损坏深度，再以修复置信度融合回地图。
7. 下游通过服务/动作接口查询语义物体和抓取候选。

## 7. 优点
- **信源感知表示**：体素不仅存储占据状态，还携带来源、置信度、时间戳，使系统能区分“真正测量到的”与“假设的”“修复的”信息，增强了鲁棒性和透明性。
- **观测-假设分离**：保证了持久几何的完整性，防止语义假阳性被永久写入地图，同时允许任务层临时利用检测假设。
- **地图先验反馈**：将地图作为主动感知组件，而不是被动接收传感器数据，体现了系统级设计智慧。
- **任务接口设计**：通过服务/动作暴露物体和抓取查询，使得行为树和操作管线能直接使用，无需解析原始点云，降低了系统集成难度。

## 摘要
机器人操作的强化学习通常需要手动设计密集奖励函数，这难以调整且往往脆弱，或者从人类演示或偏好中学习奖励，这代价高昂。最近一系列工作使用预训练的视觉-语言模型作为零样本奖励模型，用单个文本提示替代这些成本。然而，我们认为单个全局提示对于具有随机初始条件的长时域操作任务过于粗糙。单提示VLM奖励在大部分轨迹中近乎平坦，使得智能体难以检测早期进展。我们提出了强化微任务学习，一种将操作任务分解为一小组语言描述的微任务并训练智能体在它们之间切换的方法。每一步，智能体接收使用当前活跃微任务提示计算的多视角VLM奖励，并在多个相机视角上平均以减少视角特定遮挡的影响。逆向课程逐渐让智能体暴露于更难的初始条件，而PPO工作器首先使用固定的基于距离的规则选择活跃微任务进行训练。然后我们用学习到的分层管理器替换该规则，将基于规则的阶段选择转变为完全学习的分层策略。我们在Fetch操作环境上实例化RMTL，使用三个短阶段特定提示，无需额外提示调优。实验表明，RMTL比单提示VLM奖励提供信息更丰富的奖励信号，实现更快的学习速度。这些结果表明，将VLM奖励分解为微任务特定的语言提示可以显著提高语言引导的强化学习在机器人操作中的可扩展性。

## Abstract
Reinforcement learning (RL) for robotic manipulation often requires manually designing a dense reward function, which is difficult to tune and often fragile, or learning a reward from human demonstrations or preferences, which can be expensive. A recent line of work uses pretrained vision-language models (VLMs) as zero-shot reward models, replacing these costs with a single text prompt. However, we argue that a single global prompt is too coarse for long-horizon manipulation tasks with randomized initial conditions. The single-prompt VLM reward is near-flat for much of the trajectory, making early progress hard for the agent to detect. We propose Reinforced Micro-Task Learning (RMTL), an approach that decomposes a manipulation task into a small set of language-described micro-tasks and trains the agent to switch between them. At each step, the agent receives a multi-view VLM reward computed using the prompt of the currently active micro-task and averaged across multiple camera views to reduce the effect of view-specific occlusions. A reverse curriculum gradually exposes the agent to harder initial conditions, while a PPO worker is first trained with a fixed distance-based rule that selects the active micro-task. We then replace this rule with a learned hierarchical manager, turning rule-based phase selection into a fully learned hierarchical policy. We instantiate RMTL on the Fetch manipulation environment using three short stage-specific prompts and without additional prompt tuning. Experiments show that RMTL provides more informative reward signals than single-prompt VLM rewards, enabling faster learning. These results suggest that decomposing VLM rewards into micro-task-specific language prompts can substantially improve the scalability of language-guided reinforcement learning for robotic manipulation.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：机器人操作的强化学习（RL）通常依赖手工设计的密集奖励函数（难以调参、脆弱），或从人类演示/偏好中学习奖励（昂贵、难扩展）。近期工作使用预训练的视觉-语言模型（VLM）作为零样本奖励模型，只需一个文本提示即可计算奖励，避免了手工设计和数据需求。
- **核心问题**：在具有随机初始条件的长时域操作任务中，单一全局提示（如“机器人抓爪举起红色立方体”）产生的VLM奖励大部分轨迹上近乎平坦，尤其早期阶段（靠近、对齐等）与目标状态语义相似性低，导致奖励梯度微弱，智能体难以有效学习。
- **整体含义**：针对该问题，作者提出**强化微任务学习（RMTL）**，将单一操作任务分解为多个语言描述的微任务阶段，每个阶段使用对应的专用提示计算奖励，并结合多视角融合、逆向课程和分层管理策略，使奖励信号更丰富、可用于PPO训练，显著提升学习效率和最终性能。

## 2. 论文提出的方法论

### 核心思想
RMTL 将长时域操作任务分解为一小组语言描述的微任务（approach, align, grasp），在每个时间步只使用当前活跃微任务的提示计算VLM奖励（多视角平均），并训练一个分层策略：底层PPO工作器执行动作，高层管理器（规则或学习型）选择当前微任务。同时采用逆向课程从简单初始条件逐渐过渡到完全随机初始化。

### 关键技术细节

1. **多视角VLM奖励聚合**：
   - 使用6个固定相机视角渲染图像。
   - 对每个微任务i，分别计算每个视角v的投影得分（基于CLIP风格编码器），然后取所有视角的平均值作为该步奖励 \( r_t^{(i)} = \frac{1}{V} \sum_{v=1}^V r_v^{(i)} \)。
   - 投影得分公式：\( r_v^{(i)} = 1 - \frac{1}{2} \| x_v - e_{\tau_i} \|_{P_\alpha(d_i)}^2 \)，其中 \( d_i = e_{\tau_i} - e_b \) 为微任务提示与基线提示的嵌入差，\( P_\alpha \) 是带参数α（取0.9）的投影混合矩阵，平衡沿语义轴的方向性。

2. **微任务分解与分阶段奖励**：
   - 三个微任务提示：approach（抓爪在立方体上方打开）、align（抓爪夹住立方体）、grasp（抓爪举起立方体）。
   - 基线提示：“机器人抓爪和桌上的红色立方体”。
   - 时间步t只使用当前活跃微任务的提示计算奖励，而非求和或平均。

3. **逆向课程（Reverse Curriculum）**：
   - 设置5个难度等级（d = 0, 0.15, 0.4, 0.65, 1.0），从最简单的“抓爪在立方体正上方”到完全随机工作空间初始化。
   - 升级条件：当前等级成功率超过阈值（如0.5）且达到最少步数；无回归。

4. **两阶段训练**：
   - **Stage 1**：使用规则（基于抓爪-立方体距离）选择活跃微任务，训练PPO工作器（MLP 256x256）。
   - **Stage 2**：加载Stage 1的PPO检查点（560k步），冻结工作器动作网络（前50k步），训练一个分层管理器（MLP 128x128 + softmax）替代规则管理器。
     - 管理器每H=3步做一次决策，通过REINFORCE优化（优势为段返回的z-score），加入熵正则化和KL散度（锚定至规则策略）。
     - 行为克隆（BC）预热：用规则标签预训练管理器3500步。
     - 50k步后解冻工作器并降低学习率。

5. **算法流程**：见论文Algorithm 1（文字描述）：收集规则标签进行BC预热；在线HRL训练中冻结工作器动作网络，每步用ε-greedy选择微任务，累积段奖励；结束时更新管理器和PPO工作器。

## 3. 实验设计

### 使用的环境与任务
- **环境**：FetchPickAndPlace-v4（Gymnasium-Robotics），7自由度Fetch机械臂，拾取红色立方体并稳定举起。
- **观测**：25维状态（抓爪位姿、立方体位姿、手指开合、目标位置），4维连续动作。渲染修改为高保真（饱和红色立方体、木质桌面、中性灰背景）以适配VLM。
- **成功判定**：抓爪与立方体距离≤0.025m且立方体提升≥0.02m持续两步，奖励+1.0。
- **基准**：自身消融：对比（1）三个微任务提示+多视角；（2）单个全局提示+多视角；（3）单个全局提示+单视角。所有设置相同RL超参。
- **对比方法**：在随机初始条件下，比较PPO（无分层）、HRL（规则管理器）、HRL（学习型管理器）、PPO（单任务提示）。

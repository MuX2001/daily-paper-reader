## 摘要
长时域任务在真实机器人部署中很常见，然而此类任务的故障检测仍未得到充分探索。在长时域机器人任务中检测故障尤其具有挑战性，因为故障发生通常模糊不清，且通常缺乏密集的时间标注。我们提出Foresight，一种故障检测框架，它利用来自动作条件世界模型的潜变量表示来监控操作轨迹。Foresight仅使用最终任务级的成功或失败标签进行训练。通过利用预测性世界模型嵌入，我们的方法为跨不同策略的故障检测提供了统一框架。我们进一步使用函数共形预测（FCP）自适应地校准检测阈值。我们在LIBERO-Long、ManiSkill-Long和BEHAVIOR-1K上使用最先进的视觉-语言-动作策略在仿真中评估Foresight，将其与最先进的故障检测方法进行比较，并在真实机器人上使用ReactorX-200臂执行三个长时域任务和Franka臂执行一个任务进行验证。我们的结果表明，动作条件世界模型嵌入为长时域操作中的可靠故障监控提供了可扩展的表示。

## Abstract
Long-horizon tasks are common in real-world robotic deployments, yet failure detection for such tasks remains underexplored. Detecting failures in long-horizon robotic tasks is particularly challenging because failure onset is often ambiguous and dense temporal annotations are typically unavailable. We present Foresight, a failure detection framework that monitors manipulation trajectories using latent representations from an action-conditioned world model. Foresight is trained using only final task-level success or failure labels. By leveraging predictive world-model embeddings, our method provides a unified framework for failure detection across different policies. We further use functional conformal prediction (FCP) to calibrate detection thresholds adaptively. We evaluate Foresight with state-of-the-art vision-language-action policies in simulation on LIBERO-Long, ManiSkill-Long, and BEHAVIOR-1K, compare it against state-of-the-artfailure detection methods, and validate it on real robots with three long-horizon tasks on a ReactorX-200 arm and one task on a Franka arm. Our results suggest that action-conditioned world-model embeddings provide a scalable representation for reliable failure monitoring in long-horizon manipulation.

## 2. 论文提出的方法论
### 核心思想
利用预训练的视觉-语言-动作世界模型（V-JEPA 2-AC）提取**动作条件预测潜变量**，该变量编码了“在给定观测上下文和策略执行的动作块后，世界模型期望场景如何演化”。将这种潜变量作为特征输入因果序列模型，输出逐时间步的故障分数，再利用函数共形预测（FCP）自适应地设定随时间变化的阈值，将连续分数转化为二值警报。

### 关键技术细节
1. **世界模型特征提取**：使用 V-JEPA 2-AC（ViT-Giant 编码器，冻结），其动作条件预测器（从头训练）接收观测上下文 \(c_t\)（8帧滑动窗口）和策略预测的动作块 \(A_t\)，输出预测的潜变量 \(z_t^p = \text{Pool}(g_\psi(z_t^h, A_t))\)，其中 \(z_t^h\) 是当前观测的隐藏潜变量。
2. **故障评分**：将 \(z_t^p\) 通过线性投影并加上正弦位置编码得到时间步 token \(u_t\)，输入因果 Transformer（或 LSTM/MLP 变体）产生故障分数 \(s_t \in [0,1]\)。因果掩码确保每步只使用过去信息。
3. **阈值校准**：在成功轨迹的校准集上，使用函数共形预测（FCP）估计非一致分数 \(R_i = \sup_t (s_t^{(i)} - \mu_t)/\sigma_t\)，取 \((1-\alpha)\) 分位数 \(\hat{q}\)，构造阈值 \(\delta_t = \mu_t + \hat{q}\sigma_t\)。当 \(s_t \geq \delta_t\) 时触发警报。

### 公式与算法流程（文字说明）
- 输入：当前观测 \(c_t\)，动作块 \(A_t\)。
- 特征提取：\(z_t^h = \text{Pool}(f_\phi(c_t))\)，\(z_t^p = \text{Pool}(g_\psi(z_t^h, A_t))\)。
- 时间步 token：\(u_t = W z_t^p + p_t\)。
- 故障分数：\(s_t = D_\theta(\{u_1,\dots,u_t\})\)（因果 Transformer）。
- 校准阈值：\(\delta_t = \mu_t + \hat{q}\sigma_t\)，其中 \(\mu_t, \sigma_t\) 为校准集均值/标准差，\(\hat{q}\) 为校准非一致分数的 \((1-\alpha)\) 分位数。
- 报警：\(\hat{y}_t = 1[s_t \geq \delta_t]\)。

## 3. 实验设计
### 数据集/场景
- **仿真基准**：
  - **LIBERO-Long**：10个桌面操作任务，平均253步/成功轨迹；使用 Franka 臂。
  - **ManiSkill-Long**：4个更长动作链任务（如堆叠6个方块），平均1484步；使用 Franka 臂。
  - **BEHAVIOR-1K**：4个移动操作任务（如设置捕鼠器、煮热狗），平均8557步；使用 R1Pro 移动操作臂。
- **真实机器人实验**：
  - ReactorX-200 臂（3个桌上任务）：分别使用 ACT、π0.5、SmolVLA 策略，每任务约40条轨迹。
  - Franka 臂（拾取3个玩具任务）：使用 GR00T N1.5 策略，44条轨迹。

### 对比方法
- FAIL-Detect：基于不确定性/策略内部潜变量的 OOD 检测。
- SAFE-MLP/LSTM：利用策略内部表示的故障检测器。
- RND（Random Network Distillation）：基于成功轨迹嵌入分布建模。
- Gauge：使用压缩视频世界模型潜变量+共形决策。

### 评估指标
- **ROC-AUC**：采用轨迹级最大故障分数，衡量阈值无关的分离能力。
- **平衡准确率**（Balanced Accuracy）：采用共形预测阈值后计算的 \(0.5(\text{TPR}+\text{TNR})\)，消除类别不平衡影响。

### 实验协议
- 3折交叉验证；每折划分训练/验证/校准/测试；仅最终任务级标签用于训练检测器；AC预测器使用除测试外所有数据训练。

## 4. 资源与算力

## 6. 论文的主要结论与发现
1. **Foresight-Transformer 在仿真和真实场景中均达到最优或次优性能**。在 BEHAVIOR-1K（最长时域）上平衡准确率比最佳 baseline 提升 14%，ROC-AUC 提升 4%。
2. **动作条件预测潜变量优于纯观测隐藏潜变量**，说明动作信息对于检测执行与预期进展的偏差至关重要。
3. **Foresight 可跨策略泛化**，但转移效果依赖于训练策略的行为覆盖范围（如 π0.5 含恢复行为，训练后对 ACT 转移良好，反之则差）。
4. **共形预测阈值提供了统计可解释的误报控制**，真实实验中误报率可控。
5. **序列检测器（Transformer/LSTM）远优于独立帧级 MLP**，说明长时域故障信号需要时间上下文建模。

## 7. 优点
- **无需策略内部状态或置信度**：仅需观测和动作块，适用于任何可观测到动作的策略（VLA、ACT、扩散策略等），实现“策略无关”监控。
- **仅需任务级标签**：无需逐时间步故障标注，降低了数据收集成本。
- **统计可靠的阈值校准**：FCP 提供有限样本保证下的误报控制，无需手动调参。
- **全面的实验验证**：覆盖三个仿真基准（包括目前最长时域的 BEHAVIOR-1K）和四种真实机器人/策略组合，消融与泛化分析详尽，结果具有说服力。
- **开源与可复现**：提供项目页面，代码公开。

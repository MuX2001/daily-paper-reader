## 摘要
现代视觉-语言-动作（VLA）模型通常难以泛化到新的设置中，例如改变的摄像机视角或机器人形态，因为它们通常仅基于当前观察和语言指令进行条件生成。通过忽略底层系统配置作为变量，这些模型隐含地假设了训练期间遇到的固定执行上下文，从而需要对任何新环境进行数据密集型微调。在这项工作中，我们引入了上下文世界建模（ICWM），这是一种将系统识别视为上下文自适应问题的框架。ICWM使机器人策略能够从短历史的自生成、任务无关的交互中自主推断出关键系统变量。与传统上下文学习使用示范来指定执行什么任务不同，ICWM利用上下文窗口来理解系统如何运行。通过在任务执行前处理这些交互，模型隐式地捕获了当前系统的世界动态，从而无需参数更新即可适应新配置。在仿真和真实世界机器人平台上的大量实验表明，ICWM在新型摄像机视角下显著优于标准VLA基线。

## Abstract
Modern Vision-Language-Action (VLA) models often fail to generalize to novel setups, such as altered camera viewpoints or robot morphologies, because they are typically conditioned only on current observations and language instructions. By ignoring the underlying system configuration as a variable, these models implicitly assume a fixed execution context encountered during training, necessitating data-intensive fine-tuning for any new environment. In this work, we introduce In-Context World Modeling (ICWM), a framework that treats system identification as an in-context adaptation problem. ICWM enables robot policies to autonomously infer essential system variables from a short history of self-generated, task-agnostic interactions. Unlike traditional In-Context Learning that uses demonstrations to specify what task to perform, ICWM leverages the context window to understand how the system operates. By processing these interactions before task execution, the model implicitly captures the world dynamics of the current system, enabling adaptation to novel configurations without parameter updates. Extensive experiments in simulation and on real-world robot platforms demonstrate that ICWM significantly outperforms standard VLA baselines on novel camera viewpoints.

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：提出**上下文世界建模（In-Context World Modeling, ICWM）**。将系统识别重新塑造成一个上下文自适应问题：在任务执行前，机器人进行一小段**任务无关的随机探索**，记录下视觉-动作过渡片段作为上下文；模型从这些上下文隐式地恢复当前系统的配置 ψ，并据此调整后续的动作生成，整个过程无需参数更新或任务特定演示。
- **关键技术细节**：
  - **形式化定义**：标准VLA策略 πθ(at|ot, l) 隐含了退化（对所有训练配置 ψ 的边际化），无法泛化到特定 ψ′。理想策略应显式条件于 ψ：π*θ(at|ot,l,ψ)。ICWM通过在测试时收集交互上下文 T = {(osi, ai, oei)}ᵢ₌₁…N，并定义一个隐式推断函数 Ψ(T) 恢复 ψ，从而将策略重写为：at ∼ πθ(at | Ψ(T), ot, l)。其中 Ψ 与 VLA 骨干共享参数（参数高效），通过标准序列建模提取因果结构。
  - **训练阶段**：在多样系统配置下收集数据，每个训练样本前拼接 N 个任务无关的交互片段作为上下文，迫使模型学习从上下文中提取动力学信息以准确预测任务动作。
  - **推理阶段**：分两步——**主动探测阶段**：机器人执行 N 个随机探测动作，记录起止图像和动作，形成上下文 T；**上下文执行阶段**：将 T 作为上下文前缀，与当前观测和语言指令一起输入模型，生成与当前物理设置对齐的动作。由于 T 的隐藏状态可用 KV 缓存复用，额外推理时延很小（N=5 时仅增加 0.185s/step）。
- **理论支撑**：论文通过一个命题证明：交互上下文 T 关于 ψ 的信息量严格大于单帧观测，即使动作是随机的。这保证了任务无关的随机探索也能提供足够的配置信息。

- ICWM 在仿真和真实实验中均显著优于所有基线，在 LIBERO OOD 视角上平均提升 13.0%，在真实机器人上提升 71%（从 17% 到 29%）。

## 7. 优点：方法或实验设计上的亮点

- **创新性**：首次将 VLA 泛化问题重新定义为测试时系统识别，并利用任务无关的随机探索作为上下文进行隐式世界建模，无需演示、奖励或梯度更新，实用性强。
- **参数高效**：Ψ 函数与 VLA 骨干共享参数，无需额外建模头或训练目标，零额外参数开销。
- **理论支撑**：证明了交互上下文的信息量大于单帧观测，为方法提供了信息论基础。
- **实验全面性**：覆盖仿真和真实平台，多种 OOD 类型（视角、语义、形态），深入消融（上下文组件、探测策略），并可视化隐藏表示（t-SNE）验证可辨识性。

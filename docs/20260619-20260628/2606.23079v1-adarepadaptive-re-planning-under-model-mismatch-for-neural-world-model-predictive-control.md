## 摘要
神经世界模型结合模型预测控制（MPC）在每个环境步骤进行重规划，以限制累积预测误差，但这会带来大量计算开销。重用缓存的计划可减少此开销，但其有效性取决于预测失配如何通过局部动力学传播。我们通过基于扰动的动态遗憾框架分析这种权衡，并表明陈旧计划惩罚与重用容差、自上次重规划步骤以来的累积失配以及局部动力学敏感性成比例。基于这一结构，我们提出AdaReP，一种无需训练的封装器，它利用与缓存推演的当前偏差和局部敏感性估计在线调整重规划容差，无需修改学习到的世界模型或规划器。在图像空间规划、潜在空间控制和真实世界机器人操作中，AdaReP显著减少了规划器侧的计算量，同时保持了相当的任务性能，包括在50次试验的实体机器人研究中减少了80%以上的查询。

## Abstract
Neural world models coupled with model predictive control (MPC) replan at every environment step to bound accumulated prediction error, but this incurs substantial computational overhead. Reusing a cached plan reduces this overhead, yet its effectiveness depends on how prediction mismatch propagates through the local dynamics. We analyze this trade-off with a perturbation-based dynamic-regret framework and show that stale-plan penalties scale with the reuse tolerance, the accumulated mismatch since the last replanning step, and the local dynamics sensitivity. Based on this structure, we propose AdaReP, a training-free wrapper that adapts the replanning tolerance online using the current deviation from the cached rollout and a local sensitivity estimate, without modifying the learned world model or planner. Across image-space planning, latent-space control, and real-world robotic manipulation, AdaReP substantially reduces planner-side computation while maintaining comparable task performance, including over 80% fewer queries on a 50-trial physical robot study.

- **核心问题**：神经世界模型结合模型预测控制（MPC）在机器人操控等领域取得了成功。然而，标准的MPC框架要求在**每个环境步骤都进行重规划**，以限制模型预测误差的累积。这虽然保证了性能，但每次重规划都需要多次查询大型的、计算昂贵的世界模型，导致**巨大的计算开销**，在计算资源受限的实体机器人平台上尤为突出。
- **解决思路**：直观地，如果当前执行轨迹与缓存的计划偏差不大，直接重复使用之前的计划可以节省计算。但这种“懒惰”策略的风险在于，当模型失配导致执行偏离计划，或局部动力学非常敏感时，继续使用陈旧计划会导致性能急剧下降。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：通过扰动动态遗憾（Perturbation-based Dynamic Regret）分析，论文揭示了使用陈旧的缓存计划所带来的性能损失（遗憾）主要由三个因素决定：
    1.  **重用容差**：允许的最大偏差。
    2.  **累积失配**：自上次重规划以来，模型预测误差的累积程度。
    3.  **局部动力学敏感性**：环境动力学对状态和动作扰动的放大程度。
    基于此，AdaReP的核心思想是：**当当前偏差大或系统很敏感时，应紧缩公差，频繁重规划；反之，则放松公差，重用计划以节省计算。**
- **关键技术细节**：
    1.  **在线监控信号**：
        - **偏差`d_t`**：真实状态 `x_t` 与缓存计划中对应状态 `ˆy_t` 在“监控空间”（如潜在空间或特征空间）的距离： `d_t = ||z_t - ˆz_t||_2`。

    2.  **自适应阈值机制**：
        - 核心公式： `ϵ_{t+1} = ϵ_0 * exp(-α_δ * d_{t+1}) * exp(-α_L * L_t)`
        - 参数含义：`ϵ_0` 是基础阈值；`α_δ` 和 `α_L` 是权重系数，用于控制偏差和敏感性对阈值的抑制程度；`d_{t+1}` 和 `L_t` 通过滑动窗口平均以增加稳定性。
        - **原理**：公式采用指数衰减形式，可以将遗憾分析中受敏感性和偏差放大的惩罚项（如 `L_t^2 * ϵ_t^2` 和 `L_t^2 * ϵ_t * s_t`）转化为由 `(ϵ_0, α_δ, α_L)` 控制的均匀项，确保性能可控。
    3.  **部署流程（Algorithm 1）**：
        - 初始化时规划一次，得到完整的行动序列。
        - 在每个时间步，执行当前控制动作，观测新状态 `x_{t+1}`。

        - 根据更新后的值计算新的自适应阈值 `ϵ_{t+1}`。
        - **触发重规划的条件**：如果当前偏差 `d_{t+1}` 超过了计算出的自适应阈值 `ϵ_{t+1}`，或者缓存计划的已执行长度超过其本身，则触发一次全新的重规划。
